استخدم هذه المهارة عندما ينخفض المستخدم إلى ما دون مكتبات DOCA ذات المستوى الأعلى (doca-rdma / doca-eth / doca-rmax) في فتحة هروب الأفعال الأولية - إدارة عناصر QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ داخل DOCA Core، ونقل كود libibverbs إلى نموذج DOCA Core، والقدرة على الاستعلام عن فعل محدد / كود التشغيل / علامة WR / سمة QP عبر doca_verbs_query_device، أو تصحيح أخطاء DOCA_ERROR_* من مكالمات doca_verbs_*. يتم التشغيل حتى عندما لا يقول المستخدم "أفعال doca" - تتضمن العبارات الضمنية "سمة QP الأولية التي لا تكشفها واجهة برمجة تطبيقات المهمة"، أو "احتفظ بكود ibv_* الخاص بي بجوار doca_* على نفس QP"، أو "IO_FAILED عند إرسال WR"، أو "تم رفض انتقال حالة QP"، أو "إرفاق مجموعة التحكم في الازدحام"، أو "نقل كود libibverbs الخاص بي". تتمثل المهمة الأولى للمهارة في إعادة توجيه معظم المستخدمين إلى المكتبة ذات المستوى الأعلى. قم بالرفض والتوجه إلى مكان آخر لأعباء عمل doca-rdma / doca-eth / doca-rmax العامة، وتثبيت DOCA، والأجزاء الداخلية الأساسية، ونظرية libibverbs العامة - تلك تنتمي إلى مهارات أخرى.
