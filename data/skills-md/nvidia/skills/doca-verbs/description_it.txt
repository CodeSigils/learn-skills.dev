Utilizzare questa abilità quando l'utente scende al di sotto delle librerie DOCA di livello superiore (doca-rdma / doca-eth / doca-rmax) nella via di fuga dei verbi grezzi: gestendo le primitive QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ all'interno di DOCA Core, portando il codice dei verbi libib nel modello DOCA Core, interrogando con capacità uno specifico verbo / codice operativo / flag WR / attributo QP tramite doca_verbs_query_device o eseguire il debug di DOCA_ERROR_* dalle chiamate doca_verbs_*. Si attiva anche quando l'utente non dice "doca-verbs" — le frasi implicite includono "attributo QP grezzo che l'API dell'attività non espone", "mantieni il mio codice ibv_* accanto a doca_* sullo stesso QP", "IO_FAILED all'invio WR", "transizione dello stato QP rifiutata", "collega un gruppo di controllo della congestione" o "porting del mio codice libibverbs". Il primo compito della competenza è reindirizzare la MAGGIOR PARTE degli utenti alla libreria di livello superiore. Rifiuta e indirizza altrove i carichi di lavoro generali di doca-rdma / doca-eth / doca-rmax, l'installazione di DOCA, i componenti interni del core e la teoria generale dei libibverbs: quelli appartengono ad altre competenze.
