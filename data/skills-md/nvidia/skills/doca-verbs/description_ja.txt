このスキルは、ユーザーが上位レベルの DOCA ライブラリ (doca-rdma / doca-eth / doca-rmax) よりも下位の raw-verbs エスケープ ハッチにドロップするときに使用します。つまり、DOCA コア内の QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ プリミティブの管理、libibverbs コードの DOCA コア モデルへの移植、特定の動詞 / オペコード / WR の機能クエリを実行します。 doca_verbs_query_device 経由の flag / QP 属性、または doca_verbs_* 呼び出しからの DOCA_ERROR_* のデバッグ。ユーザーが「doca-verbs」と言わなくてもトリガーします。暗黙的な表現には、「タスク API が公開しない生の QP 属性」、「同じ QP 上の doca_* の隣に ibv_* コードを保持する」、「WR 送信時の IO_FAILED」、「QP 状態遷移が拒否されました」、「輻輳制御グループのアタッチ」、または「libibverbs コードの移植」が含まれます。スキルの最初の仕事は、ほとんどのユーザーを上位レベルのライブラリに戻すことです。一般的な doca-rdma / doca-eth / doca-rmax ワークロード、DOCA インストール、コア内部、および一般的な libibverbs 理論については、拒否して別の場所にルーティングします。これらは他のスキルに属します。
