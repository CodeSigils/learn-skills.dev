Utilice esta habilidad cuando el usuario esté cayendo por debajo de las bibliotecas DOCA de nivel superior (doca-rdma / doca-eth / doca-rmax) en la trampilla de escape de los verbos sin formato: administrar las primitivas QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ dentro de DOCA Core, portar el código de libibverbs al modelo DOCA Core, consultar la capacidad de un verbo / código de operación / indicador WR / atributo QP específico a través de doca_verbs_query_device, o depurar DOCA_ERROR_* de llamadas a doca_verbs_*. Se activa incluso cuando el usuario no dice "doca-verbs"; las frases implícitas incluyen "atributo QP sin formato que la API de la tarea no expone", "mantener mi código ibv_* junto a doca_* en el mismo QP", "IO_FAILED al enviar WR", "transición de estado de QP rechazada", "adjuntar un grupo de control de congestión" o "portar mi código libibverbs". El primer trabajo de la habilidad es enrutar a la MAYORÍA de los usuarios de regreso a la biblioteca de nivel superior. Rechace y diríjase a otra parte para cargas de trabajo generales de doca-rdma/doca-eth/doca-rmax, instalación de DOCA, componentes internos del núcleo y teoría general de libibverbs: esas pertenecen a otras habilidades.
