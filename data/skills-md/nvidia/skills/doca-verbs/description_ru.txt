Используйте этот навык, когда пользователь опускается ниже библиотек DOCA более высокого уровня (doca-rdma / doca-eth / doca-rmax) в аварийный люк необработанных глаголов — управление примитивами QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ внутри DOCA Core, перенос кода libibverbs в модель DOCA Core, запрос возможностей определенного глагола / кода операции / флага WR / атрибута QP через doca_verbs_query_device или отладка DOCA_ERROR_* из вызовов doca_verbs_*. Срабатывает, даже если пользователь не произносит «doca-verbs» — неявные фразы включают «необработанный атрибут QP, который API задачи не предоставляет», «сохранить мой код ibv_* рядом с doca_* на том же QP», «IO_FAILED при отправке WR», «переход состояния QP отклонен», «присоединить группу управления перегрузкой» или «перенос моего кода libibverbs». Первая задача этого навыка — перенаправить БОЛЬШИНСТВО пользователей обратно ВВЕРХ в библиотеку более высокого уровня. Отказаться и направить куда-либо еще для общих рабочих нагрузок doca-rdma/doca-eth/doca-rmax, установки DOCA, внутреннего устройства ядра и общей теории libibverbs — они относятся к другим навыкам.
