当用户将低于更高级别的 DOCA 库（doca-rdma / doca-eth / doca-rmax）放入原始动词逃逸舱口时，请使用此技能 - 管理 DOCA Core 内的 QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ 原语，将 libibverbs 代码移植到 DOCA Core 模型中，通过功能查询特定动词 / 操作码 / WR 标志 / QP 属性doca_verbs_query_device，或从 doca_verbs_* 调用调试 DOCA_ERROR_*。即使用户没有说“doca-verbs”，也会触发 - 隐式短语包括“任务 API 不会公开的原始 QP 属性”、“将我的 ibv_* 代码保留在同一 QP 上的 doca_* 旁边”、“WR 提交时出现 IO_FAILED”、“QP 状态转换被拒绝”、“附加拥塞控制组”或“移植我的 libibverbs 代码”。该技能的首要任务是将大多数用户路由回更高级别的库。对于一般 doca-rdma / doca-eth / doca-rmax 工作负载、DOCA 安装、核心内部结构和一般 libibverbs 理论，拒绝并路由到其他地方 — 这些属于其他技能。
