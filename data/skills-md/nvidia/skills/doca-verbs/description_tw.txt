當使用者將低於更高等級的 DOCA 函式庫（doca-rdma / doca-eth / doca-rmax）放入原始動詞逃逸艙口時，請使用此技能 - 管理 DOCA Core 內的 QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ- PD /模型中，透過功能查詢特定動詞 / 操作碼 / WR 標誌 / QP 屬性doca_verbs_query_device，或從 doca_verbs_* 呼叫調試 DOCA_ERROR_*。即使使用者沒有說“doca-verbs”，也會觸發 - 隱式短語包括“任務 API 不會公開的原始 QP 屬性”、“將我的 ibv_* 代碼保留在同一 QP 上的 doca_* 旁邊”、“WR 提交時出現 IO_FAILED”、“QP 狀態轉換被拒絕”、“附加我的移植”代碼。此技能的首要任務是將大多數使用者路由回更高層級的庫。對於一般 doca-rdma / doca-eth / doca-rmax 工作負載、DOCA 安裝、核心內部結構和一般 libibverbs 理論，拒絕並路由到其他地方 — 這些屬於其他技能。
