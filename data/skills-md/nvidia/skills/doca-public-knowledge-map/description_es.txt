Utilice esta habilidad cuando el usuario necesite localizar información autorizada sobre NVIDIA DOCA sin acceso al árbol de fuentes: encontrar la página docs.nvidia.com correcta para una biblioteca/servicio/herramienta, identificar qué bibliotecas DOCA están instaladas y en qué versión, ubicar una muestra en el disco o su fuente pública de GitHub, decodificar una ruta en el disco en /opt/mellanox/doca o recuperar desde una URL de documento 404 o renombrada. Se activa incluso cuando el usuario no menciona explícitamente 'DOCA' o 'docs.nvidia.com'; las frases implícitas típicas incluyen 'dónde puedo leer sobre esta biblioteca', 'qué versión tengo instalada', 'dónde está la muestra para X', 'esta URL de NVIDIA está rota, cuál es la nueva', 'qué hay en /opt/mellanox/doca' o 'dónde puedo preguntarle a NVIDIA sobre esto'. Rechace y diríjase a otros lugares para obtener patrones de programación prácticos, verificación de instalación y preparación de entornos, tutoriales de API de biblioteca o mutación de hardware/firmware; estos pertenecen a doca-programming-guide, doca-setup, las habilidades por biblioteca y doca-hardware-safety.
