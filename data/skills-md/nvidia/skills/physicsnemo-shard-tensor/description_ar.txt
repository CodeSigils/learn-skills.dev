التوجيه الرسمي من NVIDIA لتوازي مجال PhysicsNeMo ShardTensor — دمج توازي المجال في نصوص التدريب/الاستدلال (الجديدة أو الحالية) مع DDP أو FSDP2، وكتابة تصحيحات الأجزاء وتسجيلها لتمكين الطبقات/العمليات الجديدة، واختبارات صحة وحدات معالجة الرسومات المتعددة. يُستخدم عند العمل مع ShardTensor، أو scatter_tensor، أو توازي المجال، أو التجزئة التسلسلية/المكانية، أو انتباه الحلقة، أو التوازي المختلط DeviceMesh + DDP/FSDP2، أوphysicnemo.domain_parallel. لا تستخدم لإعداد PyTorch DDP/FSDP العام بدون توازي المجال، أو اختيار نموذج PhysicsNeMo أو مثال (استخدم Physicsnemo-discover)، أو أسئلة التدريب غير الموزعة.
