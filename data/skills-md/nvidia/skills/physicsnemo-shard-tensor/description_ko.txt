PhysicsNeMo ShardTensor 도메인 병렬 처리에 대한 공식 NVIDIA 작성 지침 — DDP 또는 FSDP2를 사용하여 도메인 병렬 처리를 교육/추론 스크립트(신규 또는 기존)에 통합하고 샤드 패치를 작성 및 등록하여 새 레이어/작업을 활성화하고 다중 GPU 정확성 테스트를 부트스트랩합니다. ShardTensor, 분산_텐서, 도메인 병렬 처리, 시퀀스/공간 샤딩, 링 어텐션, DeviceMesh + DDP/FSDP2 하이브리드 병렬 처리 또는 물리네모.도메인_병렬 처리를 사용할 때 사용합니다. 도메인 병렬 처리가 없는 일반 PyTorch DDP/FSDP 설정, PhysicsNeMo 모델이나 예제 선택(physicsnemo-discover 사용) 또는 비분산 교육 질문에는 사용하지 마세요.
