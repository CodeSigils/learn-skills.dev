Utilice esta habilidad cuando el usuario esté operando el contenedor del Servicio DOCA Firefly en BlueField: seleccionando los cuatro ejes de configuración de PTP (rol/perfil/dominio/interfaz), cableando el emparejamiento de carga de trabajo de BlueField PHC + seguidor de host + consumidor, decidiendo si se necesita tiempo de grado PTP (vs. chrony/NTP) o depurando una implementación de Firefly donde PTP no se sincroniza o el reloj del host no sigue. Se activa incluso cuando el usuario no menciona explícitamente "DOCA Firefly" o "PTP"; las frases implícitas típicas incluyen "contenedor verde pero PTP nunca pasa de ESCUCHAR", "Firefly dice sincronizado pero el reloj del host aún se desvía", "sincronización adquirida pero el desplazamiento es de decenas de microsegundos", "mi carga de trabajo Rivermax SMPTE necesita PTP" o "es lo suficientemente bueno". Rechazar y enrutar a otro lugar para instalar DOCA, cuerpos de configuración chrony/ptp4l del lado del host, topología PTP/diseño de reloj límite, creación de aplicaciones DOCA que leen el PHC disciplinado u otros servicios DOCA (DMS, Flow-Inspector, HBN): esas pertenecen a otras habilidades.
