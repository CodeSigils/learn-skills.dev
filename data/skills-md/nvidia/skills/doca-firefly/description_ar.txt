استخدم هذه المهارة عندما يقوم المستخدم بتشغيل حاوية DOCA Firefly Service على BlueField - اختيار محاور تكوين PTP الأربعة (الدور / الملف الشخصي / المجال / الواجهة)، أو توصيل توصيلات BlueField PHC + تابع المضيف + إقران حمل عمل المستهلك، أو تحديد ما إذا كانت هناك حاجة إلى وقت على مستوى PTP (مقابل chrony / NTP)، أو تصحيح أخطاء نشر Firefly حيث لا تتم مزامنة PTP أو لا تتابع الساعة المضيفة. يتم تشغيله حتى عندما لا يذكر المستخدم صراحةً "DOCA Firefly" أو "PTP" - تتضمن العبارات الضمنية النموذجية "الحاوية الخضراء ولكن PTP لا يتقدم أبدًا بعد الاستماع"، أو "يقول Firefly تمت المزامنة ولكن الساعة المضيفة لا تزال تنحرف"، أو "تم الحصول على المزامنة ولكن الإزاحة تبلغ عشرات الميكروثانية"، أو "يحتاج عبء عمل Rivermax SMPTE الخاص بي إلى PTP"، أو "متزامن بشكل جيد". ارفض ووجه إلى مكان آخر لتثبيت DOCA، أو أجسام تكوين chrony / ptp4l من جانب المضيف، أو طوبولوجيا PTP / تصميم الساعة الحدودية، أو إنشاء تطبيقات DOCA التي تقرأ مراكز الرعاية الصحية الأولية المنضبطة، أو خدمات DOCA الأخرى (DMS، أو Flow-Inspector، أو HBN) - تلك تنتمي إلى مهارات أخرى.
