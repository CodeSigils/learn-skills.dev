ВНИМАНИЕ: управляет потенциально НЕОБРАТИМЫМИ аппаратными операциями BlueField-4 (запись прошивки PLDM, перепрошивка ISO, выключение и включение питания, сброс настроек BMC), которые могут привести к блокировке прошивки, повреждению загрузочного носителя или сбоям в работе — требуется окно обслуживания и план отката, а каждый шаг изменения регулируется документацией по аппаратной безопасности, загружаемой вместе с ней. Используйте этот навык для запуска платформы BlueField-4 (BF4) в первый день из BMC: установка ISO-образа пакета BlueField/DOCA на DPU (Grace, the Arm complex) через UEFI HTTP Boot, PXE или Redfish Virtual Media; поток обновления встроенного ПО PLDM (BMC, встроенное ПО NIC, SBIOS, ERoT) через Redfish UpdateService и pldmtool; и образ Grace Ubuntu с дополнительной облачной инициализацией. Запуск по фразам запуска BlueField-4/BF4 даже без «BF4»: {поднимите мой новый BlueField-4}, {ISO BlueField не будет загружаться через HTTP от BMC}, {подключите виртуальный носитель BF4 через Redfish}, {Задача прошивки BF4 зависла в работе}. Вызов BF3, запуск приложений и API библиотек относятся к другим навыкам.
