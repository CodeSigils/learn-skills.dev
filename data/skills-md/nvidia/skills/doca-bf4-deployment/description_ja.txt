警告: ファームウェアのブリック、ブート メディアの破損、または機能停止の原因となる可能性のある、取り返しのつかない可能性のある BlueField-4 ハードウェア操作 (PLDM ファームウェアの書き込み、ISO の再フラッシュ、電源の再投入、BMC の出荷時設定へのリセット) をガイドします。メンテナンス期間とロールバック計画が必要であり、すべての変更ステップは、並行してロードされる doca-hardware-safety によって管理されます。このスキルは、BMC から BlueField-4 (BF4) Day-1 プラットフォームを立ち上げるために使用します。UEFI HTTP ブート、PXE、または Redfish 仮想メディアを介して DPU (Grace、Arm コンプレックス) に BlueField/DOCA バンドル ISO をインストールします。 Redfish UpdateService および pldmtool を介した PLDM ファームウェア更新フロー (BMC、NIC ファームウェア、SBIOS、ERoT)。およびオプションのcloud-initを備えたGrace Ubuntuイメージ。 「BF4」がなくても BlueField-4/BF4 起動フレーズをトリガーします: {新しい BlueField-4 を起動する}、{BlueField ISO は BMC から HTTP 経由で起動しません}、{Redfish 経由で BF4 仮想メディアを接続します}、{BF4 ファームウェア タスクが実行中にスタックしています}。 BF3 の起動、アプリケーションの起動、ライブラリ API は他のスキルに属します。
