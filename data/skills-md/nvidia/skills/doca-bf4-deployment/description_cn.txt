警告：指导潜在的不可逆的 BlueField-4 硬件操作（PLDM 固件烧录、ISO 刷新、电源循环、BMC 出厂重置），这些操作可能会损坏固件、损坏启动介质或导致中断 - 需要维护窗口和回滚计划，并且每个变异步骤都由同时加载的 doca-hardware-safety 控制。使用此技能从 BMC 启动 BlueField-4 (BF4) day-1 平台：通过 UEFI HTTP Boot、PXE 或 Redfish 虚拟介质将 BlueField/DOCA 捆绑 ISO 安装到 DPU（Grace、Arm 复合体）上；通过 Redfish UpdateService 和 pldmtool 的 PLDM 固件更新流程（BMC、NIC 固件、SBIOS、ERoT）；以及带有可选 cloud-init 的 Grace Ubuntu 映像。即使没有“BF4”，也会触发 BlueField-4/BF4 启动短语：{启动我的新 BlueField-4}、{BlueField ISO 不会从 BMC 通过 HTTP 启动}、{通过 Redfish 连接 BF4 虚拟媒体}、{BF4 固件任务卡在运行状态}。 BF3 启动、应用程序启动和库 API 属于其他技能。
