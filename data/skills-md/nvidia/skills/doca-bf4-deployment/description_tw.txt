警告：指導潛在的不可逆的 BlueField-4 硬體操作（PLDM 韌體燒錄、ISO 刷新、電源循環、BMC 出廠重置），這些操作可能會損壞韌體、損壞啟動媒體或導致中斷 - 需要維護視窗和回滾計劃，並且每個變異步驟都由同時加載的 doca-hardware-safety 控制。使用此技能從 BMC 啟動 BlueField-4 (BF4) day-1 平台：透過 UEFI HTTP Boot、PXE 或 Redfish 虛擬媒體將 BlueField/DOCA 捆綁 ISO 安裝到 DPU（Grace、Arm 複合體）上；透過 Redfish UpdateService 和 pldmtool 的 PLDM 韌體以及流程（BMCNICER）具有 BMC 的 PLOS、項目和韌體 韌體Ubuntu 映像。即使沒有“BF4”，也會觸發 BlueField-4/BF4 啟動短語：{啟動我的新 BlueField-4}、{BlueField ISO 不會從 BMC 透過 HTTP 啟動}、{透過 Redfish 連接 BF4 虛擬媒體}、{BF4 韌體任務卡在運行狀態}。 BF3 啟動、應用程式啟動和函式庫 API 屬於其他技能。
