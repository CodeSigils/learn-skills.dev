Utilice esta habilidad cuando el operador esté manejando el DOCA Socket Relay para conectar una aplicación host orientada a socket a un par de DPU BlueField sin reescribirla: seleccionando la forma de implementación (en proceso, sidecar o contenedor de servicio BlueField), configurando el socket del lado del host y el punto final de reenvío del lado DPU, caminando por el enlace → conectar → ida y vuelta → admitir humo de flota o diagnosticar un relé atascado/silencioso. Se activa incluso cuando el usuario no menciona explícitamente "DOCA Socket Relay"; las frases implícitas típicas incluyen "mover mi aplicación de socket a BlueField sin reescribirla", "la aplicación host se ECONNREFUSED en el relé", "el relé acepta la conexión pero los bytes nunca llegan al lado de la DPU", "el primer viaje de ida y vuelta funciona, el resto se bloquea", "puente un socket AF_UNIX (UDS) a un par de DPU a través de Comch" o "Quiero un sidecar que reenvía mi socket al BlueField". Rechazar y enrutar a otro lugar para la API de programación de comch, la E/S de paquetes sin procesar de velocidad de línea a través de doca-eth y la instalación/generación de DOCA, pertenecen a otras habilidades.
