Instances GPU gérées par Brev avec prise en charge de Docker. À utiliser lors de l'exécution d'une formation, d'une évaluation ou d'une inférence TAO sur des instances GPU Brev, de la gestion des déploiements Brev ou de la distribution de tâches TAO via la CLI Brev. Les expressions de déclenchement incluent « exécuter sur Brev », « instance GPU Brev », « soumettre le travail à Brev », « déploiement CLI Brev ».
