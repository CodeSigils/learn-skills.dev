当用户拥有现有的 DPDK 应用程序并就地添加 DOCA 功能（最常见的是 DOCA Flow 硬件控制）而无需以 DOCA 原生形式重写数据平面时，请使用此技能：将 DPDK 端口 ID 绑定到 `doca_dev` (`doca_dpdk_port_probe` / `doca_dpdk_port_as_dev`)，转换 `rte_mbuf` ↔ `doca_buf`，查詢`doca_dpdk_cap_is_rep_port_supported`，或從橋接呼叫調試`DOCA_ERROR_*`。即使沒有“DOCA DPDK Bridge”，也會觸發：“如何將 DOCA Flow 新增至我的 DPDK 應用程式”、“使 DPDK 連接埠對 DOCA 可見”、“橋加載但每個操作都會傳回錯誤”、“pkg-config --exists doca-dpdk-bridge 失敗”或“連接埠在其他地方路由新的 DOCA 本機資料包 I/O (doca-eth)、流規則程式設計 (doca-flow)、DOCA 或 DPDK 安裝 (doca-setup) 或 RDMA 資料移動 (doca-rdma)。
