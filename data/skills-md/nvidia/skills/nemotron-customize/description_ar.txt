تخطيط وتكوين وتسلسل خطوات تخصيص Nemotron الأصلية في خطوط أنابيب أحادية الخطوة أو متعددة الخطوات: المعالجة والترجمة وSFT/PEFT (AutoModel أو Megatron-Bridge)، والتدريب المسبق/CPT، ومحاذاة RL (DPO/RLVR/GRPO/RLHF)، ومعايير BYOB/MCQ، وتحويل نقاط التفتيش، وتحسين ModelOpt، وملفات تعريف env، وتقييم نقاط التفتيش المدربة أو نقاط النهاية الحالية/المستضافة. يُستخدم عندما يقوم طلب بتسمية خطوة Nemotron أو سير عمل، أو يطلب تنظيفها أو ترجمتها أو تدريبها أو تحسينها أو محاذاتها أو تحويلها أو تحسينها أو تقييمها أو إنشائها في مسار. لا تستخدمه في أعمال الواجهة الأمامية/لوحة المعلومات/التصور، أو نصائح ML العامة، أو الفوترة/الوصول، أو مهام الترميز غير المتعلقة بـ Nemotron.
