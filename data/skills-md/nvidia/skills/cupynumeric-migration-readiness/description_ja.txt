NumPy を cuPyNumeric に移植するための移行前準備状況評価ツール。コードが GPU 上でスケーリングするかどうか、cuPyNumeric に移行する必要があるかどうか、どの NumPy パターンがきれいに転送されるか、移植前に何をリファクタリングする必要があるか、または移植前評価、スケーリング分析、またはリファクタリング計画についてユーザーが尋ねた場合、実質的な移植作業が始まる前に使用してください。ユーザーのソース コードを検査し、NumPy の使用状況を調べ、cuPyNumeric API サポート マニフェストを相互参照し、分散スケーリングに適したパターンを、サポートされていない API、スカラー同期、ホスト ラウンドトリップ、Python/オブジェクトを多用する制御フロー、形状/データ依存の分岐、インプレース変更の危険などのブロッカーから区別します。具体的なリファクタリング ポインタを使用して、READY、LIGHT REFACTOR、SIGNIFICANT REFACTOR、または NOT RECOMMENDED の判定を生成します。
