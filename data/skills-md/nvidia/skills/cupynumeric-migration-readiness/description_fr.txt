Évaluateur de préparation à la migration pour le portage de NumPy vers cuPyNumeric. À utiliser AVANT le début d'un travail de portage substantiel lorsque l'utilisateur demande si le code sera mis à l'échelle sur le GPU, s'il doit migrer vers cuPyNumeric, quels modèles NumPy transfèrent proprement, ce qui doit être refactorisé avant le portage, ou mentionne une évaluation préalable au portage, une analyse de mise à l'échelle ou une planification de refactorisation. Inspectez le code source de l'utilisateur, recherchez l'utilisation de NumPy, croisez le manifeste de prise en charge de l'API cuPyNumeric et distinguez les modèles compatibles avec la mise à l'échelle distribuée des bloqueurs tels que les API non prises en charge, la synchronisation scalaire, les allers-retours de l'hôte, le flux de contrôle Python/objet-lourd, le branchement dépendant de la forme/des données et les risques de mutation sur place. Produisez un verdict de PRÊT, RÉFACTEUR LÉGER, RÉFACTEUR SIGNIFICATIF ou NON RECOMMANDÉ, avec des pointeurs de refactor concrets.
