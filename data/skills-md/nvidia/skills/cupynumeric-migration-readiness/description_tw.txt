用於將 NumPy 移植到 cuPyNumeric 的遷移前準備評估器。當使用者詢問程式碼是否可以在 GPU 上擴展、是否應該遷移到 cuPyNumeric、哪些 NumPy 模式可以乾淨地傳輸、移植前必須重構什麼，或者提到移植前評估、擴展分析或重構規劃時，請在大量移植工作開始之前使用。檢查使用者的原始程式碼、尋找 NumPy 使用情況、交叉引用 cuPyNumeric API 支援清單，並將分散式擴充友善模式與阻礙因素（例如不支援的 API、標量同步、主機往返、Python/物件密集型控制流、形狀/資料相關分支和就地突變危險）區分開來。使用具體的重構指標產生「就緒」、「輕度重構」、「重要重構」或「不建議」的判斷。
