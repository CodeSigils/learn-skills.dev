사용자가 직접 DOCA Flow DPA Provider 작업을 수행할 때 이 기술을 사용하십시오. 'doca-flow' 파이프 또는 외부 리소스(인덱스 선택기/메모리)를 BlueField DPA 주소 공간으로 내보내 DPACC 구축 커널이 Flow와 함께 인라인으로 카운터를 읽고, 해시 파이프 항목을 변경하고, 메모리 또는 인덱스 선택기 리소스를 업데이트/읽을 수 있도록 합니다. 포트별 `doca_flow_dpa_ctx`, 세 가지 대기열 유형(일반/resources-write/resources-read), 순서 구분 내보내기 핸드셰이크(`_export_prepare` → 항목 추가 → `_export` → `_get_device_addr`) 및 DPA 측 장치 API를 다룹니다. 사용자가 "DOCA Flow DPA Provider"라고 말하지 않는 경우에도 트리거됩니다. 암시적 문구에는 "DPA 커널이 내보낸 파이프의 항목을 표시하지 않습니다.", "`_pipe_export`의 BAD_STATE", "DPA 커널에서 해시 항목을 비활성화하는 방법", "DPA 메모리 읽기가 값을 반환하지 않습니다." 또는 "DPA 측 게시물이 계속 AGAIN을 반환합니다."가 포함됩니다. `doca-flow` 파이프 구성, 일반 호스트 측 DPA(`doca-dpa`) 또는 DPA 측 커널 작성을 거부하고 다른 곳으로 라우팅하세요. 이러한 것들은 다른 기술에 속합니다.
