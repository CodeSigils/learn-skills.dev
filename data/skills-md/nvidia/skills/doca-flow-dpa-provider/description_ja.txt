このスキルは、ユーザーが DOCA Flow DPA プロバイダーの実践的な作業、つまり「doca-flow」パイプまたは外部リソース (インデックス セレクター/メモリ) を BlueField DPA アドレス空間にエクスポートするときに使用します。これにより、DPACC で構築されたカーネルは、カウンターの読み取り、ハッシュ パイプ エントリの変更、フローとインラインでのメモリまたはインデックス セレクター リソースの更新/読み取りを行うことができます。ポートごとの `doca_flow_dpa_ctx`、3 つのキュー タイプ (general/resources-write/resources-read)、順序依存のエクスポート ハンドシェイク (`_export_prepare` → エントリの追加 → `_export` → `_get_device_addr`)、および DPA 側のデバイス API をカバーします。ユーザーが「DOCA Flow DPA Provider」と言わなくてもトリガーされます。暗黙的な表現には、「DPA カーネルはエクスポートされたパイプ内のエントリを決して認識しません」、「`_pipe_export` からの BAD_STATE」、「DPA カーネルからのハッシュ エントリを無効にするにはどうすればよいですか」、「DPA メモリ読み取りで値が返されない」、「DPA 側のポストが AGAIN を返し続ける」などがあります。 「doca-flow」パイプ構築、汎用ホスト側 DPA (「doca-dpa」)、または DPA 側カーネル作成については、拒否して別の場所にルーティングします。これらは他のスキルに属します。
