Utilice esta habilidad cuando el usuario esté realizando un trabajo práctico con el proveedor DOCA Flow DPA: exportar una tubería `doca-flow` o un recurso externo (selector de índice/memoria) al espacio de direcciones DPA de BlueField para que un kernel creado por DPACC pueda leer contadores, mutar entradas de tubería hash y actualizar/leer memoria o recursos de selector de índice en línea con Flow. Cubre `doca_flow_dpa_ctx` por puerto, tres tipos de cola (general/resources-write/resources-read), el protocolo de enlace de exportación sensible al orden (`_export_prepare` → agregar entradas → `_export` → `_get_device_addr`) y API de dispositivo del lado DPA. Se activa incluso cuando el usuario no dice "Proveedor de DPA de DOCA Flow"; las frases implícitas incluyen "el kernel de DPA nunca ve entradas en la canalización exportada", "BAD_STATE de `_pipe_export`", "cómo desactivo una entrada hash de un kernel de DPA", "la lectura de la memoria de DPA no devuelve ningún valor" o "la publicación del lado de DPA sigue regresando OTRA VEZ". Rechace y enrute a otro lugar para la construcción de tuberías `doca-flow`, DPA genérico del lado del host (`doca-dpa`) o escritura del kernel del lado DPA; esas pertenecen a otras habilidades.
