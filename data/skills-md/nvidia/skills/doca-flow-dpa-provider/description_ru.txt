Используйте этот навык, когда пользователь выполняет практическую работу с провайдером DOCA Flow DPA — экспортирует канал `doca-flow` или внешний ресурс (селектор индекса/память) в адресное пространство BlueField DPA, чтобы встроенное в DPACC ядро ​​могло считывать счетчики, изменять записи хэш-канала и обновлять/считывать ресурсы памяти или селектора индекса, встроенные в Flow. Охватывает `doca_flow_dpa_ctx` для каждого порта, три типа очередей (general/resources-write/resources-read), чувствительное к порядку экспортное рукопожатие (`_export_prepare` → добавить записи → `_export` → `_get_device_addr`) и API устройства на стороне DPA. Срабатывает, даже если пользователь не произносит «Поставщик DPA потока DOCA» — неявные фразы включают «Ядро DPA никогда не видит записи в экспортированном канале», «BAD_STATE из `_pipe_export`», «как отключить хеш-запись из ядра DPA», «Чтение памяти DPA не возвращает никакого значения» или «Сообщение на стороне DPA продолжает возвращать СНОВА». Отказываться и направлять куда-либо еще для построения канала `doca-flow`, общего DPA на стороне хоста (`doca-dpa`) или написания ядра на стороне DPA — это относится к другим навыкам.
