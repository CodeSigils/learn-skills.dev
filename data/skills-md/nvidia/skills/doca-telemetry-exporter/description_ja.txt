このスキルは、ユーザーが DOCA がインストールされているホスト上で実践的な DOCA Telemetry Exporter プログラミングを行う場合、つまり doca_telemetry_exporter_schema の定義、ソースの作成、カウンター/ゲージ/イベント タイプの選択、制限を想定する前の機能クエリの実行、最初の出力前のスキーマの登録、またはエクスポーター API からの DOCA_ERROR_* エラーのデバッグを行うときに使用します。ユーザーが「DOCA Telemetry Exporter」または「doca_telemetry_exporter_*」を明示的に言及していない場合でもトリガーされます。一般的な暗黙的な表現には、「DOCA アプリからカウンターを公開する」、「バルク ロードで再度出力を返す」、「消費者はレポートの出力成功以外何も表示されない」、「最初の送信で NOT_FOUND が見つかりません」、または「エクスポーターまたはテレメトリ サービスをリンクする必要があります」などがあります。 DOCA Telemetry Service の受信を拒否して別の場所にルーティングする、doca_log を介したプレーンな stdout ログ、非 DOCA Prometheus のスクレープ シンク、または doca-comch を介してアプリに戻すリアルタイム イベント サブスクリプション - これらは他のスキルに属します。
