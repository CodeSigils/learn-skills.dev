当用户在安装了 DOCA 的主机上进行 DOCA Telemetry Exporter 实际编程时，请使用此技能 — 定义 doca_telemetry_exporter_schema、创建源、选择计数器/量规/事件类型、在假设限制之前运行功能查询、在第一次发出之前注册模式，或者从导出器 API 调试 DOCA_ERROR_* 故障。即使用户没有明确提及“DOCA Telemetry Exporter”或“doca_telemetry_exporter_*”，也会触发 - 典型的隐式短语包括“从我的 DOCA 应用程序发布计数器”、“在批量加载下再次发射返回”、“消费者除了发射报告成功之外什么也看不到”、“首次提交时未找到”或“我应该链接导出器或遥测服务”。拒绝并路由到其他地方以接收 DOCA 遥测服务、通过 doca_log 进行普通标准输出日志记录、非 DOCA Prometheus 抓取接收器或通过 doca-comch 将实时事件订阅回应用程序 — 这些属于其他技能。
