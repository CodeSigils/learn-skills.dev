使用此技能在 BlueField DPU、ConnectX NIC 或具有 DOCA 的主機上進行實踐 DOCA 壓縮編程 — 在 doca_compress 上下文上啟用 compress-deflate、decompress-deflate、decompress-lz4-stream 或 decompress-lz4-block 任務（硬體支援 DEFLATE 雙向上限以及 Llz4-stream 或 decompress-lz4-block 任務（硬體支援 DEFLATE 鍵支援以及 LZ4-194 L74 原始碼。 doca_buf 大小，設定 mmap權限，決定卸載與 CPU zlib / zstd，使用往返煙霧進行驗證，或從壓縮呼叫中調試 DOCA_ERROR_*。觸發諸如「卸載此 gzip」、「解壓縮傳入網路資料」、「壓縮任務在 alloc_init 上傳回 INVALID_VALUE」、「已提交任務但未完成」或「在 BlueField 上解壓縮 LZ4」等短語。拒絕並路由到其他地方的非 DEFLATE / 非 LZ4 演算法 (zstd / Snappy / brotli)、LZ4 編碼（路由到 CPU LZ4 函式庫）、純 mmap 到 mmap 副本 (doca-dma) 或 DOCA Core 生命週期內部結構。
