使用此技能在 BlueField DPU、ConnectX NIC 或具有 DOCA 的主机上进行实践 DOCA 压缩编程 — 在 doca_compress 上下文上启用 compress-deflate、decompress-deflate、decompress-lz4-stream 或 decompress-lz4-block 任务（硬件支持 DEFLATE 双向以及 LZ4 解压缩；不支持 LZ4 编码），根据每个任务上限查询调整源/目标 doca_buf 大小，设置 mmap权限，决定卸载与 CPU zlib / zstd，使用往返烟雾进行验证，或从压缩调用中调试 DOCA_ERROR_*。触发诸如“卸载此 gzip”、“解压缩传入网络数据”、“压缩任务在 alloc_init 上返回 INVALID_VALUE”、“已提交任务但未完成”或“在 BlueField 上解压缩 LZ4”等短语。拒绝并路由到其他地方的非 DEFLATE / 非 LZ4 算法 (zstd / Snappy / brotli)、LZ4 编码（路由到 CPU LZ4 库）、纯 mmap 到 mmap 副本 (doca-dma) 或 DOCA Core 生命周期内部结构。
