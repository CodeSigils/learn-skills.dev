仅纯文本：附带的“doca_flow_grpc”服务器使用“grpc::InsecureServerCredentials()”，二进制文件上没有 TLS / mTLS / 令牌身份验证旋钮 - 传输安全必须来自受信任段上的外部基础设施（例如 mTLS 代理/sidecar）。在启动、配置、强化或调试“doca_flow_grpc”时使用此技能 - DOCA 提供的 gRPC 远程控制界面位于“doca-flow”前面，允许非 C++ 客户端（Python、Go、Rust、Java）通过 RPC 对 Flow 管道和条目进行编程，而不是直接链接“libdoca_flow.so”。即使用户没有说“doca-flow-grpc-server”或“gRPC”也会触发 - 例如'从另一台主机上的 Python 编写 Flow 规则'、'在 BlueField 上远程配置管道'、'客户端连接到 Flow 服务器超时'、'Flow 的 .proto 在哪里'、'Flow RPC 上的 UNAUTHENTICATED / FAILED_PRECONDITION'。在其他地方路由底层 doca-flow API、通用 gRPC 工具（协议、语言绑定）或 DOCA 安装/BFB 启动。
