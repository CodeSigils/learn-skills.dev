일반 텍스트 전용: 제공된 `doca_flow_grpc` 서버는 바이너리의 TLS/mTLS/토큰 인증 손잡이 없이 `grpc::InsecureServerCredentials()`를 사용합니다. 전송 보안은 신뢰할 수 있는 세그먼트의 외부 인프라(예: mTLS 프록시/사이드카)에서 제공되어야 합니다. `doca_flow_grpc`를 시작, 구성, 강화 또는 디버깅할 때 이 기술을 사용하세요. `doca-flow` 앞에 DOCA 제공 gRPC 원격 제어 표면이 있어 `libdoca_flow.so`를 직접 연결하는 대신 비 C++ 클라이언트(Python, Go, Rust, Java)가 RPC를 통해 Flow 파이프와 항목을 프로그래밍할 수 있습니다. 사용자가 'doca-flow-grpc-server' 또는 'gRPC'라고 말하지 않는 경우에도 트리거됩니다. '다른 호스트의 Python에서 Flow 규칙 프로그래밍', 'BlueField에서 원격으로 파이프 구성', '클라이언트가 Flow 서버 연결 시간 초과', 'Flow에 대한 .proto는 어디에 있습니까?', 'Flow RPC에서 UNAUTHENTICATED/FAILED_PRECONDITION'. 기본 doca-flow API, 일반 gRPC 도구(프로토크, 언어 바인딩) 또는 DOCA 설치/BFB 가져오기를 위해 다른 곳으로 라우팅하세요.
