ТОЛЬКО PLAINTEXT: поставляемый сервер `doca_flow_grpc` использует `grpc::InsecureServerCredentials()` без ручки TLS / mTLS / аутентификации токена в двоичном файле — транспортная безопасность должна исходить из внешней инфраструктуры (например, прокси-сервера mTLS / сайдкара) в доверенном сегменте. Используйте этот навык при запуске, настройке, усилении или отладке `doca_flow_grpc` — поверхности удаленного управления gRPC, поставляемой DOCA, перед `doca-flow`, которая позволяет клиентам, не использующим C++ (Python, Go, Rust, Java), программировать потоки и записи Flow через RPC вместо прямого связывания `libdoca_flow.so`. Срабатывает, даже если пользователь не произносит «doca-flow-grpc-server» или «gRPC» — например. «запрограммировать правила Flow из Python на другом хосте», «удаленно настроить каналы на BlueField», «время ожидания клиента при подключении к серверу Flow», «где находится .proto для Flow», «UNAUTHENTICATED / FAILED_PRECONDITION на Flow RPC». Направьте в другое место базовый API-интерфейс doca-flow, общие инструменты gRPC (протокол, языковые привязки) или установку DOCA / запуск BFB.
