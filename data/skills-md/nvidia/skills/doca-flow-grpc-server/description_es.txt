SOLO TEXTO SIMPLE: el servidor `doca_flow_grpc` enviado usa `grpc::InsecureServerCredentials()` SIN botón TLS/mTLS/token-auth en el binario; la seguridad del transporte debe provenir de una infraestructura externa (por ejemplo, un proxy/sidecar mTLS) en un segmento confiable. Utilice esta habilidad al abrir, configurar, reforzar o depurar `doca_flow_grpc`: la superficie de control remoto gRPC enviada por DOCA frente a `doca-flow` que permite a los clientes que no son C++ (Python, Go, Rust, Java) programar canales y entradas de flujo a través de RPC en lugar de vincular `libdoca_flow.so` directamente. Se activa incluso cuando el usuario no dice 'doca-flow-grpc-server' o 'gRPC' (p. ej. 'programar reglas de flujo desde Python en otro host', 'configurar tuberías de forma remota en BlueField', 'el cliente agota el tiempo de conexión al servidor de Flow', 'dónde está el .proto para Flow', 'NO AUTHENTICADO/FAILED_PRECONDITION en un RPC de Flow'. Dirija a otro lugar para la API de flujo de doca subyacente, las herramientas gRPC genéricas (protocolo, enlaces de idiomas) o la instalación de DOCA/BFB.
