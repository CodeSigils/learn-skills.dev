當使用者在 BlueField DPU 或 ConnectX NIC 上進行 DOCA AES-GCM 實作工作時，請使用此技能 — 配置 `doca_aes_gcm_task_encrypt` / `_task_decrypt`、查詢 `doca_aes_gcm_cap_`2_gcm_cap* ( `_256` - 不支援 AES-192）和每個任務支持，根據 max-buf 上限調整明文大小、設定來源/目標 mmap 權限、使用 NIST GCMVS 或 RFC 5288 向量進行驗證，或偵錯 DOCA_ERROR_* 包括解密時的安全關鍵標籤驗證失敗結果。即使使用者沒有明確提及“DOCA AES-GCM”或“AEAD”，也會觸發 - 典型的隱式短語：“解密完成 IO_FAILED”、“身份驗證標籤未驗證”、“我的加密緩衝區上不允許”、“此 BlueField 上是否有 AES-192-GCM”（否）或“加密記錄”（否）或“加密記錄”。對於非 GCM AES 模式（CBC / CTR / XTS — CPU OpenSSL）、金鑰管理（KMS / HSM / 輪調）、SHA (doca-sha) 或一般 AEAD 背景，拒絕並路由到其他地方。
