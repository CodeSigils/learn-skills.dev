当用户在 BlueField DPU 或 ConnectX NIC 上进行 DOCA AES-GCM 实践工作时，请使用此技能 — 配置 `doca_aes_gcm_task_encrypt` / `_task_decrypt`、查询 `doca_aes_gcm_cap_*` 以获取每个密钥类型（仅 `DOCA_AES_GCM_KEY_128` / `_256` - 不支持 AES-192）和每个任务支持，根据 max-buf 上限调整明文大小、设置源/目标 mmap 权限、使用 NIST GCMVS 或 RFC 5288 矢量进行验证，或调试 DOCA_ERROR_* 包括解密时的安全关键标签验证失败结果。即使用户没有明确提及“DOCA AES-GCM”或“AEAD”，也会触发 - 典型的隐式短语：“解密完成 IO_FAILED”、“身份验证标签未验证”、“我的加密缓冲区上不允许”、“此 BlueField 上是否有 AES-192-GCM”（否）或“加密记录返回已被篡改”。对于非 GCM AES 模式（CBC / CTR / XTS — CPU OpenSSL）、密钥管理（KMS / HSM / 轮换）、SHA (doca-sha) 或一般 AEAD 背景，拒绝并路由到其他地方。
