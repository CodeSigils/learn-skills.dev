사용자가 BlueField DPU 또는 ConnectX NIC에서 직접 DOCA AES-GCM 작업을 수행할 때 이 기술을 사용하십시오. `doca_aes_gcm_task_encrypt` / `_task_decrypt` 구성, 키 유형별 `doca_aes_gcm_cap_*` 쿼리(`DOCA_AES_GCM_KEY_128` / `_256`만 지원 — AES-192는 지원되지 않음) 작업별 지원, max-buf 한도에 대한 일반 텍스트 크기 조정, 소스/대상 mmap 권한 설정, NIST GCMVS 또는 RFC 5288 벡터로 유효성 검사 또는 해독 시 보안에 중요한 태그 검증 실패 결과를 포함하여 DOCA_ERROR_* 디버깅 등이 있습니다. 사용자가 "DOCA AES-GCM" 또는 "AEAD"를 명시적으로 언급하지 않은 경우에도 트리거됩니다. 일반적인 암시적 표현: "암호 해독 완료 IO_FAILED", "인증 태그가 확인되지 않습니다", "내 암호화 버퍼에서 NOT_PERMITTED", "이 BlueField에서 AES-192-GCM입니다"(아니요) 또는 "암호화된 레코드가 변조되어 돌아왔습니다".
