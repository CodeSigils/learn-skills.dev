Utilice esta habilidad cuando el usuario esté realizando un trabajo práctico con DOCA AES-GCM en una DPU BlueField o una NIC ConnectX, configurando `doca_aes_gcm_task_encrypt` / `_task_decrypt`, consultando `doca_aes_gcm_cap_*` por tipo de clave (solo `DOCA_AES_GCM_KEY_128` / `_256` — AES-192 no compatible) y soporte por tarea, dimensionar texto sin formato con respecto al límite máximo de buf, configurar permisos mmap de origen/destino, validar con un vector NIST GCMVS o RFC 5288, o depurar DOCA_ERROR_*, incluido el resultado de error de verificación de etiqueta crítica para la seguridad al descifrar. Se activa incluso cuando el usuario no menciona explícitamente "DOCA AES-GCM" o "AEAD": frases implícitas típicas: "descifrado completado IO_FAILED", "la etiqueta de autenticación no se está verificando", "NOT_PERMITTED en mi búfer de cifrado", "es AES-192-GCM en este BlueField" (no) o "el registro cifrado regresó manipulado". Rechace y enrute a otro lugar para modos AES que no sean GCM (CBC / CTR / XTS - CPU OpenSSL), administración de claves (KMS / HSM / rotación), SHA (doca-sha) o antecedentes generales de AEAD.
