当用户在 BlueField 上亲自部署捆绑内 DOCA 服务容器（Argus、DMS、Firefly、Flow-Inspector、OS-Inspector、UROM 服务）时，请使用此技能 — kubelet 独立监视静态 pod 清单目录、YAML pod-spec 删除、kubelet 状态/ENTRYPOINT 日志/每个服务活跃度、smoke-before-bulk 和分层错误分类法（pod-spec、调度、镜像拉取、运行时、挂载、网络、版本、主机）。即使用户没有说“容器部署”，也会触发 - 典型的隐式短语包括“如何在 BlueField 上运行我构建的服务？”、“我在哪里放置 pod 规范 YAML？”、“pod 陷入 Pending / ImagePullBackOff / CrashLoopBackOff”、“容器正在运行但服务尚未准备好”、“编辑后 pod 重新启动循环”或“DMS 和 Firefly 在一起”。拒绝并路由到其他地方的每服务配置模式、DOCA 安装、库 API 问题、外部 NVIDIA 服务（BlueMan、HBN、SNAP、Virtio-net）或完整的 Kubernetes 集群操作 — 这些属于其他技能。
