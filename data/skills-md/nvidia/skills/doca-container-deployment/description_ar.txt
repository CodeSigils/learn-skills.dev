استخدم هذه المهارة عندما يقوم المستخدم بنشر حاوية خدمة DOCA ضمن الحزمة (Argus، وDMS، وFirefly، وFlow-Inspector، وOS-Inspector، وخدمة UROM) على BlueField — kubelet مستقل يراقب دليل بيانات البود الثابت، وإسقاط مواصفات pod YAML، وحالة kubelet / سجلات ENTRYPOINT / حيوية كل خدمة، والدخان قبل التجميع، والطبقات تصنيف الأخطاء (مواصفات الجراب، الجدولة، سحب الصور، وقت التشغيل، التثبيت، الشبكة، الإصدار، المضيف). يتم التشغيل حتى عندما لا يقول المستخدم "نشر الحاوية" - تتضمن العبارات الضمنية النموذجية "كيف يمكنني تشغيل الخدمة المضمنة الخاصة بي على BlueField؟"، أو "أين يمكنني إسقاط مواصفات YAML؟"، أو "الكبسولة عالقة في انتظار / ImagePullBackOff / CrashLoopBackOff"، أو "الحاوية قيد التشغيل ولكن الخدمة ليست جاهزة"، أو "حلقات إعادة تشغيل pod بعد التحرير"، أو "DMS وFirefly معًا". قم بالرفض والتوجيه إلى مكان آخر لمخططات التكوين لكل خدمة، أو تثبيت DOCA، أو أسئلة Library-API، أو خدمات NVIDIA الخارجية (BlueMan، أو HBN، أو SNAP، أو Virtio-net)، أو عمليات مجموعة Kubernetes الكاملة - تلك تنتمي إلى مهارات أخرى.
