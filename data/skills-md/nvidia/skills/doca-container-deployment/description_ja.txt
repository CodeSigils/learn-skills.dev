このスキルは、ユーザーがバンドル内 DOCA サービス コンテナ (Argus、DMS、Firefly、Flow-Inspector、OS-Inspector、UROM サービス) を BlueField に実際にデプロイするときに使用します。kubelet スタンドアロンで静的ポッド マニフェスト ディレクトリ、YAML ポッド仕様のドロップ、kubelet ステータス / ENTRYPOINT ログ / サービスごとの稼働状況、Smoke-Before-Bulk、および階層型エラー分類を監視します。 (ポッド仕様、スケジューリング、イメージプル、ランタイム、マウント、ネットワーク、バージョン、ホスト)。ユーザーが「コンテナのデプロイ」と言わなくてもトリガーします。典型的な暗黙の表現には、「BlueField でビルドしたサービスを実行するにはどうすればよいですか?」、「ポッド仕様の YAML をどこにドロップしますか?」、「ポッドが保留中 / ImagePullBackOff / CrashLoopBackOff でスタックしている」、「コンテナは実行中ですがサービスの準備ができていません」、「編集後のポッドの再起動ループ」、または「DMS と Firefly を一緒に」などがあります。サービスごとの構成スキーマ、DOCA インストール、ライブラリ API の質問、外部 NVIDIA サービス (BlueMan、HBN、SNAP、Virtio-net)、または完全な Kubernetes クラスター操作については、拒否して別の場所にルーティングします。これらは他のスキルに属します。
