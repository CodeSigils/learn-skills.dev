Используйте этот навык, когда пользователь непосредственно развертывает встроенный в пакет сервисный контейнер DOCA (Argus, DMS, Firefly, Flow-Inspector, OS-Inspector, сервис UROM) на BlueField — автономный kubelet, наблюдающий за каталогом манифестов статического модуля, сброс спецификаций модуля YAML, статус kubelet/журналы ENTRYPOINT/живучесть каждого сервиса, дым перед массовым использованием и многоуровневая таксономия ошибок. (спецификация модуля, планирование, получение образа, среда выполнения, монтирование, сеть, версия, хост). Триггер, даже если пользователь не говорит «развертывание контейнера» — типичные неявные фразы включают «как мне запустить встроенный сервис на BlueField?», «куда мне поместить YAML-спецификация модуля?», «модуль застрял в режиме ожидания / ImagePullBackOff / CrashLoopBackOff», «контейнер работает, но служба не готова», «циклы перезапуска модуля после редактирования» или «DMS и Firefly вместе». Отказаться и направить куда-либо еще для схем конфигурации каждого сервиса, установки DOCA, вопросов по API библиотеки, внешних сервисов NVIDIA (BlueMan, HBN, SNAP, Virtio-net) или полных операций кластера Kubernetes — это относится к другим навыкам.
