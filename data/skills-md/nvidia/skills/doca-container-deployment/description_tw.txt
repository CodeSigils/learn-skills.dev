當使用者在 BlueField 上親自部署捆綁內 DOCA 服務容器（Argus、DMS、Firefly、Flow-Inspector、OS-Inspector、UROM 服務）時，請使用此技能 — kubelet 獨立監視靜態 pod 清單目錄、YAML pod-spec 刪除、kubelet 狀態/ENTRY和分層錯誤分類法（pod-spec、調度、鏡像拉取、運行時、掛載、網路、版本、主機）。即使用戶沒有說“容器部署”，也會觸發 - 典型的隱式短語包括“如何在 BlueField 上運行我構建的服務？”、“我在哪裡放置 pod 規範 YAML？”、“pod 陷入 Pending / ImagePullBackOff / CrashLoopBackOff”、“容器正在運行但“服務尚未準備好”、“拒絕並路由到其他地方的每服務配置模式、DOCA 安裝、庫 API 問題、外部 NVIDIA 服務（BlueMan、HBN、SNAP、Virtio-net）或完整的 Kubernetes 叢集操作 — 這些屬於其他技能。
