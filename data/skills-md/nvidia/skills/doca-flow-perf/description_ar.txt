استخدم هذه المهارة عندما يقوم المستخدم بقياس معدل مستوى التحكم في المضيف أو DPU-CPU لخط أنابيب DOCA Flow باستخدام doca_flow_perf - اختيار سياسة JSON من configs/، واختيار الواجهة الخلفية لـ DPDK أو DOCA، وتشغيل دخان التكرار الفردي ثم حلقة التقييم التكرارية، وتفسير دورات وحدة المعالجة المركزية لكل تكرار و num_pushed / num_failed، أو التقاط المجموعة الأربعة (إصدار DOCA، BlueField/firmware، سياسة JSON، عامل/قائمة الانتظار/تكوين الاندفاع) الذي يجعل رقم Kops/sec قابلاً للدفاع عنه. يتم تفعيله حتى عندما لا يذكر المستخدم صراحةً "doca-flow-perf" - تتضمن العبارات الضمنية النموذجية "كم عدد القواعد التي يمكن لـ BlueField إدراجها في الثانية"، أو "معدل قاعدة دبوس الشعر المكون من 5 صفوف"، أو "Kops/sec للتوجيه"، أو "رقم أداء التدفق لا يتطابق مع ملاحظات الإصدار"، أو "معيار DPDK مقابل DOCA"، أو "تباين تثبيت القواعد مرتفع جدًا". قم بالرفض والتوجيه إلى مكان آخر لتحسين تطبيق التدفق المباشر (doca-flow-tune)، أو المسار الذي تم إلغاء تحميل DPA (doca-flow-dpa-perf)، أو إنتاجية طائرة البيانات أو زمن الاستجابة، أو دلالات الأنابيب الداخلية للمكتبة - تلك تنتمي إلى مهارات أخرى.
