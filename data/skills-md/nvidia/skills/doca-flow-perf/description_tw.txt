當使用者使用 doca_flow_perf 測量 DOCA Flow 管道的主機或 DPU-CPU 控制平面速率時，請使用此技能 — 從 configs/ 選擇 JSON 策略，選擇 DPDK 或 DOCA 後端，運行單次迭代 Smoke，然後運行迭代 eval 循環，解釋每次迭代 CPU 週期和 DOC_pushed，Afailed，failed，Afailed版本、BlueField/韌體、JSON 策略、 worker/queue/burst 配置），讓 Kops/sec 數字變得可防禦。即使使用者沒有明確提及“doca-flow-perf”，也會觸發 — 典型的隱式短語包括“我的 BlueField 每秒可以插入多少條規則”、“5 元組髮夾規則速率”、“轉向每秒每秒數”、“flow-perf 數量與發行說明不匹配”、“DPDK 與 DOCA 安裝基準測試”或“安裝方差”太高”、“DPDK 與 DOCA 安裝基準測試”或“安裝差異”。拒絕並路由到其他地方以優化即時 Flow 應用程式 (doca-flow-tune)、DPA 卸載路徑 (doca-flow-dpa-perf)、資料平面吞吐量或延遲或庫內部管道語義 - 這些屬於其他技能。
