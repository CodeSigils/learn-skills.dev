Utilice esta habilidad cuando el usuario esté midiendo la velocidad del plano de control del host o DPU-CPU de una tubería DOCA Flow con doca_flow_perf: seleccionando una política JSON de configs/, eligiendo el backend DPDK o DOCA, ejecutando el humo de una sola iteración y luego el bucle de evaluación iterativo, interpretando los ciclos de CPU por iteración y num_pushed/num_failed, o capturando las cuatro tuplas (versión DOCA, BlueField/firmware, Política JSON, configuración de trabajador/cola/ráfaga) que hace que un número de Kops/seg sea defendible. Se activa incluso cuando el usuario no menciona explícitamente "doca-flow-perf"; las frases implícitas típicas incluyen "cuántas reglas por segundo puede insertar mi BlueField", "velocidad de regla de horquilla de 5 tuplas", "Kops/seg para dirección", "el número de flow-perf no coincide con las notas de la versión", "punto de referencia DPDK vs DOCA" o "variación de instalación de reglas demasiado alta". Rechace y diríjase a otra parte para optimizar una aplicación Flow en vivo (doca-flow-tune), la ruta descargada por DPA (doca-flow-dpa-perf), el rendimiento o la latencia del plano de datos o la semántica de canalización interna de la biblioteca: esas pertenecen a otras habilidades.
