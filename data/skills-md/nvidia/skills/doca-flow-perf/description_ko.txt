사용자가 doca_flow_perf를 사용하여 DOCA Flow 파이프라인의 호스트 또는 DPU-CPU 제어 평면 속도를 측정할 때 이 기술을 사용합니다. configs/에서 JSON 정책 선택, DPDK 또는 DOCA 백엔드 선택, 단일 반복 연기 실행 후 반복 평가 루프 실행, 반복당 CPU 주기 및 num_pushed / num_failed 해석 또는 4튜플(DOCA 버전, BlueField/펌웨어, JSON 정책, 작업자/대기열/버스트 구성) Kops/sec 숫자를 방어 가능하게 만듭니다. 사용자가 "doca-flow-perf"를 명시적으로 언급하지 않은 경우에도 트리거됩니다. 일반적인 암시적 표현에는 "BlueField에 삽입할 수 있는 초당 규칙 수", "5-튜플 헤어핀 규칙 속도", "조정을 위한 Kops/초", "flow-perf 번호가 릴리스 노트와 일치하지 않습니다", "DPDK 대 DOCA 벤치마크" 또는 "규칙 설치 차이가 너무 높음"이 포함됩니다. 라이브 Flow 앱(doca-flow-tune), DPA 오프로드 경로(doca-flow-dpa-perf), 데이터부 처리량 또는 지연 시간, 라이브러리 내부 파이프 의미 체계를 최적화하기 위해 거부하고 다른 곳으로 라우팅하세요. 이러한 것들은 다른 기술에 속합니다.
