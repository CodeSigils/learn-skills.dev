このスキルは、ユーザーがワークロード周辺の DOCA 環境を扱う場合、つまり、インストールが正常であることの確認、ビルド環境 (pkg-config、ヘッダー、LD_LIBRARY_PATH、hugepages、devlink、representors) の準備、環境クラスの障害のデバッグ、コンテナ対ベアメタルのデプロイメント形状の決定、または NGC DOCA コンテナのステージ 1 フォールバックを介して、まだインストールされていないホストから DOCA インストールに到達するときに使用します。ユーザーが「DOCA セットアップ」と明示的に言及していない場合でもトリガーされます。典型的な暗黙の表現には、「BlueField を入手したところですが、どうすればよいですか」、「コードがビルドされましたが、どうやって実行すればよいですか」、「pkg-config で doca-flow が見つかりません」、「空き 2048 KB の巨大ページがありません」、「レプレッサ X が見つかりません」、「Mac を使用しているので、DOCA を学びたいのですが」などがあります。ライブラリ API の詳細 (フロー パイプ、RDMA キュー)、サンプルの最初のアプリのワークフローまたは DOCA_ERROR_* プログラム側のデバッグ、および「X が文書化されている場所」というナレッジマップの質問については、拒否して別の場所にルーティングします。これらは他のスキルに属します。
