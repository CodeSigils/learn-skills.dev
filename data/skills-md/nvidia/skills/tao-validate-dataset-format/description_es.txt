Ejecute `tao-daft validar` para comprobar los conjuntos de datos de NVIDIA TAO DAFT en busca de errores de estructura, esquema y referencias cruzadas. No lo utilice para formatos que no sean DAFT. Úselo cuando el usuario solicite validar un conjunto de datos DAFT, verificar el esquema DAFT, validar un formato de conjunto de datos TAO o ejecutar "tao-daft validar".
