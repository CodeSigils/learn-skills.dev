Exécutez `tao-daft validate` pour vérifier les ensembles de données NVIDIA TAO DAFT pour les erreurs de structure, de schéma et de références croisées. Ne pas utiliser pour les formats non-DAFT. À utiliser lorsque l'utilisateur demande de valider un ensemble de données DAFT, de vérifier le schéma DAFT, de valider un format d'ensemble de données TAO ou d'exécuter « tao-daft validate ».
