Reconocimiento de aprendizaje métrico (ml-recog) para un reconocimiento visual detallado. Aprende incrustaciones para coincidencias basadas en recuperación (por ejemplo, reconocimiento de productos minoristas) utilizando pérdidas tripletes/contrastivas. Úselo al entrenar, evaluar, exportar o ejecutar inferencias para un modelo de reconocimiento de aprendizaje métrico TAO. Las frases desencadenantes incluyen "entrenar aprendizaje de métricas", "ml-recog", "incrustaciones de recuperación", "reconocimiento de pérdida de tripletes", "coincidencia detallada".
