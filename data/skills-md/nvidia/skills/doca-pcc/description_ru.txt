Используйте этот навык, когда пользователь выполняет практическую работу DOCA PCC на стороне хоста для загрузки ПОЛЬЗОВАТЕЛЬСКОГО программируемого алгоритма управления перегрузкой в BlueField DPU — создание контекстов `doca_pcc` для каждого порта, загрузка скомпилированного dpacc `doca_pcc_app` в `doca_dev` для порта, несущего RoCE, его параметризация, обнаружение возможностей трехосного движения (DOCA cap-query + DPA-совместимый). BlueField + встроенный слот специального PCC включен) или отладка `DOCA_ERROR_*` из `doca_pcc_*`. Запуск даже без явной фразы «DOCA PCC» — неявные формы включают «загрузку моего собственного контроля перегрузки в порт BF», «DOCA_ERROR_NOT_PERMITTED при загрузке алгоритма», «DOCA_ERROR_DRIVER, когда я подключаю свой собственный алгоритм», «моё пользовательское обновление скорости не влияет на трафик RoCE» или «загрузка прошла успешно, но никаких изменений по сети не произошло». Отказаться и направить куда-либо еще для проектирования тела алгоритма на стороне DPA, CLI `pcc_counters`, заводского PCC по умолчанию в прошивке ConnectX или настройки трафика RDMA/RoCE — это относится к другим навыкам.
