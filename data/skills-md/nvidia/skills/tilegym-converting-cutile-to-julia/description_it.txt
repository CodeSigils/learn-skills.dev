Converte i kernel GPU cuTile Python (@ct.kernel) negli equivalenti cuTile.jl Julia. Gestisce la traduzione della sintassi del kernel, la conversione da indicizzato a 0, le differenze di trasmissione, il layout della memoria (da riga principale a colonna principale), la mappatura del sistema di tipi e le differenze di avvio dell'API. Da utilizzare durante la conversione, il porting o la traduzione dei kernel cuTile Python in Julia cuTile.jl o il debug/ottimizzazione delle traduzioni Julia cuTile esistenti.
