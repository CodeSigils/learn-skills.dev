Преобразует ядра графического процессора cuTile Python (@ct.kernel) в эквиваленты cuTile.jl Julia. Обрабатывает преобразование синтаксиса ядра, преобразование индекса 0 в индекс 1, различия широковещательной передачи, структуру памяти (от строк к столбцам), сопоставление системы типов и различия в API запуска. Используйте при преобразовании, портировании или переводе ядер Python cuTile в Julia cuTile.jl или при отладке/оптимизации существующих переводов Julia cuTile.
