Exécutez le pipeline de formation canonique NVIDIA AOI en trois phases : phase 1 de base AutoML (HPO), phase 2 de la boucle DEFT (RCA → SDG → mining → plain-train retrain), phase 3 d'affinement AutoML sur l'ensemble de données augmenté par DEFT. Il s'agit du point d'entrée par défaut pour toute requête « exécuter le workflow AOI », « affiner mon modèle PCB AOI de bout en bout », « améliorer mon modèle AOI ChangeNet » ou « workflow AOI avec AutoML » — acheminez ici au lieu de tao-run-deft-aoi directement, sauf si l'utilisateur demande explicitement la boucle DEFT UNIQUEMENT (par exemple « exécuter JUSTE la boucle DEFT », « ignorer AutoML, uniquement DEFT »). Gère également le même modèle en trois phases pour les applications DEFT non-AOI : ligne de base AutoML, puis boucle DEFT démarrée à chaud à partir des HP gagnants d'AutoML, puis affinement AutoML post-DEFT sur l'ensemble de données augmenté par itération. Les phrases de déclenchement incluent « exécuter le flux de travail AOI », « AOI de bout en bout », « AutoML + DEFT », « AutoML puis DEFT », « régler les hyperparamètres puis DEFT », « DEFT avec AutoML aux deux extrémités », « démarrage à chaud DEFT », « améliorer mon modèle AOI ».
