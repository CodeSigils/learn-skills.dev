运行规范的 NVIDIA AOI 三阶段训练管道 - 第 1 阶段 AutoML 基线 (HPO)、第 2 阶段 DEFT 循环（RCA → SDG → 挖掘 → 普通训练再训练）、第 3 阶段在 DEFT 增强数据集上的 AutoML 细化。这是任何“运行 AOI 工作流程”、“端到端微调我的 PCB AOI 模型”、“改进我的 AOI ChangeNet 模型”或“使用 AutoML 的 AOI 工作流程”请求的默认入口点 — 在此处路由，而不是直接路由 tao-run-deft-aoi，除非用户明确要求仅 DEFT 循环（例如“仅运行 DEFT 循环”、“跳过 AutoML，仅 DEFT”）。还为非 AOI DEFT 应用程序处理相同的三相模式 - AutoML 基线，然后从 AutoML 的获胜 HP 热启动 DEFT 循环，然后在迭代增强数据集上进行 DEFT 后 AutoML 细化。触发短语包括“运行 AOI 工作流程”、“AOI 端到端”、“AutoML + DEFT”、“AutoML 然后 DEFT”、“调整超参数然后 DEFT”、“两端使用 AutoML 进行 DEFT”、“热启动 DEFT”、“改进我的 AOI 模型”。
