GitHub funziona tramite gh CLI: PR, conversazioni di revisione, errori CI, stato del repository. Da utilizzare durante l'ispezione di un PR, la lettura di una revisione (corpi, commenti, thread in linea), il debug di CI (individuazione di quale esecuzione non è riuscita, perché un controllo o un'esecuzione di azioni è rossa, lettura dei registri di lavoro) o la composizione di comandi gh non banali. Gli script coprono ciò che gh grezzo non può fare (stato di risoluzione del thread) o armeggia in modo affidabile (istantanee PR, drilldown del registro CI); usa raw gh direttamente per tutto il resto.
