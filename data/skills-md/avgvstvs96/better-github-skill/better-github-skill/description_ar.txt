يعمل GitHub عبر gh CLI: العلاقات العامة، ومحادثات المراجعة، وفشل CI، وحالة الريبو. يُستخدم عند فحص العلاقات العامة، أو قراءة المراجعة (النصوص، أو التعليقات، أو المواضيع المضمنة)، أو تصحيح أخطاء CI (العثور على التشغيل الفاشل، أو سبب ظهور اللون الأحمر في الفحص أو تشغيل الإجراءات، أو قراءة سجلات المهام)، أو إنشاء أوامر gh غير تافهة. تغطي البرامج النصية ما لا يمكن لـ gh الخام فعله (حالة دقة مؤشر الترابط) أو التحسس بشكل موثوق (لقطات العلاقات العامة، والتنقل في سجل CI)؛ استخدم gh الخام مباشرة لكل شيء آخر.
