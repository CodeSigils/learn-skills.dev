GitHub-Arbeit über gh CLI: PRs, Überprüfungsgespräche, CI-Fehler, Repo-Status. Verwenden Sie diese Funktion, wenn Sie eine PR überprüfen, eine Rezension lesen (Körper, Kommentare, Inline-Threads), CI debuggen (herausfinden, welche Ausführung fehlgeschlagen ist, warum eine Prüfung oder Aktionsausführung rot ist, Jobprotokolle lesen) oder nicht triviale GH-Befehle verfassen. Skripte decken ab, was Raw-GH nicht kann (Thread-Auflösungsstatus) oder zuverlässig fummelt (PR-Snapshots, CI-Protokoll-Drilldown); Verwenden Sie für alles andere direkt rohes Wachstumshormon.
