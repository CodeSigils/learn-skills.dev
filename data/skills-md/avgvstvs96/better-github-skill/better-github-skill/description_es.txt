GitHub funciona a través de gh CLI: relaciones públicas, conversaciones de revisión, fallas de CI, estado del repositorio. Úselo al inspeccionar un PR, leer una revisión (cuerpos, comentarios, subprocesos en línea), depurar CI (buscar qué ejecución falló, por qué una verificación o ejecución de Acciones está en rojo, leer registros de trabajo) o redactar comandos gh no triviales. Los scripts cubren lo que gh sin procesar no puede hacer (estado de resolución de subprocesos) o errores confiables (instantáneas de relaciones públicas, desglose de registros de CI); use gh crudo directamente para todo lo demás.
