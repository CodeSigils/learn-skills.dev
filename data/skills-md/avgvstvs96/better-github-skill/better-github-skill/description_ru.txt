GitHub работает через gh CLI: PR, обзорные беседы, сбои CI, состояние репо. Используйте при проверке PR, чтении обзора (тела, комментариев, встроенных тредов), отладке CI (определение того, какой запуск завершился неудачно, почему проверка или запуск действий выделены красным, чтение журналов заданий) или составлении нетривиальных команд gh. Скрипты охватывают то, что сырой gh не может сделать (состояние разрешения потока) или надежно ошибается (снимки PR, детализация журнала CI); используйте сырой GH напрямую для всего остального.
