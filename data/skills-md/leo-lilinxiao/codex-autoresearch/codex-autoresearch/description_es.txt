Iteración autónoma de larga duración para Codex CLI. Se utiliza cuando el usuario desea que Codex planifique o ejecute un ciclo de mejora y verificación desatendido hacia un resultado medible o verificable, especialmente para ejecuciones nocturnas; también cubre flujos de trabajo repetidos de depuración, reparación, auditoría de seguridad y preparación del envío. No lo utilice para ayuda ordinaria de codificación de una sola vez ni para preguntas y respuestas informales.
