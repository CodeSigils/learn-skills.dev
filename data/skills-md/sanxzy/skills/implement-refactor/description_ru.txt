Этот навык следует использовать, когда пользователь хочет выполнить одну возобновляемую часть плана рефакторинга чистой архитектуры. Триггеры: «применить чистый план», «продолжить миграцию», «сделать следующий фрагмент/слой», «выполнить рефакторинг», «запустить следующий возобновляемый модуль», `/implement-refactor`. Только рефакторинг — сохранение поведения; сначала записывает тесты характеристик, когда зеленая базовая линия не существует. Одна единица на вызов, одна атомарная фиксация на единицу.
