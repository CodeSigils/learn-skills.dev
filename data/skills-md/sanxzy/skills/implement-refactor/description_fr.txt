Cette compétence doit être utilisée lorsque l'utilisateur souhaite exécuter une unité pouvant être reprise d'un plan de refactorisation d'une architecture propre. Déclencheurs : "appliquer le plan de nettoyage", "continuer la migration", "effectuer la tranche/couche suivante", "exécuter le refactor", "exécuter la prochaine unité pouvant être reprise", `/implement-refactor`. Refactor uniquement – préservation du comportement ; écrit d'abord des tests de caractérisation lorsqu'aucune ligne de base verte n'existe. Une unité par invocation, un commit atomique par unité.
