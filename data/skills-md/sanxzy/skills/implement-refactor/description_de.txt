Diese Fähigkeit sollte verwendet werden, wenn der Benutzer eine wiederaufnehmbare Einheit eines Clean Architecture-Refaktorierungsplans ausführen möchte. Auslöser: „Wenden Sie den sauberen Plan an“, „setzen Sie die Migration fort“, „führen Sie den nächsten Slice/die nächste Ebene aus“, „führen Sie den Refactor aus“, „führen Sie die nächste fortsetzbare Einheit aus“, „/implement-refactor“. Nur Refaktor – verhaltenserhaltend; schreibt Charakterisierungstests zuerst, wenn keine grüne Basislinie vorhanden ist. Eine Einheit pro Aufruf, ein atomares Commit pro Einheit.
