Создайте поэтапный план реализации на основе PRD — триггеры типа «создать план», «разбить PRD на этапы», «план трассирующей пули», «разбить мой PRD на этапы». Считывает один `<cwd>/.plans/<feature>/prd.md`, записывает `<cwd>/.plans/<feature>/plan.md` в виде вертикальных срезов трассировщика (каждая фаза представляет собой тонкий сквозной разрез через схему, API, пользовательский интерфейс, тесты). Каждый этап содержит `### Что создавать` плюс `### Критерии приемки` с флажками `- [ ]` — навыки нижестоящего реализатора анализируют этот контракт. Один PRD → один план; никогда не суммируется. Жесткая остановка, если PRD не существует в `.plans/<feature>/prd.md`.
