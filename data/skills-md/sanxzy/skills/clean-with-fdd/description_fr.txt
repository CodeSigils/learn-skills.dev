Auditez une base de code par rapport à une architecture propre + un développement axé sur les fonctionnalités et produisez un plan de migration vers une logique métier sans framework et indépendante des tiers dans les tranches de fonctionnalités. À utiliser lorsque l'utilisateur demande à auditer les violations d'architecture propre, à planifier une migration vers des tranches de fonctionnalités, à vérifier une différence pour les violations, à examiner les dépendances des couches ou à restructurer en tranches de fonctionnalités. Modes : `entier`, `fonctionnalité <nom>`, `diff`. Indépendant de la langue. Audit et plan uniquement : ne modifie jamais le code de production.
