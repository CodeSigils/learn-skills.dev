Validieren Sie einen Implementierungsbericht anhand seines Plans und der tatsächlichen Commits – liest den Diff jedes AC und prüft, ob der Code das Versprechen erfüllt. Auslöser: „Überprüfen Sie die Implementierung“, „Überprüfen Sie Phase X“, „Überprüfen Sie den Bericht“, „Entsprach die Implementierung dem Plan“. Erkennt fehlende ACs, halluzinierte SHAs, Scope Creep, Verstöße gegen die FP-Disziplin, Komplexitätsinkongruenzen und (UI-)Design-Entscheidungslücken. Schreibt ein Urteil in „.plans/<feature>/reviews/{with-design,code}/<phase>.md“. Ein Aufruf = eine Phase.
