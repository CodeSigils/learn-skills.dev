Recherche BFS pouvant être reprise sur n'importe quel sujet fourni par l'utilisateur, citant les URL/titres/ID Context7, indiquez dans `.plans/research-with-instructions/<topic>/`. Exa-d'abord, puis WebSearch/WebFetch ; Context7 comme solution de secours pour la documentation officielle du package. Demande uniquement lorsque les sources sont en conflit ou que la portée est ambiguë. Déclencheurs : "recherche approfondie X", "recherche X", "enquêter sur X", "/deep-research-with-instructions". Effectue des recherches sur des documents externes et sur le Web ouvert, et non sur la base de code de l'utilisateur ; pour les questions "comment ce dépôt fait X", ne tirez pas.
