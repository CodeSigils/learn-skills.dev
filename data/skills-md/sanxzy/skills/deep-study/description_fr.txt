Étude guidée d'une recherche `REPORT.md` — un rapport de base de code (`.plans/research/<topic>/`) ou un rapport thématique (`.plans/research-with-instructions/<topic>/`). Parcourt l'utilisateur section par section, ouvre chaque « fichier : ligne » ou URL source cité, le paraphrase, s'enregistre avant de continuer. S'arrête brutalement si aucun rapport n'existe : consomme un rapport, n'en écrit jamais. Détecte automatiquement l'emplacement ou emprunte un chemin explicite. Déclencheurs : "étudier ce rapport", "étudier le rapport sur X", `/deep-study`. Apatride, en lecture seule.
