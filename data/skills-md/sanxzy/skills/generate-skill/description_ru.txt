Строгое знание Scaffold Claude Code: четкие правила, структурированный рабочий процесс, проверка. Триггер «создать навык для X», «подготовить навык», «Мне нужен навык для <домен>» или «/generate-skill <имя>». Обеспечивает соблюдение дисциплины в заставке и бюджета длины описания (подтверждается встроенным сценарием). Автономный. Никогда не перезаписывает молча. Контрольный список для самопроверки; при необходимости запускает агент проверки по имени пользователя, но не запускается автоматически.
