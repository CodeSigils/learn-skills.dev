Recherche de base de code pouvant être reprise qui répond « comment cette base de code fait X » via la traversée BFS d'un arbre de questions de recherche, avec des citations `file:line` et un état dans `.plans/research/<topic>/`. Enquête de manière autonome : demande uniquement lorsque le code ne peut pas répondre. Déclencheurs : « recherche approfondie sur X », « plongée approfondie dans la base de code », « enquêter sur la base de code », « comment cette base de code fait-elle X », « expliquer comment X fonctionne dans ce dépôt », « tracer comment X circule ». Les réponses proviennent de la lecture du code — pour les questions qui nécessitent les propres réponses de l'utilisateur plutôt que ce que fait la base de code, ne déclenchez pas. Lecture seule, base de code uniquement (pas de Context7/Exa/web).
