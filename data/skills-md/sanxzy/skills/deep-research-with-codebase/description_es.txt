Investigación de base de código reanudable que responde "¿cómo hace X esta base de código" a través de un recorrido BFS de un árbol de preguntas de investigación, con citas `file:line` y estado en `.plans/research/<topic>/`. Investiga de forma autónoma: pregunta sólo cuando el código no puede responder. Activadores: "investigación profunda de X", "profundización en el código base", "investigar el código base", "cómo este código base hace X", "explicar cómo funciona X en este repositorio", "rastrear cómo fluye X". Las respuestas provienen de la lectura del código: para preguntas que necesitan respuestas de diseño propias del usuario en lugar de lo que hace el código base, no active. Solo lectura, solo código base (sin Context7/Exa/web).
