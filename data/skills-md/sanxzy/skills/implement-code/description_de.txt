Implementieren Sie eine **Nicht-UI**-Phase – Backend, Bibliothek, CLI, Infrastruktur, Datenpipeline – aus einem Plan unter „.plans/<feature>/plan.md“; Die Phase darf keine UI-Arbeit enthalten (Komponenten, Seiten, Stil, Interaktionen). Löst auf „Phase X implementieren“, „Phase N ausführen“, „Phase 2 von <Feature> erstellen“ aus. Bevorzugt FP-Redewendungen (reine Funktionen, Unveränderlichkeit, Zusammensetzung); greift auf OOP für klassenbasierte Sprachen oder OOP-lastige Codebasen („FP.md“) zurück. Optionaler **TDD-Modus** (Rot→Grün→Refaktor) auf „tdd“ / „test-first“ – siehe „TDD.md“.
