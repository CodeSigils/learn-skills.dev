Implémentez une phase **non-UI** — backend, bibliothèque, CLI, infra, pipeline de données — à partir d'un plan dans `.plans/<feature>/plan.md` ; la phase ne doit comporter aucun travail d'interface utilisateur (composants, pages, style, interactions). Se déclenche sur "implémenter la phase X", "faire la phase N", "construire la phase 2 de <fonctionnalité>". Préfère les idiomes FP (fonctions pures, immuabilité, composition) ; revient à la POO pour les langages basés sur les classes ou les bases de code lourdes en POO (`FP.md`). **Mode TDD** facultatif (rouge→vert→refactor) sur "tdd" / "test-first" — voir `TDD.md`.
