**非 UI** フェーズ (バックエンド、ライブラリ、CLI、インフラ、データ パイプライン) を `.plans/<feature>/plan.md` のプランから実装します。フェーズには UI 作業 (コンポーネント、ページ、スタイル、インタラクション) が含まれていてはなりません。 「フェーズ X の実装」、「フェーズ N の実行」、「<機能> のフェーズ 2 の構築」でトリガーされます。 FP イディオム (純粋関数、不変性、構成) を好みます。クラスベース言語または OOP を多用するコードベース (`FP.md`) の場合は、OOP にフォールバックします。 「tdd」/「test-first」のオプションの **TDD モード** (赤→緑→リファクタリング) — `TDD.md` を参照してください。
