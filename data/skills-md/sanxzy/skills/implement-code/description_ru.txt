Реализуйте этап **не-UI** — серверную часть, библиотеку, интерфейс командной строки, инфраструктуру, конвейер данных — из плана в `.plans/<feature>/plan.md`; на этом этапе не должно быть работы с пользовательским интерфейсом (компоненты, страницы, стили, взаимодействия). Триггеры: «реализация этапа X», «выполнение этапа N», «создание этапа 2 <функции>». Предпочитает идиомы FP (чистые функции, неизменяемость, композиция); возвращается к ООП для языков на основе классов или кодовых баз с большим количеством ООП (FP.md). Необязательный **режим TDD** (красный → зеленый → рефакторинг) для «tdd» / «test-first» — см. `TDD.md`.
