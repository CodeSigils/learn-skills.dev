Implementar una fase **sin interfaz de usuario** (backend, biblioteca, CLI, infraestructura, canalización de datos) desde un plan en `.plans/<feature>/plan.md`; la fase no debe tener ningún trabajo de UI (componentes, páginas, estilos, interacciones). Activadores en "implementar fase X", "hacer fase N", "construir fase 2 de <característica>". Prefiere modismos FP (funciones puras, inmutabilidad, composición); recurre a la programación orientada a objetos para lenguajes basados ​​en clases o bases de código con mucha programación orientada a objetos (`FP.md`). **Modo TDD** opcional (rojo→verde→refactor) en "tdd" / "test-first" — consulte `TDD.md`.
