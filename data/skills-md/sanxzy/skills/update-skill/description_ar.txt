قم بتعديل مهارة Claude Code الموجودة بأمان - قم بتحرير المادة الأمامية أو الجسم أو المرافقين؛ إعادة تسمية؛ نسخة عثرة. تطبيق نتائج المراجعة. قم بتشغيل "تحديث المهارة X"، أو "إصلاح وصف المهارة Y"، أو "إعادة تسمية المهارة Z"، أو "/ تحديث المهارة <الاسم>". اختر توليد المهارات لمهارات جديدة؛ اختر هذا لتعديل ما هو موجود. يقوم بتدقيق الهدف، ويقترح مجموعة تغيير، ويفرق كل ملف، ولا يكتب إلا بعد التأكيد. المطبات التلقائية semver (MAJOR/MINOR/PATCH) لكل تأثير تغيير؛ أبدا الكتابة بصمت. مكتفية ذاتيا.
