Ejecute una fase de un archivo de plan por fases en `<cwd>/.plans/<feature>/plan.md` cuando la fase toque la interfaz de usuario (componentes, páginas, diseños, estilos, interacciones) o combine la interfaz de usuario con trabajo que no sea de interfaz de usuario. Para fases puramente ajenas a la interfaz de usuario (backend, biblioteca, CLI, infraestructura, scripts), no active. Los activadores incluyen "implementar la fase X", "realizar la fase N", "iniciar la implementación", "construir la fase 2 de <característica>". Escribe código de producción que satisface todos los criterios de aceptación y crea un compromiso atómico de git por AC. FP primero con respaldo de programación orientada a objetos; admite el modo TDD opcional (rojo → verde → refactor) cuando el usuario opta por participar.
