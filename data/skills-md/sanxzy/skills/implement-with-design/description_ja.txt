フェーズが UI (コンポーネント、ページ、レイアウト、スタイル、インタラクション) に触れるか、UI と UI 以外の作業を混合する場合、`<cwd>/.plans/<feature>/plan.md` にあるフェーズ化された計画ファイルの 1 つのフェーズを実行します。純粋に UI 以外のフェーズ (バックエンド、ライブラリ、CLI、インフラ、スクリプト) の場合は、起動しないでください。トリガーには、「フェーズ X の実装」、「フェーズ N の実行」、「実装の開始」、「<機能> のフェーズ 2 の構築」が含まれます。すべての受け入れ基準を満たす実稼働コードを作成し、AC ごとに 1 つのアトミック git コミットを作成します。 OOP フォールバックを使用した FP ファースト。ユーザーがオプトインすると、オプションの TDD モード (赤→緑→リファクタリング) がサポートされます。
