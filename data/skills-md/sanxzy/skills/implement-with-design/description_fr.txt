Exécutez une phase d'un fichier de plan par étapes dans `<cwd>/.plans/<feature>/plan.md` lorsque la phase touche l'interface utilisateur (composants, pages, mises en page, style, interactions) ou mélange l'interface utilisateur avec des travaux non liés à l'interface utilisateur. Pour les phases purement non-UI (backend, bibliothèque, CLI, infra, scripts), ne déclenchez pas. Les déclencheurs incluent « mettre en œuvre la phase X », « faire la phase N », « démarrer la mise en œuvre », « construire la phase 2 de <fonctionnalité> ». Écrit du code de production satisfaisant tous les critères d'acceptation et crée un commit git atomique par AC. FP-first avec repli POO ; prend en charge le mode TDD en option (rouge → vert → refactor) lorsque l'utilisateur s'y inscrit.
