Esegui una fase di un file di piano in più fasi in "<cwd>/.plans/<feature>/plan.md" quando la fase tocca l'interfaccia utente (componenti, pagine, layout, stile, interazioni) o combina l'interfaccia utente con lavoro non-interfaccia utente. Per le fasi puramente non dell'interfaccia utente (backend, libreria, CLI, infrastrutture, script), non attivare. I trigger includono "implementa la fase X", "esegui la fase N", "avvia l'implementazione", "crea la fase 2 della <funzionalità>". Scrive il codice di produzione che soddisfa ogni criterio di accettazione e crea un commit atomic git per AC. FP-first con fallback OOP; supporta la modalità TDD opzionale (rosso → verde → refactoring) quando l'utente accetta.
