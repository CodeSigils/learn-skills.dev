Выполните одну фазу файла поэтапного плана по адресу `<cwd>/.plans/<feature>/plan.md`, когда фаза затрагивает пользовательский интерфейс (компоненты, страницы, макеты, стили, взаимодействия) или смешивает пользовательский интерфейс с работой, не связанной с пользовательским интерфейсом. На этапах, не связанных с пользовательским интерфейсом (бэкэнд, библиотека, CLI, инфраструктура, сценарии), не запускайте. Триггеры включают «реализация фазы X», «выполнение фазы N», «начало реализации», «фаза 2 сборки <функции>». Пишет рабочий код, удовлетворяющий всем критериям приемки, и создает один атомарный git-коммит для каждого AC. FP-first с резервным вариантом ООП; поддерживает дополнительный режим TDD (красный → зеленый → рефакторинг), когда пользователь соглашается.
