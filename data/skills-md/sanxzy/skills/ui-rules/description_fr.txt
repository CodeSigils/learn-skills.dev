Définissez la direction de l'interface utilisateur à l'échelle du projet avant l'écriture de tout code : des déclencheurs tels que "définir les règles de l'interface utilisateur", "écrire des garde-corps anti-inclinaison", "planifier la direction de l'interface utilisateur". Lit un `<cwd>/.plans/DESIGN.md` existant, organise un entretien de découverte ciblé et écrit `<cwd>/.plans/UI-RULES.md` — un livre de règles à l'échelle du projet pour les compétences de mise en œuvre en aval. Choisissez ceci pour un livre de règles à l'échelle du projet plutôt que pour un dossier de conception par fonctionnalité, et lorsque l'objectif est un document de planification et non un code d'interface utilisateur fonctionnel. N'écrit jamais de code d'interface utilisateur.
