Определите направление пользовательского интерфейса в рамках всего проекта до написания любого кода — такие триггеры, как «установить правила пользовательского интерфейса», «написать защитные ограждения», «планировать направление пользовательского интерфейса». Считывает существующий `<cwd>/.plans/DESIGN.md`, проводит целенаправленное собеседование и записывает `<cwd>/.plans/UI-RULES.md` — свод правил для всего проекта для последующих навыков реализации. Выбирайте это для свода правил для всего проекта, а не для описания дизайна каждой функции, и когда целью является документ планирования, а не работающий код пользовательского интерфейса. Никогда не пишет код пользовательского интерфейса.
