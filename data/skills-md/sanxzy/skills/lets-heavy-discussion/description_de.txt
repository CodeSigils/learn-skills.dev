Fortsetzbares Designinterview mit Verzweigungsverfolgung, das jeden offenen Zweig in einem expliziten Baum verfolgt (damit kein Zweig vergessen wird), den Status nach jeder Runde auf „.plans/discussion/<topic>/“ beibehält, die Breite zuerst durchläuft, um Tunnelbildung zu vermeiden, und genau dort fortfährt, wo die letzte Sitzung aufgehört hat. Verwenden Sie diese Option, wenn der Benutzer sagt: „Lass uns diskutieren“, „Lass uns darüber reden“, „Hilf mir, durchzudenken“, „Führe mich durch die Kompromisse“, „Ich muss mich entscheiden“, „Teste mein Design einem Stresstest“ oder „Lass uns unsere Diskussion fortsetzen“ – insbesondere bei Architektur-, Produkt- oder Designentscheidungen mit mehreren Zweigen oder um eine Diskussion fortzusetzen, die in einer früheren Sitzung begonnen wurde. Nur Audit + Interview – Code wird nie geändert. Empfiehlt immer eine Antwort; Erkundet die Codebasis stillschweigend, wenn die Antwort im Code enthalten ist.
