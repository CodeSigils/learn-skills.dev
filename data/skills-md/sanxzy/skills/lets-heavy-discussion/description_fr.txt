Entretien de conception de suivi de branche avec reprise qui suit chaque branche ouverte dans une arborescence explicite (afin qu'aucune branche ne soit oubliée), conserve l'état dans `.plans/discussion/<topic>/` après chaque tour, traverse d'abord la largeur pour éviter le tunneling et reprend exactement là où la dernière session s'est arrêtée. À utiliser lorsque l'utilisateur dit « discutons », « discutons », « aidez-moi à réfléchir », « expliquez-moi les compromis », « je dois décider », « testez ma conception » ou « poursuivons notre discussion » — en particulier pour les décisions d'architecture, de produit ou de conception avec plusieurs branches, ou pour reprendre une discussion commencée lors d'une session précédente. Audit + entretien uniquement – ​​ne modifie jamais le code. Recommande toujours une réponse ; explore la base de code en silence lorsque la réponse est dans le code.
