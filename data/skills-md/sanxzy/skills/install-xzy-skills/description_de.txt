Installieren Sie jeden Skill aus der sanxzy/Skills-Sammlung im aktuellen Projekt. Wird ausgelöst bei „xzy-Skills installieren“, „xzy-Skills einrichten“, „alle xzy-Skills hinzufügen“ oder „/install-xzy-skills“. Verknüpft alle Skills mit .agents/skills/ und meldet eine Zusammenfassung dessen, was installiert wurde.
