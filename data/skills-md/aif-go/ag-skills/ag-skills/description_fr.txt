Cette compétence doit être utilisée lorsque l'utilisateur demande de créer un microservice ag-core, de définir une API protobuf, de générer du code avec aggo, d'implémenter une logique de service, d'ajouter un adaptateur Kitex/Hertz, de générer un DAO/Modèle avec gen-go-db, de concevoir des tables de base de données, de créer un service gRPC/HTTP avec ag-core, d'utiliser des commandes aggo new/proto, des commandes gen-go-db db ou de travailler avec des fichiers ag-core .proto, des répertoires internes/service/, idl/api/.
