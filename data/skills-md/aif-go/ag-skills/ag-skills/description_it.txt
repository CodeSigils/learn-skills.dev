Questa competenza dovrebbe essere utilizzata quando l'utente chiede di creare un microservizio ag-core, definire un'API protobuf, generare codice con aggo, implementare la logica del servizio, aggiungere un adattatore Kitex/Hertz, generare DAO/modello con gen-go-db, progettare tabelle di database, creare un servizio gRPC/HTTP con ag-core, utilizzare comandi aggo new/proto, comandi gen-go-db db o lavorare con file ag-core .proto, internal/service/, idl/api/ directory.
