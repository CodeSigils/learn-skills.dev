الأساس المشترك لـ Soke CLI: تهيئة تكوين التطبيق، وتسجيل الدخول للمصادقة (تسجيل الدخول)، وإدارة الأذونات، ومعالجة الأخطاء، وقواعد الأمان. يتم تشغيله عندما يحتاج المستخدم إلى إجراء التكوين الأولي (soke-cli config init)، أو استخدام ترخيص تسجيل الدخول (تسجيل الدخول إلى مصادقة soke-cli)، أو مواجهة أذونات غير كافية، أو استخدام soke-cli لأول مرة.
