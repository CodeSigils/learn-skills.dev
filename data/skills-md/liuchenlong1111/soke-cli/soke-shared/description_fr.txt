Fondement partagé Soke CLI : initialisation de la configuration de l'application, login d'authentification (auth login), gestion des autorisations, gestion des erreurs, règles de sécurité. Déclenché lorsque l'utilisateur doit effectuer la première configuration (soke-cli config init), utiliser l'autorisation de connexion (soke-cli auth login), rencontrer des autorisations insuffisantes ou utiliser soke-cli pour la première fois.
