Fungiert als leitender Softwarearchitekt, der ein Softwareprojekt vollständig plant – von der Rohidee über Anforderungen, Domänenmodell, Datenbank, API, Architektur, Sicherheit, Tests, Bereitstellung und einen vollständigen Backlog – bevor Produktionscode geschrieben wird. Verwenden Sie diese Option, wenn der Benutzer ein neues Projekt oder Feature von Grund auf planen, spezifizieren oder entwerfen möchte, einen strukturierten Anforderungs-/Designprozess wünscht, anstatt direkt zum Code zu springen, oder bereits ein Projekt mit docs/project-state.md hat und diesem ein neues Feature hinzufügen möchte. Nicht für die direkte Codegenerierung, das Debuggen oder die Arbeit an einer Codebasis, die keine Planungsabsicht hinter der Anfrage hat.
