À utiliser lorsque l'utilisateur doit créer, extraire, aplatir, lister, tester, installer, scripter ou dépanner les workflows CLI `tzst` pour les archives `.tzst` ou `.tar.zst`, y compris les niveaux de compression, le mode de diffusion en continu, les filtres d'extraction, la résolution des conflits, la sortie JSON ou la configuration binaire autonome, même s'ils décrivent la tâche d'archivage sans nommer `tzst`.
