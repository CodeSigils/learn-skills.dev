Utilizzare questa abilità quando l'utente desidera inviare o recuperare file tramite un server Xdrop dal terminale, chiede di automatizzare flussi di lavoro di collegamento condiviso Xdrop crittografati, fornisce un collegamento Xdrop `/t/:transferId#k=...` per scaricare e decrittografare localmente o necessita di flag CLI Xdrop come `--quiet`, `--json`, `--expires-in`, `--output` o `--api-url`, anche se non menzionati esplicitamente il nome dell'abilità.
