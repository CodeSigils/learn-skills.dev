ابحث عن الوظائف اليتيمة والواردات المتدلية والأكواد الميتة عبر GitNexus CLI (gitnexus). CLI فقط - لا يوجد خادم MCP، لا تستخدم readMcpResource مطلقًا مع gitnexus:// URIs. المشغلات - التعليمات البرمجية الميتة، والوظائف اليتيمة، والواردات غير المستخدمة، والمراجع المتدلية، والتعليمات البرمجية التي لا يمكن الوصول إليها.
