Справочное руководство по новейшим инструментам Rust для рефакторинга, профилирования, сравнительного анализа, тестирования и SIMD-оптимизации. Используйте всякий раз, когда пользователь спрашивает об ast-grep, Cargo-Semver-Checks, samply, Cargo-PGO, Cargo-Wizard, Divan, Criterion, Cargo-nextest, Cargo-мутантах, Cargo-hack или macerator. Также используйте, когда пользователь хочет провести рефакторинг кода Rust с помощью инструментов, поддерживающих AST, профилировать или тестировать производительность Rust, запускать мутационное тестирование или оптимизировать с помощью SIMD. НЕ используйте для аудита зависимостей (вместо этого используйте ржавчину-зависимость-аудит) или для общих вопросов языка Rust, не связанных с инструментами.
