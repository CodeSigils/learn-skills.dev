Guida di riferimento per strumenti Rust all'avanguardia per refactoring, profilazione, benchmarking, test e ottimizzazione SIMD. Utilizzare ogni volta che l'utente richiede informazioni su ast-grep, cargo-semver-checks, samply, cargo-pgo, cargo-wizard, divan, Criterion, cargo-nextest, cargo-mutants, cargo-hack o macerator. Da utilizzare anche quando l'utente desidera effettuare il refactoring del codice Rust con strumenti compatibili con AST, profilare o confrontare le prestazioni di Rust, eseguire test di mutazione o ottimizzare con SIMD. NON utilizzare per il controllo delle dipendenze (utilizzare invece ruggine-dipendenza-audit) o ​​per domande generali sul linguaggio Rust non correlate agli strumenti.
