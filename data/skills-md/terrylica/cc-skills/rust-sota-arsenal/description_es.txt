Guía de referencia para herramientas Rust de última generación en refactorización, creación de perfiles, evaluación comparativa, pruebas y optimización SIMD. Úselo siempre que el usuario pregunte sobre ast-grep, cargo-semver-checks, samply, cargo-pgo, cargo-wizard, divan, Criterion, cargo-nextest, cargo-mutants, cargo-hack o macerator. Úselo también cuando el usuario desee refactorizar el código de Rust con herramientas compatibles con AST, perfilar o comparar el rendimiento de Rust, ejecutar pruebas de mutación u optimizar con SIMD. NO lo use para auditoría de dependencia (use en su lugar Rust-dependency-audit) o ​​para preguntas generales sobre el lenguaje Rust no relacionadas con las herramientas.
