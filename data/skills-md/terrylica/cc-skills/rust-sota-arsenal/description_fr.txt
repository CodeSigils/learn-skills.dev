Guide de référence pour les outils Rust de pointe en matière de refactoring, de profilage, d'analyse comparative, de tests et d'optimisation SIMD. À utiliser chaque fois que l'utilisateur pose des questions sur ast-grep, cargo-semver-checks, samply, cargo-pgo, cargo-wizard, divan, Criterion, cargo-nextest, cargo-mutants, cargo-hack ou macerator. À utiliser également lorsque l'utilisateur souhaite refactoriser le code Rust avec des outils compatibles AST, profiler ou évaluer les performances de Rust, exécuter des tests de mutation ou optimiser avec SIMD. Ne PAS utiliser pour l'audit des dépendances (utilisez plutôt rust-dependency-audit) ou pour des questions générales sur le langage Rust sans rapport avec les outils.
