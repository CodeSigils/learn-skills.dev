دليل مرجعي لأدوات الصدأ الحديثة عبر إعادة الهيكلة، والتنميط، والقياس، والاختبار، وتحسين SIMD. استخدم عندما يسأل المستخدم عن ast-grep، أو فحص البضائع، أو samply، أو Cargo-pgo، أو Cargo-Wizard، أو Divan، أو Criterion، أو Cargo-Nextest، أو Cargo-Mutants، أو Cargo-Hack، أو Macerator. استخدمه أيضًا عندما يريد المستخدم إعادة بناء كود Rust باستخدام أدوات AST-aware، أو ملف تعريف أو أداء Rust المعياري، أو تشغيل اختبار الطفرات، أو التحسين باستخدام SIMD. لا تستخدمه لتدقيق التبعية (استخدم تدقيق التبعية الصدأ بدلاً من ذلك) أو للأسئلة العامة المتعلقة بلغة الصدأ التي لا علاقة لها بالأدوات.
