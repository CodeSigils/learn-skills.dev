Référence pour la CLI de téléchargement et ses outils MCP stdio/hébergés — indicateurs exacts, clés et contrats pour le placement et la pièce jointe, capture d'écran, clés PR/problème stables, commentaire des pièces jointes gérées, métadonnées et recherche, galeries, valeurs de configuration par défaut, connexion/médecin et formats de sortie. À utiliser lors du pilotage de la CLI `uploads` ou de ses outils MCP (y compris le MCP hébergé sur agents.uploads.sh pour les agents sans système de fichiers local/accès git), lorsque vous avez besoin d'une URL publique pour un fichier local ("télécharger ceci", "héberger cette image", "donnez-moi une URL publique pour ce fichier"), lorsque la CLI elle-même imprime un indice ou un coup de pouce sur lequel vous devez agir (un champ `indice` au format `--format json`, ou la note stderr suggérant `--pr`/`attach --branch`), ou lorsque vous avez besoin d'indicateurs exacts, de dispositions de touches ou de détails de configuration et d'authentification. Pour savoir quand et comment obtenir une capture d'écran ou un enregistrement dans un PR ou un problème GitHub, commencez par la compétence github-screenshots - elle est reportée ici pour les détails de la CLI.
