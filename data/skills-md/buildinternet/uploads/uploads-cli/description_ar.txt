مرجع لـ CLI للتحميلات وأدوات MCP الخاصة بـ stdio/المستضافة - العلامات الدقيقة، والمفاتيح، والعقود للوضع والإرفاق، والتقاط لقطة الشاشة، ومفاتيح العلاقات العامة/الإصدار المستقرة، وتعليق المرفقات المُدارة، وبيانات التعريف والبحث، والمعارض، وافتراضيات التكوين، وتسجيل الدخول/الدكتوراه، وتنسيقات الإخراج. استخدمه عند تشغيل سطر الأوامر "التحميلات" أو أدوات MCP الخاصة به (بما في ذلك MCP المستضاف على agents.uploads.sh للوكلاء الذين ليس لديهم وصول إلى نظام الملفات المحلي/git)، عندما تحتاج إلى عنوان URL عام لملف محلي ("تحميل هذا"، "استضافة هذه الصورة"، "أعطني عنوان URL عام لهذا الملف")، عندما تطبع واجهة سطر الأوامر نفسها تلميحًا أو دفعة تحتاج إلى التصرف بناءً عليها (حقل "تلميح" في "--format json"، أو ملاحظة stderr التي تقترح `--pr`/`attach --branch`)، أو عندما تحتاج إلى علامات دقيقة أو تخطيطات مفاتيح أو تفاصيل الإعداد والمصادقة. لمعرفة متى وكيف يتم الحصول على لقطة شاشة أو التسجيل في GitHub PR أو إصدار ما، ابدأ بمهارة لقطات شاشة github - فهي تؤجل هنا للحصول على تفاصيل CLI.
