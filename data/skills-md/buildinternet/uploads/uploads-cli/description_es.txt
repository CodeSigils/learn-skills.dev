Referencia para la CLI de cargas y sus herramientas estándar/MCP alojadas: indicadores, claves y contratos exactos para colocar y adjuntar, captura de pantalla, claves de relaciones públicas/problemas estables, comentarios de archivos adjuntos administrados, metadatos y búsqueda, galerías, valores predeterminados de configuración, inicio de sesión/médico y formatos de salida. Úselo cuando controle la CLI `uploads` o sus herramientas MCP (incluido el MCP alojado en agentes.uploads.sh para agentes sin sistema de archivos local/acceso git), cuando necesite una URL pública para un archivo local ("cargar esto", "alojar esta imagen", "darme una URL pública para este archivo"), cuando la CLI misma imprima una sugerencia o un empujón sobre el que necesita actuar (un campo `hint` en `--format json`, o la nota stderr que sugiere `--pr`/`attach --branch`), o cuando necesite indicadores exactos, diseños de teclas o detalles de configuración y autenticación. Para saber cuándo y cómo obtener una captura de pantalla o grabar en un PR o problema de GitHub, comience con la habilidad de capturas de pantalla de github; se pospone aquí para obtener detalles de la CLI.
