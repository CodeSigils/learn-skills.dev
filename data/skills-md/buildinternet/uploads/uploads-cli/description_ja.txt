アップロード CLI とその stdio/ホスト型 MCP ツールのリファレンス — プットとアタッチの正確なフラグ、キー、コントラクト、スクリーンショット キャプチャ、安定した PR/発行キー、管理された添付ファイルのコメント、メタデータと検索、ギャラリー、設定のデフォルト、ログイン/ドクター、出力形式。 `uploads` CLI またはその MCP ツール (ローカル ファイル システム/git アクセスのないエージェントの場合は、agents.uploads.sh でホストされる MCP を含む) を実行するとき、ローカル ファイルのパブリック URL が必要なとき (「これをアップロードする」、「このイメージをホストする」、「このファイルのパブリック URL を教えてください」)、CLI 自体が操作する必要があるヒントやナッジを出力するとき (「--format json」の「ヒント」フィールド、または`--pr`/`attach --branch` を示唆する stderr メモ）、または正確なフラグ、キー レイアウト、セットアップと認証の詳細が必要な場合。スクリーンショットを取得したり、GitHub PR や問題に記録したりするタイミングと方法については、github-screenshots スキルから始めてください。CLI の詳細については、ここで説明します。
