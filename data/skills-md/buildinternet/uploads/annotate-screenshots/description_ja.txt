手書きのボックス、矢印、ラベル、フリーフォーム ストローク、墨消しをスクリーンショットに焼き付けると、PR レビュー担当者やチームメイトが、キャプションを読んで探す代わりに、何が変更され、どこを見るべきかを正確に確認できます。スクリーンショットに吹き出しが必要な場合は常にこれを使用します。「新しいボタンをポイントする」、「バグを丸で囲む」、「差分への矢印」、「このスクリーンショットの API キーをぼかす」、「添付する前にこの画像をマークアップする」などです。キャプチャ中のライブ ページへの注釈付け (「スクリーンショットのアップロード --annotate」、CSS セレクター ターゲティング) と、既存の画像への注釈付け (「注釈のアップロード」、ピクセル/フリーフォーム座標のみ) の両方をカバーします。結果のイメージを GitHub PR または Issue に取り込むには、github-screenshots スキルに引き渡します。このスキルは、注釈付きイメージの生成のみをカバーします。
