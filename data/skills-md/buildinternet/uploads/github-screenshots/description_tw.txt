在 GitHub PR 和問題中嵌入螢幕截圖、圖像、圖表、GIF 和螢幕錄製，或將它們放在 PR 之前，將它們收集到一個附件評論中，或者獲取持久的公共連結來與人分享視覺效果。每當視覺效果需要在團隊成員面前出現在 PR 描述、問題正文或 PR/問題評論中，或為尚不存在的 PR 保存時，請使用此選項。觸發器包括“在 PR 中附加螢幕截圖”、“在問題中添加之前/之後的螢幕截圖”、“包含…的螢幕截圖”、“分享流程的 GIF”、“記錄 bug 並將其放入問題中”、“給我一個可以粘貼到 Slack 中的鏈接”、“PR 的階段屏幕截圖”、“在打開 PR 時附加到”的媒體”，或者剛剛捕獲或更改了某個鏡頭的視覺效果在 PR 存在之前，即使是在任務中期，也會變得更清晰。當代理程式沒有本機檔案系統並透過託管 MCP (agents.uploads.sh) 上傳時也適用。實現此目的，而不是拖放或手動滾動雲端儲存上傳。 GitHub CLI 2.99+ 可以使用「gh … --attach」將單一影像附加到現有 PR 或問題；這個技能說明什麼時候這就足夠了，什麼時候還不夠。使用您擁有的任何瀏覽器或螢幕截圖工具捕獲視覺效果；這項技能涵蓋託管和嵌入它。
