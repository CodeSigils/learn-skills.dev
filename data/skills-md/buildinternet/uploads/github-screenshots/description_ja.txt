スクリーンショット、画像、図、GIF、画面録画を GitHub の PR や問題に埋め込みます。あるいは、PR の前にステージングしたり、1 つの添付コメントに集めたり、ビジュアルを人と共有するための永続的なパブリック リンクを取得したりできます。ビジュアルを PR の説明、問題の本文、PR/問題のコメント、チームメイトの前で使用する必要がある場合、またはまだ存在しない PR 用に保存する必要がある場合は、これを使用します。トリガーには、「PR にスクリーンショットを添付する」、「課題に前後を追加する」、「…のスクリーンショットを含める」、「フローの GIF を共有する」、「バグを記録して課題に入れる」、「Slack に貼り付けられるリンクを取得する」、「PR のスクリーンショットをステージングする」、「PR を開くときにこれを添付する」、「PR 用にこれを保存する」、「PR のメディアを収集する」、または視覚的な何かをキャプチャまたは変更した直後などが含まれます。 PR が存在する前であれば、タスクの途中であっても、ショットによって明確になります。エージェントにローカル ファイル システムがなく、ホストされた MCP (agents.uploads.sh) 経由でアップロードしている場合にも適用されます。ドラッグ アンド ドロップや手動でクラウド ストレージにアップロードする代わりに、これを利用します。 GitHub CLI 2.99 以降では、単一のイメージを既存の PR に添付するか、`gh … --attach` を発行できます。このスキルは、それで十分な場合とそうでない場合を示します。お持ちのブラウザやスクリーンショット ツールを使用してビジュアルをキャプチャします。このスキルでは、ホスティングと埋め込みについて説明します。
