Incorpora screenshot, immagini, diagrammi, GIF e registrazioni di schermate nei PR e nei problemi di GitHub oppure mettili in scena prima di un PR, raccoglili in un commento allegato o ottieni un collegamento pubblico duraturo per condividere un'immagine con una persona. Utilizzalo ogni volta che un elemento visivo deve finire in una descrizione PR, nel corpo del problema o in un commento PR/problema, di fronte a un compagno di squadra o salvato per un PR che non esiste ancora. I trigger includono "allega uno screenshot al PR", "aggiungi un prima/dopo al problema", "includi uno screenshot di...", "condividi una GIF del flusso", "registra il bug e inseriscilo nel problema", "procurami un collegamento che posso incollare in Slack", "screenshot dello stage per il PR", "allegalo quando apro il PR", "salva questo per il PR", "raccogli i media del PR" o aver appena catturato o modificato qualcosa di visivo che uno scatto potrebbe rendere più chiaro - anche a metà dell'attività, prima che esista un PR. Si applica anche quando un agente non ha un file system locale e sta caricando tramite l'MCP ospitato (agents.uploads.sh). Raggiungi questo invece di trascinare e rilasciare o caricare manualmente l'archiviazione nel cloud. GitHub CLI 2.99+ può allegare una singola immagine a un PR o a un problema esistente con `gh … --attach`; questa abilità dice quando è sufficiente e quando non lo è. Cattura l'immagine con qualsiasi browser o strumento di screenshot di cui disponi; questa competenza copre l'hosting e l'incorporamento.
