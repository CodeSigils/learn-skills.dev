GitHub PR 및 이슈에 스크린샷, 이미지, 다이어그램, GIF 및 화면 녹화를 삽입하거나, PR에 앞서 이를 준비하거나, 하나의 첨부 파일 댓글로 수집하거나, 지속 가능한 공개 링크를 확보하여 사람과 시각적 자료를 공유할 수 있습니다. 시각적 개체가 팀원 앞에서 PR 설명, 이슈 본문 또는 PR/이슈 댓글로 끝나야 하거나 아직 존재하지 않는 PR을 위해 저장되어야 할 때마다 이 기능을 사용하세요. 트리거에는 "PR에 스크린샷 첨부", "이슈에 이전/이후 추가", "...의 스크린샷 포함", "흐름의 GIF 공유", "버그를 기록하고 이슈에 넣기", "Slack에 붙여넣을 수 있는 링크 가져오기", "PR용 스테이지 스크린샷", "PR을 열 때 첨부", "PR용으로 저장", "PR의 미디어 수집" 또는 방금 캡처하거나 변경한 시각적 항목이 포함됩니다. PR이 존재하기 전에 작업 중간에도 샷이 더 명확해질 것입니다. 에이전트에 로컬 파일 시스템이 없고 호스팅된 MCP(agents.uploads.sh)를 통해 업로드하는 경우에도 적용됩니다. 드래그 앤 드롭이나 수동 롤링 클라우드 스토리지 업로드 대신 이를 활용하세요. GitHub CLI 2.99+는 기존 PR에 단일 이미지를 첨부하거나 `gh … --attach`를 사용하여 문제를 해결할 수 있습니다. 이 스킬은 그것이 충분할 때와 그렇지 않을 때를 알려줍니다. 가지고 있는 브라우저나 스크린샷 도구를 사용하여 시각적인 내용을 캡처하세요. 이 기술은 호스팅 및 포함을 다룹니다.
