Incruste capturas de pantalla, imágenes, diagramas, GIF y grabaciones de pantalla en problemas y relaciones públicas de GitHub, o prepárelos antes de un PR, reúnalos en un comentario adjunto u obtenga un enlace público duradero para compartir una imagen con una persona. Use esto siempre que una imagen necesite terminar en una descripción de PR, cuerpo de problema o PR/comentario de problema, frente a un compañero de equipo o guardarse para un PR que aún no existe. Los desencadenantes incluyen "adjuntar una captura de pantalla al PR", "agregar un antes/después del problema", "incluir una captura de pantalla de...", "compartir un GIF del flujo", "grabar el error y ponerlo en el problema", "consígueme un enlace que pueda pegar en Slack", "preparar capturas de pantalla para el PR", "adjuntar esto cuando abra el PR", "guardar esto para el PR", "recopilar los medios del PR", o haber capturado o cambiado algo visual que una toma aclararía, incluso a mitad de la tarea, antes de que exista un RP. También se aplica cuando un agente no tiene un sistema de archivos local y realiza cargas a través del MCP alojado (agents.uploads.sh). Utilice esto en lugar de arrastrar y soltar o realizar cargas de almacenamiento en la nube manualmente. GitHub CLI 2.99+ puede adjuntar una sola imagen a un PR existente o emitir un problema con `gh... --attach`; esta habilidad dice cuándo es suficiente y cuándo no. Capture lo visual con cualquier navegador o herramienta de captura de pantalla que tenga; esta habilidad cubre alojarlo e incrustarlo.
