قم بتضمين لقطات الشاشة والصور والرسوم البيانية وملفات GIF وتسجيلات الشاشة في العلاقات العامة والمشكلات في GitHub - أو قم بوضعها قبل العلاقات العامة، أو اجمعها في تعليق مرفق واحد، أو احصل على رابط عام دائم لمشاركة صورة مرئية مع شخص ما. استخدم هذا عندما تحتاج العناصر المرئية إلى أن تنتهي في وصف العلاقات العامة، أو نص المشكلة، أو تعليق العلاقات العامة/المشكلة، أمام أحد أعضاء الفريق، أو حفظها في علاقات عامة غير موجودة بعد. تتضمن المشغلات "إرفاق لقطة شاشة للعلاقات العامة"، و"إضافة قبل/بعد للمشكلة"، و"تضمين لقطة شاشة لـ..."، و"مشاركة صورة GIF للتدفق"، و"تسجيل الخطأ ووضعه في المشكلة"، و"أحصل على رابط يمكنني لصقه في Slack"، و"لقطات شاشة للمسرحية للعلاقات العامة"، و"إرفاق هذا عندما أفتح العلاقات العامة"، و"حفظ هذا للعلاقات العامة"، و"جمع وسائط العلاقات العامة"، أو التقاط شيء مرئي أو تغييره. ستجعل اللقطة أكثر وضوحًا - حتى في منتصف المهمة، قبل وجود العلاقات العامة. ينطبق أيضًا عندما لا يكون لدى الوكيل نظام ملفات محلي ويتم التحميل عبر MCP المستضاف (agents.uploads.sh). يمكنك الوصول إلى هذا بدلاً من السحب والإفلات أو التحميل اليدوي للتخزين السحابي. يمكن لـ GitHub CLI 2.99+ إرفاق صورة واحدة بعلاقات عامة موجودة أو مشكلة مع `gh … --attach`؛ هذه المهارة تقول متى يكون ذلك كافيا ومتى لا يكون كذلك. التقط العناصر المرئية باستخدام أي متصفح أو أداة لقطة شاشة لديك؛ تغطي هذه المهارة استضافتها وتضمينها.
