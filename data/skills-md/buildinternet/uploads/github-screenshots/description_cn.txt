在 GitHub PR 和问题中嵌入屏幕截图、图像、图表、GIF 和屏幕录制，或者将它们放在 PR 之前，将它们收集到一个附件评论中，或者获取持久的公共链接来与人分享视觉效果。每当视觉效果需要在团队成员面前出现在 PR 描述、问题正文或 PR/问题评论中，或为尚不存在的 PR 保存时，请使用此选项。触发器包括“在 PR 中附加屏幕截图”、“在问题中添加之前/之后的屏幕截图”、“包含……的屏幕截图”、“分享流程的 GIF”、“记录 bug 并将其放入问题中”、“给我一个可以粘贴到 Slack 中的链接”、“PR 的阶段屏幕截图”、“在打开 PR 时附加此内容”、“将其保存到 PR 中”、“收集 PR 的媒体”，或者刚刚捕获或更改了某个镜头的视觉效果在 PR 存在之前，即使是在任务中期，也会变得更清晰。当代理没有本地文件系统并通过托管 MCP (agents.uploads.sh) 上传时也适用。实现此目的，而不是拖放或手动滚动云存储上传。 GitHub CLI 2.99+ 可以使用“gh … --attach”将单个图像附加到现有 PR 或问题；这个技能说明什么时候这就足够了，什么时候还不够。使用您拥有的任何浏览器或屏幕截图工具捕获视觉效果；这项技能涵盖托管和嵌入它。
