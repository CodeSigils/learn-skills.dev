Controlla e aggiorna i file della memoria di Serena in modo che rimangano concisi, datati e collegati alla fonte. Da utilizzare quando esiste `.serena/memories` e l'attività mantiene le memorie di Serena, legge o modifica i file di memoria di Serena, aggiorna la memoria/documenti di progetto canonici o controlla una memoria che potrebbe essere obsoleta rispetto a documenti di repository, manifest, sorgenti o test canonici.
