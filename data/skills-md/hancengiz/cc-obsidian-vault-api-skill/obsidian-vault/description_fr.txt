Intégrez-vous aux coffres Obsidian via le plugin API REST Local.

Utilisez cette compétence lorsque l'utilisateur souhaite :
- Rechercher des notes dans leur coffre-fort en obsidienne
- Lire des notes spécifiques
- Créer de nouvelles notes
- Modifier les notes existantes
- Gérer les notes quotidiennes/périodiques
- Exécuter des requêtes Dataview

IMPORTANT : Cette compétence effectue des opérations destructrices (créer, modifier, supprimer).
Suivez toujours les règles de sécurité et les exigences de confirmation.

S'active lorsque l'utilisateur mentionne :
- "Obsidienne", "mon coffre-fort", "mes notes"
- "note quotidienne", "entrée de journal"
- "rechercher mes notes", "trouver dans Obsidian"
- Création, mise à jour ou suppression de notes
