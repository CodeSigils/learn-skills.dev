ローカル REST API プラグインを介して Obsidian Vault と統合します。

ユーザーが次のことを行う場合にこのスキルを使用します。
- 黒曜石の保管庫でメモを検索
- 特定のメモを読む
- 新しいメモを作成する
- 既存のメモを変更する
- 毎日/定期的なメモを管理
- データビュークエリの実行

重要: このスキルは、破壊的な操作 (作成、変更、削除) を実行します。
常に安全規則と確認要件に従ってください。

ユーザーが次のことを言及するとアクティブ化されます。
- 「黒曜石」、「私の保管庫」、「私のメモ」
- 「日々のメモ」、「日記」
- 「メモを検索」、「オブシディアンで検索」
- メモの作成、更新、削除
