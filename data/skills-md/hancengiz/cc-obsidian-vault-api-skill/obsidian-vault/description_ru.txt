Интегрируйтесь с хранилищами Obsidian через плагин Local REST API.

Используйте этот навык, когда пользователь хочет:
- Ищите заметки в их обсидиановом хранилище.
- Прочитайте конкретные примечания
- Создание новых заметок
- Изменить существующие заметки
- Управление ежедневными/периодическими заметками
- Выполнение запросов к просмотру данных

ВАЖНО: Этот навык выполняет деструктивные операции (создание, изменение, удаление).
Всегда соблюдайте правила безопасности и требования подтверждения.

Активируется, когда пользователь упоминает:
- «Обсидиан», «мое хранилище», «мои записи»
- «ежедневная заметка», «запись в журнале»
- "поищи в моих заметках", "найди в Обсидиане"
- Создание, обновление или удаление заметок
