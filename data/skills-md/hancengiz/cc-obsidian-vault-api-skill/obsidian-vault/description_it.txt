Integrazione con le casseforti Obsidian tramite il plug-in API REST locale.

Utilizza questa abilità quando l'utente desidera:
- Cerca appunti nel loro caveau di ossidiana
- Leggere note specifiche
- Creare nuove note
- Modificare le note esistenti
- Gestire le note giornaliere/periodiche
- Eseguire query Dataview

IMPORTANTE: questa abilità esegue operazioni distruttive (crea, modifica, elimina).
Seguire sempre le regole di sicurezza e i requisiti di conferma.

Si attiva quando l'utente menziona:
- "Ossidiana", "la mia volta", "i miei appunti"
- "nota giornaliera", "annotazione nel diario"
- "cerca nei miei appunti", "trova in Obsidian"
- Creazione, aggiornamento o eliminazione di note
