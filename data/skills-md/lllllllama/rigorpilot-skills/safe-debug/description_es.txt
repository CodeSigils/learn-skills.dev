Habilidad Rigor Debug / Rigor Audit para trabajos de investigación de aprendizaje profundo. Úselo cuando el usuario pega un rastreo, un error de terminal, CUDA OOM, una falla de carga del punto de control, una falta de coincidencia de formas, un síntoma de pérdida de NaN o una falla de entrenamiento y desea un diagnóstico conservador antes de cualquier parche, con correcciones de depuración claramente separadas de las contribuciones de investigación. No lo utilice para refactorización amplia, adaptación especulativa, parcheo exploratorio automático o familiarización general con el repositorio.
