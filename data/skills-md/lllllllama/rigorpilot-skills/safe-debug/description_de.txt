Rigor Debug/Rigor Audit-Fähigkeit für Deep-Learning-Forschungsarbeiten. Verwenden Sie diese Option, wenn der Benutzer einen Traceback, einen Terminalfehler, einen CUDA OOM, einen Checkpoint-Ladefehler, eine Formabweichung, ein NaN-Verlustsymptom oder einen Trainingsfehler einfügt und vor dem Patchen eine konservative Diagnose wünscht, wobei Debug-Fixes klar von Forschungsbeiträgen getrennt sind. Nicht für umfassendes Refactoring, spekulative Anpassung, automatisches exploratives Patching oder allgemeine Repository-Einarbeitung verwenden.
