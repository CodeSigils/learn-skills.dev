Competenza Rigor Run per la riproduzione del primo repository di deep learning README. Da utilizzare quando l'attività è specificatamente quella di acquisire o normalizzare le prove dal test del fumo selezionato o dall'inferenza documentata o dal comando di valutazione e scrivere file "repro_outputs/" standardizzati, incluse le note sulla patch quando i file del repository vengono modificati. Non utilizzare per l'esecuzione del training, l'assunzione iniziale di repository, la configurazione di un ambiente generico, la ricerca di documenti, la selezione di target, modifiche nascoste di significato scientifico o l'orchestrazione end-to-end di per sé.
