Habilidad Rigor Run para la reproducción de repositorios de aprendizaje profundo, el primero en README. Úselo cuando la tarea sea específicamente capturar o normalizar evidencia de la prueba de humo seleccionada o del comando de evaluación o inferencia documentada y escribir archivos `repro_outputs/` estandarizados, incluidas notas de parche cuando los archivos del repositorio cambiaron. No lo utilice para la ejecución de capacitación, la ingesta inicial de repositorios, la configuración de un entorno genérico, la búsqueda de documentos, la selección de objetivos, los cambios ocultos de significado científico ni la orquestación de un extremo a otro.
