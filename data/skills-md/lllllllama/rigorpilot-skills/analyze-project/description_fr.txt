Compétence en lecture seule Rigor Analyse / Rigor Audit pour les référentiels de recherche en apprentissage profond. À utiliser lorsque l'utilisateur souhaite lire et comprendre un référentiel, inspecter la structure du modèle et les points d'entrée de formation ou d'inférence, examiner les configurations et les points d'insertion, ou signaler les modèles d'implémentation suspects sans modifier le code ni exécuter de tâches lourdes. Ne pas utiliser pour l'exécution active de commandes, la refactorisation à grande échelle, l'adaptation spéculative de code ou la correction automatique de bogues.
