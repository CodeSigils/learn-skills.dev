Habilidad de solo lectura Rigor Analyse / Rigor Audit para repositorios de investigación de aprendizaje profundo. Úselo cuando el usuario quiera leer y comprender un repositorio, inspeccionar la estructura del modelo y los puntos de entrada de entrenamiento o inferencia, revisar configuraciones y puntos de inserción, o marcar patrones de implementación sospechosos sin modificar el código ni ejecutar trabajos pesados. No lo utilice para la ejecución activa de comandos, refactorización amplia, adaptación de código especulativo o corrección automática de errores.
