مهارة الإعداد الصارمة لإعادة إنتاج مستودعات التعلم العميق لـ README-first. يُستخدم عندما تكون المهمة مخصصة لإعداد بيئة كوندا أولية متحفظة، وافتراضات مسار نقطة التفتيش ومجموعة البيانات، وتلميحات موقع ذاكرة التخزين المؤقت، وملاحظات الإعداد قبل أي تشغيل على مستودع README الموثق. لا تستخدمه في المسح الضوئي الريبو، أو التنسيق الكامل، أو التفسير الورقي، أو إعداد تقارير التشغيل النهائي، أو إعداد البيئة العامة غير المرتبطة بهدف إعادة إنتاج محدد.
