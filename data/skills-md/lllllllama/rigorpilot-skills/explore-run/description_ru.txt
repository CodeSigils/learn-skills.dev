Rigor Improve / Rigor Explore. Навык запуска листьев для ограниченного исследовательского доказательства в репозиториях исследований глубокого обучения. Используйте, когда исследователь явно разрешает исследовательские прогоны, такие как проверка небольшого подмножества, угадывание и проверка с коротким циклом, пакетная проверка, поиск бездействующего графического процессора или быстрые испытания переноса обучения, с предостережениями о справедливом сравнении и сводками без завышения в `explore_outputs/`. Не используйте для оркестрации сквозного исследования поверх current_research, доверенного базового выполнения, консервативной проверки обучения, маршрутизации по умолчанию, проверенных утверждений SOTA или неявного экспериментирования.
