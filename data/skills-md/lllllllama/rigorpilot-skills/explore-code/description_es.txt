Rigor Mejorar la habilidad de implementación de hojas para la implementación de candidatos auditables en repositorios de investigación de aprendizaje profundo. Úselo cuando el investigador autoriza explícitamente el trabajo exploratorio en una rama o árbol de trabajo aislado para trasplantar módulos, adaptar una red troncal, agregar LoRA o capas de adaptador, reemplazar una cabeza o unir ideas significativas de migración de bajo riesgo con registros con capacidad de reversión en `explore_outputs/`. No lo utilice para la orquestación de exploración de un extremo a otro además de `current_research`, reproducción de línea de base confiable, depuración conservadora, configuración del entorno, declaraciones de contribución verificadas o análisis de repositorio predeterminado.
