الدقة تحسين مهارة ورقة التنفيذ لتنفيذ المرشح القابل للتدقيق في مستودعات أبحاث التعلم العميق. يُستخدم عندما يسمح الباحث صراحةً بعمل استكشافي على فرع أو شجرة عمل معزولة لزرع الوحدات النمطية، أو تكييف العمود الفقري، أو إضافة LoRA أو طبقات المحول، أو استبدال الرأس، أو تجميع أفكار ترحيل ذات معنى منخفضة المخاطر معًا باستخدام سجلات مدركة للتراجع في `explore_outputs/`. لا تستخدم لتنسيق الاستكشاف الشامل فوق "البحث_الحالي"، أو إعادة إنتاج خط الأساس الموثوق به، أو التصحيح المحافظ، أو إعداد البيئة، أو مطالبات المساهمة التي تم التحقق منها، أو تحليل المستودع الافتراضي.
