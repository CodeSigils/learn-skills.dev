الصرامة إعادة إنتاج سبيكة المهارات المتوافقة لإعادة إنتاج مستودع التعلم العميق لـ README الأول. يُستخدم عندما يريد المستخدم تدفقًا شاملاً وجديرًا بالثقة يقرأ المستودع أولاً، ويحدد أصغر استدلال موثق أو هدف تقييم، وينسق الإدخال، والإعداد، والتنفيذ الموثوق، والتدريب الموثوق الاختياري، وتحليل المستودع الاختياري، وحل الفجوة الورقية الاختيارية، ويفرض قواعد التصحيح المحافظة، ويسجل انحرافات افتراضات الأدلة ونقاط القرار البشري، ويكتب حزمة `repro_outputs/` القياسية. لا تستخدم لملخص الورق، أو إعداد البيئة العامة، أو مسح الريبو المعزول، أو تنفيذ الأوامر المستقلة، أو تغييرات البروتوكول الصامتة، أو مطاردة النتائج، أو المساعدة البحثية الواسعة خارج النسخ المستند إلى المستودع.
