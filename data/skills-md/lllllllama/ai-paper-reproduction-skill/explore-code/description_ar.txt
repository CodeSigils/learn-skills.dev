استكشاف مهارة التكيف مع كود المسار لمستودعات أبحاث التعلم العميق. يُستخدم عندما يسمح الباحث صراحةً بالعمل الاستكشافي على فرع أو شجرة عمل معزولة لزرع الوحدات النمطية، أو تكييف العمود الفقري، أو إضافة LoRA أو طبقات المحول، أو استبدال الرأس، أو تجميع أفكار الترحيل منخفضة المخاطر معًا باستخدام سجلات ملخصة فقط في `explore_outputs/`. لا تستخدم لتنسيق الاستكشاف الشامل أعلى "البحث_الحالي"، أو إعادة إنتاج خط الأساس الموثوق به، أو التصحيح المحافظ، أو إعداد البيئة، أو تحليل المستودع الافتراضي.
