Capacità di adattamento del codice Explore-Lane per repository di ricerca di deep learning. Da utilizzare quando il ricercatore autorizza esplicitamente il lavoro esplorativo su un ramo isolato o un albero di lavoro per trapiantare moduli, adattare una dorsale, aggiungere LoRA o livelli di adattatore, sostituire una testa o unire idee di migrazione a basso rischio con record di solo riepilogo in "explore_outputs/". Non utilizzare per l'orchestrazione dell'esplorazione end-to-end su "current_research", riproduzione di base attendibile, debug conservativo, configurazione dell'ambiente o analisi del repository predefinito.
