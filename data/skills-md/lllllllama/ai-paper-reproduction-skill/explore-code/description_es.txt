Habilidad de adaptación de código de carril de exploración para repositorios de investigación de aprendizaje profundo. Úselo cuando el investigador autoriza explícitamente el trabajo exploratorio en una rama o árbol de trabajo aislado para trasplantar módulos, adaptar una columna vertebral, agregar capas LoRA o adaptadoras, reemplazar una cabeza o unir ideas de migración de bajo riesgo con registros de solo resumen en `explore_outputs/`. No lo utilice para la orquestación de exploración de un extremo a otro además de `current_research`, reproducción de línea de base confiable, depuración conservadora, configuración del entorno o análisis de repositorio predeterminado.
