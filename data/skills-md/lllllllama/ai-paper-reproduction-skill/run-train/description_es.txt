Habilidad de ejecución de capacitación de carril confiable para repositorios de investigación de aprendizaje profundo. Úselo cuando un comando de entrenamiento documentado o seleccionado debe ejecutarse de manera conservadora para la verificación de inicio, la verificación de ejecución corta, el inicio completo o la reanudación, con el estado, el punto de control y la captura de métricas escritos en `train_outputs/` estandarizados. No lo utilice para la configuración del entorno, barridos exploratorios, implementación de ideas especulativas ni orquestación de un extremo a otro.
