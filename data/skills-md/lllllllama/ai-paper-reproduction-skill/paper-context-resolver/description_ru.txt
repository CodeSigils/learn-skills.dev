Дополнительный дополнительный навык для воспроизведения репозитория AI в формате README. Используйте только тогда, когда файлы README и репозитория оставляют узкий критический для воспроизведения пробел, и задача состоит в том, чтобы разрешить определенные детали документа, такие как разделение набора данных, предварительная обработка, протокол оценки, сопоставление контрольных точек или предположения времени выполнения из первичных бумажных источников при записи конфликтов. Не используйте для общего обзора статьи, сканирования репозитория, настройки среды, выполнения команд, поиска статьи только по заголовку или замены руководства README по умолчанию.
