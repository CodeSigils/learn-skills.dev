Sous-compétence facultative pour la reproduction du dépôt AI README-first. À utiliser uniquement lorsque les fichiers README et de référentiel laissent un espace critique pour la reproduction et que la tâche consiste à résoudre un détail papier spécifique tel que la division d'un ensemble de données, le prétraitement, le protocole d'évaluation, le mappage de points de contrôle ou l'hypothèse d'exécution à partir de sources papier principales lors de l'enregistrement des conflits. Ne pas utiliser pour le résumé général du papier, l'analyse des dépôts, la configuration de l'environnement, l'exécution de commandes, la recherche de papier par titre uniquement ou le remplacement des instructions README par défaut.
