Subhabilidad opcional para la reproducción del primer repositorio de IA README. Úselo solo cuando los archivos README y del repositorio dejen una brecha estrecha y crítica para la reproducción y la tarea sea resolver un detalle específico del papel, como la división del conjunto de datos, el preprocesamiento, el protocolo de evaluación, el mapeo de puntos de control o la suposición del tiempo de ejecución de fuentes primarias del papel mientras se registran los conflictos. No lo utilice para resúmenes generales de artículos, escaneo de repositorios, configuración del entorno, ejecución de comandos, búsqueda de artículos solo por títulos ni para reemplazar la guía README de forma predeterminada.
