Abilità di supporto ristretta opzionale per la riproduzione del primo repository AI README. Utilizzare solo quando i file README e repository lasciano uno stretto divario critico per la riproduzione e l'attività consiste nel risolvere un dettaglio cartaceo specifico come la suddivisione del set di dati, la preelaborazione, il protocollo di valutazione, la mappatura dei checkpoint o l'ipotesi di runtime da fonti cartacee primarie durante la registrazione dei conflitti. Non utilizzare per riepiloghi generali del documento, scansione di repository, configurazione dell'ambiente, esecuzione di comandi, ricerca di documenti solo per titolo o sostituzione della guida README per impostazione predefinita.
