Создавайте интеллектуальные карты Xmind со сгенерированными тематическими изображениями с помощью рабочего процесса с контактным листом. Требуется возможность создания изображений (встроенная в интерфейс командной строки Codex/Gemini или внешний API изображений). Используйте для иллюстрированных карт; для текстовых карт используйте xmind-file.
