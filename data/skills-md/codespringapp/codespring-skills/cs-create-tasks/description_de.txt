Verwandeln Sie die Notizen und PRDs einer CodeSpring-Funktion in eine nummerierte, priorisierte Kanban-Aufgabenliste, die mit dieser Funktion verknüpft ist. Liest das Feature, seine Unterfeatures, seine PRDs und alle damit verknüpften Features und schreibt dann geordnete Aufgaben, die sicher parallel erstellt werden können – jede mit Was/Warum/Was-es-berührt/Was-nicht-anfassen/Abhängigkeiten. Verwenden Sie diese Option, wenn der Benutzer eine Funktion geplant hat und einen Build-Plan möchte. Auslöser: „Aufgaben erstellen“, „Aufgabenliste erstellen“, „Diese Funktion in Aufgaben aufteilen“, „Build-Plan generieren“, „meine PRD in Aufgaben umwandeln“, „Was baue ich zuerst“.
