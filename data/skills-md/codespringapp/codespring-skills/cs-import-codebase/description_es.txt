Importe una base de código existente a CodeSpring como un mapa de características visuales: características principales (barra lateral/páginas de navegación) con subcaracterísticas anidadas y una nota de "cómo funciona" por característica; luego genere PRD de frontend + backend (a través de cs-create-prd) y ejecute una auditoría en segundo plano independiente del código frente al mapa. Entonces CodeSpring entiende la aplicación y el usuario puede diseñar nuevas funciones sin duplicar ni romper lo que existe. Activadores, "importar mi código base a CodeSpring", "mapear mi aplicación existente", "realizar ingeniería inversa en funciones de mi aplicación", "traer este proyecto a CodeSpring", "visualizar mi código en CodeSpring".
