Importez une base de code existante dans CodeSpring en tant que carte visuelle des fonctionnalités - fonctionnalités principales (barre latérale/pages de navigation) avec des sous-fonctionnalités imbriquées et une note "comment ça marche" par fonctionnalité - puis générez des PRD Frontend + Backend (via cs-create-prd) et exécutez un audit en arrière-plan indépendant du code par rapport à la carte. Ainsi CodeSpring comprend l'application et l'utilisateur peut concevoir de nouvelles fonctionnalités sans dupliquer ni casser ce qui existe. Déclencheurs, « importer ma base de code dans CodeSpring », « mapper mon application existante », « procéder à l'ingénierie inverse de mon application en fonctionnalités », « importer ce projet dans CodeSpring », « visualiser mon code dans CodeSpring ».
