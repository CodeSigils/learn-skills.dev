Импортируйте существующую кодовую базу в CodeSpring в виде визуальной карты функций — основные функции (боковые панели/страницы навигации) с вложенными подфункциями и примечанием «как это работает» для каждой функции — затем сгенерируйте PRD Frontend + Backend (через cs-create-prd) и запустите независимый фоновый аудит кода по сравнению с картой. Таким образом, CodeSpring понимает приложение, и пользователь может разрабатывать новые функции, не дублируя и не нарушая уже существующие. Триггеры: «импортировать мою кодовую базу в CodeSpring», «сопоставить мое существующее приложение», «перепроектировать мое приложение с функциями», «перенести этот проект в CodeSpring», «визуализировать мой код в CodeSpring».
