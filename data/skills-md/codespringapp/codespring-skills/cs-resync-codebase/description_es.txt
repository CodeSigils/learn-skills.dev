Vuelva a sincronizar CodeSpring con el código real después de compilarlo. Comprueba de forma independiente si las funciones, notas y PRD en CodeSpring aún coinciden con lo que el código realmente hace ahora (las funciones se desvían de su plan una vez creadas), luego actualiza CodeSpring para que coincida. Solo lectura en el código base: solo lee código/git y escribe en CodeSpring. Úselo después de finalizar una función, o periódicamente, para evitar que el mapa se quede obsoleto. Activadores, "resincronizar mi código base", "CodeSpring está actualizado", "verificar si hay PRD obsoletos", "actualizar CodeSpring desde el código", "mi plan se desvió del código".
