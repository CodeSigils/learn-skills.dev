Vérifie indépendamment si les fonctionnalités, les notes et les PRD de CodeSpring correspondent toujours à ce que le code fait actuellement (les fonctionnalités dérivent de leur plan une fois construit), puis met à jour CodeSpring pour qu'il corresponde. En lecture seule sur la base de code — il lit uniquement le code/git et écrit dans CodeSpring. À utiliser une fois qu'une fonctionnalité est terminée, ou périodiquement, pour éviter que la carte ne devienne obsolète. Déclencheurs, "resynchroniser ma base de code", "CodeSpring est-il à jour", "vérifier les PRD périmés", "mettre à jour CodeSpring à partir du code", "mon plan a dérivé du code".
