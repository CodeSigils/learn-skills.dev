Synchronisieren Sie CodeSpring nach der Erstellung erneut mit dem echten Code. Überprüft unabhängig, ob die Funktionen, Hinweise und PRDs in CodeSpring immer noch mit dem übereinstimmen, was der Code jetzt tatsächlich tut (Funktionen weichen nach der Erstellung von ihrem Plan ab) und aktualisiert dann CodeSpring entsprechend. Schreibgeschützt in der Codebasis – es liest nur Code/Git und schreibt in CodeSpring. Verwenden Sie diese Funktion, nachdem eine Funktion abgeschlossen ist, oder in regelmäßigen Abständen, um zu verhindern, dass die Karte veraltet. Auslöser: „Meine Codebasis neu synchronisieren“, „Ist CodeSpring auf dem neuesten Stand“, „Auf veraltete PRDs prüfen“, „CodeSpring aus dem Code aktualisieren“, „Mein Plan ist vom Code abgewichen“.
