Spécialiste de la création de PRD CodeSpring. Interactif - il répertorie les fonctionnalités principales de l'utilisateur, demande laquelle et s'il doit générer un PRD frontend, backend ou les deux, puis approfondit le code réel, génère le ou les PRD et les attache au pont de la fonctionnalité sur le canevas. Les PRD capturent les contrats backend partagés et le système de conception afin que de nouvelles fonctionnalités soient créées sans dupliquer ni casser ce qui existe. À utiliser lorsque l'utilisateur souhaite un PRD/spécification pour une fonctionnalité. Déclencheurs, "créer un PRD", "créer un PRD frontend", "créer un PRD backend", "générer des PRD pour cette fonctionnalité", "documenter cette fonctionnalité dans CodeSpring", "spécifier X afin que je puisse concevoir de nouvelles fonctionnalités".
