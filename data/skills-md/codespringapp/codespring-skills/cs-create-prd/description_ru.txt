Специалист по созданию PRD CodeSpring. Интерактивный — он перечисляет основные функции пользователя, спрашивает, какая из них и нужно ли создавать Frontend, Backend или оба PRD, затем глубоко погружается в реальный код, генерирует PRD(ы) и прикрепляет их к мосту функции на холсте. PRD фиксируют общие контракты на серверную часть и систему проектирования, поэтому новые функции создаются без дублирования или нарушения существующих. Используйте, когда пользователю нужен PRD/спецификация для функции. Триггеры: «создать PRD», «создать PRD внешнего интерфейса», «создать PRD внутреннего интерфейса», «сгенерировать PRD для этой функции», «задокументировать эту функцию в CodeSpring», «специфицировать X, чтобы я мог разработать новые функции».
