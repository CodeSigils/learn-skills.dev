CodeSpring PRD 作成のスペシャリスト。インタラクティブ — ユーザーのコア機能をリストし、どれをフロントエンド、バックエンド、または両方の PRD を生成するかを尋ね、実際のコードを詳しく調べて PRD を生成し、キャンバス上の機能のブリッジにアタッチします。 PRD は共有バックエンド コントラクトと設計システムをキャプチャするため、既存のものを複製したり壊したりすることなく新しい機能が構築されます。ユーザーが機能の PRD / 仕様を必要とする場合に使用します。トリガー、「PRD を作成する」、「フロントエンド PRD を作成する」、「バックエンド PRD を作成する」、「この機能の PRD を生成する」、「CodeSpring でこの機能を文書化する」、「新しい機能を設計できるように X を仕様化する」。
