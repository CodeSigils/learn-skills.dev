Especialista en la creación de PRD CodeSpring. Interactivo: enumera las funciones principales del usuario, pregunta cuál y si se debe generar un PRD de frontend, backend o ambos, luego profundiza en el código real, genera los PRD y los adjunta al puente de la función en el lienzo. Los PRD capturan los contratos de backend compartidos y el sistema de diseño para que se creen nuevas funciones sin duplicar ni romper lo que existe. Úselo cuando el usuario desee un PRD/especificaciones para una función. Activadores, "crear un PRD", "crear un PRD frontal", "crear un PRD backend", "generar PRD para esta característica", "documentar esta característica en CodeSpring", "especificar X para poder diseñar nuevas características".
