Interactive orchestrator that builds a feature from its CodeSpring plan. It interviews the user about what they're building, checks the feature has enough context (notes + Frontend/Backend PRDs) and a numbered task list, guides them to fill any gaps, then builds the Kanban tasks — optionally spawning up to 5 parallel sub-agents — while guarding the shared systems it could break. Use when the user wants to build/implement a feature they planned in CodeSpring. Triggers, "build this feature", "implement my feature", "start building from CodeSpring", "let's build X", "work through my Kanban tasks".
