Применяйте эти самоуверенные соглашения Next.js при написании или проверке кода App Router (14+): компоненты сервера по умолчанию, к которым относится граница «использовать клиент», параметры кэширования по умолчанию, которые были изменены в Next 15, повторная проверка на основе тегов, обработка действий сервера как общедоступных конечных точек, API метаданных, а также next/image и next/font.
