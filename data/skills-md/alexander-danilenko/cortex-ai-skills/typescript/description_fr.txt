Appliquez ces conventions TypeScript avisées chaque fois que vous écrivez ou révisez TypeScript : types de marque pour la modélisation de domaine, unions discriminées pour l'état, « satisfait » plutôt que « comme », des objets const au lieu d'énumérations, des importations de type uniquement et la ligne de base stricte tsconfig au-delà de « strict : true ». À utiliser également pour les références de projets monorepo et la configuration de construction incrémentielle.
