docstring、JSDoc/TSDoc、または REST API ドキュメントを含むタスクについては、リクエストがそれなしで処理できるように見える場合でも、常に呼び出してください。 Microsoft の契約優先規則と、Claude がデフォルトでは適用しない最低限のルールを強制します。署名を再記述しない、名前と型のみをエコーする @param/@returns を削除する、常に @throws を文書化する、データ形状を「WHAT not WHY」として文書化する。 Python docstring スタイル (Google/NumPy/Sphinx)、TSDoc タグと @inheritDoc、NestJS/Express/FastAPI/Django の API ドキュメント パターンをカバーします。トリガー: docstring の追加または監査、タグの冗長または欠落、コメントの腐敗の削除、またはドキュメントの健全性レポートの作成。文書化タスクをスキップしないでください。一貫した規則が重要です。
