قم دائمًا باستدعاء أي مهمة تتضمن مستندات أو وثائق JSDoc/TSDoc أو REST API - حتى عندما يبدو الطلب قابلاً للمعالجة بدونه. يفرض اصطلاحات العقد الأول لـ Microsoft وقاعدة الحد الأدنى التي لن يطبقها Claude افتراضيًا: لا تقم أبدًا بإعادة صياغة التوقيع، وإسقاط @param/@returns الذي يردد الأسماء والأنواع فقط، وتوثيق @throws دائمًا، وتوثيق أشكال البيانات على أنها "ماذا وليس لماذا". يغطي أنماط مستندات Python (Google/NumPy/Sphinx)، وعلامات TSDoc و@inheritDoc، وأنماط مستندات API لـ NestJS/Express/FastAPI/Django. تشغيل: إضافة أو تدقيق سلاسل المستندات، أو العلامات الزائدة أو المفقودة، أو حذف التعليقات الفاسدة، أو إنتاج تقرير صحة التوثيق. لا تتخطى مهام التوثيق، فالاتفاقيات المتسقة هي بيت القصيد.
