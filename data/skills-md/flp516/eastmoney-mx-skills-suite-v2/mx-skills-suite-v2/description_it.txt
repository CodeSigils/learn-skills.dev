East Money Miaoxiang Financial Skills Suite (Enhanced Edition), comprendente 5 sotto-competenze finanziarie specializzate:  
1. eastmoney_fin_data – query di dati finanziari (quotazioni, dati finanziari, relazioni)  
2. eastmoney_fin_search – ricerca di informazioni finanziarie (notizie, annunci, rapporti di ricerca, politiche)  
3. mx_select_stock – screening intelligente delle scorte (filtri condizionali, query di settore, raccomandazioni sulle scorte)  
4. mx_self_select – gestione della watchlist (interroga, aggiungi, rimuovi titoli della watchlist)  
5. eastmoney_stock_simulator – gestione simulata del portafoglio (posizioni, acquisto/vendita, annullamento ordini, ordini, fondi)

✨ Funzionalità migliorata: file di configurazione salvato in modo persistente su ~/.config/eastmoney-mx-skills/.env  
Parole chiave: East Money, Miaoxiang, dati finanziari, query di quotazione, informazioni sulle azioni, screening delle azioni, watchlist, trading simulato, negoziazione di azioni simulata, query di posizione, dati East Money, API East Money.
