Пакет финансовых навыков East Money Miaoxiang (расширенная версия), включающий 5 специализированных финансовых поднавыков:  
1. Eastmoney_fin_data – запросы финансовых данных (котировки, финансы, отношения)  
2. Eastmoney_fin_search – поиск финансовой информации (новости, объявления, исследовательские отчеты, политика)  
3. mx_select_stock – умный скрининг акций (условные фильтры, отраслевые запросы, рекомендации по акциям)  
4. mx_self_select – управление списком наблюдения (запрос, добавление, удаление акций из списка наблюдения)  
5. Eastmoney_stock_simulator – имитация управления портфелем (позиции, покупка/продажа, отмена ордеров, поручения, фонды)  
✨ Расширенная функция: файлы конфигурации постоянно сохраняются в ~/.config/eastmoney-mx-skills/.env.  
Триггерные слова: East Money, Miaoxiang, финансовые данные, запрос котировок, биржевые новости, проверка акций, список наблюдения, симуляция торговли, виртуальная торговля, запрос позиции, данные East Money, API East Money.
