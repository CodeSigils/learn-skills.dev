East Money Miaoxiang Financial Skills Suite (Edición mejorada), que comprende 5 subhabilidades financieras especializadas:  
1. eastmoney_fin_data: consultas de datos financieros (cotizaciones, finanzas, relaciones)  
2. eastmoney_fin_search – búsqueda de información financiera (noticias, anuncios, informes de investigación, políticas)  
3. mx_select_stock: selección inteligente de acciones (filtros condicionales, consultas sectoriales, recomendaciones de acciones)  
4. mx_self_select: gestión de listas de seguimiento (consultar, agregar, eliminar acciones de la lista de seguimiento)  
5. eastmoney_stock_simulator: gestión simulada de cartera (posiciones, compra/venta, cancelación de órdenes, encomiendas, fondos)  
✨ Función mejorada: archivos de configuración guardados persistentemente en ~/.config/eastmoney-mx-skills/.env  
Palabras desencadenantes: East Money, Miaoxiang, datos financieros, consulta de cotizaciones, noticias bursátiles, selección de acciones, lista de vigilancia, operaciones simuladas, operaciones virtuales, consulta de posición, datos de East Money, API de East Money.
