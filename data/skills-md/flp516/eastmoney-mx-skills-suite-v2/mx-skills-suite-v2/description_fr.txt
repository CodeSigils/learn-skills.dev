East Money Miaoxiang Financial Skills Suite (Enhanced Edition), comprenant 5 sous-compétences financières spécialisées :  
1. eastmoney_fin_data – requêtes de données financières (cotations, données financières, relations)  
2. eastmoney_fin_search – recherche d'informations financières (actualités, annonces, rapports de recherche, politiques)  
3. mx_select_stock – sélection intelligente des stocks (filtres conditionnels, requêtes sectorielles, recommandations de stocks)  
4. mx_self_select – gestion de la liste de surveillance (requête, ajout, suppression des actions de la liste de surveillance)  
5. eastmoney_stock_simulator – simulation de gestion de portefeuille (positions, achat/vente, annulation d'ordres, mandats, fonds)  
✨ Fonctionnalité améliorée : fichiers de configuration enregistrés de manière persistante dans ~/.config/eastmoney-mx-skills/.env  
Mots déclencheurs : East Money, Miaoxiang, données financières, requête de cotation, actualités boursières, sélection d'actions, liste de surveillance, trading simulé, trading virtuel, requête de position, données East Money, API East Money.
