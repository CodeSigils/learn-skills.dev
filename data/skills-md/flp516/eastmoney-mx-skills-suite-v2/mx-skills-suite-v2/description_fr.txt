Oriental Fortune Miaoxiang Financial Skill Suite (Enhanced Edition), comprenant 5 sous-compétences financières professionnelles :  
1. eastmoney_fin_data – requête de données financières (cotations, données financières, relations)  
2. eastmoney_fin_search – recherche d'informations financières (actualités, annonces, rapports de recherche, politiques)  
3. mx_select_stock – sélection de titres intelligente (filtrage conditionnel, requête sectorielle, recommandations de titres)  
4. mx_self_select – gestion des stocks auto-sélectionnés (requête, ajout, suppression des stocks auto-sélectionnés)  
5. eastmoney_stock_simulator – gestion de portefeuille simulée (positions, achat/vente, annulation d'ordres, mandats, fonds)  

✨ Fonctionnalité améliorée : fichier de configuration enregistré de manière persistante dans ~/.config/eastmoney-mx-skills/.env  
Mots déclencheurs : Oriental Fortune, Miaoxiang, données financières, requête de cotation, informations boursières, sélection de titres, actions auto-sélectionnées, trading simulé, trading d'actions simulé, requête de position, données Oriental Fortune, API Oriental Fortune.
