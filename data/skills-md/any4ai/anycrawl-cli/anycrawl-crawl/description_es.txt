Extraiga contenido de forma masiva de un sitio web completo o de una sección del sitio. Úselo cuando el usuario quiera rastrear un sitio, extraer todas las páginas de una sección de documentos, extraer de forma masiva varias páginas siguiendo enlaces o decir "rastrear", "obtener todas las páginas", "extraer todo en /docs" o "extraer en masa".
