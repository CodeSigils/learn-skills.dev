Entrées Liaison Cloud (alias proxys) : créez, répertoriez, mettez à jour, activez/désactivez, supprimez les points de terminaison publics qui exposent les applications d'un connecteur à Internet. Une entrée lie une application à un port public (TCP) ou à un domaine (HTTP). Utilisez cette compétence pour des intentions telles que « exposer mon application via une URL publique », « ouvrir le port 8080 au monde », « répertorier mes entrées », « mettre l'entrée 10 hors ligne ». Lisez toujours ../liaison-shared/SKILL.md en premier.
