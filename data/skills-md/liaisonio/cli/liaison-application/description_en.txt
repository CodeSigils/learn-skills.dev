Liaison Cloud applications: register, list, update, delete the IP+port backend services that sit behind a connector. An application is just metadata — it points at an existing TCP/HTTP service on the connector's host network so an entry can route traffic to it. Use this skill for intents like 'register my SSH server with connector X', 'list applications behind connector 100017', 'change application 5's port'. Always read ../liaison-shared/SKILL.md first.
