Applicazioni Liaison Cloud: registra, elenca, aggiorna, elimina i servizi backend IP+porta che si trovano dietro un connettore. Un'applicazione è semplicemente metadata: punta a un servizio TCP/HTTP esistente sulla rete host del connettore in modo che una voce possa instradare il traffico verso di esso. Utilizza questa abilità per intenti come "registra il mio server SSH con il connettore X", "elenca le applicazioni dietro il connettore 100017", "cambia la porta dell'applicazione 5". Leggi sempre prima ../liaison-shared/SKILL.md.
