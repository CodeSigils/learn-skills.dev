Aplicaciones Liaison Cloud: registre, enumere, actualice y elimine los servicios backend del puerto IP+ que se encuentran detrás de un conector. Una aplicación es solo metadatos: apunta a un servicio TCP/HTTP existente en la red host del conector para que una entrada pueda enrutar el tráfico hacia él. Utilice esta habilidad para intenciones como "registrar mi servidor SSH con el conector X", "enumerar aplicaciones detrás del conector 100017", "cambiar el puerto de la aplicación 5". Lea siempre ../liaison-shared/SKILL.md primero.
