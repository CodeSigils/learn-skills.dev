Applications Liaison Cloud : enregistrez, répertoriez, mettez à jour, supprimez les services backend IP+port qui se trouvent derrière un connecteur. Une application n'est que des métadonnées : elle pointe vers un service TCP/HTTP existant sur le réseau hôte du connecteur afin qu'une entrée puisse y acheminer le trafic. Utilisez cette compétence pour des intentions telles que « enregistrer mon serveur SSH avec le connecteur X », « lister les applications derrière le connecteur 100017 », « modifier le port de l'application 5 ». Lisez toujours ../liaison-shared/SKILL.md en premier.
