Общая основа Liaison Cloud CLI: установка, аутентификация с помощью токенов личного доступа, приоритет токенов (флаг > env > файл конфигурации), обработка ошибок и формат вывода. Автоматически загружается всеми остальными навыками liaison-* — всегда сначала консультируйтесь, когда помогаете пользователю работать с liaison-cli.
