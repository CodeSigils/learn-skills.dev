Одноэтапная загрузка Liaison Cloud: создайте соединитель + зарегистрируйте приложение + откройте его через общедоступную запись с помощью одной команды. Используйте этот навык, когда пользователь спрашивает: «Настройте новый туннель для моего SSH-сервера», «Я хочу открыть свое локальное веб-приложение для Интернета», «Создайте новый соединитель для моего домашнего компьютера» или любой другой запрос «перейти с нуля к работающей общедоступной конечной точке». Всегда сначала читайте ../liaison-shared/SKILL.md.
