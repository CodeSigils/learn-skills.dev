Liaison Cloud one-shot bootstrap : créer un connecteur + enregistrer une application + l'exposer via une entrée publique, en une seule commande. Utilisez cette compétence lorsqu'un utilisateur demande « configurer un nouveau tunnel pour mon serveur SSH », « Je souhaite exposer mon application Web locale à Internet », « créer un nouveau connecteur pour ma box domestique » ou toute autre demande de champ vert « passer de rien à un point de terminaison public fonctionnel ».
