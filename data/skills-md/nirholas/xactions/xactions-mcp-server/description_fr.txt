Serveur MCP gratuit fournissant plus de 68 outils permettant aux agents IA d'automatiser X/Twitter. Scrape les profils, les abonnés, les tweets. Publiez, suivez, aimez, retweets, téléchargez des vidéos, analysez les sentiments, surveillez les marques, gérez les DM, exécutez des flux de travail, et bien plus encore. Utilise un marionnettiste local – aucune clé API ni paiement requis. Compatible avec Claude Desktop, Cursor, Windsurf, VS Code. À utiliser lors de la configuration ou de l'utilisation de l'automatisation Twitter de l'agent IA via MCP.
