Server MCP gratuito che fornisce oltre 68 strumenti per gli agenti AI per automatizzare X/Twitter. Raschia profili, follower, tweet. Pubblica, segue, Mi piace, retweet, scarica video, analizza il sentiment, monitora i marchi, gestisce i messaggi diretti, esegue flussi di lavoro e altro ancora. Utilizza Puppeteer locale: non sono richieste chiavi API o pagamenti. Compatibile con Claude Desktop, Cursore, Windsurf, VS Code. Da utilizzare durante la configurazione o l'utilizzo dell'automazione Twitter dell'agente AI tramite MCP.
