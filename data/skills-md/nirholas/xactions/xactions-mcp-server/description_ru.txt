Бесплатный сервер MCP, предоставляющий более 68 инструментов для ИИ-агентов для автоматизации X/Twitter. Парсит профили, подписчиков, твиты. Публикует, подписывается, ставит лайки, ретвитит, загружает видео, анализирует настроения, отслеживает бренды, управляет личными сообщениями, запускает рабочие процессы и многое другое. Использует локальный Puppeteer — никаких ключей API или платежей не требуется. Совместим с Claude Desktop, Cursor, Windsurf, VS Code. Используйте при настройке или использовании автоматизации Twitter агента AI через MCP.
