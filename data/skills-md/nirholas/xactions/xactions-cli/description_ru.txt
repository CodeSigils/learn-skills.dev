Интерфейс командной строки для сбора данных X/Twitter, управления конфигурацией сервера MCP и запуска автоматизации. Удаляет профили, подписчиков, твиты, результаты поиска и многое другое с терминала. Выводит текст, JSON или CSV. Использует скрытность Кукловода. Используйте при запуске операций Twitter из командной строки или автоматических конвейеров.
