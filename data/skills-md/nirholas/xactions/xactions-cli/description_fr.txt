Interface de ligne de commande pour récupérer les données X/Twitter, gérer la configuration du serveur MCP et exécuter l'automatisation. Récupère les profils, les abonnés, les tweets, les résultats de recherche et bien plus encore du terminal. Produit du texte, JSON ou CSV. Utilise la furtivité du Marionnettiste. À utiliser lors de l'exécution d'opérations Twitter à partir d'une ligne de commande ou de pipelines automatisés.
