Включите и интегрируйте протокол криптографических платежей x402 для доступа к API XActions. Поддерживает многоцепочные платежи с несколькими токенами для вызовов API с оплатой за использование. Используйте, когда пользователи хотят оплачивать операции XActions с помощью криптовалюты или интегрировать x402 в свой собственный агент/приложение.
