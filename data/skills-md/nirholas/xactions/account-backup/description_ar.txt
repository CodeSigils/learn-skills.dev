قم بتصدير بيانات حساب X/Twitter الخاص بك ونسخها احتياطيًا - التغريدات والإعجابات والإشارات المرجعية والمتابعين والمتابعة - بتنسيق JSON قابل للتنزيل. يؤدي أيضًا إلى تشغيل تنزيل أرشيف البيانات الرسمي لـ X. يُستخدم عندما يريد المستخدمون إجراء نسخ احتياطي لبيانات حساب X الخاصة بهم أو تصديرها أو أرشفتها.
