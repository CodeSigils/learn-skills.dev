Konvertieren Sie Docker Compose-Dateien oder Installationsdokumente in Sealos-Vorlagen in Produktionsqualität. Verwenden Sie diese Option, wenn der Benutzer über eine docker-compose.yml verfügt und eine Sealos- oder Kubernetes-Vorlage möchte, von Docker Compose zu Sealos migrieren möchte, Container-Orchestrierungskonfigurationen in das Sealos-Format konvertieren muss oder die Konvertierung von Compose in eine Vorlage erwähnt. Wird auch bei „/docker-to-sealos“ ausgelöst.
