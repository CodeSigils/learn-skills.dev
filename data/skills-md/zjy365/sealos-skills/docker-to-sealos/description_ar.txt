قم بتحويل ملفات Docker Compose أو مستندات التثبيت إلى قوالب Sealos على مستوى الإنتاج. يُستخدم عندما يكون لدى المستخدم ملف docker-compose.yml ويريد قالب Sealos أو Kubernetes، أو يريد الترحيل من Docker Compose إلى Sealos، أو يحتاج إلى تحويل تكوينات تنسيق الحاوية إلى تنسيق Sealos، أو يذكر تحويل الإنشاء إلى قالب. يتم تشغيله أيضًا على "/ docker-to-sealos".
