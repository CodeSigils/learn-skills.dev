Stellen Sie jedes GitHub-Projekt mit einem Befehl in der Sealos Cloud bereit. Bewertet die Bereitschaft, generiert eine Docker-Datei, erstellt ein Image, erstellt eine Sealos-Vorlage und stellt sie bereit – vollständig automatisiert. Wird verwendet, wenn der Benutzer „Auf Sealos bereitstellen“, „Dieses Projekt bereitstellen“, „In der Cloud bereitstellen“, „Dieses Repo bereitstellen“ sagt, die Sealos-Bereitstellung erwähnt, eine GitHub-URL oder ein lokales Projekt auf einer Cloud-Plattform bereitstellen möchte oder nach einer Ein-Klick-Bereitstellung fragt. Wird auch bei „/sealos-deploy“ ausgelöst.
