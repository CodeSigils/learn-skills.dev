Разверните любой проект GitHub в Sealos Cloud с помощью одной команды. Оценивает готовность, генерирует Dockerfile, создает образ, создает шаблон Sealos и развертывает — полностью автоматически. Используйте, когда пользователь говорит «развернуть в sealos», «развернуть этот проект», «развернуть в облаке», «развернуть этот репозиторий», упоминает развертывание Sealos, хочет развернуть URL-адрес GitHub или локальный проект на облачной платформе или спрашивает о развертывании одним щелчком мыши. Также срабатывает при «/sealos-deploy».
