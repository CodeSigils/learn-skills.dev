Implemente cualquier proyecto de GitHub en Sealos Cloud con un solo comando. Evalúa la preparación, genera Dockerfile, crea imágenes, crea plantillas Sealos y las implementa, de forma totalmente automatizada. Úselo cuando el usuario diga "implementar en sealos", "implementar este proyecto", "implementar en la nube", "implementar este repositorio", mencione la implementación de Sealos, quiera implementar una URL de GitHub o un proyecto local en una plataforma en la nube, o pregunte sobre la implementación con un solo clic. También se activa en "/sealos-deploy".
