Déployez n'importe quel projet GitHub sur Sealos Cloud en une seule commande. Évalue l'état de préparation, génère un Dockerfile, crée une image, crée un modèle Sealos et déploie - entièrement automatisé. À utiliser lorsque l'utilisateur dit « déployer sur sealos », « déployer ce projet », « déployer sur le cloud », « déployer ce dépôt », mentionne le déploiement de Sealos, souhaite déployer une URL GitHub ou un projet local sur une plate-forme cloud, ou pose des questions sur le déploiement en un clic. Se déclenche également sur "/sealos-deploy".
