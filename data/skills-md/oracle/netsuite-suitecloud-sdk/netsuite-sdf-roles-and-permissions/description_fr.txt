À utiliser lors de la génération ou de la révision des configurations d'autorisations NetSuite SDF telles que le XML de rôle personnalisé, les autorisations de déploiement de script, les valeurs de clé permanente, les choix de niveau d'autorisation, la conception de rôle d'exécution et l'accès avec le moindre privilège. Confirme les ID d'autorisation ADMI_ / LIST_ / REGT_ / REPO_ / TRAN_ exacts, distingue les autorisations standard des ID de script customrecord_* et valide les autorisations par rapport aux données de référence NetSuite regroupées.
