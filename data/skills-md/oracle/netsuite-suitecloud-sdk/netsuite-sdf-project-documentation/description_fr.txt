Générez une documentation de niveau entreprise pour les projets NetSuite SDF. Analysez les scripts, les fichiers XML d'objets, les requêtes « manifest.xml » et SuiteQL pour produire README.md, des diagrammes d'architecture (Mermaid/ASCII), des guides de déploiement et des tableaux de dépannage. Peut s'intégrer aux workflows de documentation post-déploiement lorsque l'automatisation (par exemple, des hooks) est disponible.
