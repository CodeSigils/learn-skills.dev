Создавайте документацию корпоративного уровня для проектов NetSuite SDF. Анализируйте сценарии, объектные XML-файлы, manifest.xml и запросы SuiteQL для создания README.md, архитектурных диаграмм (Mermaid/ASCII), руководств по развертыванию и таблиц устранения неполадок. Может интегрироваться с рабочими процессами документации после развертывания, если доступна автоматизация (например, перехватчики).
