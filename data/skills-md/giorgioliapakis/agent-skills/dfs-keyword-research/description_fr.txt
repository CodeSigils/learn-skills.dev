Recherche de mots clés, analyse SERP et veille sur les concurrents via la CLI dfs (data-4-seo-cli).
Renvoie des réponses 10 à 20 fois plus petites que l'API DataForSEO brute, optimisée pour les fenêtres de contexte d'agent.
À utiliser lorsqu'on vous pose des questions sur les volumes de mots-clés, la difficulté de recherche, les idées de mots-clés, les fonctionnalités SERP, les concurrents.
classements, chevauchement de domaines, analyse de contenu, résumés de contenu ou analyse des écarts entre concurrents.
Nécessite : npm install -g data-4-seo-cli
