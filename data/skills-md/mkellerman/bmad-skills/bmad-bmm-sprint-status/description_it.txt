Utilizza questa competenza per leggere il file sprint-status.yaml e produrre un riepilogo chiaro e utilizzabile dello stato attuale dello sprint con rilevamento dei rischi e un'azione successiva consigliata per il flusso di lavoro. Richiamare quando l'utente dice "controlla lo stato dello sprint" o "mostra lo stato dello sprint", quando un'altra competenza necessita di dati dello sprint leggibili dalla macchina (modalità d'uso: data) o quando l'integrità di sprint-status.yaml deve essere convalidata (modalità d'uso: validate). La capacità analizza tutte le voci dello sprint, calcola i conteggi di storie ed epici in base allo stato, rileva i rischi (storie bloccate, revisioni bloccate, file mancanti), seleziona l'azione successiva consigliata e presenta un report formattato o un output di dati strutturati a seconda della modalità. L'output è un riepilogo dello sprint con raccomandazioni per il passaggio successivo, dati strutturati o un risultato di validità. A differenza di bmad-bmm-sprint-planning (che genera il file di stato da epics), questa abilità legge e riporta un file esistente. Non invocare se non esiste ancora sprint-status.yaml: esegui prima la pianificazione dello sprint.
