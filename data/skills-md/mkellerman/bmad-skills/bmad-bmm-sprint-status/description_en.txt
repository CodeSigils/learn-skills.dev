Use this skill to read the sprint-status.yaml file and produce a clear, actionable summary of the current sprint state with risk detection and a recommended next workflow action. Invoke when the user says "check sprint status" or "show sprint status", when another skill needs machine-readable sprint data (use mode: data), or when the sprint-status.yaml integrity needs to be validated (use mode: validate). The skill parses all sprint entries, computes story and epic counts by status, detects risks (blocked stories, stalled reviews, missing files), selects the top recommended next action, and presents a formatted report or structured data output depending on the mode. Output is a sprint summary with next-step recommendation, structured data, or a validity result. Unlike bmad-bmm-sprint-planning (which generates the status file from epics), this skill reads and reports on an existing file. Do not invoke if no sprint-status.yaml exists yet — run sprint planning first.
