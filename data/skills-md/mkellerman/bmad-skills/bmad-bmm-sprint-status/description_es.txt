Utilice esta habilidad para leer el archivo sprint-status.yaml y producir un resumen claro y procesable del estado actual del sprint con detección de riesgos y una siguiente acción de flujo de trabajo recomendada. Invocar cuando el usuario dice "verificar el estado del sprint" o "mostrar el estado del sprint", cuando otra habilidad necesita datos de sprint legibles por máquina (modo de uso: datos) o cuando es necesario validar la integridad de sprint-status.yaml (modo de uso: validar). La habilidad analiza todas las entradas de sprint, calcula recuentos de historias y épicas por estado, detecta riesgos (historias bloqueadas, revisiones estancadas, archivos faltantes), selecciona la siguiente acción más recomendada y presenta un informe formateado o una salida de datos estructurados según el modo. El resultado es un resumen del sprint con recomendaciones para el siguiente paso, datos estructurados o un resultado de validez. A diferencia de bmad-bmm-sprint-planning (que genera el archivo de estado a partir de epopeyas), esta habilidad lee e informa sobre un archivo existente. No lo invoque si aún no existe sprint-status.yaml; primero ejecute la planificación de sprint.
