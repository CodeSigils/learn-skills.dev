Utilisez cette compétence interne pour charger toutes les valeurs de configuration du projet BMAD (à la fois les paramètres de base et les remplacements spécifiques au module), les rendant ainsi disponibles pour la compétence appelante. Invoqué automatiquement au début de chaque compétence BMAD nécessitant une configuration ; jamais invoqué directement par l'utilisateur. La compétence dérive le module appelant du modèle de nom de compétence (bmad-[module]-...), lit la configuration de base à partir de _bmad/core/config.yaml (en revenant aux valeurs par défaut pour nom_utilisateur, langage_communication, langage_output_document et dossier_sortie s'ils sont absents), puis délègue à la compétence de configuration de module appropriée (par exemple, bmad-bmm-config) pour superposer les valeurs spécifiques au module. Ne produit aucune sortie destinée à l'utilisateur : toutes les valeurs sont transmises silencieusement en tant que contexte. La différence avec les compétences de configuration de module est que cette compétence gère les valeurs de base et agit comme couche de découverte et de routage ; les compétences de configuration du module gèrent les remplacements spécifiques au domaine. N'invoquez pas cette compétence à partir de requêtes adressées aux utilisateurs ; il s'agit d'un chargeur de configuration destiné à un usage interne uniquement.
