Utilice esta habilidad interna para cargar todos los valores de configuración del proyecto BMAD (tanto configuraciones principales como anulaciones específicas del módulo) para ponerlos a disposición de la habilidad que llama. Se invoca automáticamente al inicio de cada habilidad BMAD que necesita configuración; nunca invocado directamente por el usuario. La habilidad deriva el módulo de llamada del patrón de nombre de habilidad (bmad-[módulo]-...), lee la configuración principal de _bmad/core/config.yaml (recurriendo a los valores predeterminados para nombre_usuario, idioma_comunicación, idioma_salida_documento y carpeta_salida si está ausente), luego delega a la habilidad de configuración del módulo apropiada (por ejemplo, bmad-bmm-config) para superponer valores específicos del módulo. No produce resultados de cara al usuario: todos los valores se pasan silenciosamente como contexto. La diferencia con las habilidades de configuración del módulo es que esta habilidad maneja valores de nivel central y actúa como capa de descubrimiento y enrutamiento; Las habilidades de configuración del módulo manejan anulaciones específicas del dominio. No invoque esta habilidad desde solicitudes de usuarios; es un cargador de configuración solo para uso interno.
