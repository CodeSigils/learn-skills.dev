Используйте этот внутренний навык для загрузки всех значений конфигурации проекта BMAD — как основных настроек, так и переопределений для конкретного модуля — делая их доступными для вызывающего навыка. Вызывается автоматически в начале каждого навыка BMAD, требующего настройки; никогда не вызывается непосредственно пользователем. Навык извлекает вызывающий модуль из шаблона имени навыка (bmad-[module]-...), считывает основную конфигурацию из _bmad/core/config.yaml (возврат к значениям по умолчанию для user_name, communication_language, document_output_language и выходной_папки, если они отсутствуют), затем делегирует соответствующему навыку конфигурации модуля (например, bmad-bmm-config) для наложения значений, специфичных для модуля. Не производит никаких выводов, ориентированных на пользователя — все значения автоматически передаются в качестве контекста. Отличие от навыков настройки модуля заключается в том, что этот навык обрабатывает значения основного уровня и действует как уровень обнаружения и маршрутизации; Навыки настройки модуля позволяют выполнять переопределения, специфичные для домена. Не используйте этот навык из запросов пользователя; это загрузчик конфигурации только для внутреннего использования.
