استخدم هذه المهارة لمراجعة بنية المستند واقتراح إعادة تنظيم عالية المستوى قبل بدء أي تحرير للنسخة. يتم الاستدعاء عندما يقول المستخدم "مراجعة بنية هذا المستند" أو "المراجعة الهيكلية" أو عند استدعائها بواسطة مهارة أخرى لتحسين تنظيم المستند. تقوم هذه المهارة بتقييم بنية المستند على مستوى المستند بأكمله - وليس الجمل الفردية - وتصنيف النتائج إلى قطع، أو دمج، أو نقل، أو تكثيف، أو سؤال، أو عرض، كل منها مع الأساس المنطقي وتأثير الكلمات المقدر. يقبل المدخلات الاختيارية: style_guide، غرض، target_audience، Reader_type (بشر أو ماجستير)، و length_target. قم دائمًا بتشغيل هذه المهارة قبل bmad-core-editorial-review-prose - التغييرات الهيكلية التي يتم إجراؤها بعد تحرير النثر تهدر جهد تحرير النسخ. الأفضل للمستندات الطويلة والمواصفات الفنية ومستندات PRD ومستندات الهندسة المعمارية التي تبدو غير منظمة أو منتفخة.
