使用此技能，通过用户体验促进者和产品利益相关者之间的协作视觉探索和逐步促进来创建全面的用户体验设计规范。当用户说“创建 UX 设计”、“创建 UX 规范”或“帮助我规划 UX”时，或者当 PRD 存在且项目已准备好在架构决策最终确定之前定义视觉和交互模式时调用。该技能指导发现项目背景和用户体验挑战、核心体验和平台、情感反应和设计灵感、设计系统选择、视觉基础（颜色、排版、间距）、设计方向、用户旅程流程、组件策略、用户体验一致性模式和响应式可访问性。输出是保存到规划工件文件夹中的完整 UX 设计规范。支持恢复未完成的工作流程。与 bmad-bmm-create-architecture（处理技术决策）不同，此技能专门关注用户体验层。
