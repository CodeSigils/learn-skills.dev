Utilizza questa competenza per generare API automatizzate e test end-to-end per funzionalità già implementate utilizzando il framework di test esistente del progetto. Richiamare quando l'utente dice "crea test automatizzati QA per [funzionalità]", "genera test e2e" o quando il codice implementato necessita di una copertura di test verificata. La competenza rileva il framework di test esistente, identifica le funzionalità o i componenti da testare, genera file di test leggibili e gestibili concentrandosi su percorsi felici e casi di errore critici, quindi esegue i test e corregge eventuali guasti prima di produrre un documento di riepilogo della copertura. L'input è un nome di funzionalità, un percorso di componente o una directory. L'output sono file di test e un riepilogo della copertura. A differenza di bmad-bmm-code-review (che convalida i criteri di accettazione della storia), questa abilità riguarda esclusivamente la generazione di codice di test. Non utilizzare su funzionalità che non esistono ancora: implementa prima con bmad-bmm-dev-story o bmad-bmm-quick-dev, quindi genera i test. Per una strategia di test avanzata, utilizzare il modulo TEA.
