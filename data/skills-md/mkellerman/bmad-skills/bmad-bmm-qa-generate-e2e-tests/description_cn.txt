使用此技能可以使用项目的现有测试框架为已实现的功能生成自动化 API 和端到端测试。当用户说“为[功能]创建 QA 自动测试”、“生成 e2e 测试”时，或者当实现的代码需要验证测试覆盖率时调用。该技能检测现有的测试框架，识别要测试的功能或组件，生成可读且可维护的测试文件，重点关注顺利路径和关键错误案例，然后在生成覆盖率摘要文档之前执行测试并修复任何故障。输入是功能名称、组件路径或目录。输出是测试文件和覆盖率摘要。与 bmad-bmm-code-review（验证故事接受标准）不同，此技能纯粹是关于生成测试代码。不要使用尚不存在的功能 - 首先使用 bmad-bmm-dev-story 或 bmad-bmm-quick-dev 实现，然后生成测试。对于高级测试策略，请使用 TEA 模块。
