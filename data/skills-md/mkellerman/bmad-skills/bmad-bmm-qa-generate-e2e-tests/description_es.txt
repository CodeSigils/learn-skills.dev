Utilice esta habilidad para generar API automatizadas y pruebas de un extremo a otro para funciones ya implementadas utilizando el marco de prueba existente del proyecto. Invocar cuando el usuario dice "crear pruebas automatizadas de control de calidad para [función]", "generar pruebas e2e" o cuando el código implementado necesita una cobertura de prueba verificada. La habilidad detecta el marco de prueba existente, identifica las características o componentes a probar, genera archivos de prueba legibles y mantenibles centrándose en caminos felices y casos de errores críticos, luego ejecuta las pruebas y corrige cualquier falla antes de producir un documento de resumen de cobertura. La entrada es un nombre de característica, ruta de componente o directorio. El resultado son archivos de prueba y un resumen de cobertura. A diferencia de bmad-bmm-code-review (que valida los criterios de aceptación de la historia), esta habilidad se trata únicamente de generar código de prueba. No lo use en funciones que aún no existen: implemente primero con bmad-bmm-dev-story o bmad-bmm-quick-dev, luego genere pruebas. Para una estrategia de prueba avanzada, utilice el módulo TEA.
