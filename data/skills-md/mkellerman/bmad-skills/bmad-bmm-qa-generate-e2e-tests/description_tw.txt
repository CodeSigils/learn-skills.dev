使用此技能可以使用專案的現有測試框架為已實現的功能產生自動化 API 和端到端測試。當使用者說「為[功能]建立 QA 自動測試」、「產生 e2e 測試」時，或當實現的程式碼需要驗證測試覆蓋率時呼叫。此技能可偵測現有的測試框架，識別要測試的功能或元件，產生可讀且可維護的測試文件，重點在於順利路徑和關鍵錯誤案例，然後在產生覆蓋率摘要文件之前執行測試並修復任何故障。輸入是功能名稱、元件路徑或目錄。輸出是測試檔案和覆蓋率摘要。與 bmad-bmm-code-review（驗證故事接受標準）不同，此技能純粹是關於產生測試程式碼。不要使用尚不存在的功能 - 首先使用 bmad-bmm-dev-story 或 bmad-bmm-quick-dev 實現，然後產生測試。對於進階測試策略，請使用 TEA 模組。
