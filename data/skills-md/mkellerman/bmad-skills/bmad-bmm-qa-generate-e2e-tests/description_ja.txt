このスキルを使用して、プロジェクトの既存のテスト フレームワークを使用して、すでに実装されている機能の自動 API とエンドツーエンドのテストを生成します。ユーザーが「[機能] の QA 自動テストを作成する」、「e2e テストを生成する」と言った場合、または実装されたコードでテスト カバレッジを検証する必要がある場合に呼び出します。このスキルは、既存のテスト フレームワークを検出し、テストする機能またはコンポーネントを特定し、ハッピー パスと重大なエラー ケースに焦点を当てた読み取り可能で保守可能なテスト ファイルを生成します。その後、テストを実行して障害を修正してから、カバレッジ概要ドキュメントを作成します。入力は機能名、コンポーネントのパス、またはディレクトリです。出力はテスト ファイルとカバレッジの概要です。 bmad-bmm-code-review (ストーリーの受け入れ基準を検証する) とは異なり、このスキルは純粋にテスト コードの生成に関するものです。まだ存在しない機能には使用しないでください。最初に bmad-bmm-dev-story または bmad-bmm-quick-dev を実装してから、テストを生成します。高度なテスト戦略には、TEA モジュールを使用します。
