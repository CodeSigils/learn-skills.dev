使用此技能通过机械路径跟踪来详尽枚举差异、完整文件或函数中的每个未处理的代码路径和边界条件 - 而不是直观的审查。当用户说“寻找边缘情况”、“查找未处理的路径”时，或者当其他技能需要对代码更改进行纯路径分析时调用。该技能系统地遍历每个分支、循环和条件，仅收集缺乏显式处理的路径，然后默默地丢弃已处理的路径。输出是结果的 JSON 数组，没有额外的文本或 Markdown 包装。每个发现包含：位置（文件和行范围）、trigger_condition（单行描述）、guard_snippet（缩小差距的最小代码草图）和潜在结果（可能出错的地方）。接受可选的also_consider输入以将注意力集中在特定区域。处理所有路径时返回一个空数组。不是一般的代码审查 - 使用 bmad-core-review-adversarial-general 进行审查。
