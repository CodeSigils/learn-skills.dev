Utilizza questa capacità per enumerare in modo esaustivo ogni percorso di codice non gestito e condizione al contorno in un file diff, completo o funzione attraverso il tracciamento meccanico del percorso, non una revisione intuitiva. Richiamare quando l'utente dice "cerca casi limite", "trova percorsi non gestiti" o quando un'altra competenza necessita dell'analisi pura del percorso di una modifica del codice. L'abilità percorre sistematicamente ogni ramo, ciclo e condizionale, raccogliendo solo i percorsi privi di gestione esplicita, quindi scartando silenziosamente i percorsi gestiti. L'output è un array JSON di risultati senza testo aggiuntivo o ritorno a capo. Ogni risultato contiene: posizione (intervallo di file e righe), trigger_condition (descrizione di una riga), guard_snippet (schizzo di codice minimo che colma il divario) e potenziali_consequence (cosa potrebbe andare storto). Accetta anche input facoltativi_considera per focalizzare l'attenzione su aree specifiche. Restituisce un array vuoto quando vengono gestiti tutti i percorsi. Non una revisione generale del codice: usa bmad-core-review-adversarial-general per questo.
