Используйте этот навык для исчерпывающего перечисления каждого необработанного пути кода и граничных условий в файле различий, полном файле или функции посредством механической трассировки пути, а не интуитивного просмотра. Вызывайте, когда пользователь говорит «ищите крайние случаи», «находите необработанные пути» или когда другому навыку требуется чистый анализ пути изменения кода. Этот навык систематически обходит каждую ветвь, цикл и условие, собирая только пути, которые не имеют явной обработки, а затем автоматически отбрасывает обработанные пути. Выходные данные представляют собой массив результатов в формате JSON без дополнительного текста или переноса уценки. Каждый результат содержит: местоположение (файл и диапазон строк), триггер_условие (однострочное описание), Guard_snippet (минимальный набросок кода, который закрывает пробел) и потенциальное_последствие (что может пойти не так). Принимает необязательный ввод «alse_consider», чтобы сосредоточить внимание на определенных областях. Возвращает пустой массив, когда обработаны все пути. Это не общий обзор кода — для этого используйте bmad-core-review-adversarial-general.
