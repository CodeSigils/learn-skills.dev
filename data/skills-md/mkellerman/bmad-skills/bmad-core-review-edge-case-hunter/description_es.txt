Utilice esta habilidad para enumerar exhaustivamente cada ruta de código no controlada y condición de límite en una diferencia, un archivo completo o una función mediante el rastreo mecánico de rutas, no una revisión intuitiva. Invocar cuando el usuario dice "buscar casos extremos", "encontrar rutas no controladas" o cuando otra habilidad necesita un análisis de ruta puro de un cambio de código. La habilidad recorre cada rama, bucle y condicional de manera sistemática, recopilando solo rutas que carecen de manejo explícito y luego descarta silenciosamente las rutas manejadas. La salida es una matriz JSON de resultados sin texto adicional ni ajuste de rebajas. Cada hallazgo contiene: ubicación (archivo y rango de líneas), trigger_condition (descripción de una línea), guard_snippet (esbozo de código mínimo que cierra la brecha) y potencial_consequence (qué podría salir mal). Acepta entradas opcionales also_consider para centrar la atención en áreas específicas. Devuelve una matriz vacía cuando se manejan todas las rutas. No es una revisión de código general; use bmad-core-review-adversarial-general para eso.
