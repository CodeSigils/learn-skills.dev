Utilisez cette compétence pour énumérer de manière exhaustive tous les chemins de code et conditions limites non gérés dans un fichier différentiel, un fichier complet ou une fonction via le traçage mécanique du chemin – et non un examen intuitif. À invoquer lorsque l'utilisateur dit « rechercher les cas extrêmes », « trouver des chemins non gérés » ou lorsqu'une autre compétence a besoin d'une analyse pure du chemin d'un changement de code. La compétence parcourt systématiquement chaque branche, boucle et condition, en collectant uniquement les chemins qui manquent de gestion explicite, puis supprime silencieusement les chemins gérés. La sortie est un tableau JSON de résultats sans texte supplémentaire ni habillage de démarque. Chaque résultat contient : l'emplacement (fichier et plage de lignes), trigger_condition (description sur une ligne), guard_snippet (esquisse de code minimale qui comble l'écart) et potential_consequence (ce qui pourrait mal se passer). Accepte l'entrée facultative also_consider pour concentrer l'attention sur des domaines spécifiques. Renvoie un tableau vide lorsque tous les chemins sont gérés. Pas une révision générale du code – utilisez bmad-core-review-adversarial-general pour cela.
