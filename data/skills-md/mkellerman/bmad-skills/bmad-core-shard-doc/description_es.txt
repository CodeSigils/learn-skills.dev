Utilice esta habilidad para dividir un documento de rebajas grande en archivos de secciones más pequeños y organizados según los encabezados de nivel 2, utilizando npx @kayvan/markdown-tree-parser. Invoca cuando el usuario dice "fragmentar este documento", "dividir este documento" o cuando un archivo de rebajas de gran tamaño debe dividirse en partes navegables y utilizables de forma independiente. La habilidad analiza el documento fuente, crea un archivo por sección H2 con nombres de archivo limpios derivados del texto del encabezado y genera un punto de entrada index.md que vincula todas las secciones. Luego, el documento original se maneja según las preferencias del usuario: eliminarlo, archivarlo en una ubicación específica o conservarlo. Requiere la ruta del documento fuente como entrada; La carpeta de destino es opcional y por defecto es un subdirectorio que lleva el nombre del archivo de origen. Depende de que Node.js y npx estén disponibles. Lo mejor para PRD grandes, documentos de arquitectura, wikis o cualquier archivo de rebajas monolítico que se haya vuelto difícil de manejar.
