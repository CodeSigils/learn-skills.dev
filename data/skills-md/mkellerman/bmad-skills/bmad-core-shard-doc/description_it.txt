Utilizza questa capacità per dividere un documento markdown di grandi dimensioni in file di sezioni più piccoli e organizzati in base alle intestazioni di livello 2, utilizzando npx @kayvan/markdown-tree-parser. Richiamare quando l'utente dice "shard questo documento", "dividi questo documento" o quando un file di markdown di grandi dimensioni deve essere suddiviso in parti navigabili e utilizzabili in modo indipendente. La capacità analizza il documento di origine, crea un file per sezione H2 con nomi di file puliti derivati ​​dal testo dell'intestazione e genera un punto di ingresso index.md che collega tutte le sezioni. Il documento originale viene quindi gestito in base alle preferenze dell'utente: eliminare, archiviare in una posizione specifica o mantenere sul posto. Richiede il percorso del documento di origine come input; la cartella di destinazione è facoltativa e per impostazione predefinita è una sottodirectory denominata in base al file di origine. Dipende dalla disponibilità di Node.js e npx. Ideale per PRD di grandi dimensioni, documenti di architettura, wiki o qualsiasi file di markdown monolitico diventato ingombrante.
