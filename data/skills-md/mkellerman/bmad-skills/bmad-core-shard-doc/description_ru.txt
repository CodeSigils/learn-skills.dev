Используйте этот навык, чтобы разделить большой документ с уценкой на более мелкие, организованные файлы разделов на основе заголовков уровня 2, используя npx @kayvan/markdown-tree-parser. Вызывается, когда пользователь говорит «разделить этот документ», «разделить этот документ» или когда большой файл уценки необходимо разбить на части, по которым можно перемещаться и которые можно использовать независимо. Навык анализирует исходный документ, создает по одному файлу для каждого раздела H2 с чистыми именами файлов, полученными из текста заголовка, и генерирует точку входа index.md, связывающую все разделы. Затем исходный документ обрабатывается в соответствии с предпочтениями пользователя: удаляется, архивируется в указанное место или сохраняется на месте. В качестве входных данных требуется путь к исходному документу; Папка назначения является необязательной и по умолчанию представляет собой подкаталог, названный в честь исходного файла. Зависит от доступности Node.js и npx. Лучше всего подходит для больших PRD, документации по архитектуре, вики или любого монолитного файла уценки, который стал громоздким.
