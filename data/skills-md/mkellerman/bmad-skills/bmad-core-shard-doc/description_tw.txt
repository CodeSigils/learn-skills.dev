使用此技能，使用 npx @kayvan/markdown-tree-parser，根據 2 級標題將大型 Markdown 文件拆分為較小的、有組織的部分文件。當使用者說「分片此文件」、「分割此文件」時，或當需要將大型 Markdown 文件分解為可導航、獨立可用的部分時呼叫。此技能解析來源文檔，為每個 H2 部分建立一個文件，並使用從標題文字派生的乾淨文件名，並產生連結所有部分的 index.md 入口點。然後根據使用者首選項處理原始文件：刪除、存檔到指定位置或保留在原處。需要來源文件路徑作為輸入；目標資料夾是可選的，預設為以來源檔案命名的子目錄。取決於 Node.js 和 npx 是否可用。最適合大型 PRD、架構文件、wiki 或任何變得笨重的整體 Markdown 文件。
