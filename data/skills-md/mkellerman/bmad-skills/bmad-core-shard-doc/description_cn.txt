使用此技能，使用 npx @kayvan/markdown-tree-parser，根据 2 级标题将大型 Markdown 文档拆分为较小的、有组织的部分文件。当用户说“分片此文档”、“拆分此文档”时，或者当需要将大型 Markdown 文件分解为可导航、独立可用的部分时调用。该技能解析源文档，为每个 H2 部分创建一个文件，并使用从标题文本派生的干净文件名，并生成链接所有部分的 index.md 入口点。然后根据用户首选项处理原始文档：删除、存档到指定位置或保留在原处。需要源文档路径作为输入；目标文件夹是可选的，默认为以源文件命名的子目录。取决于 Node.js 和 npx 是否可用。最适合大型 PRD、架构文档、wiki 或任何变得笨重的整体 Markdown 文件。
