Используйте этот навык для создания или обновления файла index.md, который ссылается на все документы в целевом каталоге с краткими описаниями на основе содержимого. Вызывается, когда пользователь говорит «создать индекс файлов в этой папке», «обновить индекс» или когда каталогу документации требуется точка входа с возможностью навигации. Навык сканирует указанный каталог, читает каждый документ для извлечения осмысленных однострочных описаний и собирает их в алфавитный индекс с относительными путями и чистым форматированием уценки. Если index.md уже существует, он обновляется на месте, сохраняя любой пользовательский вводный контент при обновлении списка файлов. В качестве входных данных требуется путь к целевому каталогу. Лучше всего подходит для каталогов документации, папок артефактов, разделов вики и любого места, где людям или агентам ИИ необходим последовательный и точный обзор доступных файлов.
