Utilizza questa capacità per generare o aggiornare un file index.md che fa riferimento a tutti i documenti in una directory di destinazione con brevi descrizioni derivate dal contenuto. Richiamare quando l'utente dice "crea un indice di file in questa cartella", "aggiorna l'indice" o quando una directory di documentazione necessita di un punto di ingresso navigabile. L'abilità esegue la scansione della directory specificata, legge ogni documento per estrarre descrizioni significative di una riga e li assembla in un indice ordinato alfabeticamente con percorsi relativi e formattazione markdown pulita. Se un file index.md esiste già, viene aggiornato sul posto, preservando qualsiasi contenuto introduttivo personalizzato mentre si aggiorna l'elenco dei file. Richiede un percorso di directory di destinazione come input. Ideale per directory di documentazione, cartelle di artefatti, sezioni wiki e qualsiasi luogo in cui gli esseri umani o gli agenti di intelligenza artificiale necessitano di una panoramica coerente e accurata dei file disponibili.
