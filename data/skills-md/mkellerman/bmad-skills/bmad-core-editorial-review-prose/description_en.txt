Use this skill to review prose for communication issues that impede comprehension, targeting clarity, concision, and reader fit. Invoke when the user says "review this prose", "editorial review", or when another skill needs text polished before output. The skill adopts the role of a clinical copy-editor who treats content as sacrosanct — sentence structure, word choice, and flow are improved, but meaning is never altered. Output is a three-column markdown table listing original text, the issue, and a suggested fix. Accepts optional inputs: a style_guide file path (PDF, markdown, or URL) to apply project-specific rules, and reader_type (humans or llm) to calibrate formality and compression. For human readers it targets natural, engaging prose; for LLM readers it favors dense, unambiguous instruction. Run this AFTER bmad-core-editorial-review-structure to avoid prose-level fixes on text that may be cut or reorganized.
