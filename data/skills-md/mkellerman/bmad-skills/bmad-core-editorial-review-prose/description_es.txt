Utilice esta habilidad para revisar la prosa en busca de problemas de comunicación que impidan la comprensión, centrándose en la claridad, la concisión y la adaptación al lector. Invocar cuando el usuario dice "revisar esta prosa", "revisión editorial" o cuando otra habilidad necesita pulir el texto antes de publicarlo. La habilidad adopta el papel de un corrector clínico que trata el contenido como sacrosanto: se mejoran la estructura de la oración, la elección de las palabras y la fluidez, pero el significado nunca se altera. El resultado es una tabla de rebajas de tres columnas que enumera el texto original, el problema y una solución sugerida. Acepta entradas opcionales: una ruta de archivo de guía de estilo (PDF, rebajas o URL) para aplicar reglas específicas del proyecto y tipo de lector (humanos o llm) para calibrar la formalidad y la compresión. Para los lectores humanos, apunta a una prosa natural y atractiva; para los lectores de LLM, favorece una instrucción densa e inequívoca.
