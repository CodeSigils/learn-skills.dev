Utilice esta habilidad para crear un documento de decisión arquitectónica integral mediante la facilitación colaborativa paso a paso entre un par arquitectónico y el usuario. Invocar cuando el usuario dice "crear arquitectura", "crear arquitectura técnica" o "crear un diseño de solución", o cuando un proyecto tiene un diseño PRD o UX completo y necesita decisiones técnicas establecidas antes de escribir epopeyas e historias. La habilidad guía el descubrimiento de preferencias técnicas, opciones de plantillas iniciales, decisiones arquitectónicas centrales, patrones para la coherencia del agente de IA, estructura del proyecto y validación de la arquitectura. El resultado es un documento de decisión de arquitectura completo guardado en la carpeta de artefactos de planificación. Admite la reanudación de flujos de trabajo incompletos. A diferencia de Quick-Spec o Quick-Dev, este es un flujo de trabajo de fase de planificación completa, no una herramienta de implementación. No lo invoque para decisiones técnicas menores; utilícelo para cimientos arquitectónicos a nivel de proyecto.
