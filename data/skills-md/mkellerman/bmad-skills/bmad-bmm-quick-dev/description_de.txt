Nutzen Sie diese Fähigkeit, um kleine Funktionen oder Änderungen aus einer Quick-Tech-Spec-Datei oder direkten Benutzeranweisungen zu implementieren, mit autonomer Ausführung, gefolgt von Selbstprüfung und kontradiktorischer Prüfung. Wird aufgerufen, wenn der Benutzer sagt: „Implementieren Sie diese Kurzspezifikation“, „Fahren Sie mit der Implementierung von [Spezifikation] fort“ oder gibt direkte Implementierungsanweisungen ohne eine formelle Story. Der Skill bestimmt den Ausführungsmodus (Spezifikationsdatei vs. direkte Anweisung), sammelt bei Bedarf minimalen Kontext, führt alle Aufgaben aus, führt eine Selbstprüfung anhand von Akzeptanzkriterien und -mustern durch, ruft eine kontradiktorische Überprüfung auf und löst Ergebnisse interaktiv vor der Finalisierung. Eingabe ist ein technischer Dateipfad oder eine direkte Aufgabenbeschreibung. Die Ausgabe ist abgeschlossener, getesteter Code mit gelösten Überprüfungsergebnissen. Im Gegensatz zu bmad-bmm-quick-dev-new-preview (das auch die Planung/Spezifikationserstellung übernimmt) geht dieser Skill davon aus, dass eine Spezifikation bereits verfügbar ist oder die Anweisungen klar sind. Nicht für große mehrstöckige Features verwenden – verwenden Sie stattdessen den vollständigen BMAD-Story-Workflow.
