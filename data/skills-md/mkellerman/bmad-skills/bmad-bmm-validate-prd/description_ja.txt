このスキルを使用して、12 の品質側面にわたる BMAD 標準に対する PRD の包括的な自動検証を実行し、実用的な改善推奨事項を含む詳細な検証レポートを作成します。ユーザーが「この PRD を検証する」または「PRD 検証を実行する」と言ったとき、または PRD を作成または編集した後、アーキテクチャに移る前に品質ゲートが必要なときに呼び出します。このスキルは PRD 形式を検出し、情報密度、製品概要の範囲、要件の測定可能性、トレーサビリティ チェーン、実装漏れ、ドメイン コンプライアンス、プロジェクト タイプのセクション、各要件の SMART スコアリング、全体的な品質、完全性を自律的にチェックし、bmad-bmm-edit-prd を使用して問題を修正するオプションを含む対話型レポートを表示します。入力は PRD ファイル パスです。出力は、スコアと優先順位付けされた結果を含む検証レポートです。 bmad-bmm-check-implementation-readiness (計画スイート全体を検証する) とは異なり、このスキルは 1 つの PRD ドキュメントのみを検証します。空の PRD または存在しない PRD を呼び出さないでください。
