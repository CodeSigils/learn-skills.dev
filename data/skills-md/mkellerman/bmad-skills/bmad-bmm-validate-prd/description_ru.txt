Используйте этот навык для проведения комплексной автоматической проверки PRD на соответствие стандартам BMAD по 12 параметрам качества, создавая подробный отчет о проверке с практическими рекомендациями по улучшению. Вызывайте, когда пользователь говорит «проверить этот PRD» или «запустить проверку PRD», а также после создания или редактирования PRD и необходимости контроля качества перед переходом к архитектуре. Навык определяет формат PRD, затем автономно проверяет плотность информации, краткое описание продукта, измеримость требований, цепочки отслеживания, утечку реализации, соответствие предметной области, разделы типа проекта, оценку SMART каждого требования, целостное качество и полноту, а затем представляет интерактивный отчет с вариантами устранения проблем с помощью bmad-bmm-edit-prd. Входные данные — путь к файлу PRD. Результатом является отчет о проверке с оценками и приоритетными выводами. В отличие от bmad-bmm-check-implementation-readiness (который проверяет весь пакет планирования), этот навык проверяет только один документ PRD. Не вызывайте пустой или несуществующий PRD.
