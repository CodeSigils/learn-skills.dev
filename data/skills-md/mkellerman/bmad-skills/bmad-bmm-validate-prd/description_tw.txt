使用此技能可以根據 BMAD 標準在 12 個品質維度上對 PRD 進行全面的自動驗證，產生詳細的驗證報告以及可行的改進建議。當使用者說「驗證此 PRD」或「執行 PRD 驗證」時，或在建立或編輯 PRD 並在轉向架構之前需要品質閘控時呼叫。此技能可偵測 PRD 格式，然後自動檢查資訊密度、產品簡介覆蓋範圍、需求可衡量性、可追溯性鏈、實施洩漏、領域合規性、項目類型部分、每個需求的 SMART 評分、整體品質和完整性 - 然後提供互動式報告，其中包含使用 bmad-bmm-edit-prd 修復問題的選項。輸入是 PRD 檔案路徑。輸出是一份包含分數和優先發現結果的驗證報告。與 bmad-bmm-check-implementation-readiness（驗證整個規劃套件）不同，此技能僅驗證一個 PRD 文件。不要在空的或不存在的 PRD 上呼叫。
