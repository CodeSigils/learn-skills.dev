Utilizza questa competenza per generare un singolo file di storia pronto per l'implementazione, completo di tutto il contesto di cui un agente di sviluppo ha bisogno per implementarlo correttamente (posizioni dei file, modelli, dipendenze, versioni della libreria e criteri di accettazione), prevenendo gli errori di reinvenzione e regressione comuni agli sviluppatori LLM. Richiamare quando l'utente dice "crea la storia successiva", "crea storia 1-2" o simili, o quando esiste un piano di sprint e una storia deve passare dallo stato di arretrato allo stato di pronto per lo sviluppo. La competenza analizza in modo esaustivo tutti gli artefatti del progetto (epic, architettura, PRD, UX, storie precedenti, cronologia git) ed esegue ricerche sul web per le versioni della libreria prima di scrivere il file della storia. L'output è un file di storia strutturato nella cartella degli artefatti di implementazione con lo stato dello sprint aggiornato. A differenza di bmad-bmm-create-epics-and-stories (che crea l'intero arretrato), questa abilità crea una storia alla volta pronta per l'implementazione. Richiede l'esistenza di file epici.
