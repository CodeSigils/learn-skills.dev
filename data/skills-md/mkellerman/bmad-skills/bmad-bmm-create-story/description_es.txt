Utilice esta habilidad para generar un archivo de historia único, listo para la implementación, que contenga todo el contexto que un agente de desarrollo necesita para implementarlo correctamente (ubicaciones de archivos, patrones, dependencias, versiones de biblioteca y criterios de aceptación), evitando los errores de reinvención y regresión comunes entre los desarrolladores de LLM. Invocar cuando el usuario dice "crear la siguiente historia", "crear la historia 1-2", o similar, o cuando existe un plan de sprint y una historia necesita pasar del estado de trabajo pendiente al estado de lista para el desarrollo. La habilidad analiza exhaustivamente todos los artefactos del proyecto (épicas, arquitectura, PRD, UX, historias anteriores, historial de git) y realiza una investigación web para versiones de la biblioteca antes de escribir el archivo de la historia. La salida es un archivo de historia estructurado en la carpeta de artefactos de implementación con el estado del sprint actualizado. A diferencia de bmad-bmm-create-epics-and-stories (que crea el trabajo pendiente completo), esta habilidad crea una historia a la vez lista para su implementación. Requiere que existan archivos épicos.
