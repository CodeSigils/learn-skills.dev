Используйте этот навык для итеративного улучшения и углубления недавно созданного контента с помощью структурированных методов извлечения информации, взятых из библиотеки из 50 методов. Вызывайте, когда пользователь говорит «вызвать», «расширенное извлечение» или «запустить извлечение», или когда другому навыку необходимо повысить качество вывода, прежде чем продолжить. Входные данные — это контент или раздел, созданный последним за сеанс. Результат — это улучшенная версия, достигаемая посредством интерактивного применения многоперспективного анализа, творческого переосмысления, оценки рисков, проверки предположений или методов совместного рассуждения, выбранных из меню. Пользователь выбирает методы по одному, каждый из которых основан на предыдущих улучшениях, пока не будет удовлетворен и завершает работу с помощью «x». В отличие от мозгового штурма в режиме вечеринки, этот навык основан на уже существующих результатах, а не на генерации новых идей с нуля. Не вызывайте, если нет предварительного контента для уточнения.
