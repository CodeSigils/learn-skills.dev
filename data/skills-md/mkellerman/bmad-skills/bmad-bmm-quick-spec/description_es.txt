Utilice esta habilidad para crear rápidamente una especificación técnica completa y lista para implementar para una pequeña característica o cambio a través del descubrimiento conversacional y la investigación de la base de código. Invocar cuando el usuario dice "crear una especificación rápida", "generar una especificación técnica rápida" o cuando un pequeño cambio necesita una especificación independiente antes de que comience la implementación. La habilidad comprende el delta de requisitos (estado actual versus estado deseado), investiga la base del código para mapear restricciones técnicas y puntos de anclaje, genera un plan de implementación completo con criterios de aceptación Dado/Cuándo/Entonces y tareas ordenadas por dependencia, luego revisa y finaliza. El resultado es un archivo de especificaciones técnicas sin marcadores de posición, listo para que lo implemente un nuevo agente de desarrollo sin leer el historial del flujo de trabajo. A diferencia de bmad-bmm-quick-dev (que implementa), esta habilidad solo produce la especificación. A diferencia de bmad-bmm-create-story (que es para historias BMAD completas), este es un camino más liviano para pequeños cambios. No lo utilice para elementos de varios pisos.
