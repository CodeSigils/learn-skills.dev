Используйте этот навык, чтобы быстро создать полную, готовую к реализации техническую спецификацию для небольшой функции или изменения посредством диалогового обнаружения и исследования кодовой базы. Вызывайте, когда пользователь говорит «создать краткую спецификацию», «создать краткую техническую спецификацию» или когда для небольшого изменения требуется автономная спецификация до начала реализации. Навык понимает разницу требований (текущее состояние по сравнению с желаемым состоянием), исследует кодовую базу для сопоставления технических ограничений и опорных точек, генерирует полный план реализации с критериями приемки «Дано/Когда/То» и задачами, упорядоченными по зависимостям, затем проверяет и завершает работу. Выходные данные представляют собой файл технических характеристик без заполнителей, готовый к реализации новым агентом разработки без чтения истории рабочего процесса. В отличие от bmad-bmm-quick-dev (который реализует), этот навык создает только спецификацию. В отличие от bmad-bmm-create-story (который предназначен для полных историй BMAD), это более легкий путь для небольших изменений. Не используйте для многоэтажных объектов.
