Используйте этот навык для создания комплексного документа с требованиями к продукту с нуля посредством структурированного, пошагового содействия проектированию проекта. Вызывайте, когда пользователь говорит «создать документ с требованиями к продукту», «создать новый PRD» или когда идею продукта, краткое описание или исследовательские документы необходимо формализовать в виде спецификации требований. Навык действует как коллега по совместному проектированию, направляя определение классификации проектов, видения продукта, критериев успеха, пути пользователя, требований к предметной области, аспектов инноваций, границ объема, функциональных и нефункциональных требований и окончательной доработки. Выходные данные представляют собой полный PRD стандарта BMAD, сохраненный в папке артефактов планирования. Поддерживает возобновление незавершенных рабочих процессов. В отличие от bmad-bmm-edit-prd (который изменяет существующий PRD), этот навык создает новый PRD. Не вызывайте команду для обновления или исправления существующего документа — используйте для этой цели bmad-bmm-edit-prd.
