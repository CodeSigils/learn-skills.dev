Utilisez cette compétence interne pour résoudre les valeurs de configuration du module BMM et les superposer aux valeurs de configuration de base déjà chargées par bmad-core-config. Invoqué automatiquement par bmad-core-config lorsqu'il détecte que la compétence appelante appartient au module BMM. Lit _bmad/bmm/config.yaml lorsqu'il est présent, en revenant aux valeurs par défaut raisonnables (nom du projet à partir de la racine de l'espace de travail, niveau de compétence intermédiaire, chemins de sortie standard) lorsque le fichier est absent — il fonctionne donc sans installation complète de BMAD. Les valeurs résolues incluent project_name, user_skill_level, planning_artifacts, Implementation_artifacts et project_knowledge. Ne produit aucune sortie destinée à l’utilisateur. N'invoquez pas directement ; laissez bmad-core-config l'appeler dans le cadre de l'initialisation normale. La différence avec bmad-core-config est que cette compétence gère uniquement les remplacements spécifiques à BMM, et non les paramètres de base tels que le nom d'utilisateur ou la langue de communication.
