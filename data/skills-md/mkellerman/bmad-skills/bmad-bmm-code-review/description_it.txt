Utilizza questa abilità per eseguire una revisione approfondita del codice contraddittorio di una storia implementata, verificando che ogni criterio di accettazione e attività nel file della storia sia realmente soddisfatto dal codice effettivo, non solo dichiarato come fatto. Richiamare quando l'utente dice "esegui revisione del codice" o "rivedi questo codice" o quando una storia raggiunge lo stato di revisione nello sprint. La competenza legge il file della storia, scopre i file modificati da git, verifica ogni casella di controllo e criterio di accettazione dell'attività completata, identifica i problemi reali classificati in base alla gravità, si offre di risolvere i problemi critici e aggiorna la storia e lo stato dello sprint in base al risultato. L'input è un percorso del file della storia. L'output è costituito da risultati classificati e da uno stato aggiornato della storia. A differenza di bmad-core-review-adversarial-general, questa abilità è consapevole della storia e integrata nello sprint. Non utilizzare per la revisione di documenti, specifiche o codice a cui non è associato un file di storia.
