Verwenden Sie diese Fähigkeit, um eine gründliche kontradiktorische Codeüberprüfung einer implementierten Story durchzuführen und zu bestätigen, dass jedes Akzeptanzkriterium und jede Aufgabe in der Story-Datei tatsächlich vom tatsächlichen Code erfüllt wird – und nicht nur als erledigt behauptet wird. Wird aufgerufen, wenn der Benutzer „Codeüberprüfung ausführen“ oder „Diesen Code überprüfen“ sagt oder wenn eine Story im Sprint den Überprüfungsstatus erreicht. Der Skill liest die Story-Datei, erkennt von Git geänderte Dateien, hinterfragt jedes Kontrollkästchen und jedes Akzeptanzkriterium für abgeschlossene Aufgaben, identifiziert echte Probleme nach Schweregrad kategorisiert, bietet die Behebung kritischer Probleme an und aktualisiert die Story und den Sprint-Status basierend auf dem Ergebnis. Die Eingabe ist ein Story-Dateipfad. Die Ausgabe besteht aus kategorisierten Ergebnissen und einem aktualisierten Story-Status. Im Gegensatz zu bmad-core-review-adversarial-general ist diese Fähigkeit storybewusst und sprintintegriert. Nicht zum Überprüfen von Dokumenten, Spezifikationen oder Code verwenden, denen keine Story-Datei zugeordnet ist.
