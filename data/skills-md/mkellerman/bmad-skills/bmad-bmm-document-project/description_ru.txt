Используйте этот навык для создания подробной документации по контексту ИИ для существующего (действующего) проекта, чтобы агенты ИИ могли понимать его и эффективно работать в нем. Вызывается, когда пользователь говорит «задокументировать этот проект», «создать документацию проекта» или хочет создать документацию по архитектуре, анализ дерева исходного кода, контракты API, модели данных и руководства разработчиков для существующей базы кода. Этот навык сканирует структуру проекта, классифицирует технологический стек и шаблоны архитектуры, генерирует набор файлов документации и создает главный index.md — все это немедленно записывается на диск, чтобы избежать перегрузки контекста. Поддерживает полное сканирование, повторное сканирование и целенаправленное глубокое погружение в конкретные подсистемы. Входные данные — это корень проекта; выходные данные — это заполненный каталог project_knowledge. В отличие от bmad-bmm-generate-project-context (который фиксирует правила реализации ИИ), этот навык документирует то, что проект уже делает. Не используйте в новом проекте без существующего кода.
