Utilisez cette compétence pour générer une documentation complète sur le contexte de l'IA pour un projet existant (zone industrielle) afin que les agents d'IA puissent le comprendre et y travailler efficacement. À appeler lorsque l'utilisateur dit « documenter ce projet », « générer des documents de projet » ou souhaite créer des documents d'architecture, une analyse de l'arborescence des sources, des contrats d'API, des modèles de données et des guides de développement pour une base de code existante. La compétence analyse la structure du projet, classe la pile technologique et les modèles d'architecture, génère une suite de fichiers de documentation et crée un index.md principal, le tout écrit immédiatement sur le disque pour éviter une surcharge de contexte. Prend en charge les analyses complètes, les réanalyses et les analyses approfondies ciblées dans des sous-systèmes spécifiques. L'entrée est la racine du projet ; la sortie est un répertoire project_knowledge rempli. Contrairement à bmad-bmm-generate-project-context (qui capture les règles de mise en œuvre de l'IA), cette compétence documente ce que le projet fait déjà. Ne pas utiliser sur un nouveau projet sans code existant.
