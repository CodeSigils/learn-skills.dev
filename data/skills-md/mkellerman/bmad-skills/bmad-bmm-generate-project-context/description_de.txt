Nutzen Sie diese Fähigkeit, um gemeinsam eine project-context.md-Datei zu generieren, die die kritischen KI-Implementierungsregeln, Codierungsmuster und Richtlinien enthält, die Entwicklungsagenten befolgen müssen, um konsistenten, qualitativ hochwertigen Code für ein Projekt zu erstellen. Wird aufgerufen, wenn der Benutzer „Projektkontext generieren“ oder „Projektkontext erstellen“ sagt oder wenn ein Projekt vor Beginn der Entwicklung nicht offensichtliche technische Regeln erfassen muss. Der Skill erkennt den vorhandenen Tech-Stack und die vorhandenen Muster und führt den Benutzer dann durch die Definition von Regeln Kategorie für Kategorie (Benennungskonventionen, Architekturmuster, Anti-Muster, Tooling-Anforderungen usw.), während der Inhalt schlank und für die LLM-Kontextnutzung optimiert bleibt. Die Ausgabe ist eine project-context.md im Ausgabeordner. Im Gegensatz zu bmad-bmm-document-project (das beschreibende Dokumente zu den Aufgaben des Projekts generiert) erstellt dieser Skill präskriptive Regeln dafür, wie KI-Agenten Code implementieren sollten. Nicht zum Schreiben einer narrativen Dokumentation über vorhandenen Code verwenden.
