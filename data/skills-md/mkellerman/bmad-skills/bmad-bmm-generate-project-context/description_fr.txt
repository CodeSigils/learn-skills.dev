Utilisez cette compétence pour générer de manière collaborative un fichier project-context.md contenant les règles critiques de mise en œuvre de l'IA, les modèles de codage et les directives que les agents de développement doivent suivre pour produire un code cohérent et de haute qualité sur un projet. Invoquer lorsque l'utilisateur dit « générer un contexte de projet » ou « créer un contexte de projet », ou lorsqu'un projet doit capturer des règles techniques non évidentes avant le début du développement. La compétence découvre la pile technologique et les modèles existants, puis guide l'utilisateur dans la définition de règles catégorie par catégorie (conventions de dénomination, modèles d'architecture, anti-modèles, exigences en matière d'outils, etc.) tout en gardant un contenu simple et optimisé pour la consommation du contexte LLM. La sortie est un project-context.md dans le dossier de sortie. Contrairement à bmad-bmm-document-project (qui génère des documents descriptifs sur ce que fait le projet), cette compétence produit des règles prescriptives sur la manière dont les agents d'IA doivent implémenter le code. Ne pas utiliser pour rédiger une documentation narrative sur le code existant.
