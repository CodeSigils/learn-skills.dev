Используйте этот навык для совместной генерации файла project-context.md, содержащего важные правила реализации ИИ, шаблоны кодирования и рекомендации, которым должны следовать агенты разработки для создания согласованного высококачественного кода в проекте. Вызывайте, когда пользователь говорит «создать контекст проекта» или «создать контекст проекта», или когда проекту необходимо уловить неочевидные технические правила до начала разработки. Навык обнаруживает существующий технологический стек и шаблоны, а затем помогает пользователю определять правила по категориям (соглашения об именах, шаблоны архитектуры, антишаблоны, требования к инструментам и т. д.), сохраняя при этом контент компактным и оптимизированным для использования в контексте LLM. Выходные данные — это файл project-context.md в выходной папке. В отличие от bmad-bmm-document-project (который генерирует описательную документацию о том, что делает проект), этот навык создает предписывающие правила того, как агенты ИИ должны реализовывать код. Не используйте для написания описательной документации по существующему коду.
