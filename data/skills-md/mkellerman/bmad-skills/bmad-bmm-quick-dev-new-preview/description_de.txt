Nutzen Sie diese Fähigkeit, um jede Benutzerabsicht – eine Funktion, Fehlerbehebung, Umgestaltung oder Änderungsanforderung – durch einen disziplinierten Klärungs-, Planungs-, Implementierungs-, Überprüfungs- und Präsentationsablauf umzusetzen, der sauberen Code entsprechend der vorhandenen Architektur und den Mustern des Projekts erzeugt. Wird aufgerufen, wenn der Benutzer einen Code, eine Komponente oder ein Feature erstellen, reparieren, optimieren, umgestalten, hinzufügen oder ändern möchte, und stellt eine Beschreibung der Absicht, eine vorhandene Spezifikation oder einen Fehlerbericht bereit. Die Fertigkeit klärt die Absicht und legt den Umfang fest (bei Bedarf werden Anfragen mit mehreren Zielen aufgeteilt), sie untersucht die Codebasis, generiert eine Implementierungsspezifikation zur Genehmigung, führt sie autonom aus, wendet eine kontradiktorische Prüfung an und präsentiert Ergebnisse mit einem optionalen Commit. Die Ausgabe ist funktionierender Code mit einer ehrlichen Rezensionszusammenfassung. Im Gegensatz zu bmad-bmm-quick-dev (bei dem davon ausgegangen wird, dass bereits eine Spezifikation vorhanden ist) übernimmt dieser Skill den gesamten Zyklus vom Fuzzy-Intent bis zum ausgelieferten Code. Niemals automatisch auf die Fernbedienung übertragen. Am besten für einzelne benutzerorientierte Ziele innerhalb eines Spezifikationsbereichs von 900–1600 Token geeignet.
