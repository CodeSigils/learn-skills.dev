Utilisez cette compétence pour mettre en œuvre toute intention de l'utilisateur (une fonctionnalité, une correction de bogue, une refactorisation ou une demande de modification) grâce à un flux discipliné de clarification, de planification, de mise en œuvre, de révision et de présentation qui produit un code propre suivant l'architecture et les modèles existants du projet. Invoquer lorsque l'utilisateur souhaite créer, réparer, peaufiner, refactoriser, ajouter ou modifier un code, un composant ou une fonctionnalité, et fournit une description de l'intention, une spécification existante ou un rapport de bogue. La compétence clarifie et définit l'intention (divisant les demandes multi-objectifs si nécessaire), étudie la base de code, génère une spécification d'implémentation pour approbation, s'exécute de manière autonome, applique un examen contradictoire et présente les résultats avec une validation facultative. La sortie est un code fonctionnel avec un résumé de révision honnête. Contrairement à bmad-bmm-quick-dev (qui suppose qu'une spécification existe déjà), cette compétence gère le cycle complet depuis l'intention floue jusqu'au code expédié. Ne poussez jamais automatiquement vers la télécommande. Idéal pour les objectifs destinés à un seul utilisateur dans une portée de spécifications de 900 à 1 600 jetons.
