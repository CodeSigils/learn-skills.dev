Utilice esta habilidad para implementar cualquier intención del usuario (una característica, corrección de errores, refactorización o solicitud de cambio) a través de un flujo disciplinado de clarificación, planificación, implementación, revisión y presentación que produzca código limpio siguiendo la arquitectura y los patrones existentes del proyecto. Invocar cuando el usuario desea crear, arreglar, ajustar, refactorizar, agregar o modificar cualquier código, componente o característica y proporciona una descripción de la intención, una especificación existente o un informe de error. La habilidad aclara y define el alcance de la intención (dividiendo solicitudes de múltiples objetivos si es necesario), investiga el código base, genera una especificación de implementación para su aprobación, se ejecuta de forma autónoma, aplica una revisión contradictoria y presenta los hallazgos con una confirmación opcional. El resultado es un código de trabajo con un resumen de revisión honesto. A diferencia de bmad-bmm-quick-dev (que supone que ya existe una especificación), esta habilidad maneja el ciclo completo desde la intención difusa hasta el código enviado. Nunca presiona automáticamente al control remoto. Lo mejor para objetivos de usuario único dentro de un alcance de especificación de token de 900-1600.
