Utilizza questa abilità per generare o aggiornare il file di tracciamento sprint-status.yaml analizzando tutti i file epici e rilevando automaticamente lo stato corrente di ogni storia. Richiamare quando l'utente dice "esegui pianificazione sprint" o "genera piano sprint", o quando i file epici sono completi e l'implementazione sta per iniziare, o quando il file di stato dello sprint deve essere ricostruito dallo stato corrente del file system. La funzionalità rileva tutti i file epici, estrae ogni voce della storia, rileva gli stati della storia cercando i file della storia esistenti e i relativi stati, crea uno sprint-status.yaml strutturato e visualizza un riepilogo del completamento. L'output è un file sprint-status.yaml nella cartella degli artefatti di implementazione. A differenza di bmad-bmm-sprint-status (che legge e riporta un file di stato esistente), questa abilità crea o ricostruisce il file di tracciamento da documenti epici di origine. Eseguilo prima che venga sviluppata la prima storia o ogni volta che il file di stato dello sprint manca o non è sincronizzato con le epopee. Richiede almeno un file epico.
