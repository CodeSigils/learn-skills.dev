使用此技能通过结构化分析和批准的变更计划来改进、修复或重新格式化现有的 PRD。当用户说“编辑此 PRD”或“改进此 PRD”时，或者当生成验证报告并且 PRD 需要应用有针对性的修复时调用。该技能确定编辑目标，检测 PRD 的格式（BMAD 标准、变体或非标准遗留），深入审查文档以构建逐节更改计划，获得用户批准，然后按优先顺序应用更改。可以执行有针对性的编辑、结构修复或完全转换为 BMAD 格式。输出是一个改进的 PRD，带有编辑摘要和要验证的报价。与 bmad-bmm-create-prd（从头开始）和 bmad-bmm- Correct-course（处理多工件变更管理）不同，此技能仅在单个现有 PRD 上运行。需要 PRD 文件路径作为输入。
