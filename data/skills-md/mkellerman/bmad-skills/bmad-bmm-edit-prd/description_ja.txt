このスキルを使用して、構造化分析と承認された変更計画を通じて既存の PRD を改善、修正、または再フォーマットします。ユーザーが「この PRD を編集する」または「この PRD を改善する」と言った場合、または検証レポートが生成され、PRD に対象を絞った修正を適用する必要がある場合に呼び出します。このスキルは、編集目標を特定し、PRD の形式 (BMAD 標準、バリアント、または非標準レガシー) を検出し、ドキュメントを徹底的にレビューしてセクションごとの変更計画を作成し、ユーザーの承認を得て、優先順位に従って変更を適用します。対象を絞った編集、構造修正、または BMAD 形式への完全な変換を実行できます。出力は、編集の概要と検証のオファーを含む改良された PRD です。 bmad-bmm-create-prd (最初から開始) や bmad-bmm-correct-course (複数の成果物の変更管理を処理) とは異なり、このスキルは単一の既存の PRD でのみ動作します。入力として PRD ファイル パスが必要です。
