Utilice esta habilidad para mejorar, arreglar o reformatear un PRD existente mediante un análisis estructurado y un plan de cambio aprobado. Invocar cuando el usuario dice "editar este PRD" o "mejorar este PRD", o cuando se ha generado un informe de validación y el PRD necesita que se apliquen correcciones específicas. La habilidad identifica los objetivos de edición, detecta el formato del PRD (estándar BMAD, variante o legado no estándar), revisa el documento en profundidad para crear un plan de cambios sección por sección, obtiene la aprobación del usuario y luego aplica los cambios en orden de prioridad. Puede realizar ediciones específicas, correcciones estructurales o conversión completa al formato BMAD. El resultado es un PRD mejorado con un resumen de edición y una oferta para validar. A diferencia de bmad-bmm-create-prd (que comienza desde cero) y bmad-bmm-correct-course (que maneja la gestión de cambios de múltiples artefactos), esta habilidad opera solo en un único PRD existente. Requiere la ruta del archivo PRD como entrada.
