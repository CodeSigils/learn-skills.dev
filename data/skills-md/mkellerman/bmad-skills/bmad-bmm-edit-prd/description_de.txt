Nutzen Sie diese Fähigkeit, um ein bestehendes PRD durch eine strukturierte Analyse und einen genehmigten Änderungsplan zu verbessern, zu korrigieren oder neu zu formatieren. Wird aufgerufen, wenn der Benutzer „dieses PRD bearbeiten“ oder „dieses PRD verbessern“ sagt oder wenn ein Validierungsbericht erstellt wurde und das PRD gezielte Korrekturen erfordert. Der Skill identifiziert Bearbeitungsziele, erkennt das PRD-Format (BMAD-Standard, Variante oder nicht standardmäßiges Legacy), überprüft das Dokument gründlich, um einen abschnittsweisen Änderungsplan zu erstellen, holt die Benutzergenehmigung ein und wendet dann Änderungen in der Reihenfolge ihrer Priorität an. Kann gezielte Bearbeitungen, strukturelle Korrekturen oder eine vollständige Konvertierung in das BMAD-Format durchführen. Die Ausgabe ist ein verbessertes PRD mit einer Bearbeitungszusammenfassung und einem Angebot zur Validierung. Im Gegensatz zu bmad-bmm-create-prd (das bei Null beginnt) und bmad-bmm-correct-course (das das Änderungsmanagement für mehrere Artefakte übernimmt) funktioniert dieser Skill nur auf einem einzigen vorhandenen PRD. Erfordert den PRD-Dateipfad als Eingabe.
