Utilice esta habilidad para guiar a los usuarios al siguiente flujo de trabajo BMAD recomendado según el estado actual del proyecto, el módulo activo y los artefactos completados. Invocar cuando el usuario dice "¿qué debo hacer a continuación?", "ayúdame a navegar" o "ayuda bmad", o cuando otra habilidad necesita recomendar los siguientes pasos después de completar un flujo de trabajo. La habilidad carga un catálogo de ayuda CSV, detecta el módulo BMAD activo y resuelve las rutas de los artefactos de salida para inferir qué fases se han completado. Las recomendaciones se clasifican por fase y secuencia, y los flujos de trabajo requeridos bloquean el progreso hasta que se completan. Siempre hay disponibles herramientas universales sin asignación de fases. El formato de visualización varía según el tipo de flujo de trabajo: las habilidades basadas en comandos se muestran como invocaciones de habilidades, los flujos de trabajo basados ​​en agentes solicitan al usuario que cargue el agente primero. Todos los resultados se presentan en el idioma de comunicación configurado. Cada flujo de trabajo recomendado se ejecuta mejor en una ventana de contexto nueva; Los flujos de trabajo de validación se benefician de un LLM diferente de alta calidad cuando esté disponible.
