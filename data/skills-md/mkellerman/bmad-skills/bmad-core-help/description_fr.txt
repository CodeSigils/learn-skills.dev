Utilisez cette compétence pour guider les utilisateurs vers le prochain flux de travail BMAD recommandé en fonction de l'état actuel du projet, du module actif et des artefacts terminés. Invoquer lorsque l'utilisateur dit « que dois-je faire ensuite », « aidez-moi à naviguer » ou « bmad help », ou lorsqu'une autre compétence doit recommander les prochaines étapes après avoir terminé un flux de travail. La compétence charge un catalogue d'aide CSV, détecte le module BMAD actif et résout les chemins d'artefact de sortie pour déduire quelles phases ont été terminées. Les recommandations sont triées par phase et séquence, les flux de travail requis bloquant la progression jusqu'à ce qu'ils soient terminés. Des outils universels sans affectation de phase sont toujours disponibles. Le format d'affichage varie selon le type de flux de travail : les compétences basées sur des commandes sont affichées sous forme d'appels de compétences, les flux de travail basés sur un agent invitent l'utilisateur à charger d'abord l'agent. Toutes les sorties sont présentées dans la langue de communication configurée. Chaque flux de travail recommandé fonctionne mieux dans une nouvelle fenêtre contextuelle ; les workflows de validation bénéficient d’un LLM différent de haute qualité lorsqu’il est disponible.
