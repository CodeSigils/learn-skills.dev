Détecter les tests Playwright instables : exécute chaque spécification N fois, signale celles qui réussissent puis échouent puis réussissent, les classe par taux de défaillance, suggère les causes profondes (synchronisation, réseau, parallélisme, fuite d'état). À utiliser lorsque l'utilisateur dit "tests irréguliers", "échec intermittent", "CI irrégulier", "les tests réussis échouent localement dans CI".
