Tests de mutation pour PHP via Infection — mesure la qualité du TEST (pas la qualité du code). Mute chaque ligne de code (par exemple `<` → `<=`, `&&` → `||`) et exécute la suite de tests. Si les tests réussissent toujours, la mutation "a survécu" = le test a raté le bug. Taux de mortalité plus élevé = meilleurs tests. À utiliser lorsque l'utilisateur dit "tests de mutation", "Infection PHP", "qualité des tests", "mes tests sont-ils bons".
