Flujo de trabajo de investigación de depuración estandarizado y basado en hipótesis para comportamientos inesperados, regresiones, incidentes, pruebas inestables o problemas de producción. Úselo para planificar instrumentación, reproducir con señales decisivas, comparar ejecuciones y limitar la causa raíz sin asumir ningún proveedor o infraestructura.
