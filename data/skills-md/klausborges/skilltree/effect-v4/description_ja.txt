TypeScript の Effect v4 (4.0.0-beta.x) パターンとアーキテクチャ判定。エフェクト サービス、レイヤー、スキーマ、型付きエラー、境界、構成、CLI、ランタイム、またはテストを作成またはレビューするときに使用します。 Effect プロジェクトの構造を形成またはレビューするとき、サービスや境界を提案するとき、またはラッパーが不要であると主張するとき、またはプロジェクトが `effect@4` に依存しているとき。 Effect v4 は、v3 や単純な TypeScript とは大きく異なります。 API を呼び出すのではなく、プロジェクトの固定ソースと照合して API を検証します。
