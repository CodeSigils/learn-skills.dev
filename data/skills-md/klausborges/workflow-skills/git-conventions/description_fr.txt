Conventions git partagées pour les dépôts personnels couvrant la dénomination à distance, le choix à distance principal, la forme de validation conventionnelle, le placement de l'arbre de travail et le style d'écriture de validation/RP. À utiliser pour configurer ou renommer des télécommandes, choisir où pousser ou ouvrir des PR, décider où se trouve un arbre de travail ou quand une autre compétence Git pointe ici.
