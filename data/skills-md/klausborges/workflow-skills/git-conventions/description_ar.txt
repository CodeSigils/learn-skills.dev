اصطلاحات git المشتركة لعمليات إعادة الشراء الشخصية التي تغطي التسمية عن بعد، والاختيار الأساسي عن بعد، وشكل الالتزام التقليدي، ووضع شجرة العمل، وأسلوب كتابة الالتزام/العلاقات العامة. يُستخدم عند إعداد أجهزة التحكم عن بعد أو إعادة تسميتها، أو اختيار مكان دفع أو فتح العلاقات العامة، أو تحديد مكان وجود شجرة العمل، أو عندما تشير مهارة git أخرى هنا.
