Convenzioni git condivise per repository personali che coprono la denominazione remota, la scelta remota primaria, la forma di commit convenzionale, il posizionamento dell'albero di lavoro e lo stile di scrittura di commit/PR. Da utilizzare quando si configurano o si rinominano telecomandi, si sceglie dove inviare o aprire PR, si decide dove risiede un albero di lavoro o quando un'altra abilità git punta qui.
