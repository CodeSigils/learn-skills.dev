Convenciones de Git compartidas para repositorios personales que cubren nombres remotos, elección remota primaria, forma de confirmación convencional, ubicación del árbol de trabajo y estilo de escritura de confirmación/PR. Úselo al configurar o cambiar el nombre de los controles remotos, elegir dónde presionar o abrir PR, decidir dónde vive un árbol de trabajo o cuándo otra habilidad de Git apunta aquí.
