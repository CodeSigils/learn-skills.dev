Simplifiez une zone de code ou de documentation déjà délimitée sans modifier le comportement prévu. À utiliser pour la suppression, les refactors à flux direct, la réduction de wrapper ou de branche, des modèles de données plus clairs, un état mutable réduit ou des résultats de simplification concrets ; utilisez l'amélioration de l'architecture lorsque l'opportunité ou la conception n'est toujours pas claire.
