قم بتبسيط التعليمات البرمجية أو منطقة التوثيق المحددة بالفعل دون تغيير السلوك المقصود. الاستخدام للحذف، أو إعادة بناء التدفق المباشر، أو تقليل الغلاف أو الفرع، أو نماذج بيانات أكثر وضوحًا، أو تقليل الحالة القابلة للتغيير، أو نتائج التبسيط الملموسة؛ استخدم تحسين البنية عندما لا تزال الفرصة أو التصميم غير واضح.
