调查功能模块的任何前端视图（页面/路由/部分/选项卡/弹出/抽屉/仪表板卡/图表/过滤表单/列表/详细页面等），并编译每个模块显示哪些字段（标签、值字段、列表列、过滤条件、统计指标）以及相应的查询接口。当用户说出“调查/汇总某个页面（或模块）下的显示内容”、“有哪些字段和接口”、“字段映射是什么”、“这个字段来自哪个接口”、“这些代码是如何显示为名称的”、“过滤条件调用了哪些接口”、“这张仪表板卡的数据来自哪里”等时，触发这个——即使没有明确提及“汇总接口”，只要在梳理视图/模块的显示内容和数据源，使用此技能。适用于React、UMI、Vue等前端仓库的场景，按照“视图→模块→字段/列表/指标→接口”结构完成数据源映射。
