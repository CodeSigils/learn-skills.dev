Esaminare qualsiasi visualizzazione front-end (pagina/percorso/sezione/scheda/popup/cassetto/scheda dashboard/grafico/modulo filtro/elenco/pagina dei dettagli, ecc.) per moduli funzionali e compilare quali campi vengono visualizzati da ciascun modulo (etichetta, campi valore, colonne elenco, condizioni filtro, metriche statistiche) insieme alle interfacce di query corrispondenti. Quando un utente dice "investiga/riepilogo del contenuto visualizzato in una determinata pagina (o modulo)", "quali campi e interfacce sono presenti", "qual è la mappatura dei campi", "da quale interfaccia proviene questo campo", "come vengono visualizzati questi codici come nomi", "quali interfacce sono richiamate dalle condizioni del filtro", "da dove provengono i dati per questa dashboard card", ecc., attiva questo messaggio, anche se non menziona esplicitamente "interfacce di riepilogo", purché stia risolvendo un visualizzare il contenuto e l'origine dati della vista/modulo, utilizzare questa competenza. Si applica agli scenari nei repository front-end come React, UMI, Vue, in cui la mappatura dell'origine dati viene eseguita secondo la struttura "visualizzazione → modulo → campo/elenco/metrica → interfaccia".
