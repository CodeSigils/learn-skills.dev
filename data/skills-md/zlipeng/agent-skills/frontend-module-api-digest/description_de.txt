Durchsuchen Sie jede Front-End-Ansicht (Seite / Route / Abschnitt / Registerkarte / Modal / Schublade / Dashboard-Karte / Diagramm / Filterformular / Liste / Detailseite usw.) nach ihren Funktionsmodulen und fassen Sie zusammen, welche Felder jedes Modul anzeigt (Beschriftung, Wertfelder, Listenspalten, Filterkriterien, statistische Metriken) zusammen mit den entsprechenden Abfrage-APIs. Wenn ein Benutzer sagt: „Den angezeigten Inhalt einer bestimmten Seite (oder eines bestimmten Moduls) recherchieren/zusammenfassen“, „Welche Felder und APIs hat jede“, „Was ist die Feldzuordnung“, „Von welcher API stammt dieses Feld“, „Wie werden diese Codes als Namen angezeigt“, „Welche APIs werden für die Filterkriterien aufgerufen“, „Woher kommen die Daten für diese Dashboard-Karte“ usw., wird dieser Skill ausgelöst – auch wenn er „APIs zusammenfassen“ nicht ausdrücklich erwähnt, solange er den Anzeigeinhalt und die Daten klarstellt Quelle einer Ansicht/eines Moduls, verwenden Sie diese Fähigkeit. Es ist auf Szenarien in React-/UMI-/Vue-Frontend-Codebasen anwendbar, in denen Datenquellen gemäß der Struktur „Ansicht → Modul → Feld/Liste/Metrik → API“ organisiert sind.
