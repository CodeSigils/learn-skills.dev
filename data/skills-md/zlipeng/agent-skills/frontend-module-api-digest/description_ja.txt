フロントエンド ビュー (ページ / ルート / セクション / タブ / モーダル / ドロワー / ダッシュボード カード / チャート / フィルター フォーム / リスト / 詳細ページなど) の機能モジュールを調査し、各モジュールが表示するフィールド (ラベル、値フィールド、リスト列、フィルター条件、統計メトリック) と対応するクエリ インターフェイスを要約します。ユーザーが「特定のページ (またはモジュール) の下に表示されているコンテンツを調査/要約する」、「どのようなフィールドとインターフェースがあるか」、「フィールド マッピングは何であるか」、「このフィールドはどのインターフェースからのものか」、「これらのコードが名前としてどのように表示されるか」、「フィルター条件によってどのインターフェースが呼び出されるか」、「このダッシュボード カードのデータはどこから来るのか」などを言うと、たとえ「インターフェースの要約」と明示的に言及していなくても、このスキルはトリガーされます。ビュー/モジュールの表示コンテンツとデータ ソースを整理するときに、このスキルを使用します。これは、データ ソースが「ビュー → モジュール → フィールド/リスト/メトリック → インターフェイス」の構造に従って編成されている React / UMI / Vue フロントエンド リポジトリのシナリオに適用されます。
