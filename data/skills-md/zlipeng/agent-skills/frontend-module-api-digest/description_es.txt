Investigue cualquier vista frontal (página/ruta/sección/pestaña/ventana emergente/cajón/tarjeta de panel/gráfico/formulario de filtro/lista/página de detalles, etc.) para módulos funcionales y recopile qué campos muestra cada módulo (etiqueta, campos de valor, columnas de lista, condiciones de filtro, métricas estadísticas) junto con las interfaces de consulta correspondientes. Cuando un usuario dice "investigar/resumen del contenido mostrado en una determinada página (o módulo)", "qué campos e interfaces hay", "cuál es el mapeo de campos", "de qué interfaz proviene este campo", "cómo se muestran estos códigos como nombres", "qué interfaces son invocadas por las condiciones del filtro", "de dónde provienen los datos para esta tarjeta del tablero", etc., se desencadena esto, incluso si no menciona explícitamente "interfaces de resumen", siempre y cuando esté clasificando un Ver el contenido de visualización/módulo y la fuente de datos, utilice esta habilidad. Se aplica a escenarios en repositorios front-end como React, UMI, Vue, donde el mapeo de fuentes de datos se realiza de acuerdo con la estructura “ver → módulo → campo/lista/métrica → interfaz”.
