기능 모듈에 대한 프런트 엔드 보기(페이지/경로/섹션/탭/팝업/서랍/대시보드 카드/차트/필터 양식/목록/세부 정보 페이지 등)를 조사하고 해당 쿼리 인터페이스와 함께 각 모듈이 표시하는 필드(레이블, 값 필드, 목록 열, 필터 조건, 통계 지표)를 컴파일합니다. 사용자가 "특정 페이지(또는 모듈) 아래의 표시 콘텐츠 조사/요약", "어떤 필드와 인터페이스가 있습니까?", "필드 매핑이 무엇입니까", "이 필드가 어떤 인터페이스에서 왔는지", "이 코드가 어떻게 이름으로 표시됩니까?", "필터 조건에 의해 호출되는 인터페이스가 무엇입니까?", "이 대시보드 카드의 데이터가 어디에서 왔는지" 등을 말하면 이를 트리거합니다. "요약 인터페이스"를 명시적으로 언급하지 않는 한 뷰/모듈의 표시 내용과 데이터 소스를 정렬하는 경우 이 스킬을 사용하세요. 이는 "뷰 → 모듈 → 필드/목록/메트릭 → 인터페이스" 구조에 따라 데이터 소스 매핑이 수행되는 React, UMI, Vue와 같은 프런트 엔드 저장소의 시나리오에 적용됩니다.
