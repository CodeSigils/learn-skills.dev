Recherchez n'importe quelle vue frontale (page/itinéraire/section/onglet/popup/tiroir/carte de tableau de bord/graphique/formulaire de filtre/liste/page de détail, etc.) et ses modules fonctionnels, et compilez les champs affichés par chaque module (étiquette, champs de valeur, colonnes de liste, conditions de filtre, métriques statistiques) ainsi que les interfaces de requête correspondantes. Déclenchez cette compétence lorsque l'utilisateur dit "rechercher/résumer le contenu d'affichage d'une certaine page (ou module)", "quels champs et interfaces y a-t-il", "quel est le mappage des champs", "de quelle interface provient ce champ", "comment ces codes sont-ils affichés sous forme de noms", "quelles interfaces sont appelées par les conditions de filtre", "d'où viennent les données de cette carte de tableau de bord", etc. - même s'il ne mentionne pas explicitement "résumer les interfaces", tant qu'il trie le contenu d'affichage d'une vue/module et les sources de données, utilisez cette compétence. Cela s'applique aux scénarios dans les référentiels frontaux tels que React / UMI / Vue où le mappage des sources de données est effectué selon la structure « vue → module → champ/liste/métrique → interface ».
