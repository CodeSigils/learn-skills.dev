قم بحفظ وتحميل المعرفة الدائمة - حقائق المشروع أو سياق المحادثة أو متطلبات/تفضيلات المستخدم - في مخزن ذاكرة لكل مشروع ضمن `~/.agents/memories/`.
TRIGGER (حفظ) عندما: يستدعي المستخدم هذه المهارة للاستمرار في شيء ما؛ يقول "احفظ هذا في الذاكرة"، "تذكر هذا"، "记一下"، "保存记忆"، "记住这个"، "把这个存到记忆里"؛ ينص على تفضيل أو قرار أو قيد دائم يستحق الاستمرار فيه عبر الجلسات؛ أو يطلب تلخيص المشروع/السياق لوقت لاحق.
الزناد (التحميل) عندما: يستدعي المستخدم هذه المهارة للتذكير؛ يقول "تحميل ذاكرة المشروع"، "اقرأ ذكرياتي"، "ماذا تتذكر"، "读取该项目记忆"، "加载记忆"، "回忆一下这个项目"؛ أو يبدأ العمل في مشروع ويريد استعادة السياق السابق.
لا تقم بالتشغيل عندما: تكون الحقيقة مهمة فقط للدور الحالي، أو تكون مسجلة بالفعل في الريبو (الكود، الملف التمهيدي، سجل git)، أو عندما يقوم المستخدم فقط بطرح سؤال دون الرغبة في استمرار أي شيء أو استرجاعه.
