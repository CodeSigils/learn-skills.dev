Сохраняйте и загружайте надежные знания — факты о проекте, контекст разговора или требования/предпочтения пользователя — в хранилище памяти каждого проекта в `~/.agents/memories/`.
ТРИГГЕР (сохранение), когда: пользователь вызывает этот навык, чтобы сохранить что-то; говорит «сохрани это в памяти», «запомни это», «记一下», «保存记忆», «记住这个», «把这个存到记忆里»; заявляет о устойчивом предпочтении, решении или ограничении, которое стоит перенести на протяжении всех сессий; или просит подвести итог проекта/контекста на будущее.
ТРИГГЕР (загрузка), когда: пользователь вызывает этот навык для вызова; говорит: «загрузи память проекта», «прочитай мои воспоминания», «что ты помнишь», «读取该项目记忆», «加载记忆», «回忆一下这个项目»; или начинает работу над проектом и хочет восстановить предыдущий контекст.
НЕ ЗАПУСКАЙТЕ, когда: факт имеет значение только для текущего хода, уже записан в репозитории (код, README, история git) или пользователь просто задает вопрос, не желая, чтобы что-либо сохранялось или вызывалось.
