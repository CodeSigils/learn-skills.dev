프로젝트 사실, 대화 컨텍스트 또는 사용자 요구 사항/기본 설정과 같은 지속적인 지식을 `~/.agents/memories/` 아래의 프로젝트별 메모리 저장소에 저장하고 로드합니다.
TRIGGER(저장) 언제: 사용자가 무언가를 지속하기 위해 이 기술을 호출합니다. "이것을 메모리에 저장하세요", "기억하세요", "记一下", "保存记忆", "记住这个", "把这个存到记忆里"라고 말합니다. 세션 전반에 걸쳐 수행할 가치가 있는 지속적인 선호, 결정 또는 제약 조건을 명시합니다. 또는 나중에 프로젝트/컨텍스트를 요약하도록 요청합니다.
TRIGGER(로드) 언제: 사용자가 회상하기 위해 이 스킬을 호출합니다. "프로젝트 메모리 로드", "내 추억 읽기", "무엇을 기억하시나요?", "读取该项目记忆", "加载记忆", "回忆一下这个项目"라고 말합니다. 또는 프로젝트 작업을 시작하고 이전 컨텍스트를 복원하기를 원합니다.
DO NOT TRIGGER: 사실이 현재 턴에만 중요하거나 저장소(코드, README, git 기록)에 이미 기록되었거나 사용자가 지속되거나 호출되는 것을 원하지 않고 질문만 하는 경우.
