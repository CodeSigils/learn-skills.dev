Speichern und laden Sie dauerhaftes Wissen – Projektfakten, Konversationskontext oder Benutzeranforderungen/-präferenzen – in einem projektspezifischen Speicher unter „~/.agents/memories/“.
TRIGGER (speichern), wenn: der Benutzer diesen Skill aufruft, um etwas beizubehalten; sagt „speichern Sie dies“, „merken Sie sich das“, „记一下“, „保存记忆“, „记住这个“, „把这个存到记忆里“; gibt eine dauerhafte Präferenz, Entscheidung oder Einschränkung an, die es wert ist, sitzungsübergreifend getragen zu werden; oder bittet darum, das Projekt/den Kontext für später zusammenzufassen.
TRIGGER (Laden), wenn: der Benutzer diese Fertigkeit zum Abrufen aufruft; sagt „Projektspeicher laden“, „Meine Erinnerungen lesen“, „Woran erinnern Sie sich“, „读取该项目记忆“, „加载记忆“, „回忆一下这个项目“; oder beginnt mit der Arbeit an einem Projekt und möchte, dass der vorherige Kontext wiederhergestellt wird.
NICHT AUSLÖSEN, wenn: die Tatsache nur für die aktuelle Runde von Bedeutung ist, bereits im Repo aufgezeichnet ist (Code, README, Git-Verlauf) oder der Benutzer nur eine Frage stellt, ohne dass etwas beibehalten oder abgerufen werden soll.
