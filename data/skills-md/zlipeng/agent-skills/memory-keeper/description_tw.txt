在「~/.agents/memories/」下的每個項目記憶體儲存中保存和載入持久知識——項目事實、對話上下文或使用者需求/偏好。
觸發（保存）時間：使用者調用此技能來保存某些內容；說“把這個保存到記憶中”，“記住這個”，“記一下”，“保存記憶”，“記住這個”，“把這個存到記憶裡”；陳述值得跨會議進行的持久偏好、決定或約束；或者要求總結項目/背景以供稍後使用。
TRIGGER（加載）時：用戶調用該技能進行召回；說“加載項目記憶”，“讀取我的記憶”，“你記得什麼”，“讀取該項目記憶”，“加載記憶”，“回憶一下這個項目”；或者開始一個項目並希望恢復之前的上下文。
不要在以下情況下觸發：事實僅與當前回合有關，已經記錄在儲存庫中（程式碼、自述文件、git 歷史記錄），或使用者只是提出一個問題，而不希望保留或召回任何內容。
