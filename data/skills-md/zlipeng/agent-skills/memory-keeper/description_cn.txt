在“~/.agents/memories/”下的每个项目内存存储中保存和加载持久知识——项目事实、对话上下文或用户需求/偏好。
触发（保存）时间：用户调用此技能来保存某些内容；说“把这个保存到记忆中”，“记住这个”，“记一下”，“保存记忆”，“记住这个”，“把这个存到记忆里”；陈述值得跨会议进行的持久偏好、决定或约束；或者要求总结项目/背景以供稍后使用。
TRIGGER（加载）时：用户调用该技能进行召回；说“加载项目记忆”，“读取我的记忆”，“你记得什么”，“读取该项目记忆”，“加载记忆”，“回忆一下这个项目”；或者开始一个项目并希望恢复之前的上下文。
不要在以下情况下触发：事实仅与当前回合有关，已经记录在存储库中（代码、自述文件、git 历史记录），或者用户只是提出一个问题，而不希望保留或召回任何内容。
