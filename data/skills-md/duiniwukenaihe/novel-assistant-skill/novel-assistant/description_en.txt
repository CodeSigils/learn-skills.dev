The novel writing single-directory installation package. Users only need to install and invoke /novel-assistant, which will automatically route to internal capabilities such as long-form writing, short-form writing, ranking sweep, text splitting, removing AI flavor, cover creation, import, manuscript review, project deployment, etc. It is suitable for scenarios like Codex, Claude Code, OpenClaw/qclaw, etc., where only one skill directory is desired; long-form writing defaults to enabling a stability control closed loop; the top-level repository skills retain only novel-assistant.
