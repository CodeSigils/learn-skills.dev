Web novel writing single-directory installation package. Users only need to install and invoke /novel-assistant, which automatically routes to internal capabilities such as long-form writing, short-form writing, ranking sweep, text disassembly, AI-flavor removal, cover creation, import, manuscript review, project deployment, and more. Suitable for scenarios like Codex, Claude Code, OpenClaw/qclaw, etc., that want to install just one skill directory; long-form writing enables a stability control closed loop by default; the repository's top-level skills retain only novel-assistant.
