Создавайте речь, диалоги и звук с помощью ElevenLabs через RunAPI. Используйте, когда пользователь просит агента создать речь, диалог или звуковые эффекты или расшифровать аудио с помощью ElevenLabs. По умолчанию используется интерфейс командной строки RunAPI для однократной генерации; используйте SDK только тогда, когда пользователь интегрирует RunAPI в приложение или серверную часть.
