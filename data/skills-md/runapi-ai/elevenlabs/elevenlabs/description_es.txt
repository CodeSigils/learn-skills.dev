Genere voz, diálogo y sonido con ElevenLabs a través de RunAPI. Se utiliza cuando el usuario le pide a un agente que cree discursos, diálogos o efectos de sonido, o que transcriba audio con ElevenLabs. El valor predeterminado es la CLI RunAPI para una generación única; use SDK solo cuando el usuario esté integrando RunAPI en una aplicación o backend.
