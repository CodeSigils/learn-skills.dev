Créez et maintenez un wiki de projet de code local sous .wiki. Utilisez cette compétence chaque fois que l'utilisateur mentionne « wiki », « ingérer », « actualiser le wiki », « mettre à jour le wiki », « lint wiki », « vérifier le wiki », « documenter la base de code » ou pose une question à laquelle on peut répondre à partir des pages wiki. Utilisez-le également lorsque l'utilisateur demande comment quelque chose fonctionne dans le projet et qu'une page wiki pourrait capturer la réponse pour référence future.
