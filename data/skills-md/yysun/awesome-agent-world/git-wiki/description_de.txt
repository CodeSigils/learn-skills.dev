Erstellen und pflegen Sie ein lokales Code-Projekt-Wiki unter .wiki. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer „Wiki“, „Ingest“, „Wiki aktualisieren“, „Wiki aktualisieren“, „Lint-Wiki“, „Wiki überprüfen“, „Codebasis dokumentieren“ erwähnt oder eine Frage stellt, die auf Wiki-Seiten beantwortet werden kann. Verwenden Sie es auch, wenn der Benutzer fragt, wie etwas im Projekt funktioniert, und eine Wiki-Seite die Antwort zum späteren Nachschlagen festhalten könnte.
