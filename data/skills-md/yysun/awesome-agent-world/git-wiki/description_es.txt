Cree y mantenga un wiki de proyecto de código local en .wiki. Utilice esta habilidad siempre que el usuario mencione "wiki", "ingerir", "actualizar wiki", "actualizar wiki", "lint wiki", "verificar wiki", "documentar el código base" o haga una pregunta que pueda responderse desde páginas wiki. Úselo también cuando el usuario pregunte cómo funciona algo en el proyecto y una página wiki podría capturar la respuesta para referencia futura.
