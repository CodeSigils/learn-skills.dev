تخطيط وتنسيق وتنفيذ وتتبع ومراجعة والإبلاغ عن المشاريع الأصلية للمجلد. يُستخدم عندما يحتاج Codex إلى تهيئة مجلد مشروع أو إدارته، أو تحليل النتائج إلى مهام، أو تحديد العمل التالي، أو تتبع أدوات الحظر أو الأدلة، أو تنسيق المنفذين البشريين/الوكلاء/الخارجيين/RPD، وتنفيذ مهام RPD الجاهزة للتبعية مع الوكلاء الفرعيين وأشجار عمل Git من طلبات اللغة الطبيعية الإنجليزية أو الصينية، أو تقييم تأثير التغيير، أو إنشاء تقارير حالة المشغل أو مدير المشروع أو المدير التنفيذي أو مجلس الإدارة. حالة مشروع Markdown العامة هي الأساس؛ تعد Git، والكود المصدري، وأجهزة التتبع، وRPD عمليات تكامل اختيارية.
