Planifiez, coordonnez, exécutez, suivez, examinez et créez des rapports sur les projets natifs de dossiers. À utiliser lorsque Codex doit initialiser ou gérer un dossier de projet, décomposer les résultats en tâches, sélectionner le travail suivant, suivre les bloqueurs ou les preuves, coordonner les exécuteurs humains/agents/externes/RPD, exécuter des tâches RPD prêtes pour les dépendances avec des sous-agents et des arbres de travail Git à partir de requêtes en langage naturel anglais ou chinois, évaluer l'impact du changement ou créer des rapports d'état d'opérateur, de chef de projet, de direction ou de conseil d'administration. L’état générique du projet Markdown est au cœur ; Git, le code source, les trackers et RPD sont des intégrations facultatives.
