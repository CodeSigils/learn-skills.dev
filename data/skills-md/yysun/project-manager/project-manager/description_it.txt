Pianifica, coordina, esegui, monitora, rivedi e segnala progetti nativi di cartelle. Utilizzare quando Codex deve inizializzare o gestire una cartella di progetto, scomporre i risultati in attività, selezionare il lavoro successivo, tenere traccia di blocchi o prove, coordinare esecutori umani/agenti/esterni/RPD, eseguire attività RPD pronte per le dipendenze con subagenti e alberi di lavoro Git da richieste in linguaggio naturale inglese o cinese, valutare l'impatto del cambiamento o creare report sullo stato di operatori, project manager, dirigenti o consigli di amministrazione. Lo stato del progetto Markdown generico è il nucleo; Git, codice sorgente, tracker e RPD sono integrazioni opzionali.
