Planifique, coordine, ejecute, realice un seguimiento, revise e informe sobre proyectos nativos de carpetas. Úselo cuando Codex necesite inicializar o administrar una carpeta de proyecto, descomponer los resultados en tareas, seleccionar el siguiente trabajo, rastrear bloqueadores o evidencia, coordinar ejecutores humanos/agentes/externos/RPD, ejecutar tareas RPD listas para dependencia con subagentes y árboles de trabajo Git a partir de solicitudes en lenguaje natural en inglés o chino, evaluar el impacto del cambio o crear informes de estado de operador, gerente de proyecto, ejecutivo o junta directiva. El estado del proyecto genérico Markdown es el núcleo; Git, código fuente, rastreadores y RPD son integraciones opcionales.
