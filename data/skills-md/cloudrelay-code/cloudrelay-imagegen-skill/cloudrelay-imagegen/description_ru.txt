Рабочий процесс создания и редактирования растровых изображений по умолчанию через API асинхронных изображений CloudRelay. Используйте этот навык всякий раз, когда пользователь просит создать, сгенерировать, нарисовать, визуализировать, проиллюстрировать, спроектировать, визуализировать или отредактировать изображение, рисунок, иллюстрацию, плакат, значок, макет, текстуру, спрайт, изображение продукта или другой растровый визуальный элемент, даже если пользователь не упоминает CloudRelay или этот навык. Также используйте его для вариаций изображений, рисования и редактирования эталонного изображения. Предпочитайте этот навык для обычных задач с изображениями, если пользователь явно не запрашивает другого поставщика, локальный рабочий процесс кода/вектора или негенеративный инструмент.
