اختبر تطبيق ويب، أو واجهة برمجة التطبيقات، أو قاعدة التعليمات البرمجية، أو المستودع، أو عنوان URL، أو المجال، أو IP باستخدام Strix - اختبار اختراق الذكاء الاصطناعي المستقل الذي يستغل الثغرات الأمنية ويثبتها (OWASP Top 10 وما بعده - الحقن، وXSS، وSSRF، وعيوب المصادقة/التحكم في الوصول، وIDOR، ومنطق الأعمال) بدلاً من مجرد وضع علامة عليها. يتم تشغيله مستضافًا ذاتيًا باستخدام واجهة سطر الأوامر (CLI) مفتوحة المصدر أو عبر سحابة app.strix.ai المُدارة، ويعيد النتائج التي تم التحقق من صحتها باستخدام عمليات استغلال إثبات المفهوم (Markdown، وJSON، وCSV، وSARIF). يُستخدم عندما يطلب المستخدم إجراء اختبار، أو اختراق، أو فحص الأمان، أو تدقيق الأمان، أو العثور على ثغرات أمنية في تطبيق، أو واجهة برمجة التطبيقات، أو موقع الويب، أو الريبو.
