Strix 침투 테스트(오픈 소스 CLI 또는 app.strix.ai 클라우드)에서 발견된 보안 취약점을 수정합니다. 심각도별로 분류하고, 증상이 아닌 근본 원인을 패치하고, Strix를 다시 실행하여 각 수정 사항이 실제로 악용을 종료하는지 증명합니다. 삽입, XSS, SSRF, 손상된 액세스 제어, IDOR 및 기타 검증된 결과를 처리합니다. Strix 스캔에서 결과를 보고한 후 또는 사용자가 strix_runs 보고서, vulnerabilities.json, Finding.sarif 또는 클라우드 스캔에서 보안 문제를 교정, 패치 또는 수정하도록 요청할 때 사용합니다.
