Strix を使用した製品全体にわたるアプリケーション セキュリティ テスト (AppSec) — どの資産にどのテスト (ソース コード、実行中の Web アプリ、API、CI パイプライン) が必要かを決定し、実行して、結果をランク付けされた修復計画に変換します。自律エージェントは静的分析アラートを発行するのではなく、各問題を利用して証明するため、計画は実際に到達可能なものに基づいて順序付けされます。ユーザーがアプリケーションのセキュリティ レビューや監査、appsec 評価、スタック全体の脆弱性スキャン、発売前のセキュリティ レビューや顧客セキュリティ アンケートを要求する場合、またはどの種類のセキュリティ テストが必要かまだわからない場合に使用します。
