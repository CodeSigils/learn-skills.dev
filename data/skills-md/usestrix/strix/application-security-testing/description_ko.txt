Strix를 사용하여 전체 제품에 대한 애플리케이션 보안 테스트(AppSec) — 어떤 자산에 어떤 테스트(소스 코드, 웹 앱 실행, API, CI 파이프라인 실행)가 필요한지 결정하고 이를 실행한 후 결과를 순위가 높은 수정 계획으로 전환합니다. 자율 에이전트는 정적 분석 경고를 내보내는 대신 각 문제를 활용하고 증명하므로 실제로 도달할 수 있는 항목에 따라 계획이 정렬됩니다. 사용자가 애플리케이션 보안 검토 또는 감사, appsec 평가, 스택 전체의 취약성 검색, 출시 전 보안 검토 또는 고객 보안 설문지를 요청하거나 어떤 종류의 보안 테스트가 필요한지 아직 모르는 경우에 사용합니다.
