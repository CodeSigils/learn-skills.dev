Recherchez les vulnérabilités de sécurité dans une base de code ou un référentiel avec Strix – un examen de sécurité de l'IA en boîte blanche qui lit votre source, raisonne sur le flux de données réel et le modèle d'autorisation, puis exploite ce qu'il trouve dans un bac à sable en direct afin que chaque problème signalé ait une preuve de concept fonctionnelle au lieu d'une alerte d'analyse statique bruyante. Couvre l'injection, XSS, SSRF, le contrôle d'accès et IDOR brisés, la désérialisation non sécurisée, les secrets du code, les dépendances non sécurisées et les failles de logique métier. À utiliser lorsque l'utilisateur demande une analyse de sécurité, un examen de sécurité ou un audit de son code, de son dépôt ou de sa demande d'extraction pour les vulnérabilités.
