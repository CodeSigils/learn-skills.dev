Trova le vulnerabilità della sicurezza in una codebase o in un repository con Strix: una revisione della sicurezza basata sull'intelligenza artificiale white-box che legge la tua fonte, spiega il flusso di dati effettivo e il modello di autorizzazione, quindi sfrutta ciò che trova in una sandbox live in modo che ogni problema segnalato abbia una prova di concetto funzionante invece di un rumoroso avviso di analisi statica. Copre injection, XSS, SSRF, controllo degli accessi interrotti e IDOR, deserializzazione non sicura, segreti nel codice, dipendenze non sicure e difetti della logica aziendale. Da utilizzare quando l'utente richiede di eseguire la scansione di sicurezza, la revisione della sicurezza o il controllo del codice, del repository o della richiesta pull per le vulnerabilità.
