Strix を使用して、コードベースまたはリポジトリ内のセキュリティの脆弱性を見つけます。ホワイトボックス AI セキュリティ レビューでは、ソースを読み取り、実際のデータ フローと認可モデルに関する理由を調べ、ライブ サンドボックスで見つかったものを悪用します。そのため、報告されたすべての問題は、ノイズの多い静的分析アラートではなく、動作する概念実証となります。インジェクション、XSS、SSRF、壊れたアクセス制御と IDOR、安全でない逆シリアル化、コード内の秘密、安全でない依存関係、ビジネス ロジックの欠陥をカバーします。ユーザーが脆弱性のコード、リポジトリ、またはプル リクエストのセキュリティ スキャン、セキュリティ レビュー、または監査を要求する場合に使用します。
