Pruebe la seguridad de una API REST, GraphQL o gRPC con Strix: agentes autónomos que enumeran puntos finales desde un esquema OpenAPI/GraphQL (o mediante rastreo) y luego explotan las clases de vulnerabilidad específicas de la API en OWASP API Security Top 10 (2023): autorización rota a nivel de objeto (BOLA/IDOR), autorización rota a nivel de propiedad de objeto (exposición excesiva de datos y asignación masiva), autorización rota a nivel de función, consumo de recursos sin restricciones, SSRF, inyección, y fallas de autenticación/token. Cada hallazgo viene acompañado de una solicitud de prueba de concepto funcional. Úselo cuando el usuario solicite realizar una prueba de penetración, una prueba de seguridad, una auditoría o encontrar vulnerabilidades en una API, un punto final o un servicio de backend.
