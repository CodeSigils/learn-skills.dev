Протестируйте безопасность API REST, GraphQL или gRPC с помощью Strix — автономных агентов, которые пересчитывают конечные точки из схемы OpenAPI/GraphQL (или путем сканирования), а затем фактически используют классы уязвимостей, специфичные для API, из списка OWASP API Security Top 10 (2023 г.) — нарушение авторизации на уровне объекта (BOLA/IDOR), нарушение авторизации на уровне свойств объекта (чрезмерное раскрытие данных и массовое назначение), нарушение авторизации на уровне функций, неограниченное потребление ресурсов, Ошибки SSRF, внедрения и аутентификации/токена. Каждое открытие сопровождается рабочим запросом на подтверждение концепции. Используйте, когда пользователь просит провести пентест, проверку безопасности, аудит или найти уязвимости в API, конечной точке или внутренней службе.
