Führen Sie einen Sicherheitstest für eine REST-, GraphQL- oder gRPC-API mit Strix durch – autonome Agenten, die Endpunkte aus einem OpenAPI/GraphQL-Schema (oder durch Crawling) auflisten und dann tatsächlich die API-spezifischen Schwachstellenklassen in den OWASP API Security Top 10 (2023) ausnutzen – fehlerhafte Autorisierung auf Objektebene (BOLA/IDOR), fehlerhafte Autorisierung auf Objekteigenschaftsebene (übermäßige Datenfreilegung und Massenzuweisung), fehlerhafte Autorisierung auf Funktionsebene, uneingeschränkter Ressourcenverbrauch, SSRF-, Injektions- und Authentifizierungs-/Token-Fehler. Zu jedem Ergebnis gehört eine funktionierende Proof-of-Concept-Anfrage. Verwenden Sie diese Option, wenn der Benutzer einen Pentest, einen Sicherheitstest, eine Prüfung oder die Suche nach Schwachstellen in einer API, einem Endpunkt oder einem Back-End-Dienst durchführen möchte.
