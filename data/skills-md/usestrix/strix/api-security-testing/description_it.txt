Testare la sicurezza di un'API REST, GraphQL o gRPC con Strix — agenti autonomi che enumerano gli endpoint da uno schema OpenAPI/GraphQL (o mediante scansione), quindi sfruttano effettivamente le classi di vulnerabilità specifiche dell'API nella OWASP API Security Top 10 (2023) — autorizzazione a livello di oggetto interrotta (BOLA/IDOR), autorizzazione a livello di proprietà dell'oggetto interrotta (esposizione eccessiva di dati e assegnazione di massa), autorizzazione a livello di funzione interrotta, consumo illimitato di risorse, SSRF, injection, e difetti di autenticazione/token. Ogni risultato viene fornito con una richiesta di prova di concetto funzionante. Da utilizzare quando l'utente richiede di eseguire pentest, test di sicurezza, audit o individuare vulnerabilità in un'API, un endpoint o un servizio backend.
