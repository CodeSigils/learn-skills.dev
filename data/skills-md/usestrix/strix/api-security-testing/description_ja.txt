Strix を使用して REST、GraphQL、または gRPC API のセキュリティ テストを行います。これは、OpenAPI/GraphQL スキーマから (またはクロールによって) エンドポイントを列挙する自律エージェントであり、OWASP API セキュリティ トップ 10 (2023) の API 固有の脆弱性クラスを実際に悪用します。壊れたオブジェクト レベルの認可 (BOLA/IDOR)、壊れたオブジェクト プロパティ レベルの認可 (過度のデータ露出と一括割り当て)、壊れた関数レベル認可、無制限のリソース消費、SSRF、インジェクション、認証/トークンの欠陥。すべての発見には、実用的な概念実証のリクエストが伴います。ユーザーが API、エンドポイント、またはバックエンド サービスの侵入テスト、セキュリティ テスト、監査、または脆弱性の検索を要求する場合に使用します。
