اختبار الأمان لواجهة برمجة التطبيقات REST أو GraphQL أو gRPC باستخدام Strix - الوكلاء المستقلون الذين يقومون بتعداد نقاط النهاية من مخطط OpenAPI/GraphQL (أو عن طريق الزحف)، ثم استغلال فئات الثغرات الأمنية الخاصة بواجهة برمجة التطبيقات في OWASP API Security Top 10 (2023) - الترخيص المعطل على مستوى الكائن (BOLA/IDOR)، والتفويض على مستوى خاصية الكائن المعطل (التعرض المفرط للبيانات والتخصيص الجماعي)، والتفويض المعطل على مستوى الوظيفة، والاستهلاك غير المقيد للموارد، SSRF، والحقن، وعيوب المصادقة/الرمز المميز. تأتي كل نتيجة مع طلب إثبات صحة المفهوم. يُستخدم عندما يطلب المستخدم إجراء اختبار اختراق أو اختبار أمان أو تدقيق أو العثور على ثغرات أمنية في واجهة برمجة التطبيقات أو نقطة النهاية أو خدمة الواجهة الخلفية.
