Strix(GitHub Actions, GitLab CI 또는 기타 파이프라인)를 사용하여 CI/CD에 보안 스캐닝을 추가하면 모든 풀 요청은 취약한 코드가 병합되기 전에 차단하는 diff 범위의 AI 침투 테스트를 받게 되며 결과는 PR 댓글 및 SARIF로 코드 스캐닝에 업로드됩니다. 자체 호스팅 오픈 소스 CLI(러너에서 실행)와 관리형 app.strix.ai 플랫폼(GitHub/GitLab 앱 또는 API, 러너 인프라 없음)을 모두 다룹니다. 사용자가 CI 파이프라인, 사전 병합 게이트 또는 PR 워크플로에 보안 검사, SAST/DAST, 침투 테스트, 취약성 검사 또는 자동화된 보안 검토를 추가하도록 요청할 때 사용합니다.
