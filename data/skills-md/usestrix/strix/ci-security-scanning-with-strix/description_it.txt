Aggiungi la scansione di sicurezza a CI/CD con Strix (GitHub Actions, GitLab CI o qualsiasi pipeline) in modo che ogni richiesta pull riceva un pentest AI con ambito diff che blocca il codice vulnerabile prima che si unisca, con risultati come commenti PR e SARIF caricati nella scansione del codice. Copre sia la CLI open source self-hosted (viene eseguita nel runner) che la piattaforma app.strix.ai gestita (app o API GitHub/GitLab, nessuna informativa del runner). Da utilizzare quando l'utente richiede di aggiungere scansione di sicurezza, SAST/DAST, pentesting, controlli di vulnerabilità o revisione di sicurezza automatizzata alla pipeline CI, al gate pre-unione o al flusso di lavoro PR.
