أضف فحصًا أمنيًا إلى CI/CD باستخدام Strix — GitHub Actions، أو GitLab CI، أو أي مسار — بحيث يحصل كل طلب سحب على اختبار ذكاء اصطناعي مختلف النطاق يحظر التعليمات البرمجية الضعيفة قبل دمجها، مع تحميل النتائج كتعليقات PR وSARIF لمسح التعليمات البرمجية. يغطي كلاً من واجهة سطر الأوامر (CLI) مفتوحة المصدر المستضافة ذاتيًا (يتم تشغيلها في برنامج التشغيل الخاص بك) ومنصة app.strix.ai المُدارة (تطبيق GitHub/GitLab أو واجهة برمجة التطبيقات، بدون مشغل الأشعة تحت الحمراء). يُستخدم عندما يطلب المستخدم إضافة فحص الأمان، أو SAST/DAST، أو اختبار الاختراق، أو عمليات فحص الثغرات الأمنية، أو مراجعة الأمان التلقائية إلى خط أنابيب CI، أو بوابة الدمج المسبق، أو سير عمل العلاقات العامة.
