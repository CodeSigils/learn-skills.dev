Fügen Sie Sicherheitsscans zu CI/CD mit Strix hinzu – GitHub Actions, GitLab CI oder eine beliebige Pipeline – damit jede Pull-Anfrage einen Diff-Scope-KI-Pentest erhält, der anfälligen Code blockiert, bevor er zusammengeführt wird, mit Ergebnissen als PR-Kommentare und SARIF, die zum Code-Scanning hochgeladen werden. Deckt sowohl die selbstgehostete Open-Source-CLI (läuft in Ihrem Runner) als auch die verwaltete app.strix.ai-Plattform (GitHub/GitLab-App oder API, keine Runner-Infrastruktur) ab. Verwenden Sie diese Option, wenn der Benutzer Sicherheitsscans, SAST/DAST, Pentesting, Schwachstellenprüfungen oder automatisierte Sicherheitsüberprüfungen zu seiner CI-Pipeline, seinem Pre-Merge-Gate oder seinem PR-Workflow hinzufügen möchte.
