Добавьте сканирование безопасности в CI/CD с помощью Strix — GitHub Actions, GitLab CI или любого другого конвейера — чтобы каждый запрос на вытягивание проходил пентест ИИ с областью различий, который блокирует уязвимый код перед его слиянием, с результатами в виде PR-комментариев и SARIF, загружаемых на сканирование кода. Охватывает как самостоятельный интерфейс командной строки с открытым исходным кодом (запускается в вашем раннере), так и управляемую платформу app.strix.ai (приложение или API GitHub/GitLab, без инфра-раннера). Используйте, когда пользователь просит добавить сканирование безопасности, SAST/DAST, тестирование на проникновение, проверку уязвимостей или автоматическую проверку безопасности в свой конвейер CI, шлюз предварительного слияния или рабочий процесс PR.
