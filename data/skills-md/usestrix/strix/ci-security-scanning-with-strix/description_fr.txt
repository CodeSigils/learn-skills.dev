Ajoutez une analyse de sécurité à CI/CD avec Strix — GitHub Actions, GitLab CI ou tout autre pipeline — afin que chaque demande d'extraction reçoive un pentest d'IA à portée différente qui bloque le code vulnérable avant sa fusion, avec des résultats sous forme de commentaires PR et SARIF téléchargés vers l'analyse de code. Couvre à la fois la CLI open source auto-hébergée (s'exécute dans votre runner) et la plate-forme app.strix.ai gérée (application ou API GitHub/GitLab, pas d'infra du runner). À utiliser lorsque l'utilisateur demande à ajouter une analyse de sécurité, un SAST/DAST, un test d'intrusion, des contrôles de vulnérabilité ou un examen de sécurité automatisé à son pipeline CI, à sa porte de pré-fusion ou à son flux de travail de relations publiques.
