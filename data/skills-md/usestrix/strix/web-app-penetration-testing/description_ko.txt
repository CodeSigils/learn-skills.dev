웹 앱이나 웹사이트를 엔드 투 엔드로 침투 테스트합니다. 실제 취약점(인증 우회, 손상된 액세스 제어, IDOR, 주입, XSS, SSRF, 비즈니스 로직)을 찾아 활용하고 서명 일치 대신 작동하는 개념 증명으로 각각을 증명하는 라이브 URL, 스테이징 환경 또는 로컬 개발 서버의 블랙박스 테스트입니다. 자체 호스팅 오픈 소스 CLI 또는 관리형 app.strix.ai 클라우드인 Strix와 함께 실행됩니다. 사용자가 웹 앱, 웹 사이트, 웹 애플리케이션 또는 스테이징 사이트에 대한 침투 테스트, 해킹, 보안 테스트 또는 감사를 요청할 때 사용합니다.
