Pentestez une application Web ou un site Web de bout en bout : test en boîte noire d'une URL en direct, d'un environnement de test ou d'un serveur de développement local qui trouve et exploite des vulnérabilités réelles (contournement d'authentification, contrôle d'accès brisé, IDOR, injection, XSS, SSRF, logique métier) et prouve chacune d'entre elles avec une preuve de concept fonctionnelle au lieu d'une correspondance de signature. Fonctionne avec Strix, soit la CLI open source auto-hébergée, soit le cloud app.strix.ai géré. À utiliser lorsque l'utilisateur demande un test d'intrusion, un piratage, un test de sécurité ou un audit de son application Web, de son site Web, de son application Web ou de son site de test.
