Pentest di un'app Web o di un sito Web end-to-end: test in scatola nera di un URL live, un ambiente di staging o un server di sviluppo locale che trova e sfrutta vulnerabilità reali (bypass di autenticazione, controllo degli accessi interrotti, IDOR, iniezione, XSS, SSRF, logica di business) e dimostra che ognuno di essi ha una prova di concetto funzionante invece di una corrispondenza della firma. Funziona con Strix, la CLI open source self-hosted o il cloud gestito app.strix.ai. Da utilizzare quando l'utente richiede di eseguire pentest, hacking, test di sicurezza o audit della propria app Web, sito Web, applicazione Web o sito di staging.
