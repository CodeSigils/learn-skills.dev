Guíe a un agente de instalación a través de un flujo de trabajo de diapositivas o PPT por etapas sin limitar sus opciones de implementación. Úselo cuando el usuario desee una presentación, un mazo, un guión gráfico o una estructura lista para diapositivas de un tema, artículo, informe o resumen, y el éxito depende de alguna combinación de: aclarar el resumen, recopilar datos cuando sea necesario, crear un esquema, crear una planificación a nivel de página, generar artefactos intermedios revisables y degradarse elegantemente cuando el entorno carece de capacidades de investigación, renderizado o entrega.
