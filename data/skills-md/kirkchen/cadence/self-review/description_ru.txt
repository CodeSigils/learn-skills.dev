Используйте при выполнении самопроверки на этапе разработки в текущей ветке перед отправкой или открытием PR — запускает автоматический цикл проверки кодекса (межмодельная, OpenAI) + исправление каждого обнаружения + повторную проверку до тех пор, пока результаты не сойдутся или не прекратятся срабатывания условий. Кодекс следует многоролевой методологии pr-review (безопасность/штатный инженер/детектор/специалист-аудитор). Триггеры — «самопроверка», «самопроверка», «проверка версии», «проверка версии», «проверка перекрестной модели», «проверка перед отправкой», «проверка и исправление моей ветки». НЕ для живого PR-обзора с прикрепленными/встроенными комментариями (используйте pr-review), НЕ для управляемого PR-присмотра за детьми (используйте pr-babysit), НЕ для первого обзора без намерения исправить (используйте режим = согласие только на просмотр).
