PR をプッシュまたは開く前に、現在のブランチで開発段階のセルフレビューを行うときに使用します。結果が収束するか停止条件が発火するまで、コーデックス レビュー (クロスモデル、OpenAI) + 結果ごとの修正 + 再レビューの自動ループを実行します。 Codex は、pr-review の複数の役割の方法論 (セキュリティ / スタッフ エンジニア / SDET / 仕様監査人) に従っています。トリガー — 「自己レビュー」、「自己レビュー」、「自己レビュー」、「自我レビュー」、「クロスモデルレビュー」、「プリプッシュレビュー」、「ブランチのレビューと修正」。スティッキー/インライン コメントを含むライブ PR レビューには使用できません (pr-review を使用)、マネージド PR ベビーシッターには使用できません (pr-babysit を使用)、修正する意図のない初回レビューには使用できません (mode=review-only オプトインを使用)。
