À utiliser pour surveiller un PR/MR jusqu'à ce que CI soit vert et que tous les commentaires valides des évaluateurs soient pris en compte — prend en charge GitHub PR (gh) et GitLab MR (glab), trie les commentaires en Valid/Discuter/Hors de portée, traite les éléments valides avec de petits commits et des réponses de fil de discussion en ligne, escalade les résultats invisibles (tableaux de bord SonarQube/Snyk) et les blocages de robots à 3 tours, rapporte prêt à fusionner (jamais de fusion automatique). Déclencheurs — « 監看 PR », « babysit PR/MR », « PR 顧到 fusion », « adresse review feedback », « attendre que CI soit vert », « 把 PR 顧到綠 ». PAS pour écrire des descriptions de PR, PAS pour la révision du code différent (utilisez pr-review), PAS pour fusionner réellement le PR (l'utilisateur le fait).
