CI가 녹색이고 모든 유효한 리뷰어 피드백이 처리될 때까지 PR/MR을 보살피는 데 사용합니다. GitHub PR(gh) 및 GitLab MR(glab)을 지원하고, 댓글을 유효/토론/범위 외로 분류하고, 작은 커밋과 인라인 스레드 응답으로 유효한 항목을 처리하고, 보이지 않는 결과(SonarQube/Snyk 대시보드)와 3라운드 봇 교착 상태를 에스컬레이션하고, 병합 준비가 완료된 보고서를 보고합니다(자동 병합되지 않음). 트리거 — '監看 PR', 'PR/MR 베이비시팅', 'PR 顧到 병합', '주소 검토 피드백', 'CI 녹색까지 대기', '把 PR 顧到綠'. PR 설명 작성용이 아니고, diff 코드 검토용이 아니고(pr-review 사용), 실제로 PR 병합용이 아닙니다(사용자가 수행함).
