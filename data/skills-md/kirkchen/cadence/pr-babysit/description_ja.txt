CI が緑色になり、有効なレビューアーのフィードバックがすべて対処されるまで PR/MR を子守する場合に使用します。GitHub PR (gh) と GitLab MR (glab) をサポートし、コメントを有効/議論/範囲外に分類し、小さなコミットとインライン スレッド返信で有効なアイテムに対処し、目に見えない調査結果 (SonarQube/Snyk ダッシュボード) と 3 ラウンドのボット デッドロックをエスカレートし、マージ準備ができているレポート (決して自動マージ)。トリガー — 「監察 PR」、「ベビーシット PR/MR」、「PR 顧到マージ」、「アドレス レビュー フィードバック」、「CI グリーンになるまで待機」、「PR 顧到綠」。 PR の説明を書くためではなく、差分コード レビューのためではなく (pr-review を使用)、実際に PR をマージするためではありません (ユーザーがそれを行います)。
