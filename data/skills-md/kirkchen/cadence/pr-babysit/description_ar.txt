يُستخدم عند رعاية PR/MR حتى يتحول CI إلى اللون الأخضر ويتم التعامل مع كل تعليقات المراجعين الصالحة - يدعم GitHub PR (gh) وGitLab MR (glab)، ويصنف التعليقات إلى صالح/مناقشة/خارج النطاق، ويعالج العناصر الصالحة بالتزامات صغيرة وردود سلسلة مضمنة، ويصعد النتائج غير المرئية (لوحات معلومات SonarQube/Snyk) وحالات توقف تام لروبوتات ثلاثية، وإعداد تقارير جاهزة للدمج (لا يتم الدمج التلقائي أبدًا). المشغلات — '監看 PR'، 'babysit PR/MR'، 'PR 顧到 merge'، 'عنوان مراجعة التعليقات'، 'انتظر حتى يصبح CI أخضر'، '把 PR 顧到綠'. ليس لكتابة أوصاف العلاقات العامة، وليس لمراجعة كود الفرق (استخدم مراجعة العلاقات العامة)، وليس لدمج العلاقات العامة فعليًا (يقوم المستخدم بذلك).
