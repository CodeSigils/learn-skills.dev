Используйте при присмотре за PR/MR до тех пор, пока CI не станет зеленым и не будут рассмотрены все действительные отзывы рецензентов — поддерживает GitHub PR (gh) и GitLab MR (glab), сортирует комментарии по действительным / обсуждаемым / вне области видимости, обрабатывает действительные элементы с небольшими коммитами и встроенными ответами в цепочках, эскалирует невидимые выводы (панели мониторинга SonarQube / Snyk) и трехраундовые тупиковые ситуации ботов, сообщает о готовности к слиянию (никогда) автоматическое слияние). Триггеры — «監看 PR», «PR/MR присмотра за детьми», «PR 顧到 слияние», «обратная связь по проверке адреса», «подождать, пока CI зеленый», «把 PR 顧到綠». НЕ для написания описаний PR, НЕ для проверки кода различий (используйте pr-review), НЕ для фактического объединения PR (это делает пользователь).
