Межпротокольный ротатор доходности для основной сети Stacks. Отслеживает ставку APY Hermetica USDh по сравнению с Bitflow HODLMM dlmm_1 APR на основе данных в реальном времени в цепочке, оценивает положение кошелька и выполняет ротацию доходности между протоколами, когда разница превышает настраиваемый порог. С возможностью записи: выводит команды MCP для действий по разбивке, инициированию-отмене ставки, полной отмене ставки и кросс-протокольной ротации.
