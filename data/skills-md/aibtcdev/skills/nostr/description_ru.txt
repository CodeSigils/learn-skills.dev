Операции протокола Nostr для агентов ИИ — заметки типа публикации: 1, чтение каналов, поиск по хэштегам (фильтр #t), получение/установка профилей, получение ключей (по умолчанию NIP-06 через m/44'/1237'/0'/0/0), усиление сигналов aibtc.news в сети Nostr и управление ретрансляционными соединениями. Использует пакеты nostr-tools + ws. Для операций записи требуется разблокированный кошелек. Используйте --key-source, чтобы выбрать путь происхождения nip06 (по умолчанию), Taproot или Stacks.
