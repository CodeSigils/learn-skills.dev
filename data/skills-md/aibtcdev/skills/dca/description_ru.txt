Усреднение долларовой стоимости (DCA) для Stacks DeFi — автоматизируйте повторяющиеся покупки или продажи любой пары токенов Bitflow посредством прямых свопов. Агент выполняет каждый заказ по графику с обязательным подтверждением, защитой от проскальзывания, проверкой баланса, полной регистрацией транзакций и сводками статуса в формате Telegram. Пары HODLMM поддерживаются автоматически через преобразователь маршрутов SDK с дополнительным явным режимом только HODLMM.
