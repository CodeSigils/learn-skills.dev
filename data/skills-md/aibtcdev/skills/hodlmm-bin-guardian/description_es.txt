Supervisa los contenedores de Bitflow HODLMM para mantener las posiciones de LP en el rango de ganancias activas. Obtiene el estado del pool en vivo a través de la API de la aplicación HODLMM de Bitflow, verifica si la posición de una billetera está dentro del rango, calcula el deslizamiento a partir de los datos de precios nativos de Bitflow y genera una recomendación JSON. Solo lectura: las acciones de reequilibrio requieren aprobación humana explícita.
