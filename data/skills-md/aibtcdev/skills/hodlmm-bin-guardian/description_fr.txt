Surveille les bacs Bitflow HODLMM pour maintenir les positions LP dans la plage de gains active. Récupère l'état du pool en direct via l'API de l'application HODLMM de Bitflow, vérifie si la position d'un portefeuille est dans la plage, calcule le glissement à partir des données de prix natives de Bitflow et génère une recommandation JSON. En lecture seule : les actions de rééquilibrage nécessitent une approbation humaine explicite.
