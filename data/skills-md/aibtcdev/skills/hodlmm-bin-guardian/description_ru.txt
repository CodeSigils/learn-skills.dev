Отслеживает бункеры Bitflow HODLMM, чтобы поддерживать позиции LP в активном диапазоне прибыли. Получает текущее состояние пула через API-интерфейс приложения Bitflow HODLMM, проверяет, находится ли позиция кошелька в пределах диапазона, вычисляет проскальзывание на основе собственных ценовых данных Bitflow и выводит рекомендацию в формате JSON. Только для чтения — действия по перебалансировке требуют явного одобрения человека.
