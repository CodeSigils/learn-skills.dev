Добавьте визуальные возможности к текстовой модели рассуждения. Пользователи предоставляют изображения, снимки экрана, фотографии, диаграммы, снимки экрана пользовательского интерфейса, снимки кода, изображения математических задач, сканы, PDF-файлы или документы, а также запрашивают описание, понимание, рассуждение, чтение, распознавание текста, извлечение текста, анализ диаграмм или анализ контента. По умолчанию вызывается скрипты/vision-router.ps1 для автоматической маршрутизации: распознавание изображения сначала проходит через пул бесплатных соревнований GLM/Agnes, затем через custom‑1/custom‑2/custom‑3/local; анализ документов использует MinerU; Для чистого распознавания текста используется Baidu OCR или Windows OCR. Все выходные данные инструмента представляют собой стандартный JSON, который затем передаются в основную модель для вывода и обобщения.
