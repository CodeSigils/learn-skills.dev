순수 텍스트 추론 모델에 시각적 기능을 추가합니다. 사용자는 이미지, 스크린샷, 사진, 차트, UI 스크린샷, 코드 스크린샷, 수학 문제 이미지, 스캔, PDF 또는 문서를 제공하고 설명, 이해, 추론, 읽기, OCR, 텍스트 추출, 차트 구문 분석 또는 콘텐츠 분석을 요청합니다. 기본적으로 자동 라우팅을 위한 Invokescripts/vision-router.ps1: 이미지 이해는 먼저 무료 경쟁 풀 GLM/Agnes를 통과한 다음 custom‑1/custom‑2/custom‑3/local을 통과합니다. 문서 구문 분석은 MinerU를 사용합니다. 순수 텍스트 인식은 Baidu OCR 또는 Windows OCR을 사용합니다. 모든 도구 출력은 표준 JSON이며 추론 및 요약을 위해 기본 모델로 전달됩니다.
