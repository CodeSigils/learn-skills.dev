Add visual capabilities to a pure‑text reasoning model. Users provide images, screenshots, photos, charts, UI screenshots, code screenshots, math problem images, scans, PDFs, or documents, and request description, comprehension, reasoning, reading, OCR, text extraction, chart parsing, or content analysis. By default, invoke scripts/vision-router.ps1 for automatic routing: image understanding first goes through the free competition pool GLM/Agnes, then through custom‑1/custom‑2/custom‑3/local; document parsing uses MinerU; pure text recognition uses Baidu OCR or Windows OCR. All tool outputs are standard JSON, then handed to the main model for inference and summarization.
