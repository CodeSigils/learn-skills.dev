تكملة القدرات البصرية لنموذج المنطق النصي الخالص. يقدم المستخدمون الصور ولقطات الشاشة والصور والمخططات ولقطات واجهة المستخدم ولقطات شاشة التعليمات البرمجية وصور المشكلات الرياضية أو عمليات المسح الضوئي أو ملفات PDF أو المستندات، ويطلبون الوصف أو الفهم أو الاستدلال أو القراءة أو التعرف الضوئي على الحروف أو استخراج النص أو تحليل المخطط أو تحليل المحتوى. افتراضيًا، يتم استدعاء scripts/vision-router.ps1 للتوجيه التلقائي: يمر فهم الصورة أولاً عبر مجموعة المنافسة المجانية (GLM/Agnes)، ثم عبر custom‑1/custom‑2/custom‑3/local؛ تحليل المستندات يستخدم MinerU؛ يستخدم التعرف على النص الخالص Baidu OCR أو Windows OCR. جميع مخرجات الأداة هي JSON قياسية، والتي يتم تمريرها بعد ذلك إلى النموذج الرئيسي للاستدلال والتلخيص.
