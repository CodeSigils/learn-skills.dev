أضف الإمكانات المرئية إلى نموذج الاستدلال النصي الخالص. يقدم المستخدمون الصور، ولقطات الشاشة، والصور، والمخططات، ولقطات شاشة واجهة المستخدم، ولقطات شاشة التعليمات البرمجية، وصور المسائل الرياضية، وعمليات المسح الضوئي، وملفات PDF، أو المستندات، ويطلبون الوصف أو الفهم أو الاستدلال أو القراءة أو التعرف الضوئي على الحروف أو استخراج النص أو تحليل المخطط أو تحليل المحتوى. بشكل افتراضي، invocscripts/vision-router.ps1 للتوجيه التلقائي: فهم الصورة يمر أولاً عبر مجموعة المنافسة المجانية GLM/Agnes، ثم من خلال custom‑1/custom‑2/custom‑3/local؛ تحليل المستندات يستخدم MinerU؛ يستخدم التعرف على النص النقي Baidu OCR أو Windows OCR. جميع مخرجات الأداة هي JSON قياسية، ثم يتم تسليمها إلى النموذج الرئيسي للاستدلال والتلخيص.
