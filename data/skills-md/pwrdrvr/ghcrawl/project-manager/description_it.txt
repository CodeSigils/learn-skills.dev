Gestisci i problemi di GitHub e la bacheca del progetto GitHub per il repository corrente, mantenendo sincronizzato il tracker locale. Da utilizzare quando l'utente desidera acquisire requisiti in formato libero come problemi, arricchire le descrizioni dei problemi dal repository o dalla ricerca upstream, valutare priorità/dimensioni/flusso di lavoro/stato, aggiungere problemi o PR alla scheda di progetto configurata del repository o riconciliare lo stato GitHub con ".local/work-items.yaml".
