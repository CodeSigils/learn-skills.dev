Gérez les problèmes GitHub et le tableau du projet GitHub pour le référentiel actuel, tout en gardant le tracker local synchronisé. À utiliser lorsque l'utilisateur souhaite capturer des exigences de forme libre en tant que problèmes, étoffer les descriptions des problèmes à partir du dépôt ou de la recherche en amont, trier la priorité/taille/flux de travail/statut, ajouter des problèmes ou des PR au tableau de projet configuré du dépôt, ou réconcilier l'état de GitHub avec `.local/work-items.yaml`.
