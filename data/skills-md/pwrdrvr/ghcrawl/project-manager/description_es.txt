Administre los problemas de GitHub y el tablero del Proyecto GitHub para el repositorio actual, mientras mantiene sincronizado el rastreador local. Úselo cuando el usuario desee capturar requisitos de formato libre como problemas, desarrollar descripciones de problemas del repositorio o investigación anterior, clasificar Prioridad/Tamaño/Flujo de trabajo/Estado, agregar problemas o relaciones públicas al tablero de proyecto configurado del repositorio o conciliar el estado de GitHub con `.local/work-items.yaml`.
