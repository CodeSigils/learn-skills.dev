Pianifica e pubblica una versione GitHub in un repository basato su tag. Da utilizzare quando un utente chiede di tagliare, preparare o pubblicare una versione software, proporre il successivo tag vX.Y.Z, supportare tag pre-release come vX.Y.Z-beta.N, redigere note di rilascio migliori dai PR e commit diretti dall'ultima versione, aggiornare CHANGELOG.md, creare il tag aggiunto a un commit esatto e osservare il flusso di lavoro di pubblicazione.
