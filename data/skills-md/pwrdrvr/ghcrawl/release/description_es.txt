Planifique y publique una versión de GitHub en un repositorio controlado por etiquetas. Úselo cuando un usuario solicite cortar, preparar o publicar una versión de software, proponer la siguiente etiqueta vX.Y.Z, admitir etiquetas preliminares como vX.Y.Z-beta.N, redactar mejores notas de la versión de los PR y confirmaciones directas desde la última versión, actualizar CHANGELOG.md, crear la etiqueta fijada a una confirmación exacta y observar el flujo de trabajo de publicación.
