Lorsque l'utilisateur souhaite obtenir de l'aide pour rédiger les lignes d'ouverture, les crochets ou les premières phrases qui attirent l'attention. À utiliser également lorsque l'utilisateur mentionne « accroche », « ligne d'ouverture », « première ligne », « butée de défilement », « accrocheur », « titre », « comment commencer mon message » ou « personne ne lit au-delà de ma première ligne ». Peut être utilisé seul ou invoqué par d’autres compétences de création. Pour rédiger des articles complets, voir post-writer-sms. Pour les discussions, voir thread-writer-sms.
