Lorsque l'utilisateur souhaite trouver des modèles quant au contenu qui fonctionne et à ce qui ne fonctionne pas. À utiliser également lorsque l'utilisateur mentionne « ce qui fonctionne », « les modèles de contenu », « les meilleurs sujets », « le meilleur format », « le meilleur moment pour publier », « analyser mon contenu », « faire plus », « faire moins » ou « que dois-je changer ». Pour les métriques brutes, voir performance-analyzer-sms. Pour une analyse spécifique à l’audience, consultez audience-growth-tracker-sms.
