Cuando el usuario quiere analizar el rendimiento de sus publicaciones en las redes sociales. Úselo también cuando el usuario mencione "análisis", "rendimiento", "cómo les fue a mis publicaciones", "participación", "impresiones", "qué está funcionando", "métricas de publicaciones", "mis mejores publicaciones" o "por qué esta publicación no tiene rendimiento". Utiliza análisis de BlackTwist cuando están disponibles; de lo contrario, funciona a partir de datos proporcionados por el usuario. Para conocer específicamente el crecimiento de la audiencia, consulte audiencia-crecimiento-seguimiento-sms. Para la detección de patrones, consulte content-pattern-analyzer-sms. Para conocer los próximos pasos prácticos, consulte optimización-advisor-sms.
