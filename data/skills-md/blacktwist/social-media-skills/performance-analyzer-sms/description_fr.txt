Lorsque l'utilisateur souhaite analyser les performances de ses publications sur les réseaux sociaux. À utiliser également lorsque l'utilisateur mentionne « analyses », « performances », « comment ont fonctionné mes publications », « engagement », « impressions », « ce qui fonctionne », « métriques de publication », « mes meilleures publications » ou « pourquoi cette publication ne fonctionne-t-elle pas ». Utilise les analyses BlackTwist lorsqu'elles sont disponibles, sinon fonctionne à partir des données fournies par l'utilisateur. Pour plus spécifiquement la croissance de l'audience, voir audience-growth-tracker-sms. Pour la détection de modèles, voir content-pattern-analyzer-sms. Pour connaître les prochaines étapes concrètes, consultez optimisation-advisor-sms.
