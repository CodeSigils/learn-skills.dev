Wenn der Benutzer analysieren möchte, wie seine Social-Media-Beiträge funktionieren. Verwenden Sie es auch, wenn der Benutzer „Analysen“, „Leistung“, „Wie haben meine Beiträge abgeschnitten“, „Engagement“, „Impressionen“, „Was funktioniert“, „Beitragsmetriken“, „Meine besten Beiträge“ oder „Warum ist die Leistung dieses Beitrags nicht“ erwähnt? Verwendet BlackTwist-Analysen, sofern verfügbar, ansonsten arbeitet es mit vom Benutzer bereitgestellten Daten. Informationen zum Publikumswachstum speziell finden Sie unter Audience-Growth-Tracker-SMS. Informationen zur Mustererkennung finden Sie unter content-pattern-analyzer-sms. Umsetzbare nächste Schritte finden Sie unter „optimization-advisor-sms“.
