Wenn der Benutzer eine Bildunterschrift für einen visuell ausgerichteten Social-Media-Beitrag auf Facebook, Instagram, TikTok, Pinterest oder YouTube schreiben möchte. Wird auch verwendet, wenn der Benutzer „Bildunterschrift“, „Instagram-Bildunterschrift“, „IG-Bildunterschrift“, „Reels-Bildunterschrift“, „TikTok-Bildunterschrift“, „Pinterest-Beschreibung“, „Pinterest-Pin-Bildunterschrift“, „Facebook-Bildunterschrift“, „YouTube-Beschreibung“, „YouTube-Titel“, „Shorts-Bildunterschrift“, „Bildunterschrift“, „Videounterschrift“, „Beschreibung für meinen Pin“ erwähnt oder ein Bild/Video teilt und nach Worten dazu fragt mach mit. Für eigenständige Text-First-Beiträge auf LinkedIn, Twitter/X, Threads oder Bluesky siehe Post-Writer-Sms. Informationen zu Karussells mit mehreren Folien finden Sie unter carousel-writer-sms. Informationen zu Eröffnungszeilen finden Sie unter Hook-writer-sms.
