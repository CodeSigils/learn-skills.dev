Lorsque l'utilisateur souhaite écrire une légende pour une publication visuelle sur les réseaux sociaux sur Facebook, Instagram, TikTok, Pinterest ou YouTube. À utiliser également lorsque l'utilisateur mentionne «légende», «légende Instagram», «légende IG», «légende Reels», «légende TikTok», «description Pinterest», «légende pin Pinterest», «légende Facebook», «description YouTube», «titre YouTube», «légende des courts métrages», «légende photo», «légende vidéo», «description pour mon épingle', ou partage une image/vidéo et demande des mots pour l'accompagner. Pour les publications autonomes contenant d'abord du texte sur LinkedIn, Twitter/X, Threads ou Bluesky, consultez post-writer-sms. Pour les carrousels multi-diapositives, voir carrousel-writer-sms. Pour les lignes d'ouverture, voir hook-writer-sms.
