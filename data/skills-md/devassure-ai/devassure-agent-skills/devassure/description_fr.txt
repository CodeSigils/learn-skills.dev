À utiliser lorsque l'utilisateur souhaite installer, configurer ou exécuter des tests d'interface utilisateur de bout en bout avec DevAssure CLI (@devassure/cli). Déclencheurs pour : l'initialisation devassure, les tests d'exécution devassure, l'écriture de cas de test YAML, la configuration du jeton CI/CD, la structure du dossier .devassure/ ou toute mention de DevAssure.
