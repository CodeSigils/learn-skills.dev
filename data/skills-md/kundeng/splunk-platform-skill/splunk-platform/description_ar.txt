مهارة عميقة لتطوير Splunk، والإدارة، وهندسة التطبيقات/الوظائف الإضافية، ولوحات المعلومات، وتكاملات SDK/REST، وأدوات مواجهة الذكاء الاصطناعي. استخدم هذه المهارة دائمًا عندما تتضمن المهمة splunklib، أو Splunk REST API، أو البحث/الوظائف أو أنماط الوظائف/التصدير، أو Python SDK، أو JavaScript SDK، أو اكتشاف SPL/عمليات البحث الإدارية، أو كائنات المعرفة، أو تطوير الوظائف الإضافية لـ UCC، أو Dashboard Studio، أو Simple XML، أو تكامل Splunk MCP، أو التحقق من صحة AppInspect/الحزمة، أو أتمتة نشر النظام الأساسي. تشغيل: Splunk SDK، وsplunklib، وSPL، وSplunk REST API، والوظائف/التصدير، والوظيفة الإضافية، وUCC، والإدخال المعياري، وإجراء التنبيه، وDashboard Studio، وSimple XML، وappinspect، وعمليات البحث المحفوظة، وكائنات المعرفة، وMCP، وSplunk admin، وSplunk Cloud، وSplunk Enterprise، وأتمتة Splunk.
