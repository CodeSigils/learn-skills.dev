Convierta diseños de interfaz de usuario (capturas de pantalla, maquetas, estructuras alámbricas o descripciones) en paquetes de especificaciones JSONC estructurados y listos para la implementación, antes de escribir cualquier código. Esta habilidad es especialmente valiosa para plataformas especializadas donde saltar directamente al código causa un daño real: extensiones de Chrome (restricciones de CSP, restricciones de manifiesto v3), paneles de control de Splunk React (límites de SDK, requisitos de componentes de SplunkUI), aplicaciones de escritorio Tauri (puente Rust/JS, patrones de IPC), aplicaciones de Electron (aislamiento de procesos, scripts de precarga), extensiones de VS Code (restricciones de API de vista web), React Native (restricciones de módulos nativos) o cualquier plataforma con reglas no obvias que obtenga la generación de código genérico. mal. Utilice esta habilidad siempre que el usuario quiera analizar un diseño y producir una especificación, diga "preparar una transferencia", "crear una especificación a partir de este diseño", "convertir esta captura de pantalla en algo que se pueda construir" o proporcione un diseño para un sistema especializado. También se activa en solicitudes como "Necesito crear una extensión de Chrome que se vea así", "implementar este panel en Splunk" o "crear esta interfaz de usuario como una aplicación Tauri". Esta habilidad emite especificaciones JSONC estructuradas: NO genera código de implementación.
