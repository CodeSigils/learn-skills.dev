Convertissez les conceptions d'interface utilisateur (captures d'écran, maquettes, wireframes ou descriptions) en packages de spécifications JSONC structurés et prêts à être mis en œuvre, avant l'écriture du code. Cette compétence est particulièrement utile pour les plates-formes spécialisées où le passage direct au code provoque de réels dommages : extensions Chrome (restrictions CSP, contraintes manifestes v3), tableaux de bord Splunk React (limites du SDK, exigences des composants SplunkUI), applications de bureau Tauri (pont Rust/JS, modèles IPC), applications Electron (isolation des processus, scripts de préchargement), extensions VS Code (restrictions de l'API WebView), React Native (contraintes de module natif) ou toute plate-forme avec des règles non évidentes selon lesquelles la génération de code générique est erronée. Utilisez cette compétence chaque fois que l'utilisateur souhaite analyser une conception et produire une spécification, dit "préparer un transfert", "créer une spécification à partir de cette conception", "transformer cette capture d'écran en quelque chose de constructible" ou fournit une conception pour un système spécialisé. Se déclenche également sur des requêtes telles que « Je dois créer une extension Chrome qui ressemble à ceci », « implémenter ce tableau de bord dans Splunk » ou « créer cette interface utilisateur en tant qu'application Tauri ». Cette compétence émet des spécifications JSONC structurées — elle ne génère PAS de code d'implémentation.
