코드를 작성하기 전에 UI 디자인(스크린샷, 모형, 와이어프레임 또는 설명)을 구조화된 구현 준비 JSONC 사양 패키지로 변환하세요. 이 기술은 Chrome 확장 프로그램(CSP 제한, 매니페스트 v3 제약 조건), Splunk React 대시보드(SDK 경계, SplunkUI 구성 요소 요구 사항), Tauri 데스크톱 앱(Rust/JS 브리지, IPC 패턴), Electron 앱(프로세스 격리, 사전 로드 스크립트), VS Code 확장(webview API 제한), React Native(네이티브 모듈 제약 조건) 또는 일반 코드 생성에 적용되는 명확하지 않은 규칙이 있는 모든 플랫폼과 같이 코드로 바로 이동하면 실질적인 피해를 입힐 수 있는 전문 플랫폼에 특히 유용합니다. 틀렸어. 사용자가 디자인을 분석하고 사양을 생성하려고 할 때, "인계 준비", "이 디자인에서 사양 만들기", "이 스크린샷을 구축 가능한 것으로 전환"이라고 말하거나 특수 시스템에 대한 디자인을 제공할 때마다 이 기술을 사용하세요. 또한 "이런 모양의 Chrome 확장 프로그램을 빌드해야 합니다", "Splunk에서 이 대시보드 구현" 또는 "이 UI를 Tauri 앱으로 빌드"와 같은 요청에 대해서도 트리거됩니다. 이 기술은 구조화된 JSONC 사양을 내보내며 구현 코드를 생성하지 않습니다.
