Konvertieren Sie UI-Designs (Screenshots, Mockups, Wireframes oder Beschreibungen) in strukturierte, umsetzungsbereite JSONC-Spezifikationspakete – bevor Code geschrieben wird. Diese Fähigkeit ist besonders wertvoll für spezialisierte Plattformen, bei denen der direkte Sprung zum Code echten Schaden anrichtet: Chrome-Erweiterungen (CSP-Einschränkungen, Manifest-v3-Einschränkungen), Splunk-React-Dashboards (SDK-Grenzen, SplunkUI-Komponentenanforderungen), Tauri-Desktop-Apps (Rust/JS-Bridge, IPC-Muster), Electron-Apps (Prozessisolation, Preload-Skripte), VS-Code-Erweiterungen (Webview-API-Einschränkungen), React Native (native Moduleinschränkungen) oder jede Plattform mit nicht offensichtlichen Regeln, die bei der generischen Codegenerierung fehlschlagen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Design analysieren und eine Spezifikation erstellen möchte, sagt: „Übergabe vorbereiten“, „eine Spezifikation aus diesem Design erstellen“, „diesen Screenshot in etwas Baubares umwandeln“ oder einen Entwurf für ein spezielles System bereitstellen möchte. Wird auch bei Anfragen wie „Ich muss eine Chrome-Erweiterung erstellen, die so aussieht“, „Implementieren Sie dieses Dashboard in Splunk“ oder „Erstellen Sie diese Benutzeroberfläche als Tauri-App“ ausgelöst. Dieser Skill gibt strukturierte JSONC-Spezifikationen aus – er generiert KEINEN Implementierungscode.
