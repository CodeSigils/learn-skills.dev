Преобразуйте проекты пользовательского интерфейса (скриншоты, макеты, каркасы или описания) в структурированные, готовые к реализации пакеты спецификаций JSONC — еще до написания кода. Этот навык особенно ценен для специализированных платформ, где прямой переход к коду наносит реальный ущерб: расширения Chrome (ограничения CSP, ограничения манифеста v3), информационные панели Splunk React (границы SDK, требования к компонентам SplunkUI), настольные приложения Tauri (мост Rust/JS, шаблоны IPC), приложения Electron (изоляция процессов, сценарии предварительной загрузки), расширения VS Code (ограничения API веб-просмотра), React Native (ограничения собственных модулей) или любая платформа с неочевидными правилами, которые получает генерация общего кода. неправильно. Используйте этот навык всякий раз, когда пользователь хочет проанализировать проект и создать спецификацию, говорит «подготовить передачу», «создать спецификацию на основе этого проекта», «превратить этот снимок экрана во что-то, что можно построить» или предоставляет проект для специализированной системы. Также срабатывает по таким запросам, как «Мне нужно создать расширение Chrome, которое выглядит вот так», «реализовать эту панель мониторинга в Splunk» или «создать этот пользовательский интерфейс как приложение Tauri». Этот навык генерирует структурированные спецификации JSONC — он НЕ генерирует код реализации.
