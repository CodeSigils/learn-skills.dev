Converti i progetti dell'interfaccia utente (screenshot, mockup, wireframe o descrizioni) in pacchetti di specifiche JSONC strutturati e pronti per l'implementazione, prima che venga scritto qualsiasi codice. Questa competenza è particolarmente preziosa per le piattaforme specializzate in cui passare direttamente al codice provoca danni reali: estensioni Chrome (restrizioni CSP, vincoli manifest v3), dashboard Splunk React (limiti SDK, requisiti dei componenti SplunkUI), app desktop Tauri (ponte Rust/JS, modelli IPC), app Electron (isolamento dei processi, script di precaricamento), estensioni VS Code (restrizioni API Webview), React Native (vincoli dei moduli nativi) o qualsiasi piattaforma con regole non ovvie che la generazione di codice generico ottiene errate. Utilizza questa competenza ogni volta che l'utente desidera analizzare un progetto e produrre una specifica, dice "preparare un trasferimento", "crea una specifica da questo progetto", "trasforma questo screenshot in qualcosa di realizzabile" o fornisce un progetto per un sistema specializzato. Si attiva anche su richieste come "Devo creare un'estensione Chrome simile a questa", "implementa questa dashboard in Splunk" o "crea questa interfaccia utente come app Tauri". Questa abilità emette specifiche JSONC strutturate: NON genera codice di implementazione.
