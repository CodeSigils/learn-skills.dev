在編寫任何程式碼之前，將 UI 設計（螢幕截圖、模型、線框圖或描述）轉換為結構化、可實施的 JSONC 規格包。這項技能對於直接跳到程式碼會造成真正損害的專用平台特別有價值：Chrome 擴充功能（CSP 限制、清單 v3 約束）、Splunk React 儀表板（SDK 邊界、SplunkUI 元件要求）、Tauri 桌面應用程式（Rust/JS 橋接器、IPC 模式）、Electron 載入程式設定程式設定值、預測試程式）、隔離程式碼Native（本機模組約束）或任何具有通用程式碼產生錯誤的非明顯規則的平台。每當使用者想要分析設計並產生規格時，例如說「準備交接」、「根據此設計建立規格」、「將此螢幕截圖轉換為可建構的內容」或為專用系統提供設計，請使用此技能。還會觸發諸如「我需要建立一個如下所示的 Chrome 擴充功能」、「在 Splunk 中實作此儀表板」或「將此 UI 建置為 Tauri 應用程式」等請求。此技能發出結構化 JSONC 規範 - 它不會產生實作程式碼。
