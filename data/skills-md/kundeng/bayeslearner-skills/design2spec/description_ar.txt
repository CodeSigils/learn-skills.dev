قم بتحويل تصميمات واجهة المستخدم (لقطات الشاشة أو النماذج بالحجم الطبيعي أو الإطارات السلكية أو الأوصاف) إلى حزم مواصفات JSONC جاهزة للتنفيذ - قبل كتابة أي تعليمات برمجية. تعتبر هذه المهارة ذات قيمة خاصة للمنصات المتخصصة حيث يؤدي القفز مباشرة إلى التعليمات البرمجية إلى حدوث ضرر حقيقي: ملحقات Chrome (قيود CSP، وقيود البيان v3)، ولوحات معلومات Splunk React (حدود SDK، ومتطلبات مكونات SplunkUI)، وتطبيقات Tauri لسطح المكتب (جسر Rust/JS، وأنماط IPC)، وتطبيقات Electron (عزل العملية، ونصوص التحميل المسبق)، وامتدادات VS Code (قيود واجهة برمجة تطبيقات عرض الويب)، أو React Native (قيود الوحدة الأصلية)، أو أي منصة ذات قواعد غير واضحة تخطئ في إنشاء التعليمات البرمجية العامة. استخدم هذه المهارة عندما يريد المستخدم تحليل تصميم وإنتاج مواصفات، مثل "إعداد عملية تسليم"، أو "إنشاء مواصفات من هذا التصميم"، أو "تحويل لقطة الشاشة هذه إلى شيء قابل للبناء"، أو تقديم تصميم لنظام متخصص. يتم تشغيله أيضًا عند طلبات مثل "أحتاج إلى إنشاء ملحق Chrome يبدو بهذا الشكل"، أو "تنفيذ لوحة المعلومات هذه في Splunk"، أو "إنشاء واجهة المستخدم هذه كتطبيق Tauri". تُصدر هذه المهارة مواصفات JSONC منظمة، ولا تُنشئ كود التنفيذ.
