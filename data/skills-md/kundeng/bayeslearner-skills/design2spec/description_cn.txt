在编写任何代码之前，将 UI 设计（屏幕截图、模型、线框图或描述）转换为结构化、可实施的 JSONC 规范包。这项技能对于直接跳到代码会造成真正损害的专用平台特别有价值：Chrome 扩展（CSP 限制、清单 v3 约束）、Splunk React 仪表板（SDK 边界、SplunkUI 组件要求）、Tauri 桌面应用程序（Rust/JS 桥、IPC 模式）、Electron 应用程序（进程隔离、预加载脚本）、VS Code 扩展（webview API 限制）、React Native（本机模块约束）或任何具有通用代码生成错误的非明显规则的平台。每当用户想要分析设计并生成规范时，例如说“准备交接”、“根据此设计创建规范”、“将此屏幕截图转换为可构建的内容”或为专用系统提供设计，请使用此技能。还会触发诸如“我需要构建一个如下所示的 Chrome 扩展程序”、“在 Splunk 中实现此仪表板”或“将此 UI 构建为 Tauri 应用程序”等请求。该技能发出结构化 JSONC 规范 - 它不会生成实现代码。
