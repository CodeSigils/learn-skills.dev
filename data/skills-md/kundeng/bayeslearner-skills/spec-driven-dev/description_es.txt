Flujo de trabajo de desarrollo basado en especificaciones: requisitos → diseño → tareas → implementar bucle. Úselo al planificar funciones, implementar a partir de especificaciones, refinar especificaciones, reanudar el trabajo o cuando un proyecto existente ya tenga archivos de especificaciones que deban moverse a `.kiro/specs/` o `.windloop/specs/`. Utilícelo también para especificaciones analíticas y de flujo de trabajo de datos cuando el usuario desee requisitos/diseño/tareas para cuadernos, barridos de experimentos, DAG de Hamilton, puertas de revisión o promoción de análisis reproducibles. Se activa especialmente en solicitudes que mencionan especificaciones, requisitos/diseño/tareas, ayuda con especificaciones, plan de especificaciones, `.kiro`, `.windloop` o migración de especificaciones de flujo de trabajo analítico al diseño adecuado. IMPORTANTE: nunca edite requisitos.md, diseño.md, tareas.md o progreso.txt sin leer primero esta habilidad y las referencias/documentos relevantes.
