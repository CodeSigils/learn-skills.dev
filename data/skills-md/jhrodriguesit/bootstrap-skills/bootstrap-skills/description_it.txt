Esegui una breve intervista strutturata su un progetto software (forma del progetto, stile di lavoro, stack di creazione, problemi di qualità, problemi di produzione), quindi cerca skills.sh per le competenze corrispondenti della massima qualità e installale nella cartella delle competenze locali del progetto. Da utilizzare quando l'utente esegue /bootstrap-skills, dice "avvia questo progetto", "imposta competenze per questo progetto", "quali competenze dovrei installare" o avvia un nuovo progetto e desidera un set di competenze consigliato.
