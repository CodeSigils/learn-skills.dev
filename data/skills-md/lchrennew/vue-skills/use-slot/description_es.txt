Aplica la sintaxis de ranura más simple de Vue (número abreviado de ranura v). Úselo al escribir o modificar plantillas de Vue que consumen componentes con ranuras. Se activa incluso si el usuario simplemente dice "pasar contenido al componente" o "usar ranura del componente". Impone el uso de # y evita la sintaxis v-slot:/slot-scope obsoleta.
