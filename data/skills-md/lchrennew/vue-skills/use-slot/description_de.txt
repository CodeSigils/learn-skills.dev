Wendet die einfachste Slot-Syntax von Vue an (V-Slot-Kurzschrift #). Wird beim Schreiben oder Ändern von Vue-Vorlagen verwendet, die Komponenten mit Slots nutzen. Wird auch dann ausgelöst, wenn der Benutzer nur „Inhalt an Komponente übergeben“ oder „Komponentensteckplatz verwenden“ sagt. Erzwingt die Verwendung von # und verhindert die veraltete v-slot:/slot-scope-Syntax.
