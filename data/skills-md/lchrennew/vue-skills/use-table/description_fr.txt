Utilisez cette compétence chaque fois que l'utilisateur souhaite afficher des données structurées, créer un tableau ou modifier une grille de données existante dans Vue. Vous DEVEZ invoquer cette compétence même si l'utilisateur dit seulement « afficher une liste d'utilisateurs », « ajouter une colonne d'action » ou « afficher les données », sans mentionner explicitement « table », « Ant Design » ou « style de modèle ».
