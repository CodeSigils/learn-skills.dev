Utilice esta habilidad siempre que el usuario quiera mostrar datos estructurados, crear una tabla o modificar una cuadrícula de datos existente en Vue. DEBE invocar esta habilidad incluso si el usuario solo dice "mostrar una lista de usuarios", "agregar una columna de acción" o "mostrar los datos", sin mencionar explícitamente "tabla", "Diseño Ant" o "estilo de plantilla".
