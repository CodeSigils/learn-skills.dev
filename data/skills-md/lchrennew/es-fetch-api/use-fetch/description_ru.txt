Используйте этот навык, когда пользователю необходимо вызвать удаленный интерфейс HTTP, инкапсулировать клиент API или создать запрос с аутентификацией, параметрами или телом запроса. Это относится к запросам GET/POST/PUT/DELETE, параметрам запроса, телам запросов JSON или формы, загрузке файлов, заголовкам запросов (например, токенов) и запросам на отмену. Даже если пользователь явно не упоминает «извлечение», «API» или «HTTP», если речь идет о вызове внутреннего интерфейса, запросе удаленных данных или взаимодействии с сервером, этот навык следует использовать.
