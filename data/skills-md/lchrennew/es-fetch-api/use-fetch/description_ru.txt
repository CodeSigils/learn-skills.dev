Используйте это, когда пользователю необходимо вызвать удаленный интерфейс HTTP, обернуть клиент API или создать запрос с аутентификацией, параметрами или телом запроса. Это применимо к запросам GET/POST/PUT/DELETE, параметрам запроса, телам запросов JSON или формы, загрузкам файлов, заголовкам запросов (например, токенов) и отмене запросов. Даже если пользователь явно не упоминает «извлечение», «API» или «HTTP», если задача включает в себя вызов внутренней конечной точки, получение удаленных данных или взаимодействие с сервером, эту возможность следует использовать.
