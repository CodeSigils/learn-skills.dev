استخدم هذا عندما يحتاج المستخدم إلى الاتصال بواجهة HTTP بعيدة، أو تغليف عميل API، أو إنشاء طلب باستخدام المصادقة، أو المعلمات، أو نص الطلب. وينطبق ذلك على طلبات GET/POST/PUT/DELETE، ومعلمات الاستعلام، وهيئات طلب JSON أو النماذج، وتحميل الملفات، ورؤوس الطلبات (على سبيل المثال، الرمز المميز)، وإلغاء الطلب. حتى إذا لم يذكر المستخدم صراحةً "جلب" أو "API" أو "HTTP"، طالما أن ذلك يتضمن استدعاء واجهة خلفية، أو طلب بيانات عن بعد، أو التفاعل مع خادم، فيجب استخدام هذه الإمكانية.
