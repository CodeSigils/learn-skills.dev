عندما يحتاج المستخدم إلى الاتصال بواجهة HTTP بعيدة، أو تغليف عميل API، أو إنشاء طلب باستخدام المصادقة، أو المعلمات، أو نص الطلب، استخدم هذا. وينطبق ذلك على طلبات GET/POST/PUT/DELETE، ومعلمات الاستعلام، وهيئات طلب JSON أو النماذج، وتحميل الملفات، ورؤوس الطلبات (مثل الرمز المميز)، وإلغاء الطلب. حتى لو لم يذكر المستخدم صراحةً "جلب" أو "API" أو "HTTP"، طالما أن المهمة تتضمن استدعاء نقطة نهاية خلفية، أو جلب بيانات عن بعد، أو التفاعل مع خادم، فيجب استخدام هذه الإمكانية.
