Lorsqu'un utilisateur a besoin d'appeler une interface HTTP distante, d'encapsuler un client API ou de construire une requête avec une authentification, des paramètres ou un corps de requête, utilisez-le. Il s'applique aux requêtes GET/POST/PUT/DELETE, aux paramètres de requête, aux corps de requête JSON ou de formulaire, aux téléchargements de fichiers, aux en-têtes de requête (tels qu'un jeton) et à l'annulation de requête. Même si l'utilisateur ne mentionne pas explicitement « récupérer », « API » ou « HTTP », tant que la tâche implique l'appel d'un point de terminaison backend, la récupération de données distantes ou l'interaction avec un serveur, cette fonctionnalité doit être utilisée.
