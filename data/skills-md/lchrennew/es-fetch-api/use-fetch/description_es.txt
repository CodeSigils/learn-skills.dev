Cuando un usuario necesite llamar a una interfaz HTTP remota, empaquetar un cliente API o crear una solicitud con autenticación, parámetros o un cuerpo de solicitud, utilice esto. Se aplica a solicitudes GET/POST/PUT/DELETE, parámetros de consulta, JSON o cuerpos de solicitud de formulario, carga de archivos, encabezados de solicitud (como un token) y cancelación de solicitudes. Incluso si el usuario no menciona explícitamente "buscar", "API" o "HTTP", siempre que la tarea implique invocar un punto final de backend, recuperar datos remotos o interactuar con un servidor, se debe emplear esta capacidad.
