Use this when the user wants to call a remote HTTP interface, encapsulate an API client, or construct a request with authentication, parameters, or a request body. It applies to GET/POST/PUT/DELETE requests, query parameters, JSON or form request bodies, file uploads, request headers (such as tokens), and canceling requests. Even if the user does not explicitly mention “fetch,” “API,” or “HTTP,” as long as it involves invoking a backend endpoint, requesting remote data, or interacting with a server, this capability should be used.
