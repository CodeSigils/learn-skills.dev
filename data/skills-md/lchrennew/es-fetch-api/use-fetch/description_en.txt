When a user needs to call a remote HTTP interface, wrap an API client, or construct a request with authentication, parameters, or a request body, use this. It applies to GET/POST/PUT/DELETE requests, query parameters, JSON or form request bodies, file uploads, request headers (such as a token), and request cancellation. Even if the user does not explicitly mention “fetch,” “API,” or “HTTP,” as long as the task involves invoking a backend endpoint, fetching remote data, or interacting with a server, this capability should be employed.
