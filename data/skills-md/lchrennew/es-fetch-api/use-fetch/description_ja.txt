ユーザーがリモート HTTP インターフェイスを呼び出す必要がある場合、API クライアントをラップする必要がある場合、または認証、パラメータ、またはリクエスト本文を使用してリクエストを構築する必要がある場合は、これを使用します。これは、GET/POST/PUT/DELETE リクエスト、クエリ パラメーター、JSON またはフォームのリクエスト本文、ファイルのアップロード、リクエスト ヘッダー (トークンなど)、およびリクエストのキャンセルに適用されます。ユーザーが「フェッチ」、「API」、または「HTTP」について明示的に言及していなくても、タスクにバックエンド エンドポイントの呼び出し、リモート データのフェッチ、またはサーバーとの対話が含まれる限り、この機能を使用する必要があります。
