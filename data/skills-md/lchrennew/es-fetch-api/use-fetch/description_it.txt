Quando un utente deve chiamare un'interfaccia HTTP remota, eseguire il wrapper di un client API o costruire una richiesta con autenticazione, parametri o un corpo della richiesta, utilizzalo. Si applica a richieste GET/POST/PUT/DELETE, parametri di query, corpi di richieste JSON o moduli, caricamenti di file, intestazioni di richiesta (come un token) e annullamento di richieste. Anche se l'utente non menziona esplicitamente "fetch", "API" o "HTTP", purché l'attività implichi il richiamo di un endpoint backend, il recupero di dati remoti o l'interazione con un server, è opportuno utilizzare questa funzionalità.
