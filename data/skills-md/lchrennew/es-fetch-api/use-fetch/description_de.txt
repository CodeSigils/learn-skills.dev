Wenn ein Benutzer eine Remote-HTTP-Schnittstelle aufrufen, einen API-Client umschließen oder eine Anfrage mit Authentifizierung, Parametern oder einem Anfragetext erstellen muss, verwenden Sie dies. Dies gilt für GET/POST/PUT/DELETE-Anfragen, Abfrageparameter, JSON- oder Formularanforderungstexte, Datei-Uploads, Anforderungsheader (z. B. ein Token) und die Stornierung von Anforderungen. Auch wenn der Benutzer „Abrufen“, „API“ oder „HTTP“ nicht ausdrücklich erwähnt, sollte diese Funktion genutzt werden, solange die Aufgabe das Aufrufen eines Backend-Endpunkts, das Abrufen von Remote-Daten oder die Interaktion mit einem Server umfasst.
