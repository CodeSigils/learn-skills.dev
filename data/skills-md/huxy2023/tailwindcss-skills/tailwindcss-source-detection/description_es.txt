Utilice esta habilidad cuando Tailwind CSS v4 no genere las clases esperadas o cuando configure el escaneo de origen. Cubre la detección de clases de texto plano, nombres completos de clases, obstáculos de clases dinámicas, mapeo de accesorios a cadenas de clases estáticas, archivos ignorados, `@source`, `source()` rutas base de importación, `source(none)`, `@source not`, `@source inline()` listas seguras, expansión de llaves y exclusión de clases generadas. Activadores de: clase faltante, clase no generada, clase dinámica, bg-${color}, @source, lista segura, fuente (ninguna), fuente en línea, fuente no, archivos escaneados, configuración de contenido.
