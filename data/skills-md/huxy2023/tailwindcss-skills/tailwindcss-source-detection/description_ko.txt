Tailwind CSS v4가 예상 클래스를 생성하지 않거나 소스 검색을 구성할 때 이 기술을 사용하세요. 일반 텍스트 클래스 감지, 완전한 클래스 이름, 동적 클래스 함정, 정적 클래스 문자열에 소품 매핑, 파일 무시, `@source`, `source()` 가져오기 기본 경로, `source(none)`, `@source not`, `@source inline()` 허용 목록 지정, 중괄호 확장 및 생성된 클래스 제외를 다룹니다. 트리거 대상: 클래스 누락, 클래스가 생성되지 않음, 동적 클래스, bg-${color}, @source, 허용 목록, 소스(없음), 소스 인라인, 소스 없음, 스캔 파일, 콘텐츠 구성.
