Utilizza questa competenza quando Tailwind CSS v4 non genera le classi previste o quando si configura la scansione dell'origine. Riguarda il rilevamento delle classi di testo semplice, i nomi completi delle classi, le trappole delle classi dinamiche, la mappatura delle proprietà su stringhe di classi statiche, i file ignorati, `@source`, `source()` percorsi di base di importazione, `source(none)`, `@source not`, `@source inline()` elenchi sicuri, espansione delle parentesi graffe ed esclusione delle classi generate. Si attiva su: classe mancante, classe non generata, classe dinamica, bg-${color}, @source, lista sicura, source(none), sorgente in linea, sorgente non, scansiona file, configurazione contenuto.
