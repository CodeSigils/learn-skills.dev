Используйте этот навык, когда Tailwind CSS v4 не генерирует ожидаемые классы или при настройке сканирования источника. Охватывает обнаружение классов в виде простого текста, полные имена классов, ловушки динамических классов, сопоставление реквизитов со строками статических классов, игнорируемые файлы, базовые пути импорта `@source`, `source()`, `source(none)`, `@source not`, `@source inline()`, список надежных источников, раскрытие скобок и исключение сгенерированных классов. Срабатывает при: отсутствующем классе, классе не созданном, динамическом классе, bg-${color}, @source, списке надежных источников, источнике (нет), встроенном источнике, отсутствии источника, файлах сканирования, конфигурации контента.
