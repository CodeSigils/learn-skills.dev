Utilisez cette compétence lorsque Tailwind CSS v4 ne génère pas les classes attendues ou lors de la configuration de l'analyse des sources. Couvre la détection de classe en texte brut, les noms de classe complets, les pièges des classes dynamiques, le mappage des accessoires sur les chaînes de classe statiques, les fichiers ignorés, les chemins de base d'importation `@source`, `source()`, `source(none)`, `@source not`, la liste sécurisée `@source inline()`, l'expansion des accolades et l'exclusion des classes générées. Déclencheurs sur : classe manquante, classe non générée, classe dynamique, bg-${color}, @source, liste sécurisée, source (aucun), source en ligne, source non, fichiers d'analyse, configuration du contenu.
