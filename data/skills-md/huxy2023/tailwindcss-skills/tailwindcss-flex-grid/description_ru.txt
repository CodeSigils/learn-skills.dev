Используйте этот навык при создании флексбоксов или макетов сетки в Tailwind CSS v4. Охватывает гибкое направление/обтекание/основу/рост/уменьшение/порядок, столбцы/строки шаблона сетки, диапазоны столбцов/строк сетки, автоматическое расположение, автоматические столбцы/строки, пробелы, утилиты выравнивания/выравнивания/размещения, адаптивные изменения макета и общие шаблоны карточек/списков/боковых панелей. Запускается по: flex, сетке, flex-row, flex-col, flex-wrap, базису, росту, сжатию, порядку, Grid-cols, col-span, row-span, auto-cols, auto-rows, зазору, выравниванию, выравниванию, размещению, сетке макета.
