Используйте этот навык при стилизации текста с помощью Tailwind CSS v4. Охватывает семейство шрифтов/размер/сглаживание/стиль/вес/растяжение, числовые варианты, настройки функций шрифта, межбуквенный интервал, зажим строки, высоту строки, списки, выравнивание текста/цвет/украшение/трансформацию/переполнение/перенос/отступ, размер табуляции, вертикальное выравнивание, пробелы, разрыв слова, перенос переполнения, дефисы и утилиты для работы с содержимым. Срабатывает при: типографике, шрифте, тексте, интерлиньяже, отслеживании, зажиме строки, диске списка, цвете текста, подчеркивании, усечении, переносе текста, пробелах, разрыве слов, переносе переполнения, дефисах, размере табуляции, содержимом.
