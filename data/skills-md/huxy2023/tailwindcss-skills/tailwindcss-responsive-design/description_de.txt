Nutzen Sie diese Fähigkeit, wenn Sie reaktionsfähige Tailwind CSS v4-Schnittstellen erstellen. Deckt Mobile-First-Haltepunkte („sm“, „md“, „lg“, „xl“, „2xl“), maximale Haltepunktbereiche, beliebige Min/Max-Medienvarianten, benutzerdefinierte „--breakpoint-*“-Variablen, Containerabfragen mit „@container“, maximale/benannte Container, „@container-size“, benutzerdefinierte „--container-*“-Größen und Containerabfrageeinheiten ab. Löst aus auf: Responsive, Breakpoint, Mobile First, sm:, md:, lg:, max-md, min-[...], max-[...], @container, @container-size, @sm, @max-md, Containerabfrage.
