Utilisez cette compétence lors de la création d’interfaces Tailwind CSS v4 réactives. Couvre les points d'arrêt mobiles d'abord (`sm`, `md`, `lg`, `xl`, `2xl`), les plages de points d'arrêt maximales, les variantes multimédias min/max arbitraires, les variables `--breakpoint-*` personnalisées, les requêtes de conteneur avec `@container`, les conteneurs max/nommés, `@container-size`, les tailles `--container-*` personnalisées et les unités de conteneur de requête. Déclencheurs sur : responsive, point d'arrêt, mobile first, sm :, md :, lg :, max-md, min-[...], max-[...], @container, @container-size, @sm, @max-md, requête de conteneur.
