반응형 Tailwind CSS v4 인터페이스를 구축할 때 이 기술을 사용하세요. 모바일 우선 중단점(`sm`, `md`, `lg`, `xl`, `2xl`), 최대 중단점 범위, 임의의 최소/최대 미디어 변형, 사용자 정의 `--breakpoint-*` 변수, `@container`를 사용한 컨테이너 쿼리, 최대/이름이 지정된 컨테이너, `@container-size`, 사용자 정의 `--container-*` 크기 및 컨테이너 쿼리 단위를 다룹니다. 트리거 대상: 반응형, 중단점, 모바일 우선, sm:, md:, lg:, max-md, min-[...], max-[...], @container, @container-size, @sm, @max-md, 컨테이너 쿼리.
