Use this skill when building responsive Tailwind CSS v4 interfaces. Covers mobile-first breakpoints (`sm`, `md`, `lg`, `xl`, `2xl`), max breakpoint ranges, arbitrary min/max media variants, custom `--breakpoint-*` variables, container queries with `@container`, max/named containers, `@container-size`, custom `--container-*` sizes, and container query units. Triggers on: responsive, breakpoint, mobile first, sm:, md:, lg:, max-md, min-[...], max-[...], @container, @container-size, @sm, @max-md, container query.
