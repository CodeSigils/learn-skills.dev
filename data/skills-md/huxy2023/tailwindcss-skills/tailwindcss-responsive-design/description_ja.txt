このスキルは、応答性の高い Tailwind CSS v4 インターフェイスを構築するときに使用します。モバイルファーストブレークポイント (`sm`、`md`、`lg`、`xl`、`2xl`)、最大ブレークポイント範囲、任意の最小/最大メディア バリアント、カスタム `--breakpoint-*` 変数、`@container` を使用したコンテナ クエリ、最大/名前付きコンテナ、`@container-size`、カスタム `--container-*` サイズ、およびコンテナ クエリをカバーします。単位。トリガー対象: レスポンシブ、ブレークポイント、モバイル ファースト、sm:、md:、lg:、max-md、min-[...]、max-[...]、@container、@container-size、@sm、@max-md、コンテナ クエリ。
