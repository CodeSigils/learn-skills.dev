Copre punti di interruzione mobile-first (`sm`, `md`, `lg`, `xl`, `2xl`), intervalli massimi di punti di interruzione, varianti multimediali min/max arbitrarie, variabili personalizzate `--breakpoint-*`, query sui contenitori con `@container`, contenitori massimi/denominati, `@container-size`, dimensioni personalizzate `--container-*` e unità di query dei contenitori.
