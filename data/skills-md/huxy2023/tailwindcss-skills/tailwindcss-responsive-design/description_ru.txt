Используйте этот навык при создании адаптивных интерфейсов Tailwind CSS v4. Охватывает точки останова для мобильных устройств (`sm`, `md`, `lg`, `xl`, `2xl`), максимальные диапазоны точек останова, произвольные минимальные и максимальные варианты мультимедиа, пользовательские переменные `--breakpoint-*`, контейнерные запросы с `@container`, максимальные/именованные контейнеры, `@container-size`, пользовательские размеры `--container-*` и единицы запроса контейнера. Срабатывает при: отзывчивости, точке останова, сначала мобильных устройствах, sm:, md:, lg:, max-md, min-[...], max-[...], @container, @container-size, @sm, @max-md, запрос контейнера.
