Используйте этот навык при проверке совместимости браузера и инструментов Tailwind CSS v4. Охватывает требования браузера (Safari 16.4+, Chrome 111+, Firefox 128+), зависимости современных функций CSS, когда следует оставаться на версии 3.4, рекомендации по Sass/Less/Stylus, встроенное объединение/префикс импорта с помощью Lightning CSS, модули CSS и блоки стилей компонентов, `@reference` и подводные камни производительности сборки. Срабатывает при: совместимости, поддержке браузера, Safari, Chrome, Firefox, Sass, Less, Stylus, модулях CSS, блоке стилей Vue, стиле Svelte, стиле Astro, @reference, автопрефиксере, импорте postcss.
