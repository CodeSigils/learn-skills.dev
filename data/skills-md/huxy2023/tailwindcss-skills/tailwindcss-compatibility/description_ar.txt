استخدم هذه المهارة عند التحقق من توافق متصفح/أدوات Tailwind CSS v4. يغطي متطلبات المتصفح (Safari 16.4+، Chrome 111+، Firefox 128+)، تبعيات ميزات CSS الحديثة، متى يجب البقاء على الإصدار 3.4، توجيه Sass/Less/Stylus، تجميع/بادئة الاستيراد المضمنة عبر Lightning CSS، وحدات CSS وكتل نمط المكونات، `@reference`، ومزالق بناء الأداء. المشغلات على: التوافق، دعم المتصفح، Safari، Chrome، Firefox، Sass، Less، Stylus، وحدات CSS، كتلة نمط Vue، نمط Svelte، نمط Astro، @reference، autoprefixer، postcss-import.
