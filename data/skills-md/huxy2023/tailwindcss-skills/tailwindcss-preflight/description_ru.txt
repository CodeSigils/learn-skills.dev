Используйте этот навык при работе с базовыми стилями и сбросом в Tailwind CSS v4. Охватывает Preflight, modern‑normalize, автоматическое внедрение базового слоя, удалённые отступы по умолчанию, сброс границ, заголовки и списки без стилей, блочные адаптивные изображения, поведение атрибута hidden, расширение `@layer base`, отключение Preflight путем отдельного импорта theme/utilities и конфликты со сторонними библиотеками. Срабатывает по: Preflight, reset, base styles, headings unstyled, lists no bullets, border reset, image block, max‑width image, @layer base, disable preflight.
