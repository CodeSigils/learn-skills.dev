このスキルは、Tailwind CSS v3 プロジェクトを v4 にアップグレードするとき、または v4 プロジェクトで v3 パターンを診断するときに使用します。 `npx @tailwindcss/upgrade`、Node.js 20+ 要件、ブラウザーのサポート、パッケージ分割 (`@tailwindcss/postcss`、`@tailwindcss/vite`、`@tailwindcss/cli`)、`@tailwind` ディレクティブの `@import` への置き換え、設定の CSS `@theme` への移動、削除/名前変更されたユーティリティ、不透明度修飾子の置換、アウトライン/リング/シャドウ/半径/ブラーの変更、および手動レビュー戦略。トリガー条件: Tailwind v4 のアップグレード、v3 の移行、@tailwind ベース、tailwind.config.js、コンテンツ構成、bg-opacity、flex-shrink、shadow-sm 変更、outline-none、@tailwindcss/upgrade。
