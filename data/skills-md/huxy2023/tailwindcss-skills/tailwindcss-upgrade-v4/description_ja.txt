このスキルは、Tailwind CSS v3 プロジェクトを v4 にアップグレードする際、または v4 プロジェクトで v3 のパターンを診断する際に使用してください。`npx @tailwindcss/upgrade`、Node.js 20 以上の要件、ブラウザサポート、パッケージ分割（`@tailwindcss/postcss`、`@tailwindcss/vite`、`@tailwindcss/cli`）、`@tailwind` ディレクティブを `@import` に置き換えること、設定を CSS の `@theme` に移行すること、削除・名称変更されたユーティリティ、透明度モディファイアの置換、outline / ring / shadow / radius / blur の変更、そして手動レビュー戦略をカバーしています。トリガーは、Tailwind v4 のアップグレード、v3 の移行、@tailwind base、tailwind.config.js、content 設定、bg-opacity、flex‑shrink、shadow‑sm の変更、outline‑none、@tailwindcss/upgrade です。
