استخدم هذه المهارة عند ترقية مشاريع Tailwind CSS v3 إلى الإصدار 4 أو تشخيص أنماط الإصدار 3 في مشروع الإصدار 4. يغطي `npx @tailwindcss/upgrade`، ومتطلبات Node.js 20+، ودعم المتصفح، وتقسيم الحزمة (`@tailwindcss/postcss`، `@tailwindcss/vite`، `@tailwindcss/cli`)، واستبدال توجيهات `@tailwind` بـ `@import`، ونقل التكوين إلى CSS `@theme`، وإزالة/إعادة تسمية الأدوات المساعدة، والعتامة بدائل المعدل، وتغييرات المخطط التفصيلي/الحلقة/الظل/نصف القطر/التمويه، واستراتيجية المراجعة اليدوية. تشغيل المشغلات: ترقية Tailwind v4، وترحيل الإصدار 3، وقاعدة @tailwind، وtailwind.config.js، وتكوين المحتوى، وbg-opacity، وflex-shrink، وتغيير Shadow-sm، والمخطط التفصيلي بلا شيء، و@tailwindcss/upgrade.
