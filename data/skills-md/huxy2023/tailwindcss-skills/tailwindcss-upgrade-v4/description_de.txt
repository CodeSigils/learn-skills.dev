Verwenden Sie diese Fähigkeit, wenn Sie Tailwind CSS v3-Projekte auf v4 aktualisieren oder v3-Muster in einem v4-Projekt diagnostizieren. Behandelt „npx @tailwindcss/upgrade“, Node.js 20+-Anforderungen, Browserunterstützung, Paketaufteilung („@tailwindcss/postcss“, „@tailwindcss/vite“, „@tailwindcss/cli“), Ersetzen von „@tailwind“-Anweisungen durch „@import“, Verschieben der Konfiguration nach CSS „@theme“, entfernte/umbenannte Dienstprogramme, Deckkraftmodifikator Ersetzungen, Umriss-/Ring-/Schatten-/Radius-/Unschärfeänderungen und manuelle Überprüfungsstrategie. Auslöser bei: Upgrade von Tailwind v4, Migration von v3, @tailwind base, tailwind.config.js, Content Config, BG-Opacity, Flex-Shrink, Shadow-SM geändert, Outline-none, @tailwindcss/upgrade.
