Используйте этот навык при обновлении проектов Tailwind CSS v3 до версии 4 или диагностике шаблонов версии 3 в проекте версии 4. Охватывает `npx @tailwindcss/upgrade`, требования Node.js 20+, поддержку браузеров, разделение пакетов (`@tailwindcss/postcss`, `@tailwindcss/vite`, `@tailwindcss/cli`), замену директив `@tailwind` на `@import`, перемещение конфигурации в CSS `@theme`, удаленные/переименованные утилиты, замену модификатора непрозрачности, изменения контура/кольца/тени/радиуса/размытия и стратегия ручного просмотра. Срабатывает при: обновлении Tailwind v4, миграции v3, базе @tailwind, Tailwind.config.js, конфигурации контента, bg-opacity, flex-shrink, изменении тени-sm, Outline-none, @tailwindcss/upgrade.
