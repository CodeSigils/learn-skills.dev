Use this skill when upgrading Tailwind CSS v3 projects to v4 or diagnosing v3 patterns in a v4 project. Covers `npx @tailwindcss/upgrade`, Node.js 20+ requirement, browser support, package split (`@tailwindcss/postcss`, `@tailwindcss/vite`, `@tailwindcss/cli`), replacing `@tailwind` directives with `@import`, moving config to CSS `@theme`, removed/renamed utilities, opacity modifier replacements, outline/ring/shadow/radius/blur changes, and manual review strategy. Triggers on: upgrade Tailwind v4, migrate v3, @tailwind base, tailwind.config.js, content config, bg-opacity, flex-shrink, shadow-sm changed, outline-none, @tailwindcss/upgrade.
