Utiliza esta habilidad al actualizar proyectos Tailwind CSS v3 a v4 o al diagnosticar patrones v3 en un proyecto v4. Cubre `npx @tailwindcss/upgrade`, el requisito de Node.js 20+, compatibilidad con navegadores, la división de paquetes (`@tailwindcss/postcss`, `@tailwindcss/vite`, `@tailwindcss/cli`), reemplazar directivas `@tailwind` por `@import`, mover la configuración a CSS `@theme`, utilidades eliminadas/renombradas, sustituciones de modificadores de opacidad, cambios en outline/ring/shadow/radius/blur y la estrategia de revisión manual. Se activa con: actualizar Tailwind v4, migrar v3, `@tailwind base`, `tailwind.config.js`, configuración de `content`, `bg-opacity`, `flex-shrink`, cambio en `shadow-sm`, `outline-none`, `@tailwindcss/upgrade`.
