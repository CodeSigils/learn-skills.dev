Utilice esta habilidad cuando actualice proyectos Tailwind CSS v3 a v4 o diagnostique patrones v3 en un proyecto v4. Cubre `npx @tailwindcss/upgrade`, requisito de Node.js 20+, compatibilidad con navegador, división de paquetes (`@tailwindcss/postcss`, `@tailwindcss/vite`, `@tailwindcss/cli`), reemplazo de directivas `@tailwind` con `@import`, movimiento de configuración a CSS `@theme`, utilidades eliminadas/renombradas, reemplazos de modificadores de opacidad, cambios de contorno/anillo/sombra/radio/desenfoque y estrategia de revisión manual. Activadores de: actualizar Tailwind v4, migrar v3, @tailwind base, tailwind.config.js, configuración de contenido, bg-opacity, flex-shrink, shadow-sm cambiado, contorno-none, @tailwindcss/upgrade.
