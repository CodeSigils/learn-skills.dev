Utilizza questa competenza durante l'aggiornamento dei progetti Tailwind CSS v3 alla v4 o la diagnosi dei modelli v3 in un progetto v4. Riguarda `npx @tailwindcss/upgrade`, requisiti Node.js 20+, supporto browser, suddivisione dei pacchetti (`@tailwindcss/postcss`, `@tailwindcss/vite`, `@tailwindcss/cli`), sostituzione delle direttive `@tailwind` con `@import`, spostamento della configurazione in CSS `@theme`, utilità rimosse/rinominate, sostituzioni dei modificatori di opacità, modifiche a contorno/anello/ombra/raggio/sfocatura e strategia di revisione manuale. Si attiva su: aggiornamento Tailwind v4, migrazione v3, @tailwind base, tailwind.config.js, configurazione contenuto, bg-opacity, flex-shrink, shadow-sm modificato, contour-none, @tailwindcss/upgrade.
