Utilisez cette compétence lors de la mise à niveau des projets Tailwind CSS v3 vers la v4 ou du diagnostic des modèles v3 dans un projet v4. Couvre `npx @tailwindcss/upgrade`, l'exigence Node.js 20+, la prise en charge du navigateur, le fractionnement du package (`@tailwindcss/postcss`, `@tailwindcss/vite`, `@tailwindcss/cli`), le remplacement des directives `@tailwind` par `@import`, le déplacement de la configuration vers CSS `@theme`, les utilitaires supprimés/renommés, les remplacements de modificateurs d'opacité, changements de contour/anneau/ombre/rayon/flou et stratégie de révision manuelle. Déclencheurs sur : mise à niveau de Tailwind v4, migration v3, @tailwind base, tailwind.config.js, configuration du contenu, bg-opacity, flex-shrink, shadow-sm modifié, outline-none, @tailwindcss/upgrade.
