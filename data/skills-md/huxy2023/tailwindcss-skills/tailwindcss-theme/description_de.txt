Verwenden Sie diese Fähigkeit, wenn Sie Tailwind CSS v4-Design-Tokens mit „@theme“ anpassen. Behandelt Themenvariablen, Token-Namespaces („--color-*“, „--font-*“, „--text-*“, „--spacing-*“, „--breakpoint-*“, „--container-*“, Schatten, Radius, Beschleunigung, Animation), generierte Dienstprogramme, standardmäßige Themenerweiterung/-entfernung, Verwendung von CSS-Variablen und wann „:root“ anstelle von verwendet werden sollte „@theme“. Auslöser für: @theme, Designvariablen, Design-Tokens, CSS-Variablen, benutzerdefinierte Farben, benutzerdefinierte Schriftart, benutzerdefinierter Haltepunkt, Abstandsskala, Standarddesign, Token-Namespace.
