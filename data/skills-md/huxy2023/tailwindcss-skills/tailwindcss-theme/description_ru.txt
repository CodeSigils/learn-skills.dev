Используйте этот навык при настройке токенов дизайна Tailwind CSS v4 с помощью @theme. Охватывает переменные темы, пространства имен токенов (`--color-*`, `--font-*`, `--text-*`, `--spacing-*`, `--breakpoint-*`, `--container-*`, тени, радиус, плавность, анимация), сгенерированные утилиты, расширение/удаление темы по умолчанию, использование переменных CSS и когда использовать `:root` вместо `@theme`. Запускается по: @theme, переменным темы, маркерам дизайна, переменным CSS, пользовательским цветам, пользовательскому шрифту, пользовательской точке останова, масштабу интервалов, теме по умолчанию, пространству имен токена.
