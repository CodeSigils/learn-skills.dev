Utilisez cette compétence lors de la personnalisation des jetons de conception Tailwind CSS v4 avec « @theme ». Couvre les variables de thème, les espaces de noms de jetons (`--color-*`, `--font-*`, `--text-*`, `--spacing-*`, `--breakpoint-*`, `--container-*`, ombres, rayon, assouplissement, animation), les utilitaires générés, l'extension/suppression de thème par défaut, l'utilisation des variables CSS et quand utiliser `:root` au lieu de `@theme`. Déclencheurs sur : @theme, variables de thème, jetons de conception, variables CSS, couleurs personnalisées, police personnalisée, point d'arrêt personnalisé, échelle d'espacement, thème par défaut, espace de noms de jeton.
