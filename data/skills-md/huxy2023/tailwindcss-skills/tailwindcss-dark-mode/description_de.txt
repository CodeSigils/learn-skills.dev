Verwenden Sie diese Fähigkeit, wenn Sie den Dunkelmodus in Tailwind CSS v4 implementieren oder debuggen. Behandelt die Variante „dark:“, das Standardverhalten „prefers-color-scheme“, den selektorgesteuerten Dunkelmodus mit „@custom-variant dark“, die Strategien „.dark“ und „data-theme“, dreifache System-/Hell-/Dunkel-Umschaltung, localStorage, vom Server gerenderte Designklassen und die Vermeidung von FOUC. Wird ausgelöst durch: Dark Mode, Dark:, Prefers-Color-Schema, .dark, Data-Theme, Theme Toggle, System Theme, LocalStorage Theme, FOUC.
