Используйте этот навык при добавлении собственных стилей в Tailwind CSS v4 помимо встроенных утилит. Охватывает произвольные значения (`top-[117px]`), произвольные свойства (`[mask-type:luminance]`), произвольные варианты, пробелы и подсказки по типам, пользовательский CSS, `@layer base/comComponents`, `@utility`, функциональные утилиты с `--value()`, `--modifier()`, `--default()`, а также когда следует отдавать предпочтение компонентам вместо `@apply`. Срабатывает по: произвольному значению, произвольному свойству, произвольному варианту, пользовательскому CSS, @layer, @utility, @apply, --value, --modifier, --default, классу компонента.
