Utilisez cette compétence lors de l'ajout d'un style personnalisé dans Tailwind CSS v4 au-delà des utilitaires intégrés. Couvre les valeurs arbitraires (`top-[117px]`), les propriétés arbitraires (`[mask-type:luminance]`), les variantes arbitraires, les espaces et les indications de type, le CSS personnalisé, `@layer base/components`, `@utility`, les utilitaires fonctionnels avec `--value()`, `--modifier()`, `--default()`, et quand préférer les composants à `@apply`. Déclencheurs sur : valeur arbitraire, propriété arbitraire, variante arbitraire, CSS personnalisé, @layer, @utility, @apply, --value, --modifier, --default, classe de composant.
