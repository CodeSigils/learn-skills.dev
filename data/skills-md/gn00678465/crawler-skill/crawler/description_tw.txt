取得網頁並使用強大的 3 層鏈將其轉換為乾淨的 Markdown（Firecrawl → Jina Reader → Scrapling 隱形瀏覽器）。每當使用者提供 URL 並需要頁面的文字內容時，請使用此技能而不是 WebFetch，尤其是對於阻止直接訪問的網站：medium.com 文章（付費/計量）、微信公眾號（mp.weixin.qq.com，地理限制）、具有機器人程式保護的文件網站，或簡單 HTTP 獲取可能返回驗證頁面驗證碼或空白頁面的任何頁面驗證。觸發器：「閱讀此 URL」、「總結此文章/頁面」、「從中獲取內容」、「從中提取文字」、「此頁面說了什麼」、「獲取此連結」或訪問和處理特定網頁的任何請求。請勿觸發：建立抓取工具、檢查 HTTP 狀態碼、解析已下載的 HTML 檔案、回答有關抓取工具的概念性問題或監視頁面變更。
