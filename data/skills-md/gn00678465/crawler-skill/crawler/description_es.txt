Recupera páginas web y las convierte en rebajas limpias utilizando una sólida cadena de 3 niveles (Firecrawl → Jina Reader → Navegador sigiloso Scrapling). Utilice esta habilidad en lugar de WebFetch siempre que el usuario proporcione una URL y necesite el contenido de texto de la página, especialmente para sitios que bloquean el acceso directo: artículos de medium.com (de pago/medidos), cuentas públicas de WeChat (mp.weixin.qq.com, con restricciones geográficas), sitios de documentación con protección contra bots o cualquier página donde una simple búsqueda de HTTP pueda devolver un CAPTCHA o una página vacía. Activadores para: "leer esta URL", "resumir este artículo/página", "tomar el contenido de", "extraer texto de", "qué dice esta página", "buscar este enlace" o cualquier solicitud para acceder y procesar una página web específica. NO lo active para: crear raspadores, verificar códigos de estado HTTP, analizar archivos HTML ya descargados, responder preguntas conceptuales sobre herramientas de raspado o monitorear cambios en la página.
