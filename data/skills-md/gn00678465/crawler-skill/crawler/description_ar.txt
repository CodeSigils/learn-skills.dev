جلب صفحات الويب وتحويلها إلى علامة تجارية نظيفة باستخدام سلسلة قوية من 3 طبقات (Firecrawl → Jina Reader → متصفح Scrapling الخفي). استخدم هذه المهارة بدلاً من WebFetch عندما يقدم المستخدم عنوان URL ويحتاج إلى المحتوى النصي للصفحة - خاصة للمواقع التي تحظر الوصول المباشر: مقالات Medium.com (paywalled/metered)، وحسابات WeChat العامة (mp.weixin.qq.com، مقيدة جغرافيًا)، ومواقع التوثيق التي تتمتع بحماية الروبوت، أو أي صفحة حيث قد يؤدي جلب HTTP البسيط إلى عرض اختبار CAPTCHA أو صفحة فارغة. مشغلات لـ: "قراءة عنوان URL هذا"، أو "تلخيص هذه المقالة/الصفحة"، أو "التقاط المحتوى من"، أو "استخراج نص من"، أو "ماذا تقول هذه الصفحة"، أو "جلب هذا الرابط"، أو أي طلب للوصول إلى صفحة ويب معينة ومعالجتها. لا تقم بتشغيل ما يلي: إنشاء أدوات استخراج البيانات، أو التحقق من رموز حالة HTTP، أو تحليل ملفات HTML التي تم تنزيلها بالفعل، أو الإجابة على الأسئلة المفاهيمية حول أدوات استخراج البيانات، أو مراقبة تغييرات الصفحة.
