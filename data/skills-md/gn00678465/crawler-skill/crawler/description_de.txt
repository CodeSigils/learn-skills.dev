Ruft Webseiten ab und konvertiert sie mithilfe einer robusten dreistufigen Kette (Firecrawl → Jina Reader → Scrapling-Stealth-Browser) in einen sauberen Markdown. Verwenden Sie diesen Skill anstelle von WebFetch, wenn der Benutzer eine URL angibt und den Textinhalt der Seite benötigt – insbesondere für Websites, die den direkten Zugriff blockieren: medium.com-Artikel (Paywalled/Metered), öffentliche WeChat-Konten (mp.weixin.qq.com, geografisch eingeschränkt), Dokumentationsseiten mit Bot-Schutz oder jede Seite, auf der ein einfacher HTTP-Abruf möglicherweise ein CAPTCHA oder eine leere Seite zurückgibt. Auslöser für: „Diese URL lesen“, „Diesen Artikel/diese Seite zusammenfassen“, „Inhalt abrufen von“, „Text extrahieren“, „Was sagt diese Seite“, „Diesen Link abrufen“ oder jede Anfrage zum Zugriff auf eine bestimmte Webseite und deren Verarbeitung. NICHT auslösen für: Scraper erstellen, HTTP-Statuscodes überprüfen, bereits heruntergeladene HTML-Dateien analysieren, konzeptionelle Fragen zu Scraping-Tools beantworten oder Seitenänderungen überwachen.
