Web ページを取得し、堅牢な 3 層チェーン (Firecrawl → Jina Reader → Scrapling ステルス ブラウザ) を使用してクリーンなマークダウンに変換します。ユーザーが URL を指定し、ページのテキスト コンテンツが必要な場合は常に、WebFetch の代わりにこのスキルを使用します。特に、直接アクセスをブロックするサイト (medium.com 記事 (ペイウォール/従量制)、WeChat パブリック アカウント (mp.weixin.qq.com、地域制限あり)、ボット保護を備えたドキュメント サイト、または単純な HTTP フェッチで CAPTCHA または空のページが返される可能性のあるページなど) では、このスキルを使用します。トリガー: 「この URL を読む」、「この記事/ページを要約する」、「コンテンツを取得する」、「テキストを抽出する」、「このページには何と書かれているか」、「このリンクを取得する」、または特定の Web ページにアクセスして処理するためのリクエスト。スクレイパーの構築、HTTP ステータス コードのチェック、ダウンロード済みの HTML ファイルの解析、スクレイピング ツールに関する概念的な質問への回答、ページ変更の監視などの目的でトリガーしないでください。
