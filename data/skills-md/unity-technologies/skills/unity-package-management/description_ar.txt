يُستخدم عند إضافة حزم Unity (UPM) أو إزالتها أو ترقيتها أو اكتشافها برمجيًا من خارج المحرر - يتم تثبيت حزمة بدون رأس أو حزمة CI عبر C# UnityEditor.PackageManager.Client API، أو التحقق من معرفات/إصدارات الحزمة مقابل سجل Unity، أو اختيار الحزم التي تحتاجها اللعبة حسب النوع والنظام الأساسي وتحقيق الدخل. لا تدير Unity CLI حزم UPM، لذا فإن هذه المهارة تغطي هذه الفجوة. مشغلات على "تثبيت حزمة Unity"، و"add com.unity.*"، و"إعداد الحزم مقطوعة الرأس/CI"، و"الحزم الخاصة بلعبة <genre>".
