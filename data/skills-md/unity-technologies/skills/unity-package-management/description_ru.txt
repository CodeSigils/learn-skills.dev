Используйте при добавлении, удалении, обновлении или обнаружении пакетов Unity (UPM) программным способом вне редактора — установка безголового пакета или пакета CI через C# UnityEditor.PackageManager.Client API, проверка идентификаторов/версий пакетов по реестру Unity или выбор пакетов, которые нужны игре, в зависимости от жанра, платформы и монетизации. Unity CLI не управляет пакетами UPM, поэтому этот навык восполняет этот пробел. Запускается при «установке пакета Unity», «добавлении com.unity.*», «настройке пакетов headless/CI», «каких пакетах для игры <жанр>».
