エディターの外部からプログラムで Unity (UPM) パッケージを追加、削除、アップグレード、または検出する場合に使用します。ヘッドレスまたは CI パッケージは C# UnityEditor.PackageManager.Client API 経由でインストールされ、Unity レジストリに対してパッケージ ID/バージョンを確認したり、ジャンル、プラットフォーム、収益化によってゲームに必要なパッケージを選択したりします。 Unity CLI は UPM パッケージを管理しないため、このスキルはそのギャップをカバーします。 「Unity パッケージのインストール」、「com.unity.* の追加」、「パッケージのヘッドレス/CI のセットアップ」、「<ジャンル> ゲームのパッケージ」でトリガーされます。
