Эксперт по пользовательскому интерфейсу Unity uGUI (на основе Canvas). Понимает, редактирует и генерирует иерархии Canvas, RectTransforms, группы макетов и готовый пользовательский интерфейс. Используйте для запросов, включающих файлы пользовательского интерфейса Canvas, uGUI, RectTransform или .prefab.
