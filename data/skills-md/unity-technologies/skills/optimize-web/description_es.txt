Optimiza las compilaciones de Unity 6 WebGL y WebGPU para lograr un tamaño de descarga más pequeño, una carga inicial más rápida y un rendimiento eficiente del tiempo de ejecución del navegador. Úselo cuando la compilación web del usuario es demasiado grande, tartamudea en un navegador específico, consume batería excesiva, necesita configuración de compresión CDN/servidor o necesita orientación sobre eliminación de recursos, reducción de variantes de sombreado, texturas KTX, configuraciones de calidad o creación de perfiles web.
