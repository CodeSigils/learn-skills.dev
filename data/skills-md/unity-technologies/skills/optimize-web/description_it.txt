Ottimizza le build Unity 6 WebGL e WebGPU per dimensioni di download più piccole, caricamento iniziale più rapido ed efficienti prestazioni di runtime del browser. Da utilizzare quando la build web dell'utente è troppo grande, balbetta in un browser specifico, consuma una batteria eccessiva, necessita di configurazione di compressione CDN/server o necessita di indicazioni sull'eliminazione delle risorse, sulla riduzione delle varianti dello shader, sulle texture KTX, sulle impostazioni di qualità o sulla profilazione web.
