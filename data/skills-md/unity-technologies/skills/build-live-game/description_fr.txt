Créez et exploitez un jeu en direct à l’aide des services Unity. À utiliser lorsque l'utilisateur a besoin d'implémenter, de connecter ou de déboguer des fonctionnalités basées sur le backend : passes de combat, succès, progression des joueurs, sauvegardes dans le cloud, classements, matchmaking, économies virtuelles, logique faisant autorité sur le serveur, anti-triche, comptes et authentification des joueurs, configuration à distance, indicateurs de fonctionnalités, tests A/B, analyses ou déploiement de ressources cloud. Déclencheurs sur les opérations en direct, le service en direct, le backend, l'autorité du serveur, le code cloud, la sauvegarde dans le cloud, la configuration à distance, les données des joueurs, la rétention, la boucle de monétisation, le pass de saison, le classement, les sessions multijoueurs, les lobbies ou toute intégration de services Unity.
