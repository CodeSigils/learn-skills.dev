Ajoutez et configurez le chat vocal et le chat textuel dans le jeu pour les jeux multijoueurs Unity à l'aide de Unity Vivox. Couvre la configuration du microphone et les autorisations du micro sur Android/iOS, le réglage de la détection d'activité vocale (VAD), le volume de la voix et les commandes de sourdine dans une interface utilisateur de paramètres (VoiceVadMinimumVolume, curseur de micro, bouton de sourdine, indicateur de parole), la voix spatiale de proximité/3D pour les FPS/jeux coopératifs, les canaux vocaux d'équipe/fête/lobby/guilde, le push-to-talk, la mise en sourdine de soi et des autres joueurs, les messages chuchotés/directs, le chat textuel dans le jeu et l'initialisation du SDK Vivox + Connexion à l'authentification Unity. À utiliser lorsque l'utilisateur demande à ajouter un chat vocal, des communications vocales, une prise en charge microphone/micro, une interface utilisateur de paramètres de chat vocal, un bouton de sourdine, un seuil VAD, un push-to-talk, une voix de proximité ou spatiale, une voix d'équipe, un chat de groupe, un chat dans le hall, des messages directs ou mentionne Vivox, VivoxService, com.unity.services.vivox, JoinGroupChannelAsync, JoinPositionalChannelAsync, LoginAsync ou une migration depuis l'ancien Vivox. (Client.Instance / LoginSession / AccountId).
