Unity Vivox を使用して、Unity マルチプレイヤー ゲーム用のゲーム内ボイス チャットとテキスト チャットを追加および構成します。 Android/iOS でのマイクのセットアップとマイクの許可、音声アクティビティ検出 (VAD) の調整、設定 UI の音声ボリュームとミュート コントロール (VoiceVadMinimumVolume、マイク スライダー、ミュート ボタン、スピーキング インジケーター)、FPS/協力ゲーム用の近接/3D 空間音声、チーム/パーティー/ロビー/ギルドの音声チャネル、プッシュ トゥ トーク、自分と他のプレイヤーのミュート、ささやき/ダイレクト メッセージ、ゲーム内テキスト チャット、および Vivox をカバーします。 SDK 初期化 + Unity 認証サインイン。ユーザーがボイス チャット、音声通信、マイク/マイク サポート、ボイス チャット設定 UI、ミュート ボタン、VAD しきい値、プッシュ トゥ トーク、近接音声または空間音声、チーム ボイス、パーティー チャット、ロビー チャット、ダイレクト メッセージ、または Vivox、VivoxService、com.unity.services.vivox、JoinGroupChannelAsync、JoinPositionalChannelAsync、LoginAsync、またはメンションの追加を要求する場合に使用します。従来の Vivox (Client.Instance / LoginSession / AccountId) からの移行。
