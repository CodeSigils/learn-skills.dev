قم بإضافة وتكوين الدردشة الصوتية والدردشة النصية داخل اللعبة لألعاب Unity متعددة اللاعبين باستخدام Unity Vivox. يغطي إعداد الميكروفون وأذونات الميكروفون على Android/iOS، وضبط اكتشاف النشاط الصوتي (VAD)، وضبط مستوى الصوت وكتم الصوت في واجهة المستخدم للإعدادات (VoiceVadMinimumVolume، شريط تمرير الميكروفون، زر كتم الصوت، مؤشر التحدث)، الصوت المكاني القرب/ثلاثي الأبعاد لألعاب FPS/التعاونية، القنوات الصوتية للفريق/الحفلة/الردهة/النقابة، الضغط والتحدث، كتم الصوت الذاتي واللاعبين الآخرين، الرسائل الهمس/المباشرة، والنص داخل اللعبة الدردشة وVivox SDK init + تسجيل الدخول إلى مصادقة الوحدة. يُستخدم عندما يطلب المستخدم إضافة دردشة صوتية، أو اتصالات صوتية، أو دعم الميكروفون/الميكروفون، أو واجهة مستخدم إعدادات الدردشة الصوتية، أو زر كتم الصوت، أو حد VAD، أو الضغط والتحدث، أو الصوت القرب أو المكاني، أو صوت الفريق، أو الدردشة الجماعية، أو دردشة الردهة، أو الرسائل المباشرة، أو الإشارة إلى Vivox، أو VivoxService، أو com.unity.services.vivox، أو JoinGroupChannelAsync، أو JoinPositionalChannelAsync، أو LoginAsync، أو الترحيل من Vivox القديم (Client.Instance / LoginSession / AccountId).
