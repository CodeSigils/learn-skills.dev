À utiliser lors de l'interaction avec Unity CLI à partir du terminal : installez ou désinstallez des éditeurs, répertoriez ou ouvrez des projets, gérez des modules, gérez les licences, vérifiez l'état d'authentification, lisez les journaux, parcourez les versions d'Unity, créez/testez des projets ou exécutez toute autre opération Unity CLI.
