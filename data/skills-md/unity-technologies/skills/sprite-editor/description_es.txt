Edita las propiedades de los sprites de Unity generando scripts del editor de C# mediante las API de ISpriteEditorDataProvider. Maneja rectángulos de sprites, bordes, pivotes, contornos y operaciones de corte (automáticas, de cuadrícula, isométricas). Úselo cuando trabaje con recursos de sprites, hojas de sprites, atlas de texturas o corte de sprites.
