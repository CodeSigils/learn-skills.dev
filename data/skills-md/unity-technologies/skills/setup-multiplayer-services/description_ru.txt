Руководит разработкой многопользовательских онлайн-игр, в которых игроки подключаются, группируются и взаимодействуют в режиме реального времени с помощью Unity Multiplayer Services. Используйте, когда пользователь запрашивает выбор топологии, группировку игроков, хостинг, подбор игроков, обнаружение, настройку сети и игру на основе сеанса (комнаты, вечеринки, лобби) с помощью API-интерфейсов Unity Multiplayer Services.
