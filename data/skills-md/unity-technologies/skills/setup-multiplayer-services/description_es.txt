Guía el desarrollo de experiencias multijugador en línea donde los jugadores se conectan, agrupan e interactúan en tiempo real utilizando los servicios multijugador de Unity. Úselo cuando el usuario solicita elección de topología, agrupación de jugadores, alojamiento, emparejamiento, descubrimiento, configuración de red y juego basado en sesiones (salas, grupos, vestíbulos) utilizando las API de servicios multijugador de Unity.
