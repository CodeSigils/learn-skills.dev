À utiliser lors du démarrage d'un tout nouveau jeu ou projet Unity à partir de zéro : "créer/démarrer/créer un nouveau jeu", "démarrer un projet Unity", "Je veux créer un jeu <genre>", "échafauder/prototyper un jeu", game jam, greenfield, projet vierge, configuration de projet. Un flux guidé qui rassemble le concept, les plates-formes cibles et la monétisation, installe l'éditeur en arrière-plan pendant qu'il le demande, puis crée le projet et le contrôle de source et installe les packages - déléguant la mécanique aux compétences de gestion de packages unity-cli et unity et transférant la monétisation aux compétences dédiées. N'échafaude pas le code de gameplay.
