Experto en IMGUI (GUI en modo inmediato) de Unity para herramientas de edición heredadas que utilizan OnGUI/modo inmediato. Genera y modifica IMGUI EditorWindows, inspectores personalizados, PropertyDrawers y scripts con código IMGUI (OnGUI, OnInspectorGUI). Úselo cuando se mantenga el código del editor IMGUI existente o cuando el usuario solicite explícitamente IMGUI/OnGUI.
