Esperto di Unity IMGUI (Immediate Mode GUI) per strumenti di editor legacy che utilizzano OnGUI/modalità immediata. Genera e modifica IMGUI EditorWindows, ispettori personalizzati, PropertyDrawers e script con codice IMGUI (OnGUI, OnInspectorGUI). Da utilizzare quando si mantiene il codice dell'editor IMGUI esistente o quando l'utente richiede esplicitamente IMGUI/OnGUI.
