Expert Unity IMGUI (Immediate Mode GUI) pour les outils d'édition existants utilisant OnGUI/mode immédiat. Génère et modifie IMGUI EditorWindows, des inspecteurs personnalisés, des PropertyDrawers et des scripts avec du code IMGUI (OnGUI, OnInspectorGUI). À utiliser lors de la maintenance du code de l'éditeur IMGUI existant ou lorsque l'utilisateur demande explicitement IMGUI/OnGUI.
