Unity IMGUI-Experte (Immediate Mode GUI) für ältere Editor-Tools mit OnGUI/Immediate-Modus. Erzeugt und ändert IMGUI-EditorWindows, benutzerdefinierte Inspektoren, PropertyDrawer und Skripte mit IMGUI-Code (OnGUI, OnInspectorGUI). Wird verwendet, wenn vorhandener IMGUI-Editorcode beibehalten wird oder wenn der Benutzer explizit IMGUI/OnGUI anfordert.
