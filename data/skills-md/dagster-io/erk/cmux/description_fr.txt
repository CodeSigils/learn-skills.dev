Cette compétence doit être utilisée lorsque vous travaillez avec cmux, l'application de multiplexage de terminal. À utiliser lorsque les utilisateurs mentionnent les commandes cmux, la gestion de l'espace de travail, les opérations du volet de terminal ou l'intégration cmux avec erk. Essentiel pour comprendre le modèle d'espace de travail de cmux, les commandes CLI et les modèles de script.
