Refactorisez les tests qui utilisent unittest.mock.patch ou MagicMock dans le faux modèle basé sur la passerelle d'erk. À utiliser lorsque les tests importent unittest.mock, utilisent les décorateurs @patch ou appellent directement mock.patch() en tant que gestionnaires de contexte. Essentiel lorsque les fichiers test_*.py corrigent des attributs au niveau du module tels que subprocess.run,shuil.which, os.environ ou d'autres appels système. Couvre à la fois la création de code source injectable ET les tests de réécriture.
