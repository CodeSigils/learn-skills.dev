Refaktorieren Sie Tests, die unittest.mock.patch oder MagicMock verwenden, in das Gateway-basierte Fake-Muster von erk. Verwenden Sie es, wenn Tests unittest.mock importieren, @patch-Dekoratoren verwenden oder Mock.patch() direkt als Kontextmanager aufrufen. Unverzichtbar, wenn test_*.py-Dateien Attribute auf Modulebene wie subprocess.run, Shutil.which, os.environ oder andere Systemaufrufe patchen. Deckt sowohl das Erstellen von injizierbarem Quellcode als auch das Umschreiben von Tests ab.
