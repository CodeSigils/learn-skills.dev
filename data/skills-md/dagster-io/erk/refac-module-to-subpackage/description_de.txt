Leitfaden zum Konvertieren eines monolithischen Python-Moduls in ein Unterpaket mit Untermodulen. Verwenden Sie diese Option, wenn Sie eine große .py-Datei in ein Verzeichnis mit kleineren Modulen aufteilen, ein Modul in ein Paket aufteilen, eine einzelne Datei in Unterverzeichnisse umorganisieren oder wenn ein Benutzer Dinge wie „Teilen Sie dieses Modul“, „Teilen Sie diese Datei auf“, „In Unterpaket konvertieren“ oder „Diese Datei ist zu groß“ sagt. Verwenden Sie es auch, wenn ein Benutzer eine große Python-Datei identifiziert und diese ohne Verhaltensänderung neu organisieren möchte.
