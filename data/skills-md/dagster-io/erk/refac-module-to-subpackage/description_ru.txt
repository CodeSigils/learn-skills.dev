Руководство по преобразованию монолитного модуля Python в подпакет с подмодулями. Используйте при разбиении большого файла .py на каталог более мелких модулей, разделении модуля на пакет, реорганизации одного файла в подкаталоги или когда пользователь говорит такие вещи, как «разделить этот модуль», «разбить этот файл на части», «преобразовать в подпакет» или «этот файл слишком большой». Также используйте, когда пользователь идентифицирует большой файл Python и хочет реорганизовать его, не меняя поведения.
