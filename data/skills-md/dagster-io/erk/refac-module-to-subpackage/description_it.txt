Guida per convertire un modulo Python monolitico in un sottopacchetto con sottomoduli. Da utilizzare quando si suddivide un file .py di grandi dimensioni in una directory di moduli più piccoli, si divide un modulo in un pacchetto, si riorganizza un singolo file in sottodirectory o quando un utente dice cose come "dividi questo modulo", "dividi questo file", "converti in sottopacchetto" o "questo file è troppo grande". Da utilizzare anche quando un utente identifica un file Python di grandi dimensioni e desidera riorganizzarlo senza modificarne il comportamento.
