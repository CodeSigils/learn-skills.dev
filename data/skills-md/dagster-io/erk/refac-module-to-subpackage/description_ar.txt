دليل لتحويل وحدة Python المتجانسة إلى حزمة فرعية تحتوي على وحدات فرعية. يُستخدم عند تقسيم ملف .py كبير إلى دليل وحدات أصغر، أو تقسيم وحدة إلى حزمة، أو إعادة تنظيم ملف واحد إلى أدلة فرعية، أو عندما يقول المستخدم أشياء مثل "تقسيم هذه الوحدة"، أو "تقسيم هذا الملف إلى أجزاء"، أو "التحويل إلى حزمة فرعية"، أو "هذا الملف كبير جدًا". يُستخدم أيضًا عندما يتعرف المستخدم على ملف Python كبير ويريد إعادة تنظيمه دون تغيير السلوك.
