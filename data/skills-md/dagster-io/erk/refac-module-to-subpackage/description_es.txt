Guía para convertir un módulo Python monolítico en un subpaquete con submódulos. Úselo al dividir un archivo .py grande en un directorio de módulos más pequeños, dividir un módulo en un paquete, reorganizar un solo archivo en subdirectorios o cuando un usuario dice cosas como "dividir este módulo", "dividir este archivo", "convertir en subpaquete" o "este archivo es demasiado grande". Úselo también cuando un usuario identifica un archivo Python grande y desea reorganizarlo sin cambiar el comportamiento.
