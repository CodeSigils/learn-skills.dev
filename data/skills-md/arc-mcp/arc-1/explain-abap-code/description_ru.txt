Объясняйте объекты ABAP с полным контекстом зависимостей (через SAPContext) и дополнительным анализом качества кода ATC — копирует возможность SAP Joule «Объяснять код», включая определения поведения (BDEF — график CRUD, определения/проверки, класс связанного обработчика). Используйте, когда вас просят «объяснить этот ABAP», «что делает ZCL_X», «познакомить меня с этим классом/представлением/определением поведения CDS» или «проверить качество этого объекта».
