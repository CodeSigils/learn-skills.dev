Finden Sie benutzerdefinierte Z/Y-Objekte, die zur Laufzeit nie aufgerufen wurden, indem Sie die Nutzungsdaten des SAP Call Monitor (SCMON) mit einer statischen Verwendungsanalyse kombinieren – klassifizieren Sie jedes als UNUSED/LIKELY_UNUSED/USED/INDETERMINATE. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „nicht verwendeten benutzerdefinierten Code zu finden“, „Kandidaten für den Ruhestand zu identifizieren“, „tote Z-Objekte“ oder „Was können wir sicher löschen“.
