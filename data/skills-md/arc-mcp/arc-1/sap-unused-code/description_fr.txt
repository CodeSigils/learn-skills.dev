Trouvez des objets personnalisés Z/Y jamais appelés au moment de l'exécution en combinant les données d'utilisation de SAP call-monitor (SCMON) avec une analyse statique des lieux d'utilisation — classe chacun comme INUTILISÉ/PROBABLE_INUTILISÉ/UTILISÉ/INDÉTERMINÉ. Utilisez lorsque vous êtes invité à « trouver un code personnalisé inutilisé », « identifier les candidats à la retraite », « objets Z morts » ou « que pouvons-nous supprimer en toute sécurité ».
