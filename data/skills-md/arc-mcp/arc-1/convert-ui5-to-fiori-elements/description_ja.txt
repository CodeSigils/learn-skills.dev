Fiori MCP サーバーの 3 ステップ (list_functionities → get_functionity_details →execute_functionity) ワークフローを使用して、V4 RAP サービス上の @UI.* アノテーションによって駆動される Fiori Elements V4 LROP アプリ (リスト レポート + オブジェクト ページ) を生成します。 「Fiori Elements アプリを構築する」、「この V4 サービスから LROP を生成する」、「アノテーション駆動型 UI に変換する」、または「Fiori Elements V4 をスキャフォールディングする」ように求められた場合に使用します。
