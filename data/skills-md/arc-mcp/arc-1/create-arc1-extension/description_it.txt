Da utilizzare quando uno sviluppatore desidera aggiungere i propri strumenti personalizzati a un'istanza MCP ARC-1: una "estensione" o un "plug-in" (FEAT-61). Guida le decisioni chiave sull'architettura (estensione vs server separato; livello codice vs livello manifest; quale API SAP; ambito/opType), quindi supporta il plug-in e segue build + caricamento + test. NON utilizzare per aggiungere uno strumento al core ARC-1 stesso (ovvero una modifica nell'albero) o per un backend SAP diverso (ovvero un server separato).
