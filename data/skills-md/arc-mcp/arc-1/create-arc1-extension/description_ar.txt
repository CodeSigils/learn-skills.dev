استخدم عندما يرغب المطور في إضافة أدوات مخصصة خاصة به إلى حالة ARC-1 MCP — «امتداد» أو «ملحق» (FEAT-61). يوجّه قرارات الهندسة المعمارية الرئيسية (امتداد مقابل خادم منفصل؛ طبقة الكود مقابل طبقة البيان؛ أي واجهة SAP؛ النطاق/نوع العملية)، ثم يُنشئ هيكل الملحق ويرشد إلى البناء + التحميل + الاختبار. لا تستخدم لإضافة أداة إلى نواة ARC-1 نفسها (هذا تعديل داخل الشجرة)، أو لواجهة خلفية SAP مختلفة (هذا خادم منفصل).  

يرجى دائمًا الرد بلغة المستخدم.
