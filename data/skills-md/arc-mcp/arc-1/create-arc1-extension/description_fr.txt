À utiliser lorsqu'un développeur souhaite ajouter son(ses) propre(s) outil(s) personnalisé(s) à une instance ARC-1 MCP — une « extension » ou un « plugin » (FEAT-61). Guide les décisions clés en matière d'architecture (extension par rapport au serveur séparé ; niveau de code par rapport au niveau de manifeste ; quelle API SAP ; portée/opType), puis échafaude le plugin et parcourt la construction + le chargement + le test. Ne PAS utiliser pour ajouter un outil au noyau ARC-1 lui-même (c'est-à-dire un changement dans l'arborescence) ou pour un backend SAP différent (c'est-à-dire un serveur distinct).
