Úselo cuando un desarrollador quiera añadir su (s) propia (s) herramienta(s) personalizada (s) a una instancia ARC-1 MCP — una "extensión" o "plugin" (FEAT-61). Guía las decisiones clave de la arquitectura (extensión frente a servidor separado; nivel de código frente a nivel de manifiesto; qué API de SAP; alcance/opType), luego estructura el complemento y camina compilación + carga + prueba. NO utilizar para añadir una herramienta al propio núcleo de ARC-1 (que es un cambio en el árbol), o para un backend de SAP diferente (que es un servidor separado).
