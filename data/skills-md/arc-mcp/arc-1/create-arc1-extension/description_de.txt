Verwenden Sie diese Option, wenn ein Entwickler seine eigenen benutzerdefinierten Tools zu einer ARC-1 MCP-Instanz hinzufügen möchte – eine „Erweiterung“ oder ein „Plugin“ (FEAT-61). Leitet die wichtigsten Architekturentscheidungen (Erweiterung vs. separater Server; Codeschicht vs. Manifestschicht; welche SAP-API; Scope/OpType), baut dann das Plugin auf und führt Build + Load + Test durch. NICHT zum Hinzufügen eines Tools zum ARC-1-Kern selbst (das ist eine Änderung innerhalb der Baumstruktur) oder für ein anderes SAP-Backend (das ist ein separater Server) verwenden.
