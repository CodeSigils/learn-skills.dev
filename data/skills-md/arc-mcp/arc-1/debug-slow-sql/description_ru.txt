Найдите основную причину медленного запроса OData ABAP SQL или Fiori-Elements и предложите самое дешевое исправление — без графического интерфейса через ARC-1 (разделение времени odata_perf sap-statistics, cds_sql «Показать SQL», метрики выполнения SAPQuery, управление трассировкой SQL ST05, трассировки профилировщика ABAP), эскалация в SAP GUI / HANA только для записей трассировки и планов выполнения. Используйте, когда отчет, транзакция, список Fiori, представление CDS или объект OData работают медленно, время выполнения запроса истекает под нагрузкой или кто-то спрашивает: «Почему этот SQL/OData такой медленный» или «куда уходит время».
