اعثر على السبب الجذري لطلب ABAP SQL أو OData بطيء في Fiori‑Elements واقترح الإصلاح الأرخص — بدون واجهة GUI عبر ARC‑1 (odata_perf sap‑statistics تقسيم التوقيت، cds_sql “إظهار SQL”، مقاييس تنفيذ SAPQuery، التحكم في تتبع SQL بـ ST05، تتبعات ملف التعريف ABAP)، مع تصعيد إلى SAP GUI / HANA فقط لسجلات التتبع وخطط التنفيذ. استخدم ذلك عندما يكون تقرير أو معاملة أو قائمة Fiori أو عرض CDS أو كيان OData بطيئًا، أو ينتهي استعلام بمهلة تحت الحمل، أو يسأل أحدهم “لماذا هذا الـ SQL/OData بطيء” أو “أين يذهب الوقت”.
