Encuentre la causa raíz de una solicitud lenta de ABAP SQL o Fiori-Elements OData y proponga la solución más económica: sin GUI a través de ARC-1 (división de tiempo de sap-statistics odata_perf, cds_sql "Mostrar SQL", métricas de ejecución de SAPQuery, control de seguimiento de SQL ST05, seguimientos del perfilador ABAP), escalando a SAP GUI/HANA solo para registros de seguimiento y planes de ejecución. Úselo cuando un informe, transacción, lista Fiori, vista CDS o entidad OData es lenta, una consulta agota el tiempo de espera bajo carga o alguien pregunta "por qué este SQL/OData es tan lento" o "adónde se va el tiempo".
