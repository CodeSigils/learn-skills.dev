Mettez l'assistant à la terre dans le système SAP cible avant tout travail de codage en produisant un fichier system-info.md ​​local qui capture le SID, la version, les composants, les fonctionnalités détectées, les contraintes RAP et le préréglage de charpie ARC-1. À utiliser lorsqu'on vous demande de « configurer le contexte du système », de « démarrer le système SAP », de « créer system-info.md ​​» ou lors du démarrage d'une session sur un système SAP inconnu.
