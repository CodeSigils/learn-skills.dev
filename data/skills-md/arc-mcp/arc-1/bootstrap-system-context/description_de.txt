Erden Sie den Assistenten vor jeglicher Codierungsarbeit im SAP-Zielsystem, indem Sie eine lokale system-info.md ​​erstellen, die SID, Release, Komponenten, erkannte Funktionen, RAP-Einschränkungen und ARC-1-Lint-Voreinstellungen erfasst. Wird verwendet, wenn Sie aufgefordert werden, „Systemkontext einzurichten“, „das SAP-System zu booten“, „system-info.md ​​zu erstellen“ oder wenn Sie eine Sitzung mit einem unbekannten SAP-System starten.
