أنشئ ملفات ترحيل عملية من ECC إلى S/4HANA للرمز المخصص تشمل حزم SAP، المساحات الاسمية، قوائم الكائنات، أو المستخرجات المرفوعة. استخدمه عند طلب تدقيق الرمز المخصص ABAP جاهزيةً لـ S/4HANA، إنشاء تقرير جاهزية للترحيل يمكن مشاركته، دمج ATC + الكود غير المستخدم + دليل النواة النظيفة، جرد واجهات التكامل (RFC، IDoc، SEGW/OData، الوجهات) لتكامل النواة النظيفة، تصنيف الخروجات المستخدِمة/BAdIs/التعزيزات/التعديلات القياسية، حفظ النتائج بصيغة Markdown/HTML/CSV/JSON، أو تصور نطاق الترحيل.
