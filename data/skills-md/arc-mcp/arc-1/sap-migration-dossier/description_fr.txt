Créez des dossiers pratiques de migration du code personnalisé d'ECC vers S/4HANA pour les packages SAP, les espaces de noms, les listes d'objets ou les extraits téléchargés. Utilisez-le lorsqu’on vous demande d’auditer le code ABAP personnalisé pour la préparation à S/4HANA, de créer un rapport de préparation à la migration partageable, de combiner les preuves ATC + code inutilisé + core propre, d’inventorier les interfaces d’intégration (RFC, IDoc, SEGW/OData, destinations) pour une intégration core propre, de classifier les exits utilisateur/BAdI/ améliorations/modifications standard, d’enregistrer les résultats en Markdown/HTML/CSV/JSON, ou de visualiser la portée de la migration.

Veuillez toujours répondre dans la langue de l’utilisateur.
