Générez un service d'interface utilisateur RAP OData complet à partir d'une description d'objet métier en langage naturel : table, vues CDS, définitions de comportement, extension de métadonnées, définition de service et classe de pool de comportements. À utiliser lorsqu'on vous demande de « créer un service RAP pour X », « d'élaborer une interface utilisateur RAP », de « créer une application Fiori RAP » ou de « générer la pile RAP à partir de zéro ».
