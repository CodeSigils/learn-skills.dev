Genere y edite imágenes utilizando los modelos de imágenes Gemini de Google (Nano Banana 2 predeterminado, Nano Banana Pro heredado). Se utiliza cuando el usuario solicita generar, crear, editar, modificar, cambiar, alterar o actualizar imágenes. También se utiliza cuando el usuario hace referencia a un archivo de imagen existente y solicita modificarlo de alguna manera (por ejemplo, "modificar esta imagen", "cambiar el fondo", "reemplazar X con Y"). Admite texto a imagen, edición de imágenes con hasta 14 imágenes de referencia, resolución configurable (0,5K-4K), relación de aspecto y pensamiento ajustable. NO lea el archivo de imagen primero; use esta habilidad directamente con el parámetro --input-image.
