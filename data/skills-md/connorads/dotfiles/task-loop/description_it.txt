Impalcatura di una directory di loop per l'esecuzione automatizzata delle attività dell'agente. Utilizzare quando viene richiesto di "creare un ciclo di attività", "impostare un ciclo", "impalcare una directory di ciclo", "preparare attività per rl" o "impostare l'esecuzione automatizzata" per un backlog. Prende un backlog esistente e genera PROMPT.md (contratto di loop), run-log.md (cronologia delle esecuzioni) e .gitignore per loop-state.md effimero.
