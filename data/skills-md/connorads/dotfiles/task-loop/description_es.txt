Armar un directorio de bucle para la ejecución automatizada de tareas del agente. Úselo cuando se le solicite "crear un bucle de tareas", "configurar un bucle", "desarrollar un directorio de bucle", "preparar tareas para rl" o "configurar la ejecución automatizada" para un trabajo pendiente. Toma un trabajo pendiente existente y genera PROMPT.md (contrato de bucle), run-log.md (historial de ejecución) y .gitignore para loop-state.md efímero.
