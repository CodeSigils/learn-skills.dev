Создайте каталог цикла для автоматического выполнения задач агента. Используйте, когда вас просят «создать цикл задач», «настроить цикл», «подготовить каталог цикла», «подготовить задачи для rl» или «настроить автоматическое выполнение» для невыполненной работы. Берет существующую невыполненную работу и генерирует PROMPT.md (контракт цикла), run-log.md (история выполнения) и .gitignore для эфемерного цикла-state.md.
