Используйте этот навык для интеграции API стилей Jetpack Compose в проект Android. Этот навык поможет вам обновить зависимости, настроить темы компонентов, сделать пользовательские компоненты стилизованными и перенести существующие свойства макета для использования унифицированных стилей. Переносите компоненты пользовательской системы проектирования, заменяйте жестко запрограммированные параметры атрибутами стиля и используйте Modifier.styleable для состояний взаимодействия.
