Nutzen Sie diesen Skill, um die Jetpack Compose Styles API in ein Android-Projekt zu integrieren. Diese Fertigkeit führt Sie durch das Aktualisieren von Abhängigkeiten, das Einrichten von Komponententhemen, das Gestalten benutzerdefinierter Komponenten mit Stilen und das Migrieren vorhandener Layouteigenschaften zur Verwendung einheitlicher Stile. Migrieren Sie benutzerdefinierte Designsystemkomponenten, ersetzen Sie fest codierte Parameter durch Stilattribute und verwenden Sie Modifier.styleable für Interaktionszustände.
