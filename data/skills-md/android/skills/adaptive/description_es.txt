Instrucciones para crear o actualizar la interfaz de usuario de una aplicación para que se adapte a diferentes dispositivos Android, incluidos teléfonos, tabletas, dispositivos plegables, computadoras portátiles, de escritorio, TV, Auto y XR. Incluye cómo manejar diferentes tamaños de ventana, dispositivos señaladores (como el mouse) y dispositivos de entrada de texto (como el teclado) usando la API Compose MediaQuery. También cubre diseños de múltiples paneles usando escenas de Navigation3, componentes de interfaz de usuario adaptables (como botones) con diferentes tamaños de destino y diseños adaptables (incluidas áreas de navegación: rieles y barras de navegación) usando las API Compose Grid y FlexBox.
