携帯電話、タブレット、折りたたみ式デバイス、ラップトップ、デスクトップ、TV、Auto、XR などのさまざまな Android デバイスに適応するようにアプリの UI を作成または更新する手順。 Compose MediaQuery API を使用して、さまざまなウィンドウ サイズ、ポインティング デバイス (マウスなど)、テキスト入力デバイス (キーボードなど) を処理する方法が含まれています。また、Navigation3 シーンを使用したマルチペイン レイアウト、さまざまなターゲット サイズを持つアダプティブ UI コンポーネント (ボタンなど)、Compose Grid および FlexBox API を使用したアダプティブ レイアウト (ナビゲーション領域 - ナビゲーション レールとナビゲーション バーを含む) についても説明します。
