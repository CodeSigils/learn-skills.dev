Proporciona un flujo de trabajo estructurado para migrar una vista XML de Android a Jetpack Compose. Esta habilidad detalla el proceso paso a paso, desde la planificación y configuración de dependencias hasta la migración de temas y diseños, validación y limpieza de XML. Utilice esta habilidad cuando necesite migrar una vista XML a Jetpack Compose en un proyecto de Android. Resuelve el problema de convertir la interfaz de usuario de una vista XML heredada en componentes de composición declarativos y modernos manteniendo la interoperabilidad.
