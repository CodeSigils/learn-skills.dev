Proporciona pautas para desarrollar aplicaciones Android XR proyectadas para gafas de visualización utilizando el kit de herramientas de interfaz de usuario Jetpack Compose Glimmer. Esta habilidad cubre los principios fundamentales del diseño de Glimmer, los flujos de trabajo para implementar Jetpack Compose Glimmer y los modelos de interacción para el factor de forma de las gafas. Utilice esta habilidad para crear una aplicación de experiencia aumentada para Android XR con Jetpack Compose Glimmer que se adhiera al sistema de diseño Glimmer para optimizar el estilo de las gafas.
