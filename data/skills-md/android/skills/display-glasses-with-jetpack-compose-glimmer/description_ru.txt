Содержит рекомендации по разработке прогнозируемых приложений Android XR для очков с использованием набора инструментов Jetpack Compose Glimmer UI. Этот навык охватывает основополагающие принципы проектирования Glimmer, рабочие процессы реализации Jetpack Compose Glimmer и модели взаимодействия для форм-фактора очков. Используйте этот навык для создания приложения Android XR Augmented Experience с помощью Jetpack Compose Glimmer, которое соответствует системе дизайна Glimmer для оптимизации стиля очков.
