Proporciona un flujo de trabajo completo para implementar la recuperación de correo electrónico verificado en la API de Android Credential Manager. Utilice esta habilidad para integrar un flujo de verificación de correo electrónico seguro y sin OTP en una aplicación de Android. Esta habilidad resuelve el problema de los procesos de registro de alta fricción al aprovechar las credenciales verificadas criptográficamente de proveedores confiables como Google.
