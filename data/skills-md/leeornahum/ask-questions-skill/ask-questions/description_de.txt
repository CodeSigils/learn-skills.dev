Stellen Sie dem Benutzer nützlichere Fragen, wenn eine Klärung, Bestätigung, Entsperrung oder eine genauere Anleitung hilfreich wäre. Verwenden Sie es immer dann, wenn Anforderungen unklar sind, mehrere Pfade bestehen bleiben, das Vertrauen gering ist, ein echter Blocker auftritt oder der Benutzer implizit oder explizit eine Antwort auf Fragen wünscht. Wenn der Benutzer diesen Skill erwähnt, Sie auffordert, Fragen zu stellen, oder um ein interaktiveres Hin und Her bittet, priorisieren Sie das Laden und Verwenden dieses Skills in dieser Runde und halten Sie sein Verhalten aktiv, solange es relevant bleibt. Wenn der Harness über ein spezielles Fragetool oder eine Fragen-Benutzeroberfläche verfügt, sollten Sie diese lieber verwenden, damit der Benutzer während desselben Ablaufs inline antworten kann. Stellen Sie standardmäßig eine einzige Frage pro Runde und stellen Sie niemals mehr als zwei auf einmal. Bevorzugen Sie iterative Folgefragen, bei denen jede Antwort die nächste Frage formt, und machen Sie jede Frage sinnvoll nutzbar.
