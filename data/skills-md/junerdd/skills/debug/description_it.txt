Debug runtime basato sull'evidenza per bug dell'applicazione, regressioni, comportamenti instabili ed errori poco chiari. Da utilizzare quando a un agente viene chiesto di eseguire il debug di un problema e deve evitare correzioni speculative formulando ipotesi, collegandosi o avviando una sessione di registrazione, strumentando il codice, raccogliendo log di runtime, analizzando il file di log registrato, applicando solo correzioni comprovate e verificando il risultato prima di rimuovere la strumentazione, in particolare per problemi del browser o del frontend in cui i log devono andare direttamente all'endpoint del raccoglitore attivo anziché alle API proxy locali dell'app.
