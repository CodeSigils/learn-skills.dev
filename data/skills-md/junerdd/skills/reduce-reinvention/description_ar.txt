تحديد ومنع ومعالجة الأخطاء عبر التعليمات البرمجية والمكتبات والخدمات والقوالب والمستندات وسير عمل النظام الأساسي وقرارات الهندسة المعمارية. استخدم عندما يُطلب منك تدقيق عمليات التنفيذ المكررة، أو البحث عن الأصول الحالية القابلة لإعادة الاستخدام قبل البناء، أو تحديد البناء مقابل إعادة الاستخدام/الشراء، أو دمج المكونات/الأدوات/واجهات برمجة التطبيقات المماثلة، أو إنشاء كتالوجات إعادة الاستخدام، أو كتابة خطط ADR/RFC/الترحيل، أو إنشاء مسارات ذهبية/طرق معبدة، أو تحسين قابلية الاكتشاف والملكية والحوكمة للأصول القابلة لإعادة الاستخدام.
