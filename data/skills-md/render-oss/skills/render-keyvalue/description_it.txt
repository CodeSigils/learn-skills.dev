Effettua il provisioning e configura le istanze Render Key Value (Valkey 8 compatibile con Redis) per la memorizzazione nella cache, l'archiviazione delle sessioni e le code dei processi. Da utilizzare quando l'utente ha bisogno di Redis, Key Value, Valkey, una cache, un archivio sessioni, un backend della coda dei processi o deve configurare la policy maxmemory, ipAllowList, stringhe di connessione o accesso interno o esterno. Termini di attivazione: Valore chiave, Redis, Valkey, cache, session store, REDIS_URL, maxmemory, ipAllowList, allkeys-lru, noeviction.
