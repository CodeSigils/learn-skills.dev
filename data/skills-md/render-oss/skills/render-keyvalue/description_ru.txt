Предоставляет и настраивает экземпляры Render Key Value (Redis-совместимые Valkey 8) для кэширования, хранения сеансов и очередей заданий. Используйте, когда пользователю нужны Redis, Key Value, Valkey, кэш, хранилище сеансов, серверная часть очереди заданий или необходимо настроить политику maxmemory, ipAllowList, строки подключения или внутренний или внешний доступ. Условия триггера: значение ключа, Redis, Valkey, кеш, хранилище сеансов, REDIS_URL, maxmemory, ipAllowList, allkeys-lru, noeviction.
