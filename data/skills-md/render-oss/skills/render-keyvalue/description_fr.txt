Provisionne et configure les instances Render Key Value (Valkey 8 compatible Redis) pour la mise en cache, le stockage de session et les files d'attente de tâches. À utiliser lorsque l'utilisateur a besoin de Redis, Key Value, Valkey, d'un cache, d'un magasin de sessions, d'un backend de file d'attente de tâches ou doit configurer la stratégie maxmemory, ipAllowList, les chaînes de connexion ou l'accès interne ou externe. Termes déclencheurs : Key Value, Redis, Valkey, cache, session store, REDIS_URL, maxmemory, ipAllowList, allkeys-lru, noeviction.
