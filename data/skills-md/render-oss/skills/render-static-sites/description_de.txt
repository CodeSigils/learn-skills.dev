Stellt statische Sites im globalen CDN von Render bereit und konfiguriert sie – Build-Befehle, Veröffentlichungspfade, SPA-Routing, Weiterleitungen, benutzerdefinierte Header und PR-Vorschauen. Verwenden Sie diese Option, wenn der Benutzer eine statische Site bereitstellen, ein React/Vue/Hugo/Gatsby-Frontend einrichten, SPA-Fallback-Routing konfigurieren, Umleitungsregeln hinzufügen, Antwortheader anpassen oder zwischen einer statischen Site und einem Webdienst für sein Frontend wählen muss. Auslöserbegriffe: statische Site, CDN, SPA, Single-Page-App, React Deploy, Vue Deploy, Hugo, Gatsby, Docusaurus, Jekyll, staticPublishPath.
