Déploie et configure des sites statiques sur le CDN global de Render : commandes de création, chemins de publication, routage SPA, redirections, en-têtes personnalisés et aperçus PR. À utiliser lorsque l'utilisateur doit déployer un site statique, configurer une interface React/Vue/Hugo/Gatsby, configurer le routage de secours SPA, ajouter des règles de redirection, personnaliser les en-têtes de réponse ou choisir entre un site statique et un service Web pour son interface. Termes déclencheurs : site statique, CDN, SPA, application monopage, déploiement React, déploiement Vue, Hugo, Gatsby, Docusaurus, Jekyll, staticPublishPath.
