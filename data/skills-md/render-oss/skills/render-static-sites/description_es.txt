Implementa y configura sitios estáticos en la CDN global de Render: crea comandos, publica rutas, enrutamiento SPA, redirecciones, encabezados personalizados y vistas previas de relaciones públicas. Úselo cuando el usuario necesite implementar un sitio estático, configurar una interfaz React/Vue/Hugo/Gatsby, configurar el enrutamiento alternativo de SPA, agregar reglas de redireccionamiento, personalizar encabezados de respuesta o elegir entre un sitio estático y un servicio web para su interfaz. Términos de activación: sitio estático, CDN, SPA, aplicación de una sola página, implementación de React, implementación de Vue, Hugo, Gatsby, Docusaurus, Jekyll, staticPublishPath.
