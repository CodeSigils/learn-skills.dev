Configure et optimise Managed PostgreSQL on Render : chaînes de connexion (internes ou externes), contraintes de création, mise à l'échelle automatique du stockage, limites de connexion, haute disponibilité, réplicas en lecture, sauvegardes et inspection MCP. À utiliser lorsque l'utilisateur mentionne Postgres, PostgreSQL, la base de données de rendu, la chaîne de connexion, DATABASE_URL, les sauvegardes, les instantanés, les répliques, la haute disponibilité, le stockage sur disque, le regroupement de connexions ou le dépannage de la connectivité de base de données.
