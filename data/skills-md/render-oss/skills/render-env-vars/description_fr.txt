Configure les variables d'environnement, les secrets et les groupes d'environnement sur Render. À utiliser lorsque l'utilisateur doit définir des variables d'environnement, câbler des secrets entre services, créer des groupes d'environnement, utiliser generateValue, définir sync: false ou dépanner les valeurs de variables d'environnement manquantes ou incorrectes dans les Blueprints ou le tableau de bord.
