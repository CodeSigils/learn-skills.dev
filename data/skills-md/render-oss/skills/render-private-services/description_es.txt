Configura servicios privados de Render: aplicaciones solo internas que aceptan tráfico exclusivamente de otros servicios de Render a través de la red privada. Úselo cuando el usuario necesite una API interna, un microservicio, un servidor gRPC, un sidecar o cualquier servicio que no deba ser accesible públicamente. Úselo también al elegir entre un servicio privado y un trabajador en segundo plano. Términos de activación: servicio privado, pserv, servicio interno, API interna, microservicio, gRPC, servicio de red privada y no pública.
