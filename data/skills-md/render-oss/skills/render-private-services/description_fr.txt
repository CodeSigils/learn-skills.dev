Configure les services privés de Render : des applications internes uniquement qui acceptent le trafic exclusivement provenant d'autres services de Render sur le réseau privé. À utiliser lorsque l'utilisateur a besoin d'une API interne, d'un microservice, d'un serveur gRPC, d'un side-car ou de tout autre service qui ne doit pas être accessible au public. À utiliser également pour choisir entre un service privé et un travailleur en arrière-plan. Termes déclencheurs : service privé, pserv, service interne, API interne, microservice, gRPC, non public, service de réseau privé.
