Installa e utilizza la CLI di rendering per distribuzioni, log, SSH, psql, convalida del progetto e automazione. Da utilizzare quando l'utente deve eseguire comandi CLI di rendering, distribuire script in CI/CD, eseguire l'autenticazione con una chiave API, eseguire query sui servizi in modo non interattivo o risolvere problemi di autenticazione CLI. Termini di attivazione: rendering CLI, rendering login, rendering distribuzioni, rendering log, rendering ssh, rendering psql, convalida di progetti di rendering, competenze di rendering, RENDER_API_KEY, non interattivo, distribuzione CI/CD.
