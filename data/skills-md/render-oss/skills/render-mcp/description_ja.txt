AI コーディング ツール用にレンダー MCP サーバーを接続して構成します。ツールごとのセットアップ (カーソル、クロード コード、コーデックス)、認証、ワークスペースの選択、ツール カタログ、トラブルシューティングを行います。 MCP が設定されていない場合、list_services() が失敗した場合、ユーザーが Render MCP 設定について質問した場合、またはアクション スキルに MCP が必要であるがまだ接続されていない場合に使用します。トリガー用語: MCP、レンダー MCP、list_services、MCP セットアップ、MCP サーバー、OAuth、API キー、ベアラー トークン、mcp.render.com、ワークスペースの選択。
