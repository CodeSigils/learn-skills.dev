Connecte et configure le serveur Render MCP pour les outils de codage d'IA : configuration par outil (Curseur, Code Claude, Codex), authentification, sélection de l'espace de travail, catalogue d'outils et dépannage. À utiliser lorsque MCP n'est pas configuré, que list_services() échoue, que l'utilisateur pose des questions sur la configuration de Render MCP ou qu'une compétence d'action a besoin de MCP mais n'est pas encore connectée. Termes déclencheurs : MCP, Render MCP, list_services, configuration MCP, serveur MCP, OAuth, clé API, jeton Bearer, mcp.render.com, sélection de l'espace de travail.
