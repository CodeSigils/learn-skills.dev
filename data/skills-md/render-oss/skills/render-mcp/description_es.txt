Conecta y configura el servidor Render MCP para herramientas de codificación de IA: configuración por herramienta (Cursor, Claude Code, Codex), autenticación, selección de espacio de trabajo, catálogo de herramientas y resolución de problemas. Úselo cuando MCP no está configurado, list_services() falla, el usuario pregunta sobre la configuración de Render MCP o una habilidad de acción necesita MCP pero aún no está conectada. Términos de activación: MCP, Render MCP, list_services, configuración de MCP, servidor MCP, OAuth, clave API, token de portador, mcp.render.com, selección de espacio de trabajo.
