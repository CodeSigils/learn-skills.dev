يقوم بتوصيل وتكوين خادم Render MCP لأدوات تشفير الذكاء الاصطناعي - الإعداد لكل أداة (المؤشر، Claude Code، Codex)، والمصادقة، واختيار مساحة العمل، وكتالوج الأدوات، واستكشاف الأخطاء وإصلاحها. يُستخدم عندما لا يتم تكوين MCP، أو تفشل list_services()، أو يسأل المستخدم عن إعداد Render MCP، أو تحتاج مهارة الإجراء إلى MCP ولكنها غير متصلة بعد. مصطلحات التشغيل: MCP، وRender MCP، وlist_services، وإعداد MCP، وخادم MCP، وOAuth، ومفتاح API، ورمز Bearer، وmcp.render.com، واختيار مساحة العمل.
