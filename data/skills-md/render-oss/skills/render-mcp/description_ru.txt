Подключает и настраивает сервер Render MCP для инструментов кодирования AI — настройка для каждого инструмента (курсор, код Клода, кодекс), аутентификация, выбор рабочего пространства, каталог инструментов и устранение неполадок. Используйте, когда MCP не настроен, list_services() завершается сбоем, пользователь запрашивает настройку Render MCP или навыку действия требуется MCP, но он еще не подключен. Условия триггера: MCP, Render MCP, list_services, настройка MCP, сервер MCP, OAuth, ключ API, токен носителя, mcp.render.com, выбор рабочей области.
