Connette e configura il server Render MCP per gli strumenti di codifica AI: impostazione per strumento (Cursore, Codice Claude, Codice), autenticazione, selezione dell'area di lavoro, catalogo strumenti e risoluzione dei problemi. Da utilizzare quando MCP non è configurato, list_services() fallisce, l'utente chiede informazioni sulla configurazione di Render MCP o una capacità di azione necessita di MCP ma non è ancora connessa. Termini di attivazione: MCP, Render MCP, list_services, configurazione MCP, server MCP, OAuth, chiave API, token bearer, mcp.render.com, selezione dell'area di lavoro.
