Configura dominios personalizados y certificados TLS en Render: configuración de DNS, registros CNAME, dominios apex, dominios comodín y solución de problemas de certificados. Úselo cuando el usuario necesite agregar un dominio personalizado, configurar DNS, configurar HTTPS/TLS, solucionar problemas de emisión de certificados, deshabilitar el subdominio onrender.com o agregar un dominio comodín. Términos de activación: dominio personalizado, DNS, CNAME, TLS, SSL, HTTPS, certificado, dominio apex, dominio comodín, onrender.com, verificación de dominio.
