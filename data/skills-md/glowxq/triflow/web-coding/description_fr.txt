Spécification de développement front-end Web Triflow. Il comprend le développement de composants Vue 3.5 + Element Plus + TypeScript, les définitions de types d'API, la gestion de l'état Pinia, la table VXE, les directives de style et d'autres conventions de projet. Il doit être suivi lors de l'écriture ou de la modification du code triflow-web.
