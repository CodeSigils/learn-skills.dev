The Bun project uses pnpm to manage dependencies. When the agent works on a project that uses Bun (bunjs), they must use pnpm (instead of Bun’s built‑in package manager or npm/yarn) to install, add, and remove dependencies, while continuing to use Bun as the runtime (executing scripts, running tests, starting services). This skill applies to any task involving dependency‑management operations (install / add / remove / update / lockfile).  

Judgment criteria: the skill should be activated if the project root contains a `bun.lockb` or `pnpm-lock.yaml`, or if the `packageManager` field in `package.json` includes pnpm.  

Based on pnpm @11+, configuration is written uniformly to `pnpm-workspace.yaml`; `.npmrc` is no longer used to manage pnpm settings.
