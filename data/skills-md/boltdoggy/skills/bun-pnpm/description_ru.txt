Проект Bun использует pnpm для управления зависимостями. Когда агент работает над проектом, в котором используется Bun (bunjs), он должен использовать pnpm (вместо встроенного менеджера пакетов Bun или npm/yarn) для установки, добавления и удаления зависимостей, продолжая при этом использовать Bun в качестве среды выполнения (выполнение сценариев, запуск тестов, запуск служб). Этот навык применим к любой задаче, включающей операции управления зависимостями (установка/добавление/удаление/обновление/файл блокировки).  

Критерии оценки: навык следует активировать, если корень проекта содержит `bun.lockb` или `pnpm-lock.yaml`, или если поле `packageManager` в `package.json` включает pnpm.  

На основе pnpm@11+ конфигурация единообразно записывается в `pnpm-workspace.yaml`; `.npmrc` больше не используется для управления настройками pnpm.
