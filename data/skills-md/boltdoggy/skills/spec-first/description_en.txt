Requirement clarification and prototype confirmation skill. When an agent receives tasks such as feature development, UI design, or system refactoring, they must first clarify the requirements and confirm the prototype/solution, obtaining explicit user approval before moving into the coding phase. This skill applies to any tasks involving new features, new interfaces, new processes, or architectural adjustments, and does not apply to one‑line fixes, typos, clear bug fixes, or other tasks with a well‑defined intent.
