Compétence d’exécution du document selon le premier principe. Lorsqu'un agent participe à ce projet, il doit adhérer au principe du document d'abord stipulé par cette compétence : rédiger d'abord la documentation, puis coder ; les modifications de code doivent être synchronisées avec les mises à jour de la documentation ; toute fonctionnalité sans documentation est considérée comme incomplète. Cette compétence s'applique à toutes les tâches impliquant des modifications de code, des ajouts de nouvelles fonctionnalités, des modifications d'interface ou des ajustements architecturaux.
