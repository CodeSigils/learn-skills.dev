Fertigkeit „Entwicklungsabschlussakzeptanz“. Wenn der Agent eine Entwicklungsaufgabe (Funktionsentwicklung, Fehlerbehebung, Refactoring, Konfigurationsänderung usw.) als abgeschlossen erachtet, muss vor der Übermittlung oder Erklärung des Abschlusses eine systematische Abnahme durchgeführt werden, bei der die Codequalität, der Testdurchlauf, die Anforderungserfüllung, die Dokumentationssynchronisierung und das Fehlen eines Regressionsrisikos Punkt für Punkt bestätigt werden. Die Abnahmemethoden werden je nach Projekttyp (CLI / Web / Server) unterschieden und verfügen jeweils über eine eigene Checkliste. Diese Fähigkeit gilt für die letzte Phase jeder Aufgabe, die Codeänderungen beinhaltet. Beurteilungskriterium: Wenn der Agent im Begriff ist, „Fertig“ zu sagen oder Code einzureichen, sollte diese Fähigkeit aktiviert werden.
