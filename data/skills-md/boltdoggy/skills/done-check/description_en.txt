Development Completion Acceptance skill. When the agent deems a development task (feature development, bug fix, refactoring, configuration change, etc.) to be finished, a systematic acceptance must be performed before submitting or declaring completion, confirming code quality, test pass, requirement fulfillment, documentation synchronization, and absence of regression risk item by item. Acceptance methods are differentiated by project type (CLI / Web / Server), each with its own checklist. This skill applies to the final stage of any task involving code changes. Judgment criterion: when the agent is about to say “done” or to submit code, this skill should be activated.
