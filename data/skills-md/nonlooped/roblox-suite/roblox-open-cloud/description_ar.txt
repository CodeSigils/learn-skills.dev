Roblox Open Cloud REST API للوصول إلى مخازن البيانات والأصول والأكوان والأماكن والمستخدمين والمجموعات والاشتراكات وتنفيذ Luau من خارج المحرك أو عبر HttpService. يغطي المصادقة (مفاتيح API، OAuth 2.0، تجنب مصادقة ملفات تعريف الارتباط القديمة)، والنطاقات والامتيازات الأقل، وقوائم IP المسموح بها، وتدوير المفاتيح وقاعدة انتهاء الصلاحية التلقائي لمدة 60 يومًا، ومخازن الأسرار، والمجموعة الفرعية القابلة للاستدعاء HttpService وحدود معدلاتها، وخطافات الويب، وشجرة القرار داخل المحرك مقابل Open Cloud. يُستخدم للأتمتة الخارجية، وCI/CD، والبيانات المجمعة، واللقطات المجدولة، والأدوات المشتركة بين الخبرات.
