Roblox オープン クラウド REST API は、エンジンの外部からまたは HttpService 経由でデータ ストア、アセット、ユニバース、場所、ユーザー、グループ、サブスクリプション、および Luau 実行にアクセスするための API です。認証 (API キー、OAuth 2.0、レガシー Cookie 認証の回避)、スコープと最小特権、IP ホワイトリスト、キーのローテーションと 60 日間の自動有効期限ルール、シークレット ストア、HttpService 呼び出し可能なサブセットとそのレート制限、Webhook、およびエンジン内 vs オープン クラウド デシジョン ツリーについて説明します。外部自動化、CI/CD、バルクデータ、スケジュールされたスナップショット、クロスエクスペリエンスツールに使用します。
