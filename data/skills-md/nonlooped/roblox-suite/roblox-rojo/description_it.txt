Gestione progetti Rojo per Roblox: installa CLI e plugin Studio, init/serve/build/upload/sourcemap/syncback, formato `.project.json`, regole di sincronizzazione da file a istanza (`.luau`/`.server.luau`/`.client.luau`/`.plugin.luau`), meta file, `emitLegacyScripts`, limiti di sincronizzazione live e porting di luoghi esistenti. Da utilizzare durante la configurazione di Rojo, la scrittura di file di progetto, la sincronizzazione dal vivo con Studio, la creazione di luoghi/modelli o la conversione di un luogo con syncback.
