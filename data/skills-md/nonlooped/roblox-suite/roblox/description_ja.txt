Roblox Luau 開発ハブは、エージェントを適切な専門スキルに導き、すべての API 推奨事項を公式エンジン リファレンスに引用したままにします。サーバー権限アーキテクチャ、最新の API の選択 (Animator、task.*、TweenService、IKControl)、およびデータストア、ネットワーキング、UI、アニメーション、VFX、オーディオ、物理学、NPC、収益化、オープン クラウド、テレポーテーション、テスト、Rojo、Studio MCP にわたる深いスキルへの段階的な開示をカバーします。特殊なスキルをロードする前に、Roblox タスクのエントリ ポイントとして使用します。
