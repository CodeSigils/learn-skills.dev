Roblox TeleportService и многоместная архитектура — современный API TeleportAsync, который заменяет устаревшие варианты Teleport/TeleportPartyAsync/TeleportToPrivateServer. Охватывает TeleportOptions, зарезервированные серверы через ReserveServerAsync, ограничение группы в 50 игроков, ограничения перекрестного опыта, данные телепортации (и предупреждение о подделке безопасности клиента), настраиваемые экраны загрузки, передачу хранилища данных и подбор игроков с помощью MessagingService/MemoryStoreService. Используйте при перемещении игроков между местами, серверами или зарезервированными серверами.
