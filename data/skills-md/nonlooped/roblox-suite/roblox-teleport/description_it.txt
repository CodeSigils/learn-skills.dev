Roblox TeleportService e architettura multiposto: la moderna API TeleportAsync che sostituisce le varianti Teleport/TeleportPartyAsync/TeleportToPrivateServer deprecate. Copre TeleportOptions, server riservati tramite ReserveServerAsync, limite di gruppo di 50 giocatori, restrizioni tra esperienze diverse, dati di teletrasporto (e il relativo avvertimento di sicurezza falsificabile dal client), schermate di caricamento personalizzate, trasferimento di DataStore e matchmaking con MessagingService/MemoryStoreService. Da utilizzare ogni volta che si spostano i giocatori tra luoghi, server o server riservati.
