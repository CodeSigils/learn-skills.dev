Affichage des abonnements aux comptes X (Twitter) et récupération de contenu (basés sur le service Mp2rss qui convertit les comptes X en RSS) : liste des comptes X abonnés, récupération des flux de tweets (posts) et des flux d'articles (articles) par xUserId. Correspond aux requêtes telles que « À quels comptes X suis-je abonné ? », « Liste de mes abonnements X », « Qu'est-ce que ce compte X a publié récemment ? ⚠️ La CLI n'expose que trois commandes en lecture seule ; Les actions « rechercher / s'abonner / se désabonner » du compte X ne sont disponibles que dans la console Web (<https://mp2rss.bugcode.dev>), et ni la CLI ni l'Open API ne fournissent ces points de terminaison d'écriture — lorsque les utilisateurs demandent une telle fonctionnalité, ils doivent être dirigés vers la console Web plutôt que de rechercher « x s'abonner / x supprimer / x rechercher » (qui n'existent pas).
