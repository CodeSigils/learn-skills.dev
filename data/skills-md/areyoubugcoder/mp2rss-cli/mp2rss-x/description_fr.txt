Affichage des abonnements aux comptes X (Twitter) et récupération de contenu (basés sur le service Mp2rss qui convertit les comptes X en RSS) : liste des comptes X abonnés, récupération des flux de tweets (posts) et des flux longs (articles) par xUserId. Correspond aux requêtes telles que « À quels comptes X suis-je abonné ? », « Liste de mes abonnements X », « Qu'est-ce que ce compte X a publié récemment ? », « Récupérer les tweets de <xUserId> », « Les longs articles de <xUserId> », « Articles du compte X <id> », « mp2rss x liste/posts/articles ». ⚠️ La CLI expose uniquement les trois opérations en lecture seule ; les actions « rechercher / s'abonner / se désinscrire » du compte X sont uniquement disponibles dans la console web (<https://mp2rss.bugcode.dev>). Ni la CLI ni l'Open API ne fournissent ces points de terminaison d'écriture — lorsque les utilisateurs demandent une telle fonctionnalité, ils doivent être dirigés vers la console Web plutôt que de rechercher « x Subscribe / x Remove / x Search » (qui n'existent pas).
