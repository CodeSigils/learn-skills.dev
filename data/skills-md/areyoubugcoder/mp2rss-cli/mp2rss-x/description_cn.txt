X (Twitter) 帐户订阅查看和内容获取（基于将 X 帐户转换为 RSS 的 Mp2rss 服务）— 列出订阅的 X 帐户，按 xUserId 对推文流（帖子）和长格式流（文章）进行分页获取。匹配诸如“我订阅了哪些 X 帐户？”、“列出我的 X 订阅”、“这个 X 帐户最近发布了什么？”、“获取 <xUserId> 的推文”、“<xUserId> 的长文章”、“X 帐户 <id> 文章”、“mp2rss x 列表/帖子/文章”等查询。 ⚠️ CLI 仅公开三个只读操作； X 帐户“搜索/订阅/取消订阅”操作仅在 Web 控制台 (<https://mp2rss.bugcode.dev>) 中可用。 CLI 和 Open API 都不提供这些写入端点——当用户请求此类功能时，他们应该被定向到 Web 控制台，而不是寻找“x subscribe / x remove / x search”（这些功能不存在）。
