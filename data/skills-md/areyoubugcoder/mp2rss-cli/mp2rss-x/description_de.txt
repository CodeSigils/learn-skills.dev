Anzeigen von X-Kontoabonnements (Twitter) und Abrufen von Inhalten (basierend auf dem Mp2rss-Dienst, der X-Konten in RSS umwandelt) – abonnierte X-Konten auflisten, paginierender Abruf von Tweet-Streams (Beiträgen) und langen Streams (Artikeln) nach xUserId. Entspricht Abfragen wie „Welche X-Konten habe ich abonniert?“, „Meine X-Abonnements auflisten“, „Was hat dieses ⚠️ Die CLI macht die drei schreibgeschützten Vorgänge nur verfügbar; Die Aktionen „Suchen / Abonnieren / Abbestellen“ des X-Kontos sind nur in der Webkonsole (<https://mp2rss.bugcode.dev>) verfügbar. Weder die CLI noch die Open API bieten diese Schreibendpunkte – wenn Benutzer eine solche Funktionalität anfordern, sollten sie an die Webkonsole weitergeleitet werden, anstatt nach „x subscribe / x remove / x search“ zu suchen (die es nicht gibt).
