Anzeigen von X-Kontoabonnements (Twitter) und Abrufen von Inhalten (basierend auf dem Mp2rss-Dienst, der X-Konten in RSS umwandelt) – abonnierte Entspricht Abfragen wie „Welche X-Konten habe ich abonniert“, „Listen Sie meine X-Abonnements auf“, „Was hat dieses ⚠️ Die CLI stellt nur drei schreibgeschützte Vorgänge zur Verfügung; Die Funktionen „Suchen / Abonnieren / Abbestellen“ des X-Kontos sind nur in der Webkonsole (https://mp2rss.bugcode.dev) verfügbar. Weder die CLI noch die Open API bieten diese Schreibendpunkte – wenn Benutzer eine solche Funktionalität anfordern, sollten sie an die Webkonsole weitergeleitet werden, anstatt nach „x subscribe / x remove / x search“ zu suchen (die es nicht gibt).
