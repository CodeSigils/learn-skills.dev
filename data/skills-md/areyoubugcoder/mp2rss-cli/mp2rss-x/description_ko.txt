X(Twitter) 계정 구독 보기 및 콘텐츠 가져오기(X 계정을 RSS로 변환하는 Mp2rss 서비스 기반) - 구독한 X 계정 목록, xUserId를 통한 트윗 스트림(게시물) 및 긴 형식 스트림(기사)의 페이지 매기기 가져오기. "내가 구독한 X 계정은 무엇입니까?", "내 X 구독 목록", "이 X 계정이 최근에 게시한 내용은 무엇입니까?", "<xUserId>의 트윗 가져오기", "<xUserId>의 긴 기사", "X 계정 <id> 기사", "mp2rss x 목록/게시물/기사"와 같은 쿼리와 일치합니다. ⚠️ CLI는 세 가지 읽기 전용 작업만 노출합니다. X 계정의 “검색/구독/구독 취소” 작업은 웹 콘솔(<https://mp2rss.bugcode.dev>)에서만 사용할 수 있습니다. CLI나 Open API 모두 이러한 쓰기 엔드포인트를 제공하지 않습니다. 사용자가 이러한 기능을 요청할 때 'x subscribe / x Remove / x search'(존재하지 않음)를 찾는 대신 웹 콘솔로 연결되어야 합니다.
