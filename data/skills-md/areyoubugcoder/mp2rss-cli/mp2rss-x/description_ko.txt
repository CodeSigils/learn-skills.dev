X(Twitter) 계정 구독 보기 및 콘텐츠 가져오기(X 계정을 RSS로 변환하는 Mp2rss 서비스 기반) — 구독한 X 계정 목록을 나열하고, xUserId를 통해 트윗 스트림(게시물) 및 긴 기사 스트림(기사)을 페이지별로 가져옵니다. "내가 구독한 X 계정은 무엇입니까?", "내 X 구독 목록", "이 X 계정이 최근에 게시한 내용은 무엇입니까?", "<xUserId>에서 트윗 가져오기", "<xUserId>의 긴 기사", "X 계정 <id> 기사", "mp2rss x 목록/게시물/기사"와 같은 쿼리와 일치합니다. ⚠️ CLI는 읽기 전용 명령 3개만 표시합니다. X 계정의 “검색/구독/구독 취소” 작업은 웹 콘솔(https://mp2rss.bugcode.dev)에서만 사용할 수 있습니다. CLI나 Open API는 이러한 쓰기 엔드포인트를 제공하지 않습니다. 사용자가 이러한 기능을 요청하면 'x 구독 / x 제거 / x 검색'(존재하지 않음)을 찾는 대신 웹 콘솔로 안내하세요.
