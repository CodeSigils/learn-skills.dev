عرض الاشتراك في حساب X (Twitter) وجلب المحتوى (استنادًا إلى خدمة Mp2rss التي تحول حسابات X إلى RSS) - قم بإدراج حسابات X المشتركة، وجلب صفحات تدفقات التغريدات (المشاركات) والتدفقات الطويلة (المقالات) بواسطة xUserId. يطابق استعلامات مثل "ما هي حسابات X التي اشتركت فيها؟"، "أدرج اشتراكاتي X"، "ما الذي نشره حساب X هذا مؤخرًا؟"، "جلب تغريدات <xUserId>"، "مقالات <xUserId> الطويلة"، "مقالات حساب X <id>"، "قائمة / منشورات / مقالات mp2rss x". ⚠️ تعرض واجهة سطر الأوامر (CLI) فقط العمليات الثلاث للقراءة فقط؛ إجراءات "البحث / الاشتراك / إلغاء الاشتراك" الخاصة بحساب X متاحة فقط في وحدة تحكم الويب (<https://mp2rss.bugcode.dev>). لا توفر واجهة سطر الأوامر (CLI) ولا Open API نقاط نهاية الكتابة هذه - عندما يطلب المستخدمون مثل هذه الوظيفة، يجب توجيههم إلى وحدة تحكم الويب بدلاً من البحث عن `x الاشتراك / x إزالة / x البحث` (التي لا وجود لها).
