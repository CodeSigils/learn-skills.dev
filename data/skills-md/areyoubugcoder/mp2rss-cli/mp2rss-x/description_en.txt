X (Twitter) account subscription viewing and content fetching (based on the Mp2rss service that converts X accounts to RSS) — list subscribed X accounts, paginate fetching of tweet streams (posts) and long‑form streams (articles) by xUserId. Matches queries like “Which X accounts have I subscribed to?”, “List my X subscriptions”, “What has this X account posted recently?”, “Fetch <xUserId>'s tweets”, “<xUserId>'s long articles”, “X account <id> articles”, “mp2rss x list / posts / articles”. ⚠️ The CLI only exposes the three read‑only operations; the X account “search / subscribe / unsubscribe” actions are only available in the web console (<https://mp2rss.bugcode.dev>). Neither the CLI nor the Open API provide these write endpoints — when users request such functionality, they should be directed to the web console rather than looking for `x subscribe / x remove / x search` (which do not exist).
