X (Twitter) 帳戶訂閱檢視和內容擷取（基於將 X 帳戶轉換為 RSS 的 Mp2rss 服務） — 列出訂閱的 X 帳戶，按 xUserId 對推文串流（貼文）和文章串流（文章）進行分頁。符合「我訂閱了哪些 X 帳號」、「列出我的 X 訂閱」、「這個 X 帳號最近發布了什麼」、「取得 <xUserId> 的推文」、「<xUserId> 的文章」、「X 帳號 <id> 文章」、「mp2rss x 清單/貼文/文章」等查詢。 ⚠️ CLI 僅公開三個唯讀命令； X 帳戶的“搜尋/訂閱/取消訂閱”功能僅在 Web 控制台 (<https://mp2rss.bugcode.dev>) 中可用，並且 CLI 或 Open API 中沒有寫入類型端點 - 當用戶請求此類功能時，他們應該被定向到 Web 控制台，而不是查找“x scem”。
