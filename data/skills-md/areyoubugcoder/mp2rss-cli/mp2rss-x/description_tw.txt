X (Twitter) 帳戶訂閱檢視和內容取得（基於將 X 帳戶轉換為 RSS 的 Mp2rss 服務）— 列出訂閱的 X 帳戶，按 xUserId 對推文串流（貼文）和長格式串流（文章）進行分頁取得。符合「我訂閱了哪些 X 帳號？」、「列出我的 X 訂閱」、「這個 X 帳號最近發布了什麼？」、「取得 <xUserId> 的推文」、「<xUserId> 的長文章」、「X 帳號 <id> 文章」、「mp2rss x 查詢清單/貼文/文章」等查詢清單/文章/文章」等查詢清單/文章/文章」等。 ⚠️ CLI 僅公開三個唯讀操作； X 帳戶「搜尋/訂閱/取消訂閱」操作僅在 Web 控制台 (<https://mp2rss.bugcode.dev>) 中可用。 CLI 和 Open API 都不提供這些寫入端點——當使用者要求此類功能時，他們應該被導向到 Web 控制台，而不是尋找「x subscribe / x remove / x search」（這些功能不存在）。
