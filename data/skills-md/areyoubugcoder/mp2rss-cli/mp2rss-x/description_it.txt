Visualizzazione e recupero dei contenuti dell'abbonamento all'account X (Twitter) (basato sul servizio Mp2rss che converte gli account X in RSS): elenca gli account X sottoscritti, impagina il recupero dei flussi di tweet (post) e dei flussi di formato lungo (articoli) in base a xUserId. Corrisponde a query come "A quali X account mi sono iscritto?", "Elenca le mie X iscrizioni", "Cosa ha pubblicato di recente questo account X?", "Recupera i tweet di <xUserId>", "Articoli lunghi di <xUserId>", "Articoli di account X <id>", "elenco/post/articoli x mp2rss". ⚠️ La CLI espone solo le tre operazioni di sola lettura; le azioni “cerca/iscriviti/annulla iscrizione” dell'account X sono disponibili solo nella console web (<https://mp2rss.bugcode.dev>). Né la CLI né l'Open API forniscono questi endpoint di scrittura: quando gli utenti richiedono tale funzionalità, dovrebbero essere indirizzati alla console web anziché cercare "x Subscribe / x Remove / x Search" (che non esiste).
