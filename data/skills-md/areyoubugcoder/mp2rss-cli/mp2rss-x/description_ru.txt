Просмотр подписки на учетную запись X (Twitter) и получение контента (на основе службы Mp2rss, которая преобразует учетные записи X в RSS) — список подписанных учетных записей X, разбиение на страницы потоков твитов (сообщений) и потоков длинных статей (статей) по xUserId. Соответствует «на какие аккаунты X я подписан», «перечислить мои подписки X», «что недавно опубликовал этот аккаунт X», «получить твиты <xUserId>», «длинные статьи <xUserId>», «статьи аккаунта X <id>», «mp2rss x list/posts/articles». ⚠️ Интерфейс командной строки предоставляет только три функции только для чтения; Действия «поиск/подписка/отписка» учетной записи X доступны только в веб-консоли (<https://mp2rss.bugcode.dev>); CLI и Open API не имеют таких конечных точек записи — когда пользователи запрашивают эти функции, направляйте их к веб-консоли, а не ищите `x subscribe/x удалить/x search` (которых не существует).
