Просмотр подписки на учетную запись X (Twitter) и получение контента (на основе службы Mp2rss, которая преобразует учетные записи X в RSS) — список подписанных учетных записей X, постраничная выборка потоков твитов (сообщений) и длинных потоков (статей) по xUserId. Соответствует таким запросам, как «На какие учетные записи X я подписан?», «Составьте список моих подписок X», «Что недавно опубликовал этот аккаунт X?», «Получить твиты <xUserId>», «длинные статьи <xUserId>», «Статьи учетной записи X <id>», «mp2rss x list/posts/articles». ⚠️ Интерфейс командной строки предоставляет только три операции только для чтения; действия «поиск/подписка/отписка» учетной записи X доступны только в веб-консоли (<https://mp2rss.bugcode.dev>). Ни CLI, ни Open API не предоставляют эти конечные точки записи — когда пользователи запрашивают такую ​​функциональность, их следует направлять в веб-консоль, а не искать `x subscribe/x удалить/x search` (которых не существует).
