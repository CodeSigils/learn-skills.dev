X (Twitter) アカウントのサブスクリプションの表示とコンテンツの取得 (X アカウントを RSS に変換する Mp2rss サービスに基づく) — サブスクライブされた X アカウントのリスト、xUserId によるツイート ストリーム (投稿) と記事ストリーム (記事) のページネーションの取得。 「どの X アカウントが購読していますか?」、「X 購読のリスト」、「この X アカウントは最近何を投稿しましたか?」、「<xUserId> からツイートを取得」、「<xUserId> 記事」、「X アカウント <id> 記事」、「mp2rss x リスト / 投稿 / 記事」などのクエリに一致します。 ⚠️ CLI は 3 つの読み取り専用操作のみを公開します。 X アカウントの「検索 / サブスクライブ / アンサブスクライブ」機能は、Web コンソール (<https://mp2rss.bugcode.dev>) でのみ使用でき、CLI も Open API もこれらの書き込みエンドポイントを提供しません。ユーザーがそのようなアクションを要求した場合、「x submit / x delete / x search」(存在しない) を探すのではなく、Web コンソールに誘導される必要があります。
