X (Twitter) アカウントのサブスクリプションの表示とコンテンツの取得 (X アカウントを RSS に変換する Mp2rss サービスに基づく) — サブスクライブされた X アカウントのリスト、ツイート ストリーム (投稿) および長文ストリーム (記事) のページ分割取得を xUserId で行います。 「私が購読している X アカウントはどれですか?」、「私の X 購読をリストします」、「この X アカウントは最近何を投稿しましたか?」、「<xUserId> のツイートを取得する」、「<xUserId> の長い記事」、「X アカウント <id> の記事」、「mp2rss x リスト / 投稿 / 記事」などのクエリに一致します。 ⚠️ CLI は 3 つの読み取り専用操作のみを公開します。 X アカウントの「検索 / 購読 / 購読解除」アクションは、Web コンソール (<https://mp2rss.bugcode.dev>) でのみ使用できます。 CLI も Open API もこれらの書き込みエンドポイントを提供しません。ユーザーがそのような機能をリクエストした場合、「x submit / x replace / x search」（存在しない）を探すのではなく、Web コンソールに誘導される必要があります。
