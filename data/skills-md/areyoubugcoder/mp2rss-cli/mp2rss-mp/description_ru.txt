Подписка на общедоступные учетные записи WeChat и управление статьями (на основе службы Mp2rss, которая превращает общедоступные учетные записи в RSS) — подписка/список/отмена подписки на общедоступные учетные записи WeChat, запрос исторических статей общедоступной учетной записи и нечеткий поиск подписанных источников по ключевому слову. Распознаваемые команды включают в себя «подписаться на эту общедоступную учетную запись <URL-адрес статьи>», «преобразовать эту общедоступную учетную запись в RSS», «подписаться на <mp.weixin.qq.com/s/...>», «на какие общедоступные учетные записи я подписался», «перечислить RSS моей общедоступной учетной записи», «что недавно опубликовало эту общедоступную учетную запись», «исторические статьи <некоторая общедоступная учетная запись>», «извлечь статьи из <некоторая общедоступная учетная запись>», «отказаться от подписки <некоторая общедоступная учетная запись>», «удалить <некоторая общедоступная учетная запись> из подписок», «поищите в моих подписанных общедоступных учетных записях <какое-то ключевое слово>» и «mp2rss mp list/search/подписаться/удалить/статьи». При подписке в качестве входных данных используется URL-адрес статьи общедоступной учетной записи (mp.weixin.qq.com/s/...), а не само имя учетной записи. ⚠️ Обрабатывать только семантику «публичной учетной записи WeChat»; вместо этого упоминания об «аккаунте X/Twitter/xUserId/длинных статьях/твитах» следует направлять на mp2rss‑x.
