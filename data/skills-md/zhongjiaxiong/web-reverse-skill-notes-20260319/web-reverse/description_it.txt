Competenze di reverse engineering del front-end web: utilizzate per invertire la logica JS/WASM del front-end web, deoffuscamento/unpacking, analisi dei bundle (Webpack/Vite/Rollup), ripristino del bytecode JS‑VM/VM personalizzato, WebCrypto/crittografia personalizzata e riproduzione dell'algoritmo di firma API, ricostruzione della mappa sorgente, bypass anti-debugging del browser, riproduzione di protocollo/richiesta e sfide Web CTF. Ogni volta che un utente menziona "invertire un sito Web / recuperare firma o parametri di crittografia / ripristinare la logica JS / capture‑replay / VM / WASM / ob‑fuscator / JSFuck / eval‑pack” deve essere attivato. Questa competenza non è destinata allo sviluppo front-end/ottimizzazione delle prestazioni/insegnamento generale della crittografia/scansione di penetrazione/reverse engineering Android.
