Generieren Sie eine wirklich schöne, markengerechte Benutzeroberfläche anstelle von generischem „KI-Schlapp“ – verwenden Sie sie immer dann, wenn der Benutzer eine Benutzeroberfläche, eine Zielseite, ein Dashboard, einen App-Bildschirm oder eine Komponente erstellen, entwerfen, gestalten oder verbessern möchte, wenn ein PRD/eine Spezifikation vor der Implementierung einen Entwurfsdurchlauf benötigt, wenn der Benutzer Referenzbilder/Pinterest-/Dribbble-Links einfügt und möchte, dass die App so aussieht, oder wenn sich der Benutzer beschwert, dass die von der KI generierte Benutzeroberfläche generisch, langweilig, schablonenhaft oder „wie alle anderen“ aussieht andere KI-App.“ Stellen Sie sicher, dass dies auch dann ausgelöst wird, wenn der Benutzer nicht explizit „Design“ sagt – Formulierungen wie „Lass das gut aussehen“, „Erstelle das Frontend für Löst außerdem auf zwei Verben aus: „studieren“/„das Aussehen eines Referenz-Screenshots oder einer Referenz-URL extrahieren“ und „prüfen“/„überprüfen“/„warum sieht das aus?“ zur Kritik der vorhandenen Benutzeroberfläche.
