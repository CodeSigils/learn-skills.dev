Genere una interfaz de usuario genuinamente hermosa y de marca en lugar de un "descuido de IA" genérico: úselo cada vez que el usuario solicite crear, diseñar, diseñar o mejorar una interfaz de usuario, una página de inicio, un tablero, una pantalla de aplicación o un componente, siempre que un PRD/especificaciones necesite un pase de diseño antes de su implementación, cada vez que el usuario pegue imágenes de referencia/enlaces de Pinterest/Dribbble y quiera que la aplicación se parezca a ellos, o cuando el usuario se queje de que la interfaz de usuario generada por IA parece genérica, aburrida, sencilla o "como cualquier otra IA". aplicación." Asegúrese de activar esto incluso si el usuario no dice "diseñar" explícitamente; frases como "haga que esto se vea bien", "construya la interfaz para X", "esto se parece a cualquier otro sitio SaaS" o "coincida con este ambiente" califican.
