À utiliser lorsque l'utilisateur souhaite se connecter, interroger ou explorer une source de données via un pilote CData via la ligne de commande. Cela inclut : créer ou tester une connexion à un système d'entreprise (Salesforce, NetSuite, Snowflake, SQL Server, Jira, etc.) ; exécuter des requêtes SQL sur les données connectées ; explorer le schéma (répertorier les tables, les colonnes ou les procédures stockées) ; exécuter des procédures stockées spécifiques à la source ; et télécharger, installer ou activer les pilotes CData. Agit comme base préalable à toutes les compétences cdata au niveau du pilote (cdata-salesforce, cdata-airtable, etc.) qui ajoutent des conseils spécifiques à la source.
