Verwenden Sie diese Option, wenn der Benutzer über einen CData-Treiber über die Befehlszeile eine Verbindung zu einer Datenquelle herstellen, diese abfragen oder erkunden möchte. Dazu gehört: Erstellen oder Testen einer Verbindung zu einem Unternehmenssystem (Salesforce, NetSuite, Snowflake, SQL Server, Jira usw.); Ausführen von SQL-Abfragen für verbundene Daten; Erkunden von Schemata (Auflisten von Tabellen, Spalten oder gespeicherten Prozeduren); Ausführen quellenspezifischer gespeicherter Prozeduren; und Herunterladen, Installieren oder Aktivieren von CData-Treibern. Fungiert als Voraussetzung für alle cdata-Skills auf Treiberebene (cdata-salesforce, cdata-airtable usw.), die quellenspezifische Anleitungen hinzufügen.
