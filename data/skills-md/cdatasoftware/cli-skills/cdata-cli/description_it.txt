Da utilizzare quando l'utente desidera connettersi, interrogare o esplorare un'origine dati tramite un driver CData tramite la riga di comando. Ciò include: creare o testare una connessione a un sistema aziendale (Salesforce, NetSuite, Snowflake, SQL Server, Jira, ecc.); eseguire query SQL sui dati connessi; esplorare lo schema (elencare tabelle, colonne o procedure memorizzate); esecuzione di procedure memorizzate specifiche dell'origine; e scaricare, installare o attivare i driver CData. Funge da prerequisito per tutte le competenze cdata a livello di driver (cdata-salesforce, cdata-airtable, ecc.) che aggiungono indicazioni specifiche per l'origine.
