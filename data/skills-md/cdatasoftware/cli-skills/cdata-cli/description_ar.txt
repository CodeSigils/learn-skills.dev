يُستخدم عندما يريد المستخدم الاتصال بمصدر بيانات أو الاستعلام عنه أو استكشافه من خلال برنامج تشغيل CData عبر سطر الأوامر. يتضمن ذلك: إنشاء أو اختبار اتصال بنظام مؤسسي (Salesforce، وNetSuite، وSnowflake، وSQL Server، وJira، وما إلى ذلك)؛ تشغيل استعلامات SQL مقابل البيانات المتصلة؛ استكشاف المخطط (سرد الجداول أو الأعمدة أو الإجراءات المخزنة)؛ وتنفيذ الإجراءات المخزنة الخاصة بالمصدر؛ وتنزيل أو تثبيت أو تنشيط برامج تشغيل CData. يعمل كأساس أساسي لجميع مهارات cdata على مستوى السائق (cdata-salesforce، cdata-airtable، وما إلى ذلك) التي تضيف إرشادات خاصة بالمصدر.
