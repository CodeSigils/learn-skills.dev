Используйте, когда пользователь хочет подключиться, запросить или изучить источник данных через драйвер CData через командную строку. Сюда входит: создание или тестирование подключения к корпоративной системе (Salesforce, NetSuite, Snowflake, SQL Server, Jira и т. д.); выполнение SQL-запросов к подключенным данным; изучение схемы (перечисление таблиц, столбцов или хранимых процедур); выполнение хранимых процедур, специфичных для источника; и загрузка, установка или активация драйверов CData. Выступает в качестве необходимой основы для всех навыков работы с данными на уровне водителя (cdata-salesforce, cdata-airtable и т. д.), которые добавляют рекомендации для конкретного источника.
