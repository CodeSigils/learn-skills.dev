Úselo cuando el usuario desee conectarse, consultar o explorar una fuente de datos a través de un controlador CData a través de la línea de comando. Esto incluye: crear o probar una conexión a un sistema empresarial (Salesforce, NetSuite, Snowflake, SQL Server, Jira, etc.); ejecutar consultas SQL contra datos conectados; explorar esquemas (enumerar tablas, columnas o procedimientos almacenados); ejecutar procedimientos almacenados de fuente específica; y descargar, instalar o activar controladores CData. Actúa como requisito previo para todas las habilidades de cdata a nivel del controlador (cdata-salesforce, cdata-airtable, etc.) que agregan orientación específica de la fuente.
