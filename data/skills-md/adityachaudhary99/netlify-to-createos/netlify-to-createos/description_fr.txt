Migrez les applications Web de Netlify vers CreateOS. Analyse netlify.toml, mappe les paramètres de construction, les variables d'environnement, les redirections, les en-têtes et les fonctions. Utilisez cette compétence lorsque l'utilisateur mentionne la migration depuis Netlify, quitter Netlify, quitter Netlify, passer de Netlify, netlify.toml, les alternatives Netlify, remplacer Netlify, Netlify est trop cher, les temps d'arrêt de Netlify ou le déploiement d'un projet Netlify ailleurs. N'utilisez PAS cette compétence pour des projets flambant neufs qui n'ont jamais été sur Netlify – utilisez plutôt la compétence de base createos.
