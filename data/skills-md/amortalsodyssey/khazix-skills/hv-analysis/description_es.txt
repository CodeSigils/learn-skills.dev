El análisis horizontal-vertical (análisis H-V) es una habilidad de investigación profunda propuesta por Digital Life Khazix, que integra el análisis diacrónico-sincrónico de Saussure, el diseño de investigación transversal longitudinal de las ciencias sociales, la metodología de estudio de casos de las escuelas de negocios y los conceptos básicos del análisis de estrategias competitivas.

Úselo cuando los usuarios quieran estudiar sistemáticamente un producto, empresa, concepto, tecnología o persona. El núcleo es el análisis de doble eje: el eje vertical rastrea el viaje completo de la vida desde el nacimiento hasta el presente (presentado como una narración narrativa), el eje horizontal realiza una comparación transversal sistemática con competidores/pares en el momento presente y, finalmente, cruza ambos ejes para producir conocimientos únicos. El resultado final es un informe de investigación en PDF bellamente formateado.

Las palabras desencadenantes incluyen, entre otras: análisis horizontal-vertical, investigar esto, ayúdame a analizar, investigación profunda, hacer un estudio, investigar, análisis competitivo, ayúdame a ver cómo es esto, cuál es el problema con este producto/empresa/concepto, ayúdame a resolver esto, ayúdame a comprender, ayúdame a hacer una investigación profunda.

Incluso si los usuarios simplemente dicen "ayúdenme a entender XX" o "cuáles son los antecedentes de XX", siempre que el contexto implique la necesidad de una investigación profunda y sistemática (en lugar de una simple explicación conceptual), se debe activar. También se aplica a escenarios en los que los usuarios colocan el nombre de un producto, el nombre de una empresa o un término técnico que dice "ayúdame a investigar esto".

No lo use para definiciones de términos simples (el usuario simplemente pregunta "qué es XX"), no lo use para escribir artículos en WeChat (use khazix-writer para eso), no lo use para generación pura de títulos/resumen (use wechat-title para eso).
