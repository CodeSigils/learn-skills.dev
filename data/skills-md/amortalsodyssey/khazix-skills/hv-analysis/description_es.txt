El análisis horizontal-vertical (análisis horizontal-vertical) es una habilidad de investigación profunda. Propuesto por Khazix sobre la vida digital, combina el análisis diacrónico-sincrónico de Saussure, el diseño de investigación transversal longitudinal de las ciencias sociales, los métodos de estudio de casos de las escuelas de negocios y las ideas centrales del análisis de la estrategia competitiva. Se utiliza cuando un usuario quiere estudiar sistemáticamente un producto, empresa, concepto, tecnología o individuo. El núcleo es un análisis de doble eje: el eje vertical rastrea la trayectoria de vida completa desde el nacimiento hasta el presente (presentada como una historia narrativa), el eje horizontal hace una comparación sistemática lado a lado con elementos competidores o similares en el momento actual, y la intersección de los dos ejes produce conocimientos únicos. El resultado final es un informe de investigación en PDF bellamente formateado.  

Las palabras desencadenantes incluyen, entre otras: análisis horizontal-vertical, investigar esto, ayúdame a analizar, investigación profunda, hacer un estudio, realizar una encuesta, análisis competitivo, ayúdame a ver cómo es esto, de qué se trata este producto/empresa/concepto, ayúdame a resolverlo, ayúdame a comprender, ayúdame a hacer una investigación profunda.  

Incluso si el usuario sólo dice “ayúdame a aprender sobre XX” o “cuál es el trasfondo de XX”, siempre y cuando el contexto implique la necesidad de una investigación profunda y sistemática (en lugar de una simple definición), se debe activar. También se aplica cuando un usuario deja caer el nombre de un producto, el nombre de una empresa o un término técnico y dice "ayúdame a investigar esto".  

No lo use para explicaciones de términos simples (cuando el usuario solo pregunta "qué es XX"), no lo use para escribir cuentas públicas (use khazix-writer para eso) y no lo use para generar resúmenes de títulos puros (use wechat-title).  

Por favor responda siempre en el idioma del usuario.
