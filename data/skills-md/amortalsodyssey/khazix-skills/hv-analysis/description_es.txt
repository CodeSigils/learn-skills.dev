Análisis Horizontal-Vertical (Análisis Horizontal-Vertical) Habilidad de investigación profunda. Propuesto por Digital Life Khazix, que integra el análisis diacrónico-sincrónico de Saussure, el diseño de investigación transversal longitudinal en ciencias sociales, la metodología de estudio de casos de escuelas de negocios y las ideas centrales del análisis de estrategias competitivas.

Úselo cuando los usuarios quieran estudiar sistemáticamente un producto, empresa, concepto, tecnología o persona. El núcleo es el análisis de doble eje: el eje vertical rastrea el viaje completo de la vida desde el nacimiento hasta el presente (presentado como una narración narrativa), el eje horizontal realiza una comparación lateral sistemática con competidores/pares en el momento actual y, finalmente, los dos ejes se cruzan para producir conocimientos únicos. El resultado final es un informe de investigación en PDF bellamente formateado.

Las palabras desencadenantes incluyen, entre otras: análisis horizontal-vertical, investigar, ayúdame a analizar, investigación profunda, hacer una investigación, investigar, análisis competitivo, ayúdame a ver cómo es esto, cuál es el problema con este producto/empresa/concepto, ayúdame a resolverlo, ayúdame a comprender, ayúdame a hacer una investigación profunda.

Incluso si el usuario simplemente dice "ayúdame a entender XX" o "cuál es el trasfondo de XX", siempre que el contexto implique la necesidad de una investigación profunda y sistemática (en lugar de una simple explicación conceptual), se debe activar. También se aplica cuando los usuarios colocan el nombre de un producto, el nombre de una empresa o un término técnico y dicen "ayúdame a investigar esto".

No lo use para explicaciones de sustantivos simples (el usuario simplemente pregunta "qué es XX"), no lo use para escribir cuentas oficiales de WeChat (use khazix-writer para eso), no lo use para títulos puros y generación de resúmenes (use wechat-title para eso).
