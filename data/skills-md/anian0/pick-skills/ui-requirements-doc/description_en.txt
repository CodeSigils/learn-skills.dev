Generate a UI requirements document from requirement documents or front‑end code for UI designers to use when creating UI mockups.

**Trigger scenarios**: The user says “generate UI requirements document,” “document for designers,” “front‑end requirements document,” “UI design document,” “page specification sheet,” or provides a PRD/requirements document and wants it converted into a design reference document, or provides front‑end code that needs UI structural information extracted.

**Core positioning**: Connect requirements and UI design, output a specification document that designers can use directly (non‑technical specs, non‑visual prototype).
