Generate UI requirement documents from requirement documents or frontend code for UI designers to create UI designs.

**Trigger Scenarios**: User says "generate UI requirement document," "document for designers," "frontend requirement document," "UI design document," "page specification," or user provides PRD/requirement documents and wants to convert them into design reference documents, or user provides frontend code that needs UI structure information extracted.

**Core Positioning**: Bridge requirements and UI design, output specification documents that designers can directly use (not technical specifications, not visual prototypes).
