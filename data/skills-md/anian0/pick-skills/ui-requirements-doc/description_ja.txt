UI デザイナーが UI 図を作成するために、要件ドキュメントまたはフロントエンド コードから UI 要件ドキュメントを生成します。

**トリガー シナリオ**: ユーザーが「UI 要件ドキュメントを生成する」、「デザイナー向けのドキュメント」、「フロントエンド要件ドキュメント」、「UI デザイン ドキュメント」、または「ページ仕様」と言ったとき、ユーザーが PRD/要件ドキュメントを提供し、それをデザイン リファレンス ドキュメントに変換したいとき、またはユーザーがフロントエンド コードを提供し、UI 構造情報の抽出が必要なとき。

**中心的な位置付け**: 要件と UI 設計を橋渡しし、設計者が直接使用できる仕様ドキュメントを出力します (技術仕様やビジュアル プロトタイプではありません)。
