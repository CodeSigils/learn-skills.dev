要件ドキュメントまたはフロントエンド コードから UI 要件ドキュメントを生成し、UI デザイナーが UI モックアップを作成するときに使用します。

**トリガー シナリオ**: ユーザーは、「UI 要件ドキュメントを生成する」、「デザイナー用のドキュメント」、「フロントエンド要件ドキュメント」、「UI デザイン ドキュメント」、「ページ仕様シート」と言うか、PRD/要件ドキュメントを提供してそれをデザイン リファレンス ドキュメントに変換することを希望するか、UI 構造情報の抽出が必要なフロントエンド コードを提供します。

**中心的な位置付け**: 要件と UI 設計を結び付け、設計者が直接使用できる仕様ドキュメントを出力します (非技術仕様、非ビジュアル プロトタイプ)。
