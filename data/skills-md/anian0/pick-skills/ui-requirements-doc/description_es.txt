Genere un documento de requisitos de interfaz de usuario a partir de documentos de requisitos o código de interfaz de usuario para que los diseñadores de interfaz de usuario lo utilicen al crear maquetas de interfaz de usuario.

**Escenarios desencadenantes**: el usuario dice "generar documento de requisitos de UI", "documento para diseñadores", "documento de requisitos de interfaz de usuario", "documento de diseño de interfaz de usuario", "hoja de especificaciones de página" o proporciona un documento PRD/requisitos y quiere convertirlo en un documento de referencia de diseño, o proporciona código de interfaz de usuario que necesita que se extraiga información estructural de la interfaz de usuario.

**Posicionamiento central**: conecte los requisitos y el diseño de la interfaz de usuario, genere un documento de especificaciones que los diseñadores puedan usar directamente (especificaciones no técnicas, prototipo no visual).
