Genere documentos de requisitos de interfaz de usuario a partir de documentos de requisitos o código de interfaz para que los diseñadores de interfaz de usuario creen maquetas de interfaz de usuario.

**Escenarios de activación**: cuando los usuarios dicen "Generar documento de requisitos de interfaz de usuario", "Documento para diseñadores", "Documento de requisitos de interfaz de usuario", "Documento de diseño de interfaz de usuario", "Especificación de página", o cuando los usuarios proporcionan documentos PRD/requisitos y desean convertirlos en documentos de referencia de diseño, o cuando los usuarios proporcionan código de interfaz de usuario que necesita extraer información de la estructura de la interfaz de usuario.

**Posicionamiento central**: requisitos de puente y diseño de interfaz de usuario, documentos de especificaciones de salida que los diseñadores pueden usar directamente (no especificaciones técnicas, no prototipos visuales).
