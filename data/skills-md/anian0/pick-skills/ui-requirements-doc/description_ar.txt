قم بإنشاء مستند متطلبات واجهة المستخدم من مستندات المتطلبات أو كود الواجهة الأمامية ليستخدمه مصممو واجهة المستخدم عند إنشاء نماذج واجهة المستخدم.

**سيناريوهات التشغيل**: يقول المستخدم "إنشاء مستند متطلبات واجهة المستخدم"، أو "مستند للمصممين"، أو "مستند متطلبات الواجهة الأمامية"، أو "مستند تصميم واجهة المستخدم"، أو "ورقة مواصفات الصفحة"، أو يقدم مستند PRD/المتطلبات ويريد تحويله إلى مستند مرجعي للتصميم، أو يوفر كود الواجهة الأمامية الذي يحتاج إلى استخراج المعلومات الهيكلية لواجهة المستخدم.

**الموضع الأساسي**: ربط المتطلبات وتصميم واجهة المستخدم، وإخراج مستند مواصفات يمكن للمصممين استخدامه مباشرة (مواصفات غير فنية، ونموذج أولي غير مرئي).
