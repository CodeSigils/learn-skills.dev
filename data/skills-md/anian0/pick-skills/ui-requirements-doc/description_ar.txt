قم بإنشاء مستندات متطلبات واجهة المستخدم من مستندات المتطلبات أو كود الواجهة الأمامية لمصممي واجهة المستخدم لإنشاء نماذج بالحجم الطبيعي لواجهة المستخدم.

**سيناريوهات التشغيل**: عندما يقول المستخدم "إنشاء مستند متطلبات واجهة المستخدم"، أو "مستند للمصممين"، أو "مستند متطلبات الواجهة الأمامية"، أو "مستند تصميم واجهة المستخدم"، أو "مواصفات الصفحة"؛ أو عندما يقدم المستخدم مستند PRD/المتطلبات ويريد تحويله إلى مستند مرجعي للتصميم؛ أو عندما يقدم المستخدم كود الواجهة الأمامية الذي يحتاج إلى استخراج معلومات بنية واجهة المستخدم.

**الموضع الأساسي**: متطلبات الجسر وتصميم واجهة المستخدم، ومستندات مواصفات المخرجات التي يمكن للمصممين استخدامها مباشرة (وليست المواصفات الفنية، وليست النماذج الأولية المرئية).
