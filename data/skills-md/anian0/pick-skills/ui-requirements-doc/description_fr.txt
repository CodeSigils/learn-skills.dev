Générez un document d'exigences d'interface utilisateur à partir de documents d'exigences ou de code frontal que les concepteurs d'interface utilisateur pourront utiliser lors de la création de maquettes d'interface utilisateur.

**Scénarios de déclenchement** : l'utilisateur dit « générer un document sur les exigences de l'interface utilisateur », « un document pour les concepteurs », « un document sur les exigences frontales », « un document de conception de l'interface utilisateur », « une feuille de spécifications de page », ou fournit un document PRD/exigences et souhaite qu'il soit converti en un document de référence de conception, ou fournit un code frontal qui nécessite l'extraction d'informations structurelles sur l'interface utilisateur.

**Positionnement principal** : connectez les exigences et la conception de l'interface utilisateur, générez un document de spécifications que les concepteurs peuvent utiliser directement (spécifications non techniques, prototype non visuel).
