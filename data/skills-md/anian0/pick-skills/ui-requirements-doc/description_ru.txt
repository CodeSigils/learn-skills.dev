Создайте документ с требованиями к пользовательскому интерфейсу на основе документов с требованиями или внешнего кода, который дизайнеры пользовательского интерфейса смогут использовать при создании макетов пользовательского интерфейса.

**Сценарии срабатывания**: пользователь говорит «создать документ с требованиями к пользовательскому интерфейсу», «документ для дизайнеров», «документ с требованиями к интерфейсу», «документ с дизайном пользовательского интерфейса», «лист спецификации страницы» или предоставляет документ PRD/требования и хочет преобразовать его в справочный документ по проектированию, или предоставляет интерфейсный код, для которого необходимо извлечь структурную информацию пользовательского интерфейса.

**Основное позиционирование**: соедините требования и дизайн пользовательского интерфейса, выведите документ со спецификацией, который дизайнеры смогут использовать напрямую (нетехнические спецификации, невизуальный прототип).
