Generieren Sie ein UI-Anforderungsdokument aus Anforderungsdokumenten oder Front-End-Code, das UI-Designer beim Erstellen von UI-Modellen verwenden können.

**Triggerszenarien**: Der Benutzer sagt „UI-Anforderungsdokument generieren“, „Dokument für Designer“, „Front-End-Anforderungsdokument“, „UI-Designdokument“, „Seitenspezifikationsblatt“ oder stellt ein PRD-/Anforderungsdokument bereit und möchte, dass es in ein Design-Referenzdokument umgewandelt wird, oder stellt Front-End-Code bereit, für den UI-Strukturinformationen extrahiert werden müssen.

**Kernpositionierung**: Verbinden Sie Anforderungen und UI-Design und geben Sie ein Spezifikationsdokument aus, das Designer direkt verwenden können (nicht technische Spezifikationen, nicht visueller Prototyp).
