Pflegen und führen Sie den gesamten Satz an Testfällen aus, bevor eine Projektiteration veröffentlicht wird. Diese Fähigkeit wird ausgelöst, wenn der Benutzer „Testfälle vor der Veröffentlichung“, „Testfälle aktualisieren“, „vollständiges Testen“, „Testfälle ausführen“, „Testsuite warten“, „Testabdeckung“ oder „Erkennen, welche Tests aufgrund von Codeänderungen aktualisiert werden müssen“ erwähnt. Dies gilt auch für Szenarien, in denen der Benutzer ein Funktionsmodul angibt, das das Hinzufügen oder Aktualisieren von Tests erfordert.
