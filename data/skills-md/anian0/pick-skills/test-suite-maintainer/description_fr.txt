Maintenir et exécuter la suite complète de cas de test avant la publication de l'itération du projet. Cette compétence est déclenchée lorsque les utilisateurs mentionnent « tests préliminaires », « mettre à jour les cas de test », « tests complets », « exécuter des cas de test », « maintenir la suite de tests », « couverture des tests » ou « détecter les tests qui nécessitent une mise à jour pour les modifications de code ». Applicable également lorsque les utilisateurs spécifient des modules fonctionnels qui nécessitent l'ajout ou la mise à jour de tests.
