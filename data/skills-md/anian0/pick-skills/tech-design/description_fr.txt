Compétence en conception de solutions techniques. Produire une solution technique complète basée sur le document d’exigence. Prérequis obligatoire : d'abord discuter et confirmer les exigences du document technique ; les nouvelles fonctionnalités doivent avoir une documentation de référence et les fonctionnalités existantes doivent avoir un document de description de la pile technologique. La documentation doit être stockée dans le répertoire Workplace/{version}/references avant que la conception de la solution technique puisse commencer. Livrables finaux : conception d'architecture, modèle de données, conception d'API, stratégie de tests, plan de mise en œuvre. Mots déclencheurs : solution technique, conception de solution, planification de mise en œuvre, conception d'architecture, document de conception technique.
