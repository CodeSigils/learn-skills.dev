使用此技能通过比较技能状态并从配置的源目录（例如 ~/.cc-switch/skills/ 和 ~/.agents/skills/）链接来管理 Claude Code、Codex、Gemini、OpenCode、OpenClaw、Cursor、Copilot 和其他配置的代理工具中已安装的技能。在两种主要情况下触发：第一，当用户想要跨多个代理同步、删除、修复或对齐技能或代理技能时；其次，当用户还不知道当前的技能状态并想要检查技能差异、缺失的技能、每个代理的技能覆盖范围、每个技能的覆盖范围或决定下一步要进行哪些技能更改时。当主题是跨代理技能或代理技能管理时，请使用此技能，而不是用于一般代理比较、一般模型功能问题或从 GitHub 创建、编辑或安装技能。
