استخدم هذه المهارة لإدارة المهارات المثبتة بالفعل عبر Claude Code وCodex وGemini وOpenCode وOpenClaw وCursor وCopilot وأدوات الوكيل الأخرى التي تم تكوينها من خلال مقارنة حالة المهارة والربط من أدلة المصدر التي تم تكوينها مثل ~/.cc-switch/skills/ و~/.agents/skills/. قم بتشغيله في حالتين رئيسيتين: أولاً، عندما يريد المستخدم مزامنة المهارات أو مهارات الوكيل أو إزالتها أو إصلاحها أو مواءمتها عبر وكلاء متعددين؛ ثانيًا، عندما لا يعرف المستخدم حتى الآن حالة المهارة الحالية ويريد فحص اختلافات المهارات، أو المهارات المفقودة، أو تغطية المهارات لكل وكيل، أو التغطية لكل مهارة، أو تحديد تغييرات المهارات التي يجب إجراؤها بعد ذلك. استخدم هذه المهارة عندما يكون الموضوع هو المهارة المشتركة بين الوكلاء أو إدارة مهارات الوكلاء، وليس لمقارنة الوكلاء العامة، أو الأسئلة العامة حول قدرة النموذج، أو إنشاء المهارات أو تحريرها أو تثبيتها من GitHub.
