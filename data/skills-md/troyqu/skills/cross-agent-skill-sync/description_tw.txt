使用此技能透過比較技能狀態並從配置的來源目錄（例如 ~/.cc-switch/skills/ 和 ~/.agents/skills/）連結來管理 Claude Code、Codex、Gemini、OpenCode、OpenClaw、Cursor、Copilot 和其他配置的代理工具中已安裝的技能。在兩種主要情況下觸發：第一，當用戶想要跨多個代理同步、刪除、修復或對齊技能或代理技能時；其次，當用戶還不知道當前的技能狀態並想要檢查技能差異、缺少的技能、每個代理的技能覆蓋範圍、每個技能的覆蓋範圍或決定下一步要進行哪些技能更改時。當主題是跨代理技能或代理技能管理時，請使用此技能，而不是用於一般代理比較、一般模型功能問題或從 GitHub 建立、編輯或安裝技能。
