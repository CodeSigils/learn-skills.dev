デザイン システムの品質チェック (トークン検証、コンポーネントのリンティング、ビジュアル リグレッション、アクセシビリティ スキャン、リリース ゲーティングなど) を自動化する CI/CD パイプライン構成を生成します。 GitHub Actions、GitLab CI、CircleCI、または Bitbucket Pipelines 用のすぐに使用できるパイプライン ファイルを生成し、監査スキル チェックの標準を手動で強制するように構成されます。誰かが次のように言ったときにトリガーされます: デザイン システムの CI のセットアップ、これらのチェックの自動化、トークンのパイプラインの追加、デザイン システムの GitHub Action、コンポーネントの CI/CD の作成、リリース プロセスの自動化、デザイン システムの継続的インテグレーション、監査で見つかったものを自動化する方法、CI の品質ゲート、またはパイプラインでのデザイン システムの品質チェックの自動化に関する何か。手動監査の実行をトリガーしないでください。そのためには、特定の監査スキルを使用してください。リリース チェックリストの生成をトリガーにしないでください。そのためには変更コミュニケーションを使用してください。
