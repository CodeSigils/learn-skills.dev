Générez des configurations de pipeline CI/CD qui automatisent les contrôles qualité du système de conception : validation des jetons, peluchage des composants, régression visuelle, analyse de l'accessibilité et contrôle des versions. Produit des fichiers de pipeline prêts à l'emploi pour GitHub Actions, GitLab CI, CircleCI ou Bitbucket Pipelines, configurés pour appliquer les normes que les compétences d'audit vérifient manuellement. Déclenchez lorsque quelqu'un dit : configurez CI pour le système de conception, automatisez ces vérifications, ajoutez un pipeline pour les jetons, créez une action GitHub pour le système de conception, CI/CD pour les composants, automatisez le processus de publication, intégration continue pour le système de conception, comment automatiser ce que l'audit a trouvé, les portes de qualité dans CI ou tout ce qui concerne l'automatisation des contrôles de qualité du système de conception dans un pipeline. Ne déclenchez PAS l’exécution d’un audit manuel – utilisez la compétence d’audit spécifique pour cela. Ne déclenchez PAS la génération d'une liste de contrôle de publication - utilisez la communication de changement pour cela.
