Identifique dónde un sistema de diseño se ha desviado de su intención original en todo el sistema: componentes implementados de manera diferente según las especificaciones, tokens anulados localmente, patrones bifurcados entre equipos. Este es un barrido de todo el sistema para patrones de divergencia, NO una comparación de especificaciones de un solo componente. Se activa cuando alguien dice: encontrar deriva, dónde se ha desviado el sistema, inconsistencia en el código de diseño, qué no está sincronizado, dónde se salen los equipos del sistema, deriva de componentes o cualquier cosa relacionada con la identificación de brechas entre la intención del sistema de diseño y la implementación real. NO active la verificación de un componente específico con su especificación de diseño; use la verificación de diseño a código para eso.
