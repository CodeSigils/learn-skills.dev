Напишите документацию для токенов дизайна, охватывающую семантическое намерение, контекст использования и примеры того, что можно и чего нельзя делать. Срабатывает, когда кто-то говорит: задокументируйте эти токены, ссылку на токен, что означает этот токен, руководство по использованию токена, напишите документацию по токену, намерение токена или что-нибудь о создании удобочитаемой документации для токенов проектирования.
