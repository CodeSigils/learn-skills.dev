اكتب الوثائق الخاصة برموز التصميم - التي تغطي النية الدلالية وسياق الاستخدام وأمثلة "افعل/لا تفعل". يتم تشغيله عندما يقول شخص ما: قم بتوثيق هذه الرموز المميزة، أو مرجع الرمز المميز، أو ماذا يعني هذا الرمز المميز، أو دليل استخدام الرمز المميز، أو كتابة مستندات الرمز المميز، أو نية الرمز المميز، أو أي شيء يتعلق بإنشاء وثائق يمكن قراءتها بواسطة الإنسان لرموز التصميم المميزة.
