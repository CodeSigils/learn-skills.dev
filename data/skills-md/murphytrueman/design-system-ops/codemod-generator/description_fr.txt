Générez des codemods (scripts de transformation de code automatisés) pour les migrations du système de conception : renommage des jetons, modifications de l'API des composants, dépréciations des accessoires et mises à jour du chemin d'importation. Produit des scripts de transformation jscodeshift ou AST personnalisés prêts à l'emploi qui appliquent en toute sécurité les modifications dans les bases de code consommatrices. Déclenchez-vous lorsque quelqu'un dit : générer un codemod, automatiser cette migration, écrire un script de transformation, renommer en bloc les jetons, migrer automatiquement les composants, jscodeshift pour ce changement, créer un script de migration, mettre à jour toutes les importations, renommer cet accessoire partout, ou quoi que ce soit sur l'automatisation des changements de code entre les consommateurs d'un système de conception. Ne déclenchez PAS la planification du processus de dépréciation - utilisez deprecation-process pour cela. Ne déclenchez PAS la rédaction de notes de version concernant un changement – ​​utilisez la communication de changement pour cela.
