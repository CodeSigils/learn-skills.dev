قم بإنشاء تعديلات برمجية (برامج نصية لتحويل التعليمات البرمجية تلقائيًا) لعمليات ترحيل نظام التصميم - إعادة تسمية الرمز المميز، وتغييرات واجهة برمجة التطبيقات للمكونات، وإهمال الدعامات، وتحديثات مسار الاستيراد. يُنتج jscodeshift جاهزة للتشغيل أو نصوص تحويل AST مخصصة تطبق التغييرات بأمان عبر قواعد التعليمات البرمجية المستهلكة. يتم التشغيل عندما يقول شخص ما: قم بإنشاء كود مود، أو أتمتة هذا الترحيل، أو كتابة برنامج نصي للتحويل، أو إعادة تسمية الرموز المميزة بشكل مجمّع، أو ترحيل المكونات تلقائيًا، أو jscodeshift لهذا التغيير، أو إنشاء برنامج نصي للترحيل، أو تحديث جميع الواردات، أو إعادة تسمية هذه الدعامة في كل مكان، أو أي شيء يتعلق بأتمتة تغييرات التعليمات البرمجية عبر مستهلكي نظام التصميم. لا تقم بتشغيل التخطيط لعملية الإهمال - استخدم عملية الإهمال لذلك. لا تقم بتشغيل كتابة ملاحظات الإصدار حول التغيير - استخدم التواصل الخاص بالتغيير لذلك.
