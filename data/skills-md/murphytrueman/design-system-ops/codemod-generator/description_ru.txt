Создавайте codemods (скрипты автоматического преобразования кода) для миграции системы проектирования — переименования токенов, изменения API компонентов, прекращения поддержки свойств и обновлений путей импорта. Создает готовые к запуску сценарии преобразования jscodeshift или пользовательские AST, которые безопасно применяют изменения во всех потребляющих базах кода. Срабатывает, когда кто-то говорит: сгенерируйте кодовый мод, автоматизируйте эту миграцию, напишите сценарий преобразования, массовое переименование токенов, автоматическую миграцию компонентов, jscodeshift для этого изменения, создайте сценарий миграции, обновите весь импорт, переименуйте этот реквизит везде или что-нибудь об автоматизации изменений кода среди потребителей дизайн-системы. НЕ запускайте триггер для планирования процесса устаревания — для этого используйте deprecation-process. НЕ запускайте триггер для написания примечаний к выпуску об изменении — используйте для этого коммуникацию об изменениях.
