Generieren Sie Codemods (automatisierte Codetransformationsskripte) für Designsystemmigrationen – Token-Umbenennungen, Komponenten-API-Änderungen, veraltete Requisiten und Importpfadaktualisierungen. Erstellt betriebsbereite jscodeshift- oder benutzerdefinierte AST-Transformationsskripte, die Änderungen sicher auf verbrauchende Codebasen anwenden. Wird ausgelöst, wenn jemand sagt: Generieren Sie ein Codemod, automatisieren Sie diese Migration, schreiben Sie ein Transformationsskript, benennen Sie Token in großen Mengen um, migrieren Sie Komponenten automatisch, verschieben Sie jscode für diese Änderung, erstellen Sie ein Migrationsskript, aktualisieren Sie alle Importe, benennen Sie diese Requisite überall um oder irgendetwas über die Automatisierung von Codeänderungen zwischen Verbrauchern eines Designsystems. Lösen Sie NICHT aus, um den Deprecation-Prozess zu planen – verwenden Sie dafür deprecation-process. Versuchen Sie NICHT, Versionshinweise zu einer Änderung zu schreiben – nutzen Sie dazu die Änderungskommunikation.
