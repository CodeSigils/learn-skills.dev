Genera codemod (script di trasformazione automatizzata del codice) per le migrazioni del sistema di progettazione: ridenominazioni di token, modifiche alle API dei componenti, deprecazioni delle prop e aggiornamenti del percorso di importazione. Produce script di trasformazione jscodeshift o AST personalizzati pronti per l'esecuzione che applicano in modo sicuro le modifiche alle basi di codice che utilizzano. Si attiva quando qualcuno dice: genera un codemod, automatizza questa migrazione, scrivi uno script di trasformazione, rinomina in blocco i token, migra automaticamente i componenti, jscodeshift per questa modifica, crea uno script di migrazione, aggiorna tutte le importazioni, rinomina questo oggetto ovunque o qualsiasi cosa sull'automazione delle modifiche al codice tra i consumatori di un sistema di progettazione. NON attivare per pianificare il processo di deprecazione: utilizzare il processo di deprecazione per questo. NON attivarsi per scrivere note di rilascio relative a una modifica: utilizzare la comunicazione della modifica per questo.
