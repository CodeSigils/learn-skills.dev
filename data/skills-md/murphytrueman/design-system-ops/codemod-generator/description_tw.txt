產生用於設計系統遷移的 codemod（自動程式碼轉換腳本）－令牌重命名、元件 API 變更、道具棄用和匯入路徑更新。產生可立即執行的 jscodeshift 或自訂 AST 轉換腳本，這些腳本可以在使用的程式碼庫中安全地套用變更。當有人說：產生 codemod、自動執行此遷移、編寫轉換腳本、批次重命名令牌、自動遷移元件、針對此變更的 jscodeshift、建立遷移腳本、更新所有匯入、在各處重命名此 prop 或有關在設計系統的使用者之間自動執行程式碼變更的任何內容時觸發。不要觸發計劃棄用過程 - 使用 deprecation-process 來實現。不要觸發編寫有關更改的發行說明 - 為此使用更改通訊。
