Escriba documentación para un patrón de sistema de diseño: una receta de múltiples componentes que cubra casos de uso, antipatrones, composición y patrones relacionados. Los patrones abarcan múltiples componentes que trabajan juntos (por ejemplo, un patrón de formulario, un patrón de tabla de datos). Se activa cuando alguien dice: documentar este patrón, escribir la página del patrón, patrón de uso, cuándo usarlo, pautas de patrón, documentar cómo funciona o cualquier cosa sobre la creación de documentación para un patrón de interfaz de usuario reutilizable en lugar de un solo componente. NO active la escritura de pautas de uso para un solo componente con nombre; use pautas de uso para eso.
