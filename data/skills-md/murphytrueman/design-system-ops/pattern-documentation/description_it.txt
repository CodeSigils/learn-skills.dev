Scrivere la documentazione per un modello di sistema di progettazione: una ricetta multicomponente che copra casi d'uso, anti-pattern, composizione e modelli correlati. I modelli si estendono su più componenti che lavorano insieme (ad esempio un modello di modulo, un modello di tabella dati). Si attiva quando qualcuno dice: documenta questo pattern, scrivi la pagina del pattern, il pattern di utilizzo, quando usarlo, le linee guida del pattern, documenta come funziona o qualsiasi cosa sulla creazione di documentazione per un pattern di interfaccia utente riutilizzabile anziché per un singolo componente. NON attivare la scrittura di linee guida sull'utilizzo per un singolo componente denominato: utilizzare le linee guida sull'utilizzo per questo.
