Schreiben Sie eine Dokumentation für ein Designsystemmuster – ein mehrkomponentiges Rezept, das Anwendungsfälle, Anti-Patterns, Zusammensetzung und verwandte Muster abdeckt. Muster umfassen mehrere zusammenarbeitende Komponenten (z. B. ein Formularmuster, ein Datentabellenmuster). Wird ausgelöst, wenn jemand sagt: Dokumentieren Sie dieses Muster, schreiben Sie die Musterseite, das Verwendungsmuster, wann es verwendet werden soll, Musterrichtlinien, dokumentieren Sie, wie das funktioniert, oder irgendetwas über die Erstellung einer Dokumentation für ein wiederverwendbares UI-Muster anstelle einer einzelnen Komponente. Lösen Sie NICHT das Schreiben von Verwendungsrichtlinien für eine einzelne benannte Komponente aus – verwenden Sie dazu verwendende Richtlinien.
