Rédigez la documentation d'un modèle de système de conception : une recette à plusieurs composants couvrant les cas d'utilisation, les anti-modèles, la composition et les modèles associés. Les modèles couvrent plusieurs composants travaillant ensemble (par exemple un modèle de formulaire, un modèle de table de données). Déclenchez lorsque quelqu'un dit : documentez ce modèle, écrivez la page du modèle, le modèle d'utilisation, quand l'utiliser, les directives du modèle, documentez son fonctionnement ou tout ce qui concerne la création de documentation pour un modèle d'interface utilisateur réutilisable plutôt qu'un seul composant. Ne déclenchez PAS l'écriture de directives d'utilisation pour un seul composant nommé - utilisez des directives d'utilisation pour cela.
