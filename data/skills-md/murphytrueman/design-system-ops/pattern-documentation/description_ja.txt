デザイン システム パターン (ユースケース、アンチパターン、構成、および関連パターンをカバーする複数コンポーネントのレシピ) のドキュメントを作成します。パターンは、連携して動作する複数のコンポーネントにまたがります (フォーム パターン、データ テーブル パターンなど)。誰かが「このパターンを文書化する、パターン ページを作成する、使用パターン、これをいつ使用するか、パターン ガイドラインを作成する、これがどのように機能するかを文書化する、または単一のコンポーネントではなく再利用可能な UI パターンのドキュメントの作成に関するあらゆること」と言ったときにトリガーします。単一の名前付きコンポーネントの使用ガイドラインの作成をトリガーしないでください。そのためには、使用ガイドラインを使用してください。
