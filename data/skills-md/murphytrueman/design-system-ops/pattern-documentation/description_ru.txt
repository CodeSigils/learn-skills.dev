Напишите документацию для шаблона системы дизайна — многокомпонентного рецепта, охватывающего варианты использования, антишаблоны, композицию и связанные шаблоны. Шаблоны охватывают несколько компонентов, работающих вместе (например, шаблон формы, шаблон таблицы данных). Триггер, когда кто-то говорит: задокументируйте этот шаблон, напишите страницу шаблона, шаблон использования, когда это использовать, рекомендации по шаблонам, задокументируйте, как это работает, или что-нибудь о создании документации для многократно используемого шаблона пользовательского интерфейса, а не для одного компонента. НЕ инициируйте написание инструкций по использованию для одного именованного компонента — используйте для этого инструкции по использованию.
