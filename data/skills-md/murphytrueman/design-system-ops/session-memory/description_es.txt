Persista y recuerde los hallazgos en las ejecuciones de habilidades dentro y entre sesiones, creando una base de conocimiento acumulativo de lo que se ha descubierto sobre un sistema de diseño. Esta es la capa de memoria entre habilidades: guarda lo que se encontró, cuándo y mediante qué habilidad, para que las ejecuciones futuras puedan comparar, correlacionar y evitar repetir el trabajo. Se activa cuando alguien dice: guardar estos hallazgos, recordar esto para más adelante, comparar con la última ejecución, qué encontramos antes, cargar hallazgos anteriores, recuperar la última auditoría, historial de sesiones, mostrarme qué cambió, hacer referencias cruzadas con ejecuciones anteriores o cualquier cosa sobre persistir, recordar o comparar hallazgos a lo largo del tiempo. NO active la generación de un único informe independiente; utilice la habilidad específica para ello. NO active la ejecución de un diagnóstico completo; utilice el diagnóstico completo del sistema para eso.
