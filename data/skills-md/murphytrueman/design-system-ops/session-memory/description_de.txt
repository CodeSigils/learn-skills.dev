Behalten und erinnern Sie sich an Erkenntnisse aus allen Fertigkeitsläufen innerhalb und zwischen Sitzungen und bauen Sie so eine kumulative Wissensbasis darüber auf, was über ein Designsystem herausgefunden wurde. Dies ist die fähigkeitsübergreifende Speicherebene – sie speichert, was wann und von welcher Fähigkeit gefunden wurde, sodass künftige Durchläufe verglichen und korreliert werden können und wiederholte Arbeiten vermieden werden können. Wird ausgelöst, wenn jemand sagt: Speichern Sie diese Ergebnisse, merken Sie sich dies für später, vergleichen Sie sie mit dem letzten Lauf, was haben wir zuvor gefunden, laden Sie frühere Ergebnisse, rufen Sie das letzte Audit ab, Sitzungsverlauf, zeigen Sie mir, was sich geändert hat, stellen Sie Querverweise zu früheren Läufen her oder irgendetwas über das Beibehalten, Abrufen oder Vergleichen von Ergebnissen im Zeitverlauf. Lösen Sie NICHT aus, um einen einzelnen eigenständigen Bericht zu erstellen – nutzen Sie dafür die entsprechende Fähigkeit. Lösen Sie NICHT aus, um eine vollständige Diagnose auszuführen – verwenden Sie dazu die vollständige Systemdiagnose.
