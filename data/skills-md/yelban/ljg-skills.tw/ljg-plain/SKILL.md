# ljg-plain: 白

讓人 grok。

不規定怎麼寫。規定不能怎麼寫。下限鎖死，上限放開。不同主題有不同的最佳寫法——類比、故事、問答、遞進的例子、一個長場景——由內容決定形式。

## 格式約束

### Org-mode 語法

- 加粗用 `*bold*`（單星號），禁止 `**bold**`
- 標題層級從 `*` 開始，不跳級

### ASCII Art

所有圖表用純 ASCII 字元。允許：`+ - | / \ > < v ^ * = ~ . : # [ ] ( ) _ , ; ! ' "` 和空格。禁止 Unicode 繪圖符號。

### Denote 檔案規範

- 時間戳：`date +%Y%m%dT%H%M%S`
- 可讀時間：`date "+%Y-%m-%d %a %H:%M"`
- 檔名：`{時間戳}--plain-{簡短標題}__plain.org`
- 輸出目錄：`~/Documents/notes/`

### Org 檔案頭

```
#+title:      plain-{簡短標題}
#+date:       [{YYYY-MM-DD Day HH:MM}]
#+filetags:   :plain:atom:
#+identifier: {YYYYMMDDTHHMMSS}
#+source:     {URL 或來源描述}
```

檔案寫入後報告路徑。

## 紅線（每條必須過，順序即優先順序）

1. *口語檢驗* — 最高法則。讀出聲來，你會這樣跟一個聰明的朋友說話嗎？不會→改到會。連詞不是敵人——"但是""所以"是思維轉彎的聲音，只砍機械連詞（"此外""值得注意的是"）
2. *零術語* — 聰明的 12 歲孩子能複述。專業詞必須出現時，先用大白話把意思落地，再順帶提術語名
3. *短詞優先* — 能用兩個字說的不用四個字。「進行分析」→「看」。大詞不讓你顯得聰明，只讓人讀得累
4. *一句一事* — 每句只推進一步。長句拆短
5. *具體* — 名詞看得見，動詞有力氣。「有人覺得情況不太好」→「張三說專案要黃了」。形容詞能砍就砍
6. *開頭給理由* — 第一句話讓人想讀下一句。不鋪墊、不背景、不「自古以來」
7. *不填充* — 刪開場白、柺杖詞、誇大象徵。每句都在幹活
8. *信任讀者* — 跳過軟化、辯解、手把手引導。說一遍夠了
9. *誠實* — 想不清楚就說想不清楚。"大概 70%" 比"可能"誠實

## 工具箱（選用，不必全用）

寫的時候可以從這裡拿工具，沒有哪個是必須的：

- *類比* — 找結構對得上的日常經驗。好類比承重（去掉它文章塌），多層（挖一層還像），自明（不需要解釋類比本身）。動詞延伸到新物件時檢查中文動賓搭配是否自然
- *好問題* — 找讀者的卡點，變成問題。讀者被卡住，才想往下讀
- *裂縫* — 模型/類比在哪裡不夠？那個點往往最值錢。不宣佈它，讓讀者自己感到
- *畫面* — 閉眼能看到的場景。硬造的畫面比沒有更糟
- *故事* — 一個具體的人遇到一個具體的問題。讀者跟著走
- *反問入鏈* — 遇到隱含前提，用問題開啟，然後回答它
- *骨架圖* — 概念涉及空間關係時，嵌入 ASCII 圖（`#+begin_example` 塊）

## 執行

### 1. 獲取內容

URL → WebFetch | 文字 → 直接用 | 檔案路徑 → Read | 概念 → 直接解釋 | 書名/論文名 → WebSearch

### 2. 寫

形式自由。從工具箱裡選最適合這個主題的方式，也可以不選——如果有更好的寫法，用它。

輸出是一篇從第一行流到最後一行的連貫文章。全文只有檔案標題，正文無子標題。

禁止：
- 結構標籤（`* 類比` / `* 裂縫` 等）
- 指向寫作過程的元評論（「打個比方」「接下來我們討論」）

### 3. 過紅線

逐條掃紅線清單。額外檢查：

- 破公式——否定式排比全文不超過兩處，三段式改兩項或四項
- 變節奏——長短句交替，段落結尾多樣
- 殺金句——聽起來像可引用的，重寫
- 查跳躍——每步邏輯可追？前句說 A，後句跳到 B→補橋
- 查譯感——動賓搭配中文天然嗎？不自然→換動詞或換句式

掃完列修改清單（哪句觸發什麼，改前→改後）。清單不寫入檔案。

### 4. 生成 Org 檔案

按 Denote 規範獲取時間戳，寫出檔案頭 + 正文，存入 `~/Documents/notes/`。

## 驗收

- *Grok*：讀完能用自己的話複述核心
- *零術語*：12 歲孩子能跟上
- *記得住*：讀完腦子裡留下了什麼——一個畫面、一個問題、一個轉折，什麼都行
- *想讀完*：從頭到尾沒有想跳過的段落
