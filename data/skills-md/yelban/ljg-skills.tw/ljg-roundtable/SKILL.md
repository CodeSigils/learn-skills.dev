  Structured roundtable discussion framework with a truth-seeking moderator
  who invites representative figures for dialectical debate on any topic.
  Use when user says "圓桌討論", "圓桌", "roundtable", "辯論",
  or wants to explore a topic through multi-perspective structured debate.

## Usage

<example>
User: 圓桌討論 人工智慧是否擁有真正的創造力？
Assistant: [Launches roundtable with moderator and representative figures]
</example>

<example>

Assistant: [Launches roundtable discussion on free will]

## Instructions

為了執行本項技能，請嚴格按照以下步驟操作：

1. **讀取參考資料**
   讀取 `~/.claude/skills/ljg-roundtable/references/original-prompt.org` 瞭解原始框架設計意圖。

2. **解析議題**
   從使用者輸入中提取核心議題。如果使用者只說"圓桌討論"未給議題，詢問議題。

3. **選人：提議代表人物**
   根據議題，選擇 3-5 位**真實歷史/當代人物**作為代表，覆蓋儘可能多的立場維度。每位人物需要：
   - 姓名（真實人物，非虛構）
   - MBTI 人格型別
   - 核心立場（一句話）
   - 選擇理由（為什麼此人對此議題有獨特視角）

   選人原則：
   - 立場必須形成**張力網路**（非簡單正反方）
   - 優先選擇在該領域有**經典著作或知名言論**的人物
   - 至少包含一位"意外視角"——來自議題本身領域之外的人

4. **開場：統一定義**
   以主持人身份開場，展示參會人物列表，然後提出**定義性問題**：
   > 「在深入探討之前，我們應當如何定義 [議題核心概念]？它的核心要素是什麼？」

   每位參會者依次發言，格式為：
   ```
   【人物名】【行動標籤】：發言內容

   **簡言之**：一句話總結
   ```

   行動標籤包括：`陳述`、`質疑`、`補充`、`反駁`、`修正`、`綜合`

5. **對話迴圈**
   每輪執行以下流程：

   **5a. 動態發言輪**
   - 不是每人固定說一次——根據討論動態決定誰該發言
   - 每人發言必須是對**前面發言的回應**（質疑/補充/反駁），不許自說自話
   - 每段發言末尾必須有 `**簡言之**：` 一句話壓縮

   **5b. 主持人綜述**
   發言結束後，主持人做三件事：
   - 提煉本輪**核心爭議點**（不是面面俱到，而是找到最深的裂縫）
   - 生成**ASCII 思考框架圖**（拓撲圖/矩陣/光譜/樹形——選最貼合本輪結構的形式）
   - 提出**下一層引導問題**（從核心爭議中生長出來的更深問題）

   ASCII 圖的設計原則：
   - 高度概括本輪討論的**結構**，不是複述內容
   - 標出正/負反饋環、因果鏈、張力維度
   - 形式不固定：可以是 2x2 矩陣、光譜軸、因果環路、層級樹——哪種最見骨用哪種

   **5c. 使用者指令**
   綜述後展示指令選單：
   ```
   【主持】：(指令: 可 / 止 / 深入此節 / 引入新人物)
   ```

   指令含義：
   - `可`：接受下一層問題，繼續推進
   - `止`：結束討論，進入總結
   - `深入此節`：不推進新問題，繼續圍繞當前爭議點深挖
   - `引入新人物`：使用者指定一位新人物加入（主持人介紹並請其就當前話題表態）

6. **結束：生成知識網路**
   使用者發出 `止` 指令後：
   - 主持人做**全域性總結**
   - 生成**完整知識網路** ASCII 圖：標出所有關鍵概念、立場、爭議點及其關係
   - 列出**未解決的開放問題**（討論中暴露但未窮盡的方向）

7. **寫入 org 檔案（完整儲存，一字不差）**
   將討論**全部原文**寫入 org-mode 檔案，不壓縮、不刪減、不改寫任何發言內容：
   1. 執行 `date +%Y%m%dT%H%M%S` 獲取時間戳
   2. 寫入 `~/Documents/notes/{timestamp}--圓桌-{議題關鍵詞}__roundtable.org`
   3. org 檔案結構：
      ```org
      #+title: 圓桌：{議題}
      #+date: [{日期}]
      #+filetags: :roundtable:
      * 議題與參會者
      [完整的參會者介紹，包括姓名、MBTI、立場、選擇理由]
      * 開場：定義
      [主持人開場詞 + 每位參會者的完整定義性發言，原文照錄]
      * 各輪討論記錄
      ** 第 N 輪：{引導問題}
      *** 發言記錄
      [本輪所有發言的完整原文，包括行動標籤、全部論述、簡言之]
      *** 主持人綜述
      [核心爭議點 + ASCII 框架圖 + 下一層引導問題，原文照錄]
      * 知識網路（全域性）
      [完整的全域性總結 + ASCII 知識網路圖]
      * 開放問題
      [所有未解決的開放問題]
      ```
      **關鍵要求：每一段發言、每一個 ASCII 圖、每一句主持人綜述，都必須完整保留原文，禁止摘要或壓縮。**
   4. 向用戶報告檔案路徑

### 主持人行為準則

- **理性之錨**：冷靜客觀，不偏向任何一方
- **挖深不鋪廣**：每輪只追一條最深的裂縫，不面面俱到
- **求真 > 和諧**：鼓勵尖銳但有建設性的交鋒，拒絕表面共識
- **元認知**：在綜述中暴露討論的**結構**（假設、前提、推理鏈），不只複述內容

### 參會者行為準則

- 必須**忠於其真實思想體系**發言，不是泛泛而談
- 引用/化用其**經典著作或知名觀點**
- 發言有鋒芒：質疑要見骨，補充要推進，不說正確的廢話
- 每段結尾 `**簡言之**` 一句話壓到極致
