Crea, aggiorna o gestisci report HTML sicuri e con versione in HiGantic. Utilizzare questa capacità solo quando l'utente richiede esplicitamente di creare, aggiornare o gestire un report o un elemento HTML in HiGantic; menziona un'area di lavoro, una pagina o un artefatto HiGantic come destinazione; oppure chiede di gestire revisioni, risorse, visibilità o condivisioni bloccate di HiGantic. Non attivare report generici, visualizzazioni, dashboard, piani, revisioni o confronti senza destinazione HiGantic.
