Bibliothèques open source Trust Wallet – Wallet Core (portefeuilles HD, dérivation d'adresses, signature tx dans Swift/Kotlin/TypeScript/Go pour plus de 140 chaînes), fournisseur Web3 (connexion dApp pour Ethereum/Solana/Cosmos/Bitcoin/Aptos/TON/Tron), liens profonds, intégration d'extensions de navigateur, WalletConnect, référentiel d'actifs de jetons et portefeuille intelligent Barz ERC-4337. À utiliser lorsque vous travaillez avec trustwallet/wallet-core, @trustwallet/wallet-core, trust-web3-provider, les liens profonds Trust Wallet, les logos/métadonnées de jetons de trustwallet/assets ou l'abstraction de compte Barz.
