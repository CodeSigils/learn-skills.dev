Библиотеки с открытым исходным кодом Trust Wallet — Wallet Core (HD-кошельки, деривация адресов, подпись tx в Swift/Kotlin/TypeScript/Go для более чем 140 цепочек), Web3 Provider (соединение dApp для Ethereum/Solana/Cosmos/Bitcoin/Aptos/TON/Tron), глубокие ссылки, интеграция расширений браузера, WalletConnect, хранилище активов токенов и интеллектуальный кошелек Barz ERC-4337. Используйте при работе сtrustwallet/wallet-core, @trustwallet/wallet-core,trust-web3-provider, глубокими ссылками Trust Wallet, логотипами/метаданными токенов из Trustwallet/assets или абстракцией учетной записи Barz.
