Trust Wallet CLI («twak») — установка, создание кошельков, проверка баланса, отправка токенов, обмен, просмотр истории, установка оповещений о ценах, автоматизация DCA, лимитные заказы, управление утверждениями ERC-20, проверка рисков токенов, просмотр трендов/DApps и запуск микроплатежей x402. Используйте всякий раз, когда пользователь хочет использовать интерфейс командной строки twak, управлять криптокошельком с терминала, отправлять или обменивать токены через командную строку, проверять портфель, создавать оповещения о ценах, настраивать DCA, создавать лимитные ордера, утверждать тратителей ERC-20 или взаимодействовать с Trust Wallet из оболочки. Также рассматривается настройка сервера MCP для агентов ИИ.
