Trust Wallet CLI (`twak`) — installez, créez des portefeuilles, vérifiez les soldes, envoyez des jetons, échangez, affichez l'historique, définissez des alertes de prix, des automatisations DCA, des ordres limités, gérez les approbations ERC-20, vérifiez le risque de jeton, parcourez les tendances/DApp et exécutez des micropaiements x402. À utiliser chaque fois que l'utilisateur souhaite utiliser la CLI twak, gérer un portefeuille crypto depuis le terminal, envoyer ou échanger des jetons via la ligne de commande, vérifier le portefeuille, créer des alertes de prix, configurer DCA, créer des ordres limités, approuver les dépenses ERC-20 ou interagir avec Trust Wallet à partir d'un shell. Couvre également la configuration du serveur MCP pour les agents IA.
