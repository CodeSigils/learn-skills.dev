Trust Wallet CLI (`twak`) - التثبيت وإنشاء المحافظ والتحقق من الأرصدة وإرسال الرموز المميزة والمبادلة وعرض السجل وتعيين تنبيهات الأسعار وأتمتة DCA والحد من الطلبات وإدارة موافقات ERC-20 والتحقق من مخاطر الرمز المميز وتصفح الاتجاهات/التطبيقات اللامركزية وتشغيل عمليات الدفع الصغيرة x402. استخدمه عندما يريد المستخدم استخدام twak CLI، أو إدارة محفظة تشفير من الجهاز، أو إرسال الرموز المميزة أو تبديلها عبر سطر الأوامر، أو التحقق من المحفظة، أو إنشاء تنبيهات الأسعار، أو إعداد DCA، أو إنشاء أوامر محددة، أو الموافقة على إنفاق ERC-20، أو التفاعل مع Trust Wallet من shell. يغطي أيضًا إعداد خادم MCP لوكلاء الذكاء الاصطناعي.
