Trust Wallet CLI (「twak」) — インストール、ウォレットの作成、残高の確認、トークンの送信、スワップ、履歴の表示、価格アラートの設定、DCA 自動化、指値注文、ERC-20 承認の管理、トークンのリスクのチェック、トレンド/DApps の参照、x402 マイクロペイメントの実行。ユーザーが twak CLI の使用、端末からの暗号ウォレットの管理、コマンドライン経由のトークンの送信または交換、ポートフォリオの確認、価格アラートの作成、DCA の設定、指値注文の作成、ERC-20 支出者の承認、シェルからの Trust Wallet の操作を行う場合に使用します。 AI エージェント用の MCP サーバーのセットアップについても説明します。
