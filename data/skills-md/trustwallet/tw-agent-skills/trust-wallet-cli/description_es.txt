Trust Wallet CLI (`twak`): instale, cree billeteras, verifique saldos, envíe tokens, intercambie, vea el historial, establezca alertas de precios, automatizaciones DCA, limite órdenes, administre aprobaciones ERC-20, verifique el riesgo de tokens, explore tendencias/DApps y ejecute micropagos x402. Úselo siempre que el usuario quiera usar la CLI de twak, administrar una billetera criptográfica desde la terminal, enviar o intercambiar tokens a través de la línea de comando, verificar la cartera, crear alertas de precios, configurar DCA, crear órdenes limitadas, aprobar gastadores ERC-20 o interactuar con Trust Wallet desde un shell. También cubre la configuración del servidor MCP para agentes de IA.
