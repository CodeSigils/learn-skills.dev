Trust Wallet CLI ("twak"): installa, crea portafogli, controlla i saldi, invia token, scambia, visualizza la cronologia, imposta avvisi sui prezzi, automazioni DCA, ordini limite, gestisci approvazioni ERC-20, controlla il rischio dei token, sfoglia trend/DApp ed esegui micropagamenti x402. Da utilizzare ogni volta che l'utente desidera utilizzare la CLI di twak, gestire un portafoglio crittografico dal terminale, inviare o scambiare token tramite riga di comando, controllare il portafoglio, creare avvisi di prezzo, impostare DCA, creare ordini limite, approvare chi spende ERC-20 o interagire con Trust Wallet da una shell. Copre anche la configurazione del server MCP per gli agenti AI.
