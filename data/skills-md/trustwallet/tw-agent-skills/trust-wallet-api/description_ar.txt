Trust Wallet API لبيانات التشفير - البحث عن الرموز المميزة، والأسعار، والرموز المميزة، وأسعار المبادلة، وبيانات السوق، والفحوصات الأمنية، والتحقق من صحة العنوان، ومعلومات الأصول، وحالة العملة عبر أكثر من 100 سلسلة بلوكتشين. استخدمه عندما يسأل المستخدم عن أسعار العملات المشفرة، أو معلومات الرمز المميز، أو أسعار المبادلة، أو القيمة السوقية، أو العملات المتداولة، أو مخاطر الرمز المميز، أو اكتشاف مصيدة الجذب، أو التحقق من صحة العنوان، أو يريد الاتصال بـ Trust Wallet / tws.trustwallet.com API مباشرة. يغطي مصادقة HMAC-SHA256 والسلاسل المدعومة وجميع نقاط نهاية REST.
