暗号データ​​用の信頼できるウォレット API — 100 以上のブロックチェーンにわたるトークン検索、価格、トレンドトークン、スワップ相場、市場データ、セキュリティチェック、アドレス検証、資産情報、コインステータス。ユーザーが暗号価格、トークン情報、スワップレート、時価総額、トレンドコイン、トークンリスク、ハニーポット検出、アドレス検証について質問する場合、または Trust Wallet / tws.trustwallet.com API を直接呼び出したい場合に使用します。 HMAC-SHA256 認証、サポートされているチェーン、およびすべての REST エンドポイントをカバーします。
