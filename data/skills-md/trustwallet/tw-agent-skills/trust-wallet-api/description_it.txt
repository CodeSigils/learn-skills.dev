API Trust Wallet per dati crittografici: ricerca di token, prezzi, token di tendenza, quotazioni di swap, dati di mercato, controlli di sicurezza, convalida degli indirizzi, informazioni sulle risorse e stato delle monete su oltre 100 blockchain. Da utilizzare ogni volta che l'utente richiede informazioni sui prezzi delle criptovalute, informazioni sui token, tassi di swap, capitalizzazione di mercato, monete di tendenza, rischio dei token, rilevamento degli honeypot, convalida degli indirizzi o desidera chiamare direttamente l'API Trust Wallet/tws.trustwallet.com. Copre l'autenticazione HMAC-SHA256, le catene supportate e tutti gli endpoint REST.
