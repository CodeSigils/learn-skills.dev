API Trust Wallet pour les données cryptographiques : recherche de jetons, prix, jetons de tendance, cotations de swap, données de marché, contrôles de sécurité, validation d'adresse, informations sur les actifs et statut des pièces sur plus de 100 blockchains. À utiliser chaque fois que l'utilisateur pose des questions sur les prix des cryptomonnaies, les informations sur les jetons, les taux de swap, la capitalisation boursière, les tendances des pièces, le risque de jeton, la détection de pot de miel, la validation d'adresse ou souhaite appeler directement l'API Trust Wallet / tws.trustwallet.com. Couvre l'authentification HMAC-SHA256, les chaînes prises en charge et tous les points de terminaison REST.
