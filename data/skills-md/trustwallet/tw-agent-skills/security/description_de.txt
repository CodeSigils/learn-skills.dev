Validieren Sie Wallet-Adressen und prüfen Sie das Token-Risiko – Honeypot-Erkennung, Prüfstatus, Einfrierberechtigung und andere Sicherheitssignale. Verwenden Sie dies, bevor Sie mit einem unbekannten Token oder einer unbekannten Adresse interagieren, wenn jemand fragt: „Ist dieser Token sicher“, „Ist diese Adresse echt“, auf Betrügereien/Tricks prüfen möchte oder eine sorgfältige Sicherheitsprüfung bei einem Vertrag benötigt.
