Ein umfassender Prüfer für alle Agentenfähigkeiten – einschließlich Manus, OpenClaw/ClawHub, Claude, LobeHub oder benutzerdefinierte SKILL.md-basierte Fähigkeiten. Verwenden Sie diesen Skill immer dann, wenn ein Benutzer einen Agenten-Skill vor der Veröffentlichung, Aktualisierung oder Bereitstellung bewerten, prüfen, überprüfen, bewerten oder einer Qualitätsprüfung unterziehen möchte. Deckt zwei harte Veto-Gates ab (strukturelle Redlines + Redlines für die Forschungsintegrität), statische Qualitätsbewertung über 25 Kriterien (ISO 25010 + OpenSSF + Agent), dynamische Testeingabegenerierung, Multi-Mode-Ausführungstests, mehrschichtige Ausgabebewertung mit fünf speziellen Kategorierubriken (Evidence Insight / Protocol Design / Data Analysis / Academic Writing / Other), ein Forschungsveto, das für alle vier Forschungskategorien gilt, die Generierung menschlicher Evaluierungsbetrachter, umsetzbare P0/P1/P2-Optimierungsempfehlungen, und automatische Fähigkeitsverbesserung, die ein ausgefeiltes, produktionsbereites SKILL.md ausgibt. Verwenden Sie es auch immer dann, wenn ein Benutzer „meine Fertigkeit prüfen“, „meine Fertigkeit bewerten“, „meine Fertigkeit verbessern“ sagt oder nach der Bewertung eine korrigierte Version wünscht.
