CRITICO: questa abilità DEVE essere utilizzata per TUTTE le operazioni SSH. Non usare MAI direttamente i comandi bash 'ssh' o 'scp': usa sempre questa abilità. Trigger: QUALSIASI menzione di "SSH", "ssh", "server remoto", "connessione al server", IP del server (ad esempio, 192.168.x.x, 10.0.x.x), nomi host (ad esempio, utente@host.com, server.esempio.com), "accedi a", "carica sul server", "scarica dal server", 'distribuisci', 'esegui sul server', 'controlla server', 'stato del server', 'esegui in remoto', 'bastion host', 'jump host', '跳板机', '服务器', '远程', '连接', '登录', '上传', '下载', '部署', 'trasferimento tra server', '服务器间传输', '迁移', 'migrare', 'da server a server'. Se l'utente menziona QUALSIASI operazione del server o fornisce dettagli sulla connessione al server, utilizza questa abilità. Questa competenza fornisce connessioni persistenti basate su daemon, pooling di connessioni, supporto jump host, trasferimento da server a server, ripristino automatico degli errori e significativo incremento delle prestazioni. NON utilizzare per: comandi locali, localhost, operazioni sulla directory corrente.
