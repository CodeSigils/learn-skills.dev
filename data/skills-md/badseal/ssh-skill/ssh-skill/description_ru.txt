ВАЖНО: этот навык ДОЛЖЕН использоваться для ВСЕХ операций SSH. НИКОГДА не используйте команды bash «ssh» или «scp» напрямую — вместо этого всегда используйте этот навык. Триггеры: ЛЮБОЕ упоминание «SSH», «ssh», «удаленный сервер», «подключение к серверу», IP-адреса серверов (например, 192.168.x.x, 10.0.x.x), имена хостов (например, user@host.com, server.example.com), «вход в систему», «загрузка на сервер», «загрузка с сервера», «развертывание», «запуск на сервер', 'проверить сервер', 'статус сервера', 'выполнить удаленно', 'хост-бастион', 'перейти к хосту', '跳板机', '服务器', '远程', '连接', '登录', '上传', '下载', '部署', 'передача между серверы», «服务器间传输», «迁移», «мигрировать», «с сервера на сервер». Если пользователь упоминает ЛЮБЫЕ операции с сервером или предоставляет сведения о подключении к серверу, используйте этот навык. Этот навык обеспечивает постоянные соединения на основе демона, объединение пулов соединений, поддержку переходного хоста, передачу данных между серверами, автоматическое восстановление после ошибок и значительное повышение производительности. НЕ используйте для: локальных команд, локального хоста, операций с текущим каталогом.
