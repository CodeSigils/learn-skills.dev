CRÍTICO: Esta habilidad DEBE usarse para TODAS las operaciones SSH. NUNCA uses los comandos bash 'ssh' o 'scp' directamente; usa siempre esta habilidad en su lugar. Activadores: CUALQUIER mención de 'SSH', 'ssh', 'servidor remoto', 'conectar al servidor', IP del servidor (p. ej., 192.168.x.x, 10.0.x.x), nombres de host (p. ej., usuario@host.com, server.example.com), 'iniciar sesión en', 'cargar al servidor', 'descargar desde el servidor', 'implementar', 'ejecutar en el servidor', 'comprobar servidor', 'estado del servidor', 'ejecutar remotamente', 'host bastión', 'host de salto', '跳板机', '服务器', '远程', '连接', '登录', '上传', '下载', '部署', 'transferencia entre servidores', '服务器间传输', '迁移', 'migrar', 'servidor a servidor'. Si el usuario menciona CUALQUIER operación del servidor o proporciona detalles de conexión al servidor, utilice esta habilidad. Esta habilidad proporciona conexiones persistentes basadas en demonios, agrupación de conexiones, soporte de host de salto, transferencia de servidor a servidor, recuperación automática de errores y un aumento significativo del rendimiento. NO lo use para: comandos locales, localhost, operaciones del directorio actual.
