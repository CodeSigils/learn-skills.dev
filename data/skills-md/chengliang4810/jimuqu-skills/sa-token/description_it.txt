Assistere nello sviluppo, nella configurazione, nel debug e nella spiegazione del framework di autenticazione delle autorizzazioni Sa-Token. Ogni volta che l'utente menziona Sa-Token, cn.dev33, StpUtil, StpLogic, SaManager, SaTokenConfig, StpInterface, SaTokenDao, @SaCheckLogin/@SaCheckPermission/@SaIgnore, SaRouter, SaInterceptor, SaServletFilter, SaTokenFilter, autenticazione di accesso, autenticazione di autorizzazione/ruolo, espulsione degli utenti offline, sessioni, Token, separazione fronte-retro, Persistenza Redis, sistema multi-account, SSO, OAuth2, chiave API, JWT, firma dell'interfaccia, integrazione Solon/Spring Boot/WebFlux o necessità di verificare API e meccanismi secondo il repository open source Sa-Token ufficiale, è necessario utilizzare questa competenza. Questa competenza registra solo le capacità generali del Sa-Token e non include specifiche specifiche del progetto.
