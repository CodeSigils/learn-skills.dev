Помощь в разработке, настройке, отладке и объяснении структуры аутентификации разрешений Sa-Token. Всякий раз, когда пользователь упоминает Sa-Token, cn.dev33, StpUtil, StpLogic, SaManager, SaTokenConfig, StpInterface, SaTokenDao, @SaCheckLogin/@SaCheckPermission/@SaIgnore, SaRouter, SaInterceptor, SaServletFilter, SaTokenFilter, аутентификацию входа, аутентификацию разрешений/ролей, отключение пользователей от сети, сеансы, токен, разделение спереди и сзади, Постоянство Redis, система с несколькими учетными записями, единый вход, OAuth2, ключ API, JWT, подписывание интерфейса, интеграция Solon/Spring Boot/WebFlux или необходимость проверки API и механизмов в соответствии с официальным репозиторием Sa-Token с открытым исходным кодом, необходимо использовать этот навык. Этот навык фиксирует только общие возможности Sa-Token и не включает каких-либо спецификаций, специфичных для проекта.
