Cartesi Rollups v2 アプリケーションをローカルで実行、テスト、反復します。 CLI バージョンの検出、Cartesi マシン イメージの構築、ローカル devnet の実行、cartesi run の使用、CLI 経由の事前リクエストと検査リクエストの送信、出力の読み取り、現実的なテストのためのフォークされたチェーンでの実行について説明します。ユーザーがローカル環境でアプリを実行したり、ハンドラーをテストしたり、入力を送信したり、出力を読み取ったり、アプリケーションの動作をデバッグしたりする場合は常にこれを使用します。トリガー: 「ローカルで実行」、「cartesi run」、「アプリのテスト」、「入力の送信」、「検査」、「出力の読み取り」、「ローカル devnet」、「Anvil」、「fork」、「健全性チェック」、「cartesi ビルド」。
