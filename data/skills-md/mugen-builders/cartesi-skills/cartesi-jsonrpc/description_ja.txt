JSON-RPC 2.0 API (ポート 10011) を介して、実行中の Cartesi Rollups v2 ノードをクエリします。アプリケーション、エポック、入力、出力 (通知、伝票、DELEGATECALL 伝票)、レポート、またはノードのメタデータをプログラムでリストまたは取得する必要がある場合は、これを使用します。すべての cartesi_ 接頭辞付きメソッド、型定義、ページネーションとフィルタリング パターン、エラー処理、および完全な TypeScript インターフェイス リファレンスをカバーします。トリガー: 「JSON-RPC」、「cartesi_listInputs」、「cartesi_getOutput」、「cartesi_listReports」、「クエリ ノード」、「JSON-RPC API」、「ポート 10011」、「クエリ出力」、「通知の取得」、「伝票の取得」、「エポックのリスト」、「処理された入力の取得」、「ノード バージョン」、「チェーン ID」、 「jsonrpc-api サービス」。
