Best practice per il framework CSS basato sull'utilità Tailwind CSS v4.x. Da utilizzare per lo styling di applicazioni Web con classi di utilità, la creazione di layout reattivi, la personalizzazione di sistemi di progettazione con variabili @theme, la migrazione da v3 a v4, la configurazione della modalità oscura, la creazione di utilità personalizzate con @utility o l'utilizzo di qualsiasi funzionalità Tailwind CSS v4. Questa competenza copre l'intera linea dalla versione v4.x alla versione v4.2, comprese ombre di testo, maschere, proprietà logiche e rilevamento della fonte. Usa questa abilità anche per semplici domande su Tailwind: la v4 ha cambiato molti nomi di classi e modelli di configurazione che fanno inciampare le persone.
