Лучшие практики CSS-фреймворка Tailwind CSS v4.x, ориентированные на утилиту. Используйте при стилизации веб-приложений с помощью служебных классов, создании адаптивных макетов, настройке систем дизайна с помощью переменных @theme, переходе с версии 3 на версию 4, настройке темного режима, создании пользовательских утилит с помощью @utility или работе с любыми функциями Tailwind CSS v4. Этот навык охватывает всю линейку версий от 4.x до 4.2, включая тени текста, маски, логические свойства и обнаружение источника. Используйте этот навык даже для простых вопросов о попутном ветре — в версии 4 были изменены многие имена классов и шаблоны конфигурации, которые сбивают людей с толку.
