Tailwind CSS v4.x ユーティリティファーストの CSS フレームワークのベスト プラクティス。ユーティリティ クラスを使用した Web アプリケーションのスタイル設定、レスポンシブ レイアウトの構築、@theme 変数を使用したデザイン システムのカスタマイズ、v3 から v4 への移行、ダーク モードの構成、@utility を使用したカスタム ユーティリティの作成、または Tailwind CSS v4 機能の操作を行う場合に使用します。このスキルは、テキスト シャドウ、マスク、論理プロパティ、ソース検出を含む、v4.x から v4.2 までの全ラインをカバーします。 Tailwind の単純な質問にもこのスキルを使用してください。v4 では、人々をつまずかせる多くのクラス名と構成パターンが変更されました。
