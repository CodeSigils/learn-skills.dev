Meilleures pratiques du framework CSS axé sur l'utilitaire Tailwind CSS v4.x. À utiliser pour styliser des applications Web avec des classes d'utilitaires, créer des mises en page réactives, personnaliser des systèmes de conception avec des variables @theme, migrer de la v3 vers la v4, configurer le mode sombre, créer des utilitaires personnalisés avec @utility ou travailler avec n'importe quelle fonctionnalité Tailwind CSS v4. Cette compétence couvre toute la gamme v4.x jusqu'à la v4.2, y compris les ombres de texte, les masques, les propriétés logiques et la détection de source. Utilisez cette compétence même pour des questions simples sur Tailwind : la v4 a modifié de nombreux noms de classes et modèles de configuration qui font trébucher les gens.
