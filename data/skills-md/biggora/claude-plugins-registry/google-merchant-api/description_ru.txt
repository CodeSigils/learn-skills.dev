Используйте этот навык всякий раз, когда пользователь хочет работать с API Google Merchant Center, включая новый Merchant API (v1) или устаревший Content API для покупок (v2.1). Триггеры включают в себя: загрузку продуктов или управление ими, фиды продуктов, управление запасами (локальные/региональные), рекламные акции, источники данных, отчеты, обзоры продавцов, обзоры продуктов, настройки доставки, управление учетными записями, отслеживание заказов, источники конверсий или любую интеграцию с Google Shopping. Также используйте для таких задач, как «добавление товаров в Google Shopping», «синхронизация ресурсов с Merchant Center», «настройка фидов товаров», «управление рекламными акциями», «получение отчетов об эффективности покупок», «переход с Content API на Merchant API», «настройка доставки в Merchant Center» или «загрузка данных о товарах в Google». Используйте этот навык, даже если пользователь упоминает фиды товаров электронной коммерции, списки покупок в Google или спецификации данных о товарах, не называя API явно.
