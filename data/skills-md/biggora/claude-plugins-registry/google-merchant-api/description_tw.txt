每當使用者想要使用 Google Merchant Center API（包括新的 Merchant API (v1) 或舊版 Content API for Shopping (v2.1)）時，請使用此技能。觸發器包括：上傳或管理產品、產品 Feed、庫存管理（本地/區域）、促銷、資料來源、報告、商家評論、產品評論、運輸設定、帳戶管理、訂單追蹤、轉換來源或任何 Google 購物整合。也可用於「將產品新增至 Google 購物」、「與 Merchant Center 同步庫存」、「設定產品 Feed」、「管理促銷」、「取得購物效果報告」、「從 Content API 遷移到 Merchant API」、「在 Merchant Center 中配置送貨」或「將產品資料上傳到 Google」等任務。即使用戶在沒有明確命名 API 的情況下提及電子商務產品 Feed、Google 購物清單或產品資料規範，也可以使用此技能。
