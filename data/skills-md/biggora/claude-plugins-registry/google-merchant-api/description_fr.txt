Utilisez cette compétence chaque fois que l'utilisateur souhaite travailler avec les API de Google Merchant Center, y compris la nouvelle API Merchant (v1) ou l'ancienne API de contenu pour Shopping (v2.1). Les déclencheurs incluent : le téléchargement ou la gestion de produits, les flux de produits, la gestion des stocks (local/régional), les promotions, les sources de données, les rapports, les avis des marchands, les avis sur les produits, les paramètres d'expédition, la gestion des comptes, le suivi des commandes, les sources de conversion ou toute intégration de Google Shopping. Utilisez-le également pour des tâches telles que "ajouter des produits à Google Shopping", "synchroniser l'inventaire avec Merchant Center", "configurer les flux de produits", "gérer les promotions", "obtenir des rapports sur les performances d'achat", "migrer de Content API vers Merchant API", "configurer les expéditions dans Merchant Center" ou "télécharger des données produit sur Google". Utilisez cette compétence même lorsque l'utilisateur mentionne des flux de produits de commerce électronique, des listes Google Shopping ou des spécifications de données de produits sans nommer explicitement l'API.
