Utilizza questa competenza ogni volta che l'utente desidera lavorare con le API di Google Merchant Center, inclusa la nuova API Merchant (v1) o la Content API precedente per Shopping (v2.1). I trigger includono: caricamento o gestione di prodotti, feed di prodotti, gestione dell'inventario (locale/regionale), promozioni, origini dati, report, recensioni di commercianti, recensioni di prodotti, impostazioni di spedizione, gestione dell'account, monitoraggio degli ordini, origini di conversione o qualsiasi integrazione di Google Shopping. Utilizzare anche per attività come "aggiungere prodotti a Google Shopping", "sincronizzare l'inventario con Merchant Center", "impostare feed di prodotti", "gestire promozioni", "ottenere rapporti sulle prestazioni degli acquisti", "migrare da Content API a Merchant API", "configurare la spedizione in Merchant Center" o "caricare dati di prodotto su Google". Utilizza questa capacità anche quando l'utente menziona feed di prodotti e-commerce, schede di Google Shopping o specifiche dei dati di prodotto senza nominare esplicitamente l'API.
