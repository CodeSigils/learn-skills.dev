استخدم هذه المهارة عندما يريد المستخدم العمل مع واجهات برمجة تطبيقات Google Merchant Center، بما في ذلك Merchant API الجديدة (الإصدار 1) أو واجهة Content API القديمة للتسوق (الإصدار 2.1). تتضمن المشغلات: تحميل المنتجات أو إدارتها، أو خلاصات المنتجات، أو إدارة المخزون (المحلي/الإقليمي)، أو العروض الترويجية، أو مصادر البيانات، أو التقارير، أو مراجعات التجار، أو مراجعات المنتجات، أو إعدادات الشحن، أو إدارة الحساب، أو تتبع الطلب، أو مصادر التحويل، أو أي تكامل مع Google Shopping. استخدمه أيضًا لمهام مثل "إضافة منتجات إلى Google Shopping"، أو "مزامنة المخزون مع Merchant Center"، أو "إعداد خلاصات المنتجات"، أو "إدارة العروض الترويجية"، أو "الحصول على تقارير أداء التسوق"، أو "الترحيل من Content API إلى Merchant API"، أو "تهيئة الشحن في Merchant Center"، أو "تحميل بيانات المنتج إلى Google". استخدم هذه المهارة حتى عندما يذكر المستخدم خلاصات منتجات التجارة الإلكترونية أو قوائم Google Shopping أو مواصفات بيانات المنتج دون تسمية واجهة برمجة التطبيقات (API) بشكل صريح.
