每当用户想要使用 Google Merchant Center API（包括新的 Merchant API (v1) 或旧版 Content API for Shopping (v2.1)）时，请使用此技能。触发器包括：上传或管理产品、产品 Feed、库存管理（本地/区域）、促销、数据源、报告、商家评论、产品评论、运输设置、帐户管理、订单跟踪、转化来源或任何 Google 购物集成。还可用于“将产品添加到 Google 购物”、“与 Merchant Center 同步库存”、“设置产品 Feed”、“管理促销”、“获取购物效果报告”、“从 Content API 迁移到 Merchant API”、“在 Merchant Center 中配置送货”或“将产品数据上传到 Google”等任务。即使用户在没有明确命名 API 的情况下提及电子商务产品 Feed、Google 购物列表或产品数据规范，也可以使用此技能。
