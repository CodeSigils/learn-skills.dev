Verwenden Sie diesen Skill immer dann, wenn der Nutzer mit Google Merchant Center-APIs arbeiten möchte, einschließlich der neuen Merchant API (v1) oder der alten Content API für Shopping (v2.1). Zu den Auslösern gehören: Hochladen oder Verwalten von Produkten, Produkt-Feeds, Bestandsverwaltung (lokal/regional), Werbeaktionen, Datenquellen, Berichte, Händlerbewertungen, Produktbewertungen, Versandeinstellungen, Kontoverwaltung, Auftragsverfolgung, Conversion-Quellen oder jede Google Shopping-Integration. Auch für Aufgaben wie „Produkte zu Google Shopping hinzufügen“, „Inventar mit Merchant Center synchronisieren“, „Produkt-Feeds einrichten“, „Werbeaktionen verwalten“, „Einkaufsleistungsberichte abrufen“, „Von Content API zur Merchant API migrieren“, „Versand im Merchant Center konfigurieren“ oder „Produktdaten auf Google hochladen“ verwenden. Nutzen Sie diese Fähigkeit auch dann, wenn der Benutzer E-Commerce-Produkt-Feeds, Google Shopping-Einträge oder Produktdatenspezifikationen erwähnt, ohne die API explizit zu benennen.
