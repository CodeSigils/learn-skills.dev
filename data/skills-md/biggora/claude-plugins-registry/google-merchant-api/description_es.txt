Utilice esta habilidad siempre que el usuario quiera trabajar con las API de Google Merchant Center, incluida la nueva API de comerciante (v1) o la API de contenido heredada para compras (v2.1). Los activadores incluyen: cargar o administrar productos, feeds de productos, administración de inventario (local/regional), promociones, fuentes de datos, informes, reseñas de comerciantes, reseñas de productos, configuración de envío, administración de cuentas, seguimiento de pedidos, fuentes de conversión o cualquier integración de Google Shopping. Úselo también para tareas como "agregar productos a Google Shopping", "sincronizar inventario con Merchant Center", "configurar feeds de productos", "administrar promociones", "obtener informes de rendimiento de compras", "migrar de Content API a Merchant API", "configurar envíos en Merchant Center" o "cargar datos de productos a Google". Utilice esta habilidad incluso cuando el usuario mencione feeds de productos de comercio electrónico, listados de Google Shopping o especificaciones de datos de productos sin nombrar explícitamente la API.
