ユーザーが新しい Merchant API (v1) や従来の Content API for Shopping (v2.1) などの Google Merchant Center API を操作する場合は常にこのスキルを使用します。トリガーには、商品のアップロードまたは管理、商品フィード、在庫管理 (ローカル/地域)、プロモーション、データ ソース、レポート、販売者レビュー、商品レビュー、配送設定、アカウント管理、注文追跡、コンバージョン ソース、または Google ショッピングの統合が含まれます。 「Google ショッピングへの商品の追加」、「Merchant Center と在庫の同期」、「商品フィードの設定」、「プロモーションの管理」、「ショッピング パフォーマンス レポートの取得」、「Content API から Merchant API への移行」、「Merchant Center での配送の設定」、「Google への商品データのアップロード」などのタスクにも使用します。ユーザーが API に明示的に名前を付けずに、e コマースの商品フィード、Google ショッピングのリスト、または商品データの仕様に言及する場合でも、このスキルを使用します。
