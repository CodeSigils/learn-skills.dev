Utilizza questa competenza ogni volta che l'utente desidera lavorare con le piattaforme lettoni di confronto/aggregazione dei prezzi, in particolare Salidzini.lv o KurPirkt.lv. I trigger includono: creazione o generazione di feed di prodotti XML, integrazione di un negozio e-commerce con aggregatori lettoni, esportazione di cataloghi di prodotti per salidzini o kurpirkt, convalida del formato di feed XML, debug di errori di feed, impostazione dell'esportazione di dati di prodotto per siti di confronto dei prezzi lettoni o qualsiasi menzione di "salidzini", "kurpirkt", "cenu salīdzināšana", "preču eksports", "XML feed Lettonia", "integrazione del mercato lettone" o "feed aggregatore di prezzi". Da utilizzare anche quando l'utente menziona feed di prodotti e-commerce per il mercato lettone, esporta dati di prodotto nel contesto LV o desidera elencare prodotti sui motori di shopping comparativo lettoni, anche senza nominare una piattaforma specifica.
