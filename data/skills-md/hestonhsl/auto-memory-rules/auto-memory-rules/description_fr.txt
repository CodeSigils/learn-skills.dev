Scénarios de déclenchement :  
(1) Demandes de mémoire explicites : mémoriser, enregistrer, ne pas oublier, noter pour la prochaine fois, former une règle, générer un document résumé/enregistrer ;  
(2) Corrections et modifications — faites attention, c'est faux, incorrect, cela devrait être, changer, remplacer par, ce n'est pas nécessaire, ce n'est pas nécessaire, ce n'est pas nécessaire ;  
(3) Expressions de préférence — Je préfère, désormais, c'est mieux, je suggère, mon habitude, j'ai l'habitude ;  
(4) Normes mondiales : unifier tout, tout, toujours, tout, chaque, à chaque fois, entièrement, sans exception ;  
(5) Règlement de fin de conversation – lorsque la conversation se termine naturellement ou que le sujet change. Convertissez les corrections, les préférences et les règles de l’utilisateur en fichiers de mémoire structurée pour améliorer la qualité des sorties de dialogue ultérieures.
