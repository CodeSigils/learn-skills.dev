트리거 시나리오:  
(1) 명시적 기억 요청 - 기억하기, 기록하기, 잊지 않기, 다음 시간을 위해 메모하기, 규칙 작성하기, 요약 생성하기/문서 기록하기,  
(2) 정정 - 참고, 틀렸음, 올바르지 않음, 변경해야 함, 교체해야 함, 필요 없음, 누락됨;  
(3) 선호 표현 - 나는 평소에 내 습관을 선호합니다.  
(4) 글로벌 규범 - 모든, 모든, 어떤, 각각, 매번, 모든 경우를 예외 없이 통합합니다.  
(5) 대화 종료 해결 - 대화가 자연스럽게 끝나거나 주제가 바뀔 때. 사용자 수정, 기본 설정 및 규칙을 구조화된 메모리 파일로 변환하여 후속 대화에서 출력 품질을 향상시킵니다.
