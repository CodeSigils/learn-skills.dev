Создает запросы на включение с проверкой двуязычной документации. Используйте, когда пользователь просит создать PR, сделать запрос на включение или отправить изменения на проверку. Обеспечивает синхронизацию файлов README на английском и китайском языках, когда этого требуют изменения каталога навыков, ориентированных на пользователя.
