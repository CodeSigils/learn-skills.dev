Erstellt Pull-Requests mit zweisprachigen Dokumentationsprüfungen. Verwenden Sie diese Option, wenn der Benutzer eine PR erstellen, eine Pull-Anfrage stellen oder Änderungen zur Überprüfung einreichen möchte. Stellt sicher, dass englische und chinesische README-Dateien synchron bleiben, wenn benutzerseitige Änderungen im Fertigkeitskatalog dies erfordern.
