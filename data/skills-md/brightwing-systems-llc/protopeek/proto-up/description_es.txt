Cargue un prototipo HTML autónomo en ProtoPeek (protopeek.dev) e imprima el enlace de revisión privado que se puede compartir. Volver a ejecutar el mismo archivo publica una nueva versión detrás del mismo enlace. Úselo cuando el usuario quiera compartir un prototipo para revisarlo, publicar una nueva versión de uno o decir "proto-up".
