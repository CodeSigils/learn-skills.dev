Laden Sie einen eigenständigen HTML-Prototyp auf ProtoPeek (protopeek.dev) hoch und drucken Sie den privaten, gemeinsam nutzbaren Bewertungslink aus. Durch die erneute Ausführung derselben Datei wird eine neue Version hinter demselben Link veröffentlicht. Verwenden Sie diese Option, wenn der Benutzer einen Prototyp zur Überprüfung freigeben, eine neue Version davon veröffentlichen oder „Proto-Up“ sagen möchte.
