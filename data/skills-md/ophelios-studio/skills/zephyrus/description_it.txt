Da utilizzare quando si lavora in un progetto framework Zephyrus PHP (`zephyrus-framework/core`). Trigger sull'instradamento degli attributi (`#[Get]`, `#[Post]`, `#[Put]`, `#[Patch]`, `#[Delete]`, `#[Root]`, `#[Middleware]`, `#[RequiresEnv]`), `ApplicationBuilder`, `Controller`, tratto `RenderResponses`, oggetti valore `Request`/`Response`, `Configuration::fromYamlFile`, sottoclassi `ConfigSection`, modelli Latte in `app/Views/`, layer Broker/Service/Entity, estensioni `Zephyrus\Data\Broker` o `Zephyrus\Data\Entity`, rilevamento automatico del controller e la forma `config.yml` con sezioni `application:`/`render:`/`localization:`/`security:`/`database:`. Copre il routing degli attributi con scoping del controller basato su MODE (una base di codice, più punti di ingresso), registrazione del middleware denominato rispetto all'applicazione degli attributi, pattern Broker SQL raw con stratificazione di servizio/entità, sanificazione dei bytea PostgreSQL, factory di controller personalizzata per l'iniezione del motore di rendering, analisi di `DATABASE_URL` per distribuzioni cloud, DECIMAL-as-string per precisione monetaria, bootstrap di nuovi DB per test con test di integrazione isolati dalle transazioni, impaginazione di keyset (cursore) e la filosofia no-ORM/no-migration. Modelli empirici tratti dalla produzione "immunity-app".
