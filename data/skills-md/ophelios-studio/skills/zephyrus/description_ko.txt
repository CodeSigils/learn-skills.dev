Zephyrus PHP 프레임워크 프로젝트(`zephyrus-framework/core`)에서 작업할 때 사용합니다. 속성 라우팅(`#[Get]`, `#[Post]`, `#[Put]`, `#[Patch]`, `#[Delete]`, `#[Root]`, `#[Middleware]`, `#[RequiresEnv]`), `ApplicationBuilder`, `Controller`, `RenderResponses` 특성, `Request`/`Response` 값 개체, `Configuration::fromYamlFile`에서 트리거됩니다. `ConfigSection` 하위 클래스, `app/Views/`의 Latte 템플릿, Broker/Service/Entity 계층화, `Zephyrus\Data\Broker` 또는 `Zephyrus\Data\Entity` 확장, 컨트롤러 자동 검색 및 `application:`/`render:`/`localization:`/`security:`/`database:` 섹션이 있는 `config.yml` 모양. MODE 기반 컨트롤러 범위 지정(1개의 코드베이스, 여러 진입점)을 사용한 속성 라우팅, 명명된 미들웨어 등록과 속성 애플리케이션, 서비스/엔티티 계층이 포함된 원시 SQL 브로커 패턴, PostgreSQL bytea 삭제, 렌더링 엔진 삽입을 위한 사용자 정의 컨트롤러 팩토리, 클라우드 배포를 위한 'DATABASE_URL' 구문 분석, 돈의 정확성을 위한 DECIMAL-as-string, 트랜잭션 격리 통합 테스트가 포함된 테스트당 신선한 DB 부트스트랩, 키 세트(커서) 페이지 매김 및 no-ORM/no-migration 철학. '면역 앱' 제작에서 도출된 경험적 패턴.
