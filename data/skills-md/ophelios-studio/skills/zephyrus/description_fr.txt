À utiliser lorsque vous travaillez dans un projet de framework PHP Zephyrus (`zephyrus-framework/core`). Déclencheurs sur le routage des attributs (`#[Get]`, `#[Post]`, `#[Put]`, `#[Patch]`, `#[Delete]`, `#[Root]`, `#[Middleware]`, `#[RequiresEnv]`), `ApplicationBuilder`, `Controller`, trait `RenderResponses`, Objets de valeur `Request`/`Response`, `Configuration::fromYamlFile`, sous-classes `ConfigSection`, modèles Latte dans `app/Views/`, superposition Broker/Service/Entity, `Zephyrus\Data\Broker` ou `Zephyrus\Data\Entity`, découverte automatique du contrôleur et forme `config.yml` avec `application:`/`render:`/`localisation:`/`security:`/`database:` sections. Couvre le routage des attributs avec la portée du contrôleur basé sur MODE (une base de code, plusieurs points d'entrée), l'enregistrement du middleware nommé par rapport à l'application d'attributs, le modèle de courtier SQL brut avec superposition de services/entités, la désinfection des octets PostgreSQL, l'usine de contrôleurs personnalisée pour l'injection du moteur de rendu, l'analyse `DATABASE_URL` pour les déploiements dans le cloud, DECIMAL-as-string pour la précision de l'argent, l'amorçage d'une nouvelle base de données par test avec des tests d'intégration isolés par transaction, le jeu de clés (curseur) la pagination et la philosophie sans ORM/sans migration. Modèles empiriques tirés de l'application d'immunité de production.
