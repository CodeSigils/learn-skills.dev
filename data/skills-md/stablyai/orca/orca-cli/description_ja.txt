Orca CLI を使用して、実行中の Orca エディターを通じてワークツリーとライブ端末を調整します。エージェントが Orca ワークツリーを作成、検査、更新、または削除する必要がある場合に使用します。 Orca に知られているリポジトリの状態を検査します。または、Orca 管理の端末の読み取り、送信、待機、または停止を行います。トリガーには、「orca cli の使用」、「Orca ワークツリーの管理」、「Orca ターミナルの読み取り」、「Orca でのクロード コードへの返信」、「Orca でのワークツリーの作成」、またはエージェントが git ワークツリーやターミナル プロセスと直接通信するのではなく、Orca を通じて動作する必要があるタスクが含まれます。
