Utilisez la CLI Orca pour orchestrer les arbres de travail et les terminaux en direct via un éditeur Orca en cours d'exécution. À utiliser lorsqu'un agent doit créer, inspecter, mettre à jour ou supprimer des arbres de travail Orca ; inspecter l'état du dépôt connu d'Orca ; ou lire, envoyer, attendre ou arrêter les terminaux gérés par Orca. Les déclencheurs incluent "utiliser orca cli", "gérer les arbres de travail Orca", "lire le terminal Orca", "répondre au code Claude dans Orca", "créer un arbre de travail dans Orca", ou toute tâche où l'agent doit opérer via Orca au lieu de parler directement aux arbres de travail git et aux processus du terminal.
