Configura, rivedi, esegui il debug o convalida le ricette dell'ambiente Orca per ogni area di lavoro: runtime usa e getta on-demand (sandbox cloud, VM o locali) creati di recente per ogni area di lavoro. Copre la configurazione iniziale (prerequisiti del provider, snapshot di base riutilizzabile, snapshot di autenticazione dell'agente di codifica, credenziali e stato), non solo gli script del ciclo di vita per area di lavoro. Da utilizzare per gestire ambienti per area di lavoro, correggere una voce "environmentRecipes" in "orca.yaml", script del ciclo di vita del provider di impalcature o risolvere un errore di "orca vm Recipe Doctor".
