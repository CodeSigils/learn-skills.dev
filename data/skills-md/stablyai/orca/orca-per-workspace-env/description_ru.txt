Настраивайте, просматривайте, отлаживайте или проверяйте рецепты среды Orca для каждого рабочего пространства — одноразовые среды выполнения по требованию (облачные песочницы, виртуальные машины или локальные), создаваемые заново для каждого рабочего пространства. Охватывает первоначальную настройку (предварительные требования поставщика, повторно используемый базовый снимок, снимок аутентификации агента кодирования, учетные данные и состояние), а не только сценарии жизненного цикла для каждой рабочей области. Используйте для поддержки сред для каждой рабочей области, исправления записи `environmentRecipes` в `orca.yaml`, сценариев жизненного цикла поставщика строительных лесов или устранения сбоя `orca vm Рецепт доктора`.
