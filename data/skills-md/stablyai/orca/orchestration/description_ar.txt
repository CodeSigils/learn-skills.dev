استخدم Orca CLI لتنسيق وكلاء الترميز المتعددين عبر المراسلة بين الوكلاء، وDAGs للمهام، والإرسال باستخدام حقن التمهيد، وبوابات القرار، وحلقات المنسق. يُستخدم عندما يحتاج الوكيل إلى إرسال رسائل بين الوكلاء أو التحقق منها؛ إنشاء مهام التنسيق أو إرسالها أو تتبعها؛ تنسيق سير العمل متعدد الوكلاء؛ أو العمل كمنسق لإرسال العمل عبر المحطات. تتضمن المشغلات "وكلاء التنسيق"، أو "مهمة الإرسال"، أو "إرسال رسالة إلى الوكيل"، أو "التحقق من البريد الوارد"، أو "الوكلاء المنسقون"، أو "الوكلاء المتعددون"، أو "إنشاء مهمة DAG"، أو "worker_done"، أو "التصعيد"، أو أي مهمة تتضمن التنسيق بين الوكلاء من خلال Orca.
