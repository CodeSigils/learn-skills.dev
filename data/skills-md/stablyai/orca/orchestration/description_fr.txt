Utilisez la CLI Orca pour coordonner plusieurs agents de codage via la messagerie inter-agents, les DAG de tâches, la répartition avec injection de préambule, les portes de décision et les boucles de coordination. À utiliser lorsqu'un agent doit envoyer ou vérifier des messages inter-agents ; créer, répartir ou suivre des tâches d'orchestration ; coordonner les flux de travail multi-agents ; ou agir en tant que coordinateur en répartissant le travail entre les terminaux. Les déclencheurs incluent "orchestrer les agents", "tâche de répartition", "envoyer un message à l'agent", "vérifier la boîte de réception", "coordonner les agents", "multi-agent", "créer une tâche DAG", "worker_done", "escalade" ou toute tâche impliquant une coordination inter-agents via Orca.
