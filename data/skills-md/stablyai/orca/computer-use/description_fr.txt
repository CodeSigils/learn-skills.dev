Utilisez la CLI sur ordinateur d'Orca pour inspecter et contrôler les applications de bureau locales via des arborescences d'accessibilité, des captures d'écran et des actions sécurisées de l'interface utilisateur. À utiliser lorsqu'un agent doit répertorier les applications de bureau, obtenir l'état d'une application, lire l'interface utilisateur visible, cliquer, saisir, appuyer sur des touches, faire défiler, faire glisser, définir des valeurs ou effectuer des actions d'accessibilité des applications. Les déclencheurs incluent « utilisation de l'ordinateur », « ordinateur orca », « liste des applications », « obtenir l'état de l'application », « lire Spotify », « lire Slack », « cliquer sur l'application », « saisir du texte », « appuyer sur la touche », « définir la valeur », « faire défiler l'application », « faire glisser l'application » et les tâches d'interaction avec l'application de bureau.
