Orca のコンピュータ用 CLI を使用して、アクセシビリティ ツリー、スクリーンショット、安全な UI アクションを通じてローカル デスクトップ アプリを検査および制御します。エージェントがデスクトップ アプリの一覧表示、アプリの状態の取得、表示されている UI の読み取り、クリック、入力、キーの押し、スクロール、ドラッグ、値の設定、またはアプリのアクセシビリティ アクションの実行を行う必要がある場合に使用します。トリガーには、「コンピューターの使用」、「orca コンピューター」、「アプリの一覧表示」、「アプリの状態の取得」、「Spotify の読み取り」、「Slack の読み取り」、「アプリのクリック」、「テキストの入力」、「キーを押す」、「値の設定」、「アプリのスクロール」、「アプリのドラッグ」、およびデスクトップ アプリのインタラクション タスクが含まれます。
