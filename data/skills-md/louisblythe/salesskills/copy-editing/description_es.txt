Cuando el usuario desea editar, revisar o mejorar mensajes, correos electrónicos o scripts de ventas. Úselo también cuando el usuario mencione "editar este correo electrónico", "revisar mi alcance", "mejorar este discurso", "mejorarlo", "comentar sobre mi mensaje" o "pulir este guión". Esta habilidad proporciona un enfoque sistemático para editar la comunicación de ventas.
