Lorsque l'utilisateur souhaite créer ou améliorer la capacité d'un robot de vente à extraire des points de données clés (budget, calendrier, taille de l'entreprise, emplacement, exigences) à partir de réponses non structurées des prospects. À utiliser également lorsque l'utilisateur mentionne « extraire des données », « analyser les réponses », « extraire des détails », « données structurées à partir de conversations » ou « NER pour les ventes ».
