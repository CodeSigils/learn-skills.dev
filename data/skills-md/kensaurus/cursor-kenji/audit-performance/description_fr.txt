Auditer et optimiser les performances des applications. À utiliser pour optimiser les performances, déboguer du code lent, réduire les temps de chargement ou lorsque l'utilisateur mentionne des problèmes de performances. Intègre Sentry MCP pour les données de performances de production (Web Vitals, transactions lentes), Firecrawl pour la recherche des techniques d'optimisation actuelles et l'analyse automatisée de la base de code.
