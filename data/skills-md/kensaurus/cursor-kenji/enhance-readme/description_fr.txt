Transformez un fichier README en texte brut en une vitrine visuellement riche avec une image de héros adaptée au thème, une grille de visite des fonctionnalités, un GIF de visite guidée animée en option et des badges techniques mis à jour. Capture des captures d'écran en direct via playwright-cli en mode sombre et clair en qualité héros 1600x1000, les associe à `<picture>` pour un échange de thème automatique et les intègre dans le README à l'aide du HTML pris en charge par GitHub. Enregistre éventuellement une visite guidée `.gif` (lecture automatique en ligne sur github.com via `record-readme-tour.mjs`) pour une démo animée au-dessus des captures d'écran statiques. Fonctionne avec n'importe quelle application Web dotée d'une URL en direct ou d'un serveur de développement local. À utiliser lorsqu'on vous le demande pour « améliorer le README », « rendre le README plus joli », « ajouter des captures d'écran au README », « présenter l'application dans le README », « concevoir le README », « ajouter une image de héros », « pimenter le README », « rendre le README plus amusant », « ajouter une démo animée au README », « enregistrer un GIF de visite » ou « créer un GIF README ».
