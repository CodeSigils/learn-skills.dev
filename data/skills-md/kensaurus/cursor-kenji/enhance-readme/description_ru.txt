Захватывает живые снимки экрана через playwright-cli как в темном, так и в светлом режиме с героическим качеством 1600x1000, объединяет их с `<picture>` для автоматической замены тем и встраивает их в README с использованием HTML, поддерживаемого GitHub. При необходимости записывает экскурсию `.gif` (автоматически воспроизводится на github.com через `record-readme-tour.mjs`) для анимированной демонстрации над статическими скриншотами. Работает с любым веб-приложением, имеющим действующий URL-адрес или локальный сервер разработки.
