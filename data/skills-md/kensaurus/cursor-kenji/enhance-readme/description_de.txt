Erfasst Live-Screenshots über playwright-cli sowohl im dunklen als auch im hellen Modus in Heldenqualität 1600 x 1000, verknüpft sie mit „<picture>“ für den automatischen Themenwechsel und integriert sie mithilfe von GitHub-unterstütztem HTML in die README-Datei. Zeichnet optional eine geführte Tour „.gif“ auf (automatische Inline-Wiedergabe auf github.com über „record-readme-tour.mjs“) für eine animierte Demo über den statischen Screenshots. Funktioniert mit jeder Web-App, die über eine Live-URL oder einen lokalen Entwicklungsserver verfügt.
