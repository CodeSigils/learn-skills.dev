Проведите аудит приложения на базе LLM на предмет неконтролируемых расходов и злоупотреблений квотами, а затем разработайте поэтапный план ограждения. Используйте, когда пользователь говорит «ограничить мои расходы на ИИ», «мой счет за LLM может взорваться», «ограничить ставку моего ИИ», «бюджет токенов», «исчерпать мою квоту API», «цикл неконтролируемого агента», «ограничения ИИ для каждого пользователя» или усиливает функции LLM перед запуском. Стоимость масштабируется с помощью токенов, а не подсчета запросов — ограничения RPM не учитывают реальный риск. Аудит трехуровневого шаблона: ограничения на сегменты токенов, автоматические выключатели стоимости и скорости, резервная цепочка (более дешевая модель → кэш → 503), а также оповещения о затратах Langfuse и учет использования потоковой передачи. Перекрестное оперативное внедрение и мошенничество с квотами с помощью поддельных веб-перехватчиков для проверки ввода плана. Планируйте только до одобрения. Сочетается с Audit-langfuse-llm, plan-input-validation. НЕ используйте для выходных оценок (audit-langfuse-llm).
