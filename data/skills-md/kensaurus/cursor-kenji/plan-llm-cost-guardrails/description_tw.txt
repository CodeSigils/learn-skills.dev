審核法學碩士支援的應用程式是否存在成本失控和配額濫用風險，然後製定分階段的護欄計劃。當用戶說「限制我的 AI 成本」、「我的 LLM 帳單可能會爆炸」、「對我的 AI 進行速率限制」、「代幣預算」、「耗盡我的 API 配額」、「失控的代理循環」、「每用戶 AI 限制」或在發布前強化 LLM 功能時使用。成本與代幣無關，而不是請求數量——RPM 限制忽略了真正的風險。審核 3 層模式：令牌桶限制、成本速度斷路器、後備鏈（較便宜的型號 → 快取 → 503），以及 Langfuse 成本警報和串流使用統計。交叉手提示注入和偽造 webhook 配額詐欺來規劃輸入驗證。僅計劃直至獲得批准。與audit-langfuse-llm、計畫輸入驗證配對。請勿用於輸出評估 (audit-langfuse-llm)。
