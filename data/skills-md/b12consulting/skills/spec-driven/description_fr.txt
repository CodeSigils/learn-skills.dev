Référence de méthodologie de projet basée sur les spécifications. À utiliser lorsqu'un projet dispose d'un dossier de spécifications pour gérer les exigences du produit, la vision, les objectifs, l'architecture, les enregistrements de décision (ADR), le glossaire, le journal des modifications et le suivi des travaux basé sur des tickets. Chargé lorsque : vous travaillez sur un projet avec specs/; lire ou mettre à jour le PRD, la vision, les objectifs, l'architecture ou le glossaire ; détecter la dérive entre le code et les spécifications ; examiner la méthodologie du projet ou les formats de documents. Déclencheurs sur : "spécifications", "PRD", "vision", "objectifs", "architecture", "ADR", "enregistrement de décision", "glossaire", "journal des modifications", "ticket", "méthodologie du projet", "vérité terrain".
