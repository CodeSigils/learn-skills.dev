Atlassian CLI (acli) 的參考指南 - 用於與 Jira Cloud 和 Atlassian 組織管理互動的命令列工具。當使用者想要執行 Jira 操作（建立/編輯/搜尋/轉換工作項目、管理專案、看板、衝刺、過濾器、儀表板）、管理 Atlassian 組織（管理使用者、身分驗證）或從終端自動化 Atlassian 工作流程時，請使用此技能。涵蓋所有 acli 命令，包括：jira workitem（建立、編輯、搜尋、分配、轉換、註解、複製、連結、存檔）、jira 專案（建立、清單、更新、存檔）、jira board/sprint、jira 過濾器/儀表板、admin 使用者管理和 rovodev（Rovo Dev Dev AI 代理）。需要係統上已安裝經過驗證的 acli 二進位。
