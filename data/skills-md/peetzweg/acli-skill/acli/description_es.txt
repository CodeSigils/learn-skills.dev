Guía de referencia para Atlassian CLI (acli): una herramienta de línea de comandos para interactuar con Jira Cloud y la administración de organizaciones de Atlassian. Utilice esta habilidad cuando el usuario quiera realizar operaciones de Jira (crear/editar/buscar/transición de elementos de trabajo, administrar proyectos, tableros, sprints, filtros, paneles), administrar organizaciones de Atlassian (administrar usuarios, autenticación) o automatizar flujos de trabajo de Atlassian desde la terminal. Cubre todos los comandos de acli, incluidos: jira workitem (crear, editar, buscar, asignar, hacer transición, comentar, clonar, vincular, archivar), jira project (crear, enumerar, actualizar, archivar), jira board/sprint, jira filter/dashboard, administración de usuarios y rovodev (agente Rovo Dev AI). Requiere un binario acli autenticado ya instalado en el sistema.
