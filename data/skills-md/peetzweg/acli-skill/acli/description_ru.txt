Справочное руководство по Atlassian CLI (acli) — инструменту командной строки для взаимодействия с Jira Cloud и администрирования организации Atlassian. Используйте этот навык, когда пользователь хочет выполнять операции Jira (создавать/редактировать/поиск/перемещать рабочие элементы, управлять проектами, досками, спринтами, фильтрами, информационными панелями), администрировать организации Atlassian (управлять пользователями, аутентификацию) или автоматизировать рабочие процессы Atlassian с терминала. Охватывает все команды acli, включая: рабочий элемент jira (создание, редактирование, поиск, назначение, переход, комментирование, клонирование, ссылка, архив), проект jira (создание, список, обновление, архив), доску/спринт jira, фильтр/панель мониторинга jira, управление пользователями администратора и rovodev (агент Rovo Dev AI). Требуется проверенный двоичный файл ali, уже установленный в системе.
