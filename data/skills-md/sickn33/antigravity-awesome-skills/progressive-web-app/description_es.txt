Cree aplicaciones web progresivas (PWA) con soporte fuera de línea, instalabilidad y estrategias de almacenamiento en caché. Se activa cada vez que el usuario menciona PWA, trabajadores de servicios, manifiestos de aplicaciones web, Workbox, "agregar a la pantalla de inicio" o quiere que su aplicación web funcione sin conexión, se sienta nativa o sea instalable.
