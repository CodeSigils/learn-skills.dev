Создавайте приложения, которые программно взаимодействуют с GitHub Copilot. SDK объединяет интерфейс командной строки Copilot через JSON-RPC, обеспечивая управление сеансами, пользовательские инструменты, перехватчики, интеграцию с сервером MCP и потоковую передачу через Node.js, Python, Go и .NET.
