Uno stile di architettura portatile e indipendente dal framework per qualsiasi frontend React o React Native. Organizza le app in moduli di funzionalità con directory pagina/schermata, una rigorosa suddivisione tra stato del server e stato dell'interfaccia utente, importazioni tra moduli solo barile, stili co-ubicati e regole chiare per la promozione dei componenti....
