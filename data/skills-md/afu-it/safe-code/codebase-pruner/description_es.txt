Escanee una base de código completa para detectar y eliminar de forma segura código inactivo, como funciones no utilizadas, módulos huérfanos, exportaciones sin referencia, configuraciones obsoletas, rutas inactivas y artefactos de flujo de trabajo sobrantes. Úselo cuando se le solicite limpiar código inactivo, eliminar código no utilizado, eliminar archivos obsoletos, encontrar módulos huérfanos, auditar el exceso de código base o eliminar el código que queda después de un cambio de flujo de trabajo o arquitectura.
