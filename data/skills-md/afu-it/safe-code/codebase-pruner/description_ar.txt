قم بمسح قاعدة التعليمات البرمجية بالكامل لاكتشاف التعليمات البرمجية الميتة وإزالتها بأمان مثل الوظائف غير المستخدمة والوحدات المعزولة والصادرات غير المرجعية والتكوينات القديمة والمسارات الميتة وعناصر سير العمل المتبقية. استخدمه عندما يُطلب منك تنظيف التعليمات البرمجية الميتة، أو إزالة التعليمات البرمجية غير المستخدمة، أو تقليم الملفات التي لا معنى لها، أو العثور على الوحدات المعزولة، أو تدقيق قاعدة التعليمات البرمجية المتضخمة، أو حذف التعليمات البرمجية المتبقية بعد تغيير سير العمل أو البنية.
