Esegui la scansione di un'intera base di codice per rilevare e rimuovere in modo sicuro il codice morto come funzioni inutilizzate, moduli orfani, esportazioni senza riferimenti, configurazioni obsolete, percorsi morti e artefatti rimanenti del flusso di lavoro. Da utilizzare quando viene richiesto di ripulire codice morto, rimuovere codice inutilizzato, eliminare file obsoleti, trovare moduli orfani, controllare il rigonfiamento della base di codice o eliminare il codice rimasto dopo una modifica del flusso di lavoro o dell'architettura.
