Analysez l'intégralité d'une base de code pour détecter et supprimer en toute sécurité le code mort tel que les fonctions inutilisées, les modules orphelins, les exportations non référencées, les configurations obsolètes, les routes mortes et les artefacts de flux de travail restants. À utiliser lorsqu'on vous demande de nettoyer le code mort, de supprimer le code inutilisé, d'élaguer les fichiers obsolètes, de rechercher des modules orphelins, d'auditer l'encombrement de la base de code ou de supprimer le code laissé après un flux de travail ou une modification d'architecture.
