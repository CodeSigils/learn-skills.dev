قم بإعادة بناء التعليمات البرمجية بأمان في شرائح صغيرة تم التحقق منها مع الحفاظ على مزامنة مستندات استمرارية الريبو داخل المجلد الخاص بالوكيل النشط. يُستخدم عندما يُطلب من الوكيل إعادة البناء، أو إعادة الهيكلة، أو التنظيف، أو إزالة أو استبدال التعليمات البرمجية، أو تحديث الوحدات، أو متابعة النظافة في الريبو.
