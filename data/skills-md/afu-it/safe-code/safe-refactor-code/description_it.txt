Effettua il refactoring del codice in modo sicuro in piccole sezioni verificate mantenendo sincronizzati i documenti di continuità del repository all'interno della cartella dell'agente attivo. Da utilizzare quando a un agente viene richiesto di effettuare il refactoring, ristrutturare, ripulire, rimuovere o sostituire il codice, modernizzare i moduli o eseguire operazioni di follow-up in un repository.
