Безопасно проводите рефакторинг кода в небольших проверенных фрагментах, сохраняя при этом синхронизацию документов о непрерывности репозитория внутри собственной папки активного агента. Используйте, когда агенту предлагается выполнить рефакторинг, реструктуризацию, очистку, удаление или замену кода, модернизацию модулей или выполнение последующих гигиенических действий в репозитории.
