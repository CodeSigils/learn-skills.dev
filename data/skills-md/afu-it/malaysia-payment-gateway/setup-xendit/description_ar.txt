قم بإعداد وبناء وتصحيح الأخطاء وشرح عمليات تكامل بوابة الدفع Xendit، بما في ذلك Payments API v3 وطلبات الدفع ورموز الدفع وخطافات الويب والمبالغ المستردة وتوجيه الحساب الفرعي xenPlatform. يُستخدم عند تنفيذ الدفع، أو تحصيل الدفع من جانب الخادم، أو طرق الدفع المحفوظة، أو معالجة خطاف الويب، أو تسوية حالة الدفع، أو تدفقات سوق النظام الأساسي باستخدام Xendit.
