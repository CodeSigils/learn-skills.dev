قم بإعداد وبناء وتصحيح وشرح عمليات تكامل الدفع الخاصة بـ CHIP Collect باستخدام وثائق CHIP Collect API الرسمية. استخدمه عند العمل مع مشتريات CHIP Collect، أو عناوين URL الخاصة بالخروج، أو روابط الدفع، أو النشر المباشر، أو FPX، أو DuitNow QR، أو البطاقات، أو المحافظ الإلكترونية، أو رد الاتصال، أو خطافات الويب، أو التحقق من التوقيع، أو العملاء، أو الرموز المميزة المتكررة، أو الاشتراكات، أو التفويض المسبق، أو المبالغ المستردة، أو عمليات الالتقاط، أو الإصدارات، أو طرق الدفع، أو البيانات، أو رصيد الحساب، أو معدل دوران الحساب، أو مفاتيح واجهة برمجة التطبيقات، أو معرف العلامة التجارية، أو مخططات نقطة النهاية الخاصة بتجميع CHIP.
