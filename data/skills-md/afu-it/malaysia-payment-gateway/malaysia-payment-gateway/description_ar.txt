بناء وتصحيح ومراجعة وشرح عمليات تكامل بوابة الدفع الماليزية. يُستخدم عند تنفيذ الخروج، أو روابط الدفع، أو صفحات الدفع المستضافة، أو عمليات إعادة التوجيه، أو عمليات رد الاتصال، أو خطافات الويب، أو HMAC/التحقق من التوقيع، أو التسوية غير الفعالة، أو فتح الوصول المدفوع، أو المبالغ المستردة، أو التسوية، أو وضع الحماية/الإعداد المباشر، أو تبديل الموفر للبوابات الماليزية مثل CHIP Collect، وCurlec/Razorpay، وXendit Malaysia، وBayarcash، وBCL Pay، وtoyyibPay، وBillplz، وFPX، وDuitNow QR، والبطاقات، أو المحافظ الإلكترونية.
