قم بتحويل PR أو فرع أو فرق إلى لوحة مراجعة مرئية تفاعلية - بطاقات قابلة للسحب للاختلافات لكل ملف، ومخططات حورية البحر، وملاحظات توضيحية، ومقتطفات من التعليمات البرمجية، ولقطات شاشة، وتحذيرات P0/P1/P2، متصلة بحواف تحمل علامات على لوحة عرض شاملة/تكبير/تصغير. يُستخدم عندما يطلب المستخدم "مراجعة العلاقات العامة هذه بشكل مرئي"، أو يريد "مراجعة مرئية" أو "لوحة مراجعة"، أو يقول "أطلعني على هذا الاختلاف/العلاقات العامة"، أو يطلب شرح التغيير/الفرع/العلاقات العامة بشكل مرئي.
