Convierta un PR, una rama o una diferencia en un lienzo de revisión visual interactivo: tarjetas arrastrables para diferencias por archivo, diagramas de sirena, notas explicativas, fragmentos de código, capturas de pantalla y advertencias P0/P1/P2, conectadas por bordes etiquetados en un lienzo de panorámica/zoom. Úselo cuando el usuario solicite "revisar este PR visualmente", quiera una "revisión visual" o "revisar lienzo", diga "guíeme a través de esta diferencia/PR" o solicite explicar un cambio/rama/PR visualmente.
