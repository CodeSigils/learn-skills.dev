Verwandeln Sie einen PR, Zweig oder Diff in eine interaktive visuelle Überprüfungsfläche – ziehbare Karten für Unterschiede pro Datei, Meerjungfrauendiagramme, Erläuterungsnotizen, Codeausschnitte, Screenshots und P0/P1/P2-Warnungen, verbunden durch beschriftete Kanten auf einer Schwenk-/Zoomfläche. Verwenden Sie diese Option, wenn der Benutzer darum bittet, „diese PR visuell zu überprüfen“, eine „visuelle Überprüfung“ oder „Überprüfungsleinwand“ wünscht, sagt: „Führen Sie mich durch diesen Unterschied/diese PR“ oder bittet darum, eine Änderung/einen Zweig/eine PR visuell zu erklären.
