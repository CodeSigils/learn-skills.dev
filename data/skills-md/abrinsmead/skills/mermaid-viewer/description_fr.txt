Restituez les diagrammes Mermaid dans une visionneuse HTML interactive autonome avec panoramique/zoom, thème clair/sombre, exportation PNG/SVG et vue source. À utiliser lorsque l'utilisateur demande de « schématiser ceci », « visualiser », « afficher l'architecture », demande un organigramme, un couloir, un diagramme de séquence, une machine à états, un ERD, une carte mentale, un sankey, un gantt, une chronologie, un diagramme de classes ou tout autre diagramme, ou fournit une source Mermaid à restituer.
