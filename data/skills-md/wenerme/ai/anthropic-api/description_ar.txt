يُستخدم عند العمل مع Anthropic REST API: واجهة برمجة التطبيقات للرسائل، أو Batches API، أو Token Counting، أو Models API، أو Files API، أو Skills API، أو Admin API، أو حدود المعدلات، أو الأخطاء، أو الإصدارات، أو طبقات الخدمة، أو المناطق المدعومة. المشغلات على واجهة برمجة التطبيقات البشرية، وواجهة برمجة تطبيقات الرسائل، ومفتاح واجهة برمجة التطبيقات، والحد الأقصى للمعدل، ومعالجة الدُفعات، وواجهة برمجة تطبيقات المشرف.
