يُستخدم عند تنفيذ تحويل الكلام إلى نص، أو النسخ الصوتي، أو البث STT في الوقت الفعلي، أو ميزات الذكاء الصوتي، أو الذكاء الاصطناعي الصوتي باستخدام واجهات برمجة تطبيقات AssemblyAI أو مجموعات SDK. يُستخدم عندما يذكر المستخدم AssemblyAI، أو وكلاء الصوت، أو النسخ، أو تسجيل المتحدث، أو تنقيح PII للصوت، أو بوابة LLM لفهم الصوت، أو تطبيق LLM على النصوص. استخدمه أيضًا عند إنشاء وكلاء صوت باستخدام LiveKit أو Pipecat الذين يحتاجون إلى تحويل الكلام إلى نص، أو عندما يعمل المستخدم مع أي مسار معالجة صوت/فيديو يمكن أن يستفيد من النسخ، حتى لو لم يذكروا AssemblyAI بالاسم.
