AssemblyAI API または SDK を使用して音声テキスト変換、音声文字起こし、リアルタイム ストリーミング STT、オーディオ インテリジェンス機能、または音声 AI を実装する場合に使用します。ユーザーが AssemblyAI、音声エージェント、文字起こし、話者ダイアライゼーション、音声の PII 編集、音声理解のための LLM ゲートウェイ、または文字起こしへの LLM の適用について言及する場合に使用します。 LiveKit または Pipecat を使用して音声からテキストへの変換を必要とする音声エージェントを構築する場合、またはユーザーが AssemblyAI の名前を言及していなくても、文字起こしの利点が得られるオーディオ/ビデオ処理パイプラインを使用している場合にも使用します。
