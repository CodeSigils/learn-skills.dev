Multi-Lens-Codeüberprüfung für PR-, Commit-, Unstaged-, Staged-, Merge- und Implementierungsunterschiede. Nur standardmäßige Dateizusammenführungsblocker; Sagen Sie „Verbesserungen einschließen“ für Politur/Tests/Refactor. Versendet den Rat über parallele Subagenten; Durchsuchbare Finding-Block-Ausgabe (output.md – nicht Cursor-Bugbot-Subagent). Verwenden Sie diese Option, wenn Sie Code überprüfen, einen Unterschied prüfen, Änderungen analysieren oder wenn der Benutzer eine Codeüberprüfung anfordert. Wird der Modus weggelassen, wird er automatisch erkannt.
