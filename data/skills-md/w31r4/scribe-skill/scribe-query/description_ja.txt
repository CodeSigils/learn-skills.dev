scribe の CLI クエリ プリミティブ (scribe q) を使用して、AI エージェントの動作トレースをクエリおよび分析します。 AI エージェント (クロード コード、コーデックス、カーソル) が API 呼び出しで送信または受信した内容を検査する必要がある場合は、このスキルをいつでも使用してください。システム プロンプト、ツール定義、または会話履歴を検索します。エージェントとサブエージェントのリクエストの親子階層を理解する。プロンプトがターンごとにどのように変化するかを比較します。または、エージェントが特定の動作をした理由をデバッグします。ユーザーがスクライブ、トレース分析、エージェントの動作検査、プロンプト考古学、リクエスト ツリーについて言及した場合、またはコーディング エージェント セッションで何が起こったのかを理解したい場合に、このスキルをトリガーします。また、ユーザーが「クロードが何を送信したか」、「システム プロンプトを表示」、「生成されたサブエージェントの数」、「利用可能なツールは何か」、または「ターン間に何が変更されたか」などの発言をしたときにもトリガーされます。
