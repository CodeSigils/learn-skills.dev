使用 scribe 的 CLI 查詢原語 (scribe q) 查詢和分析 AI 代理行為追蹤。每當您需要執行以下操作時，請使用此技能： 檢查 AI 代理（Claude Code、Codex、Cursor）在其 API 呼叫中發送或接收的內容；搜尋系統提示、工具定義或對話歷史記錄；了解代理和子代理請求的父子層次結構；比較提示如何在不同回合中演變；或以某種方式調試代理程式。當使用者提到抄寫、追蹤分析、代理行為檢查、提示考古、請求樹或想要了解編碼代理會話中發生的情況時，觸發此技能。當使用者說出「Claude 發送了什麼」、「向我顯示系統提示」、「產生了多少個子代理程式」、「可用的工具」或「回合之間發生了什麼變化」等內容時也會觸發。
