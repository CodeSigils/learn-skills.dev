الاستعلام عن آثار سلوك وكيل الذكاء الاصطناعي وتحليلها باستخدام أساسيات استعلام CLI الخاصة بالكاتب (الكاتب q). استخدم هذه المهارة عندما تحتاج إلى: فحص ما أرسله أو استقبله وكيل الذكاء الاصطناعي (Claude Code، Codex، Cursor) في مكالمات API الخاصة به؛ البحث من خلال مطالبات النظام، أو تعريفات الأدوات، أو سجل المحادثات؛ فهم التسلسل الهرمي بين الوالدين والطفل لطلبات الوكيل والوكيل الفرعي؛ قارن كيف تتطور المطالبات عبر المنعطفات؛ أو تصحيح سبب تصرف الوكيل بطريقة معينة. قم بتشغيل هذه المهارة عندما يذكر المستخدم الكاتب، أو تحليل التتبع، أو فحص سلوك الوكيل، أو علم الآثار الفوري، أو طلب الأشجار، أو يريد فهم ما حدث في جلسة وكيل الترميز. يتم التشغيل أيضًا عندما يقول المستخدم أشياء مثل "ماذا أرسل كلود"، أو "أرني مطالبة النظام"، أو "كم عدد الوكلاء الفرعيين الذين تم إنتاجهم"، أو "ما هي الأدوات المتاحة"، أو "ما الذي تغير بين الأدوار".
