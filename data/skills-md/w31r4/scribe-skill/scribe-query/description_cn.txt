使用 scribe 的 CLI 查询原语 (scribe q) 查询和分析 AI 代理行为跟踪。每当您需要执行以下操作时，请使用此技能： 检查 AI 代理（Claude Code、Codex、Cursor）在其 API 调用中发送或接收的内容；搜索系统提示、工具定义或对话历史记录；了解代理和子代理请求的父子层次结构；比较提示如何在不同回合中演变；或调试代理为何以某种方式行事。当用户提到抄写、跟踪分析、代理行为检查、提示考古、请求树或想要了解编码代理会话中发生的情况时，触发此技能。当用户说出“Claude 发送了什么”、“向我显示系统提示”、“生成了多少个子代理”、“可用的工具”或“回合之间发生了什么变化”等内容时也会触发。
