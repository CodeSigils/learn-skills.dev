연중무휴 작동을 위해 Raspberry Pi에 자체 작성 앱을 홈어시스턴트 OS(HAOS) 로컬 추가 기능(현재 HA UI/CLI에서 '앱'으로 표시됨)으로 배포합니다. git 아카이브 전달, ha CLI 문제(bash -lc, 저장소 다시 로드, 업데이트 대 재구축), ​​구성으로 추가 기능 옵션, /data 지속성, 기본 이미지(musl 대 glibc) 선택 등 전체 전투 테스트 절차와 알려진 모든 함정을 다룹니다. HAOS 로컬 추가 기능/HA 앱을 배포, 설치, 업데이트 또는 디버깅할 때 또는 사용자가 PART署到 RPi/HAOS/HA 추가 기능/HA 앱을 언급할 때 사용합니다.
