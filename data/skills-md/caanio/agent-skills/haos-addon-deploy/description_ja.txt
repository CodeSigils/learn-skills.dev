自作アプリを Home Assistant OS (HAOS) ローカル アドオン (HA UI/CLI では「アプリ」というラベルが付けられています) として Raspberry Pi にデプロイして、24 時間年中無休で動作させます。完全な実証済みの手順とすべての既知の落とし穴をカバーします: git アーカイブの配信、ha CLI の癖 (bash -lc、ストアのリロード、更新と再構築)、構成としてのアドオン オプション、/data 永続性、およびベースイメージ (musl と glibc) の選択。 HAOS ローカル アドオン / HA アプリを展開、インストール、更新、またはデバッグする場合、またはユーザーが RPi / HAOS / HA アドオン / HA アプリへの展開に言及した場合に使用します。
