ホーム アシスタント OS (HAOS) インスタンスに、ポート転送やデバイス側のインストールを行わずに、Cloudflare トンネル (クラウドフレア アドオン) 経由で、LAN 内外で実際の HTTPS URL を与えます。ユーザーがホーム アシスタントの HTTPS / リモート アクセス / 外部アクセスを希望する場合、cloudflared、Cloudflare トンネル、HA アプリ外部連線、HA 走 https について言及する場合、またはホーム IP を公開せずに外部から HA にアクセスする方法を尋ねる場合に使用します。また、HAOS ボックスに DuckDNS、ポート転送、または HA ネイティブ SSL を提案する前に、このガイドを参照してください。このルートは安全性と副作用の点で優れています。
