Expédiez les sauvegardes du système d'exploitation Home Assistant (HAOS) de la carte SD vers le stockage cloud (Google Drive ou toute télécommande rclone) avec une limite de bande passante de téléchargement et une politique de rétention de type GFS (éclaircissement quotidien/hebdomadaire/mensuel), à l'aide du module complémentaire Rclone Backup. À utiliser lorsque l'utilisateur souhaite que les sauvegardes HA soient téléchargées sur Google Drive / Dropbox / cloud, se plaint que la carte SD se remplit de sauvegardes, a besoin d'un support pour Home Assistant ou demande de limiter le débit / de limiter les téléchargements de sauvegardes car la bande passante en amont de la maison est rare. Consultez également avant de suggérer l'agent de sauvegarde natif google_drive ou le module complémentaire sabeechen - ni l'un ni l'autre ne peuvent limiter la vitesse de téléchargement.
