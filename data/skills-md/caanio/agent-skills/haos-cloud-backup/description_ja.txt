Ship Home Assistant OS (HAOS) は、Rclone Backup アドオンを使用して、アップロード帯域幅の上限と GFS スタイルの保持ポリシー (毎日/毎週/毎月の間引き) を使用して、SD カードからクラウド ストレージ (Google ドライブまたは任意の rclone リモート) にバックアップします。ユーザーが HA バックアップを Google Drive / Dropbox / クラウドにアップロードしたい場合、SD カードがバックアップでいっぱいになっていると訴える場合、Home Assistant に異地備份が必要な場合、または自宅のアップストリーム帯域幅が不足しているためにバックアップのアップロードをレート制限/スロットルするように要求する場合に使用します。また、ネイティブの google_drive バックアップ エージェントや sabeechen アドオンを提案する前に相談してください。どちらもアップロード速度を抑制することはできません。
