Envíe copias de seguridad de Home Assistant OS (HAOS) desde la tarjeta SD al almacenamiento en la nube (Google Drive o cualquier control remoto rclone) con un límite de ancho de banda de carga y una política de retención estilo GFS (diaria/semanal/mensualmente reducida), utilizando el complemento Rclone Backup. Úselo cuando el usuario quiere que se carguen copias de seguridad de alta disponibilidad en Google Drive/Dropbox/nube, se queja de que la tarjeta SD se está llenando de copias de seguridad, necesita 異地備份 para Home Assistant o solicita limitar/acelerar las cargas de copias de seguridad porque el ancho de banda ascendente del hogar es escaso. Consulte también antes de sugerir el agente de copia de seguridad nativo google_drive o el complemento sabeechen; ninguno de los dos puede acelerar la velocidad de carga.
