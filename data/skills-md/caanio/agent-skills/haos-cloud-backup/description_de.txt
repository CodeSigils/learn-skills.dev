Versenden Sie Home Assistant OS (HAOS)-Backups von der SD-Karte an einen Cloud-Speicher (Google Drive oder eine beliebige Rclone-Remote) mit einer Upload-Bandbreitenbeschränkung und einer GFS-ähnlichen Aufbewahrungsrichtlinie (tägliche/wöchentliche/monatliche Ausdünnung) mithilfe des Rclone Backup-Add-ons. Verwenden Sie diese Option, wenn der Benutzer HA-Backups auf Google Drive/Dropbox/Cloud hochladen möchte, sich darüber beschwert, dass die SD-Karte mit Backups voll ist, eine App für Home Assistant benötigt oder darum bittet, die Rate für das Hochladen von Backups zu begrenzen/zu drosseln, weil die Upstream-Bandbreite zu Hause knapp ist. Informieren Sie sich auch, bevor Sie den nativen Backup-Agenten google_drive oder das Add-on sabeechen vorschlagen – beides kann die Upload-Geschwindigkeit nicht drosseln.
