Kollaborativer Seitenerstellungsmodus für die OpenSpec-Dokumente. Erstellt einen Scratch-Plan innerhalb der Zielseite (Zweck, Struktur, nummerierte Entwurfsschritte), iteriert ihn mit dem Benutzer, entwirft dann einen Abschnitt pro genehmigtem Schritt und bereinigt ihn anschließend. Verwenden Sie diese Option, wenn eine Seite von Grund auf neu geschrieben werden muss oder eine neue Seite gestaltet wird, während der Benutzer auf dem Laufenden bleibt.
