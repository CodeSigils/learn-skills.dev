Используйте этот навык при выпуске OpenSpec: проверяйте объединенную работу и охват набора изменений, решайте, нужен ли догоняющий PR для набора изменений, готовьте или возобновляйте PR для пакетов версий наборов изменений, вырезайте бета-версию или стабильную версию, проверяйте публикацию и дорабатывайте примечания к выпуску GitHub. Также используйте, когда вас спрашивают, завершен ли PR с открытым выпуском, каков следующий этап выпуска или для продолжения выпуска, приостановленного для одобрения человеком.
