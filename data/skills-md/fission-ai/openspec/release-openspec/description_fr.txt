Utilisez cette compétence lors de la publication d'OpenSpec : auditez le travail fusionné et la couverture des ensembles de modifications, décidez si un PR de l'ensemble de modifications de rattrapage est nécessaire, préparez ou reprenez le PR des packages de versions des ensembles de modifications, supprimez une version bêta ou stable, vérifiez la publication et peaufinez les notes de version de GitHub. À utiliser également lorsqu'on vous demande si une PR de version ouverte est terminée, quelle est la prochaine étape de publication ou pour poursuivre une version suspendue pour approbation humaine.
