Создайте и разверните прототип ИИ-агента с помощью LangGraph и SAP GenAI Hub, разверните его в SAP BTP Cloud Foundry, создайте возможность Joule с действием A2A (агент-агент) и разверните его в Joule. Поддерживает TypeScript (Express или CAP) и Python. Используйте этот навык всякий раз, когда пользователь упоминает: создание специального агента для Joule, развертывание агента AI в BTP Cloud Foundry, интеграцию протокола A2A с Joule, расширяемость агента pro-code, агент LangGraph на SAP BTP, подключение внешнего агента к Joule, «привлечение собственного агента» для Joule, создание возможности Joule с действием A2A, агент CAP, развертывание MTA или любую комбинацию LangGraph/A2A/Joule/BTP/Cloud. Foundry/CAP в контексте разработки агентов. Также срабатывает, когда пользователь хочет создать шаблон, изменить или повторно развернуть существующий проект агента A2A.
