Générez et déployez un agent IA pro-code à l'aide de LangGraph et SAP GenAI Hub, déployez-le sur SAP BTP Cloud Foundry, créez une fonctionnalité Joule avec une action A2A (Agent à Agent) et déployez-la sur Joule. Prend en charge TypeScript (Express ou CAP) et Python. Utilisez cette compétence chaque fois que l'utilisateur mentionne : création d'un agent personnalisé pour Joule, déploiement d'un agent IA sur BTP Cloud Foundry, intégration du protocole A2A avec Joule, extensibilité de l'agent pro-code, agent LangGraph sur SAP BTP, connexion d'un agent externe à Joule, "apportez votre propre agent" pour Joule, création d'une fonctionnalité Joule avec action A2A, agent CAP, déploiement MTA ou toute combinaison de LangGraph/A2A/Joule/BTP/Cloud Foundry/CAP dans un agent contexte de développement. Se déclenche également lorsque l'utilisateur souhaite échafauder, modifier ou redéployer un projet d'agent A2A existant.
