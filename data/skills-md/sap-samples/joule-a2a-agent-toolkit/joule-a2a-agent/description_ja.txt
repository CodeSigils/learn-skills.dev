LangGraph と SAP GenAI Hub を使用してプロコード AI エージェントを生成およびデプロイし、それを SAP BTP Cloud Foundry にデプロイし、A2A (エージェント間) アクションを備えた Joule 機能を作成して、Joule にデプロイします。 TypeScript (Express または CAP) と Python をサポートします。 Joule のカスタム エージェントの構築、BTP Cloud Foundry への AI エージェントのデプロイ、Joule との A2A プロトコルの統合、プロコード エージェントの拡張性、SAP BTP 上の LangGraph エージェント、Joule への外部エージェントの接続、Joule の「独自のエージェントの導入」、A2A アクションによる Joule 機能の作成、CAP エージェント、MTA 導入、または LangGraph/A2A/Joule/BTP/Cloud Foundry/CAP の任意の組み合わせについてユーザーが言及した場合は、必ずこのスキルを使用してください。エージェント開発コンテキスト。また、ユーザーが既存の A2A エージェント プロジェクトをスキャフォールディング、変更、または再デプロイしたいときにもトリガーされます。
