مساعد شامل لواجهة سطر أوامر SAP BTP (btp CLI) لإنشاء الأوامر، وأتمتة سير العمل متعدد الخطوات، واستكشاف الأخطاء وإصلاحها. استخدم هذه المهارة عندما يذكر المستخدم "btp" أو "BTP CLI" أو "سطر أوامر SAP BTP" أو إدارة الحساب الفرعي عبر CLI أو تعيين الاستحقاق عبر الوحدة الطرفية أو إنشاء مثيل الخدمة باستخدام btp أو تعيين مجموعة الأدوار من سطر الأوامر أو أي مهمة تتضمن SAP Business Technology Platform CLI - حتى لو قالوا شيئًا مثل "إعداد حساب BTP الفرعي الخاص بي" أو "كيف يمكنني تسجيل الدخول إلى حسابي العالمي من الوحدة الطرفية". يتم التشغيل أيضًا عندما يسأل المستخدم عن البرمجة النصية أو أتمتة عمليات SAP BTP، أو تحليل إخراج btp باستخدام jq، أو إدارة بيئات Cloud Foundry / Kyma من خلال btp CLI.
