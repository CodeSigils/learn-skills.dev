Комплексный помощник по интерфейсу командной строки SAP BTP (btp CLI) для создания команд, автоматизации многоэтапных рабочих процессов и устранения ошибок. Используйте этот навык всякий раз, когда пользователь упоминает «btp», «BTP CLI», «командную строку SAP BTP», управление субаккаунтом через CLI, назначение прав через терминал, создание экземпляра службы с помощью btp, назначение коллекции ролей из командной строки или любую задачу, связанную с CLI SAP Business Technology Platform — даже если он просто говорит что-то вроде «настройте мою субучетную запись BTP» или «как мне войти в мою глобальную учетную запись с терминала». Также срабатывает, когда пользователь спрашивает о написании сценариев или автоматизации операций SAP BTP, анализе выходных данных btp с помощью jq или управлении средами Cloud Foundry/Kyma через интерфейс командной строки btp.
