Implemente o actualice el código de interfaz de usuario coherente con el proyecto desde una selección de Figma o un nodeId utilizando TemPad Dev MCP. Úselo cuando el usuario desee recrear, portar o integrar la interfaz de usuario de Figma visible en el marco, el sistema de estilo, los tokens y los componentes existentes del proyecto de destino, cuando estén disponibles. No lo utilice para críticas de diseño, invención de productos, revisión de códigos genéricos ni para adivinar estados ocultos, capacidad de respuesta o comportamientos que no se muestran en la evidencia del diseño o del proyecto.
