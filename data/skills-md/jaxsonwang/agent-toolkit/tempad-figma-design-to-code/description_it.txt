Implementa o aggiorna il codice dell'interfaccia utente coerente con il progetto da una selezione Figma o nodeId utilizzando TemPad Dev MCP. Utilizzare quando l'utente desidera che l'interfaccia utente Figma visibile sia ricreata, trasferita o integrata nel framework, nel sistema di stile, nei token e nei componenti esistenti del progetto di destinazione, quando disponibili. Non utilizzare per critiche di progettazione, invenzioni di prodotti, revisioni generiche di codici o per indovinare stati nascosti, reattività o comportamenti non mostrati nelle prove di progettazione o di progetto.
