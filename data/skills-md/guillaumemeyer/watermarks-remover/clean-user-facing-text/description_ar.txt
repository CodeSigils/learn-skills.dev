نظّف وسنّ النص الطبيعي المصرّح به الموجه للقراء من خلال مراجعة Unicode المخفي المشبوه وإعادة صياغة النثر مع الحفاظ على الحقائق والمعنى. استخدمه في Cursor عندما يطلب المستخدم تنظيف، أو إضفاء طابع إنساني، أو صقل، أو إنهاء المقالات، المخطوطات، التقارير، الوثائق، الرسائل الإلكترونية، نصوص المنتج، نصوص واجهة المستخدم، Markdown أو HTML، أو عندما تتطلب قاعدة Cursor المثبتة صراحةً هذا سير العمل. لا تستخدمه للمهام التي تقتصر على الشيفرة أو لتجنب الكشف عن المؤلف؛ اترك الشيفرة، الأوامر، المعرفات، المسارات، واجهات برمجة التطبيقات، الصيغ، الاستشهادات، الإفصاحات المطلوبة والاقتباسات النصية دون تغيير.
