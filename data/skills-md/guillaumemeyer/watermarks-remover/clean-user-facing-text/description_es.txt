Limpie y finalice el texto autorizado en lenguaje natural destinado a los lectores auditando Unicode invisible y sospechoso y reescribiendo la prosa preservando los hechos y el significado. Úselo en Cursor cuando el usuario solicite limpiar, humanizar, pulir o finalizar artículos, manuscritos, informes, documentación, correos electrónicos, copias de productos, texto de interfaz de usuario, Markdown o prosa HTML, o cuando una regla de cursor instalada requiera explícitamente este flujo de trabajo. No lo utilice para tareas de solo código o para evadir la autoría no revelada; Deje el código, los comandos, los identificadores, las rutas, las API, las fórmulas, las citas, las divulgaciones requeridas y las citas textuales sin cambios.
