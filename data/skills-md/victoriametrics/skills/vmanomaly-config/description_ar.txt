تصميم وضبط والتحقق من صحة واختبار تكوينات VictoriaMetrics vmanomaly للمقاييس المعروفة أو استعلامات LogsQL. يُستخدم عند اختيار التنبيه الثابت مقابل ML، أو تحديد نموذج vmanomaly، ​​أو تكوين المغلف الزمني، أو إنشاء YAML للنشر، أو ضبط حساسية الشذوذ، أو إنشاء قواعد VMAlert. تشغيل عند تكوين الشذوذ، أو اختيار النموذج، أو الضبط التلقائي المشترك، أو اكتشاف الشذوذ الموسمي، أو التنبؤ، أو "كيف يمكنني مراقبة هذا المقياس؟" لا تستخدمه للاكتشاف المفتوح عبر إشارات غير معروفة.
