Запрос AlertManager через Curl с использованием API версии 2. Используйте при отображении списка активных/отключенных оповещений, создании/управлении отключением звука или проверке состояния запрета оповещений. Запускается по: alertmanager, отключению звука, оповещениям о молчании, фильтрам оповещений, запрету оповещений, API alertmanager, созданию тишины, удалению тишины.
