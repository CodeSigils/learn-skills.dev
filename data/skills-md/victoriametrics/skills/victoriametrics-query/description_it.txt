Interroga le metriche VictoriaMetrics tramite curl. Da utilizzare durante l'esecuzione di query PromQL/MetricsQL, il rilevamento di metriche/etichette, il controllo di avvisi e regole, l'ispezione dello stato TSDB, l'esportazione di dati grezzi, il controllo delle statistiche di utilizzo delle metriche o il debug di configurazioni di rietichettatura/downsampling/conservazione. Trigger su: query di metriche, PromQL, MetricsQL, rilevamento di etichette, esplorazione di serie, controlli di cardinalità, stato di avviso, regole di registrazione, query attive/principali, esportazione di dati, statistiche di metrica, debug di rietichettatura, debug di downsampling, debug di conservazione, flag.
