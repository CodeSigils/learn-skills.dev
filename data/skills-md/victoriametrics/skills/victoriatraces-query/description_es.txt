Consulta VictoriaTraces mediante curl utilizando la API compatible con Jaeger. Úselo al descubrir servicios y operaciones rastreados, buscar rastreos por servicio/operación/duración/etiquetas, recuperar rastreos por ID o mapear dependencias de servicios. Activadores de: consultas de seguimiento, búsqueda de intervalos, búsqueda de ID de seguimiento, descubrimiento de servicios, descubrimiento de operaciones, dependencias de servicios, seguimiento distribuido, API de Jaeger.
