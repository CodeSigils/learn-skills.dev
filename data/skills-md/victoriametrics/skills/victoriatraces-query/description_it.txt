Interroga VictoriaTraces tramite curl utilizzando l'API compatibile con Jaeger. Da utilizzare durante l'individuazione di servizi e operazioni tracciati, la ricerca di tracce per servizio/operazione/durata/tag, il recupero di tracce per ID o la mappatura delle dipendenze del servizio. Si attiva su: query di traccia, ricerca di span, ricerca di ID di traccia, rilevamento di servizi, rilevamento di operazioni, dipendenze di servizi, traccia distribuita, API Jaeger.
