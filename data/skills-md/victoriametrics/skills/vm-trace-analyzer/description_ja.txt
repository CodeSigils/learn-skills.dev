VictoriaMetrics クエリ トレース JSON を分析して、遅いクエリを診断し、時間の内訳、ボトルネック分析、最適化の推奨事項を含む構造化されたパフォーマンス レポートを作成します。このスキルは、次の場合に常に使用してください: (1) ユーザーが VictoriaMetrics または VM トレース、クエリ トレース、またはトレース JSON について言及した場合、(2) ユーザーが、duration_msec/message/children フィールドを含む JSON ファイルを提供または参照した場合、(3) VictoriaMetrics/VM クエリが遅く、トレース出力がある理由をユーザーが尋ねた場合、(4) ユーザーがトレースのコンテキストでの vmstorage ノードの分散、キャッシュ ミス、またはロールアップ パフォーマンスについて尋ねた場合、(5) ユーザーがvmselect トレース、trace=1、または VictoriaMetrics を使用したクエリ パフォーマンスのデバッグについて言及しています。このスキルは、一貫性のある徹底的な分析を保証する構造化されたレポート テンプレートを提供します。このスキルなしで VM トレースを分析しようとしないでください。
