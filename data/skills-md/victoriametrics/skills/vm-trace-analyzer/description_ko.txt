VictoriaMetrics 쿼리 추적 JSON을 분석하여 느린 쿼리를 진단하고 시간 분석, 병목 현상 분석 및 최적화 권장 사항이 포함된 구조화된 성능 보고서를 생성합니다. (1) 사용자가 VictoriaMetrics 또는 VM 추적, 쿼리 추적 또는 추적 JSON을 언급하는 경우, (2) 사용자가 Duration_msec/message/children 필드가 포함된 JSON 파일을 제공하거나 참조하는 경우, (3) 사용자가 VictoriaMetrics/VM 쿼리가 느리고 추적 출력이 있는 이유를 묻는 경우, (4) 사용자가 추적 컨텍스트에서 vmstorage 노드 배포, 캐시 누락 또는 롤업 성능에 대해 질문하는 경우, (5) 사용자가 vmselect를 언급하는 경우 항상 이 기술을 사용하십시오. VictoriaMetrics를 사용한 추적, 추적=1 또는 쿼리 성능 디버깅. 이 기술은 일관되고 철저한 분석을 보장하는 구조화된 보고서 템플릿을 제공합니다. 이 기술 없이는 VM 추적을 분석하지 마십시오.
