Analice el JSON de seguimiento de consultas de VictoriaMetrics para diagnosticar consultas lentas y producir un informe de rendimiento estructurado con desglose de tiempo, análisis de cuellos de botella y recomendaciones de optimización. SIEMPRE use esta habilidad cuando: (1) el usuario menciona un seguimiento de VictoriaMetrics o VM, un seguimiento de consulta o un JSON de seguimiento, (2) el usuario proporciona o hace referencia a un archivo JSON que contiene campos duración_msec/mensaje/hijos, (3) el usuario pregunta por qué una consulta de VictoriaMetrics/VM es lenta y tiene resultados de seguimiento, (4) el usuario pregunta sobre la distribución de nodos de vmstorage, errores de caché o rendimiento de acumulación en el contexto de un seguimiento, (5) el usuario menciona vmselect trace, trace=1 o depuración del rendimiento de consultas con VictoriaMetrics. Esta habilidad proporciona una plantilla de informe estructurada que garantiza un análisis coherente y exhaustivo; no intente analizar los seguimientos de la máquina virtual sin ella.
