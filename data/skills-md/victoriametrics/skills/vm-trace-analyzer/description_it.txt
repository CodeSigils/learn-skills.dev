Analizza il JSON di tracciamento delle query VictoriaMetrics per diagnosticare query lente e produrre un report strutturato sulle prestazioni con suddivisione temporale, analisi dei colli di bottiglia e consigli di ottimizzazione. Utilizzare SEMPRE questa abilità quando: (1) l'utente menziona una traccia VictoriaMetrics o VM, una traccia di query o un JSON di traccia, (2) l'utente fornisce o fa riferimento a un file JSON contenente campi length_msec/message/children, (3) l'utente chiede perché una query VictoriaMetrics/VM è lenta e presenta un output di traccia, (4) l'utente chiede informazioni sulla distribuzione del nodo vmstorage, sugli errori di cache o sulle prestazioni di rollup nel contesto di una traccia, (5) l'utente menziona vmselect trace, trace=1 o debug delle prestazioni delle query con VictoriaMetrics. Questa competenza fornisce un modello di report strutturato che garantisce un'analisi coerente e approfondita: non tentare di analizzare le tracce delle VM senza di essa.
