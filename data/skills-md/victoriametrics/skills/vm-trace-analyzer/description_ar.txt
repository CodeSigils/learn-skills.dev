قم بتحليل تتبع استعلام VictoriaMetrics JSON لتشخيص الاستعلامات البطيئة وإنتاج تقرير أداء منظم مع تقسيم الوقت وتحليل عنق الزجاجة وتوصيات التحسين. استخدم هذه المهارة دائمًا عندما: (1) يذكر المستخدم تتبع VictoriaMetrics أو VM، أو تتبع الاستعلام، أو تتبع JSON، (2) يقدم المستخدم أو يشير إلى ملف JSON يحتوي على حقول Duration_msec/message/children، (3) يسأل المستخدم عن سبب بطء استعلام VictoriaMetrics/VM ويحتوي على إخراج تتبع، (4) يسأل المستخدم عن توزيع عقدة vmstorage، أو أخطاء ذاكرة التخزين المؤقت، أو أداء القيمة المحتسبة في سياق التتبع، (5) المستخدم يذكر vmselect Trace أو Trace=1 أو تصحيح أداء الاستعلام باستخدام VictoriaMetrics. توفر هذه المهارة قالب تقرير منظم يضمن تحليلًا متسقًا وشاملاً - لا تحاول تحليل تتبعات الأجهزة الافتراضية بدونها.
