قم بتشغيل اكتشاف الشذوذ الخاص بـ VictoriaMetrics (vmanomaly) من خلال HTTP API الخاص به. يُستخدم عند التحقق من الصحة، أو الإصدارات، أو توافق الحالة المستمرة، أو مقاييس المراقبة الذاتية، أو النماذج المتاحة، أو مخططات النماذج، أو استعلامات الخادم، أو خصائص السلاسل الزمنية، أو الضبط التلقائي المشترك، أو مهام الكشف غير المتزامنة. استخدم أيضًا لإنشاء تكوين vmanomaly أو قاعدة التنبيه YAML والتحقق من صحتها. المشغلات على vmanomaly API، والمهام الشاذة، والتحقق من صحة النموذج، ومخطط النموذج، والتوافق، والمغلف الزمني، وملفات تعريف السلاسل الزمنية، والضبط التلقائي vmanomaly.
