HTTP API를 통해 VictoriaMetrics 이상 탐지(vmanomaly)를 작동합니다. 상태, 버전, 지속 상태 호환성, 자체 모니터링 지표, 사용 가능한 모델, 모델 스키마, 서버 쿼리, 시계열 특성, 공유 자동 조정 또는 비동기 감지 작업을 확인할 때 사용합니다. vmanomaly 구성 또는 경고 규칙 YAML을 생성하고 검증하는 데에도 사용됩니다. vmanomaly API, 이상 작업, 모델 검증, 모델 스키마, 호환성, Temporal Envelope, 시계열 프로파일링 및 vmanomaly 자동 조정을 트리거합니다.
