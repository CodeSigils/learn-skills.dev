Opere la detección de anomalías de VictoriaMetrics (vmanomaly) a través de su API HTTP. Úselo al verificar el estado, las versiones, la compatibilidad de estado persistente, las métricas de autocontrol, los modelos disponibles, los esquemas de modelos, las consultas del servidor, las características de series temporales, el ajuste automático compartido o las tareas de detección asincrónicas. También se utiliza para generar y validar la configuración de vmanomaly o YAML de reglas de alerta. Activadores de API de vmanomaly, tareas de anomalías, validación de modelos, esquema de modelos, compatibilidad, envolvente temporal, creación de perfiles de series temporales y ajuste automático de vmanomaly.
