Управляйте обнаружением аномалий VictoriaMetrics (vmanomaly) через HTTP API. Используйте при проверке работоспособности, версий, совместимости постоянного состояния, метрик самоконтроля, доступных моделей, схем моделей, запросов к серверу, характеристик временных рядов, общей автонастройки или задач асинхронного обнаружения. Также используйте для создания и проверки конфигурации vmanomaly или YAML-правила оповещения. Триггеры по API vmanomaly, аномальным задачам, проверке модели, схеме модели, совместимости, временной оболочке, профилированию временных рядов и автонастройке vmanomaly.
