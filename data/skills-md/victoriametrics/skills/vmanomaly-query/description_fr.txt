Exploitez la détection des anomalies VictoriaMetrics (vmanomaly) via son API HTTP. À utiliser pour vérifier l'intégrité, les versions, la compatibilité des états persistants, les métriques d'auto-surveillance, les modèles disponibles, les schémas de modèle, les requêtes du serveur, les caractéristiques des séries chronologiques, le réglage automatique partagé ou les tâches de détection asynchrone. Également utilisé pour générer et valider la configuration de vmanomaly ou le YAML de règle d'alerte. Déclencheurs sur l'API vmanomaly, les tâches d'anomalie, la validation du modèle, le schéma du modèle, la compatibilité, l'enveloppe temporelle, le profilage de séries chronologiques et le réglage automatique de vmanomaly.
