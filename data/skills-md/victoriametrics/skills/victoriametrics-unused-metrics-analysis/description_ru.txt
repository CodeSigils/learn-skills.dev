Найдите неиспользуемые и редко запрашиваемые метрики в VictoriaMetrics с помощью API metric_names_stats, а затем предложите действия по оптимизации (удаление правил, изменение меток конфигураций). Используйте этот навык, когда пользователь хочет найти неиспользуемые метрики, определить неиспользуемое хранилище, оптимизировать прием метрик, уменьшить количество элементов за счет удаления ненужных метрик, очистить цели очистки или спросить, какие метрики никогда не запрашиваются. Также срабатывает, когда пользователь упоминает «очистку метрик», «неиспользуемые серии», «какие метрики я могу удалить», «оптимизацию метрик», «бесполезное использование» или хочет сократить потребление ресурсов VictoriaMetrics за счет исключения ненужных метрик.
