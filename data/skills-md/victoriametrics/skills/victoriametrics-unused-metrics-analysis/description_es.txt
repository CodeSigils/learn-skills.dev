Encuentre métricas no utilizadas y rara vez consultadas en VictoriaMetrics utilizando la API metric_names_stats, luego sugiera acciones de optimización (eliminar reglas, volver a etiquetar configuraciones). Utilice esta habilidad cuando el usuario quiera encontrar métricas no utilizadas, identificar almacenamiento desperdiciado, optimizar la ingesta de métricas, reducir la cardinalidad eliminando métricas innecesarias, limpiar objetivos de scrape o preguntar qué métricas nunca se consultan. También se activa cuando el usuario menciona "limpieza de métricas", "series no utilizadas", "qué métricas puedo eliminar", "optimización de métricas", "ingesta desperdiciada" o quiere reducir el consumo de recursos de VictoriaMetrics eliminando métricas innecesarias.
