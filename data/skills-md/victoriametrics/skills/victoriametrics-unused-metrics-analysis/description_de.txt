Finden Sie ungenutzte und selten abgefragte Metriken in VictoriaMetrics mithilfe der API „metric_names_stats“ und schlagen Sie dann Optimierungsmaßnahmen vor (Regeln löschen, Konfigurationen neu kennzeichnen). Verwenden Sie diese Fähigkeit, wenn der Benutzer ungenutzte Metriken finden, verschwendeten Speicher identifizieren, die Metrikaufnahme optimieren, die Kardinalität durch Löschen nicht benötigter Metriken reduzieren, Scrape-Ziele bereinigen möchte oder fragt, welche Metriken nie abgefragt werden. Wird auch ausgelöst, wenn der Benutzer „Metrikbereinigung“, „nicht verwendete Serien“, „Welche Metriken kann ich löschen“, „Metrikoptimierung“, „verschwendete Aufnahme“ erwähnt oder den Ressourcenverbrauch von VictoriaMetrics durch Eliminieren unnötiger Metriken reduzieren möchte.
