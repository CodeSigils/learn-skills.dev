metric_names_stats API を使用して、VictoriaMetrics で未使用およびほとんどクエリされないメトリクスを検索し、最適化アクション (ルールの削除、構成の再ラベル) を提案します。このスキルは、ユーザーが未使用のメトリクスの検索、無駄なストレージの特定、メトリクスの取り込みの最適化、不要なメトリクスの削除によるカーディナリティの削減、スクレイピング ターゲットのクリーンアップ、またはどのメトリクスがクエリされないのかを尋ねる場合に使用します。また、ユーザーが「メトリクスのクリーンアップ」、「未使用のシリーズ」、「削除できるメトリクス」、「メトリクスの最適化」、「無駄な取り込み」に言及した場合、または不要なメトリクスを削除して VictoriaMetrics リソースの消費を削減したい場合にもトリガーされます。
