Crema (Chuangke) Agent Conversation Skill – wird verwendet, wenn ein Benutzer Bilder oder Videos über Crema generieren, bearbeiten, ändern, fortfahren oder herunterladen möchte. Zu den abgedeckten Szenarien gehören: Bilder generieren, Poster erstellen, Text-zu-Bild, Bild-zu-Bild, Bild-zu-Video, Text-zu-Video, Animationen erstellen, „Zeichne ein xxx“, „Gib mir ein xxx“; Bearbeiten und Modifizieren wie Ersetzen von xxx durch yyy, Entfernen von xxx, Hinzufügen von xxx, Ändern in xxx, Anpassen von xxx, Teilbearbeitungen, Ändern der Kamerawinkel; Stilkonvertierung wie Neuzeichnen, Stilwechsel, Stilübertragung; Fortsetzung/Erweiterung von Videos, Replikation von Videos/TVCs/Werbeclips, Erstellung von Kurzdramen/Kurzanimationen, Erstellung von Musik-MVs, Produktion von Produktanzeigen/Displayvideos, Storyboard/Szenendesign, Produktion von Lehrvideos/Kurzvideos. Der Skill sollte auch ausgelöst werden, wenn der Benutzer Crema, AIGC, Agent erwähnt, Referenzbilder/-videos hochlädt, den Generierungsfortschritt überprüft oder die generierten Ergebnisse herunterlädt. Wichtigste Regel: Jede Benutzeranfrage, die die Erstellung, Generierung, Bearbeitung oder Änderung von Bildern, Designs oder Videos auf KI-Basis beinhaltet – unabhängig vom Wortlaut – muss diese Fähigkeit aktivieren.
