Revisión de calidad de la documentación interactiva para documentos de Mastra. Úselo al auditar, revisar o criticar la documentación de Mastra; comparar documentos con el código fuente; validar ejemplos de código, precisión de API o integridad de la propiedad; comprobar si los documentos siguen la guía de estilo y los linters deterministas; o evaluar si un principiante o un agente puede seguir a un médico para completar un trabajo. Esta habilidad mantiene a los humanos informados con Ask_user y submit_plan, luego siempre ejecuta una evaluación de compilación del agente después de las correcciones aprobadas.
