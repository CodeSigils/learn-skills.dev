Интерактивный анализ качества документации для документов Matra. Используйте при аудите, обзоре или критике документации Mastra; проверка документации на соответствие исходному коду; проверка примеров кода, точности API или полноты свойств; проверка соответствия документации руководству по стилю и детерминированным линтерам; или оценить, сможет ли новичок или агент следовать документу для выполнения работы. Этот навык позволяет людям быть в курсе событий с помощью Ask_user и submit_plan, а затем всегда запускает оценку сборки агента после одобрения исправлений.
