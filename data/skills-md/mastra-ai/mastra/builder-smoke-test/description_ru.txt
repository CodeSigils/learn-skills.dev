Сквозное тестирование функциональной ветки Agent Builder на основе герметичного проекта, основанного на навыке (связанного с текущим рабочим деревом). Охватывает сверку рабочей области, хранимые агенты/навыки CRUD, владение, видимость, звездочки, поток копирования реестра/библиотеки, списки разрешенных средств выбора, политику модели, шлюзование ролей RBAC, пользовательский интерфейс олицетворения ролей, настройки по умолчанию для сборщика, диагностику инфраструктуры, каналы и пользовательский интерфейс Studio + Agent Builder. Запускается при проверке ветки функций агента-построителя, PR, которые касаются пакетов/сервера, пакетов/игровой площадки, маршрутов агента-построителя пакетов/игровой площадки-ui или путей кода EE компоновщика.
