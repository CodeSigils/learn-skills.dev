Agent Builder 機能ブランチを、スキルによってスキャフォールディングされた (現在のワークツリーにリンクされた) 気密プロジェクトに対してエンドツーエンドでスモーク テストします。ワークスペース調整、保存されたエージェント/スキル CRUD、所有権、可視性、スター、レジストリ/ライブラリ コピー フロー、ピッカー許可リスト、モデル ポリシー、RBAC ロール ゲーティング、ロール偽装 UI、ビルダーのデフォルト、インフラストラクチャ診断、チャネル、Studio + Agent Builder UI をカバーします。 Agent-Builder 機能ブランチ、packages/server、packages/playground、packages/playground-ui エージェント-Builder ルート、または Builder EE コード パスに触れる PR を検証するときにトリガーします。
