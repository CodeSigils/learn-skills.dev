Руководство по использованию Tailwind CSS v4 и различия между версиями 3 и 4. Этот навык следует использовать при написании, проверке или рефакторинге любого CSS-кода Tailwind в этом репозитории. Запускается при выполнении задач, включающих классы Tailwind, блоки @theme, настройку CSS или очистку синтаксиса эпохи v3.
