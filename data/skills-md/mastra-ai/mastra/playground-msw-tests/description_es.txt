Enfoque de prueba REQUERIDO y PRIMARIO para paquetes/playground y paquetes/playground-ui. Se desencadena en: agregar o modificar enlaces, páginas, componentes de ruta, código de recuperación de datos, interacciones de React Query o cualquier trabajo de prueba en estos paquetes. Genera pruebas de Vitest que impulsan la pila real de @mastra/client-js + React Query a través de controladores MSW y elementos fijos escritos derivados de los tipos de respuesta @mastra/client-js. Esta es la forma número uno de probar los paquetes de juegos infantiles: ARRIBA Playwright E2E. Utilice Playwright solo para recorridos de usuarios entre páginas que MSW no puede modelar.
