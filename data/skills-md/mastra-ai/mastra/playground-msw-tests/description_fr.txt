Approche de test REQUISE et PRIMAIRE pour les packages/playground et packages/playground-ui. Déclencheurs sur : l'ajout ou la modification de hooks, de pages, de composants de route, de code de récupération de données, d'interactions React Query ou de tout travail de test dans ces packages. Génère des tests Vitest qui pilotent la vraie pile de requêtes @mastra/client-js + React via des gestionnaires MSW et des appareils typés dérivés des types de réponse @mastra/client-js. C'est le moyen n°1 de tester les packages de jeux pour enfants – CI-DESSUS Playwright E2E. Utilisez Playwright uniquement pour les parcours utilisateur sur plusieurs pages que MSW ne peut pas modéliser.
