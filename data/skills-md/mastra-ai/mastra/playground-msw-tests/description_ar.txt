نهج الاختبار المطلوب والأساسي للحزم/الملعب والحزم/ساحة اللعب-ui. يتم التشغيل على: إضافة أو تعديل الخطافات، أو الصفحات، أو مكونات المسار، أو كود جلب البيانات، أو تفاعلات React Query، أو أي عمل اختباري في هذه الحزم. يُنشئ اختبارات Vitest التي تقود مجموعة @mastra/client-js + React Query الحقيقية من خلال معالجات MSW والتركيبات المكتوبة المشتقة من أنواع استجابة @mastra/client-js. هذه هي الطريقة رقم 1 لاختبار حزم الملعب — فوق الكاتب المسرحي E2E. استخدم Playwright فقط لرحلات المستخدم عبر الصفحات التي لا تستطيع MSW تصميمها.
