ОБЯЗАТЕЛЬНЫЙ и ОСНОВНОЙ подход к тестированию для пакетов/playground и packages/playground-ui. Запускается при: добавлении или изменении перехватчиков, страниц, компонентов маршрута, кода получения данных, взаимодействиях с запросами React или любых тестовых работах в этих пакетах. Генерирует тесты Vitest, которые управляют реальным стеком запросов @mastra/client-js + React через обработчики MSW и типизированные приспособления, полученные из типов ответов @mastra/client-js. Это способ №1 протестировать игровые пакеты — ВЫШЕ Playwright E2E. Используйте Playwright только для путешествий пользователя между страницами, которые MSW не может моделировать.
