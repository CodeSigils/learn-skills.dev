Flux de travail de planification structuré pour toute tâche de codage. À utiliser au début de chaque nouvelle fonctionnalité, correction de bug, refactorisation ou demande d'implémentation. Analyse le projet, pose jusqu'à 5 questions de clarification, crée un TODO.md, obtient l'approbation de l'utilisateur, puis exécute tâche par tâche. N'écrit jamais de code avant qu'un plan ne soit approuvé.
