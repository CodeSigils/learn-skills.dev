Ensemble de compétences en matière de données financières technologiques non convexes. Couvre la liste des actions A, les cotations boursières, les introductions en bourse, les transactions de bloc, le financement sur marge et le prêt de titres, la valorisation boursière d'une action unique, les obligations convertibles, les ETF, les fonds, les indices (y compris les descriptions d'indices paginées, les PDF de description téléchargeables, les résumés de pondération/détails des composants, la pondération téléchargeable XLSX, les détails/ligne K/intrajournalière), la macroéconomie, ainsi que les introductions de sociétés boursières de Hong Kong/analyse de valorisation/vues de base/ligne K et autres interfaces. (marché.ft.tech / ftai.chat). Utilisé lorsque les utilisateurs se renseignent sur les codes d'actions A ou de Hong Kong, les cotations boursières, les valorisations, les lignes K, les pondérations/descriptions des indices, les actualités et les données macro.
