Guide de l'utilisateur de l'API de données RQData. Utilisez-le lorsque vous devez accéder à l'interface de données RQData et obtenir des données financières. Prend en charge les requêtes de données de marché pour les actions A, les actions de Hong Kong, les contrats à terme, les options, les indices, les fonds, les obligations convertibles, etc., y compris la documentation de l'API HTTP et de l'API Python.
