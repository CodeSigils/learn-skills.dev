Guida per l'utente dell'API dati RQData. Da utilizzare quando è necessario interrogare le interfacce RQData e ottenere dati finanziari. Supporta query sui dati di mercato per azioni A, azioni di Hong Kong, futures, opzioni, indici, fondi, obbligazioni convertibili, ecc., inclusa la documentazione dell'API HTTP e dell'API Python.
