Руководство по использованию API данных RQData. Используйте его, когда вам нужно запросить интерфейс данных RQData и получить финансовые данные. Поддерживает запросы рыночных данных для акций A, гонконгских акций, фьючерсов, опционов, индексов, фондов, конвертируемых облигаций и т. д., включая документацию по HTTP API и Python API.
