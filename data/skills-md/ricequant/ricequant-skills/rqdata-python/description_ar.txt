دليل مستخدم واجهة برمجة تطبيقات بيانات RQData. يُستخدم عند الاستعلام عن واجهات بيانات RQData والحصول على البيانات المالية. يدعم استعلامات بيانات السوق للأسهم A، وأسهم هونج كونج، والعقود الآجلة، والخيارات، والمؤشرات، والصناديق، والسندات القابلة للتحويل، وما إلى ذلك، بما في ذلك وثائق HTTP API وPython API.
