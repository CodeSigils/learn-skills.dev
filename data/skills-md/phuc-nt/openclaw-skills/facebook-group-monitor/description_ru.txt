Следите за новыми публикациями в группах Facebook с помощью автоматизации браузера Playwright со скрытым режимом и постоянным сеансом входа в систему. Парсит ленту группы, отслеживает просмотренные посты, сообщает только о новых. Сохраняет один сшитый снимок экрана «ленты ленты» (прокрутка области просмотра + стежок «подушка») для эффективного анализа зрения LLM — одно изображение покрывает всю ленту. Используйте, когда: мониторинг групп Facebook, очистка сообщений FB, проверка активности новых групп, автоматизация Facebook, мониторинг рынка, отслеживание продаж книг, мониторинг групп конкурентов. Триггеры: «проверить группу Facebook», «очистить сообщения FB», «новые сообщения в группе», «отслеживать группу», «торговую площадку Facebook», «обновление группы».
