스텔스 모드와 영구 로그인 세션을 갖춘 Playwright 브라우저 자동화를 사용하여 Facebook 그룹에서 새 게시물을 모니터링하세요. 그룹 피드를 스크랩하고, 본 게시물을 추적하고, 새로운 게시물만 보고합니다. 효율적인 LLM 비전 분석을 위해 단일 스티치 "피드 스트립" 스크린샷(뷰포트 스크롤 + 필로우 스티치)을 캡처합니다. 하나의 이미지가 전체 피드를 포괄합니다. 사용 시기: Facebook 그룹 모니터링, FB 게시물 스크랩, 새 그룹 활동 확인, Facebook 자동화, 마켓플레이스 모니터링, 도서 판매 추적, 경쟁사 그룹 모니터링. 트리거: 'Facebook 그룹 확인', 'FB 게시물 스크랩', '그룹의 새 게시물', '그룹 모니터링', 'Facebook 마켓플레이스', '그룹 업데이트'.
