Registra le sessioni di conversazione dell'agente di codifica AI con timestamp in markdown strutturato. Supporta Claude Code, OpenAI Codex CLI e GitHub Copilot. Da utilizzare quando l'utente dice "registra questa sessione", "log convo" o desidera creare un record di richieste e risposte per un progetto. Rileva automaticamente quale agente è in esecuzione e legge i timestamp dal file di cronologia corretto.
