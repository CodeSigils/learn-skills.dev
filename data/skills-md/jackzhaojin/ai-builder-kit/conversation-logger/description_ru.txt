Регистрируйте сеансы разговоров агента по кодированию ИИ с временными метками в структурированной уценке. Поддерживает Claude Code, OpenAI Codex CLI и GitHub Copilot. Используйте, когда пользователь говорит «записать этот сеанс», «журнал конво» или хочет создать запись подсказок и ответов для проекта. Автоматически определяет, какой агент запущен, и считывает временные метки из правильного файла истории.
