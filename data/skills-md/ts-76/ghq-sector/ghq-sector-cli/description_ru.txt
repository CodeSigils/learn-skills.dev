Пошаговое руководство по использованию ghq-sector (gsec) — интерфейса командной строки, который распределяет представления рабочего пространства по категориям поверх ghq. Используйте этот навык всякий раз, когда пользователь спрашивает о настройке ghq-сектора, запуске команд gsec (инициализация, клонирование, синхронизация, редактирование, доктор, применение), настройке ghq-sector.config.json, управлении рабочими пространствами с несколькими репозиториями с помощью агентов ИИ или организации репозиториев, управляемых ghq, по категориям. Также используйте, когда пользователь упоминает ghq-сектор, gsec, представления рабочей области, репозитории по категориям или генерацию .code-workspace с помощью ghq, даже если он явно не называет инструмент.
