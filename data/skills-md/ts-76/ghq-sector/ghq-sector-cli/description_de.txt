Schritt-für-Schritt-Anleitung zur Verwendung von ghq-sector (gsec) – einer CLI, die kategorisierte Arbeitsbereichsansichten über ghq legt. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Fragen zum Einrichten von ghq-sector, zum Ausführen von gsec-Befehlen (init, clone, sync, edit, doctor, apply), zum Konfigurieren von ghq-sector.config.json, zum Verwalten von Multi-Repo-Arbeitsbereichen mit KI-Agenten oder zum Organisieren von von ghq verwalteten Repositorys in Kategorien stellt. Wird auch verwendet, wenn der Benutzer ghq-sector, gsec, Workspace-Ansichten, kategorisierte Repos oder .code-workspace-Generierung mit ghq erwähnt, auch wenn er das Tool nicht explizit nennt.
