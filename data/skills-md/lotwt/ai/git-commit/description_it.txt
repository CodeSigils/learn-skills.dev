Analizzare le modifiche all'area di staging di Git, leggere prima la configurazione di commitlint nel repository e generare il messaggio di commit in base alle regole del progetto; se non esiste alcuna configurazione di questo tipo, ricorrere alla convenzione commitlint (Angular) incorporata. Attivato quando l'utente dice "aiutami a eseguire il commit", "genera un commit", "scrivi un messaggio di commit", "conferma commit", "conferma questo messaggio", "commit: <messaggio>"; se un singolo messaggio candidato è già stato mostrato nell'ultimo turno, dovrebbe procedere anche qualsiasi breve risposta che indichi chiaramente l'accordo per impegnarsi.
