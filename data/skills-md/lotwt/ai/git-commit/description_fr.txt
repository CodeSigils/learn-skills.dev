Analyser les changements dans la zone de transit Git, lire de préférence la configuration commitlint dans le dépôt et générer le message de validation selon les règles du projet ; si aucune configuration pertinente n'existe, revenez à la convention commitlint (Angular) intégrée. Déclenché lorsque l'utilisateur dit « aidez-moi à valider », « générer un commit », « écrire un message de commit », « confirmer le commit », « valider ce message », « commit : <message> » ; si un message de candidat unique a déjà été affiché au tour précédent, toute réponse courte indiquant clairement l'accord de validation doit également être poursuivie.
