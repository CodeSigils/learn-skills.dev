Git ステージング領域の変更を分析し、まずリポジトリ内の commitlint 構成を読み取り、プロジェクト ルールに従ってコミット メッセージを生成します。そのような構成が存在しない場合は、組み込みの commitlint (Angular) 規則に戻ります。ユーザーが「コミットを手伝ってください」、「コミットを生成してください」、「コミットメッセージを書いてください」、「コミットを確認してください」、「このメッセージをコミットしてください」、「コミット: <メッセージ>」と言ったときにトリガーされます。単一の候補メッセージが最後のターンですでに表示されている場合は、コミットへの同意を明確に示す短い応答も続行する必要があります。
