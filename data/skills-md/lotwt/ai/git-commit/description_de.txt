Analysieren Sie die Änderungen im Staging-Bereich, lesen Sie zunächst die Commitlint-Konfiguration des Repos und generieren Sie die Commit-Nachricht gemäß den Projektregeln. Wenn keine solche Konfiguration vorhanden ist, greifen Sie auf die integrierte Commitlint-Konvention (Angular) zurück. Wird ausgelöst, wenn der Benutzer „帮我提交“, „生成 commit“, „写个 commit message“, „确认提交“, „提交这个 message“, „提交:<message>“ sagt; Wenn in der vorherigen Runde bereits eine einzelne Kandidatennachricht angezeigt wurde, sollte auch jede kurze Antwort fortgesetzt werden, die eindeutig die Zustimmung zum Commit anzeigt.
