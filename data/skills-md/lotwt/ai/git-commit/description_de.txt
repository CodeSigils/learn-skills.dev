Analysieren Sie die Änderungen im Git-Staging-Bereich, lesen Sie zunächst die Commitlint-Konfiguration im Repo und generieren Sie die Commit-Nachricht gemäß den Projektregeln. Wenn keine solche Konfiguration vorhanden ist, greifen Sie auf die integrierte Commitlint-Konvention (Angular) zurück. Wird ausgelöst, wenn der Benutzer „Hilf mir beim Commit“, „Commit generieren“, „Commit-Nachricht schreiben“, „Commit bestätigen“, „Diese Nachricht committen“, „Commit: <Nachricht>“ sagt; Wenn in der letzten Runde bereits eine einzelne Kandidatennachricht angezeigt wurde, sollte auch jede kurze Antwort fortgesetzt werden, die eindeutig auf die Zustimmung zum Commit hinweist.
