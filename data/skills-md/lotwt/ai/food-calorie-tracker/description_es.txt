Identifique alimentos a partir de fotografías y calcule calorías, generando una imagen larga de un registro diario de alimentos. Se activa cuando los usuarios envían fotos de comida o mencionan frases como "registrar mi comida", "seguir calorías", "qué comí hoy", "calcular calorías para mí", "calorías", "registro de comidas", "registrar desayuno/almuerzo/cena". También aplica cuando los usuarios envían múltiples imágenes de alimentos para resumen o envían gradualmente imágenes de diferentes comidas en el chat y finalmente solicitan una imagen de resumen diario. Incluso si el usuario simplemente envía una imagen de comida y dice "este es mi almuerzo", aún así debería activarse. No lo utilice para reconocimiento de imágenes no alimentarias, consultas nutricionales o recomendaciones de recetas.
