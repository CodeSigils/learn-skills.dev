Помощник по поиску и бронированию отелей RollingGo, который реализует полный процесс запроса отелей путем вызова API гостиничного сервиса RollingGo. Поддерживаемые сценарии: 1) Поиск отелей по городу, достопримечательности, станции метро, ​​аэропорту и т. д.; 2) Фильтровать по рейтингу, бюджету, тегам (бассейн, завтрак включен, для всей семьи, для домашних животных и т. д.); 3) Запрашивать типы номеров и цены в реальном времени для конкретного отеля; 4) Сравните несколько отелей; 5) Помогите пользователям завершить бронирование. Триггерные фразы: найти отель, забронировать отель, поиск отелей, рекомендация отеля, запрос отеля, близлежащие отели, пятизвездочные отели, проживание в семье, курорт, проверить стоимость номеров, просмотреть типы номеров, заселение, где остановиться, размещение, роллингго, размещение во время путешествия, размещение в деловых поездках, семейный отель, отель с бассейном, отель с завтраком.
