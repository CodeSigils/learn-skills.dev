Плагин Claude Code для создания технических презентаций, ориентированных на разработчиков (технические переговоры,
содержание конференции) с использованием Slidedev с научно обоснованными ограничениями качества слайдов.
Добавляет самоуверенные ограничения поверх исходного Slidev для полировки презентации.
