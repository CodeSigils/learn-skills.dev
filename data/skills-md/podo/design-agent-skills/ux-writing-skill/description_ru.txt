Систематическое написание UX для цифровых продуктов — применяет четыре стандарта качества.
(Целевой, Краткий, Разговорный, Четкий) для всех копий интерфейса. Обложки
шаблоны микрокопий для кнопок, сообщений об ошибках, пустых состояний, меток форм,
уведомления, всплывающие подсказки и регистрация. Включает в себя написание текста о доступности
рекомендации, структура голоса/тона и примеры до/после. v1.6.0.
