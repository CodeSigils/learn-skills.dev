Rédaction UX systématique pour les produits numériques – applique quatre normes de qualité
(Utilisé, concis, conversationnel, clair) pour toutes les copies d'interface. Couvertures
modèles de microcopie pour les boutons, les messages d'erreur, les états vides, les étiquettes de formulaire,
notifications, info-bulles et intégration. Comprend la rédaction sur l'accessibilité
directives, cadre voix/ton et exemples avant/après. v1.6.0.
