Escritura sistemática de UX para productos digitales: aplica cuatro estándares de calidad
(Decidido, Conciso, Conversacional, Claro) para copiar todas las interfaces. Cubiertas
patrones de microcopia para botones, mensajes de error, estados vacíos, etiquetas de formulario,
notificaciones, información sobre herramientas e incorporación. Incluye escritura de accesibilidad.
pautas, marco de voz/tono y ejemplos de antes/después. v1.6.0.
