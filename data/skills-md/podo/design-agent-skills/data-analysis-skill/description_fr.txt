Workflow d'analyse parallèle multi-experts qui sélectionne 3 à 5 sous-agents experts de domaine à analyser
ensembles de données en parallèle, synthétise les résultats dans des rapports HTML interactifs avec des graphiques, et
exporte vers PowerPoint en un seul clic. Nécessite les packages Python : pandas, openpyxl, tabulate, chardet.
