أنماط كتابة فصول الكتاب الفني في Markdown باستخدام مخططات حورية البحر، يتم تقديمها عبر MkDocs. استخدم هذه المهارة عند كتابة فصول الكتاب أو تحريرها أو مراجعتها أو إضافتها أو إزالتها أو إعادة تسميتها، أو تنظيم محتوى متعدد الفصول، أو إصلاح مشكلات عرض حورية البحر، أو تغيير بنية الكتاب. يتم تشغيله أيضًا عند تحديث mkdocs.yml أو المستندات/الارتباطات الرمزية أو التنقل - حتى إذا قال المستخدم فقط "أضف فصلًا" أو "أعد تنظيم الأقسام" دون ذكر MkDocs.
