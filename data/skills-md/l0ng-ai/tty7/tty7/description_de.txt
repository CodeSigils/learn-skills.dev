Steuern Sie die tty7-Terminal-Workbench von der Shell aus mit der Binärdatei „tty7“ – Listen Sie Arbeitsbereiche/Registerkarten/Bereiche auf, teilen Sie einen Bereich, senden Sie Tastenanschläge in einen Bereich, erfassen Sie, was auf dem Bildschirm eines Bereichs angezeigt wird, führen Sie einen Befehl in einem echten PTY aus und leiten Sie dessen Exit-Code weiter, sehen Sie, welche Codierungsagenten ausgeführt werden und welche Ports ein Bereich überwacht. Verwenden Sie dies immer dann, wenn tty7, Bereiche, Arbeitsbereiche oder „%42“/„@7“/„der andere Bereich“/„der andere Agent“ angezeigt werden. wann immer Sie etwas starten müssen, das lange läuft oder interaktiv ist (Entwicklungsserver, REPL, SSH-Sitzung, „tail -f“, eine TUI), das Ihr Bash-Tool nicht blockieren sollte; wann immer ein Programm ein echtes Terminal benötigt, um sich so zu verhalten, wie der Benutzer es sieht; und wann immer Sie sich ansehen oder darüber berichten müssen, was in einem *anderen* Terminal auf diesem Rechner läuft. Günstig zu überprüfen: Wenn „$TTY7_PANE“ gesetzt ist, befinden Sie sich bereits in tty7 und jeder Befehl hier funktioniert ohne Setup.
