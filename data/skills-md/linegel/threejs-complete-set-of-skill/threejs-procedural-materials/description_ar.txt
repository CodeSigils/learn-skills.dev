المواد الإجرائية لأنظمة NodeMaterial PBR المتماسكة في Three.js WebGPU/TSL. يُستخدم عندما تحتاج مهمة إلى هويات مشتركة عبر قنوات PBR، أو يجب تحديد الأشعة فوق البنفسجية، أو المصفوفة، أو الأطلس، أو التعيين المسقط، أو تحتاج إلى معايير عادية تمت تصفيتها بالبصمة وAA مرآوية، أو تحتاج إلى حالة مادية ديناميكية لكل مثيل مع ملكية مخرجات صريحة.
