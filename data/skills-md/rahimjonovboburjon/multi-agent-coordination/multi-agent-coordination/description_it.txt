Coordina più terminali Claude Code sullo stesso progetto senza collisioni. Da utilizzare quando l'utente desidera eseguire più di 2 sessioni Claude in parallelo su un repository, chiede informazioni su flussi di lavoro multi-agente, Claude parallelo, coordinamento del terminale, blocchi di file, schede kanban condivise, ruoli pianificatore/architetto o come evitare due sessioni AI che modificano lo stesso file. Fornisce una procedura guidata di configurazione interattiva, protocollo di blocco a livello di file, bacheca attività condivisa, cancello di approvazione del pianificatore, flusso di lavoro git configurabile (ramo singolo o ramo funzionalità), rilevamento di blocchi obsoleti con TTL, introduzioni di terminale personalizzate per il ruolo e comandi barra (/multi-agent-init, /agents-status, /agent-intro, /release-locks).
