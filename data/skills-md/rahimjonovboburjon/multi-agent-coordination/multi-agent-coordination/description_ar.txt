قم بتنسيق محطات Claude Code المتعددة في نفس المشروع دون حدوث تصادمات. يُستخدم عندما يريد المستخدم تشغيل أكثر من جلستين لـ Claude بالتوازي في ريبو واحد، أو يسأل عن سير العمل متعدد الوكلاء، أو Claude المتوازي، أو التنسيق الطرفي، أو أقفال الملفات، أو لوحات كانبان المشتركة، أو أدوار المخطط/المهندس المعماري، أو كيفية تجنب جلستي الذكاء الاصطناعي لتحرير نفس الملف. يوفر معالج إعداد تفاعلي، وبروتوكول قفل على مستوى الملف، ولوحة مهام مشتركة، وبوابة موافقة المخطط، وسير عمل git قابل للتكوين (فرع واحد أو فرع ميزات)، واكتشاف القفل القديم باستخدام TTL، ومقدمات طرفية مصممة حسب الدور، وأوامر الشرطة المائلة (/multi-agent-init، /agents-status، /agent-intro، /release-locks).
