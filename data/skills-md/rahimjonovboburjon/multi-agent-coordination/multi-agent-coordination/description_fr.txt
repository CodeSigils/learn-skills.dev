Coordonnez plusieurs terminaux Claude Code sur le même projet sans collisions. À utiliser lorsque l'utilisateur souhaite exécuter plus de 2 sessions Claude en parallèle sur un dépôt, pose des questions sur les flux de travail multi-agents, Claude parallèle, la coordination des terminaux, les verrouillages de fichiers, les tableaux Kanban partagés, les rôles de planificateur/architecte ou comment éviter que deux sessions d'IA ne modifient le même fichier. Fournit un assistant de configuration interactif, un protocole de verrouillage au niveau des fichiers, un tableau de tâches partagé, une porte d'approbation du planificateur, un flux de travail git configurable (branche unique ou branche de fonctionnalité), une détection de verrouillage obsolète avec TTL, des intros de terminal adaptées au rôle et des commandes slash (/multi-agent-init, /agents-status, /agent-intro, /release-locks).
