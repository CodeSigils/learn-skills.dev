Coordine múltiples terminales Claude Code en el mismo proyecto sin colisiones. Úselo cuando el usuario quiera ejecutar más de 2 sesiones de Claude en paralelo en un repositorio, pregunte sobre flujos de trabajo de múltiples agentes, Claude paralelo, coordinación de terminales, bloqueos de archivos, tableros kanban compartidos, roles de planificador/arquitecto o cómo evitar dos sesiones de IA editando el mismo archivo. Proporciona un asistente de configuración interactivo, protocolo de bloqueo a nivel de archivos, tablero de tareas compartido, puerta de aprobación del planificador, flujo de trabajo de git configurable (de una sola rama o de funciones), detección de bloqueos obsoletos con TTL, introducciones de terminales adaptadas a roles y comandos de barra (/multi-agent-init, /agents-status, /agent-intro, /release-locks).
