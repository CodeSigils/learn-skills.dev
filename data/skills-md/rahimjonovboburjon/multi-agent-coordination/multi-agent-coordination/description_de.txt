Koordinieren Sie mehrere Claude Code-Terminals im selben Projekt ohne Kollisionen. Verwenden Sie diese Option, wenn der Benutzer mehr als zwei Claude-Sitzungen parallel auf einem Repository ausführen möchte, nach Multi-Agent-Workflows, parallelem Claude, Terminalkoordination, Dateisperren, gemeinsam genutzten Kanban-Boards, Planer-/Architektenrollen fragt oder wie er vermeiden kann, dass zwei KI-Sitzungen dieselbe Datei bearbeiten. Bietet einen interaktiven Einrichtungsassistenten, ein Sperrprotokoll auf Dateiebene, ein gemeinsames Taskboard, ein Planer-Genehmigungstor, einen konfigurierbaren Git-Workflow (Einzelzweig oder Feature-Zweig), die Erkennung veralteter Sperren mit TTL, rollenspezifische Terminal-Intros und Slash-Befehle (/multi-agent-init, /agents-status, /agent-intro, /release-locks).
