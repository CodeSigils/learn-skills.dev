Координируйте несколько терминалов Claude Code в одном проекте без конфликтов. Используйте, когда пользователь хочет запустить более двух сеансов Claude параллельно в одном репозитории, спрашивает о многоагентных рабочих процессах, параллельном Claude, координации терминалов, блокировках файлов, общих досках канбана, ролях планировщика/архитектора или о том, как избежать двух сеансов AI, редактирующих один и тот же файл. Предоставляет мастер интерактивной настройки, протокол блокировки на уровне файла, общую доску задач, шлюз утверждения планировщика, настраиваемый рабочий процесс git (одна ветвь или ветвь функции), обнаружение устаревших блокировок с помощью TTL, заставки терминала с учетом ролей и команды с косой чертой (/multi-agent-init, /agents-status, /agent-intro, /release-locks).
