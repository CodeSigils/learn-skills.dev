Transformez n'importe quelle base de code en un superbe cours HTML interactif d'une seule page qui enseigne le fonctionnement du code aux personnes non techniques. Utilisez cette compétence chaque fois que quelqu'un souhaite créer un cours interactif, un didacticiel ou une procédure pédagogique à partir d'une base de code ou d'un projet. Déclenchez également lorsque les utilisateurs mentionnent « transformer cela en cours », « expliquer cette base de code de manière interactive », « enseigner ce code », « didacticiel interactif à partir du code », « présentation pas à pas de la base de code », « apprendre à partir de cette base de code » ou « créer un cours à partir de ce projet ». Cette compétence produit un superbe fichier HTML autonome avec une navigation par défilement, des visualisations animées et des traductions côte à côte de code avec anglais simple.
