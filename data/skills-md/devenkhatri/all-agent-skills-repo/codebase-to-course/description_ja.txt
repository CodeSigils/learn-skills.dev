あらゆるコードベースを、非技術者向けにコードがどのように機能するかを教える、美しくインタラクティブな単一ページの HTML コースに変換します。コードベースまたはプロジェクトからインタラクティブなコース、チュートリアル、教育ウォークスルーを作成したい場合は、このスキルを使用してください。また、ユーザーが「これをコースに変える」、「このコードベースを対話的に説明する」、「このコードを教える」、「コードからの対話型チュートリアル」、「コードベースのチュートリアル」、「このコードベースから学ぶ」、または「このプロジェクトからコースを作成する」と述べたときにもトリガーされます。このスキルは、スクロールベースのナビゲーション、アニメーション化された視覚化、および平易な英語の並列翻訳を備えたコードを備えた、魅力的な自己完結型 HTML ファイルを生成します。
