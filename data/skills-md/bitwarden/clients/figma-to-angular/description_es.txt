Convierte diseños de Figma en componentes Angular de producción con historias de Storybook para el monorepo de Bitwarden Clients. Utilice esta habilidad siempre que el usuario proporcione una URL de Figma y quiera crear un componente Angular, o mencione "implementar este diseño", "crear un componente a partir de Figma", "construir esto a partir de la especificación de diseño" o similar. También se activa cuando el usuario pega un enlace de Figma y solicita un componente, incluso si no dice "Figma" explícitamente.
