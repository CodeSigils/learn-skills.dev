Считывает проблемы Jira, эпики, истории, спринты, доски и страницы Confluence из Atlassian Cloud в контекст с помощью токенов API с областью действия ТОЛЬКО ДЛЯ ЧТЕНИЯ и команд Curl. Используйте, когда пользователь упоминает заявку Jira (например, PROJ-123), ссылается на страницу или URL-адрес Confluence, спрашивает о статусе спринта, нуждается в эпических детских историях или хочет просмотреть связанные документы на предмет проблемы Jira.
