Immer wenn eine Benutzeraufgabe PDF-Dateivorgänge, Inhaltsverarbeitung oder Formatkonvertierung umfasst, muss diese Fähigkeit verwendet werden. Dazu gehören unter anderem: Lesen/Anzeigen von PDF-Inhalten, Extrahieren von Text/Tabellen/Formeln/Bildern, Konvertieren von PDFs in Markdown oder andere Formate, Zusammenführen mehrerer PDFs, Teilen von PDF-Seiten, Drehen von Seiten, Hinzufügen von Wasserzeichen, Erstellen neuer PDFs, Ausfüllen von PDF-Formularen, Verschlüsseln/Entschlüsseln von PDFs, Komprimieren/Optimieren von PDFs. Unabhängig davon, ob die Aufgabe einfach oder komplex ist, muss diese Fähigkeit zuerst geladen werden, solange der Benutzer PDF-Dateien oder PDF-Dokumente erwähnt oder eine Verarbeitung von PDFs benötigt (einschließlich Inhaltszusammenfassung, Informationssuche, Datenextraktion, Textanalyse, OCR-Erkennung). Wenn der Benutzer den Vergleich mehrerer PDFs, die Suche nach bestimmten Informationen in PDFs oder die Durchführung nachfolgender Vorgänge auf der Grundlage von PDF-Inhalten anfordert, muss diese Fähigkeit ebenfalls genutzt werden.
