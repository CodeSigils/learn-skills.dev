ユーザー タスクに PDF ファイルの操作、コンテンツの処理、または形式の変換が含まれる場合は常に、このスキルを**使用する必要があります**。これには、PDF コンテンツの読み取り/表示、テキスト/表/数式/画像の抽出、PDF から Markdown またはその他の形式への変換、複数の PDF の結合、PDF ページの分割、ページの回転、透かしの追加、新しい PDF の作成、PDF フォームの入力、PDF の暗号化/復号化、PDF の圧縮/最適化が含まれますが、これらに限定されません。タスクが単純であるか複雑であるかに関係なく、ユーザーが .pdf ファイルや PDF ドキュメントに言及する場合、または PDF の処理 (内容の要約、情報検索、データ抽出、テキスト分析、OCR 認識など) を必要とする場合には、このスキルを最初にロードする必要があります。ユーザーが複数の PDF の比較、PDF 内の特定の情報の検索、または PDF コンテンツに基づいた後続の操作の実行を要求した場合も、このスキルを使用する必要があります。
