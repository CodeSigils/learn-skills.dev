Ogni volta che un'attività dell'utente implica manipolazione, elaborazione di contenuti o conversione del formato di file PDF, **devi** utilizzare questa abilità. Ciò include, ma non è limitato a: leggere/visualizzare contenuto PDF, estrarre testo/tabelle/formule/immagini, convertire PDF in Markdown o altri formati, unire più PDF, dividere pagine PDF, ruotare pagine, aggiungere filigrane, creare nuovi PDF, compilare moduli PDF, crittografare/decrittografare PDF, comprimere/ottimizzare PDF. Indipendentemente dal fatto che l'attività sia semplice o complessa, purché l'utente menzioni un file .pdf, un documento PDF o richieda qualsiasi elaborazione di un PDF (incluso riepilogo del contenuto, ricerca di informazioni, estrazione di dati, analisi di testo, riconoscimento OCR), è necessario prima caricare questa abilità. Se l'utente chiede di confrontare più PDF, cercare informazioni specifiche all'interno di un PDF o eseguire qualsiasi azione successiva basata sul contenuto PDF, è necessario utilizzare anche questa capacità.
