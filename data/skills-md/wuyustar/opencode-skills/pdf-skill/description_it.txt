Ogni volta che un'attività utente coinvolge operazioni su file PDF, elaborazione di contenuto o conversione di formato, questa competenza **deve** essere utilizzata. Ciò include ma non è limitato a: leggere/visualizzare contenuto PDF, estrarre testo/tabelle/formule/immagini, convertire PDF in Markdown o altri formati, unire più PDF, dividere pagine PDF, ruotare pagine, aggiungere filigrane, creare nuovi PDF, compilare moduli PDF, crittografare/decrittografare PDF, comprimere/ottimizzare PDF. Indipendentemente dal fatto che l'attività sia semplice o complessa, purché l'utente menzioni file .pdf, documenti PDF o richieda qualsiasi elaborazione di PDF (incluso riepilogo dei contenuti, ricerca di informazioni, estrazione di dati, analisi di testo, riconoscimento OCR), questa abilità deve essere caricata per prima. Se l'utente richiede il confronto di più PDF, la ricerca di informazioni specifiche all'interno dei PDF o l'esecuzione di qualsiasi operazione successiva basata sul contenuto PDF, è necessario utilizzare anche questa capacità.
