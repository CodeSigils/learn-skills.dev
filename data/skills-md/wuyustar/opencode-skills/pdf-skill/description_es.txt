Siempre que una tarea de usuario implique operaciones con archivos PDF, procesamiento de contenido o conversión de formato, **debe** utilizarse esta habilidad. Esto incluye, entre otros: leer/ver contenido PDF, extraer texto/tablas/fórmulas/imágenes, convertir PDF a Markdown u otros formatos, fusionar varios archivos PDF, dividir páginas PDF, rotar páginas, agregar marcas de agua, crear nuevos archivos PDF, completar formularios PDF, cifrar/descifrar archivos PDF, comprimir/optimizar archivos PDF. Independientemente de si la tarea es simple o compleja, siempre que el usuario mencione archivos .pdf, documentos PDF o requiera algún procesamiento de archivos PDF (incluido resumen de contenido, búsqueda de información, extracción de datos, análisis de texto, reconocimiento OCR), esta habilidad debe cargarse primero. Si el usuario solicita comparar varios archivos PDF, buscar información específica dentro de los archivos PDF o realizar operaciones posteriores basadas en el contenido del PDF, también se debe utilizar esta habilidad.
