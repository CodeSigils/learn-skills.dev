إدارة وتشغيل الوظائف الكاملة لنظام ملاحظات المذكرات. استخدم هذه المهارة عندما يحتاج المستخدم إلى:
- إنشاء أو عرض أو تعديل أو حذف المذكرات/الملاحظات
- البحث في قائمة المذكرات أو تصفيتها أو فرزها
- إدارة مرفقات المذكرات (تحميل، عرض، حذف)
- إدارة علامات المذكرة
- إضافة أو إدارة التعليقات
- إضافة ردود الفعل التعبيرية
- ضبط رؤية المذكرة (خاصة، محمية، عامة)
- دبوس أو أرشفة المذكرات
- إنشاء روابط المشاركة
- ربط المذكرات ذات الصلة
بغض النظر عما إذا كان المستخدم يذكر صراحةً "المذكرات" أو "备忘录"، استخدم هذه المهارة عندما يتعلق الأمر بإدارة الملاحظات.
