Manage and operate the full functionality of the Memos note system. Use this skill when the user needs to:
- Create, view, edit, or delete memos/notes
- Search, filter, or sort the memo list
- Manage memo attachments (upload, view, delete)
- Manage memo tags
- Add or manage comments
- Add emoji reactions
- Set memo visibility (private, protected, public)
- Pin or archive memos
- Create share links
- Link related memos
Use this skill for any note-management tasks, even if the user does not explicitly mention "memos" or "备忘录."
