Eine Fähigkeit, die Benutzern hilft, sechsdimensionale Framework-Eingabeaufforderungen zu erstellen. Wird ausgelöst, wenn der Benutzer Dinge wie „Schreibe eine Eingabeaufforderung“, „Hilf mir beim Entwerfen eines KI-Assistenten“ oder „Erstelle eine sechsdimensionale Framework-Eingabeaufforderung“ sagt.

Führen Sie den Benutzer durch Gesprächsführung Schritt für Schritt durch die Definition der Ebenen „Ziel“, „Wissen“, „Verhalten“, „Norm“, „Verifizierung“ und „Protokoll“, um letztendlich eine professionelle Eingabeaufforderung zu erstellen, die dem MECE-Prinzip entspricht.
