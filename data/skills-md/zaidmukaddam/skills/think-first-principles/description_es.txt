Reconstruir una decisión a partir de lo que debe ser cierto y no del precedente. Recupere el objetivo real, etiquete cada suposición, calcule el piso teórico y compare el sistema actual con él, elimine antes de optimizar y luego proponga la prueba más barata que resolvería la duda restante. Utilice esto siempre que el usuario elija una arquitectura, dimensione un sistema, reduzca costos o latencia, cuestione un requisito, evalúe la viabilidad, rediseñe un proceso o diga cosas como "por qué es tan caro", "hay una mejor manera", "todos hacen X pero" o "desafía mis suposiciones". Consúltelo cada vez que sea costoso revertir una decisión o la respuesta obvia se herede en lugar de derivarse, incluso cuando el usuario nunca use la frase.
