Gérez une pull request GitHub jusqu'à ce qu'elle soit prête à la fusion en interrogeant sans relâche le statut et en n'agissant qu'une fois que tous les réviseurs automatiques ont terminé. Ne fusionne JAMAIS sans l’approbation humaine explicite. À utiliser lorsque l'utilisateur dit des choses comme « surveiller ce PR », « garder ce PR », « préparer ce PR à la fusion », « attendre Cubic », « attendre Bugbot » ou demande de conduire un PR via l'examen.
