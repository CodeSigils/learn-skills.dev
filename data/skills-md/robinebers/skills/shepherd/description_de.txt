Führen Sie einen GitHub-Pull-Request bis zur Merge-Bereitschaft durch, indem Sie den Status kontinuierlich abfragen und erst dann handeln, wenn alle automatischen Prüfer fertig sind. Führt NIEMALS ohne ausdrückliche menschliche Zustimmung zusammen. Verwenden Sie diese Option, wenn der Benutzer Dinge sagt wie „Diese PR betreuen“, „Diese PR babysitten“, „Diese PR für die Zusammenführung vorbereiten“, „Auf Cubic warten“, „Auf Bugbot warten“ oder darum bittet, eine PR durch die Überprüfung zu bringen.
