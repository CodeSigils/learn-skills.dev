Kit de herramientas de disciplina de ingeniería para usuarios no técnicos que trabajan con codificadores de IA. Utiliza KISS, DRY, YAGNI, fail-fast e idempotencia como comandos. Úselo cuando el usuario solicite auditar, simplificar, limpiar, deduplicar o reforzar el código; o dice "simplifique esto", "¿hay duplicados?", "es seguro ejecutarlo dos veces", "explica esta aplicación", "encuentra código inactivo", "simplifica el plan" o "encuentra fallas silenciosas".
