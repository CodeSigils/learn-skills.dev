Boîte à outils de discipline d'ingénierie pour les utilisateurs non techniques travaillant avec des codeurs d'IA. Utilise KISS, DRY, YAGNI, fail-fast et idempotency comme commandes. À utiliser lorsque l'utilisateur demande à auditer, simplifier, nettoyer, dédupliquer ou renforcer le code ; ou dit "rendre cela plus simple", "des doublons ?", "est-il sûr d'exécuter deux fois", "expliquer cette application", "trouver le code mort", "simplifier le plan" ou "trouver les échecs silencieux".
