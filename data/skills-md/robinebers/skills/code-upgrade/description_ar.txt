مجموعة أدوات الانضباط الهندسي للمستخدمين غير التقنيين الذين يعملون مع مبرمجي الذكاء الاصطناعي. يستخدم KISS، وDRY، وYAGNI، وفشل سريع، والعجز كأوامر. يُستخدم عندما يطلب المستخدم تدقيق التعليمات البرمجية أو تبسيطها أو تنظيفها أو حذفها أو تقويتها؛ أو يقول "اجعل هذا أبسط"، أو "هل هناك أي نسخ مكررة؟"، أو "هل هذا آمن للتشغيل مرتين"، أو "اشرح هذا التطبيق"، أو "ابحث عن التعليمات البرمجية الميتة"، أو "تبسيط الخطة"، أو "ابحث عن حالات الفشل الصامتة".
