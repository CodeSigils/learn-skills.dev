Toolkit für technische Disziplinen für technisch nicht versierte Benutzer, die mit KI-Programmierern arbeiten. Führt KISS, DRY, YAGNI, Fail-Fast und Idempotenz als Befehle aus. Verwenden Sie diese Option, wenn der Benutzer Code prüfen, vereinfachen, bereinigen, deduplizieren oder härten möchte. oder sagt: „Machen Sie dies einfacher“, „Gibt es Duplikate?“, „Ist dies sicher, es zweimal auszuführen“, „Erklären Sie diese App“, „Finden Sie toten Code“, „Vereinfachen Sie den Plan“ oder „Finden Sie stille Fehler“.
