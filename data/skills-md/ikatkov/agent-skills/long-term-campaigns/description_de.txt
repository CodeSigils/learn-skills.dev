Behalten Sie Überwachungs- oder Besitzkampagnen bei, planen Sie sie, setzen Sie sie fort und übergeben Sie sie, wenn sie eine Agentensitzung oder einen verfügbaren Arbeitsbereich überdauern. Verwenden Sie diese Funktion, wenn die Arbeit über Tage hinweg wiederholt überprüft werden muss, wenn eine neue Langzeitkampagne erstellt wird, wenn laufende Arbeiten an einen zukünftigen Agenten übertragen werden oder wenn ein verzögerter evidenzbasierter Bericht erstellt wird.
