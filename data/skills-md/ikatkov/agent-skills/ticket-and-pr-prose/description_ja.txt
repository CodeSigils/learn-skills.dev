リニア チケットまたはプル リクエストの説明をスタンドアロンの漸進的開示の散文スタイルで作成します。固定された「これが重要な理由 (平易な言葉) / これが適合する場所 / 私たちが構築しているもの (またはこれが変更するもの)」の背骨がエンジニアリングの詳細にスライドし、フローが人魚図 (動作が変化する前と後) として示されます。チケットや PR の説明を作成/作成/書き換えたり、エンジニアリング以外のユーザーがフォローできるように変更を作成したり、コンテキストを持たない人が PR をレビューできるようにするよう求められた場合に使用します。トリガー: 「リニアチケットを作成する」、「これをチケットとして作成する」、「PR の説明を作成する」、「PR 本文を記入する」、「この PR をレビュー可能にする」、「非エンジニア向けのチケット」。
