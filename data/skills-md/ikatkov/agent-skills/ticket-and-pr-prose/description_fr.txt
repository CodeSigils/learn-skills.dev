Rédigez un ticket linéaire ou une description de demande d'extraction dans le style de prose autonome à divulgation progressive : une colonne vertébrale fixe "Pourquoi cela est important (langage simple) / Où cela correspond / Ce que nous construisons (ou Qu'est-ce que cela change)" glissant dans les détails techniques, avec le flux affiché sous forme de diagrammes de sirène (avant + après lorsque le comportement change). À utiliser lorsqu'on vous demande de créer/écrire/réécrire un ticket ou une description de PR, de rédiger une modification afin qu'un public non-ingénieur puisse la suivre, ou de rendre un PR révisable par une personne sans contexte. Déclencheurs : « créer un ticket linéaire », « rédiger ceci sous forme de ticket », « rédiger la description du PR », « remplir le corps du PR », « rendre ce PR révisable », « ticket pour un public non-anglais ».
