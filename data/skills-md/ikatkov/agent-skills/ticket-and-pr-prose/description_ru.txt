Напишите линейный билет или описание запроса на включение в автономном стиле с прогрессивным раскрытием информации: фиксированный «Почему это важно (простой язык) / Где это подходит / Что мы строим (или Что это меняет)», плавно переходящий в инженерные детали, с потоком, показанным в виде диаграмм-русалок (до + после, когда поведение меняется). Используйте, когда вас просят создать/написать/переписать заявку или описание PR, записать изменение, чтобы за ним могла следить нетехническая аудитория, или сделать PR доступным для просмотра кем-то без контекста. Триггеры: «создать линейную заявку», «записать это как заявку», «написать описание PR», «заполнить тело PR», «сделать этот PR доступным для просмотра», «заявка для неанглоязычной аудитории».
