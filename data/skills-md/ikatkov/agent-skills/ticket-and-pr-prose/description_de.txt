Schreiben Sie ein lineares Ticket oder eine Pull-Request-Beschreibung im eigenständigen Prosastil mit progressiver Offenlegung: ein fester „Warum das wichtig ist (Klartext) / Wo das passt / Was wir bauen (oder Was sich das ändert)“-Rückgrat, das in technische Details übergeht, wobei der Ablauf als Meerjungfrauendiagramme dargestellt wird (vorher + nachher, wenn sich das Verhalten ändert). Verwenden Sie diese Option, wenn Sie aufgefordert werden, ein Ticket oder eine PR-Beschreibung zu erstellen/schreiben/umzuschreiben, eine Änderung so aufzuschreiben, dass ein nicht-technisches Publikum sie verfolgen kann, oder eine PR für jemanden ohne Kontext überprüfbar zu machen. Auslöser: „Ein lineares Ticket erstellen“, „Dies als Ticket verfassen“, „PR-Beschreibung schreiben“, „PR-Text ausfüllen“, „Diese PR überprüfbar machen“, „Ticket für nicht-englischsprachiges Publikum“.
