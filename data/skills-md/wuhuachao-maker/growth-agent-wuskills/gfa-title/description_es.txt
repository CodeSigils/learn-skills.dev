Habilidad de metodología de títulos virales multi‑plataforma (archivo único, autónomo, sin lecturas de archivos externos). Se activa cuando un usuario desea crear un título / redactar un título viral / optimizar un título, o menciona “título de Xiaohongshu / título de cuenta pública / título de Douyin / título SEO / optimización GEO / el título no recibe clics / cómo escribir un título”, o proporciona un contenido y quiere un título con alto número de clics. Basado en la psicología de los títulos + mecanismos de tráfico de tres plataformas + descubribilidad dual SEO/GEO, incluye bibliotecas de fórmulas integradas para Xiaohongshu (5), cuentas públicas (9), Douyin (5) y una plantilla completa de hoja de cálculo de salida, permitiendo la generación directa de títulos multi‑plataforma listos para auditoría y optimizables. No ejecuta APIs de pago para el usuario, no acepta datos privados.
