Skill-manager-cli를 통해 사용자의 공유 에이전트 기술 라이브러리를 관리합니다. 에이전트당 기술을 설치, 업데이트, 제거, 배포 또는 배포 취소하고, 사전 설정을 관리하고, 태그를 구성하고, 검색하고, 기존 기술을 채택합니다. 사용자가 Claude Code, Codex, Cursor 또는 다른 에이전트가 스킬을 얻거나 잃기를 원할 때, 중앙 라이브러리를 구성하고 싶을 때, 무엇이 설치되거나 배포되었는지 물어볼 때마다 이것을 사용하십시오. Skills Manager는 소스 메타데이터, 사전 설정된 멤버십, 업데이트 및 에이전트 간 배포 상태를 유지하므로 직접 에이전트 폴더 설치보다 이를 선호합니다.
