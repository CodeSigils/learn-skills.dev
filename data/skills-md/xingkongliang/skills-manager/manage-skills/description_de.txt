Verwalten Sie die gemeinsame Agenten-Skill-Bibliothek des Benutzers über skills-manager-cli – installieren, aktualisieren, entfernen, bereitstellen oder deinstallieren Sie Skills pro Agent, verwalten Sie Voreinstellungen, organisieren Sie Tags, suchen Sie und übernehmen Sie vorhandene Skills. Verwenden Sie dies immer dann, wenn der Benutzer möchte, dass Claude Code, Codex, Cursor oder ein anderer Agent eine Fertigkeit erlangt oder verliert, die Zentralbibliothek organisieren möchte oder fragt, was installiert oder bereitgestellt wird. Bevorzugen Sie dies gegenüber direkten Agent-Ordner-Installationen, da der Skills Manager Quellmetadaten, voreingestellte Mitgliedschaften, Aktualisierungen und den agentenübergreifenden Bereitstellungsstatus beibehält.
