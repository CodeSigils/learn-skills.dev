قم بإدارة مكتبة مهارات الوكيل المشتركة للمستخدم عبر Skills-manager-cli — تثبيت المهارات أو تحديثها أو إزالتها أو نشرها أو إلغاء نشرها لكل وكيل، وإدارة الإعدادات المسبقة، وتنظيم العلامات، والبحث، واعتماد المهارات الحالية. استخدم هذا عندما يريد المستخدم أن يكتسب Claude Code أو Codex أو Cursor أو أي وكيل آخر مهارة ما أو يفقدها، أو يريد تنظيم المكتبة المركزية، أو يسأل عما تم تثبيته أو نشره. قم بتفضيل ذلك على عمليات التثبيت المباشرة لمجلد الوكيل لأن Skills Manager يحتفظ ببيانات تعريف المصدر والعضوية المعينة مسبقًا والتحديثات وحالة النشر عبر الوكيل.
