قم بإنشاء عروض شرائح HTML عالية الجودة باستخدام قوالب جميلة. تأكد من استخدام هذه المهارة عندما يذكر المستخدم شرائح أو عرضًا تقديميًا أو PPT أو عرضًا تقديميًا أو كلمة رئيسية أو 演示文稿 أو 幻灯片 - حتى لو لم يطلبوا صراحةً HTML أو القوالب. تتعامل هذه المهارة مع سير العمل المصقول متعدد القوالب والموضوعات السريعة المستقلة. استخدمه لأي طلب يتضمن إنشاء أو إنشاء أو إنشاء عرض تقديمي بغض النظر عن كيفية صياغة الطلب.
