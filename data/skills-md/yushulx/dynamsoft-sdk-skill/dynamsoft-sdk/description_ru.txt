Создавайте и проверяйте точный код для Dynamsoft SDK — Dynamic Web TWAIN (DWT), Document Viewer (DDV), Barcode Reader (DBR) и Capture Vision (DCV) — используя пошаговое руководство по штрих-кодам, QR-кодам, MRZ и считыванию документов в Интернете, на мобильных устройствах, на серверах и настольных компьютерах. Включает поднавык оптимизатора шаблона для настройки JSON шаблона DBR для максимизации скорости декодирования. Используйте для интеграции Dynamsoft SDK, примера кода, миграции, использования API, устранения неполадок, рабочих процессов CaptureVisionRouter или настройки шаблонов штрих-кодов.
