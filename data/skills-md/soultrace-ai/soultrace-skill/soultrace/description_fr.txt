Faites une évaluation de personnalité via l'API SoulTrace. À utiliser lorsque l'utilisateur souhaite passer un test de personnalité, découvrir son archétype psychologique, comprendre ses traits de personnalité ou obtenir un profil de personnalité basé sur la couleur. L'API utilise un modèle psychologique à 5 couleurs (Blanc = structure, Bleu = compréhension, Noir = agence, Rouge = intensité, Vert = connexion) avec sélection de questions adaptatives bayésiennes pour classer les utilisateurs dans l'un des 25 archétypes. Se déclenche sur : test de personnalité, évaluation de personnalité, quelle est ma personnalité, répondre à un quiz, test d'archétype, personnalité de couleur, trace d'âme.
