Пройдите оценку личности с помощью SoulTrace API. Используйте, когда пользователь хочет пройти личностный тест, раскрыть свой психологический архетип, понять черты своей личности или получить профиль личности на основе цвета. API использует 5-цветную психологическую модель (белый = структура, синий = понимание, черный = агентство, красный = интенсивность, зеленый = связь) с байесовским адаптивным выбором вопросов для классификации пользователей по одному из 25 архетипов. Запускается по: тесту личности, оценке личности, какая у меня личность, пройти тест, тест архетипа, цвет личности, след души.
