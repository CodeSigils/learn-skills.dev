Führen Sie eine Persönlichkeitsbeurteilung über die SoulTrace-API durch. Verwenden Sie diese Option, wenn der Benutzer einen Persönlichkeitstest durchführen, seinen psychologischen Archetyp entdecken, seine Persönlichkeitsmerkmale verstehen oder ein farbbasiertes Persönlichkeitsprofil erstellen möchte. Die API verwendet ein psychologisches 5-Farben-Modell (Weiß=Struktur, Blau=Verstehen, Schwarz=Agentur, Rot=Intensität, Grün=Verbindung) mit bayesianischer adaptiver Fragenauswahl, um Benutzer in einen von 25 Archetypen zu klassifizieren. Auslöser für: Persönlichkeitstest, Persönlichkeitsbewertung, Was ist meine Persönlichkeit, an einem Quiz teilnehmen, Archetypentest, Farbpersönlichkeit, Seelenspur.
