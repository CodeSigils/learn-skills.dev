Realice una evaluación de personalidad a través de la API SoulTrace. Úselo cuando el usuario quiera realizar una prueba de personalidad, descubrir su arquetipo psicológico, comprender sus rasgos de personalidad u obtener un perfil de personalidad basado en colores. La API utiliza un modelo psicológico de cinco colores (Blanco=estructura, Azul=comprensión, Negro=agencia, Rojo=intensidad, Verde=conexión) con selección de preguntas adaptativa bayesiana para clasificar a los usuarios en uno de 25 arquetipos. Activadores de: prueba de personalidad, evaluación de personalidad, cuál es mi personalidad, realizar una prueba, prueba de arquetipo, color de personalidad, soultrace.
