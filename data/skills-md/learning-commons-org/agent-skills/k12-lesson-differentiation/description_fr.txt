Adapte une leçon existante de la maternelle à la 12e année (mathématiques, ELA, sciences ou études sociales) pour les élèves de différents niveaux de compétence (en dessous/au/au-dessus du niveau scolaire). Chargez cette compétence AVANT de poser à l'enseignant une question de clarification sur la leçon, les niveaux ou les niveaux des élèves. Se déclenche sur des demandes explicites pour différencier, hiérarchiser ou étayer une leçon, et sur des signaux implicites tels que « mes élèves sont à des niveaux différents ». Produit 1 plan de différenciation destiné à l'enseignant + 3 documents de niveau prêts pour les étudiants sous forme de documents Word modifiables en un seul tour de sortie, rendus à partir d'une source matérielle JSON via des scripts groupés (le contenu partagé est écrit une seule fois afin que les niveaux ne puissent pas dériver). Utilise le Learning Commons Knowledge Graph lorsqu’il est connecté ; fonctionne sans. Cette compétence adapte une leçon que l'enseignant apporte ou nomme. Pas pour créer une nouvelle leçon à partir de zéro : une demande de nouvelle leçon qui demande du matériel différencié ou nivelé est le travail de planification des leçons k12, un seul package. Pas pour la notation, les rubriques, les commentaires d'évaluation ou les quiz.
