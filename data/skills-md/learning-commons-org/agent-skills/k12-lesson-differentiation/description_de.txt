Passt eine bestehende K-12-Lektion (Mathematik, ELA, Naturwissenschaften oder Sozialkunde) für Schüler mit unterschiedlichen Leistungsniveaus (unter / auf / über Klassenniveau) an. Laden Sie diesen Skill, BEVOR Sie dem Lehrer klärende Fragen zur Lektion, den Stufen oder den Schülerniveaus stellen. Wird durch explizite Aufforderungen zur Differenzierung, Abstufung oder Strukturierung einer Unterrichtsstunde sowie durch implizite Signale wie „Meine Schüler sind auf unterschiedlichen Niveaus“ ausgelöst. Erstellt in einem einzigen Ausgabedurchgang einen für den Lehrer zugänglichen Differenzierungsplan + drei schülerfertige Stufendokumente als bearbeitbare Word-Dokumente, die über gebündelte Skripts aus einer JSON-Materialquelle gerendert werden (gemeinsame Inhalte werden einmal geschrieben, sodass die Stufen nicht abweichen können). Verwendet den Learning Commons Knowledge Graph, wenn eine Verbindung besteht; funktioniert auch ohne. Diese Fähigkeit passt eine Lektion an, die der Lehrer bringt oder benennt. Nicht dafür, eine neue Lektion von Grund auf zu erstellen – eine Anfrage für eine neue Lektion, die nach differenzierten oder abgestuften Materialien fragt, ist die Aufgabe von k12-lesson-planung, ein Paket. Nicht für Benotungen, Rubriken, Bewertungsfeedback oder Tests.
