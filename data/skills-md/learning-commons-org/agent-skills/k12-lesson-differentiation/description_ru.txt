Адаптирует существующий урок K-12 (математика, ELA, естествознание или обществознание) для учащихся разного уровня подготовки (ниже/на уровне/выше класса). Закрепите этот навык ПРЕЖДЕ ЧЕМ задавать учителю уточняющие вопросы об уроке, уровнях или уровнях учащихся. Запускается по явным запросам дифференцировать, ранжировать или формировать урок, а также по неявным сигналам, таким как «мои ученики находятся на разных уровнях». Создает 1 план дифференциации для преподавателей + 3 многоуровневых документа, готовых для учащихся, в виде редактируемых документов Word за один выходной поток, визуализируемых из одного исходного материала в формате JSON с помощью связанных сценариев (общий контент записывается один раз, чтобы уровни не могли меняться). При подключении использует график знаний Learning Commons; работает без него. Этот навык адаптирует урок, который учитель приносит или называет. Не для создания нового урока с нуля — запрос на новый урок, требующий дифференцированных или уровневых материалов, — это работа по планированию урока k12, один пакет. Не для выставления оценок, рубрик, отзывов об оценках или викторин.
