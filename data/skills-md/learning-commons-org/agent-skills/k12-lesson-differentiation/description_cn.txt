针对不同熟练程度（低于/等于/高于年级水平）的学生调整现有的 K-12 课程（数学、ELA、科学或社会研究）。在向老师询问有关课程、级别或学生水平的任何澄清问题之前，先加载此技能。触发明确的要求来区分、分层或构建课程，以及触发诸如“我的学生处于不同水平”之类的隐含信号。在单个输出回合中生成 1 个面向教师的差异化计划 + 3 个学生就绪的分层文档作为可编辑的 Word 文档，通过捆绑脚本从一个材料源 JSON 呈现（共享内容写入一次，因此分层不会漂移）。连接时使用学习共享知识图；没有它也能工作。这项技能适应老师带来或命名的课程。不是为了从头开始创建新课程 - 要求差异化或分级材料的新课程请求是 k12 课程规划的工作，一个包。不适用于评分、评分标准、评估反馈或测验。
