Adapta una lección existente desde K-12 (matemáticas, ELA, ciencias o estudios sociales) para estudiantes con diferentes niveles de competencia (por debajo/al nivel/superior al nivel de grado). Cargue esta habilidad ANTES de hacerle al maestro cualquier pregunta aclaratoria sobre la lección, los niveles o los niveles de los estudiantes. Se desencadenan solicitudes explícitas para diferenciar, clasificar o estructurar una lección, y señales implícitas como "mis alumnos están en diferentes niveles". Produce 1 plan de diferenciación orientado al profesor + 3 documentos de niveles listos para estudiantes como documentos de Word editables en un solo turno de salida, renderizados a partir de un JSON de fuente de material a través de secuencias de comandos empaquetadas (el contenido compartido se escribe una vez para que los niveles no puedan variar). Utiliza el Gráfico de conocimiento de Learning Commons cuando está conectado; Funciona sin él. Esta habilidad adapta una lección que el maestro trae o nombra. No para crear una nueva lección desde cero: una solicitud de nueva lección que solicita materiales diferenciados o nivelados es el trabajo de k12-lesson-planning, un solo paquete. No para calificaciones, rúbricas, comentarios de evaluaciones ni cuestionarios.
