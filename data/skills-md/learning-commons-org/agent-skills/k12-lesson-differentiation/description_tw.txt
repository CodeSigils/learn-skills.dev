針對不同熟練程度（低於/等於/高於年級水平）的學生調整現有的 K-12 課程（數學、ELA、科學或社會研究）。在向老師詢問有關課程、級別或學生水平的任何澄清問題之前，先加載此技能。觸發明確的要求來區分、分層或建立課程，以及觸發諸如「我的學生處於不同水平」之類的隱含訊號。在單一輸出回合中產生 1 個教師的差異化計畫 + 3 個學生就緒的分層文檔作為可編輯的 Word 文檔，透過捆綁腳本從一個材料來源 JSON 呈現（共享內容寫入一次，因此分層不會漂移）。連結時使用學習共享知識圖；沒有它也能運作。這項技能適應老師帶來或命名的課程。不是為了從頭開始創建新課程 - 要求差異化或分級材料的新課程請求是 k12 課程規劃的工作，一個包。不適用於評分、評分標準、評估回饋或測驗。
