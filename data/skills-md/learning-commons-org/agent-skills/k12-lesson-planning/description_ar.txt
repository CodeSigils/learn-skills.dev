يقوم بإنشاء خطة الدرس والمواد الموجهة للطالب ونموذج الملاحظة. قم بتحميل هذه المهارة قبل أن تطرح على المعلم أي سؤال توضيحي حول الصف أو المادة أو الموضوع أو المعيار أو التوقيت. يُستخدم عندما يحتاج معلم مرحلة الروضة حتى الصف الثاني عشر إلى درس الرياضيات أو ELA أو العلوم أو الدراسات الاجتماعية المبني من الصفر - حتى إذا لم يتم تحديد الدرجة أو المادة أو الموضوع بعد. لا تقم بالتحميل من أجل التقدير، أو نموذج التقييم، أو تعليقات التقييم، أو الاختبار القصير، أو البحث عن المعايير - أجب عن ذلك مباشرة. تفعيل الطلبات الصريحة (خطة الدرس، الدرس المصغر، خطة الوحدة، الخطة اليومية) ونية المعلم الضمنية: "أقوم بتدريس القسمة المطولة لطلاب الصف الخامس"، "أحتاج إلى تدريس عملية التمثيل الضوئي غدًا". الإشارة الأساسية: يحتاج المعلم إلى إنشاء محتوى تعليمي جديد. لا يزال الدرس الجديد الذي يطلب مواد متمايزة أو متدرجة أو مستوية بمثابة طلب تخطيط واحد - تنتج هذه المهارة تلك المواد داخل حزمة الدرس؛ لا تستدعي أيضًا تمايز الدرس k12. ليس للتمييز بين درس موجود (استخدم تمييز درس k12) أو إعادة كتابة المقطع.
