Профессиональный инструмент для создания и проверки тестовых примеров. Поддерживает создание 11 типов тестовых примеров (функциональный, интерфейс, пользовательский интерфейс, производительность, безопасность, интеграция, маршрутизация, навигация, адаптация, доступность, совместимость) с охватом ≥90%.  
Принимает принцип поэтапного раскрытия информации, загружая по требованию. Тесты, специфичные для платформы, генерируются только после того, как пользователь явно укажет их.  
Поддерживает проверку существующих тестовых примеров, вывод отчета о проверке и дополнение отсутствующих тестовых примеров.
