# 测试用例生成与审查 Skill

## 核心能力

1. **生成测试用例** - 根据需求生成结构化测试用例（覆盖度≥90%）
2. **审查测试用例** - 审查已有用例，输出审查报告并自动补全
3. **按需加载** - 采用逐步披露原则，只加载需要的参考文件

## 测试类型（11种必做）

| 类型 | 说明 | 对应章节 |
|------|------|----------|
| 功能测试 | 正常/异常/边界/等价类 | general-test-cases.md 一 |
| 接口测试 | API请求/响应/异常 | general-test-cases.md 二 |
| UI测试 | 布局/样式/交互 | general-test-cases.md 三 |
| 性能测试 | 加载/响应/网络 | general-test-cases.md 四 |
| 安全测试 | 输入/认证/权限/数据 | general-test-cases.md 五 |
| 联动测试 | 功能/页面/多端联动 | general-test-cases.md 六 |
| 路由测试 | 访问/守卫/参数 | general-test-cases.md 七 |
| 跳转测试 | 跳转/传参/异常 | general-test-cases.md 八 |
| 适配测试 | 屏幕/OS/设备特性 | general-test-cases.md 九 |
| 可访问性 | 键盘/读屏/对比度 | general-test-cases.md 十 |
| 兼容测试 | 浏览器/分辨率/组件 | general-test-cases.md 十一 |

**覆盖度要求**：整体覆盖度≥90%

## 逐步披露原则

| 级别 | 内容 | 加载时机 |
|------|------|----------|
| Level 1 | SKILL.md（概要） | 始终加载 |
| Level 2 | 指令映射表 | 按需加载 `references/instruction-mapping.md` |
| Level 3 | 测试用例模板 | 按需加载 `references/general-test-cases.md` |
| Level 4 | 组件测试设计 | 按需加载 `references/component-test.md` |
| Level 5 | 平台专项 | 明确指定后加载 |

**加载决策**：读取SKILL.md → 匹配指令映射表 → 按需加载references

**禁止**：不要一次性读取所有references文件

## 工作流程

### 流程1：生成测试用例

1. **分析需求**
   - 读取需求文档或功能描述
   - 识别功能模块和测试范围
   - 询问目标平台（APP/小程序/PC Web/H5/PC应用）

2. **确定测试类型**
   - 功能测试（必做）
   - 接口测试（如涉及则做）
   - UI/性能/安全/联动/路由/跳转/适配/可访问性/兼容测试（必做）
   - 平台专项（用户明确指定后做）

3. **生成测试用例**
   - 参考 `references/general-test-cases.md` 生成通用用例
   - 如涉及特定组件，参考 `references/component-test.md`
   - 如涉及平台，参考对应platform-*.md
   - **确保覆盖度≥90%**

4. **自动审查与补全**
   - 检查完整性、格式、覆盖度、可执行性
   - **直接补全缺失部分**，无需询问

5. **输出用例**
   - 按模块分组输出
   - 每个用例包含完整字段
   - 提供汇总统计

### 流程2：审查已有测试用例

1. 读取待审查用例文件
2. 执行审查检查（完整性/格式/覆盖度/可执行性）
3. 生成审查报告（总体评分/问题列表/改进建议）
4. **自动补全缺失用例**

**注意**：审查模式下仅输出报告，如需补全需用户明确指示

**审查报告模板**：`references/review-report-template.md`

## 测试级别定义

| 级别 | 定义 | 比例 |
|------|------|------|
| P0 | 阻塞级，核心功能 | ≤20% |
| P1 | 高优先级，重要功能 | ~30% |
| P2 | 中优先级，一般功能 | ~40% |
| P3 | 低优先级，边缘场景 | ~10% |

## 平台专项触发规则

**仅在用户明确指定平台后生成**

询问话术：
> "请确认测试目标平台：1. APP 2. 小程序 3. PC Web 4. H5 5. PC应用"

平台文件：
- APP：`references/platform-app.md`
- 小程序：`references/platform-miniprogram.md`
- PC Web：`references/platform-pcweb.md`
- H5：`references/platform-mobileweb.md`
- PC应用：`references/platform-pcapp.md`

## 注意事项

1. **用例编号**：TC-{模块}-{序号}
2. **步骤编写**：编号列表，每步一个操作
3. **预期结果**：明确可验证，每步对应一结果
4. **覆盖度**：必须≥90%，每个测试类型都需覆盖
5. **接口格式**：与其他用例格式不同，单独处理
6. **平台专项**：必须用户明确指定后才生成
