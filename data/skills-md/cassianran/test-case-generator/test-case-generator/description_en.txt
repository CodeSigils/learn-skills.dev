Professional test case generation and review tool. Supports generating 11 types of test cases (functional, interface, UI, performance, security, integration, routing, navigation, adaptation, accessibility, compatibility), with coverage required to be ≥90%.  
Adopts a step-by-step disclosure principle, loading on demand. Platform-specific tests are generated only after the user explicitly specifies them.  
Supports reviewing existing test cases, outputting a review report, and supplementing missing test cases.
