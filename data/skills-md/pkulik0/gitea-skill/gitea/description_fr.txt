Interface avec les instances Gitea via la CLI tea. Gérez les référentiels, les problèmes, les demandes d'extraction, les versions, les étiquettes, les jalons, les actions CI/CD, les webhooks, les organisations et les notifications. À utiliser lorsque l'utilisateur mentionne « Gitea », « tea CLI » ou demande de créer/lister/modifier/fermer des problèmes, de créer/réviser/fusionner des demandes d'extraction, de gérer des dépôts, de créer des versions, d'afficher les exécutions de flux de travail CI/CD, de gérer les webhooks, de suivre le temps ou d'effectuer toute tâche d'hébergement de code sur un serveur Gitea. Ne PAS utiliser pour GitHub (utilisez gh CLI) ou GitLab.
