Interfaccia con istanze Gitea tramite la CLI tea. Gestisci repository, problemi, richieste pull, versioni, etichette, tappe fondamentali, azioni CI/CD, webhook, organizzazioni e notifiche. Da utilizzare quando l'utente menziona "Gitea", "tea CLI" o chiede di creare/elencare/modificare/chiudere problemi, creare/revisionare/unire richieste pull, gestire repository, creare versioni, visualizzare esecuzioni di flussi di lavoro CI/CD, gestire webhook, tenere traccia del tempo o eseguire qualsiasi attività di hosting di codice su un server Gitea. NON utilizzare per GitHub (usa gh CLI) o GitLab.
