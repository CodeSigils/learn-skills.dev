Interfaz con instancias de Gitea a través de la CLI de té. Administre repositorios, problemas, solicitudes de extracción, lanzamientos, etiquetas, hitos, acciones de CI/CD, webhooks, organizaciones y notificaciones. Úselo cuando el usuario mencione "Gitea", "tea CLI" o solicite crear/enumerar/editar/cerrar problemas, crear/revisar/fusionar solicitudes de extracción, administrar repositorios, crear lanzamientos, ver ejecuciones de flujo de trabajo de CI/CD, administrar webhooks, realizar un seguimiento del tiempo o realizar cualquier tarea de alojamiento de código en un servidor de Gitea. NO lo use para GitHub (use gh CLI) o GitLab.
