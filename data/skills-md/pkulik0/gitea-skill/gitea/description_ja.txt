tea CLI を介して Gitea インスタンスとインターフェースします。リポジトリ、問題、プル リクエスト、リリース、ラベル、マイルストーン、CI/CD アクション、Webhook、組織、通知を管理します。ユーザーが「Gitea」、「tea CLI」に言及する場合、または問題の作成/一覧表示/編集/クローズ、プル リクエストの作成/レビュー/マージ、リポジトリの管理、リリースの作成、CI/CD ワークフロー実行の表示、Webhook の管理、時間の追跡、または Gitea サーバー上でのコード ホスティング タスクの実行を要求する場合に使用します。 GitHub (gh CLI を使用) または GitLab には使用しないでください。
