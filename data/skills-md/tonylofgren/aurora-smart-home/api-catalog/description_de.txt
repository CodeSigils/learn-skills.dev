Referenzhandbuch zum Verbinden beliebter APIs mit Home Assistant über Node-RED, YAML oder benutzerdefinierte Integrationen. Behandelt Authentifizierung, Endpunkte und vollständige Arbeitsbeispiele für: Energie-APIs (Tibber, Nordpool), Wetter (SMHI, OpenWeatherMap, yr.no), Transport (SL, Trafikverket, Resrobot), Smart-Home-Clouds (Shelly, Tuya, Philips Hue, IKEA) und globale APIs (OpenAI, Spotify, Google Calendar, Telegram, GitHub). Verwenden Sie diesen Skill immer dann, wenn der Benutzer einen bestimmten externen Dienst, eine bestimmte API oder eine Datenquelle erwähnt, die er mit Home Assistant verbinden möchte – auch wenn er nicht „API“ sagt.
