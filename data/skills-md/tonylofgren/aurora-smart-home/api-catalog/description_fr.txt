Guide de référence pour connecter les API populaires à Home Assistant via Node-RED, YAML ou des intégrations personnalisées. Couvre l'authentification, les points de terminaison et des exemples de travail complets pour : les API énergétiques (Tibber, Nordpool), la météo (SMHI, OpenWeatherMap, yr.no), les transports (SL, Trafikverket, Resrobot), les nuages ​​​​de maison intelligente (Shelly, Tuya, Philips Hue, IKEA) et les API mondiales (OpenAI, Spotify, Google Calendar, Telegram, GitHub). Utilisez cette compétence chaque fois que l'utilisateur mentionne un service externe spécifique, une API ou une source de données qu'il souhaite connecter à Home Assistant, même s'il ne dit pas « API ».
