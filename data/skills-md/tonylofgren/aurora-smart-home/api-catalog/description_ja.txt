Node-RED、YAML、またはカスタム統合を介して一般的な API を Home Assistant に接続するためのリファレンス ガイド。エネルギー API (Tibber、Nordpool)、天気 (SMHI、OpenWeatherMap、yr.no)、交通機関 (SL、Trafikverket、Resrobot)、スマート ホーム クラウド (Shelly、Tuya、Philips Hue、IKEA)、およびグローバル API (OpenAI、Spotify、Google Calendar、Telegram、GitHub) の認証、エンドポイント、完全な動作例をカバーします。ユーザーが「API」と言わなくても、Home Assistant に接続したい特定の外部サービス、API、またはデータ ソースについて言及するときは常に、このスキルを使用します。
