Guida di riferimento per connettere le API più diffuse a Home Assistant tramite Node-RED, YAML o integrazioni personalizzate. Copre autenticazione, endpoint ed esempi di lavoro completi per: API energetiche (Tibber, Nordpool), meteo (SMHI, OpenWeatherMap, yr.no), trasporti (SL, Trafikverket, Resrobot), cloud domestici intelligenti (Shelly, Tuya, Philips Hue, IKEA) e API globali (OpenAI, Spotify, Google Calendar, Telegram, GitHub). Utilizza questa abilità ogni volta che l'utente menziona uno specifico servizio esterno, API o origine dati a cui desidera connettersi a Home Assistant, anche se non dice "API".
