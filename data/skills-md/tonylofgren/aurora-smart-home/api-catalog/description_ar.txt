دليل مرجعي لتوصيل واجهات برمجة التطبيقات الشائعة بـ Home Assistant عبر Node-RED أو YAML أو عمليات التكامل المخصصة. يغطي المصادقة ونقاط النهاية وأمثلة عمل كاملة لـ: واجهات برمجة تطبيقات الطاقة (Tibber، Nordpool)، الطقس (SMHI، OpenWeatherMap، yr.no)، النقل (SL، Trafikverket، Resrobot)، السحب المنزلية الذكية (Shelly، Tuya، Philips Hue، IKEA)، وواجهات برمجة التطبيقات العالمية (OpenAI، Spotify، Google Calendar، Telegram، GitHub). استخدم هذه المهارة عندما يذكر المستخدم خدمة خارجية معينة، أو واجهة برمجة تطبيقات، أو مصدر بيانات يريد توصيله بـ Home Assistant - حتى لو لم يذكر "API".
