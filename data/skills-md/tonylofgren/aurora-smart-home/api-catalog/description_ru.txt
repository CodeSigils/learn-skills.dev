Справочное руководство по подключению популярных API к Home Assistant через Node-RED, YAML или пользовательские интеграции. Охватывает аутентификацию, конечные точки и полные рабочие примеры для: энергетических API (Tibber, Nordpool), погоды (SMHI, OpenWeatherMap, yr.no), транспорта (SL, Trafikverket, Resrobot), облачных сервисов «умного дома» (Shelly, Tuya, Philips Hue, IKEA) и глобальных API (OpenAI, Spotify, Google Calendar, Telegram, GitHub). Используйте этот навык всякий раз, когда пользователь упоминает конкретную внешнюю службу, API или источник данных, который он хочет подключить к Home Assistant, даже если он не говорит «API».
