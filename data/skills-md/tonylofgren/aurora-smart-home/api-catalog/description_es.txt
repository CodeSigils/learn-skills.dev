Guía de referencia para conectar API populares a Home Assistant a través de Node-RED, YAML o integraciones personalizadas. Cubre autenticación, puntos finales y ejemplos de trabajo completos para: API de energía (Tibber, Nordpool), clima (SMHI, OpenWeatherMap, yr.no), transporte (SL, Trafikverket, Resrobot), nubes domésticas inteligentes (Shelly, Tuya, Philips Hue, IKEA) y API globales (OpenAI, Spotify, Google Calendar, Telegram, GitHub). Utilice esta habilidad siempre que el usuario mencione un servicio externo, API o fuente de datos específicos que desee conectar a Home Assistant, incluso si no dice "API".
