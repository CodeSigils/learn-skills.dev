جلب البيانات المالية من EODHD API - الأسعار التاريخية والأساسيات والخيارات والمؤشرات الفنية والأخبار والمشاعر والمؤشرات الكلية وأحداث الشركات ونتائج ESG وتحليلات المخاطر والبيانات المصرفية وأسعار سندات الخزانة الأمريكية وساعات التداول. يُستخدم عندما يسأل المستخدم عن أسعار الأسهم، أو أساسيات الشركة، أو التحليل المالي، أو بيانات السوق، أو الأرباح، أو أرباح الأسهم، أو الانقسامات، أو الاكتتابات العامة الأولية، أو المعاملات الداخلية، أو أداة الفرز، أو إنشاء أدوات مالية باستخدام بيانات EODHD.
