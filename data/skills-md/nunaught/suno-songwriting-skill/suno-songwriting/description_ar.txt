قم بإنشاء كلمات الأغاني ومراجعتها وترجمتها وتكييفها بالإضافة إلى مطالبات النمط المضغوط لـ Suno أو مولدات موسيقى الذكاء الاصطناعي المماثلة. يُستخدم عندما يريد المستخدم إنشاء كلمات الأغاني الجاهزة لللصق باستخدام الذكاء الاصطناعي، أو العلامات الغنائية، أو المطالبات بنمط Suno/Udio، أو التوجيه الصوتي، أو الآلات الموسيقية، أو صياغة النوع/النمط، أو بنية الأغنية، أو كلمات الأغاني المنفردة متعددة اللغات، أو مقابلة توضيحية لأغنية تم إنشاؤها بواسطة الذكاء الاصطناعي. لا تقم بتوجيه نظرية الموسيقى العامة، أو بحث الفنان العادي، أو مناقشة كتابة الأغاني خارج الجيل هنا ما لم يكن الناتج المطلوب عبارة عن كلمات أو موجه أسلوب جاهز للجيل.
