À utiliser lorsqu'on vous le demande pour gérer le réseau UniFi : répertorier/redémarrer/mettre à niveau les appareils, bloquer/débloquer les clients, gérer les réseaux WiFi, contrôler les ports PoE, gérer les règles de trafic, créer des bons d'invité ou toute tâche de contrôleur UniFi. Fonctionne avec UDM Pro/SE, Dream Machine, Cloud Key Gen2+ ou les contrôleurs auto-hébergés.
