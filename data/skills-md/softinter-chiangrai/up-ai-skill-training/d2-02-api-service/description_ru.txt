Создает службу Angular, которая вызывает конечные точки CRUD up-api для данного объекта (getAll, getById, save, update, delete). Используйте, когда пользователь запрашивает шаг 3 этапа CRUD 2-го дня или просит создать службу Angular, которая взаимодействует с up-api. Требуется тот же объект, который использовался в первый день.
