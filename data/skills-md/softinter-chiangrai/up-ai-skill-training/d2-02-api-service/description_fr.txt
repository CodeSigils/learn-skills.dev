Génère un service Angular qui appelle les points de terminaison CRUD up-api pour une entité donnée (getAll, getById, save, update, delete). À utiliser lorsque l'utilisateur demande le jour 2, étape 3 de l'exercice CRUD, ou demande de créer le service Angular qui communique avec up-api. Nécessite la même entité utilisée le jour 1.
