Genera un PPT web a scorrimento orizzontale (singolo file HTML) con modelli come uno sfondo WebGL, copertina di capitolo, poster di dati di grande formato, griglie di immagini, ecc. Fornisci due stili:① "Rivista elettronica×E-ink" (serif + sfondo fluido + colori caldi) ② "Internazionalismo svizzero" (sans‑serif + griglia a matrice di punti + IKB / giallo limone / verde limone / evidenziazioni arancioni di sicurezza). Utilizzalo quando l'utente desidera creare un PPT web per la condivisione, la presentazione o lo stile di lancio del prodotto oppure menziona "PPT in stile rivista", "PPT in stile svizzero", "Stile svizzero" o "mazzo a scorrimento orizzontale".
