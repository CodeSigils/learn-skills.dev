WebGL の背景、章の表紙、データ ポスター、画像グリッドなどのテンプレートを含む水平スワイプ Web PPT (単一の HTML ファイル) を生成します。 1)「電子雑誌×E‑ink」(セリフ+流体背景+暖色)、2)「スイス国際主義」(サンセリフ+方眼ドット+IKB/レモンイエロー/レモングリーン/セーフティオレンジハイライト)の2つのスタイルを提供します。ユーザーが共有、プレゼンテーション、発表会スタイルの Web PPT を作成する必要がある場合、または「雑誌スタイル PPT」、「スイス スタイル PPT」、「スイス スタイル」、または「水平スワイプ デッキ」について言及する場合にこれを使用します。
