WebGL の背景、章の表紙、データ ポスター、画像グリッドなどのテンプレートを使用して、水平スワイプ Web PPT (単一の HTML ファイル) を生成します。 2 つのスタイルを提供します:1) 「電子マガジン×E インク」 (セリフ + 流体背景 + 暖色)、2) 「スイス国際主義」 (サンセリフ + グリッド ドット マトリックス + IKB/レモン イエロー/レモン グリーン/セーフティ オレンジ ハイライト)。ユーザーが共有、プレゼンテーション、または発表イベント スタイル用の Web PPT を作成したい場合、または「雑誌スタイル PPT」、「スイス スタイル PPT」、「スイス スタイル」、または「水平スワイプ デッキ」について言及する場合にこれを使用します。
