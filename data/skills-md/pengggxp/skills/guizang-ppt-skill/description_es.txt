Genere un PPT (archivo HTML único) de página web de deslizamiento horizontal con plantillas como un fondo WebGL, portada de capítulo, póster de datos y cuadrícula de imágenes. Ofrezca dos estilos: ① “Revista electrónica×tinta electrónica” (serif+fondo fluido+colores cálidos) ② “Internacionalismo suizo” (sans‑serif+matriz de puntos cuadriculado+IKB / amarillo limón / verde limón / reflejos naranja de seguridad). Utilícelo cuando el usuario necesite crear un PPT web para compartir, presentar o dar estilo a una conferencia de prensa, o mencione "PPT estilo revista", "PPT estilo suizo", "Estilo suizo" o "plataforma de diapositivas horizontal".
