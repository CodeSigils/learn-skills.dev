قم بإنشاء ملف PPT للويب بتمرير أفقي (ملف HTML واحد) باستخدام قوالب مثل خلفية WebGL وأغلفة الفصول وملصقات البيانات وشبكات الصور والمزيد. قم بتوفير نمطين: 1) "المجلة الإلكترونية × الحبر الإلكتروني" (serif + خلفية سائلة + ألوان دافئة) و2) "الدولية السويسرية" (sans-serif + مصفوفة نقطية شبكية + IKB/أصفر ليموني/أخضر ليموني/برتقالي آمن). استخدم هذا عندما يريد المستخدم إنشاء PPT على الويب للمشاركة أو العرض التقديمي أو نمط حدث الإطلاق، أو يذكر "PPT بنمط المجلة" أو "PPT بالنمط السويسري" أو "النمط السويسري" أو "مجموعة التمرير الأفقية".
