Этапы 1-2 Фабрики программного обеспечения — неустанное собеседование, состоящее из одного вопроса за раз, которое превращает неопределенную идею в краткое описание (factory/BRIEF.md), а затем разбивает его на поэтапный список задач, упорядоченный по зависимостям (factory/PLAN.md). Это навык, который СОЗДАЕТ список задач. Создано для полутехнических и нетехнических строителей - простой язык, рекомендации по каждому вопросу. Используйте автономно или через /factory. Триггеры — «спланировать свою сборку», «превратить эту идею в задачи», «заводской план».
