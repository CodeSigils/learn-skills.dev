Génère 2 à 3 brouillons de publications sociales sur les travaux d'ingénierie dans le référentiel actuel. Lit le code et l'historique Git du référentiel, pose des questions ciblées pour combler les lacunes et enregistre un brouillon de démarque localement. À utiliser lorsque vous souhaitez du contenu sur ce qui a été construit sans exposer les transcriptions ni pousser nulle part.
