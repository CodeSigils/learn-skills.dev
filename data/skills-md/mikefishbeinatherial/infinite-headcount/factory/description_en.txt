Software Factory — the conductor. One command that walks a semi-technical or non-technical builder through the whole software assembly line - grill the idea sharp, plan it as tasks, define tests that prove each task works, hand off to an overnight coding loop, then review, prove it on video, and explain it in plain language. Reads factory/STATE.md to know where you are and always tells you what's next. Invoke as /factory in Claude Code or Cursor. Triggers - "factory", "software factory", "start a build", "what's next on my build".
