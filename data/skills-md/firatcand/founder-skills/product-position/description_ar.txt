يُستخدم عندما يحتاج منتج B2B SaaS إلى تحديد موضع المنبع أو وضوح الرسائل - تحديد الجهة المخصصة له، أو الفئة، أو البدائل التنافسية، أو التمايز، أو دعائم القيمة، أو السرد الاستراتيجي، أو التسلسل الهرمي للرسائل. تتضمن المشغلات "الرسائل الخاصة بي لا تعمل"، أو "نبدو مثل أي شخص آخر"، أو إعادة تحديد موضع، أو مراجعة مستند تحديد موضع موجود. يُستخدم قبل عمل الصفحة الرئيسية أو المجموعة أو سرد المبيعات. ليس لكتابة النسخة النهائية (استخدم مهارة كاتب الإعلانات) أو لتشغيل عملية البيع (استخدم مهارة المبيعات).
