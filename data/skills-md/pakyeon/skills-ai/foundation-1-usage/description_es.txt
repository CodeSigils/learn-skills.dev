Cómo utilizar el modelo de generación de música de texto a muestra Foundation-1 (Foundation_1.safetensors) para la generación de muestras de audio estructurado. Utilice esta habilidad siempre que el usuario quiera generar muestras de música, bucles o audio usando Foundation-1, necesite ayuda para escribir indicaciones para el modelo, quiera comprender el sistema de etiquetas del modelo (instrumentos, timbre, efectos, notación), necesite orientación sobre la configuración, los requisitos de hardware, BPM/temporización de compases o cualquier cosa relacionada con los flujos de trabajo de producción e inferencia de Foundation-1. Utilícelo también cuando el usuario mencione "Foundation-1", "Foundation_1.safetensors", "stable-audio-tools with Foundation" o "generación de texto a muestra". NO active preguntas generales sobre producción musical que no estén relacionadas con Foundation-1 ni para otros modelos de generación de audio (por ejemplo, MusicGen, AudioLDM).
