Как использовать модель генерации музыки Foundation-1 (Foundation_1.safetensors) для создания структурированных аудиосэмплов. Используйте этот навык всякий раз, когда пользователь хочет создать музыкальные сэмплы, петли или аудио с помощью Foundation-1, ему нужна помощь в написании подсказок для модели, он хочет понять систему тегов модели (инструменты, тембр, эффекты, нотация), нуждается в руководстве по настройке, требованиям к оборудованию, синхронизации BPM/тактов или чему-либо, связанному с выводами Foundation-1 и рабочими процессами производства. Также используйте, когда пользователь упоминает «Foundation-1», «Foundation_1.safetensors», «инструменты для стабильного звука с Foundation» или «генерацию текста в образец». НЕ срабатывает для общих вопросов по созданию музыки, не связанных с Foundation-1, или для других моделей генерации звука (например, MusicGen, AudioLDM).
