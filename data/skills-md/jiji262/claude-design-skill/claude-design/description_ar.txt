قم بإنتاج عناصر تصميمية مدروسة وعالية الدقة بتنسيق HTML - الصفحات المقصودة ومجموعات الشرائح والنماذج الأولية التفاعلية ومقاطع الفيديو المتحركة والملصقات والإطارات السلكية والاستكشافات المرئية. استخدمه عندما يطلب المستخدم التصميم أو إنشاء نماذج أولية أو تصور أو لوحة عمل أو استكشاف خيارات واجهة المستخدم - بما في ذلك عبارات مثل "إنشاء مجموعة"، أو "تصميم صفحة مقصودة"، أو "نموذج أولي لهذا التدفق"، أو "تحريك هذا المفهوم"، أو "تحويل هذا إلى نموذج بالحجم الطبيعي قابل للنقر عليه"، أو "إظهار خيارات لـ X"، أو "إنشاء عرض تقديمي مخطَّط"، أو "إنشاء ملصق"، أو "تصور هذه الفكرة"، أو "لا أعرف النمط الذي أريده"، أو "تصميم شيء ما لـ <العلامة التجارية>". يفرض التحقق من الحقائق (البحث على الويب قبل افتراض وجود منتج أو إصداره)، وبروتوكول الأصول الأساسية للعمل ذي العلامة التجارية (لقطات الشعار والمنتج ولقطات شاشة واجهة المستخدم من الدرجة الأولى، وليس فقط الألوان والخطوط)، ومستشار اتجاه التصميم الاحتياطي الذي يقدم 3 اتجاهات مختلفة من 10 فلسفات تصميم عندما يكون الموجز غامضًا للغاية، ويلتزم بنظام مرئي مقدمًا، ويقدم أشكالًا متعددة، ويتجنب استعارات تصميم الذكاء الاصطناعي (التدرجات العدوانية، الرموز التعبيرية النقطية، البطاقة المستديرة ذات الحد الأيسر، الصور الظلية لـ CSS كمنتج لقطات).
