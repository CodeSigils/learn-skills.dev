Verwenden Sie es, wenn der Benutzer echte UCloud-Ressourcenvorgänge über die offizielle UCloud-CLI ausführen muss, einschließlich der Anzeige, Erstellung, Aktualisierung oder Löschung von Cloud-Hosts, Netzwerken, EIPs, Load Balancern und Datenbanken. Verwenden Sie diese Fähigkeit auch, wenn der Benutzer eine Webanwendung auf UCloud bereitstellen oder einen Dienst starten möchte, selbst wenn der Benutzer eine Bereitstellungsaufgabe beschreibt, anstatt explizit ein Cloud-Produkt anzugeben.
