Auditez et corrigez les problèmes de sécurité de la chaîne d’approvisionnement npm dans le référentiel actuel. Détecte le gestionnaire de packages, vérifie les protections manquantes (fichier de verrouillage, blocage des scripts de cycle de vie, temps de recharge avant la publication, sous-départements exotiques/politique de confiance pnpm, mode renforcé Yarn Berry), présente les résultats et applique les correctifs après confirmation de l'utilisateur. Prend en charge npm, pnpm, Yarn, Bun et Aube. À utiliser lorsqu'on vous demande de « renforcer NPM », « réparer la chaîne d'approvisionnement », « sécuriser les dépendances » ou « auditer la sécurité de NPM ».
