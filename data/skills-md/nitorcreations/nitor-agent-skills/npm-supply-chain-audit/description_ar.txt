قم بمراجعة وإصلاح مشكلات أمان سلسلة التوريد npm في الريبو الحالي. يكتشف مدير الحزم، ويتحقق من الحماية المفقودة (ملف القفل، وحظر البرنامج النصي لدورة الحياة، وفترة تباطؤ عمر الإصدار، والسياسة الفرعية/الثقة الغريبة لـ pnpm، ووضع Yarn Berry المقوى)، ويقدم النتائج، ويطبق الإصلاحات بعد تأكيد المستخدم. يدعم npm، pnpm، Yarn، Bun، وAube. يُستخدم عندما يُطلب منك "تقوية npm" أو "إصلاح سلسلة التوريد" أو "التبعيات الآمنة" أو "تدقيق أمان npm".
