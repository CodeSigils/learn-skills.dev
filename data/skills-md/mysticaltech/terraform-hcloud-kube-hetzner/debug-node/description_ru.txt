Используйте, когда узел Hetzner недоступен, происходит сбой SSH, Cloud-init кажется сломанным или подготовка зависает. Загружается в режим восстановления через интерфейс командной строки hcloud для проверки файловой системы, журналов, ключей SSH, конфигурации sshd и состояния инициализации облака без необходимости доступа по SSH к самому узлу.
