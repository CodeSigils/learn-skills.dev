Universal web search and content extraction skills. Multi-source parallel search (WebSearch, MCP search tools, ctx7, agent-browser), web body extraction (crwl), and structured article analysis. Used when users need to search for information, research topics, find materials, obtain web content, read articles, or analyze web pages. Trigger scenarios include: search, research, investigation, fetch, look up, help me find, read this link, analyze this article. Even if the user does not explicitly say "search", as long as it involves information acquisition and web content processing, this skill should be triggered.
