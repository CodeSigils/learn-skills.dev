Compétences en analyse boursière stk-cli. Quatre modes : aperçu du marché (indices + actualités), points chauds techniques (analyse haussière/ourse sur 8 écrans + sélection de titres), analyse de titres individuels (notation + techniques + fondamentaux), analyse de portefeuille (analyse par lots de liste de surveillance + commentaire). Mots-clés déclencheurs : aperçu du marché/analyse de marché/rapport quotidien/hotspots techniques/hotspot/sélection de titres/analyse de titres individuels/analyse de titres/analyse de portefeuille/analyse de liste de surveillance/vérification de détention.
