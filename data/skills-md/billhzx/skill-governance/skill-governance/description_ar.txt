اكتشاف مهارات الوكيل وجردها وإدارتها بشكل آمن في Codex وClaude Code وCC Switch وWorkBuddy وHermes وأدوات الذكاء الاصطناعي المحلية الأخرى. استخدم هذا عندما تبدو المهارة مكررة أو منسوخة أو مرتبطة، أو أصبحت غير صالحة، أو بها حالة تمكين غير متناسقة، أو تتم إدارتها بواسطة مثبتات متعددة، أو يصعب تحديثها أو حذفها، أو عندما يلزم إنشاء مصدر فريد للحقيقة، وإنشاء دفتر أستاذ للأصول يمكن قراءته آليًا، وإنشاء خطة تنظيف آمنة. يجب إجراء التدقيق أولاً، ويجب الحصول على إذن صريح من المستخدم لقائمة الأهداف الدقيقة قبل إجراء أي تغييرات.
