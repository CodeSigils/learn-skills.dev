قم بإعداد أو تدقيق أو مراجعة بيانات توفر البيانات الجاهزة لدورية Nature، وخطط مستودع البيانات، واستشهادات مجموعة البيانات، وقوائم مراجعة البيانات التعريفية FAIR للمخطوطات. يُستخدم عندما يسأل المستخدم عن مدى توفر بيانات Nature، أو مشاركة بيانات البحث، أو اختيار المستودع، أو أرقام الانضمام، أو البيانات المقيدة أو الحساسة، أو بيانات المصدر، أو مجموعات البيانات التكميلية، أو مراجع مجموعة البيانات بنمط DataCite، أو البيانات التعريفية FAIR للنشر الأكاديمي، أو صياغة توفر البيانات من الصينية إلى الإنجليزية للمؤلفين الناطقين باللغة الصينية الذين يقومون بإعداد طلبات تقديم Nature-family.
