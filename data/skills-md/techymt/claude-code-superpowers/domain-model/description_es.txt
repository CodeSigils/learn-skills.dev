Enseña el modelo de dominio central de Claude Code: herramienta, mensaje, tarea, contexto de uso de herramienta, estado de aplicación y comando: los seis conceptos en torno a los cuales se construye cada parte del sistema. Úselo antes de escribir cualquier herramienta, comando o característica nueva que toque el ciclo de conversación. Esencial para comprender cómo está estructurado el sistema de capacidades de Claude y por qué existen las abstracciones.
