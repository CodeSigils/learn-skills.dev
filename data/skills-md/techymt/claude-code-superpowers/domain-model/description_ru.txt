Обучает базовой модели предметной области Claude Code: инструмент, сообщение, задача, ToolUseContext, AppState и команда — шесть концепций, вокруг которых построена каждая часть системы. Используйте это перед написанием любого нового инструмента, команды или функции, которая затрагивает цикл разговора. Необходим для понимания того, как структурирована система возможностей Клода и почему существуют абстракции.
