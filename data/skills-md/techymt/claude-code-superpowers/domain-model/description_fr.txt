Enseigne le modèle de domaine principal de Claude Code : outil, message, tâche, ToolUseContext, AppState et Command – les six concepts autour desquels chaque partie du système est construite. Utilisez-le avant d'écrire un nouvel outil, commande ou fonctionnalité touchant la boucle de conversation. Indispensable pour comprendre comment le système de capacités de Claude est structuré et pourquoi les abstractions existent.
