Cette compétence doit être utilisée lorsque l'utilisateur demande de « tester une fonctionnalité de dépôt croisé », de « déployer une branche de fonctionnalités vers la préparation », de « tester le SDK sur OH Cloud », « e2e tester une fonctionnalité d'espace de travail cloud », « tester les jetons du fournisseur », « tester l'héritage des secrets », ou lorsque les modifications couvrent les dépôts du SDK et du serveur OpenHands et nécessitent une validation de bout en bout par rapport à un déploiement de préparation.
