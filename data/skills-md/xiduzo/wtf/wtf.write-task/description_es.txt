Esta habilidad debe usarse cuando un usuario desea crear una tarea, escribir un ticket, descomponer una característica en trabajo implementable, desglosar una historia, definir una sección vertical para el desarrollo o escribir escenarios de Gherkin; por ejemplo, "crear una tarea", "escribir una tarea para esta característica", "dividir esta característica en tareas", "definir el trabajo de implementación" o "agregar un subtema a esta característica". Guía la creación de un problema de tarea de GitHub vinculado a una característica principal y a Epic, deriva escenarios de aceptación de Gherkin a partir de los AC de la característica, aplica el lenguaje ubicuo de DDD en los escenarios y verifica la integridad del segmento vertical y las dependencias de las tareas.
