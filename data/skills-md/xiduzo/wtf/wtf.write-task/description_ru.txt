Этот навык следует использовать, когда пользователь хочет создать задачу, написать заявку, разложить функцию на реализуемую работу, разбить историю, определить вертикальный срез для разработки или написать сценарии Gherkin — например, «создать задачу», «написать задачу для этой функции», «разбить эту функцию на задачи», «определить работу по реализации» или «добавить подзадачу к этой функции». Управляет созданием задачи GitHub, связанной с родительской функцией и Epic, извлекает сценарии принятия Gherkin из AC функции, обеспечивает повсеместное использование языка DDD в сценариях, а также проверяет целостность вертикального среза и зависимости задач.
