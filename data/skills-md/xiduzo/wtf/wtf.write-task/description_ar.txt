يجب استخدام هذه المهارة عندما يريد المستخدم إنشاء مهمة، أو كتابة تذكرة، أو تحليل الميزة إلى عمل قابل للتنفيذ، أو تقسيم القصة، أو تحديد شريحة رأسية للتطوير، أو كتابة سيناريوهات Gherkin - على سبيل المثال "إنشاء مهمة"، أو "كتابة مهمة لهذه الميزة"، أو "تقسيم هذه الميزة إلى مهام"، أو "تحديد أعمال التنفيذ"، أو "إضافة مشكلة فرعية لهذه الميزة". يرشد إنشاء مشكلة مهمة GitHub المرتبطة بميزة أصل وEpic، ويستمد سيناريوهات قبول Gherkin من ACs الخاصة بالميزة، ويفرض لغة DDD واسعة الانتشار في السيناريوهات، ويتحقق من سلامة الشريحة الرأسية وتبعيات المهام.
