이 기술은 사용자가 작업 생성, 티켓 작성, 기능을 구현 가능한 작업으로 분해, 스토리 분할, 개발을 위한 수직적 슬라이스 정의 또는 Gherkin 시나리오 작성을 원할 때 사용해야 합니다(예: "작업 생성", "이 기능에 대한 작업 작성", "이 기능을 작업으로 분할", "구현 작업 정의" 또는 "이 기능에 하위 문제 추가"). 상위 기능 및 Epic에 연결된 GitHub 작업 문제 생성을 안내하고, 기능의 AC에서 Gherkin 수용 시나리오를 파생시키고, 시나리오에서 DDD 유비쿼터스 언어를 적용하고, 수직 슬라이스 무결성 및 작업 종속성을 확인합니다.
