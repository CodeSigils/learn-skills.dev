Diese Fähigkeit sollte verwendet werden, wenn ein Benutzer ein GitHub Epic-Problem erstellen, entwerfen oder planen möchte – zum Beispiel „ein Epos schreiben“, „Ich möchte eine neue Initiative definieren“, „dieses strategische Projekt ausarbeiten“, „diese Idee in ein Epos umwandeln“, „Arbeit planen, die mehrere Funktionen umfasst“ oder „von einem begrenzten Kontext ausgehen“. Verwenden Sie es auch, wenn der Benutzer Domänenergebnisse definieren, eine große Initiative erfassen möchte, bevor sie in Funktionen aufgeteilt wird, oder die Arbeit anhand von Geschäftszielen und nicht anhand technischer Aufgaben beschreiben möchte.
