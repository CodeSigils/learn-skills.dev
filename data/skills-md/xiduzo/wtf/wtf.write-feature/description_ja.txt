このスキルは、ユーザーが GitHub フィーチャーの問題を作成する場合、エピックをユーザー向けの機能に分解する場合、ドメイン言語でユーザー ストーリーを作成する場合、またはドメイン アクターができることをキャプチャする場合に使用する必要があります。たとえば、「フィーチャーを作成する」、「このエピックのフィーチャーを作成する」、「エピックにフィーチャーを追加する」、「このエピックをフィーチャーに分割する」、「この機能のユーザー ストーリーを作成する」、または「このアクターができることを説明する」などです。このスキルを使用して、単一のフィーチャーを作成します。 `wtf.epic-to-features` を使用して、エピックのフィーチャーの完全なセットを一度に生成します。タスク、エピック、またはバグ レポートには適用されません。
