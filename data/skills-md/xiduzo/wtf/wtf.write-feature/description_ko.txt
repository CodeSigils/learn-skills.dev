이 기술은 사용자가 GitHub 기능 문제를 생성하거나, Epic을 사용자가 직면하는 기능으로 분류하거나, 도메인 언어로 사용자 스토리를 작성하거나, 도메인 행위자가 할 수 있는 작업을 캡처하려고 할 때 사용해야 합니다(예: "기능 생성", "이 에픽에 대한 기능 작성", "에픽에 기능 추가", "이 에픽을 기능으로 분할", "이 기능에 대한 사용자 스토리 작성" 또는 "이 행위자가 수행할 수 있는 작업 설명"). 단일 기능을 작성하려면 이 기술을 사용하십시오. Epic의 전체 기능 세트를 한 번에 생성하려면 `wtf.epic-to-features`를 사용하세요. 태스크, 에픽 또는 버그 보고서에는 적용되지 않습니다.
