Diese Fähigkeit sollte verwendet werden, wenn ein Benutzer ein GitHub-Feature-Problem erstellen, ein Epic in benutzerorientierte Funktionen aufteilen, User Stories in Domänensprache schreiben oder erfassen möchte, was ein Domänenakteur tun kann – zum Beispiel „ein Feature erstellen“, „ein Feature für dieses Epos schreiben“, „ein Feature zu einem Epos hinzufügen“, „dieses Epos in Features aufteilen“, „User Stories für dieses Feature schreiben“ oder „beschreiben, was dieser Akteur tun kann“. Verwenden Sie diese Fähigkeit, um ein einzelnes Feature zu schreiben. Verwenden Sie „wtf.epic-to-features“, um den vollständigen Satz an Funktionen für ein Epic auf einmal zu generieren. Gilt nicht für Aufgaben, Epics oder Fehlerberichte.
