Esta habilidad debe usarse cuando un usuario desea crear un problema de característica de GitHub, dividir una epopeya en capacidades orientadas al usuario, escribir historias de usuario en el lenguaje del dominio o capturar lo que un actor de dominio puede hacer; por ejemplo, "crear una característica", "escribir una característica para esta epopeya", "agregar una característica a una epopeya", "dividir esta epopeya en características", "escribir historias de usuario para esta característica" o "describir lo que este actor puede hacer". Utilice esta habilidad para escribir una única característica; use `wtf.epic-to-features` para generar el conjunto completo de funciones para un Epic a la vez. No se aplica a tareas, épicas o informes de errores.
