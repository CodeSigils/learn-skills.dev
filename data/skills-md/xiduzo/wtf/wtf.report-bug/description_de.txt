Diese Fähigkeit sollte verwendet werden, wenn ein Entwickler oder QA-Ingenieur einen Fehler melden, ein Fehlerticket erstellen, einen Testfehler dokumentieren, einen Fehler protokollieren, ein während einer QA-Sitzung gefundenes Problem melden oder etwas melden möchte, das fehlerhaft ist – zum Beispiel „Fehler melden“, „Fehlerticket erstellen“, „Ich habe einen Fehler gefunden“, „Etwas ist in der Aufgabe fehlerhaft“.
