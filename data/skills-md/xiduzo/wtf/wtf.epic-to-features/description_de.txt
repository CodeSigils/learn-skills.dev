Diese Fertigkeit sollte verwendet werden, wenn ein Benutzer ein Epic auf einmal in seinen kompletten Funktionssatz zerlegen möchte, automatisch aufgerufen wird, nachdem das Schreiben des Epics abgeschlossen ist, oder durch Phrasen wie „Alle Features für dieses Epic erstellen“, „Führe mich durch alle Features“, „Lassen Sie uns dieses Epic aufschlüsseln“ oder „Planen Sie die Features für das Epic“ ausgelöst werden soll
