Esta habilidad debe usarse cuando un usuario desea descomponer una epopeya en su conjunto completo de funciones de una vez, invocada automáticamente después de que se completa la escritura épica o activada por frases como "crea todas las funciones para esta epopeya", "guíame a través de todas las funciones", "desglosemos esta epopeya" o "planifique las funciones para la epopeya".
