TRIGGER quando: l'utente interroga i dati della sessione STDM o i record di traccia Data Cloud; indaga sugli errori, sulle regressioni o sui problemi di prestazioni degli agenti di produzione; chiede informazioni sulle tracce delle sessioni, sui registri delle conversazioni o sulle metriche dell'agente; vuole riprodurre in anteprima un problema di produzione segnalato; esegue findSessions o traccia query di analisi. NON SI ATTIVA quando: l'utente crea, modifica o esegue il debug di file .agent durante lo sviluppo (usa development-agentforce); scrive o esegue specifiche di test (usa testing-agentforce); utilizza l'anteprima dell'agente sf per l'iterazione dello sviluppo locale; distribuisce o pubblica agenti.
