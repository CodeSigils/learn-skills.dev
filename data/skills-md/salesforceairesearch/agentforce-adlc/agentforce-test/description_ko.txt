Agentforce 에이전트에 대한 구조화된 테스트 스위트를 작성, 실행 및 분석합니다. TRIGGER 언제: 사용자가 테스트 사양 YAML(AiEvaluationDefinition)을 작성하거나 수정합니다. SF 에이전트 테스트 생성, 실행, 실행 평가 또는 결과 명령을 실행합니다. 테스트 적용 범위 전략, 지표 선택 또는 사용자 정의 평가에 대해 질문합니다. 테스트 결과를 해석하거나 테스트 실패를 진단합니다. 일괄 테스트, 회귀 제품군 또는 CI/CD 테스트 통합에 대해 질문합니다. 다음과 같은 경우에는 트리거하지 마세요. 사용자가 .agent 파일을 생성, 수정, 미리보기 또는 디버깅하는 경우(agentforce-generate 사용) 에이전트를 배포하거나 게시합니다. 에이전트 스크립트 코드를 작성합니다. 개발 반복을 위해 SF 에이전트 미리보기를 사용합니다. 프로덕션 세션 추적을 분석합니다(agentforce-observe 사용). OWASP, 보안 또는 레드팀 테스트를 요청합니다(agentforce-secure 사용).
