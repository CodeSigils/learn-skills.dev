Crea, modifica, esegui il debug e distribuisci gli agenti con Agentforce Agent Script. TRIGGER quando: l'utente crea, modifica o richiede file .agent o metadati aiAuthoringBundle; modifica il comportamento, le risposte o la logica della conversazione dell'agente; progetta argomenti, azioni, strumenti, agenti secondari o controllo del flusso degli agenti; scrive o esamina una specifica dell'agente; visualizza in anteprima, esegue il debug, distribuisce, pubblica o testa gli agenti; utilizza i comandi CLI di Agent Script (generazione/anteprima/pubblicazione/test dell'agente sf). NON SI ATTIVA quando: sviluppo Apex, creazione di flussi, creazione di modelli di prompt, configurazione di Experience Cloud o attività generali della CLI di Salesforce non correlate allo script dell'agente.
