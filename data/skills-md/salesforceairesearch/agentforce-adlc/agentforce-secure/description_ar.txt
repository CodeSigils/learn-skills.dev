قم بإجراء أفضل 10 تقييمات أمنية لـ OWASP LLM ضد عملاء Agentforce المباشرين. يتم تشغيله عندما: يطلب المستخدم إجراء اختبار الأمان، أو فحص OWASP، أو الفريق الأحمر، أو اختبار الاختراق، أو درجة الأمان، أو تقييم نقاط الضعف، أو اختبار الحقن الفوري، أو اختبار تسرب البيانات، أو اختبار الوكالة المفرط، أو فحص الوضع الأمني، أو توصيات صارمة. لا تقم بالتشغيل عندما: يقوم المستخدم بإجراء اختبارات الدخان الوظيفية أو اختبارات الدُفعات (استخدم اختبار agentforce)؛ يقوم بمراجعة السلامة الثابتة لمحتوى ملف الوكيل (استخدم القسم 15 من إنشاء agentforce)؛ ويحلل آثار جلسة الإنتاج (استخدم agentforce-observe)؛ يكتب أو يعدل ملفات .agent.
