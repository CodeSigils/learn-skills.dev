Téléchargez un fichier local sur AceData Cloud CDN et récupérez une URL publique. À utiliser chaque fois que vous produisez un artefact local (image, audio, vidéo, document) dont une autre API a besoin comme URL, ou que vous devez renvoyer/conserver (par exemple, introduire une image générée dans une API d'image en vidéo, ou publier une vidéo terminée).
