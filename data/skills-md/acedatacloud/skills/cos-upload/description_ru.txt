Загрузите локальный файл в AceData Cloud CDN и получите общедоступный URL-адрес. Используйте всякий раз, когда вы создаете локальный артефакт (изображение, аудио, видео, документ), который нужен другому API в качестве URL-адреса или который вам нужно вернуть/сохранить (например, передать сгенерированное изображение в API преобразования изображения в видео или опубликовать готовое видео).
