Laden Sie eine lokale Datei in das AceData Cloud CDN hoch und erhalten Sie eine öffentliche URL zurück. Verwenden Sie es immer dann, wenn Sie ein lokales Artefakt (Bild, Audio, Video, Dokument) erstellen, das eine andere API als URL benötigt oder das Sie zurückgeben/behalten müssen (z. B. ein generiertes Bild in eine Bild-zu-Video-API einspeisen oder ein fertiges Video veröffentlichen).
