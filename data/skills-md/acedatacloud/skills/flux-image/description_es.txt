Genere y edite imágenes con Flux (Black Forest Labs) a través de la API AceDataCloud. Úselo al crear imágenes a partir de indicaciones de texto, editar imágenes existentes con instrucciones de texto o cuando se necesite generar imágenes de alta calidad. Admite múltiples modelos de Flux, incluidos dev, pro, variantes de Flux 2 y kontext para edición.
