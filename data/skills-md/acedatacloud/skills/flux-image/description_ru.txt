Создавайте и редактируйте изображения с помощью Flux (Black Forest Labs) через API AceDataCloud. Используйте при создании изображений из текстовых подсказок, редактировании существующих изображений с помощью текстовых инструкций или когда требуется создание высококачественных изображений. Поддерживает несколько моделей Flux, включая dev, pro, варианты Flux 2 и контекст для редактирования.
