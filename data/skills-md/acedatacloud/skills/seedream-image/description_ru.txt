Создавайте и редактируйте изображения AI с помощью Seedream (ByteDance) через API AceDataCloud. Используйте при создании изображений из текстовых подсказок, редактировании существующих изображений или работе с результатами с высоким разрешением. Поддерживает модели Seedream 3.0 T2I, 4.0, 4.5, 5.0 и SeedEdit 3.0.
