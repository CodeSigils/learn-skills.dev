Verwalten Sie Apple Notes unter macOS – Listen Sie Notizen auf, suchen Sie, lesen Sie sie, erstellen Sie sie, hängen Sie sie an, verschieben Sie sie, löschen Sie sie, exportieren Sie sie und verwalten Sie Ordner. Verwenden Sie diese Option, wenn der Benutzer Apple Notes / 备忘录, „eine Notiz hinzufügen“, „meine Notizen“ erwähnt, seine Notizen durchsucht, Ordner organisiert oder eine Notiz nach Markdown/HTML exportiert. Nur macOS; Läuft lokal gegen Notes.app – keine Cloud-API, kein Token.
