Выполняйте поиск в Интернете с помощью Google через API AceDataCloud. Используйте при поиске веб-страниц, изображений, новостей, карт, местных мест или видео. Поддерживает локализацию, фильтрацию по времени и нумерацию страниц. Возвращает структурированные результаты с заголовками, фрагментами, URL-адресами и расширенными данными.
