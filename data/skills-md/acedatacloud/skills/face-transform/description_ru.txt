Анализируйте и преобразуйте лица с помощью API AceDataCloud. Используйте при обнаружении ключевых точек лица, украшении портретов, старении/омоложении лиц, смене пола, замене лиц на фотографиях, создании мультяшных аватаров или определении живости. Предоставляет 7 специализированных API-интерфейсов для лиц.
