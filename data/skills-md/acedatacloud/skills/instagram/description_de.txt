Veröffentlichen Sie Bilder, Videos, Reels oder Karussells über die Instagram Content Publishing API auf Ihrem professionellen Instagram-Konto und lesen Sie Ihre eigenen aktuellen Medien. Verwenden Sie diese Option, wenn der Benutzer auf Instagram posten möchte (Foto/Video/Reel/Karussell), ein Bild Cross-Posten oder seine eigenen Instagram-Beiträge überprüfen möchte. Instagram besteht nur aus Bildern/Videos (keine reinen Textbeiträge). Auth verwendet ein Zugriffstoken (BYOC). 支持 Instagram 图片 / 视频 / Reels / 轮播发布.
