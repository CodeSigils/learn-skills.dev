Gérez le compte WeChat personnel de l'utilisateur via son service Wisdom auto-hébergé (BYOC) : vérifiez l'état de connexion, répertoriez les contacts/conversations, lisez et résumez l'historique, recherchez des contacts, actualisez la base de données de l'historique local et envoyez des messages uniquement après confirmation explicite. À utiliser lorsque l'utilisateur mentionne 个人微信, 我的微信, le chat personnel WeChat, 微信聊天记录, 微信联系人, lit/résume les messages WeChat ou envoie un message WeChat.
