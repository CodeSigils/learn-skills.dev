Listen Sie Kanäle auf, lesen Sie aktuelle Nachrichten und senden Sie Nachrichten auf Discord mit dem eigenen Bot des Benutzers über die Discord REST API. Verwenden Sie diese Option, wenn der Benutzer möchte, dass sein Discord-BOT eine Nachricht postet, einen Kanal liest oder Server/Kanäle auflistet – alles, was auf einem Server agiert, zu dem der Bot eingeladen wurde.
