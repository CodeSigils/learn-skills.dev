Lesen und bearbeiten Sie Live-Excel-Arbeitsmappen, die in OneDrive/SharePoint gespeichert sind, über die Microsoft Graph-Arbeitsmappen-API. Verwenden Sie diese Option, wenn der Benutzer eine Excel-Datei, eine Tabelle auf OneDrive, das Lesen eines Bereichs oder einer Tabelle, das Anhängen von Zeilen, das Aktualisieren von Zellen oder das Auflisten von Arbeitsblättern in einer Cloud-XLSX-Datei erwähnt.
