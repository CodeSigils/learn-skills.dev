Чтение и редактирование интерактивных книг Excel, хранящихся в OneDrive/SharePoint, с помощью API книг Microsoft Graph. Используйте, когда пользователь упоминает файл Excel, электронную таблицу в OneDrive, читает диапазон или таблицу, добавляет строки, обновляет ячейки или выводит листы в облаке .xlsx.
