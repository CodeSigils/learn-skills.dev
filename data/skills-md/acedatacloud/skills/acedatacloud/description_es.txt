Administre su cuenta AceDataCloud a través de la API de administración
(plataforma.acedata.cloud). Utilizar cuando el usuario quiera consultar su saldo /
créditos restantes, busque registros de llamadas (uso) de API y gaste, enumere o cree
o eliminar claves API (credenciales), enumerar servicios suscritos, enumerar/crear/pagar
recargar pedidos, administrar tokens de plataforma, ver ganancias de referencias/afiliados, o
(administradores) publicar un anuncio. También cubre el catálogo y los documentos PÚBLICOS (no
token necesario): detalles y precios del servicio, lista de API y especificaciones de OpenAPI, conjuntos de datos,
integraciones, búsqueda de documentación de texto completo y el catálogo de modelos con
Precios de crédito por modelo. Esta es la API de "consola" de autoservicio: distinta
desde las API de generación de datos (imagen/vídeo/música/búsqueda).
