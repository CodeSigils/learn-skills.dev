Lesen und senden Sie Microsoft Teams-Chatnachrichten über Microsoft Graph v1.0. Verwenden Sie diese Option, wenn der Benutzer Microsoft Teams-Chats, einen 1:1- oder Gruppenchat, das Lesen aktueller Teams-Nachrichten oder das Senden einer Teams-Chat-Nachricht erwähnt. (Kanalnachrichten werden nicht abgedeckt – sie erfordern vom Administrator genehmigte Bereiche.)
