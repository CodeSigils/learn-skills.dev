Читайте и управляйте событиями/повесткой дня/свободно-занято/приглашениями Календаря Google через REST API Календаря v3. Используйте, когда пользователь упоминает события Календаря Google, повестку дня на сегодня, встречи на этой неделе, поиск конфликтов, перечисление приглашений, проверку свободного времени или планирование/перепланирование/отмену встречи.
