Чтение и запись документов Feishu (飞书), таблиц, базовых (битовых), файлов Диска, событий календаря, задач, вики и мгновенных сообщений через API REST открытой платформы Feishu. Используйте, когда пользователь упоминает 飞书 / Feishu / Lark, ссылку на документ или лист Feishu, свой календарь Feishu или хочет отправить сообщение Feishu.
