Gérez Tencent Cloud EdgeOne (CDN + sécurité périphérique). À utiliser lorsque l'utilisateur
demande de : lister les zones, purger le cache CDN (URL/préfixe/nom d'hôte/tout),
pré-extraire les URL sur les bords chauds, vérifier l'état de la tâche de purge/pré-extraction,
gérer les domaines d'accélération, lister/créer/supprimer EdgeOne DNS
enregistrements, inspectez la configuration WAF/sécurité. Soutenu par le fonctionnaire
Client TEO tencentcloud-sdk-python.
