Veröffentlichen Sie Text-, Bild-, Video- oder Karussellbeiträge über die offizielle Threads-API in Ihrem Threads-Konto (@threads) und lesen Sie Ihre eigenen aktuellen Beiträge. Verwenden Sie diese Option, wenn der Benutzer in Threads posten, ein kurzes Update/einen Thread posten, ein Bild oder einen Link anhängen oder seine eigenen Threads-Beiträge überprüfen möchte. Auth verwendet ein Threads-Zugriffstoken (BYOC). 支持 Threads 文本 / 图片 / 视频 / 轮播发布与自有贴文读取.
