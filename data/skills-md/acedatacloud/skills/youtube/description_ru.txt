Ищите на YouTube, читайте свой собственный канал и загружайте видео (статистику, комментарии), а также загружайте новые видео через API данных YouTube v3. Используйте, когда пользователь упоминает YouTube, «мой канал», «мои видео», поиск на YouTube, просмотры видео/лайки/статистику, загрузку видео на YouTube или проверку эффективности опубликованного видео.
