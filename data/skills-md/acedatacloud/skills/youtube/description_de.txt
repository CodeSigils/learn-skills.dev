Durchsuchen Sie YouTube, lesen Sie Ihren eigenen Kanal und hochgeladene Videos (Statistiken, Kommentare) und laden Sie neue Videos über die YouTube Data API v3 hoch. Wird verwendet, wenn der Benutzer YouTube, „mein Kanal“, „meine Videos“ erwähnt, YouTube durchsucht, Videoaufrufe/Likes/Statistiken angibt, ein Video auf YouTube hochlädt oder prüft, wie ein veröffentlichtes Video abschneidet.
