ابحث في YouTube، واقرأ قناتك ومقاطع الفيديو التي تم تحميلها (الإحصائيات والتعليقات)، وقم بتحميل مقاطع فيديو جديدة عبر YouTube Data API v3. يُستخدم عندما يذكر المستخدم YouTube، أو "قناتي"، أو "مقاطع الفيديو الخاصة بي"، أو البحث في YouTube، أو مشاهدات / إعجابات / إحصائيات الفيديو، أو تحميل مقطع فيديو على YouTube، أو التحقق من أداء مقطع فيديو منشور.
