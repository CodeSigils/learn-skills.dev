Über das MCP von DiDi Mobility können Sie Fahrten anfordern, Tarife prüfen, Bestellungen abfragen, Bestellungen stornieren, Routen planen (Fahren/öffentliche Verkehrsmittel/Gehen/Radfahren) und nach Standorten suchen. Verwenden Sie diese Funktion, wenn der Benutzer DiDi erwähnt, eine Fahrt anfordert, ein Auto ruft, eine Fahrt nach Hause/zur Arbeit benötigt, prüft, wie viel es kostet/wie man von A nach B kommt, eine Bestellung abfragt, wo sich der Fahrer befindet/wie lange bis zur Ankunft dauert, eine Fahrt plant, eine Routenplanung, DiDi, Mitfahrgelegenheiten oder die Buchung eines Taxis.
