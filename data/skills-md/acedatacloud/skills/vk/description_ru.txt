Публикуйте сообщения в своем профиле ВКонтакте или на стене сообщества и читайте свои последние публикации через официальный API ВК (wall.post / wall.get). Используйте, когда пользователь хочет опубликовать сообщение в ВК, перекрестно опубликовать статью для русскоязычной аудитории или перечислить свои недавние публикации на стене ВК с вовлечением. Для аутентификации используется токен доступа к ВКонтакте (рекомендуется использовать ключ доступа к сообществу).
