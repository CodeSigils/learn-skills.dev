Создавайте видеоролики с искусственным интеллектом с помощью Luma Dream Machine через API AceDataCloud. Используйте при создании видео из текстовых подсказок, создании видео из эталонных изображений, расширении существующих видео или любых задачах создания видео с помощью Luma. Поддерживает преобразование текста в видео, изображение в видео и расширение видео.
