Управляйте сегментами и объектами Tencent Cloud COS (Cloud Object Storage).
Используйте всякий раз, когда пользователь спрашивает о сегменте COS / 对象存储 / Tencent Cloud.
операции: список сегментов, список объектов, загрузка, скачивание, удаление,
предварительно подписанные URL-адреса, расчет размера корзины (du), пакетное удаление с префиксом,
копировать объекты между ключами. Поддерживается официальным пакетом cos-python-sdk-v5.
