Administre depósitos y objetos de Tencent Cloud COS (Cloud Object Storage).
Úselo siempre que el usuario pregunte sobre COS / 对象存储 / Tencent Cloud bucket
operaciones: enumerar depósitos, enumerar objetos, cargar, descargar, eliminar,
URL prefirmadas, cálculo del tamaño del depósito (du), eliminación por lotes con prefijo,
copiar objetos entre claves. Respaldado por el cos-python-sdk-v5 oficial.
