Verwalten Sie Tencent Cloud COS (Cloud Object Storage)-Buckets und -Objekte.
Verwenden Sie es immer dann, wenn der Benutzer nach COS / 对象存储 / Tencent Cloud-Bucket fragt
Operationen: Buckets auflisten, Objekte auflisten, hochladen, herunterladen, löschen,
Vorsignierte URLs, Bucket-Größe (DU) berechnen, Stapellöschung mit Präfix,
Kopieren Sie Objekte zwischen Schlüsseln. Unterstützt durch das offizielle cos-python-sdk-v5.
