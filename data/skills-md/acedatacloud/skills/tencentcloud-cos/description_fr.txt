Gérez les buckets et les objets Tencent Cloud COS (Cloud Object Storage).
À utiliser chaque fois que l'utilisateur pose des questions sur le bucket COS / 对象存储 / Tencent Cloud
opérations : lister les buckets, lister les objets, charger, télécharger, supprimer,
URL pré-signées, calcul de la taille du bucket (du), suppression par lots avec préfixe,
copier des objets entre les clés. Soutenu par le cos-python-sdk-v5 officiel.
