Recherchez et analysez les journaux Tencent Cloud CLS (Cloud Log Service). Utiliser
chaque fois que l'utilisateur demande : rechercher les journaux, déboguer les erreurs de l'API, tracer
requêtes par ID de trace, recherchez les erreurs 5xx, exécutez des analyses CQL/SQL sur
enregistrer les sujets, extraire les champs structurés. Soutenu par le fonctionnaire
client CLS tencentcloud-sdk-python.
