Поиск и анализ журналов Tencent Cloud CLS (Cloud Log Service). Использование
всякий раз, когда пользователь просит: поиск в журналах, отладка ошибок API, отслеживание
запросы по идентификатору трассировки, поиск ошибок 5xx, запуск аналитики CQL/SQL
темы журналов, извлечение структурированных полей. При поддержке официального
CLS-клиент tencentcloud-sdk-python.
