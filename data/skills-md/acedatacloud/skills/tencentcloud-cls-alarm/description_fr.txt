Gérez les politiques d'alarme Tencent Cloud CLS, les groupes de notification, les boucliers et
journaux d’exécution des alarmes. À utiliser lorsque l'utilisateur demande : lister / créer /
modifier/supprimer les alarmes CLS, activer ou désactiver les alarmes, gérer les notifications
destinataires (SMS/e-mail/webhook), désactiver les alarmes pendant les déploiements, ou
voir quelles alarmes se sont déclenchées et quand. Pour rechercher le journal sous-jacent
contenu, utilisez la compétence compagnon « tencentcloud-cls ».
