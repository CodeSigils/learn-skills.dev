Verwalten Sie DNS-Einträge auf DNSPod (dem DNS-Dienst von Tencent Cloud). Verwenden Sie wann
Der Benutzer bittet darum, A / AAAA / CNAME / MX / TXT / hinzuzufügen / zu aktualisieren / zu löschen
NS-/SRV-/CAA-Einträge, Listeneinträge für eine Domain, Sucheinträge,
Fügen Sie ACME-Challenge-/SPF-/DKIM-/Domänenüberprüfungs-TXT-Einträge hinzu.
Unterstützt durch den offiziellen tencentcloud-sdk-python DNSPod-Client.
