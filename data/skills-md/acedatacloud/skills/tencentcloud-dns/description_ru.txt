Управляйте записями DNS на DNSPod (служба DNS Tencent Cloud). Используйте, когда
пользователь просит добавить/обновить/удалить A/AAAA/CNAME/MX/TXT/
Записи NS/SRV/CAA, записи списка для домена, записи поиска,
добавьте записи ACME Challenge/SPF/DKIM/TXT для проверки домена.
Поддерживается официальным клиентом DNSPod tencentcloud-sdk-python.
