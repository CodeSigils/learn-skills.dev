Utilice Fusion DevTools CLI (fdev) para pruebas de API, adquisición de tokens, descubrimiento de servicios y búsqueda de personas durante el desarrollo. USO PARA: llamar a las API REST de Fusion, obtener tokens de acceso como JSON, descubrir servicios y entornos, resolver personas, activación de roles PIM. NO LO UTILICE PARA: modificar el código del servicio backend, implementar servicios, cambios de infraestructura, configuración de canalización de CI/CD u operaciones de Service Bus.
