Utilisez Fusion DevTools CLI (fdev) pour les tests d'API, l'acquisition de jetons, la découverte de services et la recherche de personnes pendant le développement. UTILISER POUR : appeler des API Fusion REST, obtenir des jetons d'accès au format JSON, découvrir des services et des environnements, résoudre des personnes, activer le rôle PIM. NE PAS UTILISER POUR : la modification du code du service backend, le déploiement de services, les modifications d'infrastructure, la configuration du pipeline CI/CD ou les opérations Service Bus.
