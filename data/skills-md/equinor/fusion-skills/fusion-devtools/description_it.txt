Utilizza la CLI di Fusion DevTools (fdev) per il test delle API, l'acquisizione di token, l'individuazione dei servizi e la ricerca di persone durante lo sviluppo. UTILIZZARE PER: chiamare le API REST di Fusion, ottenere token di accesso come JSON, scoprire servizi e ambienti, risolvere persone, attivare ruoli PIM. NON UTILIZZARE PER: modifica del codice del servizio backend, distribuzione di servizi, modifiche dell'infrastruttura, configurazione della pipeline CI/CD o operazioni del bus di servizio.
