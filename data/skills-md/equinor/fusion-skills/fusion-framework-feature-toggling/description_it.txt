Guida gli sviluppatori che utilizzano i flag delle funzionalità di Fusion Framework con il recupero iniziale del framework supportato da MCP e le risorse di fallback di origine pubblica in bundle quando MCP non è disponibile. UTILIZZARE PER: assistenza con `enableFeatureFlag`, `enableFeatureFlagging`, `useFeature`, indicazioni sull'implementazione/pulizia e ricerca di esempi di flag di funzionalità di Fusion Framework. NON UTILIZZARE PER: piattaforme di flag SaaS generiche, sistemi di implementazione solo backend o API di framework inventati.
