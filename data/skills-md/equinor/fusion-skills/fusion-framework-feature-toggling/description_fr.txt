Guide les développeurs utilisant les indicateurs de fonctionnalités de Fusion Framework avec la récupération du framework basée sur MCP en premier et les actifs de secours de source publique regroupés lorsque MCP n'est pas disponible. UTILISER POUR : aider avec `enableFeatureFlag`, `enableFeatureFlagging`, `useFeature`, les conseils de déploiement/nettoyage et trouver des exemples d'indicateurs de fonctionnalités de Fusion Framework. NE PAS UTILISER POUR : les plates-formes de drapeaux SaaS génériques, les systèmes de déploiement backend uniquement ou l'invention d'API de framework.
