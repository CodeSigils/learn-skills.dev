Guía a los desarrolladores que utilizan indicadores de funciones de Fusion Framework con la recuperación del marco respaldado por MCP primero y activos de reserva de fuente pública incluidos cuando MCP no está disponible. UTILIZAR PARA: ayudar con `enableFeatureFlag`, `enableFeatureFlagging`, `useFeature`, orientación de implementación/limpieza y búsqueda de ejemplos de indicadores de funciones de Fusion Framework. NO LO UTILICE PARA: plataformas de bandera SaaS genéricas, sistemas de implementación solo de backend o API de marco inventadas.
