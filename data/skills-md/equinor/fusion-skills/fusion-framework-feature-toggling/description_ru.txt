Помогает разработчикам использовать флаги функций Fusion Framework с первым получением инфраструктуры на основе MCP и объединенными резервными ресурсами с открытым исходным кодом, когда MCP недоступен. ИСПОЛЬЗОВАНИЕ ДЛЯ: помощь с `enableFeatureFlag`, `enableFeatureFlagging`, `useFeature`, руководство по развертыванию/очистке и поиск примеров флагов функций Fusion Framework. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: общих платформ флагов SaaS, систем развертывания только для серверной части или разработки API-интерфейсов платформы.
