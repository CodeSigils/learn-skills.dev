MCP が利用できない場合は、最初に MCP ベースのフレームワークを取得し、バンドルされたパブリック ソースのフォールバック アセットを使用して、Fusion Framework の機能フラグを使用する開発者をガイドします。用途: 「enableFeatureFlag」、「enableFeatureFlagging」、「useFeature」、ロールアウト/クリーンアップのガイダンスの支援、Fusion Framework の機能フラグの例の検索。以下の用途には使用しないでください: 汎用 SaaS フラグ プラットフォーム、バックエンドのみのロールアウト システム、または発明中のフレームワーク API。
