Améliore systématiquement la documentation TSDoc et README entre les packages dans un monorepo TypeScript. Découvre les surfaces d'API publiques, génère ou améliore TSDoc sur toutes les exportations, réécrit les README dans une structure cohérente et conviviale pour la récupération et valide chaque package indépendamment. UTILISER POUR : les passages de documentation à l'échelle d'un monorepo, les améliorations de documents d'un seul paquet, la génération de TSDoc sur les exportations publiques, la normalisation README, les contrôles de qualité du conseil de révision. NE PAS UTILISER POUR : les modifications du code d'exécution, l'analyse de sécurité, la génération de sites de référence API, les langages non TypeScript.
