Систематически улучшает документацию TSDoc и README для всех пакетов в монорепозитории TypeScript. Обнаруживает общедоступные поверхности API, генерирует или улучшает TSDoc для всех экспортируемых файлов, переписывает README в согласованную, удобную для извлечения структуру и фиксирует каждый пакет независимо. ИСПОЛЬЗОВАНИЕ ДЛЯ: прохождения документации по всему монорепозиторию, улучшения документации по одному пакету, создания TSDoc для публичного экспорта, стандартизации README, проверок качества экспертным советом. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: изменения кода во время выполнения, сканирования безопасности, создания справочного сайта API, языков, отличных от TypeScript.
