Migliora sistematicamente la documentazione TSDoc e README tra i pacchetti in un monorepo TypeScript. Rileva le superfici API pubbliche, genera o migliora TSDoc su tutte le esportazioni, riscrive i file README in una struttura coerente di facile recupero e conferma ogni pacchetto in modo indipendente. UTILIZZO PER: passaggi di documentazione a livello di monorepo, miglioramenti dei documenti a pacchetto singolo, generazione di TSDoc sulle esportazioni pubbliche, standardizzazione README, revisione dei controlli di qualità del consiglio. NON UTILIZZARE PER: modifiche al codice runtime, scansione di sicurezza, generazione di siti di riferimento API, linguaggi non TypeScript.
