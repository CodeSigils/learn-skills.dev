Mejora sistemáticamente la documentación TSDoc y README en todos los paquetes en un monorepo de TypeScript. Descubre superficies de API públicas, genera o mejora TSDoc en todas las exportaciones, reescribe archivos README en una estructura coherente y fácil de recuperar y confirma cada paquete de forma independiente. USO PARA: pases de documentación para todo monorepo, mejoras de documentos de paquete único, generación de TSDoc en exportaciones públicas, estandarización README, controles de calidad del consejo de revisión. NO UTILIZAR PARA: cambios de código en tiempo de ejecución, escaneo de seguridad, generación de sitios de referencia de API, lenguajes que no sean TypeScript.
