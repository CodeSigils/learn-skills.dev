Porte principale de compétences Copilot pour l'écosystème Fusion : routeur inter-domaines. UTILISER POUR : le routage entre différents domaines Fusion (compétences, problèmes, PR, avis) lorsque la compétence de domaine appropriée n'est pas claire ; obtenir des conseils d'installation pour les compétences manquantes. NE PAS UTILISER POUR : les opérations du cycle de vie des compétences (utiliser directement les compétences de fusion), les tâches pour lesquelles une compétence de fusion spécifique est déjà active.
