Точка входа для всех операций жизненного цикла навыков Fusion. ИСПОЛЬЗОВАНИЕ ДЛЯ: поиска, установки, обновления, синхронизации или сохранения навыков; настройка автоматизации навыков; создание или разработка нового навыка; сообщить об ошибке с помощью навыка. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: решения проблем GitHub, просмотра запросов на запросы, планирования разбивки задач или создания проблем GitHub — они решаются другими навыками Fusion.
