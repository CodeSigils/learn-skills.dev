Guía las integraciones entre las API del servicio Fusion Core desde una única habilidad instalable. USO PARA: descubrimiento de servicios en aplicaciones, personas, contexto, roles, notificaciones, informes, tareas y otras API de Fusion Core; planificación de integración entre servicios; elegir la guía de modelo/punto final adecuada para un flujo de trabajo. NO UTILIZAR PARA: modificar el código fuente del backend de Fusion, las API que no son de Fusion o el trabajo de arquitectura de nube genérica sin un objetivo de integración de servicios de Fusion.
