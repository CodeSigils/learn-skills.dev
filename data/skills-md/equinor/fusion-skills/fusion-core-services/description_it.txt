Guida le integrazioni tra le API del servizio Fusion Core da un'unica competenza installabile. UTILIZZARE PER: rilevamento di servizi tra app, persone, contesto, ruoli, notifiche, report, attività e altre API Fusion Core; pianificazione dell'integrazione tra servizi; scegliere la giusta guida per endpoint/modello per un flusso di lavoro. NON UTILIZZARE PER: modificare il codice sorgente del backend Fusion, API non Fusion o lavori generici sull'architettura cloud senza una destinazione di integrazione del servizio Fusion.
