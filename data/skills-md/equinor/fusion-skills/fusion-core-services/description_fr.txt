Guide les intégrations dans les API du service Fusion Core à partir d’une seule compétence installable. UTILISER POUR : découverte de services dans les applications, les personnes, le contexte, les rôles, les notifications, les rapports, les tâches et autres API Fusion Core ; planification de l'intégration interservices ; choisir le bon point de terminaison/modèle pour un flux de travail. NE PAS UTILISER POUR : la modification du code source du backend Fusion, des API non Fusion ou du travail d'architecture cloud générique sans cible d'intégration de service Fusion.
