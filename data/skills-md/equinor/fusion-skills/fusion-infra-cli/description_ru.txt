Подготовьте и перенесите базы данных Fusion с помощью fusion-infra-cli (finf). ИСПОЛЬЗОВАНИЕ ДЛЯ: подготовка базы данных для службы, запуск миграции SQL, подготовка временных баз данных для PR, проверка состояния базы данных. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: изменения кода приложения, развертывания служб, управления ролями или инфраструктуры, отличной от баз данных.
