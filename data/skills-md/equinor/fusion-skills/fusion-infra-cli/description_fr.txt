Provisionnez et migrez les bases de données Fusion à l'aide de fusion-infra-cli (finf). UTILISER POUR : provisionner une base de données pour un service, exécuter des migrations SQL, provisionner des bases de données éphémères spécifiques au PR, vérifier l'état de la base de données. NE PAS UTILISER POUR : les modifications du code d’application, les déploiements de services, la gestion des rôles ou l’infrastructure autre que les bases de données.
