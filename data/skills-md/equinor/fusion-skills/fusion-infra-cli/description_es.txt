Aprovisione y migre bases de datos de Fusion mediante fusion-infra-cli (finf). UTILIZAR PARA: aprovisionar una base de datos para un servicio, ejecutar migraciones SQL, aprovisionar bases de datos efímeras específicas de PR, comprobar el estado de la base de datos. NO UTILIZAR PARA: cambios de código de aplicaciones, implementaciones de servicios, administración de roles o infraestructura que no sea bases de datos.
