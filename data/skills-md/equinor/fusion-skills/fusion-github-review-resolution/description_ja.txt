未解決の GitHub PR レビュー スレッドをエンドツーエンドで解決します。各レビュー コメントが正しいかどうかを評価し、有効な場合はターゲットを絞った修正を適用し、そうでない場合は根拠を返信し、スレッドをコミットして解決します。用途: 未解決のレビュー スレッド、PR レビューのフィードバック、リクエストされた PR の変更、PR レビューの URL (#pullrequestreview-...)、レビュー コメントの修正、開いているスレッドの閉鎖、PR フィードバックの対処。 FOR は使用しないでください: コードを変更せずにフィードバックを要約する場合、新しい PR を作成する場合、または読み取り専用ブランチを作成する場合。
