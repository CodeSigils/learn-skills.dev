Risolve i thread di revisione GitHub PR irrisolti end-to-end: valuta se ciascun commento di revisione è corretto, applica una correzione mirata quando valida, risponde con motivazione quando non lo è, esegue il commit e risolve il thread. UTILIZZARE PER: thread di revisione non risolti, feedback di revisione PR, modifiche richieste ai PR, URL di revisione PR (#pullrequestreview-...), correggere i commenti di revisione, chiudere i thread aperti, rispondere al feedback di PR. NON UTILIZZARE PER: riepilogare il feedback senza modifiche al codice, creare nuovi PR o rami di sola lettura.
