Résout les fils de discussion de révision GitHub PR non résolus de bout en bout : évalue si chaque commentaire de révision est correct, applique un correctif ciblé lorsqu'il est valide, répond avec une justification dans le cas contraire, valide et résout le fil de discussion. UTILISER POUR : les fils de discussion non résolus, les commentaires de révision des relations publiques, les modifications demandées, les URL de révision des relations publiques (#pullrequestreview-...), corriger les commentaires de révision, fermer les fils de discussion ouverts, traiter les commentaires des relations publiques. NE PAS UTILISER POUR : résumer les commentaires sans modifier le code, créer de nouveaux PR ou des branches en lecture seule.
