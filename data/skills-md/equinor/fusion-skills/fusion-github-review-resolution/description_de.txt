Löst ungelöste GitHub PR-Review-Threads End-to-End auf: Bewertet, ob jeder Review-Kommentar korrekt ist, wendet eine gezielte Korrektur an, wenn sie gültig ist, antwortet mit Begründung, wenn dies nicht der Fall ist, schreibt fest und löst den Thread auf. VERWENDUNG FÜR: ungelöste Bewertungsthreads, PR-Bewertungsfeedback, angeforderte Änderungen an PRs, PR-Bewertungs-URLs (#pullrequestreview-...), Korrektur der Bewertungskommentare, Schließen der offenen Threads, Behandeln von PR-Feedback. NICHT VERWENDEN FÜR: das Zusammenfassen von Feedback ohne Codeänderungen, das Erstellen neuer PRs oder schreibgeschützte Zweige.
