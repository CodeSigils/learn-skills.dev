Комплексно разрешает неразрешенные потоки обзоров PR GitHub: оценивает, является ли каждый комментарий обзора правильным, применяет целевое исправление, если оно действительно, отвечает с обоснованием, если нет, фиксирует и разрешает поток. ИСПОЛЬЗОВАНИЕ ДЛЯ: неразрешенных тем проверки, отзывов о проверке PR, запрошенных изменений PR, URL-адресов проверки PR (#pullrequestreview-...), исправления комментариев к обзору, закрытия открытых тем, рассмотрения отзывов PR. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: обобщения отзывов без изменений кода, создания новых PR или ветвей, доступных только для чтения.
