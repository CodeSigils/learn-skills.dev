Guide la consommation et la compréhension des services backend, des API et des modèles Fusion pour les développeurs frontend/clients, les intégrateurs et les architectes. Montre les implémentations de référence, explique les décisions architecturales et clarifie les contrats. UTILISER POUR : comprendre les API backend de Fusion, apprendre les modèles d'implémentation, explorer le code de référence, choisir le bon point d'intégration et comprendre les modèles d'autorisation/validation/async. NE PAS UTILISER POUR : modifier les services backend, créer de nouveaux points de terminaison, modifier la base de données ou développer un développement spécifique au backend (utilisez plutôt fusion-services-develop ou le dépôt de services backend).
