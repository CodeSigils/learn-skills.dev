Направляет использование и понимание серверных служб, API и шаблонов Fusion для разработчиков внешнего интерфейса/клиентов, интеграторов и архитекторов. Показывает эталонные реализации, объясняет архитектурные решения и уточняет контракты. ИСПОЛЬЗОВАНИЕ ДЛЯ: понимания API серверной части Fusion, изучения шаблонов реализации, изучения справочного кода, выбора правильной точки интеграции и понимания шаблонов авторизации/проверки/асинхронности. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: изменения серверных служб, создания новых конечных точек, изменения базы данных или разработки для конкретной серверной части (вместо этого используйте fusion-services-develop или репозиторий серверных служб).
