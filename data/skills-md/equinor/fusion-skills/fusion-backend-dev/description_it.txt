Guida l'utilizzo e la comprensione dei servizi backend, delle API e dei modelli Fusion per sviluppatori frontend/client, integratori e architetti. Mostra le implementazioni di riferimento, spiega le decisioni relative all'architettura e chiarisce i contratti. UTILIZZARE PER: comprendere le API backend di Fusion, apprendere i modelli di implementazione, esplorare il codice di riferimento, scegliere il punto di integrazione corretto e comprendere i modelli di autorizzazione/convalida/asincroni. NON UTILIZZARE PER: modifica dei servizi di backend, creazione di nuovi endpoint, modifiche del database o sviluppo specifico del backend (utilizzare invece fusion-services-develop o il repository del servizio backend).
