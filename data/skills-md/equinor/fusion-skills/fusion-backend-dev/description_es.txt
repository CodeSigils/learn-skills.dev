Guía el consumo y la comprensión de los servicios backend, API y patrones de Fusion para desarrolladores, integradores y arquitectos de frontend/cliente. Muestra implementaciones de referencia, explica decisiones arquitectónicas y aclara contratos. UTILIZAR PARA: comprender las API de backend de Fusion, aprender patrones de implementación, explorar el código de referencia, elegir el punto de integración correcto y comprender los patrones de autorización/validación/asincrónicos. NO LO UTILICE PARA: modificar servicios backend, crear nuevos puntos finales, cambios en la base de datos o desarrollo específico de backend (use fusion-services-develop o repositorio de servicios backend en su lugar).
