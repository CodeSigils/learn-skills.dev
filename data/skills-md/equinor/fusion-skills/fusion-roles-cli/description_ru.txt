Развертывайте конфигурацию Fusion Roles V2 и управляйте ею с помощью fusion-roles-cli (froles). ИСПОЛЬЗОВАНИЕ ДЛЯ: развертывание конфигурации роли из файла JSON, создание ролей/привязок/назначений, экспорт текущего состояния роли, проверка назначений ролей. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: подготовки базы данных, изменения кода приложения, управления группами Azure AD за пределами привязок ролей или управления ролями V1.
