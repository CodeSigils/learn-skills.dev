Déployez et gérez la configuration de Fusion Roles V2 à l'aide de fusion-roles-cli (froles). UTILISER POUR : déployer la configuration de rôle à partir d'un fichier JSON, créer des rôles/liaisons/affectations, exporter l'état actuel du rôle, inspecter les attributions de rôles. NE PAS UTILISER POUR : le provisionnement de bases de données, les modifications du code d’application, la gestion de groupe Azure AD en dehors des liaisons de rôle ou la gestion des rôles V1.
