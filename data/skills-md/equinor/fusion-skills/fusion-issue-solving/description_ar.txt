يتعامل مع حل مشكلة GitHub من البداية إلى النهاية للمطالبات مثل "حل #123"، أو "دعونا نحل #123"، أو "العمل على #123"، أو "العمل على https://github.com/owner/repo/issues/123"، أو عن طريق لصق عنوان URL المباشر لمشكلة GitHub كالطلب. الاستخدام من أجل: حل رقم 123، ومواصلة العمل على المشكلة رقم 123، والعمل على https://github.com/owner/repo/issues/123، ولصق عنوان URL لمشكلة GitHub لأعمال التنفيذ. لا تستخدم من أجل: صياغة المشكلات فقط، أو مراجعة العلاقات العامة فقط، أو الأبحاث غير التنفيذية.
