Gère la résolution des problèmes GitHub de bout en bout pour les invites telles que « résoudre #123 », « permet de résoudre le numéro 123 », « travailler sur le numéro 123 », « travailler sur https://github.com/owner/repo/issues/123 », ou en collant une URL directe du problème GitHub en tant que demande. UTILISER POUR : résoudre le problème 123, continuer à travailler sur le problème 123, travailler sur https://github.com/owner/repo/issues/123, coller une URL de problème GitHub pour le travail de mise en œuvre. NE PAS UTILISER POUR : la rédaction de problèmes uniquement, l'examen des relations publiques uniquement ou la recherche sans mise en œuvre.
