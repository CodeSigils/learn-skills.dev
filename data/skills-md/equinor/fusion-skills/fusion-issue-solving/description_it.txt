Gestisce la risoluzione dei problemi GitHub end-to-end per richieste come "risolvi #123", "risolviamo #123", "lavora su #123", "lavora su https://github.com/owner/repo/issues/123" o incollando l'URL diretto di un problema GitHub come richiesta. UTILIZZARE PER: risolvere il problema n. 123, continuare a lavorare sul problema n. 123, lavorare su https://github.com/owner/repo/issues/123, incollare l'URL del problema GitHub per il lavoro di implementazione. NON UTILIZZARE PER: solo stesura di questioni, solo revisione delle pubbliche relazioni o ricerca di non implementazione.
