「#123 を解決する」、「#123 を解決しましょう」、「#123 で作業します」、「https://github.com/owner/repo/issues/123 で作業します」などのプロンプトに対して、または直接 GitHub 問題 URL をリクエストとして貼り付けることで、GitHub の問題解決をエンドツーエンドで処理します。用途: #123 の解決、問題 #123 の作業の継続、https://github.com/owner/repo/issues/123 の作業、実装作業用の GitHub 問題の URL の貼り付け。次の用途には使用しないでください: 問題の草案作成のみ、PR レビューのみ、または実装以外の研究には使用できません。
