Обрабатывает сквозное разрешение проблем GitHub для таких запросов, как «решить № 123», «давайте решим № 123», «работаем над № 123», «работаем над https://github.com/owner/repo/issues/123» или путем вставки прямого URL-адреса проблемы GitHub в качестве запроса. ИСПОЛЬЗОВАНИЕ ДЛЯ: решить № 123, продолжить работу над проблемой № 123, работать над https://github.com/owner/repo/issues/123, вставить URL-адрес проблемы GitHub для работы по реализации. НЕ ИСПОЛЬЗОВАТЬ ДЛЯ: только разработки проекта, только PR-обзора или исследования, не связанного с внедрением.
