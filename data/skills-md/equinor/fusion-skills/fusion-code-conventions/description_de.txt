Wendet Codekonventionen für TypeScript, React, C# und Markdown an und erklärt sie. Erzwingt Benennungsregeln, Dateibenennungsmuster, TSDoc- und XML-Dokumentstandards, Inline-Kommentarabsicht (das *Warum*, nicht das *Was*), Codestruktur, Fehlerbehandlung, asynchrone Muster und Richtlinien für toten Code. Erzwingt außerdem ADR- und Mitwirkendendokumententscheidungen und markiert Entscheidungen, die veraltet erscheinen oder nicht mit den aktuellen Tools übereinstimmen. VERWENDUNG FÜR: Konventionsfragen, Codeüberprüfung anhand von Projektstandards, Anwenden von Benennungsregeln, Prüfung von Absichtskommentaren, Überprüfung der TSDoc-Vollständigkeit, Durchsetzung aufgezeichneter ADR-Entscheidungen und Kennzeichnung veralteter Architekturentscheidungen. NICHT VERWENDEN FÜR: Sicherheitslücken-Scans, Leistungsprofilierung, Laufzeit-Debugging oder Generierung von völlig neuem Code ohne Überprüfungsziel.
