Applique et explique les conventions de code dans TypeScript, React, C# et Markdown. Applique les règles de dénomination, les modèles de dénomination de fichiers, les normes de documentation TSDoc et XML, l'intention de commentaire en ligne (le *pourquoi*, pas le *quoi*), la structure du code, la gestion des erreurs, les modèles asynchrones et la politique de code mort. Applique également les décisions ADR et les documents des contributeurs, et signale les décisions qui semblent obsolètes ou mal alignées avec les outils actuels. UTILISER POUR : les questions de convention, la révision du code par rapport aux normes du projet, l'application de règles de dénomination, l'audit des commentaires d'intention, la vérification de l'exhaustivité du TSDoc, l'application des décisions ADR enregistrées et le signalement des décisions architecturales obsolètes. NE PAS UTILISER POUR : l'analyse des vulnérabilités de sécurité, le profilage des performances, le débogage d'exécution ou la génération d'un nouveau code net sans cible de révision.
