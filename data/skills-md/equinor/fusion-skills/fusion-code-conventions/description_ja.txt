TypeScript、React、C#、Markdown にわたるコード規則を適用して説明します。命名規則、ファイル命名パターン、TSDoc および XML ドキュメント標準、インライン コメントの意図 (「内容」ではなく「理由」)、コード構造、エラー処理、非同期パターン、およびデッド コード ポリシーを強制します。また、ADR および貢献者のドキュメント決定を強制し、最新のツールと一致していない、または古いと思われる決定にフラグを立てます。用途: 規約の質問、プロジェクト標準に対するコード レビュー、命名規則の適用、意図コメントの監査、TSDoc の完全性のチェック、記録された ADR 決定の適用、古いアーキテクチャ上の決定のフラグ付け。次の用途には使用しないでください: セキュリティ脆弱性スキャン、パフォーマンス プロファイリング、ランタイム デバッグ、またはレビュー対象のないまったく新しいコードの生成。
