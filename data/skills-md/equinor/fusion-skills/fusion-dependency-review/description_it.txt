Esamina le PR di dipendenza con ricerca strutturata, acquisizione delle discussioni sulle PR esistenti, analisi multi-obiettivo (sicurezza, qualità del codice, impatto) e un modello di verdetto ripetibile. UTILIZZARE PER: PR di aggiornamento delle dipendenze, PR di Renovate/Dependabot, revisioni dell'aggiornamento della libreria, "rivedi questo PR di dipendenza", "dovremmo unire questo aggiornamento". NON UTILIZZARE PER: PR di funzionalità, revisioni del codice dell'applicazione, automazione delle dipendenze/configurazione di bot o unione automatica senza conferma.
