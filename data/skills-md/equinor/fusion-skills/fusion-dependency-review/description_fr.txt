Examinez les PR de dépendance avec une recherche structurée, une capture des discussions sur les PR existantes, une analyse multi-objectifs (sécurité, qualité du code, impact) et un modèle de verdict reproductible. UTILISER POUR : PR de mise à jour des dépendances, PR Renovate/Dependabot, révisions de mise à niveau de bibliothèque, "examiner ce PR de dépendance", "devrions-nous fusionner cette mise à jour". NE PAS UTILISER POUR : les PR de fonctionnalités, les révisions de code d'application, l'automatisation des dépendances/la configuration de robots ou la fusion sans surveillance sans confirmation.
