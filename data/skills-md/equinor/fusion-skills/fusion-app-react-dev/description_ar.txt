تطوير ميزات الأدلة في تطبيقات Fusion Framework React - مكونات السقالات والخطافات والخدمات والأنواع التي تتبع اصطلاحات EDS وأنماط Fusion Framework. الاستخدام من أجل: إنشاء ميزات جديدة، وإضافة مكونات أو صفحات، وإنشاء خطافات وخدمات، وتوصيل نقاط نهاية واجهة برمجة التطبيقات (API)، وتوسيع تكوين وحدة Fusion. لا تستخدمه من أجل: تأليف المشكلات، أو تأليف المهارات، أو تكوين CI/CD، أو تغييرات الخدمة الخلفية.
