Les guides présentent le développement de fonctionnalités dans les applications Fusion Framework React : composants d'échafaudage, hooks, services et types qui suivent les conventions EDS et les modèles Fusion Framework. UTILISER POUR : créer de nouvelles fonctionnalités, ajouter des composants ou des pages, créer des hooks et des services, câbler les points de terminaison de l'API et étendre la configuration du module Fusion. NE PAS UTILISER POUR : la création de problèmes, la création de compétences, la configuration CI/CD ou les modifications du service backend.
