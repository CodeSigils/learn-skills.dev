Las guías presentan el desarrollo en aplicaciones Fusion Framework React: componentes de andamiaje, enlaces, servicios y tipos que siguen las convenciones de EDS y los patrones de Fusion Framework. UTILIZAR PARA: crear nuevas funciones, agregar componentes o páginas, crear enlaces y servicios, conectar puntos finales API y ampliar la configuración del módulo Fusion. NO UTILIZAR PARA: creación de problemas, creación de habilidades, configuración de CI/CD o cambios en el servicio backend.
