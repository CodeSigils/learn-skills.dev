Le guide presentano lo sviluppo nelle app Fusion Framework React: componenti di impalcatura, hook, servizi e tipi che seguono le convenzioni EDS e i modelli Fusion Framework. UTILIZZARE PER: creare nuove funzionalità, aggiungere componenti o pagine, creare hook e servizi, collegare endpoint API ed estendere la configurazione del modulo Fusion. NON UTILIZZARE PER: creazione di problemi, creazione di competenze, configurazione CI/CD o modifiche al servizio backend.
