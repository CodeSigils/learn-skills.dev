Руководства посвящены разработке в приложениях Fusion Framework React — компонентам каркаса, перехватчикам, сервисам и типам, которые соответствуют соглашениям EDS и шаблонам Fusion Framework. ИСПОЛЬЗОВАНИЕ ДЛЯ: создания новых функций, добавления компонентов или страниц, создания перехватчиков и сервисов, подключения конечных точек API и расширения конфигурации модуля Fusion. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания проблем, разработки навыков, конфигурации CI/CD или изменений внутренних служб.
