Точка входа для создания правил помощника по кодированию с использованием ИИ в GitHub Copilot, Cursor и Claude Code. ИСПОЛЬЗОВАНИЕ ДЛЯ: настройки правил, просмотра существующих правил, создания файлов инструкций или запроса, какой формат редактора использовать. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: навыков разработки (SKILL.md), определений агентов (.agent.md) или принудительного применения файлов правил CI.
