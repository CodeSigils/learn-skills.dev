Point d'entrée pour la création de règles de l'assistant de codage IA sur GitHub Copilot, Cursor et Claude Code. UTILISER POUR : configurer des règles, réviser les règles existantes, créer des fichiers d'instructions ou demander quel format d'éditeur utiliser. NE PAS UTILISER POUR : les compétences de création (SKILL.md), les définitions d'agent (.agent.md) ou l'application CI des fichiers de règles.
