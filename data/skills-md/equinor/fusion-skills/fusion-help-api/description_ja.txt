Fusion Help REST API との直接対話を通じて開発者と管理者をガイドします。つまり、記事、FAQ、リリース ノートの読み取り、コンテンツの検索、プログラムによるヘルプ ドキュメントの管理を行います。用途: API からヘルプ記事を取得する、アプリにヘルプ コンテンツを統合する、ヘルプ コンテンツを検索する、API 経由でヘルプ ドキュメントを管理する、ヘルプ コンテンツを自動化する、ヘルプ ツールを構築する。次の目的には使用しないでください: fhelp CLI ツールの使用 (fusion-help-docs スキルを使用)、Fusion.Services.Help バックエンド コードの変更、または非ヘルプ API タスク。
