يرشد المطورين والمسؤولين من خلال التفاعل المباشر مع Fusion Help REST API — قراءة المقالات والأسئلة الشائعة وملاحظات الإصدار والبحث في المحتوى وإدارة وثائق المساعدة برمجيًا. الاستخدام من أجل: جلب مقالات المساعدة من واجهة برمجة التطبيقات (API)، ودمج محتوى المساعدة في التطبيق، والبحث في محتوى المساعدة، وإدارة وثائق المساعدة عبر واجهة برمجة التطبيقات (API)، وأتمتة محتوى المساعدة، وإنشاء أدوات المساعدة. لا تستخدمه من أجل: استخدام أداة fhelp CLI (استخدم مهارة fusion-help-docs)، أو تعديل Fusion.Services.Help كود الواجهة الخلفية، أو المهام التي لا تتعلق بواجهة برمجة التطبيقات (API).
