Помогает разработчикам и администраторам осуществлять прямое взаимодействие с API REST Fusion Help — чтение статей, часто задаваемых вопросов, примечаний к выпуску, поиск контента и программное управление справочной документацией. ИСПОЛЬЗОВАНИЕ: получение справочных статей из API, интеграция справочного содержимого в приложение, поиск справочного содержимого, управление справочной документацией через API, автоматизация справочного содержимого, создание справочных инструментов. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: использования инструмента CLI fhelp (используйте навык fusion-help-docs), изменения внутреннего кода Fusion.Services.Help или задач, не связанных с help-API.
