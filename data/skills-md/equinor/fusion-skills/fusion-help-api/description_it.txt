Guida gli sviluppatori e gli amministratori attraverso l'interazione diretta con l'API REST di Fusion Help: lettura di articoli, domande frequenti, note di rilascio, ricerca di contenuti e gestione della documentazione della guida in modo programmatico. UTILIZZARE PER: recuperare articoli della guida dall'API, integrare contenuti della guida nell'app, cercare contenuti della guida, gestire la documentazione della guida tramite API, automatizzare i contenuti della guida, creare strumenti di guida. NON UTILIZZARE PER: utilizzare lo strumento CLI fhelp (utilizzare la competenza fusion-help-docs), modificare il codice backend Fusion.Services.Help o attività non API di aiuto.
