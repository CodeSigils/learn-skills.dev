Führt Entwickler und Administratoren durch die direkte Interaktion mit der Fusion Help REST API – Lesen von Artikeln, FAQs, Versionshinweisen, Durchsuchen von Inhalten und programmgesteuertes Verwalten der Hilfedokumentation. VERWENDUNG FÜR: Hilfeartikel von der API abrufen, Hilfeinhalte in die App integrieren, Hilfeinhalte durchsuchen, Hilfedokumentation über die API verwalten, Hilfeinhalte automatisieren, Hilfetools erstellen. NICHT VERWENDEN FÜR: die Verwendung des fhelp-CLI-Tools (verwenden Sie den Skill fusion-help-docs), das Ändern des Fusion.Services.Help-Backend-Codes oder Nicht-Hilfe-API-Aufgaben.
