Guide les développeurs et les administrateurs via une interaction directe avec l'API REST Fusion Help : lecture d'articles, de FAQ, de notes de version, recherche de contenu et gestion de la documentation d'aide par programmation. UTILISER POUR : récupérer des articles d'aide à partir de l'API, intégrer du contenu d'aide dans l'application, rechercher du contenu d'aide, gérer la documentation d'aide via l'API, automatiser le contenu d'aide, créer des outils d'aide. NE PAS UTILISER POUR : l'utilisation de l'outil CLI fhelp (utilisez la compétence fusion-help-docs), la modification du code backend Fusion.Services.Help ou des tâches non-aide-API.
