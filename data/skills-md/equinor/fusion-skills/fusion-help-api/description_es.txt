Guía a los desarrolladores y administradores a través de la interacción directa con la API REST de Fusion Help: lectura de artículos, preguntas frecuentes, notas de la versión, búsqueda de contenido y administración de documentación de ayuda mediante programación. UTILIZAR PARA: recuperar artículos de ayuda desde API, integrar contenido de ayuda en la aplicación, buscar contenido de ayuda, administrar documentación de ayuda a través de API, automatizar contenido de ayuda, crear herramientas de ayuda. NO LO UTILICE PARA: usar la herramienta CLI fhelp (use la habilidad fusion-help-docs), modificar el código backend de Fusion.Services.Help o tareas que no sean de API de ayuda.
