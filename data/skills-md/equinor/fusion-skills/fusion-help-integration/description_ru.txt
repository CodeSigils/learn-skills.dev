Справочный центр Wires Fusion на страницах приложения — создает константы фрагментов статей, добавляет перехват useHelpCenter и подключает реквизиты PageLayout, чтобы пользователи могли открывать контекстные справочные статьи. ИСПОЛЬЗОВАНИЕ ДЛЯ: добавления кнопки справки на страницу, подключения useHelpCenter, создания констант helpArticles, интеграции справки Fusion в приложение, подключения PageLayout к справочному центру, добавления openHelpArticle на страницу. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания справочных статей по уценке (используйте fusion-help-docs), прямых вызовов Help REST API (используйте fusion-help-api), изменения общих компонентов @fra/ui.
