Fusion 도움말 센터를 앱 페이지에 연결 - 기사 슬러그 상수를 생성하고, useHelpCenter 후크를 추가하고, PageLayout 소품을 연결하여 사용자가 상황별 도움말 기사를 열 수 있도록 합니다. 사용 대상: 페이지에 도움말 버튼 추가, useHelpCenter 연결, helpArticles 상수 생성, 앱에 Fusion 도움말 통합, PageLayout을 도움말 센터에 연결, 페이지에 openHelpArticle 추가. 사용하지 마십시오: 마크다운 도움말 문서 작성(fusion-help-docs 사용), 직접 도움말 REST API 호출(fusion-help-api 사용), @fra/ui 공유 구성 요소 수정.
