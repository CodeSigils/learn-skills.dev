Verwenden Sie diese Fähigkeit, wenn der Benutzer eine Frontend-Projektarchitektur nach der Feature-Sliced ​​Design (FSD)-Methodik entwerfen, organisieren oder umgestalten muss. Zu den spezifischen Szenarien gehören: Erstellen einer FSD-kompatiblen Verzeichnisstruktur, Entscheiden, zu welcher Ebene (App/Seiten/Widgets/Features/Entities/Shared) ein Code gehört, Überprüfen, ob Code gegen unidirektionale Abhängigkeiten oder öffentliche API-Regeln verstößt, und Umgestalten eines vorhandenen Projekts auf FSD-Architektur. Nicht geeignet für: das Schreiben eigenständiger Komponenten, die Diskussion von Nicht-FSD-Architekturansätzen oder Problemen, die nichts mit der Frontend-Architektur zu tun haben.
