사용자가 FSD(Feature-Sliced ​​Design) 방법론에 따라 프런트엔드 프로젝트 아키텍처를 디자인, 구성 또는 리팩터링해야 하는 경우 이 기술을 사용하십시오. 특정 시나리오에는 FSD 호환 디렉터리 구조 생성, 코드 조각이 속한 계층(app/pages/widgets/features/entities/shared) 결정, 코드가 단방향 종속성 또는 공개 API 규칙을 위반하는지 확인, 기존 프로젝트를 FSD 아키텍처로 리팩터링하는 작업이 포함됩니다. 적합하지 않은 분야: 독립형 구성 요소 작성, FSD가 아닌 아키텍처 접근 방식 논의 또는 프런트엔드 아키텍처와 관련 없는 문제.
