Use this skill when the user needs to design, organize, or refactor a frontend project architecture following the Feature-Sliced Design (FSD) methodology. Specific scenarios include: creating an FSD-compliant directory structure, deciding which layer (app/pages/widgets/features/entities/shared) a piece of code belongs to, checking whether code violates unidirectional dependency or public API rules, and refactoring an existing project to FSD architecture. Not suitable for: writing standalone components, discussing non-FSD architecture approaches, or problems unrelated to frontend architecture.
