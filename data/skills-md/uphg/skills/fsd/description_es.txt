Utilice esta habilidad cuando el usuario necesite diseñar, organizar o refactorizar la arquitectura de un proyecto frontend siguiendo la metodología Feature-Sliced ​​Design (FSD). Los escenarios específicos incluyen: crear una estructura de directorio compatible con FSD, decidir a qué capa (aplicación/páginas/widgets/características/entidades/compartido) pertenece un fragmento de código, verificar si el código viola la dependencia unidireccional o las reglas API públicas y refactorizar un proyecto existente a la arquitectura FSD. No apto para: escribir componentes independientes, discutir enfoques de arquitectura que no sean FSD o problemas no relacionados con la arquitectura frontend.
