Создавайте недорогие, высокотехнологичные веб-интерфейсы — поверхности бренда (целевые страницы, сайты брендов, запуски, портфолио, главные страницы с реальными движками WebGL/Three.js/Canvas/GSAP), пользовательский интерфейс продукта (панели мониторинга, панели администратора, аналитика, таблицы данных, оболочки приложений, настройки) и коммерческие страницы (страницы сведений о продукте, страницы списков/категорий, корзина, оформление заказа). Маршруты по регистру: бренд → соул + двигатель зрелища; продукт → компонентная система + плотность информации + данные, а именно; коммерция → скелеты PDP/PLP + правила защиты от темных шаблонов. Всегда сначала читает краткое описание и проверяет наличие черного списка по борьбе с дешевизной. Поддерживает глагольные команды (проверять · жирнее · тише · душу · оживлять · уплотнять · перепроектировать) для целенаправленной итерации на существующих страницах. Триггеры: «сделать это премиум-классом», «целевая страница», «панель управления», «панель администратора», «пользовательский интерфейс аналитики», «таблица данных», «пользовательский интерфейс приложения», «страница продукта», «PDP», «страница списка», «оформление заказа», «придать ему душу / атмосферу», «анти-отстой», «анимация героя», «/finesse».
