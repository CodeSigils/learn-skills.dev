Wird verwendet, wenn ein Agent die Buildin-API über die Buildin-CLI aufrufen, Buildin authentifizieren, eine Datei hochladen, eine Seite erstellen oder aktualisieren, eine Datenbank abfragen, Inhalte durchsuchen, Markdown-Seiteninhalte bearbeiten oder eine andere Aufgabe ausführen muss, die den Befehl „buildin“ beinhaltet.
