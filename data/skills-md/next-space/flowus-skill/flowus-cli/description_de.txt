Wird verwendet, wenn ein Agent die FlowUs-API über die FlowUs-CLI aufrufen, FlowUs authentifizieren, eine Datei hochladen, eine Seite erstellen oder aktualisieren, eine Datenbank abfragen, Inhalte durchsuchen, Markdown-Seiteninhalte bearbeiten oder eine andere Aufgabe ausführen muss, die den Befehl „flowus“ beinhaltet.
