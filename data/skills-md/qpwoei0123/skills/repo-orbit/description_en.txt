A pipeline that automatically analyzes a repository from seven viewpoints (SAFE/ARCH/DEP/BUILD/DATA/OPS/DOC) and publishes only the technical issues that pass the criteria as GitHub/GitLab issues. When requests like "analyze my repo", "check my codebase", "find my technical debt", "auto-create issues", "check if CI is missing", "audit dependencies", "verify test coverage", or "$repo-orbit" come in, this skill must be used. If a repo URL or local path is provided, it runs immediately; otherwise, it asks first.
