A code-inspection pipeline that automatically analyzes a repository from seven viewpoints (SAFE/ARCH/DEP/BUILD/DATA/OPS/DOC) and opens only the technical issues that meet the criteria as GitHub/GitLab issues. When requests like “analyze the repo,” “audit the codebase,” “find tech debt,” “auto-register issues,” “check if CI is missing,” “inspect dependencies,” “verify test coverage,” or “$repo-orbit” come in, this skill must be used. If a repo URL or local path is provided, run immediately; otherwise, ask first.
