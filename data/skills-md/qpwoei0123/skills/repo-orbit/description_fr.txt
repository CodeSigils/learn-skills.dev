Un pipeline d'inspection de code qui analyse automatiquement un référentiel sous sept points de vue (SAFE/ARCH/DEP/BUILD/DATA/OPS/DOC) et ouvre uniquement les problèmes techniques qui répondent aux critères en tant que problèmes GitHub/GitLab. Lorsque des requêtes telles que « analyser le dépôt », « auditer la base de code », « trouver une dette technologique », « problèmes d'enregistrement automatique », « vérifier si le CI est manquant », « inspecter les dépendances », « vérifier la couverture des tests » ou « $repo-orbit » arrivent, cette compétence doit être utilisée. Si une URL de dépôt ou un chemin local est fourni, exécutez-le immédiatement ; sinon, demandez d'abord.
