Un pipeline qui analyse automatiquement un référentiel sous sept points de vue (SAFE/ARCH/DEP/BUILD/DATA/OPS/DOC) et publie uniquement les problèmes techniques qui répondent aux critères en tant que problèmes GitHub/GitLab. Lorsque des requêtes telles que « analyser mon dépôt », « vérifier ma base de code », « trouver ma dette technique », « créer automatiquement des problèmes », « vérifier si le CI est manquant », « auditer les dépendances », « vérifier la couverture des tests » ou « $repo-orbit » arrivent, cette compétence doit être utilisée. Si une URL de dépôt ou un chemin local est fourni, il s'exécute immédiatement ; sinon, il demande d'abord.
