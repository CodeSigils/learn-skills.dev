Un canal de inspección de código que analiza automáticamente un repositorio desde siete puntos de vista (SAFE/ARCH/DEP/BUILD/DATA/OPS/DOC) y abre solo los problemas técnicos que cumplen con los criterios como problemas de GitHub/GitLab. Cuando llegan solicitudes como "analizar el repositorio", "auditar el código base", "encontrar deuda tecnológica", "problemas de registro automático", "verificar si falta CI", "inspeccionar dependencias", "verificar la cobertura de la prueba" o "$repo-orbit", se debe utilizar esta habilidad. Si se proporciona una URL de repositorio o una ruta local, ejecútela inmediatamente; de lo contrario, pregunte primero.
