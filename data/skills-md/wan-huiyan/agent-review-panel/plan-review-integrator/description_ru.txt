Интегрируйте выводы структурированной группы обзора в документ плана реализации. Получает данные из панели проверки агентов (или любой структурированной проверки с выводами по степени серьезности) и сопоставляет каждый результат с планом, классифицирует их по категориям действий, применяет конкретные изменения и создает сводную информацию о отслеживаемости. Запускается, когда пользователь говорит «обновить план с результатами проверки», «включить в план отзывы о проверке», «интегрировать результаты проверки», «применить рекомендации проверки к плану», «сопоставить результаты проверки с планом», «объединить результаты проверки с планом реализации», «что необходимо изменить в плане на основе проверки», «взять результаты проверки и обновить мой план», «согласовать отзывы проверки с текущим планом» или вызывает /plan-review-integrator. НЕ срабатывает при запуске панели проверки (используйте Agent-Review-Panel), написании плана с нуля, общей проверке кода, подведении итогов проверки без их применения или мозговом штурме подходов к реализации.
