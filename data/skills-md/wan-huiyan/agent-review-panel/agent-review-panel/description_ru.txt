Организуйте многоагентную состязательную обзорную комиссию, в которой несколько субагентов Клода Кода с разными точками зрения независимо проверяют часть работы, спорят друг с другом, достигают (или не достигают) консенсуса, а затем верховный судья выносит окончательный вердикт. Используйте этот навык всякий раз, когда пользователь запрашивает «комиссию проверки», «многоагентную проверку», «состязательную проверку», «предлагает агентам обсудить это», «проверку с нескольких точек зрения», «групповую проверку», «получите разные мнения по этому коду/плану/документу» или вызывает /agent-review-panel. Также срабатывает, когда пользователь говорит такие вещи, как «Мне нужна подробная информация с разных точек зрения», «Проведите стресс-тестирование этого проекта», «Красная команда», «получите второе (третье, четвертое) мнение», «свежий взгляд на это», «несколько рецензентов», «точка зрения адвоката дьявола», «охвачены все аспекты», «я хочу, чтобы агенты обсуждали плюсы и минусы», «независимо оценивали», «критический взгляд с точки зрения безопасности и производительности», «высокие ставки — охватывают все аспекты» или «обсуждать плюсы и минусы». Этот навык конкретно предназначен для запуска нескольких агентов-рецензентов с разными личностями, которые обсуждают и спорят, а НЕ для проверки кода одним рецензентом, быстрой проверки работоспособности, исправления ошибок, задач по развертыванию, рассмотрения существующих комментариев по связям с общественностью, улучшения навыков, экспертной оценки, объяснения кода или написания тестов. Поддерживает «режим глубокого исследования», когда пользователь говорит «глубокий обзор», «тщательный обзор», «исследовательский обзор» или передает «глубокий» в /agent-review-panel — добавляет веб-исследование лучших практик домена перед запуском рецензентов. Поддерживает «режим объединения нескольких прогонов», когда пользователь говорит «проверка нескольких прогонов», «выполнить N раз и объединить», «выполнить дважды», «выполнить 3 раза» или «проверка максимального покрытия» — повторяет панель с повернутыми наборами персонажей и объединяет результаты с оценкой стабильности. Поддерживает «уровни трассировки потока данных» (стандартный/тщательный/исчерпывающий), когда пользователь говорит «тщательная проверка», «исчерпывающая проверка», «отслеживать все» или «вылавливать все ошибки» — этап предварительной проверки посвящается отслеживанию данных по критическим путям и обнаружению ошибок композиции/стыка.
