マルチエージェントの敵対的審査パネルを組織し、異なる視点を持つ複数のクロード・コードのサブエージェントが独立して作品を審査し、互いに議論し、合意に達した（または達しなかった）後、最高裁判事が最終評決を下します。ユーザーが「レビューパネル」、「マルチエージェントレビュー」、「敵対的レビュー」、「エージェントに議論させる」、「複数の視点でレビューする」、「パネルレビュー」、「このコード/計画/ドキュメントについて異なる意見を得る」を要求するとき、または /agent-review-panel を呼び出すときは常に、このスキルを使用します。また、ユーザーが「さまざまな角度から徹底的なフィードバックが欲しい」、「この設計のストレステストを行う」、「レッドチームはこれを行う」、「2 番目 (3 番目、4 番目) の意見を得る」、「これについて新たな視点を得る」、「複数のレビュー担当者」、「悪魔の代弁者の視点」、「あらゆる角度からカバーする」、「エージェントに賛否両論を議論してもらいたい」、「独立して評価する」、「セキュリティとパフォーマンスの観点から批判的に見る」、「一か八かの - あらゆる角度をカバーする」などのことを言ったときにもトリガーされます。または「賛否両論を議論する」。このスキルは、具体的には、議論や討論を行う個別のペルソナを持つ複数のレビューアー エージェントを立ち上げることに関するものであり、単一レビューアーのコード レビュー、迅速な健全性チェック、バグ修正、展開タスク、既存の PR コメントへの対応、スキル向上、ピア レビュー、コードの説明、テストの作成などには適していません。ユーザーが「詳細レビュー」、「徹底的なレビュー」、「調査レビュー」と発言した場合、または「詳細」を /agent-review-panel に渡した場合の「詳細調査モード」をサポートします。レビュー担当者を起動する前に、ドメインのベスト プラクティスに関する Web 調査を追加します。ユーザーが「複数実行レビュー」、「N 回実行してマージ」、「2 回実行」、「3 回実行」、または「最大カバレッジレビュー」と言った場合の「複数実行ユニオン モード」をサポートします。回転されたペルソナ セットでパネルを繰り返し、結果を安定性スコアとマージします。ユーザーが「徹底的なレビュー」、「徹底的なレビュー」、「すべてをトレース」、または「すべてのバグをキャッチ」した場合の「データ フロー トレース層」（標準/詳細/徹底的）をサポートします。プレレビュー フェーズを、クリティカル パスを介してデータをトレースし、構成/シームのバグにフラグを立てることに専念します。
