Orqueste un panel de revisión adversario de múltiples agentes donde varios subagentes del Código Claude con diferentes perspectivas revisen de forma independiente un trabajo, debatan entre sí, alcancen (o no logren) un consenso y luego un juez supremo emita el veredicto final. Utilice esta habilidad siempre que el usuario solicite un "panel de revisión", "revisión de múltiples agentes", "revisión contradictoria", "hacer que los agentes debatan esto", "revisión con múltiples perspectivas", "revisión de panel", "obtener diferentes opiniones sobre este código/plan/doc" o invoque /agent-review-panel. También se activa cuando un usuario dice cosas como "Quiero comentarios completos desde diferentes ángulos", "probar este diseño", "equipo rojo", "obtener una segunda (tercera, cuarta) opinión", "ojos nuevos sobre esto", "múltiples revisores", "perspectiva del abogado del diablo", "todos los ángulos cubiertos", "Quiero que los agentes discutan los pros y los contras", "evaluar de forma independiente", "mirada crítica desde ángulos de seguridad y rendimiento", "alto en juego: cubra todos los ángulos" o "debatir los pros y los contras". contras". Esta habilidad se trata específicamente de lanzar múltiples agentes revisores con distintas personas que discuten y debaten, NO para la revisión de código de un solo revisor, verificaciones rápidas de cordura, corrección de errores, tareas de implementación, abordar comentarios de relaciones públicas existentes, mejora de habilidades, revisión por pares, explicación de código o pruebas de redacción. Admite el "modo de investigación profunda" cuando el usuario dice "revisión profunda", "revisión exhaustiva", "revisión de investigación" o pasa "profunda" a /agent-review-panel: agrega investigación web para conocer las mejores prácticas del dominio antes de lanzar revisores. Admite el "modo de unión de ejecución múltiple" cuando el usuario dice "revisión de ejecución múltiple", "ejecutar N veces y fusionar", "ejecutar dos veces", "ejecutar 3 veces" o "revisión de cobertura máxima": repite el panel con conjuntos de personas rotados y combina los resultados con la puntuación de estabilidad. Admite "niveles de seguimiento de flujo de datos" (Estándar/Completo/Exhaustivo) cuando el usuario dice "revisión exhaustiva", "revisión exhaustiva", "rastrear todo" o "detectar todos los errores"; dedica una fase previa a la revisión para rastrear datos a través de rutas críticas y marcar errores de composición/costura.
