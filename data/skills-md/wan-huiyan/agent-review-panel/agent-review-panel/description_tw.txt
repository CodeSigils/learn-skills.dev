組織一個多智能體對抗性評審小組，由幾個具有不同觀點的 Claude Code 子智能體獨立評審一件作品，相互辯論，達成（或未能達成）共識，然後由最高法官做出最終裁決。每當使用者要求「評審小組」、「多代理評審」、「對抗性評審」、「讓代理人對此進行辯論」、「多角度評審」、「小組評審」、「對此代碼/計畫/文件取得不同意見」或調用 /agent-review-panel 時，請使用此技能。當使用者說出「我想要從不同角度進行全面回饋」、「對這個設計進行壓力測試」、「紅隊這個」、「獲得第二（第三、第四）意見」、「對此有新的看法」、「多個審查者」、「魔鬼擁護者的觀點」、「涵蓋各個角度」、「我希望代理爭論利」、「獨立評估」、「從安全和角度進行辯論」此技能專門針對啟動具有不同角色的多個審閱者代理進行討論和辯論 - 不適用於單一審閱者程式碼審查、快速健全性檢查、錯誤修復、部署任務、解決現有 PR 評論、技能改進、同行評審、程式碼解釋或編寫測試。當使用者說「深度審查」、「徹底審查」、「研究審查」或將「深度」傳遞給 /agent-review-panel 時，支援「深度研究模式」 - 在啟動審閱者之前添加針對領域最佳實踐的網路研究。當使用者說「多次運行審查」、「運行 N 次並合併」、「運行兩次」、「運行 3 次」或「最大覆蓋率審查」時，支援「多次運行聯合模式」——使用旋轉的角色集重複面板，並將結果與穩定性評分合併。當使用者說「徹底審查」、「詳盡審查」、「追蹤一切」或「捕獲所有錯誤」時，支援「資料流追蹤層」（標準/徹底/詳盡）—專用於預審查階段透過關鍵路徑追蹤資料並標記組合/接縫錯誤。
