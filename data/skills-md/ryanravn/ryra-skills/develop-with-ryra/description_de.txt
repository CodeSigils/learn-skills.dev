Erstellen Sie auf dieser Ryra-Maschine einen neuen Dienst, eine neue App, eine neue API, einen neuen Agenten, einen neuen Bot, ein neues Skript oder ein neues Tool. Verwenden Sie dies, WENN der Benutzer hier ein neues Projekt entwickeln, erstellen, ein Gerüst erstellen, erstellen oder starten möchte – es richtet das Ryra-Service-Layout (service.toml / test.toml) ein, damit das Ding als verwalteter Service hinzugefügt, ausgeführt und aktualisiert werden kann.
