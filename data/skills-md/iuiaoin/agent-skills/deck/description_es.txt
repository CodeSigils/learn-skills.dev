Genere presentaciones HTML de alta calidad con un estricto flujo de trabajo de dos etapas; se invoca manualmente solo cuando el usuario ejecuta `/deck --plan` (resumen guiado, luego crea PLANNING.md), `/deck --generate` (produce diapositivas finales a partir de PLANNING.md aprobado) y, opcionalmente, `/deck --export pptx` (exporta diapositivas generadas a formato PPTX), lo que admite el intercambio técnico, revisiones de arquitectura, presentaciones de estrategia, resúmenes de investigación, presentaciones y actualizaciones de equipo de forma independiente 1280x720 (16:9) Diapositivas HTML.
