厳密な 2 段階のワークフローで高品質の HTML プレゼンテーション デッキを生成します。ユーザーが `/deck --plan` (ガイド付き概要、その後 PLANNING.md を作成)、`/deck --generate` (承認された PLANNING.md から最終スライドを作成)、およびオプションで `/deck --export pptx` (生成されたスライドを PPTX 形式にエクスポート) を実行した場合にのみ手動で呼び出され、技術共有、アーキテクチャ レビュー、戦略デッキ、調査概要、ピッチ デッキ、およびチームの更新をスタンドアロンとしてサポートします。 1280x720 (16:9) の HTML スライド。
