Orchestre la boucle complète post-implémentation : appuyez sur PR → attendez CI → corrigez les échecs → répétez jusqu'à ce que CI réussisse ou que les règles de résiliation déclenchent une pause. Cette compétence doit être utilisée lorsque l'utilisateur dit « expédier », « finaliser pr », « pousser et réparer CI », « pousser pr et attendre CI » ou invoque « codagent:finalize-pr ».
