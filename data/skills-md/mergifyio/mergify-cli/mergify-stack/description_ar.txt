استخدم مكدسات Mergify لإنشاء git Push والالتزام والتفرع والعلاقات العامة. استخدم هذه المهارة دائمًا عند دفع التعليمات البرمجية أو إنشاء الالتزامات أو إنشاء الفروع أو إنشاء العلاقات العامة. المشغلات عند الدفع، الالتزام، الفرع، العلاقات العامة، طلب السحب، المكدس، المكدس، git، rebase، الخروج، إعادة الترتيب، النقل، المزامنة، التعديل، الملاحظة، سجل المراجعة.
