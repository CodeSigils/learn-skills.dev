Utilice las protecciones de fusión de Mergify para controlar cuándo se fusionan los PR: dependencias de PR (encabezado Depende de), fusiones retrasadas (encabezado Merge-After) y congelaciones programadas (CLI). SIEMPRE utilice esta habilidad al administrar congelaciones de fusiones, ventanas de implementación, bloquear fusiones temporalmente, configurar dependencias de PR, bloquear un PR en otro PR, coordinar fusiones entre repositorios, programar una fusión para un tiempo específico o agregar encabezados Depends-On o Merge-After a los PR.
