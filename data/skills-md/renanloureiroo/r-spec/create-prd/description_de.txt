Erstellen Sie ein PRD (Documento de Requisitos do Produto) und testen Sie es im Rahmen einer Anforderung für ein Feature. Nachdem Sie vor der Redaktion eine Klarstellung vorgenommen haben, konzentrieren Sie sich auf die Aufgaben/<NN>-<feature>/prd.md. Wir haben zu Beginn ein neues Feature erstellt oder den Benutzer mit den Anforderungen/PRD versorgt. Verwenden Sie keine Details zur Implementierung, zur Architektur oder zum Code – es handelt sich um einen Bezug zu create-techspec.
