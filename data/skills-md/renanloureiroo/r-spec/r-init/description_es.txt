Inicializa un proyecto para el pipeline r-spec (Desarrollo impulsado por especificaciones). Detecta/pergunta el contexto (tipo de proyecto, pila, comandos, idioma, arnés), utiliza AGENTS.md a partir de la plantilla, crea CLAUDE.md para Claude Code, instala los subagentes de revisión conforme al tipo de proyecto y crea los esqueletos de las habilidades de convención, preenchendo o que descubre y deixando marcadores de posición claros para cada sección necesaria en detalle. Accionar UMA VEZ ao adotar o r-spec num projeto novo ou existente, antes de rodar create-prd. No usar para crear PRD/feature (use create-prd) para implementar el código.
