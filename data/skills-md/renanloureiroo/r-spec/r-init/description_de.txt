Starten Sie ein Projekt für die Pipeline R-Spec (Spec-Driven Development). Erkennen/erkennen Sie den Kontext (Projekttyp, Stapel, Befehle, Sprache, Kabelbaum), erstellen Sie AGENTS.md als Teil der Vorlage, rufen Sie CLAUDE.md für Claude Code auf, installieren Sie Unteragenten für die Überprüfung entsprechend dem Projekttyp und erstellen Sie die entsprechenden Fähigkeiten – lernen Sie es kennen und lernen Sie es kennen Platzhalter verdeutlichen, dass jeder Abschnitt genau ausgearbeitet werden muss. Wenn Sie ein neues oder bestehendes Projekt erstellen oder erstellen möchten, müssen Sie zuerst ein Projekt erstellen. Sie können PRD/Feature (verwenden Sie create-prd) nicht für die Implementierung des Codes verwenden.
