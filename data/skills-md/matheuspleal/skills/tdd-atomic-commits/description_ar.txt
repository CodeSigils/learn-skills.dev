إنشاء التزامات تقليدية ذرية لسير عمل TDD. يقسم شجرة العمل التي تحتوي على كل من تغييرات التنفيذ والاختبار إلى التزامين لكل ميزة - التنفيذ أولاً، ثم اختبارها - بحيث يُقرأ سجل git كقصة TDD نظيفة وقابلة للقسمة. استخدم هذه المهارة عندما يطلب المستخدم الالتزام، ويقول "ارتكب هذا"، أو "ارتكب التغييرات"، أو "قم بالالتزام"، أو "أكمل الالتزام"، أو عندما يحتوي الفرق المرحلي/غير المرحلي على ملفات مصدر واختبار مقترنة (foo.ts + foo.test.ts، foo.py + test_foo.py، foo.go + foo_test.go، Foo.java + FooTest.java، وما إلى ذلك) - حتى لو لم يفعل المستخدم ذلك قل صراحةً "الالتزامات الذرية" أو "الالتزامات التقليدية". تفضل هذه المهارة على الالتزام البسيط عندما تظهر ملفات التنفيذ والاختبار معًا في الفرق.
