قم بإنشاء كائنات قيمة TypeScript أو إعادة تشكيلها. يُستخدم عندما يُطلب منك: إنشاء كائن قيمة، أو إنشاء نوع مجال غير قابل للتغيير، أو تغليف بدائي بالتحقق من الصحة، أو إضافة تحويل DTO أولي، أو تنفيذ مساعدات toRaw/fromRaw، أو إنشاء ملفات مخطط للاستمرارية أو النقل. مشغلات على: "كائن القيمة"، "المجمع غير القابل للتغيير"، "المجمع العددي"، "المجال البدائي"، "نوع المال"، "نوع البريد الإلكتروني"، "toRaw"، "fromRaw"، أنماط التسمية IFoo/FooRaw، ملفات المخطط، "إضافة التحقق من الصحة إلى"، "التعديل التحديثي لإنشاء المصنع".
