Verwenden Sie diese Option, wenn Sie dazu aufgefordert werden: ein Wertobjekt erstellen, einen unveränderlichen Domänentyp erstellen, ein Grundelement mit Validierung umschließen, rohe DTO-Konvertierung hinzufügen, toRaw/fromRaw-Helfer implementieren, Mapper-Dateien für Persistenz oder Transport generieren. Auslöser bei: „Wertobjekt“, „unveränderlicher Wrapper“, „Skalar-Wrapper“, „Domänenprimitiv“, „Geldtyp“, „E-Mail-Typ“, „toRaw“, „fromRaw“, IFoo/FooRaw-Benennungsmuster, Mapper-Dateien, „Validierung hinzufügen zu“, „Retrofit-Create-Factory“.
