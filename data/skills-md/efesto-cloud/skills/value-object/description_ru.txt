Создайте или реорганизуйте объекты значений TypeScript. Используйте, когда вас просят: создать объект значения, создать неизменяемый тип домена, обернуть примитив проверкой, добавить необработанное преобразование DTO, реализовать помощники toRaw/fromRaw, сгенерировать файлы сопоставления для сохранения или транспортировки. Срабатывает по: «объект значения», «неизменяемая оболочка», «скалярная оболочка», «примитив домена», «тип денег», «тип электронной почты», «toRaw», «fromRaw», шаблоны именования IFoo/FooRaw, файлы сопоставления, «добавить проверку в», «модернизация создания фабрики».
