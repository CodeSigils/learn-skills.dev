تنفيذ طبقة الثبات MongoDB لمشروع TypeScript للبنية السداسية. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء أو تعديل واجهة مستودع، أو تنفيذ المستودع، أو نوع مستند MongoDB، أو مخطط الكيان. يتم تشغيله عندما يقول المستخدم أشياء مثل "إنشاء ريبو لـ Foo"، أو "إضافة مخطط خرائط لـ Bar"، أو "أحتاج إلى استمرار Baz إلى MongoDB"، أو "إضافة طبقة الثبات لـ X"، أو "كتابة نوع المستند لـ Foo"، أو "إنشاء مستودع ومخطط خرائط"، أو "توصيل Foo بقاعدة البيانات"، أو عند وجود كيان مجال وطبقة التخزين مفقودة أو غير مكتملة. يتم تشغيله أيضًا عندما يقوم المستخدم بتعديل أحد الكيانات ويقول إن ملفات الثبات تحتاج إلى البقاء متزامنة، أو عندما يشيرون إلى ملفات الريبو/مخطط الخرائط/المستندات بالاسم.
