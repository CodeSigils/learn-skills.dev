Implementa il livello di persistenza MongoDB per un progetto TypeScript con architettura esagonale. Utilizza questa competenza ogni volta che l'utente deve creare o modificare un'interfaccia del repository, un'implementazione del repository, un tipo di documento MongoDB o un mappatore di entità. Si attiva quando l'utente dice cose come "crea un repository per Foo", "aggiungi un mapper per Bar", "devo persistere Baz su MongoDB", "aggiungi il livello di persistenza per X", "scrivi il tipo di documento per Foo", "crea repository e mapper", "collega Foo al database" o ogni volta che esiste un'entità di dominio e il livello di archiviazione è mancante o incompleto. Si attiva anche quando l'utente modifica un'entità e afferma che i file di persistenza devono rimanere sincronizzati o quando fanno riferimento a file repository/mapper/documenti per nome.
