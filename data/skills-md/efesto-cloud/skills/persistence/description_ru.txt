Реализуйте уровень персистентности MongoDB для проекта TypeScript с шестиугольной архитектурой. Используйте этот навык всякий раз, когда пользователю необходимо создать или изменить интерфейс репозитория, реализацию репозитория, тип документа MongoDB или преобразователь сущностей. Срабатывает, когда пользователь говорит такие вещи, как «создать репозиторий для Foo», «добавить сопоставитель для Bar», «Мне нужно сохранить Baz в MongoDB», «добавить уровень персистентности для X», «написать тип документа для Foo», «создать репозиторий и сопоставитель», «подключить Foo к базе данных» или всякий раз, когда существует объект домена, а уровень хранения отсутствует или является неполным. Также срабатывает, когда пользователь изменяет объект и говорит, что файлы сохраняемости должны оставаться синхронизированными, или когда они ссылаются на файлы репозитория/сопоставителя/документа по имени.
