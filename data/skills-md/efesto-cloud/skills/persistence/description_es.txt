Implemente la capa de persistencia de MongoDB para un proyecto TypeScript de arquitectura hexagonal. Utilice esta habilidad siempre que el usuario necesite crear o modificar una interfaz de repositorio, una implementación de repositorio, un tipo de documento MongoDB o un asignador de entidades. Se activa cuando el usuario dice cosas como "crear un repositorio para Foo", "agregar un asignador para Bar", "Necesito persistir Baz en MongoDB", "agregar la capa de persistencia para X", "escribir el tipo de documento para Foo", "crear repositorio y asignador", "conectar Foo a la base de datos", o cuando existe una entidad de dominio y la capa de almacenamiento falta o está incompleta. También se activa cuando el usuario modifica una entidad y dice que los archivos de persistencia deben permanecer sincronizados, o cuando hacen referencia a archivos de repositorio/mapeador/documentos por su nombre.
