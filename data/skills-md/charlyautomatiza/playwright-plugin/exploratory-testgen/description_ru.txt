Используйте этот навык всякий раз, когда пользователь запрашивает исследовательское функциональное тестирование, обнаружение с помощью браузера, проверку потока пользовательского интерфейса, быструю проверку работоспособности перед автоматизацией или предложение плана тестирования для внешнего интерфейса. Этот навык выполняет неинвазивное обнаружение, предлагает план для утверждения, выполняет утвержденные исследовательские потоки с помощью Playwright (предпочтительно Chrome, резервный вариант Chromium), делает снимки экрана с доказательствами потока и записывает окончательный отчет в документации/тестировании. Запустите его для быстрой проверки состояния продукта перед официальной автоматизацией.
