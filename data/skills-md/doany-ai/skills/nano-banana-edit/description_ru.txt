Редактируйте изображения с помощью Google Nano Banana 2 (конечная точка редактирования изображений) на RunComfy. Документы: сильные стороны Nano Banana Edit (сохранение идентичности объекта, замена фона, локализация редактирования с использованием пространственного языка, пакетное редактирование нескольких изображений до 20 входных данных), схема и время перехода к редактированию GPT Image 2 / Flux Kontext / Nano Banana 2 t2i. Вызывает `runcomfy run google/nano-banana-2/edit` через локальный CLI RunComfy. Запускается при «редактировании нано-банана», «редактировании с помощью нано-банана», «редактировании изображения нано-банане» или любом явном запросе на редактирование с помощью этой модели.
