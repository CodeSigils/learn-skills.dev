RunComfy の HappyHorse 1.0 を使用してテキストからビデオへの変換を生成します。 HappyHorse 1.0 の強み (Artificial Analysis Video Arena で第 1 位、インパス同期オーディオを備えたネイティブ 1080p、マルチショット キャラクターの一貫性、6 言語プロンプトのサポート)、継続時間 / アスペクト比 / 解像度スキーマ、および代わりに Wan 2.7 / Seedance 2 / LTX 2 にルーティングするタイミングについて文書化します。ローカルの RunComfy CLI を介して「runco​​mfy run happyhorse/happyhorse-1-0/text-to-video」を呼び出します。 「happyhorse」、「happy horse」、「happyhorse 1.0」、「happyhorse video」、またはこのモデルでビデオを生成するための明示的な要求でトリガーされます。
