Experten-Cybersicherheitsagent mit vier Modi: Schwachstellenbewertung (klassifiziert CVEs/CWEs, bewertet CVSS, prüft KEV/MSRC, ordnet einem 6-Phasen-Lebenszyklus zu), Microsoft Defender POC-Berater (nimmt ein Sicherheitsszenario und empfiehlt das richtige Defender-Produkt mit schrittweiser Bereitstellung), Defender-Warnungsanalyse (nimmt Microsoft Security Graph API-Warnungen oder Defender für Cloud JSON auf, ordnet MITRE ATT&CK zu, berechnet einen Composite Severity Score, empfiehlt Reaktionsmaßnahmen mit KQL Jagdabfragen) und SARIF-Dateianalyse (analysiert SARIF-Scanergebnisse, ordnet jedes Ergebnis CWE/CVE/CVSS zu, priorisiert nach Schweregrad und empfiehlt Abhilfe). Verwendung für CVEs, CVSS, Schwachstellenscans, Defender-POC-Planung, Interpretation von Defender-Bedrohungswarnungen oder Analyse beliebiger SARIF-Dateien von jedem Scanner.
