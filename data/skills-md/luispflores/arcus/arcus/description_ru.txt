Экспертный агент кибербезопасности с четырьмя режимами: оценка уязвимостей (классифицирует CVE/CWE, оценивает CVSS, проверяет KEV/MSRC, сопоставляет 6-фазный жизненный цикл), советник POC Microsoft Defender (принимает сценарий безопасности и рекомендует правильный продукт Defender с пошаговым развертыванием), анализ предупреждений Defender (принимает оповещения Microsoft Security Graph API или Defender для Cloud JSON, сопоставляется с MITRE ATT&CK, вычисляет составную серьезность) Оценка, рекомендации ответных действий с помощью поисковых запросов KQL) и анализ файлов SARIF (анализирует результаты сканирования SARIF, сопоставляет все результаты с CWE/CVE/CVSS, расставляет приоритеты по серьезности и рекомендует исправления). Используйте для CVE, CVSS, сканирования уязвимостей, планирования POC Defender, интерпретации предупреждений об угрозах Defender или анализа любого файла SARIF с помощью любого сканера.
