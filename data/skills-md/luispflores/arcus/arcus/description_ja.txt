4 つのモードを備えたエキスパート サイバーセキュリティ エージェント: 脆弱性評価 (CVE/CWE の分類、CVSS のスコア付け、KEV/MSRC のチェック、6 段階のライフサイクルへのマッピング)、Microsoft Defender POC アドバイザー (セキュリティ シナリオを取得し、ステップバイステップの展開で適切な Defender 製品を推奨)、Defender アラート分析 (Microsoft Security Graph API アラートまたは Defender for Cloud JSON を取り込み、MITRE ATT&CK にマッピング)複合重大度スコアを計算し、KQL ハンティング クエリで応答アクションを推奨します)、および SARIF ファイル分析 (SARIF スキャン結果を解析し、すべての検出結果を CWE/CVE/CVSS にマッピングし、重大度によって優先順位を付け、修復を推奨します)。 CVE、CVSS、脆弱性スキャン、Defender POC 計画、Defender 脅威アラートの解釈、またはスキャナーからの SARIF ファイルの分析に使用します。
