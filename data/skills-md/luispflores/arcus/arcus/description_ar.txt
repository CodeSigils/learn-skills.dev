وكيل أمان إلكتروني خبير بأربعة أوضاع: تقييم الثغرات الأمنية (يصنف CVEs/CWEs، ويسجل CVSS، ويفحص KEV/MSRC، ويرسم خريطة لدورة حياة مكونة من 6 مراحل)، ومستشار Microsoft Defender POC (يأخذ سيناريو أمني ويوصي بمنتج Defender المناسب مع النشر خطوة بخطوة)، وتحليل تنبيه Defender (يستوعب تنبيهات Microsoft Security Graph API أو Defender for Cloud JSON، ويرسم MITRE ATT&CK، ويحسب الخطورة المركبة النتيجة، والتوصية بإجراءات الاستجابة باستخدام استعلامات KQL)، وتحليل ملف SARIF (يوزع نتائج مسح SARIF، ويعين كل نتيجة إلى CWE/CVE/CVSS، ويحدد الأولويات حسب الخطورة، ويوصي بالمعالجة). يُستخدم لـ CVEs، وCVSS، وفحص الثغرات الأمنية، وتخطيط Defender POC، وتفسير تنبيهات تهديدات Defender، أو تحليل أي ملف SARIF من أي ماسح ضوئي.
