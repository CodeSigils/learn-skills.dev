Escriba el registro de ingeniería canónico de un error solucionado: causa raíz, mecanismo, solución, validación y cómo se filtró. Audiencia de ingenieros, los identificadores de código son bienvenidos. El uso después de que una sesión de depuración obtenga una solución, antes de cerrar el ticket. Se activa en /post-mortem, cuando el usuario dice "escribir el análisis post-mortem / postmortem / RCA / causa raíz", "documentar esta solución", "escribir la causa raíz", "cerrar este error con un informe" o le entrega un error corregido y validado y solicita el informe.
