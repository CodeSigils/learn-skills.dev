قم بتفويض مهام الترميز الوضيعة وواسعة النطاق إلى وكيل فرعي رخيص مدعوم من Qwen عبر الأمر "claude-9arm" بدلاً من حرق رموز/حصص Claude المميزة. يُستخدم عندما يكون العمل ميكانيكيًا ومنخفض المخاطر - عمليات إعادة التسمية المجمعة، أو التنسيق، أو النموذج المعياري، أو البحث عن استبدال، أو البحث والتلخيص بنمط grep، أو قراءة/تكثيف السجلات أو الملفات، أو سقالات الاختبار/سلسلة المستندات/التعليق، أو تشغيل عمليات الإنشاء/النسخ/الاختبارات والإبلاغ عن فشل النجاح. استخدمه أيضًا عندما يقول المستخدم "استخدام qwen"، أو "تفويض هذا"، أو "إرساله إلى 9arm/qwen"، أو "افعل هذا بسعر رخيص". لا تستخدم للهندسة المعمارية أو التصميم أو تصحيح الأخطاء أو التعديلات الحساسة للأمان أو أي شيء يحتاج إلى سياق هذه المحادثة.
