يبقي مهمة Claude Code الطويلة على المسار الصحيح - يكسر التفكير التكراري/الدائري، ويراقب ميزانية السياق، ويحد من التفكير الداخلي، ويطلق عملية تسليم نظيفة قبل أن تمتلئ النافذة. يُستخدم عندما يقوم النموذج بتكرار الخطوات، أو إعادة قراءة نفس الملفات، أو التخمين مرة أخرى في دوائر، أو التوقف أو الدوران، أو تشغيل مهمة طويلة متعددة الخطوات مع مخاطر استنفاد السياق. استخدمه أيضًا عندما يقول المستخدم إنه "يتكرر"، أو "يدور في دوائر"، أو "عالق"، أو "يكرر نفسه"، أو يطلب التسليم قبل نفاد السياق.
