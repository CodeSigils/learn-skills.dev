Utilice esta habilidad para hacer cumplir los estándares en todo el repositorio para el cumplimiento de la cadena de herramientas, la pureza del administrador de paquetes, la seguridad de tipos, las pruebas, la mantenibilidad y la arquitectura. Cuando existe una habilidad más específica para una preocupación como el linting final o la corrección de formato, esa habilidad más específica tiene prioridad sobre la guía generalizada de esta habilidad.
