Reuse-first gate. BEFORE adopting, cloning, or installing any open-source repo or dependency, use this to decide should-I-reuse-this: real GitHub stats + a transparent GO/MAYBE/SKIP verdict, resource-fit for the current machine, and license/freshness signals. Also finds reuse candidates for a need, and summarizes a GitHub user/org's public work as facts. Use whenever the task is "find/evaluate/choose an open-source project", "should I add this dependency", or "build vs. reuse".
