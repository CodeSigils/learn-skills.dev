Puerta de reutilización primero. ANTES de adoptar, clonar o instalar cualquier repositorio o dependencia de código abierto, use esto para decidir si debería reutilizarlo: estadísticas reales de GitHub + un veredicto transparente GO/QUIZÁS/SALTAR, recursos adecuados para la máquina actual y señales de licencia/actualización. También encuentra candidatos de reutilización para una necesidad y resume el trabajo público de un usuario/organización de GitHub como hechos. Úselo siempre que la tarea sea "buscar/evaluar/elegir un proyecto de código abierto", "debería agregar esta dependencia" o "compilar o reutilizar".
