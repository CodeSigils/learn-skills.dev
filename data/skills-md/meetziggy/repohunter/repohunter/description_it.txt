Riutilizzare il primo cancello. PRIMA di adottare, clonare o installare qualsiasi repository o dipendenza open source, usa questo per decidere se dovrei riutilizzarlo: statistiche reali di GitHub + un verdetto GO/MAYBE/SKIP trasparente, idoneità delle risorse per la macchina attuale e segnali di licenza/aggiornamento. Trova anche candidati al riutilizzo per un'esigenza e riassume il lavoro pubblico di un utente/organizzazione GitHub come fatti. Utilizzare ogni volta che l'attività è "trovare/valutare/scegliere un progetto open source", "devo aggiungere questa dipendenza" o "creare o riutilizzare".
