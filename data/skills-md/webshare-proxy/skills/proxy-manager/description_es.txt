Administre los servidores proxy de Webshare a través de la API de Webshare: enumere los servidores proxy activos, descargue la lista de servidores proxy, actualice los grupos rotativos, reemplace los servidores proxy rotos, lea y actualice la configuración del proxy, administre las listas de direcciones IP permitidas, inspeccione los planes de suscripción e inicie un flujo de pago rápido para comprar más servidores proxy. Úselo cuando el usuario quiera trabajar con proxies webshare.io, sin raspado, solo aprovisionamiento y operaciones.
