أضف تسميات محتوى الذكاء الاصطناعي الرسمية للاتحاد الأوروبي (أيقونات الاتحاد الأوروبي لتصنيف المحتوى الناتج عن الذكاء الاصطناعي، المادة 50 من قانون الذكاء الاصطناعي) إلى الصور ومقاطع الفيديو. يُستخدم عندما يطلب المستخدم تصنيف الوسائط أو وضع علامة مائية أو وضع علامة عليها أو وضع شارة عليها على أنها وسائط تم إنشاؤها بواسطة الذكاء الاصطناعي أو تعديلها بواسطة الذكاء الاصطناعي أو تزييف عميق، أو عندما يذكر أيقونات الاتحاد الأوروبي للذكاء الاصطناعي / الكشف عن شفافية قانون الذكاء الاصطناعي، أو يطلب وضع علامة/شارة "الذكاء الاصطناعي" في زاوية الصورة أو لقطة الشاشة أو ملف GIF أو الفيديو.
