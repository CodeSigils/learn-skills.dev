Используйте при выпуске версии репозитория Git — пометка тегами, объединение веток выпуска в основную, разрешение конфликтов или синхронизация изменений между ветками выпуска. Обрабатывает неоднозначные имена тегов (v-префикс или обычный), неизвестную основную ветку (master/main/develop), метод слияния только для ff (принудительно выбирает стратегию вишневого выбора), правила защищенных ветвей, синхронизацию с учетом хеша перекрестных выпусков и очистку дополнительных файлов MR/PR. Одно или несколько репо. Триггеры — 「发版」「打tag」「发布版本」「版本发布」「release流程」「git-release」「multi-repo Release」「release同步到另一个release」 / выпустить версию, пометить и объединить, завершить ветку выпуска.
