Da utilizzare quando si rilascia una versione del repository Git: tagging, unione dei rami di rilascio in quelli principali, risoluzione dei conflitti o sincronizzazione delle modifiche tra i rami di rilascio. Gestisce la denominazione dei tag ambigua (prefisso v vs semplice), ramo principale sconosciuto (master/main/develop), metodo di unione ff-only (forza la strategia cherry-pick), regole del ramo protetto, sincronizzazione sensibile all'hash tra versioni incrociate e pulizia di file extra MR/PR. Repo singolo o multiplo. Trigger — 「发版」「打tag」「发布版本」「版本发布」「release流程」「git-release」「multi-repo release」「release同步到另一个release」 / rilascia una versione, tagga e unisci, termina il ramo di rilascio.
