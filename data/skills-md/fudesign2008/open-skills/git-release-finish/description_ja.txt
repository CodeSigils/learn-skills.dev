Git リポジトリ バージョンをリリースするときに使用します。タグ付け、リリース ブランチをメインにマージ、競合を解決、またはリリース ブランチ間の変更を同期します。あいまいなタグの命名 (v-prefix とプレーン)、不明なメイン ブランチ (master/main/develop)、ff のみのマージ メソッド (チェリーピック戦略を強制)、保護されたブランチ ルール、クロスリリースのハッシュに依存した同期、および MR/PR の余分なファイルのクリーンアップを処理します。単一または複数のリポジトリ。トリガー — 「発行版」「打タグ」「発行版本」「バージョン本発行」「リリース流程」「git-release」「マルチリポリリース」「リリース同步到另一リリース」 / バージョンをリリースし、タグ付けしてマージし、リリースブランチを終了します。
