À utiliser lors de la publication d'une version du référentiel Git : marquage, fusion des branches de version dans la version principale, résolution des conflits ou synchronisation des modifications entre les branches de version. Gère les noms de balises ambigus (préfixe v vs plain), la branche principale inconnue (maître/main/développement), la méthode de fusion ff uniquement (force la stratégie de sélection sélective), les règles de branche protégée, la synchronisation sensible au hachage entre versions et le nettoyage extra-fichier MR/PR. Repo unique ou multiple. Déclencheurs — 「发版」「打tag」「发布版本」「版本发布」「release流程」「git-release」「multi-repo release」「release同步到另一个release」 / publier une version, marquer et fusionner, terminer la branche de publication.
