Переключатель удаленной отладки Unified WebView для проектов Android. `android-webview-debug-enable` устанавливает для всех вызовов `setWebContentsDebuggingEnabled` значение `true` и записывает измененные местоположения с их исходным содержимым; `android-webview-debug-revert` восстанавливает данные из записи, перечисляя в конце все несовпадающие записи для подтверждения вручную. Триггеры: 「开启 WebView」「恢复 WebView 调试」 / android-webview-debug-enable, android-webview-debug-revert. Подходит для проектов Android, которым необходимо единообразно включить или восстановить отладку WebView.
