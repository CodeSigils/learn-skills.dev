Toolkit di debugging del runtime del browser: dai la priorità agli strumenti DevTools e CDP del browser per l'ispezione e il controllo del runtime durante il debug del layout UI/CSS/DOM, dell'interazione frontend e dei problemi di rendering. Canale predefinito: ego-browser (macOS, controllato in fase di esecuzione): interazione completa, js(), cdp() grezzo, stato di accesso ereditato, spazio attività isolato, passaggio uomo-intelligenza artificiale. In caso di indisponibilità o guasto si degrada lungo: playwright-mcp → agent-browser (non macOS); Proxy CDP con accesso web (controllo leggero + stato di accesso, curl-parallelo); chrome-devtools-mcp (pannelli DevTools: stile computerizzato, rete, traccia perf). Trigger: 「浏览器调试」「UI 调试」「DOM 检查」「CSS调试」「页面布局问题」「前端运行时调试」「chrome devtools」「CDP 调试」「登录态调试」 / debug del browser, devtools, dom inspect, debug css, debug runtime, debug dello stato di accesso.
