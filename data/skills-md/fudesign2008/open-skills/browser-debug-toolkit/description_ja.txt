ブラウザ ランタイム デバッグ ツールキット — UI/CSS/DOM レイアウト、フロントエンド インタラクション、レンダリングの問題をデバッグする際に、ランタイム検査と制御のためにブラウザ DevTools と CDP ツールを優先します。デフォルトのチャネル: ego-browser (macOS、ランタイムチェック済み) — 完全なインタラクション、js()、生の cdp()、継承されたログイン状態、分離されたタスクスペース、人間と AI のハンドオフ。利用不能または障害が発生すると、playwright-mcp → エージェントブラウザ (macOS 以外) に沿って機能が低下します。 Web アクセス CDP プロキシ (軽量制御 + ログイン状態、カールパラレル)。 chrome-devtools-mcp (DevTools パネル: 計算されたスタイル、ネットワーク、パフォーマンス トレース)。トリガー: 「浏览器调试」「UI 调试」「DOM 检查」「CSS 调试」「页面布局问题」「フロントエンド运行時間调试」「chrome devtools」「CDP 调试」「登录态调试」 / ブラウザデバッグ、devtools、dom検査、cssデバッグ、ランタイムデバッグ、ログイン状態デバッグ。
