Kit de herramientas de depuración del tiempo de ejecución del navegador: priorice las herramientas DevTools y CDP del navegador para la inspección y el control del tiempo de ejecución al depurar el diseño de UI/CSS/DOM, la interacción del frontend y los problemas de representación. Canal predeterminado: ego-browser (macOS, tiempo de ejecución verificado): interacción completa, js(), cdp() sin formato, estado de inicio de sesión heredado, espacio de tareas aislado, transferencia entre humanos e IA. En caso de falta de disponibilidad o falla, se degrada junto con: dramaturgo-mcp → agente-navegador (no macOS); Proxy CDP de acceso web (control ligero + estado de inicio de sesión, curl-paralelo); chrome-devtools-mcp (paneles DevTools: estilo calculado, red, seguimiento de rendimiento). Activadores: 「浏览器调试」「UI 调试」「DOM 检查」「CSS调试」「页面布局问题」「前端运行时调试」「chrome devtools」「CDP 调试」「登录态调试」 / depuración del navegador, devtools, dom inspect, depuración de CSS, depuración en tiempo de ejecución, depuración del estado de inicio de sesión.
