مجموعة أدوات تصحيح أخطاء وقت تشغيل المتصفح - قم بإعطاء الأولوية لأدوات DevTools وCDP للمتصفح لفحص وقت التشغيل والتحكم فيه عند تصحيح أخطاء تخطيط UI/CSS/DOM، وتفاعل الواجهة الأمامية، ومشكلات العرض. القناة الافتراضية: متصفح الأنا (macOS، تم التحقق من وقت التشغيل) - التفاعل الكامل، js()، cdp() الخام، حالة تسجيل الدخول الموروثة، مساحة المهام المعزولة، تسليم الإنسان والذكاء الاصطناعي. عند عدم التوفر أو الفشل في التدهور على طول: playwright-mcp → agent-browser (غير نظام التشغيل macOS)؛ وكيل CDP للوصول إلى الويب (تحكم خفيف + حالة تسجيل الدخول، حليقة متوازية)؛ chrome-devtools-mcp (لوحات DevTools: النمط المحسوب والشبكة وتتبع الأداء). المشغلات: واجهة المستخدم UI UI """"""""""""""""""""""""أدوات تطوير Chrome""""""CDP""""/ تصحيح أخطاء المتصفح، أدوات التطوير، فحص dom، تصحيح أخطاء CSS، تصحيح أخطاء وقت التشغيل، تصحيح أخطاء حالة تسجيل الدخول.
