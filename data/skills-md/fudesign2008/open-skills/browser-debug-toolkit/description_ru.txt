Набор инструментов для отладки во время выполнения браузера — отдайте приоритет браузерным DevTools и инструментам CDP для проверки и контроля во время выполнения при отладке макета пользовательского интерфейса/CSS/DOM, взаимодействия с внешним интерфейсом и проблем с рендерингом. Канал по умолчанию: ego-браузер (macOS, проверено во время выполнения) — полное взаимодействие, js(), raw cdp(), унаследованное состояние входа в систему, изолированное пространство задач, передача управления человеком и ИИ. При недоступности или сбое ухудшение происходит по следующему принципу: playwright-mcp → агент-браузер (не для macOS); CDP Proxy с веб-доступом (облегченное управление + состояние входа в систему, параллельная загрузка); chrome-devtools-mcp (панели DevTools: вычисляемый стиль, сеть, трассировка производительности). Триггеры: 「浏览器调试」「UI 调试」「DOM 检查」「CSS调试」「页面布局问题」「前端运行时调试」「chrome devtools」「CDP 调试」「登录态调试」 / отладка браузера, devtools, Проверка dom, отладка CSS, отладка во время выполнения, отладка состояния входа.
