Asegúrese de que el proyecto actual tenga un conjunto de pruebas adecuado: detecte la pila y el marco tecnológico, realice un andamiaje si es necesario, genere pruebas unitarias (obligatorias, solo código lógico) y, opcionalmente, genere/ejecute pruebas E2E. Se activa cuando el usuario dice "test-suite-ensure", 「补全测试」「生成测试」「确保测试」「补充单元测试」「添加单元测试」「检查测试覆盖」 (completar pruebas / generar pruebas / asegurar pruebas / agregar pruebas unitarias / verificar la cobertura de las pruebas). También se puede invocar mediante solve-workflow y opsx-solve-workflow en sus pasos de prueba de la etapa de ejecución.
