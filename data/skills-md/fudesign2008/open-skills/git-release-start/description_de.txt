Wird verwendet, wenn eine Versionsiteration beginnt und ein Release-Zweig erstellt werden muss. Behandelt inkonsistente Zweignamenskonventionen über Repositorys hinweg, synchronisiert die Erstellung mehrerer Repositorys und stellt sicher, dass die lokale Nachverfolgung korrekt auf Ursprung/Release/X.Y.Z und nicht auf den Basiszweig verweist. Funktioniert mit GitLab, GitHub und anderen Git-Hosting-Plattformen; Single-Repo oder Multi-Repo. Auslöser – 「创建release分支」「开release分支」「开分支」「迭代分支」 / Release-Zweig erstellen.
