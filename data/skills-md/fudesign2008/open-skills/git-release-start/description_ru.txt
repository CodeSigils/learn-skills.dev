Используйте, когда начинается итерация версии и необходимо создать ветку выпуска — обрабатывает несогласованные соглашения об именах ветвей в репозиториях, синхронизирует создание нескольких репозиториев и обеспечивает правильное локальное отслеживание, указывающее на источник/выпуск/X.Y.Z, а не на базовую ветку. Работает с GitLab, GitHub и другими хостинговыми платформами Git; одно- или многорепо. Триггеры — 「创建release分支」「开release分支」「开分支」「迭代分支」 / создать ветку выпуска.
