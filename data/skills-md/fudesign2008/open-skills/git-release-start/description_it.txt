Da utilizzare quando inizia l'iterazione di una versione e deve essere creato un ramo di rilascio: gestisce convenzioni di denominazione dei rami incoerenti tra repository, creazione sincronizzata di più repository e garantisce che il tracciamento locale punti correttamente a origin/release/X.Y.Z anziché al ramo di base. Funziona con GitLab, GitHub e altre piattaforme di hosting Git; single-repo o multi-repo. Trigger — 「创建release分支」「开release分支」「开分支」「迭代分支」 / crea ramo di rilascio.
