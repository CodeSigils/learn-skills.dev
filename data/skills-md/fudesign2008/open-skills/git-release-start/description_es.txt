Úselo cuando comienza una iteración de versión y se debe crear una rama de lanzamiento: maneja convenciones de nomenclatura de ramas inconsistentes en todos los repositorios, creación sincronizada de múltiples repositorios y garantiza que el seguimiento local apunte correctamente a origen/lanzamiento/X.Y.Z en lugar de a la rama base. Funciona con GitLab, GitHub y otras plataformas de alojamiento Git; repositorio único o repositorio múltiple. Activadores: 「创建release分支」「开release分支」「开分支」「迭代分支」 / crear rama de lanzamiento.
