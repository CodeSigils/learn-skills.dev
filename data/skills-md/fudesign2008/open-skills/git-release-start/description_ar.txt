يُستخدم عند بدء تكرار الإصدار ويجب إنشاء فرع إصدار - يعالج اصطلاحات تسمية الفروع غير المتسقة عبر عمليات إعادة الشراء، والإنشاء المتزامن متعدد الريبو، ويضمن أن التتبع المحلي يشير بشكل صحيح إلى الأصل/الإصدار/X.Y.Z بدلاً من الفرع الأساسي. يعمل مع GitLab وGitHub ومنصات استضافة Git الأخرى؛ الريبو الفردي أو الريبو المتعدد. المشغلات — 「创建release分支」「开release分支」「开分支」「迭代分支」 / إنشاء فرع الإصدار.
