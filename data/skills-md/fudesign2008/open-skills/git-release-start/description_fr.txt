À utiliser lorsqu'une itération de version démarre et qu'une branche de version doit être créée - gère les conventions de dénomination de branche incohérentes entre les dépôts, la création synchronisée entre plusieurs dépôts et garantit que le suivi local pointe correctement vers l'origine/la version/X.Y.Z plutôt que vers la branche de base. Fonctionne avec GitLab, GitHub et d'autres plateformes d'hébergement Git ; single-repo ou multi-repo. Déclencheurs — 「创建release分支」「开release分支」「开分支」「迭代分支」 / créer une branche de publication.
