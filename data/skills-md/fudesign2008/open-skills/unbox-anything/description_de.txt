Universeller Datei-/Container-Entpacker für KI-Agenten. Verwenden Sie diese Option immer dann, wenn der Benutzer über eine bestimmte benannte Datei verfügt, die heimlich ein Container für andere Dateien ist (ein Installationsprogramm, ein Dokument, ein App-Bundle, ein Disk-Image oder ein beliebiges Archiv) und deren inneren Inhalt extrahieren oder untersuchen möchte – auch wenn er nicht explizit „Unbox“ sagt. Knackt etwa 30 „boxartige“ Formate in saubere Verzeichnisse mit einem Manifest: Standardarchive (zip/tar/7z/rar), ZIP-Container (docx/xlsx/pptx/jar/apk/whl), Systempakete (deb/rpm/msi), Installationsprogramme und Disk-Images (exe/dmg/iso/pkg) und verkettete verschachtelte Container. Plattformübergreifend (Mac/Linux/Windows) über 7z als primäres Tool mit eleganten Fallbacks. Auslöser: 「拆箱」「开箱」「解压文件」「拆包」「解压任意文件」「提取容器内容」「拆开[文件]」「看[文件]里面」 / entpacken, beliebige Datei entpacken, Container extrahieren, was in dieser Datei enthalten ist. NICHT verwenden für: das Schreiben von Extraktionscodes/Skripten, das Erstellen oder Bearbeiten von Office-Dokumenten, das Installieren von Software, das Vergleichen von Archivformaten oder das Zusammenführen von Dateien.
