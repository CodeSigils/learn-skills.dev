Disciplina estricta para el trabajo de cambio de comportamiento: escriba primero una prueba fallida, observe la falla y luego escriba un código de producción mínimo; eliminar el código de producción escrito antes de que se observara una prueba fallida. Distinto de test-suite-ensure (cobertura/andamio post-hoc). Referenciado por etapas de ejecución de PDCA. Desencadenantes: 「测试先行」「先写失败测试」「红绿重构」「TDD 铁律」「test-first」 / disciplina de prueba primero, prueba reprobada primero. NO lo utilice como alias de nombre para tdd o desarrollo basado en pruebas.
