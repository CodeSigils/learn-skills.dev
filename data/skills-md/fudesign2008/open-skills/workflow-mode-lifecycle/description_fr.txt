Contrat de cycle de vie partagé pour les modes manuel/auto dans les compétences de flux de travail de style PDCA : le mode automatique revient toujours au manuel à la fin ou à l'interruption, la rentrée automatique nécessite un déclencheur explicite, la continuation implicite ne le réactive jamais et les orchestrateurs par lots passent le mode explicitement. Référencé par les hôtes PDCA via les dépendances frontmatter ; se charge lorsqu'un hôte délègue ses règles de mode.
