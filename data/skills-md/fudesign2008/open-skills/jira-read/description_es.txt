Lea los datos de problemas de Jira desde la caché local o la API y descargue archivos adjuntos mediante un script (nunca en contexto). Se activa cuando el usuario dice "jira-read [JIRA-ID]", 「读取 Jira」「查看 Jira」「下载 Jira」「下载附件」 (leer/ver/descargar Jira/descargar archivos adjuntos), o necesita recuperar datos de problemas de Jira. Requiere $JIRA_CACHE_DIR (por ejemplo, ~/.cache/jira).
