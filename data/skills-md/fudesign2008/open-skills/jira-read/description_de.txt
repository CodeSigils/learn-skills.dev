Lesen Sie Jira-Problemdaten aus dem lokalen Cache oder der API und laden Sie Anhänge per Skript herunter (nie in den Kontext). Wird ausgelöst, wenn der Benutzer sagt „jira-read [JIRA-ID]“, 「读取 Jira」「查看 Jira」「下载 Jira」「下载附件」 (Jira lesen/anzeigen/herunterladen / Anhänge herunterladen) oder Jira-Problemdaten abrufen muss. Erfordert $JIRA_CACHE_DIR (z. B. ~/.cache/jira).
