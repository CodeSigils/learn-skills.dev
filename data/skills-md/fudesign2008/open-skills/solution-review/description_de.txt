Maßgebliches Framework zur Überprüfung aller vorgeschlagenen Lösungen (Code, Konfiguration, Prozess, Tool oder Architekturentscheidung) vor der Implementierung. Deckt vier Kerndimensionen ab (Wirksamkeit, Nebenwirkungen/Risiken, Durchführbarkeit, Spezifikationskonformität) sowie fünf strategische Dimensionen, die Fehler auf Entscheidungsebene erfassen, die die vier Kernfunktionen übersehen: Reversibilitätskalibrierung (Ein-/Zwei-Wege-Türen von Bezos), Fehlermodusanalyse (FMEA), Bedienbarkeit (SRE Production Readiness Review), Kosten-Wert-Verhältnis (CBAM/WSJF) und kognitive Eignung des Teams (Team-Topologien). Nutzen Sie diese Fähigkeit immer dann, wenn Sie eine vorgeschlagene Lösung, einen Plan, ein Entwurfsdokument oder einen Ansatz prüfen, validieren, einem Stresstest unterziehen oder genehmigen müssen – bevor Code geschrieben oder eine Änderung vorgenommen wird.
