Utiliza las CRD de políticas propias de Calico más allá de la API de Kubernetes ascendente (GlobalNetworkPolicy, HostEndpoint, NetworkSet, niveles de políticas y reglas de salida basadas en DNS) aplicadas y auditadas con calicoctl. Úselo cuando una política deba abarcar espacios de nombres o proteger el propio host, cuando la salida deba expresarse por nombre de dominio o cuando ordene políticas en niveles. Palabras clave: calicoctl, GlobalNetworkPolicy, HostEndpoint, NetworkSet, nivel, salida DNS, orden. No lo use para NetworkPolicy ascendente portátil; use implementing-network-policies-for-kubernetes; para instalar Calico y escribir una política estándar con él, utilice implementar-kubernetes-network-policy-with-calico.
