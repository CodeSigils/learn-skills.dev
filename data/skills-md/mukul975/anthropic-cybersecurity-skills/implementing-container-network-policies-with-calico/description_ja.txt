アップストリームの Kubernetes API (GlobalNetworkPolicy、HostEndpoint、NetworkSet、ポリシー層、DNS ベースの出力ルール) を超えた Calico 独自のポリシー CRD を使用し、calicoctl で適用および監査されます。ポリシーが名前空間にまたがる場合やホスト自体を保護する必要がある場合、出力をドメイン名で表現する必要がある場合、またはポリシーを階層化する場合に使用します。キーワード: calicoctl、GlobalNetworkPolicy、HostEndpoint、NetworkSet、層、DNS エグレス、順序。ポータブルなアップストリーム NetworkPolicy には使用しないでください。implementing-network-policies-for-kubernetes を使用してください。 Calico をインストールし、それを使用して標準ポリシーを作成するには、implementing-kubernetes-network-policy-with-calico を使用します。
