Использует собственные CRD политики Calico, выходящие за пределы вышестоящего API Kubernetes — GlobalNetworkPolicy, HostEndpoint, NetworkSet, уровни политики и правила выхода на основе DNS — применяемые и проверяемые с помощью Calicoctl. Используйте, когда политика должна охватывать пространства имен или защищать сам хост, когда выход должен быть выражен именем домена или при упорядочивании политик по уровням. Ключевые слова: Calicoctl, GlobalNetworkPolicy, HostEndpoint, NetworkSet, уровень, выход DNS, порядок. Не используйте для переносимого вышестоящего NetworkPolicy — используйтеimplementation-network-policy-for-kubernetes; для установки Calico и написания стандартной политики с его помощью используйтеimplementation-kubernetes-network-policy-with-calico.
