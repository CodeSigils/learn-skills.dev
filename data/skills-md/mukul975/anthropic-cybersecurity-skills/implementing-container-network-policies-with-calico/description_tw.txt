使用 Calico 自己的策略 CRD，超越上游 Kubernetes API - GlobalNetworkPolicy、HostEndpoint、NetworkSet、策略層和基於 DNS 的出口規則 - 使用 calicoctl 應用和審核。當策略必須跨越命名空間或保護主機本身時、當出口必須以網域表示時或當將策略排序到層時使用。關鍵字：calicoctl、GlobalNetworkPolicy、HostEndpoint、NetworkSet、層、DNS 出口、順序。不要用於可移植的上游 NetworkPolicy - 使用implementation-network-policies-for-kubernetes；要安裝 Calico 並用它編寫標準策略，請使用 Implementing-kubernetes-network-policy-with-calico。
