使用 Calico 自己的策略 CRD，超越上游 Kubernetes API - GlobalNetworkPolicy、HostEndpoint、NetworkSet、策略層和基於 DNS 的出口規則 - 使用 calicoctl 應用和審核。当策略必须跨越命名空间或保护主机本身时、当出口必须用域名表示时或当将策略排序到层时使用。关键词：calicoctl、GlobalNetworkPolicy、HostEndpoint、NetworkSet、层、DNS 出口、顺序。不要用於可移植的上游 NetworkPolicy - 使用implementation-network-policies-for-kubernetes；要安裝 Calico 並用它編寫標準策略，請使用 Implementing-kubernetes-network-policy-with-calico。
