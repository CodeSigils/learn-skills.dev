Analyse les profils C2 malléables Cobalt Strike à l'aide de pyMalleableC2 pour extraire la configuration des balises, les modèles de communication HTTP et les paramètres de veille/gigue. Se combine avec les empreintes digitales JARM TLS pour détecter les serveurs C2 sur le réseau. À utiliser lors de l'enquête sur une infrastructure suspectée de Cobalt Strike ou lors de la création de signatures de détection pour le trafic C2.
