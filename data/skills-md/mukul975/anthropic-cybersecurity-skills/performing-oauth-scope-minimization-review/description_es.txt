Realiza una revisión de minimización del alcance de OAuth 2.0 para identificar integraciones de aplicaciones de terceros con permisos excesivos, alcances de API excesivos, concesiones de tokens no utilizados y patrones de consentimiento de OAuth riesgosos entre proveedores de identidad y plataformas SaaS. Se activa para solicitudes que involucran auditoría del alcance de OAuth, revisión de permisos de API, evaluación de riesgos de aplicaciones de terceros o minimización de concesión de consentimiento.
