Этот навык инструктирует специалистов по безопасности по развертыванию Microsoft Defender для облака в качестве облачной платформы защиты приложений для Azure, мультиоблачных и гибридных сред. Он охватывает включение планов Defender для серверов, контейнеров, хранилищ и баз данных, настройку рекомендаций по безопасности, управление показателем безопасности и интеграцию с единым порталом Defender для централизованного управления угрозами.
