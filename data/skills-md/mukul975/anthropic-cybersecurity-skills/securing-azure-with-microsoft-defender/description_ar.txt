تُرشد هذه المهارة ممارسي الأمان إلى كيفية نشر Microsoft Defender for Cloud كنظام أساسي لحماية التطبيقات السحابية الأصلية لبيئات Azure والبيئات السحابية المتعددة والمختلطة. ويغطي تمكين خطط Defender للخوادم والحاويات والتخزين وقواعد البيانات، وتكوين توصيات الأمان، وإدارة Secure Score، والتكامل مع بوابة Defender الموحدة لإدارة التهديدات المركزية.
