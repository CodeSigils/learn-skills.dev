Esta habilidad instruye a los profesionales de la seguridad sobre la implementación de Microsoft Defender para la nube como una plataforma de protección de aplicaciones nativa de la nube para entornos Azure, multinube e híbridos. Cubre la habilitación de planes de Defender para servidores, contenedores, almacenamiento y bases de datos, la configuración de recomendaciones de seguridad, la gestión de Secure Score y la integración con el portal unificado de Defender para la gestión centralizada de amenazas.
