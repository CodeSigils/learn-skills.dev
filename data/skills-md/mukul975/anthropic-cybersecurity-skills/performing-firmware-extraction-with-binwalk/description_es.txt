Realiza extracción y análisis de imágenes de firmware utilizando binwalk para identificar sistemas de archivos integrados, archivos comprimidos, cargadores de arranque, imágenes del kernel y material criptográfico. Cubre el análisis de entropía para detectar regiones cifradas o comprimidas, la extracción recursiva de archivos anidados, el montaje del sistema de archivos SquashFS/CramFS/JFFS2 y el análisis de cadenas para el descubrimiento de credenciales y configuraciones. Se activa para solicitudes que involucran ingeniería inversa de firmware, análisis de dispositivos IoT, evaluación de seguridad del sistema integrado o extracción de firmware de enrutador/cámara.
