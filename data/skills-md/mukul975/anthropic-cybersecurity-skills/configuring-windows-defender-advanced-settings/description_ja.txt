攻撃対象領域削減ルール、制御されたフォルダー アクセス、ネットワーク保護、エクスプロイト保護など、Microsoft Defender for Endpoint (MDE) の高度な保護設定を構成します。デフォルトの Defender 設定を超えて Windows エンドポイントを強化する場合、エンタープライズ グレードのエンドポイント保護を展開する場合、または高度なマルウェア防御のコンプライアンス要件を満たす場合に使用します。 Windows Defender 構成、ASR ルール、MDE チューニング、または Microsoft エンドポイント セキュリティに関連する要求に対してアクティブ化されます。
