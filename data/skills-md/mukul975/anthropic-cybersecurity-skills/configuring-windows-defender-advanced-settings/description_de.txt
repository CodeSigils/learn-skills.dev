Konfiguriert die erweiterten Schutzeinstellungen von Microsoft Defender für Endpoint (MDE), einschließlich Regeln zur Reduzierung der Angriffsfläche, kontrollierten Ordnerzugriff, Netzwerkschutz und Exploit-Schutz. Verwenden Sie diese Option, wenn Sie Windows-Endpunkte über die standardmäßigen Defender-Einstellungen hinaus härten, einen Endpunktschutz der Enterprise-Klasse bereitstellen oder Compliance-Anforderungen für eine erweiterte Malware-Abwehr erfüllen. Wird für Anfragen aktiviert, die die Windows Defender-Konfiguration, ASR-Regeln, MDE-Optimierung oder Microsoft-Endpunktsicherheit betreffen.
