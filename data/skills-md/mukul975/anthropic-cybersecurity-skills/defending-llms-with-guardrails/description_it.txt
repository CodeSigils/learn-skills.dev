Distribuisce la classificazione di sicurezza Llama Guard 3, i binari di dialogo programmabili di NeMo Guardrails e le pipeline di scanner di input/output LLM Guard come difese runtime complementari che ispezionano e vincolano i prompt e le risposte LLM. Da utilizzare quando si aggiunge un livello di sicurezza del runtime di produzione a un'applicazione LLM, RAG o agente per bloccare jailbreak, prompt injection (OWASP LLM01), contenuto tossico o perdita di dati sensibili prima che raggiunga o lasci il modello.
