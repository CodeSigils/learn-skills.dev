ينشر تصنيف الأمان Llama Guard 3، وقضبان الحوار القابلة للبرمجة NeMo Guardrails، وخطوط أنابيب الماسح الضوئي للإدخال/الإخراج LLM Guard كدفاعات تكميلية في وقت التشغيل تعمل على فحص مطالبات واستجابات LLM وتقييدها. يُستخدم عند إضافة طبقة أمان وقت التشغيل للإنتاج إلى تطبيق LLM أو RAG أو وكيل لمنع عمليات كسر الحماية أو الحقن الفوري (OWASP LLM01) أو المحتوى السام أو تسرب البيانات الحساسة قبل وصول النموذج أو مغادرته.
