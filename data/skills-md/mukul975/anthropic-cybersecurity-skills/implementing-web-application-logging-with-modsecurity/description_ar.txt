قم بتكوين ModSecurity WAF باستخدام مجموعة قواعد OWASP الأساسية (CRS) لتسجيل تدقيق تطبيقات الويب، وضبط مستويات جنون العظمة SecRuleEngine، وSecAuditEngine، وCRS لتقليل الإيجابيات الكاذبة، وكتابة SecRules مخصصة للتهديدات الخاصة بالتطبيقات. يُستخدم عند نشر ModSecurity WAF أو ضبطه، أو تحليل سجلات التدقيق لاكتشاف الهجوم، أو تقليل النتائج الإيجابية الخاطئة لـ CRS.
