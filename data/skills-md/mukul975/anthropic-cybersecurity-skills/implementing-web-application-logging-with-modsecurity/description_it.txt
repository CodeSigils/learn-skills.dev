Configura ModSecurity WAF con OWASP Core Rule Set (CRS) per la registrazione di audit delle applicazioni Web, l'ottimizzazione dei livelli di paranoia SecRuleEngine, SecAuditEngine e CRS per ridurre i falsi positivi e la scrittura di SecRules personalizzate per minacce specifiche dell'applicazione. Da utilizzare durante la distribuzione o l'ottimizzazione di un WAF ModSecurity, l'analisi dei log di controllo per il rilevamento degli attacchi o la riduzione dei falsi positivi CRS.
