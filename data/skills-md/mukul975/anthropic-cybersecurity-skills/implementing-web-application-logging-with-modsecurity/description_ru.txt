Настройте ModSecurity WAF с помощью основного набора правил OWASP (CRS) для ведения журнала аудита веб-приложений, настройки уровней паранойи SecRuleEngine, SecAuditEngine и CRS для уменьшения ложных срабатываний и написания пользовательских SecRules для угроз, специфичных для приложения. Используйте при развертывании или настройке ModSecurity WAF, анализе журналов аудита на предмет обнаружения атак или уменьшении количества ложных срабатываний CRS.
