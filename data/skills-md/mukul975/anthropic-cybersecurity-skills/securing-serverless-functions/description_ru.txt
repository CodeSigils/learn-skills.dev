Этот навык охватывает усиление безопасности для бессерверных вычислительных платформ, включая AWS Lambda, функции Azure и облачные функции Google. Он касается ролей IAM с наименьшими привилегиями, сканирования уязвимостей зависимостей, интеграции управления секретами, проверки входных данных, аутентификации URL-адресов функций и мониторинга во время выполнения для защиты от атак путем внедрения, кражи учетных данных и взлома цепочки поставок.
