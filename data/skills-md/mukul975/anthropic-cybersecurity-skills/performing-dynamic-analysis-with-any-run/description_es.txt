Realiza análisis interactivos y dinámicos de malware utilizando el entorno aislado en la nube ANY.RUN para observar el comportamiento de ejecución en tiempo real, interactuar con indicaciones de malware y capturar árboles de procesos, tráfico de red y cambios en el sistema. Se activa para solicitudes que involucran análisis interactivo de sandbox, detonación de malware basado en la nube, observación del comportamiento en tiempo real o uso de ANY.RUN.
