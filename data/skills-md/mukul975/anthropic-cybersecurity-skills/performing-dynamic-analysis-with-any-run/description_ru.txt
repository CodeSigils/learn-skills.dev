Выполняет интерактивный динамический анализ вредоносных программ с использованием облачной песочницы ANY.RUN для наблюдения за поведением выполнения в реальном времени, взаимодействия с подсказками вредоносных программ и сбора данных о деревьях процессов, сетевом трафике и системных изменениях. Активируется для запросов, включающих интерактивный анализ в песочнице, детонацию вредоносного ПО в облаке, наблюдение за поведением в реальном времени или использование ANY.RUN.
