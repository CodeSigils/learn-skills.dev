أتمتة إثراء المؤشرات الأولية للتسوية مع سياق معلومات التهديدات متعددة المصادر باستخدام منصات SOAR أو خطوط أنابيب Python أو أدلة تشغيل TIP لتقليل وقت فرز المحللين وتوحيد مخرجات الإثراء. يُستخدم عند إنشاء مسارات عمل مؤتمتة مدمجة مع تنبيهات SIEM، أو مسارات إرسال البريد الإلكتروني، أو معالجة IOC المجمعة من خلاصات التهديدات. يتم التنشيط للطلبات التي تتضمن إثراء SOAR، أو Cortex XSOAR، أو Splunk SOAR، أو TheHive، أو خطوط أنابيب إثراء Python، أو معالجة IOC الآلية.
