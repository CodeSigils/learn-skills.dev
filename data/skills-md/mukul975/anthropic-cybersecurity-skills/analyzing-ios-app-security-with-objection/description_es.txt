Realiza una exploración de seguridad móvil en tiempo de ejecución de aplicaciones iOS utilizando Objection, un conjunto de herramientas desarrollado por Frida que permite a los evaluadores de seguridad interactuar con las partes internas de las aplicaciones sin hacer jailbreak. Úselo al evaluar la situación de seguridad de las aplicaciones iOS, eludir las protecciones del lado del cliente, desechar elementos del llavero, inspeccionar el almacenamiento del sistema de archivos y evaluar el comportamiento del tiempo de ejecución. Se activa para solicitudes que involucran pruebas de seguridad de iOS, análisis de tiempo de ejecución de objeciones, evaluación de iOS basada en Frida o exploración de tiempo de ejecución móvil.
