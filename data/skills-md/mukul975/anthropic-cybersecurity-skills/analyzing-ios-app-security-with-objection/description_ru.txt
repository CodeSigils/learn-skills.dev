Выполняет исследование мобильной безопасности приложений iOS во время выполнения с помощью Objection, набора инструментов на базе Frida, который позволяет тестировщикам безопасности взаимодействовать с внутренними компонентами приложений без взлома. Используйте при оценке состояния безопасности приложений iOS, обходе защиты на стороне клиента, выгрузке элементов связки ключей, проверке хранилища файловой системы и оценке поведения во время выполнения. Активируется для запросов, связанных с тестированием безопасности iOS, анализом времени выполнения Objection, оценкой iOS на основе Frida или исследованием среды выполнения мобильных устройств.
