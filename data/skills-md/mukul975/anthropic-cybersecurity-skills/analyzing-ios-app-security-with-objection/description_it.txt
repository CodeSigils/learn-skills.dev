Esegue l'esplorazione runtime della sicurezza mobile delle applicazioni iOS utilizzando Objection, un toolkit basato su Frida che consente ai tester della sicurezza di interagire con gli interni delle app senza jailbreak. Da utilizzare per valutare il livello di sicurezza delle app iOS, aggirare le protezioni lato client, scaricare elementi portachiavi, ispezionare l'archiviazione del file system e valutare il comportamento di runtime. Si attiva per richieste che coinvolgono test di sicurezza iOS, analisi runtime di obiezione, valutazione iOS basata su Frida o esplorazione runtime mobile.
