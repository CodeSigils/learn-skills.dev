Implemente gestión de acceso privilegiado para sistemas de bases de datos, incluidos Oracle, SQL Server, PostgreSQL y MySQL, que abarque la configuración de proxy de sesión, almacenamiento de credenciales, auditoría de consultas, generación dinámica de credenciales y roles de bases de datos con privilegios mínimos. Úselo para proteger el acceso al DBA, implementar controles PAM de la base de datos o auditar sesiones de bases de datos privilegiadas.
