Déployez la gestion des accès privilégiés pour les systèmes de bases de données, notamment Oracle, SQL Server, PostgreSQL et MySQL, couvrant la configuration du proxy de session, la sauvegarde des informations d'identification, l'audit des requêtes, la génération dynamique des informations d'identification et les rôles de base de données avec moindre privilège. À utiliser pour sécuriser l'accès DBA, implémenter des contrôles PAM de base de données ou auditer des sessions de base de données privilégiées.
