انشر إدارة الوصول المميز لأنظمة قواعد البيانات بما في ذلك Oracle وSQL Server وPostgreSQL وMySQL، والتي تغطي تكوين وكيل الجلسة وتخزين بيانات الاعتماد وتدقيق الاستعلامات وإنشاء بيانات الاعتماد الديناميكية وأدوار قاعدة البيانات ذات الامتيازات الأقل. يُستخدم عند تأمين الوصول إلى DBA، أو تنفيذ عناصر تحكم PAM في قاعدة البيانات، أو تدقيق جلسات قاعدة البيانات ذات الامتيازات.
