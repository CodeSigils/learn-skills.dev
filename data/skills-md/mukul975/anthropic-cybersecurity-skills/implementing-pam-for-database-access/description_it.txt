Distribuisci la gestione degli accessi privilegiati per sistemi di database tra cui Oracle, SQL Server, PostgreSQL e MySQL, coprendo la configurazione del proxy di sessione, l'archivio delle credenziali, il controllo delle query, la generazione di credenziali dinamiche e i ruoli del database con privilegi minimi. Da utilizzare per proteggere l'accesso DBA, implementare controlli PAM del database o controllare sessioni di database privilegiate.
