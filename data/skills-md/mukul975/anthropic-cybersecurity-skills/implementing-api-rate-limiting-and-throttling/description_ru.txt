Реализует ограничение и регулирование скорости API с использованием алгоритмов ведра токенов, скользящего окна и фиксированного окна для защиты от атак методом перебора, заполнения учетных данных, истощения ресурсов и злоупотребления API. Инженер настраивает ограничения скорости для каждого пользователя, IP-адреса и конечной точки с помощью счетчиков на базе Redis, подключаемых модулей шлюза API или промежуточного программного обеспечения приложений, а также реализует правильные ответы HTTP 429 с заголовками Retry-After. Активируется для запросов, включающих реализацию ограничения скорости, настройку регулирования API, управление квотами запросов или предотвращение злоупотреблений API.
