Implementiert API-Ratenbegrenzungs- und Drosselungskontrollen mithilfe von Token-Bucket-, Sliding-Window- und Fixed-Window-Algorithmen zum Schutz vor Brute-Force-Angriffen, Credential Stuffing, Ressourcenerschöpfung und API-Missbrauch. Der Techniker konfiguriert die Ratenbegrenzungen pro Benutzer, pro IP und pro Endpunkt mithilfe von Redis-gestützten Zählern, API-Gateway-Plugins oder Anwendungs-Middleware und implementiert ordnungsgemäße HTTP 429-Antworten mit Retry-After-Headern. Wird für Anfragen aktiviert, die die Implementierung einer Ratenbegrenzung, die Einrichtung der API-Drosselung, die Verwaltung von Anforderungskontingenten oder die Verhinderung von API-Missbrauch betreffen.
