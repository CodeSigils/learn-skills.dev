ينفذ الحد من معدل واجهة برمجة التطبيقات (API) وعناصر التحكم في الاختناق باستخدام مجموعة الرمز المميز، والنافذة المنزلقة، وخوارزميات النافذة الثابتة للحماية من هجمات القوة الغاشمة، وحشو بيانات الاعتماد، واستنفاد الموارد، وإساءة استخدام واجهة برمجة التطبيقات (API). يقوم المهندس بتكوين حدود المعدل لكل مستخدم، ولكل IP، ولكل نقطة نهاية باستخدام العدادات المدعومة من Redis، أو المكونات الإضافية لبوابة API، أو البرامج الوسيطة للتطبيق، وتنفيذ استجابات HTTP 429 المناسبة مع رؤوس إعادة المحاولة بعد. يتم التنشيط للطلبات التي تتضمن تنفيذ تحديد المعدل، أو إعداد تقييد واجهة برمجة التطبيقات، أو إدارة حصة الطلب، أو منع إساءة استخدام واجهة برمجة التطبيقات.
