Развертывает Honeytoken на основе обмана в Active Directory, включая поддельные привилегированные учетные записи с AdminCount=1, поддельные имена SPN для обнаружения Kerberoasting (обжаривание меда), обманные объекты групповой политики с помощью ловушек cpassword и поддельные пути BloodHound. Отслеживает идентификаторы событий безопасности Windows 4769, 4625, 4662, 5136 на предмет взаимодействия с HoneyToken. Используйте при реализации защиты от обмана AD для обнаружения бокового движения, кражи учетных данных и разведки.
