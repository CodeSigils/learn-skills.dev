Realiza evaluaciones de escalada de privilegios en sistemas Linux y Windows comprometidos para identificar rutas desde el acceso con bajos privilegios al control raíz o a nivel de SISTEMA. El evaluador enumera configuraciones erróneas, servicios vulnerables, vulnerabilidades del kernel, archivos binarios SUID, rutas de servicios sin comillas y almacenes de credenciales para demostrar el impacto total de un compromiso inicial. Se activa para solicitudes que involucran pruebas de escalada de privilegios, explotación local, escalada posterior al compromiso o evaluación de seguridad a nivel del sistema operativo.
