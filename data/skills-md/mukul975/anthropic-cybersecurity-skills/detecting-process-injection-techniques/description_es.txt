Detecta y analiza las técnicas de inyección de procesos utilizadas por el malware, incluida la inyección clásica de DLL, el vaciado de procesos, la inyección de APC, el secuestro de subprocesos y la carga reflectante. Utiliza análisis forense de memoria, monitoreo de API y análisis de comportamiento para identificar artefactos de inyección. Se activa para solicitudes que involucran detección de inyección de procesos, análisis de inyección de código, investigación de procesos vacíos o detección de amenazas en memoria.
