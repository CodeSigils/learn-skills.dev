Обнаруживает и анализирует методы внедрения процессов, используемые вредоносным ПО, включая классическое внедрение DLL, удаление процессов, внедрение APC, перехват потоков и отражающую загрузку. Использует экспертизу памяти, мониторинг API и поведенческий анализ для выявления артефактов внедрения. Активируется для запросов, включающих обнаружение внедрения процесса, анализ внедрения кода, исследование пустого процесса или обнаружение угроз в памяти.
