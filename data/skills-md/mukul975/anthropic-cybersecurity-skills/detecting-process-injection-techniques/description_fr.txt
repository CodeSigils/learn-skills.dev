Détecte et analyse les techniques d'injection de processus utilisées par les logiciels malveillants, notamment l'injection classique de DLL, le creusement de processus, l'injection APC, le détournement de threads et le chargement réfléchissant. Utilise l'investigation de la mémoire, la surveillance des API et l'analyse comportementale pour identifier les artefacts d'injection. S'active pour les requêtes impliquant une détection d'injection de processus, une analyse d'injection de code, une enquête sur un processus creux ou une détection de menace en mémoire.
