Implementa observabilidad del tiempo de ejecución basada en eBPF y aplicación en el kernel en Kubernetes con Cilium Tetragon, monitoreando la ejecución del proceso, el acceso a archivos, las conexiones de red y las llamadas al sistema, y ​​bloqueando llamadas peligrosas a nivel del kernel. Úselo al implementar Tetragon para detectar o bloquear llamadas al sistema como ptrace, mount y unshare, aplicar políticas a nivel de kernel o agregar detección de tiempo de ejecución de baja sobrecarga a un clúster. Palabras clave: Tetragon, Cilium, eBPF, TracingPolicy, kprobe, aplicación, linaje de procesos. No lo use para la detección basada en Falco; use la detección de amenazas en tiempo de ejecución de contenedor con falco.
