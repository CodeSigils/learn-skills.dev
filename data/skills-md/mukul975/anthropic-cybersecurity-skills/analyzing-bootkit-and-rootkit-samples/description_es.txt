Analiza el malware de bootkit y rootkit avanzado que infecta el Master Boot Record (MBR), el Volume Boot Record (VBR) o el firmware UEFI para ganar persistencia bajo el sistema operativo. Cubre el análisis del sector de arranque, la inspección del módulo UEFI y técnicas de detección anti-rootkit. Se activa para solicitudes que involucran análisis de bootkit, investigación de malware MBR, análisis de persistencia UEFI o detección de malware previo al sistema operativo.
