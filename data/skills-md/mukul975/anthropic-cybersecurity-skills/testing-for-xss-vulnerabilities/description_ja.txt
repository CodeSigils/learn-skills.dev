反映、保存された DOM ベースのコンテキストに JavaScript ペイロードを挿入して、クライアント側のコード実行、セッション ハイジャック、およびユーザーの偽装を実証することにより、Web アプリケーションのクロスサイト スクリプティング (XSS) 脆弱性をテストします。テスターはすべての注入ポイントと出力コンテキストを識別し、コンテキストに適したペイロードを作成し、サニタイズと CSP 保護をバイパスします。 XSS テスト、クロスサイト スクリプティング評価、クライアント側インジェクション テスト、または JavaScript インジェクション脆弱性テストを含むリクエストに対してアクティブ化されます。
