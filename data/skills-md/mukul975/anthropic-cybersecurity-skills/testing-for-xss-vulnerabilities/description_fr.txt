Teste les applications Web pour les vulnérabilités de Cross-Site Scripting (XSS) en injectant des charges utiles JavaScript dans des contextes réfléchis, stockés et basés sur DOM pour démontrer l'exécution de code côté client, le piratage de session et l'usurpation d'identité d'utilisateur. Le testeur identifie tous les points d'injection et contextes de sortie, crée des charges utiles adaptées au contexte et contourne la désinfection et les protections CSP. S'active pour les demandes impliquant des tests XSS, une évaluation de scripts intersites, des tests d'injection côté client ou des tests de vulnérabilité d'injection JavaScript.
