Prueba aplicaciones web para detectar vulnerabilidades de secuencias de comandos entre sitios (XSS) inyectando cargas útiles de JavaScript en contextos reflejados, almacenados y basados ​​en DOM para demostrar la ejecución de código del lado del cliente, el secuestro de sesiones y la suplantación de usuarios. El probador identifica todos los puntos de inyección y contextos de salida, crea cargas útiles apropiadas para el contexto y evita la desinfección y las protecciones de CSP. Se activa para solicitudes que involucran pruebas XSS, evaluación de secuencias de comandos entre sitios, pruebas de inyección del lado del cliente o pruebas de vulnerabilidad de inyección de JavaScript.
