Testa le applicazioni Web per le vulnerabilità Cross-Site Scripting (XSS) inserendo payload JavaScript in contesti riflessi, archiviati e basati su DOM per dimostrare l'esecuzione del codice lato client, il dirottamento della sessione e la rappresentazione dell'utente. Il tester identifica tutti i punti di iniezione e i contesti di output, crea payload adeguati al contesto e ignora la sanificazione e le protezioni CSP. Si attiva per richieste che coinvolgono test XSS, valutazione di scripting cross-site, test di injection lato client o test di vulnerabilità di injection JavaScript.
