Diese Fähigkeit umfasst die Absicherung von GitHub Actions-Workflows gegen Angriffe auf die Lieferkette, Diebstahl von Anmeldeinformationen und Rechteausweitung. Es befasst sich mit dem Anheften von Aktionen an SHA-Digests, der Minimierung von GITHUB_TOKEN-Berechtigungen, dem Schutz von Geheimnissen vor Exfiltration, der Verhinderung der Skriptinjektion in Workflow-Ausdrücken und der Implementierung erforderlicher Prüfer für Workflow-Änderungen.
