Этот навык охватывает усиление защиты рабочих процессов GitHub Actions от атак в цепочке поставок, кражи учетных данных и повышения привилегий. Он касается закрепления действий в дайджестах SHA, минимизации разрешений GITHUB_TOKEN, защиты секретов от эксфильтрации, предотвращения внедрения сценариев в выражения рабочего процесса и внедрения необходимых рецензентов для изменений рабочего процесса.
