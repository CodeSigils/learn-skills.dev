تغطي هذه المهارة تقوية سير عمل GitHub Actions ضد هجمات سلسلة التوريد، وسرقة بيانات الاعتماد، وتصعيد الامتيازات. فهو يعالج تثبيت الإجراءات في ملخصات SHA، وتقليل أذونات GITHUB_TOKEN، وحماية الأسرار من التسلل، ومنع إدخال البرنامج النصي في تعبيرات سير العمل، وتنفيذ المراجعين المطلوبين لتغييرات سير العمل.
