Questa competenza copre il rafforzamento dei flussi di lavoro di GitHub Actions contro attacchi alla catena di fornitura, furto di credenziali ed escalation di privilegi. Risolve le azioni di aggiunta di azioni ai digest SHA, riducendo al minimo le autorizzazioni GITHUB_TOKEN, proteggendo i segreti dall'esfiltrazione, impedendo l'inserimento di script nelle espressioni del flusso di lavoro e implementando i revisori richiesti per le modifiche del flusso di lavoro.
