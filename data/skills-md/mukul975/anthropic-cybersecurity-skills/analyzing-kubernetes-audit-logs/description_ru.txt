Анализирует журналы аудита сервера Kubernetes API (строки JSON) для обнаружения exec-into-pod, секретного доступа, модификаций RBAC, создания привилегированных модулей и анонимного доступа к API. Создает правила обнаружения угроз на основе шаблонов событий аудита. Используйте при расследовании компрометации кластера Kubernetes или создании правил обнаружения SIEM для k8s.
