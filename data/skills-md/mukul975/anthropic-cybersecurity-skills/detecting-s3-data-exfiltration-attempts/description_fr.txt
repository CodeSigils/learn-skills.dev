Détection des tentatives d'exfiltration de données à partir des compartiments AWS S3 en analysant les événements de données CloudTrail S3, les journaux de flux VPC, les résultats GuardDuty, les alertes Amazon Macie et les modèles d'accès S3 pour identifier les téléchargements groupés non autorisés et les transferts de données entre comptes.
