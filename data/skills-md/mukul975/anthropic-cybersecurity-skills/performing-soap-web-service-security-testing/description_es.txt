Realiza pruebas de seguridad de los servicios web SOAP mediante el análisis de definiciones WSDL y pruebas de inyección XML, XXE, omisión de WS-Security, suplantación de SOAPAction e inyección XPath. Úselo al evaluar un punto final de API basado en SOAP/WSDL para detectar vulnerabilidades relacionadas con XML durante una prueba de penetración.
