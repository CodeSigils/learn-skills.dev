Führt Sicherheitstests von SOAP-Webdiensten durch, indem WSDL-Definitionen analysiert und auf XML-Injection, XXE, WS-Security-Bypass, SOAPAction-Spoofing und XPath-Injection getestet werden. Verwenden Sie diese Option, wenn Sie während eines Penetrationstests einen SOAP/WSDL-basierten API-Endpunkt auf XML-bezogene Schwachstellen bewerten.
