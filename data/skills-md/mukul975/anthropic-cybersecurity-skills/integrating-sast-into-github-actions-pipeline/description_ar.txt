تغطي هذه المهارة دمج أدوات اختبار أمان التطبيقات الثابتة (SAST) —CodeQL وSemgrep — في مسارات GitHub Actions CI/CD. وهو يعالج تكوين المسح الآلي للكود عند طلبات السحب والدفع، وضبط القواعد لتقليل النتائج الإيجابية الخاطئة، وتحميل نتائج SARIF إلى GitHub Advanced Security، وإنشاء بوابات الجودة التي تمنع عمليات الدمج عند اكتشاف ثغرات أمنية عالية الخطورة.
