Cette compétence couvre l'intégration des outils de test de sécurité des applications statiques (SAST) (CodeQL et Semgrep) dans les pipelines CI/CD GitHub Actions. Il aborde la configuration de l'analyse automatisée du code sur les demandes d'extraction et les poussées, le réglage des règles pour réduire les faux positifs, le téléchargement des résultats SARIF sur GitHub Advanced Security et l'établissement de portes de qualité qui bloquent les fusions lorsque des vulnérabilités de haute gravité sont détectées.
