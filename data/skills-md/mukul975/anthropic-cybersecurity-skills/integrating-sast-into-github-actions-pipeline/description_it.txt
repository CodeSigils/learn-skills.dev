Questa competenza riguarda l'integrazione degli strumenti SAST (Static Application Security Testing), CodeQL e Semgrep, nelle pipeline CI/CD di GitHub Actions. Riguarda la configurazione della scansione automatizzata del codice su richieste pull e push, l'ottimizzazione delle regole per ridurre i falsi positivi, il caricamento dei risultati SARIF su GitHub Advanced Security e la creazione di controlli di qualità che bloccano le unioni quando vengono rilevate vulnerabilità di elevata gravità.
