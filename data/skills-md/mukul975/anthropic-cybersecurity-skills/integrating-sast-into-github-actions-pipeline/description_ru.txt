Этот навык охватывает интеграцию инструментов статического тестирования безопасности приложений (SAST) — CodeQL и Semgrep — в конвейеры CI/CD GitHub Actions. В нем рассматривается настройка автоматического сканирования кода при запросах на включение и отправке, настройка правил для уменьшения ложных срабатываний, загрузка результатов SARIF в GitHub Advanced Security и установка шлюзов качества, которые блокируют слияния при обнаружении уязвимостей высокой степени серьезности.
