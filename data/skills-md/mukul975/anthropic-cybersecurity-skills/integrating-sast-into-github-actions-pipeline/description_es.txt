Esta habilidad cubre la integración de herramientas de pruebas de seguridad de aplicaciones estáticas (SAST), CodeQL y Semgrep, en canalizaciones de CI/CD de GitHub Actions. Aborda la configuración del escaneo de código automatizado en solicitudes de extracción e inserción, el ajuste de reglas para reducir los falsos positivos, la carga de resultados de SARIF en GitHub Advanced Security y el establecimiento de puertas de calidad que bloquean las fusiones cuando se detectan vulnerabilidades de alta gravedad.
