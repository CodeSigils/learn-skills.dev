Diese Fähigkeit umfasst die Integration von SAST-Tools (Static Application Security Testing) – CodeQL und Semgrep – in GitHub Actions CI/CD-Pipelines. Es befasst sich mit der Konfiguration automatisierter Code-Scans bei Pull-Requests und Pushs, der Optimierung von Regeln zur Reduzierung von Fehlalarmen, dem Hochladen von SARIF-Ergebnissen auf GitHub Advanced Security und der Einrichtung von Qualitätstoren, die Zusammenführungen blockieren, wenn Schwachstellen mit hohem Schweregrad erkannt werden.
