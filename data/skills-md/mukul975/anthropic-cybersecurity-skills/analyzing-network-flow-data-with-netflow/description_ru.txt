Анализ записей NetFlow v9 и IPFIX для обнаружения объемных аномалий, сканирования портов, утечки данных и шаблонов маяков C2. Использует библиотеку Python netflow для декодирования записей потоков, построения базовых показателей трафика и применения статистического анализа для выявления потоков с аномальным количеством байтов, длительностью соединения и периодическими шаблонами синхронизации.
