Analice registros NetFlow v9 e IPFIX para detectar anomalías volumétricas, escaneo de puertos, exfiltración de datos y patrones de baliza C2. Utiliza la biblioteca netflow de Python para decodificar registros de flujo, crea líneas de base de tráfico y aplica análisis estadístico para identificar flujos con recuentos de bytes anormales, duraciones de conexión y patrones de sincronización periódicos.
