Analysez les enregistrements NetFlow v9 et IPFIX pour détecter les anomalies volumétriques, l'analyse des ports, l'exfiltration de données et les modèles de balisage C2. Utilise la bibliothèque Python netflow pour décoder les enregistrements de flux, crée des lignes de base de trafic et applique une analyse statistique pour identifier les flux présentant un nombre d'octets, des durées de connexion et des modèles de synchronisation périodiques anormaux.
