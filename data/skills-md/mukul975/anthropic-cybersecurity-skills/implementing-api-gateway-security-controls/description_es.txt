Configura puertas de enlace API como Kong, AWS API Gateway, Azure APIM o Apigee como un punto de aplicación de seguridad centralizado, que cubre la aplicación de autenticación, limitación y aceleración de velocidad, validación de solicitudes, listas de direcciones IP permitidas, terminación de TLS y protección contra amenazas. Úselo para proteger el tráfico de API en la capa de puerta de enlace, configurar la autenticación a nivel de puerta de enlace y la administración de cuotas, o centralizar la protección de API antes de que las solicitudes lleguen a los servicios de backend.
