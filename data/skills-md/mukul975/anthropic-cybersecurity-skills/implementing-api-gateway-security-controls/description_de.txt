Konfiguriert API-Gateways wie Kong, AWS API Gateway, Azure APIM oder Apigee als zentralisierten Sicherheitsdurchsetzungspunkt und deckt Authentifizierungsdurchsetzung, Ratenbegrenzung und -drosselung, Anforderungsvalidierung, IP-Zulassungsliste, TLS-Terminierung und Bedrohungsschutz ab. Verwenden Sie es, wenn Sie den API-Verkehr auf der Gateway-Ebene sichern, die Authentifizierung und Kontingentverwaltung auf Gateway-Ebene einrichten oder den API-Schutz zentralisieren, bevor Anforderungen die Back-End-Dienste erreichen.
