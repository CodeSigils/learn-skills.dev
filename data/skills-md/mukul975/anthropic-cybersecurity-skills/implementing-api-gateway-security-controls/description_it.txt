Configura gateway API come Kong, AWS API Gateway, Azure APIM o Apigee come punto di applicazione della sicurezza centralizzato, coprendo l'applicazione dell'autenticazione, la limitazione e la limitazione della velocità, la convalida delle richieste, l'inserimento nella lista consentita degli IP, la terminazione TLS e la protezione dalle minacce. Da utilizzare per proteggere il traffico API a livello gateway, configurare l'autenticazione a livello gateway e la gestione delle quote o centralizzare la protezione API prima che le richieste raggiungano i servizi backend.
