تكوين بوابات واجهة برمجة التطبيقات (API) مثل Kong أو AWS API Gateway أو Azure APIM أو Apigee كنقطة إنفاذ أمان مركزية، تغطي فرض المصادقة وتحديد المعدل والتقييد والتحقق من صحة الطلب وقائمة عناوين IP المسموح بها وإنهاء TLS والحماية من التهديدات. يُستخدم عند تأمين حركة مرور واجهة برمجة التطبيقات في طبقة البوابة، أو إعداد المصادقة على مستوى البوابة وإدارة الحصص، أو حماية واجهة برمجة التطبيقات المركزية قبل وصول الطلبات إلى خدمات الواجهة الخلفية.
