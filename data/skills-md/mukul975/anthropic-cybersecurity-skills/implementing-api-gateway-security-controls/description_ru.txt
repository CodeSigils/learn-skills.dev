Настраивает шлюзы API, такие как Kong, AWS API Gateway, Azure APIM или Apigee, в качестве централизованной точки обеспечения безопасности, включая обеспечение аутентификации, ограничение и регулирование скорости, проверку запросов, внесение разрешенных IP-адресов, завершение TLS и защиту от угроз. Используйте при защите трафика API на уровне шлюза, настройке аутентификации на уровне шлюза и управлении квотами или при централизации защиты API до того, как запросы достигнут серверных служб.
