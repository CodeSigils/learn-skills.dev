Esta habilidad cubre la implementación de Microsoft Sentinel como una plataforma SIEM y SOAR nativa de la nube para operaciones de seguridad centralizadas. Detalla la configuración de conectores de datos para la ingesta de registros en múltiples nubes, la redacción de consultas de detección KQL, la creación de guías de respuestas automatizadas con Logic Apps y el aprovechamiento del lago de datos Sentinel para la búsqueda de amenazas a escala de petabytes en la telemetría de seguridad de AWS, Azure y GCP.
