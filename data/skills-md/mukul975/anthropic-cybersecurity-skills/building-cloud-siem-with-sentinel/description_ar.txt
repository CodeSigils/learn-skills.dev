تغطي هذه المهارة نشر Microsoft Sentinel كمنصة سحابية أصلية لـ SIEM وSOAR لعمليات الأمان المركزية. وهو يعرض تفاصيل تكوين موصلات البيانات لاستيعاب السجلات السحابية المتعددة، وكتابة استعلامات اكتشاف KQL، وإنشاء أدلة تشغيل للاستجابة الآلية باستخدام Logic Apps، والاستفادة من بحيرة بيانات Sentinel لتعقب التهديدات على نطاق بيتابايت عبر القياس الأمني ​​عن بعد لـ AWS وAzure وGCP.
