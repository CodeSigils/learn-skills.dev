Этот навык охватывает развертывание Microsoft Sentinel в качестве облачной платформы SIEM и SOAR для централизованных операций безопасности. В нем подробно описывается настройка коннекторов данных для приема журналов из нескольких облаков, написание запросов обнаружения KQL, создание сборников автоматических ответов с помощью Logic Apps и использование озера данных Sentinel для поиска угроз петабайтного масштаба в телеметрии безопасности AWS, Azure и GCP.
