Тестирует механизмы аутентификации и авторизации в API мобильных приложений для выявления нарушенной аутентификации, небезопасного управления токенами, фиксации сеанса, повышения привилегий и уязвимостей IDOR. Используйте при выполнении оценок безопасности API для серверных частей мобильных приложений, тестировании реализаций JWT, оценке потоков OAuth или оценке управления сеансами. Активируется для запросов, включающих тестирование аутентификации мобильного API, оценку безопасности токена, тестирование мобильного потока OAuth или обход авторизации API.
