يختبر آليات المصادقة والترخيص في واجهات برمجة تطبيقات تطبيقات الهاتف المحمول لتحديد المصادقة المعطلة، وإدارة الرمز المميز غير الآمن، وتثبيت الجلسة، وتصعيد الامتيازات، ونقاط ضعف IDOR. يُستخدم عند إجراء تقييمات أمان واجهة برمجة التطبيقات مقابل الواجهات الخلفية لتطبيقات الأجهزة المحمولة، أو اختبار تطبيقات JWT، أو تقييم تدفقات OAuth، أو تقييم إدارة الجلسة. يتم التنشيط للطلبات التي تتضمن اختبار مصادقة واجهة برمجة تطبيقات الهاتف المحمول، أو تقييم أمان الرمز المميز، أو اختبار تدفق OAuth عبر الهاتف المحمول، أو تجاوز ترخيص واجهة برمجة التطبيقات.
