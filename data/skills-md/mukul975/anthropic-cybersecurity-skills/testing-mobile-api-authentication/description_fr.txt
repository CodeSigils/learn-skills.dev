Teste les mécanismes d'authentification et d'autorisation dans les API d'applications mobiles pour identifier les authentifications rompues, la gestion non sécurisée des jetons, la fixation de session, l'élévation de privilèges et les vulnérabilités IDOR. À utiliser pour effectuer des évaluations de sécurité des API sur les backends d'applications mobiles, tester les implémentations JWT, évaluer les flux OAuth ou évaluer la gestion des sessions. S'active pour les demandes impliquant des tests d'authentification d'API mobile, une évaluation de la sécurité des jetons, des tests de flux mobile OAuth ou un contournement d'autorisation d'API.
