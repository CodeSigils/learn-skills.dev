Testa i meccanismi di autenticazione e autorizzazione nelle API delle applicazioni mobili per identificare l'autenticazione interrotta, la gestione dei token non sicura, la correzione delle sessioni, l'escalation dei privilegi e le vulnerabilità IDOR. Da utilizzare quando si eseguono valutazioni della sicurezza API rispetto ai backend delle app mobili, si testano le implementazioni JWT, si valutano i flussi OAuth o si valuta la gestione delle sessioni. Si attiva per richieste che coinvolgono test di autenticazione API mobile, valutazione della sicurezza dei token, test del flusso mobile OAuth o bypass dell'autorizzazione API.
