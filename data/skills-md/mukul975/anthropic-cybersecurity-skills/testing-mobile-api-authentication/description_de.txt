Testet Authentifizierungs- und Autorisierungsmechanismen in APIs mobiler Anwendungen, um fehlerhafte Authentifizierung, unsichere Token-Verwaltung, Sitzungsfixierung, Rechteausweitung und IDOR-Schwachstellen zu identifizieren. Verwenden Sie diese Option, wenn Sie API-Sicherheitsbewertungen für mobile App-Backends durchführen, JWT-Implementierungen testen, OAuth-Flows bewerten oder die Sitzungsverwaltung bewerten. Wird für Anfragen aktiviert, die mobile API-Authentifizierungstests, Token-Sicherheitsbewertung, OAuth-Mobile-Flow-Tests oder API-Autorisierungsumgehung beinhalten.
