Prueba los mecanismos de autenticación y autorización en las API de aplicaciones móviles para identificar autenticación rota, administración de tokens insegura, fijación de sesiones, escalada de privilegios y vulnerabilidades IDOR. Úselo al realizar evaluaciones de seguridad de API en backends de aplicaciones móviles, probar implementaciones de JWT, evaluar flujos de OAuth o evaluar la gestión de sesiones. Se activa para solicitudes que involucran pruebas de autenticación de API móviles, evaluación de seguridad de tokens, pruebas de flujo móvil de OAuth o omisión de autorización de API.
