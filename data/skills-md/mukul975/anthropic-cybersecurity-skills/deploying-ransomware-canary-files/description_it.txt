Distribuisce e monitora i file canary ransomware nelle directory critiche utilizzando la libreria watchdog di Python per il rilevamento degli eventi del file system in tempo reale. Inserisce file esca con nomi strategici che imitano obiettivi di alto valore (documenti finanziari, credenziali, esportazioni di database) nelle posizioni che il ransomware in genere elenca per prime. Monitora eventuali operazioni di lettura, modifica, ridenominazione o eliminazione sui file Canary e attiva avvisi immediati tramite e-mail, webhook Slack o syslog quando viene rilevata un'interazione, fornendo un avviso tempestivo prima che inizi la crittografia completa.
