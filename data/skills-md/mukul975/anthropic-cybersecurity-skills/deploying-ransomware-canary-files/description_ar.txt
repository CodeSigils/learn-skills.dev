ينشر ويراقب ملفات كناري برامج الفدية عبر الدلائل المهمة باستخدام مكتبة مراقبة Python لاكتشاف أحداث نظام الملفات في الوقت الفعلي. يضع ملفات خادعة ذات أسماء استراتيجية تحاكي الأهداف عالية القيمة (السجلات المالية، وبيانات الاعتماد، وصادرات قاعدة البيانات) في المواقع التي عادةً ما تعدادها برامج الفدية أولاً. يراقب أي عمليات قراءة أو تعديل أو إعادة تسمية أو حذف على ملفات الكناري ويطلق تنبيهات فورية عبر البريد الإلكتروني أو Slack webhook أو سجل النظام عند اكتشاف التفاعل، مما يوفر تحذيرًا مبكرًا قبل بدء التشفير الكامل.
