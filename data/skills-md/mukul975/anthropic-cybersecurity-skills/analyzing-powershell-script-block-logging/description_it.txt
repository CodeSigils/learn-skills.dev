Analizza i log dei blocchi di script di Windows PowerShell (ID evento 4104) dai file EVTX per rilevare comandi offuscati, payload codificati e tecniche di vita fuori terra. Utilizza python-evtx per estrarre e ricostruire script multi-blocco, applica analisi entropica e corrispondenza di modelli per comandi codificati Base64, abuso di Invoke-Expression, basi di download e tentativi di bypass AMSI.
