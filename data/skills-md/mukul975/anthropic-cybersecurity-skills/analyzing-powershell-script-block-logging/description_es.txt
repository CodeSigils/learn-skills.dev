Analice los registros de bloques de scripts de Windows PowerShell (ID de evento 4104) de archivos EVTX para detectar comandos ofuscados, cargas útiles codificadas y técnicas de subsistencia. Utiliza python-evtx para extraer y reconstruir scripts de múltiples bloques, aplica análisis de entropía y coincidencia de patrones para comandos codificados en Base64, abuso de Invoke-Expression, bases de descarga e intentos de omisión de AMSI.
