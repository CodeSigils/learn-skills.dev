Анализируйте журналы блоков сценариев Windows PowerShell (идентификатор события 4104) из файлов EVTX для обнаружения запутанных команд, закодированных полезных данных и методов «жизни за пределами земли». Использует python-evtx для извлечения и восстановления многоблочных сценариев, применяет энтропийный анализ и сопоставление шаблонов для команд в кодировке Base64, злоупотреблений Invoke-Expression, поддержек загрузки и попыток обхода AMSI.
