Analysez les journaux de blocs de script Windows PowerShell (ID d'événement 4104) à partir de fichiers EVTX pour détecter les commandes obscurcies, les charges utiles codées et les techniques de subsistance. Utilise python-evtx pour extraire et reconstruire des scripts multiblocs, applique une analyse d'entropie et une correspondance de modèles pour les commandes codées en Base64, les abus d'Invoke-Expression, les berceaux de téléchargement et les tentatives de contournement AMSI.
