قم بتحليل سجلات كتلة Windows PowerShell Script (معرف الحدث 4104) من ملفات EVTX لاكتشاف الأوامر المبهمة، والحمولات المشفرة، وتقنيات العيش خارج الأرض. يستخدم python-evtx لاستخراج وإعادة بناء البرامج النصية متعددة الكتل، ويطبق تحليل الإنتروبيا ومطابقة الأنماط للأوامر المشفرة بـ Base64، وإساءة استخدام تعبير الاستدعاء، وحوامل التنزيل، ومحاولات تجاوز AMSI.
