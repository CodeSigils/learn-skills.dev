Teste les mécanismes d'authentification de l'API pour détecter les faiblesses, notamment la validation de jeton brisée, l'authentification manquante sur les points de terminaison, les politiques de mot de passe faibles, la susceptibilité au credential stuffing, la fuite de jeton dans les URL ou les journaux et les failles de gestion de session. Le testeur évalue l'implémentation de JWT, la gestion des clés API, les flux OAuth et l'entropie des jetons de session pour identifier les contournements d'authentification. Correspond à OWASP API2 : 2023 Authentification interrompue. S'active pour les demandes impliquant des tests d'authentification API, une évaluation de validation de jeton, des tests de sécurité des informations d'identification ou un contournement de l'authentification API.
