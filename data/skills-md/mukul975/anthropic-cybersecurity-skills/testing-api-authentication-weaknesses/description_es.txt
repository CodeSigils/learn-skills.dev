Prueba los mecanismos de autenticación de API para detectar debilidades, incluida la validación de tokens rota, la falta de autenticación en los puntos finales, las políticas de contraseñas débiles, la susceptibilidad al relleno de credenciales, la fuga de tokens en URL o registros y fallas en la administración de sesiones. El evaluador evalúa la implementación de JWT, el manejo de claves API, los flujos de OAuth y la entropía del token de sesión para identificar omisiones de autenticación. Se asigna a OWASP API2:2023 Autenticación rota. Se activa para solicitudes que involucran pruebas de autenticación de API, evaluación de validación de tokens, pruebas de seguridad de credenciales o omisión de autenticación de API.
