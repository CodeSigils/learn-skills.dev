Testa i meccanismi di autenticazione API per individuare eventuali punti deboli, tra cui convalida di token non funzionante, autenticazione mancante sugli endpoint, policy di password deboli, suscettibilità al credential stuffing, perdita di token negli URL o nei log e difetti di gestione delle sessioni. Il tester valuta l'implementazione JWT, la gestione delle chiavi API, i flussi OAuth e l'entropia del token di sessione per identificare i bypass di autenticazione. Mappa su OWASP API2:2023 Autenticazione interrotta. Si attiva per richieste che coinvolgono test di autenticazione API, valutazione della convalida dei token, test di sicurezza delle credenziali o bypass dell'autenticazione API.
