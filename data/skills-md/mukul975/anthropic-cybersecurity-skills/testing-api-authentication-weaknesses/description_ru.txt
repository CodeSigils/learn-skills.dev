Тестирует механизмы аутентификации API на наличие слабых мест, включая неработающую проверку токенов, отсутствие аутентификации на конечных точках, слабые политики паролей, подверженность вбросу учетных данных, утечку токенов в URL-адресах или журналах, а также недостатки управления сеансами. Тестер оценивает реализацию JWT, обработку ключей API, потоки OAuth и энтропию токена сеанса, чтобы выявить способы обхода аутентификации. Сопоставляется с OWASP API2:2023 Нарушенная аутентификация. Активируется для запросов, включающих тестирование аутентификации API, оценку проверки токена, тестирование безопасности учетных данных или обход аутентификации API.
