Esta habilidad cubre la realización de evaluaciones de ciberseguridad específicas para instalaciones de petróleo y gas, incluidas las operaciones upstream (exploración/producción), midstream (ductos/transporte) y downstream (refinación/distribución). Aborda sistemas SCADA que controlan las operaciones de ductos, DCS para el control de procesos de refinería, sistemas instrumentados de seguridad para procesos peligrosos, unidades terminales remotas en sitios de boca de pozo no tripulados y el cumplimiento de API 1164, Directivas de seguridad de ductos de la TSA, IEC 62443 y Marco de ciberseguridad del NIST para infraestructura crítica.
