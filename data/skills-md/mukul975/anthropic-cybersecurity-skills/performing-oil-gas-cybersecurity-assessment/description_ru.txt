Этот навык охватывает проведение оценок кибербезопасности, характерных для нефтегазовых объектов, включая операции по добыче (разведка/добыча), переработке (трубопровод/транспортировка) и переработке (переработка/распределение). Он касается систем SCADA, контролирующих работу трубопроводов, РСУ для управления процессами нефтеперерабатывающего завода, автоматизированных систем безопасности для опасных процессов, удаленных терминалов на необслуживаемых устьевых площадках скважин, а также соответствия требованиям API 1164, директивам безопасности трубопроводов TSA, IEC 62443 и структуре кибербезопасности NIST для критической инфраструктуры.
