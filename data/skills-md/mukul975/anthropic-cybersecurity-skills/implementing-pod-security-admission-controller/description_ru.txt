Настраивает и управляет контроллером Kubernetes Pod Security Admission (PSA), который обеспечивает соблюдение стандартов безопасности модулей: метки принудительного применения/аудита/предупреждения пространства имен, значения по умолчанию для всего кластера через AdmissionConfiguration, исключения для имен пользователей, классов среды выполнения и пространств имен, закрепление версий и модули устранения неполадок, которые контроллер отклонил. Используйте при подключении PSA к кластеру, настройке принудительного применения по умолчанию на уровне всего кластера, исключении системных пространств имен, отладке того, почему модуль был отклонен или почему принудительное применение не срабатывает, а также при чтении результатов аудита PSA и предупреждений. Ключевые слова: Pod Security Admission, PSA, контроллер допуска, AdmissionConfiguration, метки pod-security.kubernetes.io, принудительное предупреждение аудита, исключения, kube-apiserver. Не используйте для выбора профиля безопасности, который нужен рабочей нагрузке — используйтеimplementation-kubernetes-pod-security-standards.
