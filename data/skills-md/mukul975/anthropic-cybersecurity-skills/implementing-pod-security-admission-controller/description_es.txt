Configura y opera el controlador de admisión de seguridad de pods (PSA) de Kubernetes que aplica los estándares de seguridad de pods: etiquetas de aplicación/auditoría/advertencia de espacio de nombres, valores predeterminados en todo el clúster a través de AdmissionConfiguration, exenciones para nombres de usuario, clases y espacios de nombres de tiempo de ejecución, fijación de versiones y solución de problemas de pods que el controlador rechazó. Úselo al conectar PSA en un clúster, configurar la aplicación predeterminada en todo el clúster, eximir espacios de nombres del sistema, depurar por qué se rechazó un pod o por qué la aplicación no se activa, o leer la auditoría de PSA y la salida de advertencia. Palabras clave: Admisión de seguridad de pod, PSA, controlador de admisión, AdmissionConfiguration, etiquetas pod-security.kubernetes.io, aplicar advertencia de auditoría, exenciones, kube-apiserver. No lo use para elegir qué perfil de seguridad necesita una carga de trabajo; use implementar-kubernetes-pod-security-standards.
