Обнаруживайте атаки Kerberos Pass-the-Ticket (PtT), анализируя идентификаторы событий Windows 4768, 4769 и 4771 на предмет аномальных шаблонов использования билетов, с помощью запросов обнаружения для Splunk и Elastic SIEM. Используйте при расследовании инцидентов, связанных с украденными или воспроизведенными билетами Kerberos, правилами обнаружения зданий или запросами поиска угроз для злоупотреблений билетами, а также при проверке покрытия мониторинга SOC для методов атак с кражей учетных данных.
