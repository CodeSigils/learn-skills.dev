Erkennen Sie indirekte Prompt-Injection, die in von einem Agenten konsumierten Webseiten, Dokumenten und Bildern verborgen ist, und schützen Sie sich davor, indem Sie Inhalte extrahieren (HTML/PDF/OCR), Normalisierung und Scannen mit dem PromptInjection-Scanner von LLM Guard oder Hugging Face Prompt Guard 2. Verwenden Sie diese Option, wenn ein Agent nicht vertrauenswürdige externe Inhalte aufnimmt und Sie diese auf injizierte Anweisungen überprüfen müssen, bevor das LLM sie verarbeitet.
