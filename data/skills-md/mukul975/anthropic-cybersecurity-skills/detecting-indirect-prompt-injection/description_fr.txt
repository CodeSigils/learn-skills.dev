Détectez et défendez-vous contre l'injection d'invite indirecte cachée dans les pages Web, les documents et les images consommées par un agent, via l'extraction de contenu (HTML/PDF/OCR), la normalisation et l'analyse avec le scanner PromptInjection de LLM Guard ou Hugging Face Prompt Guard 2. À utiliser lorsqu'un agent ingère du contenu externe non fiable et que vous devez le filtrer pour les instructions injectées avant que le LLM ne le traite.
