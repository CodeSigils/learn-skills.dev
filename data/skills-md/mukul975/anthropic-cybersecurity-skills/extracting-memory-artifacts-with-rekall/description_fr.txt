Utilise le framework d'investigation de la mémoire Rekall pour analyser les vidages de mémoire pour détecter les processus creux, le code injecté via des anomalies VAD, les processus cachés et la détection des rootkits. Applique des plugins tels que pslist, psscan, vadinfo, malfind et dlllist pour extraire les artefacts médico-légaux des images mémoire Windows. À utiliser lors de l'analyse de la mémoire des réponses aux incidents.
