Verwendet das Rekall-Speicherforensik-Framework zur Analyse von Speicherauszügen auf Process Hollowing, injizierten Code über VAD-Anomalien, versteckte Prozesse und Rootkit-Erkennung. Wendet Plugins wie pslist, psscan, vadinfo, malfind und dlllist an, um forensische Artefakte aus Windows-Speicherabbildern zu extrahieren. Verwendung bei der Analyse des Incident-Response-Gedächtnisses.
