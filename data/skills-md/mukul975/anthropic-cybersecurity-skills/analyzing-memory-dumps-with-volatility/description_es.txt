Analiza volcados de memoria RAM de sistemas comprometidos utilizando el marco Volatility para identificar procesos maliciosos, código inyectado, conexiones de red, módulos cargados y credenciales extraídas. Admite análisis forense de memoria de Windows, Linux y macOS. Se activa para solicitudes que involucran análisis forense de memoria, análisis de RAM, examen de datos volátiles, detección de inyección de procesos o investigación de malware residente en la memoria.
