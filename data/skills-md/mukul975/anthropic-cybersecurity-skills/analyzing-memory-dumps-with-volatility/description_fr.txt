Analyse les vidages de mémoire RAM des systèmes compromis à l'aide du framework Volatility pour identifier les processus malveillants, le code injecté, les connexions réseau, les modules chargés et les informations d'identification extraites. Prend en charge l'analyse de la mémoire Windows, Linux et macOS. S'active pour les requêtes impliquant une analyse de la mémoire, une analyse de la RAM, un examen des données volatiles, une détection d'injection de processus ou une enquête sur les logiciels malveillants résidant en mémoire.
