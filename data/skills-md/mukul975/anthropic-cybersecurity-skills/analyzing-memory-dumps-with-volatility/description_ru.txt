Анализирует дампы оперативной памяти взломанных систем с помощью платформы Volatility для выявления вредоносных процессов, внедренного кода, сетевых подключений, загруженных модулей и извлеченных учетных данных. Поддерживает анализ памяти Windows, Linux и macOS. Активируется для запросов, связанных с криминалистической экспертизой памяти, анализом ОЗУ, проверкой нестабильных данных, обнаружением внедрения процесса или исследованием вредоносного ПО, находящегося в памяти.
