Cette compétence couvre l'intégration du scanner Trivy d'Aqua Security dans les pipelines CI/CD pour une détection complète des vulnérabilités des images de conteneurs. Il aborde l'analyse des images Docker pour les CVE de dépendances entre les packages de système d'exploitation et les applications, la détection des erreurs de configuration dans les fichiers Docker, l'analyse du système de fichiers et des référentiels git et l'établissement de portes de qualité basées sur la gravité qui bloquent le déploiement d'images vulnérables.
