Questa competenza riguarda l'integrazione dello scanner Trivy di Aqua Security nelle pipeline CI/CD per il rilevamento completo della vulnerabilità dell'immagine del contenitore. Risolve la scansione delle immagini Docker per individuare pacchetti del sistema operativo e CVE di dipendenza delle applicazioni, rilevando configurazioni errate nei file Docker, scansionando file system e repository git e stabilendo controlli di qualità basati sulla gravità che bloccano la distribuzione di immagini vulnerabili.
