يكتشف سرقة رمز OAuth المميز ويستجيب لها ويعيد الهجمات في البيئات السحابية، مع التركيز على حماية الرمز المميز لـ Microsoft Entra ID (Azure AD)، وسياسات الوصول المشروط، واكتشاف الحالات الشاذة في تسجيل الدخول. يغطي سرقة رمز الوصول، وإعادة تشغيل رمز التحديث، وإساءة استخدام رمز التحديث الأساسي (PRT)، وهجمات تمرير ملف تعريف الارتباط. يتم التنشيط للطلبات التي تتضمن الكشف عن سرقة رمز OAuth المميز، أو منع إعادة تشغيل الرمز المميز، أو حماية الرمز المميز للوصول المشروط لـ Azure AD، أو التحقيق في هجوم الهوية السحابية.
