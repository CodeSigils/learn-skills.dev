Implementa una estrategia de copia de seguridad inmutable utilizando restic con almacenamiento compatible con S3 y bloqueo de objetos para una protección de datos resistente al ransomware. Automatiza la creación de copias de seguridad, la verificación de la integridad mediante verificación restic: lectura de datos, aplicación de políticas de retención de instantáneas y pruebas de restauración. Se integra con AWS S3 Object Lock, MinIO y Backblaze B2 para almacenamiento WORM (Write Once Read Many) que evita la eliminación o el cifrado de copias de seguridad por parte de actores de ransomware.
