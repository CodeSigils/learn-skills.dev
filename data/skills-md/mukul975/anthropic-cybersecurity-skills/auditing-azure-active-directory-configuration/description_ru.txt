Аудит конфигурации Microsoft Entra ID (Azure Active Directory) для выявления рискованных политик аутентификации, чрезмерно разрешительных назначений ролей, устаревших учетных записей, пробелов в условном доступе и рисков гостевых пользователей с помощью AzureAD PowerShell, Microsoft Graph API и ScoutSuite.
