Audit de la configuration de Microsoft Entra ID (Azure Active Directory) pour identifier les politiques d'authentification à risque, les attributions de rôles trop permissives, les comptes obsolètes, les lacunes d'accès conditionnel et les risques liés aux utilisateurs invités à l'aide d'AzureAD PowerShell, de l'API Microsoft Graph et de ScoutSuite.
