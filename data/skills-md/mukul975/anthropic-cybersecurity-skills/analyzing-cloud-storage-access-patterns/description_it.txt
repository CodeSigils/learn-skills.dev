Rileva modelli di accesso anomali in AWS S3, GCS e Archiviazione BLOB di Azure analizzando gli eventi di dati CloudTrail, i log di controllo GCS e l'analisi di archiviazione di Azure. Identifica download in blocco fuori orario, accesso da nuovi indirizzi IP, chiamate API insolite (picchi GetObject) e potenziale esfiltrazione di dati utilizzando linee di base statistiche e rilevamento di anomalie di serie temporali.
