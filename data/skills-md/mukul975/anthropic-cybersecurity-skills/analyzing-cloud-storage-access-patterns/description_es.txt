Detecte patrones de acceso anormales en AWS S3, GCS y Azure Blob Storage mediante el análisis de eventos de datos de CloudTrail, registros de auditoría de GCS y Azure Storage Analytics. Identifica descargas masivas fuera del horario laboral, acceso desde nuevas direcciones IP, llamadas API inusuales (picos de GetObject) y posible filtración de datos mediante líneas de base estadísticas y detección de anomalías de series temporales.
