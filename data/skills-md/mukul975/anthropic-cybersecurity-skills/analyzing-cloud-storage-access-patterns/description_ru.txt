Обнаруживайте ненормальные шаблоны доступа в AWS S3, GCS и Azure Blob Storage, анализируя события данных CloudTrail, журналы аудита GCS и аналитику хранилища Azure. Выявляет массовые загрузки в нерабочее время, доступ с новых IP-адресов, необычные вызовы API (всплески GetObject) и потенциальную утечку данных с использованием базовых статистических показателей и обнаружения аномалий временных рядов.
