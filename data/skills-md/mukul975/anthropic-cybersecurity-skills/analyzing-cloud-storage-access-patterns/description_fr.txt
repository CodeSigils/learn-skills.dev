Détectez les modèles d'accès anormaux dans AWS S3, GCS et Azure Blob Storage en analysant les événements de données CloudTrail, les journaux d'audit GCS et Azure Storage Analytics. Identifie les téléchargements groupés en dehors des heures d'ouverture, l'accès à partir de nouvelles adresses IP, les appels d'API inhabituels (pics GetObject) et l'exfiltration potentielle de données à l'aide de lignes de base statistiques et de détection d'anomalies de séries chronologiques.
