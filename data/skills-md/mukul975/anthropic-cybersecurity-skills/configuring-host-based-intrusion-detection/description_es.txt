Configura sistemas de detección de intrusiones (HIDS) basados ​​en host para monitorear la integridad de los archivos de los endpoints, las llamadas al sistema y los cambios de configuración en busca de violaciones de seguridad. Úselo al implementar OSSEC, Wazuh o AIDE para monitorear puntos finales, crear políticas de monitoreo de integridad de archivos (FIM) o cumplir con los requisitos de cumplimiento para la detección de cambios. Se activa para solicitudes que involucran configuración HIDS, monitoreo de integridad de archivos, implementación de OSSEC/Wazuh o detección basada en host.
