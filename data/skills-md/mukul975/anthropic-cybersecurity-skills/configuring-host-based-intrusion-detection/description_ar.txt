يقوم بتكوين أنظمة كشف التسلل المستندة إلى المضيف (HIDS) لمراقبة سلامة ملفات نقطة النهاية واستدعاءات النظام وتغييرات التكوين لانتهاكات الأمان. يُستخدم عند نشر OSSEC أو Wazuh أو AIDE لمراقبة نقطة النهاية أو إنشاء سياسات مراقبة سلامة الملفات (FIM) أو تلبية متطلبات الامتثال لاكتشاف التغيير. يتم التنشيط للطلبات التي تتضمن تكوين HIDS، أو مراقبة سلامة الملفات، أو نشر OSSEC/Wazuh، أو الكشف المستند إلى المضيف.
