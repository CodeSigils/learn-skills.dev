يقوم بتحليل سجلات أحداث Windows Security والنظام وSysmon في Splunk للكشف عن هجمات المصادقة وتصعيد الامتيازات وآليات الاستمرار والحركة الجانبية باستخدام استعلامات SPL المعينة لتقنيات MITRE ATT&CK. يُستخدم عندما يحتاج محللو SOC إلى التحقيق في التهديدات المستندة إلى Windows، أو إنشاء استعلامات الكشف، أو إجراء تحليل المخطط الزمني الشرعي لنقاط نهاية Windows ووحدات التحكم بالمجال.
