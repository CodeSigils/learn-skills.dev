Анализирует журналы событий безопасности Windows, системы и Sysmon в Splunk для обнаружения атак аутентификации, повышения привилегий, механизмов сохранения и горизонтального перемещения с использованием запросов SPL, сопоставленных с методами MITRE ATT&CK. Используйте, когда аналитикам SOC необходимо исследовать угрозы для Windows, создавать запросы на обнаружение или выполнять судебно-медицинский анализ конечных точек Windows и контроллеров домена.
