Configura la registrazione eventi di Windows con criteri di controllo avanzati per generare eventi di sicurezza ad alta fedeltà per il rilevamento delle minacce e le indagini forensi. Da utilizzare quando si abilitano le policy di controllo per eventi di accesso, creazione di processi, utilizzo di privilegi e accesso agli oggetti per alimentare le regole di rilevamento SIEM. Si attiva per richieste che coinvolgono criteri di controllo di Windows, configurazione del registro eventi, registrazione di sicurezza o registrazione orientata al rilevamento.
