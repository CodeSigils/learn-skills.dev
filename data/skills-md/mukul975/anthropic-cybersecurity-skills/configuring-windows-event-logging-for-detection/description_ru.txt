Настраивает ведение журнала событий Windows с расширенными политиками аудита для создания высококачественных событий безопасности для обнаружения угроз и криминалистического расследования. Используйте при включении политик аудита для событий входа в систему, создания процессов, использования привилегий и доступа к объектам для подачи правил обнаружения SIEM. Активируется для запросов, касающихся политики аудита Windows, конфигурации журнала событий, ведения журнала безопасности или ведения журнала, ориентированного на обнаружение.
