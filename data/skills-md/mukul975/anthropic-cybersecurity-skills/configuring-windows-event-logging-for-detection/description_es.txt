Configura el registro de eventos de Windows con políticas de auditoría avanzadas para generar eventos de seguridad de alta fidelidad para la detección de amenazas y la investigación forense. Úselo al habilitar políticas de auditoría para eventos de inicio de sesión, creación de procesos, uso de privilegios y acceso a objetos para alimentar las reglas de detección de SIEM. Se activa para solicitudes relacionadas con la política de auditoría de Windows, la configuración del registro de eventos, el registro de seguridad o el registro orientado a la detección.
