يقوم بتكوين تسجيل أحداث Windows باستخدام سياسات التدقيق المتقدمة لإنشاء أحداث أمان عالية الدقة للكشف عن التهديدات والتحقيق الجنائي. يُستخدم عند تمكين سياسات التدقيق لأحداث تسجيل الدخول، وإنشاء العملية، واستخدام الامتيازات، والوصول إلى الكائنات لقواعد الكشف عن SIEM. يتم التنشيط للطلبات التي تتضمن سياسة تدقيق Windows، أو تكوين سجل الأحداث، أو تسجيل الأمان، أو التسجيل الموجه للاكتشاف.
