Отслеживайте горизонтальное движение на основе DCOM, обнаруживая злоупотребление COM-объектами MMC20.Application, ShellBrowserWindow и ShellWindows с помощью корреляции Sysmon Event ID 1 (создание процесса) и Event ID 3 (сетевое подключение), анализа событий WMI, трафика сопоставителя конечных точек RPC на порту 135 и отношений родительского и дочернего процессов, специфичных для DCOM.
