Выполняет комплексную оценку безопасности приложений iOS с использованием Frida для динамического инструментирования, Objection для исследования во время выполнения, обхода закрепления SSL для перехвата трафика, извлечения связки ключей для анализа учетных данных и статического анализа IPA для проверки на двоичном уровне. Используйте при проведении авторизованных тестов на проникновение iOS, оценке состояния безопасности мобильных приложений по отношению к OWASP MASTG или оценке защиты данных приложений iOS и средств контроля безопасности транспорта. Активируется для запросов, связанных с тестированием приложений iOS на проникновение, инструментарием iOS на базе Frida, обходом закрепления SSL мобильных приложений или обратным проектированием IPA.
