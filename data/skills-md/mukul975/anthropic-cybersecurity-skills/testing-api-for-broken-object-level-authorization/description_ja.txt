REST および GraphQL API で、認証されたユーザーが API リクエスト内のオブジェクト識別子を操作することで他のユーザーに属するリソースにアクセスまたは変更できる、Broken Object Level Authorization (BOLA/IDOR) の脆弱性をテストします。テスターは API 呼び出しをインターセプトし、オブジェクト ID パラメーター (数値 ID、UUID、スラッグ) を識別し、それらを他のユーザーに属する ID に体系的に置き換えて、サーバーがオブジェクトごとの認可を強制するかどうかを判断します。これは、OWASP API セキュリティ トップ 10 2023 リスク API1 です。 BOLA テスト、API の IDOR、オブジェクトレベルの認可テスト、または API アクセス制御バイパスを含むリクエストに対してアクティブ化されます。
