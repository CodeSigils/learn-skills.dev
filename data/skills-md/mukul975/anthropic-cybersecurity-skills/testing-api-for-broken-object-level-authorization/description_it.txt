Testa le API REST e GraphQL per le vulnerabilità BOLA/IDOR (Brown Object Level Authorization) in cui un utente autenticato può accedere o modificare risorse appartenenti ad altri utenti manipolando gli identificatori di oggetto nelle richieste API. Il tester intercetta le chiamate API, identifica i parametri ID dell'oggetto (ID numerici, UUID, slug) e li sostituisce sistematicamente con ID appartenenti ad altri utenti per determinare se il server applica l'autorizzazione per oggetto. Questa è la Top 10 API di rischio 2023 di OWASP API Security1. Si attiva per richieste che coinvolgono test BOLA, IDOR nelle API, test di autorizzazione a livello di oggetto o bypass del controllo di accesso API.
