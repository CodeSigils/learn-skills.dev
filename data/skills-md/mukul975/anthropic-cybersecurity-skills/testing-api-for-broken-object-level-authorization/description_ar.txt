اختبارات واجهات برمجة التطبيقات REST وGraphQL لنقاط ضعف ترخيص مستوى الكائن المكسور (BOLA/IDOR) حيث يمكن للمستخدم المعتمد الوصول إلى الموارد المملوكة لمستخدمين آخرين أو تعديلها عن طريق معالجة معرفات الكائنات في طلبات واجهة برمجة التطبيقات. يعترض المختبر مكالمات واجهة برمجة التطبيقات (API)، ويحدد معلمات معرف الكائن (المعرفات الرقمية، ومعرفات UUID، والارتباطات الثابتة)، ويستبدلها بشكل منهجي بمعرفات تخص مستخدمين آخرين لتحديد ما إذا كان الخادم يفرض ترخيصًا لكل كائن. هذا هو OWASP API Security Top 10 2023 Risk API1. يتم التنشيط للطلبات التي تتضمن اختبار BOLA، أو IDOR في واجهات برمجة التطبيقات، أو اختبار الترخيص على مستوى الكائن، أو تجاوز التحكم في الوصول إلى واجهة برمجة التطبيقات.
