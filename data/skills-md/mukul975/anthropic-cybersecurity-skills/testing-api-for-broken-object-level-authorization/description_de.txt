Testet REST- und GraphQL-APIs auf BOLA/IDOR-Schwachstellen (Broken Object Level Authorization), bei denen ein authentifizierter Benutzer auf Ressourcen anderer Benutzer zugreifen oder diese ändern kann, indem er Objektkennungen in API-Anfragen manipuliert. Der Tester fängt API-Aufrufe ab, identifiziert Objekt-ID-Parameter (numerische IDs, UUIDs, Slugs) und ersetzt sie systematisch durch IDs anderer Benutzer, um festzustellen, ob der Server eine Autorisierung pro Objekt erzwingt. Dies ist die OWASP API Security Top 10 2023 Risiko-API1. Wird für Anfragen aktiviert, die BOLA-Tests, IDOR in APIs, Autorisierungstests auf Objektebene oder die Umgehung der API-Zugriffskontrolle beinhalten.
