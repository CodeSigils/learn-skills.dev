Тестирует API-интерфейсы REST и GraphQL на наличие уязвимостей авторизации на уровне сломанных объектов (BOLA/IDOR), когда прошедший проверку подлинности пользователь может получить доступ к ресурсам, принадлежащим другим пользователям, или изменить их, манипулируя идентификаторами объектов в запросах API. Тестер перехватывает вызовы API, определяет параметры идентификатора объекта (числовые идентификаторы, UUID, пули) и систематически заменяет их идентификаторами, принадлежащими другим пользователям, чтобы определить, обеспечивает ли сервер авторизацию для каждого объекта. Это API-интерфейс OWASP API Security Top 10 2023 года. Активируется для запросов, включающих тестирование BOLA, IDOR в API, тестирование авторизации на уровне объекта или обход контроля доступа API.
