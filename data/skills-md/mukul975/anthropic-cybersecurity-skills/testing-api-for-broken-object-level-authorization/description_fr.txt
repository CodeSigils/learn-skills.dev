Teste les API REST et GraphQL pour les vulnérabilités Broken Object Level Authorization (BOLA/IDOR) où un utilisateur authentifié peut accéder ou modifier des ressources appartenant à d'autres utilisateurs en manipulant les identifiants d'objet dans les requêtes API. Le testeur intercepte les appels d'API, identifie les paramètres d'ID d'objet (ID numériques, UUID, slugs) et les remplace systématiquement par des ID appartenant à d'autres utilisateurs pour déterminer si le serveur applique une autorisation par objet. Il s’agit de l’API1 des risques de sécurité des API OWASP Top 10 2023. S'active pour les demandes impliquant des tests BOLA, IDOR dans les API, des tests d'autorisation au niveau des objets ou un contournement du contrôle d'accès des API.
