Prueba las API REST y GraphQL para detectar vulnerabilidades de autorización de nivel de objetos rotos (BOLA/IDOR) donde un usuario autenticado puede acceder o modificar recursos que pertenecen a otros usuarios mediante la manipulación de identificadores de objetos en solicitudes de API. El probador intercepta llamadas API, identifica parámetros de ID de objeto (ID numéricos, UUID, slugs) y los reemplaza sistemáticamente con ID que pertenecen a otros usuarios para determinar si el servidor aplica la autorización por objeto. Esta es la API1 de riesgo principal de seguridad API de OWASP 10 2023. Se activa para solicitudes que involucran pruebas BOLA, IDOR en API, pruebas de autorización a nivel de objeto o omisión del control de acceso a API.
