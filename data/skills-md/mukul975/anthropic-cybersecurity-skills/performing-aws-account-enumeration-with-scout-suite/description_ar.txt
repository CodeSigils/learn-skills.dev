قم بتشغيل أداة ScoutSuite مفتوحة المصدر بدون وكيل (عبر تثبيت النقطة وواجهة سطر الأوامر "scout") مقابل حساب AWS لتعداد الموارد عبر الخدمات، وتحديد التكوينات الخاطئة، وإنشاء تقرير أمان HTML تفاعلي. يُستخدم عند تقييم الوضع الأمني ​​العام لحساب AWS باستخدام بيانات اعتماد IAM للقراءة فقط، كما هو الحال أثناء تدقيق أمان السحابة أو مراجعة الامتثال.
