Esegui lo strumento ScoutSuite open source e senza agente (tramite pip install e la CLI `scout`) su un account AWS per enumerare le risorse tra i servizi, identificare errori di configurazione e generare un report di sicurezza HTML interattivo. Da utilizzare quando si valuta il livello di sicurezza generale di un account AWS con credenziali IAM di sola lettura, ad esempio durante un controllo della sicurezza del cloud o una revisione della conformità.
