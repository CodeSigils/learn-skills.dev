Ejecute la herramienta ScoutSuite de código abierto y sin agentes (a través de pip install y la CLI `scout`) en una cuenta de AWS para enumerar recursos en todos los servicios, identificar configuraciones incorrectas y generar un informe de seguridad HTML interactivo. Úselo al evaluar la postura de seguridad general de una cuenta de AWS con credenciales de IAM de solo lectura, como durante una auditoría de seguridad en la nube o una revisión de cumplimiento.
