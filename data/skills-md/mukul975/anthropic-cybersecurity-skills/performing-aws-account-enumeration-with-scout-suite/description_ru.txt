Запустите безагентный инструмент ScoutSuite с открытым исходным кодом (через установку pip и интерфейс командной строки scout) для учетной записи AWS, чтобы подсчитать ресурсы между сервисами, выявить неправильные конфигурации и создать интерактивный отчет о безопасности в формате HTML. Используйте при оценке общего состояния безопасности учетной записи AWS с учетными данными IAM, доступными только для чтения, например, во время аудита облачной безопасности или проверки соответствия.
