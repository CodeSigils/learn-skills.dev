Exécutez l'outil ScoutSuite sans agent et open source (via pip install et la CLI « scout ») sur un compte AWS pour énumérer les ressources entre les services, identifier les erreurs de configuration et générer un rapport de sécurité HTML interactif. À utiliser lors de l'évaluation de la situation de sécurité globale d'un compte AWS avec des informations d'identification IAM en lecture seule, par exemple lors d'un audit de sécurité cloud ou d'un examen de conformité.
