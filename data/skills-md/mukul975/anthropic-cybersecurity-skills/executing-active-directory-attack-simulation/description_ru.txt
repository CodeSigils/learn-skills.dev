Выполняет моделирование санкционированных атак на среды Active Directory для выявления неправильных конфигураций, слабых учетных данных, опасных путей привилегий и уязвимых доверительных отношений, которые могут привести к компрометации домена. Тестер использует BloodHound для анализа пути атаки, Mimikatz для извлечения учетных данных и Impacket для атак на уровне протокола, включая Kerberoasting, AS-REP Roasting и злоупотребление делегированием. Активируется для запросов, включающих тестирование на проникновение Active Directory, моделирование атак AD, тестирование компрометации домена или оценку атаки Kerberos.
