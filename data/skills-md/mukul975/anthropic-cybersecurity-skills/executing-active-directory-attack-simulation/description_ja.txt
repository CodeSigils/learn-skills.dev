Active Directory 環境に対して承認された攻撃シミュレーションを実行し、ドメイン侵害につながる可能性のある構成ミス、弱い認証情報、危険な特権パス、悪用可能な信頼関係を特定します。テスターは、攻撃パスの分析に BloodHound を、資格情報の抽出に Mimikatz を、Kerberoasting、AS-REP Roasting、委任の悪用などのプロトコル レベルの攻撃に Impacket を使用します。 Active Directory 侵入テスト、AD 攻撃シミュレーション、ドメイン侵害テスト、または Kerberos 攻撃評価を含むリクエストに対してアクティブ化されます。
