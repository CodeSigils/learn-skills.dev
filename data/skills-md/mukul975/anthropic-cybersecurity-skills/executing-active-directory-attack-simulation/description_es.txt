Ejecuta simulaciones de ataques autorizados contra entornos de Active Directory para identificar configuraciones erróneas, credenciales débiles, rutas de privilegios peligrosas y relaciones de confianza explotables que podrían comprometer el dominio. El evaluador utiliza BloodHound para el análisis de la ruta de ataque, Mimikatz para la extracción de credenciales e Impacket para ataques a nivel de protocolo, incluidos Kerberoasting, AS-REP Roasting y abuso de delegación. Se activa para solicitudes que involucran pentest de Active Directory, simulación de ataques de AD, pruebas de compromiso de dominio o evaluación de ataques de Kerberos.
