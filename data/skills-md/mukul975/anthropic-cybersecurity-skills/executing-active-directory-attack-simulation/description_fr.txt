Exécute des simulations d'attaques autorisées contre les environnements Active Directory pour identifier les erreurs de configuration, les informations d'identification faibles, les chemins de privilèges dangereux et les relations de confiance exploitables qui pourraient conduire à une compromission du domaine. Le testeur utilise BloodHound pour l'analyse du chemin d'attaque, Mimikatz pour l'extraction des informations d'identification et Impacket pour les attaques au niveau du protocole, notamment Kerberoasting, AS-REP Roasting et les abus de délégation. S'active pour les requêtes impliquant un pentest Active Directory, une simulation d'attaque AD, des tests de compromission de domaine ou une évaluation d'attaque Kerberos.
