ينفذ عمليات محاكاة الهجوم المصرح بها ضد بيئات Active Directory لتحديد التكوينات الخاطئة وبيانات الاعتماد الضعيفة ومسارات الامتياز الخطيرة وعلاقات الثقة القابلة للاستغلال والتي قد تؤدي إلى اختراق المجال. يستخدم جهاز الاختبار BloodHound لتحليل مسار الهجوم، وMimikatz لاستخراج بيانات الاعتماد، وImpacket للهجمات على مستوى البروتوكول بما في ذلك Kerberoasting، وAS-REP Roasting، وإساءة استخدام التفويض. يتم التنشيط للطلبات التي تتضمن اختبار Active Directory أو محاكاة هجوم AD أو اختبار اختراق المجال أو تقييم هجوم Kerberos.
