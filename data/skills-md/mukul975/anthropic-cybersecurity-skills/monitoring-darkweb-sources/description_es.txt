Supervisa foros de la web oscura, mercados, sitios de pegado y sitios de fuga de ransomware en busca de menciones de activos organizacionales, credenciales filtradas, amenazas de ataques y comunicaciones de actores de amenazas para proporcionar inteligencia de alerta temprana. Úselo al establecer una cobertura de monitoreo de la web oscura, investigar reclamos específicos de violación de datos o enriquecer las investigaciones de incidentes con el contexto de la web oscura. Se activa para solicitudes que involucran OSINT de la web oscura, monitoreo de sitios de fugas, exposición de credenciales, web oscura de Recorded Future o inteligencia de servicios ocultos de Tor.
