Cette compétence couvre l'implémentation de Gitleaks pour détecter et empêcher les secrets codés en dur dans les référentiels git. Il aborde la configuration des hooks de pré-validation, l'intégration du pipeline CI/CD, la création de règles personnalisées pour les secrets spécifiques à l'organisation, la gestion de base pour les référentiels existants et les workflows de remédiation pour les informations d'identification exposées.
