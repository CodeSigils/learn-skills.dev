Postman を使用して、認証バイパス、認可の欠陥、インジェクション、データ漏洩などの OWASP API セキュリティ トップ 10 の脆弱性をテストするコレクションを構築することで、構造化された API セキュリティ テストを実行します。テスターは、複数のユーザー ロールを持つ環境を作成し、自動セキュリティ検証用のテスト スクリプトを作成し、CI/CD セキュリティ テスト用に Postman を OWASP ZAP および Newman と統合します。 Postman セキュリティ テスト、API セキュリティ コレクション、自動化された API テスト、または Postman を使用した OWASP API テストを含むリクエストに対してアクティブ化されます。
