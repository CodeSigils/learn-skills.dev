Utilise Postman pour effectuer des tests de sécurité structurés des API en créant des collections qui testent les 10 principales vulnérabilités de sécurité des API OWASP, notamment le contournement de l'authentification, les failles d'autorisation, l'injection et l'exposition des données. Le testeur crée des environnements avec plusieurs rôles d'utilisateur, écrit des scripts de test pour une validation de sécurité automatisée et intègre Postman avec OWASP ZAP et Newman pour les tests de sécurité CI/CD. S'active pour les demandes impliquant des tests de sécurité Postman, une collecte de sécurité API, des tests API automatisés ou des tests API OWASP avec Postman.
