يستخدم Postman لإجراء اختبار أمان API منظم من خلال إنشاء مجموعات تختبر أهم 10 نقاط ضعف لـ OWASP API Security بما في ذلك تجاوز المصادقة، وعيوب التفويض، والحقن، والكشف عن البيانات. يقوم المُختبر بإنشاء بيئات ذات أدوار مستخدم متعددة، ويكتب نصوص اختبارية للتحقق من صحة الأمان تلقائيًا، ويدمج Postman مع OWASP ZAP وNewman لاختبار أمان CI/CD. يتم التنشيط للطلبات التي تتضمن اختبار أمان Postman، أو مجموعة أمان API، أو اختبار API الآلي، أو اختبار OWASP API مع Postman.
