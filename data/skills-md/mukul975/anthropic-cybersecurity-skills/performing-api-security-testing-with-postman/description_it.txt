Utilizza Postman per eseguire test strutturati sulla sicurezza delle API creando raccolte che verificano le 10 principali vulnerabilità della sicurezza API OWASP, tra cui bypass di autenticazione, difetti di autorizzazione, injection ed esposizione dei dati. Il tester crea ambienti con più ruoli utente, scrive script di test per la convalida automatizzata della sicurezza e integra Postman con OWASP ZAP e Newman per i test di sicurezza CI/CD. Si attiva per richieste che coinvolgono test di sicurezza Postman, raccolta di sicurezza API, test API automatizzati o test API OWASP con Postman.
