Postman을 사용하여 인증 우회, 권한 부여 결함, 주입 및 데이터 노출을 포함한 OWASP API 보안 상위 10개 취약점을 테스트하는 컬렉션을 구축하여 구조화된 API 보안 테스트를 수행합니다. 테스터는 여러 사용자 역할이 있는 환경을 만들고, 자동화된 보안 검증을 위한 테스트 스크립트를 작성하고, CI/CD 보안 테스트를 위해 Postman을 OWASP ZAP 및 Newman과 통합합니다. Postman 보안 테스트, API 보안 수집, 자동화된 API 테스트 또는 Postman을 사용한 OWASP API 테스트와 관련된 요청에 대해 활성화됩니다.
