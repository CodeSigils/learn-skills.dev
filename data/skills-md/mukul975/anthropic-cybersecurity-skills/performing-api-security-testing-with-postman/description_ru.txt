Использует Postman для структурированного тестирования безопасности API путем создания коллекций, проверяющих 10 основных уязвимостей безопасности API OWASP, включая обход аутентификации, недостатки авторизации, внедрение и раскрытие данных. Тестер создает среды с несколькими ролями пользователей, пишет тестовые сценарии для автоматической проверки безопасности и интегрирует Postman с OWASP ZAP и Newman для тестирования безопасности CI/CD. Активируется для запросов, связанных с тестированием безопасности Postman, сбором данных о безопасности API, автоматическим тестированием API или тестированием API OWASP с помощью Postman.
