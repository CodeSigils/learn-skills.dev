Utiliza Postman para realizar pruebas de seguridad de API estructuradas mediante la creación de colecciones que prueban las 10 vulnerabilidades principales de seguridad de API de OWASP, incluida la omisión de autenticación, fallas de autorización, inyección y exposición de datos. El probador crea entornos con múltiples roles de usuario, escribe scripts de prueba para la validación de seguridad automatizada e integra Postman con OWASP ZAP y Newman para pruebas de seguridad CI/CD. Se activa para solicitudes que involucran pruebas de seguridad de Postman, recopilación de seguridad de API, pruebas de API automatizadas o pruebas de API OWASP con Postman.
