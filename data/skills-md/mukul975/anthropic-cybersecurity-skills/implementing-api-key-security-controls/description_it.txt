Implementa controlli sicuri di generazione, archiviazione, rotazione e revoca delle chiavi API per proteggere le credenziali di autenticazione API da perdite, forza bruta e abusi. L'ingegnere progetta formati di chiave API con entropia sufficiente, implementa l'hashing sicuro per l'archiviazione, applica l'ambito per chiave e la limitazione della velocità, monitora le chiavi trapelate nei repository pubblici e crea flussi di lavoro di rotazione delle chiavi. Si attiva per richieste che coinvolgono la gestione delle chiavi API, la sicurezza delle chiavi API, la policy di rotazione delle chiavi o la protezione delle credenziali API.
