Implémente des contrôles sécurisés de génération, de stockage, de rotation et de révocation de clés API pour protéger les informations d'identification d'authentification API contre les fuites, la force brute et les abus. L'ingénieur conçoit des formats de clés API avec une entropie suffisante, met en œuvre un hachage sécurisé pour le stockage, applique la portée par clé et la limitation du débit, surveille les clés divulguées dans les référentiels publics et crée des flux de travail de rotation des clés. S'active pour les demandes impliquant la gestion des clés API, la sécurité des clés API, la politique de rotation des clés ou la protection des informations d'identification API.
