Implementa controles seguros de generación, almacenamiento, rotación y revocación de claves API para proteger las credenciales de autenticación de API contra fugas, fuerza bruta y abuso. El ingeniero diseña formatos de claves API con suficiente entropía, implementa hash seguro para el almacenamiento, aplica el alcance y la limitación de velocidad por clave, monitorea las claves filtradas en repositorios públicos y crea flujos de trabajo de rotación de claves. Se activa para solicitudes que involucran administración de claves API, seguridad de claves API, política de rotación de claves o protección de credenciales API.
