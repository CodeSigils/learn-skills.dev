Реализует безопасное создание, хранение, ротацию и отзыв ключей API для защиты учетных данных аутентификации API от утечки, грубой силы и злоупотреблений. Инженер разрабатывает форматы ключей API с достаточной энтропией, реализует безопасное хеширование для хранения, обеспечивает определение области действия каждого ключа и ограничение скорости, отслеживает утечку ключей в общедоступных репозиториях и строит рабочие процессы ротации ключей. Активируется для запросов, связанных с управлением ключами API, безопасностью ключей API, политикой ротации ключей или защитой учетных данных API.
