يطبق ضوابط آمنة لإنشاء مفاتيح API وتخزينها وتدويرها وإبطالها لحماية بيانات اعتماد مصادقة API من التسرب والقوة الغاشمة وإساءة الاستخدام. يصمم المهندس تنسيقات مفاتيح API مع إنتروبيا كافية، وينفذ التجزئة الآمنة للتخزين، ويفرض تحديد النطاق لكل مفتاح وتحديد المعدل، ويراقب المفاتيح المسربة في المستودعات العامة، ويبني سير عمل تدوير المفاتيح. يتم التنشيط للطلبات التي تتضمن إدارة مفاتيح واجهة برمجة التطبيقات، أو أمان مفتاح واجهة برمجة التطبيقات، أو سياسة تدوير المفاتيح، أو حماية بيانات اعتماد واجهة برمجة التطبيقات.
