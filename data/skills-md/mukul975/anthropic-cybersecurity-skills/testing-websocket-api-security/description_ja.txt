WebSocket アップグレード時の認証の欠如、クロスサイト WebSocket ハイジャッキング (CSWSH)、WebSocket メッセージを介したインジェクション攻撃、不十分な入力検証、メッセージ フラッディングによるサービス拒否、WebSocket フレームを介した情報漏洩などのセキュリティ脆弱性について、WebSocket API 実装をテストします。テスターは、Burp Suite を使用して WebSocket ハンドシェイクとメッセージを傍受し、悪意のあるペイロードを作成し、WebSocket チャネルでの認証バイパスをテストします。 WebSocket セキュリティ テスト、WS ペネトレーション テスト、CSWSH 攻撃、またはリアルタイム API セキュリティ評価を含むリクエストに対してアクティブ化されます。
