Тестирует реализации API WebSocket на наличие уязвимостей безопасности, включая отсутствие аутентификации при обновлении WebSocket, межсайтовый перехват WebSocket (CSWSH), атаки путем внедрения через сообщения WebSocket, недостаточную проверку входных данных, отказ в обслуживании посредством лавинной рассылки сообщений и утечку информации через фреймы WebSocket. Тестер перехватывает рукопожатия и сообщения WebSocket с помощью Burp Suite, создает вредоносные полезные данные и тестирует обход авторизации на каналах WebSocket. Активируется для запросов, включающих тестирование безопасности WebSocket, тестирование на проникновение WS, атаку CSWSH или оценку безопасности API в реальном времени.
