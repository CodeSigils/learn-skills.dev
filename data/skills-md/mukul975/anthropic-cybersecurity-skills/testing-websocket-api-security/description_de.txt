Testet WebSocket-API-Implementierungen auf Sicherheitslücken, darunter fehlende Authentifizierung beim WebSocket-Upgrade, Cross-Site WebSocket Hijacking (CSWSH), Injektionsangriffe durch WebSocket-Nachrichten, unzureichende Eingabevalidierung, Denial-of-Service durch Nachrichtenflutung und Informationslecks durch WebSocket-Frames. Der Tester fängt WebSocket-Handshakes und -Nachrichten mithilfe der Burp Suite ab, erstellt bösartige Payloads und testet die Autorisierungsumgehung auf WebSocket-Kanälen. Wird für Anfragen aktiviert, die WebSocket-Sicherheitstests, WS-Penetrationstests, CSWSH-Angriffe oder Echtzeit-API-Sicherheitsbewertungen umfassen.
