Teste les implémentations de l'API WebSocket pour détecter les vulnérabilités de sécurité, notamment l'authentification manquante lors de la mise à niveau de WebSocket, le détournement de sites WebSocket (CSWSH), les attaques par injection via des messages WebSocket, la validation d'entrée insuffisante, le déni de service via l'inondation de messages et la fuite d'informations via les trames WebSocket. Le testeur intercepte les poignées de main et les messages WebSocket à l'aide de Burp Suite, crée des charges utiles malveillantes et teste le contournement d'autorisation sur les canaux WebSocket. S'active pour les demandes impliquant des tests de sécurité WebSocket, des tests d'intrusion WS, une attaque CSWSH ou une évaluation de la sécurité des API en temps réel.
