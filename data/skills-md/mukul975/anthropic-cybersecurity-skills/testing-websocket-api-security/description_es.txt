Prueba las implementaciones de la API de WebSocket para detectar vulnerabilidades de seguridad, incluida la falta de autenticación en la actualización de WebSocket, el secuestro de WebSocket entre sitios (CSWSH), los ataques de inyección a través de mensajes de WebSocket, la validación de entrada insuficiente, la denegación de servicio mediante inundación de mensajes y la fuga de información a través de marcos de WebSocket. El probador intercepta mensajes y apretones de manos de WebSocket utilizando Burp Suite, crea cargas útiles maliciosas y prueba la omisión de autorización en los canales de WebSocket. Se activa para solicitudes que involucran pruebas de seguridad de WebSocket, pruebas de penetración de WS, ataques CSWSH o evaluaciones de seguridad de API en tiempo real.
