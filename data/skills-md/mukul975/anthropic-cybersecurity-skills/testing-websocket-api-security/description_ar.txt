اختبارات تطبيقات WebSocket API للثغرات الأمنية بما في ذلك المصادقة المفقودة عند ترقية WebSocket، وCross-Site WebSocket Hijacking (CSWSH)، وهجمات الحقن من خلال رسائل WebSocket، والتحقق غير الكافي من صحة الإدخال، ورفض الخدمة عبر تدفق الرسائل، وتسرب المعلومات من خلال إطارات WebSocket. يعترض المُختبر مصافحات ورسائل WebSocket باستخدام Burp Suite، ويصنع حمولات ضارة، ويختبر تجاوز التفويض على قنوات WebSocket. يتم التنشيط للطلبات التي تتضمن اختبار أمان WebSocket أو اختبار اختراق WS أو هجوم CSWSH أو تقييم أمان واجهة برمجة التطبيقات في الوقت الفعلي.
