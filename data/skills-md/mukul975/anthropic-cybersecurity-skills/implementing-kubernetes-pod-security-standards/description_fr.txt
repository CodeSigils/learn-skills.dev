Choisit et applique la norme de sécurité des pods Kubernetes appropriée (privilégié, de base, restreint) pour une charge de travail : ce que chaque profil interdit, comment mapper les charges de travail existantes à un profil, quels champs securityContext doivent modifier et comment planifier une migration PodSecurityPolicy vers PSS sans interrompre les pods en cours d'exécution. À utiliser pour décider sous quel profil de sécurité d'espace un espace de noms ou une charge de travail doit s'exécuter, pour vérifier quelles charges de travail échoueraient en mode restreint, pour planifier une migration PSP ou pour mapper la posture de sécurité d'un pod à un contrôle de conformité. Mots-clés : normes de sécurité des pods, PSS, privilégié, ligne de base, restreint, securityContext, runAsNonRoot, suppression de TOUTES les fonctionnalités, seccomp RuntimeDefault, migration PSP. Ne pas utiliser pour configurer le contrôleur d'admission qui applique ces profils - utilisez Implementing-pod-security-admission-controller.
