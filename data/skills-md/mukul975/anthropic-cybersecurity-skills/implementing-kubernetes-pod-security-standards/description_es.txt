Elige y aplica el estándar de seguridad de pods de Kubernetes correcto (privilegiado, básico, restringido) para una carga de trabajo: qué prohíbe cada perfil, cómo asignar cargas de trabajo existentes a un perfil, qué campos de contexto de seguridad deben cambiar y cómo planificar una migración de PodSecurityPolicy a PSS sin interrumpir los pods en ejecución. Úselo para decidir con qué perfil de seguridad del pod se debe ejecutar un espacio de nombres o carga de trabajo, auditar qué cargas de trabajo fallarían en Restringido, planificar una migración de PSP o asignar la postura de seguridad del pod a un control de cumplimiento. Palabras clave: Estándares de seguridad de pod, PSS, Privileged, Baseline, Restricted, securityContext, runAsNonRoot, eliminar TODAS las capacidades, seccomp RuntimeDefault, migración de PSP. No lo use para configurar el controlador de admisión que aplica estos perfiles; use implementar-pod-security-admission-controller.
