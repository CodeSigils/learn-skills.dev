Erkennt und verhindert Code-Injection-Angriffe, die auf serverlose Funktionen (AWS Lambda, Azure Functions, Google Cloud Functions) abzielen, durch Event Source Poisoning, bösartige Layer-Injection, Laufzeitbefehlsausführung und IAM-Berechtigungseskalation durch Funktionsänderung. Der Analyst kombiniert statische Analyse von Funktionscode, CloudTrail-Ereigniskorrelation, Überwachung des Laufzeitverhaltens und IAM-Richtlinienprüfung, um Injektionsvektoren über die erweiterte serverlose Angriffsfläche hinweg zu identifizieren, einschließlich API Gateway, S3, SQS, DynamoDB Streams und CloudWatch-Ereignisauslöser. Wird für Anfragen aktiviert, die eine Lambda-Sicherheitsbewertung, serverlose Einschleusungserkennung, Funktionsereignis-Poisoning-Analyse oder serverlose Berechtigungseskalationsuntersuchung betreffen.
