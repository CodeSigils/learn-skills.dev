Détecte et prévient les attaques par injection de code ciblant les fonctions sans serveur (AWS Lambda, Azure Functions, Google Cloud Functions) via l'empoisonnement de la source d'événements, l'injection de couches malveillantes, l'exécution de commandes d'exécution et l'élévation des privilèges IAM via la modification de fonctions. L'analyste combine l'analyse statique du code de fonction, la corrélation des événements CloudTrail, la surveillance du comportement d'exécution et l'audit des politiques IAM pour identifier les vecteurs d'injection sur la surface d'attaque sans serveur étendue, notamment API Gateway, S3, SQS, DynamoDB Streams et les déclencheurs d'événements CloudWatch. S'active pour les requêtes impliquant une évaluation de sécurité Lambda, une détection d'injection sans serveur, une analyse d'empoisonnement d'événement de fonction ou une enquête d'élévation de privilèges sans serveur.
