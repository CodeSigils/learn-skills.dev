Detecta y previene ataques de inyección de código dirigidos a funciones sin servidor (AWS Lambda, Azure Functions, Google Cloud Functions) mediante envenenamiento de fuentes de eventos, inyección de capas maliciosas, ejecución de comandos en tiempo de ejecución y escalada de privilegios de IAM mediante modificación de funciones. El analista combina el análisis estático del código de función, la correlación de eventos de CloudTrail, el monitoreo del comportamiento en tiempo de ejecución y la auditoría de políticas de IAM para identificar vectores de inyección en toda la superficie de ataque sin servidor ampliada, incluidos API Gateway, S3, SQS, DynamoDB Streams y activadores de eventos de CloudWatch. Se activa para solicitudes que involucran evaluación de seguridad de Lambda, detección de inyección sin servidor, análisis de envenenamiento de eventos de función o investigación de escalada de privilegios sin servidor.
