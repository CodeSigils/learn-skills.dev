Rileva e previene gli attacchi di code injection che prendono di mira funzioni serverless (AWS Lambda, Funzioni di Azure, Google Cloud Functions) attraverso l'avvelenamento dell'origine eventi, l'iniezione di livelli dannosi, l'esecuzione di comandi di runtime e l'escalation dei privilegi IAM tramite la modifica delle funzioni. L'analista combina l'analisi statica del codice della funzione, la correlazione degli eventi CloudTrail, il monitoraggio del comportamento in fase di esecuzione e il controllo delle policy IAM per identificare i vettori di iniezione attraverso la superficie di attacco serverless estesa, inclusi API Gateway, S3, SQS, DynamoDB Streams e trigger di eventi CloudWatch. Si attiva per richieste che coinvolgono la valutazione della sicurezza Lambda, il rilevamento dell'iniezione serverless, l'analisi dell'avvelenamento da eventi funzionali o l'indagine sull'escalation dei privilegi serverless.
