يكتشف ويمنع هجمات حقن التعليمات البرمجية التي تستهدف الوظائف بدون خادم (AWS Lambda وAzure Functions وGoogle Cloud Functions) من خلال تسميم مصدر الحدث وحقن الطبقة الضارة وتنفيذ أوامر وقت التشغيل وتصعيد امتيازات IAM عبر تعديل الوظيفة. يجمع المحلل بين التحليل الثابت لرمز الوظيفة، وارتباط حدث CloudTrail، ومراقبة سلوك وقت التشغيل، وتدقيق سياسة IAM لتحديد متجهات الحقن عبر سطح الهجوم الموسع بدون خادم بما في ذلك مشغلات API Gateway وS3 وSQS وDynamoDB Streams وCloudWatch. يتم التنشيط للطلبات التي تتضمن تقييم أمان Lambda، أو اكتشاف الحقن بدون خادم، أو تحليل تسمم حدث الوظيفة، أو التحقيق في تصعيد الامتيازات بدون خادم.
