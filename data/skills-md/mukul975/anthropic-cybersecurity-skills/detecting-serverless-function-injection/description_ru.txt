Обнаруживает и предотвращает атаки с внедрением кода, нацеленные на бессерверные функции (AWS Lambda, функции Azure, функции Google Cloud) посредством отравления источника событий, внедрения вредоносного слоя, выполнения команд во время выполнения и повышения привилегий IAM посредством модификации функции. Аналитик объединяет статический анализ функционального кода, корреляцию событий CloudTrail, мониторинг поведения во время выполнения и аудит политик IAM для определения векторов внедрения в расширенную поверхность бессерверных атак, включая API Gateway, S3, SQS, DynamoDB Streams и триггеры событий CloudWatch. Активируется для запросов, включающих оценку безопасности Lambda, обнаружение бессерверного внедрения, анализ отравления функциональных событий или расследование бессерверного повышения привилегий.
