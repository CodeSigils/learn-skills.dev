Проводит внешнюю разведку с использованием методов разведки с открытым исходным кодом (OSINT) для составления карты внешней поверхности атаки организации без прямого взаимодействия с целевыми системами. Тестер собирает информацию из общедоступных источников, включая записи DNS, журналы прозрачности сертификатов, поисковые системы, социальные сети, репозитории кода и базы данных об утечке данных, для создания комплексного целевого профиля. Активируется для запросов, связанных с разведкой OSINT, внешним мониторингом, картированием поверхностей атак или пассивным сбором информации.
