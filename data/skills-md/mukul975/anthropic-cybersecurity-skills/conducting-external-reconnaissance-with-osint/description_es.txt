Realiza reconocimiento externo utilizando técnicas de inteligencia de código abierto (OSINT) para mapear la superficie de ataque externa de una organización sin interactuar directamente con los sistemas de destino. El evaluador recopila información de fuentes públicas, incluidos registros DNS, registros de transparencia de certificados, motores de búsqueda, redes sociales, repositorios de códigos y bases de datos de violaciones de datos para crear un perfil de destino completo. Se activa para solicitudes que involucran reconocimiento OSINT, huella externa, mapeo de superficie de ataque o recopilación pasiva de información.
