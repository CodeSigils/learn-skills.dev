Отслеживает журналы прозрачности сертификатов (CT) для обнаружения несанкционированной выдачи сертификатов, обнаружения поддоменов с помощью данных CT и оповещения о подозрительной активности сертификатов для принадлежащих доменов. Использует API crt.sh и прямой запрос журнала CT на основе RFC 6962 для создания конвейеров непрерывного мониторинга, которые выявляют мошеннические сертификаты, отслеживают поведение ЦС и отображают поверхность внешней атаки. Активируется для запросов, включающих мониторинг прозрачности сертификатов, аудит журналов CT, обнаружение поддоменов с помощью сертификатов или оповещение о выдаче сертификатов.
