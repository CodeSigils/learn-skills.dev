Realiza ataques de introspección GraphQL que extraen el esquema API completo (tipos, consultas, mutaciones, suscripciones, definiciones de campos), mapea la superficie de ataque, prueba los límites de profundidad/complejidad de las consultas y explota las debilidades específicas de GraphQL, como ataques por lotes, fuerza bruta basada en alias y DoS de consultas anidadas. Úselo para pruebas de seguridad GraphQL, enumeración de esquemas o pruebas de penetración de API GraphQL.
