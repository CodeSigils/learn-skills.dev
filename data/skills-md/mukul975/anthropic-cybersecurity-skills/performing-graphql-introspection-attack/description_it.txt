Esegue attacchi di introspezione GraphQL che estraggono lo schema completo dell'API (tipi, query, mutazioni, sottoscrizioni, definizioni dei campi), mappano la superficie d'attacco, testano i limiti di profondità/complessità delle query e sfruttano vulnerabilità specifiche di GraphQL come attacchi di batching, brute force basato su alias e DoS mediante query nidificate. Usalo per test di sicurezza GraphQL, enumerazione dello schema o penetration testing delle API GraphQL.
