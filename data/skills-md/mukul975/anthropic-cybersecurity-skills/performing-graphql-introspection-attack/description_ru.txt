Выполняет интроспекционные атаки GraphQL, которые извлекают полную схему API (типы, запросы, мутации, подписки, определения полей), отображают поверхность атаки, проверяют ограничения глубины/сложности запроса и используют специфичные для GraphQL слабые места, такие как пакетные атаки, перебор на основе псевдонимов и DoS вложенных запросов. Используйте для тестирования безопасности GraphQL, перечисления схем или тестирования на проникновение GraphQL API.
