Analizza i log WAF (ModSecurity/AWS WAF/Cloudflare) per rilevare campagne di attacchi SQL injection. Analizza i log di controllo ModSecurity e i log eventi JSON WAF per identificare i modelli SQLi (UNION SELECT, OR 1=1, SLEEP(), BENCHMARK()), tiene traccia delle fonti di attacco, correla i tentativi di injection in più fasi e genera report sugli incidenti con classificazione OWASP.
