Анализируйте журналы WAF (ModSecurity/AWS WAF/Cloudflare) для обнаружения атак с использованием SQL-инъекций. Анализирует журналы аудита ModSecurity и журналы событий JSON WAF для выявления шаблонов SQLi (UNION SELECT, OR 1=1, SLEEP(), BENCHMARK()), отслеживает источники атак, сопоставляет попытки многоэтапного внедрения и генерирует отчеты об инцидентах с классификацией OWASP.
