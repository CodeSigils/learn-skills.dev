Анализируйте журналы доступа Apache и Nginx для обнаружения попыток SQL-инъекций, включения локальных файлов, обхода каталогов, отпечатков пальцев веб-сканера и шаблонов грубой силы. Использует сопоставление шаблонов на основе регулярных выражений с сигнатурами атак OWASP, расширение GeoIP для атрибуции источника и статистическое обнаружение аномалий для выявления отклонений частоты запросов и размера ответа.
