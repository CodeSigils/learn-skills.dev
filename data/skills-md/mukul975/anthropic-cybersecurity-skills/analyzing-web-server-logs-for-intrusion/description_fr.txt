Analysez les journaux d'accès Apache et Nginx pour détecter les tentatives d'injection SQL, l'inclusion de fichiers locaux, la traversée de répertoires, les empreintes digitales du scanner Web et les modèles de force brute. Utilise la correspondance de modèles basée sur les expressions régulières avec les signatures d'attaque OWASP, l'enrichissement GeoIP pour l'attribution de la source et la détection d'anomalies statistiques pour les valeurs aberrantes de fréquence de requête et de taille de réponse.
