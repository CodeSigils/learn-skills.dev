تحليل سجلات الوصول إلى Apache وNginx لاكتشاف محاولات حقن SQL، وإدراج الملفات المحلية، واجتياز الدليل، وبصمات ماسح الويب، وأنماط القوة الغاشمة. يستخدم مطابقة النمط المستند إلى regex ضد توقيعات هجوم OWASP، وإثراء GeoIP لإسناد المصدر، والكشف الإحصائي عن الشذوذ لتكرار الطلب والقيم المتطرفة لحجم الاستجابة.
