Analizza i log di accesso di Apache e Nginx per rilevare tentativi di SQL injection, inclusione di file locali, attraversamento di directory, impronte digitali di scanner web e modelli di forza bruta. Utilizza la corrispondenza di modelli basata su regex rispetto alle firme di attacco OWASP, l'arricchimento GeoIP per l'attribuzione della fonte e il rilevamento statistico delle anomalie per la frequenza delle richieste e i valori anomali delle dimensioni della risposta.
