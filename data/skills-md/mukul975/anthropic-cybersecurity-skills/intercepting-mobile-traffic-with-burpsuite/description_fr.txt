Intercepte et analyse le trafic HTTP/HTTPS des applications mobiles à l'aide du proxy Burp Suite pour identifier les communications API non sécurisées, les failles d'authentification, les fuites de données et les vulnérabilités côté serveur. À utiliser lors de la réalisation de tests d'intrusion d'applications mobiles, de l'évaluation de la sécurité des API ou de l'évaluation des modèles de communication client-serveur. S'active pour les demandes impliquant l'interception du trafic mobile, le proxy mobile Burp Suite, les tests de sécurité API ou l'analyse HTTPS mobile.
