يعترض ويحلل حركة مرور HTTP/HTTPS من تطبيقات الهاتف المحمول باستخدام وكيل Burp Suite لتحديد اتصالات API غير الآمنة، وعيوب المصادقة، وتسرب البيانات، ونقاط الضعف من جانب الخادم. يُستخدم عند إجراء اختبار اختراق تطبيقات الهاتف المحمول، أو تقييم أمان واجهة برمجة التطبيقات (API)، أو تقييم أنماط الاتصال بين العميل والخادم. يتم التنشيط للطلبات التي تتضمن اعتراض حركة مرور الهاتف المحمول، أو وكيل Burp Suite المحمول، أو اختبار أمان واجهة برمجة التطبيقات (API)، أو تحليل HTTPS المحمول.
