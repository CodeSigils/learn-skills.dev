Перехватывает и анализирует HTTP/HTTPS-трафик от мобильных приложений с помощью прокси-сервера Burp Suite для выявления небезопасных соединений API, ошибок аутентификации, утечки данных и уязвимостей на стороне сервера. Используйте при проведении тестирования на проникновение мобильных приложений, оценке безопасности API или оценке шаблонов взаимодействия клиент-сервер. Активируется для запросов, связанных с перехватом мобильного трафика, мобильным прокси-сервером Burp Suite, тестированием безопасности API или анализом мобильного HTTPS.
