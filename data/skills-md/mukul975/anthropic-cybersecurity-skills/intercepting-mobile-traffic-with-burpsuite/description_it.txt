Intercetta e analizza il traffico HTTP/HTTPS dalle applicazioni mobili utilizzando il proxy Burp Suite per identificare comunicazioni API non sicure, difetti di autenticazione, fuga di dati e vulnerabilità lato server. Da utilizzare quando si eseguono test di penetrazione delle applicazioni mobili, si valuta la sicurezza delle API o si valutano i modelli di comunicazione client-server. Si attiva per richieste che coinvolgono l'intercettazione del traffico mobile, proxy mobile Burp Suite, test di sicurezza API o analisi HTTPS mobile.
