Intercepta y analiza el tráfico HTTP/HTTPS de aplicaciones móviles utilizando el proxy Burp Suite para identificar comunicaciones API inseguras, fallas de autenticación, fugas de datos y vulnerabilidades del lado del servidor. Úselo al realizar pruebas de penetración de aplicaciones móviles, evaluar la seguridad de API o evaluar patrones de comunicación cliente-servidor. Se activa para solicitudes que involucran interceptación de tráfico móvil, proxy móvil Burp Suite, pruebas de seguridad API o análisis HTTPS móvil.
