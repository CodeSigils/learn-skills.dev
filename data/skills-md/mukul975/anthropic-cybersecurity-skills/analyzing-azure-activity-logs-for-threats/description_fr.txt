Interroge les journaux d’activité et les journaux de connexion d’Azure Monitor via Azure-monitor-query pour détecter les opérations administratives suspectes, les déplacements impossibles, l’élévation de privilèges et les modifications de ressources. Crée des requêtes KQL pour la recherche des menaces dans les environnements Azure. À utiliser lors de l’enquête sur une activité suspecte d’un locataire Azure ou lors de la création de détections SIEM dans le cloud.
