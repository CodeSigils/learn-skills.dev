Запрашивает журналы активности Azure Monitor и журналы входа с помощью azure-monitor-query для обнаружения подозрительных административных операций, невозможности перемещения, повышения привилегий и изменений ресурсов. Создает запросы KQL для поиска угроз в средах Azure. Используйте при расследовании подозрительной активности клиентов Azure или при построении облачных обнаружений SIEM.
