Esegue query sui log di attività e sui log di accesso di Monitoraggio di Azure tramite azure-monitor-query per rilevare operazioni amministrative sospette, viaggi impossibili, escalation di privilegi e modifiche alle risorse. Crea query KQL per la ricerca delle minacce negli ambienti Azure. Da utilizzare durante l'analisi di attività sospette del tenant di Azure o la creazione di rilevamenti SIEM cloud.
