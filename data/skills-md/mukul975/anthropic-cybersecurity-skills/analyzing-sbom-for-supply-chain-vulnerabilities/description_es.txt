Analiza la lista de materiales de software (SBOM) en formatos CycloneDX y SPDX JSON para identificar vulnerabilidades de la cadena de suministro correlacionando componentes con la base de datos NVD CVE a través de la API NVD 2.0. Crea gráficos de dependencia, calcula puntuaciones de riesgo, identifica rutas de vulnerabilidad transitivas y genera informes de cumplimiento. Se activa para solicitudes que involucran análisis SBOM, análisis de composición de software, evaluación de seguridad de la cadena de suministro, escaneo de vulnerabilidades de dependencia, análisis CycloneDX/SPDX o correlación CVE.
