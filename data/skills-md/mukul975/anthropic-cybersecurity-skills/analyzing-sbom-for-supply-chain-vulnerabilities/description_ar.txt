يوزع قائمة مواد البرنامج (SBOM) بتنسيقات CycloneDX وSPDX JSON لتحديد نقاط الضعف في سلسلة التوريد من خلال ربط المكونات بقاعدة بيانات NVD CVE عبر NVD 2.0 API. إنشاء الرسوم البيانية للتبعية، وحساب درجات المخاطر، وتحديد مسارات الضعف العابرة، وإنشاء تقارير الامتثال. يتم التنشيط للطلبات التي تتضمن تحليل SBOM، أو تحليل تكوين البرامج، أو تقييم أمان سلسلة التوريد، أو فحص ثغرات التبعية، أو تحليل CycloneDX/SPDX، أو ارتباط CVE.
