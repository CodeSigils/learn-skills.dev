Анализирует спецификацию программного обеспечения (SBOM) в форматах CycloneDX и SPDX JSON для выявления уязвимостей цепочки поставок путем сопоставления компонентов с базой данных NVD CVE через API NVD 2.0. Строит графики зависимостей, рассчитывает оценки риска, определяет транзитивные пути уязвимостей и генерирует отчеты о соответствии. Активируется для запросов, включающих анализ SBOM, анализ состава программного обеспечения, оценку безопасности цепочки поставок, сканирование уязвимостей зависимостей, анализ CycloneDX/SPDX или корреляцию CVE.
