Analizza la distinta base del software (SBOM) nei formati CycloneDX e SPDX JSON per identificare le vulnerabilità della catena di fornitura correlando i componenti con il database CVE NVD tramite l'API NVD 2.0. Costruisce grafici delle dipendenze, calcola i punteggi di rischio, identifica i percorsi di vulnerabilità transitiva e genera report di conformità. Si attiva per richieste che coinvolgono analisi SBOM, analisi della composizione software, valutazione della sicurezza della catena di fornitura, scansione delle vulnerabilità delle dipendenze, analisi CycloneDX/SPDX o correlazione CVE.
