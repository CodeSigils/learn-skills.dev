Подписывает и проверяет происхождение образа контейнера с помощью Sigstore Cosign, включая подписание OIDC на основе ключа и без ключа (Fulcio, журнал прозрачности Rekor), аттестации SLSA и обеспечение проверки подписи с помощью контроля доступа Kubernetes. Используйте при подписании изображений для обеспечения безопасности цепочки поставок, настройке подписи OIDC без ключа, прикреплении аттестаций или применении политики только проверенных изображений при входе. Ключевые слова: Cosign, Sigstore, Fulcio, Rekor, без ключа, аттестация, проверка cosign, политика допуска. Не используйте для аттестации конвейера на основе макета in-toto — используйте реализацию-безопасности-цепочки поставок-с-в-тото.
