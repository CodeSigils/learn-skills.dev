Esegue l'acquisizione della memoria Linux utilizzando il modulo kernel LiME (Linux Memory Extractor) e l'analisi con il framework Volatility 3. Estrae elenchi di processi, connessioni di rete, cronologia bash, moduli del kernel caricati e codice inserito dalle immagini della memoria Linux. Da utilizzare quando si esegue la risposta agli incidenti su sistemi Linux compromessi.
