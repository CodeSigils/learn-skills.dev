Effectue l'acquisition de la mémoire Linux à l'aide du module de noyau LiME (Linux Memory Extractor) et l'analyse avec le framework Volatility 3. Extrait les listes de processus, les connexions réseau, l'historique bash, les modules de noyau chargés et le code injecté à partir des images mémoire Linux. À utiliser lors de la réponse aux incidents sur des systèmes Linux compromis.
