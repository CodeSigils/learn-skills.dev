ينفذ عملية الحصول على ذاكرة Linux باستخدام وحدة kernel LiME (Linux Memory Extractor) وتحليلها باستخدام إطار عمل Volatility 3. يستخرج قوائم العمليات، واتصالات الشبكة، وسجل bash، ووحدات kernel المحملة، والتعليمات البرمجية المحقونة من صور ذاكرة Linux. يُستخدم عند تنفيذ الاستجابة للحوادث على أنظمة Linux المخترقة.
