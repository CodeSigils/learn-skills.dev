Выполняет сбор памяти Linux с использованием модуля ядра LiME (Linux Memory Extractor) и анализ с помощью платформы Volatility 3. Извлекает списки процессов, сетевые подключения, историю bash, загруженные модули ядра и внедренный код из образов памяти Linux. Используйте при реагировании на инциденты в скомпрометированных системах Linux.
