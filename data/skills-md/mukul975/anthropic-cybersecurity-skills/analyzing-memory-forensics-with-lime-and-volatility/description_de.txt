Führt die Linux-Speichererfassung mithilfe des Kernelmoduls LiME (Linux Memory Extractor) und die Analyse mit dem Volatility 3-Framework durch. Extrahiert Prozesslisten, Netzwerkverbindungen, Bash-Verlauf, geladene Kernel-Module und injizierten Code aus Linux-Speicherabbildern. Wird zur Reaktion auf Vorfälle auf kompromittierten Linux-Systemen verwendet.
