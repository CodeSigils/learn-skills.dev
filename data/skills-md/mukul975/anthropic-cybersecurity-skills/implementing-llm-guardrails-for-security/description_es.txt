Implementa barreras de validación de entrada y salida para aplicaciones impulsadas por LLM para evitar la inyección rápida, la fuga de datos, la generación de contenido tóxico y resultados alucinados. Crea un canal de validación de seguridad utilizando definiciones de NVIDIA NeMo Guardrails Colang, validadores Python personalizados para la detección de PII y aplicación de políticas de contenido, y el marco de Guardrails AI para la validación de resultados estructurados. El sistema de barreras intercepta tanto las entradas del usuario (bloqueando intentos de inyección, eliminando PII, haciendo cumplir los límites de los temas) como las salidas del modelo (detectando alucinaciones, filtrando contenido tóxico, validando el cumplimiento del esquema JSON). Se activa para solicitudes que involucran validación de salida de LLM, filtrado de contenido de IA, implementación de barreras de seguridad o aplicación de seguridad de LLM.
