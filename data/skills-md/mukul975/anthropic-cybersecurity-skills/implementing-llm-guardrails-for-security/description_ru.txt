Внедряет защитные меры проверки ввода и вывода для приложений на базе LLM, чтобы предотвратить быстрое внедрение, утечку данных, создание токсичного контента и галлюцинаторные выходные данные. Создает конвейер проверки безопасности с использованием определений NVIDIA NeMo Guardrails Colang, пользовательских валидаторов Python для обнаружения PII и соблюдения политики контента, а также платформы Guardrails AI для проверки структурированных выходных данных. Система ограждений перехватывает как вводимые пользователем данные (блокировка попыток внедрения, удаление личных данных, соблюдение границ тем), так и выходные данные модели (обнаружение галлюцинаций, фильтрация токсичного контента, проверка соответствия схемы JSON). Активируется для запросов, включающих проверку выходных данных LLM, фильтрацию контента AI, реализацию ограждений или обеспечение безопасности LLM.
