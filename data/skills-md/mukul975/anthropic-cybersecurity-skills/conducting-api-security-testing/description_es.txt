Realiza pruebas de seguridad de las API REST, GraphQL y gRPC para identificar vulnerabilidades en autenticación, autorización, limitación de velocidad, validación de entradas y lógica empresarial. El evaluador utiliza OWASP API Security Top 10 como marco de prueba, combinando la interceptación de Burp Suite con colecciones de Postman y scripts personalizados para probar la seguridad de los terminales en cada nivel de privilegio. Se activa para solicitudes que involucran pruebas de seguridad de API, pentest de API REST, evaluación de seguridad GraphQL o pruebas de vulnerabilidad de API.
