Effectue des tests de sécurité des API REST, GraphQL et gRPC pour identifier les vulnérabilités en matière d'authentification, d'autorisation, de limitation de débit, de validation des entrées et de logique métier. Le testeur utilise l'OWASP API Security Top 10 comme cadre de test, combinant l'interception de Burp Suite avec des collections Postman et des scripts personnalisés pour tester la sécurité des points de terminaison à chaque niveau de privilège. S'active pour les demandes impliquant des tests de sécurité API, un pentest API REST, une évaluation de la sécurité GraphQL ou des tests de vulnérabilité API.
