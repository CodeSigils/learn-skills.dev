Проводит тестирование безопасности API-интерфейсов REST, GraphQL и gRPC для выявления уязвимостей в аутентификации, авторизации, ограничении скорости, проверке ввода и бизнес-логике. Тестер использует OWASP API Security Top 10 в качестве среды тестирования, сочетая перехват Burp Suite с коллекциями Postman и пользовательскими скриптами для проверки безопасности конечных точек на каждом уровне привилегий. Активируется для запросов, связанных с тестированием безопасности API, пентестом REST API, оценкой безопасности GraphQL или тестированием уязвимостей API.
