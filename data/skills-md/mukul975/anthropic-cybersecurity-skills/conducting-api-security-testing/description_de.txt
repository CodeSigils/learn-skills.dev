Führt Sicherheitstests von REST-, GraphQL- und gRPC-APIs durch, um Schwachstellen in der Authentifizierung, Autorisierung, Ratenbegrenzung, Eingabevalidierung und Geschäftslogik zu identifizieren. Der Tester verwendet die OWASP API Security Top 10 als Test-Framework und kombiniert das Abfangen von Burp Suite mit Postman-Sammlungen und benutzerdefinierten Skripten, um die Endpunktsicherheit auf jeder Berechtigungsebene zu testen. Wird für Anfragen aktiviert, die API-Sicherheitstests, REST-API-Pentest, GraphQL-Sicherheitsbewertung oder API-Schwachstellentests umfassen.
