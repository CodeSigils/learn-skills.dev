إجراء اختبار أمان لواجهات برمجة تطبيقات REST وGraphQL وgRPC لتحديد نقاط الضعف في المصادقة والترخيص وتحديد المعدل والتحقق من صحة الإدخال ومنطق الأعمال. يستخدم المُختبر OWASP API Security Top 10 كإطار عمل للاختبار، ويجمع بين اعتراض Burp Suite ومجموعات Postman والبرامج النصية المخصصة لاختبار أمان نقطة النهاية في كل مستوى امتياز. يتم التنشيط للطلبات التي تتضمن اختبار أمان واجهة برمجة التطبيقات (API)، أو اختبار REST API، أو تقييم أمان GraphQL، أو اختبار ثغرات واجهة برمجة التطبيقات (API).
