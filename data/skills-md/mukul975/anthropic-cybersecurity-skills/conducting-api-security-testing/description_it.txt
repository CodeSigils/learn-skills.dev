Conduce test di sicurezza delle API REST, GraphQL e gRPC per identificare le vulnerabilità nell'autenticazione, nell'autorizzazione, nella limitazione della velocità, nella convalida dell'input e nella logica aziendale. Il tester utilizza OWASP API Security Top 10 come framework di test, combinando l'intercettazione di Burp Suite con raccolte Postman e script personalizzati per testare la sicurezza degli endpoint a ogni livello di privilegio. Si attiva per richieste che coinvolgono test di sicurezza API, pentest API REST, valutazione della sicurezza GraphQL o test di vulnerabilità API.
