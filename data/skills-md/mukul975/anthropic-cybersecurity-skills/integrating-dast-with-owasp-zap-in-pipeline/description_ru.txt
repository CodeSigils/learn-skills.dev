Этот навык охватывает интеграцию OWASP ZAP (Zed Attack Proxy) для динамического тестирования безопасности приложений в конвейерах CI/CD. В нем рассматривается настройка базового, полного сканирования и сканирования API запущенных приложений, интерпретация результатов ZAP, настройка политик сканирования и установка шлюзов качества DAST в GitHub Actions и GitLab CI.
