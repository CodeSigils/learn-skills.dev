Cette compétence couvre l'intégration d'OWASP ZAP (Zed Attack Proxy) pour les tests dynamiques de sécurité des applications dans les pipelines CI/CD. Il aborde la configuration des analyses de base, complètes et API sur les applications en cours d'exécution, l'interprétation des résultats ZAP, le réglage des politiques d'analyse et l'établissement de portes de qualité DAST dans GitHub Actions et GitLab CI.
