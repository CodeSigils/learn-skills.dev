Esta habilidad cubre la integración de OWASP ZAP (Zed Attack Proxy) para pruebas dinámicas de seguridad de aplicaciones en canalizaciones de CI/CD. Aborda la configuración de escaneos de referencia, completos y API contra aplicaciones en ejecución, la interpretación de los hallazgos de ZAP, el ajuste de las políticas de escaneo y el establecimiento de puertas de calidad DAST en GitHub Actions y GitLab CI.
