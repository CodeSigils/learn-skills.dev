يحلل بروتوكولات اتصال الأوامر والتحكم (C2) الخاصة بالبرامج الضارة لفهم أنماط الإشارات وهياكل الأوامر وترميز البيانات والبنية التحتية. يغطي تحليل HTTP وHTTPS وDNS والبروتوكول المخصص C2 لتطوير الكشف وذكاء التهديدات. يتم تنشيطه للطلبات التي تتضمن تحليل C2، أو الكشف عن الإشارات، أو الهندسة العكسية لبروتوكول C2، أو تعيين البنية التحتية للقيادة والتحكم.
