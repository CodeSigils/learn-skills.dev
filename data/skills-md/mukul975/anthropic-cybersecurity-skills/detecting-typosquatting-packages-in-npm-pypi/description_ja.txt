レーベンシュタイン距離やその他の文字列メトリクスを使用してパッケージ名の類似性を分析し、公開日のヒューリスティックを調べて既存のパッケージを模倣して最近作成されたパッケージを特定し、疑わしいパッケージの使用率が正規のターゲットと比べて不釣り合いに低いダウンロード数の異常にフラグを立てることにより、npm および PyPI パッケージ レジストリでのタイポスクワッティング攻撃を検出します。アナリストは、PyPI JSON API と npm レジストリ API にクエリを実行して、自動比較のためのパッケージ メタデータを収集します。パッケージのタイポスクワッティングの検出、依存関係の混乱の分析、悪意のあるパッケージの識別、またはパッケージ レジストリでのソフトウェア サプライ チェーンの脅威ハンティングを含むリクエストに対してアクティブ化されます。
