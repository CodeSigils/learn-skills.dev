Обнаруживает атаки опечаток в реестрах пакетов npm и PyPI, анализируя сходство имен пакетов с использованием расстояния Левенштейна и других строковых метрик, исследуя эвристику даты публикации для выявления недавно созданных пакетов, имитирующих уже существующие, и отмечая аномалии количества загрузок, когда подозрительные пакеты используются непропорционально низко по сравнению с их законными целями. Аналитик запрашивает API JSON PyPI и API реестра npm, чтобы собрать метаданные пакета для автоматического сравнения. Активируется для запросов, связанных с обнаружением опечаток пакетов, анализом путаницы в зависимостях, идентификацией вредоносных пакетов или поиском угроз в цепочке поставок программного обеспечения в реестрах пакетов.
