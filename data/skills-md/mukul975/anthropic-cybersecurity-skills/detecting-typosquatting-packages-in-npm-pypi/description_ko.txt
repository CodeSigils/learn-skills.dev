Levenshtein 거리 및 기타 문자열 메트릭을 사용하여 패키지 이름 유사성을 분석하고, 게시 날짜 휴리스틱을 검사하여 최근에 생성된 패키지를 모방한 패키지를 식별하고, 의심스러운 패키지가 합법적인 대상에 비해 사용량이 지나치게 낮은 이상 다운로드 수에 플래그를 지정하여 npm 및 PyPI 패키지 레지스트리에서 타이포스쿼팅 공격을 탐지합니다. 분석가는 PyPI JSON API 및 npm 레지스트리 API를 쿼리하여 자동 비교를 위한 패키지 메타데이터를 수집합니다. 패키지 타이포스쿼팅 감지, 종속성 혼란 분석, 악성 패키지 식별 또는 패키지 레지스트리의 소프트웨어 공급망 위협 사냥과 관련된 요청에 대해 활성화됩니다.
