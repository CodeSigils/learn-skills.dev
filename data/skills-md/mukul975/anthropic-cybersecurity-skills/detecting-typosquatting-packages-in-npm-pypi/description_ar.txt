يكتشف هجمات typosquatting في سجلات حزم npm وPyPI من خلال تحليل تشابه اسم الحزمة باستخدام مسافة Levenshtein ومقاييس السلسلة الأخرى، وفحص الاستدلال على تاريخ النشر لتحديد الحزم التي تم إنشاؤها مؤخرًا والتي تحاكي الحزم القائمة، ووضع علامة على الحالات الشاذة في عدد التنزيلات حيث يكون استخدام الحزم المشبوهة منخفضًا بشكل غير متناسب مقارنة بأهدافها المشروعة. يقوم المحلل بالاستعلام عن واجهة برمجة التطبيقات PyPI JSON API وnpm Registry API لجمع بيانات تعريف الحزمة للمقارنة التلقائية. يتم تنشيطه للطلبات التي تتضمن الكشف عن الأخطاء المطبعية للحزمة، أو تحليل ارتباك التبعية، أو تحديد الحزمة الضارة، أو البحث عن تهديدات سلسلة توريد البرامج في سجلات الحزم.
