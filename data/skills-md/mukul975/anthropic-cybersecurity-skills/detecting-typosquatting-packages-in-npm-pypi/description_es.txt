Detecta ataques de typosquatting en registros de paquetes npm y PyPI analizando la similitud de los nombres de los paquetes usando la distancia de Levenshtein y otras métricas de cadenas, examinando la heurística de la fecha de publicación para identificar paquetes creados recientemente que imitan a los establecidos y señalando anomalías en el recuento de descargas donde los paquetes sospechosos tienen un uso desproporcionadamente bajo en comparación con sus objetivos legítimos. El analista consulta la API JSON de PyPI y la API de registro npm para recopilar metadatos del paquete para una comparación automatizada. Se activa para solicitudes que involucran detección de errores tipográficos en paquetes, análisis de confusión de dependencias, identificación de paquetes maliciosos o búsqueda de amenazas en la cadena de suministro de software en registros de paquetes.
