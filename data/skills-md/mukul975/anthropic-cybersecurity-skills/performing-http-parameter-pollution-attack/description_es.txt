Ejecuta ataques de contaminación de parámetros HTTP que inyectan parámetros de solicitud duplicados para eludir la validación de entrada, las reglas WAF y otros controles de seguridad cuando los sistemas front-end y back-end analizan los parámetros duplicados de manera diferente. Úselo durante las pruebas de penetración de aplicaciones web para probar inconsistencias en el análisis de parámetros o omisión de validación/WAF.
