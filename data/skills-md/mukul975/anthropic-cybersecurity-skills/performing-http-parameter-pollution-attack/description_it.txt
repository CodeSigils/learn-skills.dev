Esegue attacchi di inquinamento dei parametri HTTP che inseriscono parametri di richiesta duplicati per aggirare la convalida dell'input, le regole WAF e altri controlli di sicurezza quando i sistemi front-end e back-end analizzano i parametri duplicati in modo diverso. Utilizzare durante i test di penetrazione delle applicazioni Web per verificare le incoerenze nell'analisi dei parametri o il bypass di WAF/convalida.
