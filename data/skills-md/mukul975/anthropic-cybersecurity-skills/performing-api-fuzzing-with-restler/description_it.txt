Utilizza Microsoft RESTler per eseguire il fuzzing dell'API REST con stato generando ed eseguendo automaticamente sequenze di test che esercitano gli endpoint API, scoprono le dipendenze produttore-consumatore tra le richieste e trovano bug di sicurezza e affidabilità. Il tester compila una specifica OpenAPI in una grammatica fuzzing RESTler, configura l'autenticazione, esegue modalità test/fuzz-lean/fuzz e analizza i risultati per 500 errori, bypass dell'autenticazione, perdite di risorse e vulnerabilità di iniezione del carico utile. Si attiva per richieste che coinvolgono fuzzing API, test RESTler, test API stateful o scansione automatizzata della sicurezza API.
