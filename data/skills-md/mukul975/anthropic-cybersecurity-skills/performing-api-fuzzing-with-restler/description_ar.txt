يستخدم Microsoft RESTler لإجراء تشويش REST API ذي الحالة عن طريق إنشاء تسلسلات اختبار وتنفيذها تلقائيًا والتي تمارس نقاط نهاية API، واكتشاف تبعيات المنتج والمستهلك بين الطلبات، والعثور على أخطاء الأمان والموثوقية. يقوم المُختبر بتجميع مواصفات OpenAPI في قواعد RESTler الغامضة، وتكوين المصادقة، وتشغيل أوضاع الاختبار/الضبابية/الضبابية، وتحليل النتائج لـ 500 خطأ، وتجاوزات المصادقة، وتسريبات الموارد، ونقاط الضعف في حقن الحمولة النافعة. يتم التنشيط للطلبات التي تتضمن تشويش واجهة برمجة التطبيقات، أو اختبار RESTler، أو اختبار واجهة برمجة التطبيقات ذات الحالة، أو الفحص الأمني ​​التلقائي لواجهة برمجة التطبيقات.
