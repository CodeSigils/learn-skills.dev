Microsoft RESTler を使用して、API エンドポイントを実行し、リクエスト間のプロデューサーとコンシューマーの依存関係を検出し、セキュリティと信頼性のバグを検出するテスト シーケンスを自動的に生成および実行することにより、ステートフル REST API ファジングを実行します。テスターは、OpenAPI 仕様を RESTler ファジング文法にコンパイルし、認証を構成し、テスト/ファズリーン/ファズ モードを実行して、500 エラー、認証バイパス、リソース リーク、およびペイロード インジェクションの脆弱性の結果を分析します。 API ファジング、RESTler テスト、ステートフル API テスト、または自動 API セキュリティ スキャンを含むリクエストに対してアクティブ化されます。
