Utilise Microsoft RESTler pour effectuer un fuzzing avec état de l'API REST en générant et en exécutant automatiquement des séquences de tests qui exercent les points de terminaison de l'API, découvrent les dépendances producteur-consommateur entre les requêtes et détectent les bogues de sécurité et de fiabilité. Le testeur compile une spécification OpenAPI dans une grammaire de fuzzing RESTler, configure l'authentification, exécute les modes test/fuzz-lean/fuzz et analyse les résultats pour 500 erreurs, contournements d'authentification, fuites de ressources et vulnérabilités d'injection de charge utile. S'active pour les requêtes impliquant le fuzzing d'API, les tests RESTler, les tests d'API avec état ou l'analyse automatisée de la sécurité des API.
