Utiliza Microsoft RESTler para realizar fuzzing de API REST con estado generando y ejecutando automáticamente secuencias de prueba que ejercitan puntos finales de API, descubren dependencias entre solicitudes entre productores y consumidores y encuentran errores de seguridad y confiabilidad. El evaluador compila una especificación OpenAPI en una gramática de fuzzing RESTler, configura la autenticación, ejecuta modos de prueba/fuzz-lean/fuzz y analiza los resultados para detectar 500 errores, omisiones de autenticación, fugas de recursos y vulnerabilidades de inyección de carga útil. Se activa para solicitudes que involucran fuzzing de API, pruebas RESTler, pruebas de API con estado o escaneo de seguridad de API automatizado.
