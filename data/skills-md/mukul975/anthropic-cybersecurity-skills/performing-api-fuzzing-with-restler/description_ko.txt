Microsoft RESTler를 사용하여 API 끝점을 실행하는 테스트 시퀀스를 자동으로 생성 및 실행하고, 요청 간의 생산자-소비자 종속성을 발견하고, 보안 및 안정성 버그를 찾아 상태 저장 REST API 퍼징을 수행합니다. 테스터는 OpenAPI 사양을 RESTler 퍼징 문법으로 컴파일하고, 인증을 구성하고, 테스트/fuzz-lean/fuzz 모드를 실행하고, 500개 오류, 인증 우회, 리소스 누출 및 페이로드 주입 취약점에 대한 결과를 분석합니다. API 퍼징, RESTler 테스트, 상태 저장 API 테스트 또는 자동화된 API 보안 검색과 관련된 요청에 대해 활성화됩니다.
