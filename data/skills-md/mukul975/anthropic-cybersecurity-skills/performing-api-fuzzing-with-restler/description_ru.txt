Использует Microsoft RESTler для выполнения фаззинга REST API с отслеживанием состояния путем автоматического создания и выполнения тестовых последовательностей, которые проверяют конечные точки API, обнаруживают зависимости между производителем и потребителем между запросами и находят ошибки безопасности и надежности. Тестер компилирует спецификацию OpenAPI в грамматику фаззинга RESTler, настраивает аутентификацию, запускает режимы тестирования/fuzz-lean/fuzz и анализирует результаты на наличие 500 ошибок, обходов аутентификации, утечек ресурсов и уязвимостей внедрения полезной нагрузки. Активируется для запросов, включающих фаззинг API, тестирование RESTler, тестирование API с отслеживанием состояния или автоматическое сканирование безопасности API.
