Escribe YAML de NetworkPolicy de Kubernetes upstream portátil: denegación predeterminada total, salida DNS, reglas de selector de namespace y pod, que funciona en cualquier CNI conforme como Calico o Cilium. Úsalo cuando la segmentación debe permanecer portable entre CNI, introduciendo una postura de denegación predeterminada, o restringiendo el tráfico este‑oeste entre pods y namespaces sin depender de un CRD de proveedor. Palabras clave: NetworkPolicy, default deny, podSelector, namespaceSelector, ingress, egress, CNI portable. No lo uses para recursos específicos de Calico; usa implementing-kubernetes-network-policy-with-calico.
