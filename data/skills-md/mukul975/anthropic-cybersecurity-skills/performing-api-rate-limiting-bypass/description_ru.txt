Тестирует реализации ограничения скорости API на предмет обхода уязвимостей путем манипулирования заголовками запросов, IP-адресами, методами HTTP, версиями API и схемами кодирования для обхода контроля регулирования запросов. Тестер идентифицирует заголовки ограничения скорости, определяет механизмы принудительного применения и пытается обойти, включая подмену X-Forwarded-For, загрязнение параметров, изменение регистра и манипулирование путями конечной точки. Соответствует OWASP API4:2023 Неограниченное потребление ресурсов. Активируется для запросов, включающих обход ограничения скорости, обход регулирования API, тестирование защиты от перебора или оценку предотвращения злоупотреблений API.
