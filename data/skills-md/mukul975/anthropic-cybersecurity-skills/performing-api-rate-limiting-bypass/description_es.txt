Prueba las implementaciones de limitación de velocidad de API para evitar vulnerabilidades mediante la manipulación de encabezados de solicitud, direcciones IP, métodos HTTP, versiones de API y esquemas de codificación para eludir los controles de limitación de solicitudes. El probador identifica encabezados de límite de velocidad, determina mecanismos de aplicación e intenta omitir, incluida la suplantación de identidad X-Forwarded-For, la contaminación de parámetros, la variación de casos y la manipulación de rutas de puntos finales. Se asigna a OWASP API4:2023 Consumo de recursos sin restricciones. Se activa para solicitudes que implican omisión de límite de velocidad, evasión de limitación de API, pruebas de protección de fuerza bruta o evaluación de prevención de abuso de API.
