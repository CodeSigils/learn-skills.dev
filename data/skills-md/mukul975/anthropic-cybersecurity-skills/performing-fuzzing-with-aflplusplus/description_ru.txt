Выполняет фаззинг скомпилированных двоичных файлов с учетом покрытия с помощью AFL++, инструментирует цели с помощью afl-cc/afl-clang-fast, минимизирует корпуса с помощью afl-cmin и afl-tmin, запускает параллельные кампании с помощью afl-fuzz и сортирует сбои с помощью сценариев CASR или GDB. Используйте для двоичного фаззинга, обнаружения сбоев и повреждений памяти, тестирования на основе покрытия или проведения кампаний по фаззингу AFL++.
