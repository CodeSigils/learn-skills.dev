Развертывает изоляцию удаленного браузера (RBI) в качестве основного компонента архитектуры нулевого доверия. Реализует политики изоляции с категоризацией URL-адресов и маршрутизацией на основе рисков, снятием с охраны и реконструкцией контента (CDR) для очистки файлов, контролем предотвращения потери данных в изолированных сеансах и интеграцией с платформами Secure Web Gateway и ZTNA. На основе подходов Cloudflare Browser Isolation, Menlo Security и Zscaler RBI. Используйте для защиты веб-доступа от эксплойтов нулевого дня, фишинга, кражи учетных данных и кражи данных через браузер.
