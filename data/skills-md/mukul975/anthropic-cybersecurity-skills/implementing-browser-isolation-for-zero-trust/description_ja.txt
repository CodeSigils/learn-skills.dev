リモート ブラウザ分離 (RBI) をゼロ トラスト アーキテクチャのコア コンポーネントとして展開します。 URL の分類とリスクベースのルーティング、ファイルの無害化のためのコンテンツの解除と再構築 (CDR)、分離されたセッション内のデータ損失防止制御、および Secure Web Gateway および ZTNA プラットフォームとの統合による分離ポリシーを実装します。 Cloudflare Browser Isolation、Menlo Security、Zscaler RBI アプローチに基づいています。ゼロデイ エクスプロイト、フィッシング、認証情報の盗難、ブラウザベースのデータ漏洩に対して Web アクセスを強化する場合に使用します。
