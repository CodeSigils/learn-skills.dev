Implementa el aislamiento remoto del navegador (RBI) como componente central de una arquitectura Zero Trust. Implementa políticas de aislamiento con categorización de URL y enrutamiento basado en riesgos, desarmado y reconstrucción de contenido (CDR) para desinfección de archivos, controles de prevención de pérdida de datos dentro de sesiones aisladas e integración con plataformas Secure Web Gateway y ZTNA. Basado en los enfoques Cloudflare Browser Isolation, Menlo Security y Zscaler RBI. Úselo para proteger el acceso web contra exploits de día cero, phishing, robo de credenciales y filtración de datos basados ​​en el navegador.
