제로 트러스트 아키텍처의 핵심 구성 요소로 RBI(원격 브라우저 격리)를 배포합니다. URL 분류 및 위험 기반 라우팅, 파일 삭제를 위한 CDR(콘텐츠 해제 및 재구성), 격리된 세션 내 데이터 손실 방지 제어, 보안 웹 게이트웨이 및 ZTNA 플랫폼과의 통합을 통해 격리 정책을 구현합니다. Cloudflare Browser Isolation, Menlo Security 및 Zscaler RBI 접근 방식을 기반으로 합니다. 제로데이 공격, 피싱, 자격 증명 도용, 브라우저 기반 데이터 유출로부터 웹 액세스를 강화할 때 사용합니다.
