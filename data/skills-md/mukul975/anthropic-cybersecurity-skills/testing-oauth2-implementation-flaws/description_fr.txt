Teste les implémentations OAuth 2.0 et OpenID Connect pour détecter les failles de sécurité, notamment l'interception du code d'autorisation, la manipulation de l'URI de redirection, le CSRF dans les flux OAuth, la fuite de jetons, l'escalade de la portée et le contournement de PKCE. Le testeur évalue le serveur d'autorisation, l'application client et la gestion des jetons pour détecter les erreurs de configuration courantes qui permettent le piratage de compte ou un accès non autorisé. S'active pour les demandes impliquant des tests de sécurité OAuth, une évaluation de vulnérabilité OIDC, un contournement de redirection OAuth2 ou des tests de flux de code d'autorisation.
