Prueba las implementaciones de OAuth 2.0 y OpenID Connect para detectar fallas de seguridad, incluida la interceptación de códigos de autorización, la manipulación de URI de redireccionamiento, CSRF en flujos de OAuth, fuga de tokens, escalamiento de alcance y omisión de PKCE. El evaluador evalúa el servidor de autorización, la aplicación cliente y el manejo de tokens en busca de configuraciones erróneas comunes que permitan la apropiación de cuentas o el acceso no autorizado. Se activa para solicitudes que involucran pruebas de seguridad de OAuth, evaluación de vulnerabilidades de OIDC, omisión de redireccionamiento de OAuth2 o pruebas de flujo de código de autorización.
