Realiza un inventario y descubrimiento de API para identificar todos los puntos finales de API en el entorno de una organización, incluidas las API documentadas, no documentadas, en la sombra, zombis y obsoletas. El probador utiliza análisis de tráfico pasivo, escaneo activo, enumeración de DNS, análisis de JavaScript e inventario de recursos en la nube para crear un catálogo de API completo. Se asigna a OWASP API9:2023 Gestión de inventario inadecuada. Se activa para solicitudes que involucran descubrimiento de API, detección de API oculta, auditoría de inventario de API o mapeo de superficie de ataque.
