يقوم بإجراء جرد واجهة برمجة التطبيقات (API) واكتشافها لتحديد جميع نقاط نهاية واجهة برمجة التطبيقات (API) في بيئة المؤسسة بما في ذلك واجهات برمجة التطبيقات الموثقة وغير الموثقة والظل والزومبي والمهملة. يستخدم المختبر تحليل حركة المرور السلبي، والمسح النشط، وتعداد DNS، وتحليل JavaScript، وجرد الموارد السحابية لإنشاء كتالوج API شامل. خرائط لـ OWASP API9:2023 إدارة المخزون غير الصحيحة. يتم تنشيطه للطلبات التي تتضمن اكتشاف واجهة برمجة التطبيقات (API)، أو اكتشاف واجهة برمجة التطبيقات (Shadow API)، أو تدقيق مخزون واجهة برمجة التطبيقات (API)، أو رسم خرائط سطح الهجوم.
