Выполняет инвентаризацию и обнаружение API для идентификации всех конечных точек API в среде организации, включая документированные, недокументированные, теневые, зомби- и устаревшие API. Тестер использует пассивный анализ трафика, активное сканирование, перечисление DNS, анализ JavaScript и инвентаризацию облачных ресурсов для создания комплексного каталога API. Сопоставляется с OWASP API9:2023 Неправильное управление запасами. Активируется для запросов, включающих обнаружение API, обнаружение теневых API, аудит инвентаризации API или сопоставление поверхностей атак.
