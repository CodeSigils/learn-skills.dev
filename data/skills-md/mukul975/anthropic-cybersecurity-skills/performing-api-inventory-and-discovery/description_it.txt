Esegue l'inventario e il rilevamento delle API per identificare tutti gli endpoint API nell'ambiente di un'organizzazione, comprese le API documentate, non documentate, shadow, zombie e deprecate. Il tester utilizza l'analisi passiva del traffico, la scansione attiva, l'enumerazione DNS, l'analisi JavaScript e l'inventario delle risorse cloud per creare un catalogo API completo. Si associa a OWASP API9:2023 Gestione impropria dell'inventario. Si attiva per richieste che coinvolgono il rilevamento API, il rilevamento API shadow, il controllo dell'inventario API o la mappatura della superficie di attacco.
