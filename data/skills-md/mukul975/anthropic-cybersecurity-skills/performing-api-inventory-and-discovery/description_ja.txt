API インベントリと検出を実行して、文書化された API、文書化されていない API、シャドウ API、ゾンビ API、非推奨 API など、組織の環境内のすべての API エンドポイントを識別します。テスターは、パッシブ トラフィック分析、アクティブ スキャン、DNS 列挙、JavaScript 分析、およびクラウド リソース インベントリを使用して、包括的な API カタログを構築します。 OWASP API9:2023 不適切な在庫管理に対応します。 API 検出、シャドウ API 検出、API インベントリ監査、または攻撃対象領域マッピングを含むリクエストに対してアクティブ化されます。
