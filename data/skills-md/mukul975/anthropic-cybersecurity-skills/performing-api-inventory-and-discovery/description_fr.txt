Effectue l'inventaire et la découverte des API pour identifier tous les points de terminaison d'API dans l'environnement d'une organisation, y compris les API documentées, non documentées, fantômes, zombies et obsolètes. Le testeur utilise l'analyse passive du trafic, l'analyse active, l'énumération DNS, l'analyse JavaScript et l'inventaire des ressources cloud pour créer un catalogue d'API complet. Correspond à l'OWASP API9 : 2023 Gestion inappropriée des stocks. S'active pour les demandes impliquant la découverte d'API, la détection d'API fantôme, l'audit d'inventaire d'API ou la cartographie de la surface d'attaque.
