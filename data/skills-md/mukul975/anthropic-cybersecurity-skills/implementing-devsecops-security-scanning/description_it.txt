Integra il test statico di sicurezza delle applicazioni (SAST), il test dinamico di sicurezza delle applicazioni (DAST) e l'analisi della composizione del software (SCA) nelle pipeline CI/CD utilizzando strumenti open source. Copre Semgrep per SAST, Trivy per SCA e scansione di contenitori, OWASP ZAP per DAST e Gitleaks per il rilevamento di segreti. Si attiva per richieste che coinvolgono la configurazione della pipeline DevSecOps, la scansione di sicurezza automatizzata in CI/CD, l'integrazione SAST/DAST/SCA o l'implementazione della sicurezza con spostamento a sinistra.
