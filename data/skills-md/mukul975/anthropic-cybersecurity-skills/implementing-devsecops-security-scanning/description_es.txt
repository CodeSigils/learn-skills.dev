Integra pruebas de seguridad de aplicaciones estáticas (SAST), pruebas de seguridad de aplicaciones dinámicas (DAST) y análisis de composición de software (SCA) en canalizaciones de CI/CD utilizando herramientas de código abierto. Cubre Semgrep para SAST, Trivy para SCA y escaneo de contenedores, OWASP ZAP para DAST y Gitleaks para detección de secretos. Se activa para solicitudes que involucran la configuración de canalización de DevSecOps, escaneo de seguridad automatizado en CI/CD, integración SAST/DAST/SCA o implementación de seguridad de desplazamiento hacia la izquierda.
