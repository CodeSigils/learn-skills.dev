Интегрирует статическое тестирование безопасности приложений (SAST), динамическое тестирование безопасности приложений (DAST) и анализ состава программного обеспечения (SCA) в конвейеры CI/CD с использованием инструментов с открытым исходным кодом. Охватывает Semgrep для SAST, Trivy для SCA и сканирования контейнеров, OWASP ZAP для DAST и Gitleaks для обнаружения секретов. Активируется для запросов, связанных с настройкой конвейера DevSecOps, автоматическим сканированием безопасности в CI/CD, интеграцией SAST/DAST/SCA или реализацией безопасности со сдвигом влево.
