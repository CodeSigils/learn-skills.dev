Выполняет систематическое тестирование безопасности веб-приложений в соответствии с методологией OWASP Web Security Testing Guide (WSTG) для выявления уязвимостей в аутентификации, авторизации, проверке ввода, управлении сеансами и бизнес-логике. Тестер использует Burp Suite в качестве основного прокси-сервера перехвата наряду с методами ручного тестирования, чтобы найти недостатки, которые пропускают автоматические сканеры. Активируется для запросов, связанных с пентестом веб-приложений, тестированием OWASP, оценкой безопасности приложений или тестированием веб-уязвимостей.
