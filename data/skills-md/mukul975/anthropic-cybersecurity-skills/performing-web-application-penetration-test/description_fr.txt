Effectue des tests de sécurité systématiques des applications Web en suivant la méthodologie OWASP Web Security Testing Guide (WSTG) pour identifier les vulnérabilités dans l'authentification, l'autorisation, la validation des entrées, la gestion des sessions et la logique métier. Le testeur utilise Burp Suite comme principal proxy d'interception, ainsi que des techniques de test manuels pour détecter les failles manquées par les scanners automatisés. S'active pour les demandes impliquant un pentest d'application Web, des tests OWASP, une évaluation de la sécurité des applications ou des tests de vulnérabilité Web.
