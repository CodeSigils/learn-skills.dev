Esegue test di sicurezza sistematici delle applicazioni web seguendo la metodologia OWASP Web Security Testing Guide (WSTG) per identificare le vulnerabilità nell'autenticazione, nell'autorizzazione, nella convalida dell'input, nella gestione delle sessioni e nella logica aziendale. Il tester utilizza Burp Suite come proxy di intercettazione principale insieme a tecniche di test manuali per individuare difetti che gli scanner automatizzati non riescono a rilevare. Si attiva per richieste che coinvolgono pentest dell'app Web, test OWASP, valutazione della sicurezza dell'applicazione o test di vulnerabilità Web.
