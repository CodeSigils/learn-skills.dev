Führt systematische Sicherheitstests von Webanwendungen gemäß der OWASP Web Security Testing Guide (WSTG)-Methodik durch, um Schwachstellen in der Authentifizierung, Autorisierung, Eingabevalidierung, Sitzungsverwaltung und Geschäftslogik zu identifizieren. Der Tester verwendet Burp Suite als primären Abfang-Proxy neben manuellen Testtechniken, um Fehler zu finden, die automatische Scanner übersehen. Wird für Anfragen aktiviert, die Web-App-Pentest, OWASP-Tests, Anwendungssicherheitsbewertung oder Web-Schwachstellentests betreffen.
