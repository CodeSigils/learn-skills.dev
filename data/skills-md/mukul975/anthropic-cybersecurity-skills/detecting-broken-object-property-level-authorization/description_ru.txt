Обнаружение и тестирование на наличие OWASP API3:2023 Broken Object Property Level Authorization (BOPLA), охватывающее чрезмерное раскрытие данных в ответах API и массовое назначение через внедренные свойства тела запроса. Используйте при проверке ответов/запросов API на наличие переоткрытых или перезаписываемых полей объекта, а также при создании правил обнаружения и тестовых примеров для выявления пробелов в авторизации на уровне свойств, которые пропускают проверки на уровне объекта.
