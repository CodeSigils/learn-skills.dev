Detecte y pruebe la autorización de nivel de propiedad de objeto roto (BOPLA) OWASP API3:2023, que cubre la exposición excesiva de datos en las respuestas API y la asignación masiva a través de propiedades inyectadas del cuerpo de la solicitud. Úselo al revisar respuestas/solicitudes de API para campos de objetos sobreexpuestos o sobrescribibles, o al crear reglas de detección y casos de prueba para brechas de autorización a nivel de propiedad que las comprobaciones a nivel de objeto pasan por alto.
