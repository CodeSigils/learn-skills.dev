Rileva e testa l'OWASP API3:2023 Broken Object Property Level Authorization (BOPLA), che copre l'eccessiva esposizione dei dati nelle risposte API e l'assegnazione di massa tramite le proprietà del corpo della richiesta inserite. Da utilizzare durante l'esame delle risposte/richieste API per campi oggetto sovraesposti o sovrascrivibili oppure durante la creazione di regole di rilevamento e casi di test per lacune di autorizzazione a livello di proprietà che i controlli a livello di oggetto non rilevano.
