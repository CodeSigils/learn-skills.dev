Erkennen und testen Sie auf OWASP API3:2023 Broken Object Property Level Authorization (BOPLA), um eine übermäßige Datenexposition in API-Antworten und Massenzuweisungen über injizierte Anforderungstexteigenschaften abzudecken. Verwenden Sie diese Option, wenn Sie API-Antworten/Anfragen auf überbelichtete oder überschreibbare Objektfelder überprüfen oder Erkennungsregeln und Testfälle für Autorisierungslücken auf Eigenschaftsebene erstellen, die bei Prüfungen auf Objektebene übersehen werden.
