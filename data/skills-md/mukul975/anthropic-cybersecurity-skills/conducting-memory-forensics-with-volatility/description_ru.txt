Выполняет криминалистический анализ памяти с использованием Volatility 3 для извлечения доказательств выполнения вредоносного ПО, внедрения процессов, сетевых подключений и кражи учетных данных из дампов оперативной памяти, полученных во время реагирования на инциденты. Охватывает сбор памяти, анализ процессов, проверку DLL и обнаружение вредоносных программ. Активируется для запросов, включающих экспертизу памяти, анализ оперативной памяти, структуру нестабильности, исследование дампа памяти, анализ нестабильных доказательств или сбор оперативной памяти.
