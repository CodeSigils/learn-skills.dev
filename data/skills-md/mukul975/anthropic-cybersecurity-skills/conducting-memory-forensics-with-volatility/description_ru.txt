Выполняет криминалистический анализ памяти с использованием Volatility 3 для извлечения доказательств выполнения вредоносного ПО, внедрения процессов, сетевых подключений и кражи учетных данных из дампов оперативной памяти, полученных во время реагирования на инциденты. Охватывает сбор памяти, анализ процессов, проверку DLL и обнаружение вредоносных программ. Активируется для запросов, связанных с криминалистической экспертизой памяти, анализом оперативной памяти, структурой нестабильности, исследованием дампа памяти, анализом нестабильных доказательств или сбором оперативной памяти.
