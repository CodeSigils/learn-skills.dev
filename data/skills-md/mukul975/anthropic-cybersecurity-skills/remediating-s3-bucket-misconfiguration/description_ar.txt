توفر هذه المهارة إجراءات خطوة بخطوة لتحديد ومعالجة التكوينات الخاطئة لحاوية Amazon S3 التي تعرض البيانات الحساسة للوصول غير المصرح به. ويغطي تمكين S3 Block Public Access على مستويات الحساب والحاوية، ومراجعة سياسات الحاوية وقوائم ACL، وفرض التشفير، وتكوين تسجيل الوصول، ونشر المعالجة الآلية باستخدام AWS Config وLambda.
