Этот навык предоставляет пошаговые процедуры для выявления и исправления неправильных конфигураций корзины Amazon S3, которые подвергают конфиденциальные данные несанкционированному доступу. В нем рассматривается включение публичного доступа S3 Block на уровне учетной записи и корзины, аудит политик корзины и списков управления доступом, принудительное шифрование, настройка ведения журнала доступа и развертывание автоматического исправления с помощью AWS Config и Lambda.
