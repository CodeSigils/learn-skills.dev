Dieser Skill bietet Schritt-für-Schritt-Verfahren zur Identifizierung und Behebung von Amazon S3-Bucket-Fehlkonfigurationen, die sensible Daten dem unbefugten Zugriff aussetzen. Es umfasst die Aktivierung von S3 Block Public Access auf Konto- und Bucket-Ebene, die Prüfung von Bucket-Richtlinien und ACLs, die Durchsetzung der Verschlüsselung, die Konfiguration der Zugriffsprotokollierung und die Bereitstellung automatisierter Korrekturen mithilfe von AWS Config und Lambda.
