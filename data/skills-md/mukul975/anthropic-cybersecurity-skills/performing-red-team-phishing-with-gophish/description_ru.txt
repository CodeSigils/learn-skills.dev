Автоматизируйте фишинговые кампании GoPhish с помощью библиотеки Python gophish. Создает шаблоны электронной почты с пикселями отслеживания, настраивает профили отправки SMTP, создает целевые группы из CSV, запускает кампании и анализирует результаты, включая показатели открытий, рейтинг кликов и статистику отправки учетных данных для оценки осведомленности о безопасности.
