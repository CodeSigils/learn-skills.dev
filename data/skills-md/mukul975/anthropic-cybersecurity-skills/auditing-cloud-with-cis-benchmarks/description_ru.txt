В этом навыке подробно описано, как проводить аудит облачной безопасности с использованием тестов Центра интернет-безопасности для AWS, Azure и GCP. Он охватывает интерпретацию средств контроля CIS Foundations Benchmark, проведение автоматизированных оценок с помощью таких инструментов, как Prowler и ScoutSuite, устранение сбоев средств контроля и поддержание непрерывного мониторинга соответствия требованиям CIS v5 для AWS, v4 для Azure и v4 для GCP.
