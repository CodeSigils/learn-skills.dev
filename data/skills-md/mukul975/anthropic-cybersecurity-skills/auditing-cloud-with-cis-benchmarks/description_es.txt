Esta habilidad detalla cómo realizar auditorías de seguridad en la nube utilizando los puntos de referencia del Centro de Seguridad de Internet para AWS, Azure y GCP. Cubre la interpretación de los controles de CIS Foundations Benchmark, la ejecución de evaluaciones automatizadas con herramientas como Prowler y ScoutSuite, la reparación de controles fallidos y el mantenimiento de un monitoreo continuo del cumplimiento de CIS v5 para AWS, v4 para Azure y v4 para GCP.
