Integra moduli di sicurezza hardware (HSM) tramite l'interfaccia PKCS#11 utilizzando python-pkcs11, eseguendo generazione di chiavi, firma, crittografia, verifica e query di token/slot su SoftHSM2, AWS CloudHSM o YubiHSM2. Da utilizzare quando si implementa la gestione delle chiavi supportata da HSM o si convalida la configurazione HSM per la conformità FIPS 140-2/3.
