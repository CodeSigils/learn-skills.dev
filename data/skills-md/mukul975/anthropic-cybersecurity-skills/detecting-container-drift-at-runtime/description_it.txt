Rileva la deviazione non autorizzata del runtime nei contenitori monitorando l'esecuzione binaria, le modifiche al file system e la deviazione della configurazione dall'immagine immutabile originale, utilizzando Falco e Microsoft Defender per contenitori. Da utilizzare durante la convalida dei controlli dell'infrastruttura immutabile, la ricerca di installazioni impreviste di pacchetti o file binari scritti all'interno di un contenitore in esecuzione o la determinazione se un contenitore si è discostato dall'immagine da cui è stato creato. Parole chiave: deriva, infrastruttura immutabile, nuovo binario eseguito, installazione di pacchetti, mancata corrispondenza delle immagini, Falco. Non utilizzare per rilevare il breakout dal contenitore all'host: utilizzare i tentativi di fuga dal contenitore.
