Укрепляет конечные точки Linux с помощью рекомендаций CIS Benchmark для Ubuntu, RHEL и CentOS, чтобы уменьшить вероятность атак, обеспечить соблюдение базовых показателей безопасности и соответствовать требованиям соответствия. Используйте при развертывании новых серверов Linux, исправлении результатов аудита или установлении базовых показателей безопасности для инфраструктуры Linux. Активируется для запросов, касающихся усиления защиты Linux, тестов CIS для Linux, базовых показателей безопасности серверов или соответствия конфигурации Linux.
