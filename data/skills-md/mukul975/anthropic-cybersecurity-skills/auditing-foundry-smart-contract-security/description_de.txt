Sicherheitsaudit vor der Bereitstellung von Solidity Smart Contracts in einem Foundry-Projekt. Kombiniert statische Analyse (Slither, Aderyn), symbolische Ausführung (Mythril) und eigenschaftsbasierte Tests (Forge Fuzz + invariante Tests mit Handlern), um Wiedereintritts-, Zugriffskontroll-, Orakel-/Preismanipulations- und Rechenfehler zu erkennen, BEVOR sie in einer EVM-Kette bereitgestellt werden. Erzwingt außerdem die Schlüsselhygiene (keine Klartext-Privatschlüssel, verschlüsselter Cast-Keystore) und einen sicheren Bereitstellungsworkflow. Wird zum Schreiben, Überprüfen, Testen oder Bereitstellen von Solidity-/Foundry-Verträgen, zum Erstellen einer dApp oder zum Arbeiten mit Forge-/Cast-/Anvil-, MetaMask- oder Web3-/DeFi-Code verwendet.
