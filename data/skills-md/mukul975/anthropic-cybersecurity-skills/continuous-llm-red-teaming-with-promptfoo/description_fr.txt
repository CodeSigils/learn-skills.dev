Connecte Promptfoo et DeepTeam à CI/CD pour une intégration rouge automatisée et reproductible des applications LLM avec les préréglages OWASP LLM Top 10, OWASP Agentic et MITRE ATLAS, faisant échouer la construction lorsque les vulnérabilités de jailbreak ou d'injection régressent. À utiliser pour des tests contradictoires continus dans CI/CD, une barrière de sécurité bloquant les fusions ou pour comparer les versions de modèles/invites pour les rapports de conformité.
