Detecta el escape de contenedores en tiempo de ejecución a través de herramientas (manipulación de espacios de nombres, abuso de capacidades, vulnerabilidades del kernel, montajes de host sensibles y llamadas al sistema anómalas) y explica qué señales importan independientemente de si Falco, Sysdig, auditd o un EDR están realizando la recopilación. Úselo para decidir qué comportamiento de fuga monitorear, investigar una sospecha de fuga de Docker o Kubernetes o comparar la cobertura de escape entre sensores de tiempo de ejecución. Palabras clave: escape de contenedor, ruptura, espacios de nombres, CAP_SYS_ADMIN, privilegiado, hostPath, exploit del kernel, syscall. No lo use para la sintaxis de la regla Falco en sí: use detecting-container-escape-with-falco-rules; para un barrido de configuración estática, utilice performance-container-escape-detection.
