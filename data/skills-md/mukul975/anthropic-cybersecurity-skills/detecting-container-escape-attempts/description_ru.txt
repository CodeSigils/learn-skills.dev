Обнаруживает выход контейнера во время выполнения с помощью инструментов — манипулирование пространством имен, злоупотребление возможностями, эксплойты ядра, конфиденциальное монтирование хостов и аномальные системные вызовы — и объясняет, какие сигналы имеют значение независимо от того, выполняет ли сбор Falco, Sysdig, Auditd или EDR. Используйте при принятии решения о том, какое поведение прорыва следует отслеживать, при расследовании предполагаемого взлома Docker или Kubernetes или при сравнении охвата аварийных ситуаций с помощью датчиков времени выполнения. Ключевые слова: выход из контейнера, прорыв, пространства имен, CAP_SYS_ADMIN, привилегированные, hostPath, эксплойт ядра, системный вызов. Не используйте для самого синтаксиса правил Falco - используйте правила обнаружения-контейнера-побега с-falco-rules; для проверки статической конфигурации используйте выполнение-побега-контейнера-обнаружения.
