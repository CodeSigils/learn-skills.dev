Выявляйте вредоносную активность PowerShell, анализируя ведение журнала блоков сценариев (событие 4104), ведение журнала модуля (событие 4103) и событий создания процессов. Аналитик анализирует файлы EVTX журнала событий Windows для обнаружения запутанных команд, попыток обхода AMSI, закодированных полезных данных, ключевых слов для сброса учетных данных и подозрительных загрузок. Активируется для запросов, включающих поиск угроз PowerShell, анализ блоков сценариев, обнаружение закодированных команд или идентификацию обхода AMSI.
