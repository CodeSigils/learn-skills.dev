ابحث عن نشاط PowerShell الضار من خلال تحليل تسجيل كتلة البرنامج النصي (الحدث 4104)، وتسجيل الوحدة النمطية (الحدث 4103)، وأحداث إنشاء العملية. يقوم المحلل بتوزيع ملفات Windows Event Log EVTX لاكتشاف الأوامر المبهمة، ومحاولات تجاوز AMSI، والحمولات المشفرة، والكلمات الرئيسية لتفريغ بيانات الاعتماد، وحوامل التنزيل المشبوهة. يتم التنشيط للطلبات التي تتضمن البحث عن تهديدات PowerShell، أو تحليل كتلة البرنامج النصي، أو اكتشاف الأوامر المشفرة، أو تحديد تجاوز AMSI.
