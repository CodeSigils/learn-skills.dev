Recherchez les activités PowerShell malveillantes en analysant la journalisation des blocs de script (événement 4104), la journalisation des modules (événement 4103) et les événements de création de processus. L'analyste analyse les fichiers EVTX du journal des événements Windows pour détecter les commandes obscurcies, les tentatives de contournement AMSI, les charges utiles codées, les mots-clés de vidage d'informations d'identification et les supports de téléchargement suspects. S'active pour les requêtes impliquant la recherche de menaces PowerShell, l'analyse de blocs de script, la détection de commandes codées ou l'identification de contournement AMSI.
