Rileva la creazione e la modifica di attività pianificate dannose utilizzando gli ID evento Sysmon 1 (Creazione processo per schtasks.exe), 11 (Creazione file per attività XML) e Evento di sicurezza Windows 4698/4702. L'analista correla la creazione delle attività con processi principali sospetti, percorsi di directory pubbliche e argomenti di comando codificati per identificare la persistenza e il movimento laterale tramite attività pianificate. Si attiva per le richieste che coinvolgono il rilevamento delle attività pianificate, la ricerca della persistenza Sysmon o l'analisi delle attività/lavori pianificati T1053.005.
