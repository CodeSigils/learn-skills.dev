Detecte la creación y modificación de tareas programadas maliciosas utilizando los ID de evento de Sysmon 1 (Creación de proceso para schtasks.exe), 11 (Creación de archivo para tarea XML) y Evento de seguridad de Windows 4698/4702. El analista correlaciona la creación de tareas con procesos principales sospechosos, rutas de directorios públicos y argumentos de comando codificados para identificar la persistencia y el movimiento lateral a través de tareas programadas. Se activa para solicitudes que involucran detección de tareas programadas, búsqueda de persistencia de Sysmon o análisis de tareas/trabajos programados T1053.005.
