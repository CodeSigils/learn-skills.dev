Развертывает и настраивает osquery для мониторинга конечных точек в режиме реального времени с использованием запросов на основе SQL для проверки запущенных процессов, открытых портов, установленного программного обеспечения и конфигурации системы. Используйте при обеспечении прозрачности состояния конечных точек, поиске угроз по всему парку или реализации мониторинга соответствия. Активируется для запросов, связанных с развертыванием osquery, видимостью конечных точек, управлением автопарком или запросами конечных точек на основе SQL.
