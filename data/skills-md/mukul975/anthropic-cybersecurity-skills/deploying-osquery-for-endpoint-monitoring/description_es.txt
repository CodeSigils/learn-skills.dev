Implementa y configura osquery para el monitoreo de terminales en tiempo real mediante consultas basadas en SQL para inspeccionar procesos en ejecución, puertos abiertos, software instalado y configuración del sistema. Úselo para generar visibilidad sobre el estado de los terminales, buscar amenazas en toda la flota o implementar monitoreo de cumplimiento. Se activa para solicitudes que involucran implementación de Osquery, visibilidad de terminales, administración de flotas o consultas de terminales basadas en SQL.
