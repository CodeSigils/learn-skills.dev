Implementiert Speicherschutzmechanismen, einschließlich DEP (Data Execution Prevention), ASLR (Address Space Layout Randomization), CFG (Control Flow Guard) und andere Exploit-Abwehrmaßnahmen, um Angriffe auf Speicherbeschädigung zu verhindern. Wird zum Absichern von Endpunkten gegen Pufferüberlauf-Exploits, ROP-Ketten und Code-Injection verwendet. Wird für Anfragen aktiviert, die Speicherschutz, Exploit-Abwehr, DEP-, ASLR- oder CFG-Konfiguration betreffen.
