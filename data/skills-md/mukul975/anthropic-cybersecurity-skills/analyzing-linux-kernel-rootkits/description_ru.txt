Обнаруживайте руткиты уровня ядра в дампах памяти Linux с помощью плагинов Volatility3 для Linux (check_syscall, lsmod, скрытые_модули), сканирования системы rkhunter и анализа несоответствий /proc и /sys для выявления перехваченных системных вызовов, скрытых модулей ядра и измененных системных структур.
