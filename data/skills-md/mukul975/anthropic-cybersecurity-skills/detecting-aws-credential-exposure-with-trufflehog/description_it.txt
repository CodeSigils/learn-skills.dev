Scansiona i repository di codice sorgente, le pipeline CI/CD e i file di configurazione alla ricerca di credenziali AWS esposte usando TruffleHog, git-secrets e il rilevamento nativo di AWS. Utilizza questo quando integri la scansione dei segreti in CI/CD, esegui audit dei repository (inclusa la cronologia di git) per chiavi AWS commesse in passato, rispondi a un avviso di GuardDuty sull'uso di credenziali da una posizione imprevista, o verifichi che la rotazione delle credenziali abbia rimosso tutte le chiavi esposte.
