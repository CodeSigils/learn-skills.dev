Erkennt Prompt-Injection-Angriffe, die auf LLM-basierte Anwendungen abzielen, mithilfe einer mehrschichtigen Verteidigung, die Regex-Mustervergleich für bekannte Angriffssignaturen, heuristische Bewertung für strukturelle Anomalien und transformatorbasierte Klassifizierung mit DeBERTa-Modellen kombiniert. Der Detektor analysiert Benutzereingaben, bevor sie das LLM erreichen, und markiert direkte Injektionen (Überschreibungen von Systemeingabeaufforderungen, Rollenspiel-Escapes, Befehlsentführung) und indirekte Injektionen (codierte Nutzlasten, mehrsprachige Verschleierung, auf Trennzeichen basierende Escapes). Basierend auf den OWASP LLM Top 10 (LLM01:2025 Prompt Injection) und der Prompt-Injection-Taxonomie von Simon Willison. Wird für Anfragen aktiviert, die eine sofortige Injektionserkennung, eine LLM-Eingabebereinigung, ein KI-Sicherheitsscan oder eine sofortige Angriffsklassifizierung beinhalten.
