알려진 공격 시그니처에 대한 정규식 패턴 일치, 구조적 이상에 대한 휴리스틱 채점, DeBERTa 모델을 사용한 변환기 기반 분류를 결합한 다층 방어를 사용하여 LLM 기반 애플리케이션을 대상으로 하는 즉각적인 주입 공격을 탐지합니다. 탐지기는 사용자 입력이 LLM에 도달하기 전에 분석하여 직접 주입(시스템 프롬프트 재정의, 역할극 이스케이프, 명령 하이재킹) 및 간접 주입(인코딩된 페이로드, 다중 언어 난독화, 구분 기호 기반 이스케이프)을 표시합니다. OWASP LLM Top 10(LLM01:2025 프롬프트 주입)과 Simon Willison의 프롬프트 주입 분류법을 기반으로 합니다. 신속한 삽입 감지, LLM 입력 삭제, AI 보안 스캐닝 또는 신속한 공격 분류와 관련된 요청에 대해 활성화됩니다.
