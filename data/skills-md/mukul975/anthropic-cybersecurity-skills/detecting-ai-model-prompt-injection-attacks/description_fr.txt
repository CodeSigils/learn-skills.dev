Détecte les attaques par injection rapide ciblant les applications basées sur LLM à l'aide d'une défense multicouche combinant la correspondance de modèles d'expression régulière pour les signatures d'attaque connues, la notation heuristique pour les anomalies structurelles et la classification basée sur les transformateurs avec les modèles DeBERTa. Le détecteur analyse les entrées de l'utilisateur avant qu'elles n'atteignent le LLM, signalant les injections directes (remplacements d'invites du système, échappements de jeux de rôle, détournement d'instructions) et les injections indirectes (charges utiles codées, obscurcissement multilingue, échappements basés sur des délimiteurs). Basé sur l'OWASP LLM Top 10 (LLM01:2025 Prompt Injection) et la taxonomie d'injection rapide de Simon Willison. S'active pour les requêtes impliquant une détection rapide d'injection, une désinfection des entrées LLM, une analyse de sécurité IA ou une classification rapide des attaques.
