Обрабатывает пакеты анализа угроз STIX 2.1, доставляемые через серверы TAXII 2.1, нормализуя объекты в собственные схемы платформы и направляя их соответствующим потребляющим системам. Используйте при подключении новых конечных точек сбора данных TAXII, автоматизации двунаправленного обмена аналитическими данными с ISAC или построении конвейерной проверки для некорректных пакетов STIX. Активируется для запросов, связанных с конфигурацией сервера OASIS STIX, TAXII, MISP TAXII или интеграцией каналов Cortex XSOAR.
