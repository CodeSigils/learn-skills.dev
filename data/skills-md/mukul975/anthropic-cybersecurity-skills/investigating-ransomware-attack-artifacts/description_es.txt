Conserve de forma forense la memoria y el disco, recopile notas de rescate y muestras de archivos cifrados, e identifique la variante de ransomware utilizando herramientas como ID Ransomware, Volatility y Chainsaw/Hayabusa para determinar el vector de acceso inicial y las opciones de recuperación. Úselo inmediatamente después de descubrir el cifrado de ransomware, cuando analice el incidente de manera forense o cuando documente evidencia para las autoridades y reclamos de seguros.
