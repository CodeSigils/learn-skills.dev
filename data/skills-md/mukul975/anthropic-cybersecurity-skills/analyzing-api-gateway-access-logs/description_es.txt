Analiza los registros de acceso de API Gateway (AWS API Gateway, Kong, Nginx) para detectar ataques BOLA/IDOR, omisión de límites de velocidad, escaneo de credenciales e intentos de inyección. Utiliza pandas para el análisis estadístico de patrones de solicitudes y detección de anomalías. Úselo al investigar el abuso de API o crear reglas de detección de amenazas específicas de API.
