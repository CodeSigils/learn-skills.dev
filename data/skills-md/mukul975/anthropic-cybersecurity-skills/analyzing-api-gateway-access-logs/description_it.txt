Analizza i log di accesso del gateway API (AWS API Gateway, Kong, Nginx) per rilevare attacchi BOLA/IDOR, bypass del limite di velocità, scansione delle credenziali e tentativi di injection. Utilizza panda per l'analisi statistica dei modelli di richiesta e il rilevamento delle anomalie. Da utilizzare quando si indaga sull'abuso dell'API o si creano regole di rilevamento delle minacce specifiche dell'API.
