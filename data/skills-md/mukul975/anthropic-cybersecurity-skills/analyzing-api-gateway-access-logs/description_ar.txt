يوزع سجلات الوصول إلى بوابة API (AWS API Gateway، وKong، وNginx) لاكتشاف هجمات BOLA/IDOR، وتجاوز حدود المعدل، ومسح بيانات الاعتماد، ومحاولات الحقن. يستخدم الباندا للتحليل الإحصائي لأنماط الطلب والكشف عن الشذوذ. يُستخدم عند التحقيق في إساءة استخدام واجهة برمجة التطبيقات (API) أو إنشاء قواعد الكشف عن التهديدات الخاصة بواجهة برمجة التطبيقات (API).
