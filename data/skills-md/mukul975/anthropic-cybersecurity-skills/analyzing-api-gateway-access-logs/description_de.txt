Analysiert API-Gateway-Zugriffsprotokolle (AWS API Gateway, Kong, Nginx), um BOLA/IDOR-Angriffe, die Umgehung von Ratenbegrenzungen, das Scannen von Anmeldeinformationen und Einschleusungsversuche zu erkennen. Verwendet Pandas zur statistischen Analyse von Anforderungsmustern und zur Erkennung von Anomalien. Verwenden Sie diese Option, wenn Sie API-Missbrauch untersuchen oder API-spezifische Regeln zur Bedrohungserkennung erstellen.
