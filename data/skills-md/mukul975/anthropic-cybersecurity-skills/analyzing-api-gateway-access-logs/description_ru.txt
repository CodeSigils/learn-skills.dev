Анализирует журналы доступа к шлюзам API (AWS API Gateway, Kong, Nginx) для обнаружения атак BOLA/IDOR, обхода ограничения скорости, сканирования учетных данных и попыток внедрения. Использует pandas для статистического анализа шаблонов запросов и обнаружения аномалий. Используйте при расследовании злоупотреблений API или создании правил обнаружения угроз для конкретных API.
