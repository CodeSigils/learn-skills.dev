Analyse les journaux d'accès à API Gateway (AWS API Gateway, Kong, Nginx) pour détecter les attaques BOLA/IDOR, le contournement de la limite de débit, l'analyse des informations d'identification et les tentatives d'injection. Utilise des pandas pour l'analyse statistique des modèles de requêtes et la détection des anomalies. À utiliser lors d'enquêtes sur des abus d'API ou lors de la création de règles de détection de menaces spécifiques à l'API.
