Realiza pruebas de penetración de aplicaciones móviles iOS y Android siguiendo la Guía de pruebas de seguridad de aplicaciones móviles (MASTG) de OWASP para identificar vulnerabilidades en el almacenamiento de datos, comunicación de red, autenticación, criptografía y controles de seguridad específicos de la plataforma. El probador realiza análisis estático de archivos binarios de aplicaciones, análisis dinámico en tiempo de ejecución y pruebas de seguridad de API para evaluar la superficie de ataque móvil completa. Se activa para solicitudes que involucran pentest de aplicaciones móviles, evaluación de seguridad de iOS, pruebas de seguridad de Android o evaluación OWASP MASTG.
