Проводит тестирование на проникновение мобильных приложений iOS и Android в соответствии с Руководством по тестированию безопасности мобильных приложений OWASP (MASTG) для выявления уязвимостей в хранении данных, сетевой связи, аутентификации, криптографии и средствах контроля безопасности для конкретных платформ. Тестер выполняет статический анализ двоичных файлов приложений, динамический анализ во время выполнения и тестирование безопасности API для оценки всей поверхности мобильных атак. Активируется для запросов, связанных с пентестом мобильных приложений, оценкой безопасности iOS, тестированием безопасности Android или оценкой OWASP MASTG.
