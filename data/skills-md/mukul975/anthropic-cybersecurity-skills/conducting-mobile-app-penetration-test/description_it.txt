Conduce test di penetrazione delle applicazioni mobili iOS e Android seguendo la OWASP Mobile Application Security Testing Guide (MASTG) per identificare le vulnerabilità nell'archiviazione dei dati, nella comunicazione di rete, nell'autenticazione, nella crittografia e nei controlli di sicurezza specifici della piattaforma. Il tester esegue analisi statiche dei file binari dell'applicazione, analisi dinamiche in fase di runtime e test di sicurezza API per valutare l'intera superficie di attacco mobile. Si attiva per richieste che coinvolgono pentest di app mobili, valutazione della sicurezza iOS, test di sicurezza Android o valutazione OWASP MASTG.
