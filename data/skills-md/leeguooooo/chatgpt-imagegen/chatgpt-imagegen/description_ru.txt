Создавайте растровые изображения (PNG/JPEG/WebP), используя подписку пользователя на ChatGPT через локальный однофайловый интерфейс командной строки Python — без OPENAI_API_KEY, без шлюза, без демона. Используйте, когда агенту необходимо создать совершенно новый растровый ресурс для текущего проекта (фотографии, иллюстрации, значки, баннеры героев, макеты, спрайты, концепт-арт), а результатом должен быть растровый файл, сохраненный в рабочей области. Не используйте, если задачу лучше решить путем редактирования существующих SVG/векторных ресурсов, написания собственной графики (HTML/CSS/canvas) или расширения установленной системы значков репозитория.
