Genere imágenes rasterizadas (PNG/JPEG/WebP) utilizando la suscripción ChatGPT del usuario a través de una CLI de Python local de un solo archivo: sin OPENAI_API_KEY, sin puerta de enlace, sin demonio. Úselo cuando un agente necesita crear un recurso de mapa de bits nuevo para el proyecto actual (fotos, ilustraciones, íconos, pancartas de héroes, maquetas, sprites, arte conceptual) y el resultado debe ser un archivo de mapa de bits guardado en el espacio de trabajo. No lo utilice cuando la tarea se resuelva mejor editando recursos SVG/vectoriales existentes, escribiendo gráficos de código nativo (HTML/CSS/canvas) o ampliando un sistema de íconos de repositorio establecido.
