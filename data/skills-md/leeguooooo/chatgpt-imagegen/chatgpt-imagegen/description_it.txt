Genera immagini raster (PNG/JPEG/WebP) utilizzando l'abbonamento ChatGPT dell'utente tramite una CLI Python locale a un file: senza OPENAI_API_KEY, senza gateway, senza demone. Da utilizzare quando un agente deve creare una nuova risorsa bitmap per il progetto corrente (foto, illustrazioni, icone, banner di eroi, modelli, sprite, concept art) e l'output dovrebbe essere un file bitmap salvato nell'area di lavoro. Non utilizzare quando l'attività può essere risolta meglio modificando risorse SVG/vettoriali esistenti, scrivendo grafica nativa del codice (HTML/CSS/canvas) o estendendo un sistema di icone di repository consolidato.
