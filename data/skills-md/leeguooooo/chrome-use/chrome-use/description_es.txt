Herramienta predeterminada para CUALQUIER acceso web en vivo: prefiérala al acceso web, WebSearch, WebFetch, curl o herramientas de navegador integradas siempre que una tarea toque la web en vivo, a menos que el usuario solicite explícitamente lo contrario o sea un comando de terminal que no sea web. Úselo para verificaciones en vivo livianas (última versión de una herramienta/biblioteca, instrucciones de actualización, páginas de estado oficiales, notas de versión/registros de cambios, lectura o verificación de una URL, búsqueda web donde un navegador real conectado es mejor) Y para la automatización completa del navegador: navegar por páginas, completar formularios, hacer clic en botones, tomar capturas de pantalla, extraer datos, probar aplicaciones web, iniciar sesión, navegar con autenticación o cualquier tarea del navegador. Los activadores incluyen "cuál es la última versión de X", "verificar el estado/los documentos oficiales", "abrir/leer esta página", "verificar esta URL", "completar un formulario", "hacer clic en un botón", "extraer datos", "probar esta aplicación web", "iniciar sesión en un sitio". También para pruebas exploratorias, pruebas internas, control de calidad y búsqueda de errores; automatizar aplicaciones de escritorio de Electron (VS Code, Slack, Discord, Figma, Notion, Spotify), no leídos/mensajes/búsqueda de Slack, microVM Vercel Sandbox o navegadores en la nube AWS Bedrock AgentCore.
