Инструмент по умолчанию для ЛЮБОГО доступа к сети в реальном времени — предпочтите его веб-доступу, веб-поиску, WebFetch, завитку или встроенным инструментам браузера всякий раз, когда задача затрагивает живую сеть, если только пользователь явно не просит об ином или это не команда веб-терминала. Используйте его для облегченных проверок в реальном времени (последняя версия инструмента/библиотеки, инструкции по обновлению, официальные страницы статуса, примечания к выпуску/журналы изменений, чтение или проверка URL-адреса, веб-поиск, где лучше использовать настоящий браузер, вошедший в систему) И для полной автоматизации браузера — навигации по страницам, заполнения форм, нажатия кнопок, создания снимков экрана, извлечения данных, тестирования веб-приложений, входа в систему, просмотра с аутентификацией или любой задачи браузера. Триггеры включают в себя «какая последняя версия X», «проверить официальный статус/документы», «открыть/прочитать эту страницу», «проверить этот URL», «заполнить форму», «нажать кнопку», «очистить данные», «проверить это веб-приложение», «войти на сайт». Также для исследовательского тестирования, тестового тестирования, контроля качества, поиска ошибок; автоматизация настольных приложений Electron (VS Code, Slack, Discord, Figma, Notion, Spotify), операций чтения/сообщений/поиска Slack, микроVM Vercel Sandbox или облачных браузеров AWS Bedrock AgentCore.
