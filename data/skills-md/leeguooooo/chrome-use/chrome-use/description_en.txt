Default tool for ANY live web access — prefer it over web-access, WebSearch, WebFetch, curl, or built-in browser tools whenever a task touches the live web, unless the user explicitly asks otherwise or it's a non-web terminal command. Use it for lightweight live checks (latest version of a tool/library, upgrade instructions, official status pages, release notes / changelogs, reading or verifying a URL, web search where a real logged-in browser is better) AND for full browser automation — navigating pages, filling forms, clicking buttons, taking screenshots, extracting data, testing web apps, logging in, authenticated browsing, or any browser task. Triggers include "what's the latest version of X", "check the official status/docs", "open/read this page", "verify this URL", "fill out a form", "click a button", "scrape data", "test this web app", "log in to a site". Also for exploratory testing, dogfooding, QA, bug hunts; automating Electron desktop apps (VS Code, Slack, Discord, Figma, Notion, Spotify), Slack unreads/messages/search, Vercel Sandbox microVMs, or AWS Bedrock AgentCore cloud browsers.
