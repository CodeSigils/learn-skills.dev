Strumento predefinito per QUALSIASI accesso al Web live: da preferire all'accesso Web, WebSearch, WebFetch, curl o agli strumenti del browser integrati ogni volta che un'attività tocca il Web live, a meno che l'utente non chieda esplicitamente diversamente o si tratti di un comando terminale non Web. Usalo per controlli in tempo reale leggeri (ultima versione di uno strumento/libreria, istruzioni di aggiornamento, pagine di stato ufficiali, note di rilascio/registri di modifiche, lettura o verifica di un URL, ricerca web dove è meglio un browser realmente connesso) E per l'automazione completa del browser: navigazione di pagine, compilazione di moduli, clic su pulsanti, acquisizione di schermate, estrazione di dati, test di app Web, accesso, navigazione autenticata o qualsiasi attività del browser. I trigger includono "qual è l'ultima versione di X", "controlla lo stato ufficiale/i documenti", "apri/leggi questa pagina", "verifica questo URL", "compila un modulo", "fai clic su un pulsante", "raschia dati", "prova questa app Web", "accedi a un sito". Anche per test esplorativi, sperimentazione, QA, caccia ai bug; automatizzando le app desktop Electron (VS Code, Slack, Discord, Figma, Notion, Spotify), messaggi/ricerca non letti/messaggi Slack, microVM Vercel Sandbox o browser cloud AWS Bedrock AgentCore.
