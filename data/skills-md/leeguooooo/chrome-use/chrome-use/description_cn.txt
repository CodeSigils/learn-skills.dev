任何实时 Web 访问的默认工具 - 每当任务接触实时 Web 时，优先使用它而不是 Web 访问、WebSearch、WebFetch、curl 或内置浏览器工具，除非用户明确要求否则或者它是非 Web 终端命令。使用它进行轻量级实时检查（工具/库的最新版本、升级说明、官方状态页面、发行说明/更改日志、读取或验证 URL、真正登录的浏览器更好的网络搜索）以及完整的浏览器自动化 - 导航页面、填写表单、单击按钮、截屏、提取数据、测试 Web 应用程序、登录、身份验证浏览或任何浏览器任务。触发器包括“X 的最新版本是什么”、“检查官方状态/文档”、“打开/阅读此页面”、“验证此 URL”、“填写表单”、“单击按钮”、“抓取数据”、“测试此 Web 应用程序”、“登录到站点”。也可用于探索性测试、dogfooding、QA、bug 查找；自动化 Electron 桌面应用程序（VS Code、Slack、Discord、Figma、Notion、Spotify）、Slack 未读/消息/搜索、Vercel Sandbox microVM 或 AWS Bedrock AgentCore 云浏览器。
