あらゆるライブ Web アクセスのデフォルト ツール — ユーザーが明示的に別の要求をした場合や Web 以外の端末コマンドである場合を除き、タスクがライブ Web に触れるときは常に、Web アクセス、WebSearch、WebFetch、curl、または組み込みのブラウザ ツールよりも優先されます。これは、軽量のライブ チェック (ツール/ライブラリの最新バージョン、アップグレード手順、公式ステータス ページ、リリース ノート/変更ログ、URL の読み取りまたは検証、実際にログインしているブラウザの方が優れている場合の Web 検索) や、ブラウザの完全な自動化 (ページの移動、フォームへの入力、ボタンのクリック、スクリーンショットの撮影、データの抽出、Web アプリのテスト、ログイン、認証されたブラウジング、その他のブラウザ タスク) に使用します。トリガーには、「X の最新バージョンは何ですか」、「公式ステータス/ドキュメントを確認する」、「このページを開く/読む」、「この URL を確認する」、「フォームに記入する」、「ボタンをクリックする」、「データをスクレイピングする」、「この Web アプリをテストする」、「サイトにログインする」などがあります。探索的テスト、ドッグフーディング、QA、バグハントにも使用できます。 Electron デスクトップ アプリ (VS Code、Slack、Discord、Figma、Notion、Spotify)、Slack の未読/メッセージ/検索、Vercel Sandbox microVM、または AWS Bedrock AgentCore クラウド ブラウザを自動化します。
