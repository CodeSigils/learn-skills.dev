Outil par défaut pour TOUT accès Web en direct : préférez-le à l'accès Web, à WebSearch, WebFetch, curl ou aux outils de navigateur intégrés chaque fois qu'une tâche touche le Web en direct, à moins que l'utilisateur ne demande explicitement le contraire ou qu'il s'agisse d'une commande de terminal non Web. Utilisez-le pour des vérifications en direct légères (dernière version d'un outil/bibliothèque, instructions de mise à niveau, pages de statut officielles, notes de version/journaux de modifications, lecture ou vérification d'une URL, recherche sur le Web où un véritable navigateur connecté est préférable) ET pour une automatisation complète du navigateur - navigation dans les pages, remplissage de formulaires, clic sur des boutons, prise de captures d'écran, extraction de données, test d'applications Web, connexion, navigation authentifiée ou toute tâche du navigateur. Les déclencheurs incluent « quelle est la dernière version de X », « vérifier le statut/la documentation officielle », « ouvrir/lire cette page », « vérifier cette URL », « remplir un formulaire », « cliquer sur un bouton », « gratter les données », « tester cette application Web », « se connecter à un site ». Également pour les tests exploratoires, le dogfooding, l'assurance qualité, la chasse aux bogues ; automatiser les applications de bureau Electron (VS Code, Slack, Discord, Figma, Notion, Spotify), les non-lectures/messages/recherches Slack, les microVM Vercel Sandbox ou les navigateurs cloud AWS Bedrock AgentCore.
