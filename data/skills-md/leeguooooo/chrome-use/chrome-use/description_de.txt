Standardtool für JEDEN Live-Webzugriff – bevorzugen Sie es gegenüber Webzugriff, WebSearch, WebFetch, Curl oder integrierten Browser-Tools, wann immer eine Aufgabe das Live-Web berührt, es sei denn, der Benutzer verlangt ausdrücklich etwas anderes oder es handelt sich um einen Nicht-Web-Terminalbefehl. Verwenden Sie es für einfache Live-Überprüfungen (neueste Version eines Tools/einer Bibliothek, Upgrade-Anweisungen, offizielle Statusseiten, Versionshinweise/Änderungsprotokolle, Lesen oder Überprüfen einer URL, Websuche, bei der ein echter angemeldeter Browser besser ist) UND für eine vollständige Browserautomatisierung – Navigieren durch Seiten, Ausfüllen von Formularen, Klicken auf Schaltflächen, Erstellen von Screenshots, Extrahieren von Daten, Testen von Web-Apps, Anmelden, authentifiziertes Surfen oder andere Browseraufgaben. Zu den Auslösern gehören „Was ist die neueste Version von Auch für explorative Tests, Dogfooding, Qualitätssicherung, Insektensuche; Automatisierung von Electron-Desktop-Apps (VS Code, Slack, Discord, Figma, Notion, Spotify), Slack-Ungelesenen/Nachrichten/Suchen, Vercel Sandbox-Mikro-VMs oder AWS Bedrock AgentCore-Cloud-Browsern.
