Gérez de nombreuses sessions de compte connectées pour n'importe quel site Web : capturez, stockez, répertoriez, changez et appliquez les connexions enregistrées sur les profils Chrome, les navigateurs isolés et les sessions connectées. À utiliser lorsque l'utilisateur souhaite « enregistrer ce compte », « passer au compte X », « se connecter sous un autre compte », « gérer mes comptes N ChatGPT/Claude », « déplacer une connexion entre profils/navigateurs » ou jongler avec des dizaines de comptes sur un seul site. Les sessions vivent dans un coffre-fort local chiffré ; Les E/S du navigateur/cookie sont déléguées à l'utilisation de Chrome. macOS.
