macOS WeChat CLI + ローカル HTTP ブリッジ + Wechaty Puppet gRPC ゲートウェイ — メッセージの送信、セッション / 連絡先 / チャット履歴 / 画像 / お気に入りのクエリを実行し、エージェント統合のための安定した HTTP / gRPC サーフェスを公開します。ユーザーが「WeChat メッセージの送信」、「発行微信」、WeChat の連絡先/グループ/メッセージのクエリ、チャットで誰が何を言ったかを調べる、履歴から画像を取得する、チャット履歴をエクスポートする、WeChat を Hermes / n8n / Dify / LangChain に接続する、または実際の macOS WeChat アカウントで Wechaty ボットを実行するように要求する場合に使用します。 macOS (Apple Silicon) 上の WeChat 4.1.8 / 4.1.9 と「wechatuse_」アクティベーション コードが必要です。 1 回限りの「wechat-use init」により DB キーが抽出されます。 sudo も WeChat.app の再署名も不要です。オプションのリモートブリッジ — 「wechat-use トンネルセットアップ --hostname <yours>」 は、リモートサービスを呼び出すために Cloudflare トンネル経由でローカル REST API を公開します。
