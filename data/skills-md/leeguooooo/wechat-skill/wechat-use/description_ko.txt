macOS WeChat CLI + 로컬 HTTP 브리지 + Wechaty Puppet gRPC 게이트웨이 — 메시지를 보내고, 세션/연락처/채팅 기록/이미지/즐겨찾기를 쿼리하고, 에이전트 통합을 위해 안정적인 HTTP/gRPC 표면을 노출합니다. 사용자가 'WeChat 메시지 보내기', '发微信', WeChat 연락처/그룹/메시지 쿼리, 채팅에서 누가 말한 내용 조회, 기록에서 이미지 가져오기, 채팅 기록 내보내기, WeChat을 Hermes / n8n / Dify / LangChain에 연결하거나 실제 macOS WeChat 계정에서 wechaty 봇 실행을 요청할 때 사용합니다. macOS(Apple Silicon)의 WeChat 4.1.8 / 4.1.9 및 'wechatuse_' 활성화 코드가 필요합니다. 일회성 'wechat-use init'은 DB 키를 추출합니다. sudo도 없고 WeChat.app에 다시 서명하지도 않습니다. 선택적 원격 브리지 — `wechat-use 터널 설정 --hostname <yours>`는 원격 서비스 호출을 위해 Cloudflare Tunnel을 통해 로컬 REST API를 노출합니다.
