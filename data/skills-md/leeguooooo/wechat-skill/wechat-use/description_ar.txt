macOS WeChat CLI + جسر HTTP المحلي + بوابة Wechaty Puppet gRPC - أرسل الرسائل وجلسات الاستعلام / جهات الاتصال / سجل الدردشة / الصور / المفضلة، واعرض أسطح HTTP / gRPC المستقرة لتكامل الوكيل. يُستخدم عندما يطلب المستخدم "إرسال رسالة WeChat"، أو "发微信"، أو الاستعلام عن جهات اتصال/مجموعات/رسائل WeChat، أو البحث عن من قال ماذا في الدردشة، أو جلب صور من السجل، أو تصدير سجل الدردشة، أو توصيل WeChat إلى Hermes / n8n / Dify / LangChain، أو تشغيل أي روبوت Wechaty على حساب macOS WeChat حقيقي. يتطلب WeChat 4.1.8 / 4.1.9 على macOS (Apple Silicon) ورمز التنشيط `wechatuse_`. يستخرج "wechat-use init" مفتاح قاعدة البيانات لمرة واحدة؛ لا سودو، لا إعادة التوقيع على WeChat.app. جسر بعيد اختياري — `إعداد نفق wechat-use --اسم المضيف <yours>` يعرض REST API المحلي عبر Cloudflare Tunnel للاتصال بالخدمات البعيدة.
