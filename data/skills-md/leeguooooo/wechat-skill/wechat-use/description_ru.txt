macOS WeChat CLI + локальный HTTP-мост + шлюз Wechaty Puppet gRPC — отправляйте сообщения, запрашивайте сеансы / контакты / историю чата / изображения / избранное и предоставляйте стабильные поверхности HTTP / gRPC для интеграции агентов. Используйте, когда пользователь просит «отправить сообщение WeChat», «发微信», запросить контакты/группы/сообщения WeChat, посмотреть, кто что сказал в чате, получить изображения из истории, экспортировать историю чата, подключить WeChat к Hermes / n8n / Dify / LangChain или запустить любого WeChat-бота на реальной учетной записи WeChat macOS. Требуется WeChat 4.1.8/4.1.9 на macOS (Apple Silicon) и код активации wechatuse_. Одноразовый `wechat-use init` извлекает ключ БД; нет sudo, нет повторной подписи WeChat.app. Дополнительный удаленный мост — `wechat-use Tunnel setup --hostname <ваш>` предоставляет локальный REST API через Cloudflare Tunnel для вызова удаленных служб.
