macOS WeChat CLI + pont HTTP local + passerelle gRPC Wechaty Puppet — envoyez des messages, interrogez des sessions/contacts/historique de discussion/images/favoris et exposez des surfaces HTTP/gRPC stables pour l'intégration d'agents. À utiliser lorsque l'utilisateur demande « d'envoyer un message WeChat », « 发微信 », d'interroger des contacts/groupes/messages WeChat, de rechercher qui a dit quoi dans une discussion, de récupérer des images de l'historique, d'exporter l'historique des discussions, de connecter WeChat à Hermes/n8n/Dify/LangChain ou d'exécuter n'importe quel robot WeChat sur un vrai compte macOS WeChat. Nécessite WeChat 4.1.8 / 4.1.9 sur macOS (Apple Silicon) et un code d'activation `wechatuse_`. « wechat-use init » unique extrait la clé de base de données ; pas de sudo, pas de re-signature de WeChat.app. Pont distant facultatif — `wechat-use tunnel setup --hostname <yours>` expose l'API REST locale via Cloudflare Tunnel pour que les services distants puissent l'appeler.
