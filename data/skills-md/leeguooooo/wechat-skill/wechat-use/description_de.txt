macOS WeChat CLI + lokale HTTP-Brücke + Wechaty Puppet gRPC-Gateway – Nachrichten senden, Sitzungen/Kontakte/Chat-Verlauf/Bilder/Favoriten abfragen und stabile HTTP-/gRPC-Oberflächen für die Agentenintegration bereitstellen. Verwenden Sie diese Option, wenn der Benutzer „eine WeChat-Nachricht senden“ oder „发微信“ auffordert, WeChat-Kontakte/-Gruppen/-Nachrichten abfragt, nachschaut, wer was in einem Chat gesagt hat, Bilder aus dem Verlauf abruft, den Chat-Verlauf exportiert, WeChat mit Hermes / n8n / Dify / LangChain verbindet oder einen beliebigen Wechaty-Bot auf einem echten macOS WeChat-Konto ausführt. Erfordert WeChat 4.1.8 / 4.1.9 auf macOS (Apple Silicon) und einen „wechatuse_“-Aktivierungscode. Einmaliges „wechat-use init“ extrahiert den DB-Schlüssel; Kein Sudo, kein erneutes Signieren von WeChat.app. Optionale Remote-Brücke – „wechat-use tunnel setup --hostname <yours>“ stellt die lokale REST-API über den Cloudflare-Tunnel bereit, damit Remote-Dienste aufgerufen werden können.
