macOS 微信 CLI + 本機 HTTP 橋接器 + Wechaty Puppet gRPC 閘道 — 傳送訊息、查詢會話/聯絡人/聊天歷史記錄/映像/收藏夾，並公開穩定的 HTTP/gRPC 表面以進行代理整合。當用戶要求「發送微信訊息」、「發微信」、查詢微信聯絡人/群組/訊息、尋找誰在聊天中說了些什麼、從歷史記錄中獲取圖像、導出聊天記錄、將微信連接到 Hermes / n8n / Dify / LangChain 或在真實的 macOS 微信帳戶上運行任何微信機器人時使用。需要 macOS (Apple Silicon) 上的微信 4.1.8 / 4.1.9 和 `wechatuse_` 啟動碼。一次性‘wechat-use init’提取DB key；無需 sudo，無需重新簽署WeChat.app。可選的遠端橋接 — `wechat-usetunnel setup --hostname <yours>` 透過 Cloudflare Tunnel 公開本機 REST API，以供遠端服務呼叫。
