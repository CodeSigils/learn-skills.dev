macOS 微信 CLI + 本地 HTTP 桥 + Wechaty Puppet gRPC 网关 — 发送消息、查询会话/联系人/聊天历史记录/图像/收藏夹，并公开稳定的 HTTP/gRPC 表面以进行代理集成。当用户要求“发送微信消息”、“发微信”、查询微信联系人/群组/消息、查找谁在聊天中说了些什么、从历史记录中获取图像、导出聊天记录、将微信连接到 Hermes / n8n / Dify / LangChain 或在真实的 macOS 微信帐户上运行任何微信机器人时使用。需要 macOS (Apple Silicon) 上的微信 4.1.8 / 4.1.9 和 `wechatuse_` 激活码。一次性‘wechat-use init’提取DB key；无需 sudo，无需重新签名WeChat.app。可选的远程桥接 — `wechat-usetunnel setup --hostname <yours>` 通过 Cloudflare Tunnel 公开本地 REST API，以供远程服务调用。
