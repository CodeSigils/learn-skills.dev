CLI WeChat per macOS + bridge HTTP locale + gateway gRPC Wechaty Puppet: invia messaggi, interroga sessioni/contatti/cronologia chat/immagini/preferiti ed esponi superfici HTTP/gRPC stabili per l'integrazione dell'agente. Da utilizzare quando l'utente chiede di "inviare un messaggio WeChat", "发微信", interrogare contatti/gruppi/messaggi WeChat, cercare chi ha detto cosa in una chat, recuperare immagini dalla cronologia, esportare la cronologia chat, collegare WeChat a Hermes / n8n / Dify / LangChain o eseguire qualsiasi bot WeChaty su un vero account WeChat macOS. Richiede WeChat 4.1.8 / 4.1.9 su macOS (Apple Silicon) e un codice di attivazione `wechatuse_`. "wechat-use init" una tantum estrae la chiave DB; no sudo, nessuna nuova firma di WeChat.app. Bridge remoto opzionale: `wechat-use tunnel setup --hostname <yours>` espone l'API REST locale tramite Cloudflare Tunnel affinché i servizi remoti possano chiamare.
