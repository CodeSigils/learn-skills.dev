macOS WeChat CLI + puente HTTP local + puerta de enlace Wechaty Puppet gRPC: envíe mensajes, consulte sesiones/contactos/historial de chat/imágenes/favoritos y exponga superficies HTTP/gRPC estables para la integración de agentes. Úselo cuando el usuario solicite 'enviar un mensaje de WeChat', '发微信', consultar contactos/grupos/mensajes de WeChat, buscar quién dijo qué en un chat, recuperar imágenes del historial, exportar el historial de chat, conectar WeChat a Hermes / n8n / Dify / LangChain o ejecutar cualquier bot wechaty en una cuenta real de macOS WeChat. Requiere WeChat 4.1.8/4.1.9 en macOS (Apple Silicon) y un código de activación `wechatuse_`. El `wechat-use init` de una sola vez extrae la clave de la base de datos; sin sudo, sin volver a firmar WeChat.app. Puente remoto opcional: `wechat-use Tunnel setup --hostname <yours>` expone la API REST local a través del túnel de Cloudflare para que los servicios remotos llamen.
