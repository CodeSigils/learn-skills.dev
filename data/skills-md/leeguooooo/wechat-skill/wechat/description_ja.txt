macOS WeChat CLI — メッセージを送信し、ローカル データベースからセッション / 連絡先 / チャット履歴 / モーメント / お気に入りをクエリします。ユーザーが「WeChat メッセージの送信」、「発行微信」、WeChat の連絡先/グループ/メッセージのクエリ、チャットで誰が何を発言したかの検索、モーメント / 朋友圈の読み取り、またはチャット履歴のエクスポートを要求する場合に使用します。 macOS (Apple Silicon) では WeChat 4.1.8 が必要です。 1 回限りの「wechat init」により DB キーが抽出されます。 sudo も WeChat.app の再署名も不要です。
