Удобство использования нескольких учетных записей в стиле AWS для Cloudflare Wrangler. Используйте, когда вам нужно запускать команды wrangler для определенной учетной записи Cloudflare, управлять сохраненными профилями OAuth, устанавливать или переключать постоянный профиль по умолчанию или открывать изолированную подоболочку для профиля. Предпочитайте --json для машиночитаемого вывода.
