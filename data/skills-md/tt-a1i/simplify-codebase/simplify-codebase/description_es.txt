Auditoría de simplificación o simplificación autorizada del código base cuyo objetivo declarado es eliminar la complejidad accidental. Úselo para la eliminación o consolidación respaldada por evidencia de código muerto, estado duplicado, API o capas redundantes, abstracciones sin propietario, registros de compatibilidad o diseño obsoletos y sobreingeniería en cualquier lenguaje; también úselo para 代码简化 o 熵回收. No lo utilice para revisiones de código generales, incorporación, refactorizaciones solo de estilo o afinamiento de rendimiento.

Por favor, responda siempre en el idioma del usuario.
