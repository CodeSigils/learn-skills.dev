يُستخدم عند اقتراح مجموعة وكلاء فرعيين واحدة فقط لـ Codex قبل بدء العمل للمهام متعددة المسارات: مراجعة الفرع/العلاقات العامة عبر الأخطاء أو الأمان أو الاختبارات أو قابلية الصيانة أو المستندات أو مخاطر الانحدار؛ تتبع مسار التعليمات البرمجية بالإضافة إلى التحقق من المستندات/واجهة برمجة التطبيقات؛ بحث الخيارات مع توليف المفاضلة. تعيين المصادقة/قاعدة التعليمات البرمجية قبل تقييم المخاطر أو التخطيط. استشارية فقط؛ لا يوجد ظهور تلقائي؛ الموافقة مطلوبة. لا تستخدم لعمليات تسليم الوكيل الفرعي المفوضة، أو الإصلاحات التافهة لملف واحد، أو تعديلات الصياغة فقط، أو البحث عن حقيقة واحدة، أو الطلبات غير الواضحة، أو إلغاء الاشتراك الصريح.
