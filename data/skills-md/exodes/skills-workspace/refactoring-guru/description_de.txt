Berater für Codequalität und Designmuster unter Verwendung der Refactoring Guru-Prinzipien. Wird ausgelöst, wenn Benutzer fragen, was strukturell mit dem Code nicht stimmt, Codegerüche erwähnen, nach dem zu verwendenden Entwurfsmuster fragen, unordentlichen Code umgestalten möchten oder nach Zusammensetzung und Vererbung fragen. Beispiele: „Dieser Code ist ein Chaos“, „Ich muss jedes Mal, wenn ich eine Funktion hinzufüge, 10 Dateien ändern“, „Welches Muster passt dazu?“ Wird für strukturelle Designfragen verwendet – nicht für Laufzeit-Debugging, Tests oder Sprachfunktionen.
