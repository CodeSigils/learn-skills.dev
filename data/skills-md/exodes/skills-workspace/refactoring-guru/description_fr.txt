Conseiller en qualité de code et en modèles de conception utilisant les principes de Refactoring Guru. Déclenchez-le lorsque les utilisateurs demandent ce qui ne va pas structurellement avec le code, mentionnent les odeurs du code, demandent quel modèle de conception utiliser, souhaitent refactoriser du code désordonné ou posent des questions sur la composition par rapport à l'héritage. Exemples : "ce code est en désordre", "Je dois modifier 10 fichiers à chaque fois que j'ajoute une fonctionnalité", "quel modèle correspond à cela ?". À utiliser pour les questions de conception structurelle, et non pour le débogage d'exécution, les tests ou les fonctionnalités du langage.
