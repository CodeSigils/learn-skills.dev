Scannen Sie die Struktur, Abhängigkeiten, Architektur, Konventionen und Domäne eines Projekts eingehend und schreiben Sie die Ergebnisse dann in eine strukturierte PROJECT_ANALYSIS.md-Datei, die jeder Mensch oder Agent zur schnellen Orientierung verwenden kann. Verwenden Sie diese Option, wenn der Benutzer sagt: „Dieses Projekt analysieren“, „die Codebasis durchleuchten“, „eine Projektübersicht schreiben“, „mich einbinden“, „Was macht dieses Projekt“, „dieses Repo zuordnen“ oder wenn eine neue Agentensitzung eine unbekannte Codebasis verstehen muss, bevor sie mit der eigentlichen Arbeit beginnen kann.
