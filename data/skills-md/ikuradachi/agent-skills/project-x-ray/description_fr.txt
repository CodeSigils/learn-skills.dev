Analysez en profondeur la structure, les dépendances, l'architecture, les conventions et le domaine d'un projet, puis écrivez les résultats dans un fichier PROJECT_ANALYSIS.md structuré que tout humain ou agent peut utiliser pour une orientation rapide. À utiliser lorsque l'utilisateur dit « analyser ce projet », « radiographier la base de code », « rédiger un aperçu du projet », « m'intégrer », « que fait ce projet », « mapper ce dépôt » ou lorsqu'une nouvelle session d'agent doit comprendre une base de code inconnue avant d'effectuer un vrai travail.
