قم بتشغيل حلقة وكيل تعتمد على المواصفات حيث تعيش مهام البرمجة كمواصفات تخفيض السعر التي تنتقل عبر البريد الوارد → نشط → الأرشيف، ويتم تنفيذها بواسطة Claude Code أو Codex، وتمرير بوابة مراجعة قبل أن يتم احتسابها على أنها منتهية. يُستخدم عندما يذكر المستخدم "مصنع الحلقات"، أو "حلقة تعتمد على المواصفات"، أو "مصنع وكيل"، أو يريد عمل وكيل قابل للتكرار/قابل للمراجعة، أو عندما يحتوي الريبو على مصنع/مواصفات/صندوق وارد أو دليل مصنع/مواصفات/نشط. يغطي أيضًا تركيب وسقالات CLI الخاصة بمصنع الحلقات في المشروع.
