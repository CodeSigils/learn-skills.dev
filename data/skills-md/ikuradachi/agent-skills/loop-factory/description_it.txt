Esegui un ciclo di agenti basato sulle specifiche in cui le attività di codifica vivono come specifiche di markdown che si spostano attraverso la posta in arrivo → attivo → archivio, vengono implementate da Claude Code o Codex e superano un controllo di revisione prima di essere considerate completate. Da utilizzare quando l'utente menziona "loop factory", un "loop basato sulle specifiche", una "fabbrica di agenti", desidera un funzionamento dell'agente ripetibile/revisionabile o quando un repository ha una directory factory/specs/inbox o factory/specs/active. Copre anche l'installazione e l'impalcatura della CLI loop-factory in un progetto.
