مهارة تقوم بتحليل سجلات JSONL لجلسة Claude Code لإنشاء تقارير كفاءة الرمز المميز/السياق (لوحة معلومات HTML + اقتراحات توفير التكلفة). يجب أن يتم تشغيله لطلبات مثل "تحليل كفاءة الرمز المميز"، و"كفاءة الجلسة"، و"تحليل التكلفة"، و"تقرير استخدام كود كلود"، و"تحليل كفاءة الرمز المميز"، و"إظهار تكلفة الجلسة"، و"تحسين كفاءة الرمز المميز"، و"درجة الكفاءة"، و"كم أنفقت على كلود"، و"تقرير الجلسة"، وما إلى ذلك. استخدمه عندما يريد المستخدم معرفة أنماط استخدام كود كلود أو التكلفة أو الكفاءة في التقرير أو يسأل عن كيفية تقليلها. قم بتطبيقه في أي حالة حيث يلزم تجميع مجموعة الجلسات بأكملها وتسجيلها وتصورها - وليس جلسة واحدة.
