Claude Code セッションの JSONL ログを解析して、トークン/コンテキスト効率レポート (HTML ダッシュボード + コスト削減の提案) を生成するスキル。これは、「トークン効率分析」、「セッション効率」、「コスト分析」、「クロード コード使用レポート」、「トークン効率の分析」、「セッション コストの表示」、「トークン効率の向上」、「効率スコア」、「クロードに費やした金額」、「セッション レポート」などのリクエストによってトリガーされる必要があります。ユーザーがレポート内のクロード コードの使用パターン、コスト、または効率を知りたい場合、または削減方法を尋ねる場合に使用します。彼ら。単一のセッションだけでなく、複数のセッション全体の集計、スコアリング、視覚化が必要なあらゆるケースに適用します。
