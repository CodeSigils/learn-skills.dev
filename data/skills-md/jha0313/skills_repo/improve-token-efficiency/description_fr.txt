Une compétence qui analyse les journaux JSONL de la session Claude Code pour générer des rapports d'efficacité des jetons/contextes (tableau de bord HTML + suggestions d'économies de coûts). Il doit être déclenché par des requêtes telles que « analyse de l'efficacité des jetons », « efficacité de la session », « analyse des coûts », « rapport d'utilisation de Claude Code », « analyser l'efficacité des jetons », « afficher le coût de la session », « améliorer l'efficacité des jetons », « score d'efficacité », « combien ai-je dépensé pour Claude », « rapport de session », etc. Utilisez-le lorsque l'utilisateur souhaite connaître les modèles d'utilisation, le coût ou l'efficacité de Claude Code dans le rapport, ou demande comment les réduire. Appliquez-le à tout cas nécessitant l'agrégation, la notation et la visualisation de plusieurs sessions dans leur ensemble, et pas seulement d'une seule session.
