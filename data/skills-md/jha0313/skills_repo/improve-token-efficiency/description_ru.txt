Навык, который анализирует журналы JSONL сеанса Claude Code для создания отчетов об эффективности токена/контекста (панель управления HTML + рекомендации по экономии долларов). Он должен запускаться для таких запросов, как «анализ эффективности токена», «эффективность сеанса», «анализ затрат», «отчет об использовании кода Claude», «анализировать эффективность токена», «показать стоимость сеанса», «повысить эффективность токена», «показатель эффективности», «сколько я потратил на Claude», «отчет о сеансе» и т. д. Используйте его, когда пользователь хочет узнать шаблоны использования кода Claude в репозитории, затраты или эффективность или спрашивает, как их уменьшить. Применяйте его к любому случаю, требующему агрегирования, оценки и визуализации нескольких сеансов в целом, а не только одного сеанса.
