Mettez à jour la liste blanche IP Scientia WiFi dans Jenkins. Capture l'adresse IP publique actuelle avant le VPN, connecte OpenVPN, puis déclenche le travail Jenkins `change-ip-wifi-scientia` avec l'adresse IP capturée. À utiliser lorsque votre IP WiFi a changé et que vous devez retrouver l'accès à Scientia.
