Управляйте содержимым рабочей области Notion через Notion MCP с помощью интерфейса командной строки UXC, включая поиск, выборку, поиск пользователей/команд, создание и обновление страниц/баз данных, а также комментарии. Используйте, когда задачи требуют вызова инструментов Notion через MCP с OAuth (authorization_code + PKCE), особенно когда требуются безопасные элементы управления записью и анализ JSON-конверта.
