Bedienen Sie den Inhalt des Notion-Arbeitsbereichs über Notion MCP mithilfe der UXC-CLI, einschließlich Suchen, Abrufen, Nachschlagen von Benutzern/Teams, Erstellen und Aktualisieren von Seiten/Datenbanken sowie Kommentaren. Wird verwendet, wenn für Aufgaben das Aufrufen von Notion-Tools über MCP mit OAuth (authorization_code + PKCE) erforderlich ist, insbesondere wenn sichere Schreibkontrollen und JSON-Envelope-Analyse erforderlich sind.
