Skill Evolver (Taotie): fortalece una habilidad objetivo "devorando" y analizando las fortalezas de otras habilidades.  
Activa esta habilidad cuando el usuario quiera: fusionar dos habilidades, optimizar una habilidad con otra, comparar y analizar los pros y los contras de dos habilidades, extraer las ventajas de una habilidad en otra, o decir cosas como "alimentar X a Y", "optimizar Y con X", "combinar estas dos habilidades", "consumir esta habilidad", "evolución de habilidades", "mejora de habilidades", "fusionar habilidades", etc. Incluso si el usuario no dice explícitamente "Taotie", siempre y cuando implique transferir capacidades entre dos habilidades, análisis comparativo o extracción de ventajas, se debe utilizar esta habilidad.
