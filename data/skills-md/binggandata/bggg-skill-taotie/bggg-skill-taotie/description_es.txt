Skill Evolver (Taotie): refuerza una habilidad objetivo "devorando" y analizando las fortalezas de otras habilidades. Debe activarse siempre que el usuario quiera: fusionar dos habilidades, optimizar una habilidad con otra, comparar y analizar los pros y los contras de dos habilidades, extraer las ventajas de una habilidad en otra o decir cosas como "alimentar X a Y", "optimizar Y con X", "fusionar estas dos habilidades", "devorar esta habilidad", "evolución de habilidades", "mejorar habilidades", "combinar habilidades", etc. Incluso si el usuario no dice explícitamente "Taotie", siempre que implique transferencia de capacidad, comparativa. análisis o extracción de ventajas entre dos habilidades, se debe utilizar esta habilidad.
