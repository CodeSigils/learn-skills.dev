قم بتحويل الصور ولقطات الشاشة والملصقات ولقطات شاشة صفحة PPT ومسودات تصميم HTML أو SVG إلى PPTX قابل للتحرير باستخدام مهارة Codex. عندما يحتاج المستخدمون إلى image2ppt، أو image2pptx، أو تحويل الصورة إلى PPT، أو لقطة الشاشة إلى PPT، أو PNG/JPEG لشرائح قابلة للتحرير، أو HTML/SVG إلى PPTX، أو تقسيم التصميم إلى مكونات صورة ومربعات نص لتجميع PowerPoint، أو يريدون إعادة استخدام إمكانية إنشاء الصور المضمنة في Codex لإعادة بناء رسم تخطيطي مسطح إلى PPT متعدد العناصر قابل للتحرير، فيجب عليهم استخدام هذه المهارة. عند التعامل مع الصور الثنائية في Codex، يتم افتراضيًا الجمع بين مهارة imagegen: أولاً استخدام فهم التخطيط المرئي لـ Codex، ثم استخدام إمكانية إنشاء/تحرير الصور المضمنة لإنشاء أو تنظيف صور مكونة متعددة، وأخيرًا تجميع PPTX باستخدام البرنامج النصي لهذه المهارة.
