The Codex skill that converts images, screenshots, posters, PPT page screenshots, HTML or SVG design drafts into editable PPTX. When users need image2ppt, image2pptx, picture-to-PPT, screenshot-to-PPT, PNG/JPEG to editable slides, HTML/SVG to PPTX, splitting a design into image components and text boxes and reassembling into PowerPoint, or wish to reuse Codex’s built‑in image generation capability to reconstruct a flat diagram into a multi‑element editable PPT, this skill should be used. When handling binary images in Codex, it is by default combined with the imagegen skill: first use Codex’s visual layout understanding, then use the built‑in image generation/editing capability to generate or clean up multiple component images, and finally assemble the PPTX with the script of this skill.
