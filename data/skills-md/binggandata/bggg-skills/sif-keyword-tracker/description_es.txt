Seguimiento dinámico de palabras clave Sif (Skill2). Cuando el mismo ASIN tiene datos históricos, sif-keyword-scout los activa automáticamente, compara la lista de palabras clave principales de PD durante un período de 1 a 7 días y genera un informe de actualización de la base de datos de palabras clave. El agente debe escribirinsights_tracker.md y, antes de escribir información, completar el punto de pausa③ para confirmar la estrategia de implementación con el usuario.
