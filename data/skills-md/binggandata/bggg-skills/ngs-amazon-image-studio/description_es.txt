Genere imágenes de productos de Amazon y de comercio electrónico transfronterizo a partir de una tarjeta de presentación de producto. Úselo cuando el usuario solicite una imagen de fondo blanco, una imagen de exhibición, una imagen de punto de venta, una imagen principal, una imagen de detalle, una imagen de estilo de vida, una o más imágenes de comercio electrónico o un conjunto completo de imágenes. Recopile siempre primero la tarjeta de presentación, luego confirme los tipos de imágenes, la ubicación de salida, los nombres de archivos y el plan de generación antes de crear imágenes.
