Générez des images de produits Amazon et de commerce électronique transfrontalier à partir d'une carte de visite produit. À utiliser lorsque l'utilisateur demande une image sur fond blanc, une image de vitrine, une image d'argument de vente, une image de héros, une image de détail, une image de style de vie, une ou plusieurs images de commerce électronique ou un ensemble d'images complet. Récupérez toujours la carte de visite en premier, puis confirmez les types d'images, l'emplacement de sortie, les noms de fichiers et le plan de génération avant de créer des images.
