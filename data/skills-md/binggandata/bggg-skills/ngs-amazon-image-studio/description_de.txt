Generieren Sie Amazon- und Cross-Border-E-Commerce-Produktbilder aus einer Produktvisitenkarte. Verwenden Sie diese Option, wenn der Benutzer ein Bild mit weißem Hintergrund, ein Präsentationsbild, ein Verkaufsargumentbild, ein Heldenbild, ein Detailbild, ein Lifestyle-Bild, ein oder mehrere E-Commerce-Bilder oder einen vollständigen Bildsatz anfordert. Sammeln Sie immer zuerst die Visitenkarte ein und bestätigen Sie dann die Bildtypen, den Ausgabeort, die Dateinamen und den Generierungsplan, bevor Sie Bilder erstellen.
