Utilice una sesión de inicio de sesión de Chrome auténtica localmente para realizar investigaciones de TikTok, admitiendo WebBridge, Chrome/CDP, Apple Events o rutas asistidas manualmente. Cuando un usuario solicita buscar palabras clave en TikTok, buscar creadores, probar videos, abrir la página de inicio de un creador, recopilar trabajos recientes, extraer enlaces de videos/títulos/autores/métricas de participación, capturar capturas de pantalla como evidencia, generar paquetes de investigación CSV/Markdown/JSON o realizar investigaciones sobre creadores/contenido/temas/direcciones de comercio electrónico de TikTok, utilice esta habilidad. No depende de API de TikTok de terceros; El principio básico es realizar únicamente lectura de páginas visibles, desplazamiento, captura de pantalla y organización estructurada.
