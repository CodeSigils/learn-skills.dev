ローカルで認証された Chrome ログイン セッションを使用して TikTok リサーチを実施し、WebBridge、Chrome/CDP、Apple Events、または手動支援パスをサポートします。ユーザーが TikTok でのキーワード検索、クリエイターの検索、サンプルビデオの検索、クリエイターのホームページのオープン、最近の作品の収集、ビデオのリンク/タイトル/作者/エンゲージメント指標の抽出、証拠としてのスクリーンショットのキャプチャ、CSV/Markdown/JSON リサーチ パッケージの出力、または TikTok クリエイター/コンテンツ/トピック/e コマースの方向性に関するリサーチをリクエストする場合、このスキルを使用します。サードパーティの TikTok API には依存しません。基本的な原則は、表示されているページの読み取り、スクロール、スクリーンショットの撮影、および構造化された整理のみを実行することです。
