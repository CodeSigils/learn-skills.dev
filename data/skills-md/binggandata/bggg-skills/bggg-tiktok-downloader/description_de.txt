Laden Sie TikTok-Videos lokal herunter. Wenn ein Benutzer einen einzelnen TikTok-Videolink, einen Freigabelink, einen Videolinktext, einen Link zur Startseite des TikTok-Erstellers oder ein @handle bereitstellt und zum Herunterladen, Speichern, Abrufen, Batch-Download, zum Herunterladen der Werke des Erstellers, zum Herunterladen einer bestimmten Anzahl von Werken oder zum Herunterladen aller Werke auffordert, verwenden Sie diesen Skill. Bevorzugen Sie yt-dlp und greifen Sie auf tikwm zurück, wenn der Download eines einzelnen Videos fehlschlägt. Verweisen Sie optional auf einen lokalen TikTokDownloader als Hilfe für die Erkennung von Linktypen.
