Skill Evolver (Taotie): fortalece una habilidad objetivo al "devorar" y analizar las ventajas de otras habilidades. Cuando el usuario quiere integrar dos habilidades, usar una habilidad para mejorar otra, comparar y analizar las fortalezas y debilidades de dos habilidades, extraer los beneficios de una habilidad en otra, o dice "alimentar X a Y", "usar X para optimizar Y", "integrar estas dos habilidades", "comer esta habilidad", "evolución de habilidades", "mejora de habilidades", "fusionar habilidades", etc., esta habilidad debe activarse. Incluso si el usuario no menciona explícitamente "Taotie", siempre que implique transferencia de habilidades, análisis comparativo o extracción de ventajas entre dos habilidades, esta habilidad debe usarse.
