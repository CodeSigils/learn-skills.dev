Amazon Sif Keyword Intelligence Reconnaissance System (Skill 1). The user inputs an ASIN to obtain three Sif reports (keyword research / reverse lookup traffic terms / ad term lookup). Python performs tiered analysis, opportunity rating, and gap analysis, and cross‑outputs a PD primary keyword list from the three tables. Supports both “manual export by the user” and “AI browser export” methods. The path is parsed via the workspace .sif-config.json and is not hard‑coded to the local machine. The agent interprets the results in the role of an Amazon keyword strategy consultant and guides the parameters. If the ASIN has historical records, sif‑keyword‑tracker is automatically triggered. Triggers: sif keywords, PD battle‑ready keywords, ASIN keyword research, run skill1.
