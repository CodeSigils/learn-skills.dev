ユーザーがすでにログインしている Chrome を制御し、X のレンダリングされた Web インターフェイスを検索し、表示される結果をスクロールし、元の投稿テキストとメタデータを DOM から正規化された JSONL に抽出することにより、監査可能な X/Twitter の公開投稿を収集します。 X がユーザーのブラウザ セッションを必要とし、Cookie、資格情報、内部 GraphQL、有料 API、または検索エンジン スニペットをエクスポートまたは使用してはならない場合に、VOC 調査、ソーシャル リスニング、多言語キーワード検出、競合他社の監視、または履歴検索に使用します。 bggg VOC スイートの X データ レイヤー (共有プロジェクト フォルダー。業界オーケストレーターによって調整され、bggg-voc-report によってレポートされます)。
