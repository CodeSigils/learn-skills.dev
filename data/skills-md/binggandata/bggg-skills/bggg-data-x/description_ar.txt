قم بتجميع منشورات X/Twitter العامة القابلة للتدقيق من خلال التحكم في Chrome الذي قام المستخدم بتسجيل الدخول بالفعل، والبحث في واجهة الويب المقدمة لـ X، وتمرير النتائج المرئية، واستخراج نص المنشور الأصلي والبيانات التعريفية من DOM إلى JSONL العادي. يُستخدم لأبحاث المركبات العضوية المتطايرة، أو الاستماع الاجتماعي، أو اكتشاف الكلمات الرئيسية متعددة اللغات، أو مراقبة المنافسين، أو البحث التاريخي عندما يتطلب X جلسة متصفح المستخدم وملفات تعريف الارتباط، أو بيانات الاعتماد، أو GraphQL الداخلي، أو واجهات برمجة التطبيقات المدفوعة، أو مقتطفات محرك البحث، ويجب ألا يتم تصديرها أو استخدامها. طبقة بيانات X لمجموعة bggg VOC (مجلد مشروع مشترك، يتم تنظيمه بواسطة منسق الصناعة، ويتم الإبلاغ عنه بواسطة bggg-voc-report).
