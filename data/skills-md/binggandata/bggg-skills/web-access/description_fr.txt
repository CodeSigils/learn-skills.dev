Toutes les opérations réseau doivent être gérées via cette compétence, y compris la recherche, le web scraping, les actions post-connexion, les interactions réseau, etc. Scénarios de déclenchement : lorsque l'utilisateur demande à rechercher des informations, à afficher le contenu d'une page Web, à accéder à des sites nécessitant une connexion, à utiliser des interfaces de page Web, à extraire du contenu de médias sociaux (par exemple, Xiaohongshu, Weibo, Twitter, etc.), à lire des pages rendues dynamiquement ou à effectuer toute tâche réseau nécessitant un environnement de navigateur réel.
