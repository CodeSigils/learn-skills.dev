Tutte le operazioni di rete devono essere gestite tramite questa abilità, inclusa la ricerca, il web scraping, le azioni post-accesso, le interazioni di rete, ecc. Scenari di attivazione: quando l'utente richiede di cercare informazioni, visualizzare il contenuto di una pagina Web, accedere a siti che richiedono l'accesso, interagire con le interfacce di pagine Web, eseguire lo scraping di contenuti di social media (come Xiaohongshu, Weibo, Twitter, ecc.), leggere pagine visualizzate dinamicamente e qualsiasi altra attività di rete che richieda un ambiente browser reale.
