Todas las operaciones de red deben procesarse a través de esta habilidad, incluida la búsqueda, el web scraping, las acciones posteriores al inicio de sesión, las interacciones de red, etc. Escenarios desencadenantes: cuando un usuario solicita buscar información, ver el contenido de una página web, acceder a sitios que requieren inicio de sesión, interactuar con una interfaz web, extraer contenido de redes sociales (por ejemplo, Xiaohongshu, Weibo, Twitter, etc.), leer páginas renderizadas dinámicamente o realizar cualquier tarea de red que requiera un entorno de navegador real.
