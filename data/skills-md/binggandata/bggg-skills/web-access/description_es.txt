Todas las operaciones de red deben manejarse a través de esta habilidad, incluida la búsqueda, el web scraping, las acciones posteriores al inicio de sesión, las interacciones de red, etc. Escenarios desencadenantes: cuando el usuario solicita buscar información, ver el contenido de una página web, acceder a sitios que requieren inicio de sesión, interactuar con interfaces de páginas web, extraer contenido de redes sociales (como Xiaohongshu, Weibo, Twitter, etc.), leer páginas renderizadas dinámicamente y cualquier otra tarea de red que requiera un entorno de navegador real.
