在 Dokploy（自託管 VPS 部署平台）上部署 Docker Compose 堆疊的綜合指南。每當使用者提到 Dokploy、將 Docker Compose 部署到 VPS、在自託管伺服器上使用 docker-compose.yml 部署應用程式或對 Dokploy 上執行的 Docker Compose 堆疊進行故障排除時，請使用此技能。涵蓋 Compose（堆疊）和應用程式（Git）部署類型、磁碟區策略、網路、環境變數、初始化容器、運行狀況檢查、Traefik 網域，以及對常見錯誤（如 EAI_AGAIN、權限被拒絕、不健康的容器和 JWT/配置問題）進行故障排除。將任何多服務 Docker Compose 堆疊部署到 Dokploy 時也適用。
