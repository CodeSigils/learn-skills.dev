دليل شامل لنشر مكدسات Docker Compose على Dokploy (منصة نشر VPS ذاتية الاستضافة). استخدم هذه المهارة كلما ذكر المستخدم Dokploy، أو نشر Docker Compose على VPS، أو نشر التطبيقات باستخدام docker-compose.yml على خادم مستضاف ذاتيًا، أو عند استكشاف أخطاء مكدسات Docker Compose التي تعمل على Dokploy وإصلاحها. يغطي كلاً من أنواع نشر الإنشاء (المكدس) والتطبيق (Git)، وإستراتيجيات الحجم، والشبكات، ومتغيرات البيئة، وحاويات init، والفحوصات الصحية، والمجالات باستخدام Traefik، واستكشاف الأخطاء الشائعة وإصلاحها مثل EAI_AGAIN، ورفض الأذونات، والحاويات غير الصحية، ومشكلات JWT/config. ينطبق أيضًا عند نشر أي مكدس Docker Compose متعدد الخدمات إلى Dokploy.
