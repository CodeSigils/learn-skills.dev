在 Dokploy（自托管 VPS 部署平台）上部署 Docker Compose 堆栈的综合指南。每当用户提到 Dokploy、将 Docker Compose 部署到 VPS、在自托管服务器上使用 docker-compose.yml 部署应用程序或对 Dokploy 上运行的 Docker Compose 堆栈进行故障排除时，请使用此技能。涵盖 Compose（堆栈）和应用程序（Git）部署类型、卷策略、网络、环境变量、初始化容器、运行状况检查、Traefik 域，以及对常见错误（如 EAI_AGAIN、权限被拒绝、不健康的容器和 JWT/配置问题）进行故障排除。将任何多服务 Docker Compose 堆栈部署到 Dokploy 时也适用。
