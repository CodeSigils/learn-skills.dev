Guide complet pour le déploiement des piles Docker Compose sur Dokploy (plateforme de déploiement VPS auto-hébergée). Utilisez cette compétence chaque fois que l'utilisateur mentionne Dokploy, déploie Docker Compose sur un VPS, déploie des applications avec docker-compose.yml sur un serveur auto-hébergé ou lors du dépannage des piles Docker Compose exécutées sur Dokploy. Couvre à la fois les types de déploiement Compose (pile) et Application (Git), les stratégies de volume, la mise en réseau, les variables d'environnement, les conteneurs d'initialisation, les contrôles de santé, les domaines avec Traefik et le dépannage des erreurs courantes telles que EAI_AGAIN, autorisation refusée, conteneurs défectueux et problèmes JWT/config. S'applique également lors du déploiement de toute pile Docker Compose multiservice sur Dokploy.
