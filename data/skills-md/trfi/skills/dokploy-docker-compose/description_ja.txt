Dokploy (セルフホスト型 VPS デプロイ プラットフォーム) に Docker Compose スタックをデプロイするための包括的なガイド。このスキルは、ユーザーが Dokploy について言及する場合、VPS への Docker Compose のデプロイ時、自己ホスト型サーバー上で docker-compose.yml を使用してアプリケーションをデプロイする場合、または Dokploy 上で実行されている Docker Compose スタックのトラブルシューティングを行う場合に使用します。 Compose (スタック) とアプリケーション (Git) の両方のデプロイメント タイプ、ボリューム戦略、ネットワーク、環境変数、初期化コンテナー、ヘルスチェック、Traefik を使用したドメイン、および EAI_AGAIN、アクセス許可の拒否、異常なコンテナー、JWT/config の問題などの一般的なエラーのトラブルシューティングをカバーします。マルチサービスの Docker Compose スタックを Dokploy にデプロイする場合にも適用されます。
