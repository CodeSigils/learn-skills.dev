Umfassende Anleitung zur Bereitstellung von Docker Compose-Stacks auf Dokploy (selbstgehostete VPS-Bereitstellungsplattform). Verwenden Sie diesen Skill immer dann, wenn der Benutzer Dokploy erwähnt, Docker Compose auf einem VPS bereitstellt, Anwendungen mit docker-compose.yml auf einem selbst gehosteten Server bereitstellt oder wenn er Probleme mit Docker Compose-Stacks behebt, die auf Dokploy ausgeführt werden. Behandelt sowohl Compose- (Stack) als auch Anwendungs- (Git) Bereitstellungstypen, Volume-Strategien, Netzwerke, Umgebungsvariablen, Init-Container, Integritätsprüfungen, Domänen mit Traefik und die Fehlerbehebung bei häufigen Fehlern wie EAI_AGAIN, verweigerter Berechtigung, fehlerhaften Containern und JWT-/Konfigurationsproblemen. Gilt auch für die Bereitstellung eines Multi-Service-Docker-Compose-Stacks auf Dokploy.
