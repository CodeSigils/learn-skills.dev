Configure la delegación de AuthZ en Injective para el comercio automático basado en sesiones. Otorga un permiso limitado en el tiempo a una clave efímera para que la IA pueda realizar y cerrar operaciones perpetuas sin una ventana emergente de billetera ni una solicitud de contraseña para cada pedido. Utilice authz_grant para habilitar, authz_revoke para deshabilitar. Requiere que el servidor Injective MCP esté conectado.
