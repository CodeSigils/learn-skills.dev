Настройте делегирование AuthZ на Injective для автоматической торговли на основе сеанса. Предоставляет ограниченное по времени разрешение на использование эфемерного ключа, чтобы ИИ мог размещать и закрывать бессрочные сделки без всплывающего окна кошелька или запроса пароля для каждого ордера. Используйте authz_grant для включения и authz_revoke для отключения. Требуется подключение сервера Injective MCP.
