Utilice la interfaz de búsqueda web de AutoGLM para realizar búsquedas de información en Internet. Utilice esta habilidad cuando el usuario necesite buscar en línea, consultar las últimas noticias, recuperar contenido de la página web u obtener información en tiempo real. El token se obtiene automáticamente a través del servicio local http://127.0.0.1:53699/get_token, sin necesidad de configurar manualmente variables de entorno.
