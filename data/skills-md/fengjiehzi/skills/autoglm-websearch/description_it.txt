Utilizza l'interfaccia di ricerca Web di AutoGLM per ricerche di informazioni online. Utilizza questa abilità quando un utente deve effettuare ricerche in Internet, interrogare le ultime notizie, recuperare il contenuto di una pagina Web o ottenere informazioni in tempo reale. Il token viene ottenuto automaticamente tramite il servizio locale all'indirizzo http://127.0.0.1:53699/get_token, senza la necessità di configurare manualmente le variabili di ambiente.
