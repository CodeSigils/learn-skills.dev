Verwenden Sie die AutoGLM-Websuchoberfläche für die Online-Informationssuche. Diese Fähigkeit wird eingesetzt, wenn der Benutzer Netzwerksuchen durchführen, die neuesten Nachrichten abfragen, Webseiteninhalte abrufen oder Echtzeitinformationen abrufen muss. Das Token wird automatisch über den lokalen Dienst http://127.0.0.1: 53699/get_token abgerufen, ohne dass Umgebungsvariablen manuell konfiguriert werden müssen.
