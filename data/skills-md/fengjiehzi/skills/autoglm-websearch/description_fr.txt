Utilisez l'interface de recherche Web AutoGLM pour les recherches d'informations en ligne. Utilisez cette compétence lorsqu'un utilisateur a besoin de rechercher sur Internet, d'interroger les dernières nouvelles, de récupérer le contenu d'une page Web ou d'obtenir des informations en temps réel. Le jeton est automatiquement obtenu via le service local à l'adresse http://127.0.0.1:53699/get_token, sans qu'il soit nécessaire de configurer manuellement les variables d'environnement.
