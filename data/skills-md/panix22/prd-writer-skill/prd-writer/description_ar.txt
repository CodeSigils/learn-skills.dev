قم بتوجيه محادثات اكتشاف المنتج وإنتاج مستندات PRD القياسية باللغة الصينية. يُستخدم عندما يصف المستخدم فكرة منتج، أو طلب ميزة، أو طلب تحسين، أو مشروع ترميز حيوي، أو نطاق MVP، أو يطلب صراحةً كتابة PRD، أو مستند متطلبات المنتج، أو 产品需求، أو 功能规格. فرض سير عمل مرحلي من خلال التشخيص من وجهات نظر المستخدم/الأعمال/التقنية، وتأكيد بنية الصفحة والتنقل، وإخراج مفهوم موجز لـ PRD للمحاذاة، وتجميد النطاق، ثم إنشاء PRD جاهز للتنفيذ مع التدفقات والحالات والحقول والنسخ ومعالجة الاستثناءات.
