Ведите переговоры по ознакомлению с продуктами и подготавливайте стандартные документы PRD на китайском языке. Используйте, когда пользователь описывает идею продукта, запрос функции, запрос на улучшение, проект vibe-кодирования, объем MVP или явно просит написать PRD, документ с требованиями к продукту, 需求文档, 产品需求 или 功能规格. Обеспечьте поэтапный рабочий процесс, проведя диагностику с точки зрения пользователя/бизнеса/технических аспектов, подтвердив структуру страницы и навигацию, выведя краткую концептуальную PRD для согласования, заморозив область, а затем сгенерировав готовую к реализации PRD с потоками, состояниями, полями, копированием и обработкой исключений.
