Guíe las conversaciones sobre descubrimiento de productos y produzca documentos PRD estándar en chino. Úselo cuando el usuario describe una idea de producto, solicitud de función, solicitud de mejora, proyecto de codificación de vibraciones, alcance de MVP o solicita explícitamente escribir un PRD, un documento de requisitos del producto, 需求文档, 产品需求 o 功能规格. Aplique un flujo de trabajo por etapas mediante el diagnóstico desde las perspectivas del usuario/negocio/técnica, confirmando la estructura de la página y la navegación, generando un concepto PRD conciso para la alineación, congelando el alcance y luego generando un PRD listo para la implementación con flujos, estados, campos, copia y manejo de excepciones.
