Utilizza la CLI @vercel/next-browser per eseguire il debug delle pagine Next.js/React. Adatto per attività che necessitano di ottenere informazioni sullo stato del browser tramite comandi shell, tra cui apertura e navigazione della pagina, screenshot, albero dei componenti React, oggetti di scena, hook, shell PPR, componenti della cache, errori, log, richieste di rete, Core Web Vitals, prestazioni di idratazione, prestazioni di re-rendering e accesso alle pagine registrate utilizzando un file cookie fornito dall'utente. 

Si prega di rispondere sempre nella lingua dell'utente.
