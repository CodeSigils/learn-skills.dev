Utilice la CLI @vercel/next-browser para depurar páginas Next.js/React. Es adecuado para tareas que requieren recuperar información del estado del navegador con comandos de shell, incluida la apertura y navegación de páginas, capturas de pantalla, el árbol de componentes de React, accesorios, enlaces, shell PPR, componentes de caché, errores, registros, solicitudes de red, Core Web Vitals, rendimiento de hidratación, rendimiento de renderizado y acceso a páginas iniciadas a través de archivos cookie proporcionados por el usuario.
