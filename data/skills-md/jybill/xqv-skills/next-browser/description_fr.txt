Utilisez la CLI @vercel/next-browser pour déboguer les pages Next.js/React. Convient aux tâches qui nécessitent d'obtenir des informations sur l'état du navigateur via des commandes shell, notamment l'ouverture et la navigation de page, les captures d'écran, l'arborescence des composants React, les accessoires, les hooks, le shell PPR, les composants de cache, les erreurs, les journaux, les requêtes réseau, les Core Web Vitals, les performances d'hydratation, les performances de rendu et l'accès aux pages connectées à l'aide d'un fichier cookie fourni par l'utilisateur. 

Veuillez toujours répondre dans la langue de l'utilisateur.
