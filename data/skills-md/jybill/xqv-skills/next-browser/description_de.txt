Verwenden Sie die @vercel/next-browser-CLI, um Next.js/React-Seiten zu debuggen. Geeignet für Aufgaben, die das Abrufen von Browserstatusinformationen über Shell-Befehle erfordern, einschließlich Seitenöffnung und -navigation, Screenshots, React-Komponentenbaum, Requisiten, Hooks, PPR-Shell, Cache-Komponenten, Fehler, Protokolle, Netzwerkanforderungen, Core Web Vitals, Hydratationsleistung, Re-Rendering-Leistung und Zugriff auf angemeldete Seiten mithilfe einer vom Benutzer bereitgestellten Cookie-Datei.
