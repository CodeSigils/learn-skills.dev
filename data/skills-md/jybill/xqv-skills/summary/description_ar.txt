بعد توضيح المتطلبات أو الخطة أو كود التنفيذ، قم بدمج الكود والاختلافات ومسارات الوحدة النمطية التي تلبي المتطلبات في ملفات الوثائق/المواصفات ضمن المستندات/المواصفات؛ استخدم هذا عندما يطلب المستخدم تلخيص الوحدات أو ترسيخ المواصفات أو تحديث المواصفات أو تنظيم نطاق التنفيذ أو تسجيل نطاق التأثير أو الحدود الحالية أو مهام المهام. وينطبق أيضًا عندما يقدم المستخدم ملفات المتطلبات/الخطة/التنفيذ ويريد مزامنة السلوك النهائي مع المستندات/المواصفات.
