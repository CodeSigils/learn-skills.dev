Best Practices für Unit-Tests, Integrationstests und End-to-End-Tests. Wenn Benutzer das Hinzufügen von Tests, das Korrigieren von Tests, das Überprüfen der Testqualität, das Unterscheiden von Testtypen, den Umgang mit bedeutungslosen Behauptungen, die Entscheidung über eine Verspottung oder das Anpassen des Abdeckungsbereichs von spec/integration/e2e anfordern, sollte diese Fähigkeit verwendet werden; Selbst wenn Benutzer lediglich „Test“, „Unit-Test“, „Integrationstest“, „E2E“, „Assertion“, „Abdeckung“ oder „Mock“ erwähnen, sollten sie hier vorrangig auf die Standards verweisen.
