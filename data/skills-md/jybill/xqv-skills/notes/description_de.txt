Wenn Benutzer explizit das Hinzufügen von Kommentaren, das Anpassen von Kommentaren, das Überprüfen der Kommentarqualität, das Festlegen von Kommentarstandards anfordern oder bestimmen müssen, welche Teile komplexer Logik, Schleifen, If-Zweige, Variablengruppen, Zustandszweige, Datentransformationen, SQL-Spezifikationen, React Hook-Nebeneffekte oder Node.js-Backend-Orchestrierung einen Kommentar verdienen, nutzen Sie diese Fähigkeit. Das Ziel besteht darin, dass Kommentare die Absicht von Codeblöcken, variablen Verantwortlichkeiten und Geschäftsgrenzen erläutern, anstatt zeilenweise Erzählungen für einfachen Code bereitzustellen.
