Wenn Benutzer explizit das Hinzufügen von Kommentaren, das Anpassen von Kommentaren, das Überprüfen der Kommentarqualität, das Konsolidieren von Kommentarstandards anfordern oder bestimmen müssen, welche Teile komplexer Logik, Schleifen, If-Zweige, Variablengruppen, Zustandszweige, Datentransformationen, SQL-Bereiche, React Hook-Nebeneffekte oder Node.js-Backend-Orchestrierung Kommentare wert sind, verwenden Sie diese Fähigkeit. Das Ziel besteht darin, dass Kommentare die Absicht von Codeblöcken, variablen Verantwortlichkeiten und Geschäftsgrenzen erläutern, ohne für einfachen Code eine zeilenweise Erzählung bereitzustellen.
