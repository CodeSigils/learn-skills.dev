When users explicitly request adding comments, adjusting comments, reviewing comment quality, solidifying comment standards, or need to determine which parts of complex logic, loops, if‑branches, variable groups, state branches, data transformations, SQL scopes, React Hook side effects, or Node.js backend orchestration merit comments, use this skill. The goal is to have comments explain the intent of code blocks, variable responsibilities, and business boundaries, without providing line‑by‑line narration for simple code.
