Lorsque les utilisateurs demandent explicitement l'ajout de commentaires, l'ajustement de commentaires, la révision de la qualité des commentaires, la consolidation des normes de commentaires ou doivent déterminer quelles parties d'une logique complexe, boucles, branches if, groupes de variables, branches d'état, transformations de données, étendues SQL, effets secondaires de React Hook ou orchestration backend Node.js méritent des commentaires, utilisez cette compétence. L'objectif est que les commentaires expliquent l'intention des blocs de code, les responsabilités variables et les limites de l'entreprise, sans fournir de narration ligne par ligne pour un code simple.
