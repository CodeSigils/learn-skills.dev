Missionsgesteuerter SDD-Orchestrator: Nehmen Sie eine Funktionsbeschreibung, strukturieren Sie sie in einen Mission Brief (Ziel, Einschränkungen, Erfolgskriterien), generieren Sie eine geordnete Schrittliste mit Eingabeaufforderungen, die installierte SDD-Fähigkeiten über Modellaufruf oder Befehlsdateierkennung auslösen, und führen Sie diese Schritte zur konvergenten Implementierung durch. Verwenden Sie diese Option, wenn Sie eine End-to-End-Schleife zum Spezifizieren → Planen → Implementieren ↔ Konvergenz mit Gates, einem Leistungsschalter, einem Lebenslauf und einem Audit-Trail wünschen – ohne YAML-Dateien oder Profile pro Framework.
