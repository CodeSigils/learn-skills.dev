Orchestratore SDD orientato alla missione: prendi una descrizione della funzionalità, strutturala in un brief della missione (obiettivo, vincoli, criteri di successo), genera un elenco di passaggi ordinato con richieste che attivano le competenze SDD installate tramite l'invocazione del modello o il rilevamento del file di comando e percorri questi passaggi fino all'implementazione convergente. Utilizzalo quando desideri un ciclo end-to-end di specifica → pianificazione → implementazione ↔ convergenza con gate, un interruttore automatico, un curriculum e un audit trail, senza file YAML o profili per framework.
