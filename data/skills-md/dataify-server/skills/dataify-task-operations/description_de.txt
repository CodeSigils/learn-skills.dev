Überwachen Sie eine Dataify Builder-Aufgabe bis zum Abschluss, stellen Sie sie nach einer Unterbrechung sicher wieder her oder leiten Sie die plattformübergreifende Einrichtung von DATAIFY_API_TOKEN. Wird nach der Scraper-Übermittlung automatisch verwendet, wenn der Benutzer eine vorhandene Aufgaben-ID bereitstellt oder fragt, wie das Token konfiguriert werden soll. Nicht verwenden, wenn der Benutzer explizit ein reines Übermittlungsverhalten anfordert.
