Supervise una tarea de Dataify Builder hasta su finalización, recupérela de forma segura después de una interrupción o guíe la configuración de DATAIFY_API_TOKEN multiplataforma. Úselo automáticamente después del envío del raspador, cuando el usuario proporciona una ID de tarea existente o pregunta cómo configurar el token. No lo utilice cuando el usuario solicite explícitamente un comportamiento de solo envío.
