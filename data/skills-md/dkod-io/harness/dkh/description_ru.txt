Автономное решение для создания полноценных приложений из одной подсказки. Использует dkod для параллельного выполнения агента с семантическим объединением на уровне AST. Управляет планировщиком, который разбивает работу по символам на параллельные блоки, агентами N Generator, которые реализуют работу одновременно через изолированные сеансы dkod, и скептически настроенным оценщиком, который проверяет результат в реальном времени с помощью chrome-devtools и dk_verify. Полностью автономный — нулевое взаимодействие с пользователем от подсказки до рабочего, проверенного PR. Используйте этот навык всякий раз, когда пользователь предоставляет приглашение на сборку («построить...», «создать...», «сделать...») или вызывает /dkh.
