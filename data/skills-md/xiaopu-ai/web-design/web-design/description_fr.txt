COMPÉTENCES en matière de conception visuelle Web. Saisissez PRD / URL de référence / capture d'écran / mots-clés (n'importe quelle combinaison), produisez d'abord une spécification de conception DESIGN.md standardisée ; après confirmation de l'utilisateur, générez un code Web qui répond pleinement aux normes UI/UX, visuelles, de mouvement et réactives. Spécialisé dans le front-end Web : pages de destination, portfolios, pages de produits, blogs, sites personnels, pages d'introduction SaaS, etc. Déclenché lorsque l'utilisateur dit « aidez-moi à créer un site Web », « concevez une page », « créez-en une basée sur XX », « transformez cette capture d'écran/PRD en page Web », « créez une page de destination » ou « publiez une spécification de conception ». Non destiné au backend, aux bases de données ou aux corrections de bogues de logique pure.
