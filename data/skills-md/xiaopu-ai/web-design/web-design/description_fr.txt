COMPÉTENCES en matière de conception visuelle Web. Saisissez PRD / URL de référence / capture d'écran / mots-clés (n'importe quelle combinaison), produisez d'abord une spécification de conception DESIGN.md standardisée ; après confirmation de l'utilisateur, générez un code Web qui répond à toutes les normes UI/UX, visuelles, d'animation et réactives. Axé sur le côté Web : page de destination, portfolio, page produit, blog, site personnel, page d'introduction SaaS, etc. Déclenché lorsque l'utilisateur dit "aidez-moi à créer un site Web", "concevoir une page", "référence XX pour en créer une", "transformer cette capture d'écran/PRD en page Web", "créer une page de destination", "produire une spécification de conception". Non utilisé pour les corrections de bugs du backend, de la base de données ou de la logique pure.
