Webvisuelles Design SKILL. Geben Sie PRD / Referenz-URL / Screenshot / Schlüsselwörter (beliebige Kombination) ein und erstellen Sie zunächst eine standardisierte DESIGN.md-Designspezifikation. Generieren Sie nach der Bestätigung durch den Benutzer einen Webcode, der den UI/UX-, visuellen, Bewegungs- und Responsive-Standards vollständig entspricht. Spezialisiert auf Web-Frontend: Zielseiten, Portfolios, Produktseiten, Blogs, persönliche Websites, SaaS-Einführungsseiten usw. Wird ausgelöst, wenn der Benutzer sagt: „Helfen Sie mir, eine Website zu erstellen“, „Entwerfen Sie eine Seite“, „Erstellen Sie eine basierend aufXX“, „Umwandeln Sie diesen Screenshot/PRD in eine Webseite“, „Erstellen Sie eine Zielseite“ oder „Geben Sie eine Designspezifikation aus.“ Nicht für Backend-, Datenbank- oder reine Logik-Fehlerbehebungen gedacht.
