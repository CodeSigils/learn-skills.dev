مهارة التصميم المرئي للويب. إدخال PRD / عنوان URL المرجعي / لقطة الشاشة / الكلمات الرئيسية (أي مجموعة)، قم أولاً بإنتاج مواصفات تصميم DESIGN.md موحدة؛ بعد تأكيد المستخدم، قم بإنشاء كود الويب الذي يتوافق تمامًا مع معايير واجهة المستخدم/تجربة المستخدم والمرئية والحركة والاستجابة. متخصص في الواجهة الأمامية للويب: الصفحات المقصودة، والمحافظ، وصفحات المنتجات، والمدونات، والمواقع الشخصية، وصفحات مقدمة SaaS، وما إلى ذلك. يتم تشغيله عندما يقول المستخدم "ساعدني في إنشاء موقع ويب"، أو "تصميم صفحة"، أو "إنشاء صفحة بناءً على XX"، أو "تحويل لقطة الشاشة/PRD هذه إلى صفحة ويب"، أو "إنشاء صفحة مقصودة"، أو "إخراج مواصفات التصميم". غير مخصص للواجهة الخلفية أو قواعد البيانات أو إصلاحات الأخطاء المنطقية البحتة.
