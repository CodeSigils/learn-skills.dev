HABILIDAD en diseño visual web. Ingrese PRD / URL de referencia / captura de pantalla / palabras clave (cualquier combinación), primero produzca una especificación de diseño DESIGN.md estandarizada; después de que el usuario confirme, genere un código web que cumpla con todos los estándares UI/UX, visuales, de animación y responsivos. Se especializa en web: página de destino, portafolio, página de producto, blog, sitio personal, página de introducción de SaaS, etc. Se activa cuando el usuario dice "ayúdame a crear un sitio web", "diseñar una página", "crear una basada en XX", "convertir esta captura de pantalla/PRD en una página web", "crear una página de destino", "producir una especificación de diseño". No se utiliza para corregir errores de backend, bases de datos o lógica pura.
