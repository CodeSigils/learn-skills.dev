Use this skill when the user wants to complete the daily check-in on WorkBuddy (to earn check-in points). If WorkBuddy is not running, it will start automatically. It uses Playwright to locate DOM elements via CSS Selector and click them: first click the user menu in the bottom-left corner (class="user-menu"), wait 2 seconds, then click the "Claim Now →" button (class="daily-checkin-banner-action") to finish the check-in. Trigger keywords include "check-in", "WorkBuddy check-in", "daily check-in", "clock-in points", etc.
