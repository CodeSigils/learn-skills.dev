Utilisez cette compétence lorsque l'utilisateur souhaite effectuer l'enregistrement quotidien sur WorkBuddy (pour gagner des points d'enregistrement). Si WorkBuddy n'est pas en cours d'exécution, il sera démarré automatiquement. Utilisez Playwright pour localiser les éléments DOM via les sélecteurs CSS et cliquez : cliquez d'abord sur le menu utilisateur dans le coin inférieur gauche (class="user-menu"), attendez 2 secondes, puis cliquez sur le bouton "Réclamer maintenant →" (class="daily-checkin-banner-action") pour terminer l'enregistrement. Les mots-clés déclencheurs incluent « enregistrement », « enregistrement WorkBuddy », « enregistrement quotidien », « points d'arrivée », etc.
