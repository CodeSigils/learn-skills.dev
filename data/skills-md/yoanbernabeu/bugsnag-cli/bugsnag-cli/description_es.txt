Utilice la herramienta de línea de comandos bugsnag-cli para interactuar con la API de acceso a datos de Bugsnag. Utilice esta habilidad siempre que el usuario mencione errores de Bugsnag, quiera investigar errores de producción rastreados en Bugsnag, verificar el estado del proyecto o las métricas de estabilidad, enumerar organizaciones/proyectos/lanzamientos, configurar su acceso a la CLI de Bugsnag o necesite ayuda con cualquier sintaxis de comando bugsnag-cli. También se activa cuando el usuario pregunta sobre tendencias de errores, tasas de ausencia de fallas o quiere comentar sobre errores de Bugsnag desde la terminal.
