bugsnag-cli コマンドライン ツールを使用して、Bugsnag Data Access API と対話します。ユーザーが Bugsnag エラーに言及した場合、Bugsnag で追跡されている本番環境のバグを調査したい場合、プロジェクトの健全性または安定性メトリクスを確認したい場合、組織/プロジェクト/リリースをリストしたい場合、Bugsnag CLI アクセスを設定したい場合、または bugsnag-cli コマンド構文についてサポートが必要な場合には、このスキルを使用してください。ユーザーがエラー傾向やクラッシュフリー率について質問したり、ターミナルから Bugsnag エラーについてコメントしたい場合にもトリガーされます。
