Verwenden Sie das Befehlszeilentool bugsnag-cli, um mit der Bugsnag Data Access API zu interagieren. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Bugsnag-Fehler erwähnt, in Bugsnag verfolgte Produktionsfehler untersuchen, Projektzustands- oder Stabilitätsmetriken überprüfen, Organisationen/Projekte/Releases auflisten, seinen Bugsnag-CLI-Zugriff konfigurieren oder Hilfe bei der Befehlssyntax von bugsnag-cli benötigen. Wird auch ausgelöst, wenn der Benutzer vom Terminal aus nach Fehlertrends oder absturzfreien Raten fragt oder Bugsnag-Fehler kommentieren möchte.
