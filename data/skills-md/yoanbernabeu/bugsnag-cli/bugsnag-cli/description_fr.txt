Utilisez l'outil de ligne de commande bugsnag-cli pour interagir avec l'API Bugsnag Data Access. Utilisez cette compétence chaque fois que l'utilisateur mentionne des erreurs Bugsnag, souhaite enquêter sur les bogues de production suivis dans Bugsnag, vérifier l'état de santé ou les mesures de stabilité du projet, répertorier les organisations/projets/versions, configurer son accès CLI Bugsnag ou a besoin d'aide avec toute syntaxe de commande bugsnag-cli. Se déclenche également lorsque l'utilisateur pose des questions sur les tendances des erreurs, les taux sans crash ou souhaite commenter les erreurs Bugsnag depuis le terminal.
