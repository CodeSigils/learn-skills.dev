Используйте инструмент командной строки bugsnag-cli для взаимодействия с API доступа к данным Bugsnag. Используйте этот навык всякий раз, когда пользователь упоминает ошибки Bugsnag, хочет исследовать производственные ошибки, отслеживаемые в Bugsnag, проверить показатели работоспособности или стабильности проекта, составить список организаций/проектов/релизов, настроить доступ к Bugsnag CLI или ему нужна помощь с любым синтаксисом команды bugsnag-cli. Также срабатывает, когда пользователь спрашивает о тенденциях ошибок, показателях без сбоев или хочет прокомментировать ошибки Bugsnag с терминала.
