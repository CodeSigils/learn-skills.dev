Lösen Sie diesen Skill immer dann aus, wenn der Benutzer eine EPUB-Buchdatei verarbeiten und auf NotebookLM hochladen möchte
für tiefes analytisches Lesen. Aktivieren Sie, wenn: der Benutzer „NotebookLM“ oder „Notebook“ zusammen mit erwähnt
„Buch“, „E-Book“, „Epub“ oder ein Buchtitel; wenn sie ein EPUB in Kapitel konvertieren/aufteilen möchten;
wenn sie das Hochladen eines Buchs auf NotebookLM erwähnen; wenn sie einen Lesebegleiter erstellen möchten
Oder verwenden Sie die Methode „How To Read a Book“ mit NotebookLM. Auch Auslöser für Phrasen wie
„Analysieren Sie dieses Buch“, „Lesen Sie dieses Buch gründlich“, „Laden Sie Kapitel auf NotebookLM hoch“, „Epub auf NotebookLM“,
oder irgendeine Erwähnung des analytischen Lesens mit NotebookLM.
