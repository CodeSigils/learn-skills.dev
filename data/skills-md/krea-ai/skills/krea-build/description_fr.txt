Modèles pour créer des applications qui intègrent l'API Krea. Authentification, discipline de sondage, gestion des erreurs, validation, intégration frontend (SvelteKit/React/Vue) et workflow « prototype dans le chat, production dans l'application ». À utiliser lorsque l'utilisateur écrit du code qui appelle directement l'API Krea - en créant une interface utilisateur de générateur, un pipeline de contenu, un outil de création - et non lorsqu'il souhaite simplement générer une image. Pour la génération interactive, utilisez plutôt la compétence frère krea-ai.
