Muster zum Erstellen von Anwendungen, die die Krea-API integrieren. Authentifizierung, Umfragedisziplin, Fehlerbehandlung, Validierung, Frontend-Integration (SvelteKit/React/Vue) und der Workflow „Prototyp im Chat, Produkt in App erstellen“. Verwenden Sie es, wenn der Benutzer Code schreibt, der die Krea-API direkt aufruft – zum Beispiel beim Erstellen einer Generator-Benutzeroberfläche, einer Inhaltspipeline oder eines Kreativtools – und nicht, wenn er nur ein Bild generieren möchte. Verwenden Sie für die interaktive Generierung stattdessen die Geschwisterfähigkeit krea-ai.
