Шаблоны для создания приложений, интегрирующих Krea API. Аутентификация, дисциплина опроса, обработка ошибок, проверка, интеграция с внешним интерфейсом (SvelteKit/React/Vue) и рабочий процесс «прототип в чате, продуктизация в приложении». Используйте, когда пользователь пишет код, который напрямую вызывает API Krea — создает пользовательский интерфейс генератора, конвейер контента, творческий инструмент — а не когда он просто хочет сгенерировать одно изображение. Для интерактивной генерации вместо этого используйте родственный навык креа-ай.
