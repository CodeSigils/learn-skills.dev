Patrones para construir aplicaciones que integren la API de Krea. Autenticación, disciplina de sondeo, manejo de errores, validación, integración frontend (SvelteKit/React/Vue) y el flujo de trabajo 'prototipo en chat, producto en aplicación'. Úselo cuando el usuario esté escribiendo código que llame directamente a la API de Krea (creando una interfaz de usuario generadora, una canalización de contenido, una herramienta creativa), no cuando solo quiera generar una imagen. Para la generación interactiva, utilice la habilidad hermano krea-ai.
