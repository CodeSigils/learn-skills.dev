Générez et transformez des médias via Krea. À utiliser pour la génération d'images génériques, de courtes vidéos génériques, l'édition d'images, l'amélioration/mise à l'échelle, la formation LoRA, les portraits, les images contenant beaucoup de texte et la visualisation architecturale à partir de captures d'écran 3D/CAO. Pour les produits, les campagnes, les UGC, les places de marché ou les créations sociales payantes, utilisez krea-marketing. Pour l'animation professionnelle, les anime, les storyboards, les shotlists et les reprises, utilisez krea-animation. Pour l'intégration application/API, utilisez krea-build.
