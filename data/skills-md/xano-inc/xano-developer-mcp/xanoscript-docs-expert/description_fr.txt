Compétence d'expert pour comprendre, utiliser et modifier le système de documentation xanoscript_docs dans le projet xano-developer-mcp. Utilisez cette compétence chaque fois que vous travaillez avec des fichiers de documentation XanoScript (fichiers .md dans src/xanoscript_docs/), que vous modifiez l'outil MCP xanoscript_docs, que vous ajoutez de nouveaux sujets de documentation, que vous modifiez des documents existants, que vous mettez à jour le registre de sujets dans xanoscript.ts ou que vous modifiez la façon dont la documentation est servie. À utiliser également lorsque quelqu'un pose des questions sur l'architecture du projet xano-developer-mcp, la configuration du serveur MCP ou le fonctionnement du système de livraison de documentation. Déclenchez toute mention de xanoscript_docs, de la documentation XanoScript, des outils Xano MCP ou de la création de documentation pour ce projet.
