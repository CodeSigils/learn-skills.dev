Экспертные навыки понимания, использования и изменения системы документации xanoscript_docs в проекте xano-developer-mcp. Используйте этот навык при работе с файлами документации XanoScript (файлы .md в src/xanoscript_docs/), изменении инструмента MCP xanoscript_docs, добавлении новых тем документации, редактировании существующих документов, обновлении реестра тем в xanoscript.ts или изменении способа предоставления документации. Также используйте, когда кто-то спрашивает об архитектуре проекта xano-developer-mcp, настройке сервера MCP или о том, как работает система доставки документации. Активируется при любом упоминании xanoscript_docs, документации XanoScript, инструментов Xano MCP или авторской документации для этого проекта.
