Competenze esperte per comprendere, utilizzare e modificare il sistema di documentazione xanoscript_docs nel progetto xano-developer-mcp. Utilizza questa competenza ogni volta che lavori con file di documentazione XanoScript (file .md in src/xanoscript_docs/), modificando lo strumento MCP xanoscript_docs, aggiungendo nuovi argomenti di documentazione, modificando documenti esistenti, aggiornando il registro degli argomenti in xanoscript.ts o modificando il modo in cui viene fornita la documentazione. Da utilizzare anche quando qualcuno chiede informazioni sull'architettura del progetto xano-developer-mcp, sulla configurazione del server MCP o su come funziona il sistema di distribuzione della documentazione. Attiva qualsiasi menzione di xanoscript_docs, documentazione XanoScript, strumenti Xano MCP o creazione di documentazione per questo progetto.
