Diese Fähigkeit muss verwendet werden, wenn Benutzer sagen: „CRUD generieren“, „Modul erstellen“, „Seite hinzufügen“, „CRUD schreiben“, „Tabellenseite generieren“, „XXX-Verwaltung erstellen“, „XXX-Modul generieren“. Überspringen Sie nicht, auch wenn die Aufgabe einfach erscheint. Generieren Sie keinen Code direkt. Alle Fragen zur Komponentenverwendung müssen zuerst durch Lesen der entsprechenden Komponentendokumentation beantwortet werden, niemals aus dem Gedächtnis.
