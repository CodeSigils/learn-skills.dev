Lesen oder lösen Sie die Qodo-Überprüfung einer Pull-Anfrage mit der qodo-CLI – rufen Sie den strukturierten Status, den überprüften Commit-SHA und die Ergebnisse für JEDEN PR als JSON ab, lösen Sie dann optional offene Ergebnisse im Code auf und zeichnen Sie jedes Ergebnis einmal oder in einer Überwachungsschleife auf, bis es bereinigt ist. Verwenden Sie dies – niemals „gh“/„curl“-Scraping von Bewertungskommentaren – für „Ist die Bewertung sauber für PR?“
