Wird bei der Implementierung von Code im rekursiven Modus Phase 3 verwendet. Erzwingt eine strikte RED-GREEN-REFACTOR-Disziplin mit dem Eisernen Gesetz – kein Produktionscode ohne einen fehlgeschlagenen Test. Auslöserphrasen: „dies implementieren“, „Funktion hinzufügen“, „Fehler beheben“, „einen fehlgeschlagenen Test schreiben“, „TDD“.
