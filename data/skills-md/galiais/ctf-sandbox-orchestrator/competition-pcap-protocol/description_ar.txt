مهارة المصب الداخلية لأوركسترا ctf-sandbox. سير عمل CTF-sandbox لتحليل التقاط الحزم، وإعادة بناء الجلسة، وفك تشفير بروتوكول التطبيق، وإعادة تجميع الدفق، وتوقيت الإشارة، وارتباط الحزمة بالعملية. يُستخدم عندما يطلب المستخدم تحليل PCAP، أو إعادة بناء جلسات TCP أو UDP، أو فك تشفير HTTP، أو WebSocket، أو DNS، أو C2 المخصص، أو البروتوكولات الثنائية، أو استخراج العناصر المنقولة، أو ربط تسلسلات الحزم بسلوك المضيف أو البرامج الضارة. استخدم فقط بعد أن يقوم `$ctf-sandbox-orchestrator` بإنشاء افتراضات وضع الحماية وتوجيهها هنا.
