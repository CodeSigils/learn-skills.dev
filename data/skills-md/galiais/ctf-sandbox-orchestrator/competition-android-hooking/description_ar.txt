مهارة المصب الداخلية لأوركسترا ctf-sandbox. سير عمل CTF-sandbox لربط Android APK، وتتبع Frida، واسترداد توقيع الطلب، وتجاوز تثبيت SSL، وفحص حدود JNI، وتحليل حدود ثقة التطبيق. يُستخدم عندما يطلب المستخدم ربط ملف APK، أو فحص منطق المُوقع، أو تتبع Java أو الحدود الأصلية، أو تجاوز التثبيت أو عمليات التحقق من الجذر، أو فحص التفضيلات المشتركة أو قواعد بيانات التطبيق، أو إعادة تشغيل طلبات الهاتف المحمول المقبولة. استخدم فقط بعد أن يقوم `$ctf-sandbox-orchestrator` بإنشاء افتراضات وضع الحماية وتوجيهها هنا.
