Compétence interne en aval pour ctf-sandbox-orchestrator. Workflow sandbox CTF pour les cartes sources, les manifestes de build, les registres de fragments, les bundles émis, le flux de chargement obscurci et la récupération du runtime frontend. À utiliser lorsque l'utilisateur demande à reconstruire la structure JavaScript servie, à inspecter les cartes sources ou les cartes de fragments, à suivre le chargement du bundle, à récupérer des routes ou des API cachées à partir d'actifs émis, ou à expliquer le comportement d'exécution à partir d'artefacts frontend construits. À utiliser uniquement après que `$ctf-sandbox-orchestrator` ait déjà établi les hypothèses du bac à sable et acheminé ici.
