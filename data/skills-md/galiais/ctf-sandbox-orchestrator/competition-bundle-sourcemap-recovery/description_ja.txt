ctf-sandbox-orchestrator の内部ダウンストリーム スキル。ソース マップ、ビルド マニフェスト、チャンク レジストリ、発行されたバンドル、難読化されたローダー フロー、フロントエンド ランタイム リカバリのための CTF サンドボックス ワークフロー。ユーザーが、提供される JavaScript 構造の再構築、ソース マップまたはチャンク マップの検査、バンドルの読み込みのトレース、発行されたアセットからの非表示のルートまたは API の回復、または構築されたフロントエンド アーティファクトからの実行時の動作の説明を要求する場合に使用します。 「$ctf-sandbox-orchestrator」がすでにサンドボックスの前提を確立し、ここにルーティングされた後にのみ使用してください。
