個人のIP図作成者。 IP イメージを使用して、専用のコンテンツ図を生成します。ユーザーが承認した写真、ホームページのスクリーンショット、略歴、アカウント データ、またはキャラクター資料を、安定したミニマルな手描きの図文字に変換し、その後、長文記事のイラスト、グラフィックアカウントのナレッジ カード、モバイル ポスター、メソッド内訳図、ストーリーボード シーン、知財プレゼンテーション PPT、ライブ共有スライド デッキ、完全に図解された手描きの PPT ページ、およびその他のビジュアル コンテンツを作成し続けます。これは、IP 主人公 + 実行エージェントのナレッジ ダイアグラム システムを強調しています。ユーザーの IP がプレゼンターとして機能し、説明、分解、注釈、スケジュール設定を実行し、実行エージェントがカードの移動、フィードバック、試行錯誤、リスク マーキング、および結果の配信を処理します。ユーザーが個人の IP イメージを作成する場合、独自のイメージを使用してナレッジ ダイアグラム、グラフィック アカウント ナレッジ カード、記事イラスト、コース ダイアグラム、コンテンツ ポスター、メソッド内訳グラフ、IP プレゼンテーション PPT、ライブ共有スライド デッキを作成する場合、または写真/ホームページのスクリーンショット/略歴をアップロードしてビジュアル コンテンツを生成する場合は、このスキルを使用する必要があります。
