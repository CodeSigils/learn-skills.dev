منشئ مخطط IP الشخصي. استخدم صورة IP الخاصة بك لإنشاء مخططات محتوى حصرية. يقوم بتحويل الصور المعتمدة من المستخدم، أو لقطات الشاشة الرئيسية، أو السيرة الذاتية، أو بيانات الحساب، أو ملفات الشخصيات إلى أحرف تخطيطية ثابتة ومبسطة مرسومة يدويًا، ثم يستمر في إنتاج رسوم توضيحية للمقالات الطويلة، وبطاقات معرفة الحساب الرسومي، وملصقات الهاتف المحمول، ومخططات تفصيلية للطرق، ومشاهد القصة المصورة، وعروض PPT الخاصة بعرض IP، ومجموعات شرائح المشاركة المباشرة، وصفحات PPT المرسومة يدويًا بالكامل، والمحتويات المرئية الأخرى. وهو يؤكد على نظام الرسم البياني المعرفي لبطل الرواية + وكيل التنفيذ: يعمل عنوان IP الخاص بالمستخدم كمقدم، ويقوم بالشرح والتحليل والتعليق التوضيحي والجدولة، بينما يتعامل وكيل التنفيذ مع نقل البطاقة، والتغذية الراجعة، والتجربة والخطأ، ووضع علامات على المخاطر، وتسليم النتائج. عندما يرغب المستخدمون في إنشاء صورة IP شخصية، استخدم صورتهم الخاصة لإنشاء مخططات معرفية، أو بطاقات معرفة للحساب الرسومي، أو رسوم توضيحية للمقالات، أو مخططات للدورة، أو ملصقات للمحتوى، أو مخططات تفصيلية للطرق، أو عروض PPT لعرض IP، أو مجموعات شرائح المشاركة المباشرة، أو تحميل الصور/لقطات الشاشة الرئيسية/السير الذاتية لإنشاء محتوى مرئي، فيجب عليهم استخدام هذه المهارة.
