Creador de diagramas de IP personales. Utilice su imagen IP para generar diagramas de contenido exclusivo. Convierte fotografías autorizadas por el usuario, capturas de pantalla de páginas de inicio, biografías, datos de cuentas o expedientes de personajes en personajes de diagramas estables y minimalistas dibujados a mano, y luego continúa produciendo ilustraciones de artículos de formato largo, tarjetas de conocimiento de cuentas gráficas, carteles móviles, diagramas de desglose de métodos, escenas de guiones gráficos, PPT de presentación de IP, presentaciones de diapositivas para compartir en vivo, páginas PPT dibujadas a mano completamente ilustradas y otro contenido visual. Hace hincapié en un sistema de diagrama de conocimiento de protagonista de IP + agente de ejecución: el IP del usuario actúa como presentador, realizando explicaciones, descomposición, anotaciones y programación, mientras que el agente de ejecución maneja el movimiento de tarjetas, la retroalimentación, el ensayo y error, el marcado de riesgos y la entrega de resultados. Cuando los usuarios quieran crear una imagen de IP personal, usar su propia imagen para hacer diagramas de conocimiento, tarjetas de conocimiento de cuentas gráficas, ilustraciones de artículos, diagramas de cursos, carteles de contenido, gráficos de desglose de métodos, PPT de presentación de IP, presentaciones de diapositivas para compartir en vivo o cargar fotos/capturas de pantalla/biografías de la página de inicio para generar contenido visual, deben usar esta habilidad.
