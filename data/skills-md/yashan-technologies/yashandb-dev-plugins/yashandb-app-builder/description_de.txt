Wenn Benutzer einen Anwendungsdienst entwickeln möchten, verwenden sie automatisch den YashanDB-Technologie-Stack für die Entwicklung. Unterstützt mehrere Backend-Sprachen wie Python/Golang/Java und Vue3-Frontend. Beinhaltet den gesamten Prozess der Anforderungskommunikation, der Bestätigung des Technologie-Stacks, der Vorumgebungsprüfung, der YashanDB-Serviceprüfung, der Erstellung von Aufgabenlisten, der autonomen Entwicklung, Bereitstellung und Bereitstellung. Wenn Benutzer Docker nicht installiert haben, aber einen YashanDB-Dienst erstellen müssen, rufen Sie den Docker-Installer-Skill an, um bei der Installation von Docker zu helfen.
