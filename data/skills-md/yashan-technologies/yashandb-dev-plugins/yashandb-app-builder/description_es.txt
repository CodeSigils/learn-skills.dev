Cuando un usuario desea desarrollar un servicio de aplicación, utiliza automáticamente la pila tecnológica YashanDB (Yashan Database) para el desarrollo. Admite múltiples lenguajes de backend como Python/Golang/Java + frontend Vue3. Incluye el proceso completo de comunicación de requisitos, confirmación de la pila tecnológica, verificación previa del entorno, verificación del servicio YashanDB, generación de lista de tareas, desarrollo autónomo, implementación y entrega. Si el usuario no ha instalado Docker pero necesita crear un servicio YashanDB, llame a la habilidad del instalador de Docker para que le ayude a instalar Docker.
