사용자가 응용 서비스를 개발하고자 할 때 자동으로 YashanDB(Yashan Database) 기술 스택을 사용하여 개발합니다. Python/Golang/Java + Vue3 프런트엔드와 같은 여러 백엔드 언어를 지원합니다. 요구사항 통신, 기술 스택 확인, 사전 환경 확인, YashanDB 서비스 확인, 작업 목록 생성, 자율 개발, 배포 및 전달의 전체 프로세스가 포함됩니다. 사용자가 Docker를 설치하지 않았지만 YashanDB 서비스를 생성해야 하는 경우 docker-installer 기술을 호출하여 Docker 설치를 돕습니다.
