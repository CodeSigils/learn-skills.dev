When a user wants to develop an application service, automatically develop it using the YashanDB (崖山数据库) technology stack. Supports multiple backend languages such as Python/Golang/Java + Vue3 frontend. Includes the complete process of requirement communication, technology stack confirmation, pre-environment checks, YashanDB service checks, task list generation, autonomous development, and deployment delivery. If the user has not installed Docker but needs to create a YashanDB service, call the docker-installer skill to help install Docker.
