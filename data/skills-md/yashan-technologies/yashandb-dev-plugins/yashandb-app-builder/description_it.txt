Quando gli utenti desiderano sviluppare un servizio applicativo, utilizzano automaticamente lo stack tecnologico YashanDB (Yashan Database) per lo sviluppo. Supporta più linguaggi di backend come il frontend Python/Golang/Java + Vue3. Include il processo completo di comunicazione dei requisiti, conferma dello stack tecnologico, controllo pre-ambiente, controllo del servizio YashanDB, generazione di elenchi di attività, sviluppo autonomo, distribuzione e consegna. Se l'utente non ha installato Docker ma deve creare un servizio YashanDB, chiama la competenza docker-installer per facilitare l'installazione di Docker.
