Когда пользователь хочет разработать службу приложения, он автоматически использует для разработки стек технологий YashanDB (база данных Yashan). Поддерживает несколько серверных языков, таких как Python/Golang/Java + интерфейс Vue3. Включает полный процесс согласования требований, подтверждения технологического стека, предварительные проверки среды, проверки службы YashanDB, создание списка задач, автономную разработку и развертывание. Если пользователь не установил Docker, но ему необходимо создать службу YashanDB, вызовите специалиста по установке Docker, чтобы помочь установить Docker.
