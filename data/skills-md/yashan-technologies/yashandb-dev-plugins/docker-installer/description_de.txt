Helfen Sie Benutzern bei der Installation und Konfiguration von Docker unter Windows, Linux (Ubuntu/Debian/CentOS/Fedora) oder macOS. Wenn Docker nicht erkannt wird, aber benötigt wird, wird dieser Skill automatisch ausgelöst. Es wählt die geeignete Installationsmethode basierend auf dem Betriebssystem des Benutzers aus.
