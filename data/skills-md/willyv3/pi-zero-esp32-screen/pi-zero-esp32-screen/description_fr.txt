Orange Pi Zero 2W + ESP32-S3 (FNK0104) Plateforme périphérique USB CDC. À utiliser lorsque vous travaillez sur la configuration matérielle OPi+ESP32 : assistant vocal Jarvis, micrologiciel opi-périphérique, protocole série ESP32, rendu d'affichage TFT, capture de micro, animation de sprite, rendu delta ou déploiement d'applications Go sur Orange Pi. Déclenche sur ~/projects/jarvis/, le micrologiciel opi-périphérique, CMD_FRAME_RECT, RSP_MIC_DATA, le débogage du protocole série ou tout travail périphérique OPi+ESP32. Il s'agit d'une plate-forme de calcul, d'affichage et d'audio à usage général, pas seulement de Jarvis. NE PAS déclencher pour les questions Go générales (utilisez effective-go), les projets ESP32 génériques (utilisez cyd-app) ou le travail Web/frontend.
