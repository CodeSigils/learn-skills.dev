Orange Pi Zero 2W + ESP32-S3 (FNK0104) منصة طرفية USB CDC. يُستخدم عند العمل على إعداد أجهزة OPi+ESP32: مساعد صوت Jarvis، أو البرامج الثابتة الطرفية opi، أو البروتوكول التسلسلي ESP32، أو عرض شاشة TFT، أو التقاط الميكروفون، أو الرسوم المتحركة المتحركة، أو عرض delta، أو نشر تطبيقات Go على Orange Pi. يتم تشغيلها على ~/projects/jarvis/، أو البرامج الثابتة الطرفية opi، أو CMD_FRAME_RECT، أو RSP_MIC_DATA، أو تصحيح أخطاء البروتوكول التسلسلي، أو أي عمل طرفي OPi+ESP32. هذه منصة حوسبة + عرض + صوت للأغراض العامة - وليس جارفيس فقط. لا تقم بطرح أسئلة Go العامة (استخدم بفعالية-go)، أو مشاريع ESP32 العامة (استخدم cyd-app)، أو عمل الويب/الواجهة الأمامية.
