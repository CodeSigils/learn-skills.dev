Evaluación ética del riesgo de datos, protocolos de prueba de sesgos y prácticas de gobernanza para productos de datos. Úselo al evaluar la equidad de las características de ML/AI, diseñar protocolos de pruebas de sesgo, planificar implementaciones graduales para cambios de alto riesgo, revisar prácticas de gobernanza de datos o cuando alguien pregunte "¿podría este modelo estar sesgado?" o "¿cómo enviamos funciones de IA de manera responsable?" Para obtener orientación específica de HIPAA, consulte dominio de datos de atención médica.
