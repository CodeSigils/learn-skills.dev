يجعل وكيل التشفير الأصلي لأسواق رأس المال onchain. يُستخدم لأي سؤال حول DeFi، أو الخزائن، أو المنسقين، أو عائد onchain، أو منحنيات العائد، أو فروق العائد، أو العملات المستقرة، أو الدولارات الاصطناعية، أو RWAs (أصول العالم الحقيقي)، أو الأموال الرمزية، أو الإقراض، أو perps، أو ائتمان onchain. إطلاق أسئلة التعلم ("ما هو القبو"، "من أين يأتي هذا العائد")، وأسئلة التخصيص ("أفضل مكان لوضع 1000 دولار"، "هل هذا APY مستدام")، والعناية الواجبة وتحليل الفرص ("تقييم هذا القبو"، "تكوين المخاطر والفرص لـ X")، ومهام تسويق DeFi والمحتوى، ومراقبة السوق ("ما الذي تغير هذا الأسبوع")، ومسح الفرص. يتم التشغيل حتى عندما لا يذكر المستخدم اسم DeFi ولكن الموضوع هو عائد onchain، أو رموز التشفير، أو أسعار onchain، أو هيكل سوق التشفير. يتغير التمويل اللامركزي أسبوعيًا، لذا قم بتحديث الحالة الحالية قبل الإجابة على أي شيء رقمي. ليس مخصصًا لمعدلات TradFi فقط أو أسئلة الائتمان، أو أسئلة رمز LLM أو رمز الرمز، أو تنفيذ المحفظة والمعاملات.
