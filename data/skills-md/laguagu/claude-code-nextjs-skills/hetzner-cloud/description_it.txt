Gestisci l'infrastruttura Hetzner Cloud con la CLI `hcloud`: server, reti, firewall, bilanciatori del carico, volumi, zone DNS, chiavi SSH, IP primari/flottanti, istantanee, certificati, gruppi di posizionamento, storage box. Da utilizzare ogni volta che l'utente menziona Hetzner, hcloud, provisioning VPS o codici di posizione Hetzner (fsn1, hel1, nbg1, ash, hil, sin), anche se non dice "hcloud". Solo CLI; NON copre Hetzner Robot (server dedicati, prodotto e API separati).
