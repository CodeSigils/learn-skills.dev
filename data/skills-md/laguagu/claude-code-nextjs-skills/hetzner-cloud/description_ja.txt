「hcloud」 CLI を使用して Hetzner クラウド インフラストラクチャ (サーバー、ネットワーク、ファイアウォール、ロード バランサー、ボリューム、DNS ゾーン、SSH キー、プライマリ/フローティング IP、スナップショット、証明書、配置グループ、ストレージ ボックス) を管理します。ユーザーが Hetzner、hcloud、VPS プロビジョニング、または Hetzner ロケーション コード (fsn1、hel1、nbg1、ash、hil、sin) に言及する場合は常に、「hcloud」と言わなくても使用します。 CLI のみ。 Hetzner Robot (専用サーバー、別個の製品および API) は対象外です。
