Administre la infraestructura de Hetzner Cloud con la CLI `hcloud`: servidores, redes, firewalls, equilibradores de carga, volúmenes, zonas DNS, claves SSH, IP primarias/flotantes, instantáneas, certificados, grupos de ubicación, cajas de almacenamiento. Úselo siempre que el usuario mencione Hetzner, hcloud, aprovisionamiento de VPS o códigos de ubicación de Hetzner (fsn1, hel1, nbg1, ash, hil, sin), incluso si no dice "hcloud". Solo CLI; NO cubre Hetzner Robot (servidores dedicados, producto independiente y API).
