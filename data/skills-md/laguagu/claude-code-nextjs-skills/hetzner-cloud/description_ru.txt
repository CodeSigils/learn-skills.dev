Управляйте облачной инфраструктурой Hetzner с помощью CLI hcloud — серверами, сетями, межсетевыми экранами, балансировщиками нагрузки, томами, зонами DNS, ключами SSH, основными/плавающими IP-адресами, снимками, сертификатами, группами размещения, ящиками для хранения. Используйте всякий раз, когда пользователь упоминает Hetzner, hcloud, предоставление VPS или коды местоположения Hetzner (fsn1, hel1, nbg1, ash, hil, sin) — даже если они не говорят «hcloud». только CLI; НЕ распространяется на Hetzner Robot (выделенные серверы, отдельный продукт и API).
