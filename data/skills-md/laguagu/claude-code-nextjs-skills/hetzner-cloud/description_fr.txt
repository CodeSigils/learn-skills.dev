Gérez l'infrastructure Hetzner Cloud avec la CLI « hcloud » : serveurs, réseaux, pare-feu, équilibreurs de charge, volumes, zones DNS, clés SSH, IP primaires/flottantes, instantanés, certificats, groupes de placement, boîtes de stockage. À utiliser chaque fois que l'utilisateur mentionne Hetzner, hcloud, VPS provisioning ou les codes de localisation Hetzner (fsn1, hel1, nbg1, ash, hil, sin) — même s'il ne dit pas « hcloud ». CLI uniquement ; ne couvre PAS Hetzner Robot (serveurs dédiés, produit et API séparés).
