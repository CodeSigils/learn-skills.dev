قم بإدارة البنية التحتية لـ Hetzner Cloud باستخدام واجهة سطر الأوامر `hcloud` - الخوادم والشبكات وجدران الحماية وموازنات التحميل ووحدات التخزين ومناطق DNS ومفاتيح SSH وعناوين IP الأساسية/العائمة واللقطات والشهادات ومجموعات المواضع وصناديق التخزين. يُستخدم عندما يذكر المستخدم رموز موقع Hetzner أو hcloud أو VPS أو رموز موقع Hetzner (fsn1، hel1، nbg1، ash، hil، sin) - حتى لو لم يذكر "hcloud". سطر الأوامر فقط؛ لا يغطي Hetzner Robot (الخوادم المخصصة والمنتج المنفصل وواجهة برمجة التطبيقات).
