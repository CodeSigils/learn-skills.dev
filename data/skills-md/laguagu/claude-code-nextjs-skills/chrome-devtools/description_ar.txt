الاختبارات في المتصفحات الحقيقية عبر Chrome DevTools MCP. يُستخدم عند إنشاء أو تصحيح أي شيء يتم تشغيله في المتصفح. يُستخدم عندما تحتاج إلى فحص DOM، أو التقاط أخطاء وحدة التحكم، أو تحليل طلبات الشبكة، أو أداء ملف التعريف (LCP/CLS/INP)، أو التحقق من الإخراج المرئي باستخدام بيانات وقت التشغيل الحقيقية. مكمل لـ Playwright - استخدم هذا لتصحيح الأخطاء المباشر وأعمال الأداء، وPlaywright لمجموعات اختبار E2E المستقرة.
