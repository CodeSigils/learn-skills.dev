Tests dans de vrais navigateurs via Chrome DevTools MCP. À utiliser lors de la création ou du débogage de tout ce qui s'exécute dans un navigateur. À utiliser lorsque vous devez inspecter le DOM, capturer les erreurs de la console, analyser les requêtes réseau, profiler les performances (LCP/CLS/INP) ou vérifier la sortie visuelle avec des données d'exécution réelles. Complète Playwright — utilisez-le pour le débogage en direct et le travail de performance, Playwright pour les suites de tests E2E stables.
