Test in browser reali tramite Chrome DevTools MCP. Da utilizzare durante la creazione o il debug di qualsiasi cosa eseguita in un browser. Da utilizzare quando è necessario ispezionare il DOM, acquisire errori della console, analizzare richieste di rete, prestazioni del profilo (LCP/CLS/INP) o verificare l'output visivo con dati di runtime reali. Complementa Playwright: utilizzalo per il debug dal vivo e il lavoro sulle prestazioni, Playwright per suite di test E2E stabili.
