Тестируется в реальных браузерах с помощью Chrome DevTools MCP. Используйте при создании или отладке всего, что работает в браузере. Используйте, когда вам нужно проверить DOM, зафиксировать ошибки консоли, проанализировать сетевые запросы, производительность профиля (LCP/CLS/INP) или проверить визуальный вывод с реальными данными времени выполнения. Дополняет Playwright — используйте его для оперативной отладки и работы с производительностью, Playwright — для стабильных наборов тестов E2E.
