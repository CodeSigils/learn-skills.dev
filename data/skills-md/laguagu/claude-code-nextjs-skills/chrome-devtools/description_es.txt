Pruebas en navegadores reales a través de Chrome DevTools MCP. Úselo al compilar o depurar cualquier cosa que se ejecute en un navegador. Úselo cuando necesite inspeccionar el DOM, capturar errores de la consola, analizar solicitudes de red, perfilar el rendimiento (LCP/CLS/INP) o verificar la salida visual con datos de tiempo de ejecución reales. Complementa a Playwright: utilícelo para depuración en vivo y trabajos de interpretación, Playwright para conjuntos de pruebas E2E estables.
