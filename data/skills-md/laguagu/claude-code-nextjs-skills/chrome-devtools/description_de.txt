Tests in echten Browsern über Chrome DevTools MCP. Wird zum Erstellen oder Debuggen von Elementen verwendet, die in einem Browser ausgeführt werden. Verwenden Sie es, wenn Sie das DOM überprüfen, Konsolenfehler erfassen, Netzwerkanforderungen analysieren, ein Leistungsprofil erstellen (LCP/CLS/INP) oder die visuelle Ausgabe mit echten Laufzeitdaten überprüfen müssen. Ergänzt Playwright – verwenden Sie es für Live-Debugging und Performance-Arbeiten, Playwright für stabile E2E-Testsuiten.
