تطوير وترحيل Vercel AI SDK v7. يُستخدم عند إنشاء تطبيقات AI SDK 7 أو ترقيتها، وخاصة ToolLoopAgent، وWorkflowAgent، وHarnessAgent، وأدوات Claude Code/Codex/Pi، وruntimeContext، وtoolsContext، وtoolApproval، والقياس عن بعد، والتفكير، وتحميل الملفات أو المهارات، أو الوقت الفعلي، أو إنشاء الفيديو، أو تغييرات كسر الإصدار 6 إلى الإصدار 7. بالنسبة إلى كود AI SDK v6، استخدم ai-sdk-6؛ لاكتشاف الإصدار والبحث العام عن المستندات، استخدم ai-sdk.
