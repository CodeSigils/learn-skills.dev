Vercel AI SDK v7 の開発と移行。 AI SDK 7 アプリ、特に ToolLoopAgent、WorkflowAgent、HarnessAgent、Claude Code/Codex/Pi ハーネス、runtimeContext、toolsContext、toolApproval、テレメトリ、推論、ファイルまたはスキルのアップロード、リアルタイム、ビデオ生成、または v6 から v7 への重大な変更を構築またはアップグレードするときに使用します。 AI SDK v6 コードの場合は、ai-sdk-6 を使用します。バージョンの検出と一般的なドキュメントの検索には、ai-sdk を使用します。
