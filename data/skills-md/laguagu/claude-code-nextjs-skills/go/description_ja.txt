実行中のアプリをブラウザーで開き、最近の UI の変更が実際に機能することを確認します。ユーザーが最近の作業の簡単なスモーク テストまたは健全性チェックを希望する場合、または「実行する」、「ブラウザで開く」、「ブラウザでチェックする」、「作業をテストする」、「動作することを確認する」、「スモーク テスト」、「検証する」、「実際に動作するかどうか」、「フォーム/ページが動作することを確認する」、「フォームの送信を確認する」、「モバイルで動作する」と言った場合、ブラウザ テストを明示的に要求していない場合でも使用します。ユーザーが UI リクエストに「...そして動作することを確認してください」を追加したときにも暗黙的にアクティブ化されます。デザインの批評をスキップします。そのためには go-ui を使用してください。
