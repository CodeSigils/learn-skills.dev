Öffnet die laufende App in einem Browser und überprüft, ob die letzten Änderungen an der Benutzeroberfläche tatsächlich funktionieren. Verwenden Sie es immer dann, wenn der Benutzer einen schnellen Rauchtest oder eine Plausibilitätsprüfung der letzten Arbeit wünscht oder „Los“, „Im Browser öffnen“, „Browser einchecken“, „Testen Sie Ihre Arbeit“, „Stellen Sie sicher, dass es funktioniert“, „Rauchtest“, „Überprüfen“, „Hat es tatsächlich funktioniert“, „Stellen Sie sicher, dass das Formular/die Seite funktioniert“, „Überprüfen Sie die Formularabsendungen“, „Funktioniert auf Mobilgeräten“ sagt – auch wenn er nicht ausdrücklich nach einem Browsertest fragt. Wird auch implizit aktiviert, wenn der Benutzer „...und stellen Sie sicher, dass es funktioniert“ an eine UI-Anfrage anhängt. Überspringt Designkritik; Verwenden Sie dazu go-ui.
