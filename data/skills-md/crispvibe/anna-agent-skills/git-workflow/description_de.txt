Git-Workflow-Fähigkeiten – Commit-Konventionen, Verzweigungsstrategien, Konfliktlösung, Commit-Validierung. Immer wenn Sie Git Commit, Git Push, Verzweigungsoperationen, Zusammenführungen, das Schreiben von Commit-Nachrichten oder Code-Commits berühren, ist diese Fähigkeit erforderlich. Auch wenn der Benutzer lediglich „commit“ oder „git“ sagt, sollte es ausgelöst werden.
