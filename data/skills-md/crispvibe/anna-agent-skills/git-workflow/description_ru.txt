Навыки рабочего процесса Git — соглашения о фиксации, стратегии ветвления, разрешение конфликтов, проверка фиксации. Каждый раз, когда вы используете git commit, git push, операции ветвления, слияния, написание сообщений о фиксации или фиксацию кода, этот навык необходим. Даже если пользователь просто говорит «commit» или «git», это должно сработать.
