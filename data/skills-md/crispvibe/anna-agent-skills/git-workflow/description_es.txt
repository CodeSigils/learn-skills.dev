Habilidades de flujo de trabajo de Git: convenciones de confirmación, estrategias de ramificación, resolución de conflictos, validación de confirmación. Siempre que toque git commit, git push, operaciones de bifurcación, fusiones, escritura de mensajes de confirmación o confirmaciones de código, se requiere esta habilidad. Incluso si el usuario simplemente dice "commit" o "git", debería activarse.
