Habilidades de flujo de trabajo de Git: convenciones de confirmación, estrategias de bifurcación, resolución de conflictos, validación de confirmación. Utilice esta habilidad siempre que estén involucrados git commit, git push, operaciones de bifurcación, fusión, escritura de mensajes de confirmación o confirmación de código. Actívelo incluso si el usuario simplemente dice "commit" o "git".
