مهارات سير عمل Git – الالتزام بالاتفاقيات، واستراتيجيات التفرع، وحل النزاعات، والالتزام بالتحقق من الصحة. عندما تلمس git Commit، أو git Push، أو العمليات الفرعية، أو الدمج، أو كتابة رسائل الالتزام، أو تنفيذ التعليمات البرمجية، تكون هذه المهارة مطلوبة. حتى لو قال المستخدم "commit" أو "git" فقط، فيجب تشغيله.
