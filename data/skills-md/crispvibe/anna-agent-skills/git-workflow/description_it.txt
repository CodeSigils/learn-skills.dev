Competenze del flusso di lavoro Git: convenzioni di commit, strategie di ramificazione, risoluzione dei conflitti, convalida del commit. Ogni volta che tocchi git commit, git push, operazioni di ramo, unioni, scrittura di messaggi di commit o commit di codice, questa abilità è richiesta. Anche se l'utente dice semplicemente "commit" o "git", dovrebbe essere attivato.
