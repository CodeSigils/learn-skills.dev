Competenze del flusso di lavoro Git: convenzioni di commit, strategie di ramificazione, risoluzione dei conflitti, convalida dei commit. Utilizza questa abilità ogni volta che sono coinvolti git commit, git push, operazioni di ramo, unione, scrittura di messaggi di commit o invio di codice. Attivalo anche se l'utente dice semplicemente "commit" o "git".
