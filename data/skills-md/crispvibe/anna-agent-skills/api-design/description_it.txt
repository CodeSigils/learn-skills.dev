Competenze dell'ingegnere API: standard di progettazione API, controllo delle versioni, gestione degli errori, sicurezza della concorrenza, ottimizzazione delle prestazioni, documentazione. Ogni volta che crei/modifichi un endpoint API, un percorso, un controller, una gestione delle richieste HTTP, un formato di risposta o un middleware, devi applicare questa competenza. Anche se l'utente dice semplicemente "aggiungi un'interfaccia" o "modifica il valore restituito", dovrebbe sempre essere attivato.
