Competenze dell'ingegnere API: standard di progettazione API, controllo della versione, gestione degli errori, sicurezza della concorrenza, ottimizzazione delle prestazioni, documentazione. È necessario applicare queste competenze ogni volta che si creano o si modificano endpoint API, route, controller, gestione delle richieste HTTP, formati di risposta o middleware. Ciò si applica anche se l'utente dice semplicemente "aggiungi un'interfaccia" o "modifica il valore restituito".
