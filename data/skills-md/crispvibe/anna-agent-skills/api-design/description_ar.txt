مهارات مهندس واجهة برمجة التطبيقات – معايير تصميم واجهة برمجة التطبيقات، والإصدار، ومعالجة الأخطاء، وأمان التزامن، وضبط الأداء، والوثائق. عندما تقوم بإنشاء/تعديل أي نقطة نهاية لواجهة برمجة التطبيقات، أو مسار، أو وحدة تحكم، أو معالجة طلب HTTP، أو تنسيق استجابة، أو برامج وسيطة، يجب عليك تطبيق هذه المهارة. حتى لو قال المستخدم ببساطة "أضف واجهة" أو "قم بتغيير قيمة الإرجاع"، فيجب دائمًا تشغيله.
