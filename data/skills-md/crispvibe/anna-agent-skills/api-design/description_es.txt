Habilidades de ingeniero de API: especificaciones de diseño de API, control de versiones, manejo de errores, seguridad de concurrencia, optimización del rendimiento, documentación. Debe utilizar esta habilidad siempre que cree/modifique cualquier punto final de API, ruta, controlador, controlador de solicitudes HTTP, formato de respuesta o middleware. Incluso si el usuario simplemente dice "agregar una interfaz" o "cambiar el valor de retorno", debería activarse.
