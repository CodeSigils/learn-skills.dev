Habilidades de ingeniero de API: estándares de diseño de API, control de versiones, manejo de errores, seguridad de concurrencia, ajuste del rendimiento, documentación. Siempre que cree/modifique cualquier punto final de API, ruta, controlador, manejo de solicitudes HTTP, formato de respuesta o middleware, debe aplicar esta habilidad. Incluso si el usuario simplemente dice "agregar una interfaz" o "cambiar el valor de retorno", siempre debe activarse.
