Навыки инженера API — стандарты проектирования API, управление версиями, обработка ошибок, безопасность параллелизма, настройка производительности, документация. Всякий раз, когда вы создаете/изменяете какую-либо конечную точку API, маршрут, контроллер, обработку HTTP-запросов, формат ответа или промежуточное программное обеспечение, вы должны применять этот навык. Даже если пользователь просто говорит «добавить интерфейс» или «изменить возвращаемое значение», это всегда должно срабатывать.
