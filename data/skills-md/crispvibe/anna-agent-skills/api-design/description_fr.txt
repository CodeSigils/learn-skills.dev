Compétences d'ingénieur API – Normes de conception d'API, gestion des versions, gestion des erreurs, sécurité de la concurrence, réglage des performances, documentation. Chaque fois que vous créez/modifiez un point de terminaison d'API, une route, un contrôleur, une gestion des requêtes HTTP, un format de réponse ou un middleware, vous devez appliquer cette compétence. Même si l'utilisateur dit simplement « ajouter une interface » ou « modifier la valeur de retour », cela doit toujours être déclenché.
