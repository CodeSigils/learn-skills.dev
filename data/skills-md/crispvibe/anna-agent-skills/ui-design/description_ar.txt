مهارات تصميم واجهة المستخدم - مراجعة واجهة المستخدم/تجربة المستخدم، وتحسين الواجهة، ومعايير نظام التصميم. استخدم هذه المهارة عندما تقوم بتعديل أو إنشاء طرق عرض أو أنماط أو تخطيطات أو ألوان أو رسوم متحركة أو تعليمات برمجية متعلقة بالأيقونات لواجهة المستخدم. يجب أن يتم تشغيله حتى إذا قال المستخدم فقط "تغيير النمط" أو "تبدو واجهة المستخدم هذه سيئة".
