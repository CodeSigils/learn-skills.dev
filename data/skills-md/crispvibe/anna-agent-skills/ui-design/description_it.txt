Competenze di progettazione dell'interfaccia utente: revisione UI/UX, ottimizzazione dell'interfaccia, standard del sistema di progettazione. Utilizza questa competenza ogni volta che modifichi/crei codice relativo a visualizzazioni, stili, layout, colori, animazioni o icone dell'interfaccia utente. Attivalo anche se l'utente dice semplicemente "cambia stile" o "questa interfaccia utente sembra brutta".
