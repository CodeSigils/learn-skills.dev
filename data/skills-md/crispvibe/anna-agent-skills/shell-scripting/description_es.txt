Habilidades de desarrollo de scripts de Shell: scripting Bash/Zsh, implementación automatizada, administración de sistemas, procesamiento de textos. Utilice esta habilidad siempre que trabaje con secuencias de comandos Shell/Bash/Zsh, secuencias de comandos de automatización como implementar.sh/build.sh, trabajos cron, comandos de administración del sistema o procesamiento de texto con sed/awk/grep. Actívelo incluso si el usuario simplemente dice "escribir un script" o "arreglar el script de implementación".
