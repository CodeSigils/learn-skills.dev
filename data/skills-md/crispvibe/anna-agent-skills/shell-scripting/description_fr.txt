Compétences en script Shell – scripts Bash/Zsh, déploiement automatisé, administration système, traitement de texte. Utilisez cette compétence chaque fois que vous écrivez des scripts Shell/Bash/Zsh, des scripts d'automatisation comme déployer.sh/build.sh, des tâches cron, des commandes d'administration système ou un traitement de texte avec sed/awk/grep. Déclenchez-le même si l'utilisateur dit simplement « écrire un script » ou « corriger le script de déploiement ».
