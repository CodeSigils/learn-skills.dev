Habilidades de desarrollo del lenguaje Go: sintaxis Go, programación concurrente, rutina/canal, manejo de errores, gestión de módulos, pruebas, optimización del rendimiento. Utilice esta habilidad siempre que se ocupe del desarrollo de código Go/Golang, goroutine, canal, go mod, diseño de interfaz, genéricos o diseño de estructuras. Debería activarse incluso si el usuario simplemente dice "escribir una función Go" o "modificar el código Go".
