Compétences en développement du langage Go – Syntaxe Go, programmation simultanée, goroutine/canal, gestion des erreurs, gestion des modules, tests, optimisation des performances. Utilisez cette compétence chaque fois que vous traitez du développement de code Go/Golang, de goroutine, de canal, de mod go, de conception d'interface, de génériques ou de conception de structures. Même si l'utilisateur dit simplement « écrire une fonction Go » ou « modifier le code Go », cela devrait être déclenché.
