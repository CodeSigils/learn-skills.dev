مهارات تطوير Python - بناء جملة Python 3.12+، نوع التعليقات التوضيحية، البرمجة غير المتزامنة/الانتظار، التحقق من صحة بيانات Pydantic، أطر الويب FastAPI/Django، SQLAlchemy ORM، اختبار pytest، البيئات الافتراضية، إدارة الحزم، تحسين الأداء. استخدم هذه المهارة عندما يتعلق الأمر بتطوير كود Python أو البرمجة غير المتزامنة أو كتابة التعليقات التوضيحية أو التحقق من صحة البيانات أو واجهات برمجة تطبيقات الويب أو ORM أو البرامج النصية للأتمتة. قم بتشغيله حتى لو قال المستخدم ببساطة "اكتب نصًا برمجيًا لـ Python" أو "أصلح كود Python".
