Habilidades de auditoría de código: auditoría de seguridad, revisión de la calidad del código, descubrimiento de vulnerabilidades. Utilice esta habilidad siempre que tenga que lidiar con controles de seguridad, correcciones de vulnerabilidades, cambios en la lógica de permisos/autenticación, administración de claves, validación de entradas o problemas relacionados con OWASP. Actívelo incluso si el usuario simplemente dice "verificar seguridad" o "agregar una verificación de permisos".
