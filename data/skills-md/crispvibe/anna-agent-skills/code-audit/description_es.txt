Habilidades de auditoría de código: auditoría de seguridad, revisión de la calidad del código, descubrimiento de vulnerabilidades. Esta habilidad debe usarse siempre que estén involucrados controles de seguridad, correcciones de vulnerabilidades, cambios en la lógica de permisos/autenticación, administración de claves, validación de entradas o problemas relacionados con OWASP. Incluso si el usuario simplemente dice "verificar seguridad" o "agregar una verificación de permiso", debería activarse.
