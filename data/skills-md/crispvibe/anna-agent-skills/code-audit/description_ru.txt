Навыки аудита кода — аудит безопасности, проверка качества кода, обнаружение уязвимостей. Используйте этот навык при проверке безопасности, исправлении уязвимостей, изменении логики разрешений/аутентификации, управлении ключами, проверке ввода или проблемах, связанных с OWASP. Запустите его, даже если пользователь просто скажет «проверить безопасность» или «добавить проверку разрешений».
