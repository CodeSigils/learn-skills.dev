مهارات تدقيق الكود - التدقيق الأمني، ومراجعة جودة الكود، واكتشاف الثغرات الأمنية. استخدم هذه المهارة عند التعامل مع عمليات التحقق من الأمان أو إصلاحات الثغرات الأمنية أو تغييرات منطق الأذونات/المصادقة أو إدارة المفاتيح أو التحقق من صحة الإدخال أو المشكلات المتعلقة بـ OWASP. قم بتشغيله حتى لو قال المستخدم ببساطة "التحقق من الأمان" أو "أضف فحص إذن".
