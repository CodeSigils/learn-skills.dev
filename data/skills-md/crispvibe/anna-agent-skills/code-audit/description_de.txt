Code-Audit-Fähigkeiten – Sicherheitsüberprüfung, Überprüfung der Codequalität, Erkennung von Schwachstellen. Verwenden Sie diese Fertigkeit immer dann, wenn Sie sich mit Sicherheitsüberprüfungen, Schwachstellenbehebungen, Änderungen der Berechtigungs-/Authentifizierungslogik, Schlüsselverwaltung, Eingabevalidierung oder OWASP-bezogenen Problemen befassen. Lösen Sie es auch dann aus, wenn der Benutzer einfach „Sicherheit prüfen“ oder „Berechtigungsprüfung hinzufügen“ sagt.
