Competenze di controllo del codice: controllo della sicurezza, revisione della qualità del codice, rilevamento delle vulnerabilità. Utilizza questa competenza ogni volta che hai a che fare con controlli di sicurezza, correzioni di vulnerabilità, modifiche alla logica di autorizzazione/autenticazione, gestione delle chiavi, convalida dell'input o problemi relativi a OWASP. Attivalo anche se l'utente dice semplicemente "controlla la sicurezza" o "aggiungi un controllo di autorizzazione".
