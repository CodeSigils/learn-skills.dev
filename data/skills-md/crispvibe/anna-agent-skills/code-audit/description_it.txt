Competenze di controllo del codice: controllo di sicurezza, revisione della qualità del codice, scoperta di vulnerabilità. È necessario utilizzare questa competenza ogni volta che sono coinvolti controlli di sicurezza, correzioni di vulnerabilità, modifiche alla logica di autorizzazione/autenticazione, gestione delle chiavi, convalida dell'input o problemi relativi a OWASP. Anche se l'utente dice semplicemente "controlla la sicurezza" o "aggiungi un controllo dei permessi", dovrebbe essere attivato.
