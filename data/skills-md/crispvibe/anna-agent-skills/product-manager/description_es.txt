Habilidades de gestión de productos: análisis de requisitos, planificación de funciones, evaluación de la experiencia del usuario, análisis de productos competitivos. Debe utilizar esta habilidad siempre que maneje la planificación de funciones, la evaluación de requisitos, la clasificación de prioridades, el análisis de la experiencia del usuario o la comparación de productos competitivos. Actívelo incluso si el usuario simplemente dice "agregar una función" o "cómo manejar este requisito".
