Orquestador de búsqueda de plataformas sociales y web unificado personal de Yichen. Se utiliza para la recuperación de sitios web públicos en tiempo real basada en palabras clave, búsquedas por lotes paralelas, búsquedas verticales como finanzas, academia, derecho y seguridad, así como para el descubrimiento de contenido público en plataformas como GitHub, cuentas públicas de WeChat, Xiaohongshu, Douyin, Toutiao, Twitter/X, Bilibili, YouTube, Xiao Universe y otras; puede verificar el texto original y realizar un enriquecimiento ligero de los candidatos obtenidos en una búsqueda, y unificar resultados de diferentes servidores en registros de candidatos. AnySearch maneja búsquedas web públicas, por lotes y verticales, mientras que OpenCLI/nativo de la plataforma sirve solo como el adaptador de plataforma correspondiente. No se utiliza para leer ni descargar URL conocidas, archivos URL ni candidatos confirmados proporcionados por el usuario; estas tareas utilizan yichen‑content‑archive.
