VPS 보안 강화 자동화 기술. SSH를 통해 VPS에 로그인하고 전체 보안 정책 구성을 수행합니다.

트리거 문구:
- "VPS 보안 강화", "VPS 보안 구성", "새 VPS 초기화"
- "SSH 보안 구성", "SSH 포트 변경", "루트 비밀번호 로그인 비활성화"
- "VPS 보안 강화", "서버 보안 설정", "강화"

특징(7가지 보안 강화 동작):
1. sudo 사용자 생성, 루트 비밀번호 로그인 비활성화
2. SSH 포트 변경(다른 Ubuntu 버전 지원)
3. Fail2ban 자동 설치 및 구성
4. SSH 키 기반 로그인 지원
5. SSH 로그인 알림(선택 사항)
6. UFW 방화벽 설정
7. Docker 보안 알림
