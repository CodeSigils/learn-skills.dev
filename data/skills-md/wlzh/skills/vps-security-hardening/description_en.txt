VPS 安全加固自动化 Skill。通过 SSH 登录 VPS 并执行完整的安全策略配置。

触发场景：
- "加固VPS安全"、"VPS安全配置"、"新VPS初始化"
- "配置SSH安全"、"修改SSH端口"、"禁用root密码登录"
- "VPS安全加固"、"服务器安全设置"、"hardening"

功能（7招安全加固）：
1. 创建 sudo 用户，禁用 root 密码登录
2. 修改 SSH 端口（支持 Ubuntu 不同版本）
3. Fail2ban 自动安装配置
4. SSH 密钥登录支持
5. SSH 登录通知（可选）
6. UFW 防火墙配置
7. Docker 安全提醒
