Habilidad de automatización de refuerzo de seguridad de VPS. Inicie sesión en el VPS a través de SSH y realice una configuración completa de la política de seguridad.

Frases desencadenantes:
- "Reforzar la seguridad del VPS", "Configuración de seguridad del VPS", "Inicializar nuevo VPS"
- "Configurar seguridad SSH", "Cambiar puerto SSH", "Desactivar inicio de sesión con contraseña de root"
- "Refuerzo de seguridad de VPS", "Configuración de seguridad del servidor", "refuerzo"

Características (7 movimientos de endurecimiento):
1. Cree un usuario sudo, deshabilite el inicio de sesión con contraseña de root
2. Cambiar el puerto SSH (admite diferentes versiones de Ubuntu)
3. Instalación y configuración automática de Fail2ban
4. Soporte de inicio de sesión con clave SSH
5. Notificación de inicio de sesión SSH (opcional)
6. Configuración del cortafuegos UFW
7. Recordatorio de seguridad de Docker
