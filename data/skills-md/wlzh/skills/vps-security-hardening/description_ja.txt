VPS のセキュリティ強化自動化スキル。 SSH 経由で VPS にログインし、完全なセキュリティ ポリシーのセットアップを実行します。

トリガーフレーズ:
- 「VPS セキュリティを強化する」、「VPS セキュリティ設定」、「新しい VPS を初期化する」
- 「SSHセキュリティの設定」、「SSHポートの変更」、「rootパスワードログインの無効化」
- 「VPSセキュリティ強化」、「サーバーセキュリティ設定」、「強化」

特徴 (7 つのセキュリティ強化の動き):
1. sudo ユーザーを作成し、root パスワードによるログインを無効にする
2. SSH ポートを変更します (さまざまな Ubuntu バージョンをサポート)
3. 自動 Fail2ban のインストールと構成
4. SSH キーベースのログインのサポート
5. SSHログイン通知（オプション）
6.UFWファイアウォールの設定
7. Docker セキュリティリマインダー
