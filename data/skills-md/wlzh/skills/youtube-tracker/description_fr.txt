Suivez les chaînes YouTube pour les nouveaux téléchargements. Prend en charge à la fois le mode RSS (aucune clé API nécessaire, quota illimité) et le mode API. À utiliser lorsque : ajoutez/supprimez/répertoriez les chaînes YouTube suivies, recherchez de nouvelles vidéos ou exécutez une surveillance programmée des chaînes YouTube.
