QuarkPanTool → mswnlz GitHub コンテンツ パブリッシング パイプライン全体を自動化します。ユーザーがQuark共有URLを提供し、次のことを行う場合に使用します:(1) Quark Driveにバッチフォルダを作成する、(2) そのフォルダにリソースを保存/コピーする、(3) 各共有リソースフォルダにプロモーションファイルをコピーする、(4) ランダムなパスコードを使用して永続的に暗号化された共有リンクを生成する、(5) リポジトリの説明によってアイテムをmswnlzリポジトリ(書籍/映画など)に自動分類する、(6) ターゲットリポジトリの追加/更新YYYYMM.md および README 月インデックス、(7) git commit+push、(8) 統合された Telegram 通知の送信、および (9) mswnlz.github.io サイトの再構築を強制的にトリガーし、最終的なサイト URL を返します。
