Генерация описания робота URDF и проверка времени генерации по умолчанию. Используйте при создании, редактировании, регенерации, проверке или отладке файлов .urdf, источников Python gen_urdf(), связей роботов, соединений, ограничений, инерции, визуальной геометрии/геометрии столкновений, ссылок на сетки, соглашений о фреймах или сгенерированных артефактов описания робота. Используйте навык SRDF для семантических групп MoveIt2 и семантики IK/планирования пути; использовать навык CAD Explorer для локальных серверных элементов управления MoveIt2; используйте навыки CAD для вывода STEP/STL/3MF/DXF/GLB.
