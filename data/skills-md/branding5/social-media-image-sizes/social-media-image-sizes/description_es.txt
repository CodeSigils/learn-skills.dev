Verifique y cambie el tamaño de las imágenes para las plataformas de redes sociales. Ejecute scripts/check.js para validar cualquier imagen según las especificaciones de Instagram, Facebook, X (Twitter), LinkedIn, TikTok, YouTube, Pinterest, Snapchat y Threads: obtenga una lista de coincidencias clasificadas con comandos de cambio de tamaño exactos. Ejecute scripts/resize.js para exportar una copia del tamaño correcto. Úselo cuando un usuario solicite validar las dimensiones de una imagen, cambiar el tamaño de una imagen para una plataforma, verificar si una imagen se ajusta a una especificación o preparar recursos para publicaciones o anuncios en redes sociales.
