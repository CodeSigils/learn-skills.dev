Levante la base del panel (la capa de plataforma: primitivas de interfaz de usuario, sistema de formularios, gráficos, repositorio + adaptadores, costura de autenticación, tema, shell de enrutamiento) en un nuevo proyecto como una aplicación ejecutable sin configuración. Ejecute esto PRIMERO cuando cree un panel, luego cree pantallas a partir de las formas del catálogo de agregar componentes (agregar página de detalles, agregar kanban,…) y la habilidad de operación de agregar backend.
