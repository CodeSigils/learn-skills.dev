Posiziona le fondamenta del dashboard (il livello della piattaforma: primitive dell'interfaccia utente, sistema di moduli, grafici, repository + adattatori, autenticazione, tema, shell di routing) in un nuovo progetto come app eseguibile a configurazione zero. Eseguilo PRIMA quando crei un dashboard, quindi componi le schermate dalle forme del catalogo di componenti aggiuntivi (pagina di aggiunta dettagli, aggiungi kanban, ...) e dalla capacità operativa di aggiunta backend.
