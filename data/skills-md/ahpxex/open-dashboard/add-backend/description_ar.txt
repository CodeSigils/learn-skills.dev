كل شيء يتعلق بطبقة البيانات - اختر واحدًا من ستة قوالب خلفية جاهزة للتشغيل (TanStack Start + Drizzle + Better-auth، Hono + Drizzle + Better-auth، Hono + Prisma + Better-auth، Hono + Drizzle + Auth.js/NextAuth، FastAPI + SQLAlchemy + JWT، Supabase) وقم بتوصيل الواجهة الأمامية إليها من خلال طبقات Repository + AuthProvider؛ سقالة مورد CRUD (جدول Postgres + خادم fns + خطافات الاستعلام + صفحة DataTable + مربع حوار إنشاء/تحرير + إدخال الشريط الجانبي) ؛ ربط أو تبديل مصدر بيانات أحد الموارد (Drizzle / REST / GraphQL / في الذاكرة)؛ أو أعد توجيه بيانات + مصادقة التطبيق بالكامل إلى واجهة خلفية مختلفة. يُستخدم عند إضافة كيان بيانات أو توجيه التطبيق إلى واجهة خلفية بخلاف Postgres الافتراضي + مصادقة أفضل.
