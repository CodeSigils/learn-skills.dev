データ層に関するすべて - すぐに実行できる 6 つのバックエンド テンプレート (TanStack Start + Drizzle + better-auth、Hono + Drizzle + better-auth、Hono + Prisma + better-auth、Hono + Drizzle + Auth.js/NextAuth、FastAPI + SQLAlchemy + JWT、Supabase) の 1 つを選択し、リポジトリ + AuthProvider シームを介してフロントエンドをそれに接続します。 CRUD リソース (Postgres テーブル + サーバー FNS + クエリ フック + DataTable ページ + 作成/編集ダイアログ + サイドバー エントリ) を足場にします。 1 つのリソースのデータ ソース (Drizzle / REST / GraphQL / インメモリ) をバインドまたはスワップします。または、アプリ全体のデータと認証を別のバックエンドに再指定します。データ エンティティを追加する場合、またはデフォルトの Postgres + better-auth 以外のバックエンドでアプリを指定する場合に使用します。
