Anleitung zur Verwendung der „Resumy“-CLI zum Erstellen maßgeschneiderter Lebenslauf-PDFs durchgängig. Verwenden Sie diese Option, wenn ein Benutzer rohe Hintergrundinformationen, einen vorhandenen Lebenslauf oder eine Zielstellenbeschreibung in eine Lebenslaufkopie und ein endgültiges PDF umwandeln möchte. Wenn ein Agent zuerst den Hintergrund des Kandidaten sammeln sollte, dann den Ziel-JD, den Lebenslauf wahrheitsgetreu anpassen und „Lebenslauf generieren PDF“ ausführen; oder bei der Fehlerbehebung beim browserbasierten PDF-Export in diesem Repository.
