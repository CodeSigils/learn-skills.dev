Руководство по использованию CLI `resumy` для создания индивидуальных PDF-файлов резюме. Используйте, когда пользователь хочет превратить необработанную справочную информацию, существующее резюме или целевое описание вакансии в копию резюме и окончательный PDF-файл; когда агент должен сначала собрать биографические данные кандидата, затем собрать целевой JD, правдиво адаптировать резюме и запустить «resumygenerate pdf»; или при устранении неполадок экспорта PDF-файлов через браузер в этом репозитории.
