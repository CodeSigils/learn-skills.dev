Guía para usar la CLI `resumy` para crear archivos PDF de currículum personalizados de principio a fin. Úselo cuando un usuario desee convertir información básica sin procesar, un currículum existente o una descripción del trabajo objetivo en una copia del currículum y un PDF final; cuando un agente debe recopilar los antecedentes del candidato primero, recopilar el JD objetivo en segundo lugar, adaptar el currículum de manera veraz y ejecutar "resumy generate pdf"; o al solucionar problemas de exportación de PDF basada en navegador en este repositorio.
