قم بترحيل عمليات تكامل بيانات الويب Exa أو Tavily أو Perplexity أو Firecrawl بالكامل إلى منتجات Parallel المناسبة مع الحفاظ على سلوك التطبيق. يُستخدم عند استبدال مجموعات SDK أو استدعاءات REST الخاصة بموفري الخدمة، والتبعيات، ومتغيرات البيئة، ومعلمات الطلب، وتحليل الاستجابة، وأدوات النموذج، ومسارات البحث بالإضافة إلى الكشط، ومسارات المحتوى الكامل أو تركيب الإجابات، والاختبارات، والوثائق؛ فصل فهرس البحث أو الزحف أو المتصفح أو تحليل الملفات أو المراقبة أو غيرها من الإمكانات غير البحثية غير المدعومة؛ التدقيق لاستخدام مقدم الخدمة المتبقي؛ أو الانتهاء والتحقق من ترحيل الموفر قيد التقدم.
