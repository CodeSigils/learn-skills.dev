Migra completamente le integrazioni dei dati web Exa, Tavily, Perplexity o Firecrawl ai prodotti Parallel appropriati preservando il comportamento dell'applicazione. Da utilizzare quando si sostituiscono gli SDK o le chiamate REST di questi provider, le dipendenze, le variabili di ambiente, i parametri di richiesta, l'analisi delle risposte, gli strumenti del modello, i percorsi di ricerca e scrape, i percorsi di contenuto completo o di sintesi delle risposte, i test e la documentazione; separazione non supportata di indicizzazione di ricerca, scansione, browser, analisi di file, monitoraggio o altre funzionalità non di ricerca; controllo dell'utilizzo residuo del fornitore; o terminare e verificare la migrazione di un provider in corso.
