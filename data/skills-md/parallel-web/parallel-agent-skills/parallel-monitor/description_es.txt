Realice un seguimiento continuo de la web en busca de cambios con una cadencia recurrente. Úselo cuando el usuario solicite "monitorear", "seguir cambios en", "observar" o "avisarme cuando" algo en la web cambie; por ejemplo, "Seguir los cambios de precios para el iPhone 16", "Avisarme cuando Tesla presente un nuevo 8-K", "Monitorear las páginas de precios de la competencia semanalmente". También se utiliza para enumerar, inspeccionar, actualizar o eliminar monitores existentes.
