Verfolgen Sie das Web kontinuierlich in regelmäßigen Abständen auf Änderungen. Verwenden Sie diese Option, wenn der Benutzer etwas im Internet „überwachen“, „Änderungen verfolgen“, „beobachten“ oder „benachrichtigen“ möchte, wenn sich etwas ändert – z. B. „Preisänderungen für iPhone 16 verfolgen“, „Mich benachrichtigen, wenn Tesla ein neues 8-K einreicht“, „Wöchentlich die Preisseiten der Konkurrenz überwachen“. Auch zum Auflisten, Überprüfen, Aktualisieren oder Löschen vorhandener Monitore verwenden.
