Monitora continuamente le modifiche sul Web con cadenza ricorrente. Da utilizzare quando l'utente chiede di "monitorare", "tenere traccia delle modifiche a", "guardare" o "avvisare quando" qualcosa sul Web cambia, ad esempio "Monitora le variazioni di prezzo per iPhone 16", "Avvisami quando Tesla presenta un nuovo 8-K", "Monitora settimanalmente le pagine dei prezzi della concorrenza". Utilizzare anche per elencare, ispezionare, aggiornare o eliminare i monitor esistenti.
