Suivez en permanence les changements sur le Web à une cadence récurrente. À utiliser lorsque l'utilisateur demande de « surveiller », « suivre les modifications », « regarder » ou « m'alerter lorsque » quelque chose sur le Web change – par exemple, « Suivre les modifications de prix pour l'iPhone 16 », « M'alerter lorsque Tesla dépose un nouveau 8-K », « Surveiller les pages de tarification des concurrents chaque semaine ». Utilisez également pour répertorier, inspecter, mettre à jour ou supprimer les moniteurs existants.
