Scopri entità (aziende, persone, prodotti, ecc.) che corrispondono a una descrizione in linguaggio naturale. Da utilizzare quando l'utente chiede di "trovare tutte le X" o "elencare tutte le Y che...", ad esempio "Trova startup AI che hanno creato una serie A nel 2026", "Elenca le società di coperture a Charlotte NC", "Mostrami le società di strumenti di sviluppo YC W24". Diversa dalla ricerca sul web (che restituisce pagine web) e dalla ricerca approfondita (che restituisce un rapporto narrativo). Utilizzalo quando l'utente desidera un elenco strutturato di entità.
