Créez des outils CLI optimisés pour les agents de codage. Utilisez cette compétence lorsque l'utilisateur demande à « créer une CLI », « créer un outil de ligne de commande », « encapsuler une API en tant que CLI », « créer une CLI pour coder des agents », « créer une CLI conviviale pour les agents » ou discute de la création d'outils de terminal, de wrappers CLI pour les serveurs API/MCP, de sorties CLI structurées ou d'interfaces de ligne de commande lisibles par les agents. Déclenchez cette compétence chaque fois que des CLI, des outils de terminal ou des utilitaires de ligne de commande sont créés (même si l'utilisateur ne dit pas « convivial pour les agents »), car la conception axée sur l'agent permet d'obtenir de meilleures CLI pour tout le monde.
