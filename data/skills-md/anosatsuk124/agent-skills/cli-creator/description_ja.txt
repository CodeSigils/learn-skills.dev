エージェントのコーディングに最適化された CLI ツールを作成します。このスキルは、ユーザーが「CLI の作成」、「コマンドライン ツールの構築」、「API を CLI としてラップ」、「エージェントをコーディングするための CLI の作成」、「エージェント フレンドリーな CLI の構築」を要求する場合、またはターミナル ツール、API/MCP サーバー用の CLI ラッパー、構造化 CLI 出力、またはエージェントが読み取り可能なコマンド ライン インターフェイスの構築について議論する場合に使用します。エージェントファーストの設計により、誰にとっても優れた CLI が作成されるため、ユーザーが「エージェントに優しい」と言わなくても、CLI、ターミナル ツール、またはコマンドライン ユーティリティを構築するときは必ずこのスキルをトリガーしてください。
