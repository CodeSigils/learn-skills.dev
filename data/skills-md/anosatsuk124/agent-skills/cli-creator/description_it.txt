Crea strumenti CLI ottimizzati per gli agenti di codifica. Utilizzare questa competenza quando l'utente chiede di "creare una CLI", "costruire uno strumento da riga di comando", "raggruppare un'API come CLI", "creare una CLI per gli agenti di codifica", "costruire una CLI di facile utilizzo per gli agenti" o discute della creazione di strumenti terminali, wrapper CLI per server API/MCP, output CLI strutturato o interfacce della riga di comando leggibili dagli agenti. Attiva questa abilità ogni volta che vengono create CLI, strumenti terminali o utilità della riga di comando, anche se l'utente non dice "agent-friendly", perché la progettazione incentrata sull'agente rende CLI migliori per tutti.
