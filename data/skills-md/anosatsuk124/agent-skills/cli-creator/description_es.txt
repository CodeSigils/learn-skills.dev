Cree herramientas CLI optimizadas para agentes de codificación. Utilice esta habilidad cuando el usuario solicite "crear una CLI", "crear una herramienta de línea de comandos", "envolver una API como una CLI", "crear una CLI para agentes de codificación", "crear una CLI compatible con agentes" o analice la creación de herramientas de terminal, contenedores de CLI para servidores API/MCP, salida de CLI estructurada o interfaces de línea de comandos legibles por el agente. Active esta habilidad siempre que se estén creando CLI, herramientas de terminal o utilidades de línea de comandos, incluso si el usuario no dice "apto para agentes", porque el diseño centrado en el agente genera mejores CLI para todos.
