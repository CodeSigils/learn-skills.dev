Erstellen Sie CLI-Tools, die für Codierungsagenten optimiert sind. Verwenden Sie diese Fähigkeit, wenn der Benutzer auffordert, „eine CLI zu erstellen“, „ein Befehlszeilentool zu erstellen“, „eine API als CLI zu verpacken“, „eine CLI zum Codieren von Agenten zu erstellen“, „eine agentenfreundliche CLI zu erstellen“ oder die Erstellung von Terminaltools, CLI-Wrappern für APIs/MCP-Server, strukturierter CLI-Ausgabe oder von Agenten lesbaren Befehlszeilenschnittstellen bespricht. Lösen Sie diese Fähigkeit immer dann aus, wenn CLIs, Terminal-Tools oder Befehlszeilen-Dienstprogramme erstellt werden – auch wenn der Benutzer nicht „Agentenfreundlich“ sagt –, da das Agent-First-Design bessere CLIs für alle ermöglicht.
