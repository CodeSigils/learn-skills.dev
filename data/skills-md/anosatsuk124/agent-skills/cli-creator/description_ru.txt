Создавайте инструменты CLI, оптимизированные для агентов кодирования. Используйте этот навык, когда пользователь просит «создать CLI», «создать инструмент командной строки», «обернуть API как CLI», «создать CLI для агентов кодирования», «создать CLI, удобный для агентов», или обсуждает создание инструментов терминала, оболочек CLI для серверов API/MCP, структурированного вывода CLI или читаемых агентом интерфейсов командной строки. Задействуйте этот навык всякий раз, когда создаются интерфейсы командной строки, инструменты терминала или утилиты командной строки — даже если пользователь не говорит «дружественный к агентам», — потому что дизайн, ориентированный на агентов, обеспечивает лучшие интерфейсы командной строки для всех.
