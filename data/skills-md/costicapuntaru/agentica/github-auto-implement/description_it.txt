Implementazione autonoma del problema su GitHub: sceglie il prossimo problema pronto, lo valuta, lo implementa con TDD e apre un PR indirizzato al ramo corretto (ramo di funzionalità epico predefinito o ramo di dipendenza concatenato a PR). Da utilizzare quando si esegue il demone autobot, si implementano i problemi di GitHub in modo autonomo o si avvia il ciclo di implementazione automatica.
