Автономная реализация проблемы GitHub — выбирает следующую готовую задачу, сортирует ее, реализует с помощью TDD и открывает PR, ориентированный на правильную ветку (по умолчанию, ветвь эпических функций или ветку зависимостей, связанную с PR). Используйте при запуске демона автобота, автономной реализации задач GitHub или запуске цикла автоматической реализации.
