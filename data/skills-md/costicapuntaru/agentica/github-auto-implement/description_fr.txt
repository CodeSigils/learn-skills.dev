Implémentation autonome du problème GitHub : sélectionne le prochain problème prêt, le trie, l'implémente avec TDD et ouvre un PR ciblant la branche correcte (branche par défaut, branche de fonctionnalité épique ou branche de dépendance chaînée PR). À utiliser lors de l'exécution du démon autobot, de l'implémentation autonome des problèmes GitHub ou du démarrage de la boucle d'implémentation automatique.
