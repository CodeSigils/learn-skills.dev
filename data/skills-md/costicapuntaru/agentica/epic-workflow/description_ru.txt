Сквозное планирование Epic — определите требования, напишите PRD, разложите проблемы GitHub с зависимостями и создайте ветку функций для автономной реализации. Используйте при запуске нового эпика, планировании большой функции или когда пользователь говорит «эпический рабочий процесс», «запланируйте эту функцию» или «начните новый эпик».
