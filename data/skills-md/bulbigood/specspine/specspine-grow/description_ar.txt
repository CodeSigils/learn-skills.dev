قم بإنشاء أو تطوير البنية المقصودة في Markdown SpecSpine المرتبط من نية المستخدم الصريحة والمواصفات الحالية. يُستخدم لتهيئة الحقول الخضراء والتغييرات المعمارية المقبولة وتحليل التأثير وتقسيم المواصفات أو دمجها أو إعادة تسميتها أو ربطها. لا تستخدم لاكتشاف المستودع (خريطة Specspine)، أو مراجعة التكامل (specspine-doctor)، أو استخراج السياق، أو التنفيذ، أو توافق التعليمات البرمجية/المواصفات.
