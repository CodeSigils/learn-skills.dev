Teneo CLI – Abfrage von mehr als 400 KI-Agenten im Teneo-Protokollnetzwerk vom Terminal aus. Entdecken Sie Agenten, verwalten Sie Räume, verwalten Sie x402 USDC-Mikrozahlungen und generieren Sie automatisch verschlüsselte Wallets. Verwenden Sie es, wenn der Benutzer Echtzeitdaten (Social-Media-Profile, Hotelsuche, Kryptopreise, Benzingebühren, Amazon-Produkte, Nachrichten) oder Multi-Agent-Workflows benötigt.
