Rails 애플리케이션에서 UUID 기본 키를 구현하기 위한 전문가 지침입니다. UUID를 기본 키로 설정, UUIDv4와 UUIDv7 중에서 선택, UUID 기본값에 대한 생성기 구성, ID 콜론 uuid를 사용하여 마이그레이션 작성, UUID 외래 키 추가, URL 친화적 ID에 대한 base36 인코딩 구현, PostgreSQL pgcrypto 또는 gen_random_uuid 구성, SQLite 바이너리 UUID 저장소 구현, 기본 키 유형 선택, 비순차 ID, 보안 ID, 무작위 ID 또는 기타 사용 시 사용 자동 증가 정수 이상의 ID 생성 전략.
