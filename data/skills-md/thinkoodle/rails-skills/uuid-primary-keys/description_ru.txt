Экспертное руководство по реализации первичных ключей UUID в приложениях Rails. Используйте при настройке UUID в качестве первичных ключей, выборе между UUIDv4 и UUIDv7, настройке генераторов для UUID по умолчанию, написании миграций с идентификатором двоеточия uuid, добавлении внешних ключей UUID, реализации кодировки base36 для идентификаторов, удобных для URL-адресов, настройке PostgreSQL pgcrypto или gen_random_uuid, реализации двоичного хранилища UUID SQLite, выборе типа первичного ключа, использовании непоследовательных идентификаторов, безопасных идентификаторов, случайные идентификаторы или любая стратегия генерации идентификаторов, кроме целых чисел с автоинкрементом.
