Rails アプリケーションに UUID 主キーを実装するための専門家によるガイダンス。 UUID を主キーとして設定する場合、UUIDv4 と UUIDv7 のどちらかを選択する場合、UUID デフォルトのジェネレーターを構成する場合、ID コロン uuid を使用して移行を作成する場合、UUID 外部キーを追加する場合、URL フレンドリー ID の Base36 エンコードを実装する場合、PostgreSQL pgcrypto または gen_random_uuid を構成する場合、SQLite バイナリ UUID ストレージを実装する場合、主キー タイプを選択する場合、非シーケンシャル ID、安全な ID、ランダムを使用する場合に使用します。 ID、または自動インクリメント整数を超える任意の ID 生成戦略。
