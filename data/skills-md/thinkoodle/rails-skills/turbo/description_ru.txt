Экспертное руководство по созданию современных пользовательских интерфейсов Rails с помощью Turbo (Drive, Frames, Streams). Используйте при реализации частичных обновлений страниц, широковещательных рассылок в реальном времени, турбокадров, турбопотоков, шаблонов Hotwire, Turbo_frame_tag, ответов Turbo_stream, отложенной загрузки кадров, морфинга, обновления страниц или любой функции Rails, связанной с «Турбо». Охватывает навигацию Turbo Drive, Turbo Frames для ограниченных обновлений, Turbo Streams для доставки HTML в реальном времени и морфинг Turbo 8.
