إرشادات الخبراء بشأن Rails I18n (التدويل والتوطين). يُستخدم عند العمل مع الترجمات، أو ملفات الإعدادات المحلية، أو مساعدات t() / l()، أو عمليات البحث البطيئة، أو الجمع، أو الاستيفاء، أو تنسيق التاريخ/الوقت/الأرقام، أو ترجمات النماذج، أو ترجمات رسائل الخطأ، أو تحديد الإعدادات المحلية من عنوان URL/الرأس/الجلسة، أو تنظيم ملفات ترجمة YAML. مشغلات على "i18n"، و"التدويل"، و"الترجمة"، و"locale"، و"localize"، و"t()"، و"translate"، و"multilingual"، و"pluralization"، و"locale file"، و"YAML Translation".
