إرشادات الخبراء لبناء مكونات واجهة مستخدم قابلة لإعادة الاستخدام في Rails باستخدام الأجزاء الجزئية وفئات CSS والمساعدين. يُستخدم عند إنشاء مكونات أو أجزاء أو أنماط واجهة مستخدم قابلة لإعادة الاستخدام أو حالات فارغة أو مشروطة أو بطاقات أو أزرار أو شارات أو تنبيهات أو جداول بيانات أو أي نمط مكون. يغطي إطار اتخاذ القرار لـ CSS فقط مقابل الجزئي مقابل المساعد مقابل ViewComponent، والاستخدام السليم لـ local_assis، وإنتاج الكتلة، والتقاط الفتحات، والأنماط المتغيرة، ومعارض المكونات.
