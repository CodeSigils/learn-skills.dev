Экспертное руководство по созданию повторно используемых компонентов пользовательского интерфейса в Rails с использованием партиалов, классов CSS и помощников. Используйте при создании компонентов, партиалов, многократно используемых шаблонов пользовательского интерфейса, пустых состояний, модальных окон, карточек, кнопок, значков, оповещений, таблиц данных или любого шаблона компонента. Охватывает структуру принятия решений только для CSS, частичного, вспомогательного и ViewComponent, правильное использование local_assigns, передачу блоков, захват для слотов, варианты шаблонов и галереи компонентов.
