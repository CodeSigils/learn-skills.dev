Conseils d'experts pour l'architecture CSS dans les applications Rails utilisant du CSS moderne (pas de Tailwind). À utiliser lors de l'écriture de feuilles de style, de l'organisation de fichiers CSS, de l'implémentation du mode sombre, de la définition de jetons de conception, de l'utilisation de propriétés personnalisées CSS, de la création de styles de composants, de l'utilisation de calques CSS (@layer), de l'utilisation de la fonction light-dark(), de la configuration de jeux de couleurs ou de la structuration du CSS pour la maintenabilité. Couvre les jetons de conception, les systèmes de couleurs sémantiques, les styles étendus aux composants, les classes utilitaires, les modèles réactifs et l'organisation des fichiers.
