إرشادات الخبراء لهندسة CSS في تطبيقات Rails باستخدام CSS الحديث (بدون Tailwind). يُستخدم عند كتابة أوراق الأنماط، وتنظيم ملفات CSS، وتنفيذ الوضع المظلم، وتحديد رموز التصميم، واستخدام خصائص CSS المخصصة، وإنشاء أنماط المكونات، والعمل مع طبقات CSS (@layer)، واستخدام وظيفة light-dark()، أو إعداد أنظمة الألوان، أو هيكلة CSS لقابلية الصيانة. يغطي رموز التصميم وأنظمة الألوان الدلالية والأنماط ذات نطاق المكونات وفئات الأدوات المساعدة والأنماط سريعة الاستجابة وتنظيم الملفات.
