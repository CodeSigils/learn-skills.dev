Guida esperta per l'architettura CSS nelle applicazioni Rails che utilizzano CSS moderni (senza Tailwind). Utilizzare quando si scrivono fogli di stile, si organizzano file CSS, si implementa la modalità oscura, si definiscono token di progettazione, si utilizzano proprietà personalizzate CSS, si creano stili di componenti, si lavora con livelli CSS (@layer), si utilizza la funzione chiaro-scuro(), si impostano combinazioni di colori o si strutturano CSS per la manutenibilità. Copre token di progettazione, sistemi di colore semantici, stili con ambito componente, classi di utilità, modelli reattivi e organizzazione di file.
