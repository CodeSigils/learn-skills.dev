Fachkundige Anleitung für die CSS-Architektur in Rails-Anwendungen mit modernem CSS (kein Rückenwind). Verwenden Sie es, wenn Sie Stylesheets schreiben, CSS-Dateien organisieren, den Dunkelmodus implementieren, Design-Tokens definieren, benutzerdefinierte CSS-Eigenschaften verwenden, Komponentenstile erstellen, mit CSS-Ebenen (@layer) arbeiten, die Funktion „light-dark()“ verwenden, Farbschemata einrichten oder CSS zur Wartbarkeit strukturieren. Behandelt Design-Tokens, semantische Farbsysteme, komponentenbezogene Stile, Utility-Klassen, responsive Muster und Dateiorganisation.
