Экспертное руководство по архитектуре CSS в приложениях Rails с использованием современного CSS (без Tailwind). Используйте при написании таблиц стилей, организации файлов CSS, реализации темного режима, определении токенов дизайна, использовании пользовательских свойств CSS, создании стилей компонентов, работе со слоями CSS (@layer), использовании функции Light-Dark(), настройке цветовых схем или структурировании CSS для удобства обслуживания. Охватывает токены дизайна, семантические цветовые системы, стили на уровне компонентов, служебные классы, адаптивные шаблоны и организацию файлов.
