إرشادات الخبراء لتحديد واستخدام اقترانات Active Record في Rails. يُستخدم عند إنشاء الارتباطات، أو تحديد علاقات النماذج، أو استكشاف أخطاء المفاتيح الخارجية وإصلاحها، أو إصلاح استعلامات N+1، أو إعداد ينتمي إلى، أو has_many، أو has_one، أو has_many :من خلال، أو الارتباطات متعددة الأشكال، أو الصلات المرجعية الذاتية، أو ربط الجداول، أو ذاكرات التخزين المؤقت للعدادات، أو الخيارات التابعة، أو inverse_of، أو التحميل المتحمس، أو أي سؤال حول كيفية ارتباط النماذج ببعضها البعض.
