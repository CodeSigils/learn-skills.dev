Экспертное руководство по Action Mailer в приложениях Rails. Используйте при создании почтовых программ, отправке электронных писем, создании шаблонов электронной почты, настройке доставки, написании предварительных просмотров почтовых программ или работе с транзакционной электронной почтой. Триггеры по «почтовой программе», «электронной почте», «отправить электронное письмо», «почтовой программе действия», «шаблону письма», «deliver_later», «уведомлению по электронной почте», «транзакционному электронному письму», «предварительному просмотру почтовой программы», «приветственному электронному письму», «электронному уведомлению по электронной почте».
