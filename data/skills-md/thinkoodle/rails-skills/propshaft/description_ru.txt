Экспертное руководство по конвейеру активов Propshaft в Rails 8+. Используйте при работе с ресурсами, таблицами стилей, организацией CSS, ресурсами JavaScript, картами импорта, предварительной компиляцией ресурсов, снятием отпечатков пальцев, изображениями, шрифтами, настройкой CDN или миграцией со Sprockets. Охватывает структуру файла, stylesheet_link_tag, image_tag, порядок @layer, @import, пользовательские свойства CSS, помощники по ресурсам, развертывание и распространенные ошибки Propshaft. Триггер по «карданному валу», «конвейеру активов», «активам», «таблице стилей», «активам Javascript», «импорту карт», «прекомпиляции активов», «организации CSS», «миграции звездочек», «отпечаткам пальцев», «stylesheet_link_tag», «image_tag», «asset_path».
