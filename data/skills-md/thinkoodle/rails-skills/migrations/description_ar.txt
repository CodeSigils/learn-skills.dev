إرشادات الخبراء لكتابة عمليات ترحيل Active Record آمنة وقابلة للعكس في تطبيقات Rails. يُستخدم عند إنشاء ترحيل، أو إضافة عمود، أو إزالة عمود، أو تغيير المخطط، أو تعديل جدول، أو إنشاء جدول، أو إضافة فهرس، أو إضافة مفتاح خارجي، أو إعادة تسمية عمود، أو تغيير نوع العمود، أو ترحيل قاعدة البيانات، أو تغيير المخطط، أو التراجع، أو خطأ في الترحيل، أو ترحيل البيانات، أو ترحيل قواعد البيانات المتعددة، أو أي تغيير في بنية قاعدة البيانات.
