Fachkundige Anleitung zum Schreiben sicherer, reversibler Active Record-Migrationen in Rails-Anwendungen. Verwenden Sie diese Option, wenn Sie eine Migration erstellen, eine Spalte hinzufügen, eine Spalte entfernen, ein Schema ändern, eine Tabelle ändern, eine Tabelle erstellen, einen Index hinzufügen, einen Fremdschlüssel hinzufügen, eine Spalte umbenennen, den Spaltentyp ändern, eine Datenbankmigration, eine Schemaänderung, ein Rollback, einen Migrationsfehler, eine Datenmigration, eine Migration mehrerer Datenbanken oder jede Änderung der Datenbankstruktur.
