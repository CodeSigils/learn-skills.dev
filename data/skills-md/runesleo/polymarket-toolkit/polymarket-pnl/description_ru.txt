Точный калькулятор прибылей и убытков для любого адреса Polymarket — восстанавливает прибыль/убыток на основе денежного потока Data API (КУПИТЬ/ПРОДАТЬ/ВЫКУПАТЬ/СЛИЯТЬ/РАЗДЕЛИТЬ/РИБАТ) плюс стоимость нереализованной позиции. Соответствует официальной/прибыли в пределах ~0,2% MAPE при проверке таблицы лидеров. Используйте свой собственный Python (httpx).
