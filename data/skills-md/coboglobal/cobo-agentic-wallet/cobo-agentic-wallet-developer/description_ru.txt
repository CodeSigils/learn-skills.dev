Руководство разработчика по интеграции Cobo Agentic Wallet SDK с агентами ИИ,
боты и конвейеры автоматизации. Охватывает установку SDK (Python/TypeScript),
Настройка CLI `caw`, управление учетными данными, авторизация на основе пакта, токен
переводы, вызовы контрактов, интеграция фреймворков (LangChain, агенты OpenAI,
CrewAI, Agno, Vercel AI SDK, Mastra), настройка сервера MCP и тестирование тестовой сети.
Используйте при создании или отладке приложений, которые программно управляют
агентский кошелек.
