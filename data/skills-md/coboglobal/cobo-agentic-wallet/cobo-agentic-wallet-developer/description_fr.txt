Guide du développeur pour l'intégration du SDK Cobo Agentic Wallet dans les agents IA,
des robots et des pipelines d'automatisation. Couvre l'installation du SDK (Python/TypeScript),
Configuration CLI `caw`, gestion des informations d'identification, autorisation basée sur un pacte, jeton
transferts, appels de contrats, intégrations de framework (LangChain, OpenAI Agents,
CrewAI, Agno, Vercel AI SDK, Mastra), configuration du serveur MCP et tests testnet.
À utiliser lors de la création ou du débogage d'applications qui contrôlent par programme
un portefeuille agent.
