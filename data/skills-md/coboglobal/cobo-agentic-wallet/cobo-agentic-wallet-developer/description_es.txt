Guía para desarrolladores para integrar el SDK de Cobo Agentic Wallet en agentes de IA,
bots y canales de automatización. Cubre la instalación del SDK (Python/TypeScript),
Configuración CLI `caw`, gestión de credenciales, autorización basada en pactos, token
transferencias, convocatorias de contratos, integraciones de marcos (LangChain, OpenAI Agents,
CrewAI, Agno, Vercel AI SDK, Mastra), configuración del servidor MCP y pruebas de testnet.
Úselo al crear o depurar aplicaciones que controlan mediante programación
una billetera agente.
