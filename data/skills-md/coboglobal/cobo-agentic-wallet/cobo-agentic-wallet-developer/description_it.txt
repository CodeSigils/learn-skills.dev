Guida per sviluppatori per l'integrazione dell'SDK del portafoglio Cobo Agentic negli agenti AI,
bot e pipeline di automazione. Copre l'installazione dell'SDK (Python/TypeScript),
Configurazione CLI "caw", gestione delle credenziali, autorizzazione basata su patto, token
trasferimenti, chiamate a contratti, integrazioni framework (LangChain, OpenAI Agents,
CrewAI, Agno, Vercel AI SDK, Mastra), configurazione del server MCP e test del testnet.
Da utilizzare durante la creazione o il debug di applicazioni che controllano a livello di codice
un portafoglio agente.
