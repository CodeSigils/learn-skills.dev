Contrôlez, inspectez, déboguer ou automatisez un émulateur apple2ts via son API HTTP localhost. À utiliser pour l'état de la machine, les lecteurs, les supports de montage, la saisie au clavier, la réinitialisation/le démarrage, les opérations de mémoire/CPU/débogueur, les points d'arrêt, les états de sauvegarde, les captures d'écran et l'exécution de programmes BASIC ou de blocs binaires.
