Cette compétence doit être utilisée lorsque l'utilisateur demande à inspecter, évaluer ou noter la configuration matérielle de la machine locale. Il automatise la collecte de données matérielles sur macOS, recherche en ligne les références actuelles du marché, note chaque composant (CPU, mémoire, stockage, GPU, affichage, valeur de revente) sur 100 et génère un rapport HTML soigné avec des barres de notation visuelles. Les phrases de déclenchement incluent : 查询本机硬件, 硬件评分, 给我的电脑打分, évaluer mon matériel, évaluer mon matériel, évaluer les spécifications de mon ordinateur.
