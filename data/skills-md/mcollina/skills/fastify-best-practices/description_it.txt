Guida lo sviluppo dei server backend Fastify Node.js e delle API REST utilizzando TypeScript o JavaScript. Da utilizzare durante la creazione, la configurazione o il debug di un'applicazione Fastify, tra cui la definizione di percorsi, l'implementazione di plug-in, l'impostazione della convalida dello schema JSON, la gestione degli errori, l'ottimizzazione delle prestazioni, la gestione dell'autenticazione, la configurazione di CORS e intestazioni di sicurezza, l'integrazione di database, l'utilizzo di WebSocket e la distribuzione in produzione. Copre l'intero ciclo di vita della richiesta Fastify (hook, serializzazione, registrazione con Pino) ​​e l'integrazione di TypeScript tramite tipi di strip. Termini di attivazione: Fastify, server Node.js, API REST, percorsi API, framework backend, fastify.config, server.ts, app.ts.
