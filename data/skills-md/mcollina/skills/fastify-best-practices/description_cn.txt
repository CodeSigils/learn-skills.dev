指导使用 TypeScript 或 JavaScript 开发 Fastify Node.js 后端服务器和 REST API。在构建、配置或调试 Fastify 应用程序时使用 - 包括定义路由、实现插件、设置 JSON 架构验证、处理错误、优化性能、管理身份验证、配置 CORS 和安全标头、集成数据库、使用 WebSocket 以及部署到生产。涵盖完整的 Fastify 请求生命周期（挂钩、序列化、使用 Pino 进行日志记录）以及通过条带类型进行的 TypeScript 集成。触发术语：Fastify、Node.js 服务器、REST API、API 路由、后端框架、fastify.config、server.ts、app.ts。
