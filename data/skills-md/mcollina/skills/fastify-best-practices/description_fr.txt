Guide le développement de serveurs backend Fastify Node.js et d'API REST à l'aide de TypeScript ou JavaScript. À utiliser lors de la création, de la configuration ou du débogage d'une application Fastify, notamment la définition d'itinéraires, la mise en œuvre de plugins, la configuration de la validation de schéma JSON, la gestion des erreurs, l'optimisation des performances, la gestion de l'authentification, la configuration de CORS et des en-têtes de sécurité, l'intégration de bases de données, l'utilisation de WebSockets et le déploiement en production. Couvre le cycle de vie complet des requêtes Fastify (hooks, sérialisation, journalisation avec Pino) ​​et l'intégration de TypeScript via les types de bandes. Termes déclencheurs : Fastify, serveur Node.js, API REST, routes API, framework backend, fastify.config, server.ts, app.ts.
