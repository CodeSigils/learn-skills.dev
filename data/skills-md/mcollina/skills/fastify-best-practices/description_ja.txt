TypeScript または JavaScript を使用した Fastify Node.js バックエンド サーバーと REST API の開発をガイドします。 Fastify アプリケーションを構築、構成、またはデバッグするときに使用します。これには、ルートの定義、プラグインの実装、JSON スキーマ検証のセットアップ、エラーの処理、パフォーマンスの最適化、認証の管理、CORS およびセキュリティ ヘッダーの構成、データベースの統合、WebSocket の操作、運用環境へのデプロイが含まれます。 Fastify リクエストのライフサイクル全体 (フック、シリアル化、Pino によるロギング) とストリップ タイプによる TypeScript の統合をカバーします。トリガー用語: Fastify、Node.js サーバー、REST API、API ルート、バックエンド フレームワーク、fastify.config、server.ts、app.ts。
