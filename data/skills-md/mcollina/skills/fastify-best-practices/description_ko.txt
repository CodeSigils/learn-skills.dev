TypeScript 또는 JavaScript를 사용하여 Fastify Node.js 백엔드 서버 및 REST API 개발을 안내합니다. 경로 정의, 플러그인 구현, JSON 스키마 검증 설정, 오류 처리, 성능 최적화, 인증 관리, CORS 및 보안 헤더 구성, 데이터베이스 통합, WebSocket 작업 및 프로덕션 배포를 포함하여 Fastify 애플리케이션을 구축, 구성 또는 디버깅할 때 사용합니다. 전체 Fastify 요청 수명주기(후크, 직렬화, Pino를 사용한 로깅) 및 스트립 유형을 통한 TypeScript 통합을 다룹니다. 트리거 용어: Fastify, Node.js 서버, REST API, API 경로, 백엔드 프레임워크, fastify.config, server.ts, app.ts.
