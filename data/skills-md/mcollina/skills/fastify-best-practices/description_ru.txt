Руководит разработкой серверных серверов Fastify Node.js и API REST с использованием TypeScript или JavaScript. Используйте при создании, настройке или отладке приложения Fastify, включая определение маршрутов, внедрение плагинов, настройку проверки схемы JSON, обработку ошибок, оптимизацию производительности, управление аутентификацией, настройку CORS и заголовков безопасности, интеграцию баз данных, работу с WebSockets и развертывание в рабочей среде. Охватывает полный жизненный цикл запроса Fastify (перехватчики, сериализация, ведение журнала с помощью Pino) ​​и интеграцию TypeScript с помощью типов полосы. Триггерные термины: Fastify, сервер Node.js, REST API, маршруты API, серверная среда, fastify.config, server.ts, app.ts.
