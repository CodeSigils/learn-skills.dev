Initialisez un nouveau référentiel backend Go avec une configuration d'ingénierie de niveau production. À utiliser lors de la création de nouveaux projets de microservices Go, de la configuration de dépôts Go à partir de zéro ou lorsque l'utilisateur demande d'échafauder un backend Go avec les meilleures pratiques (Uber FX, Ent ORM, gRPC, CI/CD, linting, Docker).
