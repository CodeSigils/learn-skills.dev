Obligatorische Codierungsdisziplinregeln, die gängige Anti-Patterns bei der KI-Codierung verhindern. MUSS für ALLE Aufgaben zum Schreiben, Bearbeiten, Überprüfen, Beheben von Fehlern und Testen von Code geladen werden. Auslöser für: Code schreiben, Code bearbeiten, Fehler beheben, Tests schreiben, Funktionen implementieren, Refactoring, Codeüberprüfung, Funktionen erstellen, Fehlerbehandlung hinzufügen, Debuggen. Diese Fähigkeit erzwingt Fail-Fast-Prinzipien, eine ordnungsgemäße Fehlerausbreitung, aussagekräftige Tests und disziplinierte Debugging-Workflows. Immer aktiv, wenn Claude Code schreibt oder ändert.
