Perform multi-dimensional priority ranking for requirements/functions/projects and output version scheduling recommendations. When the user says “help me prioritize,” “how should these requirements be prioritized,” “score with RICE,” “ICE scoring,” “Kano analysis,” “cost‑benefit analysis,” “feature scheduling,” “roadmap planning,” “which to do first and which later,” “version planning,” or when the user lists a batch of requirements/functions/projects and needs a decision order, use this skill. Also applicable when: the user wants to compare results from multiple priority models; the user has doubts about the current roadmap and wants to reassess it; resources are limited and requirements need to be cut; the user mentions professional terms such as “RICE,” “ICE,” “Kano,” “priority matrix,” etc. Not applicable for: pure project management (Gantt scheduling), pure requirement documentation writing (using pm‑prd‑writer), pure user research design (using pm‑survey‑designer).
