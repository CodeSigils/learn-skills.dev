Clonez des pages Web en direct dans un projet CSS Next.js + Tailwind local pour un prototypage rapide. Utilisez cette compétence chaque fois qu'un utilisateur partage une URL ou une capture d'écran et souhaite répliquer, reconcevoir ou itérer sur cette page localement - qu'il dise « cloner ce site », « créer un prototype basé sur cette page », « recréer cette interface utilisateur », « créer quelque chose qui ressemble à ceci » ou simplement coller un lien et vous demander de le transformer en code. Se déclenche également lorsque l'utilisateur souhaite ajouter de nouvelles pages, modifier des pages existantes ou étendre un projet prototype précédemment créé par cette compétence. Même si l'utilisateur dit simplement « Je veux créer une page comme X » avec un lien de référence ou une image, cette compétence s'applique.
