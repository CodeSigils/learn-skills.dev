신속한 프로토타이핑을 위해 라이브 웹페이지를 로컬 Next.js + Tailwind CSS 프로젝트로 복제하세요. 사용자가 URL이나 스크린샷을 공유하고 해당 페이지를 로컬에서 복제, 재설계 또는 반복하려고 할 때마다 이 기술을 사용하세요. "이 사이트 복제", "이 페이지를 기반으로 프로토타입 만들기", "이 UI 다시 만들기", "이렇게 보이는 것을 빌드"라고 말하거나 단순히 링크를 붙여넣고 코드로 변환하도록 요청할 때마다 이 기술을 사용하세요. 또한 사용자가 새 페이지를 추가하거나, 기존 페이지를 수정하거나, 이전에 이 기술로 생성된 프로토타입 프로젝트를 확장하려고 할 때 트리거됩니다. 사용자가 단지 참고링크나 이미지를 가지고 "X 같은 페이지를 만들고 싶다"고만 말해도 이 스킬은 적용된다.
