استنساخ صفحات الويب المباشرة في مشروع Next.js + Tailwind CSS المحلي لإنشاء نماذج أولية سريعة. استخدم هذه المهارة عندما يشارك أحد المستخدمين عنوان URL أو لقطة شاشة ويريد نسخ تلك الصفحة أو إعادة تصميمها أو تكرارها محليًا - سواء قال "استنساخ هذا الموقع"، أو "إنشاء نموذج أولي استنادًا إلى هذه الصفحة"، أو "إعادة إنشاء واجهة المستخدم هذه"، أو "إنشاء شيء يبدو مثل هذا"، أو ببساطة لصق رابط ويطلب منك تحويله إلى رمز. يتم التشغيل أيضًا عندما يريد المستخدم إضافة صفحات جديدة، أو تعديل الصفحات الموجودة، أو توسيع مشروع النموذج الأولي الذي تم إنشاؤه مسبقًا بواسطة هذه المهارة. حتى لو قال المستخدم "أريد إنشاء صفحة مثل X" مع رابط أو صورة مرجعية، تنطبق هذه المهارة.
