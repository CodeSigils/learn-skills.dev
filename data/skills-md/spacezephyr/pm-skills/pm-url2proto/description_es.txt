Clone páginas web en vivo en un proyecto local Next.js + Tailwind CSS para crear prototipos rápidamente. Utilice esta habilidad siempre que un usuario comparta una URL o una captura de pantalla y quiera replicar, rediseñar o iterar en esa página localmente, ya sea que diga "clonar este sitio", "crear un prototipo basado en esta página", "recrear esta interfaz de usuario", "construir algo que se parezca a esto" o simplemente pegue un enlace y le pida que lo convierta en código. También se activa cuando el usuario desea agregar nuevas páginas, modificar páginas existentes o ampliar un proyecto prototipo creado previamente por esta habilidad. Incluso si el usuario simplemente dice "Quiero crear una página como X" con un enlace de referencia o una imagen, esta habilidad se aplica.
