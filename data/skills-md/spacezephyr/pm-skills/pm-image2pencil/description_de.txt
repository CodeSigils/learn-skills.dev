Erstellen Sie Screenshots/Designentwürfe als Bleistift-.Stift-Designs neu und geben Sie ein strukturiertes Designdokument auf derselben Leinwand aus. Verwenden Sie diese Fähigkeit, wenn der Benutzer sagt: „Entsprechend dem Bild neu erstellen“, „Seite anhand des Screenshots zeichnen“, „Bild in Bleistift umwandeln“, „Eine identische Seite erstellen“, „Designentwurf basierend auf diesem Bild erstellen“ oder „Designdiagramm und Dokument ausgeben“. Dies gilt auch, wenn der Benutzer eine vorhandene .pen-Seite ändern, auf der rechten Seite ein Designdokument hinzufügen, eine Ausrichtung auf Pixelebene durchführen oder eine Reihe von Seiten aus mehreren Screenshots zusammenführen möchte. Dieser Skill muss das Pencil MCP-Tool aufrufen, um Lesen, Zeichnen und Screenshot-Überprüfung durchzuführen; Wenn die Informationen unvollständig sind, fordern Sie zunächst die fehlenden Details vom Benutzer an, bevor Sie mit der Zeichnung beginnen.
