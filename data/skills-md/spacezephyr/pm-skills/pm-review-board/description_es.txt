Simule una reunión de revisión de prototipos/PRD con funciones múltiples, proporcionando conclusiones de la revisión desde seis perspectivas: producto, desarrollo, pruebas, diseño, operaciones y legal. Se activa cuando el usuario dice "ayúdame a revisar este PRD", "verifica si hay algún problema con este requisito", "simula una reunión de revisión", "revisa este documento", "este requisito puede pasar la revisión", "ayúdame a encontrar lagunas", etc.

También aplicable cuando: el usuario sube un PRD, documento de requisitos, capturas de pantalla de prototipo o descripción funcional y solicita una inspección; el usuario menciona palabras clave como “revisar”, “revisar”, “aprobar la reunión”, “revisión de requisitos”, “revisión de solución”, etc.; el usuario solicita evaluar la viabilidad de un requisito desde una perspectiva de desarrollo o prueba.

No aplicable a: redacción de un PRD (use pm-prd-writer), revisión pura de código (use revisión de código), recorrido de diseño puro (use crítica de diseño).
