Simulate a multi‑role PRD/prototype review meeting, providing review conclusions from six perspectives: product, development, testing, design, operations, and legal. Trigger when the user says “help me review this PRD,” “check if there’s any problem with this requirement,” “simulate a review meeting,” “review this document,” “can this requirement pass the review,” “help me find gaps,” etc.

Also applicable when: the user uploads a PRD, requirement document, prototype screenshots, or functional description and requests an inspection; the user mentions keywords such as “review,” “review,” “pass the meeting,” “requirement review,” “solution review,” etc.; the user asks to assess feasibility of a requirement from a development or testing perspective.

Not applicable to: writing a PRD (use pm‑prd‑writer), pure code review (use code‑review), pure design walkthrough (use design‑critique).
