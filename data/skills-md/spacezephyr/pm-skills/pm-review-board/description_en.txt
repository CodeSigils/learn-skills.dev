Simulate a multi‑role PRD/prototype review meeting, providing review conclusions from six perspectives: product, development, testing, design, operations, and legal. Triggered when the user says “help me review this PRD,” “check if this requirement has any issues,” “simulate a review meeting,” “review this document,” “can this requirement pass the review,” “help me find gaps,” etc. Also applicable when the user uploads a PRD, requirement document, prototype screenshot, or functional description and asks for inspection; when the user mentions keywords such as “review,” “review,” “pass the meeting,” “requirement review,” “solution review,” etc.; or when the user requests to view the requirement from a development or testing perspective for feasibility. Not applicable for writing PRDs (use pm‑prd‑writer), pure code review (use code‑review), or pure design walkthrough (use design‑critique).
