A/B Experiment Design skill. Starting from the experimental goal, produce a complete experimental plan (hypotheses, grouping, metric system, sample size estimation, stop‑loss rules, decision rules).

Trigger conditions: the user mentions keywords such as “A/B testing”, “AB experiment”, “experiment design”, “control experiment”, “traffic‑splitting experiment”, “gray rollout”, “experiment plan”, “sample size calculation”, “significance testing”, “experiment evaluation”, “p‑value”, “confidence interval”, “MDE”, “statistical power”, “experiment duration”, “stop‑loss rule”, etc.

Also applicable when: the user provides the experimental goal / changeable elements / data scale / duration constraints and requests an experimental plan; the user wants to assess whether an existing experimental design is reasonable; the user wants to define experiment decision criteria and decision rules.

Typical input: experimental goal + changeable elements + current data scale + acceptable experiment duration.

Not applicable: pure data analysis (use pm-analytics), pure instrumentation design (use tracking-spec-writer), pure PRD writing (use pm-prd-writer).
