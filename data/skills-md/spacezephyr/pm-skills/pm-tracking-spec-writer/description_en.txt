Tracking point and metric design solution generator. Starting from product requirements/core flow, it outputs a complete tracking plan document (events, fields, trigger timing, definition explanation, QA validation checklist).

Trigger condition: the user mentions keywords such as “tracking point,” “tracking,” “event design,” “data collection,” “reporting scheme,” “tracking plan,” “event specification,” “field design,” “metric definition,” “data acceptance,” “QA validation,” etc.

Also applicable to: the user provides a product PRD/requirements document and requests a tracking plan; the user provides a core user flow and asks to break down events; the user requests standardized event naming or field definitions; the user requests a data acceptance plan.

Typical input: event naming specification + field dictionary + core flow description/flowchart.

Not applicable to: pure data analysis (use pm‑analytics), pure BI dashboard construction, pure SQL query writing.
