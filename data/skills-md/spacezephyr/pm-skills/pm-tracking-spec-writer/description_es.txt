Seguimiento y Generador de Plan de Diseño de KPI. A partir de los requisitos del producto o los flujos de usuarios principales, produce un documento de plan de seguimiento completo (eventos, campos, tiempos de activación, especificaciones de definición, lista de verificación de validación de calidad).

Condición de activación: el usuario menciona palabras clave como "埋点" (seguimiento), "seguimiento", "diseño de evento", "recopilación de datos", "plan de informes", "plan de seguimiento", "especificación de evento", "diseño de campo", "definición de KPI", "aceptación de datos", "validación de calidad", etc.

También aplicable cuando: el usuario proporciona un documento PRD/requisitos del producto y solicita un plan de seguimiento; el usuario proporciona un flujo de usuarios central y necesita eventos desglosados; el usuario solicita nombres de eventos o definiciones de campos estandarizados; el usuario solicita un plan de aceptación de datos.

Entrada típica: convenciones de nomenclatura de eventos + diccionario de campos + descripción/diagrama de flujo del flujo principal.

No aplicable a: análisis de datos puro (usando pm-analytics), creación de paneles de BI puro, escritura de consultas SQL pura.
