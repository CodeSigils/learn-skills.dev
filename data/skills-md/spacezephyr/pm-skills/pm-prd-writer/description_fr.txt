Transformez des exigences vagues en un document d'exigences de produit (PRD) révisable. Utilisez cette compétence lorsque l'utilisateur dit « rédiger un document d'exigences », « aidez-moi à créer un PRD », « comment rédiger des exigences pour cette fonctionnalité », « J'ai une idée que je souhaite mettre en œuvre », « organiser cette exigence dans un document », « PRD nécessaire pour la révision des exigences » ou lorsque l'utilisateur décrit une fonctionnalité mais qu'elle n'est pas structurée.

Applicable également : l'utilisateur télécharge des descriptions brutes des exigences/des procès-verbaux de réunion/des captures d'écran de chat et demande de les organiser dans un PRD ; l'utilisateur mentionne des mots-clés tels que « PRD », « exigences produit », « document d'exigence », « spécification fonctionnelle » ; l'utilisateur demande de compléter, d'optimiser ou de combler les lacunes d'un PRD existant.

Non applicable : conception de solution technique pure (utiliser l'architecture), annotation pure de maquette d'interface utilisateur (utiliser le transfert de conception), documents de gestion de projet (utiliser le rapport d'état).
