Transforme los requisitos vagos en un documento de requisitos del producto (PRD) revisable. Utilice esta habilidad cuando el usuario diga "escriba un documento de requisitos", "ayúdeme a crear un PRD", "cómo escribir requisitos para esta función", "tengo una idea que quiero implementar", "organice este requisito en un documento", "PRD necesario para la revisión de requisitos" o cuando el usuario describa una función pero no esté estructurada.

También aplicable: el usuario carga descripciones de requisitos sin procesar/actas de reuniones/capturas de pantalla de chat y solicita organizarlos en un PRD; el usuario menciona palabras clave como “PRD”, “requisitos del producto”, “documento de requisitos”, “especificación funcional”; el usuario solicita complementar, optimizar o llenar vacíos en un PRD existente.

No aplicable: diseño de solución técnica pura (usar arquitectura), anotación de maqueta de interfaz de usuario pura (usar transferencia de diseño), documentos de gestión de proyectos (usar informe de estado).
