曖昧な要件をレビュー可能な製品要件文書 (PRD) に変換します。このスキルは、ユーザーが「要件ドキュメントを書いてください」、「PRD の作成を手伝ってください」、「この機能の要件の書き方」、「実装したいアイデアがある」、「この要件を文書にまとめてください」、「要件レビューには PRD が必要です」といった場合、またはユーザーが機能について説明しているが構造化されていない場合に使用します。

また適用可能: ユーザーは、生の要件の説明/会議議事録/チャットのスクリーンショットをアップロードし、それらを PRD に整理するよう依頼します。ユーザーは「PRD」、「製品要件」、「要件文書」、「機能仕様」などのキーワードに言及します。ユーザーは、既存の PRD の補完、最適化、またはギャップを埋めることを要求します。

該当なし: 純粋な技術ソリューション設計 (アーキテクチャを使用)、純粋な UI モックアップ アノテーション (設計ハンドオフを使用)、プロジェクト管理ドキュメント (ステータス レポートを使用)。
