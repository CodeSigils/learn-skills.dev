قم بتنظيم تفكيك المنافسين وفقًا لأربعة أبعاد - الإستراتيجية، والوظيفة، والخبرة، والنمو - لإنتاج نصائح قابلة للتنفيذ، وجوانب غير قابلة للنسخ، وتوصيات للتمايز. قم بتطبيق هذه المهارة عندما يقول المستخدم "تحليل المنافس"، أو "تفكيك المنافس"، أو "ساعدني في تحليل المنافسين"، أو "انظر إلى هؤلاء المنافسين"، أو "تحليل المنافس"، أو "قارن مع المنافسين"، أو "التحليل المعياري"، أو "كيفية التمييز"، أو عندما يقدم المستخدم قائمة بالمنافسين ويطلب تحليلاً منهجيًا. وينطبق أيضًا عندما يقوم المستخدم بتحميل لقطات شاشة أو روابط أو تقارير تجربة للمنافس ويطلب تفصيلاً منظمًا؛ عندما يريد المستخدم مقارنة منتجه مع المنافسين؛ أو عندما يبحث المستخدم عن نقاط دخول التمايز. ولا ينطبق على كتابة مستندات المتطلبات البحتة (استخدم PM-PRD-writer)، أو ترتيب الأولويات البحت (استخدم محرك تحديد الأولويات PM)، أو تصميم بحث المستخدم النقي (استخدم PM-survey-designer).
