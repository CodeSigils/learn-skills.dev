Начиная с данных, создавайте действенные рекомендации по выбору продукта и выводите их в виде визуальных отчетов HTML. Запускается, когда пользователь говорит: «Проанализируйте этот набор данных», «Почему эта метрика упала», «Помогите мне провести анализ удержания», «В чем причина оттока пользователей», «Какой этап воронки снижается» или «дайте мне отчет об анализе данных». Также применимо, когда: пользователь загружает файл данных CSV/Excel и запрашивает аналитическую информацию; пользователь предоставляет результаты SQL-запроса и запрашивает интерпретацию; пользователь запрашивает декомпозицию метрик, анализ атрибуции, когортное сравнение, анализ эксперимента A/B; пользователь упоминает ключевые слова для анализа данных, такие как «дерево показателей», «воронка», «удержание», «коэффициент конверсии», «снижение DAU», «когорта», «атрибуция». Не применимо к: чистому построению информационной панели BI (с использованием xlsx), чистому написанию SQL (напрямую), чистой очистке данных (непосредственному написанию скриптов).
