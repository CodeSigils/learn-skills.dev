À partir des phénomènes de données, générez des recommandations de décision de produit exploitables et générez-les sous forme de rapports HTML visuels. Déclenché lorsque l'utilisateur dit « analyser cet ensemble de données », « pourquoi cette métrique a-t-il chuté », « aidez-moi à faire une analyse de rétention », « quelle est la raison de l'attrition des utilisateurs », « quelle étape de l'entonnoir est abandonnée » ou « donnez-moi un rapport d'analyse des données ». Applicable également lorsque : l'utilisateur télécharge un fichier de données CSV/Excel et demande des informations analytiques ; l'utilisateur fournit les résultats de la requête SQL et demande une interprétation ; l'utilisateur demande une décomposition métrique, une analyse d'attribution, une comparaison de cohortes, une analyse d'expérience A/B ; l'utilisateur mentionne des mots-clés d'analyse de données tels que « arbre métrique », « entonnoir », « rétention », « taux de conversion », « déclin des DAU », « cohorte », « attribution ». Non applicable à : la création de tableaux de bord BI purs (à l'aide de xlsx), l'écriture SQL pure (directement), le nettoyage de données pur (écriture directe de scripts).
