Starting from data phenomena, generate actionable product decision recommendations and output them as visual HTML reports. This is triggered when the user says “Analyze this dataset,” “Why did this metric drop,” “Help me do a retention analysis,” “What are the reasons for user churn,” “See which step in the funnel dropped off,” or “Give me a data analysis report.”  

It also applies when: the user uploads CSV/Excel data files and requests analytical insights; the user provides SQL query results and asks for interpretation; the user requests metric decomposition, attribution analysis, cohort comparison, or A/B experiment analysis; the user mentions data‑analysis keywords such as “metric tree,” “funnel,” “retention,” “conversion rate,” “DAU decline,” “cohort,” or “attribution.”  

It does not apply to: pure BI dashboard building (using XLSX), pure SQL writing (directly writing queries), or pure data cleaning (directly writing scripts).
