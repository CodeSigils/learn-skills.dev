Partendo dai fenomeni dei dati, genera consigli attuabili sulle decisioni sui prodotti e generali come report visivi HTML. Si attiva quando l'utente dice "analizza questo set di dati", "perché questa metrica è diminuita", "aiutami a fare un'analisi di fidelizzazione", "qual è il motivo dell'abbandono dell'utente", "quale passaggio nella canalizzazione sta cadendo" o "dammi un rapporto di analisi dei dati". Applicabile anche quando: l'utente carica un file di dati CSV/Excel e richiede approfondimenti analitici; l'utente fornisce i risultati della query SQL e chiede l'interpretazione; l'utente richiede la scomposizione metrica, l'analisi di attribuzione, il confronto di coorte, l'analisi dell'esperimento A/B; l'utente menziona parole chiave per l'analisi dei dati come "albero metrico", "imbuto", "fidelizzazione", "tasso di conversione", "rifiuto DAU", "coorte", "attribuzione". Non applicabile a: pura creazione di dashboard BI (utilizzando xlsx), pura scrittura SQL (direttamente), pura pulizia dei dati (scrittura diretta di script).
