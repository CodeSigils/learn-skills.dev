بدءًا من ظواهر البيانات، قم بإنشاء توصيات قابلة للتنفيذ بشأن قرارات المنتج وإخراجها كتقارير HTML مرئية. يتم تشغيله عندما يقول المستخدم "تحليل مجموعة البيانات هذه"، أو "لماذا انخفض هذا المقياس"، أو "ساعدني في إجراء تحليل للاحتفاظ"، أو "ما سبب توقف المستخدم"، أو "أي خطوة في مسار التحويل تنخفض"، أو "أعطني تقرير تحليل البيانات". ينطبق أيضًا عندما: يقوم المستخدم بتحميل ملف بيانات CSV/Excel ويطلب رؤى تحليلية؛ يقدم المستخدم نتائج استعلام SQL ويطلب التفسير؛ يطلب المستخدم تحليل المقاييس، وتحليل الإسناد، ومقارنة الأتراب، وتحليل تجربة أ/ب؛ يذكر المستخدم الكلمات الرئيسية لتحليل البيانات مثل "شجرة القياس"، و"مسار التحويل"، و"الاحتفاظ"، و"معدل التحويل"، و"انخفاض عدد المستخدمين النشطين يوميًا"، و"المجموعة النموذجية"، و"الإسناد". لا ينطبق على: إنشاء لوحة معلومات BI خالصة (باستخدام xlsx)، وكتابة SQL خالصة (مباشرة)، وتنظيف البيانات النقية (كتابة البرامج النصية مباشرة).
