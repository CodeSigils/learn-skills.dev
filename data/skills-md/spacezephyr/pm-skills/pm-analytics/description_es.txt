A partir de fenómenos de datos, genere recomendaciones de decisiones de productos procesables y envíelas como informes HTML visuales. Se activa cuando el usuario dice "analiza este conjunto de datos", "por qué cayó esta métrica", "ayúdame a hacer un análisis de retención", "cuál es el motivo de la pérdida de usuarios", "qué paso del embudo está cayendo" o "dame un informe de análisis de datos". También se aplica cuando: el usuario carga un archivo de datos CSV/Excel y solicita información analítica; el usuario proporciona resultados de consultas SQL y solicita interpretación; el usuario solicita descomposición de métricas, análisis de atribución, comparación de cohortes, análisis de experimentos A/B; el usuario menciona palabras clave de análisis de datos como "árbol de métricas", "embudo", "retención", "tasa de conversión", "disminución de DAU", "cohorte", "atribución". No aplicable a: creación pura de paneles de BI (usando xlsx), escritura SQL pura (directamente), limpieza de datos pura (escribiendo scripts directamente).
