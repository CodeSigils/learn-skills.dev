Career Skill Factory 2.0 (upgraded version of career-skill-planner). When a user inputs a profession or industry, this Skill automatically performs:
1) Select three top experts in that industry, distill their mental models and decision-making processes, and generate three expert-perspective Skills (referencing the Nüwa methodology);
2) Select three premier books in that industry, distill them into actionable methodologies, and generate three methodology Skills (referencing the book2skills methodology);
3) Generate one overarching Consultant Group Control Skill that orchestrates the experts and methodologies into a consultative team capable of holding an "expert review meeting."

The final deliverable consists of seven directly installable Skill files.

Trigger scenarios: the user says "Help me create an expert advisory group for the XX industry," "Create a set of Skills for the XX profession," "I am XX, help me build an advisory group," "Career Skill 2.0," "Distill the XX industry," "Methodology Skill for the XX industry," or provides a JD (job description) from which to build the team.
