Career Skill Factory 2.0 (aktualisierte Version des Career-Skill-Planners). Wenn ein Benutzer einen Beruf oder eine Branche eingibt, führt dieser Skill automatisch Folgendes aus:
1) Wählen Sie drei Top-Experten in dieser Branche aus, destillieren Sie ihre mentalen Modelle und Entscheidungsprozesse und entwickeln Sie drei Fähigkeiten aus Expertenperspektive (unter Bezugnahme auf die Nüwa-Methodik);
2) Wählen Sie drei erstklassige Bücher in dieser Branche aus, destillieren Sie sie in umsetzbare Methoden und generieren Sie drei Methodenkompetenzen (unter Bezugnahme auf die book2skills-Methodik);
3) Generieren Sie eine übergreifende Fähigkeit zur Kontrolle der Beratergruppe, die die Experten und Methoden zu einem Beratungsteam orchestriert, das in der Lage ist, ein „Expertenbewertungstreffen“ abzuhalten.

Das endgültige Ergebnis besteht aus sieben direkt installierbaren Skill-Dateien.

Auslöseszenarien: Der Benutzer sagt „Helfen Sie mir, eine Expertenberatungsgruppe für die XX-Branche zu erstellen“, „Erstellen Sie eine Reihe von Fähigkeiten für den XX-Beruf“, „Ich bin XX, helfen Sie mir beim Aufbau einer Beratergruppe“, „Karrierekompetenz 2.0“, „Destillieren Sie die XX-Branche“, „Methodologiekompetenz für die XX-Branche“ oder stellt eine JD (Stellenbeschreibung) bereit, aus der das Team aufgebaut werden soll.
