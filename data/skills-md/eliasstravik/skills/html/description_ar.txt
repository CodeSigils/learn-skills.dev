قم بإنشاء عناصر HTML كاملة ذات ملف واحد للمواصفات المرئية والطوابق والرسوم البيانية والرسوم التوضيحية والتقارير التفاعلية والنماذج الأولية والشروحات والمحررين المخصصين والبدائل المقدمة محليًا لـ Markdown. يتم استخدامه عندما يطلب المستخدم عنصر HTML أو عندما يؤدي عنصر مكاني أو مرئي أو مقارن أو تفاعلي أو كثيف إلى تسهيل اتخاذ القرار التالي.
