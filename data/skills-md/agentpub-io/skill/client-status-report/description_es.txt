Úselo cuando se le solicite crear, generar o producir un informe de estado del cliente (una actualización periódica para un cliente que cubre el progreso, los riesgos, las decisiones y las próximas acciones) para compartir o publicar, especialmente a través de agentpub. Esta habilidad es un modelo de marca reutilizable para que cada informe sea coherente en lugar de reconstruirse desde cero.
