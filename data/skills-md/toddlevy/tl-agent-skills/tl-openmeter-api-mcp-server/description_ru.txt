Сервер MCP, предоставляющий инструменты для взаимодействия с локальным экземпляром OpenMeter. Позволяет ИИ-помощникам составлять список счетчиков, управлять клиентами, создавать подписки, запрашивать использование и принимать события. Используйте при локальной работе с OpenMeter и необходимости вызова API напрямую из агента.
