Serveur MCP fournissant des outils pour interagir avec une instance OpenMeter locale. Permet aux assistants IA de répertorier les compteurs, de gérer les clients, de créer des abonnements, d'interroger l'utilisation et d'ingérer des événements. À utiliser lorsque vous travaillez avec OpenMeter localement et que vous devez appeler l'API directement depuis l'agent.
