MCP-Server, der Tools für die Interaktion mit einer lokalen OpenMeter-Instanz bereitstellt. Ermöglicht KI-Assistenten, Zähler aufzulisten, Kunden zu verwalten, Abonnements zu erstellen, die Nutzung abzufragen und Ereignisse aufzunehmen. Verwenden Sie diese Option, wenn Sie lokal mit OpenMeter arbeiten und die API direkt vom Agenten aufrufen müssen.
