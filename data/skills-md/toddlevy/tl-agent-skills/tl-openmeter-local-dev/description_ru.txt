Настройте и устраните неполадки OpenMeter для локальной разработки с помощью Docker, ngrok, приложения Stripe и конфигурации веб-перехватчика. Охватывает различия между самостоятельным размещением и облаком, синхронизацию каталога, обработку веб-перехватчиков с учетом среды и приложения OpenMeter (Stripe, Sandbox). Используйте при локальной настройке OpenMeter, настройке ngrok для веб-перехватчиков, отладке синхронизации каталога или подготовке локальной разработки для соответствия промежуточному/производственному поведению.
