Работает с REST API OpenMeter для измерения использования, выставления счетов и предоставления прав. Охватывает прием CloudEvents, счетчики, функции, планы, клиентов, подписки, права, уведомления, профили выставления счетов, счета, приложения, надстройки, гранты и торговую площадку Stripe. Используйте при интеграции OpenMeter, отладке измерений, создании сценариев синхронизации каталога или когда пользователь упоминает API OpenMeter.
