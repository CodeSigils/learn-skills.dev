Funziona con l'API REST OpenMeter per la misurazione dell'utilizzo, la fatturazione e i diritti. Copre l'acquisizione di CloudEvents, i contatori, le funzionalità, i piani, i clienti, gli abbonamenti, i diritti, le notifiche, i profili di fatturazione, le fatture, le app, i componenti aggiuntivi, le sovvenzioni e il marketplace Stripe. Da utilizzare durante l'integrazione di OpenMeter, il debug della misurazione, la creazione di script di sincronizzazione del catalogo o quando l'utente menziona l'API OpenMeter.
