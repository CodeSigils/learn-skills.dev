Fonctionne avec l'API REST OpenMeter pour la mesure de l'utilisation, la facturation et les droits. Couvre l'ingestion CloudEvents, les compteurs, les fonctionnalités, les plans, les clients, les abonnements, les droits, les notifications, les profils de facturation, les factures, les applications, les modules complémentaires, les subventions et le marché Stripe. À utiliser lors de l'intégration d'OpenMeter, du débogage de la mesure, de la création de scripts de synchronisation de catalogue ou lorsque l'utilisateur mentionne l'API OpenMeter.
