Academic paper formatting assistant based on a standard directory structure. Supports PDF / .doc / .docx / .md input formats, automatically selects OCR pipeline, reformatting pipeline, or direct MD conversion pipeline. Includes environment cleanup confirmation, breakpoint resume, smart image cropping, incremental DOCX generation by unit, dual-unit quality check, intermediate state saving, and BibTeX reference management. All intermediate files go to resources/, final outputs to outputs/.
