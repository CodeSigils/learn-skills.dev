Feature Garden-Architektur für Frontend-Projekte. Verwenden Sie diese Funktion, wenn Sie die Ordnerstruktur organisieren, entscheiden, wo ein Modul gespeichert werden soll, Features erstellen oder verschachteln, gemeinsam genutzte Features extrahieren, Bibliotheken erstellen oder strukturieren, die Durchsetzung von ESLint-Grenzen einrichten (kein Zyklus, Grenzen-Plugin, keine eingeschränkten Importe), ein neues Projekt mit Feature Garden initialisieren oder ältere Module migrieren. Behandelt: Ebenen (Bibliotheken/Features/App), Importregeln, Code-Wiederverwendungsstrategie.
