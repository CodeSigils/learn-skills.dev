ميزة هندسة الحدائق لمشاريع الواجهة الأمامية. يُستخدم عندما: تنظيم بنية المجلد، أو تحديد المكان الذي يجب أن تعيش فيه الوحدة النمطية، أو إنشاء ميزات أو تداخلها، أو استخراج الميزات المشتركة، أو إنشاء مكتبات أو هيكلتها، أو إعداد تطبيق حدود ESLint (بدون دورة، أو مكون إضافي للحدود، أو استيراد غير مقيد)، أو تهيئة مشروع جديد باستخدام حديقة الميزات، أو ترحيل الوحدات النمطية القديمة. الأغطية: الطبقات (libs/الميزات/التطبيق)، قواعد الاستيراد، استراتيجية إعادة استخدام التعليمات البرمجية.
