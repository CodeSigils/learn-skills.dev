Перебазируйте текущую проверку Git на запрошенную удаленную базовую ветвь или удаленную ветвь репозитория по умолчанию, если ни одна из них не названа, без потери локальной работы. Всегда используйте этот навык для реальной операции синхронизации базовой ветки, включая запросы на получение или синхронизацию основной, главной, магистральной ветки или ветки по умолчанию; обновить ветку из своей базы; перебазироваться на удаленную базу; перенести входящие базовые коммиты в текущую проверку; или обновите отдельное рабочее дерево из этой базы.
