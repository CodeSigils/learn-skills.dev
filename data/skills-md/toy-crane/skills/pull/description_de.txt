Rebase des aktuellen Git-Checkouts auf den angeforderten Remote-Basiszweig oder den Remote-Standardzweig des Repositorys, wenn keiner benannt ist, ohne dass lokale Arbeit verloren geht. Verwenden Sie diesen Skill immer für einen tatsächlichen Basis-Branch-Synchronisierungsvorgang, einschließlich Anfragen zum Pullen oder Synchronisieren von Main, Master, Trunk oder dem Standard-Branch; einen Zweig von seiner Basis aus aktualisieren; Rebase auf eine entfernte Basis; eingehende Basis-Commits in den aktuellen Checkout einbringen; oder aktualisieren Sie einen getrennten Arbeitsbaum von dieser Basis.
