Rebasez l'extraction Git actuelle sur la branche de base distante demandée, ou sur la branche distante par défaut du référentiel lorsqu'aucune n'est nommée, sans perdre le travail local. Utilisez toujours cette compétence pour une opération de synchronisation de branche de base réelle, y compris les demandes d'extraction ou de synchronisation de la branche principale, principale, principale ou par défaut ; mettre à jour une branche depuis sa base ; rebaser sur une base distante ; amener les commits de base entrants dans la caisse actuelle ; ou mettez à jour un arbre de travail détaché de cette base.
