Vuelva a establecer la base de pago de Git actual en la rama base remota solicitada, o en la rama remota predeterminada del repositorio cuando no se nombre ninguna, sin perder el trabajo local. Utilice siempre esta habilidad para una operación de sincronización de rama base real, incluidas solicitudes para extraer o sincronizar la rama principal, maestra, troncal o predeterminada; actualizar una rama desde su base; cambiar de base a una base remota; traer las confirmaciones base entrantes al pago actual; o actualizar un árbol de trabajo separado de esa base.
