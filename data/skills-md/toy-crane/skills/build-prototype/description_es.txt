Cree un prototipo HTML de datos ficticios de superficie completa para que el usuario se alinee con la interfaz de usuario reaccionando a las pantallas en lugar de a la prosa. Úselo cuando el usuario quiera crear un prototipo, simular o ver las pantallas de un producto o característica antes de la implementación, cuando sigue faltando la discusión sobre la interfaz de usuario en palabras o cuando una idea de forma deja de lado una pregunta experiencial que superó las variantes.
