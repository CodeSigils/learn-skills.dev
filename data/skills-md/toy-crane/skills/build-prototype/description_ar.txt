أنشئ نموذجًا أوليًا بتنسيق HTML كامل السطح وبيانات وهمية بحيث يقوم المستخدم بمحاذاة واجهة المستخدم من خلال التفاعل مع الشاشات بدلاً من النثر. يُستخدم عندما يريد المستخدم إنشاء نموذج أولي أو محاكاة أو رؤية شاشات منتج أو ميزة قبل التنفيذ، أو عندما تظل مناقشة واجهة المستخدم بالكلمات مفقودة، أو عندما تطرح فكرة الشكل سؤالًا تجريبيًا يتجاوز المتغيرات.
