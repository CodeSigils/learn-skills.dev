Решите документально подтвержденные файлы `docs/follow-ups/*.md` с помощью ограниченного руководства, запланированной задачи Кодекса или стандартной проверки Claude. Используйте, когда последующие действия по проекту должны быть воспроизведены перед редактированием, обработаны одним изолированным исполнителем и ветвью для каждого элемента и опубликованы как независимые, готовые к рассмотрению запросы на включение без автоматического слияния. Не используйте для создания предполагаемого поведения или просто для записи недавно обнаруженного последующего действия.
