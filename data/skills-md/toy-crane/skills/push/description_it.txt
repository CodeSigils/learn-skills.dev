Pubblica commit Git locali su un ramo denominato senza perdere il lavoro locale o remoto. Utilizza sempre questa competenza per la pubblicazione effettiva di un ramo Git, comprese le richieste di push, pubblicazione, caricamento o inserimento del checkout corrente o distaccato su Origin o su un altro Git remoto. Usalo per la pubblicazione di HEAD distaccato e gli aggiornamenti protetti dal lease post-rebase; spinge solo i commit esistenti e non effettua il commit di modifiche sporche, non crea un PR o non si unisce.
