نشر التزامات Git المحلية على فرع مسمى دون فقدان العمل المحلي أو البعيد. استخدم دائمًا هذه المهارة لمنشور فرع Git الفعلي، بما في ذلك طلبات الدفع أو النشر أو التحميل أو وضع عملية الدفع الحالية أو المنفصلة على الأصل أو جهاز تحكم عن بعد آخر لـ Git. استخدمه لنشر HEAD المنفصل والتحديثات المحمية بموجب عقد الإيجار بعد إعادة التأسيس؛ إنه يدفع الالتزامات الحالية فقط ولا يرتكب تغييرات قذرة أو ينشئ علاقات عامة أو يدمج.
