Publique confirmaciones de Git locales en una rama con nombre sin perder el trabajo local o remoto. Utilice siempre esta habilidad para una publicación de rama de Git real, incluidas solicitudes para enviar, publicar, cargar o colocar el pago actual o separado en origen u otro control remoto de Git. Úselo para publicaciones HEAD separadas y actualizaciones protegidas por arrendamiento posteriores a la rebase; solo impulsa las confirmaciones existentes y no realiza cambios sucios, no crea un PR ni se fusiona.
