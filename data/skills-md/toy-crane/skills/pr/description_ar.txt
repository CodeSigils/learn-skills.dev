انشر تغيير المستودع الحالي كطلب سحب GitHub جاهز للمراجعة مقابل القاعدة المطلوبة، أو الفرع الافتراضي البعيد للمستودع عند عدم تسمية أي شيء. استخدم دائمًا هذه المهارة لمنشور علاقات عامة فعلي، بما في ذلك طلبات إنشاء طلب سحب أو فتحه أو رفعه أو نشره أو إعادة استخدامه، أو طرح العمل للمراجعة، أو إنشاء رابط مراجعة GitHub ومشاركته. أكمل الالتزام المطلوب، والمزامنة الأساسية، ونشر الفرع، ولكن توقف قبل الدمج.
