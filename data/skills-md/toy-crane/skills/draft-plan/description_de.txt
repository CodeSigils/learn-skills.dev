Entwerfen Sie vor der Implementierung einen überprüfbaren Implementierungsplan (plan.md) aus einem Spezifikationsordner. Verwenden Sie diese Option, wenn das Wie einer Überprüfung bedarf: mehrere plausible Ansätze, Bereiche, die nicht berührt werden dürfen, wahrscheinliche Wiederholungsversuche oder Delegationen oder Überprüfungskriterien, die es wert sind, festgelegt zu werden. Benötigt einen vorhandenen Spezifikationsordner; Wenn Sie eine Arbeit mit einem offensichtlichen Ansatz für eine Sitzung benötigen, überspringen Sie sie und führen Sie sie direkt aus der Spezifikation aus.
