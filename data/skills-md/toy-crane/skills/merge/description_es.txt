Lleve el cambio del repositorio actual a través de una combinación de solicitud de extracción verificada de GitHub a la base solicitada, o a la rama predeterminada remota del repositorio cuando no se nombre ninguna, luego limpie solo el árbol de trabajo combinado y sus propios procesos de desarrollo. Utilice siempre esta habilidad para una fusión de PR real o su limpieza posterior a la fusión, incluidas solicitudes para inspeccionar, terminar, aterrizar o fusionar un PR existente; crear un PR y fusionarlo; preservar compromisos significativos; o limpiar un árbol de trabajo ya fusionado. Informe una combinación existente en lugar de duplicarla.
