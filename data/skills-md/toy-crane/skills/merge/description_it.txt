Trasporta la modifica corrente del repository tramite un'unione verificata della richiesta pull GitHub nella base richiesta o nel ramo remoto predefinito del repository quando non ne viene nominato nessuno, quindi pulisci solo l'albero di lavoro unito e i relativi processi di sviluppo di proprietà. Usa sempre questa abilità per un'effettiva fusione di PR o per la sua pulizia post-fusione, comprese le richieste di ispezionare, completare, atterrare o unire un PR esistente; creare un PR e unirlo; preservare commit significativi; o ripulire un albero di lavoro già unito. Segnala un'unione esistente invece di duplicarla.
