Effectuez la modification actuelle du référentiel via une fusion de demande d'extraction GitHub vérifiée dans la base demandée, ou dans la branche distante par défaut du référentiel lorsqu'aucune n'est nommée, puis nettoyez uniquement l'arbre de travail fusionné et ses processus de développement détenus. Utilisez toujours cette compétence pour une fusion de PR réelle ou son nettoyage après la fusion, y compris les demandes d'inspection, de finition, d'atterrissage ou de fusion d'un PR existant ; créer un PR et le fusionner ; préserver les engagements significatifs ; ou nettoyer un arbre de travail déjà fusionné. Signalez une fusion existante au lieu de la dupliquer.
