Prüfen und installieren Sie den offiziellen Agentenkontext für die Technologien, die den Stack eines Projekts definieren. Verwenden Sie diese Option, wenn Sie ein Projekt für die Agentenarbeit einrichten, nachdem Sie ein Framework, eine Bibliothek, ein Entwicklertool oder einen gehosteten Dienst ausgewählt oder hinzugefügt haben, oder wenn Sie ein vorhandenes Projekt eingeben, dessen offizieller Agentenkontext nicht geprüft wurde.
