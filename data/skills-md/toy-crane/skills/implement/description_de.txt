Erledigte Arbeiten aus einem ausgewählten Spezifikationsordner implementieren oder fortsetzen. Wird verwendet, wenn der Benutzer einen Ordner „docs/specs/SLUG/“ bereitstellt und möchte, dass seine festgelegte Spezifikation oder genehmigte Aufgaben im aktuellen Checkout mit Überprüfung, dem automatisierten Codeüberprüfungsprozess des aktuellen Harness und einer ausführbaren Produktübergabe abgeschlossen werden, wenn das Repository eine über einen lokalen Server verfügbar macht.
