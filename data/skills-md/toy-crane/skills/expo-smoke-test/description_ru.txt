Проверьте изменение Expo или React Native вместе с основным циклом приложения на iOS и Android с помощью агента-устройства. Используйте перед внесением изменения, когда пользователь запрашивает подтверждение поведения на обеих платформах или когда основной цикл должен быть повторен в качестве регрессии. Установите готовность среды выполнения и явный профиль состояния, скоординируйте общие предварительные требования, затем создайте ровно два изолированных субагента платформы (предпочитайте установленный профиль expo-smoke-runner), дождитесь обоих и завершите только с отдельными свидетельствами времени выполнения для каждой платформы. Для проверки одного изменения в одной цели во время обычного редактирования используйте вместо этого expo-dev-loop.
