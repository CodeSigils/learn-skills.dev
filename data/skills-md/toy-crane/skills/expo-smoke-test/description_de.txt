Überprüfen Sie eine Expo- oder React Native-Änderung zusammen mit der Kernschleife der App auf iOS und Android mithilfe von agent-device. Verwenden Sie diese Funktion, bevor Sie eine Änderung bereitstellen, wenn der Benutzer das Verhalten auf beiden Plattformen bestätigen möchte oder wenn die Kernschleife erneut als Regression ausgeführt werden soll. Stellen Sie Laufzeitbereitschaft und ein explizites Statusprofil her, koordinieren Sie gemeinsame Voraussetzungen, erzeugen Sie dann genau zwei isolierte Plattform-Subagenten – vorzugsweise das installierte Expo-Smoke-Runner-Profil –, warten Sie auf beide und beenden Sie den Vorgang nur mit separaten Laufzeitnachweisen für jede Plattform. Um eine Änderung an einem einzelnen Ziel während der normalen Bearbeitung zu überprüfen, verwenden Sie stattdessen expo-dev-loop.
