إنشاء التزامات Git للتغييرات داخل نطاق الطلب الحالي باعتبارها التزامات تقليدية منطقية. استخدم هذه المهارة دائمًا لعملية التزام Git الفعلية، بما في ذلك طلبات الالتزام بالتغييرات أو تعديلها، أو حفظ العمل في محفوظات المستودع، أو تنظيم الملفات المحددة وتسجيلها، أو مجموعة التغييرات المرحلية أو غير المرحلية في عمليات الالتزام. استخدمه حتى عندما يصف الطلب تسجيل التغييرات دون قول "الالتزام"؛ فهو ينفذ الالتزام بدلاً من اقتراح رسالة فقط، ولا يدفع.
