Cree confirmaciones de Git para los cambios dentro del alcance de la solicitud actual como confirmaciones convencionales lógicas. Utilice siempre esta habilidad para una operación de confirmación de Git real, incluidas solicitudes para confirmar o modificar cambios, guardar trabajo en el historial del repositorio, preparar y registrar archivos seleccionados, o agrupar cambios preparados o no preparados en confirmaciones. Úselo incluso cuando la solicitud describa cambios de grabación sin decir "confirmar"; realiza la confirmación en lugar de solo sugerir un mensaje y no presiona.
