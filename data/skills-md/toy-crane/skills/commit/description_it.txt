Crea commit Git per le modifiche nell'ambito della richiesta corrente come commit logici convenzionali. Utilizza sempre questa competenza per un'effettiva operazione di commit Git, comprese le richieste di commit o modifica di modifiche, salvataggio del lavoro nella cronologia del repository, gestione di stage e registrazione di file selezionati o gruppo di modifiche con o senza stage nei commit. Usatelo anche quando la richiesta descrive la registrazione delle modifiche senza dire "impegna"; esegue il commit anziché limitarsi a suggerire un messaggio e non esegue push.
