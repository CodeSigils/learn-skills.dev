قم بكتابة Python وإعادة تصميمه ومراجعته باستخدام مصطلحات Pythonic الحالية والمتحقق منها بدلاً من أنماط Java أو C أو JavaScript المستوردة. يُستخدم عند تحديد ما هو Pythonic مقابل غير Pythonic في وحدات Python والبرامج النصية والاختبارات والدفاتر وCLIs والمكتبات وواجهات برمجة التطبيقات؛ عند مراجعة التكرار، والفهم، والصدق، والاستثناءات، والتعيينات، والموارد، ومعالجة السلسلة والمسار، والطفرات، والكتابة، وتصميم الكائنات، والواردات، ومطابقة الأنماط الهيكلية؛ ومتى يجب التحقق من دعم إصدار Python قبل التوصية بميزات البنية الحديثة أو المكتبة القياسية.
