インポートされた Java、C、または JavaScript パターンの代わりに、現在検証済みの Python のイディオムを使用して、Python を作成、リファクタリング、レビューします。 Python モジュール、スクリプト、テスト、ノートブック、CLI、ライブラリ、API において何が Python 的であるか、非 Python 的であるかを判断するときに使用します。反復、内包表記、真実性、例外、マッピング、リソース、文字列とパスの処理、突然変異、型指定、オブジェクト設計、インポート、構造パターン マッチングをレビューするとき。最新の構文や標準ライブラリの機能を推奨する前に、Python バージョンのサポートを確認する必要がある場合。
