Úselo al agregar o aplicar reglas de pelusa como parte de un plan de prueba o verificación. Amplía la estrategia de prueba con orientación específica de Lint: selección de reglas, ubicación de puertas, clasificación de fallas y planificación de migración al introducir reglas a una base de código existente. NO lo use de forma independiente (cargue la habilidad de estrategia de prueba básica junto con él) y NO lo use para buscar una falla de pelusa específica en un archivo (es decir, depuración).
