À utiliser lors de l’ajout ou de l’application de règles de charpie dans le cadre d’un plan de test ou de vérification. Étend la stratégie de test avec des conseils spécifiques aux lint : sélection des règles, placement des portes, triage des échecs et planification de la migration lors de l'introduction de règles dans une base de code existante. N'utilisez PAS de manière autonome - chargez la compétence de stratégie de test de base à côté - et ne l'utilisez PAS pour rechercher une défaillance de charpie spécifique dans un fichier (c'est-à-dire le débogage).
