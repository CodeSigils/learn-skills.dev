Úselo al diseñar o auditar sistemas de íconos, colores/insignias/formas, metáforas visuales, signos de interfaz o superficies de nombres más visuales que los usuarios malinterpretan. Cubre el razonamiento semiótico a través de ícono/índice/símbolo, significante/significado, denotación/connotación/mito, color/forma/posición/iconografía, posibilidades, código/significantes API y auditorías de coherencia semiótica. NO lo use para redacción de interfaz de usuario real (use "microcopia"), paleta/tipografía (use "fundamentos de diseño visual"), accesibilidad o cumplimiento de contraste (use "a11y"), jerarquías de clases formales o reglas de morfología de palabras.
