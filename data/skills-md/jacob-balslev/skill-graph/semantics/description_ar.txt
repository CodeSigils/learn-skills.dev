يُستخدم عند تسمية العناصر عبر التعليمات البرمجية، أو واجهات برمجة التطبيقات، أو رموز التصميم، أو الالتزامات، أو إشارات الحالة/HTTP، أو تسميات واجهة المستخدم، أو رموز الخطأ، أو الأنواع ذات العلامات التجارية، خاصة عندما يبدو الاسم غامضًا أو مضللاً. يغطي ترميز المعنى عبر المجالات: تسمية الروائح، ولغة DDD المنتشرة في كل مكان، وSemVer، والالتزامات التقليدية، والأنواع ذات العلامات التجارية، ورموز التصميم الدلالي/CSS/واجهات برمجة التطبيقات، وإمكانيات واجهة المستخدم الدلالية، وتسمية الأنماط المضادة. لا تستخدمه مع شكل الكلمات/تعدد المعاني (استخدم اللغويات)، أو تنسيقات غلاف الأحرف (استخدم اصطلاحات التسمية)، أو علاقات المفاهيم المكتوبة (استخدم العلاقات الدلالية)، أو أنماط نص واجهة المستخدم داخل المنتج (استخدم النسخة المصغرة).
