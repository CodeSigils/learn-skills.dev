يُستخدم عند تصميم أو مراجعة أسطح واجهة برمجة التطبيقات: الموارد/الإجراءات، ومخططات الطلب والاستجابة، ورموز الحالة، وترقيم الصفحات، والتصفية، والقصور، والإصدار، وحدود المصادقة، ومغلفات الأخطاء. لا تستخدمه مع عقود نظام غير HTTP (استخدم "عقود واجهة النظام")، أو عقود الأحداث غير المتزامنة (استخدم "تصميم عقد الحدث")، أو تصميم قاعدة البيانات (استخدم "نمذجة البيانات")، أو آليات الرد التلقائي على الويب للموفر الداخلي (استخدم "تكامل الخطاف الويب").
