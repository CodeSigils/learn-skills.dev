Úselo al diseñar o revisar superficies de API: recursos/acciones, esquemas de solicitud y respuesta, códigos de estado, paginación, filtrado, idempotencia, control de versiones, límites de autenticación y sobres de error. NO lo use para contratos de sistema que no sean HTTP (use "contratos de interfaz de sistema"), contratos de eventos asíncronos (use "diseño de contrato de evento"), diseño de bases de datos (use "modelado de datos") o mecánicas de webhook de proveedores entrantes (use "integración de webhook").
