À utiliser lorsque vous travaillez avec Shopify : API Admin, API Storefront, étendues OAuth, vérification du webhook HMAC SHA-256, gestion des coûts des requêtes GraphQL, thèmes de la boutique en ligne 2.0 (sections, blocs, Liquid), métachamps et métaobjets, et proxy d'application. Ne PAS utiliser pour la conception générique de commerce électronique, les vitrines non-Shopify ou la conception de contrats d'événements internes.
