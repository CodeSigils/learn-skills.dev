Verwenden Sie diese Option, wenn Sie ein neues SKILL.md von Grund auf erstellen, einen vorhandenen Skill an einen anderen Archetyp anpassen oder einem anderen Autor die kanonische Skill Metadata Protocol-Frontmaterie und -Körperstruktur beibringen. Behandelt schemakonformes Frontmaterial, archetypbewusstes Körperlayout, Disziplin auf semantischer Ebene (Beschreibung vs. Abdeckung), Mechanik auf Lehrebene (Blockzitate VORLAGE ANMERKUNG), das Lint-First-Authoring-Gate und die Ehrlichkeitsregel zur Routing-Bewertung. NICHT verwenden, wenn Sie einen bereits geschriebenen Skill ändern (direkt bearbeiten), wenn Sie allgemeine technische Dokumentation schreiben (verwenden Sie „Dokumentation“) oder wenn Sie einen durch Lint erkannten fehlerhaften Skill reparieren (verwenden Sie „graph-audit“ für den systematischen Zustand der Bibliothek, nicht für die Erstellung von Gerüsthilfen).
