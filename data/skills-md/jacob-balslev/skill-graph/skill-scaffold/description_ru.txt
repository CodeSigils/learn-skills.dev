Используйте при создании нового SKILL.md с нуля, адаптации существующего навыка к другому архетипу или при обучении другого автора каноническому фронтмену и структуре тела протокола метаданных навыков. Охватывает соответствующую схеме вступительную часть, структуру тела с учетом архетипов, дисциплину семантического уровня (описание против покрытия), механику обучающего уровня (блочные кавычки TEMPLATE ПРИМЕЧАНИЕ), авторский шлюз lint-first и правило честности оценки маршрутизации. НЕ используйте при изменении уже написанного навыка (редактируйте его напрямую), при написании общей технической документации (используйте «документацию») или при исправлении неправильно сформированного навыка, обнаруженного с помощью lint (используйте «graph-audit» для систематической работоспособности библиотеки, а не для создания справки по scaffold).
