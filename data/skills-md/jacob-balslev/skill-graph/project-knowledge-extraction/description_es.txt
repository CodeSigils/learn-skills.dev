Úselo al extraer conocimiento duradero del proyecto a partir de código, documentos, problemas, incidentes, informes, capturas de pantalla o conversaciones en un contexto reutilizable, como habilidades, ADR, glosarios, documentos de contexto o memoria. NO lo use para escribir un nuevo contrato de habilidades (use `skill-scaffold`), mantener herramientas de biblioteca (use `skill-infrastructure`) o pulir documentación genérica (use `documentation`).
