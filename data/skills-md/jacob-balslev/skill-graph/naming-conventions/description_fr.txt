À utiliser pour nommer un nouveau fichier, fonction, variable, type, itinéraire, colonne de base de données, variable d'environnement ou tout autre code ou artefact système. Couvre la morphologie de l'identifiant (choix verbe-nom, pluriel ou singulier, conventions de préfixe/suffixe), kebab-case vs camelCase vs Snake_case vs PascalCase par type d'artefact, les règles d'abréviation, la sémantique nom/chemin, le flux de travail de coordination de renommage et la détection des noms qui mentent. Ne PAS utiliser pour l'écriture de contenu (utilisez « documentation »), pour restructurer du code déjà nommé (utilisez « refactor ») ou pour la copie en langage humain dans l'interface utilisateur du produit (compétence distincte, pas dans cette bibliothèque).
