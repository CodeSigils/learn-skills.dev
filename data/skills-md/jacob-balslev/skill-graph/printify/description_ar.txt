استخدمه عند العمل مع Printify - واجهة REST API للطباعة عند الطلب، ونموذج الكتالوج (المخططات، وموفري الطباعة، والمتغيرات، ومناطق الطباعة)، وإنشاء المنتج ونشر دورة الحياة على القنوات المتصلة، وتوجيه الطلب، واستعلامات تكلفة الشحن، والتحقق من خطاف الويب HMAC SHA-256. لا تستخدمه مع البائعين غير المتخصصين في طباعة POD، أو أعمال واجهة متجر Shopify العامة، أو إنشاء ملف الطباعة (العمل الفني).
