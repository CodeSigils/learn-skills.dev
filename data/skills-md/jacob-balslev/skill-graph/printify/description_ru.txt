Используйте при работе с Printify — REST API для печати по требованию, модель каталога (чертежи, поставщики печати, варианты, области печати), создание продукта и жизненный цикл публикации в подключенных каналах, маршрутизация заказов, запросы стоимости доставки и проверка веб-перехватчика HMAC SHA-256. НЕ используйте для поставщиков POD, не относящихся к Printify, для общей работы витрины Shopify или для создания файлов печати (иллюстраций).
