Используйте при аудите кода на предмет повторяющихся проблем, сортировке ошибок по кластерам, обнаружении отклонений от установленных соглашений или когда агент продолжает устранять симптомы, а не основные причины. Охватывает шестиэтапный цикл распознавания (Наблюдение → Кластер → Имя → Кодификация → Обнаружение → Предотвратить), стратегии аудита на основе grep, кластеризацию шаблонов ошибок с нормализацией, а затем хешированием, шаблоны работоспособности доски (устаревшие задачи, переполнение незавершенного производства, дубликаты), нарушения шаблонов проектирования (иерархия заголовков, дрейф токенов, тройное кодирование), шаблоны кодирования домена (различие нулевых и нулевых значений, целочисленное кодирование для денежных сумм, преобразование величин в граница отображения, иерархия доверия на уровне источника), конвейер оценки как шаблона, 5 причин для анализа первопричин и симптомов, состояния жизненного цикла шаблонов и шесть именованных ловушек дрейфа. НЕ используйте для разовой локализации ошибки без повторения — исправьте ошибку и двигайтесь дальше — или для проектирования самой системы классификации; этот навык выявляет нарушения уже существующих соглашений, а дизайн таксономии определяет систему.
