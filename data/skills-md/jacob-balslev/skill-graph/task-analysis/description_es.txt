Úselo al auditar una ruta, definir un contrato de ruta, revisar los flujos de incorporación o configuración, diagnosticar por qué una página se siente confusa o cuando el usuario pregunta sobre las tareas principales, el tiempo de obtención de valor, las ramificaciones, los callejones sin salida o la complejidad de la tarea. Proporciona un análisis de UX basado en objetivos que convierte una crítica vaga en un objetivo explícito -> tarea -> descomposición de subtareas y un contrato de jerarquía primaria/secundaria/de soporte para la primera ventana gráfica. NO lo use para elegir patrones de control (use `patrones de interacción`), artesanía visual (use `fundamentos de diseño visual`), diseño responsivo (use `composición de diseño`) o control de calidad solo para accesibilidad (use `a11y`).
