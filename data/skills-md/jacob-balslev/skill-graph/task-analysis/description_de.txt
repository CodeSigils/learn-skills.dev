Verwenden Sie diese Funktion, wenn Sie eine Route prüfen, einen Routenvertrag definieren, Onboarding- oder Setup-Abläufe überprüfen, diagnostizieren, warum eine Seite verwirrend erscheint, oder wenn der Benutzer nach Top-Aufgaben, Wertschöpfungszeit, Verzweigungen, Sackgassen oder Aufgabenkomplexität fragt. Bietet eine zielorientierte UX-Analyse, die vage Kritik in eine explizite Zerlegung von Ziel -> Aufgabe -> Unteraufgabe und einen primären/sekundären/unterstützenden Hierarchievertrag für das erste Ansichtsfenster umwandelt. NICHT für die Auswahl von Kontrollmustern (verwenden Sie „interaction-patterns“), für visuelle Gestaltung (verwenden Sie „visual-design-foundations“), für responsives Layout (verwenden Sie „layout-composition“) oder für die Qualitätssicherung nur zur Barrierefreiheit (verwenden Sie „a11y“).
