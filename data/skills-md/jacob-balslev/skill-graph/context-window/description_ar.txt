يُستخدم عند تخصيص ميزانية نافذة السياق عبر النظام / حقن المهارات / مناطق العمل، أو مراقبة سلامة السياق (موافق / مضغوط / منهك)، أو تحديد وقت ضغط الجلسة، أو الحفاظ على الحالة من خلال خطاف مضغوط مسبقًا حتى لا يتم فقدان العمل، أو الاسترداد بعد الضغط، أو تحديد إستراتيجيات فئة النموذج لنوافذ السياق 1M / 200K / 128K. يغطي نموذج الميزانية ثلاثي المناطق وجدول الميزانية العملية لكل نموذج؛ قاعدة الضغط 80% مع هامش أمان 20% (لاستكمال العملية الحالية، وكتابة نقطة التفتيش، وتشغيل بروتوكول الإغلاق، وانبعاث إشارة الاستمرار)؛ بروتوكولات ما قبل وما بعد الضغط بما في ذلك مسؤوليات الربط والتسلسل الهرمي للاستمرارية عبر الجلسات (git > files-on-disk > الذاكرة الدائمة > السياق المباشر)؛ نطاقات استهلاك الرمز المميز لكل عملية؛ تقنيات تقليل الرمز المميز الخمسة (حتمية CLI عبر MCP / الأداة الثقيلة، القراءات المستهدفة مع الإزاحة + الحد، البحث قبل القراءة، الكشف التدريجي عن المهارات، وضع العد للاستكشاف)؛ والأنماط المضادة التي تستنفد النافذة في منتصف المهمة. لا تستخدمه لتحديد *ما* السياق المطلوب تحميله أو إسقاطه في مجموعة العمل (استخدم `إدارة السياق`)، أو لتصميم الموجه نفسه (استخدم ``prompt-craft`)، أو لبنية سياق الرسوم البيانية المتعددة (استخدم ``الرسم البياني للسياق`)، أو لتنظيم الذاكرة المستمرة عبر الجلسات (مهارة تنظيم الذاكرة).
