Используйте при распределении бюджета контекстного окна по системе/внедрению навыков/рабочим зонам, мониторинге работоспособности контекста (ОК/Сжатый/Исчерпан), принятии решения о том, когда сжимать сеанс, сохранении состояния с помощью перехватчика предварительного сжатия, чтобы работа не была потеряна, восстановлении после сжатия или выборе стратегий класса модели для контекстных окон 1M/200K/128K. Охватывает трехзонную бюджетную модель и таблицу практического бюджета для каждой модели; правило уплотнения 80% с запасом безопасности 20% (для завершения текущей операции, записи контрольной точки, запуска протокола закрытия, подачи сигнала продолжения); пред- и посткомпактные протоколы, включая обязанности перехватчиков и иерархию межсессионного постоянства (git > файлы на диске > долговременная память > живой контекст); диапазоны потребления токенов для каждой операции; пять методов сокращения токенов (детерминированный CLI поверх MCP / тяжелый инструмент, целевое чтение со смещением + ограничением, поиск перед чтением, прогрессивное раскрытие навыков, режим подсчета для исследования); и антишаблоны, которые исчерпывают окно в середине задачи. НЕ используйте для принятия решения *какой* контекст загрузить или удалить в рабочем наборе (используйте `context-management`), для разработки самого приглашения (используйте `prompt-craft`), для многографовой контекстной архитектуры (используйте `context-graph`) или для межсессионного курирования постоянной памяти (навык курирования памяти).
