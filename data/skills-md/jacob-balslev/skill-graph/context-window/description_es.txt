Úselo al asignar el presupuesto de la ventana de contexto en todo el sistema/inyección de habilidades/zonas de trabajo, monitorear el estado del contexto (correcto/compacto/agotado), decidir cuándo compactar una sesión, preservar el estado a través de un enlace precompacto para que no se pierda trabajo, recuperarse después de una compactación o seleccionar estrategias de clase de modelo para ventanas de contexto de 1M/200K/128K. Cubre el modelo de presupuesto de tres zonas y la tabla de presupuesto práctico por modelo; la regla de compactación del 80% con el margen de seguridad del 20% (para completar la operación actual, escribir el punto de control, ejecutar el protocolo de cierre, emitir la señal de continuación); protocolos pre y post compactos que incluyen responsabilidades de enlace y la jerarquía de persistencia entre sesiones (git > archivos en disco > memoria duradera > contexto en vivo); rangos de consumo de tokens por operación; las cinco técnicas de reducción de tokens (CLI determinista sobre MCP/herramienta pesada, lecturas dirigidas con desplazamiento+límite, búsqueda antes de leer, divulgación progresiva de habilidades, modo de conteo para exploración); y los antipatrones que agotan la ventana a mitad de la tarea. NO lo use para decidir *qué* contexto cargar o soltar en el conjunto de trabajo (use `context-management`), para diseñar el mensaje en sí (use `prompt-craft`), para la arquitectura de contexto de múltiples gráficos (use `context-graph`), o para la curación de memoria persistente entre sesiones (una habilidad de curación de memoria).
