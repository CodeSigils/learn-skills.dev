يُستخدم عند التخطيط لاختبارات إصلاح الأخطاء أو الميزات أو إعادة البناء - لتحديد ما يستحق الاختبار، وعلى أي مستوى، وبأي دليل. يغطي قرارات نطاق الاختبار، واختيار مستوى الاختبار (الوحدة / التكامل / العقد / e2e)، ومطابقة الجهد مع المخاطر، واستهداف الانحدار، وجودة الأدلة، وتغطية حالة الفشل. لا تستخدم لمطاردة فشل معروف (أي "تصحيح الأخطاء")، أو لكتابة مستند خالص (أي "التوثيق")، أو لمناقشة البنية المفاهيمية بدون هدف التحقق (لا توجد مهارة مخصصة - تعامل كاستراتيجية، وليس اختبار).
