Используйте при рассуждениях об уровнях автономии агентов, разработке циклов автоматического улучшения, оценке качества кода, сгенерированного искусственным интеллектом, или измерении производительности агентов в кодовой базе с помощью LLM. Охватывает три эпохи программного обеспечения Карпати (1.0 явный / 2.0 изученный / 3.0 естественный язык), различие между вибрирующим кодированием и агентской инженерией, ползунок автономности 0–5 с рекомендациями по типам задач, цикл автоисследования «один актив / одна метрика / один временной блок», метрики производительности программного обеспечения 3.0 и документированные регрессии качества непроверенного кода, сгенерированного ИИ ( «вибрационное похмелье»). НЕ используйте для выбора конкретной топологии автономного цикла (используйте `agent-engineering`), для дисциплины разработки каждого приглашения (используйте `prompt-craft`) или для проверки кода, сгенерированного ИИ, который получается в рабочем процессе Software 3.0 (используйте `code-review`).
