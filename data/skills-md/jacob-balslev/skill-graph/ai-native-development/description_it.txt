Da utilizzare quando si ragiona sui livelli di autonomia degli agenti, si progettano cicli di miglioramento automatico, si valuta la qualità del codice generato dall'intelligenza artificiale o si misura la produttività degli agenti in una codebase assistita da LLM. Copre le tre ere del software di Karpathy (1.0 esplicito / 2.0 appreso / 3.0 linguaggio naturale), la distinzione tra codifica delle vibrazioni e ingegneria dell'agente, il dispositivo di scorrimento dell'autonomia 0-5 con raccomandazioni sul tipo di attività, il ciclo di ricerca automatica con una sola risorsa / una metrica / una sola volta, le metriche di produttività del Software 3.0 e le regressioni di qualità documentate del codice generato dall'intelligenza artificiale senza gate (il 'vibe postumi di una sbornia'). NON utilizzare per scegliere una specifica topologia del ciclo di autonomia (utilizzare `agent-engineering`), per la disciplina di creazione per prompt (utilizzare `prompt-craft`) o per rivedere il codice generato dall'intelligenza artificiale che esce da un flusso di lavoro del Software 3.0 (utilizzare `code-review`).
