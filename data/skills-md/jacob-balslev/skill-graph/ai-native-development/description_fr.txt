À utiliser pour raisonner sur les niveaux d'autonomie des agents, concevoir des boucles d'amélioration automatique, évaluer la qualité du code généré par l'IA ou mesurer la productivité des agents dans une base de code assistée par LLM. Couvre les trois époques de logiciels de Karpathy (1.0 explicite / 2.0 appris / 3.0 en langage naturel), la distinction entre codage vibratoire et ingénierie agentique, le curseur d'autonomie 0-5 avec recommandations de type de tâche, la boucle AutoResearch à un actif / une métrique / une boîte unique, les métriques de productivité du logiciel 3.0 et les régressions de qualité documentées du code généré par l'IA non verrouillé (l'ambiance gueule de bois'). Ne PAS utiliser pour choisir une topologie de boucle d'autonomie spécifique (utilisez « agent-engineering »), pour la discipline de création par invite (utilisez « prompt-craft ») ou pour réviser le code généré par l'IA qui sort d'un flux de travail du logiciel 3.0 (utilisez « code-review »).
