Úselo al reorganizar el código existente sin cambiar el comportamiento externo: extraer funciones, reducir la duplicación, cambiar el nombre para mayor claridad, dividir módulos o ajustar la estructura. Cubre la preservación del comportamiento, la reducción de duplicaciones, la descomposición, las mejoras de nombres, la reorganización estructural y la verificación antes/después. NO lo use para investigar errores, agregar nuevos comportamientos de productos o escribir documentación (incluso cuando los documentos describen el código refactorizado).
