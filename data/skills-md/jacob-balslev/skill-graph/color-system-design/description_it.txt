Da utilizzare durante la progettazione di un sistema di colori: costruzione di tavolozze, token di colore semantici, rapporti di contrasto WCAG, uniformità percettiva in OKLCH/LCH e parità di modalità chiaro/scuro. NON utilizzare per scelte di colori di un singolo marchio, meccanismi di cambio tema di runtime o token di progettazione senza colori.
