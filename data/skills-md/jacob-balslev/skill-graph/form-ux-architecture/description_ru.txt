Используйте при разработке или аудите структуры формы и пользовательского интерфейса проверки: группировка полей, обязательные и необязательные входные данные, время проверки, разделение проверки клиент/сервер, жизненный цикл отправки, восстановление, многоэтапные формы и ввод данных с высоким риском. НЕ используйте только для меток и объявлений (используйте `a11y`), формулировок сообщений проверки (используйте `microcopy`), проектирования схемы API (используйте `api-design`) или моделирования хранимых данных (используйте `data-modeling`).
