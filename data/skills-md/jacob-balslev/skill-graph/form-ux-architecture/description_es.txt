Úselo al diseñar o auditar la estructura del formulario y la UX de validación: agrupación de campos, entradas requeridas versus opcionales, tiempo de validación, división de validación cliente/servidor, ciclo de vida de envío, recuperación, formularios de varios pasos e ingreso de datos de alto riesgo. NO lo use solo para etiquetas y anuncios (use `a11y`), redacción de mensajes de validación (use `microcopy`), diseño de esquema API (use `api-design`) o modelado de datos almacenados (use `data-modeling`).
