Da utilizzare durante la definizione o la revisione di contratti tra sistemi, moduli, servizi, agenti, lavori, eventi, API o team: proprietà, input, output, invarianti, compatibilità, errori, idempotenza e controllo delle versioni. NON utilizzare solo per la progettazione di risorse REST (utilizzare `api-design`), dettagli del contratto di eventi asincroni (utilizzare `event-contract-design`), schemi di database (utilizzare `data-modeling`) o debug post-errore (utilizzare `debugging`).
