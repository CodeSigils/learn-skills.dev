Úselo al definir o revisar contratos entre sistemas, módulos, servicios, agentes, trabajos, eventos, API o equipos: propiedad, entradas, salidas, invariantes, compatibilidad, errores, idempotencia y control de versiones. NO lo use solo para el diseño de recursos REST (use `api-design`), detalles de contratos de eventos asíncronos (use `event-contract-design`), esquemas de bases de datos (use `data-modeling`) o depuración posterior a un error (use `debugging`).
