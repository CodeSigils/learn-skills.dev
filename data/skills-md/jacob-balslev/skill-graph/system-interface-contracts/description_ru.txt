Используйте при определении или проверке контрактов между системами, модулями, службами, агентами, заданиями, событиями, API или командами: владение, входные данные, выходные данные, инварианты, совместимость, ошибки, идемпотентность и управление версиями. НЕ используйте только для проектирования ресурсов REST (используйте api-design), детали контракта асинхронных событий (используйте event-contract-design), схемы базы данных (используйте моделирование данных) или отладку после сбоя (используйте отладку).
