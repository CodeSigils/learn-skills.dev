Wird zum Definieren oder Überprüfen von Verträgen zwischen Systemen, Modulen, Diensten, Agenten, Jobs, Ereignissen, APIs oder Teams verwendet: Eigentum, Eingaben, Ausgaben, Invarianten, Kompatibilität, Fehler, Idempotenz und Versionierung. Verwenden Sie es NICHT allein für das REST-Ressourcendesign (verwenden Sie „api-design“), für asynchrone Ereignisvertragsdetails (verwenden Sie „event-contract-design“), für Datenbankschemata (verwenden Sie „data-modeling“) oder für das Debuggen nach einem Fehler (verwenden Sie „debugging“).
