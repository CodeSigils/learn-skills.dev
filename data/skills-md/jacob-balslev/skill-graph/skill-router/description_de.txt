Verwenden Sie diese Funktion, wenn Sie eine Agentenanfrage über mehrere Fertigkeiten weiterleiten, eine Routing-Tabelle erstellen oder prüfen, Routing-Abdeckungslücken erkennen oder Fragen wie „Welcher Fertigkeit kümmert sich darum?“, „Wer leitet X weiter?“ oder „Warum wurde Fertigkeit A anstelle von B aktiviert?“ verwenden. Behandelt Trigger-Label-Matching, Dateipfad-Matching, Schlüsselwort-Matching, beschreibungsbasiertes semantisches Matching, Bereichs-/Typ-Tiebreaker und Erkennung von Abdeckungslücken. NICHT verwenden, wenn der Ziel-Skill bereits bekannt ist (laden Sie ihn direkt), beim Erstellen eines neuen Skills (verwenden Sie stattdessen „skill-metadata-template“) oder wenn Sie die Qualität eines EINZELNEN Skills bewerten (verwenden Sie „graph-audit“).
