Используйте при разработке системы тем — токены дизайна, наслоение семантических токенов, стратегия пользовательских свойств CSS, переключение тем во время выполнения и гарантии контракта темы. НЕ используйте для одноразового выбора цвета, работы с палитрой только для бренда или конфигурации библиотеки стилей для конкретной платформы.
