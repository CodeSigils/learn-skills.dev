Используйте при разработке детерминированного уровня инструментов работоспособности для библиотеки навыков, диагностике того, почему существующая библиотека незаметно разрушается, принятии решения, какие категории автоматических проверок добавить (инвентаризация, согласованность протокола, обнаружение конфликтов, работоспособность маршрутизации, дрейф-дозор), отладке нарушений пороговых значений оценки для многих навыков одновременно или при проверке наличия в системе навыков систем безопасности, необходимых производственной библиотеке. Охватывает пять категорий инструментов проверки работоспособности навыков, ментальную модель «библиотека как база данных», шаблоны качества оценки (минимальные пороговые значения, шаблон проверки на противоречия, требования отрицательных ожиданий), рабочие процессы обслуживания, запускаемые пакетными изменениями навыков, а также антишаблоны, которые приводят к ухудшению состояния библиотек навыков до тех пор, пока агенты, загружающие их, со временем не станут хуже. НЕ используйте для создания отдельного файла SKILL.md (используйте `skill-scaffold`), для запуска аудита соответствия в самом репозитории Skill Graph (используйте `graph-audit`) или для общего выбора правил проверки в базе кода (используйте `lint-overlay`).
