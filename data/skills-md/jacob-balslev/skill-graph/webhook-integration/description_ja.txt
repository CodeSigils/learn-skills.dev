サードパーティプロバイダーの受信 Webhook ハンドラーを実装またはレビューするときに使用します。署名の検証、再試行の重複排除、再試行と非再試行の適切な HTTP ステータス コードの選択、正規マッピング前の生のペイロードの保持、検証不可能なイベントの隔離などを行います。署名スキーム、べき等パターン、プロバイダーの再試行コントラクト、未加工から正規のパイプライン、隔離、シークレットのローテーション、および PII キャプチャのタイミングをカバーします。アウトバウンド Webhook の公開 (`event-contract-design` を使用)、一般的なバックグラウンド ジョブ オーケストレーション、または運用環境で既に失敗した Webhook ハンドラーの追跡 (`debugging` を使用) には使用しないでください。
