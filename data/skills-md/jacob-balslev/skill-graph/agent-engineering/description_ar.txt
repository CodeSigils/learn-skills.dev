يُستخدم عند تصميم أو تقييم نظام وكيل ذكاء اصطناعي للإنتاج، أو اختيار نمط تنسيق متعدد الوكلاء (المنسق/العامل، أو التوزيع الموسع، أو الإجماع، أو السلسلة التسلسلية، أو المُقيم/المُحسِّن)، أو تشخيص فشل التنسيق (سباقات المطالبة، أو الأكشاك الصامتة، أو تلوث السياق، أو الحلقات الجامحة)، أو تدقيق ما إذا كانت حلقة الوكيل جاهزة بالفعل للإنتاج. يغطي الركائز الأربع (البنية ودورة الحياة، وتحليل المهام، وأنماط التنسيق، وموثوقية الإنتاج)، ومتطلبات الموثوقية الستة (قابلية الملاحظة، وميزانيات التكلفة، والعجز، واسترداد الفشل، وحدود الأمان، وأقفال المطالبات)، وإطار قرار التفويض مع التقاطع العلوي، والأنماط المضادة الأكثر شيوعًا. لا تستخدم للصياغة السريعة (استخدم "prompt-craft")، أو كفاءة الأداة لكل مكالمة (استخدم "استراتيجية استدعاء الأدوات")، أو تصميم مكدس السياق داخل وكيل واحد (استخدم "هندسة السياق")، أو تصحيح الأخطاء في وقت التشغيل لنظام منشور (استخدم "تصحيح الأخطاء").
