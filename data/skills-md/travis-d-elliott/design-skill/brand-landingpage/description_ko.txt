브랜드 우선 랜딩 페이지 디자이너 — 사용자를 인터뷰하여 브랜드 아이덴티티(형용사, 색상, 타이포그래피, 모양 언어)를 발견한 다음 배포 가능한 HTML 출력이 포함된 Stitch를 통해 세련된 랜딩 페이지를 생성하고 반복합니다. 사용자가 아직 시각적 방향을 설정하지 않은 독립형 랜딩/마케팅 페이지의 경우 프런트엔드 디자인보다 선호됩니다.
TRIGGER 언제: 사용자가 "랜딩 페이지 생성/디자인/구축", "내 프로젝트/제품/서비스에 대한 홈페이지 만들기", "마케팅 페이지 구축"을 요청하거나 앱/사이드 프로젝트를 홍보하려고 합니다. 특히 브랜드 색상, 글꼴 또는 시각적 스타일을 정의하지 않은 경우 안내된 브랜드 인터뷰가 핵심 가치입니다.
사용자가 구현할 특정 디자인 모형이 있거나, 대시보드 또는 앱 UI를 원하거나, 구성 요소 수준 프런트엔드 작업(버튼, 양식, 탐색 모음)이 필요하거나, 다중 페이지 애플리케이션을 구축하거나, 알려진 디자인 토큰으로 기존 페이지의 스타일을 변경하는 경우에는 트리거하지 마세요. 이러한 경우에는 프런트엔드 디자인을 사용하세요.
