Depure y rastree juegos de Game Boy/Game Boy Color/Super Game Boy utilizando el servidor MCP del emulador Gearboy. Proporciona flujos de trabajo para la depuración de CPU SM83, gestión de puntos de interrupción, inspección de hardware, análisis de desmontaje y seguimiento de ejecución. Úselo cuando el usuario desee depurar un juego de Game Boy, rastrear la ejecución de código, inspeccionar los registros de la CPU o el estado del hardware, establecer puntos de interrupción, analizar interrupciones, seguir las instrucciones SM83, aplicar ingeniería inversa al código del juego, examinar los registros LCD, APU o SGB, ver la pila de llamadas o diagnosticar problemas de renderizado, audio o sincronización. Úselo también cuando el usuario mencione el desarrollo de Game Boy, las pruebas caseras de GB/GBC/SGB o la depuración de SM83 con Gearboy.
