Eseguire il debug e il tracciamento dei giochi Game Boy/Game Boy Color/Super Game Boy utilizzando il server MCP dell'emulatore Gearboy. Fornisce flussi di lavoro per il debug della CPU SM83, la gestione dei punti di interruzione, l'ispezione dell'hardware, l'analisi del disassemblaggio e il tracciamento dell'esecuzione. Da utilizzare quando l'utente desidera eseguire il debug di un gioco per Game Boy, tracciare l'esecuzione del codice, ispezionare i registri della CPU o lo stato dell'hardware, impostare punti di interruzione, analizzare le interruzioni, eseguire istruzioni SM83, decodificare il codice di gioco, esaminare i registri LCD, APU o SGB, visualizzare lo stack di chiamate o diagnosticare problemi di rendering, audio o temporizzazione. Da utilizzare anche quando l'utente menziona lo sviluppo per Game Boy, il test homebrew GB/GBC/SGB o il debugging SM83 con Gearboy.
