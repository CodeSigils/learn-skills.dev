Отлаживайте и отслеживайте игры Game Boy/Game Boy Color/Super Game Boy с помощью сервера MCP эмулятора Gearboy. Предоставляет рабочие процессы для отладки ЦП SM83, управления точками останова, проверки оборудования, анализа дизассемблирования и отслеживания выполнения. Используйте, когда пользователь хочет отладить игру Game Boy, отследить выполнение кода, проверить регистры ЦП или состояние оборудования, установить точки останова, проанализировать прерывания, пошагово выполнить инструкции SM83, реконструировать игровой код, проверить регистры LCD, APU или SGB, просмотреть стек вызовов или диагностировать проблемы рендеринга, звука или синхронизации. Также используйте, когда пользователь упоминает разработку Game Boy, домашнее тестирование GB/GBC/SGB или отладку SM83 с помощью Gearboy.
