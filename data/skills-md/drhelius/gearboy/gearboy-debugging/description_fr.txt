Déboguez et tracez les jeux Game Boy / Game Boy Color / Super Game Boy à l'aide du serveur MCP de l'émulateur Gearboy. Fournit des flux de travail pour le débogage du processeur SM83, la gestion des points d'arrêt, l'inspection du matériel, l'analyse du démontage et le suivi de l'exécution. À utiliser lorsque l'utilisateur souhaite déboguer un jeu Game Boy, suivre l'exécution du code, inspecter les registres du processeur ou l'état du matériel, définir des points d'arrêt, analyser les interruptions, parcourir les instructions SM83, effectuer une ingénierie inverse du code du jeu, examiner les registres LCD, APU ou SGB, afficher la pile d'appels ou diagnostiquer des problèmes de rendu, d'audio ou de synchronisation. À utiliser également lorsque l'utilisateur mentionne le développement Game Boy, les tests homebrew GB/GBC/SGB ou le débogage SM83 avec Gearboy.
