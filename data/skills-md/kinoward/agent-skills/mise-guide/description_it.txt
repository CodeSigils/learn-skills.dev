DEVE UTILIZZARE per qualsiasi cosa relativa a mise, versioni degli strumenti di sviluppo o configurazione dell'ambiente di sviluppo. Trigger: (1) L'utente menziona mise, mise.toml, .tool-versions o comandi mise come "mise use", "mise install", "mise run". (2) L'utente desidera installare, cambiare, aggiungere, aggiornare o controllare le versioni degli strumenti di sviluppo (node, python, go, ruby, java, ruggine, ecc.) a livello di progetto o globale, anche senza menzionare mise (ad esempio "imposta il nodo 22", "quale versione di Python", "aggiorna vai", "verifica strumenti obsoleti", "configura ambiente di sviluppo"). (3) L'utente desidera gestire le variabili di ambiente per progetto tramite file di configurazione (ad esempio "aggiungi DATABASE_URL env var", "imposta env vars per ambienti diversi"). (4) L'utente desidera definire o eseguire attività di progetto tramite mise (ad esempio "crea un'attività di creazione", "esegui test con mise"). NON eseguire l'attivazione per: Dockerfile, script package.json, Makefile, comandi nvm/pyenv/rbenv, installazione di pacchetti pip/npm, tag git, configurazione CI/CD o distribuzione.
