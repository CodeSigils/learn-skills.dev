Mise, 개발 도구 버전 또는 개발 환경 설정과 관련된 모든 것에 사용해야 합니다. 트리거: (1) 사용자가 mise, mise.toml, .tool-versions 또는 'mise use', 'mise install', 'mise run'과 같은 mise 명령을 언급합니다. (2) 사용자가 프로젝트 또는 전역 수준에서 개발 도구(node, python, go, ruby, java, Rust 등)의 버전을 설치, 전환, 고정, 업그레이드 또는 확인하기를 원합니다. 심지어 세부사항(예: '노드 22 설정', 'python 버전 확인', 'upgrade go', '오래된 도구 확인', '개발 환경 구성')을 언급하지 않고도 가능합니다. (3) 사용자가 구성 파일을 통해 프로젝트별 환경 변수를 관리하려고 합니다(예: 'DATABASE_URL 환경 변수 추가', '다른 환경에 대한 환경 변수 설정'). (4) 사용자가 mise를 통해 프로젝트 작업을 정의하거나 실행하려고 합니다(예: '빌드 작업 생성', 'mise로 테스트 실행'). Dockerfiles, package.json 스크립트, Makefiles, nvm/pyenv/rbenv 명령, pip/npm 패키지 설치, git 태그, CI/CD 구성 또는 배포에 대해서는 트리거하지 마십시오.
