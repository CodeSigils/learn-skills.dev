DEBE UTILIZARSE para cualquier cosa relacionada con mise, versiones de herramientas de desarrollo o configuración del entorno de desarrollo. Desencadenantes: (1) El usuario menciona mise, mise.toml, .tool-versions o comandos mise como 'mise use', 'mise install', 'mise run'. (2) El usuario desea instalar, cambiar, anclar, actualizar o verificar versiones de herramientas de desarrollo (nodo, python, go, ruby, java, rust, etc.) a nivel de proyecto o global, incluso sin mencionar mise (por ejemplo, 'configurar el nodo 22', 'qué versión de Python', 'actualizar go', 'verificar herramientas desactualizadas', 'configurar el entorno de desarrollo'). (3) El usuario desea administrar las variables de entorno por proyecto a través de archivos de configuración (por ejemplo, 'agregar var env DATABASE_URL', 'configurar vars env para diferentes entornos'). (4) El usuario desea definir o ejecutar tareas del proyecto mediante mise (por ejemplo, 'crear una tarea de compilación', 'ejecutar pruebas con mise'). NO active para: Dockerfiles, scripts package.json, Makefiles, comandos nvm/pyenv/rbenv, instalación de paquetes pip/npm, etiquetas git, configuración de CI/CD o implementación.
