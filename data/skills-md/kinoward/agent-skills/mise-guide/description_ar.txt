يجب استخدامه لأي شيء متعلق بالميز أو إصدارات أدوات التطوير أو إعداد بيئة التطوير. المشغلات: (1) يذكر المستخدم أوامر mise، أو mise.toml، أو .tool-versions، أو أوامر mise مثل 'mise use'، أو 'mise install'، أو 'mise run'. (2) يريد المستخدم تثبيت إصدارات أدوات التطوير أو تبديلها أو تثبيتها أو ترقيتها أو التحقق منها - العقدة، أو python، أو go، أو Ruby، أو Java، أو Rust، وما إلى ذلك - على مستوى المشروع أو المستوى العالمي، حتى بدون ذكر Mise (على سبيل المثال، "إعداد العقدة 22"، "ما هو إصدار python"، "upgrade go"، "التحقق من الأدوات القديمة"، "تهيئة بيئة التطوير"). (3) يريد المستخدم إدارة متغيرات البيئة لكل مشروع عبر ملفات التكوين (على سبيل المثال، "add DATABASE_URL env var"، "إعداد env vars لبيئات مختلفة"). (4) يريد المستخدم تحديد مهام المشروع أو تشغيلها عبر Mise (على سبيل المثال، "إنشاء مهمة إنشاء"، "تشغيل الاختبارات باستخدام Mise"). لا تقم بتشغيل: Dockerfiles، أو البرامج النصية package.json، أو Makefiles، أو أوامر nvm/pyenv/rbenv، أو تثبيت حزمة pip/npm، أو علامات git، أو تكوين CI/CD، أو النشر.
