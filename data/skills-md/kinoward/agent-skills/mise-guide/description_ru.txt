ДОЛЖЕН ИСПОЛЬЗОВАТЬСЯ для всего, что связано с MIS, версиями инструментов разработки или настройкой среды разработки. Триггеры: (1) Пользователь упоминает mise, mise.toml, .tool-versions или команды mise, такие как «mise use», «mise install», «mise run». (2) Пользователь хочет установить, переключить, закрепить, обновить или проверить версии инструментов разработки — Node, Python, Go, Ruby, Java, Rust и т. д. — на уровне проекта или на глобальном уровне, даже не упоминая о Мизе (например, «настроить узел 22», «какая версия Python», «обновить», «проверить наличие устаревших инструментов», «настроить среду разработки»). (3) Пользователь хочет управлять переменными среды для каждого проекта через файлы конфигурации (например, «добавить переменную окружения DATABASE_URL», «настроить переменные окружения для разных сред»). (4) Пользователь хочет определить или запустить задачи проекта с помощью Mise (например, «создать задачу сборки», «запустить тесты с помощью Mise»). НЕ запускайте триггер для: Dockerfiles, скриптов package.json, Makefiles, команд nvm/pyenv/rbenv, установки пакетов pip/npm, тегов git, конфигурации CI/CD или развертывания.
