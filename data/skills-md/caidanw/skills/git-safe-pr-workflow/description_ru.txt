Безопасный рабочий процесс запроса на извлечение GitHub для пользователей Git с низким опытом. Используйте при извлечении, синхронизации ветки функций с `main`, разрешении конфликтов, отмене ошибок, восстановлении после неправильного перебазирования или принятии решения о том, как объединить PR, сохраняя при этом `main` чистым. Срабатывает при: «обновить мою ветку», «перебазировать мою ветку», «разрешить конфликты git», «восстановиться после перебазирования», «отменить отправленную фиксацию», «сохранить основную в чистоте», «сжать слияние».
