Sicherer GitHub-Pull-Request-Workflow für Git-Benutzer mit geringer Erfahrung. Verwenden Sie diese Funktion, wenn Sie Pulls durchführen, einen Feature-Zweig mit „main“ synchronisieren, Konflikte lösen, Fehler rückgängig machen, sich von einem fehlerhaften Rebase erholen oder entscheiden, wie ein PR zusammengeführt werden soll, während „main“ sauber bleibt. Auslöser bei: „Meinen Branch aktualisieren“, „Meinen Branch neu starten“, „Git-Konflikte lösen“, „Von Rebase wiederherstellen“, „Push-Commit rückgängig machen“, „Hauptdatei sauber halten“, „Squash-Merge“.
