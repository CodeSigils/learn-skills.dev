سير عمل طلب سحب GitHub الآمن لمستخدمي Git ذوي الخبرة المنخفضة. يُستخدم عند سحب فرع ميزة أو مزامنته مع "الرئيسي"، أو حل التعارضات، أو التراجع عن الأخطاء، أو التعافي من إعادة الأساس السيئة، أو تحديد كيفية دمج العلاقات العامة مع الحفاظ على نظافة "الرئيسي". مشغلات على: "تحديث فرعي"، "إعادة إنشاء فرعي"، "حل تعارضات git"، "الاسترداد من rebase"، "التراجع عن الالتزام المدفوع"، "الحفاظ على النظافة الأساسية"، "دمج الاسكواش".
