Flusso di lavoro sicuro per le richieste pull di GitHub per utenti Git con poca esperienza. Da utilizzare durante il pull, la sincronizzazione di un ramo di funzionalità con "main", la risoluzione di conflitti, l'annullamento di errori, il ripristino da un rebase errato o la decisione su come unire un PR mantenendo pulito "main". Si attiva su: "aggiorna il mio ramo", "rebase il mio ramo", "risolvi i conflitti git", "ripristina da rebase", "annulla commit spinto", "mantieni pulito il main", "squash merge".
