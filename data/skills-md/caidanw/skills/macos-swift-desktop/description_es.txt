Cree aplicaciones de escritorio nativas de macOS en Swift usando AppKit y SwiftUI. Úselo al crear o modificar paquetes .app de macOS, aplicaciones basadas en NSDocument, aplicaciones de barra de menú, ventanas de preferencias, diseños de NSWindow/NSToolbar/NSSplitView, NSMenu/NSStatusItem, persistencia de Core Data/SwiftData/GRDB, arrastrar y soltar, deshacer/rehacer, sandboxing, notarización, actualizaciones automáticas de Sparkle, ayudantes de XPC o XCTest para macOS. También cubre el renderizado acelerado por GPU con Metal y CAMetalLayer, interfaces de usuario de lienzo infinito, incrustación de terminal libghostty e incrustación de WKWebView. Se activa en AppKit, NSApplicationDelegate, NSDocument, NSViewController, Swift+Metal, firma de código macOS o cuando un usuario solicita patrones de escritorio Swift de nivel de producción desde repositorios como CodeEdit, Triangle, CotEditor, IINA, Ice, Stats, Xcodes.app, STTextView o Ghostty.
