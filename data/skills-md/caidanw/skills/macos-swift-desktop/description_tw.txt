使用 AppKit 和 SwiftUI 在 Swift 中建立本機 macOS 桌面應用程式。在建置或修改 macOS .app 捆綁包、基於 NSDocument 的應用程式、功能表列應用程式、首選項視窗、NSWindow/NSToolbar/NSSplitView 版面、NSMenu/NSStatusItem、Core Data/SwiftData/GRDB 持久性、拖曳、使用取消/重做、沙盒、公證、Sage 幫助程式時的自動說明或重做。還涵蓋使用 Metal 和 CAMetalLayer 進行 GPU 加速渲染、無限畫布 UI、libghostty 終端嵌入和 WKWebView 嵌入。在 AppKit、NSApplicationDelegate、NSDocument、NSViewController、Swift+Metal、macOS 程式碼簽署上觸發，或當使用者從 CodeEdit、Rectangle、CotEditor、IINA、Ice、Stats、Xcodes.app、STTextView 或 Ghostty 等儲存庫請求生產級。
