AppKit と SwiftUI を使用して、Swift でネイティブ macOS デスクトップ アプリケーションを構築します。 macOS .app バンドル、NSDocument ベースのアプリ、メニュー バー アプリ、環境設定ウィンドウ、NSWindow/NSToolbar/NSSplitView レイアウト、NSMenu/NSStatusItem、Core Data/SwiftData/GRDB 永続化、ドラッグ アンド ドロップ、元に戻す/やり直し、サンドボックス、公証、Sparkle 自動更新、XPC ヘルパー、または macOS 用 XCTest を構築または変更するときに使用します。 Metal および CAMetalLayer を使用した GPU アクセラレーションによるレンダリング、無限キャンバス UI、libghostty ターミナルの埋め込み、および WKWebView の埋め込みについても説明します。 AppKit、NSApplicationDelegate、NSDocument、NSViewController、Swift+Metal、macOS コード署名時、またはユーザーが CodeEdit、Rectangle、CotEditor、IINA、Ice、Stats、Xcodes.app、STTextView、Ghostty などのリポジトリから運用グレードの Swift デスクトップ パターンを要求したときにトリガーします。
