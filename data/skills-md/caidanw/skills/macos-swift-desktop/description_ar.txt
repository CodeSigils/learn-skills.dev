أنشئ تطبيقات سطح مكتب macOS أصلية في Swift باستخدام AppKit وSwiftUI. يُستخدم عند إنشاء أو تعديل حزم macOS .app، والتطبيقات المستندة إلى NSDocument، وتطبيقات شريط القوائم، ونوافذ التفضيلات، وتخطيطات NSWindow/NSToolbar/NSSplitView، أو NSMenu/NSStatusItem، أو استمرارية Core Data/SwiftData/GRDB، أو السحب والإفلات، أو التراجع/الإعادة، أو وضع الحماية، أو التوثيق، أو التحديثات التلقائية Sparkle، أو مساعدي XPC، أو XCTest لـ ماك. ويغطي أيضًا العرض المسرع بواسطة وحدة معالجة الرسومات باستخدام Metal وCAMetalLayer وواجهات مستخدم اللوحة اللانهائية وتضمين محطة libghostty وتضمين WKWebView. يتم التشغيل على AppKit، أو NSApplicationDelegate، أو NSDocument، أو NSViewController، أو Swift+Metal، أو توقيع كود macOS، أو عندما يطلب المستخدم أنماط سطح مكتب Swift على مستوى الإنتاج من مستودعات مثل CodeEdit، أو Rectangle، أو CotEditor، أو IINA، أو Ice، أو Stats، أو Xcodes.app، أو STTextView، أو Ghostty.
