Empêchez l'utilisation inutile de « useEffect » de React en orientant le code vers l'état dérivé, les gestionnaires d'événements, la mémorisation, les réinitialisations basées sur les « clés », « useSyncExternalStore » et les API de données de framework ou de bibliothèque de requêtes. À utiliser lors de l'écriture ou de la révision de composants React/Next.js, de la refactorisation de code nécessitant beaucoup d'effets ou lorsqu'une modification introduit « useEffect », « useLayoutEffect » ou une désabonnement de tableau de dépendances.
