Verhindern Sie unnötige React-„useEffect“-Nutzung, indem Sie den Code in Richtung abgeleiteter Status, Ereignishandler, Memoisierung, „schlüsselbasiertes Zurücksetzen“, „useSyncExternalStore“ und Framework- oder Abfragebibliotheks-Daten-APIs lenken. Wird verwendet, wenn Sie React/Next.js-Komponenten schreiben oder überprüfen, effektintensiven Code umgestalten oder wenn eine Änderung „useEffect“, „useLayoutEffect“ oder eine Abwanderung von Abhängigkeitsarrays einführt. Löst aus bei: „useEffect vermeiden“, „useEffect entfernen“, „Sie benötigen möglicherweise keinen Effekt“, „Effektabhängigkeiten“, „abgeleiteter Zustand“, „Nebenwirkungen reagieren“.
