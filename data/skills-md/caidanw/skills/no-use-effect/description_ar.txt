منع استخدام React غير الضروري لـ "useEffect" من خلال توجيه التعليمات البرمجية نحو الحالة المشتقة، ومعالجات الأحداث، والحفظ، وعمليات إعادة التعيين المستندة إلى "المفتاح"، و"useSyncExternalStore"، وواجهات برمجة التطبيقات لبيانات إطار العمل أو مكتبة الاستعلام. يُستخدم عند كتابة أو مراجعة مكونات React/Next.js، أو إعادة هيكلة التعليمات البرمجية ذات التأثير الثقيل، أو عندما يقدم التغيير `useEffect`، أو `useLayoutEffect`، أو تباطؤ مصفوفة التبعية. مشغلات على: "تجنب useEffect"، "إزالة useEffect"، "قد لا تحتاج إلى تأثير"، "تبعيات التأثير"، "الحالة المشتقة"، "الآثار الجانبية لرد الفعل".
