Wählt Fertigkeiten aus installierten Fertigkeiten basierend auf Benutzereingaben aus und führt sie aus: Kategorisieren Sie Anforderungen, ordnen Sie mehrere Anforderungspunkte einer oder mehreren Fertigkeiten zu (nicht auf eine einzelne Fertigkeit beschränkt), greifen Sie auf Fertigkeit suchen/Fähigkeitserkennung zurück, wenn keine passt, und führen Sie vor der Verwendung eine schnelle Sicherheitsüberprüfung durch. Aufruf über „/skill-selector“ oder wenn der Benutzer fragt, welche Fertigkeit verwendet werden soll, eine Fertigkeit empfiehlt oder möchte, dass der Agent Fertigkeiten für eine Aufgabe automatisch auswählt. Verwenden Sie diese Fertigkeit immer, wenn eine Fertigkeitsauswahl oder -empfehlung erforderlich ist.
