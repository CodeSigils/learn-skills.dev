Creación de scripts y automatización de DaVinci Resolve y creación de composiciones, macros y animaciones de Fusion. Cubre la API de secuencias de comandos Resolve (proyectos, líneas de tiempo, grupo de medios, renderizado), el modelo de objetos Fusion, creación/edición de macros, exposición de controles de macros y animación con fotogramas clave, identificadores, aceleración y StyledTextFollower de BezierSpline. Utilice esta habilidad para cualquier secuencia de comandos DaVinci Resolve Lua/Python, creación de macros Fusion o trabajo de animación/fotogramas clave Fusion.
