Синхронизируйте плагин манифеста из dooodleood/manifest-dev в .claude/ для локальной разработки. Клонирует или извлекает репозиторий, копирует агентов/навыки/перехватчики и удаляет только ранее синхронизированные элементы, которые исчезли из исходного кода. Другие плагины в .claude/ остаются в покое. Используйте, когда вас попросят синхронизировать файл манифеста, обновить файл манифеста или получить последнюю версию файла манифеста.
