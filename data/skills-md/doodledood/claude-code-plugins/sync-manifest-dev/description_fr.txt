Synchronisez le plugin manifest-dev de doodledood/manifest-dev vers .claude/ pour le développement local. Clone ou extrait le dépôt, copie les agents/compétences/hooks et supprime uniquement les éléments précédemment synchronisés qui ont disparu en amont. Les autres plugins en .claude/ sont laissés seuls. À utiliser lorsqu'on vous demande de synchroniser manifest-dev, de mettre à jour manifest-dev ou d'extraire le dernier manifest-dev.
