Finden Sie gemeinsam Dinge heraus – jedes Thema, jedes Problem oder jede Idee. Drängt unermüdlich, bis ein gemeinsames Verständnis erreicht ist. Verwenden Sie es, wenn Sie etwas verstehen müssen, bevor Sie handeln, oder wenn Sie herausfinden, ob es das Ziel ist. Auslöser: herausfinden, mir beim Durchdenken helfen, tiefer graben, darauf drücken, was wirklich vor sich geht, nachforschen, durcharbeiten, warum.
