Manifest-Builder. Verwandelt das gemeinsame Verständnis in ein überprüfbares Manifest mit Ergebnissen, Akzeptanzkriterien, globalen Invarianten und Vorgehensweise. Verwenden Sie es beim Planen von Funktionen, beim Festlegen des Umfangs von Refaktoren, beim Debuggen komplexer Probleme oder immer dann, wenn eine Aufgabe vor dem Codieren strukturiertes Denken erfordert. Auslöser: Definieren, Manifestieren, Umfang, Planen, Spezifizieren, Aufschlüsseln.
