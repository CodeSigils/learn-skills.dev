منشئ البيان. يحول الفهم المشترك إلى بيان يمكن التحقق منه مع التسليمات ومعايير القبول والثوابت العالمية والنهج. يُستخدم عند تخطيط الميزات، أو تحديد نطاق إعادة البناء، أو تصحيح المشكلات المعقدة، أو عندما تحتاج المهمة إلى تفكير منظم قبل البرمجة. المشغلات: التحديد، والبيان، والنطاق، والخطة، والمواصفات، والانهيار.
