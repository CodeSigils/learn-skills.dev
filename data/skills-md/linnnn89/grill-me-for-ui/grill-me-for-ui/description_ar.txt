من خلال إجراء مقابلة تصميم مكونة من سؤال واحد مقترنة بالتوجيه الحتمي، أو متطلبات واجهة المستخدم الغامضة، أو إعادة تصميم الصفحة، أو الصور المرجعية، أو التعليقات على الواجهات الموجودة، يتم تقطيرها في توجيه فني، أو ملخص واجهة المستخدم، أو خطة تدريجية، أو مراجعة مرئية. يناسب هذا النهج سيناريوهات مثل "استجوابي لواجهة المستخدم"، أو "المقابلة أولاً، ثم التصميم"، أو الاتجاهات الجديدة، أو استبدال العالم المرئي، أو التوسع التدريجي، أو تحسين واجهة المستخدم الحالية، أو البحث الجمالي، أو التحقق بعد التنفيذ حيث لا تزال هناك حاجة إلى إجراء مقايضات كبيرة في التصميم. ولا ينبغي استخدامه لإجراء تغييرات نمطية محددة بالكامل وذات نقطة واحدة، أو أخطاء برمجية خالصة، أو تنفيذ خطة تنفيذ تمت الموافقة عليها بالفعل.
