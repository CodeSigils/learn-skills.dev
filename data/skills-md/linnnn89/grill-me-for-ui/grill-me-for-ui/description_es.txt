Al realizar una entrevista de diseño de una sola pregunta combinada con un enrutamiento determinista, los requisitos vagos de la interfaz de usuario, los rediseños de páginas, las imágenes de referencia o los comentarios sobre las interfaces existentes se resumen en una dirección de arte, un resumen de la interfaz de usuario, un plan incremental o una revisión visual. Este enfoque es adecuado para escenarios como "interrogarme para la interfaz de usuario", "entrevista primero, luego diseño", nuevas direcciones, reemplazo del mundo visual, expansión incremental, refinamiento de la interfaz de usuario existente, investigación estética o verificación posterior a la implementación, donde aún es necesario realizar importantes compensaciones en el diseño. No debe usarse para cambios de estilo de un solo punto completamente definidos, errores de código puro o la ejecución de un plan de implementación ya aprobado.
