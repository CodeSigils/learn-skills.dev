By conducting a single-question design interview combined with deterministic routing, vague UI requirements, page redesigns, reference images, or feedback on existing interfaces are distilled into an Art Direction, UI Brief, incremental plan, or visual review. This approach is suited for scenarios such as “grill me for UI,” “interview first, then design,” new directions, visual world replacement, incremental expansion, refinement of existing UI, aesthetic research, or post‑implementation verification where significant design trade‑offs still need to be made. It should not be used for fully defined, single‑point style changes, pure code bugs, or the execution of an already approved implementation plan.
