Through a one‑question design interview and deterministic routing, converge vague UI requirements, page redesigns, reference images, or feedback on existing interfaces into an Art Direction, UI Brief, incremental plan, or visual review. It is used for “grill me for UI,” “interview first, then design,” new directions, visual‑world replacement, incremental expansion, existing UI refinement, aesthetic research, or post‑implementation verification where important design trade‑offs still remain. Do not use it for fully specified single‑point style changes, pure code bugs, or executing an already confirmed implementation plan.
