Feishu/Lark CLI shared foundation: application configuration initialization, authentication login (auth login), identity switching (--as user/bot), permission and scope management, Permission denied error handling, security rules. Triggered when the user needs to perform the first configuration (`lark-cli config init`), use login authorization (`lark-cli auth login`), encounter insufficient permissions, switch user/bot identity, configure scope, or use lark-cli for the first time.
