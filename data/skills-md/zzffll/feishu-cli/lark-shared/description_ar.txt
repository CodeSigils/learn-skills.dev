أساسيات Feishu/Lark CLI المشتركة: تهيئة تكوين التطبيق، وتسجيل الدخول للمصادقة (تسجيل الدخول بالمصادقة)، وتبديل الهوية (--كمستخدم/روبوت)، وإدارة الأذونات والنطاق، ومعالجة الأخطاء المرفوضة للإذن، وقواعد الأمان. يتم تشغيله عندما يحتاج المستخدم إلى التهيئة لأول مرة (`lark-cli config init`)، أو استخدام ترخيص تسجيل الدخول (`lark-cli authlogin`)، أو مواجهة أذونات غير كافية، أو تبديل هوية المستخدم/الروبوت، أو تكوين النطاقات، أو استخدام lark-cli لأول مرة.
