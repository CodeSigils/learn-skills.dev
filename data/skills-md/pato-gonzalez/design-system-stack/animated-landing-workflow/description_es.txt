Habilidad de flujo de trabajo aplicada para producir páginas de destino animadas del calibre de Awwwards utilizando Claude Design como orquestador, con motionsites.ai (fondos animados), higgsfield.io o Kling 3 (generación de animación con IA), Dribbble (inspiración de componentes), shots.so (muestra de animación/edición de video) y land-book (plantillas de página de destino) como cadena de herramientas del acelerador. Úselo cuando el usuario solicite diseñar, crear prototipos, animar o enviar una página de destino con movimiento, desde la idea básica hasta la transferencia lista para el código. Orquesta sobre las tres habilidades del sistema de diseño en esta pila (extraer-sistema-de-diseño, patrones-de-sistema-de-diseño, sistemas-de-diseño-impresionantes) y pasa a las habilidades de código de animación existentes (animaciones-awwwards, diseño-web-moderno) para su implementación.
