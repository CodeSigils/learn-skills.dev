Crea, modifica e crea risorse di gioco con MeowArt per pixel sprite, risorse HD, sfondi, modelli di interfaccia utente, loop continui, riquadri di texture, set di riquadri a doppia griglia, rimozione dello sfondo, pulizia dei pixel, animazioni semplici, effetti sonori e generazione di musica/musica di sottofondo. Da utilizzare quando Codex deve produrre o perfezionare la grafica o l'audio del gioco in questo progetto, in particolare quando si scelgono i comandi MeowArt, si dimensionano le tele, si selezionano modelli, si genera musica o audio SFX o si trasformano risorse generate in file pronti per il gioco.
