قم بإنشاء أصول اللعبة وتحريرها وتوجيهها باستخدام MeowArt لكائنات البكسل والأصول عالية الدقة والخلفيات ونماذج واجهة المستخدم والحلقات السلسة وبلاطات النسيج ومجموعات بلاط الشبكة المزدوجة وإزالة الخلفية وتنظيف البكسل والرسوم المتحركة البسيطة والمؤثرات الصوتية وإنشاء الموسيقى/BGM. يُستخدم عندما يحتاج Codex إلى إنتاج أو تحسين فن اللعبة أو الصوت في هذا المشروع، خاصة عند اختيار أوامر MeowArt، أو تغيير حجم اللوحات، أو تحديد القوالب، أو إنشاء موسيقى أو صوت SFX، أو تحويل الأصول التي تم إنشاؤها إلى ملفات جاهزة للعبة.
