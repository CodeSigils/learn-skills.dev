Auswahl und Ausführung von Diagrammalgorithmen auf PyRel v1-Modellen. Behandelt die Graphkonstruktion aus Ontologiemustern, Algorithmusfamilien (Zentralität, Community, Erreichbarkeit, Entfernung, Ähnlichkeit, Komponenten), Parameteroptimierung, Ergebnisextraktion und nachgelagerte Verwendung. Wird zum Erstellen oder Ausführen von Diagrammanalysen für RAI-Modelle verwendet.
