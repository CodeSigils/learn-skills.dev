在這台機器上執行一組 Claude Code 會話，並讓它們透過 SendMessage 相互通訊 — 從 Claude Code 本身，或當呼叫者是 Codex 時透過真正的 Claude 中繼。在 cmux 視窗、窗格和分割中啟動它們，正確處理它們，分發工作，收集或恢復回复，並在使用者提出要求時將它們乾淨地拆除。每當使用者想要兩個或多個 Claude 會話一起工作、要求 Codex 聯繫現有的 Claude 會話、提及 SendMessage、ListAgents、對等會話、跨會話訊息傳遞或代理相互訊息傳遞時使用；每當他們想要在新視窗、工作區、窗格或分割中進行會話時；尤其是當發送訊息或出現在傳送者之間的「訊息套接字」。
