在这台机器上运行一组 Claude Code 会话，并让它们通过 SendMessage 相互通信 — 从 Claude Code 本身，或者当调用者是 Codex 时通过真正的 Claude 中继。在 cmux 窗口、窗格和拆分中启动它们，正确处理它们，分发工作，收集或恢复回复，并在用户提出要求时将它们干净地拆除。每当用户想要两个或多个 Claude 会话一起工作、要求 Codex 联系现有的 Claude 会话、提及 SendMessage、ListAgents、对等会话、跨会话消息传递或代理相互消息传递时使用；每当他们想要在新窗口、工作区、窗格或拆分中进行会话时；尤其是当发送失败并出现“此对话中没有代理”、“使用引用重新发送”或调用者缺少 Claude 的本机消息传递套接字时。
