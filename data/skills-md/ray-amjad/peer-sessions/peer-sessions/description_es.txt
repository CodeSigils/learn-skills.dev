Ejecute una flota de sesiones de Claude Code en esta máquina y haga que se comuniquen entre sí con SendMessage, desde el propio Claude Code o mediante un relé Claude real cuando la persona que llama es Codex. Láncelos en ventanas, paneles y divisiones de cmux, diríjalos correctamente, distribuya el trabajo, recopile o recupere respuestas y elimínelos limpiamente cuando el usuario lo solicite. Úselo siempre que el usuario desee que dos o más sesiones de Claude trabajen juntas, solicite a Codex que se comunique con una sesión de Claude existente, mencione SendMessage, ListAgents, sesiones de pares, mensajería entre sesiones o agentes que se envían mensajes entre sí; cuando quieran sesiones en nuevas ventanas, espacios de trabajo, paneles o divisiones; y especialmente cuando un envío falla con "no hay un agente en esta conversación", "reenviar con el árbitro" o la persona que llama carece del socket de mensajería nativo de Claude.
