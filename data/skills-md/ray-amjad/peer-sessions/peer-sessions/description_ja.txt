このマシン上で一連の Claude Code セッションを実行し、Claude Code 自体から、または呼び出し元が Codex の場合は実際の Claude Relay を通じて、SendMessage を使用して相互に通信させます。 cmux ウィンドウ、ペイン、分割でそれらを起動し、正しくアドレス指定し、作業を配布し、応答を収集または回復し、ユーザーの要求に応じてそれらをきれいに破棄します。ユーザーが 2 つ以上のクロード セッションを連携させたい場合、Codex に既存のクロード セッションに接続するよう依頼する場合、SendMessage、ListAgents、ピア セッション、セッション間メッセージング、またはエージェントの相互メッセージングについて言及する場合に使用します。新しいウィンドウ、ワークスペース、ペイン、または分割でセッションが必要なときはいつでも。特に、「この会話にエージェントではありません」、「参照者を指定して再送信」などの理由で送信が失敗した場合、または発信者にクロードのネイティブ メッセージング ソケットがない場合は特にそうです。
