Führen Sie eine Flotte von Claude Code-Sitzungen auf diesem Computer aus und lassen Sie sie mit SendMessage miteinander kommunizieren – von Claude Code selbst oder über ein echtes Claude-Relay, wenn der Anrufer Codex ist. Starten Sie sie in cmux-Fenstern, -Bereichen und -Splits, adressieren Sie sie richtig, verteilen Sie Arbeit, sammeln Sie Antworten oder stellen Sie sie wieder her und entfernen Sie sie sauber, wenn der Benutzer dies wünscht. Wird verwendet, wenn der Benutzer möchte, dass zwei oder mehr Claude-Sitzungen zusammenarbeiten, Codex auffordert, eine bestehende Claude-Sitzung zu kontaktieren, SendMessage, ListAgents, Peer-Sitzungen, sitzungsübergreifende Nachrichten oder Agenten, die sich gegenseitig Nachrichten senden, erwähnt; wann immer sie Sitzungen in neuen Fenstern, Arbeitsbereichen, Bereichen oder Splits wünschen; und insbesondere, wenn ein Versand fehlschlägt mit „Kein Agent in dieser Konversation“, „Erneut senden mit dem Ref“ oder dem Anrufer fehlt Claudes nativer Messaging-Socket.
