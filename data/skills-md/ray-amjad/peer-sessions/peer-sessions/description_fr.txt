Exécutez une flotte de sessions Claude Code sur cette machine et faites-les communiquer entre elles avec SendMessage — depuis Claude Code lui-même ou via un véritable relais Claude lorsque l'appelant est Codex. Lancez-les dans les fenêtres, volets et fractionnements cmux, traitez-les correctement, distribuez le travail, collectez ou récupérez les réponses et supprimez-les proprement lorsque l'utilisateur le demande. À utiliser chaque fois que l'utilisateur souhaite que deux sessions Claude ou plus travaillent ensemble, demande au Codex de contacter une session Claude existante, mentionne SendMessage, ListAgents, les sessions homologues, la messagerie inter-sessions ou les agents qui s'échangent des messages ; chaque fois qu'ils souhaitent des sessions dans de nouvelles fenêtres, espaces de travail, volets ou fractionnements ; et surtout lorsqu'un envoi échoue avec "pas d'agent dans cette conversation", "renvoyez avec la ref", ou que l'appelant n'a pas le socket de messagerie natif de Claude.
