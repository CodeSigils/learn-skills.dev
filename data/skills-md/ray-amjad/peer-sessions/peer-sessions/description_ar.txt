قم بتشغيل مجموعة من جلسات Claude Code على هذا الجهاز واجعلهم يتحدثون مع بعضهم البعض باستخدام SendMessage - من Claude Code نفسه أو من خلال جهاز Claude Relay الحقيقي عندما يكون المتصل هو Codex. قم بتشغيلها في نوافذ وأجزاء وانقسامات cmux، وقم بمعالجتها بشكل صحيح، وقم بتوزيع العمل، وجمع الردود أو استعادتها، وقم بتمزيقها بشكل نظيف عندما يطلب المستخدم ذلك. يُستخدم عندما يريد المستخدم أن تعمل جلستان أو أكثر من جلسات Claude معًا، أو يطلب من Codex الاتصال بجلسة Claude موجودة، أو يذكر SendMessage، أو ListAgents، أو جلسات النظراء، أو المراسلة عبر الجلسات، أو الوكلاء الذين يقومون بمراسلة بعضهم البعض؛ متى أرادوا عقد جلسات في نوافذ أو مساحات عمل أو أجزاء أو أقسام جديدة؛ وخاصة عندما يفشل الإرسال مع عبارة "ليس وكيلاً في هذه المحادثة"، أو "إعادة الإرسال باستخدام المرجع"، أو أن المتصل يفتقر إلى مقبس المراسلة الأصلي الخاص بـ Claude.
