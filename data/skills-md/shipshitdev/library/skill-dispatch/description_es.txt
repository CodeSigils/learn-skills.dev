Puerta de entrada única para crear y mantener habilidades de agentes. Analiza un subcomando (crear, capturar, cumplir o explorar) y lo dirige al motor correcto: creador de habilidades (guía para crear o actualizar una habilidad), captura de habilidades (extrae un flujo de trabajo de la conversación a un SKILL.md), cumplimiento de habilidades (mide si los agentes siguen una habilidad o regla) o exploración de habilidades (busca habilidades existentes antes de crear otras nuevas). Respalda el comando /skill. Úselo cuando se le solicite crear una habilidad, capturar un patrón, probar el cumplimiento de una habilidad o explorar una habilidad existente, y la acción debe elegirse a partir de un argumento como "crear", "capturar", "cumplir" o "explorar".
