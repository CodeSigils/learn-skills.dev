Generieren Sie Rasterbilder (Symbole, Illustrationen, Texturen, App-Symbole) aus einer Texteingabeaufforderung, indem Sie das Bildtool der Codex-CLI steuern und dann das fertige PNG aus dem Codex-Sitzungs-Rollout extrahieren. Verwenden Sie diese Option, wenn ein Agent ein real generiertes Bild benötigt und über kein natives Bildgenerierungstool verfügt. Erfordert die angemeldete „codex“-CLI.
