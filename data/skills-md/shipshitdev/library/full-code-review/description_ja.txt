3 つの並行次元エージェント (構造、セキュリティ、開発/フラグ衛生) にわたってファンアウト PR レビューを行い、すべての結果を敵対的に検証し、最強層の裁判官によって優先順位の高い単一の評決を総合します。ブランチまたは PR の完全、包括的、またはエンドツーエンドのレビューを求められた場合に使用します。/code-review が正確さに合格した後、このスキルは、セキュリティの深さ、構造の健全性、devex の回帰、および機能フラグの健全性など、そうでない直交する次元をカバーします。レトロ モード (コミット ログが渡される) では、クロスコミット レンズが追加され、マージ判定の代わりに優先順位付きのバックログが出力されます。
