Verteilen Sie die PR-Überprüfung auf drei parallele Dimensionen (Struktur, Sicherheit, Devex/Flag-Hygiene), verifizieren Sie jedes Ergebnis kontradiktorisch und fassen Sie über einen Richter der stärksten Ebene ein einziges priorisiertes Urteil zusammen. Wird verwendet, wenn Sie um eine vollständige, umfassende oder End-to-End-Überprüfung eines Zweigs oder einer PR gebeten werden. Nachdem /code-review die Richtigkeit bestanden hat, deckt diese Fähigkeit die orthogonalen Dimensionen ab, die sie nicht erfüllt: Sicherheitstiefe, strukturelle Gesundheit, Devex-Regressionen und Feature-Flag-Hygiene. Im Retro-Modus (ein Commit-Protokoll wird übergeben) wird eine Cross-Commit-Linse hinzugefügt und ein priorisierter Rückstand anstelle eines Zusammenführungsurteils ausgegeben.
