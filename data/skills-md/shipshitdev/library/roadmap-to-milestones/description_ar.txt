قم بتحويل خريطة الطريق المصنفة للإيرادات إلى معالم GitHub المتعقبة مع تواريخ الاستحقاق، وقم بتعيين المشكلات لها، والإبلاغ عن التعطل. الأعمال المتراكمة لمحلل خارطة طريق Bridges إلى لوحة حلقة التطوير. استخدمه عندما يُطلب منك إنشاء مراحل رئيسية، أو تحديد تواريخ استحقاق المعالم الرئيسية، أو تجميع المشكلات ضمن المعالم الرئيسية، أو تحويل خريطة الطريق إلى جدول زمني، أو تتبع تقدم المعالم الرئيسية. يقوم بإنشاء وتحرير معالم GitHub فقط بعد التأكيد.
