Conseils de débogage systématique pour les bogues, les échecs, les comportements inattendus et les régressions de performances. Met l'accent sur les boucles de rétroaction reproductibles, les tests d'hypothèses, l'instrumentation, les correctifs et les tests de régression. À utiliser lors de l'enquête sur un bogue, un comportement inattendu, un crash, une sortie incorrecte ou une régression des performances, ou lors du tri des rapports de bogues entrants.
