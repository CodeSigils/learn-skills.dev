يقوم بتحميل سياق المشروع المهم وتاريخ الجلسة الأخيرة في بداية كل جلسة أو بعد `/clear` - يقرأ `.agents/memory/` ملفات مصدر الحقيقة، ويفتح الأسطح الخطوات التالية من سجل الجلسة الأخير، وينشط مستند الجلسة. المشغلات عند: بدء الجلسة، أو `/clear`، أو "تحميل السياق"، أو "بدء الجلسة"، أو الرسالة الأولى في جلسة وكيل جديدة.
