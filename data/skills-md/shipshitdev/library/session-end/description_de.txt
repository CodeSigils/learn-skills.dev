Speichern Sie die Sitzungsnachbearbeitungsdokumentation, bevor Sie den Kontext löschen, indem Sie den Sitzungsdokumentations-Workflow ausführen und „.agents/sessions/YYYY-MM-DD.md“ schreiben. Verwenden Sie diese Option, wenn Sie eine Sitzung beenden, sich auf die Ausführung von „/clear“ vorbereiten oder aufgefordert werden, zu dokumentieren, was sich geändert hat, bevor der Kontext zurückgesetzt wird.
