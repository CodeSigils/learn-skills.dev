Créez une version sur le tronc - vérifiez que les vérifications CI requises sont vertes, puis coupez une version (balise semver + version GitHub) ou ouvrez une version PR dans la branche par défaut. Le déploiement dans les environnements de test et de production est piloté par les pipelines et les balises CI/CD, et non par les PR de branche. À utiliser lorsque l'utilisateur demande la publication, ouvre une version PR, coupe une balise, attend que les vérifications GitHub passent au vert ou vérifie que le tronc est prêt à être publié.
