Controle una versión en la troncal: verifique que las comprobaciones de CI requeridas estén en verde, luego corte una versión (etiqueta semver + versión de GitHub) o abra un PR de versión en la rama predeterminada. La implementación en entornos de ensayo y producción está impulsada por etiquetas y canalizaciones de CI/CD, no por relaciones públicas de sucursales. Úselo cuando el usuario solicite la liberación, abra un PR de liberación, corte una etiqueta, espere a que las comprobaciones de GitHub se vuelvan verdes o verifique que la troncal esté lista para liberarse.
