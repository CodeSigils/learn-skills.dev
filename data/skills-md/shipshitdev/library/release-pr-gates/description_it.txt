Effettua il gate di una versione sul trunk: verifica che i controlli CI richiesti siano verdi, quindi taglia una versione (tag semver + versione GitHub) o apri una PR di versione nel ramo predefinito. La distribuzione negli ambienti di gestione temporanea e di produzione è guidata da pipeline e tag CI/CD, non da PR di filiale. Da utilizzare quando l'utente chiede di rilasciare, aprire un PR di rilascio, tagliare un tag, attendere che i controlli GitHub diventino verdi o verificare che il trunk sia pronto per il rilascio.
