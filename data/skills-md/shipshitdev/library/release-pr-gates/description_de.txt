Gate ein Release auf dem Trunk – überprüfen Sie, ob die erforderlichen CI-Prüfungen grün sind, und schneiden Sie dann ein Release aus (Semver-Tag + GitHub-Release) oder öffnen Sie ein Release-PR im Standardzweig. Die Bereitstellung in Staging- und Produktionsumgebungen wird durch CI/CD-Pipelines und Tags gesteuert, nicht durch Branch-PRs. Verwenden Sie diese Option, wenn der Benutzer eine Veröffentlichung anfordert, eine Veröffentlichungs-PR öffnet, ein Tag ausschneidet, darauf wartet, dass GitHub-Prüfungen grün werden, oder überprüft, ob der Trunk zur Veröffentlichung bereit ist.
