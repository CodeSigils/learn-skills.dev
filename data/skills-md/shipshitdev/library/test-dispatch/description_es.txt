Puerta frontal única para pruebas. Analiza un subcomando (ejecutar, qa, tdd, e2e, cobertura, init o regresión) y lo dirige al motor de prueba correcto: test-runner (ejecutar pruebas, corregir fallas), qa-reviewer (pase de verificación estructurada del trabajo completado), tdd (flujo de trabajo de refactor rojo-verde), dramaturgo-e2e-init (pruebas de andamiaje E2E para proyectos frontend), husky-test-coverage (aplica umbrales de cobertura a través de ganchos de git), testing-cicd-init (configuración de CI de Vitest + GitHub Actions) o ai-regression-testing (diseño de pruebas de regresión dirigidas a puntos ciegos de IA). Respalda el comando /test. Úselo cuando se le solicite ejecutar pruebas, escribir pruebas, configurar pruebas, verificar la cobertura o iniciar TDD, y la acción debe seleccionarse de un argumento como "ejecutar", "qa", "tdd", "e2e", "cobertura", "init" o "regresión".
