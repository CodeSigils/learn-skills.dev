Porta singola per prove. Analizza un sottocomando - run, qa, tdd, e2e, cover, init o regression - e lo indirizza al motore di test corretto: test-runner (esegui test, corregge errori), qa-reviewer (passaggio di verifica strutturata sul lavoro completato), tdd (flusso di lavoro red-green-refactor), playwright-e2e-init (test E2E con impalcatura per progetti frontend), husky-test-coverage (applica soglie di copertura tramite git hook), testing-cicd-init (configurazione CI Vitest + GitHub Actions) o ai-regression-testing (test di regressione di progettazione mirati ai punti ciechi dell'IA). Supporta il comando /test. Da utilizzare quando viene richiesto di eseguire test, scrivere test, impostare test, controllare la copertura o avviare TDD e l'azione deve essere scelta da un argomento come "run", "qa", "tdd", "e2e", "coverage", "init" o "regression".
