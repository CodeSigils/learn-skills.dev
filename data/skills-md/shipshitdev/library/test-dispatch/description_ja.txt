テスト用の単一の正面ドア。サブコマンド (run、qa、tdd、e2e、カバレッジ、init、または回帰) を解析し、適切なテスト エンジンにルーティングします: test-runner (テストの実行、失敗の修正)、qa-reviewer (完了した作業の構造化検証パス)、tdd (red-green-refactor ワークフロー)、playwright-e2e-init (フロントエンド プロジェクトの E2E テストの足場)、husky-test-coverage (カバレッジの強制) git フック経由のしきい値)、testing-cicd-init (Vitest + GitHub Actions CI セットアップ)、または ai-regression-testing (AI の盲点を対象とした回帰テストの設計)。 /test コマンドをバックアップします。テストの実行、テストの作成、テストのセットアップ、カバレッジのチェック、または TDD の開始を求められた場合に使用します。アクションは、「ru​​n」、「qa」、「tdd」、「e2e」、「coverage」、「init」、「regression」などの引数から選択する必要があります。
