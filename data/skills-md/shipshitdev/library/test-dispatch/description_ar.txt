باب أمامي واحد للاختبار. يوزع أمرًا فرعيًا — run، أو qa، أو tdd، أو e2e، أو Coverage، أو init، أو regression — ويوجه إلى محرك الاختبار الصحيح: test-runner (اختبارات التشغيل، إصلاح الأعطال)، qa-reviewer (تمرير التحقق المنظم على العمل المكتمل)، tdd (سير عمل أحمر-أخضر-refactor)، playwright-e2e-init (اختبارات السقالة E2E لمشاريع الواجهة الأمامية)، husky-test-coverage (فرض حدود التغطية عبر git Hooks)، أو test-cicd-init (إعداد Vitest + GitHub Actions CI)، أو اختبار ai-regression (اختبارات انحدار التصميم التي تستهدف النقاط العمياء في الذكاء الاصطناعي). يدعم الأمر /test. استخدم عندما يُطلب منك تشغيل الاختبارات أو كتابة الاختبارات أو إعداد الاختبار أو التحقق من التغطية أو بدء TDD، ويجب اختيار الإجراء من وسيطة مثل "run" أو "qa" أو "tdd" أو "e2e" أو "coverage" أو "init" أو "regression".
