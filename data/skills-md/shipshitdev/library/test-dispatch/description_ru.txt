Одна входная дверь для тестирования. Анализирует подкоманду — run, qa, tdd, e2e, покрытие, init или регрессию — и направляет к нужному механизму тестирования: test-runner (запуск тестов, исправление сбоев), qa-reviewer (структурированный этап проверки завершенной работы), tdd (рабочий процесс красно-зеленого рефакторинга), playwright-e2e-init (тесты E2E scaffold для внешних проектов), husky-test-coverage (обеспечение пороговых значений покрытия через git) перехватчики), test-cicd-init (настройка Vitest + GitHub Actions CI) или ai-reгрессионное тестирование (разработка регрессионных тестов, нацеленных на слепые зоны ИИ). Поддерживает команду /test. Используйте, когда вас просят запустить тесты, написать тесты, настроить тестирование, проверить покрытие или запустить TDD, а действие необходимо выбрать из аргумента, такого как «запустить», «qa», «tdd», «e2e», «покрытие», «init» или «регрессия».
