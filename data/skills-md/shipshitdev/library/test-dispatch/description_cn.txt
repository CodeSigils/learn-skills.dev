用于测试的单前门。解析子命令——run、qa、tdd、e2e、coverage、init或regression——并路由到正确的测试引擎：test-runner（运行测试、修复故障）、qa-reviewer（对已完成工作进行结构化验证）、tdd（红绿重构工作流程）、playwright-e2e-init（前端项目的支架E2E测试）、husky-test-coverage（通过强制覆盖阈值） git hooks）、testing-cicd-init（Vitest + GitHub Actions CI 设置）或 ai-regression-testing（针对 AI 盲点的设计回归测试）。支持 /test 命令。当被要求运行测试、编写测试、设置测试、检查覆盖率或启动 TDD 时使用，并且必须从“run”、“qa”、“tdd”、“e2e”、“coverage”、“init”或“regression”等参数中选择操作。
