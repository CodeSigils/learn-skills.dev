Audita todo un repositorio privado una vez, cuando se decide hacerlo público. Ejecuta cuatro pases: licencia y atribución, secretos en todo el historial de git, referencias privadas (nombres de host internos, correos electrónicos de empleados, nombres de clientes y clientes, URL provisionales) y preparación para la publicación, y luego devuelve un veredicto de publicación o bloqueo. Úselo cuando el usuario se está preparando para abrir un repositorio, pregunta si es seguro publicar una base de código, quiere una auditoría previa al lanzamiento antes de convertir un repositorio en público o necesita saber qué sigue siendo privado en el código que está a punto de enviarse públicamente.
