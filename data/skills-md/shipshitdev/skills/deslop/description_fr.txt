Enlevez le gâchis généré par l’IA d’une base de code, d’un produit et d’un texte. Gâchis de code — instructions console, types `any`, imports inutilisés, code commenté, commentaires redondants, try‑catch défensif inutile sur des chemins fiables, sur‑imbriquement. Gâchis de produit (avec --product) — texte de remplissage marketing, formulations génériques d’IA, apparence par défaut de shadcn, états de chargement/erreur non stylisés, boutons morts et flux à moitié câblés. Gâchis d’UI (`ui`) lance un passage primitive du système de conception dérivé du projet. Gâchis de prose (`prose`) supprime les interventions de l’IA dans l’écriture. Peut être limité au diff de la branche actuelle ou balayer tout l’arbre. À utiliser lorsqu’on vous demande de nettoyer le code généré par l’IA, d’éliminer le gâchis du texte, de retirer le gâchis, ou de faire en sorte qu’une application paraisse terminée avant de l’expédier aux clients.
