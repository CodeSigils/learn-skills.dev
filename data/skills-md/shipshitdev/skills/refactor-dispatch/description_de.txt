Ein einziger Einstiegspunkt zur Verbesserung bestehenden Codes — leitet je nach Modus an die passende Engine weiter: deslop (AI‑Schlupf entfernen, Code + Produkt), code (sichere, verhaltensbewahrende Refaktur), debt (Technikverschuldungs‑Register), perf (Frontend‑ + Backend‑Optimierung), structure (nur‑lesende strukturelle Überprüfung) oder stack (Abhängigkeits‑ + Framework‑Muster‑Modernisierung). Unterstützt den Befehl /refactor. Verwenden, wenn nach Refaktur, Aufräumen, Deslop, Abbau technischer Schulden, Optimierung oder Modernisierung gefragt wird, und der Modus muss aus einem Argument wie „deslop“, „debt“, „perf“ oder „stack“ ausgewählt werden.
