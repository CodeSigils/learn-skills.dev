Une porte d'entrée unique pour améliorer le code existant — oriente vers le bon moteur selon le mode : deslop (supprimer le surplus d’IA, code + produit), code (refactorisation sûre préservant le comportement), debt (registre de la dette technique), perf (optimisation du front‑end et du back‑end), structure (revue structurelle en lecture seule), ou stack (modernisation des dépendances et des modèles de framework). Supporte la commande /refactor. À utiliser lorsqu’on demande de refactoriser, nettoyer, déslopper, réduire la dette technique, optimiser ou moderniser, et le mode doit être choisi parmi un argument tel que « deslop », « debt », « perf » ou « stack ».
