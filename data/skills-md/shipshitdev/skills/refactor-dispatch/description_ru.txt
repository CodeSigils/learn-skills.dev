Единая входная дверь для улучшения существующего кода — маршруты к нужному движку по режиму: deslop (удаление ошибок AI, код + продукт), код (безопасный рефакторинг, сохраняющий поведение), долг (регистр технического долга), производительность (оптимизация внешнего интерфейса + серверная часть), структура (структурный обзор только для чтения) или стек (зависимость + модернизация шаблона инфраструктуры). Поддерживает команду /refactor. Используйте, когда вас просят провести рефакторинг, очистку, дезалог, погашение технического долга, оптимизацию или модернизацию, а режим должен быть выбран из таких аргументов, как «удалить», «долг», «производительность» или «стек».
