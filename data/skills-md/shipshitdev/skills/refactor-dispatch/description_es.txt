Puerta única para mejorar el código existente — dirige al motor correcto según el modo: deslop (eliminar el exceso de IA, código + producto), code (refactor seguro que preserva el comportamiento), debt (registro de deuda técnica), perf (optimización frontend + backend), structure (revisión estructural de solo lectura) o stack (modernización de dependencias + patrones de framework). Respaldado por el comando /refactor. Úsalo cuando se solicite refactorizar, limpiar, deslop, pagar deuda técnica, optimizar o modernizar, y el modo debe elegirse a partir de un argumento como “deslop”, “debt”, “perf” o “stack”.
