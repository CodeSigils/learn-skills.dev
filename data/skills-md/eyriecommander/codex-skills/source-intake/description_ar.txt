يُستخدم عندما يجب الحفاظ على مصدر وارد وتفسيره ونشره اختياريًا في حالة مشروع دائمة، بما في ذلك لقطات الشاشة أو صفحات الويب أو المنشورات الاجتماعية أو المقالات أو الكتب أو الأوراق أو مقتطفات الاجتماعات أو مقتطفات البريد الإلكتروني أو ملفات PDF أو ملاحظات الريبو أو صفحات المنتج أو المواد المصدر المقدمة من المستخدم. لا تستخدم لملخصات لمرة واحدة إلا إذا طلب المستخدم دمج المصدر في نظام أو مشروع أو لوحة أو مستند أو مهارة أو ملاحظة أو متابعة.
