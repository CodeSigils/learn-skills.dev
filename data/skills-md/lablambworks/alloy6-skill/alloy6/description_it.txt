Progetta, scrivi, rivedi, esegui il debug, migra, spiega e verifica i modelli in lega 6. Utilizza questa abilità ogni volta che l'utente menziona esplicitamente il linguaggio Alloy, Alloy 6, Alloy Analyser, un file .als, un modello Alloy esistente, apprende o insegna Alloy oppure chiede di esprimere un problema relazionale, temporale, di controllo degli accessi, di protocollo o di sicurezza specificatamente in Alloy. Utilizzalo anche quando i file dell'area di lavoro rilevanti sono modelli Alloy o durante la modernizzazione di modelli Stato/Tempo espliciti pre-Alloy-6. Non utilizzarlo per database SQL o relazionali, TLA+, predicati/asserzioni generici, configurazione Grafana Alloy o leghe metalliche a meno che l'utente non richieda esplicitamente un modello Alloy.
