Fügen Sie einem Live-LiteLLM-Proxy ein neues Modell hinzu. Führt den Benutzer durch die Auswahl eines Anbieters, gibt den Bereitstellungsnamen und die Anmeldeinformationen ein, ruft POST /model/new auf und ruft dann das Modell testweise auf, um zu bestätigen, dass es korrekt weitergeleitet wird. Verwenden Sie diese Option, wenn der Benutzer ein neues Modell auf einer LiteLLM-Proxy-Instanz hinzufügen, registrieren, bereitstellen oder konfigurieren möchte.
