Agregue un nuevo modelo a un proxy LiteLLM en vivo. Guía al usuario en la elección de un proveedor, ingresa el nombre de la implementación y las credenciales, llama a POST /model/new y luego realiza una prueba de llamada al modelo para confirmar que se enruta correctamente. Úselo cuando el usuario desee agregar, registrar, implementar o configurar un nuevo modelo en una instancia de proxy LiteLLM.
