Ajoutez un nouveau modèle à un proxy LiteLLM en direct. Guide l'utilisateur dans la sélection d'un fournisseur, en saisissant le nom de déploiement et les informations d'identification, appelle POST /model/new, puis teste le modèle pour confirmer qu'il achemine correctement. À utiliser lorsque l'utilisateur souhaite ajouter, enregistrer, déployer ou configurer un nouveau modèle sur une instance de proxy LiteLLM.
