Создайте новый ключ API на работающем прокси-сервере LiteLLM. Запрашивает псевдоним, область действия (пользователь/команда), бюджет, модели и срок действия, а затем вызывает POST /key/generate. Используйте, когда пользователь хочет создать, сгенерировать или предоставить ключ API для экземпляра прокси-сервера LiteLLM.
