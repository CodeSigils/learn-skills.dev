أنشئ تطبيقات في الوقت الفعلي باستخدام ws-asyncapi — إطار عمل WebSocket الذي تم كتابته من البداية إلى النهاية لـ TypeScript. استخدم لأي مهمة ws-asyncapi: `ws-asyncapi`/`@ws-asyncapi/*` imports، `new Channel()`، تعريف serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth، الخدمة مع `createNodeWsServer`/`wsAsyncAPIAdapter`، المكتوب `createClient<typeofchannel>()`، روابط React (`createReactClient`)/Solid (`createSolidClient`)، والمؤشرات المباشرة (`@ws-asyncapi/cursors`)، وقياس Redis، وإعادة الاتصال/الاسترداد، ومولد ترميز AsyncAPI. قم بالتنشيط بمجرد رؤية واجهات برمجة التطبيقات هذه أو عند إنشاء دردشة أو حضور أو مؤشرات متعددة اللاعبين أو لوحات معلومات مباشرة أو إشعارات أو RPC مكتوب عبر WebSockets.
