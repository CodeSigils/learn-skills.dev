Crea app in tempo reale con ws-asyncapi: il framework WebSocket tipizzato end-to-end per TypeScript, basato sul contratto. Utilizzare per QUALSIASI attività ws-asyncapi: `ws-asyncapi`/`@ws-asyncapi/*` importazioni, `new Channel()`, definizione di serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth, servizio con `createNodeWsServer`/`wsAsyncAPIAdapter`, il tipo `createClient<typeof channel>()`, React (`createReactClient`)/Solid (`createSolidClient`), cursori attivi (`@ws-asyncapi/cursors`), ridimensionamento Redis, riconnessione/ripristino e codegen AsyncAPI. Attiva alla vista di queste API o durante la creazione di chat, presenza, cursori multiplayer, dashboard live, notifiche o RPC digitato su WebSocket.
