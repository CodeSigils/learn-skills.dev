ws-asyncapi を使用してリアルタイム アプリを構築します。これは、TypeScript 用のコントラクトファースト、エンドツーエンドの型指定された WebSocket フレームワークです。あらゆる ws-asyncapi タスクに使用: `ws-asyncapi`/`@ws-asyncapi/*` インポート、`new Channel()`、serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth の定義、`createNodeWsServer`/`wsAsyncAPIAdapter` での提供、型指定された `createClient<typeof channel>()`、React (`createReactClient`)/Solid (`createSolidClient`) バインディング、ライブ カーソル (`@ws-asyncapi/cursors`)、Redis スケーリング、再接続/回復、および AsyncAPI codegen。これらの API を見つけたとき、またはチャット、プレゼンス、マルチプレイヤー カーソル、ライブ ダッシュボード、通知、または WebSocket 上の型付き RPC を構築するときにアクティブ化します。
