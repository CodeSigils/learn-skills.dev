Erstellen Sie Echtzeit-Apps mit ws-asyncapi – dem vertragsorientierten, durchgängig typisierten WebSocket-Framework für TypeScript. Für JEDE ws-asyncapi-Aufgabe verwenden: „ws-asyncapi“/„@ws-asyncapi/*“-Importe, „new Channel()“, Definition von serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth, Bereitstellung mit „createNodeWsServer“/„wsAsyncAPIAdapter“, dem typisierten „createClient<typeofchannel>()“, React (`createReactClient`)/Solid (`createSolidClient`)-Bindungen, Live-Cursor (`@ws-asyncapi/cursors`), Redis-Skalierung, Wiederverbindung/Wiederherstellung und AsyncAPI-Codegenerierung. Aktivieren Sie diese APIs, wenn Sie sie sehen oder wenn Sie Chat, Präsenz, Multiplayer-Cursor, Live-Dashboards, Benachrichtigungen oder eingegebenes RPC über WebSockets erstellen.
