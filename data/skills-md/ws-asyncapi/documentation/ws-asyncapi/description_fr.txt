Créez des applications en temps réel avec ws-asyncapi, le framework WebSocket typé de bout en bout et axé sur le contrat pour TypeScript. À utiliser pour TOUTE tâche ws-asyncapi : importations `ws-asyncapi`/`@ws-asyncapi/*`, `new Channel()`, définition de serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth, service avec `createNodeWsServer`/`wsAsyncAPIAdapter`, le type `createClient<typeof channel>()`, React Liaisons (`createReactClient`)/Solid (`createSolidClient`), curseurs en direct (`@ws-asyncapi/cursors`), mise à l'échelle Redis, reconnexion/récupération et génération de code AsyncAPI. Activez à la vue de ces API ou lors de la création de discussions, de présence, de curseurs multijoueurs, de tableaux de bord en direct, de notifications ou de RPC tapés sur WebSockets.
