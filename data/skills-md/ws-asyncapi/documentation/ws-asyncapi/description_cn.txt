使用 ws-asyncapi 构建实时应用程序 - TypeScript 的契约优先、端到端类型化 WebSocket 框架。用于任何 ws-asyncapi 任务：`ws-asyncapi`/`@ws-asyncapi/*` 导入、`new Channel()`、定义 serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth、与 `createNodeWsServer`/`wsAsyncAPIAdapter` 一起服务、类型化的 `createClient<typeof channel>()`、React (`createReactClient`)/Solid (`createSolidClient`) 绑定、实时游标 (`@ws-asyncapi/cursors`)、Redis 扩展、重新连接/恢复和 AsyncAPI 代码生成。在看到这些 API 时或在构建聊天、在线状态、多人游戏光标、实时仪表板、通知或通过 WebSocket 键入的 RPC 时激活。
