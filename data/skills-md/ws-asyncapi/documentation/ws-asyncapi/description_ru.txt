Создавайте приложения реального времени с помощью ws-asyncapi — контрактной сквозной типизированной платформы WebSocket для TypeScript. Используйте для ЛЮБОЙ задачи ws-asyncapi: импорт `ws-asyncapi`/`@ws-asyncapi/*`, `new Channel()`, определение serverMessage/clientMessage/rpc/serverRpc/stream/presence/history/onAuth, обслуживание с `createNodeWsServer`/`wsAsyncAPIAdapter`, типизированный `createClient<typeofchannel>()`, Привязки React (`createReactClient`)/Solid (`createSolidClient`), живые курсоры ("@ws-asyncapi/cursors`), масштабирование Redis, повторное подключение/восстановление и создание кода AsyncAPI. Активируйте при виде этих API или при создании чата, присутствия, многопользовательских курсоров, интерактивных информационных панелей, уведомлений или ввода RPC через WebSockets.
