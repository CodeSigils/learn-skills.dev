Устанавливайте, проверяйте, восстанавливайте и управляйте мостом CLIProxyAPI только с обратной связью, который регистрирует поддерживаемые подпиской модели Codex, Grok, Antigradity/Gemini или недавно добавленные модели CLI в WorkBuddy. Используйте всякий раз, когда пользователь просит подключить локальный интерфейс командной строки или модель агента к WorkBuddy, установить CLIProxyAPI, добавить или исправить пользовательскую модель WorkBuddy, сохранить возможности изображения/инструмента/обоснования/быстрого выполнения, подключить другого поставщика CLI или диагностировать модель WorkBuddy, которая перестала работать. Этот навык в первую очередь предназначен для macOS, и его следует использовать, даже если пользователь называет только модель или сообщает, что срок действия его локального API WorkBuddy истек.
