تثبيت وتدقيق وإصلاح وإدارة جسر CLIProxyAPI للاسترجاع فقط والذي يسجل نماذج Codex أو Grok أو Antigravity/Gemini أو نماذج CLI المضافة حديثًا في WorkBuddy وتدقيقها وإصلاحها. يُستخدم عندما يطلب المستخدم توصيل نموذج CLI محلي أو نموذج وكيل بـ WorkBuddy، أو تثبيت CLIProxyAPI، أو إضافة نموذج WorkBuddy المخصص أو إصلاحه، أو الحفاظ على الصورة/الأداة/الاستدلال/القدرات السريعة، أو تضمين موفر CLI آخر، أو تشخيص نموذج WorkBuddy الذي توقف عن العمل. هذه المهارة هي macOS أولاً ويجب استخدامها حتى عندما يقوم المستخدم بتسمية النموذج فقط أو يقول إن WorkBuddy API المحلي الخاص به قد انتهت صلاحيته.
