Installieren, prüfen, reparieren und verwalten Sie eine reine Loopback-CLProxyAPI-Brücke, die abonnementgestützte Codex-, Grok-, Antigravity/Gemini- oder neu hinzugefügte CLI-Modelle in WorkBuddy registriert. Verwenden Sie diese Option immer dann, wenn der Benutzer eine Verbindung zu einer lokalen CLI oder einem Agentenmodell mit WorkBuddy herstellen, CLIProxyAPI installieren, ein benutzerdefiniertes WorkBuddy-Modell hinzufügen oder reparieren, Image-/Tool-/Reasoning-/Fast-Funktionen beibehalten, einen anderen CLI-Anbieter integrieren oder ein WorkBuddy-Modell diagnostizieren möchte, das nicht mehr funktioniert. Dieser Skill ist macOS-first und sollte auch dann verwendet werden, wenn der Benutzer nur das Modell nennt oder angibt, dass seine lokale WorkBuddy-API abgelaufen ist.
