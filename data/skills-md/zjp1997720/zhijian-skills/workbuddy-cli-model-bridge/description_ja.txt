サブスクリプション付きの Codex、Grok、Antigravity/Gemini、または新しく追加された CLI モデルを WorkBuddy に登録するループバック専用 CLIProxyAPI ブリッジをインストール、監査、修復、管理します。ユーザーがローカル CLI またはエージェント モデルの WorkBuddy への接続、CLIProxyAPI のインストール、WorkBuddy カスタム モデルの追加または修復、イメージ/ツール/推論/高速機能の保持、別の CLI プロバイダーのオンボード、または動作を停止した WorkBuddy モデルの診断を要求するたびに使用します。このスキルは macOS 初のものであり、ユーザーがモデルのみを指定する場合や、ローカル WorkBuddy API の有効期限が切れていると述べた場合でも使用する必要があります。
