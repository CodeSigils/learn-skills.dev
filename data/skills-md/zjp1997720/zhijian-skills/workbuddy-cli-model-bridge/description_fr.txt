Installez, auditez, réparez et gérez un pont CLIProxyAPI en bouclage uniquement qui enregistre les modèles Codex, Grok, Antigravity/Gemini soutenus par abonnement ou les modèles CLI nouvellement ajoutés dans WorkBuddy. À utiliser chaque fois que l'utilisateur demande à connecter une CLI ou un modèle d'agent local à WorkBuddy, à installer CLIProxyAPI, à ajouter ou à réparer un modèle personnalisé WorkBuddy, à conserver les capacités d'image/outil/raisonnement/rapide, à intégrer un autre fournisseur CLI ou à diagnostiquer un modèle WorkBuddy qui a cessé de fonctionner. Cette compétence est d'abord macOS et doit être utilisée même lorsque l'utilisateur nomme uniquement le modèle ou indique que son API WorkBuddy locale a expiré.
