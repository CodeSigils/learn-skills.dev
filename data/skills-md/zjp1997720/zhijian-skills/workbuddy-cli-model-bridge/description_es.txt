Instale, audite, repare y administre un puente CLIProxyAPI de bucle invertido que registra Codex, Grok, Antigravity/Gemini o modelos CLI recientemente agregados con respaldo de suscripción en WorkBuddy. Úselo siempre que el usuario solicite conectar una CLI local o un modelo de agente a WorkBuddy, instalar CLIProxyAPI, agregar o reparar un modelo personalizado de WorkBuddy, conservar capacidades de imagen/herramienta/razonamiento/Fast, incorporar otro proveedor de CLI o diagnosticar un modelo de WorkBuddy que dejó de funcionar. Esta habilidad es exclusiva de macOS y debe usarse incluso cuando el usuario solo nombra el modelo o dice que su API local de WorkBuddy ha caducado.
