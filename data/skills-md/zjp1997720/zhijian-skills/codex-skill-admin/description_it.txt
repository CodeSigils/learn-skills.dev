Amministrazione delle competenze esclusivamente del Codex per controllare, abilitare, disabilitare, ripristinare e verificare le competenze del Codex locale. Da utilizzare quando l'utente chiede di gestire le competenze del Codex, ridurre il carico dei token delle competenze, chiudere le competenze inutilizzate senza disinstallarle, ripristinare le competenze disabilitate, ispezionare la visibilità delle competenze correnti o automatizzare l'abilitazione delle competenze tramite il protocollo ufficiale del server app del Codex.
