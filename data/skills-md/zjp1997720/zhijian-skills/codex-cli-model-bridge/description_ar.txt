تثبيت وتدقيق وإصلاح وإدارة موفري نماذج Codex المخصصة وكتالوجات النماذج المدعومة باسترجاع CLIProxyAPI أو Codex Router. يُستخدم عندما يطلب المستخدم إضافة نماذج الجهات الخارجية أو إزالتها أو ترقيتها أو استعادتها أو تشخيصها في Codex أو منتقي نماذج Codex لسطح المكتب؛ يذكر Grok، أو OpenCode Go، أو DeepSeek، أو Gemini، أو GLM Coding Plan، أو GLM-5.3، أو نماذج CLI المدعومة بالاشتراك، أو model_provider المخصص، أو model_catalog_json، أو وضع Codex Fast؛ أو يريد مزامنة نفس نماذج الوكيل المحلي بين Codex وWorkBuddy. الحفاظ على تكوينات الدستور الغذائي وبيانات الاعتماد غير ذات الصلة. ملف التعريف المعزول هو مسار Windows الافتراضي.
