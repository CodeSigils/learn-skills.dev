ループバック CLIProxyAPI または Codex Router を利用した Codex カスタム モデル プロバイダーとモデル カタログをインストール、監査、修復、管理します。ユーザーが Codex または Codex デスクトップ モデル ピッカーでサードパーティ モデルの追加、削除、アップグレード、復元、または診断を要求する場合は常に使用します。 Grok、OpenCode Go、DeepSeek、Gemini、GLM コーディング プラン、GLM-5.3、サブスクリプション支援 CLI モデル、カスタム model_provider、model_catalog_json、または Codex Fast モードについて言及しています。または、Codex と WorkBuddy の間で同じローカル プロキシ モデルを同期したい場合。無関係な Codex 構成と資格情報を保持します。分離されたプロファイルは、デフォルトの Windows パスです。
