قم بتزويد أي وكيل تم تسجيل دخوله إلى Codex CLI بإمكانية إنشاء الصور المحلية، دون الحاجة إلى أي تبعيات خاصة. عندما يذكر المستخدم إنشاء صور، أو رسم، أو إنشاء صور، أو تحويل نص إلى صورة، أو رسم توضيحي، أو غلاف، أو ملصق، أو إنشاء صورة بناءً على مطالبة، أو يريد إعادة استخدام حالة تسجيل دخول Codex OAuth من `~/.codex/auth.json` المحلي كبرنامج نصي قابل للتنفيذ، فيجب استخدام هذه المهارة بشكل تفضيلي. ينطبق هذا على Claude Code وCodex وOpenCode وأي وكيل آخر يمكنه تشغيل البرامج النصية bash أو python3.
