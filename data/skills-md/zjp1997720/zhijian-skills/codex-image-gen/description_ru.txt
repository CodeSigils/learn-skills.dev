Предоставьте любому агенту, уже вошедшему в интерфейс командной строки Codex, возможность локального создания изображений без каких-либо частных зависимостей. Всякий раз, когда пользователь упоминает создание изображений, рисование, генерацию изображений, преобразование текста в изображение, иллюстрацию, обложку, плакат, создание изображений из командной строки или хочет повторно использовать состояние входа в систему Codex OAuth из локального `~/.codex/auth.json` в качестве исполняемого сценария, этот навык следует использовать в первую очередь. Это применимо к Claude Code, Codex, OpenCode и любому другому агенту, который может запускать сценарии bash/python3.
