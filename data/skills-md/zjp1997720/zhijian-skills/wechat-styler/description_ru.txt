Преобразуйте статьи Markdown во встроенный HTML-код, который можно использовать в общедоступных учетных записях WeChat, с поддержкой переключения нескольких тем, структурированных компонентов и анимации открытия SVG. Он используется для макета общедоступной учетной записи, создания HTML-кода статей и в качестве замены нестабильных внешних сервисов макетирования. По умолчанию используется чистый макет; добавьте --компоненты, чтобы включить интеллектуальную перезапись агента (компоненты + анимация открытия).
