Преобразуйте статьи Markdown во встроенный HTML-код, который можно использовать в общедоступных учетных записях WeChat, с поддержкой переключения нескольких тем, структурированных компонентов и анимации открытия SVG. Используется для макетирования публичной учетной записи, создания HTML-кода статей и в качестве замены нестабильных служб внешнего форматирования. По умолчанию используется чистый макет; добавьте `--comComponents`, чтобы включить интеллектуальную перезапись агента (компоненты + анимация открытия).
