Converti articoli Markdown in HTML in stile in linea utilizzabile negli account pubblici WeChat, supportando il cambio di temi multipli, componenti strutturati e animazioni di apertura SVG. Viene utilizzato per il layout di account pubblici, la generazione di articoli HTML e in sostituzione di servizi di layout esterni instabili. L'impostazione predefinita è un layout pulito; aggiungi componenti per abilitare la riscrittura intelligente dell'agente (componenti + animazione di apertura).
