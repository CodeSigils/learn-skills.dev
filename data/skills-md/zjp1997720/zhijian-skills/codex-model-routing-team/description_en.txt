In the Codex App, create background tasks for complex, parallelizable knowledge work or programming tasks that allow specifying the model and inference intensity, with the primary Agent responsible for planning, defining provider data boundaries, division of labor, integration, and acceptance. These are used for multi-source research, multi-chapter content, complex Skills/PPTs, cross-module development, independent verification, or more than two mutually independent workflows; they are also used when users explicitly require model routing, background Workers, an Agents Team, Grok/Gemini Worker, or persistent project collaboration. Simple Q&A, status queries, minor single‑file edits, strictly sequential tasks, and publishing/payment/deletion/account operations must not be triggered automatically.
