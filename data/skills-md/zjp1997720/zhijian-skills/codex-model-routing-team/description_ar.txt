في تطبيق Codex، قم بإنشاء مهام خلفية للأعمال المعرفية المعقدة أو القابلة للتوازي أو مهام البرمجة التي تسمح بتحديد النموذج وكثافة الاستدلال، مع الوكيل الأساسي المسؤول عن التخطيط وتحديد حدود بيانات الموفر وتقسيم العمل والتكامل والقبول. يتم استخدامها للبحث متعدد المصادر، أو المحتوى متعدد الفصول، أو المهارات / عروض PPT المعقدة، أو التطوير عبر الوحدات، أو التحقق المستقل، أو أكثر من سير عمل مستقل بشكل متبادل؛ يتم استخدامها أيضًا عندما يطلب المستخدمون بشكل صريح توجيه النموذج، أو عمال الخلفية، أو فريق الوكلاء، أو عامل Grok/Gemini، أو التعاون المستمر في المشروع. يجب ألا يتم تشغيل الأسئلة والأجوبة البسيطة، واستعلامات الحالة، والتحريرات البسيطة للملف الفردي، والمهام المتسلسلة بدقة، وعمليات النشر/الدفع/الحذف/الحساب تلقائيًا.
