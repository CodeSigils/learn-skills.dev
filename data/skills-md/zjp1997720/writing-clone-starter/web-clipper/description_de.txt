Entfernen Sie den Hauptinhalt einer einzelnen Artikel-URL oder einer Artikelindex-/Archivseite und speichern Sie ihn lokal als Markdown. Wenn Benutzer „Artikel sammeln“, „Webseite speichern“, „Artikel stapelweise von einer Seite entfernen“, „Die ersten N Elemente von dieser Archivseite abrufen“ oder „in Obsidian/Clippings/lokal speichern“ erwähnen, sollte dieser Ansatz Vorrang haben. Es eignet sich besonders für öffentliche Webseiten, Substacks, Blog-Artikelseiten und Artikelarchivseiten. Wenn Sie auf Lazy-Loaded-Listen, dynamische Seiten oder unvollständiges statisches Scraping stoßen, verwenden Sie zunächst einen Browser, um die Artikel-URLs zu erfassen, und führen Sie dann ein Skript zum Batch-Download aus, wobei Sie die Erfolgsquote priorisieren.
