Holen Sie sich den Hauptinhalt von einer einzelnen Artikel-URL oder einer Artikelindex-/Archivseite und speichern Sie ihn lokal als Markdown. Wenn der Benutzer „Artikel sammeln“, „Webseite speichern“, „Artikel auf einer Seite stapelweise abrufen“, „Die ersten N Elemente von dieser Archivseite herunterziehen“ oder „in Obsidian/Clippings/lokal speichern“ erwähnt, muss dieser Ansatz Vorrang haben. Es eignet sich besonders für öffentliche Webseiten, Substacks, Blog-Artikelseiten und Artikelarchivseiten. Wenn Sie auf verzögert geladene Listen, dynamische Seiten oder unvollständiges statisches Scraping stoßen, erfassen Sie zunächst die Artikel-URLs mit einem Browser und rufen Sie dann ein Skript zur Stapelspeicherung auf, wobei Sie die Erfolgsquote priorisieren.
