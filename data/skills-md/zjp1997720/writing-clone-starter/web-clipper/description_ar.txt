قم باستخراج المحتوى الرئيسي من عنوان URL لمقالة واحدة أو صفحة فهرس/أرشيف المقالة واحفظه محليًا باسم Markdown. عندما يذكر المستخدمون "جمع المقالة"، أو "حفظ صفحة الويب"، أو "جمع المقالات من الصفحة"، أو "سحب العناصر N الأولى من صفحة الأرشيف هذه"، أو "الحفظ في Obsidian / Clippings / محليًا"، يجب إعطاء الأولوية لهذا النهج. إنها مناسبة بشكل خاص لصفحات الويب العامة وSubstack وصفحات مقالات المدونات وصفحات أرشيف المقالات. إذا واجهت قوائم محملة ببطء، أو صفحات ديناميكية، أو نسخًا ثابتًا غير مكتمل، فاستخدم أولاً متصفحًا لجمع عناوين URL للمقالات، ثم قم بتشغيل برنامج نصي للتنزيل المجمع، مع إعطاء الأولوية لمعدل النجاح.
