単一の記事の URL または記事のインデックス/アーカイブ ページからメイン コンテンツを取得し、Markdown としてローカルに保存します。ユーザーが「記事を収集する」、「ウェブページを保存する」、「ページ上の記事をバッチフェッチする」、「このアーカイブ ページから最初の N 項目を取得する」、または「Obsidian / Clippings / ローカルに保存する」と述べた場合、それを優先する必要があります。これは、公開 Web ページ、サブスタック、ブログ記事ページ、記事アーカイブ ページに特に適しています。遅延ロードされたリスト、動的ページ、または不完全な静的スクレイピングが発生した場合は、まずブラウザを使用して記事の URL を収集し、次に成功率を優先してバッチ ダウンロードするスクリプトを呼び出します。
