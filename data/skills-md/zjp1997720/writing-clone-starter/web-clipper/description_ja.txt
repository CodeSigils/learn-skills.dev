単一の記事 URL または記事インデックス/アーカイブ ページからメイン コンテンツをスクレイピングし、Markdown としてローカルに保存します。ユーザーが「記事を収集する」、「Web ページを保存する」、「ページから記事をバッチ スクレイピングする」、「このアーカイブ ページから最初の N 項目を取得する」、または「Obsidian / Clippings / ローカルに保存する」と述べた場合、このアプローチを優先する必要があります。これは、公開 Web ページ、サブスタック、ブログ記事ページ、記事アーカイブ ページに特に適しています。遅延ロードされたリスト、動的ページ、または不完全な静的スクレイピングが発生した場合は、まずブラウザを使用して記事の URL を収集し、次に成功率を優先してバッチ ダウンロードするスクリプトを実行します。
