Extraiga el texto principal de la URL de un solo artículo o de una página de índice/archivo de un artículo y guárdelo localmente como Markdown. Cuando el usuario menciona "recopilar artículos", "guardar páginas web", "extraer artículos de páginas por lotes", "extraer las primeras N publicaciones de esta página de archivo" o "guardar en Obsidian/Recortes/localmente", se debe priorizar este enfoque. Es especialmente adecuado para páginas web públicas, Substack, páginas de artículos de blogs y páginas de archivo de artículos. Cuando encuentre listas cargadas de forma diferida, páginas dinámicas o scraping estático incompleto, primero use un navegador para recopilar las URL de los artículos y luego invoque una secuencia de comandos para descargarlas por lotes, priorizando la tasa de éxito.
