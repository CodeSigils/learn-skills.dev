في تطبيق Codex، قم تلقائيًا بإنشاء مهام خلفية متعددة باستخدام نماذج قابلة للتخصيص وكثافة الاستدلال للأعمال المعرفية المعقدة أو القابلة للتوازي أو مهام البرمجة، مع الوكيل الرئيسي المسؤول عن التخطيط وتقسيم العمل والتكامل والقبول. يتم استخدامه للبحث متعدد المصادر، أو المحتوى متعدد الفصول، أو المهارات المعقدة/PPT، أو التطوير عبر الوحدات، أو التحقق المستقل، أو أكثر من سير عمل مستقل بشكل متبادل؛ وينطبق أيضًا عندما يطلب المستخدمون بشكل صريح توجيه النموذج، أو العاملين في الخلفية، أو فريق الوكلاء، أو التعاون المستمر في المشروع. يجب ألا يتم تشغيل الأسئلة والأجوبة البسيطة، واستعلامات الحالة، والتحريرات الصغيرة للملف الواحد، والمهام المتسلسلة بدقة، وعمليات النشر/الدفع/الحذف/الحساب تلقائيًا.
