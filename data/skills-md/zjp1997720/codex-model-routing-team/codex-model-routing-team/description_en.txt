In the Codex App, automatically create multiple background tasks with assignable models and inference intensities for complex, parallelizable knowledge work or programming tasks, with the main Agent responsible for planning, division of labor, integration, and acceptance. This is used for multi‑source research, multi‑chapter content, complex skills/PPT, cross‑module development, independent verification, or more than two mutually independent workflows; it also applies when users explicitly request model routing, background workers, an Agents team, or persistent project collaboration. Simple Q&A, status queries, minor single‑file edits, strictly sequential tasks, and publishing/payments/deletions/account operations must not be triggered automatically.
