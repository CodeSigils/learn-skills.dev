Beginner Writing Dual-Mode Skill. It is aimed at trainees and users and does not require an existing personal profile, long‑term memory accumulation, or representative works. When a user wants to “first write a strong article” but lacks sufficient material, experience, or stylistic assets, this skill should be used as the priority. When the user explicitly says they want to “write like a certain built‑in author,” especially the current built‑in authors Dan Koe, 粥左罗, Justin Welsh, Liu Run, Liang Ning, or Xue Hui, this skill should also be used. Even if the user does not directly mention “strong article mode” or “high‑mimicry mode,” as long as the intent is “low‑threshold drafting” or “first experience a particular author’s style,” this skill should be triggered. Do not use it in scenarios where the “user already has their own mature stylistic assets and wants to write like themselves”; that is the responsibility of `writing-clone-profile`. The currently implemented scope includes: common standards, the first batch of strong‑article prototypes, formal author‑profile prototypes for Dan Koe / 粥左罗 / Justin Welsh / Liu Run / Liang Ning / Xue Hui, and the runtime closure protocol.
