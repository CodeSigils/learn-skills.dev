Newcomer Writing Dual-Mode Skill. Intended for students and users, it does not require an existing personal profile, long-term memory accumulation, or representative works.

When a user wants to “write a strong article first” but lacks sufficient material, experience, or stylistic assets, prioritize using this skill.

When a user explicitly says they want to “write like a specific built-in author,” especially the current built-in authors Dan Koe, Zhou Zuoluo, Justin Welsh, Liu Run, Liang Ning, or Xue Hui, this skill should also be used.

Even if the user does not directly mention “strong article mode” or “high-fidelity mode,” as long as the intention is “low-threshold drafting” or “first experiencing a particular author’s direction,” this skill should be triggered.

Do not use it in scenarios where “the user already has their own mature stylistic assets and wants to write as themselves”; that is the responsibility of `writing-clone-profile`.

The currently implemented scope includes: common standards, the first batch of strong article prototypes, formal author profile prototypes for Dan Koe / Zhou Zuoluo / Justin Welsh / Liu Run / Liang Ning / Xue Hui, and runtime closure protocols. Hard constraint: this skill does not use form-normalized-anchors.
