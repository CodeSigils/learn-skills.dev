Habilidad de escritura en modo dual para recién llegados. Destinado a estudiantes y usuarios, no requiere un perfil personal existente, acumulación de memoria a largo plazo ni obras representativas.

Cuando un usuario quiere "escribir primero un artículo sólido" pero carece de suficiente material, experiencia o recursos estilísticos, priorice el uso de esta habilidad.

Cuando un usuario dice explícitamente que quiere "escribir como un autor incorporado específico", especialmente los autores incorporados actuales Dan Koe, Zhou Zuoluo, Justin Welsh, Liu Run, Liang Ning o Xue Hui, esta habilidad también debe usarse.

Incluso si el usuario no menciona directamente el "modo de artículo sólido" o el "modo de alta fidelidad", siempre y cuando la intención sea "redacción de bajo umbral" o "experimentar primero la dirección de un autor en particular", esta habilidad debe activarse.

No lo utilices en escenarios donde “el usuario ya tiene sus propios recursos estilísticos maduros y quiere escribir como él mismo”; esa es responsabilidad de "escribir-clon-perfil".

El alcance implementado actualmente incluye: estándares comunes, el primer lote de prototipos de artículos sólidos, prototipos de perfiles de autor formales para Dan Koe / Zhou Zuoluo / Justin Welsh / Liu Run / Liang Ning / Xue Hui y protocolos de cierre de tiempo de ejecución. Restricción estricta: esta habilidad no utiliza anclajes de forma normalizada.
