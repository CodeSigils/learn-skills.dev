Администрирование навыков, предназначенных только для Кодекса, для аудита, включения, отключения, восстановления и проверки местных навыков Кодекса. Используйте, когда пользователь просит управлять навыками Кодекса, уменьшить нагрузку на жетоны навыков, закрыть неиспользуемые навыки, не удаляя их, восстановить отключенные навыки, проверить видимость текущих навыков или автоматизировать включение навыков через официальный протокол сервера приложений Кодекса.
