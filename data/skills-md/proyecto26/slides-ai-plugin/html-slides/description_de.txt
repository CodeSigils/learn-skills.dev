Wird verwendet, wenn der Benutzer „HTML-Folien erstellen“, „eine HTML-Präsentation erstellen“, „animierte Folien erstellen“, „interaktive Folien erstellen“, „Webfolien erstellen“, „GSAP-Präsentation“, „browserbasierte Folien“, „PPTX in HTML konvertieren“, „animiertes Deck“, „Reveal.js-Folien“ auffordert oder wenn das Ausgabeformat für eine Präsentationsaufgabe HTML ist. Wird auch bei „Einzeldatei-Präsentation“, „CSS-Animationen in Folien“, „Scroll-basierten Folien“ oder „Web-Präsentation“ ausgelöst. Erzeugt eigenständiges Einzeldatei-HTML mit Ansichtsfensteranpassung, CSS/GSAP-Animationen und kuratierten Stilvoreinstellungen.
