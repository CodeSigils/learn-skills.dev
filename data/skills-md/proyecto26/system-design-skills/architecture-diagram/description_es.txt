Esta habilidad debe usarse cuando el diseño de un sistema necesita un diagrama: "dibujar la arquitectura", "diagramar este sistema", "mostrar los componentes", "hacer un diagrama de arquitectura/infraestructura/topología" o visualizar cuadros y flechas, flujo de datos, regiones o rutas de falla para un diseño. Genera un diagrama HTML + SVG de tema oscuro autónomo (con exportación PNG/PDF). Úselo siempre que el orquestador de "diseño del sistema" o un bloque de construcción llegue al paso "dibujarlo", incluso si el usuario no dice "diagrama".
