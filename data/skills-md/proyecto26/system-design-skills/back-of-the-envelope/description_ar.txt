يجب استخدام هذه المهارة عندما يحتاج المستخدم إلى "تقدير QPS"، أو أرقام "خلف المظروف" (BOTEC)، أو "كمية التخزين/عرض النطاق الترددي"، أو "كم عدد الخوادم"، أو "الحمل الأقصى"، أو "تخطيط السعة"، أو يريد أرقام زمن الوصول / الإنتاجية / التوفر القياسية لتأريض التصميم (جدول زمن الوصول، معدلات QPS، قوى اثنين، تسعة). استخدمها عندما يتوقف قرار التصميم على نطاق واسع - قم بتحويل أي عبارة "حركة مرور عالية" / "بيانات ضخمة" إلى أرقام محددة قبل اختيار المكونات، حتى لو لم يقل المستخدم "تقدير".
