Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „verteilte Protokollierung“, „Protokollaggregation“, „zentralisierte Protokolle“, einen „ELK“- oder „EFK“-Stack, „Protokollversand“, „strukturierte Protokollierung“, eine „Korrelations-ID“ oder „Trace-ID“ in Protokollen, „Protokollaufbewahrung“ oder „Protokollaufnahme mit hohem Volumen“ entwirft. Es gibt die Pipeline „Sammeln → Puffer → Versenden → Index → ​​Speichern → Retain“, Probenahme, Bestellung und Kühllagerung. Verwenden Sie es immer dann, wenn viele Dienste Protokolle ausgeben, die unter Last an einer Stelle durchsucht werden müssen, auch wenn der Benutzer nicht „Protokollierungspipeline“ sagt.
