يجب استخدام هذه المهارة عندما يصمم المستخدم "التسجيل الموزع"، أو "تجميع السجلات"، أو "السجلات المركزية"، أو مكدس "ELK" أو "EFK"، أو "شحن السجل"، أو "التسجيل المنظم"، أو "معرف الارتباط" أو "معرف التتبع" في السجلات، أو "الاحتفاظ بالسجل"، أو "استيعاب السجل بكميات كبيرة". إنه يوفر التجميع → المخزن المؤقت → السفينة → الفهرس → المتجر → الاحتفاظ بخط الأنابيب، وأخذ العينات، والطلب، وطبقات التخزين البارد. استخدمه عندما تصدر العديد من الخدمات سجلات يجب البحث فيها في مكان واحد تحت التحميل، حتى لو لم يقل المستخدم "خط أنابيب التسجيل".
