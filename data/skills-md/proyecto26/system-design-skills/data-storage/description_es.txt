Esta habilidad debe usarse cuando el usuario pregunta "SQL o NoSQL", "qué base de datos", cómo diseñar un "modelo de datos" o "diseño de esquema", elige una estrategia de "indexación", necesita "fragmentación" o "particionamiento", configura "replicación" (líder-seguidor/múltiple), define una "clave primaria"/"clave de clasificación", pregunta si se debe "desnormalizar" o sopesa la "persistencia políglota". Úselo siempre que un diseño deba decidir dónde se encuentran los registros, cómo se codifican y se accede a ellos, y cómo el almacén escala más allá de un nodo, incluso si el usuario simplemente dice "almacenar los datos".
