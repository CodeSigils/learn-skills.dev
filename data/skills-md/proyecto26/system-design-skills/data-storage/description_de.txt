Diese Fähigkeit sollte verwendet werden, wenn der Benutzer fragt „SQL oder NoSQL“, „welche Datenbank“, wie ein „Datenmodell“ oder „Schema-Design“ entworfen werden soll, eine „Indizierungs“-Strategie auswählt, „Sharding“ oder „Partitionierung“ benötigt, „Replikation“ (Leader-Follower / Multi-Leader) einrichtet, einen „Primärschlüssel“/„Sortierschlüssel“ definiert, fragt, ob „denormalisiert“ werden soll oder „polyglotte Persistenz“ abwägt. Verwenden Sie es immer dann, wenn ein Design entscheiden muss, wo Datensätze gespeichert werden, wie sie verschlüsselt werden und auf sie zugegriffen wird und wie der Speicher über einen Knoten hinaus skaliert – selbst wenn der Benutzer nur „Speichern der Daten“ sagt.
