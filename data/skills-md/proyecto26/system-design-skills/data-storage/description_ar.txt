يجب استخدام هذه المهارة عندما يسأل المستخدم "SQL أو NoSQL"، أو "أي قاعدة بيانات"، أو كيفية تصميم "نموذج بيانات" أو "تصميم المخطط"، أو اختيار استراتيجية "الفهرسة"، أو يحتاج إلى "تقسيم" أو "تقسيم"، أو إعداد "النسخ المتماثل" (زعيم-تابع/متعدد القادة)، أو تحديد "مفتاح أساسي"/"مفتاح فرز"، أو يسأل عما إذا كان سيتم "إلغاء التطبيع"، أو يزن "استمرار متعدد اللغات". استخدمه عندما يتعين على التصميم أن يحدد مكان وجود السجلات، وكيفية إدخالها والوصول إليها، وكيفية قياس المتجر لعقدة واحدة - حتى لو قال المستخدم فقط "تخزين البيانات".
