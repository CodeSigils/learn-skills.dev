このスキルは、ユーザーが「DNS」、「ドメイン解決」、「GeoDNS / 地理的ルーティング」、「レイテンシーベースのルーティング」、「加重 / フェイルオーバー ルーティング」、「Route 53 / Cloud DNS」、「A/CNAME/ALIAS レコード」、「エニーキャスト」、または「DNS TTL / プロパゲーション」について質問する場合に使用する必要があります。これは、名前を適切な IP にマッピングし、ユーザーを適切なリージョンまたはエンドポイントに誘導するグローバル フロント ドアを提供します。設計でリージョン/データセンター間でトラフィックを誘導したり、名前層でヘルスチェックされたフェイルオーバーを実行したり、ユーザーが「DNS」と言わなくても安定したホスト名を公開したりする必要がある場合は、常にこれを使用します。
