يجب استخدام هذه المهارة عندما يسأل المستخدم عن "DNS" أو "دقة المجال" أو "GeoDNS / التوجيه الجغرافي" أو "التوجيه المستند إلى زمن الوصول" أو "توجيه تجاوز الفشل" أو "المسار 53 / Cloud DNS" أو "سجل A/CNAME/ALIAS" أو "anycast" أو "DNS TTL / الانتشار". إنه يوفر الباب الأمامي العالمي الذي يعيّن اسمًا لعنوان IP الصحيح ويوجه المستخدمين إلى المنطقة أو نقطة النهاية الصحيحة. استخدمه عندما يتعين على التصميم توجيه حركة المرور عبر المناطق/مراكز البيانات، أو إجراء تجاوز الفشل للتحقق من السلامة في طبقة الاسم، أو الكشف عن اسم مضيف مستقر حتى إذا لم يقل المستخدم "DNS".
