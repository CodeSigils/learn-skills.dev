Diese Fähigkeit sollte verwendet werden, wenn der Benutzer fragt: „Wie funktioniert das?“, „Skalierung auf Millionen“, „Skalierungs-Roadmap“, „Wo ist der Engpass“, „Was bricht zuerst“, „10-faches Wachstum“, „vertikale vs. horizontale Skalierung“, „Skalierung von Null“ oder „Was ist die nächste Skalierungskurve“. Es gibt den Evolutionspfad in der Größenordnung an (einzelner Server → Ebenen → Replikate → Cache → CDN → zustandslose Ebene → Multiregion → Sharding) und eine Möglichkeit, den *nächsten* Engpass zu diagnostizieren, anstatt sich ein großes Diagramm zu merken. Verwenden Sie es immer dann, wenn ein Design um Größenordnungen wachsen muss oder eine Lasterhöhung ansteht, auch wenn der Benutzer nicht „Skalierung“ sagt.
