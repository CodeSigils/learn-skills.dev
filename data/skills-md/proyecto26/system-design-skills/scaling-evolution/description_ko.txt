이 기술은 사용자가 "이 확장은 어떻게 합니까?", "수백만 개로 확장", "로드맵 확장", "병목 현상은 어디에 있습니까?", "먼저 중단되는 것은 무엇입니까?", "10배 성장", "수직 대 수평 확장", "0부터 확장" 또는 "다음 규모 곡선은 무엇입니까?"라고 물을 때 사용해야 합니다. 이는 규모의 진화 경로(단일 서버 → 계층 → 복제본 → 캐시 → CDN → 상태 비저장 계층 → 다중 지역 → 샤딩)와 하나의 큰 다이어그램을 기억하는 대신 *다음* 병목 현상을 진단하는 방법을 제공합니다. 사용자가 "스케일링"이라고 말하지 않더라도 디자인이 몇 배씩 커져야 하거나 부하 증가가 테이블에 있을 때마다 이 기능을 사용하세요.
