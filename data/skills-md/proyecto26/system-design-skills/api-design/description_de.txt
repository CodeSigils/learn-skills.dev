Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „die API entwerfen“, „Endpunktdesign“ durchführen, eine „Anforderungs-/Antwortform“ festlegen, eine „Paginierungs“-Strategie (Cursor vs. Offset) auswählen, einem Schreibvorgang einen „Idempotenzschlüssel“ hinzufügen, eine „API-Versionierung“ oder einen „Fehlervertrag“ planen oder zwischen „REST vs. gRPC vs. GraphQL“ oder „WebSocket vs. Polling“ wählen muss. Verwenden Sie es immer dann, wenn ein Design die Schnittstelle erreicht hat – die konkrete Anfrage, Antwort, den primären Zugriffspfad und wie Clients Seiten, Wiederholungsversuche und Versionen durchführen – auch wenn der Benutzer nur gesagt hat: „Die Kästchen kommunizieren miteinander“.
