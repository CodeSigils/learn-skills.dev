Esta habilidad debe usarse cuando el usuario necesita "diseñar la API", hacer "diseño de punto final", precisar una "forma de solicitud/respuesta", elegir una estrategia de "paginación" (cursor versus desplazamiento), agregar una "clave de idempotencia" a una escritura, planificar un "control de versiones de API", un "contrato de error" o elegir entre "REST vs gRPC vs GraphQL" o "WebSocket vs sondeo". Úselo siempre que un diseño haya llegado a la interfaz (la solicitud concreta, la respuesta, la ruta de acceso principal y cómo los clientes paginan, reintentan y versionan) incluso si el usuario solo dijo "las cajas se comunican entre sí".
