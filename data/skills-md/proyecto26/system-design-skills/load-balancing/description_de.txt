Diese Fähigkeit sollte verwendet werden, wenn der Benutzer einen „Load Balancer“ hinzufügt, nach „L4 vs. L7“ (Transport vs. Anwendungsschicht) fragt, einen Ausgleichsalgorithmus auswählt („Round Robin“, „Least Connections“, „Weighted“, „IP Hash“), „Health Checks“ konfiguriert, „Sticky Sessions“/„Session Affinity“ benötigt, einen „Reverse Proxy“ hinzufügt, „SSL/TLS-Terminierung“ durchführt, die „Verkehrsverteilung“ über eine „Autoscaling-Gruppe“ verteilt oder ein zustandsloses Web wünscht Ebene hinter einem einzelnen Einstiegspunkt. Verwenden Sie es immer dann, wenn ein Design mehr als einen Server hinter einer Adresse hat oder eine einzelne Box den Engpass oder SPOF am Einstiegspunkt darstellt, auch wenn der Benutzer nicht „Load Balancer“ sagt.
