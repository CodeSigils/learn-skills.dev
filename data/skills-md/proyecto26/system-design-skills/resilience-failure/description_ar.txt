يجب استخدام هذه المهارة عندما يسأل المستخدم عن "التسامح مع الخطأ"، أو "المرونة"، أو "قاطع الدائرة"، أو "التدهور السلس"، أو "إعادة المحاولة" أو "القطيع المدوي عند التعافي"، أو "التراجع الأسي مع عدم الاستقرار"، أو "المهلة"، أو "الحاجز"، أو "نقطة فشل واحدة" (SPOF)، أو "تجاوز الفشل"، أو "تحديد المعدل" (دلو الرمز المميز / الجرافة المتسربة / النافذة المنزلقة). استخدمه عندما يتعين على التصميم الاستمرار في العمل خلال تعطل العقدة، أو التبعيات البطيئة، أو ارتفاع حركة المرور، أو الانقطاعات الجزئية - أي في أي وقت الإجابة على "ماذا يحدث عندما ينقطع هذا؟" مفقود، حتى لو لم يقل المستخدم "المرونة".
