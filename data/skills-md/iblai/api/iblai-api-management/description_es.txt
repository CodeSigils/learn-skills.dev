Administre una organización ibl.ai a través de la API de la plataforma: administre usuarios (enumerar, activar, promover/degradar, establecer políticas), grupos, roles y políticas de RBAC, equipos (grupos de usuarios + acceso al equipo) y alertas (grupos/usuarios/observadores observados). Úselo para la administración de usuarios y accesos a nivel de organización.
