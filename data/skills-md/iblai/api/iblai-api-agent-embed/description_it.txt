Configura le impostazioni di incorporamento/widget di un agente ibl.ai tramite l'API della piattaforma: accesso anonimo, CSS/JS personalizzato, modalità, attiva/disattiva voce/allegato, prompt di avvio, SSO, collegamenti di condivisione e token di reindirizzamento. Da utilizzare quando si incorpora un agente su un sito Web esterno.
