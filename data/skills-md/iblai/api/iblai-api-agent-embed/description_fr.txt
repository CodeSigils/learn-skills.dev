Configurez les paramètres d'intégration/widget d'un agent ibl.ai via l'API de la plateforme : accès anonyme, CSS/JS personnalisé, mode, bascules voix/pièce jointe, invites de démarrage, SSO, liens de partage et jetons de redirection. À utiliser lors de l'intégration d'un agent sur un site Web externe.
