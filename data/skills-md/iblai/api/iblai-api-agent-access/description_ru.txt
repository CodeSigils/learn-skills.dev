Управляйте доступом к агенту ibl.ai на основе ролей через API платформы: список политик ролей, поиск пользователей/групп, а также предоставление/отзыв ролей редактора, чата или аналитики_просмотрщика для пользователей, групп и электронных писем. Используйте для контроля того, кто может редактировать, общаться в чате или просматривать аналитику для агента.
