Gérez l'accès basé sur les rôles à un agent ibl.ai via l'API de la plateforme : répertoriez les politiques de rôle, recherchez des utilisateurs/groupes et accordez/révoquer les rôles d'éditeur, de chat ou de visionneuse d'analyse pour les utilisateurs, les groupes et les e-mails. À utiliser pour contrôler qui peut modifier, discuter avec ou afficher les analyses d'un agent.
