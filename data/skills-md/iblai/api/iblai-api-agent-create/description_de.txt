Erstellen Sie über die Plattform-API einen neuen ibl.ai-Agenten aus einer Vorlage – legen Sie Namen, Anzeigenamen, Beschreibung, Systemaufforderung und LLM-Anbieter fest; gibt die eindeutige ID des neuen Agenten zurück. Verwenden Sie diese Option, wenn Sie einen Agenten von Grund auf erstellen und ihn dann mit den anderen /iblai-api-agent-*-Fähigkeiten konfigurieren.
