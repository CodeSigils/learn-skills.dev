Cree un nuevo agente ibl.ai a partir de una plantilla a través de la API de la plataforma: establezca el nombre, el nombre para mostrar, la descripción, el mensaje del sistema y el proveedor de LLM; devuelve la identificación única del nuevo agente. Úselo al crear un agente desde cero y luego configúrelo con las otras habilidades /iblai-api-agent-*.
