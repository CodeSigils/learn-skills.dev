Créez un nouvel agent ibl.ai à partir d'un modèle via l'API de la plateforme : définissez le nom, le nom d'affichage, la description, l'invite système et le fournisseur LLM ; renvoie l'identifiant unique du nouvel agent. À utiliser lors de la création d'un agent à partir de zéro, puis configurez-le avec les autres compétences /iblai-api-agent-*.
