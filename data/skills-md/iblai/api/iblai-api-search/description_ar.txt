اكتشف الوكلاء والمحتوى التعليمي في مؤسسة ibl.ai عبر واجهة برمجة تطبيقات النظام الأساسي - البحث متعدد الأوجه والمرقّم عن الوكلاء والكتالوج (الدورات والبرامج والمسارات والمهارات)، والتوصيات الشخصية (RAG)، والبحث العالمي/الشخصي عن الوكلاء، والبحث عن العناصر القابلة للبيع التي تواجه البائع؛ بالإضافة إلى الإدارة الإدارية لمطالبات التوصية. يُستخدم للبحث عن الوكلاء/المحتوى الموصى بهم أو تصفحهم أو الحصول عليهم (معظمهم للقراءة فقط؛ كتابة نقاط نهاية المطالبة بالتوصية).
