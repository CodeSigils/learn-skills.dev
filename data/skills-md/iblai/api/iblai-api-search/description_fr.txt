Découvrez les agents et le contenu d'apprentissage dans une organisation ibl.ai via l'API de la plateforme : recherche à facettes et paginée sur les agents et le catalogue (cours, programmes, parcours, compétences), recommandations personnalisées (RAG), recherche d'agent globale/personnalisée et recherche d'articles vendables face au vendeur ; plus la gestion administrative des invites de recommandation. Utilisé pour rechercher, parcourir ou obtenir des agents/contenus recommandés (principalement en lecture seule ; les points de terminaison d'invite de recommandation écrivent).
