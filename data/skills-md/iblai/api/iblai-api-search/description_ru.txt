Находите агентов и обучающий контент в организации ibl.ai через API платформы — фасетный постраничный поиск по агентам и каталогу (курсы, программы, направления, навыки), персонализированные рекомендации (RAG), глобальный/персонализированный поиск агентов и поиск продаваемых товаров с участием продавцов; плюс административное управление рекомендациями. Используйте для поиска, просмотра или получения рекомендуемых агентов/контента (в основном только для чтения; конечные точки с подсказками рекомендаций пишут).
