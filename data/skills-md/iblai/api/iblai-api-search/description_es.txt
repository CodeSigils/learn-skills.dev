Descubra agentes y contenido de aprendizaje en una organización ibl.ai a través de la API de la plataforma: búsqueda paginada y facetada sobre agentes y el catálogo (cursos, programas, trayectorias, habilidades), recomendaciones personalizadas (RAG), búsqueda de agentes global/personalizada y búsqueda de artículos vendibles orientada al vendedor; además de gestión administrativa de las indicaciones de recomendación. Úselo para buscar, explorar u obtener agentes/contenido recomendados (principalmente de solo lectura; escritura de puntos finales que solicitan recomendaciones).
