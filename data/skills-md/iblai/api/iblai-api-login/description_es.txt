Conecte una organización ibl.ai para acceder a la API. Obtiene que el usuario inicie sesión (ibl.ai/join si es nuevo, login.iblai.app/me si regresa), captura su clave de organización y nombre de usuario, genera un token API de plataforma y escribe IBLAI_ORG / IBLAI_USERNAME / IBLAI_API_KEY en .env. Si ya posee las credenciales de la organización (clave + secreto), el secreto funciona directamente como Api-Token, sin necesidad de un navegador. Ejecute esto primero antes que cualquier otra habilidad iblai-*.
