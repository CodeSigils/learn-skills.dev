ربط مؤسسة ibl.ai للوصول إلى واجهة برمجة التطبيقات (API). يجعل المستخدم يسجل الدخول (ibl.ai/join إذا كان جديدًا، وlogin.iblai.app/me إذا عاد)، ويلتقط مفتاح المؤسسة واسم المستخدم، ويستخرج رمز Platform API المميز، ويكتب IBLAI_ORG / IBLAI_USERNAME / IBLAI_API_KEY إلى .env. إذا كنت تمتلك بالفعل بيانات اعتماد المؤسسة (المفتاح + السر)، فسيعمل السر مباشرة كرمز Api-Token - دون الحاجة إلى متصفح. قم بتشغيل هذا أولاً قبل أي مهارة iblai-* أخرى.
