Connetti un'organizzazione ibl.ai per l'accesso API. Fa accedere l'utente (ibl.ai/join se nuovo, login.iblai.app/me se ritorna), acquisisce la chiave dell'organizzazione e il nome utente, conia un token API della piattaforma e scrive IBLAI_ORG / IBLAI_USERNAME / IBLAI_API_KEY su .env. Se possiedi già le credenziali dell'organizzazione (chiave + segreto), il segreto funziona direttamente come Api-Token, senza bisogno di browser. Eseguilo prima di qualsiasi altra abilità iblai-*.
