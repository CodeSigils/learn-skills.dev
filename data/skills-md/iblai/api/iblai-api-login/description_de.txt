Verbinden Sie eine ibl.ai-Organisation für API-Zugriff. Ruft die Anmeldung des Benutzers ab (ibl.ai/join, wenn neu, login.iblai.app/me, wenn er zurückkommt), erfasst seinen Organisationsschlüssel und Benutzernamen, prägt ein Plattform-API-Token und schreibt IBLAI_ORG / IBLAI_USERNAME / IBLAI_API_KEY in .env. Wenn Sie bereits über Organisationszugangsdaten (Schlüssel + Geheimnis) verfügen, fungiert das Geheimnis direkt als Api-Token – kein Browser erforderlich. Führen Sie dies zuerst vor allen anderen iblai-*-Fertigkeiten aus.
