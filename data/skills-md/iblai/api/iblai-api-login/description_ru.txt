Подключите организацию ibl.ai для доступа к API. Получает вход пользователя в систему (ibl.ai/join, если новый, login.iblai.app/me, если возвращается), фиксирует его ключ организации и имя пользователя, создает токен API платформы и записывает IBLAI_ORG / IBLAI_USERNAME / IBLAI_API_KEY в .env. Если у вас уже есть учетные данные организации (ключ + секрет), секрет работает напрямую как Api-токен — браузер не требуется. Запустите его перед любым другим навыком iblai-*.
