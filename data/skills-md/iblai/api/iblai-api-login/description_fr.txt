Connectez une organisation ibl.ai pour accéder à l'API. Obtient l'utilisateur connecté (ibl.ai/join s'il est nouveau, login.iblai.app/me s'il revient), capture sa clé d'organisation et son nom d'utilisateur, crée un jeton API de plate-forme et écrit IBLAI_ORG / IBLAI_USERNAME / IBLAI_API_KEY dans .env. Si vous détenez déjà les informations d'identification de l'organisation (clé + secret), le secret fonctionne directement comme l'Api-Token — aucun navigateur n'est nécessaire. Exécutez-le avant toute autre compétence iblai-*.
