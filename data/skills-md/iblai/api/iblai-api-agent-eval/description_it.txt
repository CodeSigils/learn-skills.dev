Misura e migliora la qualità degli agenti tramite l'API della piattaforma: set di dati di valutazione, elementi di set di dati (JSON, caricamento CSV o da tracce chat), esecuzioni di esperimenti, punteggio LLM-as-Judge e annotazioni umane, configurazioni di punteggi ed esportazione CSV. Da utilizzare per testare un agente rispetto a un set di dati e classificare i risultati.
