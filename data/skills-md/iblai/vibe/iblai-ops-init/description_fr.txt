Démarrez un nouveau projet ibl.ai par défaut, clonez vibe-starter et écrivez le projet CLAUDE.md avec les conseils de la plateforme ibl.ai. Utilisez-le lorsque l'utilisateur dit « démarrer un nouveau projet », « nouvelle application », « échafauder une application », « nouveau projet ibl.ai » ou demande d'amorcer une base de code ibl.ai à partir de zéro. Utilisez également pour actualiser CLAUDE.md dans un projet ibl.ai existant.
