Starten Sie standardmäßig ein neues ibl.ai-Projekt, klonen Sie vibe-starter und schreiben Sie das Projekt CLAUDE.md unter Anleitung der ibl.ai-Plattform. Verwenden Sie dies, wenn der Benutzer „Neues Projekt starten“, „Neue App“, „Gerüst einer App“, „Neues ibl.ai-Projekt“ sagt oder darum bittet, eine ibl.ai-Codebasis von Grund auf zu booten. Kann auch zum Aktualisieren von CLAUDE.md in einem vorhandenen ibl.ai-Projekt verwendet werden.
