Inicie un nuevo proyecto ibl.ai de forma predeterminada, clone vibe-starter y escriba el proyecto CLAUDE.md con la guía de la plataforma ibl.ai. Utilice esto cuando el usuario diga "iniciar un nuevo proyecto", "nueva aplicación", "desarrollar una aplicación", "nuevo proyecto ibl.ai" o solicite iniciar un código base de ibl.ai desde cero. Utilícelo también para actualizar CLAUDE.md en un proyecto ibl.ai existente.
