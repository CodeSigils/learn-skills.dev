Utilice esta habilidad siempre que el usuario desee descargar artículos académicos, buscar literatura de investigación, obtener citas (BibTeX/RIS/EndNote), administrar el proxy institucional WebVPN para acceder a artículos, importar archivos .bib o descargar artículos por lotes. Esta habilidad organiza el servidor MCP scansci-pdf que tiene más de 13 fuentes de descarga, más de 100 WebVPN universitarias y descargas paralelas. DISPARAR cuando: el usuario menciona la descarga de artículos, DOI, arXiv ID, Sci-Hub, búsqueda de artículos, revisión de literatura, exportación de citas, WebVPN, acceso institucional, Elsevier API, ScienceDirect, "帮我下载论文", "搜索文献", "批量下载", "论文下载", "文献检索", "配置 API de Elsevier" o proporciona una lista de DOI/ID de arXiv. SALTAR: el usuario solo analiza artículos conceptualmente sin intención de descargarlos, buscarlos o citarlos, o el usuario pregunta sobre archivos PDF no académicos (facturas, informes, etc.).
