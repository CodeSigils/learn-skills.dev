Governare la copertura della documentazione in linea e la qualità dei commenti nei file sorgente di proprietà del repository. Da utilizzare quando Codex deve controllare o correggere intestazioni di file, documenti di tipo, documenti di contratto di funzioni o metodi, commenti in linea non ovvi, esclusioni di file generati o regole di documentazione del repository per progetti TypeScript, JavaScript e Swift, inclusa l'impostazione di una politica di documenti/regole riutilizzabili in modo indipendente dal progetto.
