Verwenden Sie diese Option, wenn die Arbeit über GitHub Issues statt über Repository-lokale Todo-Dateien verfolgt und ausgeführt werden soll. Hilft Agenten dabei, die vorhandenen Issue-Vorlagen, Labels und Projektkonventionen eines Repos zu übernehmen, sofern vorhanden, oder auf einen portablen Seed-plus-Ausführungsworkflow zurückzugreifen, wenn diese fehlen.
