Conseils d'experts pour l'ORM Toasty Rust : définition de modèle avec `#[derive(toasty::Model)]` et les attributs `#[key]`, `#[auto]`, `#[unique]`, `#[index]`, `#[has_many]`, `#[belongs_to]`, `#[has_one]` ; les relations, le préchargement des associations, les macros et générateurs de requêtes `create!`, `update!`, `find_by_*` et `filter_*` ; opérations par lots, transactions, types intégrés, champs différés, champs de tableau scalaire « Vec » et comportement spécifique au pilote pour SQLite, PostgreSQL, MySQL et DynamoDB. Couvre également les éléments internes de Toasty pour les contributeurs : les couches de schéma et le mappage de l'application/db, le pipeline de compilation du moteur de requête (AST → Simplifier → Inférieur → Planifier → Exécuter) et le trait du pilote. Invoquez toujours cette compétence pour toute question mentionnant Toasty, la caisse `toasty`, `toasty::Model`, `toasty::Db`, `toasty::HasMany`, `toasty::BelongsTo`, `toasty::HasOne`, les macros `toasty::create!` ou `toasty::update!`, codez sous `submodules/toasty/`, ou tout code Rust qui importe `toasty`.
