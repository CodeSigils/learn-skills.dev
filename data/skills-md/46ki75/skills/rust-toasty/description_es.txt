Guía de expertos para el ORM de Toasty Rust: definición del modelo con `#[derive(toasty::Model)]` y los atributos `#[key]`, `#[auto]`, `#[unique]`, `#[index]`, `#[has_many]`, `#[belongs_to]`, `#[has_one]`; relaciones, precarga de asociaciones, macros y constructores de consulta `create!`, `update!`, `find_by_*` y `filter_*`; operaciones por lotes, transacciones, tipos incrustados, campos diferidos, campos de matriz escalares `Vec` y comportamiento específico del controlador para SQLite, PostgreSQL, MySQL y DynamoDB. También cubre los aspectos internos de Toasty para los contribuyentes: las capas y el mapeo del esquema app/db, el proceso de compilación del motor de consultas (AST → Simplificar → Bajar → Planificar → Ejecutar) y el rasgo del controlador. Invoque siempre esta habilidad para cualquier pregunta que mencione Toasty, la caja `toasty`, `toasty::Model`, `toasty::Db`, `toasty::HasMany`, `toasty::BelongsTo`, `toasty::HasOne`, las macros `toasty::create!` o `toasty::update!`, código en `submodules/toasty/`, o cualquier Rust código que importa "tostado".
