Instale, configure o incorpore un repositorio de Python para la optimización del agente Beaker mientras aísla las herramientas de evaluación en .beaker, deja el comportamiento normal del tiempo de ejecución sin cambios y nunca agrega ni modifica pruebas ni automatización de CI/CD. Úselo al agregar Beaker, crear andamios o completar una fábrica de Beaker @spec, seleccionar los archivos del repositorio que Beaker puede optimizar, configurar beaker.yaml o spec.required_env, conectar conjuntos de datos etiquetados reales y una ruta de evaluación de agente o LLM, conectar la aplicación Beaker GitHub, validar con beaker run smoke o iniciar la primera ejecución de optimización del agente alojado. Utilícelo también cuando se preserve una especificación de destino lógico existente que utilice explícitamente @spec(repository=None).
