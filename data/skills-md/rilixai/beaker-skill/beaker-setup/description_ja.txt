Beaker エージェントを最適化するための Python リポジトリをセットアップ、構成、またはオンボードしながら、.beaker の下で評価ツールを分離し、通常のランタイム動作を変更せず、テストや CI/CD 自動化を追加または変更することはありません。 Beaker の追加、Beaker @spec ファクトリのスキャフォールディングまたは完了、Beaker が最適化するリポジトリ ファイルの選択、beaker.yaml または spec.required_env の構成、実際のラベル付きデータセットとエージェントまたは LLM 評価パスの接続、Beaker GitHub アプリの接続、Beaker Run Smoke による検証、または最初のホスト型エージェント最適化実行の起動を行うときに使用します。 @spec(repository=None) を明示的に使用する既存の論理ターゲット仕様を保持する場合にも使用します。
