Die Spezifikationscodierungsmethodik für die KI-gestützte Entwicklung. Verwenden Sie diese Funktion, wenn Sie Funktionen planen, Spezifikationen erstellen/verfeinern/implementieren/überprüfen oder ein Projekt organisieren. Funktioniert mit jedem Spezifikations-Backend, das Ihr Team bereits verwendet – lokaler Markdown, GitHub Issues, Azure DevOps, Jira – durch Delegieren plattformspezifischer Details an einen LeanSpec-Adapter.
