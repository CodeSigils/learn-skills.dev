Методология кодирования спецификаций для разработки с помощью ИИ. Используйте при планировании функций, создании/уточнении/реализации/проверке спецификаций или организации проекта. Работает с любой серверной частью спецификации, которую уже использует ваша команда — локальной уценкой, GitHub Issues, Azure DevOps, Jira — путем делегирования деталей, специфичных для платформы, адаптеру LeanSpec.
