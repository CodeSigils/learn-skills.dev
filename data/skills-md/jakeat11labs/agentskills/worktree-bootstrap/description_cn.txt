配置一个新创建的 git 工作树，使其开发服务器的运行方式与活动主干完全相同。首先将工作树快速转发到活动主干（工作树固定到其自己的冻结分支，因此它默默地落后于每个主干提交 - “缺少提交”），然后从主签出复制 gitignored env 文件（.env.local、.env），使用存储库的包管理器（pnpm/npm/yarn/bun）安装 node_modules，并且 - 对于 Next.js - 检查 Turbopack 工作区根 + allowedDevOrigins 引脚，可防止嵌套工作树开发服务器冻结和无端口 HMR 块。在创建工作树（git worktree add 或 `claude --worktree`）后立即使用，或者每当工作树缺少最近的提交、因缺少环境变量而失败、“next：未找到命令”、node_modules-missing 错误或“推断工作空间根”警告时使用。触发器：设置/引导/提供/准备/捕获工作树，“我刚刚制作了一个工作树”，“工作树缺少提交/在主干后面”，“工作树缺少其.env / node_modules”，“使此工作树像主程序一样运行”，“工作树中的开发服务器损坏”。适用于任何 JS/TS 存储库。手册：/worktree-bootstrap。
