新しく作成した git ワークツリーをプロビジョニングして、その開発サーバーがアクティブなトランクとまったく同じように実行されるようにします。まず、ワークツリーをアクティブなトランクまで早送りします (ワークツリーは独自の凍結されたブランチに固定されているため、すべてのトランク コミット (「コミットの欠落」) に静かに遅れます。次に、gitignored env ファイル (.env.local、.env) をメイン チェックアウトからコピーし、リポジトリのパッケージ マネージャー (pnpm/npm/yarn/bun) でノードモジュールをインストールし、- Next.js の場合は - Turbopack をチェックします。 workspace-root + allowedDevOrigins ピン。ネストされたワークツリーの開発サーバーのフリーズとポートレス HMR ブロックを防止します。ワークツリーを作成した直後 (git worktree add または `claude --worktree`)、またはワークツリーに最近のコミットがない場合、環境変数の欠落、「next: command not found」、node_modules-missing エラー、または「inferred workspace root」警告で失敗する場合に使用します。トリガー: ワークツリーのセットアップ / ブートストラップ / プロビジョニング / 準備 / キャッチアップ、「ワークツリーを作成したところです」、「ワークツリーにコミットがありません / トランクの後ろにあります」、「ワークツリーに .env / ノードモジュールがありません」、「このワークツリーをメインのように実行する」、「ワークツリーで開発サーバーが壊れています」。あらゆる JS/TS リポジトリで動作します。マニュアル: /worktree-bootstrap。
