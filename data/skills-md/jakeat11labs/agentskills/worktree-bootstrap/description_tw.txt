配置一個新建立的 git 工作樹，使其開發伺服器的運作方式與活動主幹完全相同。首先將工作樹快速轉發到活動主幹（工作樹固定到自己的凍結分支，因此它默默地落後於每個主幹提交 - “缺少提交”），然後從主簽出複製 gitignored env 檔案（.env.local、.env），使用安裝庫的套件管理器（pnpm/npm/yarn/bunpack）， allowedDevOrigins 接腳，可防止巢狀工作樹開發伺服器凍結和無連接埠 HMR 區塊。在創建工作樹（git worktree add 或 `claude --worktree`）後立即使用，或每當工作樹缺少最近的提交、因缺少環境變數而失敗、「next：未找到命令」、node_modules-missing 錯誤或「推斷工作空間根」警告時使用。觸發器：設定/引導/提供/準備/捕獲工作樹，“我剛剛製作了一個工作樹”​​，“工作樹缺少提交/在主幹後面”，“工作樹缺少其.env / node_modules”，“使此工作樹缺少主程式一樣運行”，“工作樹中的開發伺服器損壞”。適用於任何 JS/TS 儲存庫。手冊：/worktree-bootstrap。
