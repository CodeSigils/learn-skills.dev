개발 서버가 활성 트렁크와 똑같이 실행되도록 새로 생성된 git 작업 트리를 프로비저닝합니다. FIRST는 작업 트리를 활성 트렁크까지 빨리 감은 다음(작업 트리는 자체 고정 분기에 고정되어 있으므로 자동으로 모든 트렁크 커밋 뒤에 떨어집니다 — "커밋 누락"). 그런 다음 기본 체크아웃에서 gitignored env 파일(.env.local, .env)을 복사하고 저장소의 패키지 관리자(pnpm/npm/yarn/bun)를 사용하여 node_modules를 설치하고 Next.js의 경우 Turbopack을 확인합니다. 중첩된 작업 트리 개발 서버 정지 및 포트리스 HMR 블록을 방지하는 작업 공간 루트 + allowedDevOrigins 핀. 작업 트리를 생성한 직후(git worktree add 또는 `claude --worktree`)를 사용하거나 작업 트리에 최근 커밋이 누락될 때마다 env var 누락, "next: 명령을 찾을 수 없음", node_modules 누락 오류 또는 "추론된 작업 공간 루트" 경고로 인해 실패합니다. 트리거: 작업 트리 설정/부트스트랩/프로비저닝/준비/캐치업, "방금 작업 트리를 만들었습니다", "작업 트리에 커밋이 없습니다/트렁크 뒤에 있습니다", "작업 트리에 .env/node_modules가 없습니다", "이 작업 트리를 기본처럼 실행하도록 설정", "작업 트리에서 개발 서버가 손상되었습니다". 모든 JS/TS 저장소에서 작동합니다. 매뉴얼: /worktree-bootstrap.
