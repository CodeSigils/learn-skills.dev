Effettua il provisioning di un albero di lavoro git appena creato in modo che il suo server di sviluppo funzioni esattamente come il trunk attivo. PRIMA avanza velocemente l'albero di lavoro fino al trunk attivo (un albero di lavoro è bloccato sul proprio ramo congelato, quindi rimane silenziosamente dietro ogni commit del trunk - "commit mancanti"), quindi copia i file env gitignored (.env.local, .env) dal checkout principale, installa node_modules con il gestore pacchetti del repository (pnpm/npm/yarn/bun) e, per Next.js, controlla la root dell'area di lavoro Turbopack + Pin consentitiDevOrigins che impediscono il blocco del server di sviluppo dell'albero di lavoro annidato e i blocchi HMR senza porta. Da utilizzare subito dopo la creazione di un albero di lavoro (git worktree add o `claude --worktree`), o ogni volta che in un albero di lavoro mancano i commit recenti, fallisce con variabili env mancanti, "successivo: comando non trovato", un errore di node_modules mancante o un avviso di "root area di lavoro dedotta". Trigger: imposta / bootstrap / effettua il provisioning / prepara / recupera un albero di lavoro, "Ho appena creato un albero di lavoro", "al albero di lavoro mancano i commit / dietro il trunk", "al albero di lavoro mancano i suoi .env / node_modules", "fai funzionare questo albero di lavoro come principale", "server di sviluppo rotto nell'albero di lavoro". Funziona con qualsiasi repository JS/TS. Manuale: /worktree-bootstrap.
