Создает и поддерживает двойные файлы README (README.md на английском языке, README.pt-BR.md на португальском языке), оптимизированные для GitHub.com, со значками, перекрестными ссылками и дополнительными изображениями. Используйте при создании или обновлении документации проекта, когда пользователь запрашивает README или двуязычную документацию или при добавлении нового приложения.
