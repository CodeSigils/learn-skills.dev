プロジェクトにメタベースを埋め込むための JWT SSO 認証を実装します。 SSO を使用するすべての埋め込みタイプ (モジュラー埋め込み (embed.js Web コンポーネント)、モジュラー埋め込み SDK (@metabase/embedding-sdk-react)、および完全なアプリ埋め込み (iframe ベース) をサポートします。 JWT 署名エンドポイントを作成し、フロントエンド認証層を構成し、グループ マッピングを設定します。ユーザーが Metabase 埋め込みに SSO/JWT 認証を追加する場合、埋め込み分析のユーザー ID を実装する場合、Metabase の JWT 認証を設定する場合、またはアプリの認証を Metabase 埋め込みに接続する場合に使用します。
