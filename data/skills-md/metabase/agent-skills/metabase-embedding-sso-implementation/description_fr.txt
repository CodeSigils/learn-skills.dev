Implémente l'authentification JWT SSO pour l'intégration de métabase dans un projet. Prend en charge tous les types d'intégration qui utilisent SSO : intégration modulaire (composants Web embed.js), SDK d'intégration modulaire (@metabase/embedding-sdk-react) et intégration complète d'application (basée sur iframe). Crée le point de terminaison de signature JWT, configure la couche d'authentification frontale et configure les mappages de groupe. À utiliser lorsque l'utilisateur souhaite ajouter l'authentification SSO/JWT à son intégration de métabase, implémenter l'identité de l'utilisateur pour les analyses intégrées, configurer l'authentification JWT pour la métabase ou connecter l'authentification de son application à l'intégration de métabase.
