Реализует аутентификацию JWT SSO для встраивания метабазы ​​в проект. Поддерживает все типы внедрения, использующие единый вход: модульное внедрение (веб-компоненты embed.js), модульное внедрение SDK (@metabase/embedding-sdk-react) и полное внедрение приложения (на основе iframe). Создает конечную точку подписи JWT, настраивает уровень проверки подлинности внешнего интерфейса и настраивает сопоставления групп. Используйте, когда пользователь хочет добавить аутентификацию SSO/JWT к своему внедрению в метабазу, реализовать удостоверение пользователя для встроенной аналитики, настроить аутентификацию JWT для метабазы ​​или подключить аутентификацию своего приложения к внедрению метабазы.
