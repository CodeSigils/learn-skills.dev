Implementa la autenticación JWT SSO para la incrustación de metabase en un proyecto. Admite todos los tipos de incrustación que utilizan SSO: incrustación modular (componentes web embed.js), SDK de incrustación modular (@metabase/embedding-sdk-react) e incrustación completa de aplicaciones (basada en iframe). Crea el punto final de firma JWT, configura la capa de autenticación de frontend y configura asignaciones de grupos. Úselo cuando el usuario quiera agregar autenticación SSO/JWT a la incrustación de su Metabase, implementar la identidad del usuario para análisis integrados, configurar la autenticación JWT para la Metabase o conectar la autenticación de su aplicación a la incrustación de la Metabase.
