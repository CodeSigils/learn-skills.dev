프로젝트에 메타베이스 포함을 위한 JWT SSO 인증을 구현합니다. 모듈식 임베딩(embed.js 웹 구성 요소), 모듈식 임베딩 SDK(@metabase/embedding-sdk-react), 전체 앱 임베딩(iframe 기반) 등 SSO를 사용하는 모든 임베딩 유형을 지원합니다. JWT 서명 엔드포인트를 생성하고, 프런트엔드 인증 계층을 구성하고, 그룹 매핑을 설정합니다. 사용자가 메타베이스 포함에 SSO/JWT 인증을 추가하거나, 포함된 분석을 위한 사용자 ID를 구현하거나, 메타베이스에 대한 JWT 인증을 설정하거나, 앱 인증을 메타베이스 포함에 연결하려는 경우에 사용합니다.
