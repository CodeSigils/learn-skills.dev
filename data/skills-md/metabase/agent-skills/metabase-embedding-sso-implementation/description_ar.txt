ينفذ مصادقة JWT SSO لتضمين قاعدة التعريف في المشروع. يدعم جميع أنواع التضمين التي تستخدم الدخول الموحّد (SSO) - التضمين المعياري (مكونات الويب embed.js)، والتضمين المعياري SDK (@metabase/embedding-sdk-react)، والتضمين الكامل للتطبيق (المستند إلى iframe). إنشاء نقطة نهاية توقيع JWT، وتكوين طبقة مصادقة الواجهة الأمامية، وإعداد تعيينات المجموعة. يُستخدم عندما يريد المستخدم إضافة مصادقة SSO/JWT إلى تضمين قاعدة التعريف الخاصة به، أو تنفيذ هوية المستخدم للتحليلات المضمنة، أو إعداد مصادقة JWT لقاعدة التعريف، أو توصيل مصادقة تطبيقه بتضمين قاعدة التعريف.
