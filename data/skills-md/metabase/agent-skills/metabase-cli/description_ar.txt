قم بقيادة مثيل قاعدة التعريف من الجهاز عبر `mb` CLI. المصادقة باستخدام الملفات الشخصية المسماة؛ فحص قواعد البيانات (القائمة، الحصول على، مجموعة بيانات التعريف الكاملة، المخططات، الجداول في المخطط) وتشغيل مزامنة المخطط اليدوي / إعادة فحص قيم الحقول؛ فحص الجداول والحقول. قائمة/الحصول على/إنشاء/تحديث/أرشفة البطاقات (الأسئلة والنماذج والمقاييس) وتشغيلها بتنسيق JSON/CSV/XLSX؛ قائمة/الحصول على/إنشاء/تحديث لوحات المعلومات وبطاقات المعلومات التصحيحية؛ إدراج/الحصول على/إنشاء المجموعات واجتياز التسلسل الهرمي حسب المعرف أو الكيان_معرف أو "الجذر"/"سلة المهملات" (مع العناصر والشجرة العودية)؛ قائمة/الحصول على/إنشاء/تحديث/أرشفة مقتطفات وشرائح ومقاييس الاستعلام الأصلية؛ مؤلف/تحديث/تشغيل التحويلات وجدولة وظائف التحويل؛ إعدادات القراءة/التحديث؛ محتوى البحث (البطاقات ولوحات المعلومات والمجموعات والتحويلات والمقاييس)؛ إدارة مساحات عمل المؤسسة؛ مزامنة git من/إلى جهاز التحكم عن بعد في git (الحالة، القذرة، الاستيراد، التصدير، الفروع، التخزين المؤقت، إضافة/إزالة مجموعة من المزامنة). استخدمه عندما يريد المستخدم التفاعل مع قاعدة التعريف من الوحدة الطرفية - "تسجيل الدخول إلى قاعدة التعريف"، "ما هي الملفات الشخصية التي أملكها"، "إدراج البطاقات"، "تشغيل البطاقة 42 كملف CSV"، "إنشاء تحويل"، "إدراج لوحات المعلومات"، "نقل بطاقة المعلومات"، "مجموعات القائمة"، "ما هو موجود في المجموعة 4"، "إظهار شجرة المجموعة"، "مقتطفات القائمة"، "إنشاء مقطع"، "أرشفة مقياس"، "البحث في قاعدة التعريف لـ X"، "تدوير مساحة عمل"، "استيراد أحدث التغييرات"، أو "إضافة دليل إلى مزامنة git"، أو "ضبط الإعداد"، أو "ما هي المخططات الموجودة في قاعدة البيانات هذه"، أو "تشغيل المزامنة"، أو "إعادة فحص قيم الحقول"، أو أي شيء يضرب `mb <verb>`.
