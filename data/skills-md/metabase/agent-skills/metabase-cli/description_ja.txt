「mb」CLI を介してターミナルからメタベース インスタンスを駆動します。名前付きプロファイルを使用して認証します。データベース (リスト、取得、完全なメタデータ ロールアップ、スキーマ、スキーマ内のテーブル) を検査し、手動のスキーマ同期 / フィールド値の再スキャンをトリガーします。テーブル、フィールドを検査します。カード (質問、モデル、メトリクス) をリスト/取得/作成/更新/アーカイブし、JSON/CSV/XLSX として実行します。ダッシュボードとパッチ ダッシュカードを一覧表示/取得/作成/更新します。コレクションをリスト/取得/作成し、ID、entity_id、または「ルート」/「ゴミ箱」(アイテムと再帰ツリーを含む) によって階層を横断します。ネイティブ クエリ スニペット、セグメント、メジャーのリスト/取得/作成/更新/アーカイブ。変換を作成/更新/実行し、変換ジョブをスケジュールします。設定の読み取り/更新。コンテンツの検索 (カード、ダッシュボード、コレクション、変換、メトリクス)。エンタープライズワークスペースを管理する。 git リモートとの間の git-sync (ステータス、ダーティ、インポート、エクスポート、ブランチ、スタッシュ、同期からのコレクションの追加/削除)。ユーザーが端末からメタベースを操作する場合はいつでも使用します。「メタベースへのログイン」、「どのプロファイルを持っているか」、「カードのリスト」、「カード 42 を CSV として実行」、「変換の作成」、「ダッシュボードのリスト」、「ダッシュカードの移動」、「コレクションのリスト」、「コレクション 4 の内容」、「コレクション ツリーの表示」、「スニペットのリスト」、「セグメントの作成」、「メジャーのアーカイブ」、「検索」 「X のメタベース」、「ワークスペースをスピンアップする」、「最新の変更をインポートする」、「git sync にディレクトリを追加する」、「設定を設定する」、「このデータベースに含まれるスキーマ」、「同期をトリガーする」、「フィールド値を再スキャンする」など、`mb <動詞>` に該当するものはすべて含まれます。
