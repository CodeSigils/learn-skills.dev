Управляйте экземпляром Metabase с терминала через CLI `mb`. Аутентификация с помощью именованных профилей; проверять базы данных (список, получение, полное объединение метаданных, схемы, таблицы в схеме) и запускать ручную синхронизацию схемы/повторное сканирование значений полей; проверять таблицы, поля; составлять список/получать/создавать/обновлять/архивировать карточки (вопросы, модели, показатели) и запускать их в формате JSON/CSV/XLSX; список/получение/создание/обновление информационных панелей и исправлений информационных панелей; список/получение/создание коллекций и перемещение по иерархии по идентификатору,entity_id или "корню"/"мусору" (с элементами и рекурсивным деревом); список/получение/создание/обновление/архивирование фрагментов, сегментов и показателей собственных запросов; создавать/обновлять/запускать преобразования и планировать задания преобразования; прочитать/обновить настройки; поиск по контенту (карточки, дашборды, коллекции, трансформации, метрики); управлять рабочими пространствами предприятия; git-sync с/на удаленный git (статус, грязный, импорт, экспорт, ветки, тайник, добавление/удаление коллекции из синхронизации). Используйте всякий раз, когда пользователь хочет взаимодействовать с метабазой с терминала — «войти в метабазу», «какие профили у меня есть», «перечислить карточки», «запустить карточку 42 как CSV», «создать преобразование», «составить список панелей мониторинга», «переместить панель мониторинга», «список коллекций», «что в коллекции 4», «показать дерево коллекции», «список фрагментов», «создать сегмент», «архивировать показатель», «поиск в метабазе для X», «развернуть рабочую область», «импортировать последние изменения», «добавить каталог для синхронизации git», «задать настройку», «какие схемы находятся в этой базе данных», «запустить синхронизацию», «пересканировать значения полей» или что-нибудь еще, нажимая `mb <verb>`.
