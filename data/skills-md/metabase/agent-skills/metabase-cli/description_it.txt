Guida un'istanza Metabase dal terminale tramite la CLI `mb`. Autenticarsi con profili denominati; ispezionare i database (elenco, acquisizione, rollup completo dei metadati, schemi, tabelle in uno schema) e attivare la sincronizzazione manuale dello schema/la nuova scansione dei valori dei campi; ispezionare tabelle, campi; elencare/ottenere/creare/aggiornare/archiviare schede (domande, modelli, metriche) ed eseguirle come JSON/CSV/XLSX; elencare/ottenere/creare/aggiornare dashboard e dashboard di patch; elenca/ottieni/crea raccolte e attraversa la gerarchia tramite id, entità_id o "root"/"cestino" (con elementi e albero ricorsivo); elencare/ottenere/creare/aggiornare/archiviare frammenti di query, segmenti e misure nativi; creare/aggiornare/eseguire trasformazioni e pianificare processi di trasformazione; leggere/aggiornare le impostazioni; contenuti di ricerca (schede, dashboard, raccolte, trasformazioni, metriche); gestire gli spazi di lavoro aziendali; git-sync da/verso un git remoto (stato, dirty, importazione, esportazione, rami, stash, aggiunta/rimozione di una raccolta dalla sincronizzazione). Utilizzare ogni volta che l'utente desidera interagire con una metabase dal terminale: "accedi alla metabase", "quali profili ho", "elenca le carte", "esegui la carta 42 come CSV", "crea una trasformazione", "elenca dashboard", "sposta una dashcard", "elenca raccolte", "cosa c'è nella raccolta 4", "mostra l'albero della raccolta", "elenca frammenti", "crea un segmento", "archivia una misura", "cerca X nella metabase", "avvia un'area di lavoro", "importa il ultime modifiche", "aggiungi una directory a git sync", "imposta un'impostazione", "quali schemi sono presenti in questo database", "attiva una sincronizzazione", "ripeta la scansione dei valori dei campi" o qualsiasi cosa che colpisca `mb <verb>`.
