Pilotez une instance Metabase depuis le terminal via la CLI `mb`. Authentifiez-vous avec des profils nommés ; inspecter les bases de données (liste, obtention, cumul complet des métadonnées, schémas, tables dans un schéma) et déclencher une synchronisation manuelle des schémas/une nouvelle analyse des valeurs de champ ; inspecter les tables, les champs ; lister/obtenir/créer/mettre à jour/archiver les cartes (questions, modèles, métriques) et les exécuter au format JSON/CSV/XLSX ; lister/obtenir/créer/mettre à jour les tableaux de bord et les fiches de correctifs ; lister/obtenir/créer des collections et parcourir la hiérarchie par identifiant, entité_id ou "racine"/"trash" (avec éléments et arbre récursif) ; lister/obtenir/créer/mettre à jour/archiver des extraits de requête, des segments et des mesures natifs ; créer/mettre à jour/exécuter des transformations et planifier des tâches de transformation ; lire/mettre à jour les paramètres ; rechercher du contenu (cartes, tableaux de bord, collections, transformations, métriques) ; gérer les espaces de travail d'entreprise ; git-sync vers/depuis une télécommande git (statut, dirty, import, export, branches, cache, ajouter/supprimer une collection de la synchronisation). À utiliser chaque fois que l'utilisateur souhaite interagir avec une métabase à partir du terminal : "se connecter à la métabase", "quels profils ai-je", "lister les cartes", "exécuter la carte 42 au format CSV", "créer une transformation", "lister les tableaux de bord", "déplacer une carte de tableau de bord", "lister les collections", "le contenu de la collection 4", "afficher l'arborescence des collections", "lister des extraits", "créer un segment", "archiver une mesure", "rechercher une métabase pour X", "faire tourner un espace de travail", "importer les dernières modifications", "ajouter un répertoire à git sync", "définir un paramètre", "quels sont les schémas dans cette base de données", "déclencher une synchronisation", "réanalyser les valeurs des champs" ou tout ce qui frappe `mb <verb>`.
