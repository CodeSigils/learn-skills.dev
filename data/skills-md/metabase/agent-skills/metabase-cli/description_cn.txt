通过“mb” CLI 从终端驱动元数据库实例。使用命名配置文件进行身份验证；检查数据库（列表、获取、完整元数据汇总、模式、模式中的表）并触发手动模式同步/字段值重新扫描；检查表、字段；列出/获取/创建/更新/存档卡（问题、模型、指标）并将其作为 JSON/CSV/XLSX 运行；列出/获取/创建/更新仪表板和补丁仪表板；列出/获取/创建集合并通过 id、entity_id 或“root”/“trash”（带有项目和递归树）遍历层次结构；列出/获取/创建/更新/存档本机查询片段、段和度量；编写/更新/运行转换并安排转换作业；读取/更新设置；搜索内容（卡片、仪表板、集合、转换、指标）；管理企业工作区； git-sync 到/从 git 远程（状态、脏、导入、导出、分支、存储、从同步中添加/删除集合）。每当用户想要从终端与配置数据库交互时使用 - “登录配置数据库”、“我有哪些配置文件”、“列出卡”、“以 CSV 形式运行卡 42”、“创建转换”、“列出仪表板”、“移动仪表板”、“列出集合”、“集合 4 中有什么”、“显示集合树”、“列出片段”、“创建分段”、“归档度量”、“搜索 X 的配置数据库”、 “启动工作区”、“导入最新更改”、“将目录添加到 git 同步”、“设置设置”、“此数据库中有哪些模式”、“触发同步”、“重新扫描字段值”或任何点击 `mb <verb>` 的内容。
