فهم تنسيق تمثيل قاعدة التعريف - تنسيق تسلسل قائم على YAML لمحتوى قاعدة التعريف (المجموعات، والبطاقات، ولوحات المعلومات، والمستندات، والشرائح، والمقاييس، والمقتطفات، والتحويلات). يُستخدم عندما يحتاج المستخدم إلى إنشاء ملفات YAML لتمثيل قاعدة التعريف أو تحريرها أو فهمها أو التحقق من صحتها، أو عند العمل مع تسلسل/إلغاء تسلسل قاعدة التعريف (serdes). يغطي مخططات الكيانات وMBQL والاستعلامات الأصلية وإعدادات التمثيل المرئي والمعلمات وبنية المجلد.
