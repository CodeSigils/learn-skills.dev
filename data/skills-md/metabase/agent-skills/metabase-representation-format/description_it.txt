Comprende il formato di rappresentazione Metabase: un formato di serializzazione basato su YAML per il contenuto Metabase (raccolte, schede, dashboard, documenti, segmenti, misure, frammenti, trasformazioni). Da utilizzare quando l'utente deve creare, modificare, comprendere o convalidare file YAML di rappresentazione della metabase o quando lavora con la serializzazione/deserializzazione della metabase (serdes). Copre schemi di entità, query MBQL e native, impostazioni di visualizzazione, parametri e struttura delle cartelle.
