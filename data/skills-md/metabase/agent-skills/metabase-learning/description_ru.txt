Тренер по обучению интервальному повторению для Metabase. Используйте этот навык всякий раз, когда пользователь хочет: изучить Metabase, начать сеанс обучения Metabase, выполнить обзор Metabase, попрактиковаться в концепциях Metabase, проверить, что ему следует изучить сегодня, пройти тест по Metabase, пройти активный отзыв по инструментам BI или следовать структурированной программе обучения программному обеспечению для анализа данных. Активируйте этот навык, даже если пользователь просто говорит: «давайте проведем сеанс Metabase», «проверьте меня на Metabase» или «что мне следует изучить сегодня?» в контексте обучения метабазе.
