Migre un projet React de l'intégration modulaire Metabase (composants Web embed.js) vers le SDK d'intégration modulaire (@metabase/embedding-sdk-react). À utiliser lorsque l'utilisateur souhaite passer des composants Web embed.js aux composants React SDK (MetabaseProvider). Il ne s’agit pas d’une mise à niveau de version : cela modifie la technologie d’intégration.
