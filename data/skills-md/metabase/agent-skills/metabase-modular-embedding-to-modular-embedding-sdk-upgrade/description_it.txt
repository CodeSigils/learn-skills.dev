Migra un progetto React dall'incorporamento Metabase Modular (componenti web embed.js) all'SDK di incorporamento Modular (@metabase/embedding-sdk-react). Da utilizzare quando l'utente desidera passare dai componenti Web embed.js ai componenti React SDK (MetabaseProvider). Questo non è un aggiornamento della versione: cambia la tecnologia di incorporamento.
