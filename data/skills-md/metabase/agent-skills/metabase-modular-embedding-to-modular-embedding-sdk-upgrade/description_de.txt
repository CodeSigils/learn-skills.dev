Migriert ein React-Projekt von Metabase Modular Embedding (embed.js-Webkomponenten) zum Modular Embedding SDK (@metabase/embedding-sdk-react). Verwenden Sie diese Option, wenn der Benutzer von Embed.js-Webkomponenten zu React SDK-Komponenten (MetabaseProvider) wechseln möchte. Dies ist kein Versions-Upgrade – es ändert die Einbettungstechnologie.
