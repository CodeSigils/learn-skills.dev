Переносит проект React из модульного внедрения Metabase (веб-компоненты embed.js) в SDK модульного внедрения (@metabase/embedding-sdk-react). Используйте, когда пользователь хочет переключиться с веб-компонентов embed.js на компоненты React SDK (MetabaseProvider). Это не обновление версии — это меняет технологию встраивания.
