Versteht das Metadatenformat der Metabase-Datenbank – eine YAML-basierte Darstellung von Datenbanken, Tabellen und Feldern auf der Festplatte, die von einer Metabase-Instanz synchronisiert werden. Verwenden Sie diese Option, wenn der Benutzer Metadatendateien lesen, bearbeiten oder verstehen muss, die von „@metabase/database-metadata“ erstellt wurden, oder wenn er Überlegungen zum Schema eines Projekts (Spalten, Typen, FK-Beziehungen) über den Ordner „.metabase/databases“ anstellt.
