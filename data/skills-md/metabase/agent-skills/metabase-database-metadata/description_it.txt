Comprende il formato dei metadati del database Metabase: una rappresentazione su disco basata su YAML di database, tabelle e campi sincronizzati da un'istanza Metabase. Da utilizzare quando l'utente ha bisogno di leggere, modificare o comprendere i file di metadati prodotti da "@metabase/database-metadata" o quando ragiona sullo schema di un progetto (colonne, tipi, relazioni FK) attraverso la cartella ".metabase/databases".
