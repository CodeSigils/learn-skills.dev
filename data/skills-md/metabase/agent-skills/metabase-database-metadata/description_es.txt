Comprende el formato de metadatos de la base de datos de la metabase: una representación en disco basada en YAML de bases de datos, tablas y campos sincronizados desde una instancia de metabase. Úselo cuando el usuario necesite leer, editar o comprender archivos de metadatos producidos por `@metabase/database-metadata`, o cuando razona sobre el esquema de un proyecto (columnas, tipos, relaciones FK) a través de la carpeta `.metabase/databases`.
