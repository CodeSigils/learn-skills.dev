Comprend le format de métadonnées de la base de données Metabase : une représentation sur disque basée sur YAML des bases de données, des tables et des champs synchronisés à partir d'une instance de métabase. À utiliser lorsque l'utilisateur a besoin de lire, modifier ou comprendre les fichiers de métadonnées produits par `@metabase/database-metadata`, ou lorsqu'il raisonne sur le schéma d'un projet (colonnes, types, relations FK) via le dossier `.metabase/databases`.
