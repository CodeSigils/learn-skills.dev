مهارة شاملة لـ `kb` CLI ونمط قاعدة معارف Karpathy. يغطي دورة حياة قاعدة المعارف الكاملة — دعم المواضيع، والتناول متعدد المصادر (عناوين URL، والملفات، وYouTube، والإشارات المرجعية، وقواعد التعليمات البرمجية)، وتجميع مقالات wiki، والاستعلام عبر المقالات باستخدام إرجاع الملفات، وممرات الوبر والشفاء، وفهرسة QMD، والبحث المختلط. يغطي أيضًا التحليل الخاص بقاعدة التعليمات البرمجية عبر أوامر الفحص للتعقيد، والاقتران، ونصف قطر الانفجار، والرمز الميت، والتبعيات الدائرية، وعمليات البحث عن الرموز/الملفات، والروابط الخلفية، وروائح التعليمات البرمجية. يُستخدم عند العمل مع أوامر kb CLI، أو سير عمل قاعدة المعرفة، أو إنشاء مخزن التعليمات البرمجية، أو تحليل الرسم البياني للتعليمات البرمجية، أو فحص مقاييس التعليمات البرمجية، أو تجميع wiki، أو دورة استيعاب-ترجمة-الاستعلام-lint. لا تستخدمه لمراجعة التعليمات البرمجية العامة، أو الفحص، أو التنسيق، أو إنشاء مشاريع Go، أو كتابة تعليمات برمجية للتطبيق.
