Комплексные навыки работы с CLI `kb` и шаблоном базы знаний Karpathy. Охватывает полный жизненный цикл базы знаний — формирование тем, прием данных из нескольких источников (URL-адреса, файлы, YouTube, закладки, базы кода), компиляцию вики-статей, межстатейные запросы с возвратом файлов, проходы проверки и восстановления, индексацию QMD и гибридный поиск. Также охватывает анализ конкретной кодовой базы с помощью команд проверки на предмет сложности, связи, радиуса взрыва, мертвого кода, циклических зависимостей, поиска символов/файлов, обратных ссылок и запахов кода. Используйте при работе с командами CLI базы знаний, рабочими процессами базы знаний, созданием хранилища кода, анализом графа кода, проверкой метрик кода, компиляцией вики или циклом приема-компиляции-запроса-проверки. Не используйте для общего обзора кода, анализа, форматирования, создания проектов Go или написания кода приложения.
