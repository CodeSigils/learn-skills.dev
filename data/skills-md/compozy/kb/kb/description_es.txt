Habilidad integral para la CLI `kb` y el patrón Karpathy Knowledge Base. Cubre el ciclo de vida completo de la base de conocimiento: andamiaje de temas, ingesta de múltiples fuentes (URL, archivos, YouTube, marcadores, bases de código), compilación de artículos wiki, consultas entre artículos con devolución de archivos, pases de lint-and-heal, indexación QMD y búsqueda híbrida. También cubre el análisis específico de la base de código mediante comandos de inspección para detectar complejidad, acoplamiento, radio de explosión, código inactivo, dependencias circulares, búsquedas de símbolos/archivos, vínculos de retroceso y olores de código. Úselo cuando trabaje con comandos CLI de kb, flujos de trabajo de bases de conocimientos, generación de bóvedas de código, análisis de gráficos de código, inspección de métricas de código, compilación de wiki o el ciclo de ingesta-compilación-consulta-lint. No lo utilice para revisión general de código, linting, formateo, creación de proyectos Go o escritura de código de aplicación.
