Compétence complète pour la CLI `kb` et le modèle de base de connaissances Karpathy. Couvre le cycle de vie complet de la base de connaissances : échafaudage de sujets, ingestion multi-sources (URL, fichiers, YouTube, signets, bases de code), compilation d'articles wiki, requêtes inter-articles avec retour de fichiers, passes de peluches et de réparation, indexation QMD et recherche hybride. Couvre également l'analyse spécifique à la base de code via des commandes d'inspection pour la complexité, le couplage, le rayon d'explosion, le code mort, les dépendances circulaires, les recherches de symboles/fichiers, les backlinks et les odeurs de code. À utiliser lorsque vous travaillez avec des commandes kb CLI, des flux de travail de base de connaissances, la génération de coffre-fort de code, l'analyse de graphiques de code, l'inspection de métriques de code, la compilation wiki ou le cycle ingest-compile-query-lint. Ne pas utiliser pour la révision générale du code, le peluchage, le formatage, la création de projets Go ou l'écriture de code d'application.
