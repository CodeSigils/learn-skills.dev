skeeper を使用して、メイン リポジトリの履歴を汚すことなく、スペック アーティファクト (SPEC.md、ADR、RFC、プラン/PRD/TechSpec マークダウン、カスタム グロブ) を記述されたコードの隣に保持する方法について説明します。厳密なフック、追跡される skeeper.lock ファイル、名前空間、Git のようなステータス/プル/プッシュ/同期/復元ワークフロー、追跡/追跡解除、修復、SKEEPER_SKIP、および GitHub アクションについて説明します。 skeeper のセットアップ、サイドカーの構成、ロックファイルの同期またはチェック、ドリフトまたは失敗した同期の回復、バイパスの監査、または CI の配線時に使用します。一般的な Git フックの質問、.skeeper.yml がなく、追加する意図がないリポジトリ、または skeeper の内部の編集には使用しないでください。
