Úselo al diseñar, crear, revisar o arreglar cualquier interfaz de usuario de derecha a izquierda (RTL) (persa/farsi (فارسی), árabe, hebreo, urdu) en la web (React, Next.js, Vue, Tailwind, CSS simple) o Flutter, incluso si el usuario solo dice que la aplicación es persa/iraní sin mencionar RTL. Cubre la dirección del diseño y la duplicación, qué íconos se voltean y cuáles nunca, texto bidireccional (bidi) con islas LTR (URL, correos electrónicos, números de teléfono, códigos), dígitos persa versus árabe-índico versus latino, fechas Jalali (Shamsi), tipografía persa (emparejamiento de fuentes, altura de línea, trampa de espaciado entre letras, ZWNJ نیم‌فاصله), licencias de fuentes, propiedades lógicas de CSS, entrada de formulario dirección y desbordamiento de texto largo. Úselo también cuando el texto persa/árabe se muestre incorrecto o "desactivado", al localizar una aplicación LTR en RTL o para auditar el código existente en busca de violaciones de RTL con el detector de dependencia cero incluido. No para tareas de backend o que no sean de UI.
