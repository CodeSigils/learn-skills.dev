Web (React、Next.js、Vue、Tailwind、プレーン CSS) または Flutter 上で右から左へ (RTL) ユーザー インターフェイス (ペルシア語/ペルシャ語 (فارسی)、アラビア語、ヘブライ語、ウルドゥー語) を設計、構築、レビュー、修正する場合に使用します。ユーザーがアプリがペルシャ語/イラン語であるとだけ述べ、RTL について言及していない場合でも使用します。レイアウトの方向とミラーリング、どのアイコンが反転するのか、反転しないのか、LTR アイランドを含む双方向 (bidi) テキスト (URL、電子メール、電話番号、コード)、ペルシャ語とアラビア語 - インド語とラテン語の数字、ジャラーリ語 (シャムシ) の日付、ペルシャ語のタイポグラフィ (フォントのペアリング、行の高さ、文字間隔のトラップ、ZWNJ 規則)、フォントのライセンス、論理をカバーします。 CSS プロパティ、フォーム入力方向、長いテキストのオーバーフロー。また、ペルシア語/アラビア語のテキストが間違って表示されるか「オフ」になる場合、LTR アプリを RTL にローカライズする場合、またはバンドルされたゼロ依存性検出器を使用して既存のコードの RTL 違反を監査する場合にも使用します。バックエンド専用タスクまたは非 UI タスクには使用できません。
