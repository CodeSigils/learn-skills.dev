Guide d'utilisation de Gridex — une bibliothèque complète de grilles de données React construite sur TanStack Table v8. À utiliser lorsque l'utilisateur pose des questions sur les grilles de données, les tableaux, les feuilles de calcul dans React ou a besoin d'aide avec les colonnes Gridex, le tri, le filtrage, l'édition, les données côté serveur, l'exportation, la création de thèmes ou toute API Gridex.
