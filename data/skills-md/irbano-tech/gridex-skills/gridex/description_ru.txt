Руководство по использованию Gridex — комплексной библиотеки сеток данных React, созданной на основе TanStack Table v8. Используйте, когда пользователь спрашивает о сетках данных, таблицах, электронных таблицах в React или ему нужна помощь со столбцами Gridex, сортировкой, фильтрацией, редактированием, данными на стороне сервера, экспортом, темами или любым API Gridex.
