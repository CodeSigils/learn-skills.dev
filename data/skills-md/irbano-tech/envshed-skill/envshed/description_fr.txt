Guide d'utilisation de l'envshed CLI — un outil de gestion des secrets pour gérer les variables d'environnement dans les projets, les espaces de travail et les environnements. À utiliser lorsque l'utilisateur pose des questions sur les variables d'environnement, les secrets, les fichiers .env, les commandes envshed ou a besoin d'aide pour la configuration de l'environnement.
