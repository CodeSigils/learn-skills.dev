Configure un catálogo de viñetas existente después de la clonación leyendo catalog.toml, verificando uv y auth, instalando marimo-pair, iniciando el primer cuaderno marimo en --sandbox, registrando un kernel activo y entregándolo a vignette-catalog-compose-notebook. Úselo cuando alguien esté en un repositorio de catálogo y solicite comenzar, configurar, ejecutar el catálogo, iniciar el primer cuaderno o preparar un kernel activo. No lo utilice para crear un nuevo catálogo; use viñeta-catalog-scaffold para eso.
