Schreiben, Umschreiben, Überprüfen und Organisieren von entwicklerorientierter Dokumentation für Websoftwareprojekte. Zum Erstellen oder Verbessern von README-Dateien, Dokument-Homepages, Schnellstarts, Tutorials, Anleitungen, API-/Referenzseiten, konzeptionellen Erklärungen, Migrationshandbüchern oder Fehlerbehebungsinhalten für Frontend-, Backend-, Full-Stack-, SDK-, API- oder Framework-basierte Webprodukte. Diese Fähigkeit wendet eine starke Informationsarchitektur, eine aufgabenorientierte Seitenstruktur, klare Sprache, ausführbare Beispiele, Versions- und Voraussetzungshygiene, Barrierefreiheitsregeln und Wartungsgewohnheiten für Dokumente als Code an. Verwenden Sie es nicht für Marketingtexte, Rechtstexte oder nichttechnische Kundensupportartikel.
