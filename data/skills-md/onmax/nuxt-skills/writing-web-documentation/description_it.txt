Scrivi, riscrivi, rivedi e organizza la documentazione rivolta agli sviluppatori per progetti software web. Da utilizzare durante la creazione o il miglioramento di file README, home page di documenti, guide di avvio rapido, tutorial, guide pratiche, pagine API/di riferimento, spiegazioni concettuali, guide alla migrazione o contenuti per la risoluzione di problemi per frontend, backend, full-stack, SDK, API o prodotti web basati su framework. Questa competenza applica una solida architettura dell'informazione, struttura della prima pagina delle attività, voce chiara, esempi eseguibili, igiene delle versioni e dei prerequisiti, regole di accessibilità e abitudini di manutenzione dei documenti come codice. Non utilizzarlo per testi di marketing, testi legali o articoli di assistenza clienti non tecnici.
