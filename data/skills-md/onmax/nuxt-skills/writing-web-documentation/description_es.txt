Escriba, reescriba, revise y organice documentación dirigida a desarrolladores para proyectos de software web. Úselo al crear o mejorar archivos README, páginas de inicio de documentos, inicios rápidos, tutoriales, guías prácticas, páginas de API/referencia, explicaciones conceptuales, guías de migración o contenido de solución de problemas para productos web frontend, backend, full-stack, SDK, API o basados ​​en framework. Esta habilidad aplica una sólida arquitectura de información, estructura de página de tarea primero, voz clara, ejemplos ejecutables, higiene de versiones y requisitos previos, reglas de accesibilidad y hábitos de mantenimiento de documentos como código. No lo utilice para textos de marketing, textos legales o artículos de atención al cliente no técnicos.
