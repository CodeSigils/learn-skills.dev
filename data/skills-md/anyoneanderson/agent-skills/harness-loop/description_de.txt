Führen Sie die GAN-Kontrollschleife für ein Epic aus: Verhandeln Sie für jeden Sprint die
Vertrag, Iteration Generator ⇄ Evaluator zur Rubrikkonvergenz (oder
Haupt-Skinner-Stopp), Prüfpunkt auf progress.md + _state.json +
git + metrics.jsonl bei jeder Iteration und öffnen Sie die PR. Griffe
interaktive / kontinuierliche / autonome Ralph- / geplante Ausführungsmodi.

Voraussetzung: /harness-init und /harness-plan müssen abgeschlossen sein.
_state.json.phase muss „ready-for-loop“ (frisch) oder einer der folgenden sein
In-Sprint-Phasen (Lebenslauf).

Englische Auslöser: „Run Harness-Loop“, „Start the Sprint Loop“, „Execute Sprints“
