1 つのエピックに対して GAN 制御ループを実行します。スプリントごとに、
コントラクト、反復ジェネレーター ⇄ エバリュエーターからルーブリックへの収束 (または
スキナー校長停止)、progress.md + _state.json + へのチェックポイント
反復ごとに git + metrics.jsonl を実行し、PR を開きます。ハンドル
インタラクティブ / 継続的 / 自律ラルフ / スケジュールされた実行モード。

前提条件: /harness-init および /harness-plan が完了している必要があります。
_state.json.phase は、「ready-for-loop」(新鮮)、または次のいずれかである必要があります。
スプリント中フェーズ (再開)。
