Автономная реализация одной задачи из технических документов.

Читает require.md, design.md и Tasks.md, чтобы понять полный контекст проекта.
затем реализует указанную задачу, следуя правилам кодирования и соглашениям проекта.
Поддерживает режим --feedback для рассмотрения результатов обзора или тестирования.

Английские триггеры: «Реализовать задачу», «Закодировать эту задачу», «Запустить спецкод».
日本語トリガー: 「タスクを実装」「このタスクをコーディング」「spec-codeを実行」
