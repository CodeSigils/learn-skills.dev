Implementieren Sie eine einzelne Aufgabe aus Spezifikationsdokumenten autonom.

Liest „requirement.md“, „design.md“ und „tasks.md“, um den gesamten Projektkontext zu verstehen.
Anschließend wird die angegebene Aufgabe gemäß den Codierungsregeln und Projektkonventionen implementiert.
Unterstützt den --feedback-Modus, um Überprüfungs- oder Testergebnisse zu berücksichtigen.

Englische Auslöser: „Aufgabe implementieren“, „Diese Aufgabe codieren“, „Spezifikationscode ausführen“
日本語トリガー: 「タスクを実装」「このタスクをコーディング」「spec-codeを実行」
