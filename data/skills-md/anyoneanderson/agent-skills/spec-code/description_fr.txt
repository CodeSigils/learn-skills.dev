Implémentez une seule tâche à partir des documents de spécifications de manière autonome.

Lit require.md, design.md et Tasks.md pour comprendre le contexte complet du projet,
implémente ensuite la tâche spécifiée en suivant les règles de codage et les conventions du projet.
Prend en charge le mode --feedback pour répondre aux résultats des examens ou des tests.

Déclencheurs en anglais : « Implémenter la tâche », « Coder cette tâche », « Exécuter le code de spécification »
Nom du produit : "spec-code" spec-code
