Разветвите текущий диалог Claude Code на новую панель или рабочую область cmux.
По умолчанию: разделить вправо. Поддерживает вниз и новое рабочее пространство через естественный язык.

Требуется сеанс cmux (необходимо установить CMUX_SOCKET_PATH).

Английские триггеры: «вилочный сеанс», «вилочный разговор», «разделить и разветвить».
日本語トリガー: 「フォークして」「会話をフォーク」「ターミナルをフォークして」「もう一個ターミナル立ち上げて」
Слэш-команда: /cmux-fork
