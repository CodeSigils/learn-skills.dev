MCP-Konfigurationskonverter für Agent-CLIs.

Konvertiert Claude Code MCP-Einstellungen in Codex CLI MCP-Konfiguration,
Kopieren von Umgebungswerten direkt in die Codex-Konfiguration.

Verwenden Sie dies, wenn der Benutzer Folgendes möchte:
- MCP-Server von Claude Code auf Codex CLI migrieren
- Synchronisieren Sie die MCP-Einstellungen von Claude Code mit Codex
- Claude MCP-Einstellungen als Codex-Konfiguration exportieren
- MCP-Definitionen kopieren und dabei Befehle und Umgebungsverhalten beibehalten
