에이전트 CLI용 MCP 구성 변환기.

Claude Code MCP 설정을 Codex CLI MCP 구성으로 변환합니다.
환경 값을 Codex 구성에 직접 복사합니다.

사용자가 다음을 원할 때 이 기능을 사용하세요.
- Claude Code에서 Codex CLI로 MCP 서버 마이그레이션
- Claude Code MCP 설정을 Codex에 동기화
- Claude MCP 설정을 Codex 구성으로 내보내기
- 명령 및 환경 동작을 유지하면서 MCP 정의를 복사합니다.

영어 트리거:
- "Claude MCP를 Codex로 변환"
- "Claude Code의 MCP 설정 동기화"
- "MCP 구성을 Codex CLI로 마이그레이션"
- "Claude mcpServers를 Codex에 복사"

일본어트리거:
- 「클로드 코드의 MCP를 Codex에 変換」
- 「Claude의 MCP 설명은 Codex CLI와 동일합니다」
- 「MCP設정を移行」
- 「claudeのmcpServersをcodexに持たていiku」
