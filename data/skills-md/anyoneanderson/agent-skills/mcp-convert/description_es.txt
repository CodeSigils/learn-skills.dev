Convertidor de configuración MCP para CLI de agente.

Convierte la configuración de Claude Code MCP en la configuración de Codex CLI MCP,
copiar los valores env directamente en la configuración del Codex.

Úselo cuando el usuario quiera:
- migrar servidores MCP de Claude Code a Codex CLI
- sincronizar la configuración de Claude Code MCP en Codex
- exportar la configuración de Claude MCP como configuración del Codex
- copiar definiciones de MCP conservando los comandos y el comportamiento ambiental

Desencadenantes en inglés:
- "convertir Claude MCP al Codex"
- "sincronizar la configuración de MCP desde Claude Code"
- "migrar la configuración de MCP a Codex CLI"
- "copiar Claude mcpServers al Codex"
