Конвертер конфигурации MCP для агентских интерфейсов командной строки.

Преобразует настройки Claude Code MCP в конфигурацию Codex CLI MCP,
копирование значений env непосредственно в конфигурацию Кодекса.

Используйте это, когда пользователь хочет:
- миграция серверов MCP из Claude Code в Codex CLI
- синхронизировать настройки Claude Code MCP с Кодексом.
- экспортировать настройки Claude MCP как конфигурацию Кодекса
- копировать определения MCP, сохраняя команды и поведение окружения.

Английские триггеры:
- "конвертировать Клода MCP в Кодекс"
- "синхронизировать настройки MCP из Claude Code"
- «перенести конфигурацию MCP в Codex CLI»
- «скопировать Claude mcpServers в Кодекс»

日本語トリガー:
- 「Код КлодのMCPをКодексに変換」
- 「КлодのMCP設定をCodex CLIに同期」
