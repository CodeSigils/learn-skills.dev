Installez une boucle de contrôle Harness Engineering dans le projet en cours.
Entend les paramètres d'environnement une fois, puis génère un planificateur/générateur/évaluateur
sous-agents, hooks, scripts de garde et fichiers de résilience (.harness/, .claude/).

Utilisez-le lorsque vous souhaitez faire passer un projet au développement de sprint autonome
piloté par la série /harness (modes autonome, patrouille automatique ou programmé).
Pas pour les flux de travail basés sur les spécifications – pour cela, utilisez /spec-workflow-init.

Déclencheurs en anglais : « Initialiser le faisceau », « Configurer /harnais », « Installer l'ingénierie du faisceau »
Nom du produit : "harnais" et "harnais-init"
