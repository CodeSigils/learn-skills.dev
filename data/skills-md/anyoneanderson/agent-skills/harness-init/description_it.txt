Installare un circuito di controllo Harness Engineering nel progetto corrente.
Ascolta le impostazioni dell'ambiente una volta, quindi genera Pianificatore/Generatore/Valutatore
agenti secondari, hook, script di guardia e file di resilienza (.harness/, .claude/).

Usalo quando vuoi passare un progetto allo sviluppo di sprint autonomo
guidato dalla serie /harness (modalità autonoma, auto-pattugliamento o programmata).
Non per flussi di lavoro basati su specifiche: per questo utilizzare /spec-workflow-init.

Trigger in inglese: "Inizializza cablaggio", "Configura /cablaggio", "Installa ingegneria di cablaggio"
日本語トリガー: 「harness を導入」「ハーネスを初期化」「harness-init を実行」
