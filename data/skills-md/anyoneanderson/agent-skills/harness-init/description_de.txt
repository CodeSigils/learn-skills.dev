Installieren Sie einen Harness Engineering-Regelkreis im aktuellen Projekt.
Hört einmal die Umgebungseinstellungen und generiert dann den Planer/Generator/Auswerter
Subagenten, Hooks, Guard-Skripte und Resilienzdateien (.harness/, .claude/).

Verwenden Sie dies, wenn Sie ein Projekt auf autonome Sprint-Entwicklung umstellen möchten
angetrieben durch die /harness-Serie (autonomer, automatischer Patrouillen- oder geplanter Modus).
Nicht für spezifikationsgesteuerte Workflows – verwenden Sie hierfür /spec-workflow-init.

Englische Auslöser: „Kabelbaum initialisieren“, „/Kabelbaum einrichten“, „Kabelbaum-Engineering installieren“
Suchbegriff: „harness“
