Структурированная проверка кода на соответствие review_rules.md и coding-rules.md.

Выполняет матрицу по каждому правилу и пофайловому анализу изменений кода.
Выводит результаты в структурированный файл обзора для использования кодом спецификации --feedback.
Работает автономно для ручных проверок или как часть конвейера реализации спецификаций.

Английские триггеры: «Проверить код», «Запустить проверку спецификации», «Проверить на соответствие правилам».
日本語トリガー: 「コードレビュー」「spec-reviewを実行」「ルールに照合」
