Révision structurée du code par rapport à review_rules.md et coding-rules.md.

Effectue un examen matriciel règle par règle, fichier par fichier, des modifications de code.
Génère les résultats dans un fichier de révision structuré pour une utilisation par spec-code --feedback.
Fonctionne de manière autonome pour les révisions manuelles ou dans le cadre d'un pipeline de mise en œuvre de spécifications.
