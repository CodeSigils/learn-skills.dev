Orquestador de canalización de extremo a extremo: gestiona un problema de GitHub o una solicitud humana
desde la especificación hasta la revisión contradictoria, implementación y aceptación.
pruebas y solicitudes de extracción, como una máquina de estado delgada que delega cada unidad
del trabajo a una habilidad del trabajador.

Se ejecuta en modo manual (el ser humano establece la solicitud y aprueba la especificación una vez) o
modo automático (entra un número de problema, sale un PR sin puerta humana). nunca
escribe código, especificaciones, pruebas o se revisa a sí mismo.

Desencadenantes en inglés: "Ejecutar el proceso de especificaciones", "Orquestar este problema para relaciones públicas",
"spec-orchestrate", "Llevar esta función de especificación a PR"
日本語トリガー: 「パイプラインを回して」「Issue から PR まで自動で」
「spec-orquestate を実行」「仕様から PR まで通して」
