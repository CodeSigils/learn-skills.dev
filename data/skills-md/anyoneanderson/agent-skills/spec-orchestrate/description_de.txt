End-to-End-Pipeline-Orchestrator – steuern Sie ein GitHub-Problem oder eine menschliche Anfrage
Von der Spezifikation über die kontradiktorische Prüfung, Implementierung bis hin zur Abnahme
Testing und Pull Request als Thin-State-Machine, die jede Einheit delegiert
von Arbeit zu einer Arbeiterfähigkeit.

Läuft im manuellen Modus (ein Mensch legt die Anforderung fest und genehmigt die Spezifikation einmal) oder
Auto-Modus (eine Issue-Nummer geht ein, eine PR kommt ohne menschliches Tor heraus). Niemals
schreibt selbst Code, Spezifikationen, Tests oder Rezensionen.

Englische Auslöser: „Führen Sie die Spezifikationspipeline aus“, „Orchestrieren Sie dieses Problem an PR“,
„spec-orchestrate“, „Übernehmen Sie diese Funktion von der Spezifikation zur PR“
Titel: 「パイプラインを回して」「Issue から PR まで自動で」
「spec-orchestrate を実行」「仕様から PR まで通して」
