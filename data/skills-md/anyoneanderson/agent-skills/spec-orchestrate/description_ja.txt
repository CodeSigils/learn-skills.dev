エンドツーエンドのパイプライン オーケストレーター — GitHub の問題または人間のリクエストを推進します
仕様から敵対的なレビュー、実装、承認まで
すべてのユニットを委任するシン ステート マシンとしてのテストとプル リクエスト
仕事のスキルを労働者のスキルに変える。

手動モードで実行します (人間がリクエストを設定し、仕様を一度承認します) または
自動モード (問題番号が入力され、人間によるゲートなしで PR が出力されます)。決してしない
コード、仕様書、テスト、またはレビュー自体を作成します。

英語のトリガー: 「仕様パイプラインを実行する」、「この問題を PR に調整する」、
"spec-orchestrate", "この機能を仕様から PR に取り入れます"
日本語トリガー: 「パイプラインを回して」「発行からPRまで自動で」
