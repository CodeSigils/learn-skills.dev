完成した計画に対してブラックボックス受け入れテスト計画 (test.md) を実行します。
実装し、構造化された合否結果を生成します。

各テスト ケースをその検証方法 (playwright / command /
file-check)、プロジェクト レシピからアプリを起動し、スクリーンショットを保存し、
証拠としてログを記録し、仕様レビューと互換性のある所見ファイルを書き込みます。
spec-code --フィードバックは消費できます。スタンドアロンまたは内部で実行
spec-orchestrate パイプライン、Claude サブエージェントまたは委任されたピア LLM 上。

英語のトリガー: 「この機能の受け入れテスト」、「仕様評価の実行」、
「test.md に対して検証する」、「受け入れテスト計画を実行する」
日本語トリガー: 「この機能を受け入れ試験して」「spec-evaluateを実行」
「test.mdを実行」「受け入れテストを回して」
