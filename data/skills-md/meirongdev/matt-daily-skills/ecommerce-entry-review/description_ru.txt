Используйте этот навык всякий раз, когда пользователю нужно просмотреть проект задания для нового сотрудника — особенно систему электронной коммерции Java плюс Spring Boot (монолит или микросервисы) — и подготовиться к обсуждению один на один. Запускайте такие фразы, как «проверка 新人的入职项目», «帮我看新同学的 входная задача», «准备和新人 1-1», «проверка нового кода найма», «проверка задачи по адаптации», «проверка 新人入职任务», или когда Пользователь загружает базу кода электронной коммерции Java/Spring в контексте адаптации или наставничества. Примените это, даже если пользователь просто говорит «Проверьте 一下这个项目», когда предыдущий контекст касается приема на работу нового инженера. Этот навык позволяет получить два результата — приоритетный отчет, ориентированный на рост, и сократовское руководство для дискуссий один на один с открытыми вопросами, а не прямыми ответами — с акцентом на конечные автоматы заказов, параллельный учет запасов, идемпотентность обратного вызова платежей, DDD и ограниченные контексты, границы микросервисов, распределенные транзакции, кэширование, асинхронность и наблюдаемость.
