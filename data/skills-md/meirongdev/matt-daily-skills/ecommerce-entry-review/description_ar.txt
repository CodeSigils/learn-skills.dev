استخدم هذه المهارة عندما يحتاج المستخدم إلى مراجعة مشروع مهمة دخول موظف جديد - وخاصة نظام التجارة الإلكترونية Java plus Spring Boot (متراصة أو خدمات صغيرة) - والاستعداد لمناقشة 1-1. قم بتشغيل عبارات مثل "مراجعة مهمة الإدخال"، و"مراجعة مهمة الإدخال"، و"مراجعة رمز التوظيف الجديد"، و"مراجعة مهمة الإعداد"، و"مراجعة مهمة الإعداد"، أو عندما يقوم المستخدم بتحميل قاعدة بيانات Java/Spring للتجارة الإلكترونية في سياق الإعداد أو التوجيه. قم بتطبيق هذا حتى إذا كان المستخدم يقول فقط "帮我 review 一下这个项目" عندما يكون السياق السابق يتعلق بتأهيل مهندس جديد. تنتج المهارة نتيجتين - تقرير مراجعة موجه نحو النمو حسب الأولوية، ودليل مناقشة سقراطي 1-1 مع أسئلة مفتوحة بدلاً من الإجابات المباشرة - مع التركيز على أجهزة حالة الطلب، وخصم المخزون المتزامن، وعجز رد الاتصال بالدفع، وDDD والسياقات المحدودة، وحدود الخدمات الصغيرة، والمعاملات الموزعة، والتخزين المؤقت، وعدم المزامنة، وقابلية الملاحظة.
