このスキルは、ユーザーが新入社員の入社タスク プロジェクト、特に Java と Spring Boot 電子商取引システム (モノリスまたはマイクロサービス) をレビューし、1 対 1 のディスカッションの準備をする必要がある場合に使用します。 「レビュー新人的入职项目」、「帮我看新同エントリータスク」、「標準备和新人 1-1」、「レビュー新入社員コード」、「オンボーディングタスクレビュー」、「新人入职任务レビュー」などのフレーズでトリガーされるか、ユーザーがオンボーディングまたはメンタリングのコンテキストで Java/Spring 電子商取引コードベースをアップロードしたときにトリガーされます。前のコンテキストが新しいエンジニアのオンボーディングに関するもので、ユーザーが「帮我レビュー一下这个项目」とだけ言った場合でも、これを適用します。このスキルは、注文ステート マシン、同時在庫控除、支払いコールバック冪等性、DDD と制限されたコンテキスト、マイクロサービス境界、分散トランザクション、キャッシュ、非同期、可観測性に焦点を当てた 2 つの成果物 (優先順位付けされた成長指向レビュー レポートと、直接的な回答ではなく自由回答の質問を含む Socratic 1-1 ディスカッション ガイド) を生成します。
