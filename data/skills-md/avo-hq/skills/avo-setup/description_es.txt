Instale Avo, móntelo en `config/routes.rb`, autentique el servidor de gemas privado y configure la clave de licencia. Úselo cuando el usuario quiera instalar Avo, agregar un panel de administración a una aplicación Rails, montar el administrador en una ruta/alcance/ruta anidada/subdominio (por ejemplo, `/backoffice`, `admin.myapp.com`), elegir un nivel de Avo (`avo` / `avo-pro` / `avo-advanced` / `avo-everything`), arreglar un `403 Forbidden` extrayendo una gema de Avo privada o paga, no se puede empaquete la gema paga, configure el token del servidor de gemas en Heroku/Hatchbox/GitHub Actions/Docker/Kamal, implemente el administrador cuando la gema no se instale, agregue o conecte una clave de licencia, corrija un administrador que dice sin licencia o muestra una insignia de tiempo de espera de licencia, o agregue rutas personalizadas dentro del motor Avo.
