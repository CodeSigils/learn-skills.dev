Installieren Sie Avo, mounten Sie es in „config/routes.rb“, authentifizieren Sie den privaten Gem-Server und legen Sie den Lizenzschlüssel fest. Verwenden Sie diese Option, wenn der Benutzer Avo installieren, einer Rails-App ein Admin-Panel hinzufügen, den Admin in einem Pfad/Bereich/verschachtelten Pfad/einer Subdomain (z. B. „/backoffice“, „admin.myapp.com“) bereitstellen, eine Avo-Stufe auswählen möchte („avo“ / „avo-pro“ / „avo-advanced“ / „avo-everything“) und einen „403 Forbidden“ beheben möchte, indem er ein privates oder kostenpflichtiges Avo zieht gem, kann das kostenpflichtige Gem nicht bündeln, das Gem-Server-Token auf Heroku/Hatchbox/GitHub Actions/Docker/Kamal setzen, den Administrator bereitstellen, wenn das Gem nicht installiert werden kann, einen Lizenzschlüssel hinzufügen oder verknüpfen, einen Administrator reparieren, der „nicht lizenziert“ sagt oder ein Lizenz-Timeout-Abzeichen anzeigt, oder benutzerdefinierte Routen innerhalb der Avo-Engine anhängen.
