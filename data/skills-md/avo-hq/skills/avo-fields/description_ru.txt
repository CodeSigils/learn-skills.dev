Добавляйте или изменяйте поля в `def полях` ресурса Avo — выберите тип `as:`, установите параметры (обязательные, по умолчанию, справка, видимость, форматирование) и используйте вычисляемые и специфичные для просмотра поля. Используйте, когда пользователь хочет добавить поле к ресурсу Avo или — сказано без названия Avo — «добавить поле статуса в модель проекта», «сделать поле электронной почты обязательным», «показать аватар пользователя», «добавить раскрывающийся список для статуса заказа», «цена должна отображаться в виде валюты», «добавить редактор форматированного текста для тела», «скрыть поле примечаний на индексной странице», «добавить звездный рейтинг», «сделать столбец имени сортируемым», «показать значок для состояния заказа», или «добавить в модель палитру цветов/дату/индику выполнения». Для полей own_to / has_many / has_one и других ассоциаций используйте вместо этого навык avo-associations.
