Konfigurieren Sie die appweiten Admin-Einstellungen von Avo in config/initializers/avo.rb über Avo.configure – App-Name, Zeitzone/Währung, Verhalten pro Seite und Index, Layoutbreite, Home-Umleitung, Links zum Öffnen im Editor und die anderen globalen Regler, die nicht zu einer einzelnen Funktion gehören. Verwenden Sie diese Option, wenn der Benutzer ändern möchte, wie viele Datensätze pro Seite vorhanden sind, den Administrator umbenennen/den App-Namen ändern, die Zeitzone oder Währung für den Administrator festlegen, den Index standardmäßig auf die Rasteransicht festlegen, den Administrator auf volle Breite einstellen, beim Öffnen des Datensatzes weiter auf eine Zeile klicken, die Anzeigeansicht überspringen/direkt zum Bearbeiten wechseln, Avo-Dateien in Cursor oder VS Code über die Benutzeroberfläche öffnen, die Seitenleiste immer geöffnet lassen, die Administrator-Startseite auf ein Dashboard umleiten, dem Body-Tag eine Klasse hinzufügen, Zeilen dichter machen und bestehen bleiben Filter/Paginierung über Anfragen hinweg oder Deaktivierung von Nutzungsmetadaten.
