Avo.configure を介して config/initializers/avo.rb で Avo のアプリ全体の管理設定を構成します。これには、アプリ名、タイムゾーン/通貨、ページごとおよびインデックスの動作、レイアウト幅、ホーム リダイレクト、エディター内で開くリンク、および単一の機能に属さないその他のグローバル ノブが含まれます。ユーザーが、ページごとのレコード数の変更、管理者の名前変更/アプリ名の変更、管理者のタイムゾーンまたは通貨の設定、デフォルトのインデックスをグリッド ビューに設定、管理者を全幅にする、レコードを開かないように行をクリックし続ける、表示ビューをスキップする/直接編集に進む、UI からカーソルまたは VS Code で Avo ファイルを開く、サイドバーを常に開いたままにする、管理者をダッシュボードにリダイレクトする、ボディ タグにクラスを追加する、行を作成する場合に使用します。より高密度で、リクエスト間でフィルター/ページネーションを永続化するか、使用状況メタデータをオプトアウトします。
