Configurez les paramètres d'administration à l'échelle de l'application d'Avo dans config/initializers/avo.rb via Avo.configure : nom de l'application, fuseau horaire/devise, comportement par page et index, largeur de mise en page, redirection d'accueil, liens d'ouverture dans l'éditeur et les autres boutons globaux qui n'appartiennent pas à une seule fonctionnalité. À utiliser lorsque l'utilisateur souhaite modifier le nombre d'enregistrements par page, renommer l'administrateur/changer le nom de l'application, définir le fuseau horaire ou la devise de l'administrateur, par défaut l'index en vue grille, rendre l'administrateur pleine largeur, continuer à cliquer sur une ligne depuis l'ouverture de l'enregistrement, ignorer la vue Afficher/aller directement à la modification, ouvrir les fichiers Avo dans le curseur ou VS Code à partir de l'interface utilisateur, garder la barre latérale toujours ouverte, rediriger l'accueil de l'administrateur vers un tableau de bord, ajouter une classe à la balise body, rendre les lignes plus denses, conserver les filtres/pagination dans les requêtes ou désactiver les métadonnées d'utilisation.
