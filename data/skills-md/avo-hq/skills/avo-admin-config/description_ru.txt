Настройте параметры администратора для всего приложения Avo в config/initializers/avo.rb через Avo.configure — имя приложения, часовой пояс/валюту, поведение на странице и индексе, ширину макета, перенаправление на домашнюю страницу, ссылки открытия в редакторе и другие глобальные ручки, которые не принадлежат ни одной функции. Используйте, когда пользователь хочет изменить количество записей на странице, переименовать администратора/изменить имя приложения, установить часовой пояс или валюту для администратора, по умолчанию использовать индекс в виде сетки, сделать администратора полной ширины, продолжать нажимать строку, не открывая запись, пропустить представление показа/перейти сразу к редактированию, открыть файлы Avo в курсоре или VS Code из пользовательского интерфейса, всегда держать боковую панель открытой, перенаправить администратора домой на панель мониторинга, добавить класс в тег body, создать строки более плотные, сохраняйте фильтры/пагинацию во всех запросах или отказывайтесь от метаданных об использовании.
