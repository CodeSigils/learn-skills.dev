Avo.configure를 통해 config/initializers/avo.rb에서 Avo의 앱 전체 관리 설정(앱 이름, 시간대/통화, 페이지별 및 인덱스 동작, 레이아웃 너비, 홈 리디렉션, 편집기에서 열기 링크 및 단일 기능에 속하지 않는 기타 전역 손잡이)을 구성합니다. 사용자가 페이지당 레코드 수를 변경하고, 관리자 이름을 바꾸고, 앱 이름을 변경하고, 관리자의 시간대 또는 통화를 설정하고, 기본 인덱스를 그리드 보기로 설정하고, 관리자를 전체 너비로 설정하고, 레코드를 열지 않고 행을 계속 클릭하고, 보기 표시를 건너뛰고, 바로 편집으로 이동하고, UI에서 커서 또는 VS 코드로 Avo 파일을 열고, 사이드바를 항상 열어두고, 관리자 홈을 대시보드로 리디렉션하고, 본문 태그에 클래스를 추가하고, 행을 더 조밀하게 만들고, 유지하려고 할 때 사용합니다. 요청 전반에 걸쳐 필터/페이지 매김을 수행하거나 사용 메타데이터를 옵트아웃합니다.
