Configura le impostazioni di amministrazione dell'intera app di Avo in config/initializers/avo.rb tramite Avo.configure: nome dell'app, fuso orario/valuta, comportamento per pagina e indice, larghezza del layout, reindirizzamento home, collegamenti di apertura nell'editor e le altre manopole globali che non appartengono a una singola funzionalità. Da utilizzare quando l'utente desidera modificare il numero di record per pagina, rinominare l'amministratore/cambiare il nome dell'app, impostare il fuso orario o la valuta per l'amministratore, impostare l'indice sulla visualizzazione griglia, rendere l'amministratore a larghezza intera, continuare a fare clic su una riga dall'apertura del record, saltare la visualizzazione spettacolo/vai direttamente alla modifica, aprire file Avo in Cursore o VS Code dall'interfaccia utente, mantenere la barra laterale sempre aperta, reindirizzare la home dell'amministratore a un dashboard, aggiungere una classe al tag body, creare righe filtri/impaginazione più densi e persistenti tra le richieste o disattivazione dei metadati di utilizzo.
