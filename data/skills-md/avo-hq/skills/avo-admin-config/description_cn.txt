通过 Avo.configure 在 config/initializers/avo.rb 中配置 Avo 应用程序范围的管理设置 — 应用程序名称、时区/货币、每页和索引行为、布局宽度、主页重定向、在编辑器中打开链接以及不属于单个功能的其他全局旋钮。当用户想要更改每页记录数、重命名管理员/更改应用程序名称、设置管理员的时区或货币、默认索引为网格视图、使管理员全角、持续单击一行打开记录、跳过显示视图/直接进行编辑、从 UI 中在光标或 VS Code 中打开 Avo 文件、保持侧边栏始终打开、将管理员主页重定向到仪表板、向正文标记添加类、使行更密集、持久保留筛选器/分页时使用请求，或选择不使用元数据。
