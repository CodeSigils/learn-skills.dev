Добавьте и настройте фильтрацию в представлении индекса ресурса Avo — базовые фильтры (написанные разработчиком классы фильтров Ruby), динамические фильтры (создаваемые пользователем специальные фильтры с помощью фильтруемых полей и динамического_фильтра) и области действия (вкладки сегментов, запускаемые одним щелчком мыши, и представления по умолчанию). Используйте, когда пользователь хочет отфильтровать, сегментировать или установить представление по умолчанию для записей в индексе ресурса — например. «фильтровать проекты по статусу», «фильтровать пользователей по роли», «фильтровать по диапазону дат», «разрешить пользователям создавать свои собственные специальные фильтры», «фильтровать по ассоциации», «показывать только активные записи по умолчанию», «скрывать обратимое удаление по умолчанию», «добавить вкладку для администраторов/активных пользователей», «сегментировать заказы на платные/неоплачиваемые вкладки», «показывать счетчик рядом с каждой вкладкой» или «скрыть вкладку «Все». Охватывает генераторы avo:filter и avo:scope, фильтры def и области определения, ransackable_attributes и области по умолчанию.
