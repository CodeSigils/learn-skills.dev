Las tuberías del motor Rails que tocas cuando escribes Ruby personalizado que se ejecuta dentro de Avo: ayudantes de ruta del motor (`avo.` vs `main_app.`), `Avo::Current`, `Avo::ExecutionContext`, nombres de modelos reservados/conflictos de ruta, `Avo::Services::EncryptionService` y llamadas a los ayudantes de tu aplicación desde dentro de Avo. Úselo cuando el usuario quiera vincularse desde el administrador a su aplicación principal, corregir el `método indefinido 'posts_path'` (o una ruta que se resuelve en la página incorrecta) dentro de Avo, acceder al usuario/solicitud/parámetros/contexto/inquilino actual dentro de un bloque de Avo, saber qué variables (`record`, `resource`, `view`, `current_user`) están disponibles en una lambda o por qué `record` es nulo, usar uno de los ayudantes de vista de su aplicación dentro de un campo Avo, arreglar un modelo llamado `recurso` / `chart` / `búsqueda` / `home` / `attachment` que interrumpe el administrador o causa conflictos de enrutamiento, mantener un modelo de nombre reservado mientras se cambia el nombre de su recurso Avo (`--model-class`), arreglar un conflicto de ayuda de ruta `resources :resources`, o cifrar/descifrar un valor para pasar de forma segura a través de los parámetros de Avo. Establezca el inquilino para la solicitud de administrador actual.
