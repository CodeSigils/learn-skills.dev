Avo 内で実行されるカスタム Ruby を作成するときに触れる Rails エンジンの配管 — エンジン パス ヘルパー (`avo.` と `main_app.`)、`Avo::Current`、`Avo::ExecutionContext`、予約されたモデル名 / ルートの競合、`Avo::Services::EncryptionService`、および Avo 内部からのアプリのヘルパーの呼び出し。ユーザーが管理者からメインアプリにリンクしたい場合、Avo 内の「未定義メソッド 'posts_path'」 (または間違ったページに解決されるルート) を修正する、Avo ブロック内の現在のユーザー / リクエスト / パラメータ / コンテキスト / テナントにアクセスする、ラムダでどの変数 (`record`、`resource`、`view`、`current_user`) が使用できるのかを知りたい場合、または `record` が nil である理由を知りたい場合に使用します。 Avo フィールド内のアプリのビュー ヘルパー、管理を中断するかルーティングの競合を引き起こす `resource` / `chart` / `search` / `home` / `attachment` という名前のモデルを修正する、Avo リソース (`--model-class`) の名前を変更する際に予約名モデルを保持する、`resources :resources` ルート ヘルパーの衝突を修正する、または Avo パラメータを安全に渡すための値の暗号化/復号化を行います。現在の管理リクエストのテナントを設定します。
