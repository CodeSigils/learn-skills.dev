Avo 내에서 실행되는 사용자 정의 Ruby를 작성할 때 만지는 Rails 엔진 배관 — 엔진 경로 도우미(`avo.` 대 `main_app.`), `Avo::Current`, `Avo::ExecutionContext`, 예약된 모델 이름/경로 충돌, `Avo::Services::EncryptionService` 및 Avo 내부에서 앱 도우미 호출. 사용자가 관리자에서 기본 앱으로 다시 연결하려고 할 때 사용하고, Avo 내에서 `정의되지 않은 메소드 'posts_path'`(또는 잘못된 페이지로 확인되는 경로)를 수정하고, Avo 블록 내의 현재 사용자/요청/매개변수/컨텍스트/테넌트에 액세스하고, 람다에서 사용할 수 있는 변수(`record`, `resource`, `view`, `current_user`)를 확인하거나 `record`가 nil인 이유를 확인하고, 앱 내에서 앱의 보기 도우미 중 하나를 사용합니다. Avo 필드, 관리자를 방해하거나 라우팅 충돌을 일으키는 `resource` / `chart` / `search` / `home` / `attachment`라는 모델을 수정하고, Avo 리소스 이름을 바꾸면서 예약된 이름 모델을 유지하고(`--model-class`), `resources:resources` 경로 도우미 충돌을 수정하거나, Avo 매개변수를 통해 안전하게 전달하기 위해 값을 암호화/해독합니다. 현재 관리자 요청에 대한 테넌트를 설정합니다.
