Поддержите ресурс Avo с помощью внешнего API HTTP/REST вместо модели Active Record — просматривайте, показывайте, создавайте, обновляйте и удаляйте записи прямо через API, без таблицы базы данных, через self.http_adapter. Используйте, когда пользователь хочет создать панель администратора для внешнего/стороннего/SaaS REST API, показать записи, поступающие из API, а не из базы данных, CRUD удаленную службу через Avo без локальной таблицы, сопоставить пользовательский интерфейс сортировки/фильтрации Avo с параметрами запроса API, отправлять заголовки аутентификации при каждом запросе, анализировать завернутый ответ JSON (результаты/мета/данные), выявлять сбои API с помощью `Avo::HttpError`, настраивать создавайте, обновляйте и уничтожайте с помощью специального API, скрывайте идентификаторы записей в URL-адресах или точно отлаживайте то, что ресурс отправляет и получает через консоль отладки HTTP. Платное дополнение (`avo-http_resource`), открытая бета-версия.
