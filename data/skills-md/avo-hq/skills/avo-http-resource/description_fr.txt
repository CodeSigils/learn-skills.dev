Sauvegardez une ressource Avo avec une API HTTP/REST externe au lieu d'un modèle Active Record — répertoriez, affichez, créez, mettez à jour et supprimez des enregistrements directement via l'API sans table de base de données, via `self.http_adapter`. À utiliser lorsque l'utilisateur souhaite créer un panneau d'administration pour une API REST externe/tierce/SaaS, afficher les enregistrements provenant d'une API plutôt que de la base de données, CRUD un service distant via Avo sans table locale, mapper l'interface utilisateur de tri/filtrage d'Avo aux paramètres de requête de l'API, envoyer des en-têtes d'authentification à chaque demande, analyser une réponse JSON enveloppée (résultats/méta/données), faire apparaître les échecs de l'API avec `Avo::HttpError`, personnaliser créer/mettre à jour/détruire via une API sur mesure, masquer les identifiants d'enregistrement dans les URL ou déboguer exactement ce qu'une ressource envoie et reçoit via la console de débogage HTTP. Gemme complémentaire payante (`avo-http_resource`), bêta ouverte.
