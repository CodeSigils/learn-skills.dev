Active Record モデルの代わりに外部 HTTP/REST API を使用して Avo リソースをバックアップします。「self.http_adapter」を介して、データベース テーブルを使用せずに API を介してレコードを直接一覧表示、表示、作成、更新、削除します。ユーザーが外部/サードパーティ/SaaS REST API の管理パネルを構築する場合、データベースではなく API から取得したレコードを表示する場合、ローカル テーブルを使用せずに Avo を介してリモート サービスを CRUD する場合、Avo の並べ替え/フィルター UI を API クエリ パラメーターにマップする場合、すべてのリクエストで認証ヘッダーを送信する場合、ラップされた JSON 応答 (結果/メタ/データ) を解析する場合、API エラーを「Avo::HttpError」で表示する場合、カスタマイズする場合に使用します。カスタム API に対して作成/更新/破棄したり、URL 内のレコード ID を難読化したり、HTTP デバッグ コンソールを通じてリソースが送受信するものを正確にデバッグしたりできます。有料アドオン gem (`avo-http_resource`)、オープンベータ版。
