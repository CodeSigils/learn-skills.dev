Supporta una risorsa Avo con un'API HTTP/REST esterna anziché un modello Active Record: elenca, mostra, crea, aggiorna ed elimina i record direttamente tramite l'API senza tabella del database, tramite `self.http_adapter`. Da utilizzare quando l'utente desidera creare un pannello di amministrazione per un'API REST esterna/di terze parti/SaaS, mostrare record che provengono da un'API anziché dal database, CRUD un servizio remoto tramite Avo senza tabella locale, mappare l'interfaccia utente di ordinamento/filtro di Avo ai parametri di query dell'API, inviare intestazioni di autenticazione su ogni richiesta, analizzare una risposta JSON incapsulata (risultati/meta/dati), rilevare errori API con `Avo::HttpError`, personalizzare creare/aggiornare/distruggere rispetto a un'API personalizzata, offuscare gli ID dei record negli URL o eseguire il debug esattamente di ciò che una risorsa invia e riceve tramite la console di debug HTTP. Gemma aggiuntiva a pagamento (`avo-http_resource`), Open Beta.
