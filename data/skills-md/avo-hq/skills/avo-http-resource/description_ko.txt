Active Record 모델 대신 외부 HTTP/REST API를 사용하여 Avo 리소스를 지원합니다. `self.http_adapter`를 통해 데이터베이스 테이블 없이 API를 통해 직접 레코드를 나열, 표시, 생성, 업데이트 및 삭제합니다. 사용자가 외부/타사/SaaS REST API에 대한 관리 패널을 구축하고, 데이터베이스가 아닌 API에서 오는 레코드를 표시하고, 로컬 테이블 없이 Avo를 통해 원격 서비스를 CRUD하고, Avo의 정렬/필터 UI를 API 쿼리 매개변수에 매핑하고, 모든 요청에 대해 인증 헤더를 보내고, 래핑된 JSON 응답(결과/메타/데이터)을 구문 분석하고, `Avo::HttpError`를 사용하여 API 오류를 표시하고, 생성/업데이트/파괴를 사용자 정의하려는 경우에 사용합니다. 맞춤형 API를 사용하거나, URL의 레코드 ID를 난독화하거나, HTTP 디버그 콘솔을 통해 리소스가 보내고 받는 내용을 정확하게 디버깅할 수 있습니다. 유료 추가 기능 gem(`avo-http_resource`), 오픈 베타.
