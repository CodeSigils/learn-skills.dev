使用外部 HTTP/REST API（而不是 Active Record 模型）支持 Avo 资源 — 通过“self.http_adapter”直接通过 API 列出、显示、创建、更新和删除记录，无需数据库表。当用户想要为外部/第三方/SaaS REST API 构建管理面板时使用，显示来自 API 而不是数据库的记录，通过 Avo 在没有本地表的情况下 CRUD 远程服务，将 Avo 的排序/过滤 UI 映射到 API 查询参数，在每个请求上发送身份验证标头，解析包装的 JSON 响应（结果/元/数据），使用“Avo::HttpError”显示 API 失败，针对定制 API 自定义创建/更新/销毁，混淆 URL 中的记录 ID，或通过 HTTP 调试控制台准确调试资源发送和接收的内容。付费附加 gem (`avo-http_resource`)，开放测试版。
