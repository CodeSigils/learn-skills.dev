Respalde un recurso de Avo con una API HTTP/REST externa en lugar de un modelo de Registro activo: enumere, muestre, cree, actualice y elimine registros directamente a través de la API sin una tabla de base de datos, a través de `self.http_adapter`. Úselo cuando el usuario desee crear un panel de administración para una API REST externa/de terceros/SaaS, mostrar registros que provienen de una API en lugar de la base de datos, CRUD de un servicio remoto a través de Avo sin una tabla local, asignar la interfaz de usuario de clasificación/filtro de Avo a los parámetros de consulta de API, enviar encabezados de autenticación en cada solicitud, analizar una respuesta JSON empaquetada (resultados/meta/datos), mostrar fallas de API con `Avo::HttpError`, personalizar cree/actualice/destruya con una API personalizada, ofusque los identificadores de registros en las URL o depure exactamente lo que un recurso envía y recibe a través de la consola de depuración HTTP. Gema complementaria de pago (`avo-http_resource`), Beta abierta.
