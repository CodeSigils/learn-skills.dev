اكشف واجهة برمجة تطبيقات JSON REST على كل مورد Avo باستخدام الوظيفة الإضافية `avo-api` — القائمة/القراءة/الإنشاء/التحديث/الحذف بالإضافة إلى اجتياز اقتران القراءة فقط، وإعادة استخدام حقول كل مورد، ورؤية العرض، والترخيص، بدون وحدات تحكم لكل مورد. تتم إدارة الرموز المميزة لحاملها من واجهة مستخدم Avo (الإنشاء، والكشف مرة واحدة، والتعطيل، والإلغاء) ويتم بوابتها بواسطة مصفوفة إذن الاشتراك لكل رمز مميز؛ يغطي خطاف التعليمات البرمجية (`setup_authentication`) أنظمة HTTP الأساسية / مفتاح API / الأنظمة العامة. يُستخدم عندما يريد المستخدم الكشف عن واجهة برمجة تطبيقات JSON لتطبيق جوال، أو السماح لخدمة خارجية أو SPA بقراءة/كتابة السجلات عبر HTTP، أو إضافة واجهة برمجة تطبيقات REST دون كتابة وحدات تحكم، أو إصدار رموز API لطرف ثالث أو وصول من خادم إلى خادم، أو منح الواجهة الأمامية واجهة برمجة تطبيقات مدعومة من قبل المسؤول، أو شحن واجهة برمجة تطبيقات عامة للقراءة فقط لمورد ما، أو إنشاء خطاف ويب/تكامل يسحب السجلات - سواء قالوا ذلك بمصطلحات Avo (`mount_avo_api`، "avo-api"، أو "avo_api_tokens"، أو "setup_authentication"، أو منح الأذونات، أو الفلفل المميز) أو المصطلحات البسيطة ("الوصول البرمجي إلى النماذج الخاصة بي"، أو "الوصول من خادم إلى خادم إلى بيانات المسؤول"، أو "واجهة برمجة التطبيقات لتطبيق الهاتف المحمول").
