Предоставляйте JSON REST API для каждого ресурса Avo с помощью надстройки avo-api — список/чтение/создание/обновление/удаление, а также обход ассоциации только для чтения, повторное использование полей каждого ресурса, просмотр видимости и авторизация без использования контроллеров для каждого ресурса. Токены-носители управляются из пользовательского интерфейса Avo (создание, однократное раскрытие, отключение, отзыв) и контролируются с помощью матрицы разрешений для каждого токена; перехватчик кода (`setup_authentication`) охватывает базовые схемы HTTP/ключи API/публичные схемы. Используйте, когда пользователь хочет предоставить JSON API для мобильного приложения, разрешить внешнему сервису или SPA читать/записывать записи через HTTP, добавить REST API без записи контроллеров, выдать токены API для стороннего или межсерверного доступа, предоставить интерфейсу API, поддерживаемый администратором, отправить общедоступный API только для чтения для ресурса или создать веб-перехватчик/интеграцию, которая извлекает записи — независимо от того, говорят ли они об этом в терминах Avo (`mount_avo_api`, `avo-api`, `avo_api_tokens`, `setup_authentication`, разрешения, токен-перец) или простые термины («программный доступ к моим моделям», «межсерверный доступ к административным данным», «API для мобильного приложения»).
