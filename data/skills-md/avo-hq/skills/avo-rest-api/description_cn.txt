使用“avo-api”插件在每个 Avo 资源上公开 JSON REST API - 列表/读取/创建/更新/删除以及只读关联遍历，重用每个资源的字段、视图可见性和授权，无需每个资源控制器。不记名代币通过 Avo UI 进行管理（创建、显示一次、禁用、撤销），并通过选择加入、每个代币权限矩阵进行控制；代码挂钩（`setup_authentication`）涵盖 HTTP Basic / API-key / 公共方案。当用户想要为移动应用程序公开 JSON API、让外部服务或 SPA 通过 HTTP 读取/写入记录、添加 REST API 而不编写控制器、为第三方或服务器到服务器访问颁发 API 令牌、为前端提供由管理员支持的 API、为资源提供公共只读 API 或构建提取记录的 Webhook/集成时使用 - 无论他们用 Avo 术语（“mount_avo_api”、“avo-api”、 `avo_api_tokens`、`setup_authentication`、权限授予、令牌胡椒）或简单术语（“以编程方式访问我的模型”、“对管理数据的服务器到服务器访问”、“移动应用程序的 API”）。
