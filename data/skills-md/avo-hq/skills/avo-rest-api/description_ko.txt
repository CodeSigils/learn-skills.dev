'avo-api' 추가 기능(목록/읽기/생성/업데이트/삭제)과 읽기 전용 연결 순회를 통해 모든 Avo 리소스에 JSON REST API를 노출하고, 리소스별 컨트롤러 없이 각 리소스의 필드, 보기 가시성 및 권한 부여를 재사용합니다. Bearer 토큰은 Avo UI(생성, 한 번 공개, 비활성화, 취소)에서 관리되며 옵트인, 토큰별 권한 매트릭스에 의해 관리됩니다. 코드 후크(`setup_authentication`)는 HTTP 기본/API 키/공개 체계를 다룹니다. 사용자가 모바일 앱용 JSON API를 노출하고, 외부 서비스 또는 SPA가 HTTP를 통해 레코드를 읽고 쓰도록 하고, 컨트롤러를 작성하지 않고 REST API를 추가하고, 제3자 또는 서버 간 액세스를 위한 API 토큰을 발행하고, 프런트엔드에 관리자가 지원하는 API를 제공하고, 리소스에 대한 공개 읽기 전용 API를 제공하거나, Avo 용어(`mount_avo_api`, `avo-api`, `avo_api_tokens`, `setup_authentication`, 권한 부여, 토큰 페퍼) 또는 일반 용어("내 모델에 대한 프로그래밍 방식 액세스", "관리 데이터에 대한 서버 간 액세스", "모바일 앱용 API").
