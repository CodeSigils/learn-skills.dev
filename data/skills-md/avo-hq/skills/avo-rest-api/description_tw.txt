使用「avo-api」外掛程式在每個 Avo 資源上公開 JSON REST API - 清單/讀取/建立/更新/刪除以及唯讀關聯遍歷，重複使用每個資源的欄位、視圖可見度和授權，無需每個資源控制器。不記名代幣透過 Avo UI 進行管理（建立、顯示一次、停用、撤銷），並透過選擇加入、每個代幣權限矩陣進行控制；程式碼掛鉤（`setup_authentication`）涵蓋 HTTP Basic / API-key / 公共方案。當使用者想要為行動應用程式公開 JSON API、讓外部服務或 SPA 透過 HTTP 讀取/寫入記錄、新增 REST API 而不編寫控制器、為第三方或伺服器到伺服器存取頒發 API 令牌、為前端提供由管理員支援的 API、為資源提供公共唯讀 API 或建置提取記錄的 Webhook/整合時使用 - 無論他們用 Avo 術語（“mount_avo API 或構建提取記錄的 Webhook/集成時使用 - 無論他們用 Avo 術語” `avo_api_tokens`、`setup_authentication`、權限授予、令牌胡椒）或簡單術語（「以程式設計方式存取我的模型」、「對管理資料的伺服器到伺服器存取」、「行動應用程式的 API」）。
