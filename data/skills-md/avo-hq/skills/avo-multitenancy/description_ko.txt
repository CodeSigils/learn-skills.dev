테넌트(계정, 팀 또는 조직)별로 Avo 관리자의 범위를 지정하면 각 고객이 자신의 데이터만 볼 수 있습니다. 경로 기반 테넌시(/:tenant_id + config.default_url_options + a set_tenant before_action 아래에 Avo 마운트) 및 계정 전환기를 사용한 세션 기반 테넌시를 포함하며, 모두 사용자가 직접 입력하는 Avo::Current.tenant/tenant_id 속성을 기반으로 구축됩니다. 사용자가 계정/팀/조직별로 관리자 범위를 지정하고, 각 고객이 관리자에서 자신의 데이터만 볼 수 있도록 하고, 테넌트 범위 지정을 추가하고, 다중 테넌트 관리자를 구축하고, 계정/테넌트 전환기를 추가하고, /:account_id 아래에 관리자를 마운트하거나, "관리자는 현재 계정을 기반으로 데이터를 전환해야 합니다" 또는 "각 클라이언트는 자신의 계정만 보아야 합니다"와 같이 Avo에 대한 언급이 없는 Rails 모양의 요청을 포함하여 현재 계정을 기반으로 관리자 전환 데이터를 보유하려는 경우에 사용합니다. 기록."
