Generieren Sie eine Avo CRUD-Ressource aus einem Rails-Modell und konfigurieren Sie das Verhalten auf Ressourcenebene in „app/avo/resources/<name>.rb“ und seinem Controller. Verwenden Sie diese Option, wenn der Benutzer eine Avo-Ressource generieren, ein Modell zum Admin-Panel hinzufügen, eine Tabelle im Admin verfügbar machen, Titel/Beschreibung/Symbol/Cover/Avatar oder diskrete Informationen einer Ressource festlegen, ActionDispatch::MissingController reparieren, N+1 mit Includes vermeiden, Sortier-/Paginierungs-/Indexabfragen optimieren, eine Array-Ressource (nicht DB) erstellen oder mehrere Ressourcen einem Modell zuordnen möchte.
