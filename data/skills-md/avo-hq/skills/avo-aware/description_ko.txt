Rails 모델을 변경하거나, 마이그레이션하거나, 기능을 추가할 때 Avo 관리 패널을 동기화 상태로 유지하세요. 요청에 Avo가 언급되지 않은 경우에도 마찬가지입니다. Gemfile에 `avo` gem이 있고 `app/avo/` 디렉토리가 있는 앱에서만 사용자가 모델 열 추가 또는 변경, 모델 추가, 열거형/상태 추가, 연결 생성, "관리자가 주문 승인하도록 허용" 또는 "사용자가 프로젝트 보관 가능"과 같은 기능 추가를 요청할 때 관리 화면도 업데이트해야 하는 모든 항목을 사용합니다. Rails가 먼저 변경된 다음 일치하는 Avo 변경을 제안하고 이를 올바른 수직 기술로 라우팅합니다.
