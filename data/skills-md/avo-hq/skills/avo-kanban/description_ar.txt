قم بتثبيت وتكوين Avo Kanban - لوحات السحب والإفلات متعددة الموارد والمدعومة بقاعدة البيانات في مسؤول Avo حيث يؤدي نقل البطاقة بين الأعمدة إلى كتابة قيمة على خاصية السجل الأساسي. يُستخدم عندما يريد المستخدم لوحة على نمط Trello / GitHub-Projects، لتنظيم السجلات في أعمدة حسب الحالة أو المرحلة، أو خط أنابيب أو لوحة سير عمل (تراكم ← قيد التقدم ← تم)، أو مسار مبيعات / لوحة مسرحية، لسحب السجلات بين المراحل، أو لتتبع التذاكر / المهام / المشكلات على اللوحة - وعندما يريدون إضافة لوحات أو أعمدة أو عناصر؛ جعل المورد قابلاً للإضافة إلى اللوحة؛ تصميم بحث منتقي اللوحة؛ إضافة خصائص الحالة الافتراضية؛ تخصيص بطاقة كانبان؛ أو قم بإعداد تخويل كانبان. الوظيفة الإضافية المدفوعة، بيتا.
