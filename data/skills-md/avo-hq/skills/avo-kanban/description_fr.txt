Installez et configurez Avo Kanban — des tableaux glisser-déposer multi-ressources basés sur une base de données dans l'administrateur Avo où le déplacement d'une carte entre les colonnes écrit une valeur sur une propriété de l'enregistrement sous-jacent. À utiliser lorsque l'utilisateur souhaite un tableau de style Trello / GitHub-Projects, pour organiser les enregistrements en colonnes par statut ou étape, un tableau de pipeline ou de flux de travail (backlog → en cours → terminé), un tableau de pipeline/étape de ventes, pour faire glisser des enregistrements entre les étapes, ou pour suivre les tickets/tâches/problèmes sur un tableau — et lorsqu'il souhaite ajouter des tableaux, des colonnes ou des éléments ; rendre une ressource ajoutable à un tableau ; adapter la recherche du sélecteur de tableaux ; ajouter des propriétés de statut virtuel ; personnaliser la carte Kanban ; ou configurer l'autorisation Kanban. Module complémentaire payant, bêta.
