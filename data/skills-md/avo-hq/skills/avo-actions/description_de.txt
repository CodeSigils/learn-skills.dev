Erstellen Sie Avo-Aktionen – Ruby-Klassen in „app/avo/actions/*.rb“, registriert in den „def actions“ einer Ressource – die einen benutzerdefinierten Vorgang für ausgewählte Datensätze, einen einzelnen Datensatz oder überhaupt nichts ausführen, mit optionalen Formularfeldern, einem Bestätigungsmodal, Feedback-Benachrichtigungen, benutzerdefinierten Antworten und mehrstufigen Abläufen. Verwenden Sie diese Option, wenn der Benutzer zulassen möchte, dass Administratoren diese Bestellungen in großen Mengen genehmigen, ausgewählte Rechnungen als bezahlt markieren, eine Schaltfläche zum Exportieren ausgewählter Benutzer in CSV hinzufügen, einen Benutzer aus dem Administrator deaktivieren/verbieten, eine Willkommens-E-Mail an ausgewählte Datensätze senden, einen Hintergrundjob für diese Datensätze auslösen, eine Schaltfläche „Veröffentlichen/Genehmigen“ auf der Beitragsseite hinzufügen, eine Schaltfläche für einen monatlichen Bericht hinzufügen, einen Grund erfassen, wenn jemand etwas tut, einen Bestätigungsdialog vor einem Vorgang hinzufügen oder ein mehrstufiges Formular/Assistenten im Administrator erstellen möchten.
