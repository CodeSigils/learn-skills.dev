Contrôlez le rendu des enregistrements sur l'écran Index d'une ressource Avo : style de tableau, cartes quadrillées, marqueurs de carte et types d'affichage disponibles. À utiliser lorsque l'utilisateur souhaite modifier l'apparence ou le comportement d'une liste d'enregistrements dans l'index. Phrases Avo ("activer la vue en grille", "définir le type de vue par défaut", "configurer les options de ligne", "ajouter une vue cartographique", "restreindre les types de vue") et celles en forme de Rails sans nommer Avo ("afficher ces produits sous forme de cartes d'image", "mettre les magasins sur une carte", "surligner les commandes échouées en rouge", "griser les lignes archivées", "permettre aux utilisateurs de basculer entre la liste et la grille", "faire de la grille la valeur par défaut", "ajouter un attribut de données / un contrôleur de stimulation à chaque ligne", "déplacer les boutons d'action de ligne vers la gauche", "exécuter une action sur tous les enregistrements correspondants, pas seulement sur cette page"). Pas pour créer de tout nouveaux types de vues personnalisées (c'est le travail des plugins - voir avo-custom-ui).
