Reconocimiento de imágenes para agentes sin soporte de visión nativo. Úselo cuando el usuario comparte una ruta de imagen o URL, el mensaje contiene archivos adjuntos de imágenes guardadas o el usuario solicita analizar, describir o identificar el contenido de la imagen. Envía imágenes locales o URL remotas a un modelo de visión compatible con OpenAI; --coords devuelve coordenadas de elementos de píxeles para la inspección de depuración/UI.
