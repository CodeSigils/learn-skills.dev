Minecraft 3D モデルの作成 (Java/Bedrock) — 画像モデルを使用してバニラの Minecraft デザインと 3 ビューのリファレンスを生成し、Blockbench MCP サーバーを介して Blockbench でモデルを直接構築、テクスチャー、アニメーション化します。ユーザーが 做一个 Minecraft モデル / 生成一格 XXX / 把设计图または三視图建成 Blockbench モデル / 给模组または资源包追加モデル、または Blockbench で 3D モデルを作成または編集する必要があるリクエストを要求する場合に使用します。 Blockbench MCP がインストールされ実行されていることを前提としています。 MCP ツールが利用できない場合は、最初に Blockbench MCP をインストールして起動するようにユーザーに通知します。
