Flujo de trabajo de desarrollo de mods Java de Minecraft de carga cruzada: audite el contexto del proyecto, extraiga implementaciones básicas, siga la lista de verificación de implementación estándar y depure/repare defectos. Úselo antes o durante cualquier función de modificación de Minecraft (Fabric, NeoForge o Forge); se combina con la habilidad `fabric` para las API del cargador y la habilidad `geckolib` para las API de animación.
