Flusso di lavoro di sviluppo mod Java Cross-loader per Minecraft: controlla il contesto del progetto, estrai le implementazioni Vanilla, segui l'elenco di controllo dell'implementazione standard ed esegui il debug/correggi i difetti. Utilizzare prima o durante qualsiasi lavoro relativo alla funzionalità mod di Minecraft (Fabric, NeoForge o Forge); si abbina alla competenza `fabric` per le API di caricamento e alla competenza `geckolib` per le API di animazione.
