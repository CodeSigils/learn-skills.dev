Workflow de développement de mod Java Cross-loader Minecraft : auditez le contexte du projet, exploitez les implémentations Vanilla, suivez la liste de contrôle d'implémentation standard et déboguez/corrigez les défauts. À utiliser avant ou pendant tout travail sur les fonctionnalités du mod Minecraft (Fabric, NeoForge ou Forge) ; s'associe à la compétence « fabric » pour les API de chargement et à la compétence « geckolib » pour les API d'animation.
