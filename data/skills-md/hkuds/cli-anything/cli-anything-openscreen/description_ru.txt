Интерфейс командной строки для Openscreen — редактора записи экрана. Интерфейс командной строки с сохранением состояния для редактирования записей экрана с масштабированием, изменением скорости, обрезкой, кадрированием, аннотациями и улучшенным экспортом. Создан на основе формата проекта Openscreen JSON с ffmpeg в качестве механизма рендеринга. Предназначен для агентов искусственного интеллекта и опытных пользователей, которым требуется программное редактирование видео.
