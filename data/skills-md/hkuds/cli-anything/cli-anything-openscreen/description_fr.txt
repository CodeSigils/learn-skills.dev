Interface de ligne de commande pour Openscreen — un éditeur d'enregistrement d'écran. Une CLI avec état pour éditer des enregistrements d'écran avec zoom, rampes de vitesse, découpage, recadrage, annotations et exportations soignées. Construit sur le format de projet Openscreen JSON avec ffmpeg comme backend de rendu. Conçu pour les agents IA et les utilisateurs expérimentés qui ont besoin d'un montage vidéo programmatique.
