Interfaz de línea de comandos para Openscreen: un editor de grabaciones de pantalla. Una CLI con estado para editar grabaciones de pantalla con zoom, rampas de velocidad, recortar, recortar, anotaciones y exportaciones pulidas. Construido sobre el formato de proyecto Openscreen JSON con ffmpeg como backend de renderizado. Diseñado para agentes de IA y usuarios avanzados que necesitan edición de video programática.
