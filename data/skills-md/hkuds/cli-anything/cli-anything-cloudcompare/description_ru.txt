Интерфейс командной строки для CloudCompare — удобный для агентов инструментарий для CloudCompare, программного обеспечения для обработки 3D-облаков точек и сеток с открытым исходным кодом. Поддерживает 41 команду в 9 группах: управление проектами, управление сеансами, операции с облаками точек (подвыборка, фильтр, сегмент, анализ), операции с сеткой, вычисление расстояний (C2C, C2M), преобразования (ICP, матрица), экспорт (LAS/LAZ/PLY/PCD/OBJ/STL/E57) и интерактивный REPL.
