Interface de ligne de commande pour ComfyUI - Gestion du flux de travail de génération d'images IA via l'API REST ComfyUI. Conçu pour les agents IA et les utilisateurs expérimentés qui ont besoin de mettre en file d'attente des flux de travail, de gérer des modèles, de télécharger des images générées et de surveiller la file d'attente de génération sans interface graphique.
