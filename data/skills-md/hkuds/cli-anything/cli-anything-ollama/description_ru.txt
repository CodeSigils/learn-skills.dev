Интерфейс командной строки для Ollama — локальный вывод LLM и управление моделями через Ollama REST API. Предназначен для агентов искусственного интеллекта и опытных пользователей, которым необходимо управлять моделями, генерировать текст, общаться в чате и создавать встроенные элементы без графического пользовательского интерфейса.
