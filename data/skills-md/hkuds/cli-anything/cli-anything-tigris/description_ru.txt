Интерфейс командной строки для хранилища объектов Tigris — представляет собой оболочку официального CLI `tigris` для предоставления агентам ИИ сегментов, объектов, заранее заданных URL-адресов, моментальных снимков, IAM и ключей доступа с ограниченной областью действия. Распространяется по всему миру, совместим с S3, плата за исходящий трафик отсутствует.
