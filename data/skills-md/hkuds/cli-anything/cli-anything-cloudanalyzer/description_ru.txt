Интерфейс командной строки для CloudAnalyzer — удобный для агентов инструмент для CloudAnalyzer, платформы контроля качества для отображения, локализации и восприятия выходных данных. Поддерживает 27 команд в 8 группах: оценка облака точек, оценка траектории, контроль качества наземной сегментации, контроль качества на основе конфигурации, эволюция базовой линии, обработка, визуализация и интерактивный REPL.
