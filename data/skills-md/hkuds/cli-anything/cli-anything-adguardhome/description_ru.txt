Интерфейс командной строки для AdGuard Home — блокировка рекламы по всей сети и управление DNS через AdGuard Home REST API. Предназначен для агентов искусственного интеллекта и опытных пользователей, которым необходимо управлять фильтрацией, перезаписью DNS, клиентами, DHCP и журналами запросов без графического пользовательского интерфейса.
