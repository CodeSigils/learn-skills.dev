Verwenden Sie diese Option, wenn der Agent GUI-Makros über die OpenClaw Macro System-CLI definieren, auflisten, prüfen oder ausführen möchte. Makros sind parametrisierte, über die CLI aufrufbare Workflows – der Agent ruft „Makroausführung <Name>“ auf und das System übernimmt das Backend-Routing (Plugin, Dateitransformation, Barrierefreiheit, kompilierte GUI-Wiedergabe).
