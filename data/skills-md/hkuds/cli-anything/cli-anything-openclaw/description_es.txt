Úselo cuando el agente quiera definir, enumerar, inspeccionar o ejecutar macros GUI a través de la CLI del sistema de macros OpenClaw. Las macros son flujos de trabajo parametrizados y ejecutables mediante CLI: el agente invoca `macro run <nombre>` y el sistema maneja el enrutamiento backend (complemento, transformación de archivos, accesibilidad, reproducción de GUI compilada).
