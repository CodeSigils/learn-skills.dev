À utiliser lorsque l'agent souhaite définir, répertorier, inspecter ou exécuter des macros GUI via la CLI OpenClaw Macro System. Les macros sont des workflows paramétrés et appelables par la CLI — l'agent invoque « macro run <name> » et le système gère le routage backend (plug-in, transformation de fichier, accessibilité, relecture de l'interface graphique compilée).
