Da utilizzare quando l'agente desidera definire, elencare, ispezionare o eseguire macro GUI tramite la CLI MacroCLI. Le macro sono flussi di lavoro parametrizzati e richiamabili dalla CLI: l'agente richiama `macro run <name>` e il sistema gestisce il routing del backend (plugin, trasformazione dei file, accessibilità, riproduzione della GUI compilata).
