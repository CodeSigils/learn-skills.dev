واجهة سطر الأوامر لـ Pioneer Rekordbox 6/7 - مكتبة DJ والتحكم المباشر عبر وصول SQLCipher master.db المحمي (pyrekordbox) + رسم خرائط MIDI الافتراضي. يوفر فحص المكتبة، وإنشاء قائمة التشغيل/الإضافة/المسح، والمزج المباشر (التشغيل/المزامنة/التلاشي المتداخل/معادل الصوت). لا تشحن بايونير REST API للتشغيل؛ يجمع هذا الحزام بين السطحين الحقيقيين الوحيدين (DB + MIDI المشفرين) في واجهة سطر الأوامر (CLI) الأصلية للوكيل.
