Interfaz de línea de comandos para Pioneer Rekordbox 6/7: biblioteca de DJ y control de deck en vivo mediante acceso protegido SQLCipher master.db (pyrekordbox) + mapeo MIDI virtual. Proporciona inspección de biblioteca, creación/agregación/borrado de listas de reproducción y mezcla en vivo (reproducción/sincronización/fundido cruzado/EQ). Pioneer no incluye API REST de reproducción; Este arnés combina las dos únicas superficies reales (DB cifrada + MIDI) en una CLI nativa del agente.
