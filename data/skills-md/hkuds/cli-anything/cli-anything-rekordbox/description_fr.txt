Interface de ligne de commande pour Pioneer Rekordbox 6/7 - Bibliothèque DJ et contrôle live-deck via un accès protégé SQLCipher master.db (pyrekordbox) + mappage MIDI virtuel. Fournit une inspection de la bibliothèque, la création/ajout/suppression de listes de lecture et le mixage live-deck (lecture/synchronisation/fondu enchaîné/EQ). Pioneer ne fournit aucune API REST de lecture ; ce harnais combine les deux seules surfaces réelles (DB + MIDI cryptées) en une seule CLI native d'agent.
