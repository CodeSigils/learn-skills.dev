Interfaccia della riga di comando per Pioneer Rekordbox 6/7: libreria DJ e controllo del deck live tramite accesso protetto SQLCipher master.db (pyrekordbox) + mappatura MIDI virtuale. Fornisce l'ispezione della libreria, la creazione/aggiunta/cancellazione di playlist e il missaggio del deck live (riproduzione/sincronizzazione/dissolvenza incrociata/EQ). Pioneer non fornisce alcuna API REST di riproduzione; questo cablaggio combina le uniche due superfici reali (DB crittografato + MIDI) in un'unica CLI nativa dell'agente.
