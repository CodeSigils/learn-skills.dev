Интерфейс командной строки для Pioneer Rekordbox 6/7 — DJ-библиотека и управление живой декой через защищенный доступ SQLCipher master.db (pyrekordbox) + виртуальное сопоставление MIDI. Обеспечивает проверку библиотеки, создание/добавление/очистку списка воспроизведения и микширование живой деки (воспроизведение/синхронизация/кроссфейд/эквалайзер). Pioneer не поставляет REST API без воспроизведения; этот инструмент объединяет две реальные поверхности (зашифрованная база данных + MIDI) в один собственный интерфейс командной строки агента.
