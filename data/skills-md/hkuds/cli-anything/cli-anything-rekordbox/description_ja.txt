Pioneer Rekordbox 6/7 用のコマンドライン インターフェイス - 保護された SQLCipher master.db アクセス (pyrekordbox) + 仮想 MIDI マッピングを介した DJ ライブラリとライブデッキのコントロール。ライブラリの検査、プレイリストの作成/追加/クリア、およびライブデッキのミキシング (再生/同期/クロスフェード/EQ) を提供します。パイオニアは再生 REST API を出荷していません。このハーネスは、2 つのみの実際のサーフェス (暗号化された DB + MIDI) を 1 つのエージェント ネイティブ CLI に結合します。
