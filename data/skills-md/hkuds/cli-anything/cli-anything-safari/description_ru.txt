CLI автоматизации браузера Safari на macOS через Safari-mcp. Управляет реальным Safari (родным, сохраняет логины), оборачивая MCP-сервер safari-mcp. Каждый из 84 инструментов MCP предоставляется в соотношении 1:1 с аргументами, точными по схеме — гарантированная четность, отсутствие ручного смещения.
