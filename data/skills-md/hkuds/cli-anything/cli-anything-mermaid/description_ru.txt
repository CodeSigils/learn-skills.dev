Интерфейс командной строки для Mermaid Live Editor. Создавайте, редактируйте и визуализируйте диаграммы Mermaid с помощью файлов проекта с отслеживанием состояния и URL-адресов средства визуализации mermaid.ink. Предназначен для агентов ИИ и опытных пользователей, которым необходимо создавать блок-схемы, диаграммы последовательности и другие визуализации без графического пользовательского интерфейса.
