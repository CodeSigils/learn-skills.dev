이 기술은 사용자가 "팀 만들기", "에이전트 생성", "작업 할당", "여러 에이전트 조정", "팀 상태 확인", "칸반 보드 보기", "에이전트 간 메시지 보내기", "팀 작업 관리", "팀 진행 상황 모니터링"을 요청하거나 "clawteam", "다중 에이전트 조정", "팀 협업", "에이전트 받은 편지함", "작업 보드", "작업자 생성"을 언급할 때 사용해야 합니다. 이 기술은 현재 작업이 하위 작업으로 분할하고 여러 에이전트에 위임함으로써 이점을 얻을 만큼 복잡할 때에도 트리거되어야 합니다. 예를 들어 사용자가 "전체 스택 앱 구축", "전체 코드베이스 리팩터링", "여러 기능을 병렬로 구현"을 요청하거나 에이전트가 작업 범위가 단일 에이전트가 단독으로 효율적으로 처리할 수 있는 범위를 초과한다고 판단하는 경우입니다. ClawTeam CLI를 사용하여 작업 관리, 메시징, 모니터링, 런타임 프로필, Git 컨텍스트 및 복구 도구를 통해 다중 에이전트 팀을 조율하기 위한 포괄적인 지침을 제공합니다.
