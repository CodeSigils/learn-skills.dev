Esta habilidad debe usarse cuando el usuario solicita "crear un equipo", "generar agentes", "asignar tareas", "coordinar múltiples agentes", "verificar el estado del equipo", "ver tablero kanban", "enviar mensajes entre agentes", "administrar tareas del equipo", "supervisar el progreso del equipo" o menciona "clawteam", "coordinación de múltiples agentes", "colaboración en equipo", "bandeja de entrada del agente", "tablero de tareas", "generar trabajador". Esta habilidad también debe activarse cuando la tarea actual es lo suficientemente compleja como para beneficiarse de dividirla en subtareas y delegarla a múltiples agentes; por ejemplo, cuando el usuario solicita "crear una aplicación completa", "refactorizar todo el código base", "implementar múltiples funciones en paralelo" o cuando el agente determina que el alcance del trabajo excede lo que un solo agente puede manejar de manera eficiente por sí solo. Proporciona una guía completa para usar la CLI de ClawTeam para organizar equipos de múltiples agentes con administración de tareas, mensajería, monitoreo, perfiles de tiempo de ejecución, contexto de Git y herramientas de recuperación.
