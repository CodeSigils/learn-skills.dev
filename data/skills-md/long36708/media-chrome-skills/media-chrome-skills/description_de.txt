Leitfaden und Best Practices zur Medien-Chrome-Komponentenbibliothek. Zum Entwickeln von Video-/Audio-Playern, zum Integrieren von Mediensteuerelementen und zum Anpassen von Player-Themen.  
Nutzen Sie diese Fähigkeit, wenn Sie einen Mediaplayer erstellen, konfigurieren oder anpassen müssen. Enthält einen Schnellstart, Komponentendetails, Stilanpassung, Unterstützung für Medien aus mehreren Quellen, Best Practices, einen Leitfaden zu Fallstricken und erweiterte Funktionen.
