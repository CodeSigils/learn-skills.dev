Obtient de manière itérative les vérifications vertes d’une demande d’extraction GitHub. Détecte le PR pour la branche actuelle ou utilise un numéro PR fourni, attend que chaque vérification sur le dernier SHA principal apparaisse et se termine, enquête sur les vérifications ayant échoué, corrige les problèmes de code ou de test exploitables, pousse et répète. S'intensifie avec un bloqueur précis lorsque les pannes sont externes, irrégulières ou ne peuvent pas être réparées en toute sécurité. À utiliser lorsqu'un PR a toujours des vérifications infructueuses après des correctifs de révision, y compris après greploop.
