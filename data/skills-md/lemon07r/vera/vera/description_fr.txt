Recherche de code sémantique, recherche de modèles d'expression régulière et recherche de symboles dans un référentiel local. Renvoie les blocs de code de démarque classés avec le chemin du fichier, la plage de lignes, le contenu et les informations facultatives sur les symboles. Utilisez « vera search » pour les requêtes conceptuelles/comportementales (comment fonctionne une fonctionnalité, où se trouve la logique, exploration de code inconnu). Utilisez `vera grep` pour les chaînes exactes, les modèles d'expressions régulières, les importations et les TODO. Utilisez les « références vera » pour tracer les appelants/appelés. Utilisez rg uniquement pour la recherche et le remplacement en masse ou pour les fichiers en dehors de l'index.
