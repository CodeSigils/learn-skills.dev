Sorgt dafür, dass ein Agent echte Ergebnisse erstellt und validiert, anstatt seine eigene Buchhaltung zu verwalten. Verwendung für mehrstufige Pipelines, Funktions-Roadmaps, Implementierungsschleifen mit langer Laufzeit, Migrationen, bereitgestellte Daten oder Build-Läufe sowie für alle Läufe, bei denen administrative Hashes, Sperren, Belege, Dashboards, Zertifizierungsmarkierungen oder Fortschrittsmetadaten die korrekte Arbeit blockieren können. Verwenden Sie diese Option, wenn ein Agent den Fortschritt verweigert, abgeschlossene Phasen zurückspult oder unveränderte Arbeit erneut ausführt, weil eine Markierung fehlt oder veraltet ist.
