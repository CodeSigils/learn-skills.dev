Génère une description PR en lisant docs/pull_request_template.md et en la remplissant avec des puces dérivées du git diff, du journal de validation et des fichiers modifiés sur la branche actuelle. Utilisez TOUJOURS cette compétence chaque fois que l'utilisateur demande de créer un PR, de pousser un PR, d'ouvrir une pull request ou de créer un PR - sous quelque forme que ce soit. Cette compétence DOIT s'exécuter avant que « gh pr create » ne soit appelé, à chaque fois.
