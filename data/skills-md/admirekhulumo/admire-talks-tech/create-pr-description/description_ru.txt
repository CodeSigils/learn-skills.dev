Создает описание PR, читая docs/pull_request_template.md и заполняя его маркированными точками, полученными из различий git, журнала коммитов и измененных файлов в текущей ветке. ВСЕГДА используйте этот навык всякий раз, когда пользователь просит создать PR, отправить PR, открыть запрос на включение или сделать PR — в любой форме. Этот навык ДОЛЖЕН выполняться перед вызовом `gh pr create` каждый раз.
