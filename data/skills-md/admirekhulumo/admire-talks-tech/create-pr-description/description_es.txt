Genera una descripción de PR leyendo docs/pull_request_template.md y completándolo con viñetas derivadas de git diff, registro de confirmación y archivos modificados en la rama actual. Utilice SIEMPRE esta habilidad cada vez que el usuario solicite crear un PR, enviar un PR, abrir una solicitud de extracción o realizar un PR, en cualquier forma. Esta habilidad DEBE ejecutarse antes de que se llame a `gh pr create`, cada vez.
