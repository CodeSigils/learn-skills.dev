Erstellt eine PR-Beschreibung, indem docs/pull_request_template.md gelesen und mit Aufzählungspunkten gefüllt wird, die aus dem Git-Diff, dem Commit-Protokoll und den geänderten Dateien im aktuellen Zweig abgeleitet wurden. Verwenden Sie diese Fähigkeit IMMER immer dann, wenn der Benutzer eine PR erstellen, eine PR pushen, eine Pull-Anfrage öffnen oder eine PR erstellen möchte – in welcher Form auch immer. Dieser Skill MUSS jedes Mal ausgeführt werden, bevor „gh pr create“ aufgerufen wird.
