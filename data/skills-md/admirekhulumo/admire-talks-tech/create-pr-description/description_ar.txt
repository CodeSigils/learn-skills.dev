ينشئ وصفًا للعلاقات العامة من خلال قراءة docs/pull_request_template.md وتعبئته بالنقاط النقطية المشتقة من git diff وسجل الالتزام والملفات التي تم تغييرها في الفرع الحالي. استخدم هذه المهارة دائمًا عندما يطلب المستخدم إنشاء PR، أو دفع PR، أو فتح طلب سحب، أو تقديم PR - بأي شكل من الأشكال. يجب تشغيل هذه المهارة قبل استدعاء `gh pr create` في كل مرة.
