Scaffold Next.js + Tailwind + Shadcn + Stream React SDK de bout en bout avec les étapes 0 à 7. Ajoutez Chat/Vidéo/Flux/Modération à un projet React existant (améliorer). Auditez une intégration Stream Video existante par rapport aux meilleures pratiques. Migrez/mettez à niveau une version du SDK (par exemple v13 -> v14).
