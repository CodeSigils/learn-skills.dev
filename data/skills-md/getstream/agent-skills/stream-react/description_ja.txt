すべての Web React 作業のデフォルトであるストリーム (チャット、ビデオ、フィード、モデレーション) を使用して、React / Next.js Web アプリを構築、強化、監査、または移行します。 Scaffold Next.js + Tailwind + Shadcn + Stream React SDK をステップ 0 ～ 7 でエンドツーエンドで実行します。既存の React プロジェクトにチャット/ビデオ/フィード/モデレーションを追加します (拡張)。既存の Stream Video 統合をベスト プラクティスに照らして監査します。 SDK バージョンを移行/アップグレードします (例: v13 -> v14)。 「... アプリを構築する」、「足場」、「新しい ... を作成する」、「このアプリにチャットを追加する」、「ビデオを統合する」、「フィードを ... にドロップする」、「アップグレード」/「移行」/「... バージョンをバンプ」、および React / Next.js トークン: stream-chat-react、@stream-io/video-react-sdk、でトリガーされます。 @stream-io/feeds-react-sdk、useCreateChatClient、useCreateFeedsClient、StreamVideo、チャンネル、MessageList。ライブストリーミング、ビデオ会議、チームメッセージング、ダイレクトメッセージング、ソーシャルフィードをカバーします。 Web React のみ - React Native ではありません (stream-react-native を使用)。
