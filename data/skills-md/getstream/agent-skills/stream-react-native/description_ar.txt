إنشاء وبناء ودمج تطبيقات Stream Chat React Native في React Native Community CLI وExpo. يُستخدم لتطبيقات RN/Expo Chat الجديدة من البداية، وتكامل التطبيق الحالي، وStream Chat RN، وstream-chat-react-native، وstream-chat-expo، والترحيل/الإعداد، وقائمة القنوات، وقائمة الرسائل، وMessageComposer، ومنتقي المرفقات، ومرفقات الصور/الملفات، ومنتقي الوسائط، وتحميل الكاميرا، والرسائل الصوتية، والخيوط، وقائمة الخيوط، وReact Navigation، وExpo Router، والسمات، والدعم دون اتصال، ودفع الإشعارات، وتخصيص الدردشة. الدردشة فقط في الإصدار 1؛ ليس مخصصًا لدفق الفيديو أو الخلاصات أو واجهة مستخدم الإشراف.
