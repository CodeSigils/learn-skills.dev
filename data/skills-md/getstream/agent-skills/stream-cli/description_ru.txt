Запрашивайте данные Stream и выполняйте операции CLI для чата, видео, каналов и модерации: получайте список каналов, список вызовов, показ помеченных сообщений, поиск пользователей, запрос любого ресурса Stream. Запустите командыstream api/stream config/stream auth. Установите двоичный файл Stream CLI. Используйте, когда пользователь дает операционные глаголы («список», «показать», «найти», «проверить», «запрос») с существительными Stream или буквально вызывает CLI.
