Interrogez les données Stream et exécutez des opérations CLI sur le chat, la vidéo, les flux et la modération : répertoriez les chaînes, répertoriez les appels, affichez les messages signalés, recherchez les utilisateurs, interrogez n'importe quelle ressource Stream. Exécutez les commandes stream api / stream config / stream auth. Installez le binaire Stream CLI. À utiliser lorsque l'utilisateur donne des verbes opérationnels (« liste », « afficher », « trouver », « vérifier », « requête ») avec des noms de flux ou invoque littéralement la CLI.
