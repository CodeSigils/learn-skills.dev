Fragen Sie Stream-Daten ab und führen Sie CLI-Vorgänge für Chat, Video, Feeds und Moderation aus: Kanäle auflisten, Anrufe auflisten, markierte Nachrichten anzeigen, Benutzer finden, beliebige Stream-Ressourcen abfragen. Führen Sie die Befehle stream api / stream config / stream auth aus. Installieren Sie die Stream-CLI-Binärdatei. Wird verwendet, wenn der Benutzer operative Verben („list“, „show“, „find“, „check“, „query“) mit Stream-Substantiven angibt oder die CLI wörtlich aufruft.
