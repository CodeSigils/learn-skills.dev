Consulte datos de Stream y ejecute operaciones CLI en chat, video, feeds y moderación: enumere canales, enumere llamadas, muestre mensajes marcados, busque usuarios, consulte cualquier recurso de Stream. Ejecute los comandos stream api / stream config / stream auth. Instale el binario Stream CLI. Úselo cuando el usuario proporciona verbos operativos ('lista', 'mostrar', 'buscar', 'verificar', 'consultar') con sustantivos Stream o invoca la CLI literalmente.
