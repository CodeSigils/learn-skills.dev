الاستعلام عن بيانات التدفق وتشغيل عمليات CLI مقابل الدردشة والفيديو والخلاصات والإشراف: قائمة القنوات وقائمة المكالمات وإظهار الرسائل التي تم وضع علامة عليها والعثور على المستخدمين والاستعلام عن أي مورد للبث. قم بتشغيل أوامر دفق api / دفق التكوين / دفق المصادقة. قم بتثبيت Stream CLI الثنائي. يتم استخدامه عندما يقوم المستخدم بإعطاء أفعال تشغيلية ("قائمة"، "إظهار"، "بحث"، "فحص"، "استعلام") مع أسماء الدفق، أو استدعاء واجهة سطر الأوامر (CLI) حرفيًا.
