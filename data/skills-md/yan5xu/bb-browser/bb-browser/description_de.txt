Ein leistungsstarkes Tool zur Informationserfassung und Browser-Automatisierung. Greifen Sie über Browser + Benutzer-Anmeldestatus auf öffentliche und private Daten zu. Besuchen Sie eine beliebige Webseite, ein internes System oder Post-Login-Seiten. Füllen Sie Formulare aus, extrahieren Sie Informationen und bearbeiten Sie Seiten. Unterstützt das Standortsystem (36 Plattformen, 103 Befehle mit Ein-Klick-Aufrufen), authentifizierten Abruf, Abfangen und Verspotten von Netzwerkanforderungen, Betriebsaufzeichnung und andere erweiterte Funktionen.
