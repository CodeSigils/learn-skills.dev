قم بمراجعة الصفحة المقصودة أو صفحة المبيعات أو صفحة الخروج بحثًا عن تسربات التحويل وإرجاع قائمة الإصلاح مرتبة حسب تأثير الإيرادات المتوقع. يُستخدم عندما يُطلب منك مراجعة أو انتقاد أو تحسين الصفحة المقصودة أو صفحة المبيعات أو صفحة الاشتراك أو صفحة المنتج أو تدفق الدفع، أو عندما يكون معدل التحويل منخفضًا، أو عندما لا يتم تحويل حركة المرور المدفوعة، أو عندما يسأل شخص ما "لماذا لا يتم تحويل هذه الصفحة" أو يريد مراجعة CRO / الصفحة المقصودة.
