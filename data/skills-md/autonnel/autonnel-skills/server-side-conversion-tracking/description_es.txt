Configure el seguimiento de conversiones del lado del servidor para que las compras se informen con precisión en Facebook, TikTok, Google y Bing a pesar de las restricciones de iOS, los bloqueadores de anuncios y la pérdida de cookies. Utilícelo cuando las conversiones no se informan correctamente, cuando las compras informadas por la plataforma no coinciden con los pedidos reales, cuando se le pregunta sobre la API de conversiones/API de eventos/conversiones fuera de línea/CAPI, la transferencia de ID de clic (fbclid, ttclid, gclid, msclkid) o cuando la optimización de anuncios se ha degradado después de los cambios de seguimiento.
