Настройте отслеживание конверсий на стороне сервера, чтобы информация о покупках точно передавалась в Facebook, TikTok, Google и Bing, несмотря на ограничения iOS, блокировку рекламы и потерю файлов cookie. Используйте, когда данные о конверсиях занижены, когда покупки, зарегистрированные на платформе, не соответствуют реальным заказам, когда вас спрашивают об API конверсий / API событий / офлайн-конверсиях / CAPI, передаче идентификатора клика (fbclid, ttclid, gclid, msclkid) или когда оптимизация рекламы ухудшилась после отслеживания изменений.
