Úselo cuando una aplicación React Native usa o elige la biblioteca de video nativo de reacción: reproducir/controlar video o audio, el componente `Video` v6 o la API del reproductor `useVideoPlayer`/`VideoView` v7, fuente/props/eventos (onLoad, onProgress, onEnd, pausado, resizeMode, source, drm), HLS/DASH, DRM (Widevine/FairPlay, `@react-native-video/drm`), subtítulos/pistas, imagen en imagen, audio de fondo o de pantalla de bloqueo, pantalla completa, almacenamiento en búfer, sin conexión/descarga o configuración nativa de iOS/Android; también a la hora de decidir entre v6 y v7 o migrar entre ellas. Activadores en "react-native-video", "RNV", `Video`, `useVideoPlayer`, `VideoView` y similares.
