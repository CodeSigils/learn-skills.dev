Используйте, когда приложение React Native использует или выбирает библиотеку React-Native-Video — воспроизведение/управление видео или аудио, компонент Video v6 или API проигрывателя useVideoPlayer/VideoView v7, источник/реквизит/события (onLoad, onProgress, onEnd, пауза, resizeMode, источник, drm), HLS/DASH, DRM (Widevine/FairPlay, `@react-native-video/drm`), субтитры/дорожки, картинка в картинке, фоновый звук или звук на экране блокировки, полноэкранный режим, буферизация, автономный режим/загрузка или встроенная настройка iOS/Android; также при выборе между v6 и v7 или при переходе между ними. Запускается по «react-native-video», «RNV», «Video», «useVideoPlayer», «VideoView» и т. д.
