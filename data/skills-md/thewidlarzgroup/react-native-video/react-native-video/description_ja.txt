React Native アプリが、react-native-video ライブラリを使用または選択している場合に使用します。ビデオまたはオーディオの再生/制御、v6 `Video` コンポーネントまたは v7 `useVideoPlayer`/`VideoView` プレーヤー API、source/props/events (onLoad、onProgress、onEnd、paused、resizeMode、source、drm)、HLS/DASH、DRM (widevine/FairPlay、 `@react-native-video/drm`)、キャプション/トラック、ピクチャーインピクチャー、バックグラウンドまたはロック画面オーディオ、フルスクリーン、バッファリング、オフライン/ダウンロード、またはネイティブ iOS/Android セットアップ。また、v6 と v7 のどちらを選択するか、または v6 と v7 の間で移行する場合も同様です。 「react-native-video」、「RNV」、`Video`、`useVideoPlayer`、`VideoView` などでトリガーされます。
