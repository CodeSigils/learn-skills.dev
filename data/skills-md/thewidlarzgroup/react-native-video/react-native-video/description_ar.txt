يُستخدم عندما يستخدم تطبيق React Native مكتبة الفيديو التفاعلية الأصلية أو يختارها — تشغيل/تحكم في الفيديو أو الصوت، أو مكون v6 `Video` أو واجهة برمجة تطبيقات المشغل v7 `useVideoPlayer`/`VideoView`، المصدر/الدعائم/الأحداث (onLoad، onProgress، onEnd، مؤقت، resizeMode، source، drm)، HLS/DASH، DRM (Widevine/FairPlay، `@react-native-video/drm`)، أو التسميات التوضيحية/المسارات، أو صورة داخل صورة، أو صوت الخلفية أو شاشة القفل، أو وضع ملء الشاشة، أو التخزين المؤقت، أو عدم الاتصال بالإنترنت/التنزيل، أو إعداد iOS/Android الأصلي؛ وأيضًا عند الاختيار بين الإصدارين v6 وv7 أو الترحيل بينهما. يتم تشغيلها على "react-native-video"، و"RNV"، و"Video"، و"useVideoPlayer"، و"VideoView"، وما شابه ذلك.
