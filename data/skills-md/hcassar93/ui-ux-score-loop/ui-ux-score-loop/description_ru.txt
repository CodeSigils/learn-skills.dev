Цикл улучшения UI/UX на основе браузера для одного или нескольких указанных потоков продуктов. Используйте, когда пользователь запрашивает проверку, оценку, улучшение или итеративное тестирование таких процессов, как регистрация, вход в систему, сброс пароля, оформление заказа, создание/редактирование/удаление/поделиться, адаптация или другие ключевые пути пользовательского интерфейса с использованием выбранного реального браузера, очистка сеансов браузера, настраиваемая интерактивная предварительная проверка, степень детализации просмотра, снимки экрана, адаптивные точки останова, светлые/темные режимы, оценки UX по критериям 0–100 и файлы состояния информационной панели.
