Ciclo di miglioramento dell'interfaccia utente/UX basato su browser per uno o più flussi di prodotto specificati. Da utilizzare quando l'utente chiede di ispezionare, valutare, migliorare o testare in modo iterativo flussi come registrazione, accesso, reimpostazione della password, checkout, creazione/modifica/eliminazione/condivisione, onboarding o altri percorsi chiave dell'interfaccia utente utilizzando un browser reale selezionato, sessioni del browser pulite, preflight interattivo configurabile, granularità della visualizzazione, screenshot, punti di interruzione reattivi, modalità chiaro/scuro, punteggi delle rubriche UX 0-100 e file di stato del dashboard.
