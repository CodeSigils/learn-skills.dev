Browserbasierte UI/UX-Verbesserungsschleife für einen oder mehrere bestimmte Produktabläufe. Wird verwendet, wenn der Benutzer Abläufe überprüfen, bewerten, verbessern oder iterativ testen möchte, z. B. Anmelden, Anmelden, Zurücksetzen des Passworts, Auschecken, Erstellen/Bearbeiten/Löschen/Freigeben, Onboarding oder andere wichtige UI-Pfade mithilfe eines ausgewählten echten Browsers, saubere Browsersitzungen, konfigurierbares interaktives Preflight, Ansichtsgranularität, Screenshots, reaktionsfähige Haltepunkte, Hell-/Dunkel-Modi, UX-Rubrikbewertungen von 0–100 und Dashboard-Statusdateien.
