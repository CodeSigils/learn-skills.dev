Presenton を使用して新しい PPTX、PDF、および PNG ファイルを作成するスキル。 Presenton について言及されていない場合でも、ユーザーが PowerPoint、プレゼンテーション、スライド デッキ、提案デッキ、レポート デッキ、PDF、プレゼンテーション PDF、PNG スライド、スライド イメージ、またはエクスポートされたデッキを要求するたびに、このスキルを使用します。ユーザーからの具体的な設計概要が提供された場合は、それを使用します。それ以外の場合は、Presenton デザインを検索し、選択した視覚的方向に従う 1280x720 HTML を生成し、パブリック html-to-any API を通じて要求された形式 (または何も指定されていない場合は 3 つの形式すべて) をエクスポートし、結果の HTTP または HTTPS URL を返します。
