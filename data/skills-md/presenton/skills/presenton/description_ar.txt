مهارة إنشاء ملفات PPTX وPDF وPNG جديدة باستخدام Presenton. استخدم هذه المهارة عندما يطلب المستخدم تقديم PowerPoint، أو عرض تقديمي، أو مجموعة شرائح، أو مجموعة عرض تقديمي، أو مجموعة تقارير، أو PDF، أو عرض PDF، أو شريحة PNG، أو صورة شريحة، أو مجموعة مُصدَّرة، حتى عندما لا يتم ذكر Presenton. استخدم ملخص تصميم ملموس من المستخدم عند تقديمه؛ بخلاف ذلك، ابحث عن تصميمات Presenton، وأنشئ HTML بحجم 1280 × 720 يتبع الاتجاه المرئي المختار، وقم بتصدير التنسيقات المطلوبة - أو جميع التنسيقات الثلاثة عندما لا يتم تحديد أي منها - من خلال واجهة html العامة إلى أي واجهة برمجة تطبيقات، وإرجاع عناوين URL الناتجة عن HTTP أو HTTPS.
