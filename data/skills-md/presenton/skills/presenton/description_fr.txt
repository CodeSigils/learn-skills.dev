Compétence pour créer de nouveaux fichiers PPTX, PDF et PNG avec Presenton. Utilisez cette compétence chaque fois qu'un utilisateur demande un PowerPoint, une présentation, un diaporama, un pitch deck, un rapport, un PDF, une présentation PDF, une diapositive PNG, une image de diapositive ou un deck exporté, même lorsque Presenton n'est pas mentionné. Utiliser un dossier de conception concret de l'utilisateur lorsqu'il est fourni ; sinon, recherchez les conceptions Presenton, générez du HTML 1280 x 720 qui suit la direction visuelle choisie, exportez les formats demandés (ou les trois formats lorsqu'aucun n'est spécifié) via l'API publique HTML vers n'importe quelle API et renvoyez les URL HTTP ou HTTPS résultantes.
