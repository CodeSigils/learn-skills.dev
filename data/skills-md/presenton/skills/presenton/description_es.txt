Habilidad para crear nuevos archivos PPTX, PDF y PNG con Presenton. Utilice esta habilidad siempre que un usuario solicite un PowerPoint, una presentación, una presentación de diapositivas, una presentación de presentación, una presentación de informes, un PDF, una presentación en PDF, una diapositiva PNG, una imagen de diapositiva o una presentación exportada, incluso cuando no se mencione Presenton. Utilice un resumen de diseño concreto del usuario cuando se proporcione; de lo contrario, busque diseños de Presenton, genere HTML de 1280 x 720 que siga la dirección visual elegida, exporte los formatos solicitados (o los tres formatos cuando no se especifique ninguno) a través de la API pública de html a cualquier API y devuelva las URL HTTP o HTTPS resultantes.
