Навыки создания новых файлов PPTX, PDF и PNG с помощью Presenton. Используйте этот навык всякий раз, когда пользователь запрашивает PowerPoint, презентацию, слайд-презентацию, питч-презентацию, отчет, PDF, презентацию PDF, слайд PNG, изображение слайда или экспортированную презентацию, даже если Presenton не упоминается. Используйте конкретное задание на проектирование от пользователя, если оно предоставлено; в противном случае выполните поиск по проектам Presenton, сгенерируйте HTML 1280x720, соответствующий выбранному визуальному направлению, экспортируйте запрошенные форматы (или все три формата, если ни один не указан) через общедоступный API html-to-any и верните полученные URL-адреса HTTP или HTTPS.
