عند كتابة اختبارات قبول Behat أو تصحيحها أو تحسينها لـ OroCommerce، يجب عليك استخدام هذه المهارة للتشاور مع قاعدة معارف الاختبار بدلاً من الاعتماد على الذاكرة.
سيناريوهات التشغيل: - كتابة ملفات .feature جديدة أو تعريفات خطوة Behat - إنشاء تكوين behat.yml (المجموعات والسياقات والعناصر) - تعريف العناصر لتعيين حقل النموذج - كتابة تركيبات Alice YAML لبيانات الاختبار - تصحيح أخطاء سيناريوهات Behat الفاشلة - إنشاء فئات سياق مخصصة لتوسيع OroFeatureContext - فهم خطوات Oro المضمنة المتوفرة - استخدام الخطوط العريضة للسيناريو، أو أقسام الخلفية، أو علامات التثبيت - الكتابة فئات ReferenceRepositoryInitializer - فهم سلوك عزل الاختبار بين الميزات/السيناريوهات
بالنسبة لأي هيكل اختبار Behat، أو أنماط إطار اختبار Oro، أو تعريفات الخطوات، أو تحميل التركيبات، أو تكوين العناصر، اقرأ الوثائق أولاً.
