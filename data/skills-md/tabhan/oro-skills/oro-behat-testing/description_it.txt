Quando scrivi, esegui il debug o ottimizzi i test di accettazione Behat per OroCommerce, DEVI utilizzare questa competenza per consultare la knowledge base dei test invece di fare affidamento sulla memoria.
Scenari di attivazione: - Scrittura di nuovi file .feature o definizioni di passaggi Behat - Creazione di configurazioni behat.yml (suite, contesti, elementi) - Definizione di elementi per la mappatura dei campi del modulo - Scrittura di dispositivi Alice YAML per dati di test - Debug di scenari Behat non riusciti - Creazione di classi Context personalizzate che estendono OroFeatureContext - Comprensione di quali passaggi Oro integrati sono disponibili - Utilizzo di profili di scenario, sezioni di sfondo o tag di dispositivi - Scrittura di classi ReferenceRepositoryInitializer - Comprendere il comportamento di isolamento dei test tra funzionalità/scenari
Per qualsiasi struttura di test Behat, pattern di framework di test Oro, definizioni di passaggi, caricamento di dispositivi o configurazione di elementi, leggere prima la documentazione.
