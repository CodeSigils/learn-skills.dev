Lors de l'écriture, du débogage ou de l'optimisation des tests d'acceptation Behat pour OroCommerce, vous DEVEZ utiliser cette compétence pour consulter la base de connaissances sur les tests au lieu de vous fier à la mémoire.
Scénarios de déclenchement : - Écriture de nouveaux fichiers .feature ou de définitions d'étapes Behat - Création d'une configuration behat.yml (suites, contextes, éléments) - Définition d'éléments pour le mappage des champs de formulaire - Écriture de luminaires Alice YAML pour les données de test - Débogage de scénarios Behat défaillants - Création de classes de contexte personnalisées étendant OroFeatureContext - Comprendre quelles étapes Oro intégrées sont disponibles - Utilisation des contours de scénario, des sections d'arrière-plan ou des balises de luminaire - Écriture de classes ReferenceRepositoryInitializer - Comprendre le test comportement d'isolation entre les fonctionnalités/scénarios
Pour toute structure de test Behat, modèles de cadre de test Oro, définitions d'étapes, chargement de luminaires ou configuration d'éléments, lisez d'abord la documentation.
