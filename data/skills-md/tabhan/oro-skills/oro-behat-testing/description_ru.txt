При написании, отладке или оптимизации приемочных тестов Behat для OroCommerce вы ДОЛЖНЫ использовать этот навык для обращения к базе знаний по тестированию, а не полагаться на память.
Сценарии триггеров: - Написание новых файлов .feature или определений шагов Behat - Создание конфигурации behat.yml (наборы, контексты, элементы) - Определение элементов для сопоставления полей формы - Написание фикстур Alice YAML для тестовых данных - Отладка неудачных сценариев Behat - Создание пользовательских классов контекста, расширяющих OroFeatureContext - Понимание того, какие встроенные шаги Oro доступны - Использование структур сценариев, фоновых разделов или тегов фикстур - Написание Классы ReferenceRepositoryInitializer: понимание поведения изоляции тестов между функциями/сценариями.
Для любой структуры тестирования Behat, шаблонов тестовой среды Oro, определений шагов, загрузки приспособлений или конфигурации элементов сначала прочтите документацию.
