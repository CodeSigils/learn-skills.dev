Управляйте навыками на более чем 20 платформах искусственного интеллекта (Claude Code, Cursor, Copilot, Gemini, OpenClaw, Hermes и т. д.). Включает веб-интерфейс с нулевой зависимостью (команда `web`) для визуальных навыков CRUD. По умолчанию отображается только список навыков; Наставляйте/рекомендуйте только тогда, когда пользователь явно спрашивает, какой навык использовать.
