Administre habilidades en más de 20 plataformas de IA (Claude Code, Cursor, Copilot, Gemini, OpenClaw, Hermes, etc.). Incluye una interfaz de usuario web sin dependencia (comando `web`) para CRUD de habilidades visuales. El comportamiento predeterminado es enumerar únicamente las habilidades; solo guía/recomienda cuando el usuario pregunta explícitamente qué habilidad usar.
