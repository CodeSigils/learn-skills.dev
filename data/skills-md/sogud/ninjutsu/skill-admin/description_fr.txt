Gérez les compétences sur plus de 20 plateformes d'IA (Claude Code, Cursor, Copilot, Gemini, OpenClaw, Hermes, etc.). Inclut une interface utilisateur Web sans dépendance (commande `web`) pour les compétences visuelles CRUD. Le comportement par défaut consiste uniquement à répertorier les compétences ; guider/recommander uniquement lorsque l'utilisateur demande explicitement quelle compétence utiliser.
