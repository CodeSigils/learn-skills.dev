Flujos de trabajo administrativos para el repositorio de habilidades del agente. Úselo cuando el usuario quiera contribuir con una habilidad, abrir una solicitud de extracción o actualizar una habilidad ya instalada a la última versión.
Se activa cuando los usuarios dicen: "abrir un PR", "enviar mis cambios", "impulsar esta habilidad", "actualizar mis habilidades", "actualizar el repositorio de habilidades" o "cómo contribuyo con una habilidad".
