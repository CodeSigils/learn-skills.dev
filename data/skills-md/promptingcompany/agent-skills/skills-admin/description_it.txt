Flussi di lavoro amministrativi per il repository delle competenze dell'agente. Da utilizzare quando l'utente desidera contribuire con una competenza, aprire una richiesta pull o aggiornare una competenza già installata alla versione più recente.
Si attiva quando gli utenti dicono: "apri un PR", "invia le mie modifiche", "promuovi questa competenza", "aggiorna le mie competenze", "aggiorna il repository delle competenze" o "come posso contribuire con una competenza".
