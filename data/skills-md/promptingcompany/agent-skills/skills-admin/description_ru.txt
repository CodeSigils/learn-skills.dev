Административные рабочие процессы для хранилища навыков агентов. Используйте, когда пользователь хочет добавить навык, открыть запрос на включение или обновить уже установленный навык до последней версии.
Запускается, когда пользователи говорят: «открыть PR», «отправить мои изменения», «отправить этот навык», «обновить мои навыки», «обновить репозиторий навыков» или «как мне добавить навык».
