Verwaltungsworkflows für das Agent-Skills-Repository. Verwenden Sie diese Option, wenn der Benutzer einen Skill beisteuern, eine Pull-Anfrage öffnen oder einen bereits installierten Skill auf die neueste Version aktualisieren möchte.
Wird ausgelöst, wenn Benutzer sagen: „öffne eine PR“, „sende meine Änderungen“, „pushe diesen Skill“, „aktualisiere meine Skills“, „aktualisiere das Skills-Repo“ oder „Wie trage ich einen Skill bei“.
