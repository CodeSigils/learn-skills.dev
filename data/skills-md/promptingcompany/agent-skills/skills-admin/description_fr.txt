Workflows administratifs pour le référentiel de compétences des agents. À utiliser lorsque l'utilisateur souhaite contribuer à une compétence, ouvrir une demande d'extraction ou mettre à jour une compétence déjà installée vers la dernière version.
Déclenchez lorsque les utilisateurs disent : « ouvrir un PR », « soumettre mes modifications », « pousser cette compétence », « mettre à jour mes compétences », « mettre à jour le référentiel de compétences » ou « comment puis-je contribuer à une compétence ».
