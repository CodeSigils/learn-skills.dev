سير العمل الإداري لمستودع مهارات الوكيل. يُستخدم عندما يريد المستخدم المساهمة بمهارة، أو فتح طلب سحب، أو تحديث مهارة مثبتة بالفعل إلى الإصدار الأحدث.
يتم تشغيله عندما يقول المستخدمون: "افتح PR"، أو "أرسل تغييراتي"، أو "ادفع هذه المهارة"، أو "قم بتحديث مهاراتي"، أو "قم بتحديث مستودع المهارات"، أو "كيف أساهم بمهارة".
