Генерирует конфигурации сигналов YAML для экспериментов по моделированию агентов. Используйте, когда пользователь хочет определить, какие сигналы отслеживать, как извлечь их из артефактов запуска и как агрегировать их в метрики уровня эксперимента.
Срабатывает, когда пользователи говорят: «создать конфигурацию сигнала», «создать сигналы для моего эксперимента», «я хочу отслеживать [метрику]», «написать сигнал в формате YAML», «настроить извлечение для [вещи]», «как измерить [поведение] в ходе прогонов», «настроить сигналы для [эксперимента]», «создать конфигурацию сигнала», «создать файл конфигурации сигнала» или «создать конфигурацию сигнала».
