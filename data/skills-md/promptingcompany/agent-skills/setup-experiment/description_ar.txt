سير عمل تفاعلي شامل - اختر منتجًا، ثم قم بتشغيل المهام والبيئات الحالية (المسار أ) أو قم بإعداد مهام وبيئات جديدة من المستندات والمهام المقترحة وبيانات الاعتماد والقوالب (المسار ب). يبني التجربة، ويرفق الإشارات، ويطلق التكرار الأول اختياريًا.
يتم تشغيله عندما يقول المستخدمون: "إعداد تجربة"، أو "إنشاء تجربة"، أو "أريد إجراء تجربة"، أو "تشغيل مهامي"، أو "إعداد التجربة"، أو "تجربة جديدة"، أو "تكوين تجربة"، أو "إعداد التجربة".
