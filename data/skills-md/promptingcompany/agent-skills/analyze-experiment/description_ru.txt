Превратите завершенную итерацию эксперимента в честный, подтвержденный фактами анализ — отчет об уценке и портативный дамп данных. Извлекает данные о запуске через интерфейс командной строки tpc, оценивает каждую задачу, группирует разногласия по основной причине (с примером стенограммы для каждой претензии), сравнивает варианты и устраняет пробелы в готовности агентов. Естественный спутник настройки-эксперимента: настройка → запуск → анализ.
Запускается, когда пользователи говорят: «проанализируйте мой эксперимент», «напишите отчет», «отчет об эксперименте», «проанализируйте результаты», «подведите итоги», «что произошло в этой итерации», «отчет о трениях» или «создание отчета».
