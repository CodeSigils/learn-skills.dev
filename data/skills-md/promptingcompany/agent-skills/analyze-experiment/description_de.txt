Verwandeln Sie eine abgeschlossene Experimentiteration in eine ehrliche, evidenzbasierte Analyse – einen Markdown-Bericht und einen tragbaren Datendump. Ruft Laufdaten über die tpc-CLI ab, bewertet jede Aufgabe, gruppiert Reibungen nach Grundursache (mit einem Transkriptbeispiel pro Anspruch), vergleicht Arme und schließt Lücken bei der Agentenbereitschaft. Der natürliche Begleiter zum Setup-Experiment: Setup → Ausführen → Analysieren.
Wird ausgelöst, wenn Benutzer sagen: „Mein Experiment analysieren“, „Bericht schreiben“, „Experimentbericht“, „Ergebnisse analysieren“, „Durchläufe zusammenfassen“, „Was ist in dieser Iteration passiert“, „Reibungsbericht“ oder „Bericht generieren“.
