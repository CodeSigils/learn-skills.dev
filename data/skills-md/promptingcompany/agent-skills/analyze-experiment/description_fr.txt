Transformez une itération d'expérience terminée en une analyse honnête et fondée sur des preuves : un rapport de démarque et un vidage de données portable. Extrait les données d'exécution via la CLI tpc, note chaque tâche, regroupe les frictions par cause première (avec un exemple de transcription par réclamation), compare les armes et comble les écarts de préparation des agents. Le compagnon naturel de setup-experiment : configuration → exécuter → analyser.
Déclenchez lorsque les utilisateurs disent : "analyser mon expérience", "écrire le rapport", "rapport d'expérience", "analyser les résultats", "résumer les exécutions", "ce qui s'est passé dans cette itération", "rapport de friction" ou "génération de rapport".
