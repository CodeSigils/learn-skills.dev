قم بتحويل تكرار التجربة المكتملة إلى تحليل صادق ومدعوم بالأدلة - تقرير تخفيض السعر ومخزن بيانات محمول. يسحب بيانات التشغيل عبر tpc CLI، ويسجل كل مهمة، ويجمع الاحتكاك حسب السبب الجذري (مع مثال نصي لكل مطالبة)، ويقارن الأذرع، ويغلق فجوات جاهزية الوكيل. الرفيق الطبيعي لتجربة الإعداد: الإعداد → التشغيل → التحليل.
يتم تشغيله عندما يقول المستخدمون: "تحليل تجربتي"، أو "اكتب التقرير"، أو "تقرير التجربة"، أو "تحليل النتائج"، أو "تلخيص عمليات التشغيل"، أو "ما حدث في هذا التكرار"، أو "تقرير الاحتكاك"، أو "جيل التقرير".
