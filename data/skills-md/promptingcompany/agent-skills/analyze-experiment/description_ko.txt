완료된 실험 반복을 정직하고 증거에 기반한 분석(마크다운 보고서 및 휴대용 데이터 덤프)으로 전환합니다. tpc CLI를 통해 실행 데이터를 가져오고, 각 작업에 점수를 매기고, 근본 원인별로 마찰을 클러스터링하고(청구당 기록 예시 포함), 부문을 비교하고, 에이전트 준비 격차를 해소합니다. 설정-실험의 자연스러운 동반자: 설정 → 실행 → 분석.
사용자가 "내 실험 분석", "보고서 작성", "실험 보고서", "결과 분석", "실행 요약", "이 반복에서 발생한 일", "마찰 보고서" 또는 "보고서 생성"이라고 말하면 트리거됩니다.
