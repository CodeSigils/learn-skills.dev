Plateforme de calcul GPU gérée DGX Cloud Lepton avec interface exécuter/statut/annulation. À utiliser lors de la soumission de tâches TAO à DGX Cloud, de l'envoi de formations/évaluations/inférences aux ressources GPU Lepton ou de la gestion des déploiements d'espace de travail Lepton. Les phrases de déclenchement incluent « exécuter sur Lepton », « soumettre à DGX Cloud », « tâche Lepton », « GPU géré sur DGX Cloud ».
