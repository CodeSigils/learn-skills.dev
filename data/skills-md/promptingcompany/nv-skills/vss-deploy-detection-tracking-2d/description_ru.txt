Используйте этот навык, когда пользователь хочет развернуть, запустить, отладить, отключить или вызвать REST API микросервиса 2D-обнаружения/отслеживания RTVI-CV. Срабатывает, когда пользователь говорит такие вещи, как «развернуть rtvi-cv», «запустить хранилище 2d», «добавить поток», «проверить работоспособность rtvi-cv» или «остановить контейнер восприятия». Не для VLM, внедрения или аналитики — используйте навык сопоставления vss-*.
