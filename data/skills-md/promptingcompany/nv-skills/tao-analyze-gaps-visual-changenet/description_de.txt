Führt Lückenanalysen auf NVIDIA TAO Visual ChangeNet (VCN) durch. Klassifizieren Sie Experimente, indem Sie den Datendienstcontainer (`tao_toolkit.data_services` aus `versions.yaml`) direkt über `docker run … Gap_analysis vcn_aoi …‘ aufrufen – wählt den optimalen Entscheidungsschwellenwert aus, ordnet Schwächen pro Stichprobe ein und gibt ein Top-K-Schwächstparkett pro Beleuchtung für die nachgelagerte Erweiterung aus. Verwenden Sie diese Option, wenn Sie VCN-Klassifizierungsfehler analysieren, SDA-Erweiterungsziele auswählen, PASS/NO_PASS-Grenzfälle prüfen oder eine DEFT-Lückenanalyse für ein AOI-ChangeNet-Modell ausführen.
