Как запустить распределенные учебные задания Megatron-LM на кластере SLURM. Охватывает минимальный скелет выборки, настройку переменных среды для torch.distributed.run, правила CUDA_DEVICE_MAX_CONNECTIONS для аппаратного обеспечения и режимов параллелизма, соглашения о контейнерах, мониторинг и диагностику сбоев каждого ранга.
