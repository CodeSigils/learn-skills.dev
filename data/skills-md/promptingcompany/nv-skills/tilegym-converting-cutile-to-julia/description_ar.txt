يحول نواة GPU cuTile Python (@ct.kernel) إلى مكافئات cuTile.jl Julia. يتعامل مع ترجمة بناء جملة kernel، والتحويل المفهرس من 0 إلى 1، واختلافات البث، وتخطيط الذاكرة (من الصف الرئيسي إلى العمود الرئيسي)، وتعيين نظام الكتابة، وإطلاق اختلافات واجهة برمجة التطبيقات. يُستخدم عند تحويل أو نقل أو ترجمة حبات cuTile Python إلى Julia cuTile.jl، أو تصحيح/تحسين ترجمات Julia cuTile الحالية.
