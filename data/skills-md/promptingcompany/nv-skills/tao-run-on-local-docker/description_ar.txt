تنفيذ Docker المحلي لحاويات مهام TAO SDK باستخدام البرنامج الخفي Docker المضيف ووقت تشغيل NVIDIA GPU. يُستخدم عند تشغيل مهام TAO على الجهاز الحالي أو مضيف Docker متصل مباشرةً. تتضمن عبارات التشغيل "التشغيل محليًا"، و"Docker المحلي"، و"استخدام وحدة معالجة الرسومات الخاصة بي"، و"التشغيل على جهازي"، و"host Docker daemon".
