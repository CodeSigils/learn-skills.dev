Локальное выполнение Docker для контейнеров заданий TAO SDK с использованием демона Docker хоста и среды выполнения NVIDIA GPU. Используйте при запуске заданий TAO на текущем компьютере или напрямую подключенном хосте Docker. Триггерные фразы включают «запускать локально», «локальный Docker», «использовать мой графический процессор», «запускать на моем компьютере», «хост-демон Docker».
