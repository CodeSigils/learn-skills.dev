إرشادات NemoClaw التي تواجه المستخدم لتثبيت صناديق حماية NemoClaw وتكوينها وتشغيلها وتأمينها ومراقبتها واستكشاف الأخطاء وإصلاحها. يُستخدم عندما يسأل المستخدمون عن عمليات التشغيل السريع لـ NemoClaw، وعلاقات OpenClaw وOpenShell، أو الاستدلال المحلي، أو نشر GPU عن بعد، أو دورة حياة وضع الحماية، أو سياسة الشبكة، أو الوضع الأمني، أو مهارات الوكيل، أو مرجع الأوامر، أو إصدار تعليمات الفرز.
