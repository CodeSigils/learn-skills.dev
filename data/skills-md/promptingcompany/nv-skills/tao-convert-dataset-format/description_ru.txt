Запустите «tao-daft Convert», чтобы преобразовать наборы данных NVIDIA TAO DAFT между поддерживаемыми форматами. Не используйте для данных, не относящихся к DAFT. Используйте, когда пользователь просит преобразовать набор данных DAFT, изменить формат DAFT, изменить формат набора данных TAO или запустить «tao-daft Convert».
