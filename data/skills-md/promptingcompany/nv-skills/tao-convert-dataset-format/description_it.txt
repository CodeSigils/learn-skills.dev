Esegui "tao-daft convert" per convertire i set di dati NVIDIA TAO DAFT tra i formati supportati. Non utilizzare per dati non DAFT. Da utilizzare quando l'utente chiede di convertire un set di dati DAFT, modificare il formato DAFT, modificare il formato di un set di dati TAO o eseguire "tao-daft convert".
