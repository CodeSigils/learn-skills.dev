Carica un set di dati su disco partizionato (.npy partizionato, Parquet/Arrow, binario non elaborato, HDF5 partizionato, layout personalizzati) in un ndarray cuPyNumeric distribuito tramite una partizione manuale + avvio leaf @task con varianti CPU/OMP/GPU. Da utilizzare quando non è adatto un caricatore a chiamata singola, incluso quando il conteggio delle righe per shard differisce tra i file. Preferisci cupynumeric.load o legate.io.hdf5.from_file quando si applicano.
