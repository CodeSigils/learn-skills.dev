Laden Sie einen Shard-Datensatz auf der Festplatte (Sharded .npy, Parquet/Arrow, Raw Binary, Sharding HDF5, benutzerdefinierte Layouts) über eine manuelle Partition + Leaf @task-Start mit CPU/OMP/GPU-Varianten in ein verteiltes cuPyNumeric-Ndarray. Verwenden Sie diese Option, wenn kein Single-Call-Loader passt, auch wenn die Zeilenanzahl pro Shard in den einzelnen Dateien unterschiedlich ist. Bevorzugen Sie cupynumeric.load oder legate.io.hdf5.from_file, wenn sie zutreffen.
