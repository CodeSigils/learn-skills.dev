Esegui "tao-daft validate" per verificare la presenza di errori di struttura, schema ed errori di riferimento incrociato nei set di dati NVIDIA TAO DAFT. Non utilizzare per formati non DAFT. Da utilizzare quando l'utente chiede di convalidare un set di dati DAFT, controllare lo schema DAFT, convalidare il formato di un set di dati TAO o eseguire "tao-daft validate".
