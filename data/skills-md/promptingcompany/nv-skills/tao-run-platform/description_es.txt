SDK de ejecución de TAO para enviar y monitorear trabajos de entrenamiento de GPU en plataformas compatibles (Lepton, Brev, SLURM, Docker local, Kubernetes). Úselo cuando el usuario quiera ejecutar trabajos TAO a través del SDK, obtener seguimiento de trabajos, ajuste de E/S de S3, capacitación distribuida en múltiples nodos o funciones específicas de la plataforma que docker-run no puede proporcionar. Las frases de activación incluyen "usar el SDK de TAO", "llamar a tao_sdk", "AutoMLRunner", "ActionWorkflow", "identificadores de trabajo", "ajuste de E/S de S3", "ejecución de la plataforma TAO".
