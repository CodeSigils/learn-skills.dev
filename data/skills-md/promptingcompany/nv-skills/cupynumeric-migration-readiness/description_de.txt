Prüfer für die Bereitschaftsbewertung vor der Migration für die Portierung von NumPy auf cuPyNumeric. Verwenden Sie diese Option, BEVOR umfangreiche Portierungsarbeiten beginnen, wenn der Benutzer fragt, ob Code auf der GPU skaliert werden soll, ob er zu cuPyNumeric migrieren soll, welche NumPy-Muster sauber übertragen werden sollen, was vor der Portierung umgestaltet werden muss oder ob er eine Bewertung vor dem Port, eine Skalierungsanalyse oder eine Umgestaltungsplanung erwähnt. Untersuchen Sie den Quellcode des Benutzers, suchen Sie nach der NumPy-Nutzung, verweisen Sie auf das cuPyNumeric-API-Unterstützungsmanifest und unterscheiden Sie Muster, die sich für die verteilte Skalierung eignen, von Blockern wie nicht unterstützten APIs, Skalarsynchronisierung, Host-Roundtrips, Python-/objektlastigem Kontrollfluss, form-/datenabhängiger Verzweigung und direkten Mutationsrisiken. Erstellen Sie mit konkreten Refaktorierungshinweisen ein Urteil wie „BEREIT“, „LEICHTER REFAKTOR“, „WICHTIGER REFAKTOR“ oder „NICHT EMPFOHLEN“.
