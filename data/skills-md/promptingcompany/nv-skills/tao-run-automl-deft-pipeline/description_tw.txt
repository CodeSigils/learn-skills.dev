運行規範的 NVIDIA AOI 三階段訓練管道 - 第 1 階段 AutoML 基線 (HPO)、第 2 階段 DEFT 循環（RCA → SDG → 挖掘 → 普通訓練再訓練）、第 3 階段在 DEFT 增強資料集上的 AutoML 細化。這是任何「運行 AOI 工作流程」、「端對端微調我的 PCB AOI 模型」、「改進我的 AOI ChangeNet 模型」或「使用 AutoML 的 AOI 工作流程」請求的預設入口點 — 在此處路由，而不是直接路由 tao-run-deft-aoi，除非用戶明確僅執行 DEFT DEFT 循環（例如「僅運行」」。也為非 AOI DEFT 應用程式處理相同的三相模式 - AutoML 基線，然後從 AutoML 的獲勝 HP 熱啟動 DEFT 循環，然後在迭代增強資料集上進行 DEFT 後 AutoML 細化。觸發短語包括“運行 AOI 工作流程”、“AOI 端到端”、“AutoML + DEFT”、“AutoML 然後 DEFT”、“調整超參數然後 DEFT”、“兩端使用 AutoML 進行 DEFT”、“熱啟動 DEFT”、“改進我的 AOI 模型”。
