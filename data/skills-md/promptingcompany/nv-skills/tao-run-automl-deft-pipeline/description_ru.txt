Запустите канонический трехэтапный конвейер обучения NVIDIA AOI — этап 1 базового уровня AutoML (HPO), этап 2 цикла DEFT (RCA → SDG → майнинг → простое переобучение), этап 3 уточнение AutoML на наборе данных, дополненном DEFT. Это точка входа по умолчанию для любого запроса «запустить рабочий процесс AOI», «сквозная настройка моей модели AOI на плате», «улучшить мою модель AOI ChangeNet» или «рабочий процесс AOI с AutoML» — направляйте сюда вместо непосредственно tao-run-deft-aoi, если только пользователь явно не запрашивает ТОЛЬКО цикл DEFT (например, «запустить ТОЛЬКО цикл DEFT», «пропустить AutoML, только DEFT»). Также обрабатывается один и тот же трехфазный шаблон для приложений DEFT, не использующих AOI: базовый уровень AutoML, затем цикл DEFT с горячим запуском из победивших HP AutoML, а затем уточнение AutoML после DEFT для набора данных, дополненного итерацией. Триггерные фразы включают «запустить рабочий процесс AOI», «сквозной AOI», «AutoML + DEFT», «AutoML, затем DEFT», «настроить гиперпараметры, затем DEFT», «DEFT с AutoML на обоих концах», «горячий старт DEFT», «улучшить мою модель AOI».
