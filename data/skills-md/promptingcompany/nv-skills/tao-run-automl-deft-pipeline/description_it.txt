Questo è il punto di ingresso predefinito per qualsiasi richiesta "esegui il flusso di lavoro AOI", "perfeziona il mio modello PCB AOI end-to-end", "migliora il mio modello AOI ChangeNet" o "flusso di lavoro AOI con AutoML": instrada qui invece di tao-run-deft-aoi direttamente a meno che l'utente non chieda esplicitamente SOLO il loop DEFT (ad esempio "esegui SOLO il loop DEFT", "salta AutoML, solo DEFT"). Gestisce anche lo stesso modello a tre fasi per le applicazioni DEFT non AOI: linea di base AutoML, quindi ciclo DEFT avviato a caldo dagli HP vincenti di AutoML, quindi perfezionamento AutoML post-DEFT sul set di dati potenziato dall'iterazione.
