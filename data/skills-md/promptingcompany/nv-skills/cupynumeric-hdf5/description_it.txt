Leggi e scrivi array cuPyNumeric di grandi dimensioni su HDF5 con l'I/O HDF5 distribuito parallelo e distribuito di Legate (legate.io.hdf5: to_file, from_file, from_file_batched). Utilizzalo quando uno sviluppatore deve salvare un array cuPyNumeric in un file .h5/.hdf5, caricare un set di dati HDF5 in un array cuPyNumeric distribuito, leggere un set di dati HDF5 di grandi dimensioni in blocchi, consegnare array a una pipeline HPC come un singolo file o accelerare l'I/O del disco HDF5 con GPUDirect Storage (GDS). Non utilizzarlo per Parquet/cuDF/raw-binary o altri layout partizionati/personalizzati (vedi la competenza cupynumeric-parallel-data-load), Zarr o output object-store/S3, archivi .npz o decapati, h5py semplice senza cuPyNumeric o calcolo di array puro come FFT, matmul o riduzioni.
