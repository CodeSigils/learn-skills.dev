Effectue une analyse approfondie des causes profondes (RCA) sur les expériences de classification NVIDIA TAO Visual ChangeNet avec une enquête basée sur des preuves d'images. À utiliser lors de l'analyse des échecs du modèle ChangeNet, de l'enquête sur les métriques de rappel / FAR / PASS-NO_PASS médiocres, de l'audit de la qualité du pipeline d'inspection visuelle ou de l'exécution d'un rapport RCA pour un modèle de détection de défauts AOI. Les phrases de déclenchement incluent « RCA sur mon modèle ChangeNet », « pourquoi mon modèle AOI échoue-t-il », « auditer les prédictions ChangeNet », « enquêter sur les régressions FAR », « analyse des causes profondes sur Visual-Changenet ».
