Starten, fragen und stoppen Sie einen netzwerkspezifischen TAO-Inferenz-Microservice ({network_arch}-inference-microservice), indem Sie die Containerausführung an den entsprechenden Plattform-Skill delegieren. Verwaltet die Container-Image-Auflösung, die JSON-Erstellung der Job-Nutzlast und die Dienstregistrierung. Verwenden Sie diese Option, wenn der Benutzer mithilfe eines Microservice-Containers eine Inferenz auf einem TAO-Modellprüfpunkt ausführen, einen TAO-Inferenzendpunkt bereitstellen oder einen laufenden Inferenzcontainer stoppen möchte.
