Pipeline di espressioni di riferimento delle immagini in quattro fasi: trasforma le immagini più le etichette del riquadro di delimitazione KITTI in descrizioni di regioni, didascalie di scene, espressioni di riferimento radicate e (facoltativamente) espressioni verificate tramite distillazione VLM. Da utilizzare quando l'utente desidera generare annotazioni di espressioni di riferimento da immagini con etichette KITTI, creare descrizioni di regioni, produrre frasi di base raggruppate legate a bbox, eseguire un passaggio di verifica con doppio controllo sulle espressioni di base, etichettare automaticamente immagini di traffico/scene per set di dati di riferimento o eseguire la pipeline image_referring_expression. I trigger includono "espressione di riferimento", "descrizione della regione", "etichette KITTI", "annotazione di relazione spaziale", "espressione di riferimento dell'immagine con etichetta automatica", "espressione_di_riferimento_immagine".
