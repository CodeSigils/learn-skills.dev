Canalización de expresiones de referencia de imágenes de cuatro pasos: convierte imágenes más etiquetas de cuadro delimitador KITTI en descripciones de regiones, títulos de escenas, expresiones de referencia fundamentadas y (opcionalmente) expresiones verificadas mediante destilación de VLM. Úselo cuando el usuario desee generar anotaciones de expresiones de referencia a partir de imágenes con etiquetas KITTI, crear descripciones de regiones, producir frases de conexión a tierra agrupadas vinculadas a bboxes, ejecutar una pasada de verificación de doble verificación en expresiones de conexión a tierra, etiquetar automáticamente el tráfico/imágenes de escena para conjuntos de datos de referencia o ejecutar la canalización image_referring_expression. Los activadores incluyen 'expresión de referencia', 'descripción de región', 'etiquetas KITTI', 'anotación de relación espacial', 'expresión de referencia de imagen de etiqueta automática', 'expresión_de_referencia_imagen'.
