Exécution de cluster GPU SLURM à distance sur SSH avec sbatch/srun, conteneurs Pyxis/Enroot et résultats soutenus par Lustre. À utiliser lors de l'exécution de tâches de formation/évaluation/inférence TAO sur un cluster sur site ou DGX SLURM. Les expressions de déclenchement incluent « exécuter sur SLURM », « soumettre un lot », « cluster DGX SLURM », « conteneur Pyxis/Enroot », « ensemble de données Lustre ».
