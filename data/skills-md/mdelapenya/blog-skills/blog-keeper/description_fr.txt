Vérifiez les liens internes, les références croisées et les teasers « à venir » sur tous les articles de blog de votre blog Hugo. Signale les liens rompus, les teasers non exécutés, les références de séries bidirectionnelles manquantes et vérifie éventuellement les URL externes. À utiliser lorsque l'utilisateur dit "vérifier les liens du blog", "auditer les articles", "trouver les liens brisés", "blog-keeper" ou "valider les références croisées". Lecture seule : ne modifie pas les fichiers.
