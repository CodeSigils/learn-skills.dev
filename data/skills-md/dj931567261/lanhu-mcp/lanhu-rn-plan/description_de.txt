Geben Sie die Detail-URL des Lanhu-Designdiagramms (einschließlich image_id) ein und verwenden Sie die lanhu MCP image_id, um eine präzise Linkausgabe eines React Native TSX-Seitenlayouts und -Stilentwurfs zu generieren. Anmerkungen dienen als Hauptpfad, Einheiten und Eckradien werden innerhalb des Skills vereinheitlicht, das Schema bietet nur bei Fehlern einen Fallback und Ressourcen werden einheitlich in src/assets/lanhu/<screen>/ gespeichert.
