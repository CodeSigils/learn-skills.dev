Geben Sie die Detail-URL des Lanhu-Designdiagramms (einschließlich image_id) ein und verwenden Sie die lanhu MCP image_id, um einen genauen Link zu generieren, der ein React Native TSX-Seitenlayout und einen Stilentwurf ausgibt. Anmerkungen dienen als primärer Pfad, Einheiten und Randradien sind innerhalb des Skills standardisiert, das Schema fungiert nur als Fallback bei Fehlern und Ressourcen werden einheitlich in src/assets/lanhu/<screen>/ gespeichert.
