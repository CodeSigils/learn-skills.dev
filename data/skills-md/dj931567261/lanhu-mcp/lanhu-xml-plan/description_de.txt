Geben Sie die Detail-URL der Lanhu-Designdatei (einschließlich image_id) ein und verwenden Sie die lanhu MCP image_id, um traditionelles Android-XML präzise zu generieren (Anmerkungen werden direkt in dp ausgegeben, Schema bietet nur einen Fallback bei Fehlern, drawable-nodpi wird einheitlich auf die Festplatte geschrieben; wenn die dp_xx-Basislinie fehlt, wird der vollständige Satz von sieben Dimen-Ressourcen automatisch aus den Skill-Assets ergänzt).
