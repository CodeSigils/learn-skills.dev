Entrez l'URL détaillée du fichier de conception Lanhu (y compris image_id) et utilisez l'image_id lanhu MCP pour générer avec précision du XML Android traditionnel (les annotations sont directement sorties dans dp, le schéma fournit uniquement une solution de repli en cas d'échec, drawable-nodpi est uniformément écrit sur le disque ; si la ligne de base dp_xx est manquante, l'ensemble complet des ressources à sept dimensions est automatiquement complété à partir des actifs de compétences).
