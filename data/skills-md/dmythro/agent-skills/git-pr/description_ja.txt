GitHub (gh) および GitLab (glab) の PR および MR ワークフロー。作成、レビューコメント処理、スレッド解決、レビュー状態クエリ、マージ、コストを意識したボットレビューラウンド (GitHub: Copilot、CodeRabbit)、および Copilot コードレビュー構成 (ルールセット、カスタム命令、請求)。 PR/MR の作成、レビュー フィードバックへの対応、スレッドの解決、ボット レビューのループ、承認の確認、PR データのクエリ、Copilot レビューの構成、または gh/glab 読み取り専用許可リストの構成を行うときに使用します。 git コミット (git-commit)、CI/CD ステータス (git-ci)、ローカルのプリプッシュ CodeRabbit CLI レビュー (coderabbit)、または一般的な git 操作には適用されません。
