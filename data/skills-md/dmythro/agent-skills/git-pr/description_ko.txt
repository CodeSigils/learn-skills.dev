GitHub(gh) 및 GitLab(glab)을 위한 PR 및 MR 워크플로우. 생성, 리뷰 코멘트 처리, 스레드 해결, 리뷰 상태 조회, 병합, 비용을 고려한 봇 리뷰 라운드(GitHub: Copilot, CodeRabbit) 및 Copilot 코드 리뷰 설정(룰셋, 사용자 지정 지시문, 청구). PR/MR을 만들 때, 리뷰 피드백을 다룰 때, 스레드를 해결할 때, 봇 리뷰를 반복할 때, 승인 여부를 확인할 때, PR 데이터를 조회할 때, Copilot 리뷰를 구성할 때 또는 gh/glab 읽기 전용 허용 목록을 설정할 때 사용. git 커밋(git-commit), CI/CD 상태(git-ci), 로컬 사전 푸시 CodeRabbit CLI 리뷰(coderabbit), 일반 git 작업에는 사용하지 않음.
