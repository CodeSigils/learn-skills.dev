سير عمل طلبات السحب (PR) وطلبات الدمج (MR) لـ GitHub (gh) وGitLab (glab). الإنشاء، معالجة تعليقات المراجعة، حل الخيوط، استعلامات حالة المراجعة، الدمج، جولات مراجعة الروبوت المدركة للتكلفة (GitHub: Copilot، CodeRabbit)، وتكوين مراجعة الكود باستخدام Copilot (قواعد، تعليمات مخصصة، الفوترة). استخدم عند إنشاء PRs/MRs، التعامل مع ملاحظات المراجعة، حل الخيوط، تكرار مراجعات الروبوت، التحقق من الموافقات، استعلام بيانات PR، تكوين مراجعات Copilot، أو تكوين قوائم السماح للقراءة فقط في gh/glab. ليس للاستخدام مع عمليات git commit (git-commit)، حالة CI/CD (git-ci)، مراجعات CodeRabbit CLI المحلية قبل الدفع (coderabbit)، أو عمليات git العامة.
