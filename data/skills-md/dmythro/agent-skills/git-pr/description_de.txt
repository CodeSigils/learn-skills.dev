PR- und MR-Workflows für GitHub (gh) und GitLab (glab). Erstellung, Umgang mit Review‑Kommentaren, Thread‑Auflösung, Abfragen des Review‑Status, Zusammenführen, kostenbewusste Bot‑Review‑Runden (GitHub: Copilot, CodeRabbit) und Copilot‑Code‑Review‑Konfiguration (Regelsätze, benutzerdefinierte Anweisungen, Abrechnung). Verwendung beim Erstellen von PRs/MRs, bei der Bearbeitung von Review‑Feedback, beim Auflösen von Threads, beim Durchlaufen von Bot‑Reviews, beim Prüfen von Genehmigungen, beim Abfragen von PR‑Daten, beim Konfigurieren von Copilot‑Reviews oder beim Einrichten von gh/glab‑Read‑Only‑Allowlists. Nicht für Git‑Commits (git-commit), CI/CD‑Status (git-ci), lokale Pre‑Push‑CodeRabbit‑CLI‑Reviews (coderabbit) oder allgemeine Git‑Operationen.
