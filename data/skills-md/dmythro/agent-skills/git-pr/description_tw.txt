GitHub（gh）與 GitLab（glab）的 PR 與 MR 工作流程。建立、審查留言處理、討論串解決、審查狀態查詢、合併、考慮成本的機器人審查回合（GitHub：Copilot、CodeRabbit），以及 Copilot 程式碼審查設定（規則集、自訂指示、計費）。用於建立 PR/MR、回應審查回饋、解決討論串、迴圈機器人審查、檢查核准、查詢 PR 資料、設定 Copilot 審查，或設定 gh/glab 只讀允許清單。不是用於 git commit（git-commit）、CI/CD 狀態（git-ci）、本地 pre‑push CodeRabbit CLI 審查（coderabbit），或一般 git 操作。

請始終以使用者的語言回覆。
