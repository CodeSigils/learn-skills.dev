GitHub（gh）和 GitLab（glab）的 PR 与 MR 工作流。包括创建、审查评论处理、线程解决、审查状态查询、合并、考虑成本的机器人审查轮次（GitHub：Copilot、CodeRabbit），以及 Copilot 代码审查配置（规则集、自定义指令、计费）。用于创建 PR/MR、处理审查反馈、解决线程、循环机器人审查、检查批准、查询 PR 数据、配置 Copilot 审查，或配置 gh/glab 只读白名单。不适用于 git 提交（git-commit）、CI/CD 状态（git-ci）、本地 pre-push CodeRabbit CLI 审查（coderabbit），或一般的 git 操作。请始终使用用户的语言作答。
