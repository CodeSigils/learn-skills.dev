Workflows PR et MR pour GitHub (gh) et GitLab (glab). Création, gestion des commentaires de révision, résolution des threads, révision des requêtes d'état, fusion, cycles de révision des robots tenant compte des coûts (GitHub : Copilot, CodeRabbit) et configuration de la révision du code Copilot (ensembles de règles, instructions personnalisées, facturation). À utiliser lors de la création de PR/MR, du traitement des commentaires sur les avis, de la résolution des fils de discussion, de la boucle des avis de robots, de la vérification des approbations, de l'interrogation des données de PR, de la configuration des avis Copilot ou de la configuration des listes autorisées gh/glab en lecture seule. Pas pour les commits git (git-commit), le statut CI/CD (git-ci), les revues CLI CodeRabbit pré-push locales (coderabbit) ou les opérations git générales
