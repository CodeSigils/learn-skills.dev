Рабочие процессы PR и MR для GitHub (gh) и GitLab (glab). Создание, обработка комментариев обзора, разрешение веток обсуждения, запросы состояния обзора, слияние, учитывающие стоимость раунды обзора ботами (GitHub: Copilot, CodeRabbit) и настройка обзора кода Copilot (правила, пользовательские инструкции, биллинг). Используется при создании PR/MR, обработке обратной связи обзора, разрешении веток обсуждения, повторных обзорах ботами, проверке одобрений, запросе данных PR, настройке обзоров Copilot или конфигурации allowlist только для чтения gh/glab. Не предназначено для git‑commit (git-commit), статуса CI/CD (git-ci), локальных пред‑push обзоров CodeRabbit CLI (coderabbit) или общих операций с git.
