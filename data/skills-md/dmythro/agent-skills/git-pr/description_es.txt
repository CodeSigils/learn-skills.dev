Flujos de trabajo de PR y MR para GitHub (gh) y GitLab (glab). Creación, manejo de comentarios de revisión, resolución de hilos, consultas del estado de la revisión, fusión, rondas de revisión de bots conscientes del costo (GitHub: Copilot, CodeRabbit) y configuración de revisiones de código con Copilot (conjuntos de reglas, instrucciones personalizadas, facturación). Úsalo al crear PRs/MRs, abordar comentarios de revisión, resolver hilos, iterar revisiones de bots, verificar aprobaciones, consultar datos de PR, configurar revisiones de Copilot o configurar listas blancas de solo lectura para gh/glab. No es para commits de git (git-commit), estado de CI/CD (git-ci), revisiones locales pre‑push de CodeRabbit CLI (coderabbit) o operaciones generales de git.
