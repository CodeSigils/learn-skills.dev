Configuración y administración de proyectos GitHub (v2) a través de gh CLI + GraphQL: organice los problemas de un repositorio en epopeyas con subproblemas nativos, impulse un flujo de estado del tablero (Todo -> En progreso -> Listo), establezca la Prioridad del proyecto, clasifique con tipos de problemas nativos (Tarea/Error/Función) en lugar de etiquetas, alcance el trabajo con hitos (incluida la resolución del "hito actual") y mantenga una hoja de ruta de Epic + Próximos. Úselo al configurar o administrar un proyecto/hoja de ruta de GitHub, crear una epopeya con problemas, agregar o mover problemas entre epopeyas, retomar o cerrar trabajo en el tablero, (re)priorizar, establecer tipos de problemas, crear o cerrar hitos, habilitar flujos de trabajo del proyecto o configurar listas de permitidos de solo lectura de proyectos gh. No para flujos de trabajo de relaciones públicas (git-pr), estado de CI/CD (git-ci) o mensajes de confirmación (git-commit)
