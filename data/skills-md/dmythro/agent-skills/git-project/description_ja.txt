gh CLI + GraphQL による GitHub プロジェクト (v2) のセットアップと管理: リポジトリの問題をネイティブのサブ問題を含むエピックに整理し、ボードのステータス フロー (Todo -> 進行中 -> 完了) を動かし、プロジェクトの優先度を設定し、ラベルではなくネイティブの問題タイプ (タスク/バグ/機能) で分類し、マイルストーンで作業の範囲を設定し (「現在のマイルストーン」の解決を含む)、エピックと今後のロードマップを維持します。 GitHub プロジェクト/ロードマップの設定または管理、課題を含むエピックの作成、エピック間での課題の追加または移動、ボード上の作業の選択または終了、優先順位付け (再) 、課題タイプの設定、マイルストーンの作成または終了、プロジェクト ワークフローの有効化、または gh プロジェクトの読み取り専用許可リストの構成を行うときに使用します。 PR ワークフロー (git-pr)、CI/CD ステータス (git-ci)、またはコミット メッセージ (git-commit) には適用されません。
