gh CLI + GraphQL을 통한 GitHub Projects(v2) 설정 및 관리: 레포지토리의 이슈를 네이티브 서브 이슈가 있는 에픽으로 구성하고, 보드 상태 흐름(Todo → In Progress → Done)을 운영하며, 프로젝트 우선순위를 설정하고, 라벨 대신 네이티브 이슈 유형(작업/버그/기능)으로 분류하고, 마일스톤(“현재 마일스톤” 해결 포함)으로 작업 범위를 지정하며, 에픽 및 향후 로드맵을 유지합니다. GitHub 프로젝트/로드맵을 설정하거나 관리할 때, 에픽을 이슈와 함께 만들고, 이슈를 에픽 간에 추가·이동하고, 보드에서 작업을 시작하거나 종료하며, (다시)우선순위를 조정하고, 이슈 유형을 설정하고, 마일스톤을 만들거나 종료하고, 프로젝트 워크플로를 활성화하거나 gh project 읽기 전용 허용 리스트를 구성할 때 사용합니다. PR 워크플로(git‑pr), CI/CD 상태(git‑ci), 커밋 메시지(git‑commit)에는 사용하지 마세요.
