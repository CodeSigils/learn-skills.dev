GitHub Projects (v2) Einrichtung und Verwaltung über gh CLI + GraphQL: Organisiere die Issues eines Repos in Epics mit nativen Unter‑Issues, steuere den Status‑Flow eines Boards (Todo → In Progress → Done), setze Projektpriorität, klassifiziere mit nativen Issue‑Typen (Task/Bug/Feature) anstelle von Labels, definiere den Arbeitsumfang mit Milestones (inkl. Auflösung des „aktuellen Milestones“) und pflege ein Epic‑ + Upcoming‑Roadmap. Verwenden, wenn du ein GitHub‑Projekt/Roadmap einrichtest oder verwaltest, ein Epic mit Issues erstellst, Issues zwischen Epics hinzufügst oder verschiebst, Arbeiten am Board aufnimmst oder schließt, (re)priorisierst, Issue‑Typen festlegst, Milestones erstellst oder schließt, Projekt‑Workflows aktivierst oder gh‑Project‑Read‑Only‑Allowlists konfigurierst. Nicht für PR‑Workflows (git-pr), CI/CD‑Status (git-ci) oder Commit‑Nachrichten (git-commit).
