Configurazione e gestione di GitHub Projects (v2) tramite gh CLI + GraphQL: organizza le issue di un repository in epic con sub‑issue native, gestisci il flusso di stato del tabellone (Todo → In Progress → Done), imposta la Priorità del Progetto, classifica con i tipi di issue nativi (Task/Bug/Feature) invece delle etichette, definisci il lavoro con le milestone (incl. la risoluzione della “milestone corrente”) e mantieni una roadmap Epic + Upcoming. Usalo quando imposti o gestisci un GitHub Project/roadmap, crei un epic con issue, aggiungi o sposti issue tra epic, prendi o chiudi lavoro sul tabellone, (ri)priorizzi, imposti i tipi di issue, crei o chiudi milestone, abiliti i flussi di lavoro del progetto o configuri le liste di autorizzazione in sola lettura per gh project. Non è destinato ai flussi di lavoro PR (git‑pr), allo stato CI/CD (git‑ci) o ai messaggi di commit (git‑commit).
