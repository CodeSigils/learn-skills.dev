Настройка и управление GitHub Projects (v2) через gh CLI + GraphQL: организация задач репозитория в эпики с помощью встроенных подзадач, управление потоком статусов доски (Todo → In Progress → Done), установка приоритета проекта, классификация с помощью нативных типов задач (Task/Bug/Feature) вместо меток, ограничение объёма работы вехами (включая разрешение «текущей вехи») и поддержка дорожной карты Epic + Upcoming. Используется при настройке или управлении проектом/дорожной картой GitHub, создании эпика с задачами, добавлении или перемещении задач между эпиками, взятии в работу или закрытии задач на доске, (пере)приоритизации, установке типов задач, создании или закрытии вех, включении рабочих процессов проекта или конфигурировании списков разрешённого только чтения для gh project. Не предназначено для рабочих процессов PR (git‑pr), статуса CI/CD (git‑ci) или сообщений коммитов (git‑commit).
