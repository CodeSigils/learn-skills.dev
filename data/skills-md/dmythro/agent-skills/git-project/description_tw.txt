GitHub Projects（v2）透過 gh CLI + GraphQL 進行設定與管理：將倉庫的 Issue 組織為具原生子 Issue 的史詩（Epic），推動看板狀態流程（Todo → In Progress → Done），設定專案優先順序，使用原生 Issue 類型（Task／Bug／Feature）而非標籤來分類，透過里程碑（包括解決「當前里程碑」）劃定工作範圍，並維護 Epic 與 Upcoming 路線圖。適用於設定或管理 GitHub 專案／路線圖、建立包含 Issue 的史詩、在史詩之間新增或移動 Issue、在看板上拾取或關閉工作、（重新）調整優先順序、設定 Issue 類型、建立或關閉里程碑、啟用專案工作流程，或配置 gh project 只讀允許名單的情境。不適用於 PR 工作流程（git‑pr）、CI/CD 狀態（git‑ci）或提交訊息（git‑commit）。
