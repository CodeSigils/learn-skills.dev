GitHub Projects (v2) الإعداد والإدارة عبر أداة gh CLI + GraphQL: تنظيم قضايا المستودع في ملحمات باستخدام القضايا الفرعية الأصلية، تشغيل تدفق حالة اللوحة (Todo → In Progress → Done)، تحديد أولوية المشروع، تصنيف القضايا باستخدام الأنواع الأصلية (Task / Bug / Feature) بدلاً من العلامات، تحديد نطاق العمل باستخدام المراحل (بما في ذلك حل "المرحلة الحالية")، وصيانة خريطة طريق للملحمة والملحمات القادمة. يُستخدم عند إعداد أو إدارة مشروع/خريطة طريق على GitHub، إنشاء ملحمة مع قضايا، إضافة أو نقل القضايا بين الملحمات، التقاط أو إغلاق العمل على اللوحة، (إعادة) تحديد الأولويات، تعيين أنواع القضايا، إنشاء أو إغلاق المراحل، تفعيل سير عمل المشروع، أو تكوين قوائم السماح للقراءة فقط لمشروع gh. لا يُستخدم لعمليات تدفق طلبات السحب (git-pr)، حالة CI/CD (git-ci)، أو رسائل الالتزام (git-commit).
