通过 gh CLI + GraphQL 设置和管理 GitHub Projects（v2）：将仓库的 Issue 组织为带有原生子 Issue 的史诗（Epic），驱动看板状态流（待办 → 正在进行 → 已完成），设定项目优先级，使用原生 Issue 类型（任务/缺陷/特性）而非标签进行分类，通过里程碑（包括解决“当前里程碑”）来划定工作范围，并维护史诗和即将到来的路线图。适用于设置或管理 GitHub 项目/路线图、创建包含 Issue 的史诗、在史诗之间添加或移动 Issue、在看板上接手或关闭工作、（重新）设定优先级、设置 Issue 类型、创建或关闭里程碑、启用项目工作流，或配置 gh 项目只读白名单的情形。不适用于 PR 工作流（git‑pr）、CI/CD 状态（git‑ci）或提交信息（git‑commit）。
