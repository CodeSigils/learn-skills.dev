Validez les mises à niveau des dépendances JavaScript/TypeScript après une mise à jour interactive ou manuelle. Établissez le véritable delta à partir de git, détectez les conflits homologues/moteurs/types, extrayez les modifications importantes, les migrations et les fonctionnalités adoptables des notes de version, évaluez les packages retenus ou apparemment inutilisés et exécutez des portes de vérification. Couvre le chignon, le npm, le pnpm et le fil. À utiliser lorsque les packages viennent d'être mis à niveau et doivent être validés, pour décider si un package retenu peut être déplacé, pour demander pourquoi une dépendance est présente ou pour vérifier les notes de version pour les modifications importantes et les étapes de migration. Pas pour choisir et appliquer les mises à niveau de manière autonome, pour l'utilisation de bun CLI (bun-cli) ou pour les écosystèmes de packages non JavaScript.
