対話型または手動更新後に JavaScript/TypeScript の依存関係のアップグレードを検証します。 git から実際の差分を確立し、ピア/エンジン/タイプの競合を検出し、リリース ノートから重大な変更、移行、採用可能な機能を抽出し、保留されているパッケージまたは未使用と思われるパッケージを評価し、検証ゲートを実行します。 bun、npm、pnpm、yarn をカバーします。パッケージがアップグレードされたばかりで検証が必要な場合、保留されたパッケージを移動できるかどうかを決定する場合、そもそも依存関係が存在する理由を尋ねる場合、または重大な変更や移行手順についてリリース ノートを確認する場合に使用します。自律的にアップグレードを選択して適用すること、bun CLI の使用 (bun-cli)、または非 JavaScript パッケージ エコシステムには対応しません。
