Validieren Sie JavaScript/TypeScript‑Abhängigkeits‑Upgrades nach einem interaktiven oder manuellen Update. Ermitteln Sie das tatsächliche Delta aus Git, erkennen Sie Peer‑/Engine‑/Typkonflikte, extrahieren Sie Breaking Changes, Migrationen und übernehmbare Funktionen aus den Release‑Notes, beurteilen Sie zurückgehaltene oder scheinbar ungenutzte Pakete und führen Sie Verifizierungsprüfungen durch. Unterstützt bun, npm, pnpm und yarn. Verwenden Sie es, wenn Pakete gerade aktualisiert wurden und geprüft werden müssen, wenn entschieden werden soll, ob ein zurückgehaltenes Paket verschoben werden kann, wenn gefragt wird, warum eine Abhängigkeit überhaupt vorhanden ist, oder wenn Release‑Notes auf Breaking Changes und Migrationsschritte geprüft werden. Nicht zum eigenständigen Auswählen und Anwenden von Upgrades, zur Nutzung der bun‑CLI (bun‑cli) oder für Nicht‑JavaScript‑Paketökosysteme.
