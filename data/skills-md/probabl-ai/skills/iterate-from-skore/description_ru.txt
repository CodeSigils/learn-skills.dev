Найдите следующее предложение по эксперименту ML, **прочитав дайджест аудита** по адресу `scratch/audit/<stem>/audit.md` (созданный `audit-ml-pipeline` в § 4 Record-Outcome). Для каждой строки в `## Checks сводки` дайджеста, чья `серьезность` равна `проблеме` или `совет`, следуйте `documentation_url` строки, чтобы составить черновую строку невыполненной работы, чьим `Item` является рекомендованным в документации мерой по снижению риска. `## Сводка показателей` обеспечивает контекст для абзаца сводки, написанного вручную, но не управляет строками невыполненной работы самостоятельно. Возвращает расширенные строки невыполненной работы + сводку из одного абзаца обратно в `iterate-ml-experiment`, который записывает строки в `JOURNAL.md` и повторно представляет меню источников, чтобы пользователь мог продвигать строку `B<N>`. Останавливается на «Журнал пополнен, сводка возвращена»; никогда не пишет заметки о проектировании для каждого эксперимента, никогда не выбирает «выигрышный» результат — пользователь выбирает через `B<N>`.
ТРИГГЕР, когда: `iterate-ml-experiment` выбирает стратегию поиска, а пользователь выбирает `score` из меню; пользователь говорит "создать отчет", "что видит оценка?", "заполнить отставание от диагностики"; предыдущий эксперимент завершен, и пользователь хочет преобразовать отчет в элементы невыполненной работы, требующие действий.
ПРОПУСТИТЬ, когда: предыдущий эксперимент еще не проводился (на диске нет дайджеста аудита); у пользователя есть конкретная идея моделирования (используйте `iterate-from-user`); задача — *механика* запуска/открытия отчета — маршрут к `evaluate-ml-pipeline`; пользователь хочет прочитать описательное описание одного конкретного раздела отчета (путем к `evaluate-ml-pipeline`).
КАК ИСПОЛЬЗОВАТЬ: прочитайте существующий дайджест `scratch/audit/<stem>/audit.md` в виде текста — НЕ открывайте заново проект score, НЕ вызывайте методы доступа `report.*`. Для каждой строки в разделе `## Сводка проверок`, чья серьезность равна `issue` или `tip`, следуйте `documentation_url` (через WebFetch) и нарисуйте одну строку невыполненной работы со ссылкой на `audit:<stem>:checks.<code>`. Дедупликация строк, уже находящихся в журнале `JOURNAL.md`, по цитированию источника. Верните строки-кандидаты + человеческое резюме из одного абзаца. Родительский навык записывает строки в JOURNAL.md и повторно отображает меню источников.
