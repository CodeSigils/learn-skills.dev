Pile Python avisée pour les travaux de science des données / ML : une bibliothèque par tâche, organisée en niveaux (obligatoire / choix de l'utilisateur / facultatif / transitif). SKILL.md est l'index ; Les fichiers `references/<library>.md` par bibliothèque ont une portée, "choisissez ceci quand" / "choisissez autre chose quand" et des appariements.
TRIGGER quand (l'un de ces éléments) : (1) **une importation de bibliothèque échoue** dans le domaine de cette pile — la réponse est l'installation, pas le remplacement (voir § "Dépendance manquante"); (2) **un choix de bibliothèque doit être fait** — explicitement (l'utilisateur demande « quelle bibliothèque pour X ? ») ou implicitement (le code est sur le point d'introduire une nouvelle dépendance, ou le projet est en cours d'échafaudage et la bibliothèque tabulaire n'a pas encore été sélectionnée) ; (3) démarrer un nouveau projet Python de science des données / ML ; (4) l'utilisateur ou le code actuel recherche un substitut en dehors de la pile (xgboost, lightgbm, black, isort, flake8, poetes, Hatch), ou atteint `mlflow` pour enregistrer les paramètres/métriques, ou pour `cross_val_score` + rapports manuscrits — redirection : suivi → API du projet `skore`, évaluation/rapport → classes de rapport `skore`, `mlflow` reste uniquement pour le service de modèle/le registre.
SKIP quand : le projet n’est pas Python ; le travail est web/backend/infra sans rapport avec la science des données ; la bibliothèque est déjà choisie et installée et la tâche est la mise en œuvre à l'intérieur (correction de bug, travail sur les fonctionnalités, refactorisation) sans nouvelle dépendance en jeu.
COMMENT UTILISER : **lisez ce SKILL.md de bout en bout avant de recommander ou d'installer quoi que ce soit** — la sélection à partir d'une seule entrée d'index masque le niveau (que la bibliothèque soit obligatoire, un choix de l'utilisateur, facultatif ou déjà présent de manière transitive) et les appariements, et les deux comptent. Lisez ensuite les `references/<library>.md` liés pour connaître la portée et les compromis de la bibliothèque choisie. Ne remplacez pas silencieusement une bibliothèque par une autre ; si aucune entrée ne convient, faites apparaître l'espace à l'utilisateur.
