Stack Python supponente per data science/lavoro ML: una libreria per lavoro, organizzata in livelli (obbligatorio/scelta dell'utente/facoltativo/transitivo). SKILL.md è l'indice; I file `references/<library>.md` per libreria contengono ambito, "scegli questo quando" / "scegli qualcos'altro quando" e gli accoppiamenti.
SI ATTIVA quando (uno di questi): (1) **un'importazione di libreria fallisce** nel dominio di questo stack — la risposta è installa, non sostituisci (vedi § "Dipendenza mancante"); (2) **deve essere fatta una scelta di libreria** - esplicitamente (l'utente chiede "quale libreria per X?") o implicitamente (il codice sta per introdurre una nuova dipendenza, oppure il progetto è in fase di impalcatura e la libreria tabulare non è stata ancora scelta); (3) avviare un nuovo progetto di scienza dei dati/ML Python; (4) l'utente o il codice corrente cerca un sostituto esterno allo stack (xgboost, lightgbm, black, isort, flake8, poetry, hatch), o cerca `mlflow` per registrare parametri/metriche, o `cross_val_score` + report scritti a mano — reindirizzamento: tracciamento → API del progetto `skore`, valutazione/report → classi di report `skore`, `mlflow` rimane solo per il servizio/registro del modello.
SALTA quando: il progetto non è Python; il lavoro è web/backend/infrastruttura non correlato alla scienza dei dati; la libreria è già scelta e installata e l'attività è l'implementazione al suo interno (correzione di bug, lavoro sulle funzionalità, refactoring) senza nuove dipendenze in gioco.
COME USARE: **leggi questo SKILL.md end-to-end prima di consigliare o installare qualsiasi cosa**: la selezione da una singola voce di indice nasconde il livello (se la libreria è obbligatoria, una scelta dell'utente, facoltativa o già transitivamente presente) e gli abbinamenti, ed entrambi contano. Quindi leggere i "riferimenti/<library>.md" collegati per l'ambito e i compromessi della libreria scelta. Non sostituire silenziosamente una biblioteca con un'altra; se nessuna voce si adatta, fai emergere lo spazio vuoto per l'utente.
