Pila de Python con opiniones para trabajos de ciencia de datos/ML: una biblioteca por trabajo, organizada en niveles (obligatorio/elección del usuario/opcional/transitivo). SKILL.md es el índice; Los archivos `referencias/<biblioteca>.md` por biblioteca tienen alcance, "elegir esto cuando" / "elegir otra cosa cuando" y emparejamientos.
DISPARAR cuando (cualquiera de estos): (1) **falla la importación de una biblioteca** en el dominio de esta pila; la respuesta es instalar, no sustituir (consulte § "Dependencia faltante"); (2) **se debe hacer una elección de biblioteca** — explícitamente (el usuario pregunta "¿qué biblioteca para X?") o implícitamente (el código está a punto de introducir una nueva dependencia, o el proyecto está siendo estructurado y la biblioteca tabular aún no ha sido seleccionada); (3) iniciar un nuevo proyecto de ciencia de datos/ML de Python; (4) el usuario o el código actual busca un sustituto fuera de la pila (xgboost, lightgbm, black, isort, flake8, poesía, hatch), o busca `mlflow` para registrar parámetros/métricas, o `cross_val_score` + informes escritos a mano - redireccionamiento: seguimiento → API del proyecto `skore`, evaluación/informes → clases de informes `skore`, `mlflow` permanece solo para servicio/registro de modelos.
SALTAR cuando: el proyecto no sea Python; el trabajo es web/backend/infra no relacionado con la ciencia de datos; la biblioteca ya está elegida e instalada y la tarea se implementa dentro de ella (corrección de errores, trabajo de funciones, refactorización) sin ninguna nueva dependencia en juego.
CÓMO UTILIZAR: **lea este SKILL.md de principio a fin antes de recomendar o instalar algo**: seleccionar de una sola entrada de índice oculta el nivel (si la biblioteca es obligatoria, una elección del usuario, opcional o ya presente transitivamente) y los emparejamientos, y ambos son importantes. Luego lea las `referencias/<biblioteca>.md` vinculadas para conocer el alcance y las compensaciones de la biblioteca elegida. No sustituyas silenciosamente una biblioteca por otra; Si no cabe ninguna entrada, muestre el espacio al usuario.
