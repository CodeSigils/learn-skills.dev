حزمة Python المُختارة لعلم البيانات / تعلم الآلة - مكتبة واحدة لكل وظيفة، منظمة في طبقات (إلزامية / اختيار المستخدم / اختياري / متعدٍ). SKILL.md هو الفهرس؛ تحتوي ملفات "references/<library>.md" لكل مكتبة على النطاق، "اختر هذا عندما" / "اختر شيئًا آخر عندما"، وعمليات الاقتران.
يتم تشغيله عند (أي مما يلي): (1) **فشل استيراد المكتبة** في مجال هذا المكدس - الإجابة هي التثبيت، وليس البديل (راجع الفقرة "التبعية المفقودة")؛ (2) **يجب اختيار المكتبة** — بشكل صريح (يسأل المستخدم "أي مكتبة لـ X؟") أو ضمنيًا (الكود على وشك تقديم تبعية جديدة، أو يتم دعم المشروع ولم يتم اختيار المكتبة الجدولية بعد)؛ (3) بدء مشروع جديد لعلم بيانات بايثون/تعلم الآلة؛ (4) يصل المستخدم أو الكود الحالي إلى بديل خارج المكدس (xgboost، وlightgbm، وblack، وisort، وflake8، وhair، وHatch)، أو يصل إلى `mlflow` لتسجيل المعلمات/المقاييس، أو لـ `cross_val_score` + التقارير المكتوبة بخط اليد - إعادة التوجيه: التتبع → `skore` Project API، التقييم / إعداد التقارير → فئات تقرير `skore`، يبقى `mlflow` فقط لخدمة النماذج/التسجيل.
تخطي عندما: المشروع ليس بيثون؛ العمل عبارة عن ويب/خلفية/أشعة تحت الحمراء لا علاقة له بعلم البيانات؛ تم بالفعل اختيار المكتبة وتثبيتها والمهمة هي التنفيذ بداخلها (إصلاح الأخطاء، عمل الميزات، إعادة البناء) مع عدم وجود تبعية جديدة قيد التشغيل.
كيفية الاستخدام: **اقرأ هذا SKILL.md من البداية إلى النهاية قبل التوصية بأي شيء أو تثبيته** - يؤدي الاختيار من إدخال فهرس واحد إلى إخفاء الطبقة (سواء كانت المكتبة إلزامية، أو اختيار المستخدم، أو اختيارية، أو موجودة بالفعل بشكل عابر) وعمليات الاقتران، وكلاهما مهم. ثم اقرأ المراجع/<library>.md المرتبطة لمعرفة نطاق المكتبة المختارة ومقايضاتها. لا تستبدل مكتبة بأخرى بصمت؛ إذا لم يكن هناك إدخال مناسب، قم بإظهار الفجوة للمستخدم.
