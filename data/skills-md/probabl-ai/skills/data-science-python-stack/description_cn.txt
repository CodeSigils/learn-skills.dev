用于数据科学/机器学习工作的固定 Python 堆栈——每个作业一个库，组织成层（强制/用户选择/可选/传递）。 SKILL.md 是索引；每个库的 `references/<library>.md` 文件包含范围、“何时选择这个”/“何时选择其他内容”以及配对。
当（其中任何一个）时触发：（1）在此堆栈的域中**库导入失败** - 答案是安装，而不是替换（请参阅§“缺少依赖项”）； (2) **必须做出库选择** — 显式（用户询问“X 的哪个库？”）或隐式（代码即将引入新的依赖项，或者项目正在搭建，但尚未选择表格库）； (3) 启动一个新的Python数据科学/机器学习项目； (4) 用户或当前代码到达堆栈外部的替代品（xgboost、lightgbm、black、isort、flake8、poetry、hatch），或者到达“mlflow”来记录参数/指标，或者“cross_val_score”+手写报告——重定向：跟踪→“skore”项目API，评估/报告→“skore”报告类，“mlflow”仅用于模型服务/注册。
跳过以下情况：该项目是非 Python 的；该工作是与数据科学无关的网络/后端/基础设施；该库已经选择并安装，任务正在其中实现（错误修复、功能工作、重构），没有新的依赖项在起作用。
如何使用：**在推荐或安装任何内容之前从头到尾阅读此 SKILL.md** - 从单个索引条目中进行选择会隐藏层（无论该库是强制性的、用户选择的、可选的还是已经传递存在）和配对，两者都很重要。然后阅读链接的“references/<library>.md”以了解所选库的范围和权衡。不要默默地用一个库替换另一个库；如果没有合适的入口，则向用户显示间隙。
