Единый источник достоверной информации о том, «какой менеджер среды Python используется в этом проекте и как мне установить с его помощью пакет?». Владеет таблицей обнаружения (pixi / uv / поэтика / люк / conda+mamba / pip+venv), командами установки / удаления / обновления для каждого менеджера и путем начальной загрузки, когда менеджер отсутствует (рекомендация по умолчанию: pixi). Останавливается на «команда установки была выполнена с правильным менеджером, и пакет можно импортировать».
ТРИГГЕР, когда (любое из этих событий): (1) **собирается установить/добавить/закрепить/обновить/удалить Python.
    package** — `pip install`, `pixi add`, `uv add`, `poetry add`,
    `conda install` и т.п. — под любой каркас;
(2) `data-science-python-stack` § «Отсутствующая зависимость» обнаружила
    отсутствие импорта и установка — следующий шаг;
(3) состояние остановки навыка рабочего процесса срабатывает при отсутствии
    зависимость (`build-ml-pipeline`, `evaluate-ml-pipeline`,
    `organize-ml-workspace`, `audit-ml-pipeline`);
(4) запуск нового проекта Python, но менеджер еще не назначен
    (загрузка с помощью pixi, если пользователь не выберет иное);
(5) `audit-ml-pipeline` (или другой потребитель только для агента) нуждается в
    **функция агента** (`ipython` + `pyright`), и это еще не так
    присутствует в манифесте проекта — см. § «Функции агента».

ПРОПУСКАТЬ, когда: проект не Python; команда установки/добавления предназначена для инструмента, отличного от Python (npm, Brew, apt, Cargo, Geme); зависимость уже установлена ​​и доступна для импорта; работа представляет собой чистое редактирование существующего исходного кода без каких-либо новых зависимостей.
КАК ИСПОЛЬЗОВАТЬ: **сначала определите, затем установите**. Прежде чем вводить любую команду установки, запустите таблицу § «Обнаружение» в корне проекта. Если менеджер не обнаружен, спросите пользователя перед загрузкой. Никогда не устанавливайте с другим менеджером, чем тот, который использует проект (например, никогда не используйте `pip install` в проект, управляемый pixi) — это создает расхождение в состоянии окружения, которое манифест не будет отслеживать. **Прочитайте блок «Условия остановки» и отправьте предполетный контрольный список в виде видимого текста в своем ответе — оба обязательны перед подачей какой-либо команды.**
