Possède le dossier `tests/` d'un espace de travail ML et la règle d'appariement entre une expérience et ses tests. Routeur léger : chaque catégorie de test a sa propre sous-compétence (`smoke-test-ml-pipeline` est la seule pour la v1 ; `regression-test-ml-pipeline` / `distribution-test-ml-pipeline` etc. branchez-vous en tant que frères et sœurs à mesure que l'espace de travail s'agrandit). Cette compétence place un dossier `tests/<category>/` vide, applique la règle d'appariement de tiges entre `tests/<category>/test_NN_<short_name>.py` et `experiments/NN_<short_name>.py`, et distribue à la sous-compétence correspondante lorsque l'utilisateur demande un test.
DÉCLENCHEMENT lorsque : une nouvelle note de conception vient d'être approuvée par `iterate-ml-experiment` et le test de correspondance doit être rédigé avant que l'expérience puisse être marquée comme terminée ; l'utilisateur demande "écrire le test de fumée pour `02`", "ajouter le test de régression", "avons-nous un test pour X ?" ; un script d'expérience a été édité et le test couplé doit être revu ; sur le point d'exécuter `pytest tests/` et l'un des tests appariés attendus est manquant.
SAUTER lorsque : la note de conception n'existe pas encore (route vers `iterate-ml-experiment` en premier) ; le test est destiné aux assistants internes du package et n'a aucun rapport avec une expérience spécifique (les tests unitaires réguliers sont en direct partout où la configuration « pytest » du projet les récupère – hors de portée ici) ; la question est *que signifie le résultat du test* plutôt que *le test devrait-il exister* (itinéraire vers la sous-compétence correspondante).
COMMENT UTILISER : cette compétence est un routeur. Lisez le tableau de répartition pour déterminer quelle sous-compétence possède la catégorie de test sur laquelle l'utilisateur demande, puis transmettez-la. N'écrivez pas vous-même le corps du test - cela appartient à la sous-compétence. Placez le fichier de test vide avec la tige correspondante et l'échafaudage pytest, puis confiez le contrôle.
