Владеет папкой `audit/`: один файл Python `# %%` (процент jupytext) на каждый эксперимент, выровненный 1:1 с `experiments/NN_<short_name>.py` и `journal/NN_<short_name>.md`, который загружает отчет об оценках эксперимента **только для чтения** и использует ячейки с пустым последним выражением, `__repr__` содержит сигнал аудита.   Агент выполняет файл аудита с помощью встроенного в процесс исполнителя (`audit-ml-pipeline/scripts/run_cells.py` — IPython `InteractiveShell.run_cell`), который передает уценочный дайджест стандартного вывода каждой ячейки + повтор последнего выражения в стандартный вывод (необязательно также в файл). Дайджест стимулирует повествовательную работу (обновление статуса + истории `JOURNAL.md`, дополнительные вопросы о прошлом эксперименте, сравнение перекрестных экспериментов). Останавливается на «audit/NN_*.py размещен, выполнен и дайджест доступен». Никогда не вызывает `score.evaluate(...)` или `project.put(...)`.

  ПЕРВЫЙ (заменяет щупы для извлечения показателей).
- Пользователь просит «проверить эксперимент 02», «покажите, как выглядит 03».
  нравится», «повторный аудит 04 по новому отчету».

  соответствующий файл аудита требует повторного выполнения.

  без запуска полного потока «итерации по баллам».

ПРОПУСТИТЬ, если: заметки по проекту еще не утверждены (перейдите к `iterate-ml-experiment`); эксперимент не проводился (нет отчета на диске); функция агента не установлена ​​(делегируйте `python-env-manager` § «Функция агента»); пользователь анализирует отчет для получения *следующего* эксперимента («итерация-из-оценки»); пользователь хочет изучить **необработанный набор данных**, а не отчет о результатах законченного выполнения («explore-ml-data» — аудит считывает отчет, а не данные).
КАК ИСПОЛЬЗОВАТЬ: убедитесь, что существует четырехсторонняя пара стеблей (утвержден `journal/NN_*.md` + `experiments/NN_*.py` + пройден дымовой тест + отчет под этим ключом в проекте), затем поместите `audit/NN_<short_name>.py` из `templates/audit.py`, заменив имя пакета + буквальный блок инициализации проекта, скопированный из `experiments/<stem>.py`.   Выполните с помощью встроенного средства запуска: `pixi run -e Agent Python .agents/skills/audit-ml-pipeline/scripts/run_cells.py Audit/<stem>.py`. **Прочитайте условия остановки и создайте предполетный контрольный список перед любой командой записи или оболочки.** Всегда вызывайте `python-api` для подписей символов оценки — никогда не записывайте их из памяти.
