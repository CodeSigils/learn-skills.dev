Объявите конвейер от источника данных к предиктору как **график Skrub DataOps** (а не как простой `sklearn.Pipeline`). Каждый шаг представляет собой либо функцию чистого Python (без сохранения состояния), подключенную через .skb.apply_func, либо совместимую со sklearn систему оценки (с сохранением состояния), подключенную через .skb.apply. Останавливается на заявленном объекте — без подгонки, разделения, настройки, сохранения или оценки.
ТРИГГЕР — любое из: — Написание или редактирование кода, объявляющего любое звено в цепочке.
  *источник данных → предиктор*: загрузчики, предварительная обработка, кодировщики/
  импьютеры/скалеры, этапы функций, объекты композиции
  (`Конвейер`, `ColumnTransformer`, скраб `tabular_pipeline`,
  `nn.Module`), или окончательный оценщик.
- Функция обработки данных на чистом Python, предназначенная для
  путь конвейера (очищает/выводит/изменяет форму) — независимо от того, завернут ли он
  через `FunctionTransformer`, `skrub.@deferred` / `skrub.var`,
  собственный подкласс BaseEstimator или просто вызванный в
  Путь обучения перед оценщиком.
- Шаг добавляется, удаляется, заменяется местами или переупорядочивается внутри
  существующая декларация трубопровода.
- В качестве используется пустой `sklearn.Pipeline`/`make_pipeline`.
  верхний уровень — огонь на перенаправление в граф DataOps-скраб.
- Пользователь просит построить/объявить/настроить конвейер/
  классификатор/регрессор для X.

ПРОПУСКАТЬ, когда: `.fit(...)` вызывает/циклы обучения/`Trainer.fit`/циклы эпох; разделение обучения/тестирования или разделение перекрестной проверки; поиск по гиперпараметру; постоянство (`joblib.dump`, контрольная точка); оценка/метрики/скоринг; вывод по предварительно обученной модели; чистая ЭДА; вопросы на выбор библиотеки без каких-либо конкретных заявлений.
