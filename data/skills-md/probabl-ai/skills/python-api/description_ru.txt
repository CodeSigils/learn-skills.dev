Сравните общедоступный API пакета Python с *установленной версией* и кэшируйте то, что стоит сохранить. Четыре фигуры по типам вопросов: (0) попадание в кэш под `scratch/api/<lib>/<version>/`; (1) `inspect.signature` + `pydoc.render_doc` для символа; (2) `dir` / `pkgutil.iter_modules` для поверхности модуля; (3) WebSearch + WebFetch версионных документов для повествования («как», «что», «что X возвращает, когда Y»). Никогда не записывайте символ из памяти обучающих данных — распознавание — это не поиск.
ТРИГГЕР — любое из: — О присвоении имени символу (функции/классу/методу/аргументу) в коде. - Пользователь спрашивает: «Какая подпись X?», «Что в модуле Y?»,
  «как мне позвонить X?», «какой из A/B мне использовать?».
- Пользователь спрашивает: «Что возвращает X, когда <условие>?» (Форма 3 — см.
  таблицу решений).
- Еще один навык рабочего процесса (`build-ml-pipeline`,
  `evaluate-ml-pipeline`, `iterate-from-score`,
  `smoke-test-ml-pipeline`) говорит: «Проконсультируйтесь с навыками API».
- Собираюсь извлечь из памяти «очевидный» образец библиотеки.
ПРОПУСТИТЕ, когда: подпись очевидна с сайта вызова, который вы только что прочитали в этом ходе; работа ведется только с файловой системой/оболочкой (без символов Python); файл кэша `scratch/api/<lib>/<version>/<topic>.md` уже отвечает на вопрос (все еще консультация по форме 0 — вы просто не получаете).
КАК ИСПОЛЬЗОВАТЬ: сначала определите версию пакета с помощью рабочего файла (`scratch/<ts>_version_<pkg>.py` с `import <pkg>; print(<pkg>.__version__)` — запустите с `pixi run python Scratch/<ts>_version_<pkg>.py`). Затем перечислите `scratch/api/<lib>/<version>/`. Затем выберите форму из поля «Какой вопрос?» стол. Нарративные результаты кэшируются обратно. **Все выполнение Python осуществляется через файлы `scratch/<ts>_*.py` — встроенный `python -c` запрещен независимо от длины.** Ориентация, специфичная для стека, находится в `references/stack_orientation.md` — загрузка по требованию.
