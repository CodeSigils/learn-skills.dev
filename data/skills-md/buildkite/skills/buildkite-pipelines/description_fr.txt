Cette compétence doit être utilisée lorsque l'utilisateur demande « d'écrire un pipeline », « d'ajouter une mise en cache », « de rendre cette construction plus rapide », « d'afficher les échecs de test dans la page de construction », « d'ajouter des annotations », « d'exécuter des tests uniquement lorsque le code change », « configurer des pipelines dynamiques », « ajouter une nouvelle tentative », « étapes parallèles », « construction de matrice », « ajouter des plugins » ou « travailler avec des artefacts dans le pipeline YAML ». À utiliser également lorsque l'utilisateur mentionne le répertoire .buildkite/, pipeline.yml, le téléchargement du pipeline buildkite-agent, les types d'étapes (commande, attente, bloc, déclencheur, groupe, entrée), if_changed, notify, simultanéité ou pose des questions sur la configuration de Buildkite CI.
