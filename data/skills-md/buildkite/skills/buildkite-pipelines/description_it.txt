Questa abilità dovrebbe essere utilizzata quando l'utente chiede di "scrivere una pipeline", "aggiungere la memorizzazione nella cache", "rendere questa build più veloce", "mostrare gli errori dei test nella pagina di build", "aggiungere annotazioni", "eseguire test solo quando il codice cambia", "impostare pipeline dinamiche", "aggiungere nuovi tentativi", "passaggi paralleli", "build a matrice", "aggiungere plug-in" o "lavorare con artefatti nella pipeline YAML". Da utilizzare anche quando l'utente menziona la directory .buildkite/, pipeline.yml, il caricamento della pipeline buildkite-agent, i tipi di passaggi (comando, attesa, blocco, trigger, gruppo, input), if_changed, notifica, concorrenza o chiede informazioni sulla configurazione CI Buildkite.
