Cette compétence doit être utilisée lorsque l'utilisateur demande de « déclencher une build », « vérifier l'état de la build », « regarder une build », « afficher les journaux de build », « réessayer une build », « annuler une build », « lister les builds », « télécharger des artefacts », « télécharger des artefacts », « gérer les secrets », « créer un pipeline », « lister les pipelines » ou « interagir avec Buildkite à partir de la ligne de commande ». À utiliser également lorsque l'utilisateur mentionne les commandes bk, bk build, bk job, bk pipeline, bk secret, bk artefact, bk cluster, bk package, bk auth, bk configure, bk use, bk init, bk api, ou pose des questions sur l'installation de Buildkite CLI, les workflows Buildkite basés sur un terminal ou les opérations CI/CD en ligne de commande.
