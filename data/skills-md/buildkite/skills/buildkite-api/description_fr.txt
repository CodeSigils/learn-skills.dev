À utiliser également lorsque l'utilisateur mentionne api.buildkite.com, graphql.buildkite.com, les points de terminaison Buildkite REST, les mutations GraphQL, les charges utiles de webhook, les jetons API ou pose des questions sur l'accès par programme aux données Buildkite.
