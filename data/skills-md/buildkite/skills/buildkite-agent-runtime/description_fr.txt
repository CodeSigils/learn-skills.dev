Cette compétence doit être utilisée lorsque l'utilisateur demande « ajouter une annotation », « télécharger des artefacts d'une étape », « partager des données entre les étapes », « télécharger un pipeline de manière dynamique », « demander un jeton OIDC à l'intérieur d'une étape », « acquérir un verrou distribué », « obtenir ou mettre à jour un attribut d'étape », « rédiger un secret à partir des journaux », « récupérer un secret de cluster au moment de l'exécution » ou « déboguer les variables d'environnement dans les hooks ». À utiliser également lorsque l'utilisateur mentionne buildkite-agent annotate, buildkite-agent artefact upload/download, buildkite-agent meta-data set/get, buildkite-agent pipeline upload, buildkite-agent oidc request-token, buildkite-agent step, buildkite-agent lock, buildkite-agent env, buildkite-agent secret get, buildkite-agent redactor add, buildkite-agent tool sign/verify, ou tout autre Sous-commande buildkite-agent utilisée dans une étape de travail en cours d'exécution.
