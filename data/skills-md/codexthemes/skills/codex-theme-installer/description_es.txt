Descargue un tema de Codex publicado desde codexthemes.ai e instale sus archivos fuente en la biblioteca de temas local ~/.codexthemes, de forma anónima dentro de una cuota gratuita o con una clave API de CodexThemes para límites más altos. Úselo cuando un usuario solicita instalar, descargar, obtener o probar un tema de CodexThemes, nombra una URL de tema de codexthemes.ai o una identificación de tema para instalar, o alcanza un límite de velocidad de descarga y necesita guía de clave API.
