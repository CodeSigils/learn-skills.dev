公開された Codex テーマを codexthemes.ai からダウンロードし、そのソース ファイルをローカルの ~/.codexthemes テーマ ライブラリに無料の割り当て内で匿名でインストールするか、より高い制限の場合は CodexThemes API キーを使用してインストールします。ユーザーが CodexThemes からテーマをインストール、ダウンロード、取得、または試用するよう要求する場合、インストールする codexthemes.ai テーマ URL またはテーマ ID を指定する場合、またはダウンロード速度制限に達して API キーのガイダンスが必要な場合に使用します。
