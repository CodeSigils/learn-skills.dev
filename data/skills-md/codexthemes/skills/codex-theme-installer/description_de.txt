Laden Sie ein veröffentlichtes Codex-Theme von codexthemes.ai herunter und installieren Sie seine Quelldateien in der lokalen ~/.codexthemes-Themenbibliothek, anonym im Rahmen eines kostenlosen Kontingents oder mit einem CodexThemes-API-Schlüssel für höhere Limits. Verwenden Sie diese Option, wenn ein Benutzer ein Theme von CodexThemes installieren, herunterladen, herunterladen oder ausprobieren möchte, eine codexthemes.ai-Theme-URL oder eine Theme-ID zur Installation benennt oder eine Download-Ratenbegrenzung erreicht und eine API-Schlüsselanleitung benötigt.
