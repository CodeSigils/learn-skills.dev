قم بتنزيل سمة Codex منشورة من codexthemes.ai وقم بتثبيت ملفات المصدر الخاصة بها في مكتبة سمات ~/.codexthemes المحلية، بشكل مجهول ضمن حصة مجانية أو باستخدام مفتاح CodexThemes API لحدود أعلى. يُستخدم عندما يطلب المستخدم تثبيت سمة أو تنزيلها أو الحصول عليها أو تجربتها من CodexThemes، أو تسمية عنوان URL لموضوع codexthemes.ai أو معرف السمة لتثبيته، أو الوصول إلى حد معدل التنزيل ويحتاج إلى توجيه مفتاح واجهة برمجة التطبيقات.
