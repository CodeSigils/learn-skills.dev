Envíe un archivo .codex-theme empaquetado o una muestra de tema vinculada (skin) a CodexThemes a través de la API de envío autenticada de codexthemes.ai. Úselo cuando un usuario solicita enviar, publicar, cargar o compartir un tema de Codex en codexthemes.ai, comparte una URL de un tema para incluirlo en el directorio, solicita configurar o verificar una clave API de CodexThemes o tiene un paquete de tema .codex exportado listo para enviar.
