Invia un file di tema .codex in pacchetto o una vetrina di temi collegata (skin) a CodexThemes tramite l'API di invio codexthemes.ai autenticata. Da utilizzare quando un utente chiede di inviare, pubblicare, caricare o condividere un tema Codex su codexthemes.ai, condivide un URL di un tema da elencare nella directory, chiede di configurare o controllare una chiave API CodexThemes o ha un pacchetto di temi .codex esportato pronto per l'invio.
