Отправьте упакованный файл .codex-theme или связанную демонстрацию темы (оболочку) в CodexThemes через аутентифицированный API отправки codexthemes.ai. Используйте, когда пользователь просит отправить, опубликовать, загрузить или поделиться темой Кодекса на codexthemes.ai, делится URL-адресом темы для размещения в каталоге, просит настроить или проверить ключ API CodexThemes или имеет экспортированный пакет .codex-theme, готовый к отправке.
