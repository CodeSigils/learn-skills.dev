Soumettez un fichier .codex-theme packagé ou une vitrine de thème lié (skin) à CodexThemes via l'API de soumission authentifiée codexthemes.ai. À utiliser lorsqu'un utilisateur demande à soumettre, publier, télécharger ou partager un thème Codex sur codexthemes.ai, partage l'URL d'un thème à répertorier dans le répertoire, demande à configurer ou à vérifier une clé API CodexThemes, ou dispose d'un package de thème .codex exporté prêt à être soumis.
