Trade API を介してアプリがルーティングする取引でビルダー定義の料金を収集することで、DFlow 統合を収益化します。これは、「platformFeeBps」を介した固定パーセンテージ (スポット + PM)、または「platformFeeScale」を介した確率加重動的手数料 (PM 結果トークンのみ) のいずれかです。ユーザーが「取引の一部を受け取るにはどうすればよいですか?」、「ビルダー手数料を追加します」、「スワップ UI を収益化します」、「プラットフォーム手数料を請求します」、「platformFeeBps / platformFeeScale はどのように機能しますか?」、または「手数料はどこで支払われますか?」と尋ねる場合に使用します。取引自体を実行するために使用しないでください (「dflow-spot-trading」または「dflow-kalshi-trading」を使用してください。どちらも優先手数料とスポンサー/ガスレス フローもカバーします)。
