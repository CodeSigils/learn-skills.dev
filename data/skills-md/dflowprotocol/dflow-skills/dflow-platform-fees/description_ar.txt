يمكنك تحقيق الدخل من تكامل DFlow من خلال جمع رسوم يحددها المنشئ على الصفقات التي يوجهها تطبيقك من خلال Trade API - إما نسبة مئوية ثابتة (فورية + PM) عبر "platformFeeBps"، أو رسوم ديناميكية مرجحة بالاحتمال (الرموز المميزة لنتائج PM فقط) عبر "platformFeeScale". يُستخدم عندما يسأل المستخدم "كيف يمكنني الحصول على جزء من الصفقات؟"، أو "أضف رسوم إنشاء"، أو "استثمار واجهة مستخدم المبادلة الخاصة بي"، أو "تحصيل رسوم النظام الأساسي"، أو "كيف يعمل النظام الأساسي FeeBps / النظام الأساسي FeeScale؟"، أو "أين يتم دفع الرسوم الخاصة بي؟". لا تستخدمه لتشغيل التداول نفسه (استخدم "dflow-spot-trading" أو "dflow-kalshi-trading" - وكلاهما يغطي أيضًا رسوم الأولوية والتدفقات المدعومة/غير الغازية).
