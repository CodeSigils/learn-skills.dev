Монетизируйте интеграцию DFlow, собирая определенную сборку за сделки, маршруты вашего приложения через Trade API — либо фиксированный процент (спот + PM) через «platformFeeBps», либо взвешенную по вероятности динамическую комиссию (только токены результатов PM) через «platformFeeScale». Используйте, когда пользователь спрашивает: «Как мне получить часть сделок?», «Добавить комиссию строителя», «Монетизировать мой интерфейс обмена», «Взимать комиссию за платформу», «Как работает платформаFeeBps/platformFeeScale?» или «Где выплачиваются мои комиссии?». НЕ используйте для запуска самой сделки (используйте dflow-spot-trading или dflow-kalshi-trading — оба также охватывают приоритетные комиссии и спонсируемые/безгазовые потоки).
