Monetarisieren Sie eine DFlow-Integration, indem Sie eine vom Builder definierte Gebühr für Trades erheben, die Ihre App über die Trade API weiterleitet – entweder einen festen Prozentsatz (Spot + PM) über „platformFeeBps“ oder eine wahrscheinlichkeitsgewichtete dynamische Gebühr (nur PM-Ergebnis-Tokens) über „platformFeeScale“. Wird verwendet, wenn der Benutzer fragt: „Wie nehme ich einen Anteil an Trades entgegen?“, „Füge eine Builder-Gebühr hinzu“, „monetarisiere meine Swap-Benutzeroberfläche“, „erhebe eine Plattformgebühr“, „Wie funktioniert platformFeeBps/platformFeeScale?“ oder „Wo werden meine Gebühren bezahlt?“. Verwenden Sie es NICHT, um einen Handel selbst durchzuführen (verwenden Sie „dflow-spot-trading“ oder „dflow-kalshi-trading“ – beide decken auch Prioritätsgebühren und gesponserte/gaslose Flüsse ab).
