قم بإنشاء مقترحات استثمارية شاملة تغطي تحديد المخاطر، وتوصية المحفظة النموذجية، وتوضيح الرسوم، والتوقعات، ومراجعة الامتثال. يُستخدم عندما يسأل المستخدم عن إنشاء اقتراح لأحد العملاء المحتملين، أو تعيين درجات استبيان المخاطر إلى نماذج المحافظ، أو إنشاء الرسوم التوضيحية للرسوم مع التكاليف المتدرجة، أو إنتاج توقعات مونت كارلو أو السيناريوهات، أو تحليل المحفظة الحالية للعميل المحتمل للحصول على فرص التحسين، أو مراجعة المقترحات الخاصة بالامتثال لقواعد التسويق الخاصة بهيئة الأوراق المالية والبورصات، أو تصميم قوالب المقترحات لشركة متعددة المستشارين. يتم تشغيله أيضًا عندما يذكر المستخدمون "اقتراح الاستثمار"، أو "إنشاء الاقتراح"، أو "توصيف المخاطر"، أو "تحليل المخاطر"، أو "النيتروجين"، أو "توضيح الرسوم"، أو "تحليل التحول"، أو "المحفظة الحالية مقابل المحفظة المقترحة"، أو "مراجعة امتثال الاقتراح".
