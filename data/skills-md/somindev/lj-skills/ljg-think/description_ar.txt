سهم تتبع الجذر – أداة للتفكير الرأسي العميق. بالنظر إلى وجهة نظر أو ظاهرة أو مشكلة، انتقل للأسفل كالسهم وصولاً إلى جوهرها غير القابل للتجزئة. يُستخدم عندما يقول المستخدم "想透" أو "追本" أو "本质是什么" أو "为什么会这样" أو "深挖" أو "钻到底" أو "فكر بعمق" أو "التنقل لأسفل"، أو عندما يريد تتبع أي فكرة/ظاهرة عموديًا إلى جذرها غير القابل للاختزال. يتم تشغيله أيضًا عندما يقدم المستخدم بيانًا ويريد تحليلًا متعمقًا، وليس مسحًا شاملاً.

يرجى الرد دائمًا بلغة المستخدم.
