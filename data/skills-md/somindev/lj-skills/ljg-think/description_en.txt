The Arrow of Tracing to the Root — a vertical deep‑drilling thinking tool. Given a viewpoint, phenomenon, or problem, drill down like an arrow all the way to an indivisible essence. Use when the user says “想透” (“think through”), “追本” (“trace to the root”), “本质是什么” (“what is the essence”), “为什么会这样” (“why is it like this”), “深挖” (“dig deep”), “钻到底” (“drill to the bottom”), “think deep”, “drill down”, or wants to trace any idea/phenomenon vertically to its irreducible root. Also trigger when the user provides a statement and wants depth analysis, not breadth survey.

Please always respond in the user's language.
