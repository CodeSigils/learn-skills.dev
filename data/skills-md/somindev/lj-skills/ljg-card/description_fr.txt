Lanceur de contenu (铸). Transforme le contenu en visuels PNG. Sept moules : -l (par défaut) carte de lecture longue, -i infographie, -m cartes de lecture multi-cartes (1080x1440), -v note de croquis éditorial (problème → échec → pivot → aperçu → dénomination, mise en page magazine + archive), -c bande dessinée (style manga N&B), -w tableau blanc (disposition du tableau de style marqueur), -b carte de pièce jointe à grandes polices (1080 x 1440, patinée). style 碑刻 pour 小红书). Sortie vers ~/Téléchargements/. À utiliser lorsque l'utilisateur dit '铸', 'cast', '做成图', '做成卡片', '做成信息图', '做成海报', '视觉笔记', 'sketchnote', '杂志', 'éditorial', '漫画', 'bande dessinée', 'manga', '白板', 'tableau blanc', '大字', '附件图', 'grosses polices', '小红书卡片'. Remplace les cartes ljg et ljg-infograph.
