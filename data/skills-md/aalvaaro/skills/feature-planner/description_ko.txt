Notion에서 사양 템플릿을 가져와서 사용자에게 단계별로 작성하는 과정을 안내하고, Claude Code에 붙여넣을 준비가 된 새 Notion 페이지로 완성된 기능 사양을 생성하는 대화형 기능 계획 도우미입니다. 사용자가 새 기능을 계획하고, 새 페이지나 화면을 시작하고, UI를 지정하고, 기능 개요를 작성하거나 "기능을 계획하자", "새 기능 사양", "새로운 것을 만들고 싶습니다", "이것을 사양하는 데 도움을 주세요", "기능 계획 만들기", "...에 대한 프런트엔드 계획", "새 프로젝트 시작", "새 앱 발판" 또는 "...에 대한 아이디어가 있습니다"와 같은 말을 할 때마다 이 기술을 사용하세요. 또한 사용자가 기능 사양 템플릿을 참조하거나 Claude Code에 대한 사양을 작성하고 싶다고 언급하는 경우에도 트리거됩니다. 이 기술은 새로운 프로젝트이든 기존 앱의 기능이든 아이디어 → Notion 사양 → Claude Code 구현으로 이동하는 사용자의 워크플로에 매우 중요합니다.
