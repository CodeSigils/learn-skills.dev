Asistente de planificación de funciones interactivo que extrae una plantilla de especificaciones de Notion, guía al usuario para completarla paso a paso y crea una especificación de funciones completa como una nueva página de Notion lista para pegar en Claude Code. Utilice esta habilidad siempre que el usuario quiera planificar una nueva función, iniciar una nueva página o pantalla, especificar una interfaz de usuario, crear un resumen de funciones o decir cosas como "planifiquemos una función", "nuevas especificaciones de funciones", "Quiero crear algo nuevo", "ayúdenme a especificar esto", "creemos un plan de funciones", "planifiquemos la interfaz para...", "iniciar un nuevo proyecto", "desarrollar una nueva aplicación" o "Tengo una idea para...". También se activa cuando el usuario hace referencia a la plantilla de especificaciones de funciones o menciona que desea completar una especificación para Claude Code. Esta habilidad es fundamental para el flujo de trabajo del usuario al pasar de idea → Especificación de noción → implementación de Claude Code, ya sea un proyecto nuevo o una función para una aplicación existente.
