مساعد تخطيط الميزات التفاعلي الذي يسحب قالب المواصفات من Notion، ويرشد المستخدم خلال ملئه خطوة بخطوة، وينشئ مواصفات ميزة مكتملة كصفحة Notion جديدة جاهزة للصقه في Claude Code. استخدم هذه المهارة عندما يريد المستخدم تخطيط ميزة جديدة، أو بدء صفحة أو شاشة جديدة، أو تحديد واجهة مستخدم، أو إنشاء ملخص ميزة، أو قول أشياء مثل "دعونا نخطط لميزة"، أو "مواصفات ميزة جديدة"، أو "أريد إنشاء شيء جديد"، أو "ساعدني في تحديد ذلك"، أو "إنشاء خطة ميزات"، أو "تخطيط الواجهة الأمامية لـ..."، أو "بدء مشروع جديد"، أو "دعم تطبيق جديد"، أو "لدي فكرة عن...". يتم تشغيله أيضًا عندما يشير المستخدم إلى قالب مواصفات الميزات أو يذكر رغبته في ملء مواصفات Claude Code. تعتبر هذه المهارة بالغة الأهمية لسير عمل المستخدم للانتقال من الفكرة ← مواصفات الفكرة ← تنفيذ Claude Code، سواء كان مشروعًا جديدًا تمامًا أو ميزة لتطبيق موجود.
