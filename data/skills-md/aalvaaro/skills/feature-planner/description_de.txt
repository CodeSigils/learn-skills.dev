Interaktiver Feature-Planungsassistent, der eine Spezifikationsvorlage aus Notion abruft, den Benutzer Schritt für Schritt durch das Ausfüllen führt und eine fertige Feature-Spezifikation als neue Notion-Seite erstellt, die zum Einfügen in Claude Code bereit ist. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine neue Funktion planen, eine neue Seite oder einen neuen Bildschirm starten, eine Benutzeroberfläche spezifizieren, eine Funktionsbeschreibung erstellen oder Dinge sagen möchte wie „Planen wir eine Funktion“, „neue Funktionsspezifikation“, „Ich möchte etwas Neues erstellen“, „Helfen Sie mir dabei, dies zu spezifizieren“, „Erstellen Sie einen Funktionsplan“, „planen Sie das Frontend für ...“, „starten Sie ein neues Projekt“, „bauen Sie eine neue App auf“ oder „Ich habe eine Idee für ...“. Wird auch ausgelöst, wenn der Benutzer auf die Feature-Spec-Vorlage verweist oder erwähnt, dass er eine Spezifikation für Claude Code ausfüllen möchte. Diese Fähigkeit ist entscheidend für den Arbeitsablauf des Benutzers von der Idee → Konzeptspezifikation → Claude-Code-Implementierung, unabhängig davon, ob es sich um ein brandneues Projekt oder eine Funktion für eine vorhandene App handelt.
