Интерактивный помощник по планированию функций, который извлекает шаблон спецификации из Notion, помогает пользователю шаг за шагом его заполнять и создает завершенную спецификацию функции в виде новой страницы Notion, готовой для вставки в Claude Code. Используйте этот навык всякий раз, когда пользователь хочет спланировать новую функцию, запустить новую страницу или экран, описать пользовательский интерфейс, создать краткое описание функции или сказать что-то вроде «давайте спланируем функцию», «новая спецификация функции», «Я хочу создать что-то новое», «помогите мне описать это», «создай план функции», «запланируйте интерфейс для...», «начните новый проект», «подготовьте новое приложение» или «У меня есть идея для...». Также срабатывает, когда пользователь ссылается на шаблон спецификации функций или упоминает о желании заполнить спецификацию для Claude Code. Этот навык имеет решающее значение для рабочего процесса пользователя от идеи → спецификации понятия → реализации кода Claude, будь то совершенно новый проект или функция существующего приложения.
