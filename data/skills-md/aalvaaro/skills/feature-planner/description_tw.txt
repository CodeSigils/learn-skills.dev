互動式功能規劃助手，從 Notion 中提取規範模板，引導使用者逐步填寫，並創建一個完整的功能規格作為新的 Notion 頁面，準備貼上到 Claude Code 中。每當使用者想要規劃新功能、啟動新頁面或畫面、指定 UI、建立功能簡介或說出諸如「讓我們規劃一個功能」、「新功能規格」、「我想建立一些新東西」、「幫我指定這個」、「建立功能計畫」、「規劃前端......」、「開始一個新專案」、「建立一個新應用程式」或「我有一個想法...」就可以使用此技能。當使用者引用功能規範範本或提及想要填寫 Claude Code 的規範時也會觸發。這項技能對於使用者從想法 → 概念規範 → 克勞德程式碼實現的工作流程至關重要，無論是全新的專案還是現有應用程式的功能。
