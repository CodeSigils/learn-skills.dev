Initialisieren Sie ein neues Projekt mit dem Rails-ai-kit-Starterkit. Klont das Repo, erstellt ein neues GitHub-Repository, ordnet Git-Remotes neu zu (Origin → neues Projekt, Upstream → Rails-AI-Kit), führt bin/setup aus und überprüft den Start der App. Verwenden Sie diesen Skill, wenn der Benutzer Dinge sagt wie: „Neues Rails-AI-Kit-Projekt starten“, „Eine neue App aus Rails-AI-Kit erstellen“, „Neues Projekt aus dem Kit erstellen“, „Rails-AI-Kit für ... initialisieren“, „Neues Projekt namens ...“, „Rails-AI-Kit klonen als ...“ oder eine neue Rails + React + Inertia-App aus dem Starter-Kit booten möchte.
