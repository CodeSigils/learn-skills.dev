Инициализируйте новый проект из стартового набора рельсов-ai-kit. Клонирует репозиторий, создает новый репозиторий GitHub, переназначает удаленные устройства git (origin → new project, upstream →rails-ai-kit), запускает bin/setup и проверяет загрузку приложения. Используйте этот навык, когда пользователь говорит такие вещи, как: «начать новый проект Rails-ai-kit», «создать новое приложение из рельсов-ai-kit», «создать новый проект из набора», «инициализировать Rails-ai-kit для...», «новый проект под названием...», «клонировать Rails-ai-kit как...» или хочет загрузить новое приложение Rails + React + Inertia из стартового набора.
