Inicialice un nuevo proyecto desde el kit de inicio Rails-ai-kit. Clona el repositorio, crea un nuevo repositorio de GitHub, reasigna controles remotos de git (origen → nuevo proyecto, aguas arriba → rails-ai-kit), ejecuta bin/setup y verifica el inicio de la aplicación. Utilice esta habilidad cuando el usuario diga cosas como: "iniciar un nuevo proyecto de Rails-ai-kit", "desarrollar una nueva aplicación desde Rails-ai-kit", "crear un nuevo proyecto a partir del kit", "iniciar Rails-ai-kit para...", "nuevo proyecto llamado...", "clonar Rails-ai-kit como...", o quiere iniciar una nueva aplicación Rails + React + Inertia desde el kit de inicio.
