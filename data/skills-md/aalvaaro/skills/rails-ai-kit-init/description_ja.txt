Rails-ai-kit スターター キットから新しいプロジェクトを初期化します。リポジトリのクローンを作成し、新しい GitHub リポジトリを作成し、git リモートを再マップし (オリジン→新しいプロジェクト、アップストリーム→rails-ai-kit)、bin/setup を実行して、アプリの起動を確認します。このスキルは、ユーザーが「新しい Rails-ai-kit プロジェクトを開始する」、「rails-ai-kit から新しいアプリをスキャフォールディングする」、「キットから新しいプロジェクトを作成する」、「rails-ai-kit for... を初期化する」、「... という名前の新しいプロジェクト」、「rails-ai-kit を... としてクローンする」などのことを言った場合、またはスターター キットから新しい Rails + React + Inertia アプリをブートストラップしたい場合に使用します。
