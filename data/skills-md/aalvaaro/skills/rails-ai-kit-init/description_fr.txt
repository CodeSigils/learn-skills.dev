Initialisez un nouveau projet à partir du kit de démarrage rails-ai-kit. Clone le dépôt, crée un nouveau référentiel GitHub, remappe les télécommandes git (origine → nouveau projet, en amont → rails-ai-kit), exécute bin/setup et vérifie le démarrage de l'application. Utilisez cette compétence lorsque l'utilisateur dit des choses telles que : "démarrer un nouveau projet rails-ai-kit", "échafauder une nouvelle application à partir de rails-ai-kit", "créer un nouveau projet à partir du kit", "initialiser rails-ai-kit pour...", "nouveau projet appelé...", "cloner rails-ai-kit en tant que..." ou souhaite démarrer une nouvelle application Rails + React + Inertia à partir du kit de démarrage.
