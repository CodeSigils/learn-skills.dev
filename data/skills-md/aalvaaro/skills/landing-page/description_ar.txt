منشئ الصفحات المقصودة المبني على الأبحاث. يسحب البيانات من وسائل التواصل الاجتماعي ومواقع الويب وخرائط Google ويوتيوب والمنتديات والسيرة الذاتية اختياريًا لإنشاء ملف تعريف كامل للشركة أو الشخص. يقوم بتحليل البيانات كمسوق لاستخراج المزايا التنافسية، ودعائم القيمة، ورؤى الجمهور، وصوت العلامة التجارية. ثم يقوم بإنشاء صفحة مقصودة جذابة تحتوي على صور تم إنشاؤها بواسطة الذكاء الاصطناعي ومصممة خصيصًا للجمهور. استخدم هذه المهارة عندما يقول المستخدم أشياء مثل: "إنشاء صفحة مقصودة لـ..."، أو "إنشاء موقع ويب لهذا النشاط التجاري"، أو "إنشاء صفحة مقصودة من وسائل التواصل الاجتماعي الخاصة به"، أو "إنشاء صفحة لهذه الشركة"، أو "البحث وإنشاء موقع لـ..."، أو "الصفحة المقصودة لعملائي"، أو "صفحة المحفظة لـ..."، أو "صفحة العلامة التجارية الشخصية"، أو توفير مقابض وسائل التواصل الاجتماعي، أو عنوان URL لموقع ويب، أو سيرة ذاتية ويريد إنشاء صفحة منها.
