Generador de páginas de destino basado en investigaciones. Extrae datos de redes sociales, sitios web, Google Maps, YouTube, foros y, opcionalmente, un CV para crear un perfil completo de una empresa o persona. Analiza los datos como especialista en marketing para extraer ventajas competitivas, propuestas de valor, conocimientos de la audiencia y voz de la marca. Luego genera una página de destino atractiva con imágenes generadas por IA adaptadas a la audiencia. Utilice esta habilidad cuando el usuario diga cosas como: "crear una página de destino para...", "crear un sitio web para esta empresa", "crear una página de destino a partir de sus redes sociales", "generar una página para esta empresa", "investigar y crear un sitio para...", "página de destino para mi cliente", "página de cartera para...", "página de marca personal", o proporciona identificadores de redes sociales, una URL de sitio web o un CV y ​​quiere crear una página a partir de él.
