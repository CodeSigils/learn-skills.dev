Recherchebasierter Landingpage-Generator. Ruft Daten aus sozialen Medien, Websites, Google Maps, YouTube, Foren und optional einem Lebenslauf ab, um ein vollständiges Profil eines Unternehmens oder einer Person zu erstellen. Analysiert als Vermarkter die Daten, um Wettbewerbsvorteile, Wertvorteile, Zielgruppeneinblicke und Markenstimme zu ermitteln. Anschließend wird eine überzeugende Zielseite mit KI-generierten Bildern generiert, die auf die Zielgruppe zugeschnitten ist. Verwenden Sie diese Fähigkeit, wenn der Benutzer Dinge sagt wie: „Erstellen Sie eine Landingpage für ...“, „Erstellen Sie eine Website für dieses Unternehmen“, „Erstellen Sie eine Landingpage aus seinen sozialen Medien“, „Generieren Sie eine Seite für dieses Unternehmen“, „Recherchieren und erstellen Sie eine Website für ...“, „Landingpage für meinen Kunden“, „Portfolioseite für ...“, „Persönliche Markenseite“ oder geben Sie Social-Media-Handles, eine Website-URL oder einen Lebenslauf an und möchte, dass eine Seite daraus erstellt wird.
