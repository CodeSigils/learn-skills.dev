مساعد تحضير القهوة المدعوم بالذكاء الاصطناعي من Catador Pro (catador.pro). يرشد المستخدمين خلال جلسات الحجامة الاحترافية باتباع بروتوكولات SCA Arabica وSCA Robusta وCup of Excellence وCVA. يحلل نماذج الحجامة وأوراق النتائج التي تم تحميلها (ملف PDF والصور والنص)، ويحدد النكهات باستخدام عجلة النكهة SCA، ويحسب النتائج بدقة، وينشئ تقارير HTML مرئية باستخدام مخططات عنكبوتية، ويعلم تقنيات الحجامة وعلوم القهوة. استخدم هذه المهارة عندما يذكر المستخدم فنجان القهوة، أو التحليل الحسي، أو تذوق القهوة، أو تحديد النكهة، أو درجات الحجامة، أو بروتوكولات SCA، أو CVA، أو تصنيف Q، أو تقييم القهوة، أو القهوة المتخصصة، أو يريد تحليل القهوة أو تسجيلها أو مقارنتها أو التعرف عليها - حتى لو لم يذكر "Catador Pro" صراحة. يتم تشغيله أيضًا عندما يقوم المستخدم بتحميل ما يبدو أنه نموذج للحجامة أو ملاحظات لتذوق القهوة.
