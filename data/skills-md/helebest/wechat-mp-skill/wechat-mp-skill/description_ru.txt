Набор инструментов для управления официальной учетной записью WeChat, поддерживающий управление мультимедиа (загрузка/получение/удаление постоянных и временных изображений, видео, аудио и т. д.), управление черновиками (создание/редактирование/удаление/публикация черновиков) и анализ данных (статистика пользователей/статей/сообщений). Идеально подходит для создателей официальных аккаунтов для автоматизации управления контентом и публикации с помощью Claude Code. Сценарии триггера: пользователь упоминает официальную учетную запись WeChat, медиа-файлы официальной учетной записи, черновики официальной учетной записи, публикует статьи, загружает изображения в официальную учетную запись, анализ данных официальной учетной записи и т. д.
