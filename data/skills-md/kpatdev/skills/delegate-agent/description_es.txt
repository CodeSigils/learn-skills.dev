Delegue el trabajo limitado a un arnés de agente de codificación independiente (Antigravity, Claude Code, Codex, OpenCode o Pi) como un subagente que se ejecuta fuera de esta conversación. Úselo cuando el usuario nombra uno de esos arneses, cuando se puede informar una tarea y entregarla completa, cuando sería útil una segunda opinión de un modelo diferente o cuando varios arneses deberían funcionar en paralelo.
