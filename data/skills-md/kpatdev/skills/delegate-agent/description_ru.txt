Делегируйте ограниченную работу независимому агенту кодирования — Antigravity, Claude Code, Codex, OpenCode или Pi — в качестве субагента, работающего вне этого диалога. Используйте, когда пользователь называет один из этих жгутов, когда задача может быть проинформирована и передана целиком, когда может помочь второе мнение по другой модели или когда несколько жгутов должны работать параллельно.
