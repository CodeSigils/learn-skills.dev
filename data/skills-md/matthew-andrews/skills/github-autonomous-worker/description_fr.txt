Travaillez de manière entièrement autonome sur les problèmes GitHub dans un référentiel. Lorsqu'elle est invoquée, cette compétence sélectionne un problème prioritaire, le met en œuvre, crée un PR, répond aux commentaires de révision et revient en arrière pour trouver le problème suivant, le tout sans poser de questions à l'utilisateur. Utilisez cette compétence lorsque vous souhaitez que Claude trie et résolve de manière indépendante un arriéré de problèmes GitHub sans vous tenir la main.
