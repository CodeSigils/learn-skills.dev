Trabaje de forma totalmente autónoma en los problemas de GitHub en un repositorio. Cuando se invoca, esta habilidad selecciona un problema priorizado, lo implementa, crea un PR, aborda los comentarios de revisión y retrocede para encontrar el siguiente problema, todo sin hacer ninguna pregunta al usuario. Utilice esta habilidad cuando desee que Claude clasifique y resuelva de forma independiente una acumulación de problemas de GitHub sin ayuda.
