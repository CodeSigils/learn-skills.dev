Bearbeiten Sie GitHub-Probleme vollständig autonom in einem Repository. Wenn dieser Skill aufgerufen wird, wählt er ein priorisiertes Problem aus, implementiert es, erstellt eine PR, geht auf Bewertungsfeedback ein und kehrt zurück, um das nächste Problem zu finden – und das alles, ohne dem Benutzer irgendwelche Fragen zu stellen. Nutzen Sie diese Fähigkeit, wenn Sie möchten, dass Claude einen Rückstand an GitHub-Problemen selbstständig selektiert und löst, ohne dabei Hand anlegen zu müssen.
