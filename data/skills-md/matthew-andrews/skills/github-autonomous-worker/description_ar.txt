العمل بشكل مستقل تمامًا من خلال مشكلات GitHub في المستودع. عند استدعائها، تختار هذه المهارة مشكلة ذات أولوية، وتنفذها، وتنشئ علاقات عامة، وتعالج تعليقات المراجعة، وتعود للعثور على المشكلة التالية - كل ذلك دون طرح أي أسئلة على المستخدم. استخدم هذه المهارة عندما تريد من Claude أن يقوم بشكل مستقل بفرز وحل المشكلات المتراكمة في GitHub دون الإمساك باليد.
