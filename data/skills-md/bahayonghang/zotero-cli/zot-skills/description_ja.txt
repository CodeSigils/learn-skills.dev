ユーザーが Claude Code、Codex、または同様のエージェントを使用していて、マシン上に既に存在する Zotero コンテンツを直接クエリ、抽出、整理、または安全に更新したい場合は、このスキルを使用する必要があります。焦点は、人々に CLI を暗記するように教えることではなく、Zotero のメタデータ、メモ、タグ、添付ファイル、PDF フルテキスト、アウトライン、注釈、コレクション、保存された検索、フィード、および閲覧ワークスペースにあります。 Rust の `zot` CLI は実行層のみです。これは、ライブラリ内検索、引用キー検索、注釈と PDF 抽出、ワークスペースの作成と取得、保存された検索の保存、添付ファイルのダウンロード、セマンティック インデックス作成/検索、Scite チェック、構成のトラブルシューティング、および明示的な承認を伴う Zotero Web API 書き込み操作に適用されます。一般的な論文の検索、通常の要約、引用形式の指導、または Zotero/ワークスペースを含まない PDF の処理には使用しないでください。
