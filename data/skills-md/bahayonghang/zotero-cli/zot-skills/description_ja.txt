ユーザーが Claude Code、Codex、または同様のエージェントを使用していて、マシン上に既に存在する Zotero コンテンツを直接クエリ、抽出、整理、または安全に更新したい場合は、このスキルを使用する必要があります。焦点は、Zotero のメタデータ、メモ、タグ、添付ファイル、PDF フルテキスト、アウトライン、注釈、コレクション、保存された検索、フィード、および閲覧ワークスペースにあり、人々に CLI を暗記することを教えることではありません。 Rust の `zot` CLI は実行層のみです。これは、ライブラリ内検索、引用キーの検索、注釈と PDF の抽出、ワークスペースの作成と取得、保存された検索の保存、添付ファイルのダウンロード、セマンティック インデックス作成/検索、Scite チェック、構成のトラブルシューティング、および Zotero Web API を介した承認された書き込み操作に適しています。一般的な論文検索、通常の要約、引用形式の教育、または Zotero/ワークスペースを含まない PDF 処理には使用しないでください。
