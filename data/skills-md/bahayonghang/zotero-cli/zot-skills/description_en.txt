When users are in Claude Code, Codex, or similar agents and want to directly query, extract, organize, or safely update the Zotero content already on their machine, they must use this skill. The focus is on Zotero’s metadata, notes, tags, attachments, PDF full‑text, outline, annotations, collections, saved searches, feeds, and reading workspace—not on teaching people to memorize the CLI. The Rust `zot` CLI is only the execution layer. It is suitable for in‑library search, citation‑key lookup, annotation and PDF extraction, workspace creation and retrieval, saved‑search saving, attachment downloading, semantic indexing/search, Scite checking, configuration troubleshooting, and authorized write operations via the Zotero Web API. Do not use it for generic paper hunting, ordinary summarization, citation‑style teaching, or PDF processing that does not involve Zotero/workspace.
