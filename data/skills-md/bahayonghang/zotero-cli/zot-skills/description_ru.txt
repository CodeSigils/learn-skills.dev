Когда пользователи используют Claude Code, Codex или аналогичные агенты и хотят напрямую запрашивать, извлекать, систематизировать или безопасно обновлять контент Zotero, уже находящийся на их компьютере, они должны использовать этот навык. Основное внимание уделяется метаданным Zotero, заметкам, тегам, вложениям, полнотекстовому PDF-файлу, структуре, аннотациям, коллекциям, сохраненным поисковым запросам, каналам и рабочему пространству для чтения, а не обучению людей запоминать интерфейс командной строки. CLI Rust `zot` — это только уровень выполнения. Он подходит для поиска в библиотеке, поиска по ключу цитаты, аннотаций и извлечения PDF-файлов, создания и извлечения рабочей области, сохранения сохраненных результатов поиска, загрузки вложений, семантического индексирования/поиска, проверки Scite, устранения неполадок конфигурации и авторизованных операций записи через Zotero Web API. Не используйте его для обычного поиска документов, обычного реферирования, обучения в стиле цитирования или обработки PDF-файлов, не использующей Zotero/workspace.
