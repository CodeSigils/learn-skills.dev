當使用者在 Claude Code、Codex 或類似代理程式中並希望直接查詢、提取、組織或安全性更新其機器上已有的 Zotero 內容時，必須使用此技能。重點是 Zotero 的元資料、註釋、標籤、附件、PDF 全文、大綱、註釋、集合、保存的搜尋、提要和閱讀工作區，而不是教授 CLI 使用。 Rust `zot` CLI 只是執行層。它適用於庫內搜尋、引文關鍵字查找、註釋和 PDF 提取、工作區創建和檢索、已保存搜尋保存、附件下載、語義索引/搜尋、Scite 檢查、配置故障排除以及授權 Zotero Web API 寫入操作。請勿將其用於一般論文查找、一般摘要、引文式教學或不涉及 Zotero/workspace 的 PDF 處理。
