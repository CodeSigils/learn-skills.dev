当用户在 Claude Code、Codex 或类似代理中并希望直接查询、提取、组织或安全更新其机器上已有的 Zotero 内容时，必须使用此技能。重点是 Zotero 的元数据、注释、标签、附件、PDF 全文、大纲、注释、集合、保存的搜索、提要和阅读工作区，而不是教人们记住 CLI。 Rust `zot` CLI 只是执行层。它适用于库内搜索、引文关键字查找、注释和 PDF 提取、工作区创建和检索、已保存搜索保存、附件下载、语义索引/搜索、Scite 检查、配置故障排除以及通过 Zotero Web API 进行授权写入操作。請勿將其用於一般論文搜尋、普通摘要、引文式教學或不涉及 Zotero/workspace 的 PDF 處理。
