عندما يكون المستخدمون في Claude Code أو Codex أو وكلاء مشابهين ويريدون الاستعلام مباشرة عن محتوى Zotero الموجود بالفعل على أجهزتهم أو استخراجه أو تنظيمه أو تحديثه بأمان، فيجب عليهم استخدام هذه المهارة. ينصب التركيز على بيانات تعريف Zotero، والملاحظات، والعلامات، والمرفقات، والنص الكامل بتنسيق PDF، والمخطط التفصيلي، والشروح، والمجموعات، وعمليات البحث المحفوظة، والخلاصات، ومساحة عمل القراءة - وليس على تعليم الأشخاص كيفية حفظ واجهة سطر الأوامر (CLI). الصدأ `zot` CLI هو فقط طبقة التنفيذ. وهو مناسب للبحث داخل المكتبة، والبحث عن مفتاح الاقتباس، والتعليقات التوضيحية واستخراج ملفات PDF، وإنشاء مساحة العمل واسترجاعها، وحفظ البحث المحفوظ، وتنزيل المرفقات، والفهرسة/البحث الدلالي، وفحص Scite، واستكشاف أخطاء التكوين وإصلاحها، وعمليات الكتابة المعتمدة عبر Zotero Web API. لا تستخدمه للبحث العام عن الأوراق، أو التلخيص العادي، أو التدريس بأسلوب الاقتباس، أو معالجة ملفات PDF التي لا تتضمن Zotero/مساحة العمل.
