Compétence de figures Draw.io de première qualité académique pour les articles, les thèses, les diagrammes de style IEEE, les figures d'architecture, les flux de travail, les feuilles de route, les formules et les visualisations prêtes à être publiées. À utiliser lorsque les utilisateurs demandent à dessiner, redessiner, reproduire, modifier ou exporter des diagrammes pour des articles académiques ou des documents techniques. Crée des bundles .drawio + .spec.yaml + .arch.json hors ligne, exporte SVG localement, utilise draw.io Desktop CLI pour SVG/PNG/PDF/JPG intégré, prend en charge les préréglages de style, les boucles de révision d'auto-vérification et le repli d'URL de diagrammes.net sans nécessiter MCP.
