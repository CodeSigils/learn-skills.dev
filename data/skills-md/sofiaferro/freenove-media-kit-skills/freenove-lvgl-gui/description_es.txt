Cree interfaces gráficas de usuario con LVGL (Biblioteca de gráficos ligeros y versátiles) en Freenove Media Kit. Cree botones, etiquetas, controles deslizantes, imágenes, listas e interfaces de usuario complejas con soporte táctil/de entrada. Utilice esta habilidad al crear interfaces interactivas, menús, paneles de control o cualquier aplicación GUI para ESP32-S3.
