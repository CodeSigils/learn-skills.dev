أنشئ واجهات مستخدم رسومية باستخدام LVGL (مكتبة الرسومات الخفيفة والمتعددة الاستخدامات) على Freenove Media Kit. قم بإنشاء الأزرار والتسميات وشرائح التمرير والصور والقوائم وواجهات المستخدم المعقدة مع دعم اللمس/الإدخال. استخدم هذه المهارة عند إنشاء واجهات تفاعلية أو قوائم أو لوحات تحكم أو أي تطبيق واجهة مستخدم رسومية لـ ESP32-S3.
