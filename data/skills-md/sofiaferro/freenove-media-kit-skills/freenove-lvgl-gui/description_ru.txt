Создавайте графические пользовательские интерфейсы с помощью LVGL (легкой и универсальной графической библиотеки) в Freenove Media Kit. Создавайте кнопки, метки, ползунки, изображения, списки и сложные пользовательские интерфейсы с поддержкой сенсорного ввода. Используйте этот навык при создании интерактивных интерфейсов, меню, панелей управления или любого приложения с графическим интерфейсом для ESP32-S3.
