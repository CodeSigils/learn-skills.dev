Независимое от платформы руководство по использованию Open Computer Use, сервера MCP Computer Use с открытым исходным кодом и интерфейса командной строки для macOS, Linux и Windows. Используйте, когда агенту необходимо установить, проверить, устранить неполадки, настроить или использовать Open Computer Use через собственный CLI, stdio MCP-сервер или прямые вызовы инструмента Computer Use.
