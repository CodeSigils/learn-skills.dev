Conseils indépendants de la plate-forme pour l’utilisation d’Open Computer Use, du serveur open source Computer Use MCP et de la CLI pour macOS, Linux et Windows. À utiliser lorsqu'un agent doit installer, vérifier, dépanner, configurer ou exploiter Open Computer Use via sa CLI native, son serveur MCP stdio ou des appels directs à l'outil Computer Use.
