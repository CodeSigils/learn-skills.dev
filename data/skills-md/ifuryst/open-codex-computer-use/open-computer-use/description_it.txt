Linee guida indipendenti dalla piattaforma per l'utilizzo di Open Computer Use, il server MCP Computer Use open source e l'interfaccia a riga di comando per macOS, Linux e Windows. Da utilizzare quando un agente deve installare, verificare, risolvere problemi, configurare o utilizzare Open Computer Use tramite la sua CLI nativa, il server MCP stdio o chiamate dirette allo strumento Computer Use.
