Plattformneutrale Anleitung für die Verwendung von Open Computer Use, dem Open-Source-Computer Use MCP-Server und CLI für macOS, Linux und Windows. Verwenden Sie diese Option, wenn ein Agent Open Computer Use über seine native CLI, den stdio MCP-Server oder direkte Computer Use-Toolaufrufe installieren, überprüfen, Fehler beheben, konfigurieren oder betreiben muss.
