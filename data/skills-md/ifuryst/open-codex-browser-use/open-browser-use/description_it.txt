Indicazioni indipendenti dalla piattaforma per l'utilizzo di Open Browser Use, lo stack di automazione Chrome open source per agenti AI. Da utilizzare quando un agente deve installare, verificare, risolvere problemi o utilizzare Open Browser Use tramite l'estensione del browser, la CLI nativa, l'SDK JavaScript, l'SDK Python, Go SDK o i metodi JSON-RPC in stile Browser Use; utilizzare per attività che coinvolgono schede Chrome reali, rivendicazione di schede utente, comandi CDP, download, selettori di file, assistenti degli appunti o pulizia della sessione.
