Независимое от платформы руководство по использованию Open Browser Use — стека автоматизации Chrome с открытым исходным кодом для агентов ИИ. Используйте, когда агенту необходимо установить, проверить, устранить неполадки или запустить использование открытого браузера через расширение браузера, собственный интерфейс командной строки, JavaScript SDK, Python SDK, Go SDK или методы JSON-RPC в стиле использования браузера; используйте для задач, связанных с реальными вкладками Chrome, запросом пользовательских вкладок, командами CDP, загрузками, выбором файлов, помощниками буфера обмена или очисткой сеанса.
