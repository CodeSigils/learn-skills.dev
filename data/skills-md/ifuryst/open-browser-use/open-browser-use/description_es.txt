Orientación independiente de la plataforma para utilizar Open Browser Use, la pila de automatización de Chrome de código abierto para agentes de IA. Utilícelo cuando un agente necesite instalar, verificar, solucionar problemas u operar Open Browser Use a través de su extensión de navegador, CLI nativa, JavaScript SDK, Python SDK, Go SDK o métodos de estilo JSON-RPC de Browser Use; Úselo para tareas que involucran pestañas reales de Chrome, reclamación de pestañas de usuario, comandos CDP, descargas, selectores de archivos, ayudas del portapapeles o limpieza de sesiones.
