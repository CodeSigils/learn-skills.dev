Plattformneutrale Anleitung zur Verwendung von Open Browser Use, dem Open-Source-Chrome-Automatisierungsstack für KI-Agenten. Wird verwendet, wenn ein Agent Open Browser über seine Browsererweiterung, native CLI, JavaScript SDK, Python SDK, Go SDK oder JSON-RPC-Methoden im Browser Use-Stil installieren, überprüfen, Fehler beheben oder ausführen muss. Wird für Aufgaben verwendet, die echte Chrome-Registerkarten, die Beanspruchung von Benutzerregisterkarten, CDP-Befehle, Downloads, Dateiauswahlfunktionen, Zwischenablage-Helfer oder die Sitzungsbereinigung betreffen.
