Genera historias de usuario completas en formato 3C (Tarjeta, Conversación, Confirmación) a partir de cualquier descripción de característica, requisito o idea. Utilice esta habilidad siempre que el usuario solicite escribir o crear una historia de usuario, redactar criterios de aceptación, dividir los requisitos en historias, definir un elemento de trabajo pendiente o usar frases como "historia de usuario para", "3C", "como usuario que quiero", "dado/cuándo/entonces", "criterios de aceptación" o "historia para [característica]". Se activa incluso cuando el usuario solo menciona una parte de las 3C; por ejemplo, solo solicita criterios de aceptación o simplemente quiere una tarjeta.
