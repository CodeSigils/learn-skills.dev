Generates complete user stories in the 3Cs format (Card, Conversation, Confirmation) from any feature description, requirement, or idea. Use this skill whenever the user asks to write or create a user story, draft acceptance criteria, break down requirements into stories, define a backlog item, or uses phrases like 'user story for', '3Cs', 'as a user I want', 'Given/When/Then', 'acceptance criteria', or 'story for [feature]'. Trigger even when the user only mentions one part of the 3Cs — e.g., just asks for acceptance criteria or just wants a card.
