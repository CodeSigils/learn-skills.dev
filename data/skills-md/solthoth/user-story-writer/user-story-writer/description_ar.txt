يُنشئ قصص مستخدم كاملة بتنسيق 3Cs (بطاقة، محادثة، تأكيد) من أي وصف أو متطلبات أو فكرة للميزة. استخدم هذه المهارة عندما يطلب المستخدم كتابة أو إنشاء قصة مستخدم، أو صياغة معايير القبول، أو تقسيم المتطلبات إلى قصص، أو تحديد عنصر متراكم، أو استخدام عبارات مثل "قصة مستخدم لـ"، أو "3Cs"، أو "كمستخدم أريده"، أو "معطى/متى/ثم"، أو "معايير القبول"، أو "قصة لـ [ميزة]". يتم تفعيله حتى عندما يذكر المستخدم جزءًا واحدًا فقط من العناصر الثلاثة - على سبيل المثال، يسأل فقط عن معايير القبول أو يريد بطاقة فقط.
