Когда пользователь хочет провести аудит аккаунта Google Рекламы для бизнеса по привлечению потенциальных клиентов — проверка CPL, количества потенциальных клиентов, качества потенциальных клиентов, коэффициентов конверсии форм, импорта офлайн-конверсий и оптимизации, ориентированной на конвейер. Запускается по «аудиту привлечения потенциальных клиентов», «аудиту привлечения потенциальных клиентов», «аудиту CPL», «аудиту моего аккаунта для привлечения потенциальных клиентов», «аудиту Google Рекламы B2B», «аудиту качества потенциальных клиентов», «аудиту цены за потенциального клиента», «проверке аккаунта для привлечения потенциальных клиентов» или «проверке Google Рекламы для привлечения потенциальных клиентов». Для общего аудита аккаунта см. google-ads-account-audit. Для аудита электронной торговли см. google-ads-audit-ecommerce.
