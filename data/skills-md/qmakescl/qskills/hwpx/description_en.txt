Skill to read, create, and edit Hangul (HWP/HWPX) documents. It handles the file format of Hancom Office (Hangul), a Korean document authoring program.  
Use this skill in the following situations:  
- When .hwp or .hwpx files are mentioned  
- When requested regarding “Hangul documents,” “hwp files,” or “Hancom Office”  
- When asked to extract text/tables/images from HWP files  
- When asked to create a new Hangul document or edit an existing one  
- When asked to convert HWP → PDF/DOCX or DOCX/PDF → HWP  
Whenever expressions like HWP, HWPX, Hangul, Hancom, or hwp file appear, always use this skill.
