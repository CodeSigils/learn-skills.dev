Skill to read, create, and edit Korean (HWP/HWPX) documents. Handles the file format of Hancom Office (Hangeul), a Korean document authoring program.
Use this skill in the following situations:
- When .hwp or .hwpx files are mentioned
- When there are requests related to "Hangeul documents", "hwp files", or "Hancom Office"
- When extracting text/tables/images from HWP files is requested
- When creating new Hangeul documents or editing existing ones is requested
- When converting HWP → PDF/DOCX or DOCX/PDF → HWP is requested
Always use this skill whenever expressions like HWP, HWPX, Hangeul, Hancom, hwp file, etc. appear.
