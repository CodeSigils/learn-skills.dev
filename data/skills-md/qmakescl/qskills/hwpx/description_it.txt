Capacità di leggere, creare e modificare documenti coreani (HWP/HWPX). Gestisce il formato file di Hancom Office (Hangeul), un programma di creazione di documenti coreano.
Usa questa abilità nelle seguenti situazioni:
- Quando vengono menzionati i file .hwp o .hwpx
- Quando ci sono richieste relative a "documenti Hangeul", "file hwp" o "Hancom Office"
- Quando è richiesta l'estrazione di testo/tabelle/immagini da file HWP
- Quando viene richiesta la creazione di nuovi documenti Hangeul o la modifica di quelli esistenti
- Quando è richiesta la conversione HWP → PDF/DOCX o DOCX/PDF → HWP
Usa sempre questa abilità ogni volta che compaiono espressioni come HWP, HWPX, Hangeul, Hancom, file hwp, ecc.
