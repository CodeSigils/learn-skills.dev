Capacità di leggere, creare e modificare documenti Hangul (HWP/HWPX). Gestisce il formato file di Hancom Office (Hangul), un programma di creazione di documenti coreano.  
Usa questa abilità nelle seguenti situazioni:  
- Quando viene menzionato un file .hwp o .hwpx  
- Quando è presente una richiesta relativa a "documento Hangul", "file hwp" o "Hancom Office"  
- Quando è richiesta l'estrazione di testo/tabelle/immagini da file HWP  
- Quando viene richiesta la creazione di un nuovo documento Hangul o la modifica di uno esistente  
- Quando è richiesta la conversione HWP → PDF/DOCX o DOCX/PDF → HWP  
Ogni volta che vengono visualizzate espressioni come HWP, HWPX, Hangul, Hancom o file hwp, utilizza sempre questa abilità.
