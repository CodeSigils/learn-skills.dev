Recherchez, réutilisez et implémentez le modèle éprouvé du référentiel pour une interface utilisateur Web hébergée sur un appareil, fournie avec Vite (Preact + Zustand) et intégrée dans une image de micrologiciel ESP-IDF, puis servie sur esp_http_server (éventuellement avec WebSocket). À utiliser lorsque vous avez besoin du playbook existant + exemple de firmware fonctionnel, que vous souhaitez les boutons Vite/CMake exacts pour les noms d'actifs déterministes, ou que vous avez besoin de localiser rapidement les documents/fichiers clés (tutoriel 0017 + ticket 0013).
