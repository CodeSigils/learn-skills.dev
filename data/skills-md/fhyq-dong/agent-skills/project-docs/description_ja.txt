プロジェクトの永続的なドキュメント レイヤー (plan/、AGENTS.md (エージェント向けの真実)、README.md (人間向け)、および docs/ を設定および維持します。ユーザーが新しいプロジェクトのドキュメント スキャフォールディングを構築したい場合は常にこれを使用します。既存のコードベースまたは乱雑なコードベースにこの規則を採用します (そこにあるものを監査し、実際のコードから正確なドキュメントを再生成します)。または、一連の開発の後、同期/ドリフトを調整します (永続的なレッスンを AGENTS.md に組み込み、README を現実から更新し、古くなった計画をアーカイブします)。ユーザーが特定のファイル名を指定していない場合でも、「ドキュメント/計画の構造をセットアップする」、「AGENTS.md または CLAUDE.md を書き込む/更新する」、「ドキュメントがごちゃごちゃなので整理する」、「計画と実際に構築したものを調整する」、「これをまとめて文書化する」、「この作業の後でプロジェクトのドキュメントを更新する」などのフレーズでトリガーします。計画/AGENTS.md/README/docs をセットとして一貫性を保つことが目標である場合は、アドホックなドキュメント編集よりもこのスキルを優先します。
