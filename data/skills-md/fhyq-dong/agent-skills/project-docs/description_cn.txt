设置和维护项目的持久文档层 - plan/、AGENTS.md（面向代理的真相）、README.md（面向人类）和 docs/。每当用户想要为新项目奠定文档脚手架时，请使用此选项；在现有或混乱的代码库上采用此约定（审核其中的内容，从真实代码重新生成准确的文档）；或者，经过一段时间的开发，同步/协调偏差（将持久的经验教训折叠到 AGENTS.md 中，从现实中刷新自述文件，归档现在过时的计划）。在诸如“设置文档/计划结构”、“写入/刷新 AGENTS.md 或 CLAUDE.md”、“我的文档一团糟，清理它们”、“使计划与我们实际构建的内容相一致”、“总结并记录此内容”、“在完成此工作后更新项目文档”等短语时触发它 - 即使用户没有命名特定文件。只要目标是保持 plan/AGENTS.md/README/docs 作为一个集合的连贯性，就更喜欢使用此技能而不是临时文档编辑。
