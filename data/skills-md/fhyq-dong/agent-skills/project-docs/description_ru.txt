Настройте и поддерживайте надежный уровень документации проекта — plan/, AGENTS.md (правда, обращенная к агенту), README.md (ориентированный на человека) и docs/. Используйте это всякий раз, когда пользователь хочет создать основу документации для НОВОГО проекта; ПРИНЯТЬ это соглашение для существующей или запутанной кодовой базы (проверить то, что там есть, восстановить точную документацию из реального кода); или, после продолжительной разработки, СИНХРОНИЗИРОВАТЬ/согласовать дрейф (сложить долгосрочные уроки в AGENTS.md, обновить README из реальности, заархивировать устаревший план). Запускайте его по таким фразам, как «настроить структуру документов/плана», «написать/обновить AGENTS.md или CLAUDE.md», «мои документы в беспорядке, очистите их», «согласовать план с тем, что мы на самом деле построили», «завершить и задокументировать это», «обновить документацию проекта после этой работы» — даже когда пользователь не называет конкретный файл. Предпочитайте этот навык, а не специальное редактирование документов, если цель состоит в том, чтобы план/AGENTS.md/README/docs был согласованным как набор.
