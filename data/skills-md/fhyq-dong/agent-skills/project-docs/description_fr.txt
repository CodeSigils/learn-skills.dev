Configurez et maintenez la couche de documentation durable d'un projet : plan/, AGENTS.md (vérité destinée à l'agent), README.md (face à l'humain) et docs/. Utilisez-le chaque fois que l'utilisateur souhaite établir un échafaudage de documentation pour un NOUVEAU projet ; ADOPTER cette convention sur une base de code existante ou désordonnée (auditer ce qui s'y trouve, régénérer des documents précis à partir du vrai code) ; ou, après une période de développement, SYNC/réconcilier la dérive (intégrer les leçons durables dans AGENTS.md, actualiser le README de la réalité, archivez le plan désormais obsolète). Déclenchez-le sur des expressions telles que « configurer la structure des documents/plan », « écrire/actualiser AGENTS.md ou CLAUDE.md », « mes documents sont en désordre, nettoyez-les », « réconcilier le plan avec ce que nous avons réellement construit », « conclure et documenter ceci », « mettre à jour les documents du projet après ce travail » – même lorsque l'utilisateur ne nomme pas de fichier spécifique. Préférez cette compétence aux modifications de documents ad hoc chaque fois que l'objectif est de maintenir la cohérence du plan/AGENTS.md/README/docs en tant qu'ensemble.
