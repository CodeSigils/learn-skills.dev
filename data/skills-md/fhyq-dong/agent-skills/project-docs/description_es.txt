Configure y mantenga la capa de documentación duradera de un proyecto: el plan/, AGENTS.md (verdad de cara al agente), README.md (cara de humanos) y docs/. Utilícelo siempre que el usuario desee establecer una estructura de documentos para un NUEVO proyecto; ADOPTAR esta convención en una base de código existente o desordenada (auditar lo que hay allí, regenerar documentos precisos a partir del código real); o, después de un período de desarrollo, SYNC/reconciliar la deriva (incorporar lecciones duraderas a AGENTS.md, actualizar README desde la realidad, archivar el plan ahora obsoleto). Actívelo con frases como "configurar los documentos/estructura del plan", "escribir/actualizar AGENTS.md o CLAUDE.md", "mis documentos son un desastre, límpielos", "conciliar el plan con lo que realmente construimos", "concluir y documentar esto", "actualizar los documentos del proyecto después de este trabajo", incluso cuando el usuario no nombra un archivo específico. Prefiera esta habilidad a las ediciones de documentos ad hoc siempre que el objetivo sea mantener el plan/AGENTS.md/README/docs coherente como un conjunto.
