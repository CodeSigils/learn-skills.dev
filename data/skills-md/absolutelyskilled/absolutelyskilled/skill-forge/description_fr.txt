Générez une compétence AbsolutelySkilled prête pour la production à partir de n'importe quelle source : dépôts GitHub, URL de documentation ou sujets de domaine (marketing, ventes, TypeScript, etc.). Déclencheurs sur /skill-forge, "créer une compétence pour X", "générer une compétence à partir de ces documents", "créer une compétence pour ce dépôt", "créer une compétence sur le marketing" ou "ajouter X au registre". Pour les URL : effectue une recherche approfondie de documents (README, llms.txt, références API). Pour les domaines : exécute une session de découverte de brainstorming avec l'utilisateur pour définir la portée et le contenu. Génère un dossier skills/ complet avec SKILL.md, evals.json et éventuellement sources.yaml, prêt à être PR dans le registre AbsolutelySkilled.
