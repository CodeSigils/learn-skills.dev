Создайте готовый к использованию навык AbsolutelySkilled из любого источника: репозиториев GitHub, URL-адресов документации или тем предметной области (маркетинг, продажи, TypeScript и т. д.). Запускается по /skill-forge, «создать навык для X», «создать навык из этих документов», «создать навык для этого репозитория», «создать навык по маркетингу» или «добавить X в реестр». Для URL-адресов: выполняет глубокое исследование документации (README, llms.txt, ссылки на API). Для доменов: запускает сеанс мозгового штурма с пользователем для определения объема и содержания. Выводит полную папку навыка/ с SKILL.md, evals.json и, при необходимости, source.yaml, готовую к PR в реестре AbsolutelySkilled.
