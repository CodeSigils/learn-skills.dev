GitHub 리포지토리, 문서 URL 또는 도메인 주제(마케팅, 영업, TypeScript 등) 등 모든 소스에서 프로덕션에 즉시 사용 가능한 AbsolutelySkilled 기술을 생성하세요. /skill-forge, "X에 대한 기술 생성", "이 문서에서 기술 생성", "이 저장소에 대한 기술 생성", "마케팅에 대한 기술 구축" 또는 "레지스트리에 X 추가"에 대해 트리거됩니다. URL의 경우: 심층적인 문서 조사(README, llms.txt, API 참조)를 수행합니다. 도메인의 경우: 범위와 콘텐츠를 정의하기 위해 사용자와 브레인스토밍 검색 세션을 실행합니다. AbsolutelySkilled 레지스트리에 PR할 준비가 된 SKILL.md, evals.json 및 선택적으로 source.yaml이 포함된 완전한 Skill/폴더를 출력합니다.
