GitHub リポジトリ、ドキュメント URL、またはドメイン トピック (マーケティング、販売、TypeScript など) などの任意のソースから、本番環境に対応した AbsolutelySkilled スキルを生成します。 /skill-forge でトリガーされ、「X のスキルを作成」​​、「これらのドキュメントからスキルを生成」、「このリポジトリのスキルを作成」​​、「マーケティングに関するスキルを構築」、または「レジストリに X を追加」。 URL の場合: 詳細なドキュメント調査 (README、llms.txt、API リファレンス) を実行します。ドメインの場合: ユーザーとブレインストーミング検出セッションを実行して、スコープとコンテンツを定義します。 SKILL.md、evals.json、およびオプションでsources.yamlを含む完全なスキル/フォルダーを出力し、AbsolutelySkilled レジストリに PR できるようにします。
