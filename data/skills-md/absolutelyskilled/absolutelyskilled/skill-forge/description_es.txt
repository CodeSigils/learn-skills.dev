Genere una habilidad AbsolutelySkilled lista para producción desde cualquier fuente: repositorios de GitHub, URL de documentación o temas de dominio (marketing, ventas, TypeScript, etc.). Activadores en /skill-forge, "crear una habilidad para X", "generar una habilidad a partir de estos documentos", "crear una habilidad para este repositorio", "desarrollar una habilidad sobre marketing" o "agregar X al registro". Para URL: realiza una investigación profunda de documentos (README, llms.txt, referencias de API). Para dominios: ejecuta una sesión de descubrimiento de lluvia de ideas con el usuario para definir el alcance y el contenido. Genera una carpeta Skill/ completa con SKILL.md, evals.json y, opcionalmente, sources.yaml, lista para realizar relaciones públicas en el registro AbsolutelySkilled.
