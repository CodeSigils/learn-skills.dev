Используйте этот навык при создании документации, удобной для AI-агента, для репозитория или каталога git, отвечая на вопросы о базе кода из существующих документов или постепенно обновляя документацию после изменений кода. Запускается по codedocs:generate, codedocs:ask, codedocs:update, «документировать эту кодовую базу», «создать документацию для этого репозитория», «что делает этот проект», «обновить документацию после моих изменений» или любую задачу, требующую структурированной документации по кодовой базе, которая обслуживает агентов ИИ, разработчиков и новых членов команды.
