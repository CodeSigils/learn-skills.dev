Utilisez cette compétence lorsque vous générez une documentation conviviale pour les agents IA pour un dépôt ou un répertoire git, répondez à des questions sur une base de code à partir de documents existants ou mettez à jour progressivement la documentation après des modifications de code. Déclencheurs sur codedocs : generate, codedocs :ask, codedocs :update, "documenter cette base de code", "générer des documents pour ce dépôt", "que fait ce projet", "mettre à jour les documents après mes modifications" ou toute tâche nécessitant une documentation de base de code structurée destinée aux agents d'IA, aux développeurs et aux nouveaux membres de l'équipe.
