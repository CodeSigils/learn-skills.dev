Utilice esta habilidad cuando genere documentación compatible con agentes de IA para un repositorio o directorio de git, responda preguntas sobre una base de código a partir de documentos existentes o actualice la documentación de forma incremental después de cambios de código. Activadores en codedocs:generate, codedocs:ask, codedocs:update, "documentar este código base", "generar documentos para este repositorio", "qué hace este proyecto", "actualizar los documentos después de mis cambios" o cualquier tarea que requiera documentación de código base estructurada que sirva a agentes de IA, desarrolladores y nuevos miembros del equipo.
