استخدم هذه المهارة عند إنشاء واجهات مستخدم طرفية باستخدام React Ink - تطبيقات CLI التفاعلية، أو لوحات المعلومات الطرفية، أو شاشات التقدم، أو مكونات TUI التي تعتمد على لوحة المفاتيح. يتم تشغيلها على React Ink، ومكونات Ink، وواجهة المستخدم الطرفية مع React، وuseInput، وuseFocus، وتخطيط Box/Text، وتطبيق create-ink، وأي مهمة تتطلب واجهات طرفية تفاعلية غنية تم إنشاؤها باستخدام React وFlexbox.
