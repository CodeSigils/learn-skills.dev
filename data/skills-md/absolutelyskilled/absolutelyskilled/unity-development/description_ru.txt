Используйте этот навык при работе с игровым движком Unity — написанием сценариев C#, системой Entity Component System (ECS/DOTS), физическим моделированием, программированием шейдеров (ShaderLab, HLSL, Shader Graph) и набором инструментов пользовательского интерфейса. Триггеры для программирования игрового процесса, жизненного цикла MonoBehaviour, архитектуры компонентов, физики твердых тел, raycasting, обработки столкновений, разработки пользовательских шейдеров, конфигурации материалов, стиля USS, макета UXML и оптимизации производительности для приложений реального времени. Выступает в качестве старшего инженера-консультанта Unity для разработчиков игр, создающих игры и интерактивные приложения промышленного качества.
