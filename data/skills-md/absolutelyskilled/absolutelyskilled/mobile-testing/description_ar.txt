استخدم هذه المهارة عند كتابة اختبارات تطبيقات الهاتف المحمول أو تكوينها باستخدام Detox أو Appium، أو إعداد مزارع الأجهزة (AWS Device Farm، أو Firebase Test Lab، أو BrowserStack)، أو دمج تقارير الأعطال (Crashlytics، أو Sentry، أو Bugsnag)، أو توزيع الإصدارات التجريبية (TestFlight، أو Firebase App Distribution، أو App Center). المشغلات عند اختبار e2e على الأجهزة المحمولة، وأتمتة التطبيق الأصلي، واختبار مصفوفة الجهاز، وترميز الأعطال، وسير عمل توزيع بيتا عبر الهواء.
