Очистка мертвого кода и зависимостей по всему репозиторию: неиспользуемые данные, экспорт без ссылок, недоступный код, потерянные файлы — удаляются только с помощью инструмента, обратимыми волнами. Работает на зеленой магистрали. Для очистки различий используйте Absolute-Simplify. Запускается по «абсолютному сокращению», «удалению мертвого кода», «найти неиспользуемые файлы deps/export», «что мы можем удалить», «очистить потерянные файлы».
