Spécification de conception autonome légère pour les agents de codage d'IA : analyse de la base de code → passe de clarification limitée (3 à 5 questions, pas une grille) → document de conception révisé écrit dans docs/plans/ → examen noté indépendant → arrêt. Pas de tableau de tâches, pas de build. À utiliser lorsque vous souhaitez qu'une spécification soit discutée, transmise ou révisée avant de s'engager dans la mise en œuvre. Enchaîne le travail absolu lorsqu'il est prêt à construire. Déclencheurs sur "spécification absolue", "écrire une spécification", "spécifier cette fonctionnalité", "rédiger un document de conception", "Je veux qu'une spécification soit transmise/révisée, ne la construisez pas encore".
