استخدم هذه المهارة عند إدارة أنظمة متعددة المستودعات باستخدام أداة "meta" (github.com/mateodelnorte/meta). يتم تشغيلها عند استنساخ meta git، أو meta exec، أو إنشاء/استيراد/ترحيل مشروع meta، أو تنسيق الأوامر عبر العديد من عمليات إعادة الشراء، أو تشغيل عمليات تثبيت npm/yarn عبر جميع المشاريع، أو ترحيل monorepo إلى بنية متعددة الريبو، أو أي سير عمل يتطلب تشغيل أوامر git أو shell ضد مستودعات فرعية متعددة في وقت واحد.
