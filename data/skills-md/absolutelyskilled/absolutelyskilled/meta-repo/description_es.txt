Utilice esta habilidad cuando administre sistemas de múltiples repositorios usando la herramienta `meta` (github.com/mateodelnorte/meta). Activadores en meta git clone, meta exec, meta proyecto crear/importar/migrar, coordinar comandos en muchos repositorios, ejecutar instalaciones npm/yarn en todos los proyectos, migrar un monorepo a una arquitectura de múltiples repositorios o cualquier flujo de trabajo que requiera ejecutar comandos git o shell en varios repositorios secundarios a la vez.
