Используйте этот навык при управлении системами с несколькими репозиториями с помощью инструмента «мета» (github.com/mateodelnorte/meta). Запускает мета-клонирование git, мета-исполнение, создание/импорт/миграцию мета-проекта, координацию команд во многих репозиториях, запуск установок npm/yarn во всех проектах, миграцию монорепозитория в архитектуру с несколькими репозиториями или любой рабочий процесс, который требует одновременного запуска команд git или оболочки для нескольких дочерних репозиториев.
