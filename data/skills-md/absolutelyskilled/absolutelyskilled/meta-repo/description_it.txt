Utilizza questa competenza quando gestisci sistemi multi-repository utilizzando lo strumento "meta" (github.com/mateodelnorte/meta). Trigger su meta git clone, meta exec, meta project create/import/migrate, coordinamento di comandi su più repository, esecuzione di installazioni npm/yarn su tutti i progetti, migrazione di un monorepo su un'architettura multi-repo o qualsiasi flusso di lavoro che richieda l'esecuzione di comandi git o shell su più repository secondari contemporaneamente.
