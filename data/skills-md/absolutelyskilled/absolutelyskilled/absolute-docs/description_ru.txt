Документация на основе Diátaxis для агентов кодирования ИИ: написание, улучшение или аудит учебных пособий, практических инструкций, справочных материалов, объяснений и документации для разработчиков (README, CONTRIBUTING, ADR). Обнаруживает стек документов; ворота на набросках перед написанием прозы; проверяет каждую претензию на соответствие коду перед его отправкой. Триггеры: «абсолютная документация», «написать документацию», «написать учебник», «написать README», «задокументировать это», «улучшить этот документ», «проверить нашу документацию».
