Utilice esta habilidad al revisar, escribir o refactorizar código para garantizar su limpieza y mantenibilidad siguiendo los principios del Código Limpio de Robert C. Martin (Tío Bob). Activadores de revisión de código, refactorización, mejoras de nombres, descomposición de funciones, aplicación de principios SÓLIDOS, redacción de pruebas limpias con TDD, identificación de olores de código o mejora del manejo de errores. Cubre código limpio, SÓLIDO y desarrollo basado en pruebas.
