مهارة تسويقية موحدة لكل قناة ومرحلة. يُستخدم عند كتابة نسخة، أو تحسين التحويلات، أو تخطيط استراتيجية المحتوى، أو تشغيل عمليات تدقيق تحسين محركات البحث، أو إنشاء تسلسلات البريد الإلكتروني، أو إطلاق المنتجات، أو إعداد الإعلانات المدفوعة، أو تصميم الأسعار، أو تشغيل اختبارات A/B، أو صياغة موضع العلامة التجارية، أو أي مهمة تسويقية. يستبدل المهارات الفردية لكتابة النصوص، وتحسين محركات البحث، وتسويق المحتوى، والبريد الإلكتروني، ووسائل التواصل الاجتماعي، واختراق النمو، واستراتيجية العلامة التجارية، وCRO.
