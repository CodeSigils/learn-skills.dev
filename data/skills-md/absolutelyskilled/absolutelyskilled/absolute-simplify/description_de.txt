Vereinfacht automatisch den Code in Ihren Arbeitsänderungen oder Zieldateien. Erkennt gestaffelte oder nicht gestaffelte Git-Änderungen, analysiert Vereinfachungsmöglichkeiten nach den Grundsätzen sauberen Codes und sauberer Architektur, wendet Verbesserungen direkt an, führt Tests durch, um sicherzustellen, dass nichts kaputt geht, und zeigt eine strukturierte Zusammenfassung mit Begründung an. Wird ausgelöst bei „vereinfachen“, „umgestalten“, „meine Änderungen bereinigen“, „absolut vereinfachen“, „meinen Code vereinfachen“, „sauberer machen“, „aufräumen“, „Komplexität reduzieren“, „abflachen“, „toten Code entfernen“ oder wenn Code Verbesserungen der Klarheit, Verschachtelungsreduzierung oder Redundanzentfernung benötigt. Grundsätzlich sprachunabhängig mit fundierten Meinungen zu JS/TS/React, Python und Go.
