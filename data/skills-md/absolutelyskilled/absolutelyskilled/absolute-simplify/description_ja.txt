作業中の変更または対象のファイル内のコードを自律的に簡素化します。ステージングされた Git 変更またはステージングされていない Git 変更を検出し、クリーン コードとクリーン アーキテクチャの原則に従って簡素化の機会を分析し、改善を直接適用し、テストを実行して問題がないことを確認し、推論を含む構造化された概要を表示します。 「これを単純化する」、「これをリファクタリングする」、「変更をクリーンアップする」、「絶対的単純化」、「コードを単純化する」、「これをよりクリーンにする」、「これを整理する」、「複雑さを軽減する」、「これをフラット化する」、「デッド コードを削除する」、またはコードの明瞭性の向上、ネストの削減、または冗長性の削除が必要な場合にトリガーされます。基本的に言語に依存せず、JS/TS/React、Python、Go について深い意見を持っています。
