استخدم هذه المهارة عند تأمين البنية التحتية السحابية، أو تكوين سياسات IAM، أو إدارة الأسرار، أو تنفيذ سياسات الشبكة، أو تحقيق الامتثال. المشغلات على Cloud IAM، وإدارة الأسرار، ومجموعات أمان الشبكة، وأمن VPC، والامتثال السحابي، وSOC 2، وHIPAA، والثقة الصفرية، وأي مهمة تتطلب بنية أمان سحابية أو تقوية.
