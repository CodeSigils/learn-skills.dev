استخدم هذه المهارة عند العمل مع A2UI (واجهة وكيل إلى مستخدم) - بروتوكول Google المفتوح لواجهات المستخدم التعريفية التي يحركها الوكيل. تشغيل المهام التي تتضمن إنشاء رسائل A2UI، أو كتالوجات المكونات، أو ربط البيانات، أو إدارة السطح، أو تطوير العارض، أو المكونات المخصصة، أو دمج A2UI مع بروتوكول A2A، أو AG UI، أو أطر عمل الوكيل مثل Google ADK. يغطي إنشاء وكلاء يقومون بإنشاء A2UI JSON، وإعداد عارضي العميل (Lit، وReact، وAngular، وFlutter)، وإنشاء كتالوجات مخصصة، والتعامل مع إجراءات العميل إلى الخادم.
