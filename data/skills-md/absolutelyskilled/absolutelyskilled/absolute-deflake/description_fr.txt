Corrections de tests irréguliers : détectez les tests non déterministes de manière empirique (exécutions répétées/aléatoires/parallèles), diagnostiquez la cause première, corrigez-la (ne réessayez jamais, ne sautez pas/ne mettez pas en veille) et vérifiez sur de nombreuses exécutions aléatoires. Se déclenche sur « déflagration absolue », « réparer les tests instables », « CI est instable », « ce test échoue de manière aléatoire/intermittente ».
