استخدم هذه المهارة عند تصميم مستودعات البيانات، أو بناء مخططات النجمة أو ندفة الثلج، أو تنفيذ الأبعاد المتغيرة ببطء (SCDs)، أو كتابة SQL تحليلية لـ Snowflake أو BigQuery، أو إنشاء جداول الحقائق والأبعاد، أو تخطيط خطوط أنابيب ETL/ELT للتحليلات. يتم تشغيلها عند نمذجة الأبعاد، والمفاتيح البديلة، والأبعاد المطابقة، وهندسة المستودعات، وخزينة البيانات، واستراتيجيات التقسيم، وطرق العرض المادية، وأي مهمة تتطلب تصميم مخطط OLAP أو تحسين استعلام المستودع.
