استخدم هذه المهارة عند العمل مع PostHog - تحليلات المنتج، أو تحليلات الويب، أو علامات الميزات، أو اختبار A/B، أو التجارب، أو إعادة تشغيل الجلسة، أو تتبع الأخطاء، أو الاستطلاعات، أو إمكانية ملاحظة LLM، أو مستودع البيانات. يتم تشغيل أي مهمة متعلقة بـ PostHog بما في ذلك التقاط الأحداث، وتحديد المستخدمين، وتقييم علامات الميزات، وإنشاء التجارب، وإعداد الاستطلاعات، وتتبع الأخطاء، والاستعلام عن بيانات التحليلات عبر PostHog API أو SDKs (posthog-js، posthog-node، posthog-python).
