Utilisez cette compétence lorsque vous travaillez avec Vite+, vp CLI ou la chaîne d'outils unifiée VoidZero. Déclencheurs sur l'échafaudage de projet avec vp create, migration de projets Vite existants avec vp migrate, exécution de commandes dev/build/test/lint/fmt, configuration de vite.config.ts avec lint/fmt/test/run/pack/staged blocs, gestion des versions Node.js avec vp env, exécution de tâches monorepo avec vp run et packaging de bibliothèque avec vp pack.
