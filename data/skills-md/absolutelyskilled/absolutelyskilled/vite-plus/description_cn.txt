在使用 Vite+、vp CLI 或 VoidZero 统一工具链时使用此技能。使用 vp create 触发项目脚手架，使用 vp migrate 迁移现有 Vite 项目，运行 dev/build/test/lint/fmt 命令，使用 lint/fmt/test/run/pack/staged 块配置 vite.config.ts，使用 vp env 管理 Node.js 版本，使用 vp run 执行 monorepo 任务，以及使用 vp pack 进行库打包。还会在 Vite+ 上下文中引用 Oxlint、Oxfmt、Rolldown、tsdown、Vitest 或 Vite Task 时触发。
