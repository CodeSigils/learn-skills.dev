Используйте этот навык при работе с Vite+, vp CLI или единой цепочкой инструментов VoidZero. Запускает создание шаблонов проектов с помощью vp create, миграцию существующих проектов Vite с помощью vpmigrate, выполнение команд dev/build/test/lint/fmt, настройку vite.config.ts с помощью блоков lint/fmt/test/run/pack/staged, управление версиями Node.js с помощью vp env, выполнение задач монорепо с помощью vp run и упаковку библиотеки с помощью vp package. Также срабатывает при ссылках на Oxlint, Oxfmt, Rolldown, tsdown, Vitest или Vite Task в контексте Vite+.
