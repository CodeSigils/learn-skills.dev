Vite+、vp CLI、または VoidZero 統合ツールチェーンを使用する場合は、このスキルを使用します。 vp create によるプロジェクト スキャフォールディング、vp mite による既存の Vite プロジェクトの移行、dev/build/test/lint/fmt コマンドの実行、lint/fmt/test/run/pack/staged ブロックによる vite.config.ts の設定、vp env による Node.js バージョンの管理、vp run による Monorepo タスクの実行、および vp Pack によるライブラリのパッケージ化をトリガーします。また、Vite+ コンテキスト内の Oxlint、Oxfmt、Rolldown、tsdown、Vitest、または Vite Task への参照でもトリガーされます。
