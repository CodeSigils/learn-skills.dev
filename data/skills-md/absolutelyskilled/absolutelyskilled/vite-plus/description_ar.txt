استخدم هذه المهارة عند العمل مع Vite+ أو vp CLI أو سلسلة الأدوات الموحدة VoidZero. مشغلات على سقالات المشروع باستخدام vp create، وترحيل مشاريع Vite الحالية باستخدام vp migrate، وتشغيل أوامر dev/build/test/lint/fmt، وتكوين vite.config.ts باستخدام كتل lint/fmt/test/run/pack/staged، وإدارة إصدارات Node.js باستخدام vp env، وتنفيذ مهمة monorepo باستخدام vp run، وتغليف المكتبة باستخدام vp pack. يتم تشغيله أيضًا عند الإشارات إلى Oxlint، أو Oxfmt، أو Rolldown، أو tsdown، أو Vitest، أو Vite Task في سياق Vite+.
