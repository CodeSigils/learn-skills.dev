استخدم هذه المهارة عند إدارة خوادم Linux، أو كتابة نصوص برمجية، أو تكوين خدمات systemd، أو تصحيح أخطاء الشبكات، أو تعزيز الأمان. يتم تشغيلها عند البرمجة النصية bash، ووحدات systemd، وiptables، وجدار الحماية، وتكوين SSH، وأذونات الملفات، وإدارة العمليات، ووظائف cron، وإدارة القرص، وأي مهمة تتطلب إدارة نظام Linux.
