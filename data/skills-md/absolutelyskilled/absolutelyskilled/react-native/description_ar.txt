مهارة تطوير Expert React Native وExpo لبناء تطبيقات الهاتف المحمول عبر الأنظمة الأساسية. استخدم هذه المهارة عند إنشاء مشاريع React Native أو تصحيح أخطائها أو تحسينها - إعداد Expo، والوحدات الأصلية، والتنقل (React Navigation، وExpo Router)، وضبط الأداء (Hermes، وFlatList، ومنع إعادة العرض)، وتحديثات OTA (EAS Update، وCodePush)، وربط كود iOS/Android الأصلي. المشغلات في بنية تطبيقات الهاتف المحمول، والمكونات الإضافية لتكوين Expo، ونشر متجر التطبيقات، ودفع الإشعارات، ومهام React Native CLI.
