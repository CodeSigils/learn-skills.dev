クロスプラットフォーム モバイル アプリを構築するための React Native および Expo 開発スキルの専門家。このスキルは、React Native プロジェクトの作成、デバッグ、最適化 - Expo セットアップ、ネイティブ モジュール、ナビゲーション (React Navigation、Expo Router)、パフォーマンス チューニング (Hermes、FlatList、再レンダリング防止)、OTA アップデート (EAS Update、CodePush)、およびネイティブ iOS/Android コードのブリッジングを行うときに使用します。モバイル アプリ アーキテクチャ、Expo 構成プラグイン、アプリ ストア デプロイメント、プッシュ通知、および React Native CLI タスクをトリガーします。
