Compétences expertes en développement React Native et Expo pour la création d'applications mobiles multiplateformes. Utilisez cette compétence lors de la création, du débogage ou de l'optimisation de projets React Native : configuration d'Expo, modules natifs, navigation (React Navigation, Expo Router), réglage des performances (Hermes, FlatList, prévention du rendu), mises à jour OTA (EAS Update, CodePush) et pontage du code iOS/Android natif. Déclencheurs sur l'architecture des applications mobiles, les plugins de configuration Expo, le déploiement de l'App Store, les notifications push et les tâches React Native CLI.
