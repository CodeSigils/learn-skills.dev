Экспертные навыки разработки React Native и Expo для создания кроссплатформенных мобильных приложений. Используйте этот навык при создании, отладке или оптимизации проектов React Native — настройка Expo, собственные модули, навигация (React Navigation, Expo Router), настройка производительности (Hermes, FlatList, предотвращение повторного рендеринга), OTA-обновления (EAS Update, CodePush) и объединение собственного кода iOS/Android. Запускается по архитектуре мобильных приложений, плагинам конфигурации Expo, развертыванию в магазине приложений, push-уведомлениям и задачам React Native CLI.
