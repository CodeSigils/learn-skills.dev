Competenze esperte di sviluppo React Native ed Expo per la creazione di app mobili multipiattaforma. Utilizza questa competenza durante la creazione, il debug o l'ottimizzazione di progetti React Native: configurazione Expo, moduli nativi, navigazione (React Navigation, Expo Router), ottimizzazione delle prestazioni (Hermes, FlatList, prevenzione del re-render), aggiornamenti OTA (aggiornamento EAS, CodePush) e collegamento del codice iOS/Android nativo. Trigger sull'architettura delle app mobili, plug-in di configurazione di Expo, distribuzione dell'app store, notifiche push e attività della CLI React Native.
