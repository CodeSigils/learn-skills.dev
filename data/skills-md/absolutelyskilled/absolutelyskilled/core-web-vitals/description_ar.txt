استخدم هذه المهارة عند تحسين مؤشرات الويب الأساسية - LCP (أكبر رسم محتوى)، وINP (التفاعل مع الطلاء التالي)، وCLS (إزاحة التخطيط التراكمي). مشغلات لتحسين سرعة الصفحة، وتحسين نقاط Lighthouse، وإصلاح تحولات التخطيط، وتحسين الاستجابة، وإعداد مراقبة الأداء باستخدام CrUX أو RUM، وإصلاحات CWV الخاصة بإطار العمل لـ Next.js، وNuxt، وAstro، وRemix.
