Используйте этот навык при оптимизации основных веб-показателей — LCP (наибольшая отрисовка контента), INP (взаимодействие с следующей отрисовкой) и CLS (кумулятивный сдвиг макета). Триггеры при оптимизации скорости страницы, улучшении оценки Lighthouse, исправлении сдвигов макета, улучшении отзывчивости, настройке мониторинга производительности с помощью CrUX или RUM, а также исправлениях CWV для конкретной платформы для Next.js, Nuxt, Astro и Remix.
