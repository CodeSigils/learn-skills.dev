Utilisez cette compétence lors de la rédaction, de la révision ou de la structuration de la documentation technique pour des projets logiciels. Déclencheurs sur la documentation de l'API, les didacticiels, les enregistrements de décision d'architecture (ADR), les runbooks, les guides d'intégration, les fichiers README ou toute prose destinée aux développeurs. Couvre la structure de la documentation, le style d'écriture, l'analyse d'audience et les flux de travail de documentation en tant que code pour les équipes d'ingénierie.
