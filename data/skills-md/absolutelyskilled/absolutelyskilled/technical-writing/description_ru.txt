Используйте этот навык при написании, просмотре или структурировании технической документации для программных проектов. Триггеры по документации API, руководствам, записям решений по архитектуре (ADR), модулям Runbook, руководствам по адаптации, файлам README или любой другой прозе, предназначенной для разработчиков. Охватывает структуру документации, стиль письма, анализ аудитории и рабочие процессы «документ как код» для инженерных команд.
