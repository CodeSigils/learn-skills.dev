استخدم هذه المهارة عند تنفيذ عمليات git المتقدمة، أو إستراتيجيات إعادة الأساس، أو تقسيم الأخطاء، أو إدارة أشجار العمل، أو تكوين الخطافات، أو التعامل مع سيناريوهات الدمج المعقدة. يتم تشغيلها عند إعادة القاعدة التفاعلية، وتقسيم git، وأشجار العمل، وخطافات الالتزام المسبق، والاختيار الكرزي، واسترداد إعادة التسجيل، وإدارة المخزون، وأي مهمة تتطلب سير عمل git متقدم.
