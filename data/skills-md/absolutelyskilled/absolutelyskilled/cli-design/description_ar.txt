استخدم هذه المهارة عند إنشاء واجهات سطر الأوامر، أو تصميم موزعي وسيطات CLI، أو كتابة نص التعليمات، أو إضافة مطالبات تفاعلية، أو إدارة ملفات التكوين، أو توزيع أدوات CLI. يتم تشغيلها عند تحليل الوسيطة، والأوامر الفرعية، والأعلام، والوسائط الموضعية، وأنابيب stdin/stdout، وإكمالات الصدفة، والقوائم التفاعلية، وتكوين ملف dotfile، وتعبئة واجهات سطر الأوامر (CLIs) مثل ثنائيات npm/pip/cargo/go.
