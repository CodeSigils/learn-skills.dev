استخدم هذه المهارة عند تصميم واجهات برمجة التطبيقات، أو الاختيار بين REST/GraphQL/gRPC، أو كتابة مواصفات OpenAPI، أو تنفيذ ترقيم الصفحات، أو إصدار نقاط النهاية، أو هيكلة مخططات الطلب/الاستجابة. مشغلات عند تصميم واجهة برمجة التطبيقات (API)، وتسمية نقطة النهاية، وأساليب HTTP، ورموز الحالة، وتحديد المعدل، وأنظمة المصادقة، وHATEOAS، ومعلمات الاستعلام، وأي مهمة تتطلب قرارات تتعلق ببنية واجهة برمجة التطبيقات (API).
