Используйте этот навык при управлении панелями, поверхностями и рабочими пространствами терминала cmux из Claude Code или любого агента искусственного интеллекта. Запускается при создании разделенных панелей для субагентов, отправке команд на поверхности терминала, чтении вывода с экрана, создании/закрытии рабочих пространств, автоматизации браузера через cmux и любой задаче, требующей оркестровки терминала с несколькими панелями. Также срабатывает при «cmux», «разделенной панели», «новой панели», «экране чтения», «отправке команды на панель» или разработке под управлением субагента, требующей изолированных поверхностей терминала.
