Verwenden Sie diese Fähigkeit, wenn Sie cmux-Terminalfenster, -Oberflächen und -Arbeitsbereiche über Claude Code oder einen beliebigen KI-Agenten verwalten. Löst das Erzeugen geteilter Fenster für Unteragenten, das Senden von Befehlen an Terminaloberflächen, das Lesen der Bildschirmausgabe, das Erstellen/Schließen von Arbeitsbereichen, die Browserautomatisierung über cmux und alle Aufgaben aus, die eine Terminal-Orchestrierung mit mehreren Fenstern erfordern. Wird auch bei „cmux“, „Split Pane“, „New-Pane“, „Read-Screen“, „Send Command to Pane“ oder bei subagentgesteuerter Entwicklung ausgelöst, die isolierte Terminaloberflächen erfordert.
