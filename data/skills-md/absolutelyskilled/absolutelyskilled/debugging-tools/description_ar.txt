استخدم هذه المهارة عند تصحيح أخطاء التطبيقات باستخدام Chrome DevTools أو lldb أو strace أو أدوات الشبكة أو ملفات تعريف الذاكرة. المشغلات على Chrome DevTools، ومصحح الأخطاء، ونقاط التوقف، وتصحيح أخطاء الشبكة، وملفات تعريف الذاكرة، وstrace، وltrace، ومقالب التفريغ الأساسية، وأي مهمة تتطلب تصحيحًا منهجيًا باستخدام أدوات متخصصة.
