用于 AI 编码代理的专注开发工作流引擎，以“/absolute <command> [target]”形式调用。一技能，十一条命令。一个设置：“init”（询问您希望绝对如何表现+检测一次堆栈，然后编写 JSON 配置 - 每个项目的“.absolute.config.json”和用于用户默认值和每个项目覆盖的“~/.absolute/config.json” - 每个其他命令都会读取而不是重新检测；非阻塞，其他命令软推荐它）。五个涵盖您每天运行的构建循环 - 思考 → 规范 → 计划 → 构建 → 完善 → 文档：“工作”（端到端、阶段控制的 SDLC：无休止的设计面试 → 审查规范 → 依赖关系图任务板 → 安全波 TDD 执行 → 验证）、“规范”（轻量级独立设计规范：代码库扫描 → 有界澄清传递 → 将审查的设计文档写入文档/计划 → 评分审阅者子代理 → 停止，无构建）、“ui”（完善、有意）具有具体 CSS/Tailwind 值的界面设计 — 版式、颜色、布局、深色模式、可访问性、动画）、`simplify`（自动简化工作 git 更改 — 降低复杂性、删除冗余、保持测试绿色）和 `docs`（Diátaxis 驱动的文档 — 教程、操作方法、参考、解释、自述文件、ADR，具有堆栈检测和代码验证的准确性）。另外五个保持代码库健康 - 在绿色主干上进行常设维护，每个都是风险排名、门控、安全波扫描和修复：“升级”（依赖项升级 - 过时/易受攻击的 deps 在 semver 波中碰撞，专业门控和更改日志读取，每次测试后绿色），“审计”（漏洞和安全扫描 - 依赖项 CVE 加上风险代码模式，严重性分类和修复；防御性，在您自己的存储库上）， `prune`（死代码和依赖项清理 - 未使用的 deps、导出、带证据删除的文件、整个存储库）、`debt` （lint 和类型检查债务偿还 - 按规则清除预先存在的警告/错误和抑制，不欺骗检查器）和 `deflake`（片状测试修复 - 诊断并修复根本的不确定性，从不重试/跳过/睡眠）。触发“absolute init|work|spec|ui|simplify|docs|upgrade|audit|prune|debt|deflake”、“设置absolute”、“初始化absolute”、“配置absolute”、“构建这个端到端”、“计划和构建”、“拷问我”、“写一个规范”、“起草一个设计文档”、“设计这个UI”、“让这个不像AI slop”、 “简化此操作”、“清理我的更改”、“编写文档”、“审核我们的文档”、“升级我们的依赖项”、“我们是否容易受到攻击”、“安全审核”、“删除死代码”、“修复我们的 lint/类型错误”、“修复片状测试”或任何多步骤开发、设计、清理、文档或维护任务。
