Competenze senior di ingegneria frontend per la creazione di interfacce web di alta qualità. Utilizza questa competenza durante la scrittura, la revisione o l'ottimizzazione del codice frontend: HTML, CSS, JavaScript, TypeScript, componenti, layout, moduli o interfaccia utente interattiva. Trigger sull'ottimizzazione delle prestazioni web (Core Web Vitals, dimensione del bundle, caricamento lento), controlli di accessibilità (WCAG, ARIA, navigazione da tastiera, lettori di schermo), revisioni della qualità del codice, decisioni sull'architettura dei componenti, strategia di test e modelli CSS moderni. Copre l'intero spettro del frontend, dal markup semantico alle prestazioni di produzione.
