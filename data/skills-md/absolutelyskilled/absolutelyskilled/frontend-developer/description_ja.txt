高品質の Web インターフェイスを構築するためのフロントエンド エンジニアリングの上級専門知識。このスキルは、フロントエンド コード (HTML、CSS、JavaScript、TypeScript、コンポーネント、レイアウト、フォーム、またはインタラクティブ UI) を作成、レビュー、または最適化するときに使用します。 Web パフォーマンスの最適化 (コア Web Vitals、バンドル サイズ、遅延読み込み)、アクセシビリティ監査 (WCAG、ARIA、キーボード ナビゲーション、スクリーン リーダー)、コード品質レビュー、コンポーネント アーキテクチャの決定、テスト戦略、最新の CSS パターンをトリガーします。セマンティック マークアップから運用パフォーマンスに至るまで、フロントエンドの領域全体をカバーします。
