Expertise senior en ingénierie frontend pour la création d’interfaces Web de haute qualité. Utilisez cette compétence lors de l'écriture, de la révision ou de l'optimisation du code frontend : HTML, CSS, JavaScript, TypeScript, composants, mises en page, formulaires ou interface utilisateur interactive. Déclencheurs sur l'optimisation des performances Web (Core Web Vitals, taille du bundle, chargement différé), les audits d'accessibilité (WCAG, ARIA, navigation au clavier, lecteurs d'écran), les révisions de la qualité du code, les décisions d'architecture des composants, la stratégie de test et les modèles CSS modernes. Couvre le spectre complet du frontend, du balisage sémantique aux performances de production.
