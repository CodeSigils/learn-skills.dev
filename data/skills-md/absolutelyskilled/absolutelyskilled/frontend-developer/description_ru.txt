Старший интерфейсный инженер для создания высококачественных веб-интерфейсов. Используйте этот навык при написании, проверке или оптимизации кода внешнего интерфейса — HTML, CSS, JavaScript, TypeScript, компонентов, макетов, форм или интерактивного пользовательского интерфейса. Триггеры по оптимизации веб-производительности (Core Web Vitals, размер пакета, отложенная загрузка), аудиту доступности (WCAG, ARIA, навигация с клавиатуры, программы чтения с экрана), проверкам качества кода, решениям по архитектуре компонентов, стратегии тестирования и современным шаблонам CSS. Охватывает весь спектр интерфейса: от семантической разметки до производительности.
