خبرة هندسية كبيرة في الواجهة الأمامية لبناء واجهات ويب عالية الجودة. استخدم هذه المهارة عند كتابة كود الواجهة الأمامية أو مراجعته أو تحسينه - HTML أو CSS أو JavaScript أو TypeScript أو المكونات أو التخطيطات أو النماذج أو واجهة المستخدم التفاعلية. المشغلات المتعلقة بتحسين أداء الويب (مؤشرات الويب الأساسية، وحجم الحزمة، والتحميل البطيء)، وعمليات تدقيق إمكانية الوصول (WCAG، وARIA، والتنقل عبر لوحة المفاتيح، وبرامج قراءة الشاشة)، ومراجعات جودة التعليمات البرمجية، وقرارات بنية المكونات، واستراتيجية الاختبار، وأنماط CSS الحديثة. يغطي نطاق الواجهة الأمامية بالكامل بدءًا من العلامات الدلالية وحتى أداء الإنتاج.
