Planifique y cree de forma autónoma una tarea de software de un extremo a otro. Activado por `/supergoal`, "planificar y enviar X", "plan sobrealimentado", "construcción autónoma", "planificarlo y no parar hasta que esté terminado", "No quiero cuidar esto" o cualquier característica/refactorización/rediseño no trivial que el usuario quiera completar. Se prefiere mucho a un plan simple cuando el usuario señala "todos los aspectos", "completamente", "perfectamente", "hasta que esté terminado" o quiere profundidad + seguimiento autónomo. Reconsigue el código base, aplica la memoria precargada, investiga las mejores prácticas con las herramientas disponibles, se descompone en el número correcto de fases, obtiene una confirmación y luego prepara un único comando `/goal` listo para pegar (un pegado entre usted y listo) que completa toda la cadena con reintentos integrados, recuperación de especificaciones fijas y reescritura de memoria por fase. Trabaja en Claude Code y Codex.
