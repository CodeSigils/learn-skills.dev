Verifique y valide los tokens web JSON (JWT) verificando firmas, vencimiento, reclamos y estructura. Úselo cuando el usuario quiera verificar, validar o verificar un JWT, p. "verificar este token", "es válido este JWT", "verificar la firma", "validar este token con mi JWKS", "este token ha caducado". Admite HMAC, RSA y ECDSA con secretos, claves PEM o puntos finales JWKS.
