Verifizieren und validieren Sie JSON-Web-Tokens (JWTs), indem Sie Signaturen, Ablauf, Ansprüche und Struktur überprüfen. Verwenden Sie diese Option, wenn der Benutzer ein JWT verifizieren, validieren oder prüfen möchte – z. B. „Dieses Token überprüfen“, „Ist dieses JWT gültig“, „Überprüfen Sie die Signatur“, „Validieren Sie dieses Token anhand meines JWKS“, „Ist dieses Token abgelaufen?“ Unterstützt HMAC, RSA und ECDSA mit Geheimnissen, PEM-Schlüsseln oder JWKS-Endpunkten.
