Verifica e convalida i token Web JSON (JWT) controllando firme, scadenza, attestazioni e struttura. Utilizzare quando l'utente desidera verificare, convalidare o controllare un JWT, ad es. "verifica questo token", "questo JWT è valido", "controlla la firma", "convalida questo token rispetto al mio JWKS", "questo token è scaduto". Supporta HMAC, RSA ed ECDSA con segreti, chiavi PEM o endpoint JWKS.
