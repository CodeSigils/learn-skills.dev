Decodifica e inspecciona tokens web JSON (JWT) sin verificación. Úselo cuando el usuario proporciona una cadena JWT y desea ver su encabezado, carga útil o reclamos, p. "decodificar este JWT", "qué hay en este token", "inspeccionar este JWT", "muéstrame los reclamos", "analizar este token". También se activa en cadenas JWT sin formato (tres segmentos de URL base64 separados por puntos).
