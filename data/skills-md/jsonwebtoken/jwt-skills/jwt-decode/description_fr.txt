Décodez et inspectez les jetons Web JSON (JWT) sans vérification. À utiliser lorsque l'utilisateur fournit une chaîne JWT et souhaite voir son en-tête, sa charge utile ou ses revendications, par exemple. "décoder ce JWT", "qu'est-ce qu'il y a dans ce jeton", "inspecter ce JWT", "montrer-moi les réclamations", "analyser ce jeton". Se déclenche également sur les chaînes JWT brutes (trois segments base64url séparés par des points).
