Создавайте и подписывайте веб-токены JSON (JWT) для тестирования и разработки. Используйте, когда пользователь хочет сгенерировать, создать, построить или подписать JWT — например. «создать JWT», «сгенерировать тестовый токен», «подписать эту полезную нагрузку», «создать JWT с этими утверждениями», «создать токен доступа». Поддерживает алгоритмы HMAC, RSA и ECDSA.
