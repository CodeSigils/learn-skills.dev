Erstellen und signieren Sie JSON Web Tokens (JWTs) zum Testen und Entwickeln. Verwenden Sie diese Option, wenn der Benutzer ein JWT generieren, erstellen, erstellen oder signieren möchte – z. B. „JWT erstellen“, „Testtoken generieren“, „Diese Nutzlast signieren“, „JWT mit diesen Ansprüchen erstellen“, „Zugriffstoken erstellen“. Unterstützt HMAC-, RSA- und ECDSA-Algorithmen.
