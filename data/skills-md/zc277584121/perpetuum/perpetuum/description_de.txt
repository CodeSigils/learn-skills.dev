Richten Sie eine dauerhafte mehrschichtige Agentenschleife „Erkunden → Ausführen → Eskalieren“ für ein Projekt ein, überwachen und steuern Sie sie. Verwenden Sie diese Funktion immer dann, wenn ein Benutzer darum bittet, dass ein Agent sitzungs- oder tagelang eine Aufgabe weiterführt – Fehler finden, Texte verfeinern, einen Stil verfeinern, Feeds beobachten, nach Lücken suchen oder jede andere Aufgabe, deren Wert mit der Anzahl der Erkenntnisse wächst, die der Agent generiert. Verwenden Sie es auch, wenn der Benutzer eine bereits laufende Perpetuum-Aufgabe überprüfen, anhalten, fortsetzen, stoppen oder eine neue Anweisung an sie senden möchte.
