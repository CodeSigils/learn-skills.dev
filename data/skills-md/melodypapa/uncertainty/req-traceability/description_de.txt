Verwenden Sie diese Funktion, wenn Sie Anforderungen erstellen, Testfälle ableiten, Testspezifikationen generieren, die Testabdeckung analysieren, Testabweichungen erkennen oder die bidirektionale Rückverfolgbarkeit zwischen Anforderungen, Code und Tests aufrechterhalten. Triggers for requirements extraction, test design, coverage gaps, UNCOVERED_REQ, STALE_TEST, TEST_DRIFT, ISO 29119-4 techniques.
