قم بتشغيل واختبار T3 Code Mobile على جهاز محاكاة iOS أو محاكي Android مقابل بيئات T3 المحلية التي يمكن التخلص منها، بما في ذلك إعادة استخدام Metro وعميل المطورين، وقرارات إعادة البناء الأصلية، والاقتران لكل عميل، والمشاريع المصنفة، والتحكم الدلالي في واجهة المستخدم، ولقطات الشاشة، وتدفق خدمة iOS. يُستخدم بعد واجهة مستخدم الهاتف المحمول أو التغييرات الأصلية، عند إعادة إنتاج سلوك الهاتف أو الجهاز اللوحي، أو إقران المحاكي بحالة معزولة، أو التحقق من سلوك الهاتف المحمول على نظام التشغيل macOS، أو Linux، أو Windows.
