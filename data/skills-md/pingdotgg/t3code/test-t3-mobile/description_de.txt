Starten und testen Sie T3 Code Mobile auf einem iOS-Simulator oder Android-Emulator in verfügbaren lokalen T3-Umgebungen, einschließlich Metro- und Dev-Client-Wiederverwendung, nativen Neuerstellungsentscheidungen, pro-Client-Kopplung, gesetzten Projekten, semantischer UI-Steuerung, Screenshots und iOS-Serve-Sim-Streaming. Wird nach Änderungen an der mobilen Benutzeroberfläche oder nativen Änderungen verwendet, wenn Sie das Verhalten von Telefonen oder Tablets reproduzieren, einen Emulator in den isolierten Zustand koppeln oder das mobile Verhalten unter macOS, Linux oder Windows überprüfen.
