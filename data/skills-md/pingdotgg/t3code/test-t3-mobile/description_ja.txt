iOS シミュレータまたは Android エミュレータ上で T3 コード モバイルを起動し、使い捨てのローカル T3 環境に対してテストします。これには、Metro および開発クライアントの再利用、ネイティブ リビルドの決定、クライアントごとのペアリング、シードされたプロジェクト、セマンティック UI コントロール、スクリーンショット、iOS サーブシム ストリーミングが含まれます。モバイル UI またはネイティブの変更後、携帯電話やタブレットの動作を再現する場合、エミュレータを分離状態にペアリングする場合、または macOS、Linux、または Windows でのモバイルの動作を確認する場合に使用します。
