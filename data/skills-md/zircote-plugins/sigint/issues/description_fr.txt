Orchestre l'agent d'architecte de problèmes à l'aide du modèle d'essaim complet (TeamCreate → TaskCreate → Agent (team_name) → SendMessage → TeamDelete). Utilisez cette compétence lorsque l'utilisateur invoque /sigint:issues.
