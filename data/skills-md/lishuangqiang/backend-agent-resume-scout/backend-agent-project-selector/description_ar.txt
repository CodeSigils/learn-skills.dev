يمكنك العثور على الواجهة الخلفية للبرامج التقليدية أو مشاريع وكيل الذكاء الاصطناعي على مستوى الأعمال من GitHub للطلاب أو المهندسين في بداية حياتهم المهنية، وتقييم قيمة السيرة الذاتية، وإنشاء حزمة كتابة السيرة الذاتية Markdown. يُستخدم عندما يطلب المستخدم اختيار مشاريع الواجهة الخلفية، أو مشاريع Java/Spring، أو مشاريع النظام الموزع، أو مشاريع أعمال وكيل الذكاء الاصطناعي الكاملة، أو الأنظمة متعددة الوكلاء، أو تطبيقات LLM، أو مشاريع GitHub للسير الذاتية، أو تحويل المشاريع المحددة إلى نقاط نقاش للسيرة الذاتية/مقابلات. يدعم الأوضاع: الوكيل فقط، والواجهة الخلفية فقط، والوضع المختلط، والوضع الآمن، ووضع التحدي. إذا لم يتم تحديد أي وضع، فاطلب من المستخدم الاختيار قبل البحث أو التوصية. تستبعد توصيات الواجهة الخلفية إنترنت الأشياء، والأنظمة المدمجة، وتكامل الأجهزة، وإدارة الأجهزة، ومنصات التحكم الصناعية ما لم يُطلب ذلك. تجنب ملحقات المتصفح البسيطة، وأغلفة LLM الرفيعة، ومكونات الذكاء الاصطناعي الإضافية السطحية، ومكتبات أتمتة المتصفح ما لم يُطلب ذلك.
