学生や若手エンジニアに適した従来のソフトウェア バックエンドまたはビジネス グレードの AI エージェント プロジェクトを GitHub から見つけ、履歴書の価値を評価し、Markdown 履歴書作成パッケージを生成します。ユーザーがバックエンド プロジェクト、Java/Spring プロジェクト、分散システム プロジェクト、完全な AI エージェント ビジネス プロジェクト、マルチエージェント システム、LLM アプリ、履歴書用の GitHub プロジェクトを選択するか、選択したプロジェクトを履歴書の箇条書き/面接の論点に変えるように要求する場合に使用します。サポートするモード: エージェントのみ、バックエンドのみ、混合、セーフ モード、チャレンジ モード。モードが指定されていない場合は、検索または推奨する前にユーザーに選択を依頼します。バックエンドの推奨事項には、要求がない限り、IoT、組み込み、ハードウェア統合、デバイス管理、産業用制御プラットフォームは含まれません。要求がない限り、単純なブラウザ拡張機能、薄い LLM ラッパー、浅い AI プラグイン、およびブラウザ自動化ライブラリは避けてください。
