Trouvez des projets de backend logiciels traditionnels ou d'agents d'IA de qualité professionnelle adaptés à partir de GitHub pour les étudiants ou les ingénieurs en début de carrière, évaluez la valeur du CV et générez un package de rédaction de CV Markdown. À utiliser lorsqu'un utilisateur demande de choisir des projets backend, des projets Java/Spring, des projets de systèmes distribués, des projets commerciaux complets d'agents d'IA, des systèmes multi-agents, des applications LLM, des projets GitHub pour les CV, ou de transformer les projets sélectionnés en puces de CV/points de discussion d'entretien. Modes pris en charge : agent uniquement, backend uniquement, mixte, mode sans échec et mode défi. Si aucun mode n'est spécifié, demandez à l'utilisateur de choisir avant de rechercher ou de recommander. Les recommandations back-end excluent les plates-formes IoT, embarquées, d’intégration matérielle, de gestion des appareils et de contrôle industriel, sauf demande. Évitez les extensions de navigateur simples, les wrappers LLM légers, les plugins d'IA superficiels et les bibliothèques d'automatisation du navigateur, sauf sur demande.
