Найдите на GitHub подходящие традиционные программные серверные части или проекты агентов искусственного интеллекта бизнес-класса для студентов или начинающих инженеров, оцените ценность резюме и создайте пакет для написания резюме в формате Markdown. Используйте, когда пользователь просит выбрать серверные проекты, проекты Java/Spring, проекты распределенных систем, полные бизнес-проекты агентов искусственного интеллекта, многоагентные системы, приложения LLM, проекты GitHub для резюме или превратить выбранные проекты в списки резюме/темы для обсуждения на собеседовании. Поддерживает режимы: только агент, только серверная часть, смешанный, безопасный режим и режим вызова. Если режим не указан, попросите пользователя выбрать его, прежде чем искать или рекомендовать. Рекомендации по серверной части исключают платформы Интернета вещей, встроенные платформы, платформы аппаратной интеграции, управления устройствами и промышленного контроля, если это не требуется. Избегайте простых расширений браузера, тонких оболочек LLM, поверхностных плагинов искусственного интеллекта и библиотек автоматизации браузера, если это не требуется.
