Encuentre proyectos de backend de software tradicional o agentes de IA de nivel empresarial adecuados en GitHub para estudiantes o ingenieros que inician su carrera, evalúe el valor del currículum y genere un paquete de redacción de currículum Markdown. Úselo cuando un usuario solicite elegir proyectos backend, proyectos Java/Spring, proyectos de sistemas distribuidos, proyectos comerciales completos de agentes de IA, sistemas multiagente, aplicaciones LLM, proyectos GitHub para currículums o convertir proyectos seleccionados en viñetas de currículum/puntos de conversación de entrevistas. Admite modos: solo agente, solo backend, mixto, modo seguro y modo desafío. Si no se especifica ningún modo, solicite al usuario que elija antes de buscar o recomendar. Las recomendaciones de backend excluyen plataformas de IoT, integradas, de integración de hardware, de administración de dispositivos y de control industrial, a menos que se soliciten. Evite extensiones de navegador simples, envoltorios LLM delgados, complementos de inteligencia artificial poco profundos y bibliotecas de automatización del navegador a menos que se soliciten.
