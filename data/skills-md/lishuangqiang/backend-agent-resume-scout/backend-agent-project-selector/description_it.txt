Trova backend software tradizionali adatti o progetti di agenti AI di livello aziendale da GitHub per studenti o ingegneri all'inizio della carriera, valuta il valore del curriculum e genera un pacchetto di scrittura del curriculum Markdown. Da utilizzare quando un utente chiede di scegliere progetti backend, progetti Java/Spring, progetti di sistemi distribuiti, progetti aziendali completi di agenti AI, sistemi multi-agente, app LLM, progetti GitHub per curriculum o trasformare progetti selezionati in elenchi puntati di curriculum/punti di discussione per interviste. Supporta le modalità: solo agente, solo backend, mista, modalità provvisoria e modalità sfida. Se non viene specificata alcuna modalità, chiedi all'utente di scegliere prima di cercare o consigliare. Le raccomandazioni di backend escludono piattaforme IoT, integrate, di integrazione hardware, di gestione dei dispositivi e di controllo industriale, a meno che non siano richieste. Evita semplici estensioni del browser, wrapper LLM sottili, plug-in AI superficiali e librerie di automazione del browser se non richiesto.
