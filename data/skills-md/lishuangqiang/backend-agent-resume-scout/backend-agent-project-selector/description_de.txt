Finden Sie auf GitHub geeignete traditionelle Software-Backend- oder KI-Agent-Projekte für Unternehmen für Studenten oder junge Ingenieure, bewerten Sie den Wert Ihres Lebenslaufs und erstellen Sie ein Markdown-Paket zum Verfassen von Lebensläufen. Verwenden Sie diese Option, wenn ein Benutzer Backend-Projekte, Java/Spring-Projekte, Projekte für verteilte Systeme, vollständige KI-Agent-Geschäftsprojekte, Multi-Agent-Systeme, LLM-Apps, GitHub-Projekte für Lebensläufe auswählen oder ausgewählte Projekte in Lebenslauf-Aufzählungspunkte/Interview-Gesprächsthemen umwandeln möchte. Unterstützt Modi: Nur Agent, Nur Backend, Gemischt, Abgesicherter Modus und Herausforderungsmodus. Wenn kein Modus angegeben ist, bitten Sie den Benutzer, ihn auszuwählen, bevor er sucht oder empfiehlt. Backend-Empfehlungen schließen IoT-, Embedded-, Hardware-Integrations-, Geräteverwaltungs- und Industriesteuerungsplattformen aus, sofern nicht anders gewünscht. Vermeiden Sie einfache Browsererweiterungen, dünne LLM-Wrapper, flache KI-Plugins und Browser-Automatisierungsbibliotheken, sofern Sie nicht dazu aufgefordert werden.
