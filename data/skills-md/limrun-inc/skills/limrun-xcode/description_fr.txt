Créez une application iOS/Apple sur Xcode distant avec `lim xcode build` au lieu de xcodebuild local, depuis n'importe quel environnement (Linux, Windows, macOS, VM, conteneur). À utiliser pour les projets non Bazel (un `.xcodeproj` / `.xcworkspace`, un XcodeGen `project.yml` avec un projet gitignoré, une version native de React Native / Expo) lorsque l'utilisateur souhaite créer, compiler, recharger, produire une version préliminaire ou expédier une IPA de périphérique signée. Pour exécuter, appuyer, faire une capture d'écran ou interagir de toute autre manière avec le résultat sur un simulateur, utilisez limrun-ios-simulator. Pour les espaces de travail Bazel, utilisez limrun-xcode-bazel.
