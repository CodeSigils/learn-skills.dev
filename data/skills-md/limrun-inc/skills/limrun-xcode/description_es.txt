Cree una aplicación iOS/Apple en Xcode remoto con `lim xcode build` en lugar de xcodebuild local, desde cualquier entorno (Linux, Windows, macOS, VM, contenedor). Úselo para proyectos que no sean de Bazel (un `.xcodeproj`/`.xcworkspace`, un `project.yml` de XcodeGen con un proyecto ignorado por git, compilación nativa de React Native/Expo) cuando el usuario desee compilar, compilar, recargar, producir una compilación preliminar o enviar un IPA de dispositivo firmado. Para ejecutar, tocar, hacer capturas de pantalla o interactuar de otro modo con el resultado en un simulador, utilice limrun-ios-simulator. Para espacios de trabajo de Bazel, utilice limrun-xcode-bazel.
