Создайте приложение iOS/Apple на удаленном Xcode с помощью `lim xcode build` вместо локального xcodebuild из любой среды (Linux, Windows, macOS, VM, контейнер). Используйте для проектов, отличных от Bazel (`.xcodeproj`/`.xcworkspace`, XcodeGen`project.yml` с проектом gitignored, собственная сборка React Native/Expo), когда пользователь хочет собрать, скомпилировать, перезагрузить, создать предварительную сборку или отправить подписанный IPA устройства. Чтобы запустить, коснуться, сделать снимок экрана или иным образом взаимодействовать с результатом на симуляторе, используйте limrun-ios-simulator. Для рабочих пространств Bazel используйте limrun-xcode-bazel.
