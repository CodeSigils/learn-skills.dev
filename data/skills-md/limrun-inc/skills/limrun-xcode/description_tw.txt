從任何環境（Linux、Windows、macOS、VM、容器）使用“lim xcode build”而不是本地 xcodebuild 在遠端 Xcode 上建立 iOS / Apple 應用程式。當使用者想要建置、編譯、重新載入、產生預覽版本或傳送簽章設備 IPA 時，用於非 Bazel 專案（`.xcodeproj` / `.xcworkspace`、帶有 gitignored 專案的 XcodeGen `project.yml`、React Native / Expoignored 專案的 XcodeGen `project.yml`、React Native / Expoign 機構建置）。要在模擬器上運行、點擊、螢幕截圖或以其他方式與結果交互，請使用 limrun-ios-simulator。對於 Bazel 工作區，請使用 limrun-xcode-bazel。
