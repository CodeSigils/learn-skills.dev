Erstellen Sie eine iOS-/Apple-App auf Remote-Xcode mit „lim xcode build“ anstelle von lokalem xcodebuild, aus jeder Umgebung (Linux, Windows, macOS, VM, Container). Verwendung für Nicht-Bazel-Projekte (ein „.xcodeproj“ / „.xcworkspace“, ein XcodeGen „project.yml“ mit einem gitignorierten Projekt, ein nativer React Native-/Expo-Build), wenn der Benutzer ein signiertes Geräte-IPA erstellen, kompilieren, neu laden, einen Vorschau-Build erstellen oder versenden möchte. Verwenden Sie limrun-ios-simulator, um das Ergebnis auf einem Simulator auszuführen, darauf zu tippen, einen Screenshot davon zu machen oder auf andere Weise mit ihm zu interagieren. Verwenden Sie für Bazel-Arbeitsbereiche limrun-xcode-bazel.
