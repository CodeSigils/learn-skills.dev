Exécutez les flux Maestro YAML sur un simulateur iOS cloud Limrun avec `lim ios maestro`, depuis n'importe quel environnement (Linux, Windows, macOS, VM, conteneur). À utiliser lorsque l'utilisateur souhaite exécuter, écrire ou déboguer des flux Maestro ou un « test maestro » sur iOS, migrer une suite Maestro existante vers des simulateurs distants ou demande des tests d'interface utilisateur avec Maestro. Simulateurs iOS seulement aujourd'hui. Pour les suites Detox, utilisez limrun-detox-testing ; pour piloter le simulateur sans framework de test, utilisez limrun-ios-simulator.
