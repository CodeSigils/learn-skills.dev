Запускайте потоки YAML Maestro на облачном симуляторе iOS Limrun с помощью lim ios maestro из любой среды (Linux, Windows, macOS, VM, контейнер). Используйте его, когда пользователь хочет запустить, написать или отладить потоки Maestro или «тест maestro» на iOS, перенести существующий пакет Maestro на удаленные симуляторы или запрашивает тестирование пользовательского интерфейса с помощью Maestro. Симуляторы iOS только сегодня. Для детокс-пакетов используйте limrun-detox-testing; для управления симулятором без тестовой среды используйте limrun-ios-simulator.
