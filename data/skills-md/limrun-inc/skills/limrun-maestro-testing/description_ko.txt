모든 환경(Linux, Windows, macOS, VM, 컨테이너)에서 'lim ios maestro'를 사용하여 Limrun 클라우드 iOS 시뮬레이터에 대해 Maestro YAML 흐름을 실행합니다. 사용자가 iOS에서 Maestro 흐름 또는 'maestro 테스트'를 실행, 작성 또는 디버그하거나 기존 Maestro 제품군을 원격 시뮬레이터로 마이그레이션하거나 Maestro를 사용하여 UI 테스트를 요청할 때 사용합니다. iOS 시뮬레이터는 오늘만 가능합니다. Detox 제품군의 경우 limrun-detox-testing을 사용하세요. 테스트 프레임워크 없이 시뮬레이터를 구동하려면 limrun-ios-simulator를 사용하세요.
