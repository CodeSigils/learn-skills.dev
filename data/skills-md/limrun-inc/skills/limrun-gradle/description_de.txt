Erstellen Sie eine Android-App auf einer Remote-Gradle-Sandbox mit „lim gradle build“ anstelle von lokalem Gradle oder Android Studio, aus jeder Umgebung (Linux, Windows, macOS, VM, Container). Verwenden Sie diese Option, wenn der Benutzer ein APK oder AAB erstellen, eine Veröffentlichung mit einem Upload-Schlüssel signieren oder eine Play Store-Veröffentlichung für native Android-Projekte, React Native und Expo vorbereiten möchte. Verwenden Sie die hier gezeigten „lim android“-Befehle, um das erstellte APK auf einem Emulator auszuführen, darauf zu tippen, einen Screenshot davon zu machen oder anderweitig mit ihm zu interagieren. Verwenden Sie für iOS-Builds limrun-xcode oder limrun-expo-development.
