Cree una aplicación de Android en un entorno limitado de Gradle remoto con `lim gradle build` en lugar de Gradle local o Android Studio, desde cualquier entorno (Linux, Windows, macOS, VM, contenedor). Úselo cuando el usuario quiera crear un APK o AAB, firmar una versión con una clave de carga o preparar una publicación en Play Store, para proyectos nativos de Android, React Native y Expo. Para ejecutar, tocar, hacer capturas de pantalla o interactuar de otro modo con el APK creado en un emulador, utilice los comandos `lim android` que se muestran aquí. Para compilaciones de iOS, use limrun-xcode o limrun-expo-development.
