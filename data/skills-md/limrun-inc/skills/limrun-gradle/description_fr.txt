Créez une application Android sur un bac à sable Gradle distant avec « lim gradle build » au lieu de Gradle ou Android Studio local, à partir de n'importe quel environnement (Linux, Windows, macOS, VM, conteneur). À utiliser lorsque l'utilisateur souhaite créer un APK ou un AAB, signer une version avec une clé de téléchargement ou préparer une publication sur le Play Store, pour les projets Android natifs, React Native et Expo. Pour exécuter, appuyer, faire une capture d'écran ou interagir de toute autre manière avec l'APK construit sur un émulateur, utilisez les commandes « lim android » présentées ici. Pour les versions iOS, utilisez limrun-xcode ou limrun-expo-development.
