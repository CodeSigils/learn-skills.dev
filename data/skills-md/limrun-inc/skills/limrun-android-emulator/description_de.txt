Steuern Sie eine App, die auf einem Limrun-Cloud-Android-Emulator ausgeführt wird: Installieren Sie eine APK, starten und beenden Sie Apps mit Absturzberichten, tippen Sie auf, geben Sie ein, lesen Sie den UI-Elementbaum, machen Sie einen Screenshot, zeichnen Sie Videos auf, fügen Sie Mikrofon-Audio ein, gestalten Sie die Netzwerkbandbreite und verwenden Sie ADB über den CLI-Tunnel für Logcat, Dateien und Shell. Verwenden Sie es nach einem Build (von limrun-gradle oder einem anderen Builder), wenn der Benutzer seine App auf einem Emulator sehen, testen oder mit ihr interagieren möchte oder sagt: „Zeig mir einen Screenshot“, „Tippen“, „Führen Sie ihn auf dem Emulator aus“, „Überprüfen Sie Logcat“ oder „Nehmen Sie ein Video auf“. Um zuerst das APK oder AAB zu erstellen, verwenden Sie limrun-gradle.
