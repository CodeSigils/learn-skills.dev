Erstellen Sie eine Bazel-basierte iOS-/MacOS-/Apple-App auf Limruns Remote Build Execution (RBE) anstelle eines lokalen Mac und installieren Sie sie auf einem Remote-iOS-Simulator. Verwenden Sie diese Option, wenn es sich bei dem Projekt um einen Bazel-Arbeitsbereich (MODULE.bazel / WORKSPACE) handelt, der die Ziele „rules_apple“ / „rules_swift“ erstellt und der Benutzer es „bazel-build“ oder auf einem Simulator ausführen möchte, oder wenn sich ein „--config=limrun“-Build oder eine Installation schlecht verhält. Um dann auf die laufende App zu tippen, sie einzugeben, einen Screenshot davon zu machen oder anderweitig mit ihr zu interagieren, verwenden Sie limrun-ios-simulator. Für Nicht-Bazel-Projekte (einfaches Xcodebuild) verwenden Sie stattdessen limrun-xcode.
