À utiliser lorsque l'utilisateur mentionne DhanHQ, Dhan API ou souhaite négocier sur les bourses indiennes (NSE, BSE, MCX). Déclencheurs pour : passer, modifier ou annuler des commandes de stocks/F&O/produits sur Dhan ; récupérer des avoirs ou des positions de portefeuille ; obtenir des données de marché en direct ou historiques ; accéder aux chaînes d’options avec les Grecs ; vérifier les limites ou la marge des fonds ; construire n'importe quelle automatisation commerciale pour les marchés indiens ; résoudre les identifiants des instruments NSE/ESB ; diffusez en direct des flux de marché WebSocket ou commandez des mises à jour. Déclenchez également des questions générales sur le trading programmatique sur les bourses indiennes si Dhan est le courtier de l'utilisateur.
