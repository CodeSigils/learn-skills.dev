ユーザーが DhanHQ、Dhan API について言及する場合、またはインドの取引所 (NSE、BSE、MCX) での取引を希望する場合に使用します。トリガー: Dhan での在庫/F&O/商品の注文の発注、変更、またはキャンセル。ポートフォリオの保有またはポジションを取得します。ライブまたは過去の市場データを取得します。ギリシャ人とのオプションチェーンにアクセスする。資金制限または証拠金を確認します。インド市場向けの取引自動化を構築する。 NSE/BSE 機器 ID を解決します。ライブ WebSocket マーケット フィードや注文の更新をストリーミングします。ダンがユーザーのブローカーである場合、インドの取引所でのプログラム取引に関する一般的な質問もトリガーされます。
