ユーザーが何らかの異常な動作を報告した場合、エラー、クラッシュ、機能の障害、表示の異常、スタイルの不具合、レイアウトの変化、応答性の問題、応答しないクリック、不正なデータ、期待と一致しない動作など、異常な動作を報告する必要があります。ユーザーが「デバッグ」または「バグ」について言及していなくても、「何かがオフになっている / 動作していない / 壊れている / ディスプレイに問題がある」と説明している限り、それはトリガーされます。プロセス: 呼び出しチェーンをトレースして範囲を絞り込む → 盲目的な推測を防ぐためにゲートで相互検証する (十分な 2 次元の証拠がなければ行動しない) → ソースを特定するバイナリ インストルメンテーション → 症状を変えるだけでなく根本原因を修正する。行き止まりに陥ったら、方向性について自問自答し始めます。
