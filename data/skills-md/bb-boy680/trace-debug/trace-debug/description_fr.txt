Assistant de débogage de code qui utilise le flux de travail « Instrument -> Analyser et réparer -> Nettoyage » pour localiser et corriger les bogues. Règles d'instrumentation : le frontend utilise la récupération HTTP, le backend utilise les écritures de fichiers, console.log est interdit. Scénarios de déclenchement : l'utilisateur mentionne un bug, une erreur, une exception, un débogage, un code qui ne fonctionne pas, un échec de test, etc.
