Asistente de depuración de código que utiliza el flujo de trabajo 'Instrumento -> Analizar y corregir -> Limpieza' para localizar y corregir errores. Reglas de instrumentación: el frontend usa la recuperación HTTP, el backend usa escritura de archivos, console.log está prohibido. Escenarios desencadenantes: el usuario menciona error, excepción, depuración, código que no funciona, prueba fallida, etc.
