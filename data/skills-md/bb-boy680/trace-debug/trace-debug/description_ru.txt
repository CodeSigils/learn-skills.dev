Помощник по отладке кода, который использует рабочий процесс «Инструмент -> Анализ и исправление -> Очистка» для поиска и исправления ошибок. Правила инструментирования: интерфейс использует HTTP-выборку, серверная часть использует запись в файл, console.log запрещен. Сценарии триггера: пользователь упоминает ошибку, ошибку, исключение, отладку, неработающий код, сбой теста и т. д.
