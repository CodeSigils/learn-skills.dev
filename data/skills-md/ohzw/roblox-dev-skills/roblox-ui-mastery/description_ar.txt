هندسة Roblox UI المتقدمة مع React-Lua. يُستخدم عند إنشاء أو تعديل أو تصحيح أي مكون من مكونات React-Lua UI لألعاب Roblox.
المشغلات: React-Lua، Roact، مكون واجهة المستخدم، createElement، useState، useEffect، useSpring، Binding، الرسوم المتحركة، tween، Spring، modal، اللوحة، المحدد، تلميح الأدوات، القائمة المنسدلة، علامة التبويب، الخبز المحمص، الإخطار، عرض التهدئة، شريط الصحة، المتصدرين، واجهة مستخدم المخزون، واجهة مستخدم المتجر، HUD، تراكب، نافذة منبثقة، تلاشي، شريحة، ترتد، تأثير التوهج، تأثير الظل، التدرج، التخطيط المستجيب، واجهة مستخدم الهاتف المحمول، واجهة مستخدم gamepad، DesignSystem، الرموز المميزة، السمة، أداء واجهة المستخدم، المذكرة، التمرير الظاهري، واجهة برمجة تطبيقات السياق، useReducer، الخطاف المخصص، BillboardGui، SurfaceGui، ViewportFrame، EditableImage، UIListLayout، UIGridLayout، UIFlexItem، UIDragDetector، Path2D، RichText، ScreenGui، CanvasGroup، UIStroke، UIGradient، UICorner.
المكدس التقني: jsdotlua/react، ReactRoblox، React-spring (chriscerie/react-spring)، Luau --!strict، Rojo، Wally.
