Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer eine UX-Anleitung benötigt, eine Produktfunktion entwirft, eine Benutzeroberfläche erstellt, eine Benutzerreise plant, eine UI-Kopie schreibt oder Hilfe beim Durchdenken einer benutzerorientierten Erfahrung benötigt. Wird ausgelöst, wenn der Benutzer „UX“, „Benutzererfahrung“, „Benutzerfluss“, „Interface-Design“, „Design Thinking“ erwähnt oder Fragen stellt wie „Wie bringe ich Benutzer dazu …“, „Wie sollte mein Onboarding aussehen“, „Wie verbessere ich das Engagement“ oder jede Variation, etwas für einen Endbenutzer zu entwerfen. Wird auch proaktiv ausgelöst, wenn ein Benutzer ein Produkt, eine App oder eine Funktion beschreibt, an der er arbeitet, und die Benutzerperspektive noch nicht berücksichtigt hat. Das Ziel besteht darin, sie durch die fünf zentralen UX-Fragen zu führen und ihnen dann umsetzbare, benutzerzentrierte Empfehlungen zu geben, die auf ihrem spezifischen Kontext basieren.
