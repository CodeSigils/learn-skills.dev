Use this skill whenever a user wants UX guidance, is designing a product feature, building an interface, planning a user journey, writing UI copy, or needs help thinking through any user-facing experience. Trigger when the user mentions "UX", "user experience", "user flow", "interface design", "design thinking", or asks questions like "how do I get users to...", "what should my onboarding look like", "how do I improve engagement", or any variation of designing something for an end user. Also trigger proactively when a user describes a product, app, or feature they're working on and hasn't yet considered the user perspective. The goal is to walk them through the 5 core UX questions and then provide actionable, user-centered recommendations grounded in their specific context.
