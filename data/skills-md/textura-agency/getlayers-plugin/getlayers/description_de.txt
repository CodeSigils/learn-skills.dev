Verwenden Sie dies, WENN der Benutzer etwas mit GetLayers erstellen oder entwerfen möchte – eine Website oder Landingpage, eine benutzerdefinierte 3D-Szene, einen Videohintergrund oder das Hinzufügen von Bewegung/3D zu einem vorhandenen Projekt – oder wann immer er GetLayers, „getlayers“ oder das getlayers MCP erwähnt. Es steuert den GetLayers MCP durch seinen korrekten End-to-End-Ablauf, sodass das Ergebnis tatsächlich die Bibliothek (echte Vorlagen, Szenen, Kompositionen) anstelle der generischen Ausgabe verwendet. Laden Sie es, BEVOR Sie ein getlayers_*-Tool aufrufen.
