Référence complète du schéma YAML pour les ressources File et FileSet. À utiliser lors de l'écriture de manifestes pour gérer des fichiers (CODEOWNERS, LICENSE, flux de travail CI, etc.) dans un ou plusieurs référentiels, y compris les modèles, les correctifs, les modes de réconciliation, la méthode de livraison et le comportement d'importation.
