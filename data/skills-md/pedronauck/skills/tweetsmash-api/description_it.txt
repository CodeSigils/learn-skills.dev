Utilizza l'API REST TweetSmash per recuperare segnalibri, ispezionare etichette e aggiungere o rimuovere etichette dai tweet salvati. Da utilizzare quando si integra TweetSmash in script, agenti, flussi di lavoro, processi cron o strumenti interni che richiedono il recupero dei segnalibri, il filtraggio, l'impaginazione o la gestione delle etichette. Non utilizzare per l'automazione diretta del browser all'interno di TweetSmash, API X o Twitter non correlate o attività che richiedono solo una copia di marketing del prodotto.
