Utiliza la API REST de TweetSmash para buscar marcadores, inspeccionar etiquetas y agregar o eliminar etiquetas de tweets guardados. Úselo al integrar TweetSmash en scripts, agentes, flujos de trabajo, trabajos cron o herramientas internas que necesitan recuperación de marcadores, filtrado, paginación o administración de etiquetas. No lo utilice para la automatización directa del navegador dentro de TweetSmash, API de X o Twitter no relacionadas, ni tareas que solo necesiten un texto de marketing del producto.
