Использует REST API TweetSmash для извлечения закладок, проверки меток, а также добавления или удаления меток из сохраненных твитов. Используйте при интеграции TweetSmash в сценарии, агенты, рабочие процессы, задания cron или внутренние инструменты, которым требуется извлечение закладок, фильтрация, нумерация страниц или управление метками. Не используйте для прямой автоматизации браузера внутри TweetSmash, несвязанных API-интерфейсов X или Twitter, а также для задач, для которых требуется только маркетинговая копия продукта.
