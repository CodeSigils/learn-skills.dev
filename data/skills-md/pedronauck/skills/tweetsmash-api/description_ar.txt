يستخدم TweetSmash REST API لجلب الإشارات المرجعية وفحص التسميات وإضافة أو إزالة التسميات من التغريدات المحفوظة. يُستخدم عند دمج TweetSmash في البرامج النصية أو الوكلاء أو سير العمل أو وظائف cron أو الأدوات الداخلية التي تحتاج إلى استرجاع الإشارات المرجعية أو التصفية أو ترقيم الصفحات أو إدارة التصنيفات. لا تستخدم للأتمتة المباشرة للمتصفح داخل TweetSmash، أو X أو واجهات برمجة تطبيقات Twitter غير ذات الصلة، أو المهام التي تحتاج فقط إلى نسخة تسويق المنتج.
