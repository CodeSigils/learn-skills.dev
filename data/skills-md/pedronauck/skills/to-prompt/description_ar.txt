قم بتحويل التعليمات البرمجية أو المشكلات أو السياق إلى موجه/سياق تفصيلي لـ LLM آخر لإصلاحه أو تنفيذه. يُستخدم عند إعداد سياق شامل لمساعدة LLM الخارجية أو إصلاحات الأخطاء أو التحسينات أو تطبيقات الميزات. يوفر سياقًا تفصيليًا دون اقتراحات التنفيذ، مما يسمح لمتلقي LLM بتحديد كيفية تنفيذ الحلول. يركز على "ماذا" (المشكلة، المتطلبات، الوضع الحالي) وليس "كيف" (نهج التنفيذ).
