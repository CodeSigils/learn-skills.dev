Guide la création et la modification des systèmes de fonctionnalités de domaine organisés sous un répertoire Systems/. Couvre la disposition des répertoires, les modèles de couche de service API, la configuration des requêtes TanStack et de la collection de bases de données, le contexte React et les conventions de magasin XState, l'organisation des hooks et les exportations de barils d'API publiques. À utiliser lors de l'ajout d'un nouveau système de domaine, de l'extension d'un système existant ou de la correction de bogues dans une base de code de couche système. Ne pas utiliser pour le travail de composants React génériques, la mise en œuvre d'API backend ou les bases de code non organisées autour d'un modèle de système/domaine.
