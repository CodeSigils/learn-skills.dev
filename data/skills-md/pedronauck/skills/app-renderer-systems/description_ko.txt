Guides creation and modification of domain feature systems organized under a systems/ directory. 디렉터리 레이아웃, API 서비스 계층 패턴, TanStack 쿼리 및 DB 컬렉션 설정, React 컨텍스트 및 XState 저장소 규칙, 후크 구성 및 공용 API 배럴 내보내기를 다룹니다. Use when adding a new domain system, extending an existing one, or fixing bugs in a system-layer codebase. Don't use for generic React component work, backend API implementation, or codebases not organized around a systems/ domain pattern.
