Guida la creazione e la modifica dei sistemi di funzionalità del dominio organizzati in una directory system/. Copre il layout della directory, i modelli dei livelli di servizio API, la configurazione delle query TanStack e della raccolta DB, il contesto React e le convenzioni dell'archivio XState, l'organizzazione degli hook e le esportazioni dei barili API pubblici. Da utilizzare quando si aggiunge un nuovo sistema di dominio, si estende uno esistente o si correggono bug in una base di codice a livello di sistema. Non utilizzare per lavori generici sui componenti React, implementazione API backend o basi di codice non organizzate attorno a un modello di sistema/dominio.
