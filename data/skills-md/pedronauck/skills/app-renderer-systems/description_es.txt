Guía la creación y modificación de sistemas de funciones de dominio organizados en un directorio de sistemas/. Cubre el diseño del directorio, los patrones de la capa de servicio API, la configuración de la colección de bases de datos y consultas TanStack, el contexto de React y las convenciones de la tienda XState, la organización de enlaces y las exportaciones de barriles de API públicas. Úselo al agregar un nuevo sistema de dominio, ampliar uno existente o corregir errores en una base de código de capa de sistema. No lo use para trabajos de componentes genéricos de React, implementación de API de backend o bases de código que no estén organizadas en torno a un patrón de sistemas/dominio.
