يرشد إنشاء وتعديل أنظمة ميزات المجال المنظمة ضمن دليل الأنظمة/. يغطي تخطيط الدليل، وأنماط طبقة خدمة API، وإعداد مجموعة TanStack Query ومجموعة DB، وسياق React واتفاقيات متجر XState، وتنظيم الخطاف، وتصدير براميل API العامة. يُستخدم عند إضافة نظام مجال جديد، أو توسيع نظام موجود، أو إصلاح الأخطاء في قاعدة تعليمات برمجية لطبقة النظام. لا تستخدمه في عمل مكون React العام أو تنفيذ واجهة برمجة التطبيقات الخلفية أو قواعد التعليمات البرمجية غير المنظمة حول نمط الأنظمة/المجال.
