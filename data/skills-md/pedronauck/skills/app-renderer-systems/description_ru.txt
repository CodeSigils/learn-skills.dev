Управляет созданием и изменением систем функций предметной области, организованных в каталоге Systems/. Охватывает структуру каталогов, шаблоны уровней обслуживания API, настройку запросов TanStack и коллекции БД, соглашения о контексте React и хранилище XState, организацию перехватчиков и экспорт стволов общедоступных API. Используйте при добавлении новой доменной системы, расширении существующей или исправлении ошибок в кодовой базе системного уровня. Не используйте для работы с общими компонентами React, реализации серверного API или баз кода, не организованных по шаблону систем/доменов.
