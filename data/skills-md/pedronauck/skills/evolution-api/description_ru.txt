Интеграция Evolution API для обмена сообщениями WhatsApp, управления экземплярами, веб-перехватчиков,
и оркестровка чат-ботов. Используйте, когда: (1) Создание экземпляров WhatsApp или управление ими.
через Evolution API, (2) Отправка сообщений (текстовых, медиа, аудио, списков, кнопок,
реакции), (3) Настройка веб-перехватчиков или прослушивателей событий, (4) Управление группами
или контакты, (5) Интеграция с Typebot, Chatwoot, Dify или OpenAI через
API эволюции. Запускается по: Evolution-API, Evolution API, WhatsApp API, Baileys,
интеграция WhatsApp, отправка WhatsApp, веб-хук WhatsApp.
