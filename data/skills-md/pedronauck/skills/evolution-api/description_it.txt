tramite Evolution API, (2) Invio di messaggi (testo, media, audio, elenchi, pulsanti,
reazioni), (3) Configurazione di webhook o ascoltatori di eventi, (4) Gestione di gruppi
o contatti, (5) Integrazione con Typebot, Chatwoot, Dify o OpenAI tramite
API di evoluzione. Si attiva su: evoluzione-api, evoluzione api, whatsapp api, baileys,
