Evolution API 集成用于 WhatsApp 消息传递、实例管理、webhooks、
和聊天机器人编排。在以下情况下使用：(1) 创建或管理 WhatsApp 实例
通过 Evolution API，(2) 发送消息（文本、媒体、音频、列表、按钮、
反应），（3）配置网络钩子或事件监听器，（4）管理组
或联系人，(5) 通过以下方式与 Typebot、Chatwoot、Dify 或 OpenAI 集成
进化API。触发：evolution-api、evolution api、whatsapp api、baileys、
Whatsapp 集成、发送 Whatsapp、Whatsapp Webhook。
