Evolution API 整合用於 WhatsApp 訊息傳遞、實例管理、webhooks、
和聊天機器人編排。在下列情況下使用：(1) 建立或管理 WhatsApp 實例
透過 Evolution API，(2) 發送訊息（文字、媒體、音訊、清單、按鈕、
反應），（3）配置網路鉤子或事件監聽器，（4）管理群組
或聯絡人，(5) 透過以下方式與 Typebot、Chatwoot、Dify 或 OpenAI 集成
進化API。觸發：evolution-api、evolution api、whatsapp api、baileys、
Whatsapp 整合、發送 Whatsapp、Whatsapp Webhook。
