Intégration de l'API Evolution pour la messagerie WhatsApp, la gestion des instances, les webhooks,
et orchestration de chatbot. À utiliser lorsque : (1) Création ou gestion d'instances WhatsApp
via Evolution API, (2) Envoi de messages (texte, média, audio, listes, boutons,
réactions), (3) Configuration des webhooks ou des auditeurs d'événements, (4) Gestion des groupes
ou des contacts, (5) Intégration avec Typebot, Chatwoot, Dify ou OpenAI via
API d'évolution. Déclencheurs sur : évolution-api, évolution api, WhatsApp api, baileys,
Intégration WhatsApp, envoyer WhatsApp, webhook WhatsApp.
