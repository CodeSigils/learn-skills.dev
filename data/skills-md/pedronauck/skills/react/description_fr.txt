Guide de développement React complet couvrant l'architecture des composants, les hooks, la gestion de l'état, l'intégration de TypeScript, les modèles useEffect et les tests avec Vitest. À utiliser lors de la création de composants React, de hooks personnalisés, de gestion de l'état ou de tout code React frontal. Indispensable pour le développement de React 19+.
