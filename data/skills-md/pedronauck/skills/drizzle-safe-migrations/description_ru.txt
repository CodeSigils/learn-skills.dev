Безопасный для производства рабочий процесс миграции Drizzle для изменений схемы, которые требуют заполнения данных или ужесточения ограничений. Используйте при изменении перечислений/проверочных ограничений/значений по умолчанию, удалении значений статуса или упорядочивании пользовательских и сгенерированных миграций в Drizzle. Запуск по запросам о безопасности миграции Drizzle, безопасном для развертывания обратном заполнении, заказе миграции и планировании отката.
