Синхронизируйте изменения поставщиков из клонированных репозиториев в папке поставщики/. Используйте при синхронизации исходных изменений из репозиториев внешних поставщиков (claude-code, Gemini, Codex) с сохранением локальных настроек. Включает многоэтапный рабочий процесс: проверку новых коммитов через GitHub CLI, создание различий, глубокий анализ, планирование рефакторинга Pal MCP и постепенное внесение изменений. Никогда не используйте поставщика открытого кода (созданного локально, а не клонированного).
