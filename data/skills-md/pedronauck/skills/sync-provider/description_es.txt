Sincronice los cambios del proveedor de los repositorios clonados en la carpeta proveedores/. Úselo al sincronizar cambios ascendentes desde repositorios de proveedores externos (claude-code, gemini, codex) mientras se conservan las personalizaciones locales. Incluye un flujo de trabajo de varios pasos: verificación de nuevas confirmaciones a través de GitHub CLI, generación de diferencias, análisis profundo, planificación de refactorización de Pal MCP y aplicación de cambios de forma incremental. Nunca lo use para proveedores de código abierto (creado localmente, no clonado).
