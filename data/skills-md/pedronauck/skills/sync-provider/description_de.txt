Synchronisieren Sie Anbieteränderungen aus geklonten Repositorys im Ordner „Providers/“. Wird zum Synchronisieren von Upstream-Änderungen aus Repositorys externer Anbieter (claude-code, gemini, codex) unter Beibehaltung lokaler Anpassungen verwendet. Beinhaltet einen mehrstufigen Workflow: Überprüfung auf neue Commits über die GitHub-CLI, Generierung von Diffs, Tiefenanalyse, Pal-MCP-Refactor-Planung und inkrementelles Anwenden von Änderungen. Niemals für Opencode-Anbieter verwenden (lokal erstellt, nicht geklont).
