Analyse les bases de code pour identifier les opportunités de refactorisation sur la base du catalogue d'odeurs de code et de techniques de refactorisation de Martin Fowler. Détecte le code dupliqué, le couplage élevé, les conditions complexes, l'obsession primitive, les fonctions longues et d'autres problèmes structurels. Produit un rapport de refactoring structuré avec des résultats hiérarchisés enregistrés dans docs/_refacs/. À utiliser lors de l'audit de la qualité du code, de la préparation d'un sprint de refactoring ou de l'examen de l'état de l'architecture. Ne pas utiliser pour des problèmes de style/formatage, d'optimisation des performances ou d'audits de sécurité.
