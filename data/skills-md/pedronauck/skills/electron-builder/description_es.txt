Guía completa para empaquetado de electron-builder (v26.x), firma de código, actualizaciones automáticas,
y liberar flujos de trabajo. Úselo cuando: (1) configure compilaciones de generadores de electrones (electron-builder.yml
o config.js/ts), (2) configurar la firma o certificación notarial de código macOS/Windows, (3) implementar
actualizaciones automáticas con electron-updater, (4) publicación en versiones de GitHub, S3 o servidores genéricos,
(5) configurar objetivos de plataforma (NSIS, DMG, AppImage, Snap, PKG, MSI), (6) trabajar con
cree ganchos (beforePack, afterSign, afterAllArtifactBuild) o (7) utilizando la API programática.
Activadores de: generador de electrones, actualizador de electrones, firma de código, notariado, NSIS, DMG, AppImage,
actualización automática, publicación de lanzamientos, creación de enlaces, empaquetado de electrones, distribución de electrones.
