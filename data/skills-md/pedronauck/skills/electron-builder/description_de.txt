Umfassende Anleitung für Electron-Builder (v26.x)-Paketierung, Code-Signierung, automatische Updates,
und Freigabeworkflows. Wird verwendet, wenn: (1) Electron-Builder-Builds konfiguriert werden (electron-builder.yml
oder config.js/ts), (2) Einrichten der Codesignatur oder Beglaubigung für macOS/Windows, (3) Implementieren
automatische Updates mit Electron-Updater, (4) Veröffentlichung auf GitHub Releases, S3 oder generischen Servern,
(5) Plattformziele konfigurieren (NSIS, DMG, AppImage, Snap, PKG, MSI), (6) Arbeiten mit
Build-Hooks (beforePack, afterSign, afterAllArtifactBuild) oder (7) mithilfe der programmgesteuerten API.
Auslöser bei: Electron-Builder, Electron-Updater, Code Signing, Notarisierung, NSIS, DMG, AppImage,
Automatische Aktualisierung, Veröffentlichung von Releases, Build-Hooks, Elektronenverpackung, Elektronenverteilung.
