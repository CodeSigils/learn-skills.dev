يحول المحتوى (عناوين URL والمستندات التي تم تحميلها والنص الملصق ونصوص الاجتماعات) إلى تصورات احترافية عبر أربعة أوضاع إخراج. يقبل وسيطة الوضع أو مشغل الكلمة الأساسية في رسالة المستخدم. يُنتج الوضع "مخطط" مخطط Excalidraw عبر Excalidraw:create_view. يقوم الوضع "infographic" بإنشاء ملف Swiss Pulse PNG عبر واجهة برمجة تطبيقات توليد الصور الخاصة بـ Gemini. يعرض الوضع "visualize" أداة Visualizer المضمنة (SVG أو HTML) عبر visualize:show_widget. يقوم وضع "النشر" بإرسال صورة HTML تفاعلية لـ Swiss Pulse HTML إلى HeyGenverse عبر HeyGenverse:create_app ويعيد رابطًا قابلاً للمشاركة. الكلمات الرئيسية التي تنشط المهارة: "مخطط ذلك"، "excalidraw هذا"، "ارسم مخططًا لهذا"، "nano this"، "vis it"، "ver it"، "hey it"، "heygenverse this". لا تستخدمه مع ملخصات النص العادي، أو تفسيرات التعليمات البرمجية، أو الاستجابات النثرية، أو تصورات الدردشة العامة بدون تنسيق الإخراج المختار.
