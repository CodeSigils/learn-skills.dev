Transforme le contenu (URL, documents téléchargés, texte collé, transcriptions de réunions) en visualisations professionnelles sur quatre modes de sortie. Accepte un argument de mode ou un déclencheur de mot-clé dans le message utilisateur. Le mode "diagramme" produit un diagramme Excalidraw via Excalidraw:create_view. Le mode "infographie" génère un Swiss Pulse PNG via l'API de génération d'images Gemini. Le mode « visualiser » restitue un widget Visualizer en ligne (SVG ou HTML) via visualize:show_widget. Le mode « publier » envoie un visuel HTML interactif Swiss Pulse à HeyGenverse via HeyGenverse:create_app et renvoie un lien partageable. Mots-clés qui activent la compétence : "diagramme-le", "excalidraw this", "dessine un diagramme de ceci", "nano this", "vis it", "ver it", "hey it", "heygenverse this". Ne pas utiliser pour des résumés en texte brut, des explications de code, des réponses en prose ou des visualisations de discussion génériques sans format de sortie choisi.
