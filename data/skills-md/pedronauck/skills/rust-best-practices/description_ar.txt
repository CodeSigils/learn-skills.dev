إرشادات شاملة لترميز Rust تغطي الملكية ومعالجة الأخطاء وأنماط المزامنة والسمات والاختبار والأداء والمقطع والوثائق. يُستخدم عند كتابة كود Rust جديد، أو مراجعة Rust الحالي أو إعادة هيكلته، أو تنفيذ أنظمة غير متزامنة مع Tokio، أو تصميم تسلسلات هرمية للأخطاء، أو الاختيار بين الاقتراض والاستنساخ، أو إعداد الاختبارات أو المعايير، أو تكوين الفحص، أو تحسين الأداء. لا تستخدمه للغات غير Rust أو بنية البرامج العامة التي لا علاقة لها بمصطلحات Rust.
