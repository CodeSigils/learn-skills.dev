Linee guida complete sulla codifica di Rust che coprono proprietà, gestione degli errori, modelli asincroni, tratti, test, prestazioni, clippy e documentazione. Da utilizzare quando si scrive nuovo codice Rust, si rivede o si effettua il refactoring di Rust esistente, si implementano sistemi asincroni con Tokio, si progettano gerarchie di errori, si sceglie tra prestito e clonazione, si impostano test o benchmark, si configura linting o si ottimizzano le prestazioni. Non utilizzare per linguaggi non Rust o architetture software generali non correlate agli idiomi Rust.
