Pautas integrales de codificación de Rust que cubren propiedad, manejo de errores, patrones asíncronos, rasgos, pruebas, rendimiento, clippy y documentación. Úselo al escribir nuevo código Rust, revisar o refactorizar Rust existente, implementar sistemas asíncronos con Tokio, diseñar jerarquías de errores, elegir entre tomar prestado y clonar, configurar pruebas o puntos de referencia, configurar linting u optimizar el rendimiento. No lo utilice para lenguajes que no sean de Rust o arquitectura de software general no relacionada con los modismos de Rust.
