Комплексное руководство по экосистеме XState v5, включая конечные автоматы, актеры, @xstate/store и интеграцию запросов TanStack. Используйте при реализации конечных автоматов, хранилищ, управляемых событиями, управления состоянием клиента или интеграции XState с React и TanStack Query для оркестрации выборки данных.
