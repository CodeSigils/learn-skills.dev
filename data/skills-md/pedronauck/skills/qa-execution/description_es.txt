Ejecuta el control de calidad de todo el proyecto como un usuario real al descubrir la verificación del repositorio y los contratos E2E, ejecutar comandos de compilación, lint, prueba e inicio, ejercitar flujos de trabajo centrales de extremo a extremo a través de CLI, HTTP y interfaces de navegador, lo que requiere cobertura de regresión automatizada para flujos críticos admitidos, corrige regresiones de causa raíz y vuelve a ejecutar la puerta completa. Utiliza la habilidad complementaria agente-navegador para la validación de la interfaz de usuario web cuando existe una superficie web. Úselo al validar una rama, un candidato de lanzamiento, una migración, una refactorización o una confirmación arriesgada. No lo use solo para revisión de código estático, ediciones de pruebas unitarias únicas, planificación de casos de prueba o lluvia de ideas de arquitectura sin ejecución; use qa-report para planificación y documentación.
