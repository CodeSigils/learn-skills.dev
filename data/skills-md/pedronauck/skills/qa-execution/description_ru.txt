Выполняет полный контроль качества проекта как настоящий пользователь, обнаруживая проверку репозитория и контракты E2E, выполняя команды сборки, проверки, тестирования и запуска, комплексно выполняя основные рабочие процессы через интерфейсы командной строки, HTTP и браузера, требуя автоматического покрытия регрессии для поддерживаемых критических потоков, устраняя регрессии по первопричинам и повторно запуская полный шлюз. Использует сопутствующий навык агента-браузера для проверки веб-интерфейса при наличии веб-интерфейса. Используйте при проверке ветки, кандидата на выпуск, миграции, рефакторинга или рискованного коммита. Не используйте только для статического обзора кода, разового редактирования модульных тестов, планирования тестовых случаев или мозгового штурма архитектуры без выполнения — используйте qa-report для планирования и документирования.
