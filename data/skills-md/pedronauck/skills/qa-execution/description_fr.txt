Exécute le contrôle qualité du projet complet comme un véritable utilisateur en découvrant la vérification du référentiel et les contrats E2E, en exécutant les commandes de construction, de lint, de test et de démarrage, en exerçant les flux de travail de base de bout en bout via les interfaces CLI, HTTP et de navigateur, en exigeant une couverture de régression automatisée pour les flux critiques pris en charge, en corrigeant les régressions de cause première et en réexécutant la porte complète. Utilise la compétence compagnon agent-navigateur pour la validation de l'interface utilisateur Web lorsqu'une surface Web existe. À utiliser lors de la validation d'une branche, d'une version candidate, d'une migration, d'un refactor ou d'un commit risqué. Ne l'utilisez pas uniquement pour la révision de code statique, les modifications de tests unitaires ponctuels, la planification de cas de test ou le brainstorming d'architecture sans exécution - utilisez qa-report pour la planification et la documentation.
