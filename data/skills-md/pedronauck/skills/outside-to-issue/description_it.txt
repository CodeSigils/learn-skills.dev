Trasforma i file di revisione fuori differenza in file di problemi formattati correttamente per un determinato PR. Da utilizzare quando si convertono file di revisione da ai-docs/reviews-pr-<PR>/outside/ nel formato di edizione in ai-docs/reviews-pr-<PR>/issues/. Determina automaticamente il numero di emissione iniziale e conserva tutti i metadati (percorso file, data, stato) dai file di revisione originali.
