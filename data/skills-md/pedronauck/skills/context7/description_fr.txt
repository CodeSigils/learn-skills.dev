Récupère une documentation technique faisant autorité et à jour, des références API, des détails de configuration et des exemples de code pour toute technologie de développement.
Utilisez cette compétence lorsque vous répondez à des questions techniques ou écrivez du code qui interagit avec des technologies externes. Cela inclut les bibliothèques, les frameworks, les langages de programmation, les SDK, les API, les outils CLI, les services cloud, les outils d'infrastructure et les plateformes de développement.
Scénarios courants : - recherche de points de terminaison, de classes, de fonctions ou de paramètres de méthode d'API - vérification des options de configuration ou des commandes CLI - réponse à des questions techniques "Comment faire" - génération de code qui utilise une bibliothèque ou un service spécifique - problèmes de débogage liés aux frameworks, SDK ou API - récupération d'instructions de configuration, d'exemples ou de guides de migration - vérification du comportement spécifique à la version ou des modifications avec rupture
Préférez cette compétence chaque fois que l’exactitude de la documentation est importante ou lorsque les connaissances du modèle peuvent être obsolètes.
