يقوم بإنشاء ملفات Dockerfiles، وتكوين خطوط أنابيب CI/CD، وكتابة بيانات Kubernetes، وإنشاء قوالب البنية التحتية Terraform/Pulumi. يتعامل مع أتمتة النشر وتكوين GitOps وسجلات التشغيل للاستجابة للحوادث وأدوات النظام الأساسي للمطورين الداخليين. يُستخدم عند إعداد خطوط أنابيب CI/CD، أو تخزين التطبيقات في حاويات، أو إدارة البنية الأساسية كتعليمات برمجية، أو النشر إلى مجموعات Kubernetes، أو تكوين الأنظمة الأساسية السحابية، أو أتمتة الإصدارات، أو الاستجابة لحوادث الإنتاج. استدعاء خطوط الأنابيب أو Docker أو Kubernetes أو GitOps أو Terraform أو GitHub Actions أو عند الطلب أو هندسة النظام الأساسي.
