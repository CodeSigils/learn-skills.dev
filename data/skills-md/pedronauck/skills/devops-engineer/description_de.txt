Erstellt Docker-Dateien, konfiguriert CI/CD-Pipelines, schreibt Kubernetes-Manifeste und generiert Terraform/Pulumi-Infrastrukturvorlagen. Kümmert sich um die Bereitstellungsautomatisierung, die GitOps-Konfiguration, Runbooks zur Reaktion auf Vorfälle und interne Entwicklerplattform-Tools. Verwendung beim Einrichten von CI/CD-Pipelines, Containerisieren von Anwendungen, Verwalten von Infrastruktur als Code, Bereitstellen in Kubernetes-Clustern, Konfigurieren von Cloud-Plattformen, Automatisieren von Releases oder Reagieren auf Produktionsvorfälle. Invoke für Pipelines, Docker, Kubernetes, GitOps, Terraform, GitHub Actions, Bereitschaftsdienst oder Plattform-Engineering.
