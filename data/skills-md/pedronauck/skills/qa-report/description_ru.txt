Создавайте комплексные планы тестирования, сценарии ручного тестирования, наборы регрессионных тестов и отчеты об ошибках для инженеров по обеспечению качества. Включает интеграцию Figma MCP для проверки проекта. Используйте при планировании контроля качества перед выполнением, документировании стратегий тестирования или создании структурированных отчетов об ошибках. Не используйте для выполнения тестов в реальном репозитории или запуска шлюзов проверки — для этого используйте qa-execution.
