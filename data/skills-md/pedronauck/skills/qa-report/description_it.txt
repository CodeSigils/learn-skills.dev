Genera piani di test completi, casi di test manuali, suite di test di regressione e segnalazioni di bug per gli ingegneri del QA. Include l'integrazione di Figma MCP per la convalida del progetto. Da utilizzare quando si pianifica il QA prima dell'esecuzione, si documentano le strategie di test o si creano report strutturati sui bug. Non utilizzare per eseguire test su un repository live o eseguire porte di verifica: utilizzare qa-execution per questo.
