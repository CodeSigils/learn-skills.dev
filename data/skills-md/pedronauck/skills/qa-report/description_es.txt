Genere planes de prueba integrales, casos de prueba manuales, conjuntos de pruebas de regresión e informes de errores para ingenieros de control de calidad. Incluye integración de Figma MCP para la validación del diseño. Úselo al planificar el control de calidad antes de la ejecución, documentar estrategias de prueba o crear informes de errores estructurados. No lo use para ejecutar pruebas en un repositorio activo o ejecutar puertas de verificación; use qa-execution para eso.
