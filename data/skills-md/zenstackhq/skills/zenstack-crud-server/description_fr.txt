Exposez les données ZenStack V3 en tant qu'API Web CRUD automatiques (« Query as a Service ») et consommez-les. À utiliser lors de l'ajout de points de terminaison REST/RPC avec un adaptateur de serveur (Express, Fastify, Next.js, Nuxt, SvelteKit, Hono, Elysia, TanStack Start), du câblage du contrôle d'accès par requête via getClient/$setAuth, de la génération d'une spécification OpenAPI ou de l'appel de l'API à partir d'un client (fetch-client, TanStack Query hooks).
