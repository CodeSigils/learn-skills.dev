اكشف عن بيانات ZenStack V3 كواجهات برمجة تطبيقات الويب CRUD التلقائية ("الاستعلام كخدمة") واستهلكها. يُستخدم عند إضافة نقاط نهاية REST/RPC مع محول خادم (Express، وFastify، وNext.js، وNuxt، وSvelteKit، وHono، وElysia، وTanStack Start)، أو التحكم في الوصول لكل طلب عبر getClient/$setAuth، أو إنشاء مواصفات OpenAPI، أو استدعاء واجهة برمجة التطبيقات (API) من عميل (خطافات جلب العميل، أو خطافات استعلام TanStack).
