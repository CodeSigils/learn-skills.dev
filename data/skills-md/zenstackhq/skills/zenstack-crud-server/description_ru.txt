Предоставляйте данные ZenStack V3 как автоматические веб-API CRUD («Запрос как услуга») и используйте их. Используйте при добавлении конечных точек REST/RPC с помощью серверного адаптера (Express, Fastify, Next.js, Nuxt, SvelteKit, Hono, Elysia, TanStack Start), подключении контроля доступа для каждого запроса через getClient/$setAuth, создании спецификации OpenAPI или вызове API от клиента (fetch-client, перехватчики запросов TanStack).
