Stellen Sie ZenStack V3-Daten als automatische CRUD-Web-APIs („Query as a Service“) bereit und nutzen Sie sie. Verwenden Sie diese Option, wenn Sie REST/RPC-Endpunkte mit einem Serveradapter hinzufügen (Express, Fastify, Next.js, Nuxt, SvelteKit, Hono, Elysia, TanStack Start), die Zugriffskontrolle pro Anfrage über getClient/$setAuth verknüpfen, eine OpenAPI-Spezifikation generieren oder die API von einem Client aufrufen (fetch-client, TanStack Query Hooks).
