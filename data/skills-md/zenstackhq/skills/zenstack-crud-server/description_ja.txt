ZenStack V3 データを自動 CRUD Web API (「Query as a Service」) として公開し、利用します。サーバー アダプター (Express、Fastify、Next.js、Nuxt、SvelteKit、Hono、Elysia、TanStack Start) を使用して REST/RPC エンドポイントを追加する場合、getClient/$setAuth を介してリクエストごとのアクセス制御を接続する場合、OpenAPI 仕様を生成する場合、またはクライアントから API を呼び出す場合 (fetch-client、TanStack Query フック) に使用します。
