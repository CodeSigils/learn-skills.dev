Esponi i dati ZenStack V3 come API web CRUD automatiche ("Query as a Service") e consumali. Da utilizzare quando si aggiungono endpoint REST/RPC con un adattatore server (Express, Fastify, Next.js, Nuxt, SvelteKit, Hono, Elysia, TanStack Start), cablando il controllo dell'accesso per richiesta tramite getClient/$setAuth, generando una specifica OpenAPI o chiamando l'API da un client (fetch-client, hook TanStack Query).
