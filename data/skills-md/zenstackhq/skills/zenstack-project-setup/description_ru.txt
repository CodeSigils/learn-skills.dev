Установите, настройте и управляйте проектом ZenStack V3. Используйте при установке ZenStack, создании нового проекта или запуске CLI «zen» (генерация). (Для миграции схемы базы данных используйте zenstack-db-migration; для миграции проекта Prisma используйте zenstack-migrate-from-prisma; для обновления с ZenStack V2 используйте zenstack-migrate-from-v2.)
