Instalar, configurar y gestionar un proyecto ZenStack V3. Úselo al instalar ZenStack, crear un nuevo proyecto o ejecutar la CLI `zen` (generar). (Para migraciones de esquemas de bases de datos, utilice zenstack-db-migration; para migrar un proyecto Prisma, utilice zenstack-migrate-from-prisma; para actualizar desde ZenStack V2, utilice zenstack-migrate-from-v2).
