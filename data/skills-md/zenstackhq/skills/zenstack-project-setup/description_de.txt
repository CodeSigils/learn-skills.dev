Richten Sie ein ZenStack V3-Projekt ein, konfigurieren und verwalten Sie es. Verwenden Sie diese Option, wenn Sie ZenStack installieren, ein Gerüst für ein neues Projekt erstellen oder die „zen“-CLI ausführen (generieren). (Für Datenbankschemamigrationen verwenden Sie zenstack-db-migration; zum Migrieren eines Prisma-Projekts verwenden Sie zenstack-migrate-from-prisma; für ein Upgrade von ZenStack V2 verwenden Sie zenstack-migrate-from-v2.)
