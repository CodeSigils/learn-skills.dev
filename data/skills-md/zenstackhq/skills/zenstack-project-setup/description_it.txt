Imposta, configura e gestisci un progetto ZenStack V3. Da utilizzare durante l'installazione di ZenStack, lo scaffolding di un nuovo progetto o l'esecuzione della CLI `zen` (generazione). (Per le migrazioni dello schema del database utilizzare zenstack-db-migration; per migrare un progetto Prisma utilizzare zenstack-migrate-from-prisma; per eseguire l'aggiornamento da ZenStack V2 utilizzare zenstack-migrate-from-v2.)
