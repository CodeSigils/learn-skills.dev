Consulta y muta datos con el cliente ZenStack V3. Úselo al crear un ZenStackClient (dialecto SQLite/Postgres/MySQL), usando la API ORM compatible con Prisma (findMany/create/update/etc.), consultas de relaciones (seleccionar/incluir), campos calculados, modelos polimórficos, JSON fuertemente tipado, validación de datos en escrituras (@email/@length/@@validate), transacciones, la trampilla de escape del generador de consultas Kysely ($qb / $expr), procedimientos personalizados, raw SQL, registro o manejo de ORMError.
