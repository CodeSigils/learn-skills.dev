استعلام وتعديل البيانات باستخدام عميل ZenStack V3. يُستخدم عند إنشاء ZenStackClient (نظام SQLite/Postgres/MySQL)، باستخدام واجهة ORM المتوافقة مع Prisma (findMany/create/update/إلخ)، استعلامات العلاقات (select/include)، الحقول المحسوبة، النماذج المتعددة الأشكال، JSON ذو نوعية قوية، التحقق من صحة البيانات عند الكتابة (@email/@length/@@validate)، المعاملات، مخرج هروب منشئ الاستعلام Kysely ($qb / $expr)، الإجراءات المخصصة، SQL الخام، التسجيل، أو معالجة ORMError.
