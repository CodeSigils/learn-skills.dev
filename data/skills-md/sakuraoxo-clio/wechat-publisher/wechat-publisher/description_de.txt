Formatieren Sie den Artikel in HTML, das dem offiziellen WeChat-Konto entspricht, laden Sie automatisch Bilder hoch, generieren Sie optional automatisch ein Titelbild und schreiben Sie es mit einem einzigen Klick über die offizielle API in die Entwurfsbox des offiziellen Kontos. Der Benutzer muss vor der Veröffentlichung lediglich eine Vorschau im Backend anzeigen. Bevorzugen Sie komponentenbasiertes handgeschriebenes HTML für präzisen Schriftsatz und unterstützen Sie gleichzeitig den schnellen Schriftsatz mit Markdown. Verwenden Sie dies, wenn der Benutzer „Offizielles Konto veröffentlichen“, „Zum Entwurf senden“, „Schriftsatz für offizielles Konto“, „Auf WeChat posten“ oder „Artikel zum offiziellen WeChat-Konto“ erwähnt.
