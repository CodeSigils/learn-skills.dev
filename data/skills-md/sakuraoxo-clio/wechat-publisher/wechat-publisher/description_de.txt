Formatieren Sie den Artikel in HTML, das dem offiziellen WeChat-Konto entspricht, laden Sie automatisch Bilder hoch, generieren Sie optional ein Titelbild und schreiben Sie es mit einem einzigen Klick über die offizielle API direkt in die Entwurfsbox des offiziellen Kontos. Benutzer müssen es vor der Veröffentlichung lediglich im Backend in der Vorschau anzeigen. Bevorzugen Sie komponentenbasiertes handgeschriebenes HTML für ein präzises Layout und unterstützen Sie gleichzeitig ein schnelles Layout mit Markdown. Verwenden Sie dies, wenn der Benutzer „offizielles Konto veröffentlichen“, „Push-to-Draft-Box“, „offizielles Kontolayout“, „auf WeChat posten“ oder „Artikel zum offiziellen WeChat-Konto“ erwähnt.
