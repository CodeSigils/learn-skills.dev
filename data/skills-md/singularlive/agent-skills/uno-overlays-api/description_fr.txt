Travaillez avec les graphiques de superposition overlays.uno via les API de l'application UNO. À utiliser lorsque : contrôler les graphiques de superposition, envoyer des commandes API aux applications uno, créer des scripts ou des applications Web pour les superpositions uno, intégrer uno football, badminton, tennis, handball, hockey, compte à rebours, ticker, flipper, playlist, tirage au sort, media looper ou applications essentielles, envoyer des requêtes HTTP PUT à overlays.uno, mettre à jour le tableau de bord, l'heure du match, les noms des équipes, la visibilité de la superposition, les champs de personnalisation.
