Guida per l'implementazione di animazioni fluide e native utilizzando l'API View Transition di React (componente `<ViewTransition>`, `addTransitionType` e pseudo-elementi di transizione della vista CSS). Use this skill whenever the user wants to add page transitions, animate route changes, create shared element animations, animate enter/exit of components, animate list reorder, implement directional (forward/back) navigation animations, or integrate view transitions in Next.js. Da utilizzare anche quando l'utente menziona transizioni di visualizzazione, "startViewTransition", "ViewTransition", tipi di transizione o chiede informazioni sull'animazione tra stati dell'interfaccia utente in React senza librerie di animazione di terze parti.
