تتبع أطروحات الاستثمار عبر دورة حياتها - بدءًا من فكرة الفحص وحتى المركز المغلق بعد الوفاة. قم بتسجيل الأطروحات من مخرجات الفحص، وإدارة انتقالات الحالة، وإرفاق حجم المركز، ومراجعة تواريخ الاستحقاق، وإنشاء تقارير ما بعد الوفاة باستخدام تحليل الربح والخسارة وMAE/MFE. يتم تشغيله عندما يقول المستخدم "تسجيل الأطروحة"، أو "تتبع هذه الفكرة"، أو "حالة الأطروحة"، أو "مراجعة مستحقة"، أو "إغلاق الصفقة"، أو "بعد الوفاة"، أو "مجلة التداول".
