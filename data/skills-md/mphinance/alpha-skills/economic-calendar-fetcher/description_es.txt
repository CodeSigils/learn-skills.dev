Obtenga los próximos eventos económicos y publicaciones de datos utilizando la API de FMP. Obtenga decisiones programadas del banco central, informes de empleo, datos de inflación, publicaciones del PIB y otros indicadores económicos que mueven el mercado para rangos de fechas específicos (predeterminado: los próximos 7 días). El script genera JSON o texto sin formato; el asistente filtra, evalúa el impacto y genera el informe Markdown.
