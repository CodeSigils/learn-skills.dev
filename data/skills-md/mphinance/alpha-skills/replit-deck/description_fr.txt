galerie de modèles de page de destination. Huit thèmes distincts (helix, holm, vance,
biseau, monde sombre, monde menthe, atlas, maison bleue) — chacun un visuel complet
système (palette + type + accent) capturé à partir de replit.com/slides. Choisissez-en un
thème, ne mélangez pas. Pour les pitch decks, les rapports du conseil d'administration, les mémos de marque, les campagnes
révèle - lorsque l'utilisateur souhaite explicitement le "style Replit Slides".
