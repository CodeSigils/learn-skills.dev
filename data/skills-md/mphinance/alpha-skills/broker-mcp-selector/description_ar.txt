اختر خادم MCP وسيطًا يمكن لوكيل الذكاء الاصطناعي الخاص بك تنفيذ عمليات التداول من خلاله، وربطه بأمان. يُستخدم عندما يريد المستخدم تقديم طلبات حقيقية أو إرسالها أو أتمتتها؛ ربط الوكيل بحساب الوساطة؛ اختر بين Alpaca وIBKR وTradier وRobinhood وSchwab وKraken وخوادم MCP الوسيطة الأخرى؛ الانتقال من التحليل إلى التنفيذ؛ أو تحقق مما إذا كان خادم MCP الخاص بالوسيط يمكنه التداول أو للقراءة فقط أو أنه آمن للاتصال بأموال حقيقية. هذه هي "الأيدي" التي تنفذ ما تقرره بقية مجموعة Alpha Skills.
