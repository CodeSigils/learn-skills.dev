Choisissez un serveur MCP de courtier via lequel votre agent IA peut réellement exécuter des transactions et connectez-le en toute sécurité. À utiliser lorsque l'utilisateur souhaite passer, soumettre ou automatiser des commandes réelles ; connecter un agent à un compte de courtage ; choisissez entre Alpaca, IBKR, Tradier, Robinhood, Schwab, Kraken et d'autres serveurs de courtier MCP ; passer de l'analyse à l'exécution ; ou vérifiez si le serveur MCP d'un courtier peut négocier, est en lecture seule ou peut se connecter en toute sécurité à de l'argent réel. Ce sont les « mains » qui exécutent ce que décide le reste de la suite Alpha Skills.
