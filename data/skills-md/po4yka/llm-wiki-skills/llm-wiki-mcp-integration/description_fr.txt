Concevoir ou réviser l'intégration MCP/API pour un LLM-Wiki. À utiliser lorsque l'utilisateur souhaite que des agents tels que Claude Code, Codex, Cursor, ChatGPT, VS Code, GitHub Copilot, LangGraph ou d'autres clients MCP recherchent, lisent, lintent, réanalysent, proposent, révisent ou exportent des connaissances wiki via MCP ou une API locale/distante.
