通过在具有只读访问权限的非交互模式下委托给 Claude Code CLI (`claude -p`) 来探索和分析任何存储库（本地路径或远程 GitHub/GitLab URL）。当用户要求探索、分析、调查或研究存储库或代码库时使用。在“探索存储库”、“分析存储库”、“调查存储库”、“研究代码库”、“这个存储库做什么”、“这个代码库如何工作”、“询问存储库”、“代码库问题”、“探索存储库”、“这个项目有什么 API”、“分析这个 GitHub 存储库”、“探索 https://github.com/...”或任何了解存储库的请求时触发结构、API、架构或实现细节。适用于本地路径和远程 URL（GitHub、GitLab、Bitbucket）。
