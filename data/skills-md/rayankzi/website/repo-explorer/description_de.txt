Erkunden und analysieren Sie jedes Repository (lokaler Pfad oder Remote-GitHub/GitLab-URL), indem Sie es im nicht interaktiven Modus mit schreibgeschütztem Zugriff an die Claude Code-CLI („claude -p“) delegieren. Verwenden Sie diese Option, wenn der Benutzer ein Repository oder eine Codebasis erkunden, analysieren, untersuchen oder recherchieren möchte. Löst aus bei „Repo erkunden“, „Repo analysieren“, „Repo untersuchen“, „Codebasis erforschen“, „Was macht dieses Repo“, „Wie funktioniert diese Codebasis“, „Nach Repo fragen“, „Codebasis-Frage“, „Repository erkunden“, „Welche API hat dieses Projekt“, „Dieses GitHub-Repo analysieren“, „https://github.com/ erkunden ...“ oder jede Anfrage, um die Struktur, API, Architektur oder Implementierungsdetails eines Repositorys zu verstehen. Funktioniert sowohl mit lokalen Pfaden als auch mit Remote-URLs (GitHub, GitLab, Bitbucket).
