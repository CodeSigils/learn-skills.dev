Esplora e analizza qualsiasi repository (percorso locale o URL GitHub/GitLab remoto) delegando alla CLI Claude Code (`claude -p`) in modalità non interattiva con accesso di sola lettura. Utilizzare quando l'utente chiede di esplorare, analizzare, indagare o ricercare un repository o una base di codice. Si attiva "esplora repository", "analizza repository", "investiga repo", "ricerca codebase", "cosa fa questo repository", "come funziona questo codebase", "chiedi informazioni sul repository", "domanda codebase", "esplora repository", "quale API ha questo progetto", "analizza questo repository GitHub", "esplora https://github.com/..." o qualsiasi richiesta per comprendere la struttura, l'API, l'architettura o i dettagli di implementazione di un repository. Funziona sia con percorsi locali che con URL remoti (GitHub, GitLab, Bitbucket).
