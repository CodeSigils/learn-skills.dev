Explorez et analysez n'importe quel référentiel (chemin local ou URL GitHub/GitLab distante) en déléguant à Claude Code CLI (`claude -p`) en mode non interactif avec un accès en lecture seule. À utiliser lorsque l'utilisateur demande à explorer, analyser, enquêter ou rechercher un référentiel ou une base de code. Déclencheurs sur « explorer le dépôt », « analyser le dépôt », « enquêter sur le dépôt », « rechercher la base de code », « que fait ce dépôt ? Fonctionne à la fois avec les chemins locaux et les URL distantes (GitHub, GitLab, Bitbucket).
