読み取り専用アクセスを持つ非対話型モードで Claude Code CLI (`claude -p`) に委任することで、任意のリポジトリ (ローカル パスまたはリモート GitHub/GitLab URL) を探索および分析します。ユーザーがリポジトリまたはコードベースの探索、分析、調査、研究を依頼する場合に使用します。 「リポジトリを探索する」、「リポジトリを分析する」、「リポジトリを調査する」、「コードベースを調査する」、「このリポジトリは何をするのか」、「このコードベースはどのように機能するのか」、「リポジトリについて尋ねる」、「コードベースの質問」、「リポジトリを探索する」、「このプロジェクトにはどのような API があるのか」、「この GitHub リポジトリを分析する」、「https://github.com/... を探索する」、または任意のリクエストでトリガーされます。リポジトリの構造、API、アーキテクチャ、または実装の詳細を理解するため。ローカル パスとリモート URL (GitHub、GitLab、Bitbucket) の両方で動作します。
