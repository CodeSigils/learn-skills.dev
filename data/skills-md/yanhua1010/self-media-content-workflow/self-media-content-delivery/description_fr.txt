Enregistrez les étapes de création automédia sous forme de fichiers, gérez les versions, vérifiez les chemins, générez un package de version complet et mettez à jour l'index de contenu. Il est utilisé pour conserver la première version complète de la plateforme, les collections multiplateformes, les scripts vidéo courts, les storyboards, les versions finales, les packages de version et les rapports post-mortem, ou lorsqu'un utilisateur dit « enregistrez-le, organisez la livraison, archivez, générez une liste de versions ». Les modifications mineures du titre, la suppression d'une phrase et les alternatives temporaires ne sont pas enregistrées dans de nouvelles versions distinctes.
