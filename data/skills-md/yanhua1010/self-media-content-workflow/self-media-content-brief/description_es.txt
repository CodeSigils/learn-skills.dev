Aclare los requisitos para un solo artículo o la creación de medios propios multiplataforma y genere un resumen creativo confirmable. Esto se utiliza cuando el usuario solo proporciona un tema de una oración, un enlace, algún material, un producto o requisitos creativos vagos, y necesita confirmar la audiencia objetivo, los objetivos del contenido, el juicio central, el ángulo, la profundidad, el tono, la evidencia, las áreas tabú y las diferencias de plataforma. El análisis de datos puro, las revisiones después de que se haya confirmado la dirección y los ajustes menores en detalles no utilizan esta habilidad.
