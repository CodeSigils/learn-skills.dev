Formatez l'article final confirmé du compte public WeChat dans Markdown et écrivez-le dans la zone de brouillon du compte public WeChat. Utilisé pour les scénarios dans lesquels les utilisateurs disent « publier sur le compte public, écrire dans la zone de brouillon, formater le compte public, modifier le thème de formatage, envoyer un message image Little Green Book », etc. Téléchargez automatiquement la couverture et les images en ligne, prenez en charge plusieurs thèmes et CSS personnalisés, plusieurs comptes et le mode serveur. Créez uniquement un brouillon sans envoi massif ; les informations d'identification sont fournies uniquement via des variables d'environnement et, lorsque l'outil d'adaptation n'est pas installé, fournissez un package de publication manuelle.
