Format the confirmed final draft of the WeChat Official Account in Markdown and write it into the Official Account’s draft box. It’s used for scenarios where the user says “publish to the official account, write to the draft box, official account formatting, change the formatting theme, send Little Green Book image messages,” etc. It automatically uploads the cover and in‑text images, supports multiple themes and custom CSS, multiple accounts, and server mode. It only creates a draft without mass distribution; credentials are provided solely via environment variables, and when the adaptation tool is not installed, a manual publishing package is delivered.
