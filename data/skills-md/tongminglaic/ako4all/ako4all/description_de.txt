Führen Sie eine Agentenschleife aus, die einen GPU-Kernel iterativ für maximale Geschwindigkeit optimiert. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen GPU-Kernel (CUDA, Triton, TileLang, C++, Python) optimieren/beschleunigen/benchmarkieren möchte, AKO/AKO4ALL/AKO4X/agentische Kerneloptimierung erwähnt, darum bittet, „diesen Kernel schneller zu machen“ oder einen Kernel hat, den er anhand einer PyTorch-Referenz messen möchte. Der Skill kümmert sich um Setup, Profiling (NCU), Korrektheitsprüfung, Iterationsprotokollierung und Git-Commits. Bootstrapping eines Arbeitsbereichs in einem beliebigen Verzeichnis, auf das der Benutzer zeigt.
