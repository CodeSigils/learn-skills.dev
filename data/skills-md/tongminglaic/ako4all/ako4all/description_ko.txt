최대 속도 향상을 위해 GPU 커널을 반복적으로 최적화하는 에이전트 루프를 구동합니다. 사용자가 GPU 커널(CUDA, Triton, TileLang, C++, Python)을 최적화/속도 향상/벤치마킹하거나, AKO/AKO4ALL/AKO4X/에이전트 커널 최적화를 언급하거나, "이 커널을 더 빠르게 만들기"를 요청하거나, PyTorch 참조에 대해 측정하려는 커널이 있을 때마다 이 기술을 사용하십시오. 이 기술은 설정, 프로파일링(ncu), 정확성 확인, 반복 로깅 및 git 커밋을 처리합니다. 사용자가 가리키는 모든 디렉터리에 작업 공간을 부트스트랩합니다.
