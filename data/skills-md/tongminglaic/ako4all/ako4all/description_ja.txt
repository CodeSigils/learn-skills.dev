GPU カーネルを繰り返し最適化するエージェント ループを駆動して、最大の速度向上を実現します。ユーザーが GPU カーネル (CUDA、Triton、TileLang、C++、Python) を最適化/高速化/ベンチマークしたい場合、AKO / AKO4ALL / AKO4X / エージェント カーネル最適化について言及する場合、「このカーネルを高速化する」ように要求する場合、または PyTorch リファレンスに対して測定したいカーネルがある場合は、このスキルを使用します。このスキルは、セットアップ、プロファイリング (ncu)、正当性チェック、反復ログ、および git コミットを処理します。ユーザーが指定する任意のディレクトリ内のワークスペースをブートストラップします。
