「incidentio」 CLI を呼び出して、incident.io API を実行します。インシデント、アクション、フォローアップ、アラート/アラート ソース/ルート、エスカレーションとオンコール スケジュール、カタログ (タイプ/エントリ/リソース)、カスタム フィールド、重大度、インシデント タイプ/ロール/ステータス/タイムスタンプ、ステータス ページ (公開ページ、コンポーネント、レイアウト、サブスクライバー、テンプレートの作成と管理を含む)、ワークフロー、ユーザー、チーム、API キー、ハートビート、メンテナンスウィンドウ、設定。パブリック Bearer API (OpenAPI で生成されたコマンド) に加えて、キャプチャされた HAR から生成された内部ダッシュボード (Cookie) コマンド、手動でキュレーションされた内部エンドポイント、およびコード化されていないパスの「生の」エスケープ ハッチを使用します。 「インシデントの一覧表示」、「インシデントの作成」、「オンコール スケジュールの表示」、「ステータス ページの作成または管理」、「ステータス ページのサブスクライバーの一覧表示」、「ダッシュボード設定の調整」、または「内部ダッシュボード エンドポイントのヒット」など、タスクで Incident.io データまたはアクションが必要な場合は常に使用します。
