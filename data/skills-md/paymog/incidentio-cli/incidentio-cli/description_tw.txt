呼叫「incidentio」CLI來驅動incident.io API - 事件、操作、後續、警報/警報來源/路線、升級和待命計畫、目錄（類型/條目/資源）、自訂欄位、嚴重性、事件類型/角色/狀態/時間戳記、狀態頁面（包括建立和管理公用頁面、元件、佈局、訂閱者、範本）、工作狀態、使用者、團隊使用公共 Bearer API（OpenAPI 產生的命令）以及從捕獲的 HAR 生成的內部儀表板 (cookie) 命令、手工策劃的內部端點以及針對任何未編碼路徑的「原始」逃生艙口。每當任務需要 Incident.io 資料或操作時使用，例如「列出我們的事件」、「建立事件」、「顯示待命計畫」、「建置或管理狀態頁面」、「列出狀態頁訂閱者」、「調整儀表板設定」或「點擊內部儀表板端點」。
