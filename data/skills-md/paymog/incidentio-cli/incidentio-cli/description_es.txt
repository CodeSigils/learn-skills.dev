Invoque la CLI `incidentio` para controlar la API de incident.io: incidentes, acciones, seguimientos, alertas/fuentes de alerta/rutas, escalamientos y cronogramas de guardia, catálogo (tipos/entradas/recursos), campos personalizados, gravedad, tipos de incidentes/roles/estados/marcas de tiempo, páginas de estado (incluida la creación y administración de páginas públicas, componentes, diseño, suscriptores, plantillas), flujos de trabajo, usuarios, equipos, claves API, latidos, ventanas de mantenimiento. y configuración. Utiliza la API pública de Bearer (comandos generados por OpenAPI) más comandos del panel interno (cookie) generados a partir de HAR capturados, puntos finales internos cuidadosamente seleccionados y una trampilla de escape "sin procesar" para cualquier ruta no codificada. Úselo siempre que una tarea necesite datos o acciones de incident.io, como "enumerar nuestros incidentes", "crear un incidente", "mostrar el cronograma de guardia", "crear o administrar una página de estado", "enumerar los suscriptores de la página de estado", "ajustar una configuración del panel" o "acceder a un punto final del panel interno".
