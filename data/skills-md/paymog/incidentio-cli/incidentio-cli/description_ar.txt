قم باستدعاء واجهة سطر الأوامر "incidentio" لقيادة واجهة برمجة تطبيقات Covenant.io - الحوادث، والإجراءات، والمتابعات، والتنبيهات/مصادر/مسارات التنبيه، والتصعيد والجداول الزمنية عند الطلب، والكتالوج (الأنواع/الإدخالات/الموارد)، والحقول المخصصة، ومستويات الخطورة، وأنواع الحوادث/الأدوار/الحالات/الطوابع الزمنية، وصفحات الحالة (بما في ذلك إنشاء وإدارة الصفحات العامة والمكونات والتخطيط والمشتركين والقوالب)، وسير العمل، والمستخدمين، والفرق، ومفاتيح واجهة برمجة التطبيقات، نبضات القلب ونوافذ الصيانة والإعدادات. يستخدم Bearer API العام (الأوامر التي تم إنشاؤها بواسطة OpenAPI) بالإضافة إلى أوامر لوحة المعلومات الداخلية (ملف تعريف الارتباط) التي تم إنشاؤها من HARs الملتقطة، ونقاط النهاية الداخلية المنسقة يدويًا، وفتحة الهروب "الخام" لأي مسار غير مرمز. استخدمه عندما تحتاج مهمة ما إلى بيانات أو إجراءات Covenant.io، مثل "سرد أحداثنا"، أو "إنشاء حادثة"، أو "إظهار جدول الاتصال"، أو "إنشاء صفحة حالة أو إدارتها"، أو "قائمة المشتركين في صفحة الحالة"، أو "ضبط إعداد لوحة المعلومات"، أو "الوصول إلى نقطة نهاية لوحة المعلومات الداخلية".
