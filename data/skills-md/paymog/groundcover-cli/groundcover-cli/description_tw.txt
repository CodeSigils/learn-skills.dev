呼叫「groundcover」Go CLI 來管理 Groundcover 資源（儀表板、監視器、靜音、連接的應用程式、通知路由、API 金鑰、策略、整合、管道、工作流程），並透過查詢日誌、追蹤、指標、k8s 庫存和 k8s 事件來回答生產可觀察性問題。每當任務需要對 Groundcover API 進行身份驗證的呼叫時，或者當用戶調試產品問題並詢問諸如“為什麼 X 在產品中出錯”、“顯示服務 Y 的日誌”、“Z 上的 p99 延遲是多少”、“哪些 Pod 正在崩潰循環”、“顯示慢速請求的流量”、“命名空間 N 的任何“監視器”、“創建沉默”、“更新”等問題時，請使用通知路線”，“擊中地面覆蓋物端點”。
