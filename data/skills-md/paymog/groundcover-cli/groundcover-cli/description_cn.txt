调用“groundcover”Go CLI 来管理 Groundcover 资源（仪表板、监视器、静音、连接的应用程序、通知路由、API 密钥、策略、集成、管道、工作流程），并通过查询日志、跟踪、指标、k8s 库存和 k8s 事件来回答生产可观察性问题。每当任务需要对 Groundcover API 进行身份验证的调用时，或者当用户调试产品问题并询问诸如“为什么 X 在产品中出错”、“显示服务 Y 的日志”、“Z 上的 p99 延迟是多少”、“哪些 Pod 正在崩溃循环”、“搜索慢速请求的跟踪”、“命名空间 N 的任何 k8s 事件”、“服务 S 是否正在接收流量”、“列出 Groundcover 监视器”、“创建沉默”、“更新”等问题时，请使用通知路线”，“击中地面覆盖物端点”。涵盖所需的环境变量、SDK 支持与原始命令拆分以及日志/跟踪/指标/k8s 的具体请求正文模板，以便可以从任何地方驱动 CLI。
