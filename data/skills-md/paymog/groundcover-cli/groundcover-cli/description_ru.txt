Вызовите интерфейс командной строки Groundcover Go для управления ресурсами Groundcover (панелями мониторинга, мониторами, молчанием, подключенными приложениями, маршрутами уведомлений, ключами API, политиками, интеграцией, конвейерами, рабочими процессами), а также для ответа на вопросы наблюдения за производством путем запроса журналов, трассировок, показателей, инвентаризации k8s и событий k8s. Используйте всякий раз, когда задаче требуется аутентифицированный вызов API Groundcover или когда пользователь отлаживает проблему с продуктом и задает такие вопросы, как «почему X выдает ошибку в продукте», «покажите мне журналы для службы Y», «какова задержка p99 на Z», «какие модули аварийно завершают работу», «поиск следов медленных запросов», «любые события k8s для пространства имен N», «принимает ли служба S трафик», «составить список мониторов Groundcover», «создать тишину», «обновить». маршрут уведомления», «попался на наземную конечную точку». Охватывает необходимые переменные окружения, разделение команд на основе SDK и необработанных данных и конкретные шаблоны тела запроса для журналов/трассировок/метрик/k8, поэтому CLI можно управлять откуда угодно.
