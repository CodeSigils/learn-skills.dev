Integre el SDK de pago de Prava en aplicaciones de IA: recopile tarjetas de forma segura a través de iframe compatible con PCI, inscríbase para pagos tokenizados de Visa, permita compras repetidas con verificación de clave de acceso (biométrica) y solicite credenciales de pago únicas (token de red + CVV dinámico). Para la integración de aplicaciones de IA, no para el uso de CLI del agente de IA.
