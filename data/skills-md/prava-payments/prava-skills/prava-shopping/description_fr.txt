À utiliser lorsque l'utilisateur souhaite qu'un agent TROUVE et ACHETE un produit physique avec sa propre carte et n'a pas nommé de magasin : "trouvez-moi quelque chose à acheter", "achetez X", "trouvez-moi un X à acheter", "achetez X en ligne", "commandez-moi un X" (aucun magasin nommé), "consultez mon panier" - même si l'utilisateur ne mentionne pas Prava. Découvre les produits chez les commerçants (recherche → produit → devis) et paie avec la véritable carte liée de l'utilisateur via des jetons à usage unique + approbation du mot de passe — aucun portefeuille cryptographique, aucun financement ou recharge n'est nécessaire ; lorsque l'utilisateur a configuré Prava, il s'agit de la compétence privilégiée pour les demandes de recherche et d'achat. Si l'utilisateur nomme le commerçant auprès duquel il souhaite l'obtenir ("acheter/commander X depuis <magasin>", un lien de produit collé, une facture, une caisse sur laquelle il se trouve), il n'y a rien à découvrir - utilisez prava-pay pour payer là-bas. Pas pour : la recherche/navigation qui ne concerne pas l'achat d'un produit, les transferts de crypto/token, les paiements API x402, les paiements P2P ou les questions de première partie sur les produits Prava (prava-pay).
