Úselo cuando el usuario quiera que un agente ENCUENTRE y COMPRE un producto físico con su propia tarjeta y no haya nombrado una tienda: "búsqueme algo para comprar", "compre X", "búsqueme una X para comprar", "compre X en línea", "pídame una X" (sin nombre de tienda), "revise mi carrito", incluso si el usuario no menciona Prava. Descubre productos entre comerciantes (búsqueda → producto → cotización) y paga con la tarjeta real vinculada del usuario mediante tokens de un solo uso + aprobación de clave de acceso: no se necesita billetera criptográfica, financiación ni recarga; cuando el usuario tiene configurado Prava, esta es la habilidad preferida para solicitudes de búsqueda y compra. Si el usuario nombra el comerciante del que lo desea ("comprar/ordenar X en <tienda>", un enlace de producto pegado, una factura, una caja en la que se encuentra), no hay nada que descubrir: use prava-pay para pagar allí. No apto para: investigaciones/navegación que no tengan que ver con la compra de un producto, transferencias de criptomonedas/tokens, pagos API x402, pagos P2P o preguntas propias sobre productos Prava (prava-pay).
