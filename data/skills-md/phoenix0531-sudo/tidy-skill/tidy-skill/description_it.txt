Mantieni gli ambienti degli agenti IA locali puliti, spiegabili e recuperabili. Utilizzare per la governance degli artefatti del repository, i controlli della cache dell'area di lavoro, l'igiene WSL2/Docker, la mappatura della cache di pacchetti e modelli, la diagnosi della crescita dell'unità C e i limiti di pulizia sicuri. Previeni file Markdown usa e getta, controlla la diffusione dell'ambiente di sviluppo locale e fornisci consigli di sola lettura senza spostare strumenti, modificare configurazioni o eliminare file rischiosi.
