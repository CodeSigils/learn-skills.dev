Руководство по стилю написания документации AdonisJS. Используйте при создании, редактировании или просмотре документации, учебных пособий, руководств или справочников по API AdonisJS. Предоставляет шаблоны с ранжированием приоритетов для структуры документа, примеров кода, тона, предупреждений и пояснительных текстов. Включает рабочий процесс собеседования для сбора требований при создании новой документации с нуля.
