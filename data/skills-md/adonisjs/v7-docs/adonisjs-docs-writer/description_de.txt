Leitfaden zum Schreiben von AdonisJS-Dokumentationen. Zum Erstellen, Bearbeiten oder Überprüfen von AdonisJS-Dokumentationen, Tutorials, Leitfäden oder API-Referenzen. Bietet nach Priorität geordnete Muster für Dokumentstruktur, Codebeispiele, Ton, Warnungen und erklärendes Schreiben. Beinhaltet einen Interview-Workflow zum Sammeln von Anforderungen bei der Erstellung neuer Dokumentationen von Grund auf.
