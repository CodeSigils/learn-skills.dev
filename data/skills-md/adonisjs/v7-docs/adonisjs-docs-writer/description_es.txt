Guía de estilo de redacción de documentación de AdonisJS. Úselo al crear, editar o revisar documentación, tutoriales, guías o referencias de API de AdonisJS. Proporciona patrones clasificados por prioridad para la estructura del documento, ejemplos de código, tono, advertencias y redacción explicativa. Incluye un flujo de trabajo de entrevistas para recopilar requisitos al crear nueva documentación desde cero.
