Funzionalità complete del report settimanale OCI: riepilogo multidimensionale del mercato complessivo e classifica mensile Top10 + grafico a linee sull'utilizzo settimanale del cliente + grafico a barre sull'utilizzo mensile del cliente. Riepilogare l'utilizzo multidimensionale dei clienti CSPA/Runrate in base alle vendite, elencare i primi dieci clienti del mese corrente, generare un grafico a linee di utilizzo settimanale (contrassegnando i punti più alti/più bassi) e un grafico a barre raggruppato per cliente×mese. Parole chiave: report settimanale OCI / report settimanale Oracle / report settimanale / riepilogo generale / classifica dei clienti / utilizzo settimanale / grafico a linee / grafico di fluttuazione / grafico a barre mensile.
