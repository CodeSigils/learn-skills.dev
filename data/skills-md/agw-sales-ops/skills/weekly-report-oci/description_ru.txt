Еженедельный отчет OCI. Полная функциональность: многомерная сводка рынка и ежемесячный рейтинг Top10 + линейная диаграмма использования клиентами за неделю + гистограмма использования клиентами за месяц. Подведите итоги многомерного использования клиентов CSPA/Runrate по продажам, перечислите десять крупнейших клиентов за текущий месяц, создайте линейную диаграмму еженедельного использования (с отметкой самых высоких/самых низких точек) и гистограмму, сгруппированную по клиентам×месяц. Триггерные слова: Еженедельный отчет OCI / Еженедельный отчет Oracle / Еженедельный отчет / Общая сводка / Рейтинг клиентов / Еженедельное использование / Линейный график / Диаграмма колебаний / Месячная гистограмма.
