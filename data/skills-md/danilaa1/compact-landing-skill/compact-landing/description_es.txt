Aplique un sistema de estilo de interfaz de usuario táctil compacto para páginas de productos estrechas, demostraciones de paquetes, páginas de inicio de herramientas para desarrolladores, introducciones de documentación y páginas micro-SaaS pulidas. Úselo cuando una interfaz deba parecer precisa, silenciosa, densa y premium: diseños compactos centrados, pequeños metadatos monoespaciales, superficies de color blanco neutro, etiquetas animadas de ancho estable, separadores finos, pequeños controles táctiles, profundidad sutil, movimiento CSS restringido y una composición por página simple pero distinta.
