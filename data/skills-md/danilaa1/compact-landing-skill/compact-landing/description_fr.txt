Appliquez un système de style interface utilisateur tactile compact pour les pages de produits étroites, les démonstrations de packages, les pages de destination des outils de développement, les introductions de documentation et les pages micro-SaaS raffinées. À utiliser lorsqu'une interface doit être précise, silencieuse, dense et haut de gamme : mises en page compactes centrées, minuscules métadonnées monospaces, surfaces blanc neutre, étiquettes animées de largeur stable, séparateurs capillaires, petites commandes tactiles, profondeur subtile, mouvement CSS restreint et composition simple mais distincte par page.
