Запустите цикл Forge «сначала доказательства» для предметной спецификации. Используйте это, когда вам нужно обрабатывать улики по одному, составить сводные данные по единицам, переписать скользящее резюме, перейти к субагентам для ограниченного исследования, выбрать адаптивные профили уточнения и выдать спекулятивные варианты, когда остаются блокировщики.
