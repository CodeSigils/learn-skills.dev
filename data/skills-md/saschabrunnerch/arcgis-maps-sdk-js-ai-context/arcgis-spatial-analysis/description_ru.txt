Выполняйте пространственный анализ с использованием объектов анализа, сервисов REST для маршрутизации/геокодирования/геообработки и сокращения объектов с помощью кластеризации/биннинга. Используйте при выполнении анализа видимости, прямой видимости, буфера или геообработки, а также при кластеризации или объединении плотных точечных данных для визуализации.
