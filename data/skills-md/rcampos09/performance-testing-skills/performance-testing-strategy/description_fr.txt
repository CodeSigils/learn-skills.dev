Guide les ingénieurs QA et les testeurs de performances dans la conception d’une stratégie complète de tests de performances en posant les bonnes questions et en appliquant les meilleures pratiques. Utilisez cette compétence chaque fois que l'utilisateur demande comment planifier des tests de performances, quels types de tests exécuter (Fumée, Charge, Stress, Spike, Endurance/Soak), comment définir les SLA, quelles métriques collecter, comment dimensionner leur test ou comment séquencer l'exécution des tests. Déclenchez des expressions telles que « plan de test de performances », « stratégie de test de charge », « combien d'utilisateurs dois-je utiliser », « de quel type de test de performances ai-je besoin », « par où commencer avec les tests de performances » ou « aidez-moi à concevoir mes tests de performances ».
