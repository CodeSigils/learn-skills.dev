Leitet QA-Ingenieure und Leistungstester beim Entwerfen einer vollständigen Leistungsteststrategie an, indem es die richtigen Fragen stellt und Best Practices anwendet. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer fragt, wie Leistungstests geplant werden sollen, welche Testtypen ausgeführt werden sollen (Rauch, Last, Belastung, Spitze, Ausdauer/Soak), wie SLAs definiert werden, welche Metriken erfasst werden sollen, wie der Test dimensioniert werden soll oder wie die Testausführung sequenziert werden soll. Triggern Sie auf Phrasen wie „Leistungstestplan“, „Lastteststrategie“, „wie viele Benutzer sollte ich verwenden“, „welche Art von Leistungstest benötige ich“, „wo fange ich mit Leistungstests an“ oder „helfen Sie mir beim Entwerfen meiner Leistungstests“.
