Audite un sitio web con la CLI de squirrelscan y corrija los hallazgos en el código. Ejecuta SEO, rendimiento, seguridad, aspectos técnicos, contenido, accesibilidad y otras 15 categorías de reglas (más de 260 reglas), devuelve un informe optimizado para LLM y luego impulsa un ciclo de corrección iterativo, asignando problemas a archivos de origen, aplicando correcciones y volviendo a auditar hasta que el sitio obtenga una buena puntuación. Úselo para descubrir y evaluar problemas de sitios web o aplicaciones web y solucionarlos.
