Auditez un site Web avec la CLI squirrelscan et corrigez les résultats dans le code. Exécute le référencement, les performances, la sécurité, la technique, le contenu, l'accessibilité et 15 autres catégories de règles (plus de 260 règles), renvoie un rapport optimisé pour LLM, puis pilote une boucle de correctifs itérative, mappant les problèmes aux fichiers sources, appliquant les correctifs et ré-auditant jusqu'à ce que le site obtienne de bons résultats. Utilisez-le pour découvrir et évaluer les problèmes de site Web ou d'application Web et les résoudre.
