変更をコミットし、機能ブランチを作成し、GitHub プル リクエストを開き、CI を待ち、GitHub Actions が緑色になったら PR をマージします。または、新しいコミットを既存の PR にプッシュし、CI が成功した後にマージします。誰かが「コミットしてプッシュする」、「PR を作成する」、「プルリクエストを開く」、「レビューのために送信する」、「変更をプッシュする」、「CI が通過したらマージする」、または作業が完了して出荷する準備ができているときに使用します。また、「commitold be」、「nyiss PR-t」、「mergeld ha zöld a CI」、またはプル リクエストへの変更を取得してランディングすることを希望するバリエーションのトリガーも発生します。従来のコミット メッセージ、自動クローズ キーワードによる問題リンク (Closes #N)、機密ファイルの検出、PR テンプレートの統合、ブランチ クリーンアップによる自動マージを処理します。
