Überprüfen Sie ein gesamtes Projekt auf Fehler, Sicherheitslücken, Codequalitätsprobleme, Leistungsprobleme, fehlende Tests, Dokumentationslücken und konkrete Verbesserungs- oder Feature-Ideen – und erstellen Sie dann einen priorisierten, umsetzbaren Bericht mit Datei-Zeilen-Referenzen. Standardmäßig schreibgeschützt; Ändert oder schreibt nur fest, wenn der Benutzer anschließend explizit nach einer Korrektur fragt. Wird verwendet, wenn jemand sagt: „Mein Projekt überprüfen“, „Codebasis prüfen“, „Fehler finden“, „Auf Sicherheitsprobleme prüfen“, „Was könnte verbessert werden“, „Verbesserungen vorschlagen“, „Gibt es Schwachstellen“, „Führen Sie eine Überprüfung der Codequalität durch“ oder die ungarischen Äquivalente „nézd át a projektet“, „auditáld a kódot“, „találj hibákat“, „milyen biztonsági“. problémák vannak“, „javasolj fejlesztéseket“, „mit lehetne javítani“. Lösen Sie diese Fähigkeit immer dann aus, wenn der Benutzer eine ganzheitliche Bewertung eines Projekts und nicht die Lösung einer bestimmten Sache wünscht – auch wenn er das Wort „Audit“ nicht sagt.
