قم بإحضار مشكلة GitHub، وافهم متطلباتها، وقم بتخطيط الحل وتنفيذه، ثم قم بإجراء التحقق - دون الالتزام أو دفع أو إنشاء علاقات عامة. يُستخدم عندما يقول شخص ما "العمل على المشكلة #N"، أو "do #N"، أو "implement #N"، أو "إصلاح المشكلة #N"، أو "dolgozz a #N-es Issue-n"، أو يلصق عنوان URL لمشكلة GitHub ويريد تنفيذه. يقوم المستخدم دائمًا بمراجعة النتيجة ويقرر متى يلتزم. يقترن بشكل طبيعي مع github-commit-pr لخطوة الالتزام بعد ذلك.
