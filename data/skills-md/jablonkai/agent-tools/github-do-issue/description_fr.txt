Récupérez un problème GitHub, comprenez ses exigences, planifiez et implémentez la solution, puis exécutez la vérification, sans commettre, pousser ou créer de PR. À utiliser lorsque quelqu'un dit « travailler sur le problème #N », « faire #N », « implémenter #N », « résoudre le problème #N », « dolgozz a #N-es issue-n », ou colle une URL de problème GitHub et souhaite qu'il soit implémenté. L'utilisateur examine toujours le résultat et décide quand s'engager. S'associe naturellement avec github-commit-pr pour l'étape de validation ultérieure.
