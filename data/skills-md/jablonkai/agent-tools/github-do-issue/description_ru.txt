Получите задачу GitHub, поймите ее требования, спланируйте и внедрите решение, а затем запустите проверку — без фиксации, отправки или создания запроса на запрос. Используйте, когда кто-то говорит: «работайте над проблемой #N», «сделайте #N», «реализуйте #N», «исправьте проблему #N», «долго создайте #N-es проблему-n» или вставляет URL-адрес проблемы GitHub и хочет, чтобы она была реализована. Пользователь всегда просматривает результат и решает, когда его зафиксировать. Естественно сочетается с github-commit-pr для последующего этапа фиксации.
