Rufen Sie ein GitHub-Problem ab, verstehen Sie seine Anforderungen, planen und implementieren Sie die Lösung und führen Sie dann die Überprüfung durch – ohne Commit, Push oder Erstellung einer PR. Wird verwendet, wenn jemand „An Problem #N arbeiten“, „#N ausführen“, „#N implementieren“, „Problem #N beheben“, „ein #N-es Problem-n dolgozzieren“ sagt oder eine GitHub-Problem-URL einfügt und möchte, dass es implementiert wird. Der Benutzer überprüft immer das Ergebnis und entscheidet, wann er festschreibt. Lässt sich natürlich mit github-commit-pr für den anschließenden Commit-Schritt kombinieren.
