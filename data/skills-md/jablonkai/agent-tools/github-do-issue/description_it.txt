Recupera un problema GitHub, comprendi i suoi requisiti, pianifica e implementa la soluzione, quindi esegui la verifica, senza impegnarti, spingere o creare PR. Da utilizzare quando qualcuno dice "lavora sul problema #N", "fai #N", "implementa #N", "risolvi il problema #N", "dolgozz a #N-es problema-n" o incolla l'URL di un problema GitHub e desidera che venga implementato. L'utente esamina sempre il risultato e decide quando impegnarsi. Si accoppia naturalmente con github-commit-pr per la fase di commit successiva.
