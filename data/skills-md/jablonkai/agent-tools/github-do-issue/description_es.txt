Obtenga un problema de GitHub, comprenda sus requisitos, planifique e implemente la solución y luego ejecute la verificación, sin comprometerse, presionar ni crear un PR. Úselo cuando alguien dice "trabajar en el problema #N", "hacer #N", "implementar #N", "solucionar el problema #N", "dolgozz a #N-es problema-n", o pega una URL de problema de GitHub y quiere implementarlo. El usuario siempre revisa el resultado y decide cuándo comprometerse. Se empareja naturalmente con github-commit-pr para el paso de confirmación posterior.
