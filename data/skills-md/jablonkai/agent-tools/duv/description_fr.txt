Recherchez et récupérez des données sur le site Web DUV Ultramarathon Statistics (statistik.d-u-v.org). À utiliser lorsque l'utilisateur pose des questions sur les résultats de l'ultramarathon, les profils des coureurs, les événements de course, les classements, les records ou les temps d'arrivée, par exemple. « trouver le coureur X sur DUV », « quel a été le résultat du Spartathlon 2024 », « les meilleurs temps sur 100 km en Hongrie », « rechercher un ultra coureur ». La base de données DUV couvre plus de 10 millions de performances, plus de 2,4 millions de coureurs et plus de 115 000 événements ultra dans le monde.
