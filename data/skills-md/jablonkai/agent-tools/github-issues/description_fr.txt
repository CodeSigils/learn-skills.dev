Créez, affichez, fermez, commentez, étiquetez, triez et répertoriez les problèmes GitHub avec une structure standardisée. À utiliser lorsque quelqu'un dit « créer un problème », « signaler un bug », « signaler ceci », « ouvrir un problème pour cela », « trier les problèmes », « étiqueter le problème #N », « fermer #N », « lister les problèmes ouverts », « lire un problème-t » ou souhaite gérer les problèmes GitHub de quelque manière que ce soit. Applique les modèles de problèmes avec les sections requises (Résumé, Solution proposée), applique la taxonomie des étiquettes par défaut de GitHub et valide l'existence des étiquettes avant utilisation.
