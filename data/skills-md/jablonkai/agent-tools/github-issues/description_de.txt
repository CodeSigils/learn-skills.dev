Erstellen, Anzeigen, Schließen, Kommentieren, Kennzeichnen, Sortieren und Auflisten von GitHub-Problemen mit standardisierter Struktur. Verwenden Sie diese Option, wenn jemand sagt: „Problem erstellen“, „Fehler melden“, „Dies melden“, „Problem dafür öffnen“, „Probleme sortieren“, „Problem #N kennzeichnen“, „#N schließen“, „Offene Probleme auflisten“, „Hozz létre egy issue-t“ oder GitHub-Probleme auf irgendeine Weise verwalten möchte. Erzwingt Problemvorlagen mit erforderlichen Abschnitten (Zusammenfassung, vorgeschlagene Lösung), wendet die Standard-Label-Taxonomie von GitHub an und validiert vor der Verwendung das Vorhandensein von Labels.
