標準化された構造で、GitHub の問題の作成、表示、クローズ、コメント、ラベル付け、優先順位付け、リストを作成します。誰かが「問題を作成する」、「バグを報告する」、「これを報告する」、「これについて問題をオープンする」、「問題をトリアージする」、「問題 #N にラベルを付ける」、「#N を閉じる」、「未解決の問題をリストする」、「問題をリストする」、または何らかの方法で GitHub の問題を管理したい場合に使用します。必須セクション (概要、提案されたソリューション) を含む問題テンプレートを強制し、GitHub のデフォルトのラベル分類を適用し、使用前にラベルが存在することを検証します。
