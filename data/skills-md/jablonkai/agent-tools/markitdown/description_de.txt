Konvertieren Sie Dateien und Dokumente für die LLM-Verwendung mit dem Markitdown-Tool von Microsoft in Markdown. Verwenden Sie es immer dann, wenn der Benutzer eine PDF-, Word-/Excel-/PowerPoint-Datei (.docx/.xlsx/.pptx), eine HTML-Seite, CSV/JSON/XML, EPUB, ein Bild, eine Audiodatei, ein ZIP-Archiv oder eine YouTube-URL in Markdown oder einfachen Text umwandeln möchte – z. B. „Konvertieren Sie dieses PDF in Markdown“, „extrahieren Sie den Text aus report.docx“, „wandeln Sie diese Tabelle in Markdown um“, „ziehen Sie das Transkript aus dieser Audiodatei“, „markdownifizieren Sie diese Dateien“, „alakítsd át markdownná“. Verwenden Sie es auch, wenn Sie einen Ordner mit Dokumenten stapelweise konvertieren, Office-/PDF-Inhalte in eine Eingabeaufforderung einspeisen oder einen Dokument-zu-Markdown-Schritt in einem Skript erstellen. Wird auch dann ausgelöst, wenn der Benutzer einen Dateityp benennt, ohne „Markitdown“ zu sagen.
