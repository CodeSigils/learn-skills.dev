使用 Microsoft 的 markitdown 工具將文件和文件轉換為 Markdown 以供 LLM 使用。每當使用者想要將 PDF、Word/Excel/PowerPoint 文件 (.docx/.xlsx/.pptx)、HTML 頁面、CSV/JSON/XML、EPUB、圖片、音訊檔案、ZIP 檔案或 YouTube URL 轉換為 Markdown 或純文字時使用 - 例如「將此 PDF 轉換為 markdown'、'report.docx' markdown'、'從此音訊擷取文字記錄'、'markdownify 這些檔案'、'alakítsd át markdownná'。也可以在批次轉換文件資料夾、將 Office/PDF 內容輸入提示或在腳本中建置文件到 Markdown 步驟時使用。即使使用者命名檔案類型而不說「markitdown」也會觸發。
