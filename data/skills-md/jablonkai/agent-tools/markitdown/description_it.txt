Converti file e documenti in Markdown per il consumo LLM utilizzando lo strumento markitdown di Microsoft. Da utilizzare ogni volta che l'utente desidera trasformare un file PDF, Word/Excel/PowerPoint (.docx/.xlsx/.pptx), una pagina HTML, CSV/JSON/XML, EPUB, un'immagine, un file audio, un archivio ZIP o un URL YouTube in Markdown o testo normale, ad es. 'converti questo PDF in markdown', 'estrai il testo da report.docx', 'trasforma questo foglio di calcolo in markdown', 'estrai la trascrizione da questo audio', 'markdownify questi file', 'alakítsd át markdownná'. Da utilizzare anche quando si converte in batch una cartella di documenti, si inserisce contenuto Office/PDF in un prompt o si crea un passaggio da documento a markdown in uno script. Si attiva anche se l'utente nomina un tipo di file senza dire "markitdown".
