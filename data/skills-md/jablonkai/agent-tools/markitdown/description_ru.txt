Преобразуйте файлы и документы в Markdown для использования в LLM с помощью инструмента Microsoft markitdown. Используйте, когда пользователь хочет преобразовать PDF-файл, файл Word/Excel/PowerPoint (.docx/.xlsx/.pptx), HTML-страницу, CSV/JSON/XML, EPUB, изображение, аудиофайл, ZIP-архив или URL-адрес YouTube в Markdown или обычный текст — например, «конвертировать этот PDF-файл в уценку», «извлечь текст из report.docx», «превратить эту таблицу в уценку», «извлечь расшифровку из этого аудио», «уценить эти файлы», «уценить уценку». Также используйте при пакетном преобразовании папки документов, загрузке содержимого Office/PDF в командную строку или создании этапа преобразования документа в уценку в сценарии. Срабатывает, даже если пользователь называет тип файла, не говоря «markitdown».
