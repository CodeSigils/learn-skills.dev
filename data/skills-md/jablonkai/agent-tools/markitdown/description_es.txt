Convierta archivos y documentos a Markdown para consumo LLM utilizando la herramienta Markitdown de Microsoft. Úselo siempre que el usuario desee convertir un archivo PDF, Word/Excel/PowerPoint (.docx/.xlsx/.pptx), una página HTML, CSV/JSON/XML, EPUB, una imagen, un archivo de audio, un archivo ZIP o una URL de YouTube en Markdown o texto sin formato, p. 'convertir este PDF a Markdown', 'extraer el texto de report.docx', 'convertir esta hoja de cálculo en Markdown', 'extraer la transcripción de este audio', 'markdownify estos archivos', 'alakítsd át markdownná'. Utilícelo también al convertir por lotes una carpeta de documentos, introducir contenido de Office/PDF en un mensaje o crear un paso de documento a rebajas en un script. Se activa incluso si el usuario nombra un tipo de archivo sin decir "markitdown".
