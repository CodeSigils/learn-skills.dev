使用 Microsoft 的 markitdown 工具将文件和文档转换为 Markdown 以供 LLM 使用。每当用户想要将 PDF、Word/Excel/PowerPoint 文件 (.docx/.xlsx/.pptx)、HTML 页面、CSV/JSON/XML、EPUB、图像、音频文件、ZIP 存档或 YouTube URL 转换为 Markdown 或纯文本时使用 - 例如'将此 PDF 转换为 markdown'、'从 report.docx 中提取文本'、'将此电子表格转换为 markdown'、'从此音频中提取文字记录'、'markdownify 这些文件'、'alakítsd át markdownná'。还可以在批量转换文档文件夹、将 Office/PDF 内容输入提示或在脚本中构建文档到 Markdown 步骤时使用。即使用户命名文件类型而不说“markitdown”也会触发。
