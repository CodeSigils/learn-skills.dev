قم بتحويل الملفات والمستندات إلى Markdown لاستهلاك LLM باستخدام أداة markitdown من Microsoft. يُستخدم عندما يريد المستخدم تحويل ملف PDF أو Word/Excel/PowerPoint (.docx/.xlsx/.pptx) أو صفحة HTML أو CSV/JSON/XML أو EPUB أو صورة أو ملف صوتي أو أرشيف ZIP أو عنوان URL على YouTube إلى Markdown أو نص عادي - على سبيل المثال. "تحويل ملف PDF هذا إلى تخفيض السعر"، "استخراج النص من report.docx"، "تحويل جدول البيانات هذا إلى تخفيض السعر"، "سحب النص من هذا الصوت"، "تخفيض سعر هذه الملفات"، "إيقاف تخفيض السعر" يُستخدم أيضًا عند تحويل مجلد من المستندات دفعة واحدة، أو تغذية محتوى Office/PDF في موجه، أو إنشاء خطوة من مستند إلى تخفيض السعر في برنامج نصي. يتم تشغيله حتى إذا قام المستخدم بتسمية نوع الملف دون قول "markitdown".
