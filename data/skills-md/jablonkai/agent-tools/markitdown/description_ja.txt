Microsoft の markitdown ツールを使用して、LLM で使用できるようにファイルとドキュメントを Markdown に変換します。ユーザーが PDF、Word/Excel/PowerPoint ファイル (.docx/.xlsx/.pptx)、HTML ページ、CSV/JSON/XML、EPUB、画像、音声ファイル、ZIP アーカイブ、または YouTube URL をマークダウンまたはプレーン テキストに変換する場合に使用します。 「この PDF をマークダウンに変換する」、「report.docx からテキストを抽出する」、「このスプレッドシートをマークダウンに変換する」、「この音声からトランスクリプトを取得する」、「これらのファイルをマークダウンする」、「マークダウンを実行する」。ドキュメントのフォルダーをバッチ変換する場合、Office/PDF コンテンツをプロンプトにフィードする場合、またはスクリプトで doc-to-Markdown ステップを構築する場合にも使用します。ユーザーが「markitdown」と言わずにファイルの種類に名前を付けた場合でもトリガーされます。
