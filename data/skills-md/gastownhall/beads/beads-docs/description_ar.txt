اصطلاحات المشروع لكتابة وثائق مستخدم الخرز أو تحريرها أو إعادة هيكلتها أو مراجعتها - موقع Mintlify ضمن docs/. استخدم هذا عندما تلمس أي شيء في المستندات/ (الصفحات، مستندات المفاهيم، المرجع، أدلة التكامل، سجلات تشغيل الاسترداد، المخططات، التنقل docs.json) أو كتابة/تحرير نثر حول الخرز، حتى عندما يكون الطلب مجرد "إصلاح المستندات"، أو "كتابة صفحة مستندات"، أو "المستندات خاطئة/مربكة"، أو "إعادة تسمية X عبر المستندات"، أو تحرير ملف ضمن docs/. وهو يحدد نموذج المفهوم المتعارف عليه (الخرزة → التبعيات → العمل الجاهز؛ الصيغة → بروتو → الجزيء/الخيط؛ البوابات؛ مزامنة دولت والاتحاد)، والمصطلحات المطلوبة، واصطلاحات النثر/التأكيد/الرسم البياني، والقاعدة التي تولد المستندات يتم تحريرها من مصدرها، والبوابات التي سيتم تشغيلها قبل الانتهاء من عمل المستندات.
