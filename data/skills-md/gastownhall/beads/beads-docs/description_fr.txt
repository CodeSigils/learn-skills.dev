Conventions du projet pour la rédaction, l'édition, la restructuration ou la révision de la documentation utilisateur des perles — le site Mintlify sous docs/. Utilisez-le chaque fois que vous touchez quoi que ce soit dans docs/ (pages, documents conceptuels, références, guides d'intégration, runbooks de récupération, diagrammes, navigation docs.json) ou que vous écrivez/modifiez de la prose sur les perles, même lorsque la demande consiste simplement à « corriger les documents », « écrire une page de documents », « les documents sont erronés/déroutants », « renommer X dans les documents » ou une modification d'un fichier sous docs/. Il définit le modèle de concept canonique (perle → dépendances → travail prêt ; formule → proto → molécule/follet ; portes ; synchronisation Dolt et fédération), la terminologie requise, les conventions de prose/emphase/diagramme, la règle selon laquelle les documents générés sont édités à leur source et les portes à exécuter avant que le travail de documentation ne soit terminé.
