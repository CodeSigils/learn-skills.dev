Instale e implemente el servicio xiaohongshu-mcp y configure la conexión MCP, guiando a los usuarios a través de todo el proceso desde cero hasta utilizable. Use esto cuando un usuario esté usando las funciones de Xiaohongshu por primera vez, mencione la instalación/implementación/configuración de Xiaohongshu, la configuración del entorno, una falla en la conexión del servicio MCP o herramientas MCP como check_login_status que no están disponibles.
