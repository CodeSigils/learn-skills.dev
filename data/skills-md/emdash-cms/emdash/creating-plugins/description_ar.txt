قم بإنشاء ملحقات EmDash CMS باستخدام الخطافات والتخزين والإعدادات وواجهة المستخدم الإدارية ومسارات واجهة برمجة التطبيقات وأنواع كتل النص المحمولة. استخدم هذه المهارة عندما يُطلب منك إنشاء مكون إضافي EmDash أو دعمه أو تنفيذه، أو عند إنشاء ميزات المكون الإضافي مثل أنواع الكتل المخصصة أو صفحات الإدارة أو روابط المحتوى.
