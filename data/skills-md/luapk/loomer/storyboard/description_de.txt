Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Storyboard entwickeln, sequentielle Eingabeaufforderungen für die KI-Bild-/Videogenerierung schreiben oder ein Drehbuch, eine Prämisse oder eine Beatlist in eine Bild-für-Bild-Bildsequenz aufteilen möchte. Triggern Sie auf Phrasen wie „Storyboard“, „Shot-Liste“, „Teilen Sie dies in Shots auf“, „KI-Videoansagen“, „Sequenz von Clips“, „Storyboard für eine Anzeige/ein Musikvideo/einen Kurzfilm“. Wird ausgelöst, wenn der Benutzer ein Skript, eine Prämisse, eine Beatlist oder eine grobe Idee vorgibt, die in einen sequentiellen Plan umgewandelt werden soll, den ein anderes Modell als Video oder Standbilder generieren kann. Produziert handwerklich hochwertige Storyboards, die auf Daniel Arijons Grammatik der Filmsprache basieren – Aufnahmen unter Berücksichtigung der Interessenlinie, der Bildschirmausrichtung, der Übereinstimmung der Augenlinien und des Dreiecksprinzips. Die Ausgabe ist reich an Markdown mit einer Kontinuitätsbibel, Arijon-Grammatik-Metadaten pro Aufnahme und einem Standbild key_frame_prompt pro Aufnahme für die Bildgenerierung. Die Standardästhetik ist filmisches Fotoreal. NICHT für statische Präsentationen, einmalige Aufforderungen, Filmkritik oder Drehbuchentwürfe verwenden.
