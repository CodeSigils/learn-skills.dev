Используйте этот навык всякий раз, когда пользователь хочет разработать раскадровку, написать последовательные подсказки для создания изображений/видео с помощью ИИ или разбить сценарий, предпосылку или бит-лист на пошаговую визуальную последовательность. Запускайте такие фразы, как «раскадровка», «список кадров», «разбить это на кадры», «видеоподсказки AI», «последовательность клипов», «раскадровка для рекламы/музыкального видео/короткометражного фильма». Запускается, когда пользователь дает сценарий, предпосылку, бит-лист или приблизительную идею для развития в последовательный план, который другая модель может создать в виде видео или фотографий. Создает раскадровки профессионального уровня, основанные на «Грамматике киноязыка» Дэниела Арихона — кадры с учетом линии интереса, направления экрана, совпадения линий глаз и принципа треугольника. Вывод — это богатая уценка с библией непрерывности, метаданными грамматики Арихона для каждого кадра и неподвижным ключом_frame_prompt для каждого кадра для генерации изображения. Эстетика по умолчанию — кинематографическая фотореалистичность. НЕ используйте для статических колод, одноразовых подсказок, критики фильмов или написания сценариев.
