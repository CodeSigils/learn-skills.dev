Verwaltet eine laufende Repo-Root-Datei „implementation-notes.html“, die aufzeichnet, wie Implementierungsentscheidungen eine Spezifikation interpretieren, klarstellen oder von ihr abweichen. Verwenden Sie diese Option, wenn der Benutzer explizit nach Implementierungsnotizen fragt, die Datei „implementation-notes.html“ pflegt, Entscheidungen nachverfolgt, Spezifikationsabweichungen erfasst, Kompromisse aufzeichnet oder während der Implementierung laufende Notizen führt.
