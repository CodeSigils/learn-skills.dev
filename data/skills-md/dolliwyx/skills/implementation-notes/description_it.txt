Mantiene un file repo-root implementazione-notes.html in esecuzione che registra il modo in cui le decisioni di implementazione interpretano, chiariscono o divergono da una specifica. Da utilizzare quando l'utente richiede esplicitamente note di implementazione, manutenzione di implement-notes.html, monitoraggio delle decisioni, acquisizione di deviazioni dalle specifiche, registrazione di compromessi o mantenimento di note in corso durante l'implementazione.
