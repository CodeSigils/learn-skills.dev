Estándares de codificación Roblox/Luau independientes del marco. Úselo al escribir, revisar o refactorizar cualquier código Luau (Script, LocalScript, ModuleScript) en un proyecto de Roblox, o cuando el usuario solicite tener en cuenta las mejores prácticas como guía permanente: aplica las reglas de diseño, denominación, rendimiento, memoria, redes y seguridad de VARIABLES/FUNCIONES/INICIALIZACIÓN independientemente del marco, la estructura de carpetas o el género. Dos modos: Predeterminado (aplica estas convenciones tal como están) y Adaptativo (estudia primero el estilo existente del proyecto, confirma y luego aplica). Se adapta a bibliotecas comunitarias (ProfileStore, Packet, Trove, Knit, Fusion, ...) y respeta los niveles de supervisión (!ask / !bal / !go). No para preguntas sobre Lua, UI de Studio o activos que no sean de Roblox que no toquen el código, ni discusiones sobre diseño de juegos sin Luau para escribir o revisar.
