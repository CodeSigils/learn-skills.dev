Консультант по ресурсам Alibaba Cloud Drive, предлагающий четыре типа рабочих процессов — инвентаризация, организация, каталогизация и планирование — в рамках атомарных операций soia-pkm-alipan: инвентаризация облачного диска, организация ресурсов, создание коллекций Obsidian, создание секционированного кэшированного инкрементального основного индекса Excel с навигацией по семейным курсам и создание плана обучения на основе информации о студентах, предоставленной на этот раз. Триггеры: «Организовать облачный диск», «Инвентаризация облачного диска», «Обновить индекс облачного диска», «Обновить главный индекс Excel», «Создать Excel для семейной навигации», «Создать библиотеку для облачного диска», «Использовать ресурсы облачного диска для плана обучения».
