Alibaba Cloud Disk Resource Consultant: provides four types of workflows—inventory, organize, catalog, and plan—to inventory and organize resources, generate Obsidian collections and incremental Excel/home navigation, and create learning plans based on the academic situation provided by the user. Triggers: “Organize Cloud Disk,” “Cloud Disk Inventory,” “Update Cloud Disk Index,” “Update Excel Master Index,” “Generate Home Navigation Excel,” “Build Library for Cloud Disk,” “Create Learning Plan Using Cloud Disk Resources.”
