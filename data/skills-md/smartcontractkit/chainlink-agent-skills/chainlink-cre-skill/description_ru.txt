Предоставьте разработчикам возможность быстро изучать и использовать среду выполнения Chainlink (CRE), ссылаясь на отфильтрованную документацию CRE. Запуск, когда пользователь хочет подключиться, создать рабочий процесс CRE (на TypeScript, Golang или других поддерживаемых языках), руководство по рабочему процессу, помощь CRE CLI и/или SDK, рекомендации по операциям во время выполнения или выбор возможностей.
