Chainlink Confidential AI Attester: プライベート文書を AWS Nitro Enclave 内の LLM に送信し、暗号的に証明された結果を取得します。生の文書が TEE から流出することはありません。これらのハッカソンのシナリオに使用します: (1) 過小担保の DeFi 融資 — 銀行取引明細書をアップロードし、オンチェーンの財務状況を公開することなく、証明された承認/拒否の JSON 決定を取得します。 (2) 認定投資家の検証 — 証券取引明細書から非公開で SEC ルール 501 の資格を確認します。 (3) KYC/AML スクリーニング — TEE 内の ID 文書と取引履歴を分析し、フラグ付きの合格/不合格を返します。 (4) 準備金の証明 — 請求された準備金に対してカストディアン残高報告書を検証する。 (5) AI がユーザーの機密文書を読み取る必要があり、その結果にどのモデルがどのデータで実行されたのかを暗号化して証明する必要があるユースケース。トリガー: プライベート推論、証明済み AI、TEE 推論、機密 AI、または過少担保融資 / KYC / 文書分析と並行して言及された認定投資家。
