Gérez les demandes Chainlink CCIP avec un flux de travail axé sur la sécurité. À utiliser pour les envois de messages CCIP, le pontage des fonds via les outils CCIP, le développement de contrats d'expéditeur et de destinataire, la recherche de l'état des messages, les vérifications de connectivité d'itinéraire, la découverte de jetons pris en charge ou la configuration CCT. Demandez les détails de l'itinéraire manquant, exigez une approbation explicite avant toute action en chaîne, refusez les écritures sur le réseau principal dans cette version et préférez des modèles de contrat sécurisés et conservateurs.
