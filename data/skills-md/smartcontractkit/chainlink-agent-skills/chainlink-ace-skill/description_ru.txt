Управляйте работой Chainlink ACE (Automated Compliance Engine), используя общедоступный репозиторий smartcontractkit/chainlink-ace и официальную документацию платформы docs.chain.link ACE. Используйте для проверенных основных контрактов ACE, управляемой платформы/бета-области, API координатора, API отчетности, управления политиками, PolicyEngine, PolicyProtected, цепочек политик, пользовательских политик, экстракторов, картографов, межцепочной идентификации (CCID), реестров учетных данных, учетных данных KYC/AML, проверки санкций, регулируемых токенов, примеров токенов соответствия ERC-20 и ERC-3643, руководства по обновлению и лицензирования BUSL. Запускается при любом упоминании ACE, Automated Compliance Engine, Chainlink-ace, соответствия Chainlink, соблюдения политик, ERC-3643 или правил соответствия ончейн, даже если пользователь явно не произносит «ACE».
