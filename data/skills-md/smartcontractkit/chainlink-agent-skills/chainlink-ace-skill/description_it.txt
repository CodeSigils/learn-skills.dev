Gestisci il lavoro di Chainlink ACE (Automated Compliance Engine) utilizzando il repository pubblico smartcontractkit/chainlink-ace e i documenti ufficiali della piattaforma docs.chain.link ACE. Utilizzare per contratti principali ACE controllati, ambito piattaforma/beta gestita, API Coordinator, API di reporting, gestione delle policy, PolicyEngine, PolicyProtected, catene di policy, policy personalizzate, estrattori, mappatori, Cross-Chain Identity (CCID), registri di credenziali, credenziali KYC/AML, screening delle sanzioni, token regolamentati, esempi di token di conformità ERC-20 ed ERC-3643, linee guida per l'aggiornamento e licenze BUSL. Attivare qualsiasi menzione di ACE, Automated Compliance Engine, chainlink-ace, conformità Chainlink, applicazione delle policy, ERC-3643 o regole di conformità onchain, anche se l'utente non dice esplicitamente "ACE".
