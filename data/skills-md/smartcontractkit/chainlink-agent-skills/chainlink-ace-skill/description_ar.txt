تعامل مع عمل Chainlink ACE (محرك الامتثال الآلي) باستخدام مستودع Smartcontractkit/chainlink-ace العام ومستندات docs.chain.link ACE الرسمية. الاستخدام لعقود ACE الأساسية التي تمت مراجعتها، ونطاق النظام الأساسي/الإصدار التجريبي المُدار، وواجهة برمجة تطبيقات المنسق، وواجهة برمجة التطبيقات لإعداد التقارير، وإدارة السياسات، وPolicyEngine، وPolicyProtected، وسلاسل السياسات، والسياسات المخصصة، والمستخرجين، ومصممي الخرائط، والهوية عبر السلسلة (CCIDs)، وسجلات الاعتماد، وبيانات اعتماد KYC/AML، وفحص العقوبات، والرموز المميزة المنظمة، وأمثلة الرمز المميز للامتثال ERC-20 وERC-3643، وإرشادات الترقية، وBUSL الترخيص. قم بتشغيل أي ذكر لـ ACE، أو محرك الامتثال الآلي، أو chainlink-ace، أو امتثال Chainlink، أو إنفاذ السياسة، أو ERC-3643، أو قواعد الامتثال onchain، حتى لو لم يذكر المستخدم "ACE" صراحةً.
