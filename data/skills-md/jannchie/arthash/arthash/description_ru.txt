Используйте артхэш, чтобы добавить в приложение крошечные хэши изображений-заполнителей (17–400 байт) — художественная альтернатива Blurhash/thumbhash/sqip. Активируйте этот навык, когда пользователь хочет отобразить предварительный просмотр изображения низкого качества (LQIP) во время загрузки реального изображения, заменить Blurhash или Thumbhash, сгенерировать заполнители SVG без запуска подпроцесса Go (sqip) или создать стилизованную мозаику из палитры. arthash поставляет три SDK (Rust crate, Python `arthash`, npm `arthash`), которые читают и записывают один и тот же формат байтов, поэтому хэш, созданный на сервере, одинаково декодируется в браузере. Этот навык охватывает выбор правильного SDK, правильного режима (по умолчанию «RECT» и другие режимы фигур «TRIANGLE» / «CIRCLE» / «SQUARE» / «ROTATED_RECT» для SVG, «PIXEL» для мозаики, «DCT» только тогда, когда вам конкретно нужен размытый вид в стиле размытия/thumbhash), правильную палитру, жизненный цикл кодирования → сохранения → декодирования → рендеринга, а также небольшие подводные камни (кодеки не входные данные должны быть небольшими (режимы SVG или растровые режимы); Подробности API для каждого языка находятся в файлах typescript.md, python.md иrust.md рядом с этим файлом.
