Utilisez arthash pour ajouter de minuscules hachages d'images d'espace réservé (17 à 400 octets) à une application - l'alternative artistique à Blurhash / Thumbhash / Scip. Déclenchez cette compétence lorsque l'utilisateur souhaite restituer un aperçu d'image de mauvaise qualité (LQIP) pendant le chargement d'une image réelle, remplacer Bluhash ou Thumbhash, générer des espaces réservés SVG sans générer de sous-processus Go (sqip) ou produire une mosaïque stylisée à partir d'une palette. arthash fournit trois SDK (Rust crate, Python `arthash`, npm `arthash`) qui lisent et écrivent tous le même format d'octet, donc un hachage effectué sur le serveur est décodé de manière identique dans le navigateur. Cette compétence couvre le choix du bon SDK, du bon mode (`RECT` par défaut et autres modes de forme `TRIANGLE` / `CIRCLE` / `SQUARE` / `ROTATED_RECT` pour SVG, `PIXEL` pour la mosaïque, `DCT` uniquement lorsque vous souhaitez spécifiquement un aspect flou de style flou/thumbhash), la bonne palette, l'encodage → magasin → décodage → cycle de vie du rendu, et les petits pièges (les codecs ne sont pas en octets ; les entrées doivent être petites ; modes SVG vs modes raster). Les détails de l'API par langue se trouvent dans `typescript.md`, `python.md` et `rust.md` à côté de ce fichier.
