使用 arthash 在應用程式中添加微小的佔位符圖像雜湊（17-400 位元組）——blurhash/thumbhash/sqip 的藝術替代品。當使用者想要在載入真實影像時渲染低品質影像預覽 (LQIP)、替換模糊哈希或拇指哈希、生成 SVG 佔位符而不產生 Go 子進程 (sqip) 或從調色板生成風格化馬賽克時，觸發此技能。 arthash 提供了三個 SDK（Rust crate、Python `arthash`、npm `arthash`），它們都讀取和寫入相同的位元組格式，因此在伺服器上產生的雜湊在瀏覽器中進行相同的解碼。這項技能包括選擇正確的 SDK、正確的模式（預設的「RECT」和其他形狀模式「TRIANGLE」/「CIRCLE」/「SQUARE」/「ROTATED_RECT」用於 SVG、「PIXEL」用於馬賽克、「DCT」（僅當您特別想要 Blurhash/thumbhash 風格的模糊外觀、「DCT」（僅當您特別想要 Blurhash/thumbhash 風格的模糊外觀）、 正確的色調、正確的色調、 正確的調板、正確的調板外觀、 → 正確的調板外觀）、 正確的調板外觀、 → 正確的調板外觀）、 正確的調板外觀、 → 正確的調板外觀）、 正確的調板外觀、 → 正確的調色板渲染生命週期以及小陷阱（編解碼器不是以位元組為單位；輸入必須以位元組為單位）較小；SVG 模式與光柵模式）。每種語言的 API 詳細資訊位於此檔案旁的「typescript.md」、「python.md」和「rust.md」。
