استخدم arthash لإضافة تجزئات صغيرة لصورة العنصر النائب (17–400 بايت) إلى التطبيق - البديل الفني لـ Blurhash / Thumbhash / Squip. قم بتشغيل هذه المهارة عندما يريد المستخدم تقديم معاينة صورة منخفضة الجودة (LQIP) أثناء تحميل صورة حقيقية، أو استبدال تشويش الصورة المجسمة أو تشويش الإبهام، أو إنشاء عناصر نائبة لـ SVG دون إنشاء عملية فرعية لـ Go (sqip)، أو إنتاج فسيفساء منمقة من لوحة الألوان. يشحن arthash ثلاث مجموعات SDK (Rust crate، وPython `arthash`، وnpm `arthash`) التي تقرأ جميعها وتكتب نفس تنسيق البايت، لذلك يتم فك تشفير التجزئة التي تم إجراؤها على الخادم بشكل مماثل في المتصفح. تغطي هذه المهارة اختيار SDK الصحيح، والوضع الصحيح (الافتراضي `RECT` وأوضاع الأشكال الأخرى `TRIANGLE` / `CIRCLE` / `SQUARE` / `ROTATED_RECT` لـ SVG، و`PIXEL` للفسيفساء، و`DCT` فقط عندما تريد على وجه التحديد مظهرًا ضبابيًا بنمط Blurhash/thumbhash)، واللوحة الصحيحة، والتشفير → المتجر → فك التشفير → عرض دورة الحياة، والصغيرة المزالق (برامج الترميز ليست بالبايت؛ يجب أن تكون المدخلات صغيرة؛ أوضاع SVG مقابل أوضاع البيانات النقطية). توجد تفاصيل واجهة برمجة التطبيقات لكل لغة في `typescript.md` و`python.md` و`rust.md` بجوار هذا الملف.
