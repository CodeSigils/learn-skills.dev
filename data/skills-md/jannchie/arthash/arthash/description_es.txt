Utilice arthash para agregar pequeños hashes de imágenes de marcador de posición (17 a 400 bytes) a una aplicación: la alternativa artística a blurhash/thumbhash/sqip. Active esta habilidad cuando el usuario quiera renderizar una vista previa de imagen de baja calidad (LQIP) mientras se carga una imagen real, reemplazar blurhash o thumbhash, generar marcadores de posición SVG sin generar un subproceso Go (sqip) o producir un mosaico estilizado a partir de una paleta. arthash incluye tres SDK (Rust crate, Python `arthash`, npm `arthash`) que leen y escriben el mismo formato de bytes, por lo que un hash creado en el servidor se decodifica de manera idéntica en el navegador. Esta habilidad cubre elegir el SDK correcto, el modo correcto (`RECT` predeterminado y otros modos de forma `TRIANGLE` / `CIRCLE` / `SQUARE` / `ROTated_RECT` para SVG, `PIXEL` para mosaico, `DCT` solo cuando específicamente deseas una apariencia borrosa estilo blurhash/thumbhash), la paleta correcta, el ciclo de vida codificar → almacenar → decodificar → renderizar y los pequeños errores (los códecs no están en el bytes; las entradas deben ser pequeñas; modos SVG versus modos ráster). Los detalles de la API por idioma se encuentran en `typescript.md`, `python.md` y `rust.md` junto a este archivo.
