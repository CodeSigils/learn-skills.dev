arthash を使用して、小さなプレースホルダー画像ハッシュ (17 ～ 400 バイト) をアプリケーションに追加します。これは、blurhash、thumbhash、sqip に代わる芸術的な代替手段です。ユーザーが実際の画像のロード中に低品質の画像プレビュー (LQIP) をレンダリングしたい場合、ブラーハッシュまたはサムハッシュを置き換えたい場合、Go サブプロセスを生成せずに SVG プレースホルダーを生成したい場合 (sqip)、またはパレットから様式化されたモザイクを生成したい場合に、このスキルをトリガーします。 arthash には 3 つの SDK (Rust クレート、Python `arthash`、npm `arthash`) が同梱されており、すべて同じバイト形式で読み書きできるため、サーバー上で作成されたハッシュはブラウザーで同じようにデコードされます。このスキルでは、適切な SDK、適切なモード (SVG の場合はデフォルトの「RECT」およびその他の形状モード「TRIANGLE」/「CIRCLE」/「SQUARE」/「ROTATED_RECT」、モザイクの場合は「PIXEL」、ぼかしハッシュ/サムバッシュ スタイルのぼやけた外観が特に必要な場合のみ「DCT」)、適切なパレット、エンコード → ストア → デコード → レンダリングのライフサイクルの選択をカバーします。小さな落とし穴 (コーデックはバイト単位ではありません。入力は小さくなければなりません。SVG モードとラスター モードの違い)。言語ごとの API の詳細は、このファイルの隣の `typescript.md`、`python.md`、および `rust.md` にあります。
