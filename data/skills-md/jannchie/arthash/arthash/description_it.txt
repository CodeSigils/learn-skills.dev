Utilizza arthash per aggiungere minuscoli hash di immagini segnaposto (17–400 byte) a un'applicazione: l'alternativa artistica a blurhash/thumbhash/sqip. Attiva questa abilità quando l'utente desidera eseguire il rendering di un'anteprima di immagine di bassa qualità (LQIP) durante il caricamento di un'immagine reale, sostituire blurhash o Thumbhash, generare segnaposto SVG senza generare un sottoprocesso Go (sqip) o produrre un mosaico stilizzato da una tavolozza. arthash fornisce tre SDK (Rust crate, Python `arthash`, npm `arthash`) che leggono e scrivono tutti lo stesso formato byte, quindi un hash creato sul server viene decodificato in modo identico nel browser. Questa competenza copre la scelta dell'SDK giusto, la modalità giusta (`RECT` predefinita e altre modalità di forma `TRIANGLE` / `CIRCLE` / `SQUARE` / `ROTATED_RECT` per SVG, "PIXEL` per mosaico, "DCT" solo quando si desidera specificamente un aspetto sfocato in stile blurhash/thumbhash), la tavolozza giusta, il ciclo di vita di codifica → memorizzazione → decodifica → rendering e le piccole insidie (i codec non sono presenti nel byte; gli input devono essere piccoli; modalità SVG rispetto a modalità raster). I dettagli dell'API per lingua si trovano in "typescript.md", "python.md" e "rust.md" accanto a questo file.
