使用 arthash 向应用程序添加微小的占位符图像哈希（17-400 字节）——blurhash/thumbhash/sqip 的艺术替代品。当用户想要在加载真实图像时渲染低质量图像预览 (LQIP)、替换模糊哈希或拇指哈希、生成 SVG 占位符而不生成 Go 子进程 (sqip) 或从调色板生成风格化马赛克时，触发此技能。 arthash 提供了三个 SDK（Rust crate、Python `arthash`、npm `arthash`），它们都读取和写入相同的字节格式，因此在服务器上生成的哈希在浏览器中进行相同的解码。这项技能包括选择正确的 SDK、正确的模式（默认的“RECT”和其他形状模式“TRIANGLE”/“CIRCLE”/“SQUARE”/“ROTATED_RECT”用于 SVG、“PIXEL”用于马赛克、“DCT”（仅当您特别想要 Blurhash/thumbhash 风格的模糊外观时）、正确的调色板、编码 → 存储 → 解码 → 渲染生命周期以及小陷阱（编解码器不是以字节为单位；输入必须以字节为单位）较小；SVG 模式与光栅模式）。每种语言的 API 详细信息位于此文件旁边的“typescript.md”、“python.md”和“rust.md”中。
