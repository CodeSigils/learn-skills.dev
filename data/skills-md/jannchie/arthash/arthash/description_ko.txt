arthash를 사용하여 응용 프로그램에 작은 자리 표시자 이미지 해시(17~400바이트)를 추가합니다. 이는 Blurhash / Thumbhash / sqip에 대한 예술적인 대안입니다. 사용자가 실제 이미지가 로드되는 동안 저품질 이미지 미리 보기(LQIP)를 렌더링하거나, Blurhash 또는 Thumbhash를 바꾸거나, Go 하위 프로세스(sqip)를 생성하지 않고 SVG 자리 표시자를 생성하거나, 팔레트에서 양식화된 모자이크를 생성하려는 경우 이 기술을 트리거합니다. arthash는 모두 동일한 바이트 형식을 읽고 쓰는 세 가지 SDK(Rust crate, Python `arthash`, npm `arthash`)를 제공하므로 서버에서 생성된 해시는 브라우저에서 동일하게 디코딩됩니다. 이 기술은 올바른 SDK, 올바른 모드(SVG의 경우 기본 `RECT` 및 기타 모양 모드 `TRIANGLE` / `CIRCLE` / `SQUARE` / `ROTATED_RECT`, 모자이크의 경우 `PIXEL`, 특별히 Blurhash/thumbhash 스타일의 흐릿한 모양을 원하는 경우에만 `DCT`), 올바른 팔레트, 인코딩 → 저장 → 디코딩 → 렌더링 수명 주기 및 작은 함정(코덱은 바이트에 포함되지 않습니다. 입력은 작아야 합니다. SVG 모드와 래스터 모드). 언어별 API 세부정보는 이 파일 옆의 `typescript.md`, `python.md` 및 `rust.md`에 있습니다.
