Générez une narration audio des articles de blog à l'aide de Google Gemini TTS. Prend en charge la narration résumée, la lecture complète de l'article à haute voix et le mode podcast/dialogue à deux haut-parleurs avec 30 options vocales. Sorties MP3 avec code audio intégré HTML5. Fonctionne de manière autonome via /blog audio ou en interne depuis blog-write. Se replie gracieusement lorsque la clé API n'est pas configurée. À utiliser lorsque l'utilisateur dit « audio du blog », « raconter le blog », « version audio », « synthèse vocale », « tts », « mode podcast », « lire à haute voix », « narration audio », « voix », « narration », « générer de l'audio ».
