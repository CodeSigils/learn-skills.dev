تصميم الواجهة الحرفية الأولى للوحات المعلومات ولوحات الإدارة وتطبيقات SaaS والأدوات وصفحات الإعدادات وواجهات البيانات والمنتجات التفاعلية. يُستخدم عند تصميم واجهة مستخدم المنتج أو إنشائها أو مراجعتها أو تدقيقها أو تحسينها حيث تكون الحرفية المرئية أو التسلسل الهرمي للتخطيط أو الرموز المميزة أو الحالات أو الاتجاه المرئي أو اتساق نظام التصميم أمرًا مهمًا. ليس للصفحات التسويقية، أو الصفحات المقصودة، أو الحملات، أو العمل الخاص بالعلامة التجارية فقط.
