يقوم بتدقيق أي موقع توثيق للمطور عبر 33 عملية فحص في 7 فئات وينتج تقريرًا مسجلاً (من 100) مع حالة النجاح / التحذير / الفشل لكل فحص. استخدم هذه المهارة عندما يقدم المستخدم عنوان URL للمستندات ويطلب تدقيقه أو مراجعته أو تسجيله أو التحقق من جودته أو تقييمه من حيث قابلية اكتشاف الذكاء الاصطناعي أو تحسين محركات البحث أو البنية أو المحتوى أو الاكتمال. يتم تشغيله أيضًا عندما يقول المستخدم "تشغيل تدقيق المستندات"، أو "تدقيق هذه المستندات"، أو "التحقق من هذه الوثائق"، أو "مدى جودة المستندات لـ X"، أو لصق عنوان URL للمستندات بأي غرض تقييمي. استخدم هذه المهارة دائمًا — لا تحاول إجراء مراجعة للمستندات ذات الشكل الحر دون اتباع سير العمل المنظم هذا.
