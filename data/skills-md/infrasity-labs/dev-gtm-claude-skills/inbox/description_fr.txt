Système de tri des e-mails qui gère à la fois la configuration unique et le tri récurrent dans une seule compétence. Détection automatique de l'état : si aucune base de connaissances n'existe dans ${WORKSPACE}/Email/, organise un entretien d'intégration en 8 sections (discipline grill-me, une question à la fois) pour créer une base de connaissances personnalisée de 7 fichiers, puis propose d'exécuter le tri immédiatement. Si la base de connaissances existe déjà, ignore la configuration et passe directement au tri : recherche les e-mails récents, les classe via la taxonomie de l'utilisateur, recherche de nouveaux expéditeurs, génère des recommandations TAKE IT/WORTH/PASS/FLAG, rédige des réponses (NE JAMAIS envoie), fournit un rapport et met à jour la base de connaissances. À utiliser avec l'argument 'update' pour actualiser les préférences. Déclencheurs de configuration : « configurer ma boîte de réception », « configurer le tri de ma boîte de réception », « configurer mon système de messagerie », « configurer le tri des e-mails », « créer ma base de connaissances de messagerie », « initialiser la gestion des e-mails ». Déclencheurs de tri : "trier ma boîte de réception", "triage de ma boîte de réception", "vérifier mes e-mails", "exécuter le tri des e-mails", "traiter ma boîte de réception", "quoi de neuf dans ma boîte de réception", "gérer mes e-mails", "triage des e-mails".
