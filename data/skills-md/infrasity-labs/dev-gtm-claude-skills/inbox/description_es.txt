Sistema de clasificación de correo electrónico que maneja tanto la configuración única como la clasificación recurrente en una sola habilidad. Estado de detección automática: si no existe una base de conocimientos en ${WORKSPACE}/Email/, ejecuta una entrevista de incorporación de 8 secciones (disciplina de interrogación, una pregunta a la vez) para crear una base de conocimiento personalizada de 7 archivos, luego ofrece ejecutar la clasificación de inmediato. Si la base de conocimiento ya existe, omite la configuración y va directamente a la clasificación: busca correos electrónicos recientes, los clasifica según la taxonomía del usuario, investiga nuevos remitentes, genera recomendaciones TAKE IT/WORTH/PASS/FLAG, redacta respuestas (NUNCA envía), entrega un informe y actualiza la base de conocimiento. Úselo con el argumento 'actualizar' para actualizar las preferencias.
