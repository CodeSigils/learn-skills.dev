قم بتجميع قائمة الكلمات الرئيسية في مجموعات موضوعية مع تسميات غرض البحث وحجم البحث الذي تم التحقق منه وبيانات KD وCPC. استخدم هذه المهارة عندما يقدم المستخدم قائمة بالكلمات الرئيسية (التي تم لصقها أو تحميلها كملف CSV/Excel أو عبر عنوان URL لورقة Google) ويطلب تجميعها أو تجميعها أو تعيينها أو تنظيمها أو تصنيفها. يتم تشغيله أيضًا عندما يقول المستخدم "مجموعة الكلمات الرئيسية"، أو "تجميع كلماتي الرئيسية"، أو "تجميع هذه الكلمات الرئيسية"، أو "خريطة الكلمات الرئيسية"، أو "استراتيجية الكلمات الرئيسية من هذه القائمة"، أو "تنظيم الكلمات الرئيسية حسب الموضوع"، أو لصق قائمة الكلمات الرئيسية أو تحميلها ويريد البنية منها. استخدم هذه المهارة دائمًا — لا تحاول تجميع الكلمات الرئيسية يدويًا دون اتباع سير العمل هذا.
