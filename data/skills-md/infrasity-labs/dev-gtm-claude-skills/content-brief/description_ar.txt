يُنشئ ملخصًا لمحتوى تحسين محركات البحث (SEO) منظمًا بالكامل لكلمة رئيسية مستهدفة ويدفعها اختياريًا إلى قاعدة بيانات Notion. استخدم هذه المهارة عندما يقول المستخدم "إنشاء ملخص محتوى"، أو "إحاطة هذه الكلمة الرئيسية"، أو "تشغيل ملخص محتوى لـ"، أو "إنشاء ملخص"، أو "كتابة ملخص لـ [كلمة رئيسية]"، أو "موجز محتوى حول [موضوع]"، أو أي شكل حيث يحتاج شخص ما إلى كلمة رئيسية تم البحث عنها وتحويلها إلى مهمة كتابة منظمة باستخدام مخطط H1 وH2 والأسئلة الشائعة والروابط الداخلية وهدف عدد الكلمات وملاحظات الكاتب. يتم تشغيله أيضًا عندما يقدم المستخدم كلمة رئيسية ويطلب ملخصًا لتحسين محركات البحث أو ملخصًا تحريريًا أو مواصفات كتابة. يقوم بإخراج تنسيق منظم إلزامي يقوم المحلل اللغوي بتعيينه مباشرة إلى خصائص Notion. يدعم أوضاع الكلمة الرئيسية والدُفعة (CSV).
