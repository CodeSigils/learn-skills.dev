Анализируйте изображения, веб-сайты и файлы Figma, чтобы извлечь их дизайн и создать файл design.md с системой токенов, инвентарем компонентов и примечаниями к реконструкции. Используйте этот навык всякий раз, когда пользователь хочет понять, документировать, воспроизвести или проверить дизайн чего-то визуального: скриншота, URL-адреса, ссылки Figma, ссылки на Pinterest, макета, сайта конкурента, компонента, панели управления, целевой страницы. Также, когда они просят «извлечь систему дизайна из X», «задокументировать стиль Y», «проанализировать это визуально», «конвертировать это изображение в токены», «помогите мне воспроизвести этот дизайн», «какую палитру использует этот сайт», «как это построено». Также для отдельных элементов: «скопировать эту панель навигации», «воссоздать эту иллюстрацию», «дать мне подсказку для регенерации этой графики» — режим элемента выводит сфокусированный element.md с подсказками модели изображения на основе токенов, когда элемент представляет собой визуальное искусство. Если пользователь приводит какой-либо визуальный источник и хочет понять его на уровне дизайна — этот навык должен активироваться.
