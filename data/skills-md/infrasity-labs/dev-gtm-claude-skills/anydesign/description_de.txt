Analysieren Sie Bilder, Websites und Figma-Dateien, um deren Design zu extrahieren und eine „design.md“ mit Tokensystem, Komponenteninventar und Rekonstruktionsnotizen zu generieren. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer das Design von etwas Visuellem verstehen, dokumentieren, reproduzieren oder prüfen möchte: einen Screenshot, eine URL, einen Figma-Link, eine Pinterest-Referenz, ein Modell, die Website eines Mitbewerbers, eine Komponente, ein Dashboard, eine Zielseite. Auch wenn sie fragen: „Extrahiere das Designsystem aus Auch für einzelne Elemente: „Diese Navigationsleiste kopieren“, „Diese Illustration neu erstellen“, „Geben Sie mir eine Aufforderung, diese Grafik neu zu generieren“ – der Elementmodus gibt eine fokussierte element.md mit tokenbasierten Bildmodell-Eingabeaufforderungen aus, wenn es sich bei dem Element um visuelle Kunst handelt. Wenn der Benutzer eine visuelle Quelle mitbringt und diese auf Designebene verstehen möchte, sollte diese Fähigkeit aktiviert werden.
