ブログのパフォーマンスのための Google API の統合: PageSpeed Insights、25 週間の履歴を持つ CrUX Core Web Vitals、Search Console のパフォーマンス、URL インスペクション、インデックス API、GA4 オーガニック トラフィック、E-E-A-T の NLP エンティティ分析、埋め込み用の YouTube 動画検索、Google 広告キーワード プランナー。認証情報層 (API キー、OAuth/サービス アカウント、GA4、広告) に基づいた段階的な機能の可用性。 ~/.config/claude-seo/google-api.json で claude-seo と構成を共有します。ユーザーが「Google データ」、「ページ速度」、「コア ウェブ バイタル」、「サーチ コンソール」、「インデックス作成」、「GA4」、「キーワード調査」、「NLP エンティティ」、「ブログ パフォーマンス」、「YouTube 検索」、「Google API セットアップ」と言うときに使用します。
