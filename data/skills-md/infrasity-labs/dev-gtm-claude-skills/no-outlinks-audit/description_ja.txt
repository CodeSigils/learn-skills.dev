あらゆる Web サイトに対して完全なデッドエンド ページ監査を実行します。すべてのブログ/コンテンツ ページを検出し、同じドメイン上の URL への発信リンクがゼロのページを検出し、キーワードを取得し、トピックごとにページをクラスタリングし、アンカー テキスト、配置ガイダンス、すぐに貼り付けられるコンテキスト コピーを含む行き止まりのページごとに 3 つの発信リンクの提案を生成します。 report-style-reference.html に一致するスタイル付きの HTML レポートを出力します。サイト フレームワーク (Next.js、静的、WordPress) を自動的に検出し、正しい検出方法を使用します: Next.js/Vercel サイトの場合は RSC ヘッダー、静的および従来の CMS サイトの場合は標準の CURL。ユーザーがドメインまたは URL を提供し、行き止まりページの監査、発信内部リンクの監査、「リンクアウトしていないページ」、「コンテンツ内に内部リンクがないページの検索」、「リンク行き止まりのページ」、または同じドメインへの発信リンクがゼロのページの検索のバリエーションを要求したときにトリガーされます。行き止まりのページ監査には常にこのスキルを使用してください。ここですべての手順を実行せずにワークフローを試行しないでください。
