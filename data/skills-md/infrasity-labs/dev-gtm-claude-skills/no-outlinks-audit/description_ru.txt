Проводит полный аудит тупиковых страниц любого веб-сайта. Обнаруживает все страницы блога/контента, определяет, какие из них не имеют исходящих ссылок на любой URL-адрес в том же домене, извлекает ключевые слова, группирует страницы по темам и генерирует 3 предложения исходящих ссылок на тупиковую страницу с привязочным текстом, рекомендациями по размещению и готовой к вставке копией контекста. Выводит HTML-отчет в стиле, соответствующем report-style-reference.html. Автоматически определяет структуру сайта (Next.js, статический, WordPress) и использует правильный метод обнаружения: заголовок RSC для сайтов Next.js/Vercel, стандартный завиток для статических и традиционных сайтов CMS. Срабатывает, когда пользователь предоставляет домен или URL-адрес и запрашивает аудит тупиковой страницы, аудит исходящих внутренних ссылок, «какие страницы не имеют ссылок», «найти страницы без внутренних ссылок в содержании», «страницы с тупиковыми ссылками» или любой вариант поиска страниц, у которых нет исходящих ссылок на тот же домен. Всегда используйте этот навык для проверки тупиковых страниц — никогда не пытайтесь выполнить рабочий процесс, не выполнив каждый шаг, описанный здесь.
