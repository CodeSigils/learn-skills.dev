Ejecuta una auditoría completa de la página sin salida para cualquier sitio web. Descubre todas las páginas de blog/contenido, detecta cuáles no tienen enlaces salientes a ninguna URL en el mismo dominio, busca palabras clave, agrupa páginas por tema y genera 3 sugerencias de enlaces salientes por página sin salida con texto ancla, guía de ubicación y copia de contexto lista para pegar. Genera un informe HTML con estilo que coincide con report-style-reference.html. Detecta automáticamente el marco del sitio (Next.js, estático, WordPress) y utiliza el método de detección correcto: encabezado RSC para sitios Next.js/Vercel, curl estándar para sitios CMS estáticos y tradicionales. Se activa cuando un usuario proporciona un dominio o URL y solicita una auditoría de una página sin salida, una auditoría de enlaces internos salientes, "qué páginas no tienen enlaces", "buscar páginas sin enlaces internos en el contenido", "páginas que tienen enlaces sin salida" o cualquier variación para buscar páginas que no tengan enlaces salientes al mismo dominio. Utilice siempre esta habilidad para auditorías de páginas sin salida; nunca intente el flujo de trabajo sin seguir cada paso aquí.
