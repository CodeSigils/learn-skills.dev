Audita la preparación para la IA de cualquier dominio mediante el uso de curl para probar directamente robots.txt, llms.txt y llms-full.txt, luego califica cada archivo según una lista de verificación estructurada y entrega un informe formateado con resultados de aprobación/advertencia/fallo y correcciones procesables. Utilice esta habilidad siempre que un usuario proporcione un dominio o URL y quiera saber si llms.txt o llms-full.txt están disponibles, son detectables o están estructurados correctamente. Active frases como "verificar llms.txt", "este sitio tiene llms.txt", "buscar llms.txt", "verificar llms para esta URL", "auditar llms.txt", "está llms-full.txt disponible" o cada vez que un usuario comparte una URL de dominio/documentos y desea verificar la preparación para IA. También se activa cuando el usuario desea verificar la preparación GEO/AEO de un sitio de documentación.
