Busca empresas en sectores tecnológicos centrados en desarrolladores para llegar a agencias de marketing para desarrolladores. Utilice esta habilidad siempre que un usuario proporcione una vertical (por ejemplo, AI Agentic, IAC, DevTools, Observability, DevOps, FinOps, AI/SDLC, AI Orchestration o cualquier otra vertical tecnológica) y desee una lista de empresas potenciales a las que dirigirse. También se activa cuando el usuario dice "prospectar", "buscar empresas en", "darme clientes potenciales", "crear una lista de prospectos" o proporciona un nombre vertical junto con la etapa de financiación y los filtros de personal. Utilice siempre esta habilidad: nunca intente realizar prospecciones sin seguir este flujo de trabajo estructurado. La habilidad encuentra solo empresas que encajan exactamente (nunca adyacentes), asigna una señal de alcance real y un punto débil de correo electrónico para cada uno, genera cada punto de datos con una URL y genera una tabla unificada de nueve columnas: Empresa, URL, LinkedIn, plantilla, señal, fuentes de señal, geografía, punto débil, fuentes de puntos débiles.
