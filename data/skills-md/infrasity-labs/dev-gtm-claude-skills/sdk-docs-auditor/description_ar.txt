يقوم بتدقيق أي موقع توثيق SDK وينتج تقرير HTML كامل النقاط وقابل للتنزيل. استخدم هذه المهارة عندما يقدم المستخدم عنوان URL للوثائق ويطلب تدقيق جودة مستندات SDK أو مراجعتها أو تحليلها أو تسجيلها أو التحقق منها. يمكنك أيضًا تشغيل عبارات مثل "تدقيق مستندات SDK في X"، أو "التحقق مما إذا كانت المستندات في X مكتملة"، أو "مراجعة وثائق SDK هذه"، أو "مدى جودة هذه المستندات"، أو "تشغيل تدقيق SDK على X"، أو في أي وقت يلصق فيه المستخدم عنوان URL إلى جانب كلمات مثل التدقيق أو المراجعة أو الزحف أو التحقق أو التحليل أو الجودة أو الاكتمال أو الفجوات. استخدم هذه المهارة دائمًا — لا تحاول إجراء التدقيق دون اتباع هذا الزحف المنظم ← التحليل ← الإسناد الترافقي ← سير عمل التقرير.
