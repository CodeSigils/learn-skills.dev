Audite n’importe quel site de documentation SDK et produit un rapport HTML entièrement noté et téléchargeable. Utilisez cette compétence chaque fois qu'un utilisateur fournit une URL de documentation et demande à auditer, réviser, analyser, noter ou vérifier la qualité des documents du SDK. Déclenchez également des expressions telles que « auditer les documents du SDK sur X », « vérifier si les documents sur X sont complets », « examiner cette documentation du SDK », « quelle est la qualité de ces documents », « exécuter un audit du SDK sur X » ou à chaque fois qu'un utilisateur colle une URL à côté de mots tels que audit, révision, exploration, vérification, analyse, qualité, exhaustivité ou lacunes. Utilisez TOUJOURS cette compétence - ne tentez pas l'audit sans suivre ce workflow d'exploration structuré → analyser → références croisées → rapporter.
