あらゆる SDK ドキュメント サイトを監査し、完全にスコア付けされたダウンロード可能な HTML レポートを生成します。ユーザーがドキュメントの URL を提供し、SDK ドキュメントの監査、レビュー、分析、スコア付け、または品質のチェックを要求する場合は常に、このスキルを使用します。また、「X で SDK ドキュメントを監査する」、「X でドキュメントが完全かどうかを確認する」、「この SDK ドキュメントを確認する」、「これらのドキュメントはどの程度優れているか」、「X で SDK 監査を実行する」などのフレーズ、またはユーザーが監査、レビュー、クロール、チェック、分析、品質、完全性、ギャップなどの単語と一緒に URL を貼り付けた場合にもトリガーされます。常にこのスキルを使用してください。この構造化されたクロール→分析→相​​互参照→レポートのワークフローに従わずに監査を試行しないでください。
