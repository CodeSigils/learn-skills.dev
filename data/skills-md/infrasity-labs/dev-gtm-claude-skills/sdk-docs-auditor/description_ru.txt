Проводит аудит любого сайта с документацией SDK и создает полностью оцененный загружаемый отчет в формате HTML. Используйте этот навык всякий раз, когда пользователь предоставляет URL-адрес документации и просит провести аудит, проверку, анализ, оценку или проверку качества документации SDK. Также активируются такие фразы, как «проверить документы SDK в X», «проверить, завершены ли документы в X», «просмотреть эту документацию SDK», «насколько хороши эти документы», «запустить аудит SDK в X» или каждый раз, когда пользователь вставляет URL-адрес рядом со словами, такими как аудит, просмотр, сканирование, проверка, анализ, качество, полнота или пробелы. ВСЕГДА используйте этот навык — не пытайтесь провести аудит без соблюдения этого структурированного сканирования → анализа → перекрестных ссылок → рабочего процесса отчета.
