يقوم بتدقيق أي موقع توثيق لواجهة برمجة التطبيقات (API) عن طريق الزحف إلى كل صفحة نقطة نهاية وتسجيل كل صفحة عبر 5 عمليات تحقق: جودة الوصف، ووجود مواصفات OpenAPI، وأوصاف معلمات النص، وأكواد الاستجابة، واكتمال مخطط الاستجابة. يُنتج تقرير HTML تفاعليًا مصقولًا مع بطاقة أداء ملخصة، وتحليل الأنماط على مستوى الموقع، وأهم المشكلات المصنفة، ونتائج كل نقطة نهاية مع إرشادات إصلاح محددة.
قم بتشغيل هذه المهارة عندما يقدم المستخدم عنوان URL للوثائق ويطلب التدقيق أو المراجعة أو التحليل أو التحقق من مستندات API الخاصة به. يمكنك أيضًا تشغيل ما يلي: "إجراء نفس التدقيق لـ X"، أو "audit docs.company.com"، أو "التحقق من مستندات API في X"، أو "تشغيل تدقيق مستندات API على X"، أو "مراجعة المستندات لـ Y API"، أو لصق عنوان URL إلى جانب كلمات مثل التدقيق أو المراجعة أو الزحف أو التحقق أو التحليل أو الجودة أو الاكتمال أو الفجوات. استخدم هذه المهارة دائمًا — لا تحاول إجراء التدقيق دون اتباع سير العمل المنظم لتقرير نتائج الزحف.
