Аудит любого сайта документации API, сканируя каждую страницу конечной точки и оценивая каждую из них по 5 проверкам: качество описания, наличие спецификации OpenAPI, описания параметров тела, коды ответов и полнота схемы ответа. Создает безупречный интерактивный отчет в формате HTML со сводной оценочной картой, анализом шаблонов по всему сайту, ранжированием наиболее важных проблем и выводами по каждой конечной точке с конкретными рекомендациями по исправлению.
Активируйте этот навык всякий раз, когда пользователь предоставляет URL-адрес документации и просит провести аудит, просмотр, анализ или проверку документации API. Также триггер для: «провести тот же аудит для X», «аудит docs.company.com», «проверить документы API в X», «запустить аудит документов API в X», «просмотреть документы для Y API» или вставить URL-адрес рядом со словами, такими как аудит, просмотр, сканирование, проверка, анализ, качество, полнота или пробелы. Всегда используйте этот навык — не пытайтесь провести аудит, не следуя этому структурированному рабочему процессу составления отчета об оценке сканирования.
