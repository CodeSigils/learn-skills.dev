모든 엔드포인트 페이지를 크롤링하고 설명 품질, OpenAPI 사양 존재, 본문 매개변수 설명, 응답 코드 및 응답 스키마 완전성 등 5가지 검사를 통해 각 페이지에 점수를 매겨 모든 API 문서 사이트를 감사합니다. 요약 스코어카드, 사이트 전체 패턴 분석, 상위 문제 순위, 특정 수정 지침이 포함된 엔드포인트별 조사 결과가 포함된 세련된 대화형 HTML 보고서를 생성합니다.
사용자가 문서 URL을 제공하고 API 문서를 감사, 검토, 분석 또는 확인하도록 요청할 때마다 이 기술을 트리거합니다. 또한 "X에 대해 동일한 감사 수행", "docs.company.com 감사", "X에서 API 문서 확인", "X에서 API 문서 감사 실행", "Y API에 대한 문서 검토"를 트리거하거나 감사, 검토, 크롤링, 확인, 분석, 품질, 완전성 또는 격차와 같은 단어와 함께 URL을 붙여넣습니다. 항상 이 기술을 사용하십시오. 구조화된 크롤링-점수-보고 워크플로우를 따르지 않고 감사를 시도하지 마십시오.
