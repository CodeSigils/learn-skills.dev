すべてのエンドポイント ページをクロールし、説明の品質、OpenAPI 仕様の存在、本文パラメータの説明、応答コード、応答スキーマの完全性の 5 つのチェックでそれぞれをスコアリングすることにより、API ドキュメント サイトを監査します。要約スコアカード、サイト全体のパターン分析、ランク付けされた上位の問題、および特定の修正ガイダンスを含むエンドポイントごとの調査結果を含む、洗練されたインタラクティブな HTML レポートを作成します。
ユーザーがドキュメント URL を提供し、API ドキュメントの監査、レビュー、分析、チェックを要求するたびに、このスキルをトリガーします。また、「X に対して同じ監査を行う」、「docs.company.com を監査する」、「X で API ドキュメントをチェックする」、「X で API ドキュメント監査を実行する」、「Y API のドキュメントをレビューする」をトリガーするか、監査、レビュー、クロール、チェック、分析、品質、完全性、ギャップなどの単語の横に URL を貼り付けます。常にこのスキルを使用してください。この構造化されたクロール スコア レポート ワークフローに従わずに監査を試行しないでください。
