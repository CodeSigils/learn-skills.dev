Audita cualquier sitio de documentación de API rastreando cada página de punto final y puntuando cada una de ellas en 5 comprobaciones: calidad de la descripción, presencia de especificaciones de OpenAPI, descripciones de parámetros del cuerpo, códigos de respuesta e integridad del esquema de respuesta. Produce un informe HTML interactivo pulido con un cuadro de mando resumido, análisis de patrones en todo el sitio, problemas principales clasificados y hallazgos por punto final con orientación de solución específica.
Active esta habilidad cada vez que un usuario proporcione una URL de documentación y solicite auditar, revisar, analizar o verificar sus documentos API. También se activa para: "hacer la misma auditoría para X", "auditar docs.company.com", "verificar los documentos de API en X", "ejecutar la auditoría de documentos de API en X", "revisar los documentos de Y API" o pega una URL junto con palabras como auditar, revisar, rastrear, comprobar, analizar, calidad, integridad o lagunas. Utilice siempre esta habilidad: no intente realizar la auditoría sin seguir este flujo de trabajo estructurado de informe de puntuación de rastreo.
