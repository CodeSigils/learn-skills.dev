Genera un report di analisi settimanale per infrasity.com utilizzando Google Search Console in tempo reale e i dati GA4, crea un report HTML con stile, lo salva come file scaricabile e pubblica un riepilogo su un canale Slack. Recupera le prestazioni GSC (clic, impressioni, CTR, posizione, pagine principali, query principali) e le prestazioni GA4 (sessioni, utenti, nuovi utenti, visualizzazioni di pagina, conversioni, tasso di coinvolgimento, frequenza di rimbalzo, durata media della sessione, suddivisione dei canali e traffico AI/LLM con la tabella interdimensionale completa di origine × mezzo × pagina di destinazione). Attiva questa abilità quando ti viene chiesto di eseguire il report settimanale, generare il report di analisi, inviare il riepilogo settimanale a Slack o controllare le prestazioni di questa settimana.
