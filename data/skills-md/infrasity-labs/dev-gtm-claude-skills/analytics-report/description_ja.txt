ライブ Google Search Console と GA4 データを使用して infrasity.com の週次分析レポートを生成し、スタイル付きの HTML レポートを作成してダウンロード可能なファイルとして保存し、概要を Slack チャネルに投稿します。 GSC パフォーマンス (クリック数、インプレッション数、CTR、掲載順位、トップ ページ、トップ クエリ) と GA4 パフォーマンス (セッション、ユーザー、新規ユーザー、ページビュー、コンバージョン、エンゲージメント率、直帰率、平均セッション継続時間、チャネルの内訳、完全なソース × メディア × ランディング ページのクロスディメンション テーブルによる AI/LLM トラフィック) を取得します。週次レポートの実行、分析レポートの生成、週次サマリーの Slack への送信、または今週のパフォーマンスの確認を求められたときに、このスキルをトリガーします。
