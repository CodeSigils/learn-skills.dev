DataForSEO データを使用して、任意のドメインの 3 か月間の SEO パフォーマンス HTML レポートを生成します。ベースラインと現在のトラフィック、キーワードランキング、トップコンテンツページ、競合状況を取得し、エグゼクティブブリーフィングのようなスタイルの洗練されたダークテーマの HTML レポートを出力します。ユーザーがターゲット ドメインと競合 URL のリストを提供し、SEO レポート、パフォーマンス レポート、SEO 分析、競合 SEO 比較、トラフィック レポート、ランキング レポート、または 3 か月の SEO 概要を要求するときは常に、このスキルを使用します。また、ユーザーが「X 対 Y および Z の SEO レポートを生成する」、「パフォーマンス レポートを作成する」、「自社の SEO を競合他社と比較する」と言った場合や、ドメインを貼り付けて市場との比較でパフォーマンスを尋ねた場合にもトリガーされます。 SEO レポートの生成には常にこのスキルを使用してください。この構造化されたデータ取得と HTML 生成のワークフローに従わずにレポートを構築しようとしないでください。
