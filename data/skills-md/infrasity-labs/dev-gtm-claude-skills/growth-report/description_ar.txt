يُنشئ تقرير HTML لأداء تحسين محركات البحث (SEO) لمدة 3 أشهر لأي مجال يستخدم بيانات DataForSEO. جلب خط الأساس مقابل حركة المرور الحالية، وتصنيفات الكلمات الرئيسية، وأهم صفحات المحتوى، والمشهد التنافسي، ثم إخراج تقرير HTML مصقول ذو سمة داكنة على شكل ملخص تنفيذي. استخدم هذه المهارة عندما يقدم المستخدم نطاقًا مستهدفًا وقائمة بعناوين URL للمنافسين ويطلب تقرير تحسين محركات البحث، أو تقرير الأداء، أو تحليل تحسين محركات البحث، أو مقارنة تحسين محركات البحث التنافسية، أو تقرير حركة المرور، أو تقرير التصنيف، أو ملخص تحسين محركات البحث لمدة 3 أشهر. يتم تشغيله أيضًا عندما يقول المستخدم "أنشئ تقرير تحسين محركات البحث لـ X مقابل Y وZ"، أو "أنشئ تقرير أداء"، أو "قارن مُحسنات محركات البحث الخاصة بي بالمنافسين"، أو يلصق نطاقًا ويسأل عن كيفية أدائه مقابل السوق. استخدم دائمًا هذه المهارة لإنشاء تقرير تحسين محركات البحث - لا تحاول إنشاء التقرير دون اتباع سير عمل جلب البيانات المنظمة وإنشاء HTML.
