すべての主要な CMS プラットフォームにわたって、ブログ投稿のタグとカテゴリを抽出、提案、同期します。 WordPress REST API、Shopify GraphQL、Ghost Content API、Strapi REST/GraphQL、Sanity GROQ をサポートします。コンテンツ分析 (キーワードの頻度、見出しの抽出、セマンティック グループ化) からタグの提案を生成し、ポストカウントの最小しきい値を強制して薄いタグのアーカイブを防ぎ、認証された API 呼び出しを介して分類を同期します。ユーザーが「タグ」、「カテゴリー」、「分類法」、「タグの提案」、「同期タグ」、「WordPress タグ」、「Shopify タグ」と言うときに使用します。
