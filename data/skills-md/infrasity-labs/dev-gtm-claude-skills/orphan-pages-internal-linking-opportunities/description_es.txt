Ejecuta una auditoría completa de páginas huérfanas para cualquier sitio web que utilice Ahrefs únicamente. Descubre todas las páginas de blog/contenido, encuentra cuáles no reciben enlaces internos entrantes (páginas huérfanas), busca palabras clave, agrupa páginas por tema y genera 3 sugerencias de enlaces por huérfano con texto de anclaje y orientación de ubicación. Genera un informe HTML con estilo que coincide con report-style-reference.html. Se activa cuando un usuario proporciona un dominio o URL y solicita una auditoría de enlaces internos, un informe de páginas huérfanas, un análisis de enlaces, "qué páginas no tienen enlaces internos", "buscar páginas a las que nadie enlaza", "brecha de enlaces internos" o "qué blogs están aislados". Utilice siempre esta habilidad para auditorías de enlaces internos; nunca intente el flujo de trabajo sin seguir todos los pasos aquí.
