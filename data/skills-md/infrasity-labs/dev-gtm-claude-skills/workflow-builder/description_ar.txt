قم بتصميم وكتابة نصوص برمجية محددة لسير العمل متعدد الوكلاء (ملفات .js بتنسيق .claude/workflows/) لأداة سير العمل الخاصة بـ Claude Code. يُستخدم عندما يريد المستخدم إنشاء سير عمل Claude Code مخصص أو إنشائه أو تأليفه أو دعمه أو تشغيله، أو تنسيق الوكلاء الفرعيين (الموسعين، أو الأنابيب، أو التكرارات، أو لجنة التحكيم)، أو أتمتة مهمة متعددة الخطوات قابلة للتكرار عبر وكلاء السياق الجديد.
