Progetta e scrivi script deterministici per flussi di lavoro multi-agente (file .js in .claude/workflows/) per lo strumento Workflow di Claude Code. Da utilizzare quando un utente desidera costruire, creare, creare, eseguire uno scaffold o eseguire un flusso di lavoro personalizzato di Claude Code, orchestrare agenti secondari (fan-out, pipeline, loop, pannello di valutazione) o automatizzare un'attività ripetibile in più passaggi tra agenti del nuovo contesto.
