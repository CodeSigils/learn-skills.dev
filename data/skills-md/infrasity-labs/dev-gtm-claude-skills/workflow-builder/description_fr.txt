Concevoir et écrire des scripts de workflow multi-agents déterministes (fichiers .js dans .claude/workflows/) pour l'outil Workflow de Claude Code. À utiliser lorsqu'un utilisateur souhaite créer, créer, créer, échafauder ou exécuter un flux de travail Claude Code personnalisé, orchestrer des sous-agents (fan-out, pipeline, boucle, jury) ou automatiser une tâche en plusieurs étapes répétables sur des agents à nouveau contexte.
