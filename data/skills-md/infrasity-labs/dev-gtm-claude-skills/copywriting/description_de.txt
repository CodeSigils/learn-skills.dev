Wenn der Benutzer Marketingtexte für eine beliebige Seite schreiben, umschreiben oder verbessern möchte – einschließlich Homepage, Zielseiten, Preisseiten, Feature-Seiten, Info-Seiten oder Produktseiten. Verwenden Sie es auch, wenn der Benutzer sagt: „Text schreiben für“, „Diesen Text verbessern“, „Diese Seite neu schreiben“, „Marketingtext“, „Hilfe zur Überschrift“, „CTA-Text“, „Wertversprechen“, „Slogan“, „Unterüberschrift“, „Text im Hauptteil“, „Above the Fold“, „Dieser Text ist schwach“, „Machen Sie ihn überzeugender“ oder „Hilf mir, mein Produkt zu beschreiben“. Verwenden Sie dies immer dann, wenn jemand an Website-Texten arbeitet, die überzeugen oder konvertieren möchten. Eine E-Mail-Kopie finden Sie unter E-Mails.
