Создает полностью структурированный файл CLAUDE.md для конкретного проекта путем сканирования репозитория на наличие сигнальных файлов (package.json, Makefile, .github/workflows/, .env.example и т. д.), определения стека, команд, архитектуры и соглашений, а затем задает не более 3 целевых вопросов о том, что невозможно определить. Используйте всякий раз, когда пользователь говорит «создать CLAUDE.md», «мой CLAUDE.md пуст», «создать контекст проекта», «инициализировать CLAUDE.md», «настроить контекст Claude для этого репозитория», «заполнить мой CLAUDE.md» или любой другой вариант, когда кому-то нужен документированный контекст проекта для Claude. Если файл CLAUDE.md уже существует с содержимым, перед записью выполняется поток сравнения и слияния.
