مبادئ التصميم والتوجيه الإبداعي لبناء عناصر HTML - الصفحات والتقارير والخطط والصفحات المقصودة والعروض التوضيحية والطوابق والأدوات الصغيرة. يُستخدم عند إنشاء أو إعادة تصميم أي تسليم HTML مرئي وتحديد لوحة الألوان الخاصة به، أو نوع الاقتران، أو التخطيط، أو السمات، أو التسجيل العام، أو عندما يجب ألا يبدو الإخراج بشكل عام تم إنشاؤه بواسطة الذكاء الاصطناعي.
