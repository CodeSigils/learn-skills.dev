تحسين النثر أو إعادة كتابته أو تحريره أو مراجعته بحيث يكون واضحًا ومباشرًا ومفيدًا وطبيعيًا دون اختراع حقائق أو محو صوت المؤلف. يُستخدم عند صياغة أو مراجعة رسائل البريد الإلكتروني أو الوثائق أو التقارير أو المقالات أو الرسائل أو نسخة واجهة المستخدم أو التفسيرات أو غيرها من النثر؛ عندما يطلب المستخدم الكتابة بشكل أفضل، أو إضفاء الطابع الإنساني على النص، أو إزالة لغة الذكاء الاصطناعي، أو تشديد الصياغة، أو تحسين الوضوح أو النغمة، أو تسهيل فهم الإجراء. لا تستخدم للترجمة أو البحث الواقعي إلا إذا كانت جودة الكتابة أيضًا جزءًا من الطلب.
