Scrivi una revisione guidata (una guida dettagliata in capitoli di un changeset con le differenze reali in linea) e trasformala in un file HTML portatile con `plannotator guide export`. Da utilizzare quando qualcuno richiede una guida, una procedura dettagliata, un tour o una spiegazione di una differenza, un ramo, un PR o un impegno oppure desidera una guida di revisione condivisibile. Richiede git e la CLI di plannotator.
