اكتب مراجعة إرشادية (شرح تفصيلي لمجموعة التغييرات مع الاختلافات الحقيقية المضمنة) وقم بتحويلها إلى ملف HTML محمول واحد باستخدام "تصدير دليل المدون". يُستخدم عندما يطلب شخص ما دليلاً أو جولة تفصيلية أو جولة أو شرحًا لفرق أو فرع أو علاقات عامة أو التزام، أو يريد دليل مراجعة قابلاً للمشاركة. يحتاج إلى git وplannotator CLI.
