Навыки работы с DingTalk AI Sheets (многомерными таблицами). Используйте интерфейс командной строки mcporter для подключения к серверу DingTalk MCP для создания листов, управления таблицами данных, полевых операций и записи CRUD. Требуется настроить учетные данные DINGTALK_MCP_URL. Варианты использования: создание листов AI, управление структурами таблиц данных, массовый импорт/экспорт данных, автоматизация управления запасами/проектами и другие задачи работы с таблицами.
