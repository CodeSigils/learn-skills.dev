DingTalk AI Sheets (multidimensional tables) operation skills. Use the mcporter CLI to connect to the DingTalk MCP server to perform sheet creation, data table management, field operations, and record CRUD. Requires configuring the DINGTALK_MCP_URL credential. Use cases: creating AI sheets, managing data table structures, bulk importing/exporting data, automating inventory/project management, and other sheet operation tasks.
