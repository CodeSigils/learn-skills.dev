Gestisci documenti, cartelle e contenuti in DingTalk Cloud Docs. Si applica anche agli scenari in cui l'utente menziona parole chiave come documenti cloud, documenti online, documenti DingTalk o DingDocs. Non si attiva quando l'utente deve lavorare con tabelle multidimensionali, gestire pianificazioni, inviare messaggi o gestire flussi di approvazione.
