Administre documentos, carpetas y contenido en DingTalk Cloud Docs. Úselo cuando el usuario desee crear un documento, buscar documentos, leer o escribir el contenido del documento o crear carpetas para organizar documentos. También se aplica a escenarios en los que el usuario menciona palabras clave como documentos en la nube, documentos en línea, documentos de DingTalk o DingDocs. No active cuando el usuario necesite trabajar con tablas multidimensionales, administrar programaciones, enviar mensajes o manejar flujos de aprobación.
