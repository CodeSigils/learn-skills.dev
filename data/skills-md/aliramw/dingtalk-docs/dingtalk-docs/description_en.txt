Manage documents, folders, and content in DingTalk Cloud Docs. Use it when the user wants to create a document, search for documents, read or write document content, or create folders to organize documents. It also applies to scenarios where the user mentions keywords such as cloud documents, online documents, DingTalk documents, or DingDocs. Do not trigger when the user needs to work with multidimensional tables, manage schedules, send messages, or handle approval flows.
