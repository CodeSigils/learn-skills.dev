أضف تتبع Breadcrumb LLM إلى أي مشروع Node.js/TypeScript. استخدم هذه المهارة عندما يريد المستخدم إضافة إمكانية المراقبة أو التتبع أو المراقبة إلى تطبيق LLM الخاص به - خاصة إذا ذكر Breadcrumb، أو تتبع مكالمات LLM، أو تتبع تكاليف الرمز المميز، أو مراقبة وكلاء الذكاء الاصطناعي، أو قياس استخدام Vercel AI SDK الخاص بهم. استخدم أيضًا عندما يقول المستخدم "أضف التتبع"، أو "تتبع تكاليف LLM الخاصة بي"، أو "أريد أن أرى ما يفعله وكيل أعمالي"، أو يسأل عن إمكانية المراقبة لتطبيقات الذكاء الاصطناعي.
