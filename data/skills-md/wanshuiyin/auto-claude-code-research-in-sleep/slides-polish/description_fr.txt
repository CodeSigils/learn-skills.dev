Examen du Codex par page + correctifs python-pptx / Beamer ciblés pour les diapositives de présentation académique. Utilisez APRÈS /paper-slides (ou tout PPTX/Beamer généré en externe) lorsque le jeu semble « plutôt correct » mais que l'utilisateur souhaite une passe finale qui aligne le poids visuel avec une référence, fait passer les polices PPTX à une taille lisible par le projecteur, tue les fuites de style italique, corrige le débordement de cadre de texte et capture la dérive de mise en page par diapositive. Phrases de déclenchement : « polissage des diapositives », « diapositives 排版不对 », « PPTX 字体太小 », « 和 Beamer 比一下 », « révision par page », « 和 codex 一页一页过 ».
