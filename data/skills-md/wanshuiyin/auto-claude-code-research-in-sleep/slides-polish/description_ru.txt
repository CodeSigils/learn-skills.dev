Постраничный обзор Кодекса + целевые исправления python-pptx/Beamer для слайдов научных докладов. Используйте AFTER /paper-slides (или любой внешний сгенерированный PPTX/Beamer), когда презентация выглядит «в основном нормально», но пользователю нужен последний проход, который выравнивает визуальный вес со ссылкой, увеличивает шрифты PPTX до размера, удобного для чтения на проекторе, устраняет утечки курсива, исправляет переполнение текстовых фреймов и фиксирует смещение макета для каждого слайда. Триггерные фразы: «полированные слайды», «слайды 排版不对», «PPTX 字体太小», «和 Beamer 比一下», «постраничный обзор», «和 codex 一页一页过».
