Exécutez des charges de travail GPU sur Modal : formation, réglage fin, inférence, traitement par lots. Sans serveur sans configuration : pas de SSH, pas de Docker, mise à l'échelle automatique jusqu'à zéro. À utiliser lorsque l'utilisateur dit « exécution modale », « formation modale », « inférence modale », « déployer sur modal », « besoin d'un GPU », « exécuter sur modal », « GPU sans serveur » ou a besoin d'un calcul GPU à distance.
