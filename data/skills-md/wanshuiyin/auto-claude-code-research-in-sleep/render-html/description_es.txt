Represente un artefacto ARIS Markdown/JSON (IDEA_REPORT, AUTO_REVIEW, KILL_ARGUMENT, PAPER_PLAN, estado de wiki de investigación, etc.) en una vista HTML de un solo archivo diseñada para lectura humana. Los resultados de las plantillas académicas están controlados por una nueva revisión del Codex entre modelos para la fidelidad de renderizado y la seguridad (la invariante ARIS). Úselo cuando el usuario diga "渲染 HTML", "出一份 HTML 报告", "renderizar html", "hacer legible", "exportar a html" o desea una vista pulida renderizada en web de un artefacto Markdown. Markdown/JSON sigue siendo la fuente canónica; HTML es una vista generada y revisada.
