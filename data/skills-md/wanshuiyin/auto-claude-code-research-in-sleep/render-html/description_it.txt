Gli output dei modelli accademici sono controllati da una nuova revisione del Codex multimodello per fedeltà di rendering + sicurezza (l'invariante ARIS). Da utilizzare quando l'utente dice "渲染 HTML", "出一份 HTML 报告", "renderizza html", "rendi questo leggibile", "esporta in html" o desidera una visualizzazione ottimizzata con rendering Web di un artefatto Markdown. Markdown/JSON rimane la fonte canonica; L'HTML è una vista generata e rivista.
