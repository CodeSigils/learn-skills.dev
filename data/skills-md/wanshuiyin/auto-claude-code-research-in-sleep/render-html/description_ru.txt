Преобразуйте артефакт ARIS Markdown/JSON (IDEA_REPORT, AUTO_REVIEW, KILL_ARGUMENT, PAPER_PLAN, состояние исследовательской вики и т. д.) в однофайловое HTML-представление, предназначенное для чтения человеком. Результаты академических шаблонов контролируются новой межмодельной проверкой Кодекса на предмет точности рендеринга и безопасности (инвариант ARIS). Используйте, когда пользователь говорит «渲染 HTML», «出一份 HTML 报告», «отобразить HTML», «сделать это читабельным», «экспортировать в HTML» или хочет получить отредактированное веб-изображение артефакта Markdown. Markdown/JSON остается каноническим источником; HTML — это созданное и проверенное представление.
