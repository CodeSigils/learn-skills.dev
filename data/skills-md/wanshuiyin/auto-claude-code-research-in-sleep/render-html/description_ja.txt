ARIS Markdown / JSON アーティファクト (IDEA_REPORT、AUTO_REVIEW、KILL_ARGUMENT、PAPER_PLAN、リサーチ Wiki の状態など) を、人間が読むために設計された単一ファイルの HTML ビューにレンダリングします。アカデミック テンプレートの出力は、レンダリングの忠実性と安全性 (ARIS の不変条件) について、新しいクロスモデル Codex レビューによってゲートされます。ユーザーが「HTML 渲染」、「出一份 HTML 报告」、「HTML をレンダリング」、「これを読み取り可能にする」、「HTML にエクスポート」と言う場合、または Markdown アーティファクトの洗練された Web レンダリング ビューを望む場合に使用します。 Markdown/JSON は引き続き正規のソースです。 HTML は生成され、レビューされたビューです。
