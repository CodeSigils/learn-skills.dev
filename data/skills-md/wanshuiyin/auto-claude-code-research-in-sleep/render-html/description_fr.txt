Restituez un artefact ARIS Markdown / JSON (IDEA_REPORT, AUTO_REVIEW, KILL_ARGUMENT, PAPER_PLAN, état du wiki de recherche, etc.) dans une vue HTML à fichier unique conçue pour la lecture humaine. Les résultats des modèles académiques sont contrôlés par une nouvelle révision du Codex multi-modèles pour la fidélité du rendu et la sécurité (l'invariant ARIS). À utiliser lorsque l'utilisateur dit "渲染 HTML", "出一份 HTML 报告", "rendre le HTML", "rendre ceci lisible", "exporter au format HTML" ou souhaite une vue Web raffinée d'un artefact Markdown. Markdown/JSON reste la source canonique ; HTML est une vue générée et révisée.
