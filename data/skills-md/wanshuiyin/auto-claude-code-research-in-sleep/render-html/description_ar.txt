قم بعرض قطعة أثرية ARIS Markdown / JSON (IDEA_REPORT، AUTO_REVIEW، KILL_ARGUMENT، PAPER_PLAN، حالة ويكي البحث، وما إلى ذلك) في عرض HTML بملف واحد مصمم للقراءة البشرية. يتم تحديد مخرجات القالب الأكاديمي من خلال مراجعة Codex جديدة عبر النماذج لضمان دقة العرض + السلامة (ثبات ARIS). يُستخدم عندما يقول المستخدم "HTML"، أو "HTML 报告"، أو "render html"، أو "اجعل هذا قابلاً للقراءة"، أو "export to html"، أو يريد عرضًا مصقولًا معروضًا على الويب لعنصر Markdown. يظل Markdown/JSON هو المصدر الأساسي؛ HTML عبارة عن طريقة عرض تم إنشاؤها ومراجعتها.
