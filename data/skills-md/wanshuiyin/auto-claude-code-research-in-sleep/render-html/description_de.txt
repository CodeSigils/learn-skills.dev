Rendern Sie ein ARIS-Markdown-/JSON-Artefakt (IDEA_REPORT, AUTO_REVIEW, KILL_ARGUMENT, PAPER_PLAN, Research-Wiki-Status usw.) in eine HTML-Einzeldateiansicht, die für das menschliche Lesen konzipiert ist. Akademische Vorlagenausgaben werden durch eine neue modellübergreifende Codex-Überprüfung auf Rendertreue und Sicherheit (die ARIS-Invariante) überprüft. Verwenden Sie diese Option, wenn der Benutzer „HTML anzeigen“, „HTML ändern“, „HTML rendern“, „lesbar machen“, „nach HTML exportieren“ sagt oder eine ausgefeilte, im Web gerenderte Ansicht eines Markdown-Artefakts wünscht. Markdown/JSON bleibt die kanonische Quelle; HTML ist eine generierte, überprüfte Ansicht.
