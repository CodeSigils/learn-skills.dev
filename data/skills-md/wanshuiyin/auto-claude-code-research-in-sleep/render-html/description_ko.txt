ARIS Markdown/JSON 아티팩트(IDEA_REPORT, AUTO_REVIEW, KILL_ARGUMENT, PAPER_PLAN, Research-wiki 상태 등)를 사람이 읽을 수 있도록 설계된 단일 파일 HTML 보기로 렌더링합니다. 학술 템플릿 출력은 렌더링 충실도 + 안전성(ARIS 불변)에 대한 새로운 교차 모델 Codex 검토를 통해 제어됩니다. 사용자가 "渲染 HTML", "udei份 HTML 报告", "html 렌더링", "읽기 가능하게 만들기", "html로 내보내기"라고 말하거나 Markdown 아티팩트의 세련된 웹 렌더링 보기를 원할 때 사용합니다. Markdown/JSON은 표준 소스로 유지됩니다. HTML은 생성되고 검토된 보기입니다.
