Комплексный конвейер выступлений на конференции: бумага → схема слайда → Beamer + PPTX → доработка каждой страницы → проверки достоверности (претензии / цитирование / анонимность) → окончательный экспорт и отчет. По умолчанию подходит для выступлений на академических конференциях (выступления NeurIPS / ICML / ICLR / VALSE / 投稿). Триггерные фразы: «做 разговор», «做 PPT 全流程», «конвейер разговоров», «сквозные слайды», «做演讲», «полный рабочий процесс конференции». Используйте, когда пользователю нужен полный артефакт выступления, а не просто набор слайдов.
