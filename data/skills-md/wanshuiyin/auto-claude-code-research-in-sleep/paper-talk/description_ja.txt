エンドツーエンドのカンファレンス トーク パイプライン: 論文 → スライド アウトライン → Beamer + PPTX → ページごとの磨き → 保証チェック (クレーム / 引用 / 匿名性) → 最終的なエクスポートとレポート。デフォルト - 学会講演 (NeurIPS / ICML / ICLR / VALSE / 投稿講演) に適しています。トリガーフレーズ: 「做トーク」、「做 PPT 全流程」、「トーク パイプライン」、「エンドツーエンド スライド」、「做演讲」、「カンファレンス トーク フル ワークフロー」。ユーザーが単なるスライドデッキではなく、完全なトーク成果物を必要とする場合に使用します。
