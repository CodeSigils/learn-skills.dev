مزامنة ثنائية الاتجاه بين دليل الورق المحلي ومشروع Overleaf عبر جسر Overleaf Git (ميزة مميزة). يتيح لك الاحتفاظ بسير عمل تدقيق/تحرير ARIS على النسخة المحلية بينما يقوم المتعاونون بالتحرير في واجهة مستخدم الويب Overleaf. لا يلمس الرمز المميز الوكيل أبدًا - يقوم المستخدم بالمصادقة لمرة واحدة عبر macOS Keychain. يُستخدم عندما يقول المستخدم "同步 overleaf"، أو "مزامنة overleaf"، أو "推送到 overleaf"، أو "connect overleaf"، أو "overleaf 桥接"، أو "pull overleaf"، أو "push overleaf"، أو يريد ربط دليل ARIS الورقي الخاص به بمشروع Overleaf.
