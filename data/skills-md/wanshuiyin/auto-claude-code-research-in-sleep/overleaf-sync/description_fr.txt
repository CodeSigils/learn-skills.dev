Synchronisation bidirectionnelle entre un répertoire papier local et un projet Overleaf via le pont Overleaf Git (fonctionnalité Premium). Vous permet de conserver les workflows d'audit/modification ARIS sur la copie locale pendant que les collaborateurs modifient dans l'interface utilisateur Web Overleaf. Le jeton ne touche jamais l'agent : l'utilisateur effectue l'authentification unique via le trousseau macOS. À utiliser lorsque l'utilisateur dit "同步 au verso", "overleaf sync", "推送到 au verso", "connect overleaf", "Overleaf 桥接", "pull overleaf", "push overleaf" ou souhaite relier son répertoire papier ARIS avec un projet Overleaf.
