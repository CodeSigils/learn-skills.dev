Overleaf Git ブリッジを介した、ローカルの Paper ディレクトリと Overleaf プロジェクト間の双方向同期 (プレミアム機能)。共同作業者が Overleaf Web UI で編集している間、ARIS 監査/編集ワークフローをローカル コピーに保持できます。トークンがエージェントに接触することはありません。ユーザーは macOS キーチェーンを介して 1 回限りの認証を行います。ユーザーが「オーバーリーフ同步」、「オーバーリーフ同期」、「オーバーリーフへ推送」、「オーバーリーフに接続」、「オーバーリーフ桥接」、「オーバーリーフをプル」、「オーバーリーフをプッシュ」と言う場合、または ARIS 用紙ディレクトリをオーバーリーフ プロジェクトにブリッジしたい場合に使用します。
