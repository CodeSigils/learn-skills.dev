Sincronizzazione bidirezionale tra una directory cartacea locale e un progetto Overleaf tramite il bridge Overleaf Git (funzionalità Premium). Consente di mantenere i flussi di lavoro di controllo/modifica ARIS sulla copia locale mentre i collaboratori modificano nell'interfaccia utente Web sul retro. Il token non tocca mai l'agente: l'utente esegue l'autenticazione una tantum tramite il portachiavi macOS. Da utilizzare quando l'utente dice "同步 overleaf", "sincronizzazione overleaf", "推送到 overleaf", "connect overleaf", "Overleaf 桥接", "pull overleaf", "push overleaf" o desidera collegare la propria directory cartacea ARIS con un progetto Overleaf.
