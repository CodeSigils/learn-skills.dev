Générez une aide-mémoire longue pour la préparation des entretiens en chinois sur un sujet ML/LLM spécifique : formules avec dérivations, code PyTorch à partir de zéro, tableaux de comparaison et 25 高频面试题 (L1 必会 / L2 进阶 / L3 顶级 lab). L'examen du codex inter-modèles vérifie les mathématiques, le code, les citations historiques et la discipline de style ; alors /render-html produit un fichier HTML unique avec un modèle de journal universitaire. Sortie : docs/tutorials/<slug>_tutorial.{md,html,review.json}. À utiliser lorsque l'utilisateur dit « 写面试 aide-mémoire », « 写一份 X 教程 », « 帮我准备 Y 面试题 », « 出一份 X 速查 » ou souhaite un didacticiel chinois de 600 à 1 000 lignes sur un sujet spécifique de ML.
