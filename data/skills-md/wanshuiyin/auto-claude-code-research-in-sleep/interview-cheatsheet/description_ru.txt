Создайте подробную шпаргалку для подготовки к собеседованию на китайском языке по конкретной теме ML/LLM — формулы с выводами, код PyTorch с нуля, сравнительные таблицы и 25 高频面试题 (L1 必会 / L2 进阶 / L3 顶级 лабораторная работа). Межмодельный обзор кодекса проверяет математику, код, исторические цитаты и дисциплину стиля; затем /render-html создает однофайловый HTML-файл с шаблоном академической газеты. Вывод: docs/tutorials/<slug>_tutorial.{md,html,review.json}. Используйте, когда пользователь произносит «Шпаргалка по 写面试», «写一份 X 教程», «帮我准备 Y 面试题», «出一份 X 速查» или хочет получить руководство по китайскому языку на 600–1000 строк по определенной теме машинного обучения.
