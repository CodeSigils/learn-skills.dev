Рабочий процесс 5: организуйте повторную отправку только текста доработанной статьи в другое место с жесткими ограничениями (никаких новых экспериментов, никаких правок нагрудника, никаких изменений структуры, никогда не перезаписывайте предыдущие отправленные материалы). Физическая изоляция фазы 0, фаза 0,5 проверки работоспособности + анонимности, проверка фазы 1 (доказательство / утверждение / цитирование), микроредактирование фазы 2 через автоматический цикл с редактированием белого списка + аудит цитирования --soft-only, состязательный шлюз фазы 3 уничтожения аргументов, окончательная компиляция фазы 4 + передача Overleaf через /overleaf-sync. Используйте, когда пользователь говорит «повторно отправить документ», «重投流程», «перенести бумагу в <новое место>», «повторно отправить в <место>», «сократить бумагу для повторной подачи» или если у него есть отклоненная/отозванная статья для перемещения в другое главное место в условиях ограниченного бюджета.
