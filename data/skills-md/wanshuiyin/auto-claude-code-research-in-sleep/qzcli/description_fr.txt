Gérez les tâches de calcul GPU sur la plate-forme Qizhi (启智) à l'aide de qzcli, un outil CLI de style kubectl. À utiliser lorsque l'utilisateur dit « qzcli », « 启智平台 », « soumettre la tâche », « arrêter la tâche », « 查计算组 », « disponible », « lister les tâches », « soumettre par lots » ou doit gérer des tâches de formation distribuées sur une instance Qizhi.
