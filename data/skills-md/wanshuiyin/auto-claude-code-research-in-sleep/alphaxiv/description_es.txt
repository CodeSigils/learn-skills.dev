Búsqueda rápida de un solo documento a través de resúmenes optimizados por AlphaXiv LLM con respaldo de fuentes escalonadas. Utilícelo cuando el usuario diga "explicar este artículo", "resumir el artículo", pegue una URL de arXiv/AlphaXiv o proporcione un ID de arXiv simple para una comprensión rápida, no para una búsqueda bibliográfica amplia.
