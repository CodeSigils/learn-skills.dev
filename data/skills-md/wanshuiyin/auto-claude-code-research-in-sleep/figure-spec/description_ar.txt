قم بإنشاء بنية محددة لجودة النشر وسير العمل ومخططات خطوط الأنابيب من JSON (FigarSpec) المنظمة إلى SVG قابل للتحرير. يُستخدم عندما يقول المستخدم "架构图"، أو "workflow 图"، أو "pipeline 图"، أو "确定性矢量图"، أو "مواصفات الشكل"، أو "رسم البنية"، أو يحتاج إلى مخططات متجهة دقيقة وقابلة للتحرير وجاهزة للنشر. يُفضل على الرسم التوضيحي بالذكاء الاصطناعي لأشكال الهندسة المعمارية/سير العمل الرسمية.
