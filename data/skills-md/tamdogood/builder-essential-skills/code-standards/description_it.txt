Applica un flusso di lavoro ingegneristico disciplinato a qualsiasi modifica del codice. Da utilizzare ogni volta che si implementa una funzionalità, si corregge un bug o si esegue il refactoring, prima di scrivere il codice, non dopo. Cammina orienta → linea di base → modifica più piccola → test → verifica → auto-revisione e applica controlli rigidi indipendenti dalla lingua (non riformattare in massa, mantenere puliti il ​​linter e il controllo del tipo, mantenere la build e i test verdi, apportare modifiche all'interfaccia aggiuntive, proteggere le invarianti di sicurezza).
