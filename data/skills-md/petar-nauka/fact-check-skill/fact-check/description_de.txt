Halbautomatische Faktenprüfung, Bewertung der Glaubwürdigkeit der Quelle, Erkennung von Fehlinformationen, Prebunking und Beweismittel-basierte Anspruchsüberprüfung. Wird verwendet, wenn ein Benutzer eine Behauptung, einen Artikel, einen Social-Media-Beitrag, einen Screenshot, eine URL, ein Zitat oder einen Datenpunkt überprüfen, Quellen vergleichen, Manipulationen erkennen, die Zuverlässigkeit der Quelle bewerten oder eine HTML-Faktenprüfkarte/Share-Safe-Korrektur erstellen möchte. Unterstützt Text, URLs, Screenshots/Bilder, Zwei-Quellen-Vergleich und themenspezifisches Prebunking in Bulgarisch, Englisch, Russisch, EU-Politik, Gesundheit, Wissenschaft und geopolitischen Kontexten. Auslöserphrasen: „Ist das wahr?“, „Ist das eine Fälschung?“, „Überprüfen Sie die Fakten“, „Vergleichen Sie diese Quellen“, „Überprüfen Sie die Fakten“, „Es gibt keine Informationen“, „Es gibt keine Informationen“, „Überprüfen Sie die Fakten“.
