Verwenden Sie dies, bevor Sie Abhängigkeiten hinzufügen, generische Komponenten oder Dienstprogrammfunktionen manuell erstellen und bevor Sie Tests hinzufügen, ändern oder löschen – einschließlich Tests, die Sie selbst hinzufügen möchten. Die Standardantwort besteht darin, sie wiederzuverwenden statt zu erstellen und keine Tests hinzuzufügen, sondern sie hinzuzufügen. Es bietet eine fünfstufige Entscheidungsleiter, die die Wiederverwendung priorisiert, vier Szenarien, in denen sich das Schreiben von Tests lohnt, dreizehn Testschreibmuster, die vermieden werden müssen, und was als Verifizierung gilt, wenn Sie keine Tests schreiben. Anwendbar auf jedes Repository.
