Verwenden Sie dies, bevor Sie Abhängigkeiten hinzufügen, generische Komponenten oder Dienstprogrammfunktionen manuell erstellen und bevor Sie Tests hinzufügen, ändern oder löschen – einschließlich Tests, die Sie persönlich hinzufügen möchten. Die Standardantwort besteht darin, sie wiederzuverwenden statt zu erstellen und das Hinzufügen von Tests zu vermeiden, anstatt sie hinzuzufügen. Es umfasst eine fünfstufige Entscheidungsleiter, die die Wiederverwendung priorisiert, vier Situationen, in denen sich das Schreiben von Tests lohnt, dreizehn Testmuster, die vermieden werden müssen, und was als Verifizierung gilt, wenn Sie keine Tests schreiben. Anwendbar auf jedes Repository.
