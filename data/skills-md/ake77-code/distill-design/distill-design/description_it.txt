Distilla un DESIGN.md da un sito web: esegui la scansione e analizza il design renderizzato di un sito (colori, tipografia, spaziatura, componenti, motivi della firma) e produci una specifica del sistema di progettazione DESIGN.md accurata del marchio. Su richiesta, genera anche una pagina di anteprima del token (preview.html) o una demo realistica del sito web (demo.html). Da utilizzare quando l'utente fornisce un URL e chiede di "creare/generare un DESIGN.md", "estrarre il sistema di progettazione di questo sito", "catturare il linguaggio visivo di un marchio" o "trasformare questo sito Web in token di progettazione".
