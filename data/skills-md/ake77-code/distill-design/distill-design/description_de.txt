Destillieren Sie ein DESIGN.md aus einer Website – crawlen und analysieren Sie das gerenderte Design einer Website (Farben, Typografie, Abstände, Komponenten, Signaturmotive) und erstellen Sie eine markengenaue DESIGN.md-Designsystemspezifikation. Generieren Sie auf Wunsch auch eine Token-Vorschauseite (preview.html) oder eine realistische Website-Demo (demo.html). Wird verwendet, wenn der Benutzer eine URL angibt und darum bittet, „ein DESIGN.md zu erstellen/generieren“, „das Designsystem dieser Website zu extrahieren“, „die visuelle Sprache einer Marke zu erfassen“ oder „diese Website in Design-Tokens umzuwandeln“.
