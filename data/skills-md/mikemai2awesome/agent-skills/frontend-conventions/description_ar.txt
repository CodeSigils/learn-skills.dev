تحديد وتنفيذ معايير الترميز المتسقة عبر HTML وCSS وJavaScript. استخدم هذه المهارة دائمًا عند تسمية فئة أو متغير أو مكون أو ملف جديد؛ وضع اتفاقيات مشروع جديد؛ اختيار بادئة فئة لفئة CSS جديدة؛ تحديد أسماء واجهة برمجة التطبيقات المعدلة (الأحجام، والظلال، والتسلسل الهرمي، ونقاط التوقف)؛ أو مراجعة التعليمات البرمجية للتنسيق واتساق التسمية. إذا كنت على وشك اختراع بادئة أو اختصار أو اسم معدّل دون التحقق من الاصطلاحات أولاً، فاستخدم هذه المهارة.
