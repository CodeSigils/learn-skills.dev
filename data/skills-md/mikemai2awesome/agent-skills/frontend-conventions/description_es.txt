Defina y aplique estándares de codificación consistentes en HTML, CSS y JavaScript. Utilice siempre esta habilidad al nombrar una nueva clase, variable, componente o archivo; establecer las convenciones de un nuevo proyecto; elegir un prefijo de clase para una nueva categoría CSS; decidir los nombres de las API modificadoras (tamaños, tonos, jerarquía, puntos de interrupción); o revisar el código para verificar la coherencia del formato y los nombres. Si está a punto de inventar un prefijo, una abreviatura o un nombre modificador sin comprobar primero las convenciones, utilice esta habilidad.
