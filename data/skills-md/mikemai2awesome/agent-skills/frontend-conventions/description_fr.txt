Définissez et appliquez des normes de codage cohérentes entre HTML, CSS et JavaScript. Utilisez toujours cette compétence lorsque vous nommez une nouvelle classe, variable, composant ou fichier ; mettre en place les conventions d'un nouveau projet ; choisir un préfixe de classe pour une nouvelle catégorie CSS ; décider des noms d'API des modificateurs (tailles, nuances, hiérarchie, points d'arrêt) ; ou vérifier le code pour vérifier la cohérence du formatage et des noms. Si vous êtes sur le point d'inventer un préfixe, une abréviation ou un nom de modificateur sans vérifier au préalable les conventions, utilisez cette compétence.
