Пишите масштабируемый, хорошо спроектированный CSS, используя токены дизайна, каскадные слои и современные организационные шаблоны. Используйте этот навык по умолчанию для любого реального проекта — если в нем больше нескольких файлов CSS, несколько компонентов, команда, система дизайна или какие-либо настройки токенов или тем, это правильный навык. Используйте tiny-css только тогда, когда проект явно небольшой или минималистичный (личные сайты, прототипы, простые целевые страницы).
