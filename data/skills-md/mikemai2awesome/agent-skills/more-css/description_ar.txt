قم بكتابة CSS قابلة للتطوير ومصممة بشكل جيد باستخدام رموز التصميم والطبقات المتتالية وأنماط التنظيم الحديثة. استخدم هذه المهارة كإعداد افتراضي لأي مشروع حقيقي - إذا كان يحتوي على أكثر من مجموعة من ملفات CSS، أو مكونات متعددة، أو فريق، أو نظام تصميم، أو أي نوع من الرموز المميزة أو إعداد السمات، فهذه هي المهارة الصحيحة. قم بالتأجيل إلى tiny-css فقط عندما يكون المشروع صغيرًا أو بسيطًا بشكل واضح (المواقع الشخصية، النماذج الأولية، الصفحات المقصودة البسيطة).
