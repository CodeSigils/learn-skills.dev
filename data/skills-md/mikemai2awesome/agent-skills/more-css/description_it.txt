Scrivi CSS scalabili e ben architettati utilizzando token di progettazione, livelli a cascata e modelli organizzativi moderni. Usa questa competenza come predefinita per qualsiasi progetto reale: se ha più di una manciata di file CSS, più componenti, un team, un sistema di progettazione o qualsiasi tipo di impostazione di token o temi, questa è la competenza giusta. Rimanda a tiny-css solo quando il progetto è esplicitamente piccolo o minimalista (siti personali, prototipi, semplici pagine di destinazione).
