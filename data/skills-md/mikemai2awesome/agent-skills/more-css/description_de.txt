Schreiben Sie skalierbares, gut strukturiertes CSS mit Design-Tokens, Kaskadenebenen und modernen Organisationsmustern. Verwenden Sie diese Fähigkeit als Standard für jedes reale Projekt – wenn es mehr als eine Handvoll CSS-Dateien, mehrere Komponenten, ein Team, ein Designsystem oder irgendeine Art von Token- oder Design-Setup enthält, ist dies die richtige Fähigkeit. Verlassen Sie sich nur dann auf Tiny-CSS, wenn das Projekt ausdrücklich klein oder minimalistisch ist (persönliche Websites, Prototypen, einfache Zielseiten).
