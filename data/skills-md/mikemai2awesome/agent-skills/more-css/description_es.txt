Escriba CSS escalable y bien diseñado utilizando tokens de diseño, capas en cascada y patrones de organización modernos. Utilice esta habilidad como predeterminada para cualquier proyecto real: si tiene más de un puñado de archivos CSS, múltiples componentes, un equipo, un sistema de diseño o cualquier tipo de token o configuración temática, esta es la habilidad correcta. Solo opte por tiny-css cuando el proyecto sea explícitamente pequeño o minimalista (sitios personales, prototipos, páginas de destino simples).
