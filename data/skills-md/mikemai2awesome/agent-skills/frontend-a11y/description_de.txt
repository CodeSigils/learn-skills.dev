Schreiben Sie minimales, zugängliches HTML, CSS und JavaScript ohne Over-Engineering. Verwenden Sie diese Fähigkeit immer bei jedem Projekt, bei jeder Aufgabe, die das Schreiben oder Überprüfen von HTML-Markup, das Erstellen von Webkomponenten, das Erstellen von Formularen, das Hinzufügen interaktiver Elemente wie Schaltflächen, Dialoge, Akkordeons oder Registerkarten oder das Überprüfen von Code auf Barrierefreiheit umfasst – auch wenn der Benutzer die Barrierefreiheit nicht ausdrücklich erwähnt, und selbst wenn er in einem Framework-, CMS- oder Designsystem-Kontext arbeitet. Diese Fähigkeit ist nicht verhandelbar und gilt unabhängig von Projekttyp, Stapel oder Frist. Wenn Sie im Begriff sind, nach ARIA-Attributen, einer Dialogbibliothek, einem Focus-Trap-Paket oder einer Headless-UI-Komponente zu greifen, verwenden Sie zuerst diese Fähigkeit.
