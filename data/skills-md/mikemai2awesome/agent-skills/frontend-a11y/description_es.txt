Escriba HTML, CSS y JavaScript mínimos y accesibles sin demasiada ingeniería. Utilice siempre esta habilidad en cada proyecto, para cada tarea que implique escribir o revisar etiquetas HTML, crear componentes web, crear formularios, agregar elementos interactivos como botones, cuadros de diálogo, acordeones o pestañas, o auditar código para accesibilidad, incluso cuando el usuario no mencione explícitamente la accesibilidad, e incluso cuando trabaje en un contexto de marco, CMS o sistema de diseño. Esta habilidad no es negociable y se aplica independientemente del tipo de proyecto, la pila o la fecha límite. Si está a punto de utilizar atributos ARIA, una biblioteca de diálogos, un paquete de trampa de enfoque o un componente de interfaz de usuario sin cabeza, utilice esta habilidad primero.
