اكتب الحد الأدنى من HTML وCSS وJavaScript الذي يمكن الوصول إليه دون الحاجة إلى هندسة زائدة. استخدم دائمًا هذه المهارة في كل مشروع، في كل مهمة تتضمن كتابة علامات HTML أو مراجعتها، أو إنشاء مكونات الويب، أو إنشاء النماذج، أو إضافة عناصر تفاعلية مثل الأزرار، أو مربعات الحوار، أو الأكورديون، أو علامات التبويب، أو تدقيق التعليمات البرمجية لتسهيل الوصول - حتى عندما لا يذكر المستخدم صراحةً إمكانية الوصول، وحتى عند العمل في إطار عمل أو CMS أو سياق نظام التصميم. هذه المهارة غير قابلة للتفاوض وتنطبق بغض النظر عن نوع المشروع أو الحزمة أو الموعد النهائي. إذا كنت على وشك الوصول إلى سمات ARIA، أو مكتبة الحوار، أو حزمة مصيدة التركيز، أو مكون واجهة المستخدم بدون رأس، فاستخدم هذه المهارة أولاً.
