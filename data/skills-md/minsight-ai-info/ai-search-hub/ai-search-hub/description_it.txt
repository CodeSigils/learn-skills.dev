Esegui gli script di automazione del browser AI Search Hub per Yuanbao, LongCat, Doubao, Qwen, Gemini, Grok e MiniMax. Utilizza questa abilità quando l'utente desidera chiedere a uno di questi siti un prompt, avviarsi automaticamente o collegarsi a una sessione di Chrome DevTools sulla porta 9222, eseguire il seeding di un profilo del browser di debug isolato dai dati del browser locale dell'utente, rilevare se è richiesto l'accesso, attendere che l'utente termini l'accesso, se necessario, e quindi continuare automaticamente.
