Exécutez les scripts d'automatisation du navigateur AI Search Hub pour Yuanbao, LongCat, Doubao, Qwen, Gemini, Grok et MiniMax. Utilisez cette compétence lorsque l'utilisateur souhaite demander à l'un de ces sites une invite, un démarrage automatique ou une connexion à une session Chrome DevTools sur le port 9222, créer un profil de navigateur de débogage isolé à partir des données du navigateur local de l'utilisateur, détecter si une connexion est requise, attendre que l'utilisateur ait fini de se connecter si nécessaire, puis continuer automatiquement.
