Apifox による API ドキュメントとデータ モデルの双方向同期。サポート: 1) Apifox から OpenAPI 仕様をエクスポートし、Java Spring Boot コード (コントローラー、DTO、エンティティ) を生成します。 2) ローカル Java コード (注釈またはマニュアルの説明) を解析し、Apifox にインポートして API/データ モデルを更新します。 3) ディレクトリをバッチスキャンして複数のコントローラーを同期します。 4) 変更された API のみを更新する増分同期。ユーザーが「Apifox から API を取得する」、「API コードを生成する」、「Apifox に同期する」、「Apifox に API をアップロードする」、「Apifox ドキュメントを更新する」、または「バッチ同期」について言及した場合は、このスキルを使用します。
