Двунаправленная синхронизация документации API и моделей данных с Apifox. Поддерживает: 1) Экспорт спецификаций OpenAPI из Apifox и создание кода загрузки Java Spring (контроллер, DTO, сущность); 2) Анализировать локальный код Java (аннотации или описания руководства) и импортировать в Apifox для обновления API/моделей данных; 3) Пакетное сканирование каталогов для синхронизации нескольких контроллеров; 4) Дополнительная синхронизация, которая обновляет только измененные API. Когда пользователь упоминает «получить API из Apifox», «сгенерировать код API», «синхронизировать с Apifox», «загрузить API в Apifox», «обновить документацию Apifox» или «пакетную синхронизацию», используйте этот навык.
