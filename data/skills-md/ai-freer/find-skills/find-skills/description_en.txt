A unified entry point for searching and installing external skills. Dual-source parallel search: skills.sh (primary source, large ecosystem) + ClawHub (supplementary source, OpenClaw customized). Use it in the following situations: (1) the user requests to search, look up, or discover a new skill; (2) the user requests to install an external skill; (3) the current skill cannot meet the need and requires capability expansion; (4) the user mentions “find skill”, “搜 skill”, or “有没有 xxx 的 skill”.
