A unified portal to search for and install external Skills. Dual-source parallel search: skills.sh (primary source, large ecosystem) + ClawHub (supplementary source, OpenClaw custom).

Use when:
(1) The user asks to search, find, or discover a new skill
(2) The user asks to install an external skill
(3) The current skills cannot meet the requirement and an extension is needed
(4) The user mentions "find skill", "搜 skill", or "有没有 xxx 的 skill"
