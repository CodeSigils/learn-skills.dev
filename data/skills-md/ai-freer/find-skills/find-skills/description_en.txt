A unified portal for searching and installing external Skills. Dual-source parallel search: skills.sh (primary source, large ecosystem) + ClawHub (supplementary source, OpenClaw customization).
Use when:
(1) The user asks to search, find, or discover a new skill
(2) The user requests to install an external skill
(3) Existing skills cannot meet the requirements and capability expansion is needed
(4) The user mentions "find skill", "搜 skill", or "有没有 xxx 的 skill"
