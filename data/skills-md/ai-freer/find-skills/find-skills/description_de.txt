Ein einheitlicher Einstiegspunkt für die Suche und Installation externer Fähigkeiten. Parallele Suche mit zwei Quellen: skills.sh (primäre Quelle, großes Ökosystem) + ClawHub (ergänzende Quelle, OpenClaw angepasst). Verwenden Sie es in den folgenden Situationen: (1) Der Benutzer möchte eine neue Fähigkeit suchen, nachschlagen oder entdecken; (2) der Benutzer fordert die Installation eines externen Skills an; (3) die aktuelle Fähigkeit kann den Bedarf nicht decken und erfordert eine Erweiterung der Fähigkeiten; (4) Der Benutzer erwähnt „Find Skill“, „搜 Skill“ oder „有没有 xxx 的 Skill“.
