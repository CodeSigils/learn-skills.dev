Un portal unificado para buscar e instalar Skills externos. Búsqueda paralela de fuente dual: skills.sh (fuente principal, ecosistema grande) + ClawHub (fuente complementaria, OpenClaw personalizado).

Úselo cuando:
(1) El usuario solicita buscar, encontrar o descubrir una nueva habilidad.
(2) El usuario solicita instalar una habilidad externa
(3) Las habilidades actuales no pueden cumplir con el requisito y se necesita una extensión.
(4) El usuario menciona "buscar habilidad", "搜 habilidad" o "有没有 xxx 的 habilidad"
