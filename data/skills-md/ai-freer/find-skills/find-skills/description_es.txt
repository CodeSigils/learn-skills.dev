Un portal unificado para buscar e instalar Skills externas. Búsqueda paralela de fuente dual: skills.sh (fuente principal, ecosistema grande) + ClawHub (fuente complementaria, personalización de OpenClaw).
Úselo cuando:
(1) El usuario solicita buscar, encontrar o descubrir una nueva habilidad.
(2) El usuario solicita instalar una habilidad externa
(3) Las habilidades existentes no pueden cumplir con los requisitos y se necesita expansión de capacidades.
(4) El usuario menciona "buscar habilidad", "搜 habilidad" o "有没有 xxx 的 habilidad"
