Универсальные стандарты проекта для каждого репозитория SolidStats (сервер-2, сборщик повторов, анализатор повторов-2, Интернет, инфраструктура). Охватывает обязательства рабочего процесса GSD, гигиену сеансов, соглашения git, карту границ между приложениями (то, что принадлежит каждому репозиторию и не должно пересекаться), протокол совместимости между приложениями, минимальные требования безопасности, управление рисками и язык документации. Используйте это заранее — читайте в начале любой задачи в любом репозитории SolidStats, даже если в задаче не упоминается ни одна из этих тем. Это общая базовая линия, которую принимают все остальные навыки SolidStats. Чрезмерное срабатывание допустимо. Триггеры: любая задача в репозитории SolidStats, начало рабочего сеанса, коммиты git, изменения между репозиториями, решения по архитектуре, планирование сеанса перед любой реализацией, Kubernetes, развертывание, промежуточное размещение, инфраструктура. Триггеры: любая задача в репо SolidStats, начало рабочей сессии, git коммиты, изменения под влиянием других репо, архитектурные решения, планирование, перед любой реализацией, Kubernetes, деплой, стейджинг, инфраструктура.
