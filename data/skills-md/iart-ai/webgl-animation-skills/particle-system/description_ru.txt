Этот навык следует использовать, когда пользователь просит «создать систему частиц», «сделать конфетти/снег/дым/искры», «создать сетевой фон из связанных точек/созвездий», «добавить поле потока или эффект частиц скручивающегося шума», «отобразить тысячи частиц графического процессора с помощью Three.js Points» или «анимировать излучатели с помощью сил». Охватывает интеграцию по частицам, силы, поля потока, пакетное/непрерывное излучение, точки, связанные с пространственной сеткой, а также точки графического процессора + шейдеры.
