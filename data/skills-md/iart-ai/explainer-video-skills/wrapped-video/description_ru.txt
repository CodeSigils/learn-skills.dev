Этот навык следует использовать, когда пользователь просит «сделать видео в стиле Spotify Wrapped», «создать видео с обзором за год / обзором за год», «создать видео с персонализированными данными», «создать видео с обзором», «создать генератор обернутого видео», «превратить таблицу данных в видеоролики для совместного использования» или «создать видео со статистикой для каждого пользователя». Охватывает строку данных → один шаблон видео, которым можно поделиться, грамматику завернутой сцены (отображение больших чисел, списки топ-X, превосходная степень), анимированные счетчики данных, вертикальное кадрирование 9:16 и пакетный рендеринг множества персонализированных видео из одного шаблона.
