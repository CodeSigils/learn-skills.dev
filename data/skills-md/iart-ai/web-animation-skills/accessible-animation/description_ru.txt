Этот навык следует использовать, когда пользователь просит «соблюдать предпочтение уменьшенного движения», «соблюдать уменьшенное движение», «сделать мои анимации доступными», «исправить вестибулярные проблемы/проблемы с укачиванием», «добавить хук useReducedMotion», «закрыть GSAP/Framer Motion/Lenis для уменьшения движения» или «соответствовать WCAG 2.3.3/C39». Предоставляет многоуровневые (не по принципу «все или ничего») шаблоны с уменьшенным движением в CSS и JS.
