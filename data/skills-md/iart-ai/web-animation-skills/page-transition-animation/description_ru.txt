Этот навык следует использовать, когда пользователь просит «анимировать переходы страниц или маршрутов», «добавить переход страниц или плавное затухание между представлениями», «анимировать изменения маршрута в маршрутизаторе приложений Next.js», «использовать View Transitions API», «Выход AnimatePresence не срабатывает при навигации» или «Анимация выхода Framer Motion не работает/выйти из анимации перед размонтированием в Next.js». Охватывает анимацию перехода страниц при входе и выходе с помощью API View Transitions и Framer Motion для маршрутизатора приложений Next.js и общей маршрутизации SPA.
