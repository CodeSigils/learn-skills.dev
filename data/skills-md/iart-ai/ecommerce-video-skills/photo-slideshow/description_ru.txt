Этот навык следует использовать, когда пользователь просит «сделать слайд-шоу из фотографий», «превратить фотографии в видео», «создать видео для фотомонтажа», «сделать слайд-шоу из изображений с музыкой», «создать видео из фотографий/воспоминаний», «добавить панорамирование/масштабирование Кена Бернса к фотографиям», «синхронизировать изменения слайдов с музыкальным ритмом» или «рендеринг видео из папки изображений». Охватывает движение Кена Бернса для каждой фотографии, переходы, синхронизацию ритма, обработку смешанного соотношения сторон, подписи/даты, вступительные/заключительные карточки и создание шаблонов папки с фотографиями в готовом видео.
