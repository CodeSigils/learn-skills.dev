Этот навык следует использовать, когда пользователь просит «сделать видео с фальшивым текстовым сообщением», «анимировать разговор в iMessage», «создать видео с текстовой историей», «сделать анимацию ответа в чате», «видео разговора в WhatsApp/SMS», «анимацию индикатора набора текста», «преобразовать ветку чата в видео» или «пакетную обработку видео текстовых сообщений из сценария/CSV». Охватывает пузырьковый макет отправленных/полученных сообщений, шахматное отображение времени с индикаторами набора текста, уведомления о прочтении/временные метки, синхронизацию всплывающего звука для каждого сообщения, безопасную зону 9:16 и рендеринг на основе данных из массива сообщений.
