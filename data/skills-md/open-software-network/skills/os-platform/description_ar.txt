الاستعلام المباشر عن بيانات إنتاج النظام الأساسي للبرامج المفتوحة من خلال واجهة برمجة تطبيقات النظام الأساسي. يُستخدم عندما يحتاج الوكيل إلى الإصدارات/المنح الحالية أو المؤسسات أو المشاريع أو التقديمات أو التعليقات أو النشاط أو المساهمين أو حالة واجهة برمجة التطبيقات (API) بدلاً من فحص ملفات الريبو أو التركيبات أو لقطات الشاشة أو المستندات التي لا معنى لها.
